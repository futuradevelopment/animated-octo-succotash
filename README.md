# ErrHive Cars

Automotive diagnostic-code reference for https://cars.errhive.com, adapted from the ErrHive Astro application in futuradevelopment/improved-giggle.

The launch build targets at least 10,000 distinct code reference articles, with source provenance, generic/manufacturer scope, and separately evidenced vehicle-model guidance. Shared definitions use one canonical article; model and brand combinations are not generated without supporting evidence.

Implementation and source validation are in progress. Deployment target: Cloudflare Pages, repository root, `npm run build`, output `dist`, Node 24.

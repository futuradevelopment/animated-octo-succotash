# Manufacturer model evidence

Reviewed 2026-10-30. The repository contains **32 authored guides across 20 makes**, **46 model hubs**, **26 scoped bulletin records**, and **72 manufacturer source records**. The 11,786 dictionary entries are counted separately.

Each authored guide has its own diagnostic decision, exact vehicle or engine scope and primary-source citations. Shared Chevrolet/GMC conditions use one article with explicit make/model associations. Engine-only evidence remains engine-scoped rather than generating unsupported model pages. Model hubs link the relevant guides directly.

The October 30 expansion adds 30 individually written guides. Five research groups opened manufacturer bulletins, service communications and owner manuals; an independent pass checked the main conditional branches against the originals. Source-derived prose budgets include existing companion metadata. Detailed procedure summaries are linked from concise bulletin records rather than duplicated there. This review is document research, not independent mechanical testing.

The revision review corrected existing BMW application metadata and outdated Ram bulletin scope, and retained superseded documents only where explicitly identified as history. Broad manufacturer documents are not automatically assigned to all models. A code alias used for navigation never expands the article's vehicle scope.

## Publication checks

Source and model references resolve before build. The validator rejects copied diagnostic bodies with changed titles/codes, unsupported cross-make model associations and broken bulletin-to-guide links. The static audit verifies each guide's visible sections, scope, Article markup, sources, canonical URL and internal links. Browser checks cover guide filtering, no-JavaScript discovery, representative new articles and shared-make navigation.

See [source inventory](RESEARCH_SOURCES.md), [authored guide catalog](AUTHORED_GUIDES.md) and [content standard](CONTENT_STANDARD.md). All dates describe the reviewed documents; a workshop must still select current VIN-specific instructions. No traffic or indexing result is established by publication.

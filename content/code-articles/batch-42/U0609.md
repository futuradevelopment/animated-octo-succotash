# U0609: Ford's MAP communication code includes several SENT failure paths

U0609 has a generic manifold-absolute-pressure/barometric-pressure sensor communication title. Ford's diesel summary identifies the relevant example as MAP sensor A using a SENT digital link. That scope should be retained instead of assuming that every vehicle implements the code through the same physical sensor arrangement.

## Several digital failure observations share the code

Ford lists a low-level SENT driver communication error, SENT data stuck low, or an internal SENT sensor error as alternative conditions. The result is therefore broader than a missing message alone. An internal sensor report can reach the same communication category without proving that a connector was disconnected.

The monitor group runs continuously, requires no preceding monitor sequence and has a five-second monitoring duration. The summary does not give a universal missing-message count, pulse-width tolerance or connector voltage threshold for this code. Those details must come from the exact diagnostic implementation.

## Distinguish link validity from pressure interpretation

The source separately lists P0105 with sensor status and data-threshold criteria. That separation prevents an unavailable or faulted digital link from being treated as unquestionable evidence of an unusual intake pressure. U0609 also does not automatically mean that the vehicle's CAN bus or a separate control module has failed.

Diagnosis should retain the complete code, the installed MAP sensor configuration and related electrical findings. Verification establishes reliable SENT communication and valid sensor status through the appropriate check. A plausible pressure display after the event or a fault-memory clear does not explain which of the listed failure paths occurred. The monitor summary supplies no basis for replacing a particular pressure sensor, module or intake component without the vehicle-specific assessment.

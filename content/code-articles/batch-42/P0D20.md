# P0D20: Ford's charger output-performance check evaluates delivered power

P0D20 is labeled battery-charger output-voltage performance, but Ford's documented failure description evaluates output power. The distinction prevents a reader from assuming that the code alone proves one specific voltage limit has been exceeded or that the external charging supply is necessarily defective.

## The charger must be in its active power-conversion state

Ford's entry requires the charger to be active, connected to the charging equipment, with its internal S2 state closed and utility AC present at the charger input. The summary lists a 30 second monitoring duration and describes a failure when high-voltage output power is below the expected output power. It does not publish a universal numerical deficit or a connector-level voltage test for this code.

The architecture explains that the charger receives requests from the battery controller and returns internal voltage and current measurements over the hybrid CAN network. Expected output and reported delivery therefore belong to a coordinated control sequence, not simply to a dashboard state-of-charge display.

## Separate controlled shutdown from failed performance

Ford also describes circumstances in which charging is intentionally stopped or changed, including the charge-connector release request and completion of high-voltage charging. Those commanded state changes must not be treated automatically as a failure to deliver expected power.

Useful diagnostic evidence includes charging state, requested output, measured output and associated controller or communication faults. The OBD summary does not determine which component caused a shortfall and is not a high-voltage test procedure. Appropriate verification confirms the applicable charging checks under approved conditions; a brief increase in battery percentage or a cleared code alone does not establish that the monitored performance discrepancy is resolved.

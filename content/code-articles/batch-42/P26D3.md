# P26D3: Ford infers a coolant-pump supply problem from lost communication and rising temperature

Ford's detailed P26D3 description uses an inference. When the PCM loses communication with the electric coolant pump and coolant temperature continues increasing, it identifies a possible pump supply-voltage-circuit problem. The code does not represent a direct measurement of an open power wire.

## The temperature trend separates two outcomes

The specific monitor requires the U019F LIN communication fault together with an accumulated engine-coolant temperature increase above 10°C. Its table lists five seconds to register the fault. Ford explains that, without the temperature increase, the PCM identifies the communication fault alone.

That distinction gives the temperature history practical importance. Two vehicles showing the same missing pump communication need not receive the same accompanying code if their recorded thermal behavior differs. A present temperature value without its accumulated change does not reconstruct the monitor's decision.

## The source contains an overview inconsistency

An introductory paragraph describes pump power and ground faults as information communicated by the pump controller. The later, explicitly coded P26D3 section instead states that those line states are not communicated and explains the PCM inference. This article follows that detailed section and preserves the conflict rather than claiming a verified direct supply measurement.

The supported diagnostic direction is to evaluate power, ground and the communication path using the applicable vehicle procedure, while retaining the temperature trend that contributed to the code. It is not sufficient to assume the pump has been electrically proven dead. Successful verification must account for restored valid communication and appropriate cooling behavior; erasing the code or observing a cooler engine after a rest does not test the original combination.

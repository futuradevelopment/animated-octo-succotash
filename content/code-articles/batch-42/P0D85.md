# P0D85: Ford's charger output stays above its requested voltage

Ford's P0D85 monitor identifies charging output voltage that remains too far above the requested value. The documented criterion is relative: the battery-charger control module's output is compared with the charging-voltage request. It is not simply a universal high pack-voltage limit.

## The requested value is part of the evidence

The source gives an output excess greater than 20.82 volts for 20 seconds. A diagnosis therefore needs both the reported output and the contemporaneous request. An absolute voltage display, without the command it should follow, cannot reconstruct this particular decision.

The timing also matters. A short difference during a transition is not automatically the same as the sustained excess defined by this monitor. The summary does not provide a service method for deliberately creating that condition, and its numerical limit is specific to the documented calibration example.

## Separate charger tracking from battery-state limits

Ford describes other codes for high battery state of charge, high cell voltage and general battery-voltage performance. P0D85 instead focuses on how the charger output follows its request. Related battery findings may explain the broader event, but the code does not by itself select the charger, battery controller or voltage sensor as the proven failed component.

Useful records preserve charge state, voltage request, measured output and any communication or sensing faults. Appropriate verification follows the exact vehicle's approved charging procedure and confirms that output tracks the request over the relevant operating sequence. A lower battery percentage later, a normal mains connection or the disappearance of the code immediately after clearing is insufficient evidence that this timed output-versus-command discrepancy has been corrected.

# C0567: Ford's brake-booster solenoid low-circuit observation

Ford uses C0567 for a low-circuit result associated with the brake-booster solenoid. In the documented hybrid brake arrangement, the solenoid belongs to the actuation system that helps coordinate friction braking with regenerative braking. It should not be confused with the separately controlled electric vacuum pump.

## Driver state gives the voltage observation meaning

The specific C0567 entry calls for ignition on with both the high-side and low-side booster drivers commanded off. Ford describes a monitored supply below 3.0 volts for 380 milliseconds as the failure observation. That is an internal diagnostic condition in this source; it is not a universal expected reading at an unidentified connector pin.

The entry table also lists accompanying ABS pump-motor fault categories. Those relationships make a complete scan record valuable. Treating every displayed code as an independent failed component would lose information about how the brake controller organizes the event.

## Keep circuit classification separate from booster function

C0569 is Ford's separate performance check, using defined driver states and a test pulse. A C0567 low-circuit report alone does not establish how much vacuum assistance is available or whether the solenoid can meet every commanded operating condition. The two observations answer different questions.

For PHEV OBD reporting, Ford maps the brake module's C0022 solenoid family into more specific codes reported by the hybrid powertrain controller. Capturing the reporting module and subtype can therefore preserve distinctions that a shortened code description hides.

Diagnosis and final brake verification belong to the applicable professional service procedure. A cleared fault, normal pedal feel during a brief observation or an unrelated vacuum-pump sound does not demonstrate that this solenoid circuit has passed its defined check.

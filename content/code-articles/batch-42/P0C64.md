# P0C64: Ford's generator resolver circuit loses valid position information

The generator in Ford's powersplit hybrid transaxle has its own rotor-position resolver. Ford assigns P0C64 to faults involving that generator-side resolver path. The parallel traction-motor circuit is identified separately, so the word generator in the diagnostic record should not be replaced by an assumed conventional alternator location.

## Rotor information supports hybrid-machine control

The resolver produces an analog waveform that a resolver-to-digital converter turns into usable position information. Ford uses that information to calculate speed and angular acceleration for electric-machine control. A failure in the resolver, its wiring or the conversion path can therefore affect the reliability of the position input.

P0C64 does not establish that the generator mechanically failed or that one sensor part is conclusively responsible. The monitor identifies a circuit-information problem in a path with several possible points of failure. The applicable diagnostic procedure is needed to distinguish them.

## Keep learned configuration separate from circuit faults

Ford uses P0DFC when the generator resolver has not been configured acceptably. That is a different category from the circuit faults discussed for P0C64. In particular, the source notes resolver configuration in connection with assembly initialization or replacement of the relevant inverter controller; it does not say every generator-position code is solved by repeating a learning routine.

A useful assessment preserves the reporting controller, configuration-related codes and other internal-supply or position findings. The summary is not a connector-level voltage test and supplies no universal replacement instruction. Verification should demonstrate valid generator-position information through the approved checks. A single plausible speed value or an immediate code clear cannot establish that the entire generator resolver path remains reliable.

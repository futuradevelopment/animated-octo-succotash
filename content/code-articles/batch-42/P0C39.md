# P0C39: Ford compares converter temperature with coolant after a long soak

Ford's P0C39 example is a temperature plausibility check for the DC/DC converter power electronics. It compares the reported electronics temperature with engine coolant temperature after a long engine-off soak. The code is therefore not simply an absolute overtemperature warning.

## The soak condition changes the expected relationship

The summary gives a difference greater than 30°C after 180 minutes of engine-off time as the failure condition for the A/B power-electronics temperature checks. The elapsed soak is essential context. Comparing the two temperatures during active operation, when the components can heat differently, would not reproduce that stated test.

Ford also names the relevant reference-voltage and engine-off-timer checks among the supporting conditions. A questionable time estimate or invalid sensor support can affect whether the comparison is meaningful. A single pair of temperatures without those qualifications is incomplete evidence.

## The sensor letter does not establish a physical location

The source groups P0C39 and P0C3E under the same documented comparison. It does not assign a unique mounting position or separate numeric threshold to sensor A in this section. The exact vehicle's service information is needed to connect the code with its physical implementation.

A useful diagnosis retains the temperature relationship, soak history and related reference or timer findings before deciding which observation is inaccurate. The monitor alone does not prove genuine converter overheating or identify one replacement component. Verification should use the approved procedure and a qualifying comparison, without deliberately heating or accessing high-voltage electronics. Clearing the code or observing a cooler converter later does not establish that the original temperature-correlation issue has been resolved.

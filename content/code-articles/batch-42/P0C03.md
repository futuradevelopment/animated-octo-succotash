# P0C03: Ford's second-machine current-low result is tied to its phase-circuit test

The generic P0C03 label identifies drive motor B current low. Ford includes it in the shared motor/generator current-monitor section of its powersplit hybrid system. That context is important because the vehicle architecture and reporting labels must be confirmed before treating motor B as a separately located traction motor.

## A low reading is meaningful during the specified test

Ford describes a phase-circuit fault declared by the motor/generator control unit when current remains below 5 amps for a 100 millisecond test at power-up. A normal zero-current state outside that test does not establish the same failure. The command context is what gives the low-current observation diagnostic meaning.

The current-out-of-range branch requires valid internal reference voltages, an appropriate low-voltage supply and a nonterminated machine operating mode. Those qualifications help distinguish a usable monitor result from information recorded while the control system itself is not ready for assessment.

## Confirm the machine mapping before locating a repair

The source lists P0C03 alongside the motor-side P0C00 and other motor/generator current codes but does not provide a physical connector map for this identifier. It should not be used to invent a location, phase assignment or component-replacement decision. The exact Ford diagnostic procedure must resolve the implementation.

Useful verification preserves the power-up event, the control-unit phase-circuit declaration and related sensing or reference faults. The OBD summary is not an instruction to energize a machine externally or probe high-voltage phases. A cleared code or a later low current while no output is requested does not show that the prescribed phase-circuit test has passed.

# P0D14: Ford monitors the negative charging-contactor driver during closure

Ford's documented P0D14 condition applies to the negative charging-contactor control driver. Although the generic title says circuit high, the manufacturer's malfunction description is an overcurrent report from that driver. It should not be read as proof that the battery pack's overall voltage is excessive.

## Match the electrical report to the requested state

The check requires the charging-wake-up signal to be high and the negative charge contactor to be commanded closed. Ford gives a 40 millisecond overcurrent duration. The command and wake-up state are therefore essential parts of the fault record; an observation made while the system is asleep is not an equivalent test.

The positive charging contactor has its own corresponding driver code. Keeping the negative-side identity matters because a generic description such as charging-contactor fault can otherwise lose the branch the controller actually reported.

## Do not infer the main-contact position from driver current alone

Ford evaluates apparent stuck-open and stuck-closed charging-contact states through other monitors using voltage and operating-state information. P0D14 describes the driver behavior, not a completed physical inspection of the negative contactor. Associated switching-state codes can add evidence, but the summary does not establish one mandatory repair from this current report.

The useful diagnostic approach is to retain charge-state, driver and voltage-related findings and apply the exact vehicle's approved procedure. The monitoring duration is not an instruction to command the contactor repeatedly or bypass its controller. Verification should include the permitted closing sequence without recurrence of the driver fault and the required high-voltage checks. A cleared code outside a charging event offers much less evidence.

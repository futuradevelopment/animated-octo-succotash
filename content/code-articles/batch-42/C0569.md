# C0569: Ford tests brake-booster solenoid performance with driver feedback

PHEV brake operation depends on coordinated regenerative and friction braking. Ford's C0569 monitor evaluates the brake-booster solenoid's electrical performance within that arrangement. It uses feedback during defined driver states, rather than diagnosing a vacuum leak from the code alone.

## Several observations can trigger the performance report

The summary lists three alternatives: an excessive voltage drop across the low side with the high-side driver off, insufficient current during a test pulse with the high side on, or an inadequate monitored supply with the high side on. Ford gives an 80 millisecond duration for each of those listed conditions.

The associated values are a drop above 2 volts, pulse current below 160 mA and supply below 3.0 volts. These are descriptions of the controller's internal test, not directions to energize a brake actuator or probe unspecified terminals. Their interpretation requires the correct driver state.

## The solenoid is only one part of the brake system

Ford's entry conditions include an uncommanded booster state, a low-side command interval and accompanying ABS pump-motor fault categories. Retaining those contextual observations is more informative than reducing C0569 to a generic stuck-solenoid diagnosis. The source separately describes the electric vacuum pump and hydraulic pump motor; neither is automatically the component identified by this code.

The PHEV mapping also relates C0569 to the brake module's broader C0022 family. Recording the module and subtype helps avoid treating differently displayed versions as unrelated events.

A service conclusion needs the approved vehicle-specific procedure and full brake verification. The monitor does not establish that braking assistance is adequate, and a normal static pedal observation is not evidence that the timed performance checks have all passed.

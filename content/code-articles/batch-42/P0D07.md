# P0D07: Ford's charging-contactor monitor has conflicting descriptions

Ford's P0D07 source row requires careful reading. The generic code concerns the charging-contactor circuit, and Ford's detailed malfunction description discusses charge contactors that remain open. However, the DTC list on the same page labels P0D07 as a battery-cooling-fan circuit. That conflicting heading is not adopted as a diagnosis.

## The explicit monitor condition concerns charging

The operation entry requires charging wake-up to be present and the charge contactors to be commanded closed. The specifically labeled P0D07 threshold then states that both positive and negative charge contactors remain stuck open for 1.3 seconds.

This gives a useful, bounded interpretation of the detailed row: the requested charging connection has not reached the expected closed state. It does not identify which individual contactor, driver or measurement caused that result, and it should not be converted into a battery-fan repair instruction.

## Resolve the source conflict before choosing a repair

The canonical positive-contactor circuit title and Ford's both-contactors condition are not identical descriptions of scope. The exact vehicle's diagnostic procedure is needed to determine how that particular implementation assigns and distinguishes the charging-contactor faults. This article retains a source-review flag for that unresolved mapping.

A useful assessment records the charging-wake-up state, commanded contactors and associated driver or voltage-sense codes. The summary's abbreviated row is not permission to force contactors closed or probe the high-voltage charging path. Verification should use the confirmed vehicle-specific procedure and demonstrate a correct charging sequence. Clearing the code, replacing a component based on the conflicting fan label, or observing one later successful plug-in event does not by itself resolve the documented ambiguity.

# P0570: Ford's ACC example concerns an acceleration-request message

P0570's generic cruise-control accelerate-signal title can suggest an accelerator switch, but Ford's diesel example concerns adaptive cruise control. The monitor detects an error in the maximum-acceleration request message while adaptive cruise control is operating. The code name alone does not establish a failed steering-wheel button or accelerator-pedal sensor.

## Configuration and operating mode qualify the monitor

Ford specifies that the vehicle must be configured for adaptive cruise control and must not be in Factory or Transport Mode. These are meaningful enabling conditions: an absent result outside the qualified configuration or mode cannot demonstrate that the acceleration-request path passed its check.

The monitor executes every ten milliseconds and has a monitoring duration of one tenth of a second. Those values describe different aspects of the check. The execution interval should not be substituted for the duration of the stated fault assessment.

## The message description does not identify the failed component

The source does not publish the erroneous message encoding or a numeric maximum-acceleration limit for this row. It therefore supports the message-level diagnosis without supplying a complete test for a particular switch, module or wiring connection. The actual vehicle procedure is needed to establish which information was invalid and why.

Useful records retain the adaptive-cruise configuration, operating mode and related control faults. Verification must follow the approved procedure for that vehicle, including any required controlled operating conditions. The monitor description is not an instruction to provoke unwanted acceleration or conduct an improvised road test. Clearing P0570 or finding that a cruise button responds once does not establish that the qualified acceleration-request message check has passed.

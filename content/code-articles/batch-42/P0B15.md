# P0B15: Ford compares the upper half-pack voltage with its cells

Ford's P0B15 monitor compares two ways of observing the same portion of the high-voltage battery. One is the top half-pack voltage measurement; the other is the sum of cell-voltage measurements within that half. The code indicates an unacceptable disagreement, rather than identifying one bad cell by itself.

## Battery configuration changes the documented limit

The summary gives an absolute difference above 42 volts for the plug-in hybrid configuration and above 38 volts for the full-hybrid configuration, sustained for one second. The absolute comparison means either observation can be higher; the code is not restricted to a half-pack sensor reading too low.

Those two limits are specific to the source's documented battery arrangements. Applying the plug-in value to an unidentified hybrid pack, or treating the difference as an allowable voltage at an external connector, would misuse the monitor description.

## A comparison fault does not select the inaccurate input

The monitor detects disagreement between the aggregate measurement and the cell sum. Its result alone does not establish which input is wrong. Electrical circuit codes, cell-sense findings and the validity of the accompanying data can change how the comparison should be interpreted.

The BECM uses voltage information while controlling battery charging and discharging, so validating the measurements matters before drawing conclusions about pack condition. A normal-looking total battery voltage can coexist with a disagreement within one half and is not a substitute for this check.

Appropriate professional verification follows the exact battery's service procedure and demonstrates consistent measurements under the permitted operating conditions. The OBD summary provides no safe internal probing method or automatic replacement recommendation. Clearing P0B15 without establishing the relationship between the two observations leaves the original discrepancy unexplained.

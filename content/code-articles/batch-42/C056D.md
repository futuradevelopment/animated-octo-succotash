# C056D: Ford's brake-pedal sensor supply falls below its expected window

The brake-pedal angle sensor in Ford's hybrid arrangement helps determine the driver's requested braking torque. C056D identifies the low side of its monitored supply-voltage window. A supply problem is distinct from a pedal-position disagreement, even though it can affect how those position signals should be interpreted.

## Supply validity comes before position comparison

Ford's combined C056D/C056E entry uses a supply window from 4.87 to 5.13 volts and a 50 millisecond failure duration with ignition on. The low-side code concerns the lower boundary. These values describe this documented sensor-monitor implementation and should not be applied to every brake-related five-volt circuit.

The sensor's separate signal-comparison monitor requires its supply to be in range. That dependency matters when several pedal-sensor codes appear together: a disagreement recorded with an invalid supply cannot automatically be treated as independent proof that the sensing tracks have different mechanical positions.

## Preserve the sensor's role and module identity

The pedal assembly is part of Ford's regenerative-braking architecture, in which some pedal movement can represent a braking request before conventional friction braking is engaged. The code should therefore be interpreted as a control-input problem, not a direct measurement of wheel-brake force.

For PHEV OBD reporting, the source maps the ABS module's C100F supply-voltage family to C056D for the low condition. Keeping that module-specific context can clarify apparently different scanner descriptions.

The source supplies no connector pinout or instruction to bypass the supply. Professional verification needs the correct vehicle procedure, valid sensor power and the required braking-system checks. A cleared warning or a plausible pedal reading at one moment cannot by itself establish reliable torque-request information.

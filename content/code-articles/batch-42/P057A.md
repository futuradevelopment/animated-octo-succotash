# P057A: Ford's brake-pedal sensor A signal-format check

Ford's hybrid brake-pedal sensor uses two position-signal paths. In the manufacturer's PHEV mapping, P057A corresponds to a circuit 1 signal-frequency problem, even though a generic description emphasizes sensor A circuit/open. The exact module and subtype help preserve that more specific meaning.

## Signal shape matters as well as reported angle

The shared A/B circuit check evaluates extreme angle values and unacceptable pulse-width or period characteristics. Ford gives a permitted duty-cycle interval of 8.3 to 91.7 percent and a period interval of 1735 to 2358 microseconds. Those are signal-format limits in this monitor description, not a prescribed pedal position for a driver to hold.

The same table includes angle at 0 or 100 percent for 100 milliseconds and lists the associated P05E0 plausibility fault in its entry conditions. A technician should therefore retain the complete fault set and the actual signal observation, rather than infer a permanently open wire from the base code alone.

## Distinguish the circuit from the supply and comparison checks

Ford separately monitors pedal-sensor supply voltage and agreement between the two angle tracks. A supply failure or an implausible relationship with the brake on/off switch can change the interpretation of a circuit report. These are related observations, but they are not interchangeable tests.

The source maps the brake module's C100D signal family into P057A for the HPCM's OBD reporting. That gateway relationship can explain why different scan modes display different labels. Verification requires the vehicle-specific diagnostic procedure and appropriate brake-system checks. A normal displayed pedal percentage at one instant does not show that pulse timing remains valid, and clearing the code alone does not validate the braking-torque request path.

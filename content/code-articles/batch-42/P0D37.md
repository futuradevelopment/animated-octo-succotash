# P0D37: Ford evaluates battery current over two RMS windows

Ford's P0D37 monitor evaluates excessive battery-system current using RMS current over defined time windows. This differs from treating every brief current peak as a confirmed fault. The source supplies two current-and-time combinations for the documented hybrid battery system.

## Duration is part of the measurement

One criterion uses a 60 second RMS current value at or above 250 amps. The other uses a 200 second RMS value at or above 180 amps. A lower sustained current can therefore matter over the longer window, while an isolated high reading cannot be interpreted without its contribution to the relevant RMS calculation.

The summary does not state that every instantaneous sample must remain above the threshold for the whole period. Rewriting the condition that way would change the monitor from the RMS-based description the manufacturer provides. Nor are the listed values instructions to create high current during a test.

## Validate the current information before assigning a cause

The BECM uses a battery-current sensor as part of its control of charging and discharging. Separate codes assess current-sensor electrical support and correlation. A current-performance result should be considered with those findings before treating the recorded current as unquestionable evidence of a particular battery or power-electronics defect.

Useful follow-up retains the operating event, current history and measurement validity through the approved vehicle-specific procedure. A normal current display after the vehicle has stopped is not a reconstruction of either previous RMS window. The source does not prescribe one replacement or establish battery health from this code alone. Appropriate verification accounts for the original time-dependent condition and the required high-voltage checks, rather than relying on a cleared fault memory.

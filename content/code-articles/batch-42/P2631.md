# P2631: Ford identifies a battery-short condition in the NTK trim circuit

Ford's P2631 example is an electrical diagnosis within an NTK wide-range oxygen-sensor system. The summary associates the bank-2 sensor-1 positive-current trim high result with the RL circuit shorted to battery. It is not a direct statement that exhaust oxygen or fuel mixture is unusually high.

## The trim path is distinct from other sensor connections

Ford lists the identifier as P2631/P2629_12. The wire-diagnostic table also contains separate pump-current, reference and common-circuit conditions. Identifying the RL path matters because a code naming the oxygen sensor does not make every wire in its assembly interchangeable for diagnosis.

The monitor runs continuously with no prior monitor sequence. The source requires valid UEGO heater operation and battery voltage from 11 to 16 volts. An interface ASIC reports the fault, and the circuit failure remains present for ten seconds before the stated result.

## Confirm the sensor technology before applying the example

The condition is explicitly restricted to NTK UEGO applications. Ford discusses Bosch air-rationality testing on the adjacent page, including a deceleration-fuel-shutoff strategy, but that is a different diagnostic implementation. Its sequence should not be treated as the enabling condition for P2631's NTK wire check.

The summary does not identify an accessible terminal, a universal resistance specification or a guaranteed physical side of the engine for bank 2. Exact service information is needed to locate and test the installed circuit. Verification addresses the electrical condition under its qualifying supply and heater conditions. One later normal sensor display, a code clear or a rich-mixture repair assumption cannot establish that a short-to-battery classification in the trim path has been resolved.

# U0691: Ford's exhaust-pressure communication check covers missing and stuck data

Ford's U0691 example concerns the digital link to exhaust-pressure sensor A. The diesel summary lists several ways the link can become invalid: a low-level communication error with data absent in the required interval, a signal stuck low or high, or an internal sensor error. These alternatives should not be reduced to one assumed broken wire.

## The receiver assesses whether usable data arrives

Ford groups the check under continuous monitoring with no preceding sequence and a five-second monitoring duration. Although the row refers to an inappropriate time frame for missing data, it does not publish a separate numeric message-spacing limit. The five-second monitor duration should not be relabeled as an individual SENT packet interval.

The neighboring P0470 circuit category uses sensor-status and raw-data threshold criteria. Keeping that distinction preserves the difference between a communication failure and a separate assessment of the sensor's reported state or data.

## Communication loss does not establish an exhaust restriction

A missing or faulted pressure signal cannot, by itself, prove that a particulate filter is blocked or that a particular exhaust component has failed. U0691 is also not automatically a diagnosis of the vehicle-wide CAN network; Ford's cited mechanism is the SENT sensor interface.

The summary gives no universal sensor location, terminal procedure or replacement direction for every covered engine. The applicable service procedure must identify the installed hardware and the failure branch. Verification should confirm valid exhaust-pressure communication and then assess any remaining functional concerns with reliable data. One later plausible pressure reading or a cleared code does not establish that the original missing, stuck or internally faulted signal condition has been resolved.

# U0602: Ford loses the digital link to particulate-pressure sensor B

U0602 identifies lost communication with particulate-filter pressure sensor B in Ford's gasoline OBD summary. Ford places this code in the digital SENT sensor group. The signal format matters because the neighboring analog pressure-sensor checks use voltage thresholds that do not define this communication fault.

## Communication is checked before pressure behavior

The source shows U0602 and its U0602_00 representation in a continuous check with no preceding monitor sequence and a five-second monitoring duration. It separately assigns P245E/P245E_01 to the sensor-B circuit category. Keeping the full identifiers preserves the distinction between those reported electrical conditions.

Ford's pressure range/performance assessment follows completed electrical checks. It then evaluates offset, measured pressure relative to inferred exhaust flow, and pressure response to changes in flow. Those comparisons require usable information from the sensor; a lost digital link does not itself demonstrate an offset error or a restricted filter.

## A sensor letter does not establish its physical location

The summary does not assign sensor B one universal mounting position or bank across all covered engines. It also does not publish a code-specific SENT waveform limit for U0602. The exact vehicle procedure is needed to identify the installed sensor and diagnose its link.

Useful verification establishes valid communication through the relevant interval and confirms that the required functional checks can run. A plausible pressure value seen after the event does not prove that a previous communication interruption has been corrected. Likewise, applying an analog low-voltage limit to the digital data line, or replacing the particulate filter solely because pressure information was lost, would go beyond the evidence supplied by this monitor.

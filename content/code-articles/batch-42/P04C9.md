# P04C9: Ford sees no usable request from the cabin refuel switch

P04C9 can arise before Ford's sealed fuel system ever begins its pressure-release sequence. The code identifies a fuel-fill-door request switch that appears inactive or stuck off. In the documented hybrid implementation, the controller receives no usable request to open either the fuel door or the refueling vapor valve.

## An inactive request has more than one explanation

Ford lists three supported possibilities: a circuit shorted to battery, an open circuit, or a button mechanically stuck in its undepressed position. The first two are electrical failures; the third is a mechanical input failure. Replacing a latch solely because the door does not open would skip the stage the code actually describes.

The switch-monitor table lists a five-second monitoring duration and places the system in the engine-off refueling workflow. Ford separately monitors the unlock output with P04C1 and P04C2. Keeping input and output faults separate allows the diagnostic record to show whether the command is missing or present but ineffective.

## Check the request path, not just door access

Communication between the body controller and powertrain controller is also part of this sequence. The source lists message problems separately from the physical request-switch conditions; accompanying network faults can therefore change how an absent request is interpreted.

Ford notes that, in its examples, the system behaves normally after access is obtained through the applicable override. That does not establish that an override repairs the switch or validates later refueling events. The useful verification is a recognized cabin request followed by the correct pressure-management and latch sequence. Vehicle-specific instructions are needed for any override; the code itself supplies no safe bypass procedure.

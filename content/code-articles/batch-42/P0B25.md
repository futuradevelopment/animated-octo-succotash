# P0B25: Ford's low-battery monitor changes timing with contactor state

Ford labels P0B25 as low voltage in hybrid battery A, but its detailed monitor description uses cell state of charge. The controller evaluates whether any cell's state of charge is at or below zero, with a different confirmation period depending on whether the main contactors are open or closed.

## The switching state changes the time requirement

With the main contactors closed, Ford specifies 10 seconds at the stated cell-state condition. With the main contactors open, the interval is 90 seconds. Treating both situations as a single fixed delay would discard an explicit part of the manufacturer's logic.

The summary does not give a universal cell-voltage threshold for this particular row. A technician should not replace its state-of-charge condition with a guessed voltage limit simply because the generic title contains voltage low. Ford has separate pack-voltage and low-state-of-charge monitors elsewhere in the same system.

## Use valid battery information before interpreting depletion

The BECM manages charging and discharging using cell voltage, current and temperature information. Measurement or correlation faults can affect confidence in the battery-state information and should remain visible in the diagnostic record. P0B25 alone does not identify a particular weak cell or determine the required repair.

Useful evidence includes the main-contactor state, the cell-state information and whether the appropriate duration was actually met. A total pack-voltage reading at one later moment does not reconstruct that timed condition. Verification requires the applicable battery procedure and valid control-system observations. The monitor description is not a charging workaround or permission to access internal high-voltage components, and deleting the fault does not demonstrate that the original low-state event has been resolved.

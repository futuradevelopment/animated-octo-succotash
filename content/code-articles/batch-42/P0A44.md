# P0A44: Ford's motor-resolver overspeed check has an unresolved unit omission

P0A44 is the drive-motor position-sensor overspeed category in Ford's hybrid summary. The controller derives motor speed from resolver information, so the report concerns an excessive measured speed condition. It does not, on its own, distinguish genuine rotor overspeed from invalid position information.

## Two timing paths are documented

Ford lists one motor-speed condition lasting more than 10 milliseconds and another lasting more than 100 milliseconds. The printed numerical speed values lack an explicit unit. They are therefore not converted here into rpm, radians per second or a vehicle road speed. That omission requires confirmation from the exact vehicle's calibration or diagnostic procedure before using the numbers as test limits.

The monitor's entry conditions include a period after power-up, a valid low-voltage supply and an internal communication check. Those conditions place the speed observation within a qualified control-system state rather than making every momentary scan-tool value a valid reproduction of the fault.

## Resolver-derived speed needs reliable position information

Ford explains that the resolver waveform is converted to digital position information and then used to calculate speed and angular acceleration. Separate circuit and not-learned codes address other problems in that information path. They can change how an overspeed report should be interpreted and should not be discarded as unrelated findings.

The source supports a bounded monitor explanation, not an instruction to run the motor toward a limit. Professional diagnosis should retain the event data, resolver validity and unresolved unit question. A later normal speed display or a cleared code does not explain the original timed overspeed observation or establish that the position system has been fully verified.

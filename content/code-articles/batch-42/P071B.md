# P071B: Ford's plug-in-hybrid EV-mode switch stays low

Ford's PHEV example of P071B concerns the driver's EV-mode input switch. Although the generic code says transmission mode switch A circuit low, the source describes the control used to request Auto, EV Now or EV Later operation. It is not automatically a fault in a conventional transmission selector.

## The input must remain low long enough

Ford's stated malfunction condition is an EV-switch input that remains low for more than 30 seconds. The monitor operates continuously with its documented power-up and low-voltage conditions. A brief switch activation is therefore not equivalent to the persistent state described by the fault.

A neighboring code checks excessive low-to-high transitions over a short interval. That is a different signal problem. The same physical input can be assessed for both persistence and erratic transitions, but the two tests should not be collapsed into one generic stuck-button assumption.

## Confirm the vehicle's mode-control implementation

In the source's description, Auto normally favors charge depletion before conventional hybrid operation, EV Now requests engine-off driving under the stated nonfaulted conditions, and EV Later preserves battery energy by requesting conventional hybrid operation. These are the documented mode meanings, not a guarantee that the engine will remain off in every circumstance.

Useful diagnosis identifies the actual mode switch and its reported input state before assigning a wiring location or replacing a selector assembly. The summary provides no connector-level test. Verification should demonstrate appropriate input behavior under the approved procedure and preserve any associated control-system faults. Clearing P071B without observing the switch through the relevant interval does not establish that its persistent-low condition has been corrected.

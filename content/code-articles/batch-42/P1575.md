# P1575: Ford's accelerator-pedal result from an on-demand self-test

In the Ford namespace, P1575 identifies an accelerator-pedal position outside the expected self-test range. The documented hybrid summary places it in an on-demand key-on/engine-off or key-on/engine-running sensor check. That context is essential because P1575 is not simply another name for a continuously detected pedal wiring fault.

## Preserve how the code was obtained

Ford labels this result non-MIL and gives a monitoring duration below one second. A report generated during a requested self-test therefore needs to retain the test mode and the observed pedal state. A generic scanner's code description cannot tell the reader what the operator was doing during that test.

The same page assigns separate codes to continuous pedal-circuit continuity and disagreement checks. Those monitors have their own electrical and comparison criteria. Their published voltage limits should not be copied into P1575 as though the summary had provided an identical self-test boundary. It does not state that specific boundary.

## A self-test result is not a component verdict

The useful distinction is between a pedal position that is unexpected for the test and independent evidence of a faulty signal or sensor correlation. Associated continuous-monitor codes can add that evidence, but their absence or presence must be recorded rather than assumed.

The applicable Ford self-test instructions are needed to establish the expected operating setup and to interpret a repeat result. This source does not justify replacing the pedal assembly solely because P1575 is stored. Verification should demonstrate a correctly conducted self-test with appropriate pedal information, while retaining any separate circuit or plausibility findings. The interpretation is limited to Ford's documented usage; unrelated manufacturer definitions of the same P1 code are not interchangeable.

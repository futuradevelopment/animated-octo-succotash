# P2800: Ford's hybrid range-input example needs its source-label discrepancy preserved

Ford lists P2800 as a transmission range-sensor B circuit result in its hybrid summary. The range information supports gear selection and other powertrain functions. However, a later threshold line in the same document prints the malformed identifier P20800 beside an invalid CAN gear-position description. That line is not silently treated as a fully verified P2800 criterion.

## The supported range-sensor context is clear

Ford describes an internally mounted, factory-calibrated range-sensor assembly in the powersplit transaxle. Its information is used for range selection, torque calculation and reverse-lamp operation. The earlier monitor table explicitly identifies P2800 as the PRNDL input circuit and distinguishes range/performance, low, high and alignment-related codes.

The table also gives different signal windows for the available lever positions. It does not support selecting one arbitrary voltage as the universal P2800 failure threshold across all ranges. Correct range and configuration identification is needed before interpreting the readings.

## The malformed later label limits a more precise claim

Because the later code-to-condition join is printed incorrectly, this article retains a source-review flag. The exact vehicle's diagnostic information must confirm whether that CAN-message condition belongs to the reported P2800 implementation. The source does not justify repairing a network or replacing the sensor solely from an assumed correction.

Useful records preserve the reporting module, requested range, interpreted range and related sensor or communication findings. Professional verification follows the confirmed procedure and checks correct range recognition and the required safety functions. A cleared code or one successful gear selection does not resolve the source ambiguity or establish that the monitored range-input behavior remains reliable.

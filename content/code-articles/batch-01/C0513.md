# C0513: right-rear wheel-speed signal quality and missing stop pulses

C0513 is a right-rear wheel-speed range/performance code in this GM brake-control implementation. Its table includes sensor-family-specific checks, so a generic interpretation such as “wheel speed out of range” leaves out useful diagnostic information.

## Identify the sensor protocol

The BoschVDA and ContiVdaR air-gap-related branch requires inadequate magnetic pickup over at least five rotations, with vehicle speed above 1.24 mph. Detection examples are eight seconds at 3.1 mph and 22 seconds near 1.24 mph. A short observation may therefore end before this branch has enough rotational evidence.

For standstill monitoring, BoschVDA/ContiVdaR sensors must provide their expected protocol even when speed pulses are absent. A DF11i row separately checks missing speed/stop pulses. These checks need sensor supply above 6 V and use a 3.6-second detection time.

## What changes the next check

First determine whether the record concerns moving magnetic quality or stationary protocol. That decision changes what successful verification looks like: a rotating speed display cannot validate required stop messages, while a stationary electrical pass cannot validate five rotations of pickup quality. Confirm prerequisite undervoltage checks before treating a nonrepeat as evidence.

The extracted magnetic-flux unit is unclear, and the table does not establish a physical adjustment dimension. Use the exact vehicle’s professional brake diagnostic procedure rather than inventing an air-gap specification or assuming the code proves a failed sensor.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using C0513. Confirm the vehicle’s module and calibration before applying its limits. [GM diagnostic table, PDF page 62](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=62).

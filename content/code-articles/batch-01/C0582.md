# C0582: brake-booster phase performance includes multiple plausibility checks

C0582 is labeled brake-booster motor A U-V-W circuit range/performance in the GM table, but the code appears in more than one location. The documented checks include bridge-driver control behavior and a temperature-signal plausibility comparison.

## Why both entries matter

Page 5 describes an idle-MOSFET mid-level check during initialization and checks whether monitored bridge voltages follow commanded on/off states. For example, several on-state ratios below 80% or off-state monitor values above 3.5 V are failure criteria. These are internal electronic supervision values, not universal vehicle-terminal measurements.

Page 13 uses the same code for the sum of temperature-sensor 1 and 2 signal voltages. A sum above 3.4 V or below 3.16 V, detected five times, is listed with a 0.6-second interval. That row should not be silently renamed as an ordinary motor-coil resistance test.

## Handling the scope carefully

The complete module failure subtype is essential to determine which documented check applies. An initialization switching failure and a temperature-signal relationship failure need different supporting evidence. This summary preserves the source’s unusual shared code assignment and does not claim one generic repair.

Confirm the exact controller calibration and service definition before using these thresholds. Verification must address the identified branch at initialization or during its enabled continuous check. Brake-booster electronics require the prescribed professional service method; the table provides no safe external probing sequence.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using C0582. Confirm the vehicle’s module and calibration before applying its limits.

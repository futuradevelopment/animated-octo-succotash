# P0133: oxygen-sensor slow response separates delay from transition

P0133 is an oxygen-sensor slow-response diagnostic in the 2025 GM 25OBDG07A Part 2 ECM table. The documented bank 1 response path separates the delay before a response from the time taken to complete the transition.

## Two measurements describe different behavior

The step-response branch flags an arithmetic mean delay above 0.38 second or mean transition time above 0.4 second, in either lean-to-rich or rich-to-lean direction. These are averages from controlled response evaluation, not a universal stopwatch limit applied to any scan-tool oxygen trace.

The table also describes an identification branch with different limits: identified delay above one second or transition time above 1.5 seconds. Those limits belong to that separate branch and must not be substituted for the step-response averages.

## Operating conditions affect the result

The source requires numerous non-bank-specific and bank-specific enabling conditions. They include a sufficiently developed operating state, established lambda control and an upstream sensor ready for operation; the documented temperature prerequisite is at least 655°C. Gear shifting, fuel cutoff, purge behavior and airflow stability also participate in the enable logic.

A cold-idle waveform or an unqualified acceleration event therefore cannot reproduce the complete monitor. Preserve which branch failed and the operating context, then use the exact vehicle procedure to distinguish actual slow sensor behavior from conditions that invalidate the comparison. The code alone does not establish a replacement remedy.

## Scope and verification

Verify the applicable response test completes after diagnosis, rather than treating a cleared code as proof. The file-to-model/engine mapping for this Part 2 document remains unresolved; this article explains its published monitor without assigning it to a particular model or engine.

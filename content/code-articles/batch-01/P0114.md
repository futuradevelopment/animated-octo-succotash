# P0114: intake temperature 1 is noisy despite remaining in range

P0114 is the intake-air temperature intermittent in-range diagnostic in the referenced GM strategy. It detects unexpectedly large short-term movement in the reported IAT signal while LIN communication with the MAF is established.

## An 80°C accumulated-change threshold

The ECM calculates the absolute difference between consecutive readings separated by 100 milliseconds. Ten readings contribute to a one-second string-length sample. A sum above 80°C is a failing sample; four failures out of five qualify the diagnostic.

This number is not a maximum acceptable intake-air temperature. It is also not necessarily the net change from the beginning to the end of the second. Repeated movement in opposite directions adds to the total, so the signal can finish near its original value and still fail.

## What the next observation should capture

Retain sufficiently detailed IAT history and the complete fault status. A slow display or a single plausible temperature can miss the changes this test is designed to detect. Confirm the LIN connection is established, since the monitor evaluates the quality of reported values rather than diagnosing an absent link.

After vehicle-specific diagnosis identifies and corrects the cause, verify stable data through the required sample windows and a completed passing monitor. The 80°C criterion differs from the 100°C IAT2 intermittent threshold in this file, so do not transfer limits between temperature channels. The code does not itself identify a failed sensor or MAF assembly.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using P0114. Confirm the vehicle’s module and calibration before applying its limits. [GM diagnostic table, PDF page 142](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=142).

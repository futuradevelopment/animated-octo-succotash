# P0074: ambient-temperature signal changes too much within a second

P0074 is an intermittent in-range outside-air temperature diagnostic in this GM ECM. It detects excessive signal movement even when individual readings do not continuously violate a circuit-high or circuit-low limit.

## The monitor adds movement in both directions

Every 100 milliseconds, the controller calculates the absolute change from the previous outside-temperature reading. It sums those changes across ten consecutive readings into a value the source calls string length. A total above 100°C is a failing one-second sample; four failures out of five qualify the diagnostic.

This is not a claim that ambient air changed by 100°C from beginning to end. A signal that jumps upward and then downward can end near its starting value while accumulating a large absolute-change total. Looking only at the first and last readings can therefore miss the evidence this monitor uses.

## What to capture and verify

Preserve a time-resolved raw temperature record and the complete fault status. A currently plausible temperature does not disprove an intermittent noise event, and a low-rate display may hide changes between samples. The code alone does not localize the source of the instability or justify a sensor replacement.

After the actual cause is established through the matched circuit procedure, verification should include stable raw behavior over the monitor’s sampling windows and a completed passing result. The table’s Type B, two-trip classification is distinct from the four-of-five sample qualification used within the diagnostic.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using P0074. Confirm the vehicle’s module and calibration before applying its limits. [GM diagnostic table, PDF page 102](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=102).

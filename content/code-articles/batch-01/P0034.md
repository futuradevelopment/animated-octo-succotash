# P0034: bypass valve A circuit-low under an off command

P0034 identifies the compressor recirculation valve A circuit-low monitor in this GM ECM table. It detects a possible short to ground by evaluating the low-side driver when the output is off.

## What “low” refers to here

The failure comparison is an electrical voltage classification, with the source describing a short-to-ground specification below 0.5 Ω between output and controller ground. It is not a low-boost-pressure threshold. The table does not identify the failed wiring section or prove that the valve mechanism is damaged.

Monitoring requires powertrain-relay voltage of at least 11 V, an enabled diagnostic and no engine cranking. Ten failing samples out of twelve confirm the check. Sampling differs by actuator: 100 ms for PWM CRV and 12.5 ms for eCRV. Some controllers also restrict diagnosis to when application software is driving the relevant hardware output.

## How to interpret repeatability

A nonrepeat while the software has not enabled that output may be inconclusive. Establish actuator type, software command state and supply conditions before judging whether the fault has cleared. The source also allows P0033 to accompany P0034 on certain controllers; that combination is not proof of two unrelated defects.

Verification should demonstrate a successful applicable off-state check, using the vehicle’s circuit procedure. A boost response that feels normal does not test the same electrical behavior, and this summary provides no basis for a predetermined valve replacement.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using P0034. Confirm the vehicle’s module and calibration before applying its limits. [GM diagnostic table, PDF page 89](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=89).

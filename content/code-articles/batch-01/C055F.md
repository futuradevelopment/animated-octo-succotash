# C055F: brake hydraulic-unit performance covers several self-tests

C055F is the BSCM/EBBC hydraulic-unit performance fault in this GM brake system. It includes several pressure-building and leakage checks, so the code alone cannot select one hydraulic component for replacement.

## Identify which system test failed

A master-cylinder leakage branch uses calculated leakage above 200 mm³/s while the system is in its full state, the pedal is applied and pressure sensor 1 exceeds 3 bar. A separate active test in postrun checks for unexpected pressure build-up associated with separation valves. That test runs without a braking request and uses an eight-second interval.

Other branches evaluate calculated air volume and leakage near the beginning of a power cycle, or pressure-building behavior during replenishment. These are different operating states and distinct evidence; a fault recorded after shutdown need not have arisen during a driver’s brake application.

## Useful diagnostic questions

Retain the full fault subtype, system state and pressure/plunger information from the event. A leakage-calculation failure cannot be assumed equivalent to an unexpected-pressure self-test failure. Likewise, an ordinary key-on recheck may miss a monitor that executes specifically in postrun.

Verification should demonstrate successful completion of the failed hydraulic performance test under the exact vehicle’s procedure. The table supplies detection logic, not a bleeding sequence or safe manual actuator test. Brake hydraulics and powered booster systems require appropriate professional handling, and this code does not establish whether continued vehicle operation is safe.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using C055F. Confirm the vehicle’s module and calibration before applying its limits. [GM diagnostic table, PDF page 24](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=24).

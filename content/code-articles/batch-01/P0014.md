# P0014: exhaust camshaft tracking error under active VVT

P0014 is the bank 1 exhaust camshaft system-performance code in the documented GM strategy. It compares desired and measured cam positions when variable valve timing is enabled. The generic “over-advanced” label is therefore less precise than the absolute tracking-error test described here.

## The monitor needs a stable request

The engine must be running, system voltage above 11 V and power take-off inactive. The requested cam position must exceed zero and vary by less than 3° for a calibrated period. Both requested and measured positions must lie within additional calibrated bounds.

Confirmation uses 100 failing samples out of 125, each 100 milliseconds apart. The actual position-error threshold is a calibration symbol in this source, so no single numeric angle can be responsibly assigned from the table. P0013, P2090 and P2091 are listed as faults that prevent this performance diagnostic.

## What makes the evidence useful

Capture commanded and actual exhaust angles together, including whether the command has settled. Evaluating a transient response as though it were the stable monitoring window can produce the wrong conclusion. Electrical actuator faults also need attention before interpreting the performance monitor’s availability.

P0014 alone does not establish an oil-control, phaser or mechanical-timing cause. Verification should show that a valid stable request produces acceptable tracking and that the monitor completes. A parked-angle check or a guessed universal degree limit does not cover this documented operating test.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using P0014. Confirm the vehicle’s module and calibration before applying its limits. [GM diagnostic table, PDF page 82](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=82).

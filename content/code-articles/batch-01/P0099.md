# P0099: intake temperature 2 has excessive in-range variation

P0099 is the intake-air temperature 2 intermittent in-range diagnostic for the GM humidity-sensing arrangement described here. It evaluates signal noise by adding the magnitude of successive temperature changes.

## Oscillation can fail without a large net change

The controller compares each reading with the reading 100 milliseconds earlier. It sums absolute differences over ten readings, producing a one-second string-length sample. A total above 100°C is a failed sample, and four failed samples out of five qualify the diagnostic.

Because the changes are absolute, an upward jump and a downward jump both increase the total. The reading can return near its original value while the monitor still sees excessive variation. A start-to-end temperature comparison therefore cannot verify this noise check.

## Conditions and evidence

The monitor requires established LIN communication with the MAF, relay voltage at least 11 V for 0.9 second and no active powertrain-relay fault. This distinguishes unstable values arriving through an operating connection from an absent communication link.

Preserve time-resolved IAT2 data and complete fault status. A single plausible reading after the event does not rule out the documented problem. Vehicle-specific diagnosis must determine the cause without assuming the sensor or entire MAF needs replacement. Verification should include stable communicated readings across the required sampling windows and completion of the enabled monitor, rather than relying only on a warm restart and cleared memory.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using P0099. Confirm the vehicle’s module and calibration before applying its limits. [GM diagnostic table, PDF page 112](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=112).

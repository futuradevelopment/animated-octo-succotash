# C0002: TCS channel A valve 2 and its distinct coil limits

C0002 is the GM brake controller’s traction-control channel A valve 2 fault. The monitored object includes the coil circuit, output driver and internal feedback logic. The code by itself does not identify which of those checks failed.

## Valve 2 is not electrically interchangeable with valve 1

The documented valve 2 overcurrent band is 5–8 A. Its resistance monitor flags a calculated value below 2.2 Ω or above 6.9 Ω. Those limits differ from the channel A valve 1 values in the adjacent C0001 table. A diagnosis that transfers valve 1 resistance criteria to valve 2 would therefore misread this source.

The table also checks an interrupted coil path using open-load or undercurrent feedback. Other branches cover excessive output-stage temperature, power-ground loss, PWM faults and unexpected driver-state feedback. Some operate continuously with a 0.03-second detection time; resistance and internal checks operate on a 20-second cycle.

## Evidence to retain

Record the complete module code detail and whether the event occurred during a valve command or the silent driver test. The latter requires an inactive hydraulic request and, for several branches, relay supply above 6.9 V. These conditions explain why a fault may not immediately repeat when a technician requests valve operation. Rechecking must include the applicable monitor state. The published numbers describe controller diagnostics, not permission to energize brake valves externally; vehicle-specific brake service information is needed.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using C0002. Confirm the vehicle’s module and calibration before applying its limits.

# C050C: left-rear wheel-speed circuit interruption or ground short

C050C is a left-rear wheel-speed circuit/open diagnostic in the referenced GM brake controller. Its monitor detects sensor current on the signal line below 0.0038 A, equivalent to 3.8 mA, for 0.12 seconds.

## What an open-code label can and cannot establish

The OEM description explicitly includes either interruption or a short to ground. Both can produce the low-current evidence used here. The code therefore does not establish that a wire is physically broken, and it does not distinguish the wiring from every other part of the sensor path.

This check requires ignition on and completion of the wheel-sensor undervoltage tests without their corresponding faults. The source does not list a minimum road speed for this electrical branch. A moving-wheel comparison is a different diagnostic, so waiting for a road-speed discrepancy is not necessary to understand the reported failure criterion.

## A focused next step

Preserve the exact failure status and investigate the left-rear electrical path using the vehicle-specific circuit procedure. If supply conditions have not been satisfied, first establish why the current monitor could not run reliably. The direction and incorrect-component monitors appearing farther down the same page belong to different codes and should not be used as C050C repair conclusions.

After addressing the verified cause, confirm that the enabled low-current monitor passes. A clear code memory alone is insufficient evidence of recovery. Any testing around braking components should follow professional service instructions.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using C050C. Confirm the vehicle’s module and calibration before applying its limits. [GM diagnostic table, PDF page 46](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=46).

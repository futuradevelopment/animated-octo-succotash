# P0119: coolant temperature changes faster than the sensor model permits

P0119 is the coolant-temperature intermittent circuit diagnostic in the documented GM non-ATM strategy. It identifies positive or negative temperature steps that exceed what the sensor’s thermal response model permits.

## The allowable jump changes with the previous reading

For each sample, the controller calculates a high and low limit from the preceding temperature, sensor time constant and calibrated bounds. The shown time constant is 7.4 seconds, with model bounds of −60°C and 200°C. Those bounds support the calculation; they are not a recommendation for normal coolant operating temperatures.

The source includes a separately labeled generic example with different constants. Its example values should not be substituted for the actual 7.4-second calibration. Failure qualification is five seconds within a six-second window, with continuous sampling and relevant circuit/erratic-fault prerequisites satisfied.

## What the evidence means

A temperature that changes implausibly quickly can fail even if both the old and new readings look individually believable. Conversely, a gradual change between the same endpoints may not represent this diagnostic condition. Preserve a time-resolved record rather than only the final temperature.

Use the vehicle-specific sensor-circuit procedure to determine the source of the steps; the code does not prove a sudden physical coolant-temperature change or a failed thermostat. Verification should show realistic sample-to-sample behavior and completion of the enabled erratic-signal monitor after the cause is corrected, using the correct configured coolant sensor.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using P0119. Confirm the vehicle’s module and calibration before applying its limits.

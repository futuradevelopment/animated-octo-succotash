# P0011: intake cam timing fails to follow its command

P0011 is the bank 1 intake camshaft system-performance monitor in the referenced GM ECM. Although the generic dictionary includes “timing over-advanced,” this table evaluates the absolute difference between desired and actual cam position while variable valve timing is active.

## A tracking error, not a published fixed angle

The failure threshold is expressed through calibration symbols rather than one numeric degree limit. It would be unsupported to assign this page a universal cam-angle tolerance. The monitor qualifies 100 failures out of 125 samples at 100-millisecond intervals.

It requires the intake phaser enabled, the engine running, supply above 11 V and power take-off inactive. Desired cam position must be above zero and sufficiently stable; the source lists variation below 3° for a calibrated period. Active P0010, P2088 or P2089 prevents this performance check.

## Diagnostic implications

Record desired and measured angle together with command stability. A difference while the requested position is still changing is not equivalent to the table’s qualified tracking failure. Also resolve actuator electrical faults before relying on the performance comparison, because those codes are explicit inhibitors.

The monitor does not establish one mechanical cause or justify a timing-component replacement by itself. Verification needs a valid, stable active phaser command and completion of the comparison after the cause has been established. Applying a guessed fixed-angle threshold or assessing only parked cam position would miss the way this P0011 implementation actually works.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using P0011. Confirm the vehicle’s module and calibration before applying its limits. [GM diagnostic table, PDF page 80](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=80).

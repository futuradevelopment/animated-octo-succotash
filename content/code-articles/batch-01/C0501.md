# C0501: left-front wheel-speed performance has several meanings

C0501 is broader than an incorrect left-front wheel-speed reading in this GM brake module. Its documented branches cover magnetic signal quality, missing standstill information, supply undervoltage, internal line-test failure and implausible wheel motion.

## Separate the branches before testing

For specified BoschVDA and ContiVdaR variants, the air-gap-related check needs at least five wheel rotations and vehicle speed above 1.24 mph. A stationary check cannot verify that branch. Another branch watches for missing speed pulses together with missing standstill protocol, using a 3.6-second detection period and sensor supply above 6 V.

Supply thresholds vary by sensor family. For example, the Bosch initialization branch uses ECU supply below 9 V, while the Conti branch uses below 9.3 V. These are not universal wheel-sensor specifications. Later branches also consider repeated raw-signal gaps with rough-road detection and ABS/ESP intervention absent.

## A useful diagnostic sequence

Preserve the failure subtype, sensor variant and whether the event arose during initialization, standstill or motion. If undervoltage is the recorded branch, an air-gap adjustment would not address the evidence. If repeated rotational gaps triggered the monitor, a successful stationary electrical check remains incomplete. Verification should reproduce the relevant enabled state under the vehicle’s professional brake diagnostic procedure. The table’s magnetic-flux unit is unclear in the available extraction, so no flux value is used here.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using C0501. Confirm the vehicle’s module and calibration before applying its limits.

# P00C7: intake pressure sensors disagree after the engine stops

P00C7 checks manifold, turbocharger-boost and barometric pressure consistency in the documented single-turbo GM strategy. With the engine stopped, these pressures are expected to equalize; the code identifies disagreement within that measurement system.

## Equalization is a prerequisite

The engine must not be rotating and more than five seconds must have elapsed since it last ran. The source checks pressure values against a 50–115 kPa plausibility range and uses 10 kPa pairwise comparison limits. Several combinations are covered, including an outlier and cases where a failed sensor cannot be uniquely identified.

Four failures out of five samples qualify the fault. Sampling is 12.5 milliseconds without LIN MAF and 25 milliseconds with LIN MAF. Related pressure-circuit and engine-off timer faults are listed as inhibitors; LIN communication must be established where required.

## Diagnose the relationship, not just the label

Record all three pressure values at the qualified engine-off moment. Comparing a running manifold vacuum reading with ambient pressure would not reproduce this test. When readings disagree, the code does not automatically prove which sensor is wrong, particularly in the ambiguous combinations described by the source.

Verification should confirm plausible individual values and agreement under the actual equalized, engine-off conditions. A normal boost response during operation does not establish that this static comparison passed. Use the exact vehicle’s sensor configuration and diagnostic procedure before applying these limits or selecting a replacement.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using P00C7. Confirm the vehicle’s module and calibration before applying its limits.

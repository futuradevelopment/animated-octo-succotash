# C057F: brake-booster motor phase resistance and voltage plausibility

C057F identifies the brake-booster motor A U-V-W phase circuit/open fault in this GM brake controller. Despite the “open” label, its published criteria include both abnormally high and abnormally low motor-coil resistance, plus a voltage-vector consistency check.

## Three routes to the same code

The resistance monitor flags a measured value above 0.20358 Ω or below 0.01258 Ω, each with a 0.12-second detection period. These are controller-specific internal diagnostic values. The table does not present them as a general handheld-meter specification for disconnected motor terminals.

A separate branch compares actual and calculated voltage vectors. A difference above 1.5 V uses a shorter 0.02-second interval. A satisfactory static resistance observation therefore cannot, by itself, resolve a voltage-plausibility failure.

## Choosing relevant evidence

Obtain the complete brake-module failure detail and establish whether the resistance or vector branch triggered. Both require ignition on, but they evaluate different electrical behavior. The neighboring current-high and current-low codes have their own offset and current criteria; those thresholds should not be attributed to C057F.

Verification should show that the original phase-circuit check completes without another failure after the cause is identified and corrected. The source does not establish a failed motor, connector or control module from this code alone. Professional vehicle-specific brake-booster procedures are required before accessing or testing powered motor phases; this summary is not an external energizing guide.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using C057F. Confirm the vehicle’s module and calibration before applying its limits. [GM diagnostic table, PDF page 9](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=9).

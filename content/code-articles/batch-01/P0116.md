# P0116: coolant temperature is biased against cold-soak references

P0116 is an engine-coolant temperature bias diagnostic in the documented non-ATM GM strategy. After a qualified soak, it compares the coolant reading with two configured reference temperatures to detect an in-range high or low bias.

## Configuration and auxiliary heat matter

The shown engine-outlet configuration uses intake-air and outside-air temperatures as references. It assigns a 50°C primary difference threshold and a 20°C secondary threshold. The secondary comparison depends on whether an auxiliary heat source explains the skew; the table specifically allows a block heater to bias the outlet sensor high.

The applicable cold-soak conditions include more than 28,800 seconds with propulsion off and ambient temperature above −9°C. Reference sensors must be available and free of their relevant faults. The table executes once per valid cold start, rather than continuously comparing a hot engine with ambient air.

## Why a simple mismatch can mislead

Preserve the initial coolant and reference readings plus any heater-use information. A warm engine is expected to differ from ambient, so a later comparison is not the same diagnostic. Similarly, an external heat source can change the interpretation of a cold-soak offset.

Verification requires the correct sensor configuration, valid references and another qualified cold start. The source includes auxiliary-heat detection options, with only the listed enabled method applicable to this calibration. P0116 does not establish a thermostat failure or a predetermined sensor replacement; the actual cause requires the vehicle-specific temperature-bias procedure.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using P0116. Confirm the vehicle’s module and calibration before applying its limits.

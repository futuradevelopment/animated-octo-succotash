# P0032: bank 1 sensor 1 heater driver short-to-power detection

P0032 is the bank 1 sensor 1 oxygen-sensor heater circuit-high code in this GM ECM. It checks the low-side driver for a short-to-power condition while the output is commanded on.

## Different command state from the low-circuit code

The source compares the driver’s on-state voltage with controller-specific limits. Its short-to-power design specification corresponds to less than 0.5 Ω between the output and controller power. This is an electrical-output classification, not a high oxygen-sensor signal or a rich-mixture threshold.

The monitor runs with ignition in crank or run, engine speed above 400 rpm and voltage above 11 V. Confirmation requires 20 failures among 25 samples at 250 milliseconds per sample. It is classified as a Type B, two-trip diagnostic in this table.

## What to verify

Capture whether the heater driver was actually on when the fault accumulated. An off-state check cannot demonstrate that this on-state monitor passed. A technician should use the correct wiring and heater-control procedure to distinguish where the abnormal connection or driver behavior arises; the code does not choose a component for replacement.

After repair, verification needs the on command, adequate supply conditions and a completed diagnostic result. A normal-looking oxygen reading once the sensor is hot is insufficient because it does not test the heater’s ability to respond electrically. Exact circuit thresholds and vehicle applicability still require the matching service information.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using P0032. Confirm the vehicle’s module and calibration before applying its limits. [GM diagnostic table, PDF page 87](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=87).

# P00C6: fuel rail pressure fails the cranking start check

P00C6 evaluates high-side fuel pressure during engine cranking in this GM direct-injection strategy. It is a starting-phase pressure diagnostic, distinct from a running pump-control authority check.

## The threshold is calibration-dependent

The table describes pressure-rise and pressure-fall logic, but the displayed calibration enables the rise test and disables the fall test. The minimum pressure and allowed start-control timeout are referred to supporting calibration tables. No universal MPa threshold or cranking-time limit can be taken from this page alone.

Only one diagnostic is performed for each engine start. The rise test samples every 6.25 milliseconds and requires the high-pressure pump enabled, valid pressure information and appropriate low-side pump conditions. Other prerequisites exclude relevant sensor/circuit faults, low-fuel conditions and specified device-control states. Run/crank voltage must exceed 8 V.

## What to capture

Preserve the pressure trace during the failed start, the selected start-control mode and supply conditions. A satisfactory pressure reading after the engine is already running does not reproduce a cranking failure. Nor does the code alone distinguish inadequate feed, incorrect measurement or failure to build pressure elsewhere in the system.

Verification requires a qualifying start and completion of the enabled pressure-rise diagnostic using the exact calibration’s limits. High-pressure fuel service must follow the professional vehicle procedure; this monitor description does not provide a safe manual pressure-release or line-opening method and does not prescribe pump replacement.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using P00C6. Confirm the vehicle’s module and calibration before applying its limits.

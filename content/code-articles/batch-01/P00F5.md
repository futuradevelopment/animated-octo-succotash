# P00F5: humidity value reported above its allowed range

P00F5 is the humidity-sensor circuit-high diagnostic in this GM LIN-MAF strategy. It detects a reported relative-humidity value at or above 106.25%.

## Reported data versus actual weather

The monitor supervises a numerical percentage received over LIN from the MAF. The sensing system derives that value from capacitance. The threshold is an out-of-range boundary for the reported measurement, not evidence that ordinary ambient humidity physically exceeded the normal percentage scale.

Powertrain-relay voltage must be at least 11 V for 0.9 second, the relay fault must be absent and LIN communication must be established. The ECM samples every 100 milliseconds and qualifies failure when 40 of 50 readings fail. The table classifies the diagnostic Type B, two trips.

## Interpretation that avoids a false shortcut

Record whether the link is communicating and what humidity value it carries. A valid link can transmit invalid sensor information, so resolving only communication status is not enough. Likewise, describing P00F5 as a particular high voltage at an ECM pin would add an analog-circuit assumption unsupported by this source.

The correct vehicle procedure is needed to identify the cause and decide which part of the sensing/reporting path requires attention. Verification should establish credible humidity data and completion of the enabled high-value test. A currently reasonable reading without the required sample history does not independently demonstrate that an intermittent prior event has been resolved.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using P00F5. Confirm the vehicle’s module and calibration before applying its limits. [GM diagnostic table, PDF page 126](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=126).

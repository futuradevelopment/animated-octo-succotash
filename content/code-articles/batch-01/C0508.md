# C0508: right-front circuit-low includes invalid signal patterns

C0508 is the right-front wheel-speed circuit-low code in the documented GM brake module. Its table contains both a supply-short branch and a signal-classification branch, so the word “low” does not establish one universal voltage measurement.

## Two supported interpretations

The supply-line branch recognizes current greater than 55 mA but less than 160 mA as evidence of a short to ground. A separate branch applies when current, supply-line and voltage monitors have not detected their own failures, yet the received signal is invalid. That second case is expressly different from an already classified electrical fault.

Both shown branches use a 0.12-second detection time with ignition on. Their enabling conditions include successful completion of the four wheel-sensor undervoltage checks. Codes listed in those conditions identify prerequisites; they are not proof that all four wheels have failed.

## Why the distinction helps

If the complete fault detail indicates supply overcurrent, a technician should evaluate that supply path using the matched circuit information. If it indicates an unclassified signal pattern, a static supply measurement may be insufficient even when it looks normal. Preserve both the fault subtype and supply context before clearing.

The adjacent C0506 entry handles signal current below 3.8 mA as an interruption/ground-short condition. Its criterion should not be substituted for C0508. Verification should show the correct C0508 branch completing successfully, with brake-system work performed under vehicle-specific instructions.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using C0508. Confirm the vehicle’s module and calibration before applying its limits. [GM diagnostic table, PDF page 52](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=52).

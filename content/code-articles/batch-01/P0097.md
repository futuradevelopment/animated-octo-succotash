# P0097: LIN-reported intake temperature 2 is below range

P0097 is labeled intake-air temperature 2 circuit low, but this GM LIN-MAF implementation checks the reported temperature value rather than a direct ECM analog input voltage. The failure threshold is IAT2 below −60°C.

## The communication architecture changes the interpretation

The source describes a thermistor whose temperature is transmitted to the ECM by the MAF over LIN. Consequently, a generic explanation that equates this code with a particular low voltage at an ECM pin would not follow this monitor’s evidence.

The check needs established LIN communication and powertrain-relay voltage of at least 11 V for 0.9 second. A powertrain-relay fault must be absent. Forty failures out of 50 readings qualify the fault, with a reading every 100 milliseconds. The source classifies it Type B, two trips.

## What to establish next

Record the actual reported IAT2 value and communication status. This code describes an implausibly low communicated temperature; it is different from complete loss of the LIN link, which would prevent the listed communication prerequisite. A technician still needs the vehicle-specific procedure to identify why the value is wrong.

Verification should show credible IAT2 information and successful completion of the enabled low-temperature check. A healthy communication link alone is insufficient if the value carried over it remains erroneous. Conversely, applying an unrelated analog-sensor voltage rule can misdirect diagnosis. The monitor does not by itself authorize replacement of the whole MAF assembly.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using P0097. Confirm the vehicle’s module and calibration before applying its limits. [GM diagnostic table, PDF page 110](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=110).

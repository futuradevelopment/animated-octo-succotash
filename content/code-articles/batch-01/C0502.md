# C0502: left-front wheel-speed circuit-low interpretation

C0502 is labeled left-front wheel-speed sensor circuit low in the GM electronic brake controller table. One clearly documented branch detects a sensor supply-line short to ground using supply current greater than 0.055 A and less than 0.16 A for 0.12 seconds.

## “Low” does not mean slow wheel rotation

Those values describe electrical supply current, not vehicle speed or a permitted sensor-signal voltage. The monitor runs with ignition on after the wheel-sensor undervoltage tests have completed without their corresponding faults. Failure to satisfy those prerequisites can prevent this check from offering a meaningful pass result.

A second branch describes a signal pattern that is neither a recognized electrical failure nor valid sensor information. Its Boolean wording is internally inconsistent in the published extracted row: the prose describes invalid data, while one condition is printed as “signal is not valid = False.” That branch needs source clarification before its exact logic can be asserted.

## What remains useful

Retain complete brake-module failure detail and supply-voltage history. A confirmed supply-current fault directs diagnosis toward the supply circuit described in the vehicle-specific procedure; an unclassified-signal status requires a different investigation and should not be forced into the same explanation. Do not use the code alone to choose a sensor replacement. After the cause is addressed, verify that the prerequisite tests and the relevant C0502 monitor actually complete. Brake-system testing should be performed with the matched service information.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using C0502. Confirm the vehicle’s module and calibration before applying its limits. [GM diagnostic table, PDF page 38](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=38).

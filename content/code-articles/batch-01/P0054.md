# P0054: bank 1 sensor 2 heater resistance after a cold soak

P0054 evaluates bank 1 sensor 2 oxygen-heater resistance in the documented single-bank exhaust strategy. Unlike the driver open/short codes, this monitor calculates resistance from voltage and current at a qualified cold start.

## The cold-start window is unusually narrow

The expected range is 5.7–11.7 Ω. The test requires more than 28,800 seconds of engine soak, equivalent to eight hours, coolant above −30°C, and coolant minus intake-air temperature below 8°C. It also requires engine run time below 0.05 seconds and ignition voltage below 32 V.

The table excludes active coolant-sensor, intake-air-sensor and P262B faults. Those conditions matter because the resistance comparison assumes an appropriate starting temperature and a valid soak history. A measurement taken after the heater has warmed is not equivalent to this cold-start calculation.

## What follows from a failure

Establish whether the installed sensor matches the vehicle’s specified application and whether the temperature and soak inputs were credible. The source describes an incorrect or out-of-range heater resistance; it does not prove one component defect without those prerequisites.

Verification occurs once per valid cold start. A warm restart immediately after clearing cannot demonstrate that P0054 has passed, even if no code returns. Use the exact vehicle procedure to investigate resistance and installation details, then confirm the qualified monitor completes. The stated numerical range applies to this documented monitor, not to every oxygen-sensor heater.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using P0054. Confirm the vehicle’s module and calibration before applying its limits. [GM diagnostic table, PDF page 94](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=94).

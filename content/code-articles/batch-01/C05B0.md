# C05B0: brake circuit C leak code uses calculated air-volume evidence

C05B0 is labeled brake hydraulic circuit C leak, while this GM monitor specifically describes detection of air in the plunger through calculated volume deviation. That distinction matters: the code is not direct confirmation of a visible external fluid leak.

## Three different operating opportunities

During replenishment, the documented branch uses calculated deviation above 2 cm³ for more than one second, with pressure sensor 1 above 10 bar and the system in specified degraded states. During transition to idle, another branch uses deviation above 1.5 cm³ for more than five seconds.

A power-cycle active test also uses 1.5 cm³ but requires more than ten seconds, no driver or external braking request, and the listed vehicle-speed window. The volume estimate comes from pressure sensor 2 and plunger position. These are related model inputs, not an instruction to measure drained fluid manually.

## How this informs diagnosis

Record which air-detection mode failed and whether its pressure and system-state prerequisites were met. A replenishment failure and a transition-to-idle failure need not reproduce during the same workshop observation. Because the evidence is calculated from pressure and position, the code alone does not localize a leak or establish a specific sealing component.

Verification should use the manufacturer’s controlled brake diagnostic procedure to complete the appropriate test after the verified cause is addressed. This summary does not authorize a road test, bleeding sequence or hydraulic disassembly; powered brake hydraulics require professional service information.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using C05B0. Confirm the vehicle’s module and calibration before applying its limits. [GM diagnostic table, PDF page 21](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=21).

# C0509: right-front wheel-speed signal current too high

C0509 describes a right-front wheel-speed signal-line short-to-battery monitor in this GM brake-control implementation. The actual measured criterion is signal-line sensor current above 0.05 A, with a 0.12-second detection period.

## An electrical high, not a high road speed

The controller is evaluating current in the sensor signal path. The code does not mean the right-front wheel exceeded a speed limit. This distinction matters because high reported wheel speed, missing wheel speed and electrical overcurrent are separate observations and require different evidence.

The check runs with ignition on after the wheel-sensor undervoltage tests have completed without their specified failures. Consequently, a supply problem can affect whether this monitor runs. The neighboring text on page 51 includes other speed-plausibility criteria; those preceding rows are not C0509’s overcurrent threshold.

## Using the record responsibly

Retain the module’s complete fault status and determine whether the overcurrent event is current or historical. Use the exact vehicle’s circuit documentation to identify the right-front signal path before any electrical test. The table does not establish a connector pin, a replacement part or a permitted external test current.

A meaningful verification confirms the relevant supply prerequisites, then observes the C0509 monitor passing under its enabled conditions. Merely obtaining a plausible wheel-speed display does not demonstrate that a previous short-duration electrical fault has been resolved. Brake diagnostic work should follow the manufacturer’s service procedure.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using C0509. Confirm the vehicle’s module and calibration before applying its limits.

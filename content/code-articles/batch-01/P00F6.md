# P00F6: humidity signal is too erratic within one-second windows

P00F6 is the humidity-sensor intermittent diagnostic for this GM LIN-MAF implementation. The ECM looks for excessive accumulated changes in reported humidity while communication is established.

## A change total, not an 80% humidity limit

The controller takes the absolute difference between each humidity reading and the one 100 milliseconds before it. Ten readings form a one-second string-length sample. A total greater than 80 percentage points fails that sample, and four failing samples out of five qualify the diagnostic.

For example, repeated upward and downward movements both add to the total; they do not cancel. A final reading close to the initial reading can therefore coexist with a large noise result. The code does not mean that any stable humidity above 80% is faulty.

## Conditions and useful evidence

The monitor requires relay voltage at least 11 V for 0.9 second, no active powertrain-relay fault and established LIN communication with the MAF. Preserve a sufficiently detailed time record and the module’s fault status before clearing. An occasional plausible reading or a healthy link alone cannot exclude noisy reported values.

Vehicle-specific diagnosis should establish why the data fluctuate before replacing a sensing assembly. Verification should cover consecutive sampling windows with credible stable information and a completed passing result. The source defines a signal-quality monitor; it does not provide an environmental moisture limit or a generic analog-circuit repair procedure.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using P00F6. Confirm the vehicle’s module and calibration before applying its limits. [GM diagnostic table, PDF page 127](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=127).

# C0504: left-front wheel-speed data integrity faults

C0504 is the left-front wheel-speed intermittent/erratic code, but the referenced GM monitor gives that description a specific electronic meaning. It supervises incoming data handling and, for selected sensor families, parity information.

## Two different kinds of bad data

One branch detects overflow in the direct-memory-access transfer unit or a transfer error caused by timestamps arriving too frequently. It uses a 0.03-second detection interval. That is evidence about the received pulse-data stream and processing path, not a published threshold for acceptable wheel acceleration.

For BoschVDA and ContiVdaR variants, another branch compares parity information from the sensor with the ASIC’s parity information. A mismatch lasting through the documented one-second criterion can trigger the code. The applicability of this branch depends on the installed sensor protocol.

## Capture more than a speed number

A smooth wheel-speed value on a slowly updating scan display does not establish that short data-integrity events were absent. Preserve failure details and event conditions, then use the vehicle-specific procedure to evaluate the affected signal path. Also check whether sensor undervoltage tests completed successfully: those are enabling conditions, not additional C0504 failure mechanisms.

Verification should address the recorded transfer or parity branch with ignition on and prerequisite diagnostics satisfied. The table does not justify replacing the brake controller merely because its DMA unit reported an error, nor does it provide a safe-driving assessment.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using C0504. Confirm the vehicle’s module and calibration before applying its limits.

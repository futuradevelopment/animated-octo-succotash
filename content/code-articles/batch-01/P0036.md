# P0036: bank 1 sensor 2 oxygen-heater open circuit

P0036 is the bank 1 sensor 2 oxygen-sensor heater control-circuit code in this GM implementation. The ECM checks the heater’s low-side driver for an open-circuit condition while the output is off.

## What the monitor measures

The failure is based on driver voltage outside a controller-specific range. The source relates its voltage thresholds to an open-circuit specification above 200 kΩ between output and controller ground. That is different from declaring a universal heater-element resistance limit.

Monitoring needs ignition in crank or run, voltage above 11 V and engine speed above 400 rpm. It evaluates 25 samples at 250-millisecond intervals and qualifies failure when 20 fail. The table describes a Type B, two-trip diagnostic and notes possible overlap with P0037 in certain controllers.

## Interpreting the code set

P0036 accompanied by P0037 may represent overlapping classifications of one electrical problem. Preserve the full failure data before deciding which circuit test applies. The code identifies heater control, so an exhaust-sensor voltage that appears plausible after warm-up does not resolve the heater’s open-circuit evidence.

A proper verification includes the driver-off check with the required supply and engine conditions. If that state never occurred, absence of an immediate repeat is inconclusive. Use the exact vehicle’s heater circuit procedure to distinguish the cause and confirm the correct sensor position; this table does not establish a replacement part or physical connector location.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using P0036. Confirm the vehicle’s module and calibration before applying its limits. [GM diagnostic table, PDF page 91](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=91).

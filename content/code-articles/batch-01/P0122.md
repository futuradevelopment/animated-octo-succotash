# P0122: throttle-position sensor 1 is below its reference fraction

P0122 is the TPS1 circuit-low diagnostic in this GM ECM. The controller detects a short-low or open condition when throttle-position sensor 1 falls below 6.50% of its voltage reference.

## Read the percentage as voltage, not opening angle

The source states that 100% corresponds to 5 V. On that scale, 6.50% is 0.325 V; it is not a 6.5% throttle-opening threshold. The monitor therefore concerns the electrical input range rather than a driver requesting too little throttle.

Run/crank voltage must exceed 6.41 V and the number 4 five-volt reference circuit must have no relevant error or P06A3 fault. Qualification uses either 79 failing counts out of 159 or 57 consecutive failing counts, with each count 3.125 milliseconds apart.

## Why both fault paths matter

The source explicitly includes an open circuit as well as a short-low condition. A code name alone cannot distinguish them. Preserve the input, reference status and complete failure record, then apply the matched throttle-sensor circuit procedure rather than assuming an accelerator-pedal defect from the broad generic title.

Verification should confirm a valid reference, credible TPS1 input and successful completion of the enabled low-circuit check. A signal that looks normal only at one throttle position does not address intermittent count-based failures. The code does not provide a pinout or identify a replacement throttle assembly without further diagnosis.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using P0122. Confirm the vehicle’s module and calibration before applying its limits. [GM diagnostic table, PDF page 157](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=157).

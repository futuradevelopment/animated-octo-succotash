# P0132: wide-range oxygen-sensor interface detects a high circuit

P0132 is the bank 1 sensor 1 wide-range air/fuel sensor circuit-high diagnostic for the GM Gen4 ECM implementation shown here. The ATIC142 interface ASIC monitors pump-current, reference-cell, reference-ground and trim circuits for a short-to-power condition.

## A high-circuit flag is not a rich-mixture reading

The ASIC’s listed criterion is a monitored pin above 5.2 V for more than 100 milliseconds before a fault flag qualifies. The ECM then accumulates an individual counter for each signal, using 20 failures out of 24 samples in a 25-millisecond loop. Any qualifying monitored signal can set the code.

The interface must report valid measurement and ready status. Engine run or auto-stop must be active, heater warm-up complete and a further circuit-diagnostic delay longer than 20 seconds elapsed. P0135, P0030, P0031 and P0032 must not be active during that key cycle.

## What this changes diagnostically

A cold key-on observation does not reproduce the enabled test. Preserve which signal flag failed and confirm the interface variant before interpreting voltage measurements. A general narrowband oxygen-sensor rule about high exhaust voltage would mischaracterize this wide-range electrical fault.

The matched vehicle circuit procedure must establish the actual source of the short-to-power behavior. Verification requires the warm, ready interface and completed counter-qualified monitor after correction. A plausible air/fuel value alone does not prove all monitored electrical paths are valid, and the code does not identify a predetermined replacement component.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using P0132. Confirm the vehicle’s module and calibration before applying its limits. [GM diagnostic table, PDF page 164](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=164).

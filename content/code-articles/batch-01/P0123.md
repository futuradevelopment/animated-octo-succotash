# P0123: throttle-position sensor 1 exceeds its voltage range

P0123 is the throttle-position sensor 1 circuit-high monitor in this GM table. It detects a continuous or intermittent short-high condition when TPS1 exceeds 95% of the stated reference-voltage scale.

## Electrical percentage is not throttle angle

The source defines 100% as 5 V, making the high boundary 4.75 V on that scale. This does not mean that opening the throttle past 95% normally sets the code. The monitored quantity is input voltage relative to the reference, not the requested or measured blade-angle percentage.

The check requires run/crank voltage above 6.41 V and no applicable error on five-volt reference circuit 4, identified with P06A3. It qualifies failure through 79 counts among 159 or 57 consecutive counts, sampled every 3.125 milliseconds.

## What to preserve

Keep raw TPS1 information, reference status and the complete current/history record. The fast count qualification can capture an intermittent event that is absent during a later static reading. The broad dictionary wording also should not be used to assume the accelerator pedal is the monitored component; this table specifically identifies TPS1.

Use the correct vehicle circuit procedure to locate the cause before replacing an assembly. Verification requires a valid reference and completion of the enabled high-circuit check after correction. A plausible throttle response by itself does not establish that a brief high-input failure has been eliminated, and the table provides no universal connector-level test sequence.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using P0123. Confirm the vehicle’s module and calibration before applying its limits. [GM diagnostic table, PDF page 158](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=158).

# C0018: left-rear inlet valve current and resistance checks

C0018 identifies the left-rear inlet-control valve circuit in this GM brake-module table. Its detection strategy combines current protection, interruption detection, resistance evaluation and supervision of the valve-driver electronics.

## A code with several electrical routes

The resistance monitor compares an internally measured value with a permitted band: below 4.8 Ω or above 13.7 Ω is a failure. That check runs periodically with ignition on, outside valve control and without a hydraulic request. A different branch looks for very low coil current using an undercurrent feedback threshold band of 0.075–0.125 A.

These two observations should not be collapsed into one diagnosis. Resistance outside a permitted range is a different result from inadequate current during the driver’s monitored state. The same code can also reflect an internal actuation-logic or ADC failure, for which the table does not prescribe replacement of an external component.

## Interpreting repeatability

Some C0018 checks detect faults in 0.03 seconds; others repeat on a 20-second cycle. An intermittent event captured during ordinary operation may therefore behave differently from one found by the silent driver test. Preserve event timing, module failure detail and relay-supply context before clearing. A next check should address the particular branch, then show that branch completes successfully under its required conditions. The table does not establish a universal vehicle fitment or a hydraulic repair procedure. Brake service should use the exact controller and vehicle instructions.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using C0018. Confirm the vehicle’s module and calibration before applying its limits.

# P0113: LIN-reported intake temperature 1 is above range

P0113 is the intake-air temperature circuit-high code in this GM LIN-MAF strategy. The ECM detects a reported temperature above 150°C, rather than applying the generic interpretation of a high analog thermistor-circuit voltage.

## Why the implementation matters

The MAF sends the temperature to the ECM over LIN after the sensing system derives it from the thermistor. The diagnostic requires that communication to be established. A high numerical temperature received through the link is therefore the specific evidence behind this table’s code.

Failure qualification is 40 readings out of 50 at 100-millisecond spacing, with diagnostic enable. The table lists a Type B, two-trip classification. These facts do not demonstrate that the actual intake air reached 150°C; they show that the reported value crossed the diagnostic limit.

## Separate the link from the measurement

Capture the communicated IAT value and communication status together. A healthy LIN connection can carry erroneous sensor information, while an absent connection would fail a prerequisite. Neither a generic voltage assumption nor the code name alone identifies a replacement component.

Verification should establish credible IAT information and successful completion of the enabled high-value check. Seeing a reasonable reading after clearing is insufficient if the required sample window has not completed. Use the exact vehicle’s sensing and communication procedure, and confirm that this LIN-MAF implementation applies before transferring the threshold or polarity interpretation to another vehicle.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using P0113. Confirm the vehicle’s module and calibration before applying its limits. [GM diagnostic table, PDF page 141](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=141).

# P0072: outside-air temperature signal resistance is too low

P0072 is the outside-air temperature circuit-low diagnostic in the documented GM ECM. It detects a continuous short-to-ground condition by monitoring a raw sensor input resistance at or below 46 Ω.

## Low resistance and indicated temperature move oppositely

The source describes the outside-air sensor as a thermistor whose resistance decreases as temperature increases. “Circuit low” therefore refers to the electrical resistance condition, not cold outside weather. The temperature annotation printed beside the threshold is inconsistent with that explanation, so it is not used here as a temperature conversion.

The diagnostic requires enable and qualifies 40 failing readings out of 50, with a sample every 100 milliseconds. This distinguishes a persistent low-resistance condition from a single noisy observation. The table lists a Type B, two-trip classification.

## What the code establishes

The monitor supports investigating the outside-temperature signal path for the specified electrical behavior. It does not localize the short or prove the sensor itself is the failed part. Preserve the raw input and current/history status, then use the vehicle-specific circuit procedure to separate possible paths.

Verification should show credible raw input and a completed passing low-circuit test over the required sample window. An ambient-temperature display alone may not expose the raw value used by the diagnostic. The exact 46 Ω limit belongs to this documented implementation; do not treat it as a universal thermistor test specification.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using P0072. Confirm the vehicle’s module and calibration before applying its limits. [GM diagnostic table, PDF page 100](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=100).

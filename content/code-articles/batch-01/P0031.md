# P0031: upstream oxygen-sensor heater control short to ground

P0031 is the bank 1 sensor 1 heater circuit-low diagnostic in the referenced GM ECM. The low-side heater driver is checked for a short-to-ground condition while the output is commanded off.

## Why commanded off matters

The controller expects a particular voltage range in the off state. A reading outside that range can satisfy the short-to-ground diagnostic, whose design specification is represented as less than 0.5 Ω between output and controller ground. This is not a claim that the oxygen-sensing element is reporting a lean mixture.

Monitoring requires voltage above 11 V, engine speed above 400 rpm and ignition in crank or run. The table uses 20 failing samples from 25 at 250-millisecond spacing. It also notes that some controllers may set P0030 alongside P0031.

## Evidence before replacing anything

Record the heater command state and the full code set. The allowed overlap with P0030 means the combination needs circuit diagnosis, not an assumption that both the sensor and controller failed separately. The published specification describes the controller’s electrical classification; vehicle-specific information is needed to identify accessible test points and normal readings.

A successful verification must include an enabled off-state test after the cause is corrected. A heater that appears to draw current when commanded on does not alone show that its output can return to the correct off state. Do not use this heater code as a fuel-mixture diagnosis.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using P0031. Confirm the vehicle’s module and calibration before applying its limits. [GM diagnostic table, PDF page 86](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=86).

# P0098: LIN-reported intake temperature 2 exceeds 150°C

P0098 is the intake-air temperature 2 circuit-high code for the LIN-MAF arrangement documented by GM. In this implementation, the ECM fails a communicated IAT2 temperature above 150°C.

## A high reported value, not an assumed pin voltage

The MAF transmits the temperature over LIN after deriving it from the sensing element. The diagnostic therefore supervises the numerical temperature arriving at the ECM. A generic analog “high circuit voltage equals cold” explanation would conflict with this particular table’s high-temperature criterion.

Monitoring requires powertrain-relay voltage at least 11 V for 0.9 second, no active relay fault and an established LIN connection to the MAF. Forty failing readings out of 50, sampled every 100 milliseconds, qualify the Type B, two-trip fault.

## Keep value validity separate from link validity

An established communication link can carry an implausible measurement. Record both the reported value and link status before clearing, then use the correct vehicle procedure to investigate the sensing and reporting path. The code does not demonstrate that the intake charge physically reached 150°C or identify a single replaceable part.

After correction, verify that realistic temperature data are received and that the enabled high-value monitor completes. Simply restoring communication or seeing no code during a disabled interval is not sufficient. Confirm that the vehicle actually uses this LIN-MAF strategy before applying its temperature threshold.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using P0098. Confirm the vehicle’s module and calibration before applying its limits. [GM diagnostic table, PDF page 111](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=111).

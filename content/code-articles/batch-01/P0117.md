# P0117: coolant sensor 1 circuit resistance is too low

P0117 is the engine-coolant temperature sensor 1 circuit-low diagnostic in the documented non-ATM GM strategy. It detects short-to-ground behavior by monitoring the resistance of the sensor circuit.

## The assigned sensor and threshold

This table assigns the diagnostic to the configured engine-coolant sensor 1 and lists a low-resistance threshold of 55 Ω. The associated 150°C annotation describes the sensor calibration near the fault boundary; the code does not independently establish that the coolant physically reached that temperature.

The monitor samples continuously and requires five seconds of failure within a six-second window. It is classified Type B, two trips. The configurable sensor slots shown elsewhere in the row are not evidence that five coolant sensors are fitted or have failed; only the assignment relevant to the actual vehicle should be used.

## What follows from low resistance

Preserve raw circuit information and the full failure status. The source allows the abnormal condition in the signal circuit or the sensor, so the code alone cannot localize the short or select a replacement. A qualified circuit diagnosis must use the correct sensor assignment and wiring information.

Verification should establish credible resistance-derived temperature and successful completion of the enabled circuit monitor after correction. An apparently normal gauge or a brief normal scan reading does not cover the six-second diagnostic window. This electrical code is also distinct from a cold-soak temperature-bias check and from a thermostat warm-up performance diagnosis.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using P0117. Confirm the vehicle’s module and calibration before applying its limits. [GM diagnostic table, PDF page 149](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=149).

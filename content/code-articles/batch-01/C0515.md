# C0515: right-rear wheel-speed circuit-high is an electrical test

C0515 is the right-rear wheel-speed circuit-high diagnostic in the referenced GM brake controller. Its stated strategy detects a signal-line short to battery by monitoring sensor current above 0.05 A for 0.12 seconds.

## Separate signal current from wheel-speed data

A high current measurement is not the same as a high calculated speed. The module can flag this electrical condition even though the code description does not explain what a driver would feel. The source does not support a claim that the wheel sensor is simply reporting too many revolutions.

The check requires ignition on and completed wheel-sensor undervoltage tests. If those prerequisites fail, an absent C0515 repeat may mean the check could not run. The next entry on the page, C0514, uses different supply-current and invalid-pattern logic; those rows should not be combined into C0515.

## A defensible diagnostic conclusion

Preserve current/history state and the complete fault detail, then investigate the identified signal path using matched vehicle circuitry. This table provides a detection criterion, not a pinout or permission to apply test voltage. It also does not prove whether the sensor, wiring or electronics require replacement.

After a cause is verified and addressed, confirm that the current monitor completes with its supply prerequisites met. A plausible right-rear speed on a scan tool is supporting information, but it cannot substitute for checking a short-duration electrical failure. Brake-system service requires the prescribed professional procedure.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using C0515. Confirm the vehicle’s module and calibration before applying its limits. [GM diagnostic table, PDF page 59](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=59).

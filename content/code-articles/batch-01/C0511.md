# C0511: left-rear wheel speed fails a transmission comparison

C0511 is a left-rear wheel-speed correlation code in the GM transmission-control table. It compares calculated vehicle speed from that wheel with calculated vehicle speed from the transmission output-speed sensor.

## The rear-wheel threshold is distinct

This entry uses an absolute difference above 6.0 km/h. That is larger than the 3.5 km/h threshold shown for the front-wheel correlation entries in the same section. Applying the front-wheel criterion to C0511 would misstate the documented monitor.

The failure logic updates every 25 milliseconds, advances a counter after failure time exceeds one second, and confirms the code when the counter exceeds two. It runs only with the relevant rationality diagnostic enabled, a steady-state variator and the front-wheel-drive calibration flag. Transmission output speed must be the selected source; specified output-speed faults and loss of brake-module communication must be absent.

## Interpretation and verification

A mismatch identifies disagreement, not automatically a defective left-rear sensor. Preserve both input values and the controller’s operating state. The table also describes substituting zero for the wheel-speed signal after failure, so post-fault zero data may be a default rather than the original observation.

Verify correction by allowing the enabled comparison to execute without accumulating failure counts. An ignition cycle alone does not establish this because the required steady-state conditions may not have occurred. These calibration limits should not be generalized to every vehicle that reports C0511.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using C0511. Confirm the vehicle’s module and calibration before applying its limits. [GM diagnostic table, PDF page 1068](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=1068).

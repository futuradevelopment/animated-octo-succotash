# P0035: bypass valve A driver shows a short-to-power condition

P0035 is the turbo/supercharger bypass valve A circuit-high diagnostic in this GM ECM table. The monitored component is the compressor recirculation actuator’s low-side driver, evaluated while its output is on.

## Electrical high is not overboost

The controller detects a voltage outside its acceptable on-state range. The source expresses the short-to-power specification as less than 0.5 Ω between output and controller power. It does not use manifold pressure as the failure quantity, so P0035 should not be treated as proof of an overboost event.

Powertrain-relay voltage must be at least 11 V, the engine must not be cranking and the diagnostic must be enabled. Ten failures out of twelve samples qualify the fault. PWM CRV samples occur every 100 ms; eCRV samples occur every 12.5 ms. Some controllers additionally require application software to drive the relevant output before diagnosis runs.

## What a useful recheck includes

Establish actuator type and actual command state before interpreting a cleared code that has not returned. A driver-off observation does not test this on-state fault. The table’s definition of turbocharger A also depends on series versus parallel arrangement, so the physical actuator must be identified from vehicle-specific information.

Use the matched electrical procedure to locate the cause, then verify a completed on-state diagnostic. Normal boost behavior alone cannot establish that the electrical monitor passes, and the code does not prescribe an actuator or controller replacement.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using P0035. Confirm the vehicle’s module and calibration before applying its limits. [GM diagnostic table, PDF page 90](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=90).

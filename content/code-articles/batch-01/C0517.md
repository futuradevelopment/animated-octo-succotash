# C0517: right-rear wheel speed disagrees with transmission output

C0517 is a right-rear wheel-speed correlation fault reported by the transmission-control strategy documented here. It compares vehicle-speed estimates calculated from the right-rear sensor and transmission output-speed sensor, rather than directly testing the wheel sensor’s circuit current.

## Conditions behind the comparison

The permitted difference is exceeded above 6.0 km/h. The algorithm updates at 25-millisecond intervals and uses both time and count qualification: failure time above one second increments a counter, and a counter above two confirms the code. These details distinguish a sustained diagnostic failure from a momentary unequal pair of readings.

The entry requires a front-wheel-drive calibration enable, steady-state variator operation and output-shaft speed as the selected speed source. It also requires battery and run/crank voltage above 9 V for over 0.1 second, with specified transmission-speed and brake-communication faults absent.

## What not to infer from a zero

The documented default sets the affected wheel-speed signal to zero after the fault. A zero observed afterward may be substitution by the controller, so compare original event information with post-fault data before concluding that the sensor produced no pulses.

Verification should show both credible source values and completion of the enabled correlation check. If the prerequisites are missing, a cleared code is inconclusive. The code establishes disagreement between sources; the exact vehicle’s diagnosis is needed to identify and repair the cause.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using C0517. Confirm the vehicle’s module and calibration before applying its limits. [GM diagnostic table, PDF page 1070](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=1070).

# C050F: left-rear wheel-speed signal-line overcurrent

C050F is the left-rear wheel-speed circuit-high fault in this GM electronic brake controller. The documented monitor identifies a possible signal-line short to battery when sensor current exceeds 50 mA for 0.12 seconds.

## Read the quantity correctly

“High” refers to an electrical condition measured as current. It is not an excessive wheel-speed reading or a threshold for sensor output frequency. That distinction prevents an unrelated tire-speed comparison from being mistaken for confirmation of this circuit fault.

The test requires ignition on and completed undervoltage tests for all four wheel-sensor channels. An unresolved supply condition can affect diagnostic availability. The nearby C050E entry on the same page describes different low-circuit and signal-pattern checks; its supply-current range is not the C050F threshold.

## What the code supports

The first useful evidence is the module’s complete current/history status plus the electrical conditions at the event. A vehicle-specific circuit test can then distinguish a shorted path from other explanations for the monitor’s current observation. The summary does not identify connector terminals, normal scope waveforms or which component should be replaced.

After the verified fault is corrected, confirm that prerequisite tests pass and that the C050F monitor actually completes. A reasonable left-rear wheel-speed display is useful context but does not alone rule out an intermittent overcurrent event. Brake electrical testing should use the manufacturer’s professional procedure and equipment.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using C050F. Confirm the vehicle’s module and calibration before applying its limits. [GM diagnostic table, PDF page 45](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=45).

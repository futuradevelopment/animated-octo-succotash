# P0131: wide-range oxygen sensor reports a short-to-ground fault

P0131 is a bank 1 sensor 1 wide-range air/fuel sensor circuit-low diagnostic in this GM Gen4 ECM table. It evaluates fault indications from the sensor interface ASIC, rather than interpreting a conventional narrowband oxygen voltage as a lean mixture.

## The interface hardware changes the criteria

The ATIC142 variant monitors pump-current, reference-cell, reference-ground and trim-related fault flags. The table specifies a below-150 mV criterion for the listed pump-current, reference-cell and reference-ground pins, qualified for 100 milliseconds before a fail flag. The continuation describes a different CJ136 implementation with its own electrical comparisons and shorter flag qualification.

The ECM then uses individual failure counters, with 20 failures out of 24 samples in a 25-millisecond loop. Heater-related P0135/P0030/P0031/P0032 faults must be absent for the key cycle. The interface must be ready, measurements valid, heater warm-up complete and the additional circuit-diagnostic delay above 20 seconds.

## Do not confuse warm-up with a passing test

A check performed before those prerequisites may not run this diagnostic. Identify the actual ASIC variant and failed signal flag before choosing a circuit test; one generic voltage rule cannot cover both documented implementations. The source also notes that some ground shorts may accompany P223C.

Verification should show valid interface status and completion of the appropriate circuit monitor after correction. P0131 alone does not establish fuel-mixture condition or automatically condemn the oxygen sensor assembly.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using P0131. Confirm the vehicle’s module and calibration before applying its limits.

# P0112: LIN-reported intake temperature 1 is implausibly low

P0112 is the intake-air temperature circuit-low code for the LIN-MAF application documented in this GM table. In this implementation, the failure criterion is a communicated IAT value below −60°C.

## Do not import a different circuit definition

The sensor’s temperature is transmitted to the ECM by the MAF using LIN. The monitor checks that reported value with communication established. It does not publish a low ECM pin-voltage threshold for an independent analog thermistor circuit.

The diagnostic qualifies 40 failing readings out of 50, with one reading every 100 milliseconds. It is classified Type B, two trips. The communication prerequisite separates invalid numerical temperature data from a missing LIN link; the two are not interchangeable diagnoses.

## Evidence that directs the investigation

Record the IAT value as received by the ECM and the link status. A functioning data connection does not prove the temperature measurement is credible. Conversely, the code does not prove which sensing or reporting component caused the out-of-range value and does not establish an automatic MAF replacement.

Use the exact vehicle’s LIN-MAF diagnostic procedure to identify the cause. Verification should confirm realistic temperature information and completion of the enabled low-value monitor across its sample window. A later normal reading is useful but cannot alone exclude a prior intermittent event. Before applying this explanation, confirm that the vehicle uses this serial-data implementation rather than another P0112 strategy.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using P0112. Confirm the vehicle’s module and calibration before applying its limits. [GM diagnostic table, PDF page 140](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=140).

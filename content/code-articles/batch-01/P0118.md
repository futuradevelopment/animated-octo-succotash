# P0118: coolant sensor 1 high resistance or an open circuit

P0118 is the engine-coolant temperature sensor 1 circuit-high diagnostic in this GM non-ATM strategy. It detects a short-high or open condition through circuit resistance above 175,000 Ω.

## The cold indication needs electrical interpretation

The source associates this resistance boundary with approximately −60°C. That is an electrical calibration limit, not proof that the coolant is physically that cold. The code can arise from the sensor or its signal circuit, so the high reading does not independently identify the failed part.

The check requires diagnostic enable and either engine run time above ten seconds or the listed minimum intake-air temperature above −20°C. It samples continuously and qualifies five seconds of failure within a six-second window. This additional enable logic matters when assessing a nonrepeat immediately after a very cold start.

## What to retain and verify

Record the raw coolant input, engine run time and intake-temperature context before clearing. Confirm which physical sensor is assigned to engine-coolant sensor 1; the table’s configurable slots do not establish a universal location or five installed sensors.

After the cause is verified with the matched electrical procedure, demonstrate that the enabled high-resistance monitor completes successfully. A later plausible temperature alone does not show that the original open-path behavior has been eliminated. The code is an electrical continuity diagnosis, and it should not be substituted for a judgment about thermostat operation or actual coolant warm-up performance.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using P0118. Confirm the vehicle’s module and calibration before applying its limits. [GM diagnostic table, PDF page 150](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=150).

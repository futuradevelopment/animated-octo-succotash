# P0071: ambient temperature fails an equilibrium comparison

P0071 detects an outside-air temperature signal that appears stuck within its electrical range in this GM strategy. It compares outside-air temperature with intake-air temperature after conditions indicate the readings should be sufficiently close.

## The controller waits for equilibrium

The source uses an eight-hour interval since the engine last ran and a 15°C comparison threshold. It has engine-off and engine-running branches. In the running branch, vehicle speed must be at least 12.4 mph, engine airflow at least 10 g/s, and an equilibrium counter must reach 300 counts.

The counter changes according to operating conditions; it is not simply a fixed elapsed-time delay. Similar readings can pass before the equilibrium decision, while persistent disagreement at the qualified endpoint fails. Some applications can continue the engine-off branch while moving without the combustion engine running.

## Interpreting a temperature mismatch

Do not condemn the outside sensor from a hot, stationary comparison immediately after operation. That observation does not match the documented equilibrium assumptions. Also review intake-air, coolant, airflow, vehicle-speed and engine-off timer faults, because the table uses them as diagnostic prerequisites.

Verification requires a valid soak and completion of the applicable equilibrium branch, not just clearing the code and observing an ambient display. The monitor establishes disagreement under expected equalization conditions; it does not independently identify which input caused it. Confirm the vehicle-specific strategy before applying these thresholds or planning the service verification.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using P0071. Confirm the vehicle’s module and calibration before applying its limits.

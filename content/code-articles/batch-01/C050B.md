# C050B: right-front wheel speed compared with transmission speed

C050B is a right-front wheel-speed correlation fault in the referenced GM transmission controller. The monitor derives vehicle speed separately from the right-front sensor and the transmission output-speed sensor, then evaluates the absolute difference.

## Threshold and operating state

A difference above 3.5 km/h advances the failure timer. The table uses more than one second of failure time and a fail counter above two, with updates every 25 milliseconds. This confirmation process means a transient discrepancy does not automatically equal a stored confirmed code.

The comparison is limited to the described front-wheel-drive calibration with the variator in steady state and output-shaft speed selected as the speed source. The monitor also requires adequate battery and run/crank voltage, no active U0121 communication fault and no listed transmission-output sensor faults.

## Interpreting a mismatch

Check which module reported the code. This TCM result is a consistency check between two inputs, not direct evidence of a short in the right-front wheel sensor. If multiple wheel correlations fail together, examining the shared comparison source is a reasonable diagnostic inference, but the table does not establish a particular failed component.

The controller’s described default substitutes zero for the affected wheel-speed signal. Distinguish that post-fault substitution from the raw information used to detect the mismatch. Verification should retain both speed sources and show that the enabled comparison completes without accumulating another confirmed failure.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using C050B. Confirm the vehicle’s module and calibration before applying its limits. [GM diagnostic table, PDF page 1066](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=1066).

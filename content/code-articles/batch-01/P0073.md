# P0073: outside-air sensor input indicates an open circuit

P0073 is the outside-air temperature circuit-high diagnostic in this GM ECM table. It watches for a raw resistance at or above 427,757 Ω, which the strategy identifies as an open-circuit condition.

## High circuit resistance can look very cold

The sensor is described as a thermistor with increasing resistance corresponding to decreasing temperature. A high-circuit fault therefore does not mean hot weather. The table associates the threshold with approximately −60°C, but the electrical resistance is the actual criterion being monitored.

The diagnostic takes one sample every 100 milliseconds and requires 40 failures out of 50. It is enabled as a continuous circuit check and classified Type B, two trips. A single unusual displayed temperature is not equivalent to that qualified result.

## Interpreting the evidence

Record the raw outside-temperature input and complete fault status before clearing. The code indicates open-circuit behavior in the signal path, not the exact location of the interruption. Vehicle-specific testing is needed to distinguish wiring, connection and sensor-related explanations without assuming a replacement.

A meaningful verification includes the enabled high-resistance check completing after correction. A plausible dashboard reading is useful context but does not necessarily show the raw diagnostic input or its sample history. The published threshold applies to the documented sensor/controller arrangement; using it as a general specification for another vehicle or sensor would require separate confirmation.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using P0073. Confirm the vehicle’s module and calibration before applying its limits. [GM diagnostic table, PDF page 101](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=101).

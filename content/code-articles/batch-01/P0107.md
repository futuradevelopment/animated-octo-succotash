# P0107: MAP signal voltage falls below its electrical range

P0107 is the manifold absolute-pressure circuit-low monitor in this GM ECM. It detects a continuous short-to-ground condition through MAP output voltage below 3% of the 5 V range, equivalent to below 0.15 V on that stated scale.

## Electrical failure versus actual pressure

The source maps that threshold to 7.5 kPa for the documented transducer calibration. It does not establish that true manifold pressure physically reached 7.5 kPa. The controller is classifying the electrical signal as too low, so sensor input validity must be established before drawing a mechanical airflow conclusion.

The diagnostic takes a sample every 12.5 milliseconds and qualifies 320 failures out of 400. This is a five-second observation set with a required failure count, not necessarily a claim of five uninterrupted seconds below the limit. The table classifies the monitor Type B, two trips.

## What to check and verify

Preserve raw MAP voltage and complete failure status. The code supports investigation of the signal circuit through the vehicle-specific procedure but does not localize the abnormal ground path or prescribe a sensor replacement. The correct reference and circuit arrangement must be identified before applying terminal tests.

After correction, verify credible raw voltage and completion of the enabled low-circuit monitor. A MAP performance comparison is a separate diagnostic and cannot substitute for this electrical test. Both the percentage threshold and pressure conversion are scoped to the documented sensor/controller calibration.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using P0107. Confirm the vehicle’s module and calibration before applying its limits. [GM diagnostic table, PDF page 136](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=136).

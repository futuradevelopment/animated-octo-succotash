# C0552: longitudinal acceleration compared with calculated motion

C0552 is a longitudinal-acceleration performance fault in the documented GM ECM strategy. It checks whether the raw acceleration signal agrees with acceleration derived from transmission output speed, using enabled operating windows rather than a single static sensor-voltage limit.

## A disagreement needs suitable conditions

The shown comparison uses an absolute difference above 0.25 g. Its enabling logic includes battery and run/crank voltage above 11 V, transmission-related conditions and absence of specified speed-sensor faults. The source describes several possible windows; the limits on this page should not be treated as the complete calibration for every variant.

The timing is also substantial. The table includes signal stability above ten seconds, failure accumulation above 75 seconds and sample-time qualification above 120 seconds, with 50-millisecond updates. An immediate recheck after clearing cannot demonstrate that this monitor completed.

## Interpreting the inputs

Because one side of the comparison is derived from transmission speed, the code is not proof that the acceleration sensor alone is inaccurate. Record the raw signal, comparison-source validity and active operating window. A discrepancy during an inhibited or unstable operating state is not equivalent to the documented enabled failure.

The listed default substitutes 0.0 g for the acceleration signal. Post-fault zero data may therefore be a controller default rather than a physical measurement. Verification needs successful completion of the applicable window and timing conditions, using the exact vehicle and calibration procedure.

## Source and applicability

This explanation covers the documented 2025 GM monitor, not every vehicle using C0552. Confirm the vehicle’s module and calibration before applying its limits. [GM diagnostic table, PDF page 71](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=71).

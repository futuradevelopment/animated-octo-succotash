# P1222: The second accelerator-pedal signal is too low

In BMW's LEV/ULEV monitor summary, P1222 is paired with the accelerator-pedal position sensor low-input family. The specified lower threshold is 0.33 V and the evaluation period is 60 milliseconds, continuously monitored. The code identifies the second pedal-position channel in the canonical BMW definition.

## A range fault is different from a correlation fault

The same table separately describes comparison between the two pedal sensors, using a 0.75 V difference for the rationality check. P1222 belongs to the lower-voltage row instead. That distinction prevents a technician from treating every pedal code as a disagreement between two otherwise valid signals.

A low input can require examining the channel's electrical path, but the summary does not identify a failed pedal assembly by itself. It contains no pin-level test, supply specification for this connector, or replacement instruction. Those details must come from the matching electronic-throttle service procedure.

## Use the correct sensor family

The table also contains throttle-position sensor limits, which are not identical to the accelerator-pedal limits. The pedal is the driver's request input; the throttle-position channels describe the valve. Borrowing the neighboring throttle threshold would apply the wrong row.

The lamp column lists two driving cycles. Successful verification should demonstrate that pedal channel 2 remains electrically valid throughout its movement, with the related control system assessed using the correct vehicle data. Clearing the code without exercising the input does not establish that the low-voltage condition has been removed.

# P00A1: Bank 2 charge-air temperature changes too abruptly

The N63 chart pairs P00A1 with BMW fault 10C101. It evaluates the rate of change of the Bank 2 charge-air temperature reading. A temperature that is simply hot is not the defining observation: the controller is looking for successive measurements that change too abruptly.

## What the monitor distinguishes

BMW specifies a difference greater than 3°C between consecutive values throughout the debounce period, or a single difference greater than 7.5°C. Its memory-entry description gives a persistence time longer than 1.5 seconds. These criteria describe signal behavior, not an allowable steady intake temperature or a cooling-system operating target.

That distinction changes the investigation. A sudden step in recorded temperature makes an intermittent connection or signal interruption relevant even when the sensor looks plausible before and after the event. The chart explicitly identifies wiring and the sensor as possible sources and calls attention to an intermittent open during electrical checks.

## Diagnostic direction

Inspect the sensor connection and harness, then have the signal, supply, and ground evaluated using the correct wiring information. Replacing charge-air cooling components solely because the title mentions temperature would not follow this monitor's evidence. The chart lists a slight power reduction as a possible effect, but does not establish which component has failed from the code alone.

Verification should address the abrupt signal behavior that originally triggered the fault. A stable reading at one instant cannot demonstrate that an intermittent temperature jump has been eliminated.

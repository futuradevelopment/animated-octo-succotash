# P1348: Cylinder 4 start-period misfire evidence

BMW's P1348 belongs to the cylinder-specific start-period misfire set and identifies cylinder 4. The M54 summary bases recognition on uneven crankshaft rotation. It does not directly measure whether cylinder 4's coil, injector, or compression is responsible.

## Reproduce the relevant phase

The monitor distinguishes one emissions-threshold exceedance in the first 1,000 revolutions after starting from repeated exceedances during later running. This makes the time after start a useful diagnostic discriminator. A symptom that disappears after a short period can still be consistent with the stored start-period record.

The chart provides a greater-than-1.8% criterion over 3,000 ignitions and additional speed/air-mass conditions. These figures belong to the stated emissions test groups. They should not be treated as universal misfire limits for every M54 calibration or copied into another manufacturer's procedure.

## Avoid importing the fuel-cutoff interpretation

A separate row covers the catalyst-damage misfire group and uses a 200-revolution window with immediate lamp behavior. P1348 is in the start/emissions branch instead. Its name alone does not establish that the controller disabled cylinder 4's fuel.

The practical next step is to preserve the original occurrence conditions and examine cylinder 4 using the applicable combustion diagnosis. The summary gives no ranked cause list or automatic replacement instruction.

Verification should include another appropriately monitored start after the cause is corrected. A successful warm road test is useful context, but it cannot alone confirm that a fault confined to the early-start period has been resolved.

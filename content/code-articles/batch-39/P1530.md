# P1530: Exhaust camshaft-actuator circuit high

For the M54 scope used here, BMW P1530 identifies the Bank 1 exhaust camshaft actuator's high-signal control circuit. The OBD summary groups it with electrical continuity checks for VANOS. Other BMW engine families can use different fault descriptions, so confirming this application is essential.

## What the electrical row establishes

The monitor distinguishes an inactive low-side driver from an active one. It uses a voltage boundary of 2.9 V in the former state and a 0.02–2.0 A current window in the latter, with a 1.25-second continuous evaluation interval. The source groups multiple circuit variants within those cells and does not publish a standalone connector test for P1530.

This prevents a reliable diagnosis from using a single unqualified voltage reading. The command state and exact circuit arrangement have to accompany the measurement.

## What it does not establish

The chart separately evaluates camshaft-to-crankshaft alignment and a mechanically stuck actuator. P1530 is not those performance monitors. It does not alone prove that exhaust timing is incorrect or that the VANOS hydraulic mechanism needs replacement.

The lamp is associated with two driving cycles. Verification should show that the exhaust actuator's control path behaves correctly through the relevant driver states and that no electrical high-signal fault returns.

The summary supplies neither a wiring pinout nor a component-replacement decision tree. Use the exact M54 calibration and vehicle repair information for those steps; do not transfer a P1530 interpretation from an unrelated BMW engine simply because the code string matches.

# P1329: Cylinder 5 knock-control correction reaches its limit

The ATQ DTC table maps P1329 to VAG 17737 and a knock-control limit reached for cylinder 5. The associated service directions cover knock control, abnormal engine noise, harness integrity, knock-sensor tightening, and fuel type.

## First distinguish a control result from a circuit defect

This code describes the controller reaching a correction limit. It is not an electrical short/open diagnosis and does not prove that the sensor itself is faulty. A loose mechanical component can also be relevant to the vibration being interpreted, which is why Volkswagen includes abnormal-noise checks.

The dedicated sensor procedure separates a functional assessment through measured-value groups 22–28 from resistance and wiring checks. It requires the correct sensor attachment torque, 20 Nm for this ATQ application. That value is engine-specific, not a universal knock-sensor specification.

## Avoid assigning one sensor to one cylinder

Cylinder 5 is the location associated with the knock-control result. The component procedure describes bank-related sensors G61 and G66, so the cylinder number should not be used as a physical sensor label or parts-ordering shortcut.

After wiring and mounting checks, Volkswagen evaluates recurrence over several operating states before replacing a sensor that continues to be implicated. Such verification requires controlled professional testing; the code is not a reason to deliberately provoke knocking.

A successful repair should resolve the repeated cylinder 5 limit event and the identified cause. Clearing the entry without retaining the original operating context removes useful evidence but does not establish that the control problem is gone.

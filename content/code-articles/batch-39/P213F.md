# P213F: Fuel-pump shutdown following an accident message

BMW 11B004/P213F describes emergency deactivation of the electric fuel pump when an accident message is present. The code therefore records a commanded safety response. It should not automatically be interpreted as a failed pump or an ordinary low-fuel-pressure fault.

## Follow the reason for shutdown

The N63 chart identifies an accident as the potential source and directs service attention to the ACSM, BMW's crash-safety module. This changes the diagnostic path: establish why the accident message was issued and assess the associated safety-system records before treating the pump as the primary failure.

The monitor uses Terminal 15 and electrical-system voltage above 10 V. The memory-entry section specifies persistence beyond 0.4 seconds. A separate time field in the source lists 750 seconds without sufficient explanation of its role; that line is not used here as a reset or waiting instruction.

## A stored response is not a repair procedure

The chart lists engine stalling as a possible result and does not prescribe a pump replacement. It also does not provide authorization to bypass the shutdown, bridge a relay, or restore fuel delivery after a collision without inspection.

Professional assessment should address crash information, vehicle damage, and the complete fuel and safety systems before operation is restored. If the car has not been in an accident, the unexpected message still needs investigation through the applicable module diagnostics. Clearing the code only removes a record; it cannot establish that the reason for the emergency shutdown is absent or that the vehicle is ready to run.

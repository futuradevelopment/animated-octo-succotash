# P1113: Bank 1 upstream oxygen-sensor resistance is too high

Volkswagen maps P1113 to VAG 17521 and excessive internal resistance at Bank 1 sensor 1. The ATQ chart directs the technician to the oxygen-sensor heating check before the catalytic converter. It does not identify the downstream sensor or establish a catalyst-efficiency failure.

## Confirm that heating can operate

The component procedure requires a sound fuse 34, battery voltage of at least 11.5 V, and a functioning fuel-pump relay. That relay requirement is significant: an upstream supply problem can affect heater operation even when the sensor itself is intact.

The specified heater-status display is 111, but Volkswagen explicitly permits a brief 011 because the heater is switched in pulses. Treating every momentary change as a failure would misread the test.

## Separate the sensor element from its supply

The procedure distinguishes heater continuity, ground wiring, and supplied voltage. It specifies a maximum 200-ohm heater continuity value and separate harness checks. These are workshop-test limits, not the code's published internal-resistance trigger; the DTC table does not give that trigger value.

A qualified technician should use the correct connector and test arrangement, especially because the procedure includes controlled electrical activation. The code alone does not justify replacing both upstream sensors.

Verification should establish correct heating and sensor operation, then restore readiness if diagnostic memory was erased. Volkswagen also specifies gold-plated terminals for repairs at this sensor connector, a detail that matters when correcting a connection rather than replacing the sensor assembly.

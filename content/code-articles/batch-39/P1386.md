# P1386: The DME knock-control baseline self-test fails

BMW fault 2E72/P1386 describes an internal control-module fault in the knock-sensor module. The associated standardized description is a Bank 1 knock-control baseline self-test. It is therefore not interchangeable with a sensor signal that is simply too low or too high.

## The monitor checks a different part of the system

The published entry requires the engine to be running above 1,520 rpm, a load factor above 25, and supply voltage between 9 and 15 V. Its memory-entry section gives a period below ten seconds. The chart does not define the load-factor unit or disclose the internal baseline acceptance value.

These limits are important when using the code. A measured knock-sensor voltage alone cannot be compared with an undisclosed internal self-test criterion. Nor does the phrase “Bank 1” identify a particular failed external sensor without the complete vehicle diagnosis.

## The documented service outcome

BMW's service-action field calls for DME replacement. This short chart contains no intermediate pin-level test sequence and no programming instructions. Its useful contribution is the distinction between an internal baseline test and an external signal fault, together with the conditions under which the fault is recognized.

A technician should confirm the exact BMW fault identity and applicable calibration before undertaking module replacement, then use the required vehicle-specific programming and verification process. The chart lists the emissions lamp as enabled but supplies no individual drivability symptom. It cannot establish engine mechanical damage, a sensor location, or a safe-driving conclusion from the P-code alone.

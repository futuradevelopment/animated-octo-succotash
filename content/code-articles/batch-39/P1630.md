# P1630: Accelerator-pedal sensor G79 signal is too low

P1630/VAG 18038 identifies an excessively low signal from G79. Volkswagen calls it a throttle-position sensor in the chart, but the ATQ component procedure explicitly locates G79 with G185 in the accelerator-pedal housing. It is a driver-request input, not the throttle body's angle sensor.

## Both pedal channels rise, but at different scales

The procedure observes display group 62 fields 3 and 4. Both values should rise uniformly as the pedal moves, with the G79 value approximately twice the G185 value. This differs from the opposing signals inside the throttle module.

The displayed percentages are calculated relative to a 5 V supply. Their listed ranges are service-display expectations, not a published P1630 setting voltage. The table does not provide that lower fault threshold.

## Separate input, supply, and wiring

When the displayed behavior is wrong, Volkswagen checks the two supply paths and grounds before condemning the pedal assembly. Its electrical procedure requires at least 4.5 V at the specified test points and separate harness continuity/short checks.

The code table flags the EPC lamp. If the pedal sensor is replaced on an automatic-transmission vehicle, the ECM must relearn the kick-down point. That completion requirement matters even if the new pedal immediately produces a changing value.

Verification should demonstrate smooth, correctly related pedal signals and the required adaptation. A normal throttle-body position reading cannot substitute for checking G79, because these are different sensors with different diagnostic roles.

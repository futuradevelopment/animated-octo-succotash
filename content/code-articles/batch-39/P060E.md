# P060E: Throttle-angle monitoring inside the DME

The BMW 200A08/P060E entry concerns an internal comparison of throttle-valve angle information. The DME detects deviations that are too large during its internal monitoring operations and stores the fault when the condition persists for more than half a second.

## An internal code can be secondary

The chart gives two possible origins: a collateral fault associated with the throttle valve and a defective DME. That ordering matters. Its first service instruction is to repair existing throttle-related faults. Calling the code an internal control-module failure does not remove the need to establish whether the throttle information feeding that comparison is already faulty.

The source does not publish the allowable angular deviation. Consequently, the half-second memory delay is usable context, but no particular difference in degrees can be inferred from this chart.

## Recurrence changes the decision

BMW specifies DME replacement when the recorded occurrence frequency exceeds three, after the related-fault direction has been considered. Retaining the original fault count is therefore more informative than repeatedly erasing the memory before documenting it.

Possible effects include a lack of response to accelerator input and pronounced shaking at idle. The source also notes that allowing the vehicle to enter sleep mode and restarting may temporarily restore operation. Temporary recovery is not proof of a completed repair: the internal comparison can fail again.

Diagnosis belongs with a technician who can correlate the throttle faults, occurrence counter, and actual module configuration. Reduced accelerator response should be treated as an operating problem requiring assessment, rather than a reason to rely on repeated restarts.

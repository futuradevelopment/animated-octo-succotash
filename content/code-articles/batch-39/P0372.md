# P0372: Missing crankshaft reference points

In the N62TU chart, BMW fault 2B5D/P0372 is stored after at least three crankshaft reference points are not detected. The monitor runs while the engine is turning with Terminal 15 active. This provides a concrete interpretation of “too few pulses”: the controller is losing expected reference information.

## Missing events narrow the investigation

A sensor may produce some output and still fail to deliver every required event. A basic observation that engine speed appears on the scan tool therefore does not settle this fault. The missing-reference criterion calls for attention to signal continuity and the relationship between the sensor and reluctor.

BMW directs checks of the plug, harness, and sensing geometry before replacing the sensor as indicated. That combination covers the electrical path and the physical generation of the reference pattern. The chart does not supply pin assignments, an air-gap dimension, or a universally correct waveform, so those details require the matching repair information.

## Secondary behavior can follow the lost reference

The listed reactions include emergency strategies for variable valve lift, VANOS, and RPM sensing, with the emissions lamp requested on the second driving cycle. Such reactions can complicate a symptom-based diagnosis: altered engine behavior after the code appears may be the controller's response to missing timing information.

A meaningful verification demonstrates reliable detection of the reference points during the relevant operating state. Clearing the memory or observing a momentary RPM reading is weaker evidence. The three-event criterion is specific to this source and should not be transferred to another BMW engine or another manufacturer's P0372 implementation.

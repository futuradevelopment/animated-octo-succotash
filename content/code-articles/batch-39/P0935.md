# P0935: SMG pressure-sensor input exceeds 4.7 volts

P0935 appears in BMW's SMG summary for test group 3BMXV03.0UL2. The row recognizes a hydraulic-pressure sensor signal above 4.7 V and identifies a short to supply as the monitored fault category. It is an electrical upper-limit check, not a calibrated overpressure warning.

## An implausible input can distort the pressure display

If the sensor circuit is held near its supply, a scan tool's translated pressure may be misleading. The diagnostic question is whether the measurement circuit is valid before deciding that the hydraulic pump or regulator is producing excessive pressure.

The table enables the check with the key on and cranking absent. It groups the entry with a continuous sub-500-millisecond interval and second-driving-cycle lamp behavior. An unusual bracketed supply-voltage notation is present in the original; its interpretation is not sufficiently clear to use as a workshop enable range here.

## Confirm the SMG application

Although the navigation path names a 2003 330i M54, the actual table is for SMG. It does not establish applicability to every automatic or manual transmission fitted to that model.

Appropriate diagnosis uses the exact sensor wiring and approved electrical checks to investigate the short-to-supply condition. The source does not give a connector assignment or a mechanical pressure test, and it does not direct replacement of a pump from this code alone.

Verification should establish that the sensor signal stays within a credible operating range and that the underlying pressure-control system functions correctly. High-pressure hydraulic work requires the corresponding professional service procedure.

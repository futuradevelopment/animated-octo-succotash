# P1385: BMW knock-sensor 4 circuit entry and its limits

The BMW N62TU chart maps P1385 to DME fault 2E6B and a knock-sensor 4 circuit entry. Unlike the separately described low- and high-input variants, this record does not provide a signal-amplitude threshold. Its service-action field directs DME replacement.

## Establish the exact fault identity first

That controller-directed action makes the complete BMW fault record important. The chart's P1332 and P1333 entries also share the 2E6B family but describe different input conditions and different service checks. A generic reader displaying only a brief sensor description can omit distinctions that affect the next repair decision.

For P1385, the stated operating conditions are engine running above 1,520 rpm, load factor above 25, and voltage between 9 and 15 V. The source does not define the load-factor unit. The memory-entry field specifies less than three seconds, and the emissions lamp is listed as enabled.

## Do not turn a short chart into an invented test

The published record does not supply connector measurements, a DME internal test, or a sensor resistance specification. It therefore supports explaining the documented controller-directed outcome, but not creating a substitute electrical procedure from the generic code title.

Before a control-module replacement, a technician should confirm that this is the applicable engine and fault variant and follow the complete replacement and programming instructions for the vehicle. This is particularly consequential because the chart does not tell the reader how to distinguish a wrong code interpretation from an actual controller fault. Verification must use the correct BMW diagnostic context rather than a code erase alone.

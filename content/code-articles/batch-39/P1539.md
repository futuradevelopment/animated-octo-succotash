# P1539: The clutch switch signal is implausible

Volkswagen P1539/VAG 17947 identifies an implausible signal from clutch vacuum vent valve switch F36. The ATQ component procedure explains that cruise control needs this signal to avoid tip-in shock. The code therefore concerns clutch-pedal information, not a measured clutch-friction condition.

## Watch the signal change with the pedal

The procedure observes the relevant bit in measured-value group 66. It should change from the unpressed to pressed state as the clutch pedal is operated. A value that remains fixed is different evidence from a switch that changes correctly but is interpreted inconsistently elsewhere.

The isolated switch test expects approximately zero resistance before pedal operation and an open circuit with the pedal depressed. This is a defined switching behavior, not a continuously variable position-sensor voltage.

## Separate the switch from its supply and wire

If the switch itself behaves correctly, Volkswagen proceeds to a supply check of at least 11.5 V and harness continuity toward the ECM. It also checks for shorts between conductors and to supply or ground. That sequence avoids replacing a functioning switch to correct a wiring fault.

This procedure applies to the clutch-switch-equipped configuration; a model navigation heading alone does not imply that an automatic-transmission vehicle has the same component.

Verification should demonstrate a reliable pedal-state transition in the module data and correct related system behavior. The code does not establish that the clutch assembly is slipping or requires replacement. Use the exact vehicle's wiring and switch installation information for the physical work.

# P1679: The EPC warning-lamp circuit is open

Volkswagen P1679/VAG 18087 identifies an open circuit for EPC lamp K132. Because that lamp communicates electronic engine-load-control faults, a failure of the reporting path deserves attention even when the driver sees no warning.

## The ignition-on check is useful evidence

The ATQ procedure expects the lamp to light when ignition is switched on. If it does not, the technician checks its fuses and the wiring between the ECM and instrument cluster, using the specified test-box arrangement to distinguish the lamp path from the controller.

An absent lamp therefore cannot be treated as evidence that there are no electronic-throttle faults. The code concerns whether the warning circuit can perform its function, not whether every system it reports is healthy.

## Open circuit and commanded illumination differ

The procedure separately assesses a lamp that illuminates but does not go out after the engine starts. P1679 belongs to the open-circuit category, so it should not be replaced by the neighboring ground-short interpretation without actual test evidence.

The source does not provide a universal resistance threshold for the lamp circuit or direct a throttle-module replacement. It eventually considers the ECM only after the relevant wiring checks.

Verification should restore the ignition-on lamp check and appropriate post-start response, with the open-circuit fault absent. The manual also calls for diagnostic-memory and readiness completion. Erasing P1679 while leaving the warning path inoperative would remove useful evidence without restoring the lamp's intended reporting function.

# P1858: The transmission receives an engine-speed fault message

Volkswagen P1858/VAG 18266 concerns engine-speed information received from the ECM. The chart describes a malfunction message and lists an incorrect speed signal, engine-speed sensor G28, an open intermodule connection, and incorrect or faulty control modules among the possible origins.

## Separate the source signal from its transmission

A fault stored in the transmission does not automatically identify a transmission speed sensor. This chart specifically concerns engine speed supplied by the engine controller. The next distinction is whether the ECM has valid source information and whether that information reaches the transmission correctly.

The service directions include measured-value group 001, wiring and connection checks, and assessment of both controllers. Those branches prevent the code from being reduced to a blind G28 replacement.

## Module identity also matters

The table includes an incorrect TCM or ECM as well as a defective one. Recent module replacement is therefore relevant history. A functioning but incompatible controller can require a different correction from a physically interrupted wire.

No numerical engine-speed threshold or message timeout is published in this chart. It should not be invented from the generic error-message title.

Verification should show credible engine-speed information in the appropriate controller data and no returning malfunction message after the source or transmission path is corrected. A working dashboard tachometer alone does not prove the specific ECM-to-TCM information path is valid. The exact installed gearbox and engine-controller configuration remain part of the applicability check.

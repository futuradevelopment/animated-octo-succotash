# P0934: SMG hydraulic-pressure sensor voltage falls below its limit

The source table for BMW test group 3BMXV03.0UL2 labels this system as SMG transmission control. Its P0934 row checks the lower electrical threshold of the hydraulic-pressure sensor: signal voltage below 0.4 V. The stated failure category includes an interruption or a short to ground.

## Low voltage does not establish low hydraulic pressure

The distinction between voltage and pressure matters. A pressure value derived from an electrically invalid input cannot establish whether the hydraulic system is actually underpressurized. This monitor directs attention to the sensor circuit before interpreting the displayed pressure as a reliable physical measurement.

The row requires the key on and no cranking. The source groups it with a continuously evaluated interval below 500 milliseconds and a second-driving-cycle lamp. Its supply-voltage field uses unusual bracketed ranges without explaining their meaning; those ranges are not reproduced as an instruction for testing the vehicle at abnormal voltage.

## Keep the transmission scope exact

The document is hosted under a 2003 330i M54 navigation path, but the table itself expressly identifies SMG and its test group. That internal scope takes precedence over assuming every 330i has this hydraulic system.

A technician should establish whether the low input comes from the sensor, its connections, or the applicable circuit. The table supplies no connector pinout or hydraulic-pressure target. Verification should show a valid electrical signal and correct system behavior using the exact SMG test plan, without opening pressurized components simply because P0934 is stored.

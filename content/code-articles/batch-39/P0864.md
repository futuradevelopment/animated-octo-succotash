# P0864: Touareg transmission communication is outside its expected behavior

Volkswagen's P0864 chart describes transmission-controller communication range/performance and directs correction of faults in CAN wires or other CAN components. It does not identify the TCM as the only possible failed part.

## The network includes two engine controllers

The BKW component procedure identifies engine controllers J623 and J624 for the two cylinder banks. Its termination checks are performed on the appropriate isolated controller using specified test-box adapters. The documented 115–135-ohm ranges apply to those individual test arrangements.

They are not a universal resistance target for a fully connected vehicle diagnostic connector. Measuring a network in a different configuration and comparing it with the isolated-controller value could create a false failure conclusion.

## Wiring remains a separate branch

When the controller termination checks are within range, Volkswagen directs investigation of the data-bus wiring or other components. A correct resistor result establishes only that part of the network assessment; it does not prove every message is being exchanged correctly.

The code chart supplies no specific message timeout or low-voltage threshold for P0864. It should not be silently rewritten as a total loss-of-communication code or a fixed electrical-low fault.

Verification should establish intact physical communication paths and correct information exchange among the relevant controllers, using the actual vehicle configuration. The source's test prerequisites include ignition off for the resistance assessment. Module replacement should follow the supported branch rather than the generic appearance of “TCM” in the code title.

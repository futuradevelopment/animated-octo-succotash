# P1558: The electronic throttle drive has an electrical malfunction

Volkswagen P1558/VAG 17966 identifies an electrical malfunction in throttle drive G186. The ATQ throttle module combines that motor with two opposing angle sensors, G187 and G188. The DTC table also associates this fault with the EPC warning lamp.

## Check motor behavior separately from angle feedback

The component procedure observes the two throttle-angle signals in measured-value group 62. One increases as the valve opens while the other decreases. Correct interpretation therefore requires their opposing direction, not an expectation that both percentages rise together.

If behavior is incorrect, the test distinguishes motor resistance, voltage supply, wiring integrity, and the separate accelerator-pedal inputs. Its motor-resistance test range is 3–200 ohms, but this is a workshop-check specification and not a published P1558 recognition threshold.

## Replacement has an adaptation requirement

The procedure requires the throttle valve to be clean and undamaged for testing. If J338 is replaced, it must be adapted to the ECM; automatic-transmission vehicles also require the applicable transmission adaptation. Installing a component and merely clearing faults omits that documented completion requirement.

P1558 does not establish which internal module element or external wire failed. A technician should use the exact connector arrangement and approved tests before choosing the module or controller.

Verification should demonstrate correct electrical drive, smooth opposing feedback, and successful required adaptation. The electrical code should not be treated as proof of a mechanically binding valve without separate evidence.

# P1322: W8 knock sensor 3 reports high input

P1322 identifies a high signal from knock sensor 3, G198, in Volkswagen's BDP W8 chart. This is not the cylinder 3 knock-control-limit code used in another engine's code family. Confirming the engine and sensor identity is essential.

## Inspect the physical signal path

The W8 procedure makes clean, corrosion-free, grease-free block contact surfaces and a 20 Nm securing torque prerequisites for correct operation. It also directs inspection of the sensor and wiring. A high signal therefore should not be reduced to a conclusion that fuel quality is necessarily wrong or that the sensor alone has failed.

The factory chart does not publish the upper voltage at which P1322 is stored. It supports the direction of the error and the component-check sequence, not a universal high-input threshold.

## Keep the two Bank 2 sensors distinct

The component procedure identifies G198 as sensor 3 and G199 as sensor 4, with different connector identification. It instructs the technician to mark connector allocation before disconnecting them. That detail helps prevent creating a new identification problem during diagnosis.

The electrical checks distinguish sensor isolation from harness continuity and shorts. Controller replacement appears only after the relevant wiring branch, not as the initial conclusion from this code.

Verification should establish correct attachment, connector allocation, and electrical integrity, then reassess the high-signal entry. These checks require the exact W8 wiring and test setup. The code alone cannot establish a specific mechanical engine defect or an overheated component.

# P1851: The transmission misses an ABS control-module message

Volkswagen P1851/VAG 18259 reports a missing message from the ABS control module on the engine/transmission data bus. The chart includes wiring faults, incorrect or faulty modules, and ignition switched on while transmission controller J217 was disconnected.

## Service history can explain an isolated entry

A communication code recorded during a disconnected-controller service event is different evidence from one that repeatedly returns with every module connected. That history should be recorded before a module is condemned.

The chart directs measured-value groups 008 and 009, wiring checks, and identification checks for the ABS, transmission, and engine modules. A missing message identifies information not received; it does not prove which participant caused the absence.

## Network measurements need the specified setup

Volkswagen's ATQ CAN procedure describes paired twisted wires and a central termination arrangement in the ECM. Its resistance test is performed with the controller isolated from the harness using the specified test box. That result must not be confused with a generic resistance measurement across a fully connected diagnostic connector.

The ABS-related code does not establish that braking is normal or defective; actual warnings and system operation require professional assessment.

Verification should confirm compatible module identities, intact communication, and no returning missing-message fault. Replacing the ABS controller solely because it is named in the message description would skip the wiring, service-history, and receiving-module possibilities explicitly included in the source.

# P1410: The N80 purge-valve circuit is shorted toward supply

Volkswagen P1410/VAG 17818 identifies a short to B+ in the N80 evaporative-canister purge-regulator circuit. The ATQ source directs output testing of that valve. This is an electrical control-path diagnosis, not proof of an external fuel-vapor leak.

## Separate commanded response from flow behavior

The output-test procedure expects N80 to click repeatedly while selected. If it does not, the next branch evaluates the electrical command at the disconnected connector using the specified test equipment. A command present without valve response and a missing command lead to different investigations.

The component functional check adds another distinction: N80 is closed when unpowered. Its warm-engine tank-venting test uses a controller-completed result and can be interrupted if engine load changes. Hearing a click during output testing does not, by itself, establish that the entire purge-flow function has passed.

## Use the circuit-high information

P1410's B+ branch makes unwanted connection to supply relevant. The source checks the wiring and control path before reaching a controller-replacement decision. It does not direct replacement of the fuel cap or canister from this electrical code alone.

Verification should establish correct controlled valve response and the applicable functional result. The output test also operates other components in sequence and runs the fuel pump; it belongs within the complete workshop procedure. Erasing the entry without checking the supply-side fault can leave the same electrical problem present even if the vehicle has no obvious drivability complaint.

# P1587: The W8 engine-mount solenoid circuit is shorted to ground

Volkswagen's W8 chart describes P1587 as a short to ground in the left/right electro-hydraulic engine-mount solenoid circuit, naming N144 and N145. Its linked component procedure specifically details the left valve N144, so it should not be assumed to provide every right-side connector assignment.

## The electrical valve is distinct from the mount structure

The component check measures the solenoid itself with ignition off and specifies 25–35 ohms. If that value is correct, Volkswagen moves to wiring continuity and checks for shorts to ground or supply. Thus a structurally intact mount can still have an electrical control problem, and an electrical DTC does not itself prove torn rubber or fluid leakage.

The procedure requires the relevant fuses to be sound. An electrical feed or harness condition should be established before attributing the code to the mechanical mount assembly.

## Retain the left/right limitation

The DTC row covers both named valves, while the provided test details focus on N144. The actual installed circuit and affected side must be identified with the vehicle wiring diagram. Guessing the side from P1587 alone would go beyond the chart.

The source ultimately considers the ECM only after the valve and wiring checks. It does not rank components by failure probability or describe a specific vibration symptom.

Verification should demonstrate correct solenoid electrical behavior and no returning ground-short entry, with diagnostic memory and readiness completed as required. The resistance specification belongs to this W8 procedure and is not universal for all electronically controlled mounts.

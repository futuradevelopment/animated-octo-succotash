# P1854: A hardware fault disrupts the powertrain data bus

Volkswagen P1854/VAG 18262 identifies a faulty engine/transmission data bus. The chart lists a short between the bus conductors, an open or short between the controllers, and faulty engine or transmission modules as possible causes.

## Shared wiring can affect several modules

The service direction begins with the connection between engine and transmission control and uses measured-value groups 008 and 009. Multiple communication complaints can therefore reflect one shared electrical path rather than several independent failed controllers.

The ATQ CAN procedure explains that messages travel on the twisted CAN-high and CAN-low pair. It distinguishes a controller termination-resistance test from a separate harness short test. Those are different electrical configurations and cannot be collapsed into one universal “CAN resistance” reading.

## Apply the exact test arrangement

The source's controller resistance specification is measured with the ECM separated from the vehicle harness through the specified test equipment. Applying that value to a fully connected network would use the wrong setup. The harness tests likewise require the applicable disconnections and wiring diagram.

The procedure eventually permits controller replacement where supported, but P1854 does not by itself identify which module is defective. It is also not a direct diagnosis of internal transmission wear.

Verification should establish a sound physical bus path and restored message exchange, then reassess the original fault. A temporary return of scan-tool communication is useful but insufficient if an intermittent interwire short remains. The exact ATQ network scope must be preserved when using these source-specific checks.

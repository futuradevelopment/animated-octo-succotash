# P1149: An implausible Bank 1 oxygen-control value

Volkswagen P1149/VAG 17557 identifies an implausible Bank 1 oxygen-control value. The ATQ chart points specifically to the aging check for Bank 1 sensor 1. That direction is different from the neighboring codes that explicitly describe a lean or rich system.

## The aging test needs enough heat

The component procedure requires coolant temperature of at least 85°C. During the basic-setting test, it uses an engine-speed range of 1,000–2,400 rpm and waits for the displayed catalyst temperature to exceed 350°C before assessing completion.

Those prerequisites explain why a cold sensor or a short idle observation cannot establish whether the aging test passes. The relevant outcome is the controller's completed test result, not simply seeing some oxygen-sensor voltage.

## An initial failure is not the final replacement decision

Volkswagen directs a road test to clear possible sensor residue and then repeats the aging check if the expected result is not obtained. Replacement of the Bank 1 upstream sensor follows a repeated failure. This sequence distinguishes a reproducible aging problem from an inconclusive first attempt.

The procedure should be performed by a technician with appropriate equipment and safe operating conditions. The chart does not supply a universal sensor switching-time threshold that can replace its basic-setting routine.

After diagnosis and repair, fault memory and readiness must be addressed as specified. Erasing the code can reset readiness, so an empty fault list immediately afterward is not equivalent to a completed aging test. The sensor identity remains Bank 1 before the catalyst, not Bank 1's downstream monitoring sensor.

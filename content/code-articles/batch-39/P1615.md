# P1615: Oil-temperature plausibility and the correct sensor identity

Volkswagen's ATQ chart maps P1615/VAG 18023 to an implausible oil-temperature signal. The fault-description column names G8, while the service-action column directs a wiring check to the oil-level thermal sensor G266. Those two identifiers must not be silently treated as an interchangeable parts order.

## Verify the installed measurement arrangement

The useful supported direction is to investigate the oil-temperature information and its wiring. The source does not publish an allowable temperature gradient, a voltage threshold, or a comparison with coolant temperature. No such trigger should be invented from the word “implausible.”

Because the row uses different component names, the actual vehicle wiring and equipment configuration must establish which sensor supplies the relevant information. A technician should resolve that identity before disconnecting or replacing a component.

## A plausibility entry is not proof of overheating

The code describes information that the controller cannot accept as plausible. It does not, by itself, establish an actual excessive oil temperature or inadequate oil level. Those physical conditions require their own reliable measurements and applicable checks.

This chart is narrower than a complete repair procedure: it supplies a signal description and wiring direction, but no ranked cause list or replacement decision. Verification should demonstrate credible oil-temperature information from the correctly identified source and no recurrence of the fault.

The G8/G266 naming difference remains a documented limitation of this source. It should be resolved against the exact ATQ vehicle data rather than hidden behind a generic recommendation to replace an “oil sensor.”

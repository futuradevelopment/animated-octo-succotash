# P1332: Knock sensor 4 has insufficient signal

The N62TU chart identifies BMW 2E6B/P1332 as low input from knock sensor 4. The monitor is active with the engine running above 2,000 rpm, a listed load factor above 25, and supply voltage between 9 and 15 V. The chart does not define the load-factor unit, so it should not be silently relabeled as a percentage.

## Attachment is part of the signal path

BMW's service instruction checks connectors and wires and inspects the sensor mounting torque before considering sensor replacement. That is a meaningful distinction from treating this code as a generic indication of abnormal combustion. The source is concerned with insufficient sensor input, and a mounting problem can be relevant to what the sensor detects.

The memory-entry field specifies less than three seconds. The source does not publish a low-signal voltage threshold, so a technician needs the applicable test plan to determine whether a particular measured waveform is acceptable.

## Test in the relevant operating region

An idle-only assessment does not reproduce the chart's above-2,000-rpm enable condition. Likewise, a sensor that looks physically intact has not passed the specified connector, wiring, and mounting checks.

The emissions lamp is listed as enabled, but the chart provides no particular drivability symptom. It also does not identify a cylinder pairing for sensor 4 here. Use the exact engine's component-location and tightening information instead of inferring location from the sensor number. Verification should confirm a valid input after the relevant electrical and mechanical attachment issues have been addressed.

# P1147: Bank 2 oxygen-sensor control indicates a lean system

P1147/VAG 17555 describes a lean result in Bank 2 oxygen-sensor control. Volkswagen's ATQ procedure evaluates the upstream feedback system rather than treating the code as an automatic oxygen-sensor replacement instruction.

## Establish the test conditions first

The check requires coolant temperature of at least 80°C, a sound fuse 34, and a sealed exhaust path between the cylinder head and catalytic converter. Exhaust leakage is therefore relevant to the validity of the feedback information, not merely an unrelated noise concern.

The procedure first checks oxygen-sensor control status. If that status is incorrect, it directs attention to the heater before interpreting the mixture-control readings. This prevents a cold or improperly heated sensor from being assessed as though it were operating normally.

## Distinguish adaptation from immediate feedback

Volkswagen separates additive idle adaptation from multiplicative partial-throttle adaptation in display group 32. It then examines active control and sensor-voltage movement in group 33. A static reading at one operating point does not cover all of those checks.

The published adaptation check uses a −10% to +10% range; this is a service-test specification, not an independently stated P1147 setting threshold. The source also expects changing sensor output, rather than a value frozen at one level.

Verification should establish valid Bank 2 feedback under the specified warm conditions and determine why the lean correction occurred. The DTC alone cannot distinguish an actual mixture problem from faulty measurement information, and a code erase does not complete the required functional assessment.

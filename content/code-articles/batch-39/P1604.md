# P1604: An internal engine-controller fault requires identity and supply checks

The ATQ table identifies P1604/VAG 18012 as a faulty control module and directs replacement of Motronic ECM J220. The imported catalog calls it an internal driver error, while this factory table uses broader wording and does not disclose the internal self-test criterion.

## Confirm the controller context

Volkswagen's voltage-supply procedure requires at least 11.5 V, a sound fuse 32, and a functioning generator. It distinguishes permanent and ignition-switched supply paths. Those checks do not redefine P1604 as a low-voltage code; they provide the electrical context needed before an expensive controller intervention.

The DTC chart itself contains no driver-output pin test or numerical internal-fault threshold. Inventing either would go beyond the evidence.

## Coding is part of the replacement outcome

The ECM coding procedure requires identification and coding appropriate to the vehicle. Volkswagen warns that incorrect coding can create drivability problems, nonexistent fault entries, and missing functions. It also states that the displayed coding is adopted only after the ignition has been switched off.

Therefore, replacement is not complete simply because a physically compatible box communicates with a scan tool. The installed unit's identity, vehicle configuration, and required coding must be verified by a qualified technician.

Completion should confirm correct controller configuration and absence of the original internal fault after the applicable checks. The source supports a controller-directed service decision but does not establish that every generic P1604 on every Volkswagen uses this ATQ interpretation or replacement process.

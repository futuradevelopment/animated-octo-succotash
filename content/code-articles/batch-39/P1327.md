# P1327: Knock sensor 2 reports too little engine noise

For the N63 chart, P1327 corresponds to BMW 168102 and monitors the knock sensor assigned to cylinders 3 and 4. The defined problem is insufficient signal level: voltage remains below 0.06 V. It is not a direct declaration that those cylinders have suffered detonation damage.

## Why mounting is part of diagnosis

The source names a loose knock-sensor screw and a wiring defect between the sensor and DME as possible causes. A knock sensor must transmit information about engine vibration, so its mechanical attachment belongs in the investigation alongside the electrical path. The chart directs attention to the mounting before the eventual sensor replacement step.

The monitor operates above 1,500 rpm and requires the condition to last for more than 20 crankshaft revolutions before storing the fault. The table also contains an airflow enabling value with an unusual printed unit; that value should not be used as a workshop specification without the matching calibrated service information.

## What a quiet signal does and does not prove

An engine that sounds quiet to the driver can still have a signal path that is too quiet for this diagnostic check. Conversely, changing fuel grade would not establish whether a loose sensor or interrupted harness is preventing normal vibration measurement.

The chart lists reduced power as a possible effect. Verification should establish that the correct sensor is securely installed to the vehicle's specified procedure and that its signal remains credible in the monitored operating region. The code alone does not distinguish a failed sensor from a connection or attachment problem.

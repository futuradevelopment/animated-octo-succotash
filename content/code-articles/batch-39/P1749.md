# P1749: The transmission controller recognizes incorrect coding

Volkswagen P1749/VAG 18157 describes incorrect coding recognized by the automatic-transmission controller. The chart identifies both invalid transmission coding and an incorrectly coded or incorrect engine controller as possible origins.

## Check the module pair, not just one box

The service action calls for checking both the transmission and engine control modules. A code stored in the transmission therefore does not prove that the transmission controller alone is wrong. A recently replaced ECM or changed vehicle configuration is relevant history.

Volkswagen's ATQ coding procedure requires a five-digit engine-controller code appropriate to the vehicle. It states that the displayed coding is adopted after ignition has been switched off. A diagnostic screen showing a newly entered value before that completion step is not the whole verification.

## Coding can create misleading secondary symptoms

The manufacturer lists drivability and shifting effects, incorrect fault entries, and missing functions among the consequences of wrong coding. Those effects help explain why a configuration problem can resemble several unrelated component failures.

The correct code must be established from the exact vehicle configuration; the procedure's sample coding is not a universal value to copy. This article does not supply a replacement coding number.

Verification should confirm correct module identities, compatible engine/transmission configuration, accepted coding, and resolution of the related fault behavior. Replacing mechanical transmission parts or clearing P1749 without checking the paired controller configuration would not address the specific evidence in this chart.

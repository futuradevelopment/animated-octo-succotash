# P1761: The shift-lock solenoid circuit is shorted to ground

The Volkswagen chart maps P1761/VAG 18169 to a short to ground at shift-lock solenoid N110. It lists the solenoid, wiring, Tiptronic recognition switch F189, and transmission controller among the possible sources.

## Selector electronics belong in the investigation

The inclusion of F189 is significant. The chart does not isolate N110 as the only component capable of producing the electrical fault. It directs measured-value group 003 and an electrical check before the listed switch or controller replacement outcomes.

The referenced F189 assembly is described as the symbol strip with integrated circuitry. That identity must be matched to the actual selector equipment; the code does not justify ordering an unrelated transmission solenoid from the similar name.

## A shift-lock problem is not a gear-ratio failure

This entry concerns selector-lock electrical control. It does not itself establish that the transmission's internal clutches are slipping or that hydraulic shift control has failed. An inability to select a range, if present, must be assessed in the context of the lock system and vehicle condition.

The source provides no universal coil resistance or connector pinout. Diagnosis should use the correct selector and transmission wiring, with the vehicle secured appropriately. Bypassing the lock is not a repair of the short-to-ground condition.

Verification should establish correct commanded lock operation and absence of the electrical fault, including any implicated selector electronics. Clearing the code without confirming those functions can leave the same control problem present.

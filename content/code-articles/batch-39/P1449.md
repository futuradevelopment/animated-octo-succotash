# P1449: DMTL reference-measurement current is too high

In BMW's N63 chart, 190401/P1449 is a DMTL pump-current fault during the reference-measurement phase. The recognized threshold is current above 40 mA. This identifies a problem with the leak-diagnosis module's operating behavior; it does not itself measure a hole in the fuel tank or prove that a fuel cap is leaking.

## A specific operational test matters

The chart's service sequence requires the DMTL fault memory to be cleared before running the DMTL operational test. Replacement follows if that test reproduces the fault. The service note explains why: the operational test cannot run while DMTL-related faults remain logged.

That instruction should be understood as part of a documented diagnostic session. Record the original entry before erasing it, because clearing memory merely allows the test and does not demonstrate a repair.

## Conditions are not interchangeable

The published conditions include electrical-system voltage above 10.95 V and below 16 V, ambient temperature from 1.5°C to 38°C, and fuel level between one-quarter and three-quarters. Crucially, BMW says these conditions apply to the function test and not to normal-operation diagnosis. Treating every listed condition as a universal rule for when the car can set P1449 would misread the chart.

The fault is recorded immediately and no particular apparent symptom is listed, although the US emissions lamp is enabled. Verification rests on reproducing and resolving the excessive reference current, with the correct operational-test prerequisites, rather than replacing evaporative-system parts solely from a generic leak interpretation.

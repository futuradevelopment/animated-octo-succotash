# P0782: The second-to-third shift fails its speed plausibility check

The BMW summary table classifies P0782 as a rationality problem during the second-to-third shift. It uses transmission input/output information to evaluate whether the expected change has occurred. This is a shift-performance observation, not an electrical identification of a particular solenoid.

## The shift event supplies the evidence

The row applies when the selector is outside Park, Neutral, and Reverse and output speed exceeds 500 rpm. Its monitoring interval is 90 milliseconds, continuously evaluated. These conditions explain why operating the selector while stationary is not equivalent to testing the monitored shift.

The printed comparison relates input speed in the old gear to input speed in the new gear, using a 40-rpm offset. Because it is presented as a compact inequality without a full timing diagram, it should not be converted into a universal workshop slip limit. What is clear is that the controller is judging speed change across the requested gear transition.

## What the code cannot isolate

An abnormal transition can require investigation of the transmission's control, hydraulic operation, and speed information, but this table does not rank causes or prescribe a valve-body replacement. It also distinguishes P0782 from a separate excessive-value entry for the same shift.

The emissions-lamp column specifies two driving cycles. Verification should establish correct behavior during the actual second-to-third transition, using the identified transmission and calibration. A code erase or a normal first-to-second shift does not address this particular monitor. The table is a monitor summary, not a complete transmission repair tree.

# P0173: Bank 2 fuel correction reaches the monitor limit

The BMW M62 TU summary groups P0173 with fuel-system trim-limit monitoring. Its threshold is a correction magnitude beyond 24%, evaluated while the fuel system is in closed loop. The table includes both short- and long-term correction in the monitored group.

## Determine the direction of correction

P0173's general trim-malfunction label does not specify whether the controller is adding or removing fuel. The positive or negative direction of the actual recorded correction therefore matters. Those two observations lead to different diagnostic hypotheses; the code string alone cannot choose between an air-metering discrepancy, fuel-delivery issue, or misleading feedback.

The table describes immediate, continuous evaluation and a two-driving-cycle lamp requirement. Those columns distinguish fault recognition from when the emissions lamp is requested. They do not mean that a single code erase immediately restores completed monitoring.

## Closed loop is a meaningful condition

A cold-start open-loop snapshot does not reproduce the listed fuel-system state. The relevant evidence comes from the feedback-controlled operating region, together with the vehicle's actual adaptation values.

This source is a monitor summary, not a complete fuel-system diagnostic tree. It gives no fuel-pressure specification, oxygen-sensor replacement instruction, or ranking of causes. A large correction establishes that the controller has reached its correction boundary, not which component is responsible.

Verification should demonstrate appropriate Bank 2 correction in the relevant operating conditions after the cause is found. The 24% value belongs to this documented summary and must not be treated as a universal threshold for all vehicles displaying P0173.

# P0850: A park/neutral plausibility code is not a direct mechanical-park verdict

P0850 appears in Ford’s diesel summary under the transmission park/neutral gear check at startup. The monitor is described as a park/neutral switch plausibility check, rather than a direct mechanical test of the parking lock. That distinction prevents a generic input-circuit label from becoming an unsupported conclusion about transmission hardware.

## Startup state and input credibility matter

The table specifies continuous monitoring with one second to register a malfunction. The source does not publish the input-voltage boundary, switch-state combination or detailed logic used to judge plausibility for P0850.

A later normal range display therefore cannot, by itself, recreate the startup information that produced the code. Equally, a displayed park or neutral state is not direct evidence that every related mechanical or electrical function has passed a test.

## Preserve the actual configuration and event

Record the complete identifier, reporting module, requested range and startup conditions. The summary does not establish that every application uses a directly wired mechanical switch; the correct signal path must come from vehicle-specific information.

The code alone cannot locate a defective selector, harness or control module. Verification should use the applicable park/neutral input and plausibility procedure while keeping the vehicle securely immobilized. It does not justify bypassing a starting interlock or deliberately testing whether a vehicle can move in an uncertain range state.

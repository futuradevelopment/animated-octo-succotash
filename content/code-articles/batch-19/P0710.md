# P0710: Transmission-temperature circuit evidence must be separated from a substituted value

P0710 is included in Ford’s transmission-fluid-temperature electrical open/short group. The source separates these electrical checks from longer functional temperature assessments. Treating every temperature-related fault as an actual overheating event would lose that distinction.

## Electrical thresholds are different from thermal behavior

The document lists a five-second electrical monitoring duration versus 600 seconds for the functional check. Its electrical threshold paragraph gives a TFT voltage below 0.05 V or above 4.6 V for a stated 5–12-second interval. These are published example conditions, not one universal detection delay for every transmission.

The same page separately identifies overtemperature and in-range functional behavior. A voltage outside the electrical limits does not by itself establish that the fluid actually reached an excessive temperature.

## Account for substituted information

Ford notes that engine-coolant temperature is substituted if TFT malfunctions. An internally substituted value must not be mistaken for independent proof that the original transmission-temperature sensor has become reliable.

Preserve the complete fault, original signal availability, operating state and whether substitution is active in the applicable system. The summary does not provide a universal connector pin, resistance curve or sensor replacement instruction. Vehicle-specific diagnosis must determine whether the electrical evidence comes from the sensor, wiring or input circuitry while keeping actual fluid temperature and fallback information distinct.

# P06B9: Cylinder1 glow resistance is checked after basic electrical faults

P06B9 is Ford’s cylinder 1 glow-plug resistance range/performance entry. The source places this check after open-circuit, short-to-battery and short-to-ground testing. That sequence is important: a resistance assessment should not be treated as the first or only interpretation when a basic electrical fault is also present.

## The resistance check has its own operating state

The monitor runs while glow plugs are heating and lists approximately three seconds to register a malfunction. The resistance panel provides an individual-circuit value above 2 ohms, but the threshold caption instead reads short to battery. The value is therefore retained as a documented resistance-panel statement with a source-review limitation, not a universal cold-bench acceptance specification.

An electrically continuous circuit can differ from one whose resistance is acceptable during the monitored heating condition. Passing an open-load check alone does not establish that the later performance assessment passed.

## Preserve sequence and channel evidence

Record cylinder 1 identity, heating command and the results of the preceding electrical checks before interpreting the performance entry. The source shares the method across glow channels; P06B9 identifies which channel produced the result.

The summary does not locate excess circuit resistance within the plug, wiring or driver. Vehicle-specific testing must resolve the caption ambiguity and actual operating specification before a repair decision. It does not support direct powering or automatic glow-plug replacement.

# P211B: A stuck-closed throttle B result is a control-state finding

P211B identifies the stuck-closed control result for throttle B in Ford’s dual-throttle monitor. Its detailed representation is P210A_73. The code describes an achieved control state, not a direct diagnosis of a damaged motor, dirty plate or broken harness.

## Keep the fault direction intact

The source lists P211A separately for stuck open and P211C for motor-current range/performance. Those classifications ask different questions. A current fault cannot be assumed from a closed-position result, and a later throttle position must be compared with the command that applied at that time.

The actuator monitor operates continuously and gives a registration duration below five seconds. This describes detection timing; it is not evidence that the fault is permanent or that a single static position reading recreates the original event.

## Interpret the result within dual-throttle feedback

Throttle B also has a documented position-sensor communication path. Preserve its status and any communication or intermittent-signal codes, because a control interpretation depends on understanding the information available to the controller.

Useful verification records identify which throttle and subtype were reported, the requested state and the observed response. The source supplies no numerical closed-stop tolerance or direct component test for P211B. A repair decision must therefore follow the correct vehicle procedure, rather than replacing an assembly solely from the phrase “stuck closed.” The dual-throttle scope must remain explicit when comparing this article with another engine’s diagnostic behavior.

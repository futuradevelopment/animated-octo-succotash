# P211A: Identify throttle B before interpreting a stuck-open report

P211A is Ford’s stuck-open control classification for electronic throttle B on dual-throttle applications. The table maps it to P210A_72. The B designation is therefore a real architectural boundary: a generic scanner description alone does not establish where the second throttle is fitted on an unknown vehicle.

## Separate commanded travel from signal communication

The throttle-controller group runs continuously and specifies less than five seconds to register a malfunction. Within the same group, stuck closed and motor-current performance have different entries. A stuck-open classification should not be treated as interchangeable with either electrical-current evidence or the opposite travel fault.

Ford also gives throttle B its own position-sensor communication checks on the preceding page. If position information is missing or internally faulted, that evidence must be retained alongside the controller result; the base code alone cannot establish which physical part caused the disagreement.

## What the summary leaves to the vehicle procedure

Capture the complete subtype, requested throttle state, available position information and companion faults. These observations help distinguish an inability to achieve a commanded state from an investigation centered on the reliability of feedback.

The summary does not publish a stuck-open angle threshold, a permitted tracking error or a universal cleaning or replacement instruction for P211A. It also does not justify forcing the throttle plate or inducing an unsafe operating condition. Matching the dual-throttle system and the applicable service test is necessary before translating this controller classification into a repair.

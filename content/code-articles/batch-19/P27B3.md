# P27B3: The transmission architecture determines what this supervision code means

P27B3 illustrates why an internal transmission-performance code needs an architecture boundary. Ford’s supervision list describes P0701_9A and P0701_94 in relation to selectable one-way-clutch electrical and shutoff-path behavior on eight- or ten-speed automatic applications. The TR9070 dual-clutch table uses those representations within CAN-transmit safety monitoring.

## Do not merge distinct documented contexts

The common code display does not establish that an unknown vehicle has the same actuator or safety function as another application. The transmission identity and full failure representation must be preserved before interpreting “gear select performance” as a particular mechanical fault.

For the electronic-throttle supervision list, monitoring is continuous and the general registration period is below one second. The P27B3 entries are marked non-MIL. These facts do not create a universal failure-time specification for every separate transmission table.

## Identify the information that was being supervised

A useful record retains the reporting module, subtype, requested operation and related communication or actuator findings. An electrical supervision result and an unintended-application/shutoff-path result should not be treated as the same evidence.

The summary provides no universal wire, clutch-location or replacement decision for P27B3. Verification must follow the applicable transmission’s diagnostic description rather than importing the selectable-clutch interpretation into the dual-clutch context, or vice versa. This preserves the source’s actual limits while keeping the code useful for organizing the next investigation.

# P26C5: An exhaust-valve open report is different from a stuck-valve result

P26C5 identifies the control-circuit/open classification for exhaust flow-control valve A in Ford’s bank 1 section. Its detailed representation is P26C5_13. The smart driver reports an output-circuit fault, which is a different form of evidence from deciding whether the valve reached its commanded position.

## Two monitoring paths should not be merged

The electrical group is continuous and lists five seconds of monitoring. The same page separately describes performance reporting through a PWM signal and a position-rationality check. That rationality check has a duration that varies with ambient conditions.

Consequently, applying the five-second electrical duration to every valve-performance complaint would misread the document. A successful position comparison also does not automatically explain an earlier electrical-open classification.

## Keep bank and failure type in the record

Preserve the bank 1 identity, complete suffix, commanded state and driver fault indication. The document’s second-bank section uses a different base-code family, so a similar generic description should not be treated as proof of the same physical valve.

The source does not publish an open-circuit resistance limit, connector pin or universal direct-actuation test for P26C5. Appropriate verification must establish the electrical fault path using the vehicle’s circuit information. It cannot conclude from this code alone that the valve is mechanically jammed or that the exhaust assembly requires replacement.

# P0500: A diesel vehicle-speed code can describe missing CAN information

P0500 is often displayed as vehicle speed sensor A, but Ford’s cited diesel monitor describes a communication-plausibility condition. It sets the classification when the vehicle-speed signal is missing from the CAN system for 0.5 second. That is a specific data-availability test, not a published sensor-voltage threshold.

## Identify how vehicle speed reaches the controller

The monitor runs continuously. A successful engine-speed reading does not establish that the separate vehicle-speed information was available, and a later normal speed display cannot reconstruct a short missing-message event.

The table does not identify a universal physical speed sensor or say that the ECU reads that sensor directly. A generic title should therefore not be used to select a transmission or wheel sensor without understanding the vehicle’s network architecture.

## Preserve communication evidence around the event

Record the reporting module, available vehicle-speed data, fault timing and any simultaneous network or source-module faults. These observations help distinguish absence of the information from a plausibility disagreement about a value that was actually received.

The 0.5-second criterion belongs to this Ford diesel example. It cannot be applied to every P0500 implementation or substituted for another module’s timeout. The summary does not prove a failed sensor, network wire or controller. Vehicle-specific diagnosis must establish which source supplies the speed information and why it was unavailable before a repair is selected.

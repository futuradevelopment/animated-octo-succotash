# P26C4: Clutch-pedal supervision can identify a channel or a disagreement

P26C4 is Ford’s internal clutch-pedal performance classification for manual-transmission applications. Its detailed entries distinguish sensor A performance, sensor B performance and correlation between the two, represented as P08A7_48, P08B4_48 and P08B9_48. Those are not three interchangeable descriptions of a worn clutch.

## Separate pedal information from clutch mechanics

The entries are marked non-MIL and sit within continuous internal supervision. The shared monitoring duration is below one second except for expressly identified other-code exceptions. A rapid internal result can therefore be retained even if later pedal readings appear normal.

A channel-performance finding concerns one input; a correlation finding concerns their relationship. Preserving that distinction helps determine whether the next evidence should focus on one signal or on how both signals represent pedal state together.

## Verify the architecture and full identifier

Record the reporting module, detailed suffix, pedal state and available A/B readings. The document explicitly limits these entries to manual-transmission applications, so the generic code cannot be used to infer that an unknown vehicle has the relevant dual-input arrangement.

No universal pedal voltage, angular tolerance or replacement instruction is published here. The summary does not prove clutch slip, hydraulic failure or a defective pedal assembly. The applicable vehicle procedure is needed to explain the supervisory disagreement before converting a signal-performance report into a mechanical repair recommendation.

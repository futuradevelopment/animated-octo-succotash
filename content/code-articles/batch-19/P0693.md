# P0693: Fan2 circuit low can include an open relay circuit in this Ford monitor

P0693 identifies the low circuit classification for fan 2 in Ford’s diesel summary. The documented malfunction description includes either an open circuit or a short to ground detected by the secondary electric cooling-fan relay. A generic “low” label therefore does not uniquely identify one electrical failure path.

## Relay evidence differs from fan operation

The monitor runs continuously and lists a typical duration of 0.5 second. It evaluates the relay/control-circuit condition, rather than directly measuring whether the fan moves enough air or whether coolant temperature falls.

A stationary fan is not, by itself, proof of this electrical result, particularly without knowing whether operation was requested. Conversely, a fan that operates later does not reconstruct a short control-circuit event stored earlier.

## Preserve the alternatives named by the source

Record the full code, secondary-fan identity, command state and available relay fault information. Because the source explicitly allows both open and short-to-ground classifications under P0693, an isolated code cannot decide between them.

The table supplies no universal connector pin, voltage cutoff or relay resistance for this monitor. Vehicle-specific circuit diagnosis must establish which path produced the report before a relay, fan or controller is condemned. The code does not directly establish a cooling-system mechanical fault or justify replacing a fan solely from a temperature complaint.

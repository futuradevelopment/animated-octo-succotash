# U016C: Missing pump B feedback is different from an internal-error message

U016C is Ford’s loss-of-communication classification for fuel-pump control module B in the cited returnless fuel-system example. The source describes no usable fuel-pump monitor feedback, represented by a 0% or 100% duty cycle. These values concern the diagnostic feedback signal, not a request to run the pump at zero or full speed.

## A missing report differs from a reported internal fault

The same table gives P26EA a 30% ±4% feedback band for a driver-module internal error. Receiving that diagnostic pattern is different from having no meaningful monitor feedback. A code reader that groups both as a “fuel pump module fault” loses this distinction.

The check runs continuously within an 11–16 V battery window and lists a two-to-five-second monitoring duration. Both continuous and intermittent U016C representations are identified, making the complete suffix useful when interpreting the history.

## Preserve the waveform and module identity

A diagnostic record should retain module B identity, the full code, eligible supply state and the available feedback pattern. A fuel-pressure symptom alone does not establish why the feedback disappeared, while a later normal pressure reading does not restore the missing event evidence.

The summary does not localize the problem to communication wiring, power supply or internal electronics. Verification must follow the vehicle’s actual feedback architecture rather than assuming a conventional CAN fault or replacing the pump from the communication label.

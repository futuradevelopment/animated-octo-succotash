# P261A: Pump B open-circuit monitoring has a specific cooling-loop role

P261A identifies the control-circuit/open classification for coolant pump B. Ford defines this B function as a high-temperature-loop auxiliary pump for component cooling number 1. The adjacent A-pump section instead describes cabin heating, so the letters must be tied to the actual vehicle architecture before locating hardware.

## An open report is one of several pump classifications

The detailed open representation is P261A_13. Low and high circuit conditions have separate suffixes, while performance/stuck-off monitoring is listed independently. A pump that does not appear to run therefore cannot be classified as electrically open solely from observation.

The B-pump check operates continuously, specifies five seconds of monitoring and requires battery voltage of at least 11 V. Those conditions should be retained when comparing an event with a later test.

## Identify the path the controller assessed

A useful diagnostic record keeps the complete code, requested pump operation, battery voltage and the correct component-cooling function. The summary does not supply an open-circuit resistance limit or connector pin; it cannot substitute for the applicable wiring diagram.

Several later rows under the B heading contain inconsistent A labels, so the broader table should not be used to invent a universal physical assignment for every pump code. The P261A open row itself is explicitly B. Its electrical evidence still needs localization before any decision about a motor, harness or controller replacement.

# P211C: Motor-current performance is different from throttle position error

P211C belongs to the throttle B motor-current range/performance monitor on Ford dual-throttle applications. The source maps it to P210A_1D, while separate subtypes describe stuck-open, stuck-closed and throttle-body performance conditions. Preserving that separation prevents a current assessment from being reduced to a generic position fault.

## Current evidence needs the command context

Ford places the entry in a continuously executed actuator-control group with a stated failure-registration time below five seconds. The summary does not supply a numerical current threshold, motor resistance or connector pin for this code. A test value borrowed from a different throttle motor would therefore be unsupported.

The meaningful question is which commanded operation coincided with the current-performance result and whether position-related or circuit-related classifications were recorded at the same time. A commanded movement and a stationary observation do not impose the same motor demand.

## Keep diagnosis narrower than a replacement claim

Record the full diagnostic identifier and confirm that the vehicle uses the documented B throttle architecture. A bare P211C cannot locate the component on every engine, nor prove whether the reported current behavior arose from an electrical path, control problem or mechanical load.

The adjacent entries are useful for organizing evidence, not for declaring one fault caused another. Verification should use the applicable controlled actuator test and wiring information, without externally forcing the plate or applying an invented amperage limit. The source supports a specific monitoring distinction; it does not authorize automatic throttle-body replacement.

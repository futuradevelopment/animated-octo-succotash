# P2533: Why an ignition-state fault can appear in throttle supervision

P2533 is described as the ignition switch on/start position circuit, but its placement in Ford’s summary is significant. It appears in the internal electronic-throttle monitoring group and maps to P2530_48. That context should be retained before treating the code as a simple instruction to replace a physical key switch.

## Monitoring context changes the evidence needed

The table lists continuous execution and a general registration time below one second, apart from specifically named longer exceptions. P2533 is not one of those exceptions. It is marked non-MIL with a wrench indication, so a missing check-engine lamp does not establish that the internal check passed.

The summary does not provide an ignition-terminal voltage threshold or identify the particular input path used by every vehicle. A conventional switch circuit and an electronically communicated power state cannot be assumed equivalent from this generic label alone.

## Preserve state transitions and subtype

A useful record keeps the complete code, reporting module and the on/start operating state associated with the event. A normal running-state observation later does not recreate a disagreement that occurred during a transition.

The document supports investigating how the controller assessed ignition state within its supervision system. It does not establish the cause, prescribe a switch or module replacement, or define a universal continuity test. The next diagnostic procedure must match the vehicle’s power-mode architecture and the detailed failure representation, rather than expanding the title into an unsupported hardware diagnosis.

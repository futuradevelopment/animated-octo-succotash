# P27B6: Transmission tie-up protection and deceleration supervision need different context

P27B6 is an internal transmission speed-sensor performance classification in Ford’s eight- and ten-speed automatic supervision group. The detailed P0701_92 entry concerns transmission tie-up protection, while P0701_96 concerns unintended deceleration. A generic “speed sensor performance” description does not retain that branch information.

## A supervisory result is not a missing-pulse diagnosis

These entries are marked non-MIL and are continuously monitored, with the group’s general registration duration below one second. The code is therefore distinct from a conventional electrical low/high or no-signal test whose threshold directly evaluates one sensor circuit.

A tie-up-protection result and an unintended-deceleration result assess different control consequences. Neither entry alone proves that one named speed sensor, clutch or hydraulic element caused the event.

## Retain the operating relationship

Preserve the exact subtype, transmission identity, requested gear or shift phase and the available shaft-speed history. A later plausible speed display cannot reconstruct a short supervisory discrepancy that occurred during a different control state.

The source does not publish a universal deceleration limit, speed mismatch threshold or mechanical repair for P27B6. Verification must follow the applicable transmission’s supervision procedure and distinguish signal reliability from the controlled response. Do not infer a safe driving condition, induce a tie-up event or replace a sensor solely from the shortened code label.

# P261B: Separate pump B performance from a definite stalled rotor

P261B is the coolant pump B performance/stuck-off entry in Ford’s auxiliary-pump table. The B function is defined as high-temperature-loop component cooling number 1. A performance classification describes an unsatisfactory controlled result; it does not by itself establish that the rotor is mechanically seized.

## Preserve the distinction between performance and actuation

The same table separately lists an actuator-stuck classification and low/high control-circuit faults. Those categories must remain distinct when evaluating a non-running pump. A failed electrical command path and a pump that fails to achieve the expected operation require different evidence, even if both appear inactive.

The documented monitor executes continuously, lists five seconds and requires at least 11 V battery voltage. The source does not disclose the actual performance-error threshold for this code, so no universal rpm or flow comparison can be supplied from this table.

## A source limitation affects the detailed identifier

The P261B row prints the corresponding detailed code as P261A_921, an unusual suffix that this article does not silently shorten or correct. Obtain the actual complete identifier from the vehicle and applicable service information rather than copying a guessed replacement suffix.

Useful verification keeps pump identity, command, operating feedback and companion classifications together. The printed subtype issue does not erase the supported B-pump performance meaning, but it prevents treating the summary as an exact universal scan-code mapping or a replacement instruction.

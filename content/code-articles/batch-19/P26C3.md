# P26C3: Internal range supervision preserves A, B and correlation distinctions

P26C3 appears in Ford’s internal electronic-throttle supervision list as transmission-range sensor performance. The full representations distinguish sensor A, sensor B and A-versus-B correlation: P0705_48, P2805_48 and P2800_48 respectively. A bare P26C3 display does not preserve which range-information check failed.

## A supervised range result is not a gear-ratio measurement

The source marks these entries non-MIL. They belong to continuous internal monitoring, with a general registration period below one second unless another listed code has a specific exception. Lack of a check-engine indication therefore cannot be used as proof that range supervision is healthy.

Sensor performance and correlation are different evidence. Two individually plausible inputs can disagree with each other; conversely, one input can be suspect without an established disagreement between two valid channels.

## Retain the missing detail before choosing tests

Capture the complete diagnostic identifier, reporting module, requested range and available A/B information. That context is necessary before treating the generic wording as a failed selector, harness or transmission component.

The summary does not disclose a universal voltage threshold, permitted range disagreement or connector test for P26C3. It also does not establish a mechanical inability to engage the selected gear. Verification must use the vehicle’s range-sensing and supervision procedure, preserving whether the event concerned a particular input or the relationship between inputs.

# P0547: Bank2 exhaust-temperature plausibility needs the correct operating window

P0547 identifies the bank 2 sensor 1 exhaust-temperature circuit/rationality entry in Ford’s gasoline summary. The source maps it to P0547_92, while P0548 and P0549 identify the separate low and high electrical classifications. A shortened “sensor circuit” label does not preserve those distinctions.

## A plausible temperature depends on the test state

Ford performs offset and rationality checks once per driving cycle, while electrical tests run continuously after sensor warm-up. The offset opportunity depends on a six-hour soak and an early-startup window; the running comparison instead uses inferred exhaust temperature under specified speed and fueling conditions.

For running rationality, filter regeneration must be inactive and the system must be in closed-loop stoichiometric fueling. A temperature observed during active regeneration cannot automatically be assessed as though that entry condition were satisfied.

## Keep bank and comparison type in the record

Retain bank 2 sensor identity, the full subtype, soak history and the measured-versus-inferred temperature relationship. A value inside an electrical signal range can still be implausible for the monitored operating state.

The table supplies no universal sensor replacement or mechanical-exhaust diagnosis for P0547. It also does not establish that the bank 1 sensor is an interchangeable reference under every condition. Verification must follow the vehicle-specific monitor and distinguish an electrical fault from the documented offset or model-comparison result.

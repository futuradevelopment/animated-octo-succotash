# P061B: One torque-calculation code can describe different supervised events

P061B is an internal torque-calculation performance classification, but Ford documents several distinct representations. P061B_85 concerns unintended acceleration; P061B_84 concerns unintended deceleration for MHT applications. The table also maps a motor-torque plausibility error in that architecture to P0E71_48. A shortened code erases these important distinctions.

## The direction and architecture are evidence

The listed entries carry MIL and wrench indications. They sit within continuous electronic-throttle supervision, whose general registration duration is less than one second unless an expressly listed exception applies. This is a controller plausibility result, not a direct measurement proving that a particular mechanical component failed.

An acceleration-related discrepancy and a deceleration-related discrepancy should not be interpreted as the same event. Similarly, a motor-torque plausibility entry requires the described hybrid architecture; the generic code string does not establish that architecture on an unknown vehicle.

## Keep the diagnostic record specific

Preserve the complete identifier, powertrain configuration and operating state surrounding the supervision result. Compare any reported torque limitation or disagreement with the relevant event, rather than assuming every P061B requires throttle-body replacement.

The summary does not provide the underlying calculation formula, numerical plausibility limit or a universal repair. It also does not justify inducing an acceleration or deceleration event to reproduce the code. Appropriate verification follows the vehicle-specific diagnostic procedure while keeping the documented subtype and architecture intact.

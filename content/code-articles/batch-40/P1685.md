# P1685: distinguishing an invalid Jeep key message from a bad key

P1685 in the 2003 Wrangler TJ manual reports a wrong or invalid key message received from the Sentry Key Immobilizer Module. The short description can suggest a defective key, but the diagnostic procedure first checks communication with the immobilizer, its own fault memory and the VIN programmed into the PCM.

## Where the message comes from matters

If the scan tool cannot communicate with the SKIM, the manual sends diagnosis to the communication fault. If the SKIM has its own codes, those are addressed before the PCM's P1685. These branches distinguish a missing or faulty authorization exchange from a key that is individually unrecognized. Replacing a key cannot correct every communication or configuration problem.

The procedure also treats recent work as evidence. Disconnecting the SKIM or replacing it can leave this code in memory. The intermittent branch verifies the programmed identity and checks all keys normally used with the vehicle, including whether an ordinary non-transponder duplicate was attempted. A complaint confined to one key is different from the same failure with every known authorized key.

## What a repair should demonstrate

A qualified workshop should establish that the participating modules communicate, that their configuration is appropriate and that each authorized key works consistently. Replacement modules require the specified programming; the code alone is not proof that a PCM is defective. This discussion concerns legitimate diagnosis and provides no immobilizer-bypass procedure. Its scope is the documented 2003 Wrangler TJ SKIS system, not all later Jeep security architectures.

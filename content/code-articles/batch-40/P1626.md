# P1626: Volkswagen missing transmission messages and the CAN test boundary

Volkswagen's Polo Mk3 4LV fault table assigns P1626 to missing messages from the gearbox control unit on the powertrain data bus. This tells the technician what information was unavailable to the reporting controller. It does not establish that the transmission's mechanical parts have failed or that its controller must be replaced.

## Read the fault from the receiver's perspective

The linked factory description explains that bus-capable controllers exchange messages over twisted CAN-high and CAN-low wires. More than one controller can recognize missing information. Several related communication entries can therefore describe one communication problem viewed by different recipients, rather than several independent failed modules.

The exact reporting module and the other available fault records help preserve that distinction. A generic scan description that omits the module context loses useful evidence about where the absence was detected.

## Do not turn a component test into a universal network rule

The documented electrical procedure checks the centralized matching resistor inside the engine controller with that controller separated from the vehicle harness. Its stated range is 60–72 ohms in that particular test arrangement. This is not an instruction to expect the same reading at any diagnostic socket or across an assembled vehicle network.

If that specific controller check passes, the procedure directs the technician to wiring diagnosis using current-flow diagrams. Applying its number to the wrong test configuration could lead to a false controller diagnosis.

A professional repair record should identify the communication defect and demonstrate restored gearbox-message availability, then recheck the affected systems for remaining faults. This article uses Polo 4LV documentation as the exact implementation of P1626; other Volkswagen network layouts require their own electrical procedure.

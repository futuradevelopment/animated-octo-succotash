# C0099: Ford rear actuator position sensorA and its support circuits

C0099 identifies position sensor A for rear differential actuator A in the cited Ford Escape AWD diagnostic chart. The two letters have different jobs: one names the actuator and the other names a feedback channel. Neither establishes a left-side wheel-speed sensor.

## Keep the electrical subtype

Ford lists short-to-ground/open, low-voltage and high-voltage variants under this base code. These conditions change the evidence a technician needs. An open connection and an unwanted powered connection are not interchangeable explanations merely because they interrupt useful position feedback.

The shared position-sensor pinpoint test begins with the sensor supply and return before checking the individual signal paths. This is a useful diagnostic order: testing feedback without first establishing its electrical support can make a sound sensor look defective.

## Connectors can affect more than one observation

The manual includes damaged terminals, corrosion, loose wiring and damaged seals among the possible sources. The complete connector inspection matters when several rear-actuator position entries are stored, because several affected channels may share one physical connection area. That observation supports investigation, not an automatic diagnosis of water damage.

The professional flow isolates circuit continuity and unwanted grounds before reaching a rear-unit replacement decision. It does not present the base code as proof that the entire differential has failed. Verification should preserve the original suffix and show restored feedback along with normal actuator operation under the applicable procedure.

This interpretation uses the fourth-generation Escape AWD manual reproduced by the cited mirror. The exact original revision is not identified, and no universal voltage threshold or independent sensor A repair operation should be invented from the code name.

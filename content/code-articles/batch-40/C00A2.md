# C00A2: Ford PTU driver code with current, reference and internal branches

C00A2 refers to the driveline controller's power-transfer-unit control driver in the cited Ford Escape AWD documentation. The manual routes its suffixes to different pinpoint tests. Some concern excess motor-driver current, another concerns sensor reference voltage, and others enter the controller power/ground/internal-fault flow.

## A driver fault is not one electrical measurement

Suffix 19 concerns excessive current in the PTU actuator driver. That branch belongs with motor-circuit diagnosis. Suffix 1C instead concerns a reference supply outside the documented 4.7–5.29 V range and is grouped with PTU position-sensor diagnosis. Confusing those branches could turn a feedback-supply problem into an unsupported motor replacement.

The position-sensor procedure recognizes that the cam and fork sensors share power and return. Companion C0091 and C0092 entries therefore help decide whether to investigate common support or an individual signal path.

## Internal subtypes still need supply evidence

Other listed C00A2 suffixes lead to checks for vehicle-wide voltage concerns, local module supply, connections and grounds before repeat self-testing. The word internal does not eliminate the need to establish the controller's operating conditions.

A qualified technician should retain the full suffix and use the corresponding branch. The repair record should state whether the problem involved commanded motor current, the sensor reference or the module's own operation, then demonstrate that the same failure classification no longer returns.

This explanation is specific to the reproduced fourth-generation Escape AWD procedure. Its mirror gives no exact original publication revision. The numeric reference range is a documented application value, not a generic specification for all circuits described by C00A2.

# C0091: Ford PTU cam-position sensor and shared-supply clues

In the cited Ford Escape AWD procedure, C0091 identifies position sensor A in the power-transfer-unit actuator assembly. Here sensor A follows the actuating cam, while sensor B follows the shift fork. Both are Hall-effect sensors sharing their supply and return. The component letters therefore describe different observations within one mechanism.

## A companion code changes the investigation

The first diagnostic decision asks whether a C0092 fork-sensor fault is also stored. If both are affected, Ford sends the technician toward the shared supply and return. If only the cam sensor is implicated, the flow concentrates on its individual signal path.

That is more informative than treating two sensor codes as proof that two sensors independently failed. The common electrical support needs consideration before the assembly is condemned. Conversely, the absence of the companion code helps narrow which part of the shared system needs attention.

## Retain the type of signal failure

The manual distinguishes duty below 10 percent, duty above 90 percent, incorrect frequency and a position outside the expected connected or disconnected range. Its cam-frequency reference is 1 kHz with a 150 Hz tolerance. A performance suffix evaluates the reported position in context, rather than simply repeating a high-voltage condition.

A qualified technician should follow the exact circuit-isolation procedure and confirm both believable position information and successful operation afterward. The stated frequency belongs to the cam-sensor branch and must not be copied to the fork sensor, which has a different tolerance in the same source.

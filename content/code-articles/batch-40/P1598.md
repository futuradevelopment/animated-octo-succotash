# P1598: high A/C pressure-sensor voltage on the documented Jeep system

The WJ/WG gas-powertrain manual sets P1598 when the A/C pressure-sensor signal at the PCM rises above 4.92 volts while the engine is running and the A/C relay is energized. The fault identifies a high electrical signal under those conditions. It does not independently establish excessive refrigerant pressure.

## Separate the sensor from the signal path

The factory possibilities include an open signal wire, an open sensor ground, a short to the five-volt supply and a short to battery voltage. The pressure sensor itself is another possibility. An open return path can therefore create a high input even though no refrigerant has been added.

The diagnostic tree first checks that the refrigerant system is correctly charged according to service information, then distinguishes the electrical alternatives. It tests for a connection between the reference and signal circuits separately from unwanted higher voltage on the signal. Controlled input-response testing and continuity checks then separate the sensor from its wiring.

If the current reading is normal, the procedure directs attention to an intermittent event, using the original operating conditions and connector inspection. A momentary normal scan-tool pressure display is not proof that the signal remained trustworthy throughout the complaint.

## Verification and scope

A qualified A/C technician should establish both electrical signal integrity and appropriate system operation after repair. Adding refrigerant on the basis of this code can miss the documented circuit problem. The voltage threshold and relay condition quoted here belong to the cited WJ/WG gas procedure; they should not be transferred to the separate diesel diagnostic strategy.

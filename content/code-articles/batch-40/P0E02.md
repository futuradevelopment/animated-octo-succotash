# P0E02: U-phase current-sensor low input in Mazda M Hybrid

P0E02:00 identifies a low input from the integrated starter generator's U-phase current sensor in the cited Mazda M Hybrid procedure. The detection boundary is a sensor signal of 0.1 V or less. This voltage describes the current-measurement signal; it is not a measurement of the 12 V battery and does not mean that the U-phase winding carries 0.1 amps.

## Status changes the diagnostic route

Mazda first preserves snapshot information and distinguishes a present malfunction from a past record. A present fault receives an ignition-cycle recheck after at least 10 seconds. That waiting period belongs to the recheck procedure; the page does not specify a 10-second detection threshold for the original low input.

A past event follows the repeatability branch instead. The recorded operating conditions help a qualified technician judge whether the same complaint can be reproduced. One historical entry therefore supports a different next step from an input fault that remains present immediately after the prescribed recheck.

## What the shared phase procedure establishes

The U, V and W low/high sensor codes share this diagnostic flow. For a recurring fault, communication diagnosis comes before the internal-ISG replacement decision. The page does not provide external sensor terminals to probe or an individual U-phase sensor replacement procedure.

Hybrid supply, regeneration and assist can be disabled. Mazda warns that continued operation in this state can deplete the 12 V battery, so the code is not a basis for declaring normal driving acceptable. Professional confirmation should document the fault's status, communication result and recurrence evidence. This interpretation is limited to the specified Mazda M Hybrid system, not every vehicle using P0E02.

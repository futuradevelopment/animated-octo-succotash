# B0082: Fiesta load-limiter resistance and the repair-completion check

B0082 refers to the passenger safety-belt load-limiter deployment circuit in the cited 2012 Ford Fiesta manual. The restraints controller monitors resistance, unexpected voltage and ground shorts. Retaining the suffix distinguishes an open or low-resistance concern from a short-to-ground or short-to-voltage concern.

## A disappearing code is not the only criterion

Ford explains that the controller combines measured deployment-loop resistance with an age correction factor. The fault threshold can therefore change as the vehicle ages. Temperature and small changes in terminal contact caused by vibration can also make the complaint intermittent.

For this particular circuit, Pinpoint Test L requires the DEPLOY_26_R scan value to fall between 1.7 and 2.78 ohms before considering the resistance concern repaired. That requirement applies even when an on-demand code is absent. The published range is a controller-reported diagnostic value for this Fiesta loop, not an instruction to measure a deployable belt component directly.

## The suffix selects the evidence

Open and low-resistance complaints lead into the scan-value and circuit-isolation branches. Ground and voltage shorts take different routes. The chart then distinguishes wiring and connection defects from the load limiter or restraints controller using controlled professional tests.

If the fault becomes intermittent, Ford calls for connection investigation rather than automatic replacement. Final verification includes the remaining restraints codes and system prove-out, with the resistance value still within the documented range.

A load limiter is part of a deployable restraint system. Do not probe its connector, substitute resistors or disassemble the belt assembly. The useful owner-facing information is the full code, its current or stored status and the workshop's measured PID evidence. These values and branches apply only to the cited vehicle and circuit.

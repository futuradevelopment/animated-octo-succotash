# C009A: Ford rear actuator sensorB: preserve suffix and source limits

C009A names rear differential actuator A position sensor B in the cited Ford Escape AWD documentation. It is a position-feedback channel within the rear-drive system, separate from the PTU fork sensor B at the front of the driveline. Matching only the letterB would therefore send diagnosis to the wrong assembly.

## Use the complete diagnostic entry

The source clearly lists a short-to-ground/open variant and a high-voltage variant for this channel. Its low-voltage row contains inconsistent explanatory wording, so this article does not assign an invented threshold or resolve that inconsistency by guesswork. A technician should retain the exact suffix and consult the vehicle's applicable original service information.

That limitation does not erase the useful common procedure. The manual checks sensor power, return and the paths between the rear unit and AWD controller before its component decision. A signal complaint can arise because its support or connection is wrong, even when the sensor itself is named in the fault description.

## Interpret multiple feedback complaints together

SensorA, sensor B and sensor C entries share the same diagnostic flow here. Their coexistence should prompt review of common connections and the full module report; it is not evidence that three independent repairs are required. The source does not prescribe a unique sensor B replacement operation.

After an identified circuit or assembly repair, a workshop should confirm reliable rear-actuator feedback and complete the applicable operational check. This article is deliberately scoped to the reproduced fourth-generation Escape procedure, whose exact publication revision the mirror does not provide. It is an interpretation guide, not instructions for probing a moving driveline.

# C0095: Ford rear AWD actuator: current, feedback and configuration faults

C0095 covers several different rear differential actuator complaints in the cited Ford Escape AWD documentation. It can describe current, movement, mechanical synchronization, learned position or configuration data. Reading only the base code leaves too much information missing to choose a repair.

## The actuator learns a clutch reference

The rear drive unit contains a reversible three-phase motor operating the AWD clutch. On module startup, the described system moves from the released hard stop toward the clutch kiss point: the maximum apply position before torque is transmitted. That learning process is distinct from commanding full clutch engagement.

Suffix 99 records unsuccessful kiss-point learning. Suffix 71 reports no indicated movement when the motor is commanded. For both, Ford prioritizes motor-position sensor faults, because reliable feedback is needed to interpret learning or movement. A sensor problem can therefore change the significance of an actuator complaint.

## Data-memory failure has a separate branch

C0095:44 is routed to configuration diagnosis. It means the rear-drive-unit configuration data was incomplete, unreadable or corrupted during module startup. That branch deals with stored unit-specific information, rather than automatically testing the motor phases as though current were missing.

The current and mechanical branches examine connector contamination and phase-circuit integrity before a conditional component decision. Qualified workshop verification should retain the suffix and show which operation or data check now passes. The mirror groups this as fourth-generation Escape service information without giving an exact original revision; use the vehicle-specific procedure before applying its hardware or configuration instructions.

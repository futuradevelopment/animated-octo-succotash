# C009B: Ford rear actuator sensorC and the meaning of a feedback fault

In the cited Ford Escape AWD manual, C009B identifies rear differential actuator A position sensor C. The code concerns the controller's view of actuator position. It does not directly measure the amount of torque reaching the rear wheels, so a position fault alone cannot quantify lost AWD capability.

## Three electrical classifications

The chart separates an open/ground-short condition, low circuit voltage and high circuit voltage. Recording the suffix preserves which electrical condition was recognized. A generic description that drops it leaves the workshop unable to select evidence confidently from the stored report alone.

The factory flow is shared with the other rear-actuator position channels. It checks the supply and return, then the wiring paths between the rear unit and the AWD module. The distinction between sensor support and the individual feedback path prevents a missing supply from being mistaken for an isolated sensor C defect.

## A circuit result must support an assembly decision

The procedure includes connector damage, corrosion, loose conductors and seal problems among its possible sources. It reaches a rear-unit replacement decision only through its electrical checks. That conditional decision should not be shortened to replacing the differential whenever a position-sensor code appears.

A professional repair report should explain which circuit condition was demonstrated and how feedback was verified afterward. If other actuator or position codes remain, they need their own interpretation rather than being dismissed because C009B cleared.

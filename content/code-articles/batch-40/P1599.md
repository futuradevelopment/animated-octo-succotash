# P1599: a low Jeep A/C pressure input needs an electrical diagnosis

In the WJ/WG gas-powertrain diagnostic manual, P1599 is the A/C pressure-sensor low-voltage fault. Its stated monitor requires the engine running and A/C relay energized; the signal must remain below 0.58 volt for 2.6 seconds. This is electrical evidence, not a standalone measurement of how much refrigerant remains.

## Check the reference before blaming pressure

The procedure separates loss of the five-volt reference from a signal pulled down by the sensor or wiring. A reference circuit that is open or shorted to ground can make a sound sensor report incorrectly. The signal can also be shorted directly to ground or to the sensor-ground circuit. Those are distinct paths in the factory tree.

A technician compares the available reference with the sensor's response after controlled isolation. If the reference is sound but the signal remains low independently of the sensor, wiring or controller-input investigation is needed. If the reference itself is missing, replacing the pressure sensor alone does not address that finding.

The manual separately requires the refrigerant charge to be checked using service information. It does not authorize charging by fault code. Its initial live-test boundary differs markedly from the stated set threshold, so this overview preserves the monitor condition without presenting that test boundary as a universal specification.

## Confirm the actual repair

Verification should demonstrate a credible pressure input and proper A/C operation, with intermittent connections investigated when today's reading is normal. Refrigerant handling and powered-system tests belong to a qualified workshop. The described conditions are limited to this WJ/WG gas application.

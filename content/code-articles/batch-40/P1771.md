# P1771: Passat transmission load-signal wiring and shared recipients

P1771 appears with Volkswagen fault number 18179 in the cited 2003 Passat Sedan 3B3 1.8L Turbo AWM transmission chart. The original description identifies an engine-control-module load signal with an open circuit or short to positive. The catalog's shorter “load signal stuck off” wording should not be read as proof that a throttle is mechanically stuck.

## The signal has a path beyond the two controllers

Volkswagen directs attention to the wiring and connections between engine and transmission control. It also identifies other components receiving the same signal, using the onboard computer as an example. A fault on a shared recipient branch can therefore matter to the transmission's observation.

The accompanying check references measured-value display group 009. That gives the workshop a way to examine the reported load information alongside the circuit evidence. The chart does not publish a universal voltage threshold or a replacement instruction for a particular engine sensor.

## Retain the electrical distinction

The adjacent P1772 row describes a short to ground. These are different electrical descriptions, despite the catalog's simplified off/on labels. Recording the exact fault number and wording helps avoid selecting the wrong circuit test.

A technician should use the applicable transmission-controller wiring diagram to identify every relevant connection and recipient. The chart's particular terminal reference belongs to that documented controller and should not be generalized to other Volkswagen transmissions.

Verification should show that the intended load information reaches transmission control after the identified circuit defect is corrected. This is a source-scoped interpretation of the original Volkswagen chart mirrored by Operation CHARM; it does not establish compatibility with every Passat transmission or imply that internal transmission repair is required.

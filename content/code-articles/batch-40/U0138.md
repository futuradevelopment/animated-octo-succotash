# U0138: Ford AWD controller missing all-terrain module messages

U0138:00 means the AWD controller has lost communication with the all-terrain control module in the cited Ford Escape procedure. The receiving AWD module expects network information and records this fault after messages from the named module have been absent for more than 12 seconds. The entry reports missing information, not a proven failure inside the all-terrain module.

## Compare the other receivers

Ford first asks whether other modules also report losing the same sender. If several receivers agree, the flow goes to network diagnosis. That pattern can reveal a problem affecting the sender or shared communication path, rather than an isolated issue at the AWD controller.

If the complaint is confined to the AWD module, the next decision considers stored low-voltage faults. A supply disturbance can explain communication loss, so voltage history has diagnostic value even when the current symptom looks like a network-only problem.

## Connections and service information precede replacement

The procedure then examines network connections between the reporting and suspect modules for corrosion, terminal damage and seating problems. If the concern remains, it requires checking applicable service information before its conditional module decision. A stored lost-communication code alone does not bypass those checks.

Repair verification should show that the expected messages are available and that related faults no longer recur. It should also distinguish this loss-of-message condition from a message received with invalid contents. The 12-second boundary is specific to the AWD monitor described here, not a universal U0138 timing rule.

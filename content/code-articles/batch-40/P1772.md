# P1772: Passat load-signal ground shorts can originate on a shared branch

The original 2003 Volkswagen Passat Sedan 3B3 1.8L Turbo AWM transmission chart identifies 18180/P1772 as an engine-load signal short to ground. The community catalog's “stuck on” label is an abbreviated description. The source concerns information supplied by engine control, not direct evidence of a mechanically stuck throttle or transmission clutch.

## Another recipient can affect the transmission's signal

The chart lists a short inside a component that also receives the load signal, with the onboard computer given as an example. This is a useful diagnostic distinction: the transmission controller can observe a damaged signal even when the fault is elsewhere on the shared circuit.

Volkswagen therefore calls for electrical checking and inspection of the relevant component using the wiring diagram. Looking only at the transmission-controller connector would leave a documented possible path unexplored.

## Engine-control evidence is a separate branch

The same row also allows no signal or an incorrect signal from the engine controller. The prescribed response includes checking engine-controller fault memory and repairing the associated malfunction. Engine-controller replacement is conditional, not the first conclusion from P1772.

The neighboring P1771 row describes an open circuit or short to positive. Preserving that difference is more useful than translating both records into a broad load-sensor fault. The cited P1772 row supplies no general trigger voltage or duration, so neither should be invented.

A sound verification connects the repair to restored load information at the receiving system and resolution of any relevant engine-control faults. Application remains limited to the cited Passat transmission chart and the correct controller wiring. The code alone does not justify a transmission overhaul or a universal engine-sensor replacement.

# P1899: the Wrangler park/neutral input disagrees with the selector

The 2003 Wrangler TJ diagnostic manual treats P1899 as a park/neutral-switch performance fault. Its opening test compares the scan tool's park/neutral and drive/reverse indications with the selector's actual positions. The key evidence is whether the input changes correctly, not simply whether the engine can be started on one occasion.

## The switch has a defined electrical pattern

In the documented circuit, the park/neutral sense line is grounded in Park and Neutral and open in the other selector positions. A line shorted to ground can therefore imitate the park/neutral state continuously. An open line can prevent that state from reaching the PCM. Those opposite wiring failures can both produce an incorrect range indication.

The factory sequence checks the sense wire for an unwanted ground and then for continuity before assessing the range-switch assembly's own change of state. If the correct switch pattern reaches the controller connection, the result has a different implication than a pattern that never changes at the switch. This is why a stored P1899 does not automatically condemn the transmission range sensor.

## Verification should include the full selection range

An input that behaves correctly during the initial check sends the manual toward intermittent diagnosis. Preserve the complaint history and confirm the range indication through the required selector positions after repair. Range and start-interlock testing should be performed with the vehicle secured by a qualified technician. The circuit behavior described here belongs to the 2003 TJ procedure; connector details and test limits should not be transferred to another transmission.

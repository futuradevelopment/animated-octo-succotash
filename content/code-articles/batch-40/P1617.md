# P1617: Volkswagen glow lamp code that can mean dark or continuously lit

P1617 has two electrically different branches in Volkswagen's Golf Mk 4 distributor-pump diesel documentation through April 1999. An open lamp circuit or failed bulb can leave the glow-period indicator inoperative. A short to ground can instead leave it continuously illuminated. Both fall under the same open-circuit/short-to-ground code description.

## The observed lamp state changes the question

A dark lamp and a permanently lit lamp should not trigger the same assumption about the bulb. The first is consistent with a missing current path; the second directs attention to an unwanted path. These are interpretations of the manual's separate branches, not a claim that appearance alone proves the wiring defect.

The factory final-control routine commands glow-period warning lamp K29 to flash. That controlled request gives the technician a more useful comparison than simply watching the lamp during an uncertain engine state. The routine also has a different stage for glow-plug relay J52. Heating-system operation and lamp operation must be evaluated as separate responses.

## Confirm the circuit, not just the display

If the requested flashing does not occur, the procedure refers to current-flow diagrams and electrical diagnosis. Because the output sequence actuates other engine equipment, a technician should follow its complete prerequisites and order. Manually feeding or grounding an unidentified dashboard circuit is not a substitute.

The repair should explain the original observation: an interrupted lamp path, a bulb fault or an unwanted ground connection. A lamp that happens to illuminate once does not resolve an intermittent wiring fault. Verification should show the expected commanded response and no returning P1617 after the applicable checks, with the vehicle's engine and electrical configuration matched to this source.

# P0875: interpreting the Jeep underdrive pressure-test failure

On the 2002 Jeep WJ/WG transmission system described here, P0875 is the underdrive-clutch hydraulic pressure test failure. The catalog's broader pressure sensor/switch D wording does not identify this clutch by itself. The factory chart supplies the missing system context.

## What the controller tests

After a forward shift, with engine speed above 1,000 rpm, the TCM can momentarily pressurize clutch circuits that are not currently carrying pressure. It expects the corresponding pressure switch to close; two failures of that response set P0875. The test also repeats periodically. A missing response therefore has both hydraulic and electrical explanations.

One useful distinction in the diagnostic tree is whether the line-pressure signal itself is credible. The manual includes a connector-related branch before comparing the input against a dedicated simulator. If the observed pressure changes because the sensor connection is disturbed, the evidence concerns feedback integrity, not necessarily an actual change inside the transmission.

If the line-pressure assessment does not explain the fault, the underdrive switch-sense path and relay-fed supply are tested separately. Only after the external evidence is evaluated does the procedure turn toward contamination, valve-body faults and the solenoid/range-sensor assembly.

## What a useful repair report includes

It should identify whether the failed element was hydraulic pressure delivery, switch feedback, a reference supply or wiring. Related pressure and ratio codes should remain part of that explanation. Workshop verification uses the specified transmission procedure after repair; attempting to reproduce the active test while driving is inappropriate. These details apply to the cited 2002 WJ/WG 45RFE/545RFE manual, with the diagnostic steps marked for the five-speed system.

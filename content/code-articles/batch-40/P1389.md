# P1389: the Wrangler PCM is missing ASD output feedback

For the 2003 Wrangler TJ, P1389 means the PCM does not sense voltage from the automatic shutdown relay when the relay is energized. The manual's monitor requires the ignition on, battery voltage above 10.4 volts and engine speed above 400 rpm. The fault therefore concerns the expected output reaching the controller, rather than simply the presence of an ignition-on command.

## Why starting behavior changes the investigation

The factory diagnostic tree asks whether the engine starts. That answer determines the next branch. A running engine still requires examination of the ASD output path to the PCM; successful starting does not prove that the feedback connection is sound. In the no-start branch, the procedure also checks the fused battery supply feeding the relay circuit.

An open output wire, loss of the fused battery feed and a controller-side problem are separate possibilities. The code name alone does not distinguish them. The procedure also reviews good-trip information before treating the fault as current, and checks connector condition and controller power and grounds before reaching a PCM replacement decision.

## Useful repair evidence

Ask which supply or feedback path was found defective, and whether the expected ASD output is now recognized under the original operating conditions. A relay replacement without that evidence may leave the fault unchanged. P1388, by comparison, is the relay control-circuit fault in the same manual; it should not be substituted for P1389's output-feedback diagnosis. This interpretation is limited to the documented 2003 Wrangler TJ powertrain system.

# P0E07: V-phase high input: understanding Mazda ISG fault recurrence

P0E07:00 reports a high input from the V-phase stator-current sensor in the cited Mazda M Hybrid ISG manual. The stated boundary is 4.9 V or higher. The page describes an electrical measurement fault inside the ISG system; it does not claim that the vehicle is producing a particular torque or drawing a particular number of amps when the code sets.

## A repeat event has more diagnostic weight

Mazda does not begin with an unconditional replacement instruction. It preserves the event snapshot and checks whether the fault is present. If it is, the procedure repeats the check after an ignition cycle and at least 10 seconds. If it is no longer present, the investigation uses recorded operating conditions to assess recurrence.

This means a workshop should distinguish a fault that persists at recheck from one recorded during a previous operating state. Reporting only that the code cleared loses the information needed to decide which branch actually passed.

## Why communication remains part of the decision

When the malfunction recurs, the manual calls for CAN communication diagnosis before revisiting the ISG fault. With communication normal and the malfunction recurring through the stated sequence, the procedure reaches the ISG replacement decision. It does not supply a separate V-phase sensor service operation.

The same logic covers the other listed phase-current sensor faults. No phase-specific road test or external electrical probe is justified by this page. A qualified technician should handle recurrence assessment and hybrid repairs. Because the fail-safe can leave the vehicle dependent on its 12 V battery, a high-input code should not be dismissed as harmless merely because the engine still runs. Repair verification includes checking and addressing other recorded faults.

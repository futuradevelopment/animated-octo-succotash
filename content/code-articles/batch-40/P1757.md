# P1757: distinguish real governor pressure from a false Jeep reading

In the cited WJ/WG gas-powertrain manual, P1757 means governor pressure is reported above three psi while the requested pressure is zero. The monitor also specifies solenoid duty-cycle and time conditions. Its diagnostic branch explicitly excludes the five-speed 545RFE, so transmission identification comes before using these details.

## The gauge comparison is decisive

The manual first addresses other transmission codes and checks fluid level and condition. It then compares the scan-tool governor-pressure reading with an independent pressure gauge. If the gauge shows low pressure while the scan tool reports excess pressure, the next issue is feedback accuracy. If both show excess pressure, the hydraulic system needs a different investigation.

That distinction is why P1757 cannot be reduced to either a failed pressure sensor or a sticking solenoid. The circuit branches cover reference supply, signal and sensor ground, both outside and inside the transmission. An internal harness fault can survive replacement of an externally accessible component.

Where hydraulic evidence remains, the procedure examines fluid-pan debris and the governor-pressure control/valve-body path. Contamination is evidence about the condition of the system; it should not be treated as an unrelated cosmetic finding.

## What confirms a repair

A useful report states whether the fault was excessive actual pressure or an inaccurate electrical report and identifies the failed section. Pressure-gauge installation and running tests require a qualified transmission technician. After repair, the documented transmission verification should confirm that requested and observed pressure agree. The three-psi reference is specific to this procedure, not a universal governor-pressure limit.

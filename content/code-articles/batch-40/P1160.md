# P1160: Volkswagen intake temperature fault and the 136.8°C substitute value

P1160 identifies a short-to-ground condition for intake manifold temperature sender G72 in Volkswagen's Golf Mk 4 distributor-pump diesel fault table. The documented system can replace an unusable temperature signal with 136.8 °C. That precise display is a diagnostic clue: it can be a programmed substitute rather than evidence that the intake air actually reached that temperature.

## Read temperature in context

The associated component procedure checks measured value block 7, display zone 3. An unrealistic reading or the stated substitute value leads to sender and connection checks. Treating the displayed value as a physical measurement could send diagnosis toward cooling or airflow problems while leaving the electrical problem unresolved.

G72's resistance is temperature dependent. The manual gives examples of 1500–2000 ohms at 30 °C and 275–375 ohms at 80 °C. These are reference points for this sender, not a single acceptable resistance at every temperature. Comparing resistance without knowing the sensor's temperature can produce a false failure judgment.

## Match the engine branch

The procedure separates AGR/AHF/ALH/ASV engines from AGP/AQM engines. Although both branches use the same example temperature characteristics, their connector and controller wiring checks differ. Consequently, finding a Golf diesel diagram is not enough; the technician needs the correct engine designation before checking a circuit.

If the sender follows the specified characteristic, the factory sequence continues through wiring integrity and unwanted electrical connections before reaching the controller. Verification should establish that the live temperature is credible again and that P1160 no longer returns under the applicable check. These details come from the manual section introduced in May 1999 and should not be applied to unrelated Volkswagen temperature circuits.

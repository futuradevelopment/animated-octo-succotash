# B0092: Fiesta left rear impact-sensor faults and the paired-code clue

B0092 identifies the left-side restraints sensor 2 in the cited 2012 Ford Fiesta procedure. Ford calls this the driver second-row C-pillar impact sensor. The restraints controller communicates with the sensor; a communication failure can illuminate the airbag warning lamp, but the code does not by itself identify a defective sensor.

## The companion code changes the investigation

Pinpoint Test O groups this sensor with the passenger front-door impact sensor, represented by B0096. A feed circuit shorted to ground can produce B0092:11 and B0096:11 together. Unwanted voltage on either sensor's feed or return can instead produce both codes with suffix 93.

Consequently, two sensor codes do not necessarily mean two failed sensors. They can be evidence of an electrical condition affecting the pair. Ford separates those paired-code branches from a lone B0092:93, which first receives attention to the left rear sensor and controller connections, followed by the sensor circuits.

## Present faults and stored history have different weight

An on-demand fault that returns during the restraints self-test remains an active diagnostic concern. A code found only in continuous memory follows the intermittent branch, including terminal fit, harness condition and connector locking. If the original condition cannot be reproduced, the procedure does not authorize indiscriminate replacement of restraints components.

This requires professional SRS diagnosis. Ford expressly states that an impact sensor must not be probed with a multimeter. Verification includes the complete restraints self-test and system prove-out, rather than merely erasing B0092. The documented sensor location and paired-code behavior apply to this Fiesta implementation; they should not be transferred to an unrelated vehicle from the generic code name alone.

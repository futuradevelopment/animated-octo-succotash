# B0126: GM driver-monitoring camera cases: suffix 49 versus suffix 82

B0126 identifies a driver-monitoring camera issue, but General Motors' published cases show why its suffix and vehicle context matter. The same base code appears in different diagnostic situations. A camera replacement or software update should not be selected from the five-character code alone.

## One documented software case

PIT6055C, published in May 2024, concerns specified North American HUMMER EV vehicles: 2022–2024 pickups and 2024 SUVs through the listed December 11, 2023 build cutoff. It describes B0126 symptom 49, current or historical, in the driver-monitoring module with a service-driver-assist message. GM attributes that case to software and refers technicians to the then-specified software package instructions.

This is a historical, bounded case. It does not establish that symptom 49 on another model has the same cause or that the older package remains today's service direction.

## A different camera-message case

January 2025 bulletin PIC6556H covers its listed North American models with UKL hands-free lane-following equipment. Its B0126 symptom 82 case involves the image-processing module and a diagnostic sequence that distinguishes current faults, companion codes, camera connections and the LVDS cable. The sequence cannot be reduced to replace the camera whenever B0126 appears.

A separate September 2024 Silverado EV RST bulletin, PIT6186A, identifies symptom 82 as an alive/sequence-counter complaint. For that specific Super Cruise-unavailable case, it explicitly advises against controller replacement for listed history-only faults.

## Evidence to retain

A workshop needs the full suffix, reporting module, current/history status, vehicle build and equipment, plus companion faults. Those details determine which documented case is relevant. Driver-assistance availability must be verified after the applicable professional repair; clearing a historical code alone does not demonstrate that the feature is working.

# P1495: checking the Wrangler leak-detection-pump solenoid circuit

P1495 in the 2003 Wrangler TJ manual is an electrical-state mismatch in the leak-detection-pump solenoid circuit. With the ignition on and battery voltage above 10.4 volts, the PCM continuously checks whether the circuit's state agrees with its command. This differs from finding a vapor leak or observing that the pump's mechanical switch failed to move.

## Supply and command are separate evidence

The diagnostic procedure checks the pump's source circuit before evaluating the switched control circuit. A missing supply can leave a sound pump unable to operate. If supply is present, a technician uses the scan tool's actuator function to assess whether the control circuit switches as expected. A valid control response points toward the pump assembly; an absent response leads to checks of the control wire.

The documented wiring possibilities include an open source feed, an open solenoid-control wire and a control wire shorted to ground. The manual's circuit naming includes a generator-source feed, so the applicable schematic matters: the diagnostic target is still the LDP circuit, not an automatic instruction to replace the generator.

## Confirming the repair

Good-trip information determines whether the active-fault path or intermittent diagnosis is appropriate. After the identified electrical defect is repaired, the EVAP verification should confirm operation rather than relying solely on an erased code. The neighboring P1494 procedure addresses switch/mechanical response and has a different decision path. These distinctions apply to the documented 2003 Wrangler TJ system and its wiring.

# B00C5: Fiesta passenger seat-position faults are restraint-system inputs

B00C5 identifies the passenger seat-track position input to the restraints controller in the 2012 Ford Fiesta service procedure. It is an SRS sensor complaint, so a seat that physically slides normally can still have a relevant electrical fault. The controller can detect a ground short, voltage short, interruption or current outside the expected range.

## Current information is part of the diagnosis

Pinpoint Test S groups suffix 11 and suffix 1D at its initial response check, while suffix 12 takes a voltage-short branch and suffix 13 takes an open-circuit branch. Treating every B00C5 as an open wire would therefore skip the source's distinction between current behavior and circuit continuity.

In the professional flow, a deliberately controlled change in circuit state is used to see whether the controller recognizes a different fault. The diagnostic meaning is the controller's response: a changing fault can demonstrate that the monitoring function responds. This is not permission for an owner to jumper, disconnect or probe the restraint wiring.

## Confirm the fault before selecting a component

The procedure includes both the sensor signal path and its ground path. It also requires connection checks before a sensor or controller decision. A code remaining only in continuous memory follows an intermittent branch, and an unreproduced fault does not justify installing new SRS parts automatically.

Correct component applicability matters because physically similar restraint parts can produce faults when used in the wrong application. Completion requires checking both restraints and occupant-classification fault records and carrying out the prescribed prove-out. This explanation is scoped to the cited Fiesta manual; it provides no universal current threshold or seat-position calibration for other vehicles.

# C0093: Ford PTU temperature sensor: electrical faults versus actual heat

The Ford Escape AWD procedure uses C0093 for the power-transfer-unit fluid-temperature sensor. The sensor is a thermistor in the PTU cover, and the module derives temperature from the voltage across its circuit. A temperature-sensor code is therefore not, by itself, proof that the unit physically overheated.

## Electrical extremes need interpretation

In this source, suffix 16 identifies a ground-short condition. Suffix 17 can reflect a positive short or an open circuit. Suffix 92 is a performance complaint involving the temperature information. The complete fault record helps distinguish an electrically forced reading from a plausible-looking signal that still fails a performance check.

Ford's procedure checks the two sensor circuits for interruption and unintended connections before evaluating the thermistor itself. That sequence matters because a good temperature-sensitive element cannot provide reliable information through a failed connection.

## Resistance depends on temperature

The manual provides a resistance-versus-temperature table rather than one universal pass value. For example, its 25°C row gives a nominal value of approximately 99.5kilohms with a specified allowable range. Comparing that number with a hot sensor would be an invalid test, even if the meter and connector were correct.

A professional should use the complete table and the known sensor temperature, then apply the appropriate component or circuit branch. The reproduced table contains apparent transcription anomalies in other rows, so isolated values should be checked against the vehicle's current service information.

Repair verification needs credible temperature reporting and no returning fault under the applicable check. This explanation is limited to the fourth-generation Escape AWD procedure reproduced by the cited mirror; it does not establish universal PTU temperature thresholds.

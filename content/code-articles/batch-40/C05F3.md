# C05F3: Ford rear driveshaft speed code that concerns its power supply

C05F3:00 has a broad rear-driveshaft-speed circuit label, but the cited Ford Escape AWD procedure defines its specific trigger as sensor power supply outside the expected range. That detail changes diagnosis: the missing evidence is not necessarily a defective speed signal generated by the sensor itself.

## Use the correct supply specification

The factory check expects approximately 9 V at the rear-drive speed sensor in its stated test setup. This is a useful warning against assuming every electronically supplied automotive sensor uses 5V. Applying a familiar generic value to the wrong circuit could falsely condemn a functioning controller.

When the supply is missing, the flow checks the feed for interruption and unwanted ground connection. If those checks pass, it calls for applicable Ford service information before the controller replacement branch. The sequence leaves room for a known service issue rather than treating every abnormal supply as new hardware damage.

## Separate sensor supply from sensor performance

The same manual gives a different branch to the speed-signal plausibility code C05F4. C05F3's supply complaint should not be turned into a mechanical driveshaft diagnosis merely because both codes mention speed. The sensor needs correct electrical support before its output can be assessed meaningfully.

A professional completion record should identify the original supply condition and show the corrected circuit and credible speed information afterward. This is the documented fourth-generation Escape implementation, not a universal 9 V specification for all C05F3 vehicles. The mirror does not state the original manual revision; vehicle-specific wiring and service updates remain necessary.

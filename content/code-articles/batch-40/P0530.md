# P0530: Jeep diesel A/C pressure diagnosis includes the reference supply

The 2002 WG 2.7L diesel manual groups three P0530 subtypes: A/C pressure signal high, signal low and sensor-reference supply outside its permitted range. The code therefore identifies more than a possible failed pressure transducer. The full manufacturer description is needed to choose the correct electrical branch.

## A shared reference fault changes the order

The factory procedure explicitly prioritizes P0641 or P0651 when present with P0530. Those reference-voltage faults can compromise the pressure input, so a pressure-sensor replacement should not precede their diagnosis. This is a concrete reason to retain the entire code set.

The documented signal limits are above 4.84 volts or below 0.15 volt. The supply subtype concerns reference B outside 4.9–5.1 volts for at least 100 milliseconds. These are monitor criteria for this diesel system, not charging-system voltage limits.

The high-input investigation distinguishes a signal shorted to the reference feed from unwanted voltage on the signal or sensor ground. The low-input investigation first checks the reference supply and then the signal path. The manual warns that voltage entering the sensor ground may have affected the ECM, requiring retesting after the short is repaired.

## Pressure still needs proper measurement

The source separately requires a correctly charged refrigerant system. Neither a high nor low circuit code authorizes refrigerant addition by guesswork. A qualified A/C technician should verify electrical integrity and system operation using the appropriate equipment. This account is limited to the cited WG diesel procedure and does not substitute its thresholds for other P0530 applications.

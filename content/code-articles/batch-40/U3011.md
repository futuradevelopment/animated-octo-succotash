# U3011: Ford OFF-state comparison and residual powered circuits

U3011:62 reports an OFF-state signal comparison failure in the cited 2012 Ford Fiesta intelligent-access system. The remote-function actuator compares the direct start/stop-switch request with ignition status returned by the instrument cluster. OFF in the code name describes the state being checked; it does not prove that the entire vehicle stayed awake or identify a battery-drain rate.

## Requested state and electrical state can disagree

Ford's shared pinpoint test examines the cluster's communication and power feeds before the final comparison-code branches. It also requires other relevant cluster or remote-function module faults to be diagnosed. That ordering protects against treating an incomplete status message as an isolated switch failure.

For U3011, one later check investigates unwanted voltage on the starter-control sense path. Another distinguishes unwanted voltage on the accessory input from power arriving through the accessory relay. Disconnecting the relay in the specified professional test changes the interpretation: persistence points toward the circuit, while removal of the unwanted feed points toward the relay branch.

## A module decision comes later

The procedure eventually checks terminal condition, connector seating and whether the concern remains after reconnection. If operation returns, the instructions emphasize the connection problem rather than automatic module replacement. If replacement is justified, configuration and intelligent-access security procedures are required.

These distinctions make the original full scan report and reproducible ignition-state observations valuable. Verification should demonstrate that requested and reported OFF states agree after repair, along with normal system operation. The factory flow is shared with ON, accessory and START comparison faults, but retaining U3011:62 preserves the relevant state and branch. It is not a general-purpose instruction for diagnosing any vehicle that has a discharged battery.

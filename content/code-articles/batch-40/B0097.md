# B0097: why Fiesta right rear sensor “no operation” can be a circuit fault

In the 2012 Ford Fiesta manual, B0097 concerns the passenger second-row C-pillar impact sensor, described by the generic label right-side restraints sensor 2. Suffix 93 means the restraints controller cannot obtain normal operation from the sensor. That description does not establish an internal sensor failure.

## Preserve the relationship with B0091

Ford's Pinpoint Test N also covers the driver front-door sensor. A short to ground on either sensor feed can create the pair B0091:11 and B0097:11. A voltage short on a feed or return can create B0091:93 and B0097:93. In particular, the source identifies unwanted voltage on a return circuit as one way to store a no-operation fault.

A lone B0097:93 follows a more localized route. The technician first verifies that the passenger C-pillar sensor connection and restraints-controller connectors are seated and locked. If the concern persists, the chart investigates interruptions in the sensor circuits before its conditional component decision. This is why the entire restraints scan matters more than a single dashboard description.

## Repair evidence must survive the self-test

The manual distinguishes a fault retrieved on demand from one remaining only in continuous memory. A history-only concern takes the intermittent-connection route; loss of the original symptom during diagnosis is not, by itself, a reason to install a new controller.

Impact-sensor testing belongs to a qualified SRS technician. Ford prohibits multimeter probing of the sensor and requires the restraints system to be operational and free of faults before release. The final check includes other restraints codes and system prove-out. These conclusions are limited to the cited Fiesta procedure and do not imply that every vehicle pairs the same sensor locations.

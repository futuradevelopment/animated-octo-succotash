# P1499: the Jeep hydraulic cooling-fan control circuit

P1499 in the WJ/WG gas-powertrain manual concerns the hydraulic cooling-fan solenoid circuit. This system uses a pulse-width-modulated command and an ASD-relay-fed supply. Treating it as a conventional electric fan motor fault can therefore send diagnosis toward the wrong components.

## Fan response determines the first branch

The factory procedure begins with a scan-tool hydraulic-fan test. If the fan responds correctly, it investigates intermittent wiring and connectors rather than immediately condemning the solenoid. The original freeze-frame information is useful because temperature and engine load can distinguish the earlier event from a normal workshop test.

If the fan does not respond, the procedure checks the fused ASD output at the solenoid while the relay is commanded. That supply observation is separate from checking the PWM command wire. An open supply, an open command wire and a command wire shorted to ground can all prevent the expected response, but require different repairs.

The final component decision follows isolation of the wiring and a controlled actuator check. Those tests should be performed by a qualified technician: the fan can move during commanded testing, and hydraulic components require the appropriate service precautions. Improvised grounding or relay bridging is not an owner-level diagnostic step.

## What a repair should establish

A useful report identifies whether the missing element was supply, command or solenoid response, then confirms reliable commanded fan operation. The cited manual does not provide a monitor threshold on this particular page, so none is inferred here. This explanation applies to its WJ/WG hydraulic-fan system, not every Jeep cooling-fan design.

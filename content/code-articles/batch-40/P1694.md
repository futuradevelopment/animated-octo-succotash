# P1694: the Jeep transmission controller has lost engine messages

The 2002 WJ/WG 45RFE/545RFE manual describes P1694 as missing communication with the engine module. With the ignition on, the TCM sets the fault after receiving no PCM messages for ten seconds. This identifies the receiving module's observation; it does not prove that the PCM itself has failed.

## Establish whether the loss is local or widespread

The diagnostic sequence checks communication with other modules and looks for bus-related faults elsewhere. A No Bus indication in the range display, or intermittent operation of other bus-controlled features, points toward a vehicle-wide communication problem. In that case, the manual directs diagnosis to the communication section before treating the TCM as an isolated failure.

If the evidence does not support a wider bus fault, the procedure examines the communication path between the PCM and the diagnostic connector. The source also specifically warns that aftermarket remote-start or communication equipment can set this code. Recent installation work is therefore relevant evidence, although its presence alone does not establish blame.

## Watch the network terminology

The catalog title mentions CCD messages, but this particular factory procedure names the PCI bus. The article follows the documented 2002 system and does not treat those network names as interchangeable. The correct wiring diagram is essential before any electrical isolation.

After repairing the identified communication fault, a workshop should confirm stable module communication and complete the transmission verification. Clearing P1694 without determining why messages disappeared does not distinguish a corrected fault from an intermittent one.

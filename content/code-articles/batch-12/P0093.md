# P0093: Why a large fuel-leak code can come from excessive valve demand

P0093 carries a “large leak” description, but the Ford diesel monitor does not directly observe fuel escaping from a particular location. It evaluates how much **volume-control valve demand** is required to maintain the desired rail pressure. That distinction matters before a leak location or replacement part is claimed.

## Idle and loaded operation use different evidence

At idle, the documented threshold is a valve set point above 13,500 mm³/s while maintaining desired pressure. Away from idle, the comparison changes: the required valve set point is 40% greater than the value calculated from requested injection quantity.

Ford lists a two-second typical monitoring duration and requires the fuel-rail pressure sensor checks to be satisfactory. The same valve demand cannot be interpreted without knowing whether the engine was in the idle or non-idle branch and whether the pressure information was considered valid.

## What the code supports

A useful diagnostic record connects desired pressure, operating state, requested injection quantity, and available control-effort information. The non-idle branch is a relative model comparison; it is not simply the idle volume limit applied at higher speed.

This is evidence of unusually high supply effort in the documented strategy. It does not establish an external leak, identify a leaking injector, or prove pump failure. Companion pressure-sensor faults and the applicable service tests determine how that evidence can be used. Avoid opening high-pressure connections as a shortcut: the summary supplies detection logic, not a safe mechanical leak-test procedure.

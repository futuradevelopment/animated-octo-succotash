# P0281: Cylinder-seven balance is a correction result, not an automatic injector verdict

P0281 is cylinder seven contribution/balance. In Ford’s 6.7L cold-start implementation, the relevant result is correction above 90% of the allowable fuel-balancing correction for current conditions. The code does not itself say that cylinder seven’s injector is electrically open, shorted, or mechanically leaking.

## The cold-start test has prerequisites

Cold-start mode must be active, fuel-balance wheel learning complete, and the crankshaft circuit and range/performance checks satisfactory. The documented speed window is 500–3,000 rpm and injection quantity is 3.5–90 mg/stroke. Ford gives 7.5 seconds as the typical detection duration.

Those requirements make supporting data important. An unfinished wheel learn or questionable crankshaft signal changes how a balance observation should be interpreted, rather than serving as unrelated background information.

## Compare related codes without merging their meanings

For cylinder seven, P0279 and P0280 represent separate driver-detected circuit conditions. They can coexist with P0281, but each describes different evidence. A successful electrical test does not automatically demonstrate acceptable balancing correction, and the balance code alone does not identify a short circuit.

The document’s general balancing section also excludes regeneration, whereas this cold strategy requires its specific mode. Verify the applicable event and engine mapping before following a cylinder-level procedure. Ford’s summary does not supply a universal injector replacement rule or isolate the mechanical cause of excessive correction.

## Source and applicability

This explanation follows Ford’s 2023–2024 diesel OBD summary. Match the vehicle’s engine and calibration before applying these monitor values; a generic code alone does not establish fitment.

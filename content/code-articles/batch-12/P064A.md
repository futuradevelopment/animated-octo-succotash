# P064A: Fuel-pump module diagnosis includes timing and command plausibility

P064A names fuel-pump control module A, but Ford’s diesel definition does not make the module label a replacement verdict. Two observations can qualify: the monitoring signal has an unacceptable **time period**, or the commanded duty cycle is implausible.

## Two branches behind one module code

The listed monitoring-signal period is outside a 0–1.2-second range. Ford separately lists implausible fuel-pump command duty cycle without publishing its complete plausibility calculation here. The check is continuous, with a typical detection duration of 0.5 second.

The first branch is a timing assessment, not a pressure specification. The second requires a valid interpretation of command information; it should not be replaced with the 78–82% feedback window assigned to P062A. Similarly, U0109’s extreme command-duty thresholds belong to a separate listed check.

## Why the signal identity matters

Before diagnosing a failed controller, establish whether the vehicle uses the documented separate-module architecture and which diagnostic data represents the monitoring signal. A normal average duty value cannot, by itself, prove that signal timing is correct. Conversely, a frequency or period problem does not automatically establish inadequate fuel delivery.

Useful verification preserves the related fuel-pump codes and evaluates the applicable signal definitions together. The source provides neither pin assignments nor a complete command-plausibility algorithm, so vehicle-specific service information is required to isolate the fault. It would be unsupported to identify a module, motor, or wiring defect solely from the module name in P064A’s title.

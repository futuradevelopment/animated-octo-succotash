# P2B13: Cylinder-two offset learning is an energizing-time comparison

P2B13 is the cylinder-two injection-pulse offset learning-limit code. The Ford diesel monitor compares the **observed energizing time** of a calibration injection with its intended target. This differs from checking whether the injector circuit is open or whether the cylinder contributes evenly at normal load.

## What exceeds the allowed learning range

Ford specifies a fault when energizing time is at least 156 microseconds lower than target or at least 254 microseconds higher. Those two boundaries are deliberately different. Recasting them as one generic percentage error would lose information from the actual monitor.

The check runs whenever its base zero-fuel calibration function runs, with a typical duration of 30 seconds. The summary requires suitable fuel and coolant temperatures, adequate system voltage, very low accelerator input, and a limited difference between requested and actual rail pressure.

## Separate unsuccessful learning from absent opportunity

Before treating a non-returning code as proof of correction, establish whether an eligible calibration opportunity occurred. The source identifies several 3.0L-specific conditions in addition to common conditions; the applicable engine’s requirements must be used.

P2B13 targets cylinder two, while the surrounding P2B1x codes share the same test for other cylinders. A useful diagnostic record therefore preserves cylinder identity and the learning result together. The summary does not show whether the offset originates in an injector, its control environment, or another cause, and it does not supply the vehicle-specific programming or adaptation procedure needed to resolve that question.

## Source and applicability

This explanation follows Ford’s 2023–2024 diesel OBD summary. Match the vehicle’s engine and calibration before applying these monitor values; a generic code alone does not establish fitment.

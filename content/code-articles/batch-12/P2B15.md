# P2B15: Cylinder-three pulse adaptation can fail in either timing direction

P2B15 reports an out-of-range learned injection-pulse offset for cylinder three. Ford’s zero-fuel calibration monitor can set it for a test injection whose energizing time is **too short or too long relative to target**. The code does not independently state which physical part created that discrepancy.

## Two boundaries within one code

The shorter-time boundary is 156 microseconds below target; the longer-time boundary is 254 microseconds above target. Meeting or exceeding either deviation qualifies in the documented monitor. This is an offset comparison, so the target energizing time matters; an isolated pulse duration has no equivalent meaning without that target.

Typical monitoring duration is 30 seconds, and the monitor accompanies the base calibration function. Ford lists fuel temperature between 10 and 75°C and coolant at least 50°C among the qualifying conditions, plus a rail-pressure command/actual difference capped at 50 bar.

## Interpret the cylinder-specific result carefully

The family shares these learning boundaries, and P2B15 identifies the cylinder-three record. It is useful to distinguish a repeatable third-cylinder offset result from several simultaneous learning faults, without assuming either pattern proves a particular cause.

Some listed enabling conditions are explicitly 3.0L-only. Use engine-specific service information before deciding whether learning completed or should be repeated. The summary does not publish a manual relearn sequence, injector adjustment, or replacement instruction. A smooth-running engine outside the calibration window is not a direct verification of the monitored pulse-offset limit.

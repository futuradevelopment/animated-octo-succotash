# P0170: A diesel fuel-trim fault uses a filtered global fueling error

P0170 is fuel trim, bank one. In Ford’s diesel summary it belongs to the fuel-mass observer, which assesses a **global fueling bias**. The listed failure criterion is the absolute value of the filtered fueling-error ratio exceeding 0.15.

## Magnitude is different from direction

Using an absolute value means this check concerns excessive error magnitude. The companion P0171 and P0172 tests use negative and positive limits respectively. P0170 should therefore not automatically be described as lean-only or rich-only on the strength of its code alone.

Ford gives a typical duration of 45 seconds. Qualifying operation includes 1,000–3,000 rpm, injection quantity of 20–80 mg/stroke, coolant at 70–120°C, a ready tailpipe oxygen sensor, and no post-injection. Fueling change is also bounded to a narrow rate, which makes this a stable-operation observation rather than a response to any brief acceleration transient.

## What makes the evidence useful

Relate an observed fuel-trim result to the monitor’s qualifying state. A rapid transient or an active post-injection event is not equivalent to the documented test window. Also establish whether the record includes a directional companion code before assigning a lean or rich interpretation.

The summary does not identify a specific injector or provide a complete mass-observer calculation. It cannot determine a replacement part from the 0.15 threshold alone. Its value is in separating a sustained, filtered whole-system bias from a cylinder-specific electrical fault or a momentary pressure fluctuation.

## Source and applicability

This explanation follows Ford’s 2023–2024 diesel OBD summary. Match the vehicle’s engine and calibration before applying these monitor values; a generic code alone does not establish fitment.

# P0272: Cylinder-four balance requires a completed wheel learn

P0272 identifies cylinder four’s contribution/balance fault. In the Ford 6.7L cold-start example, the system compares its fuel-balancing correction with the allowed correction for the current conditions. Exceeding 90% of that allowance is the documented failure boundary.

## Learning status is part of the evidence

The monitor requires **fuel-balance wheel learning to be complete**. It also requires satisfactory crankshaft-position circuit and range/performance checks. A balance result is therefore not independent of the rotational information used by the control system.

Cold-start mode must be active, speed must be within the listed 500–3,000 rpm range, and injection quantity within 3.5–90 mg/stroke. The typical monitoring duration is 7.5 seconds. These details help distinguish a valid completed assessment from an arbitrary snapshot of correction data.

## Do not turn correction into an assumed cause

P0272 selects cylinder four, but the same cold-start criterion is shared by the other cylinder contribution codes. It does not create a unique cylinder-four hardware test or imply a physical bank location across all engines.

Useful follow-up retains the operating mode, wheel-learn status, and related electrical or crankshaft codes. Ford separately describes general balancing outside regeneration, so that monitor’s state should not be confused with the cold strategy. The source does not decide whether an injector, mechanical condition, or another cause created the excess correction; that requires the correct vehicle diagnostic procedure.

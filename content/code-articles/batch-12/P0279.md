# P0279: Cylinder-seven injector low is an electrical classification

P0279 is the low-circuit code for cylinder seven’s injector A. In Ford’s diesel summary, the diagnostic mechanism is an **injector short circuit detected by the driver IC**. The code therefore describes electrical evidence on that cylinder’s channel; it does not directly measure how much useful combustion cylinder seven contributes.

## Injection must be requested

Ford lists continuous monitoring, but the stated entry condition is that injections are requested. Typical monitoring duration is 0.3 second. That requirement helps explain why a quiet circuit with no injection command is not an equivalent demonstration that this active electrical check passes.

The adjacent P0280 classification is more specific about a high-side-to-low-side short. Ford keeps it separate from the short-circuit category assigned to P0279. Do not assume that the words low and high are simply two generic connector-voltage readings.

## Keep electrical and balance evidence separate

Cylinder-seven contribution/balance uses P0281 in a different monitor. A balance complaint and P0279 can both be useful, but the electrical fault should not be rephrased as proof of poor fuel atomization or mechanical compression loss.

The source does not locate the short inside the injector, harness, or driver. It also does not supply universal cylinder positioning. Identify the correct engine’s cylinder-seven channel and use its approved circuit procedure. Because this is an injector driver system, improvised energizing or terminal probing is not an appropriate substitute for the specified service test.

## Source and applicability

This explanation follows Ford’s 2023–2024 diesel OBD summary. Match the vehicle’s engine and calibration before applying these monitor values; a generic code alone does not establish fitment.

# P21C4: Reductant heater voltage remains present with the power stage off

P21C4 is reductant heater relay control circuit high. Ford’s diesel threshold is **heater voltage above 5 V with both the power stage and heaters off**. This makes it an off-state electrical observation rather than a test of whether the heater can produce enough heat.

## The command context separates this code from its neighbors

P21C2 and P21C3 examine current with the power stage on. P21C4 instead examines voltage when that stage is off. Those are different diagnostic opportunities even though all appear in the relay-control family.

Ford lists a maximum 5,000 ms fault-detection duration for the group. A voltage reading captured while the driver is intentionally on cannot be compared with the off-state criterion without first establishing the actual command state.

## Unexpected voltage does not name the failed component

A useful investigation preserves the module command, heater state, and reported voltage together. The fact that a voltage is present does not, by itself, distinguish a relay-contact problem, wiring condition, or output-electronics issue.

The summary does not provide a universal connector pin or a method for bypassing the relay. It also does not prescribe replacing the complete heater assembly. Vehicle-specific circuit testing is needed to identify why the monitored path remained above the stated off-state limit. The code’s practical value is its clear voltage-versus-command mismatch, which should guide further diagnosis instead of a generic heater-performance assumption.

# U0109: A fuel-pump communication code may use duty-cycle limits

U0109 is lost communication with fuel-pump control module A. Ford’s diesel summary attaches an unusual but useful detail: this check uses **fuel-pump command duty cycle below 5% or above 95%**. A communication-code prefix therefore does not prove that the relevant failure is a CAN-message timeout in this implementation.

## Understand the actual communication evidence

Ford lists continuous monitoring and a typical duration of 0.5 second. The same system description distinguishes direct PCM pump control from arrangements using a separate fuel-pump controller. Verify the installed architecture before choosing a network or signal test.

The duty-cycle quantity also needs care. P062A checks returned lift-pump feedback against a 78–82% window, while U0109 uses the extreme command boundaries. Comparing a feedback parameter against U0109’s command limits would mix two different diagnostics.

## What the code does and does not prove

A useful record links the U0109 event to the correct control signal and any companion pump-module faults. If the controller is accessible during inspection, that alone does not disprove an earlier invalid encoded signal. Equally, poor fuel delivery is not proof of the communication mechanism described here.

The summary does not identify a failed module or publish a universal harness test. Follow the actual vehicle’s diagnostic information to determine the correct signal path and fault isolation method. Avoid turning the generic phrase “lost communication” into an assumed bus failure when the manufacturer’s stated monitor uses duty-cycle evidence.

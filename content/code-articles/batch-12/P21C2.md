# P21C2: Reductant heater relay open detection uses a commanded power-stage state

P21C2 is reductant heater relay control circuit/open. Ford’s diesel summary evaluates **heater current below 0.2 A with the power stage on and heaters off**. Both command states belong to the documented test; “heaters off” does not mean the complete relay-control system is inactive.

## The test separates relay control from normal heater load

The monitor group runs when heaters are activated and lists a maximum 5,000 ms detection duration. Within that group, the P21C2 diagnostic state deliberately specifies heaters off. This should be understood as the stated control-check context, not simplified into a normal full-heating current test.

P21C3 uses excessive current in the same listed state. P21C4 instead looks for voltage with the power stage off. Retaining those differences helps select the correct relay-control branch from the actual code.

## An open classification still needs isolation

Useful verification identifies the power-stage command, heater state, and reporting relay-control path. A current measurement taken while the system is normally heating cannot automatically be compared with the P21C2 off-heater criterion.

The summary does not locate an open in a relay, harness, output driver, or another component. Nor does it publish a connector pinout or authorize bypassing the relay. Use the correct vehicle’s service method to establish where the control path fails before selecting a replacement; the code supplies a state-dependent current observation, not a parts verdict.

## Source and applicability

This explanation follows Ford’s 2023–2024 diesel OBD summary. Match the vehicle’s engine and calibration before applying these monitor values; a generic code alone does not establish fitment.

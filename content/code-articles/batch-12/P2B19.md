# P2B19: Cylinder-five pulse-offset learning is not injector data coding

P2B19 is an excessive injection-pulse offset for cylinder five. Ford’s zero-fuel calibration function compares test-injection energizing time with a target. That is distinct from the injector-data validity checks described elsewhere in the same document, which examine stored codes and checksums.

## A learned time offset has two limits

The documented malfunction boundaries are at least 156 microseconds below the target or 254 microseconds above it. The test therefore retains both direction and an asymmetric allowed deviation. It is not enough to describe the result as simply “injector not coded.”

Ford gives 30 seconds as the typical monitoring duration while the calibration function runs. Common entry conditions include warm coolant, a bounded fuel-temperature window, sufficient voltage, low accelerator input, and close agreement between requested and actual rail pressure.

## Match the evidence to the fault type

A valid injector identifier does not automatically prove that the learned pulse offset is acceptable. Conversely, an offset-learning code alone does not establish a missing identification record. Preserve both kinds of codes if present and follow their respective service checks.

P2B19 selects cylinder five within a shared learning strategy. The table includes some explicitly 3.0L-only entry conditions, so the full enabling list must be matched to the actual engine before judging a learning attempt. Ford’s summary neither assigns a universal cylinder location nor prescribes injector replacement. It explains the detected comparison, leaving component isolation and adaptation procedures to the applicable service information.

# P0282: Cylinder-eight injector low should be read as a driver-detected short

P0282 identifies cylinder eight’s injector A circuit low. Ford’s diesel monitor places this code in the group for **short circuits recognized by the injector driver’s internal logic**. It is not an inference made simply because cylinder eight appears weak in a contribution test.

## Commanded injection provides the test opportunity

The monitor is described as continuous, with injection requests required and a typical 0.3-second duration. That makes the operating state important. Lack of a returning code while no injections are commanded is not the same evidence as a completed, passing active-circuit check.

Ford assigns P0283 to the separate high-side-to-low-side short category, while an open cylinder-eight circuit uses P0208. The code set thus retains electrical distinctions that can be lost by grouping every injector complaint as “bad injector.”

## Use companion evidence without changing the definition

P0284 concerns cylinder-eight contribution/balance in another monitor. If both classifications are present, preserve their different meanings: one reports electrical driver evidence, the other reports a combustion-balancing correction. Neither should silently replace the other in the diagnosis.

The source does not state where the short lies or provide a vehicle-independent cylinder location. The applicable wiring, engine layout, and injector-driver service procedure are needed to isolate it. High-voltage injector circuits should not be energized or disconnected experimentally using thresholds borrowed from a generic code description; this summary supplies detection logic, not those physical test instructions.

# P05A1: Grille shutter A endstop diagnosis changes between learning and normal operation

P05A1 is active grille shutter A position-sensor minimum/maximum stop. Ford labels this section **3.0L only** and evaluates the difference between commanded and actual final shutter position at an endstop. The code is not simply a general statement that the shutters look closed.

## Learning and normal movement use different limits

The monitor requires a fully open or fully closed endstop command and more than five self-learning events. Ford lists a ten-second duration.

During self-calibration toward fully closed, the documented position difference is above 40 degrees. During fully open self-calibration, it is above 20 degrees. Normal operation toward either endstop uses a 20-degree difference. Those unequal learning limits should not be replaced with one universal position-error allowance.

## A stationary inspection may miss the relevant event

Useful verification identifies whether the fault occurred during self-learning or normal endstop movement and confirms that the required learning count was reached. A shutter observed at rest does not show how accurately it reached its commanded final position.

P05B0 applies the same family’s endstop check to shutter B; P05A1 must retain its A identity. The source does not identify a broken linkage, obstruction, position sensor, or actuator as the root cause. It provides a position-following result that requires the actual vehicle procedure before mechanical intervention or replacement.

# P0275: Cylinder-five correction can exceed the cold-start balancing allowance

P0275 is cylinder five contribution/balance. Ford’s 6.7L cold-start monitor detects fuel-balancing correction above 90% of the allowable correction for current conditions. This is a **relative control-limit test**, not a universal fixed milligram-per-stroke limit for every engine state.

## Conditions determine whether the comparison is meaningful

The source specifies cold-start mode, 500–3,000 rpm, and injection quantity between 3.5 and 90 mg/stroke. It also requires completed wheel learning and valid crankshaft circuit/range checks. A typical 7.5-second monitoring duration is listed.

A displayed correction captured outside that qualifying context cannot simply be compared with the fault’s percentage boundary. The allowable correction has to belong to the same operating condition as the measured correction.

## Separate what is observed from what must be diagnosed

The observation is excessive cylinder-five balancing demand. It does not directly report an injector winding problem, a compression measurement, or a fuel-leak location. Those conclusions require independent evidence from the applicable service checks.

The document also contains a general fuel-balancing monitor that excludes regeneration. Preserve whether the original event was cold-start or general operation rather than assuming a later passing idle check reproduces both. Confirm the physical cylinder identification for the engine before following any cylinder-specific service action. This shared monitor family provides a focused starting point, but no instruction to replace cylinder-five hardware solely because P0275 is stored.

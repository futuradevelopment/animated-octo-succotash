# P025D: High feedback in the low-side fuel-pump control path

P025D reports a high condition in fuel-pump module A’s control circuit. Ford’s example connects that label to **short-to-power detection**. It does not mean the pump is delivering excessive pressure, and it should not be reduced to a general instruction to replace the pump.

## The monitored path changes with the system

The 3.0L description places short-to-power detection in the pump electronics module. The 6.7L description identifies the low side of the fuel-pump relay. Ford gives continuous monitoring and a typical 0.5-second duration for this code.

The same source distinguishes direct PCM control in its F650–F750 example from module-controlled pump arrangements in the listed F250–F550 and 3.0L applications. Consequently, an assumed module location or a wiring diagram from a different engine can lead to testing a circuit that is not present.

## Use the fault classification to narrow evidence

P025C is the corresponding short-to-ground classification. P025D preserves the opposite electrical direction, while P0629 on the same page refers to short-to-power detection on the relay’s high side. Those details help select the correct diagnostic branch once actual vehicle applicability is confirmed.

Record the complete pump fault set and relate it to the correct control architecture. The summary supplies no connector pinout and no independent method of separating an external short from a driver problem. A valid diagnosis still needs the appropriate circuit procedure; supply-pressure behavior alone cannot establish the source of this high-control feedback.

## Source and applicability

# P06A7: Sensor reference B is a separate monitored supply group

P06A7 identifies sensor reference voltage B range/performance. Ford’s diesel summary maps it to **sensor supply two**, with an output below 4.7 V or above 5.3 V as the documented failure boundary.

## Supply identity matters as much as voltage

The ECU monitor is continuous and lists a typical five-second duration. P06A6 and P06A8 use the same nominal boundaries for different supply groups. That shared numerical range does not make the physical circuits interchangeable.

Ford’s cam/crank section specifically lists sensor supply two among the prerequisites for camshaft range/performance and crankshaft/camshaft correlation checks. If P06A7 accompanies those faults, the reference validity belongs in the interpretation rather than being discarded as an unrelated code.

## What the monitor does not locate

The source does not establish which connector, sensor load, harness branch, or internal regulator is responsible for the out-of-range supply. Nor does it prove that every dependent component needs replacement.

Useful verification confirms the actual vehicle’s supply-two grouping and relates its fault state to the affected diagnostic events. An acceptable measurement on a different reference circuit cannot demonstrate that supply two passed. The ECU entry table also describes a monitored energized-state context; the complete vehicle procedure is needed to establish safe test points and valid operating conditions. P06A7 provides a focused shared-supply finding, not a general instruction to replace the cam sensor or control module.

## Source and applicability

This explanation follows Ford’s 2023–2024 diesel OBD summary. Match the vehicle’s engine and calibration before applying these monitor values; a generic code alone does not establish fitment.

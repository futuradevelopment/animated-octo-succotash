# P025C: A low lift-pump control signal depends on the engine architecture

P025C names fuel-pump module A control circuit low. Ford’s diesel summary makes the underlying architecture important: the 6.7L F650–F750 arrangement uses direct PCM pump control, whereas the listed F250–F550 arrangements and 3.0L products use a fuel-pump controller module. The code title alone does not tell you which layout is fitted.

## Which low-circuit observation is documented?

For 3.0L, Ford describes a short to ground detected by the pump electronics module. For 6.7L, the listed observation is a short to ground on the **low side of the fuel-pump relay**. The monitor is continuous and has a typical duration of 0.5 second.

That low-side designation is not interchangeable with every other pump-control code. The same page assigns high-side relay short-to-ground detection to P0628. Starting with the wrong side of the circuit would erase a useful distinction already present in the diagnostic record.

## Match the circuit before judging the pump

Establish the actual engine and control arrangement, then use its wiring and test procedure to interpret the short-to-ground evidence. A low fuel-pressure reading may be related, but it does not identify which electrical path the controller detected.

The source’s chassis and engine examples describe the monitor architecture, not proof that every vehicle in those groups supports every code. Nor does the summary identify a failed pump motor. It provides a circuit classification that must be matched to the vehicle before deciding whether wiring, relay control, or module testing is appropriate.

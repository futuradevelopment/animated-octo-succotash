# P2200: An upstream NOx circuit code includes controller self-check failures

P2200 names the bank-one sensor-one NOx circuit, but Ford’s diesel summary gives it more than one diagnostic route. The upstream NOx controller can report **RAM failure or memory CRC errors**, and the sensor circuitry can report short or open conditions. Treating the title as proof of one damaged external wire would overlook the controller self-check branch.

## Internal integrity and sensor circuits are different evidence

Ford lists a five-second malfunction duration for the controller checks. The sensor section separately identifies monitored circuits such as Vs, COM, and pump-current paths, with hardware-detected opens and low/high electrical conditions.

These are internal system diagnostics, not a universal pin-testing chart. The document does not establish that the same voltage limits can be applied to an unidentified connector on another NOx sensor design.

## What should be clarified before a replacement

Determine whether the available fault detail points to controller memory integrity or the sensor’s electrical diagnostics. Preserve supply-related and communication codes, because they represent different supporting evidence from the same system.

P2200 is also separate from the upstream NOx range/performance and heater classifications listed nearby. A plausible NOx concentration at one moment does not demonstrate that a memory self-check or intermittent electrical fault has passed. Conversely, an internal diagnostic label does not itself prescribe replacement of the complete assembly. The applicable vehicle procedure is needed to identify the reporting module, exact failure detail, and correct isolation method.

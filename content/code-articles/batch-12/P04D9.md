# P04D9: Low EGR flow reaches the closed-loop control limit

P04D9 is closed-loop EGR control at limit with flow too low. Ford’s diesel monitor evaluates **desired EGR ratio minus measured EGR ratio**, rather than directly checking an EGR motor winding or a single valve-position voltage.

## The operating point sets the allowed error

The summary describes the error limits as functions of engine speed and torque. It gives 6.7L example boundaries but does not define a complete universal ratio map or its units sufficiently for a stand-alone workshop specification here. The useful point is that the monitored discrepancy is relative to the current control expectation.

The check runs continuously with a typical twenty-second duration. It requires closed-loop EGR control and no air-system faults. A target/actual discrepancy during an invalid or open-loop interval should not be treated as a completed instance of this monitor.

## Why the low-flow label is not a root cause

The code reports that the EGR control result remains on the low-flow side of its allowed range. It does not distinguish insufficient valve movement, measurement error, or another flow-system condition. Those alternatives need the applicable service evidence rather than a guessed parts list.

P04DA is the high-flow counterpart. The nearby P02EC/P02ED family instead evaluates air mass and uses different timing. Preserve those distinctions when interpreting companion codes, and relate any logged EGR ratio to command, operating point, and monitoring eligibility before deciding what requires repair.

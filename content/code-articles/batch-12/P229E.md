# P229E: Tailpipe NOx processor and circuit faults share this code in Ford’s summary

P229E appears in Ford’s tailpipe NOx material under both a **processor-performance heading** and a **sensor-circuit heading**. That is an important source distinction: the generic title alone cannot tell which documented diagnostic branch produced the vehicle’s result.

## The circuit section supplies specific evidence

Ford lists shorts, open circuits, and pump-current path checks for the downstream sensor. The Ip2 crack-detection entry conditions include zero injection quantity for five seconds. That qualifying condition should not be generalized to every P229E branch; it belongs to the named crack-detection check.

The controller subsection lists a five-second malfunction duration, while the broader sensor subsection leaves its events-per-trip field as an unspecified placeholder. This article does not invent that missing count or treat the controller timing as a universal setting criterion for every sensor check.

## Resolve the branch before interpreting a repair

Preserve the exact reporting module, diagnostic description, and any available failure detail. Separate processor/self-check evidence from the sensor-circuit evidence rather than assuming that a code reader’s short label fully describes the fault.

The source covers 3.0L and 6.7L tailpipe sensor monitoring but does not establish every vehicle’s hardware or connector layout. It cannot by itself decide whether wiring, the sensor element, or its electronics require repair. The documented label overlap and incomplete event-count field need the applicable service information for a complete diagnostic decision.

# P245B: EGR bypass performance is checked through temperature response

P245B names EGR cooler bypass control circuit range/performance. Ford’s diesel summary describes an **intrusive temperature-response monitor**, with a failure boundary of downstream EGR temperature gradient below 3°C per second. The broad circuit label therefore does not establish that an electrical continuity fault was detected.

## Stable conditions make the response meaningful

The monitor runs once per driving cycle when qualified. Closed-loop EGR is required, and the bypass cooling command is evaluated during monitor pre-release. Coolant, speed, torque, EGR flow, and several rates of change are constrained so that unrelated operating transients do not dominate the temperature response.

Ford provides different speed and torque windows for 6.7L and 3.0L examples. The source lists detection as immediate after the monitor’s qualifying setup; that should not be read as “any cold temperature reading instantly sets P245B.”

## Temperature movement is different from absolute temperature

A gradient assesses change over time. One downstream temperature value without its timing cannot demonstrate whether the 3°C/s response boundary was met. This also differs from the P2457 undercooling comparison against coolant temperature elsewhere in the document.

Useful verification retains the intrusive test state, command context, and temperature timeline. The summary does not provide a complete actuator-command sequence or identify a replacement part. A weak response is evidence to investigate with the correct vehicle procedure, not automatic proof of a failed bypass motor, cooler blockage, or temperature sensor.

## Source and applicability

This explanation follows Ford’s 2023–2024 diesel OBD summary. Match the vehicle’s engine and calibration before applying these monitor values; a generic code alone does not establish fitment.

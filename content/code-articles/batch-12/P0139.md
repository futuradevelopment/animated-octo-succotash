# P0139: A diesel tailpipe oxygen response is timed during fuel shutoff

P0139 is bank-one sensor-two oxygen slow response. Ford’s diesel example uses the oxygen function in the **tailpipe NOx/O2 sensor system** and watches the transition from loaded operation into overrun fuel shutoff. It is not simply a rule that a downstream sensor voltage must switch at a fixed frequency.

## Three response windows reveal different delays

The monitor compares the loaded oxygen value with the approach toward atmospheric oxygen. Ford lists more than six seconds to reach 30% of that difference, more than five seconds to move from 30% to 60%, or more than eleven seconds to reach 60% from the starting value.

The last route also catches a sensor that is effectively inert. These staged comparisons distinguish initial delay from later response speed; one final oxygen reading cannot reconstruct all three timing observations.

## The operating transition must be valid

Ford says this monitor operates when particulate-filter regeneration is not occurring. The sensor section also requires dewpoint readiness. A response recorded during regeneration or before the relevant sensor state is reached should not be presented as an equivalent completed P0139 test.

Useful verification preserves the load-to-fuel-shutoff transition and the oxygen response timeline. The summary does not identify the cause of a slow response or establish the physical sensor arrangement of every vehicle with this generic code. It provides a specific diesel monitor example, requiring applicable service information before deciding on sensor replacement or further system testing.

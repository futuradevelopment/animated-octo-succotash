# P2B11: Cylinder-one injection pulse offset exceeds its learning window

P2B11 identifies cylinder one’s injection-pulse offset exceeding the learning limit. Ford places it in **zero-fuel calibration**, where observed energizing time for a test injection is compared with the target for that injector. The result concerns a learned pulse offset, not a direct finding that cylinder one has an open circuit.

## The window is asymmetric

The documented limits are 156 microseconds or more below the target, or 254 microseconds or more above it. The acceptable displacement is therefore not a symmetrical plus-or-minus value. Ford lists a typical monitoring duration of 30 seconds while the base calibration function is running.

Shared entry conditions include fuel at 10–75°C, coolant at least 50°C, system voltage at least 10 V, accelerator position no higher than 2%, and requested-versus-actual rail-pressure difference no greater than 50 bar.

## A valid learning opportunity matters

A useful verification asks whether the base calibration function actually operated under qualifying conditions. Normal cylinder behavior during an unrelated drive does not by itself demonstrate that the offset has returned inside its learning window.

Ford’s table also marks some entry conditions as 3.0L-only; those should not be applied indiscriminately to every engine using a code in this family. The threshold is shared among cylinder-specific codes, while P2B11 selects cylinder one. The summary does not establish injector replacement, publish a full relearn procedure, or identify a physical cylinder location for every vehicle.

## Source and applicability

This explanation follows Ford’s 2023–2024 diesel OBD summary. Match the vehicle’s engine and calibration before applying these monitor values; a generic code alone does not establish fitment.

# P0263: Cylinder-one balance depends on learned crankshaft information

P0263 identifies cylinder one’s contribution/balance problem. Ford’s 6.7L cold-start monitor evaluates the **fuel-balancing correction**, rather than directly naming a damaged injector. A fault occurs when the current correction exceeds 90% of the allowable correction for the operating conditions.

## A correction limit needs a valid reference

The cold-start check requires cold-start mode, completed fuel-balance wheel learning, and satisfactory crankshaft-position circuit and range/performance checks. Its stated speed window is 500–3,000 rpm, injection quantity is 3.5–90 mg/stroke, and typical monitoring duration is 7.5 seconds.

Those conditions matter because the balance result depends on a trustworthy rotational reference. A cylinder-one balance code should not be used to dismiss accompanying crankshaft information as unrelated, and an unfinished wheel learn cannot be treated as an equivalent completed monitor.

## Distinguish the cold strategy from ordinary operation

Ford separately describes a general fuel-balancing monitor that excludes regeneration and includes other supporting inputs. This article’s 90% criterion is anchored to the unambiguous 6.7L cold-start statement. The general table’s printed threshold code range contains an apparent typographical error, so it is not used to infer a separate cylinder-one threshold.

Preserve the mode in which the fault was recorded and confirm the actual cylinder mapping for the engine. The source does not separate injector delivery, combustion, and other possible causes or supply a mechanical repair procedure. The code is evidence of excessive correction, not a replacement verdict.

## Source and applicability

This explanation follows Ford’s 2023–2024 diesel OBD summary. Match the vehicle’s engine and calibration before applying these monitor values; a generic code alone does not establish fitment.

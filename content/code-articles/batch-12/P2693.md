# P2693: Cylinder-eight injector coding needs a valid individual record

P2693 is the cylinder-eight member of Ford’s injector-data incompatibility monitor. The stored injector code describes how that particular injector differs from an average injector. A fault means that the controller cannot accept the required **individual correction record**, not that it has directly observed a failed nozzle.

## Missing, implausible, or corrupted data

Ford lists three validation failures: no stored injector code, an out-of-range code value, or an incorrect checksum. The check runs continuously and normally needs 0.5 second to detect the listed malfunction.

These distinctions matter after reviewing a diagnostic record. “Data incompatible” should not be rewritten as an injector open circuit, short circuit, or contribution imbalance; those are separate electrical or combustion-monitor observations with different code families.

## Verification should address the record itself

Confirm cylinder numbering for the actual engine before comparing injector identification and stored information. An acceptable record must satisfy the controller’s own validation; simply finding a number on a component does not establish that the correct value is stored in the correct position.

The source does not give the programming workflow or every allowed code format. Use the appropriate vehicle service information to resolve those details, and do not substitute a neighboring injector’s data as a guessed repair. If the engine runs normally during inspection, that does not by itself prove the cylinder-eight record passes checksum and range validation. Conversely, P2693 alone is insufficient evidence for replacing the physical injector.

## Source and applicability

This explanation follows Ford’s 2023–2024 diesel OBD summary. Match the vehicle’s engine and calibration before applying these monitor values; a generic code alone does not establish fitment.

# P2073: Idle airflow adaptation is compared with a calibration-specific allowance

P2073 is MAP/MAF-to-throttle correlation at idle. Ford’s diesel summary ties the fault to the **final stored air-mass adaptation value in the idle cell**. It is not merely a one-time mismatch between two raw sensor readings.

## The idle allowance varies by calibration

Ford lists different idle adaptation boundaries for its 6.7L SuperDuty chassis, dynamometer, and F650–F750 examples. Those variations show why one generic percentage limit is not sufficient to diagnose every vehicle carrying P2073.

The monitor runs once per drive cycle with a typical five-second duration, and air-mass adaptation must be active. Air-meter, barometric-pressure, and EGR-related diagnostic prerequisites must be satisfactory. A value collected before valid learning has occurred is not automatically equivalent to the final stored value used by the check.

## Preserve the learned cell and its operating context

P2074 is the higher-load counterpart and also has a separate unstable-learning route. Passing a load-cell check does not directly verify the idle cell identified by P2073, and the load limits should not be applied to the idle result.

Useful diagnosis establishes the correct calibration, active learning opportunity, and supporting signal validity. The summary does not show that a throttle body, air meter, or EGR valve must be replaced. It reports an adaptation/correlation discrepancy whose cause requires the applicable service procedure, rather than a component verdict derived from the broad code title.

## Source and applicability

This explanation follows Ford’s 2023–2024 diesel OBD summary. Match the vehicle’s engine and calibration before applying these monitor values; a generic code alone does not establish fitment.

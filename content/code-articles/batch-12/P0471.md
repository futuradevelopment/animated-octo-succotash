# P0471: Exhaust pressure offset is compared with ambient pressure after shutdown

P0471 is exhaust-pressure sensor A range/performance. Ford’s diesel example checks the **offset between turbine-upstream pressure and ambient pressure** with the engine stopped. The listed failure is an absolute difference greater than 15 kPa.

## A stopped engine provides the comparison opportunity

The monitor requires zero engine speed, a sensor not considered frozen, and suitable ambient and coolant temperatures. Ford lists an engine-off time no greater than ten seconds in this entry table. Typical monitoring duration is five seconds for 6.7L and three seconds for 3.0L.

These details distinguish the offset check from a running exhaust-pressure model comparison. A pressure value recorded under load cannot be judged as if it came from the stopped-engine offset opportunity.

## Use both pressures rather than one isolated reading

A useful diagnostic record retains turbine-upstream and ambient pressure together. An offset between them does not automatically locate the fault in the exhaust-pressure sensor; the reference and qualifying conditions also matter.

Ford assigns P0474 to a separate model-based running plausibility check on the same page. Preserve that distinction when reviewing companion faults. The summary does not provide a pressure-port cleaning procedure, sensor pinout, or replacement verdict. It establishes a specific zero-speed pressure disagreement and the context in which it is meaningful, leaving physical isolation to the correct vehicle’s service instructions.

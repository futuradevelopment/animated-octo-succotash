# C050E: Left-rear wheel-speed low faults include more than one pattern

C050E is labelled left-rear wheel-speed circuit low, but the cited table includes two distinct failure paths. One concerns an implausible signal pattern that other electrical monitors do not classify. The other concerns a supply-line ground fault. The generic label alone does not identify which path failed.

## Read the diagnostic branch carefully

The unclassified-signal branch depends on current, supply and voltage monitoring not reporting their own failure. Its final validity condition is worded inconsistently in the source. The supply-ground branch lists sensor-supply current above 0.055 A and below 0.16 A, with a 0.120-second qualification.

That second description also incorrectly names the front-right corner while the code and internal failure identifier identify left rear. These contradictions are retained as source-review issues. They must not be silently resolved into a universal connector specification or a direction to work on the wrong wheel.

## What remains useful

Obtain the enhanced failure detail and confirm the actual channel identity in the vehicle's service information. A residual signal-classification error and a supply-ground report require different evidence. Looking only for a low wheel-speed value would miss both distinctions because low speed can be perfectly normal.

Brake-system electrical tests require the correct wiring procedure. This table does not prove a failed wheel-speed sensor or justify swapping parts between corners. Verification should establish that the original diagnostic branch completes without its fault and that the required brake-system functional checks pass; code erasure alone is insufficient.

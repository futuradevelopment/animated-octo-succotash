# C0514: Right-rear wheel-speed low diagnosis and supply-current context

C0514 identifies the right-rear wheel-speed circuit-low family in this source. Its main row starts at the bottom of one page and continues onto the next. Reading the code line without the continuation would omit the diagnostic conditions and a separate supply-ground branch.

## Two different electrical interpretations

One branch checks a signal pattern that is neither accepted as valid nor assigned to another electrical fault. However, the source's final validity Boolean conflicts with that explanation, so it is not converted here into a stand-alone logical test.

The other branch checks right-rear sensor-supply current between 0.055 and 0.16 A, described as a supply-line ground fault. It is qualified for 0.120 second. Ignition and the wheel-speed undervoltage-test prerequisites also apply. This is supply-current evidence, not a measurement that the wheel is turning too slowly.

## Keep the corner and failure detail explicit

Preserve enhanced fault status and the wheel-speed system's supply results. If the report concerns unclassified signal behaviour, the next question differs from a clear supply-ground current result. A plausible current wheel-speed display cannot establish that an earlier electrical event did not occur.

The contradictory validity wording needs application-specific service documentation to resolve. Do not use this summary to energize the sensor or improvise a current measurement through connected brake electronics. A repair check must include the relevant electrical diagnostic and specified functional verification. Clearing the fault does not itself establish that anti-lock or stability-control capability is restored.

# P2C01: Fuel regulator D control effort outside its plausible range

P2C01 is a high-pressure fuel-system plausibility check in the source. Its principal quantity is the filtered controller output, expressed in pressure units. This is not the same quantity as the rail-pressure sensor reading, so the code cannot be interpreted by comparing actual pressure with a single fixed maximum.

## Positive and negative control limits

One path detects controller output above 7.5 MPa for ten seconds. A second detects output below minus 7.5 MPa for ten seconds. The positive branch also lists a six-second variant when the fuel tank is empty or at reserve. Tank state can therefore affect the documented qualification even when the monitored control limit is unchanged.

The common conditions require a plausible rail-pressure sensor, appropriate post-start operation and active regulation rather than a reset state. The detailed pump, injection and synchronization conditions continue across pages. They must be considered before treating an uneventful idle period as a completed test.

## Preserve controller effort and measured pressure separately

If the diagnostic tool exposes them, capture the controller output, rail-pressure setpoint, measured pressure and fuel-level state together. A large corrective demand and a large actual pressure error are related but different observations. The adjacent pressure-deviation codes use a different measured quantity.

The table does not prove a failed regulator or pump. High-pressure fuel work requires the exact service procedure and appropriate equipment; the control-output limits are not physical pressure-test instructions. Verification should reproduce an eligible regulation interval and confirm the relevant branch no longer fails.

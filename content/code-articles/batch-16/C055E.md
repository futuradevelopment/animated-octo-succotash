# C055E: Calculated leakage in the source’s second brake circuit

C055E is listed as brake hydraulic circuit A leak in the dictionary. The cited GM monitor instead assigns its internal failure word to circuit 2. This article retains that naming difference rather than guessing that circuit A and circuit 2 are interchangeable on every vehicle.

## Leakage is inferred from hydraulic response

The controller calculates leakage using pressure sensor 2 and plunger-position information. The stated criterion exceeds 500 mm³ per second while the system is in circuit-separation mode and braking is requested by the driver or an external function. The listed qualification spans 0.1 to 0.5 second.

This is a calculated hydraulic result, not a direct observation of fluid escaping at a named fitting. A separate whole-system branch elsewhere in the same table uses another criterion. Applying that whole-system number to this circuit-specific code would lose the distinction.

## What evidence helps a professional diagnosis

Retain the system mode, requested braking, measured pressure and plunger information. Confirm which physical circuit the application associates with C055E before investigating a location. The source alone does not identify a hose, seal, caliper or visible leak.

A suspected hydraulic leak is not an invitation to reproduce the failure on the road. Use the prescribed professional hydraulic inspection and controlled test procedure. Verification must establish the cause and hydraulic integrity, not simply erase the calculated-leakage fault. The code and this summary cannot certify safe braking, and no pressure-line opening or valve actuation procedure is supplied here.

# C0021: Brake boost pressure fails to follow a substantial request

C0021 is a brake-booster performance fault based on insufficient measured pressure relative to demand. The cited monitor watches the plunger circuit while braking is requested by the driver or an external control function. It is not simply a low-fluid warning.

## A paired pressure condition

The principal row requires target pressure above 60 bar while pressure sensor 2 reports less than 30 bar. The listed qualification is 0.3 second with ignition on and the brake-boost system in its full operating state. A related good-check branch uses the same pressure relationship during a braking request.

The two pressure values must be interpreted together. A low measured value when no pressure was requested does not reproduce this test, while a large target with inadequate measured response directly matches the monitor's concern. The source does not specify a driver pedal-force test that can be safely improvised from these thresholds.

## Preserve demand, response and system state

The useful diagnostic record includes commanded pressure, sensor 2 pressure, the braking-request source and system mode. Sensor validity and other brake faults must be considered before concluding which physical component failed. This table alone does not distinguish a leak, actuator problem or misleading pressure feedback.

A braking-performance warning warrants professional assessment using the exact service procedure. Do not attempt road experiments to reach the printed pressure values. Verification requires the specified controlled functional checks and an eligible monitor result; a code erase does not establish that adequate braking assistance has returned or that the vehicle is safe to drive.

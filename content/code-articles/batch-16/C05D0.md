# C05D0: Pedal-position disagreement and prolonged overlapping pedal inputs

C05D0 is the master-cylinder position A/B correlation code. The documented controller first compares its two initialized, fault-free pedal-travel channels. It also associates a prolonged combination of brake travel and throttle input with the same code, so enhanced failure detail is important.

## Two very different routes

The channel-consistency branch fails when the absolute difference between the two travel signals exceeds 1.5 mm for 0.120 second. Both channels must be initialized and otherwise fault-free. A basic electrical fault can therefore change whether this particular comparison is eligible.

The separate overlap branch uses brake input-rod travel above 3 mm together with throttle above twenty percent, qualified for 240 seconds while speed exceeds 4.47 mph and accelerator-status information is valid. That long-duration condition should not be confused with the rapid sensor-disagreement check.

## Preserve the subtype and input states

Retrieve which branch set before assuming a sensor must be replaced. A genuine disagreement between two travel channels and a prolonged overlap of driver-input indications lead to different questions. Do not infer a driver's behaviour solely from the code; the recorded input validity and application diagnostics still require review.

These are controller criteria, not instructions to hold both pedals or reproduce a fault on the road. Professional brake-system diagnosis should use the prescribed controlled tests. Verification must address the original branch and complete the required functional checks. Clearing C05D0 alone cannot certify accurate driver-demand sensing or safe braking.

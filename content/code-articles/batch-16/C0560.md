# C0560: Brake pressure calibration status is not successful

C0560 is a missing-calibration diagnosis for the brake pressure sensor in the cited controller. The decisive information is the status stored in non-volatile memory. The source explicitly distinguishes that status from the calibrated offset also stored there.

## Status is the failure criterion

The monitor sets when the end-of-line calibration status is anything other than successful. It can evaluate the record after system wake-up and the non-volatile memory read. The table lists 500 milliseconds, although it also contains a separate unexplained goal value that is not treated here as an alternative time specification.

A calibration that was never completed and a calibration that completed unsuccessfully can therefore produce the same status-level result. A pressure reading near zero at one moment does not prove that the required stored calibration record is valid.

## What to establish before repeating calibration

Read the stored status and relevant memory or initialization faults, then obtain the exact application's calibration procedure and prerequisites. The source mentions missing calibration and non-volatile-memory error as checks to consider, but does not provide a universal pedal sequence or instruct the user to write an arbitrary offset.

Any calibration must be performed through the prescribed brake-system service process. Verification should confirm successful stored status after the controller reads its data again, as well as the required functional checks. Merely erasing C0560 or observing a plausible pressure value does not validate the calibration record. Because this concerns braking, a code-free display alone cannot establish restored safe operation.

## Source and applicability

2025 GM 04B documented monitor only; module and calibration applicability must be matched to the vehicle. [GM PDF, page 309](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG04B.pdf#page=309).

# C0555: Left-front sensor compatibility is checked through its protocol

C0555 is the left-front wheel-speed sensor incorrect-component diagnosis. The source does not identify a replacement by appearance; it evaluates characteristics of the sensor protocol. A device can physically fit while communicating in a way the controller does not expect.

## Variant-specific evidence

For the listed VDA variants, the fault condition is a received protocol-bit value different from nine. Other variants use a stop-pulse test. Importantly, the expected result reverses between the DF11i and DF11s entries: one flags a missing stop pulse, while the other flags its presence.

The table lists three seconds of qualification, ignition on, adequate sensor supply and completed undervoltage checks. This makes the sensor variant essential. Applying one variant's stop-pulse rule to another would create the wrong diagnosis even with an accurate signal observation.

## Verify identification before ordering parts

Preserve the installed sensor identification, application specification and protocol fault detail. The code supports checking compatibility, but does not prove that a recently replaced sensor is wrong or rule out every circuit influence on the received protocol.

Use the exact vehicle parts and diagnostic information to establish what format is expected at the left-front channel. The source provides no interchange list or safe probing setup. Verification should demonstrate that the applicable protocol test completes with the correct sensor supply state, followed by the prescribed brake-system checks. A normal-looking wheel-speed number alone does not prove protocol compatibility or restored ABS operation.

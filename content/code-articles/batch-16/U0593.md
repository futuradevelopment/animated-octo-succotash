# U0593: Hybrid drive-controller torque or gear messages fail integrity checks

U0593 is the invalid-data diagnosis for the hybrid drive powertrain controller in this GM brake-controller section. It checks protected brake-axle-torque and transmission-estimated-gear information. The code does not identify a failed traction motor or establish a high-voltage battery fault.

## Message identity changes the timing

Both alive-counter and authentication checks are described. The brake-axle-torque information rows use a 0.1-second qualification, while the estimated-gear rows use 0.2 second. The table also lists weighted counters with plus-two-per-step notation; those should not be restated as a simple count of missing frames.

A repeating alive counter indicates that freshness was not demonstrated as expected. An authentication error concerns another part of message integrity. Either can make a received value unacceptable even when traffic is present and the converted number looks plausible.

## Preserve data validity and network conditions

Record the rejected message, failure subtype and communication state. The monitor requires ignition on and communication prerequisites that exclude error-passive and undervoltage conditions. Evaluating the vehicle during a broader network fault may not reproduce this specific check.

Use the application's network and controller procedure to investigate the sender, receiver and communication path. No high-voltage disassembly is implied merely because the named source is a hybrid drive controller. Verification should demonstrate fresh, accepted protected information during an eligible monitor interval and the prescribed functional checks. A code erase or a normal motor response alone does not establish that the brake controller is receiving trustworthy torque and gear data.

# C0590: High booster current includes an idle-offset check

C0590 belongs to the brake-booster motor current-high family. The source includes both an offset check while the motor is not actuated and an out-of-range current check. Those branches should not be collapsed into a single claim that the motor drew too much current under load.

## Offset versus operating measurement

The offset branches flag an internally measured shunt-current offset above 38 A while the electric motor is not actuated, with a 0.2-second qualification. Separate branches flag measured current above 200 A for 0.3 second. Both current-measurement channels are represented.

The idle-state condition is decisive: a large reported current with no actuation raises a different question from excessive current during a motor demand. The source's values are internal diagnostic quantities; they are not instructions to route booster current through a handheld meter.

## Retain the failure branch and motor state

Record whether the controller reported a positive offset or an out-of-range operating measurement, plus the motor command state. This distinction can guide the professional investigation toward measurement integrity versus a real operating-current concern without prematurely naming a failed motor or driver.

The table does not supply an external current-test method or replacement verdict. Use the exact brake-system service procedure and required electrical protections. Verification should address the original branch and complete the prescribed braking checks. A code erase, an apparently normal motor sound or one current reading under a different command state does not prove the system's current sensing or assistance is restored.

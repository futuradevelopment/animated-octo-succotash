# P2BFA: Power-short status from exhaust valve B control

P2BFA is the power-short entry for exhaust valve B's PWM control circuit in this GM summary. The controller evaluates an electrical status generated by the circuit diagnostics. The high-circuit wording should not be interpreted as excessive exhaust flow or a valve that opened too far.

## The monitored result

The source lists a four-second qualification and a two-trip response. Battery conditions, basic enables and the short-to-power diagnostic enable are part of the operating context. These conditions distinguish a completed electrical judgement from an arbitrary voltage observation while the circuit is inactive or initializing.

There is a documentation conflict in the initialization condition: the description indicates that enough time has elapsed, but the printed comparison is less than five seconds. No corrected timing rule is assumed in this article. The appropriate service diagnostic must establish the actual initialization requirement.

## What this changes about the next check

Keep the power-short report separate from valve tracking or position feedback. A valve might fail to follow a command for several reasons, but this code specifically records the circuit's electrical classification. Conversely, one successful movement does not exclude an intermittent electrical event.

The summary does not identify a harness terminal or state a safe external voltage threshold. Connector access and circuit isolation require the application wiring information and exhaust-system precautions. Verification should show that the relevant electrical monitor completes without its power-short status returning. Replacing the valve solely from the code label skips the evidence needed to distinguish the circuit from the actuator assembly.

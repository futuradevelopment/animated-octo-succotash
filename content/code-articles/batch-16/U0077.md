# U0077: CAN bus fault and the adaptive-cruise fallback in this module

U0077 is the control-module CAN-bus fault entry in the cited GM sensing-module table. The monitor checks whether the CAN bus is on and names a ground-short condition or a faulty CAN controller as fault criteria. The dictionary's bus E label does not identify the physical network wiring for every application.

## Power and communication state matter

The source requires the diagnostic calibration to be enabled and communication active. It lists off, accessory or run power modes, an operating-voltage range of 9–19 V and a five-second qualification. A communication observation made with the module intentionally inactive does not reproduce those conditions.

Upon detection, the documented fallback disables adaptive cruise control. That consequence is useful context for a driver-assistance complaint, but it does not prove that the adaptive-cruise hardware itself caused the network fault.

## Find the reporting module and affected network

Preserve which module stored U0077, its power state and other network faults. Establish the actual network identified by the vehicle's wiring and diagnostic documentation before selecting terminals to test. The row describes possible bus/controller fault conditions but does not distinguish a harness defect from every internal controller problem.

Do not replace a module solely because adaptive cruise is unavailable. Network testing around a sensing or restraint-related module requires the exact professional procedure; this summary supplies no resistance test, connector pinout or disconnection sequence. Verification should confirm valid communication in an eligible power mode and the prescribed functional checks. Clearing U0077 alone does not establish recovery of the affected driver-assistance function.

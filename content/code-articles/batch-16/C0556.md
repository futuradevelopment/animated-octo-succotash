# C0556: Why a right-front wheel-speed sensor can fail identification

C0556 is the right-front wheel-speed incorrect-component check. The monitor judges whether the received protocol matches the configured sensor type. It does not simply compare the right-front speed with the other three wheels.

## Know which protocol test applies

The VDA entries expect a protocol-bit value of nine. The DF11i entry rejects absence of a stop pulse, whereas DF11s rejects presence of that pulse. Those opposite rules are not interchangeable. They reflect different sensor variants represented in the same document.

The source qualifies the result for three seconds with ignition on and supply above 6 V, alongside the wheel-speed undervoltage-test prerequisites. A compatibility conclusion reached while supply is invalid would not reproduce the documented test context.

## Use the code to verify specification

Check the required right-front sensor variant and retain any available protocol-status details before selecting a replacement. A part that plugs in and reports a plausible speed is not necessarily the correct protocol implementation. Equally, this code alone does not establish who installed a part or that the sensor itself is the only possible source of a malformed message.

The table does not supply a part number, pinout or external test waveform. Those must come from the specific application. Confirmation should include successful completion of the correct protocol test and the prescribed brake-system functional checks. Erasing the code or comparing one speed sample across wheels does not demonstrate that the identification concern is resolved.

# C0580: Brake motor phases fail expected low-state checks

C0580 concerns the brake-booster motor's phase circuitry in the GM 04B controller. Its low label groups more than one test. During operation, the controller verifies the voltage expected when a lower inverter transistor is switched on; at power-up it can check whether a phase is stuck near zero before the bridge is enabled.

## Opposite contexts explain the wording

The running low-state check flags a monitored phase voltage above 0.99 V when it should be low. The listed maturation is eighteen milliseconds or 128 counts. In contrast, the power-up check regards a phase near zero before activation as evidence of an unexpected stuck-low state.

There is no contradiction in the test contexts: low voltage can be expected during one commanded state and suspicious during another. However, some phase-2 and phase-3 threshold labels repeat the phase-1 signal name. That copy-label issue prevents using the summary as a definitive terminal-by-terminal test map.

## Preserve operating state and phase detail

Identify whether the recorded failure came from a running phase-voltage check or a startup test. An external voltage reading without the inverter's commanded state cannot reproduce either judgement reliably. The source lists possible driver faults but does not establish a particular failed transistor from the code alone.

Brake motor-drive testing requires the exact professional procedure. Do not energize phases or bypass bridge protection. Verification must exercise the relevant safe diagnostic sequence and required brake-system checks; clearing C0580 does not establish restored assistance.

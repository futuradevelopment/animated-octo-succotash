# C05D4: Stored pedal-travel calibration does not match the sensor

C05D4 is the missing-calibration code for pedal-travel sensing in the cited brake controller. Its strategy is more specific than the title alone: calibrations saved in non-volatile memory are reused at each drive cycle, and the controller compares them with values reported by the pedal-travel sensor.

## Startup data must agree

The fault sets when stored calibrations do not match the sensor-reported values. The check follows system startup and reading the non-volatile memory, with a listed thirty-millisecond maturation. The row does not provide a numeric travel offset or a universal difference tolerance to apply externally.

The source names missing calibration, memory error and controller/actuator mismatch as concerns. Those are alternative areas to investigate, not proof that the sensor was replaced or that the wrong control unit is installed. Service history is useful context but must be established independently.

## Preserve the calibration evidence

Read the available calibration status, component identification and related memory faults before resetting anything. A live travel reading that looks reasonable does not establish that the stored calibration belongs to the current sensor or was accepted at startup.

Any programming or calibration must use the correct application procedure and actual vehicle configuration. Do not enter guessed offsets or copy values from another vehicle. Verification should include a fresh startup data comparison and the prescribed braking-system checks. Clearing C05D4 or completing an unrelated sensor reset does not prove that the calibration mismatch is repaired or that brake-demand interpretation is dependable.

## Source and applicability

2025 GM 04B documented monitor only; module and calibration applicability must be matched to the vehicle. [GM PDF, page 317](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG04B.pdf#page=317).

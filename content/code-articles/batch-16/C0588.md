# C0588: Low sine, cosine or vector magnitude in booster rotor feedback

C0588 is the brake-booster rotor-position low-range diagnosis. The controller evaluates sine and cosine signal information used to determine motor position. It also checks their combined vector magnitude, so the code does not necessarily identify one simple low-voltage wire.

## Three forms of low-range evidence

The cosine branch uses a raw ADC count below ten, qualified for 0.150 second. The sine branch includes voltage below 1.047 V on either sine input and a separate summed-ADC criterion. A combined vector-magnitude check uses a limit below 0.25 and a shorter listed qualification.

These values have different representations: ADC counts, volts and a calculated vector quantity are not interchangeable units. A technician cannot apply the cosine count limit to a voltmeter or interpret the vector threshold as a physical rotor angle.

## Determine which signal check failed

Retain the enhanced sine, cosine or vector fault status if available. A valid-looking calculated angle may not expose an amplitude problem in the underlying signals. The exact application procedure is needed to distinguish a signal path fault from other position-feedback issues.

The summary does not provide safe access to internal rotor-sensor circuitry or authorize direct motor operation. Brake-booster testing requires professional equipment and the prescribed isolation procedure. Confirmation should establish valid underlying feedback during the relevant monitor, followed by required braking checks. A code erase or one plausible rotor-position value cannot prove that position sensing and braking assistance have recovered.

# C057A: High input on the booster’s second temperature channel

C057A is the high-input fault for brake-booster temperature sensor B in the cited controller. The source associates it with the second temperature signal shorted toward supply. It is an electrical range diagnosis, not direct proof that the brake booster has overheated.

## A channel-specific voltage limit

The monitor lists voltage above 3.14 V for five consecutive observations, with a 0.600-second qualification and ignition on. The table gives a two-trip response. Channel A on the same page uses a different high limit, which makes correct channel identification important.

A displayed high temperature and an input driven beyond its accepted voltage range are not interchangeable evidence. When a sensor input is rejected, a converted temperature may not describe the true component temperature. Preserve the range status before interpreting the thermal reading.

## What a useful follow-up establishes

Confirm that the application uses this channel arrangement, then retrieve the exact diagnostic procedure for the second temperature input. The table does not provide a terminal location or prove whether the fault originated in a sensor, supply path or internal electronics.

Verification should show the channel operating within its valid range long enough for the qualified monitor to complete, with the required brake-system checks also performed. Do not apply external voltage or substitute the channel A threshold to force a pass. A cleared code is not evidence that temperature supervision or safe braking has been restored; those conclusions require the matching service assessment.

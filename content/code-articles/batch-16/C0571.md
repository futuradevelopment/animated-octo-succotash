# C0571: Master-cylinder pressure feedback at its minimum reportable value

C0571 is the low-range pressure-sensor diagnosis for the master-cylinder channel in this source. The monitor checks whether the DS10 pressure value has reached its minimum reported value. The dictionary calls this pressure sensor C; the exact physical mapping requires the vehicle's service information.

## A saturation value, not a pressure target

The criterion is a reported value equal to minus 1,480 kPa, qualified for 0.960 second with ignition on. The table describes this as the sensor's minimum value. It is not an instruction to create negative hydraulic pressure or proof that the brake circuit physically experienced that reading.

The nearby communication monitor checks whether valid SENT messages arrive. This distinction matters: receipt of a minimum-value report and loss of sensor communication are separate observations. Preserve both the value and the message or sensor-error status where the diagnostic system exposes them.

## Interpret the range fault before testing hydraulics

Determine whether the controller received a saturated measurement or a separate communication failure. A single displayed low pressure after clearing may not identify the original input state. The source does not supply a connector voltage, pinout or a failed-part verdict.

Brake pressure diagnosis requires the exact professional service procedure and safe hydraulic handling. Verification should establish valid pressure feedback and successful completion of the appropriate range check, followed by the prescribed braking-system tests. Erasing the code or obtaining one plausible sensor reading cannot certify hydraulic integrity or safe braking.

# C0551: Longitudinal acceleration can fail by being frozen, offset or inconsistent

C0551 is described as a longitudinal-acceleration sensor circuit fault in the dictionary, but the GM 04B strategy groups several functional checks under it. These include a constant signal, abrupt steps, excessive offset and disagreement with estimated acceleration. The failure detail matters more than assuming every occurrence is an open circuit.

## Stationary and moving tests ask different questions

The stationary raw-offset check looks for acceleration above 8 m/s² while valid wheel-speed information indicates the vehicle is standing still. A moving gain check instead compares measured and estimated acceleration when all four wheel speeds exceed 3 m/s and forward motion is stable.

Another branch detects an abrupt raw-signal gradient, while learned-offset monitoring evaluates successive offset estimates. These checks use different timing and eligibility conditions. A signal can pass a stationary reading check yet remain wrong in its response to motion.

## Preserve the failed test identity

Retain the specific sensor test, acceleration signal validity, wheel-speed validity and vehicle-state information. Do not deliberately drive to force a fault; the brake/stability system requires controlled professional diagnosis. The source also contains malformed units and signs in the constant-signal row, so those ambiguous thresholds are not reproduced as test specifications.

The code does not independently distinguish mounting, sensor electronics or every possible input problem. Confirmation should address the original functional branch under the prescribed safe conditions. A changed display after recalibration is not equivalent to proving that gain, offset and signal-response checks all pass.

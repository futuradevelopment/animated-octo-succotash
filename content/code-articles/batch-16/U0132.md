# U0132: Missing or undersized suspension messages at the brake controller

U0132 is a loss-of-suspension-communication diagnosis recorded by the brake controller in this source. The monitored examples include trim-position offset and vehicle-level-control information. The receiver checks whether expected messages arrive and whether their length matches the defined format.

## Silence is not the only failure route

The source lists a message missing for 250 milliseconds or a message shorter than its database definition. A network can therefore carry traffic while still failing this particular reception requirement. Establishing that a bus is electrically active does not prove that the required suspension message is usable.

The diagnostic is suppressed during start mode and during specified five-second windows after power-mode transitions, resets or supply-voltage recovery. Confirmed bus-off and recovery states also prevent this message-specific fault from being set normally.

## Identify which message is missing

Preserve the reporting module, failed message identity and power/recovery context. A trim-offset message and a level-control information message are different dependencies even when they share U0132. The source lists potential issues at the signal source, sender, wiring or receiver; it does not establish one failed suspension module.

The table's maturation column includes an unexplained fractional count, so the published 250-millisecond message condition should not be converted into a guessed complete test sequence. Follow the application's network procedure. Verification should confirm the correct message and length after the exclusion windows end, plus the prescribed brake and suspension checks; clearing the code alone does not demonstrate those results.

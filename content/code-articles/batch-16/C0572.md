# C0572: Master-cylinder pressure feedback reaches its maximum value

C0572 marks a high-range value from the master-cylinder pressure sensor in this GM brake-controller strategy. The controller looks for the DS10 sensor at its maximum reported pressure value. The code is therefore a signal-range judgement, not an independent measurement confirming dangerous hydraulic pressure at a particular fitting.

## The exact monitored state

The table specifies a reported pressure of 30,000 kPa for 0.960 second with ignition on. Equality to the sensor's maximum value is the stated criterion. Do not reinterpret it as a universal maximum operating pressure or a test pressure that should be applied to the brake system.

The document has separate entries for SENT communication loss and pressure-sensor performance. A maximum-value report, missing messages and an offset error are different diagnostic states, even though they can all make the pressure information unsuitable for control.

## Preserve validity as well as the number

Capture the reported pressure, sensor status and communication result before drawing a mechanical conclusion. If the signal is saturated, a plotted value at the top of the scale does not describe how actual pressure changed beyond that reporting limit.

The source does not identify whether the sensor, circuit or another condition caused the maximum report. Use the matching brake-system procedure for electrical and hydraulic investigation. A successful verification includes valid feedback and completion of the appropriate monitor plus the required functional checks. A code erase or a normal-looking pressure at rest is not sufficient evidence of restored braking safety.

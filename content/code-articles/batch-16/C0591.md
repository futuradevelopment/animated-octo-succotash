# C0591: Negative booster-current limits are signed measurement checks

C0591 is the low-side current diagnosis for the brake-booster motor's measurement channels. The published limits are negative signed values. This is different from a simple absence-of-current test and must be interpreted using the controller's current convention.

## Two negative-limit paths

The offset checks flag a measured shunt offset below minus 38 A when the motor is not actuated, qualified for 0.2 second. The separate out-of-range checks use measured current below minus 200 A for 0.3 second. Both internal measurement channels have entries.

A negative diagnostic value should not be assumed to mean that a vehicle battery is charging or that the motor physically rotated backward. Those conclusions require the application's sign convention and operating context. The offset branch particularly concerns an implausible reading without motor actuation.

## Evidence to keep before changing components

Retain the failure subtype, signed current value and motor-command state. A low-current name alone cannot distinguish a sensing offset from an out-of-range operating measurement. Neither branch directly identifies an external wire, motor winding or driver transistor as the cause.

The numerical values are controller-monitor criteria, not permission to insert test equipment into a high-current brake circuit. Professional diagnosis must follow the exact service procedure. Verification needs the affected branch to complete under the correct state and the required braking function checks. Clearing C0591 or seeing a small current while the motor is idle does not establish that the original signed-limit fault is resolved.

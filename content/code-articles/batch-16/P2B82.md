# P2B82: Bank 2 wastegate position data with invalid SENT status

P2B82 concerns the bank 2 wastegate position sensor's SENT status information in this documented application. The performance label should not be narrowed automatically to a slow or sticking actuator: the primary failure criterion is that channel 1's status and communication nibble is invalid.

## The receiver checks more than position

The table specifies a 500-millisecond qualification. Its enable conditions include a received position-message value above 1 and below 4,088, together with the separate SENT sensor-error status being false. These are message-level conditions, not wastegate travel distances or voltage readings.

This creates an important diagnostic distinction. Data can occupy a plausible numerical range while its associated status is unacceptable. A scan tool that displays only converted position may therefore hide the information that actually caused the code. Equally, a separate sensor-error report can change which diagnostic path is active.

## Evidence for the second channel

Record bank 2's message validity and status alongside commanded and reported position where available. Bank 1 data can help establish context, but cannot prove that the second channel's message is valid. The source gives separate code identities for the two banks.

The next physical test must come from the exact sensor-interface procedure; this summary does not locate a terminal or distinguish a sensor defect from every possible communication disturbance. After correction, confirm an eligible stream with valid status rather than relying on a code erase or normal boost during a single drive. No turbocharger replacement is implied by the published criterion.

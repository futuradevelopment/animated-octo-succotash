# C0558: Right-rear wheel-speed sensor identification by message format

C0558 is the right-rear incorrect wheel-speed component diagnosis. The cited controller evaluates the sensor's message format. That makes it distinct from a missing speed signal, an air-gap fault or a simple disagreement between wheel speeds.

## Protocol criteria depend on the variant

The listed VDA variants fail when the received protocol-bit value is not nine. The DF11i branch fails when its expected stop pulse is absent. The table gives a three-second qualification, ignition-on operation and completed wheel-speed undervoltage checks as the relevant context.

These rules show why component identification cannot be decided merely by connector shape. They also show why an isolated protocol reading with unresolved supply faults is incomplete evidence. The controller's expected sensor type must be established before judging the observed message.

## Confirm the channel specification

Preserve right-rear sensor identification and enhanced diagnostic detail. A normal speed trace can coexist with an identification problem if other portions of the protocol are wrong. Conversely, the code alone does not prove that a replacement part is incorrect; the circuit and configured receiver need the application-specific checks.

Use the exact vehicle parts information and approved diagnostic method to resolve compatibility. This summary provides no pin assignments or waveform simulation instructions. Verification should include the applicable message-format test and the required braking-system checks. Do not regard a cleared fault or a few plausible wheel-speed samples as proof that anti-lock and stability-control functions have fully recovered.

# U0102: Transfer-case message timeout after CAN communication is enabled

U0102 is the lost-communication diagnosis for the transfer-case control module in the GM 04A engine-controller table. The monitored item is message $035. The failure occurs when that message is not received for more than 425 milliseconds, rather than when a generic four-wheel-drive complaint is reported.

## Enable time is separate from missing-message time

The general prerequisites must have been satisfied for at least 5,000 milliseconds. The diagnostic itself runs in a 12.5-millisecond loop. These are three different timing concepts: stabilization before eligibility, the message-absence threshold and the controller's task period. Combining them into one arbitrary timeout would misrepresent the monitor.

The relevant bus-off code must be inactive for the bus carrying the message: U0073 for bus A, U0074 for bus B or U0076 for bus S. Full communication must be requested and normal CAN transmission enabled. A sensor-bus arrangement also requires its relay on.

## Locate the missing dependency

Preserve the storing engine controller, actual network path and companion bus faults. A transfer-case message missing while the entire bus is unavailable is different context from one absent message on an otherwise communicating network. The table does not establish a failed transfer-case mechanism or module by itself.

Use the vehicle's network and power-mode procedure to check the expected message. Some supply and controller-type conditions have awkward table alignment, so no simplified universal voltage rule is asserted here. Verification should confirm receipt after eligibility is established and complete the prescribed transfer-case checks. Clearing U0102 alone cannot establish restored communication or drivetrain function.

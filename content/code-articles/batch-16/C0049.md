# C0049: The brake-fluid level switch reports its empty state

C0049 represents the brake-fluid reservoir empty indication in the cited electronic brake controller. The monitor reads the level sensor's logical state. It does not calculate the reservoir's exact fluid volume or measure how much pressure the brakes can produce.

## A sustained level indication

The failure criterion is the sensor value set to logical one, qualified for ten seconds with ignition on. The source lists continuous checking and a one-trip response. A logical value is an interpreted input state; this row gives no connector voltage or resistance specification for testing the switch directly.

That distinction matters if diagnostic data and the physical reservoir level disagree. The code establishes what the controller received, but does not independently decide whether fluid is actually low, the input is faulty or the wiring is responsible. The corresponding physical and electrical checks must resolve that question.

## Do not reduce the response to topping up

Preserve the level-input status and any accompanying braking warnings. Checking the reservoir according to the owner's and service instructions is different from assuming that adding fluid repairs the reason for a low-level indication. The table supplies no diagnosis of why fluid might be missing.

Brake-fluid and hydraulic concerns require the appropriate professional procedure, particularly when warning indications or reduced braking are present. Verification should confirm the correct level, the cause of any discrepancy and the controller's qualified level-sensor result. Erasing C0049 or temporarily changing the switch state is not evidence that hydraulic integrity or safe braking has been restored.

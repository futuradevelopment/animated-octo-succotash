# C0574: Pressure-sensor offset and internal SENT error share one code

C0574 is a performance code for the master-cylinder pressure sensor. The cited monitor gives it two distinct routes: excessive offset under a released-pedal condition, and an internal failure reported by the pressure sensor through SENT. A general performance label does not identify which one occurred.

## A released-pedal check with motion conditions

The offset branch flags an offset above 12 bar while the brake pedal is released, vehicle acceleration is positive and speed exceeds 4.47 mph. It also requires no active pressure buildup by the integrated brake system. These conditions establish a context in which residual reported pressure is unexpected.

The internal-error branch instead accepts the sensor's own failure report on SENT line 2, with a listed 0.1-second qualification. It does not depend on demonstrating the same physical offset. The source's channel numbering differs between some descriptions, so physical sensor identification must follow the application documentation.

## Distinguish offset from self-reported failure

Retain the enhanced failure detail and whether the controller was evaluating released-pedal plausibility or receiving a sensor error. A plausible pressure at rest does not necessarily clear an intermittent internal error, while a sensor error should not be treated as proof of actual residual hydraulic pressure.

These conditions are monitor evidence, not instructions to reproduce a brake fault on the road. Professional diagnosis must use the prescribed controlled procedure. Verification should address the original branch and complete the required braking checks; clearing the code alone neither establishes pressure accuracy nor certifies the vehicle safe to drive.

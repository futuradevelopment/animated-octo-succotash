# U042B: Transmission controller rejects chassis-control message integrity

U042B is the transmission controller's invalid-data diagnosis for ICCM chassis-control information in this source. The failure condition is a CAN message integrity fault. The row does not say that the chassis-control module stopped transmitting altogether.

## An observation window after stabilization

The documented decision requires at least forty failed observations out of eighty. Before evaluation, the stabilization delay must reach five seconds, and the partial network must have been active for at least five seconds. Ignition voltage must be at least 8.75 V and below 18 V.

The over-the-air programming state must be inactive. The check is also disabled when the listed U0073 bus-off-related indication is active. These restrictions separate a normal data-integrity assessment from network startup, programming or broader bus failure conditions.

## Do not turn samples into an invented timeout

The source gives an observation count but no universal sampling period for converting forty-of-eighty into seconds. A current communication snapshot therefore cannot reconstruct the original qualification by itself. Preserve the reporting transmission module, integrity status and network state.

The code does not prove an internal chassis-module defect or identify a suspension component to replace. Match the application network and controller diagnostic procedure before physical testing. Verification should show the receiver accepting the message after stabilization and outside programming or bus-off states. Erasing U042B or confirming that some CAN traffic exists does not establish that the relevant chassis information passed integrity validation.

# C0014: Right-front inlet control and internal driver checks

The documented C0014 fault belongs to the right-front inlet valve driver. Its monitor family includes electrical protection, coil-path checks, command-versus-feedback comparisons and internal driver self-tests. A single generic inlet-control description hides those different failure mechanisms.

## Commanded operation is only one test opportunity

The actuation branch can report PWM failure, incorrect on/off feedback or a current comparison deviating by more than twenty percent. It runs with adequate relay supply and no active valve test. This is different from the silent driver test, which operates outside normal valve control and with no hydraulic request.

The controller also checks whether measured coil resistance lies outside 4.8–13.7 ohms, using a cyclic twenty-second routine in the documented configuration. Internal logic and register checks have their own fault states. None of these observations alone is a complete hydraulic-flow diagnosis.

## Keep the right-front channel and failure detail together

Retrieve the specific driver-test result if available before replacing an assembly. An internal self-test report and an external coil interruption should not be treated as interchangeable evidence. The neighbouring outlet-valve code concerns another channel despite similar electronics.

These numerical criteria describe the controller's tests, not permission to energize brake valves or measure through connected electronics. Use the correct brake-system service routine, including safe pressure management. Verification needs the relevant branch to run again under its required conditions; absence of the code immediately after erasure is not proof that the valve and braking system are functioning correctly.

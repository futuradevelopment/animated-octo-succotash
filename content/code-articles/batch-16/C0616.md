# C0616: Parking-brake control faults can involve memory, supply or conversion

C0616 is a parking-brake controller performance code with several branches in this GM table. The source includes program-memory verification, motor-supply checks and analogue-to-digital conversion reference or calibration checks. Those internal results should not be treated as one universal open-wire diagnosis.

## Different branches need different evidence

The program-memory branch compares calculated flash checksums with stored values, including startup and background checks. Motor-supply branches instead flag voltage below 2 V when there is no actuation and no ADC-reference fault. The reference prerequisite matters because invalid conversion reference would make voltage readings unreliable.

Further branches compare calibration gain and offset records between the main and parking-brake microcontrollers, or report that valid calibration data was never received. A source-reported calibration mismatch is not equivalent to low motor supply, despite sharing C0616.

## Retrieve the internal failure detail

Preserve the specific parking-brake fault word, supply status and calibration/reference results. The document explicitly warns that an out-of-tolerance ADC reference undermines the accuracy of input-voltage readings. It would be inappropriate to condemn a motor supply solely from data that the controller has marked unreliable.

The summary does not prescribe opening the module, rewriting calibration or applying power to the parking-brake motor. Use the exact professional service process, including safe vehicle restraint. Verification should exercise the relevant internal check and complete the required parking-brake function assessment. Erasing the code cannot establish that the vehicle will hold securely or that the original controller fault is resolved.

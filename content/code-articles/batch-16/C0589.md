# C0589: Booster rotor-position feedback exceeds its permitted range

C0589 is the high-range rotor-position feedback code in this brake-booster strategy. The high value concerns the electrical or calculated signal representation, rather than excessive mechanical rotation of the motor.

## Several high-range branches

The cosine path flags a raw ADC value above 4,075 with a 0.150-second qualification. Sine monitoring includes either input above 2.252 V and a separate summed-ADC limit. Another branch checks calculated vector magnitude above 1.14. These checks use different quantities and do not share one external voltage threshold.

The vector calculation combines sine and cosine information. Consequently, a plausible angle alone cannot establish that the underlying amplitude is valid. A signal can encode an angle while still violating a range check that the controller relies on for trustworthy position control.

## Keep raw and converted data separate

Retrieve the specific high-range branch and relevant validity information before interpreting the code as a failed motor or mechanical stop problem. Do not convert raw ADC counts into volts without the exact channel scaling. The source provides no connector identification or safe bench-test setup.

The brake-booster assembly requires the application's professional diagnostic procedure; do not apply power to sensor lines or force motor movement to reproduce the fault. Verification should confirm the affected raw-signal or vector check and the prescribed braking-system function. A clear code list or a single normal angle reading is insufficient evidence that the position feedback is dependable.

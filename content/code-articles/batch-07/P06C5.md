# P06C5: cylinder 1 glow-plug resistance rationality

The common P06C5 label says “Cylinder 1 Glow Plug Incorrect.” In the reviewed GM table, the actual test is an electrical-resistance rationality check. It asks whether cylinder 1's glow plug continues to operate within the specified range, rather than directly identifying an incorrect part number.

## An operating calculation

The controller calculates resistance from measured voltage divided by measured current. The displayed calibration window is 0.23 to 2.00 for the glow-plug resistance parameter. The source does not explicitly print a unit alongside that expression, so these values should not become an assumed workshop specification.

This is a loaded operating calculation. A cold resistance reading taken with the component disconnected does not necessarily reproduce the conditions under which P06C5 was set. Likewise, “incorrect” alone does not prove that someone installed the wrong plug.

## The monitor first needs trustworthy inputs

The glow plug must be commanded on for a calibrated interval, and the system must have no individual electrical fault or glow-plug voltage-feedback fault. Battery voltage must be in range. The engine-running requirement excludes cranking, and diagnostics must be enabled.

GM specifies 15 failing samples within 25 samples at a 100-millisecond task rate, with Type B reporting over two trips. For verification, establish that the powered resistance check completed and that prerequisite circuit or feedback faults were absent. Repeating a start without meeting the commanded-on requirement may not exercise it. Vehicle-specific service information is still needed to identify the correct component and applicability; this monitor page does not supply those details.

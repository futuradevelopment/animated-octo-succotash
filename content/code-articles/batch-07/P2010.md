# P2010: swirl-motor high circuit uses hardware short-to-power information

P2010 is an intake-runner control circuit-high code in the reviewed GM swirl-motor strategy. The table describes a short to the power supply and uses hardware-reported H-bridge current above 8 amperes as its fault criterion. It is not the same monitor as a high position-sensor signal.

## Current alone does not identify the fault direction

The neighboring low-circuit code also uses an 8-ampere H-bridge threshold. The meaningful distinction is the hardware diagnostic's short-to-supply versus short-to-ground interpretation, together with the operating state. A current reading alone should not be used to interchange those diagnoses.

For P2010, the driver must be on and the hardware status must not be indeterminate. Calibration enablement, operation outside cranking and powertrain-relay supply above 11 volts are also required. These conditions limit which captured measurements can be compared with the published decision.

## Persistence and confirmation

The counter needs 240 failures within 300 samples at a 12.5-millisecond task rate. The reporting class is Type B over two trips. This describes how the electrical indication qualifies; it does not establish which wire, driver or component is responsible.

A meaningful retest examines the enabled, powered H-bridge diagnostic and confirms that the short-to-supply indication no longer qualifies. Successful commanded flap movement by itself does not answer the electrical question. The page provides no circuit isolation sequence or replacement instruction. Its thresholds apply only after confirming the vehicle uses this documented 2025 GM system.

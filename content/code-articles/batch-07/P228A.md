# P228A: rail pressure remains low after metering control reaches its limit

P228A is titled fuel-pressure regulator 1 forced engine shutdown in the reviewed GM table. The monitor combines a large pressure shortfall with exhausted metering-control authority. It is not a standalone electrical open-circuit check and does not identify one failed regulator from its title.

## Two conditions define the event

Desired rail pressure minus measured rail pressure must exceed 30 MPa. At the same time, commanded metering-unit fuel flow exceeds the high-pressure pump's referenced maximum-delivery criterion. The source describes this as the metering actuator reaching maximum authority while pressure remains inadequate.

The control mode matters: rail pressure must be governed by the fuel-metering unit. A pressure deficit observed while another regulating mode is active does not automatically reproduce P228A's documented logic. The maximum-flow value is referenced to the rail-pressure-control information and is not printed as a universal number here.

## Qualification and professional diagnosis

The engine must be running and powertrain-relay voltage at least 11 volts. Qualification uses 160 failures within 320 samples at 25 milliseconds each, with Type A, one-trip reporting.

Verification should review requested and measured pressure together with metering command and active control mode. The code does not distinguish a supply problem, delivery limitation or other hydraulic cause without further evidence. Because these are high-pressure fuel-system quantities and the code is associated with forced shutdown, component testing requires the applicable professional service procedure; this summary does not authorize opening pressurized connections. Exact vehicle and calibration applicability must be confirmed before applying the limits.

# P0797: GR10 solenoid C stuck-on criteria differ from adjacent clutches

P0797 is a hydraulic release-performance fault for pressure-control solenoid C in the reviewed GR10 strategy. The source associates it with the C3 clutch, identified as C23457910. It describes an electrically functional solenoid that still allows the clutch to retain hydraulic holding capacity when release is commanded.

## Do not borrow the C1 or C2 limits

The C3 row uses less than 50 rpm of clutch slip for all three printed shift categories, including garage shifts. Its garage-shift base failure time is 0.35 second. The power-downshift and general-shift base times are 0.60 and 0.15 second. These distinctions matter because neighboring clutch monitors in the same document use different garage-shift criteria.

Those times are only the base values. Shift-specific offsets and exhaust-delay tables are also involved; C3's closed-throttle downshift delay changes with fluid temperature. A single stopwatch threshold therefore does not reproduce the whole monitor.

## What evidence is useful

The continuation requires valid C3 slip calculation from functioning speed signals, enabled solenoid-driver circuitry and available hydraulic pressure. Service fast learn and solenoid cleaning must be inactive, and relevant companion faults can prevent the stuck-on test from running.

Verification should demonstrate that C3 develops appropriate slip after an eligible release command and its applicable delays. Electrical continuity alone cannot prove that hydraulic release has recovered. Conversely, this code alone cannot distinguish the individual hydraulic cause. The description is confined to the published 2025 GM GR10 monitor and must not be generalized to every P0797 application.

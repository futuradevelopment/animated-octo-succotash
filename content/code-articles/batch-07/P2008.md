# P2008: swirl-motor open-circuit detection occurs with the driver off

P2008 is the intake-runner control open-circuit fault in the reviewed GM swirl-motor system. Hardware diagnostic information indicates that the motor's load resistance exceeds the permitted boundary. This electrical test is distinct from checking whether the flaps physically follow a position command.

## Driver state is central

The source uses load resistance greater than 200 kilohms as the open-circuit criterion and requires the H-bridge driver to be off. It also requires the hardware error status to be determinate. A powered motor-current test is therefore not the same operating condition as the documented open-load check.

The system must be outside cranking and the powertrain-relay supply must exceed 11 volts. Calibration enablement is required. These conditions explain why a low-supply or startup observation cannot automatically be used to reproduce P2008's result.

## Interpreting persistence

Qualification uses 240 failures out of 300 samples at a 12.5-millisecond function interval. The row lists Type B reporting over two trips. The sample window allows the monitor to reject an isolated indication; it does not identify where an open path exists.

For verification, establish that the off-state diagnostic ran with adequate supply and a valid hardware status, then examine its result. Correct flap movement on a separate occasion would not alone prove that the off-state electrical check passed. The summary provides no connector pinout, component location or replacement instruction. Its threshold is limited to this 2025 GM monitor until the applicable vehicle and control hardware are confirmed.

# P2294: regulator 2 open circuit is diagnosed with the driver off

P2294 is the open-circuit diagnosis for the low-side driver of fuel-pressure regulator solenoid 2. In the reviewed GM table, the driver is powered off while the controller compares its measured voltage with hardware-specific acceptable limits. The code is electrical evidence, not a direct rail-pressure performance judgment.

## An off-state test with an impedance specification

The source relates the open-load voltage thresholds to a controller specification of more than 200 kilohms between the signal and controller ground. It does not publish a single external voltage threshold that works for every controller.

This distinction matters because an energized solenoid measurement does not reproduce the documented off-state check. The impedance description also identifies the circuit relationship being classified; it should not become an instruction to probe an unspecified pin or disconnect a high-pressure component.

## Qualification and verification

Powertrain-relay voltage must exceed 11 volts, cranking must be inactive and the calibration must enable the test. The diagnostic system must remain active and hardware fault feedback must be determinate. Qualification uses 61 failures in 122 samples at a 6.25-millisecond task rate, with Type A, one-trip reporting.

Verification should confirm that the valid off-state open-circuit check completes without recurrence. A satisfactory rail-pressure reading in another operating state does not prove the electrical path passed this test. The source supplies no failed-part verdict or physical location. Fuel-system access and circuit isolation require the vehicle's service procedure, and these monitor limits need exact engine and controller applicability confirmation.

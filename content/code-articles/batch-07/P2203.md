# P2203: engine-out NOx raw value exceeds the sensor range

P2203 is the high-range code for bank 1 NOx sensor 1 in the reviewed GM monitor. The direct criterion is a raw NOx concentration above 2,990 ppm. Despite the dictionary's circuit-high wording, this page does not define a voltage at an external signal pin.

## Range validity comes before emissions interpretation

The check requires the sensor's current-control and electrical fault states to be clear. Lost communication and invalid CAN data must also be absent. P2203 therefore assesses an excessive reported concentration only after those supporting checks permit it.

A raw value beyond the monitored range should not automatically be used to diagnose a failed SCR catalyst. The sensor here is identified as engine-out, and this row addresses the validity of its high reading rather than downstream conversion efficiency.

## An eligible high-range test

Relay voltage must exceed 11 volts, sensor supply exceed 9.90 volts and the NOx bus relay be commanded on. Dewpoint must be reached, the engine running, the combustion-mode enable flag satisfied and air-system control active. Failure qualification is 200 out of 240 samples on a 25-millisecond task, with Type B reporting across two trips.

Verification needs the raw signal and completed range test under those conditions. A lower value during an inhibited or uninitialized period does not establish recovery. The source provides no cause ranking, electrical pinout or replacement instruction. Exact vehicle and sensor applicability must be confirmed before using these calibration-specific limits.

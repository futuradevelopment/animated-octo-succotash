# P2055: second DEF valve control has a short-to-supply signature

The reviewed GM P2055 monitor concerns DEF metering valve 2, described in the dictionary as bank 1 unit 2. Its circuit-high label refers to a low-side control path shorted to battery. It does not mean that reductant pressure or commanded dosing quantity is too high.

## The hardware result is the evidence

The controller uses the second-valve power-short fault status. The related enable status must be different from indeterminate before the diagnostic is valid. An uninitialized or unavailable result therefore cannot be treated as an electrical pass.

No external voltage cutoff is printed on this page. The description supports the fault direction and channel assignment but does not provide enough information to identify a particular wire or condemn the metering valve. That distinction is especially useful when several reductant-system codes are present together.

## Qualification and follow-up

The test must be enabled by calibration, battery voltage must exceed 11 volts, and the system must be key-on or engine-running outside cranking. It needs 30 failing samples out of 60 on a 100-millisecond time basis. GM lists Type A, one-trip reporting.

Confirmation should focus on a completed valve 2 power-short check with a valid hardware result. A restored pressure reading elsewhere in the system does not independently prove that this control path has recovered. The source establishes no repair part, circuit location or broad model coverage. Use the exact vehicle's service information to identify the installed second dosing channel and its diagnostic procedure.

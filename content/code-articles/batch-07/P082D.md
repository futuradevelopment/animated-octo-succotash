# P082D: gear-lever Y sensor 1 has two performance failure paths

The P082D row in GM's 2025 parameter file concerns gear-lever Y-position sensor 1, identified as Beta 1. “Range/performance” includes more than a single minimum or maximum reading: the controller checks both the permitted movement path and a calibrated percentage-disagreement limit.

## Why a center-position reading is not enough

The Beta supporting map varies its threshold with position coordinates, using percentage values from 7 to 20. This means a disagreement acceptable in one part of the map may be excessive elsewhere. A stationary measurement at one lever location cannot demonstrate correct behavior throughout the monitored path.

The outside-path branch is separate from that disagreement branch. A sensor reading can leave the expected movement envelope without needing the same evidence as a pairwise discrepancy. Preserve which condition was observed rather than turning every P082D into a generic open-circuit assumption.

## How the table qualifies a fault

The monitor must be enabled by calibration and needs 10 failures in 12 samples. It is classified Type B over two trips. The summary prints no sample period; an exact failure time in seconds would require additional information.

Verification should follow Beta 1 during the relevant lever motion and confirm both plausible path behavior and permitted disagreement using the correct map. This is an interpretation of monitor evidence, not an instruction to replace the shifter or sensor. Vehicle-specific service information must establish the installed system, signal scaling and safe functional procedure before the published limits are applied.

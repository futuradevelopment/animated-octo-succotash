# P214E: pump overcurrent limits change in heating mode

P214E monitors excessive reductant pump driver current. The reviewed GM controller can use the pump as a heater to aid DEF defrosting, as well as rotate it to move fluid. That operating mode changes the permitted current and is essential to interpreting a recorded value.

## Three ways to qualify

In heating mode, the printed current threshold is above 15 amperes. Outside heating mode, it is above 7 amperes. A separate branch recognizes active pump hardware protection. A current normal for the heating mode could therefore exceed the pumping limit, so the number must be paired with the actual mode.

The software-current branch uses 400 samples at 0.01 second each, or four seconds. Hardware-protection detection can qualify from one sample instead. Treating all P214E events as a four-second sustained overcurrent would miss that independent fast path.

## Verification and scope

The vehicle must be in an active power mode and specified reductant-controller internal faults must be absent. Reporting is Type A, one trip, and recovery is listed only for the next driving cycle.

A useful verification records pump mode, current and protection status together, then confirms the eligible next-cycle outcome. Pump rotation alone does not test heating-mode behavior, and the absence of a sustained overcurrent does not disprove a hardware-protection event. The source gives no cause ranking or replacement instruction. Exact pump hardware, vehicle applicability and safe electrical testing must be established from service information before applying these 2025 GM criteria.

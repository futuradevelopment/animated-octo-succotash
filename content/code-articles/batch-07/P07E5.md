# P07E5: Drive selection and actual range remain out of agreement

P07E5 is an inability-to-engage-Drive diagnosis in the reviewed GM table. Its evidence is a disagreement between commanded Drive and the actual arbitrated transmission range. The code does not directly identify a slipping forward clutch or a specific pressure-control solenoid.

## The actual-range signal must be valid

The comparison requires actual transmission-range information with good status. If the value is valid but not Drive, the failure timer increases. The timer must reach the expected shift time before qualification. The source does not publish a universal numerical duration for that allowance.

This makes the actual-range status important alongside the displayed value. A missing or invalid input should not be treated as the same evidence as a trusted value that remains in another range. Nor does a momentary mismatch at the beginning of a normal transition necessarily satisfy the timer requirement.

## When to judge the outcome

The monitor excludes active code clearing and manufacturing mode. Run/Crank or accessory/wakeup operation is included, with internal activity extending until Park is reached and accessory/wakeup ends. GM lists Type B, two-trip reporting.

Verification should capture the Drive request, actual range and validity throughout an eligible transition. A completed comparison that reaches Drive answers the monitor's question more directly than simply observing engine response. Functional testing must follow the applicable service procedure because range selection can move the vehicle. The source establishes diagnostic logic only; it does not establish a failed part, a repair cost or exact model applicability.

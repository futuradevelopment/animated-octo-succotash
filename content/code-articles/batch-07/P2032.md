# P2032: EGT sensor 2 low-range diagnosis depends on sensor type

P2032 concerns exhaust-gas temperature sensor 2 in the reviewed GM table. The monitor covers both an analog sensor and a digital thermocouple implementation. Those branches examine different raw quantities: resistance for the analog version and reported temperature for the digital version.

## Do not combine the two measurement types

The digital branch uses a low threshold of −72.80°C. This is an electrical or probe-path plausibility boundary, not evidence that the exhaust physically reached that temperature. The analog row prints a resistance threshold below zero ohms, which is not suitable as an ordinary workshop resistance specification without further clarification. This article therefore does not prescribe that analog test.

The sensor type changes the diagnostic interpretation. GM describes the digital check as capable of recognizing issues in the wiring between the module and probes, while the analog path concerns the temperature sensor's electrical value.

## Qualification and confirmation

The test requires calibration enablement, no cranking, supply voltage in range, active Run/Crank, no diagnostic reset or communication-loss error, and completion of the initialization delay. It uses 19 failing samples within 25 at 100-millisecond updates and lists Type B, two-trip reporting.

A valid retest must allow initialization and confirm communication before evaluating the low-range result. A cold-start snapshot taken too early does not necessarily exercise the monitor. Exact sensor mapping and vehicle applicability require service information; the ambiguous analog threshold remains a source-review limitation, and the code alone establishes no replacement conclusion.

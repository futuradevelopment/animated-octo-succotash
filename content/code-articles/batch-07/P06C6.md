# P06C6: why cylinder 2 can fail the glow-plug rationality test

P06C6 does not, by itself, prove that the wrong cylinder 2 glow plug has been fitted. GM's reviewed implementation describes a resistance rationality monitor: measured voltage and current are used to calculate whether the operating plug remains within a calibrated range.

## What the controller must see

The table displays a resistance-parameter window from 0.23 to 2.00 and detects values outside it. Because the unit is not explicitly attached to that expression on the source page, it should not be republished as an unconditional ohmmeter specification. The calculation also depends on voltage and current measured during operation.

Before the test is allowed, cylinder 2 must be commanded on for the required calibrated time. The individual glow-plug electrical check and the voltage-feedback circuitry must be free of relevant faults. A voltage-feedback problem can therefore prevent a useful rationality result, even when a disconnected plug measurement appears normal.

## Confirmation requires an enabled run

Other conditions include suitable battery voltage, an enabled diagnostic system and the engine running outside cranking. Failure accumulation is 15 of 25 samples on a 100-millisecond task, with Type B, two-trip reporting.

Review powered operating data and monitor completion rather than interpreting one stored code as a component verdict. A brief crank or an on-command that ends too soon does not necessarily repeat this test. This discussion is limited to the 2025 GM parameter file; exact engine coverage, correct plug selection and the isolation procedure must come from the vehicle's service information.

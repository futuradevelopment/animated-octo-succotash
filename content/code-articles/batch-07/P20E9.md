# P20E9: reductant pressure exceeds its current target

P20E9 is a reductant high-pressure performance code. The reviewed GM monitor compares the pressure-control signal with the current pressure setpoint. The failure threshold is a positive difference greater than 63 kPa, not a single absolute pressure that applies to every operating condition.

## Compare pressure and target together

A pressure reading alone cannot reproduce this diagnosis because its acceptability depends on the commanded target. The test is enabled during buildup, closed-loop control or reductant-delivery-performance operation. Estimated DEF quantity must exceed three liters and engine auto-stop must be inactive.

The failure counter uses 400 samples at 0.01 second each, described as four seconds. This sustained difference is distinct from a momentary overshoot during a transition. Reporting is Type A over one trip.

## Inhibitors affect confirmation

The table notes that pressure-sensor, pump, supply, communication and Run/Crank faults can force the pump off and disable the monitor. Specified controller-internal faults are also excluded. A quiet pressure trace after the pump has been disabled therefore does not establish that active pressure regulation has recovered.

Verification should observe the pressure-minus-target difference in a permitted pump state with valid sensor information and sufficient fluid. Recovery is listed for the next driving cycle. The code does not establish a particular restriction, valve defect or repair part, and the summary does not provide a depressurization or disassembly procedure. Exact vehicle and calibration applicability require confirmation before using these 2025 GM limits.

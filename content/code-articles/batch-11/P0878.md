# P0878: Pressure sensor D high is an electrical limit, not a pressure verdict

P0878 is the high-circuit code for pressure sensor D. The cited GM TCM implementation assigns it to the limited-slip-differential pressure input. Its primary criterion is electrical, so the code cannot be read as proof that the differential’s actual pressure is excessive.

## The high input has a persistence requirement

The table lists voltage above 4.530 volts, 30 millivolts of hysteresis and at least 150 milliseconds of confirmation. Cranking and STOP state are excluded, and the main battery supply must be within the documented 8.75–18-volt eligible interval.

Its VREF1 enable window is printed inconsistently, requiring both above 5.5 and below 4.5 volts. The original PDF contains those bounds. Their intended correction must come from applicable service information, not an editorial guess.

## Preserve channel and reference-fault context

P0882/P0883 and P0642/P0643 disable the monitor. A non-returning P0878 while one of those faults remains active cannot establish that the D-channel input has passed.

Keep the actual pressure-sensor voltage and reference-rail status together. A main system-pressure measurement from another sensor is not verification of this limited-slip-differential channel. The summary provides no connector location or component replacement instruction. Resolve the reference-window ambiguity and follow the matching circuit procedure to determine whether the sensor, wiring or input electronics produced the high report.

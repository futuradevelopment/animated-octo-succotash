# P0358: Coil H circuit diagnosis has a source-label conflict to resolve

P0358 is cataloged as ignition coil H primary control circuit/open. The GM summary’s strategy sentence instead names coil F. That conflicting label is important because using it uncritically could direct diagnosis to the wrong ignition output.

## The source supports the electrical principle

The monitor detects low feedback while the primary low-side driver is off. It uses a 0.4-second assessment and two-trip reporting. Ignition synchronization and engine speed above 1,400 rpm are required.

The row also waits for more than nine ignition-counter increments, intended to ensure that every cylinder has fired at least once. This distinguishes the qualified running monitor from an arbitrary measurement of an inactive output.

## Confirm identity before localization

Keep the actual P0358 fault detail and the calibration’s output assignment together. The generic H label and the source’s F wording should remain visibly unresolved until the correct service information establishes the physical coil.

The unusually large upper supply boundary in the table is not a practical test instruction. Neither that number nor the open-load label identifies the exact failed connection or component. Once the output is correctly mapped, use the vehicle-specific circuit procedure to distinguish load, wiring and driver possibilities. The source supports an electrical continuity investigation; it does not establish weak spark, a failed plug or automatic coil replacement.

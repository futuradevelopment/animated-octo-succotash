# P072F: Fourth-gear stuck diagnosis follows the shift toward neutral

P072F is the stuck-in-fourth-gear code. In this GM implementation the controller observes attempts to disengage fourth and return the synchronizer toward neutral. The diagnosis concerns that transition, not a general inability to achieve the requested road speed.

## Sensor 3 and state timing supply the evidence

One failure path is an electrical or consistency fault from shift-fork position sensor 3 during the shift. Another is a missing actuation-state transition combined with the appropriate timeout. A position-sensor fault can thus contribute to the final stuck-gear label.

The controller requires fourth-gear disengagement to be requested and active, system pressure above 4.5 bar, and an application state outside error and bypass modes. At least four failed disengagement attempts confirm the fault.

## Interpret the failed transition

Retain the position feedback, neutral target and state history at the failure. Merely seeing fourth gear selected afterward does not tell which branch failed. A request to engage fourth would be a different monitor situation.

This row shares its general disengagement logic with neighboring codes but names the fourth-gear sequence and sensor-3 branch. The exact state timers are referenced elsewhere and are not invented here. Use the appropriate transmission service information to determine whether feedback, hydraulic actuation or mechanical movement explains the event. The code alone is not a replacement verdict for a synchronizer, sensor or complete transmission.

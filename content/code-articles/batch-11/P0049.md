# P0049: Turbo overspeed is evaluated from a processed speed signal

P0049 concerns a turbocharger speed value exceeding a maximum threshold. The GM example evaluates a gradient-limited speed signal, which is already processed by the controller. It is not described as a direct boost-pressure comparison.

## The particular value that triggers the monitor

The row gives a threshold above 250,000 rpm with a 50-millisecond assessment and two-trip reporting. Those numbers belong to this documented monitor. They are not a general safe operating limit or a recommendation to run a turbocharger near that speed.

GM labels the monitored channel as bank 2 here, while the catalog title uses turbocharger “A.” Letter names and bank labels should therefore be mapped through the applicable service information instead of treated as interchangeable labels on every engine.

## What a useful record includes

Identify the exact speed parameter and channel captured when the fault occurred. A boost-pressure graph alone cannot establish whether the processed speed value crossed the recorded boundary. Related speed-signal plausibility information can help distinguish a credible overspeed report from questionable measurement evidence, but this row alone does not resolve that distinction.

The enable column is awkwardly labelled around its positive-rpm condition; it should not be converted into an invented engine-speed test. Confirm the complete calibration conditions before reproducing the monitor. This source does not establish the failed turbo component, the cause of overspeed, or a safe-to-drive conclusion.

## Source and applicability

This explanation covers the cited GM monitor, not every vehicle carrying this code. The application-matrix filename does not resolve cleanly to this file, so no model or engine fitment is assigned.

# P060D: Pedal plausibility includes signal scaling and learned values

P060D concerns internal accelerator-pedal position performance. GM documents more than a simple subtraction of two displayed pedal voltages: the monitor applies a floor to the comparison and separately checks learned normalization values.

## The live-signal comparison is processed

For the part-pedal and full-pedal paths, the calculation uses the maximum of each measured voltage and an 848-millivolt threshold. The resulting absolute difference is compared with 360.6 millivolts. The two paths are separated by pedal-region conditions and use a 0.026-second interval.

The ADC’s null-load test impulse must not be active, basic enables must be satisfied, and an accelerator-pedal fault must not already be present. These qualifications prevent treating any unequal raw readings as an internal performance failure.

## Learned values provide another route

A further path compares minimum learned normalized values in two monitoring levels, separately for each pedal sensor. Thus the code can involve learned-state consistency rather than only a momentary live-voltage disagreement.

Preserve the full fault detail and relevant learned or internal parameters when the diagnostic equipment supports them. The source does not prove that the pedal assembly itself failed, nor does it provide a universal relearn or replacement procedure. Because the logic participates in accelerator supervision, use the correct vehicle service process instead of bypassing sensors or applying external signals to reproduce the threshold.

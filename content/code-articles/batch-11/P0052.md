# P0052: High heater-driver feedback requires a commanded-on comparison

P0052 is an oxygen-sensor heater control fault. Its useful distinction from the low-circuit counterpart is the command state: the GM row checks for high feedback while the heater driver is ON, describing a short-to-power condition at the low-side driver.

## The monitor needs a real heating command

The row gives a two-second detection interval and two-trip reporting. Heater diagnosis must be released, and the bank 2 sensor 1 heater duty-cycle condition must be satisfied. These requirements matter because an unloaded or inactive heater output is not the same operating case.

The controller also waits for its battery-voltage eligibility conditions. This makes the heater command, feedback and supply history more useful together than a single high-voltage observation without context.

## Resolve the source’s location conflict

The strategy sentence says bank 1 sensor 2, but the release and duty-cycle conditions name bank 2 sensor 1. The catalog identifies bank 2 sensor 1. That inconsistency is retained as a source-review issue rather than silently assigning a connector location from the contradictory text.

The defensible explanation is the electrical detection principle: high driver feedback during a qualifying ON command. Confirm the exact sensor and harness branch in vehicle-specific service information before taking measurements or choosing parts. This monitor description does not diagnose the oxygen sensing element itself, and the code alone cannot establish where the short-to-power condition originates.

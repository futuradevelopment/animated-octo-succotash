# P00A8: Separate an intake-temperature high value from a high circuit signal

P00A8 addresses the high side of the bank 2 manifold intake-temperature assessment. GM documents both a physical-range high check and an electrical high check. The shared fault code does not make the two measured quantities interchangeable.

## Two documented ways to reach the high boundary

One row evaluates a converted temperature above 122.76°C. Another evaluates the local temperature-sensor signal above 4,800 millivolts. Each specifies a two-second interval and two-trip reporting. The document calls this internal channel sensor 4; the generic catalog describes sensor 2 on bank 2.

A high displayed temperature therefore should not automatically be translated into “high voltage at a particular pin.” The installed sensor implementation and the applicable monitor row must establish that relationship.

## Verify the channel before the component

Preserve the parameter name, raw-signal availability and failure conditions from the scan record. Distinguishing an implausible converted temperature from an electrical limit crossing changes the appropriate service-information branch. Neither observation alone proves that the sensing element rather than its circuit is defective.

The monitor requires ignition on and respects other faults listed in the inhibit tables. A non-returning code is inconclusive if that assessment did not become eligible. Once the correct implementation is established, use its circuit and temperature plausibility procedures instead of importing thresholds from another engine or treating the two-second monitor interval as a repair test.

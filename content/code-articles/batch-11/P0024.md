# P0024: Bank 2 exhaust-cam target error is more specific than a stuck sensor

P0024 is commonly described as over-advanced timing or system performance on the bank 2 exhaust camshaft. The cited GM implementation calls its check a target error. Reading that actual strategy adds detail that the short code label cannot provide.

## A target remains unreached

The monitor requires failure to reach the requested angle for more than one second. Its accompanying movement condition is below three crankshaft degrees relative to the stored starting setpoint. This differs from merely noticing that the displayed cam angle does not equal zero.

The exhaust-cam governor must be working in closed loop. Oil temperature, engine speed, electrical supply and the general enable and inhibit conditions also control whether the assessment is meaningful. A request issued while cam regulation is inactive cannot be judged by the same logic.

## Follow the request and the response together

Review the requested position and actual movement during an eligible event. Limited movement despite a changing request is different evidence from a freely moving cam that eventually arrives late. Preserving that distinction helps select the relevant vehicle-specific performance test.

The table supports a two-trip classification but does not prove a particular oil, actuator or timing-drive failure. No component replacement follows automatically from this monitor description. The useful conclusion is narrower: under the stated control conditions, the bank 2 exhaust cam did not achieve its target with the expected movement behavior.

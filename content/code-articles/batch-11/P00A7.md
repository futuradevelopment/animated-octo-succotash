# P00A7: Bank 2 manifold-temperature low checks use two signal domains

P00A7 identifies a low fault on the bank 2 intake-manifold temperature channel. The GM document presents two versions of the check: one evaluates a converted temperature, while the other evaluates local sensor voltage. Keeping those domains separate prevents a misleading single-value diagnosis.

## Temperature range and electrical range

The physical-range row uses a temperature below −42.04°C for two seconds. The electrical row uses local voltage below 195 millivolts for two seconds. Both identify the channel as sensor 4 within this document, even though the catalog names intake-air temperature sensor 2 on bank 2.

These internal and external naming conventions should not be used to guess a connector location. The rows also should not be treated as proof that the converted temperature and voltage have a universal one-to-one polarity relationship across all vehicles.

## Match the evidence to the implemented check

Establish which parameter and monitor variant the applicable calibration actually uses. A displayed extreme temperature answers a different question from an electrical trace falling below the local voltage boundary. Each can guide investigation, but neither by itself identifies a failed sensor or wire.

Ignition-on operation and the referenced inhibit conditions are required. The source lists two-trip reporting, so clearing a code and observing one brief idle period is not equivalent to demonstrating that the eligible monitor has passed. Use the matching service procedure to evaluate the channel and its circuit.

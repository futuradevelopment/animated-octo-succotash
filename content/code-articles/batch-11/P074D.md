# P074D: Fifth-gear engagement is judged over repeated qualified attempts

P074D is the unable-to-engage-fifth-gear code. In the GM implementation, the controller does not judge the result from the requested gear alone. It follows an active engagement sequence and counts failed attempts under qualified conditions.

## Why the attempt can fail

One path involves synchronizer differential speed exceeding a gear-specific initial limit plus 250 rpm. Another uses the allowable differential speed for the current engagement state. A separate timing path detects failure to satisfy the next state transition before its calibrated timeout.

Fifth-gear engagement must be requested and active. System pressure must be above 4.5 bar, and the application must be outside error and bypass states. At least four failed attempts confirm the fault.

## Preserve the reason the state could not progress

A useful record includes fifth-gear request, differential speed and the point in the actuation sequence where progress stopped. If only the final “unable to engage” label is retained, the speed-related and timeout-related branches become indistinguishable.

This monitor shares its general method with neighboring engagement codes, while selecting fifth gear’s sequence and calibration limits. The table does not identify the failed part or justify transmission replacement. Exact state thresholds come from referenced calibration material, so no fixed universal engagement-speed specification is supplied here. Use the proper transmission diagnostic procedure to investigate the recorded failure path safely.

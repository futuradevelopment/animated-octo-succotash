# P0642: Reference A low is a qualified supply-rail measurement

P0642 is the low-reference-voltage A code. In this GM transmission controller, the monitored rail is VREF1. The fault concerns that sensor supply, rather than identifying one particular sensor connected to it.

## Reference voltage and battery voltage are separate

The failure boundary is VREF1 below 4.5 volts with 50 millivolts of hysteresis and a confirmation time of at least 40 milliseconds. The controller’s battery supply must separately be above 8.75 and below 18 volts.

Cranking and the STOP key state are excluded. P0882 and P0883 disable this diagnostic. Those exclusions explain why a low main supply and a low regulated reference should not be treated as interchangeable observations.

## Preserve the rail identity

A useful record includes VREF1 status, battery voltage and whether the monitor was enabled. A measurement from another reference rail cannot independently confirm that the A/VREF1 path has recovered.

The source says the check runs continuously when eligible and uses a type-A classification. It does not identify which connected sensor, wiring branch or internal supply element caused the low voltage. The vehicle’s distribution diagram and approved circuit procedure are needed to determine that. Avoid replacing the first sensor with a related symptom solely because it shares the supply; the code provides rail-level evidence that must be localized. A non-returning P0642 while a disabling battery fault remains active is not a completed verification.

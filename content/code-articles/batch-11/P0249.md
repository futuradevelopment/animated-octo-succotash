# P0249: Wastegate output 1 low is reported by the H-bridge

P0249 is a low fault in the turbocharger wastegate control circuit. The cited GM implementation is precise about the evidence: the H-bridge chip reports a short-to-ground error on output 1 for bank 2.

## A driver-reported electrical state

The table requires battery voltage above 10.9 volts and specifies that open-load diagnosis is not active. The electrical status must meet a 1,500-millisecond detection period, with one-trip reporting. This avoids treating every driver diagnostic mode as the same test.

“Output 1” is the driver channel named by the document. It should not be translated into a guessed connector terminal or into a statement about the mechanical direction of wastegate travel. Those mappings need the vehicle’s wiring and actuator information.

## Distinguish fault status from performance

A stored boost-performance complaint and an H-bridge short-to-ground report are different evidence. The former concerns the air system’s result; P0249 here concerns a specific electrical output state. Retain the driver fault status, supply condition and active diagnostic mode when assessing the event.

The report does not prove whether the grounding path is inside the actuator, within the harness or associated with the driver. A suitable circuit procedure must localize it. Do not replace the turbocharger or force the actuator to move solely because this code is present; neither action resolves the documented electrical question without further evidence.

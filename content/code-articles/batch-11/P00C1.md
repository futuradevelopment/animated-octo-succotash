# P00C1: The bypass-driver low check runs with the output off

P00C1 is the low-circuit fault for the bank 2 turbocharger bypass-valve control in this GM table. The controller describes it as a short-to-ground check. Its central detail is the state of the power stage when the feedback is evaluated.

## Low voltage has to be read with the command

The row specifies the power stage OFF and output voltage at or below 2 volts. It uses a one-second detection interval and two-trip reporting. Without the off-state information, a low output reading does not reproduce the monitor’s actual comparison.

The surrounding table includes separate electrical conditions for an energized output and for an open load. Thus the word “low” should not be interpreted as a general statement that turbo boost, air flow or valve movement is low.

## Preserve electrical context

When assessing stored evidence, identify the bank 2 bypass command, the relevant feedback value and any conditions preventing the diagnostic from running. The source points to inhibit tables, so another active fault can affect interpretation of a non-returning P00C1.

The summary row does not locate the grounding fault within a connector, harness, actuator or controller. It also does not provide a universal terminal test: neighboring open-load logic partly overlaps this voltage boundary. Use the applicable service procedure to distinguish those cases and localize the circuit. Replacing the valve solely from a boost complaint would skip the electrical question this code actually addresses.

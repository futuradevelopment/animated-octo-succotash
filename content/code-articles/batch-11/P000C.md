# P000C: What slow intake-cam response means on bank 2

P000C concerns the bank 2 intake camshaft taking too long to follow its requested position. The GM example makes an important distinction: a camshaft can move substantially and still respond too slowly. Seeing a changing position value therefore does not dismiss this fault.

## Movement is not the same as response speed

The table combines failure to reach the target within more than one second with movement exceeding three crankshaft degrees from the stored starting setpoint. This is a timed response assessment, rather than a simple declaration that the position sensor is dead. The event logic also spans multiple observations; one isolated screenshot cannot reproduce that history.

Cam control must be operating in closed loop. Oil-temperature, engine-speed, supply and other enable conditions also apply. A cold, inactive or inhibited controller is not performing the same test as the documented running monitor.

## Evidence worth comparing

A useful diagnostic record aligns requested angle, measured angle and controller operating state over time. The relevant question is whether the cam follows the requested change within the eligible interval. Comparing unrelated moments can hide a delay or create an apparent discrepancy.

These facts do not identify a failed phaser, oil-control valve or timing component. Mechanical and electrical investigations need the vehicle-specific procedure after the observed response has been confirmed. The table specifies two-trip reporting, which must not be confused with the duration of one response check.

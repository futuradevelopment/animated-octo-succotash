# P0228: A high bank 2 throttle-position input is not a position mismatch

P0228 is a high throttle-position circuit fault. GM’s specific strategy labels the monitored input as throttle-position sensor 1 on bank 2. That implementation detail should be confirmed against the vehicle, because a generic sensor-letter label alone does not locate the input.

## The fault is a raw-voltage check

The controller evaluates a value above 4.805 volts over 0.14 second and classifies the fault as one-trip. This is different from comparing two position readings or deciding whether the throttle moved to its request. A plausible-looking percentage can conceal the raw electrical condition relevant to this code.

The ECU must be in DRIVE or POSTDRIVE state. Its safety fuel-cut logic, bank 2 supply sufficiency or engine-speed condition, limp-home state and other enable tables also participate. These conditions should not be reduced to “key on means the test ran.”

## Keep location and command context

Identify the bank 2 sensor 1 parameter and preserve its raw voltage if supported by the diagnostic equipment. Compare the failure event with controller operating state before interpreting an isolated measurement taken under different conditions.

The source does not identify a connector pin, specify a harness repair or establish an internal throttle-body failure. The proper service circuit test is needed to distinguish those possibilities. Because this is an electronic throttle system, the monitor threshold is diagnostic evidence rather than an instruction to manipulate or energize the actuator externally.

# P065A: Generator performance compares alternator and battery information

P065A is a generator-system performance code. The GM row identifies the monitored quantity as an alternator–battery voltage difference. That is more specific than simply concluding that the battery is discharged or the alternator has failed.

## A comparison needs both sides

The source lists ignition-on operation, engine-running context, battery-voltage conditions and a voltage setpoint for the LIN-controlled generator. It specifies 1,000 events with two-trip reporting. The event count is not a 1,000-second timer or a prescribed drive cycle.

However, the published row leaves the actual voltage-difference threshold and several enable values blank. Those omissions prevent a defensible numerical pass/fail test from being reconstructed from this table alone.

## Preserve commanded and measured information

A useful diagnostic record keeps the alternator-related voltage, battery measurement and generator setpoint together where the vehicle exposes them. One battery-terminal reading cannot independently show whether the controller’s specific comparison failed.

The source does not identify which measurement or control path created the discrepancy. Nor does it support a fixed universal charging-voltage target for this calibration. Obtain the matching service procedure to resolve the missing limits and determine the correct test. This article retains the useful comparison principle and event-based qualification while explicitly leaving the unpublished numerical specification unresolved; it does not recommend battery or alternator replacement merely from the code.

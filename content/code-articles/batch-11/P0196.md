# P0196: Oil-temperature plausibility depends on the cold-soak reference

P0196 is an engine-oil temperature performance code. GM’s example cross-checks the oil reading against an average of other temperature sensors at cold start, rather than diagnosing an open wire directly.

## Why the previous shutdown matters

The table requires more than 28,800 seconds of engine-off time, equivalent to eight hours. It also requires a valid sensor signal and a completed reference-temperature calculation. A comparison taken immediately after a hot shutdown does not reproduce this documented cold-soak situation.

One row evaluates the reference average exceeding the oil-sensor temperature by more than 14.96°C. The paired row reverses the subtraction but prints a less-than comparator with the same positive value. The original PDF confirms this inconsistency, so it is not silently converted into a symmetric pass/fail window.

## Diagnose disagreement, not a guessed component

Retain the oil temperature, the available reference temperatures and the shutdown duration. If the comparison group itself is questionable, replacing the oil sensor from the code alone does not resolve which input created the disagreement.

The row gives one-second assessment and two-trip reporting, with supply and basic enable conditions. These conditions separate a completed plausibility evaluation from an arbitrary scan-tool comparison. Use the exact vehicle calibration to resolve the disputed comparator before applying numerical limits. The supported finding is a cold-start temperature consistency problem; the source does not establish the failed part or its location.

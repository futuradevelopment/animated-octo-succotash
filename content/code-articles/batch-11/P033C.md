# P033C: Knock-sensor D low must be separated from an ambiguous sensor number

P033C is the low-circuit code for knock sensor D. In the cited GM row, the same fault is described as a sensor 3 short-to-ground check. The electrical detection principle is clear, but that naming inconsistency prevents assigning a physical sensor from this table alone.

## The low signal is filtered and event-based

The documented boundary is filtered output below 0.2 volt with engine speed above 500 rpm. The controller uses three events and two-trip reporting. It schedules the check every 15–120 seconds as a function of speed, rather than evaluating a universal three-second timer.

This is circuit evidence. It does not state that combustion knock is absent, present or safe, and a raw vibration pulse is not necessarily the filtered diagnostic value used by the controller.

## Resolve identity before probing

Confirm which installed sensor the calibration associates with P033C. The source’s sensor 3 label is also used for another lettered channel, so changing it to sensor 4 without evidence would create a false wiring instruction.

Once the channel is established, preserve the low-output result and monitor-completion context for the proper circuit procedure. The code cannot distinguish a grounded harness path from a component or controller-side issue by itself. This article therefore explains the verified threshold and event logic while leaving physical location and repair decisions to the matching service information.

## Source and applicability

This explanation covers the cited GM monitor, not every vehicle carrying this code. The application-matrix filename does not resolve cleanly to this file, so no model or engine fitment is assigned.

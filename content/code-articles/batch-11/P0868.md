# P0868: Low transmission pressure is measured against the current target

P0868 reports transmission fluid pressure too low. GM’s specific strategy compares measured system pressure with its current target, rather than using one fixed pressure number for every operating state.

## A target shortfall must be qualified

The failure boundary is a calibrated difference between target and measured pressure, referenced in summary attachments. The row lists a 2-bar hysteresis and a 1,500-millisecond confirmation period. The hysteresis is not the complete failure threshold.

The pressure sensor and pilot-valve electrical diagnostics must be clear. Hydraulic power must be available from the main pump or requested from the auxiliary pump. Adaptive overrides, forced-low operation, recovery states and auxiliary-pump priming affect eligibility.

## Compare the request with the delivered pressure

Retain pressure target, measured pressure and the active hydraulic operating mode together. A relatively low value during a deliberately different control state cannot be judged as though the same target and monitor conditions applied.

The summary does not establish whether the cause is hydraulic leakage, pump delivery, valve behavior or a misleading input. It also does not identify fluid level or prescribe a repair from the code alone. The correct transmission procedure must confirm the pressure evidence and localize the shortfall. Use monitor eligibility and completion information when verifying an intervention; a cleared code during a disabled priming or recovery state is not a successful pressure-control test.

# P072E: Third-gear disengagement uses a different fork-feedback branch

P072E diagnoses a transmission remaining in third gear when disengagement should occur. The useful detail in the cited GM row is its association with shift-fork position sensor 1 during the neutral-shift sequence.

## A sensor fault can participate in the stuck result

The monitor includes an electrical or consistency fault on that position feedback while the synchronizer is commanded toward neutral. It also includes a failure to meet the next actuation-state transition before the calibrated timer expires.

The third-gear disengagement request must be active, system pressure must exceed 4.5 bar, and error or bypass application states are excluded. Confirmation requires at least four failed attempts. These are controller eligibility and persistence conditions, not a driver instruction to repeat the maneuver.

## Keep the correct feedback channel attached to the code

A healthy position channel for another fork does not verify the sensor-1 branch described here. Preserve the third-gear command, the corresponding feedback and the state in which progress stopped.

The code therefore supports more than a generic conclusion that “the gearbox is stuck.” It directs attention to a particular disengagement sequence and its feedback. The summary does not establish whether the cause is electrical, hydraulic or mechanical and does not publish all referenced timeout values. The installed transmission’s diagnostic procedure is required before selecting a repair or attempting further actuation.

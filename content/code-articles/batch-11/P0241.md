# P0241: Low boost-sensor voltage is distinct from low boost pressure

P0241 identifies a low condition in the bank 2 boost-pressure sensor circuit. The clearest supported path in the GM summary evaluates raw voltage from the pressure sensor upstream of the throttle valve.

## The electrical path has its own timing

A voltage below 0.15 volt for 1.5 seconds is the documented electrical condition. It runs with ignition on and the applicable basic enable conditions, using two-trip reporting. That says nothing by itself about whether the turbocharger produced enough boost under load.

A second row uses converted pressure and a shorter 400-millisecond interval with one-trip reporting. However, its “physical range low” description is paired with a greater-than pressure comparator. The original PDF confirms that wording; it is not rewritten into an assumed lower limit here.

## Establish which path set the code

Retain raw sensor voltage and the manufacturer’s monitor details, where available, rather than using only a generic boost-pressure display. Electrical and physical-range paths can share a code while supplying different evidence and reporting behavior.

The confirmed low-voltage condition still does not locate the failure within the sensor, wiring or controller input. Vehicle-specific circuitry and procedures are needed for that decision. Resolve the pressure-row ambiguity before using it as a test specification. Replacing a turbocharger because the title contains “boost” would overlook the sensor-input question this monitor actually addresses.

# P0160: Rear oxygen-sensor inactivity can involve loading and resistance checks

P0160 identifies no activity from bank 2 oxygen sensor 2. The GM example gives two diagnostic paths that are more specific than observing a flat scan-tool line: an open-circuit loading comparison and an internal-resistance plausibility check.

## What the controller actively compares

The first path compares loaded and unloaded sensor voltage over three load pulses. It also requires a prior interval of fault suspicion and operating readiness. A steady unperturbed voltage does not reproduce that active electrical comparison.

The second path evaluates sensor internal resistance above 40,000 ohms with exhaust temperature at the sensor above 600°C. The row describes this as plausibility for an interrupted ground wire. That description is a monitored hypothesis, not proof that a particular ground connection has already been located.

## Match testing to readiness

A cold rear sensor and a ready sensor undergoing the documented test are different operating cases. Preserve the readiness state, temperature information and which diagnostic path was active before interpreting the lack-of-activity label.

The source’s voltage thresholds for the loading path are not needed to invent an external pulse test; the controller performs that assessment under its own conditions. Vehicle-specific service instructions are required before applying electrical tests or identifying a ground branch. The code and summary cannot independently distinguish the sensing element, wiring and controller path, but they show which evidence would be meaningful.

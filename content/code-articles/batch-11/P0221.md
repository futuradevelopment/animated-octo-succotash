# P0221: Throttle sensor 2 rationality also uses the air-charge model

P0221 is a throttle-position rationality code. In the GM implementation, bank 1 sensor 2 is compared with the other position channel and with a throttle-angle estimate derived from the main air-charge measurement. That gives the monitor more than one way to question the reported position.

## Redundant position and independent plausibility

The sensor-to-sensor comparison uses a calibration-dependent difference of about 5–6.25 percent. A further branch compares sensor 2’s relative throttle angle with the angle inferred from the intake-pressure-based charge measurement, with a listed 9.0234-percent boundary.

The controller must be in DRIVE or POSTDRIVE state, and the table includes safety fuel-cut, supply, limp-home and charge-sensor conditions. This is therefore not a simple universal rule that any two unequal throttle percentages prove a bad throttle body.

## Preserve the third reference

Record both position channels and the relevant air-charge or pressure information. Agreement between two position channels does not independently prove that their result is consistent with the air path. Conversely, a questionable charge reference can change how the rationality result should be interpreted.

One branch prints an absolute difference with a negative boundary, which is not adopted as a usable service threshold here. Confirm the complete logic in vehicle-specific information before reproducing the monitor. The code identifies a consistency problem; it does not by itself select a sensor, throttle assembly or controller for replacement.

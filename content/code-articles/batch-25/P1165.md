# P1165: Maxima swirl-vacuum switch stays in the wrong state

P1165 in the 2001 Nissan Maxima manual concerns the vacuum-check switch used to verify swirl-control operation. The switch reports OFF when vacuum is supplied. Nissan detects a problem when that OFF state persists under engine conditions that should produce a different result.

## OFF does not mean an inactive system

This inverted interpretation is easy to miss. In the documented warm-up range, OFF can be the expected idle reading because vacuum is present. At the higher specified coolant temperature, the expected idle indication changes to ON. Diagnose the reading against the thermal and operating conditions rather than treating OFF as universally faulty.

The switch is used for onboard diagnosis, not direct engine control. Its result reports what happened in the vacuum path; it does not itself command the swirl mechanism.

## Hoses come before component replacement

Nissan begins with clogged or incorrectly connected hoses, then checks the switch ground and signal circuit. It next tests the switch's response to controlled vacuum and the control solenoid's commanded vacuum behavior. This separates a trapped or misrouted vacuum signal from an electrical switch failure.

The solenoid check also considers operating delay, so an eventual response may not be equivalent to the specified response. The full procedure supplies the correct test equipment and limits.

Record coolant temperature, switch state, hose findings and commanded response together. Replacing a switch solely because the scanner says OFF ignores the documented state logic and can miss the underlying vacuum-control problem.

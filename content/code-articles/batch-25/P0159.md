# P0159: interpreting a slow rear oxygen sensor on Titan bank 2

P0159 identifies slow response from bank 2's rear heated oxygen sensor in the 2004 Nissan Titan procedure. This is the sensor after the catalyst. It is not the front air/fuel-ratio sensor, and its normal response should not be judged by expecting it to mimic that upstream sensor.

## Catalyst storage affects the waveform

Nissan explains that oxygen stored in the catalyst makes rear-sensor switching slower than front-sensor switching. The fault means the rear signal takes longer than the permitted time to move between rich and lean during the monitored operating conditions. Merely seeing a relatively steady rear trace does not establish this fault.

The listed diagnostic possibilities include the sensor circuit and sensor, but also fuel pressure, injectors and intake-air leakage. This matters because exhaust composition and the electrical measurement both affect what the controller observes. Replacing the sensor solely because its name appears in the scan result skips those alternatives.

## An incomplete test is not a pass

The CONSULT-II procedure warms the engine and sensor, then runs the bank-specific work-support test. Nissan distinguishes an actual pass or fail from a result stating that diagnosis could not be completed. For that incomplete result, the document calls for a cooling soak and another attempt.

Record which bank was selected, whether the prerequisites were met, and the actual test outcome. An ordinary function check is useful supporting evidence, but Nissan notes that it may not confirm a first-trip DTC. These distinctions keep an uncompleted monitor from being mistaken for a successful repair.

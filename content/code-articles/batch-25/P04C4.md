# P04C4: fuel-door lock feedback changed without an unlock command

P04C4 is a lock-position plausibility result in the cited GM hybrid summary. The previous state was locked, the current state is not locked, and the controller has not commanded an unlock. The unexpected change is the important evidence.

## Preserve the sequence of states

A snapshot showing “not locked” is insufficient to explain this monitor. The controller's decision depends on the earlier locked state and absence of an unlock command. Recording only the final display would omit two parts of the diagnostic condition.

This differs from P04C0, where an actual unlock command fails to produce the expected transition. Here, the problem is a reported release without that command. The two results should not be treated as interchangeable actuator failures.

## Circuit validity is a prerequisite

The table excludes related driver and lock-position electrical faults. It also uses a repeated-sample decision: sixteen failures out of twenty samples taken at 50-millisecond intervals. The monitor is therefore looking for a sustained inconsistency rather than one isolated state update.

The summary does not distinguish an actual unintended mechanical release from erroneous position feedback. That distinction requires the vehicle-specific inspection and a comparison between physical state, command history and reported state.

After any repair, verify the relevant sequence under valid diagnostic conditions. Merely demonstrating that the fuel door can open and close once does not establish that the lock-position signal remains coherent while no unlock is requested.

## Application limits

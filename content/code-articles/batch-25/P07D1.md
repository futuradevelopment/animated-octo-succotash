# P07D1: comfort-mode switch input stays true beyond the monitor interval

P07D1 identifies transmission mode switch E in the cited GM MYB table, where the input is named the comfort-mode switch. The failure condition is that the switch state remains true through the documented ten-minute evaluation interval.

## Preserve the input identity

The adjacent tour- and normal-mode rows use different code numbers. P07D1 belongs specifically to the comfort request in this implementation. That mapping is more useful for diagnosis than a generic statement that the transmission has a mode-switch fault.

The table does not identify the physical button, connector or vehicle model. A technician must match the controller implementation before applying this mapping to a car.

## A long observation differs from a quick button check

The monitor requires the engine to operate within an allowed speed window and ignition supply within limits. It also requires that the engine-speed condition has already persisted before evaluating the switch. Briefly operating a control in a stationary key-on check may show a response without demonstrating that this long-duration monitor passes.

GM lists no MIL illumination for this special diagnostic. A stored result can therefore require enhanced transmission scanning even when the emissions warning lamp is off.

A useful record contains the comfort-switch data trace, when the input was released and how long the asserted state persisted. These observations can guide the service procedure, but the source does not establish a component replacement or prove that the selected driving mode itself is incorrect.

## Application limits

2015 GM 15OBDG06 TCM MYB unique section. Switch E is the comfort-mode input here; model, switch layout and wiring require separate confirmation.

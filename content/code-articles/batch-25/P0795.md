# P0795: Quest solenoid C links converter lockup and shift pressure

P0795 in the 2004 Nissan Quest RE5F22A manual concerns pressure-control solenoid C. This normally-low linear solenoid participates in torque-converter clutch control as well as the application and release of specified brake elements inside the transmission.

## Lack of lockup can be intentional

Nissan notes that converter lockup is prohibited when transmission fluid is too cold. A cold vehicle that does not lock the converter therefore does not, by that observation alone, establish a failed solenoid C.

The P0795 monitor instead recognizes abnormal voltage and an irregular comparison between target and monitored values. The diagnostic scan checks both output and monitor current. Those readings must be evaluated under the stated selector and warmed-transmission conditions, because the reference changes with the operating state.

## Trace the current path in sections

The procedure distinguishes the TCM-side circuit, terminal-cord assembly, external harness and solenoid-side connection. This gives a technician a way to localize a failed measurement before choosing an internal repair. A control command shown on the scanner does not prove current reached the valve.

The component inspection has its own temperature-qualified resistance specification. If it fails, the document supplies the applicable control-valve-assembly repair direction; a code alone is not that failed inspection.

After repair, complete the dedicated confirmation routine and retain the original output-versus-feedback evidence. These conclusions apply to the RE5F22A section and should not be transferred to another Quest transmission without checking its manual.

## Documented application

2004 Nissan Quest factory AT manual, RE5F22A transmission section, January 2005 revision. Hydraulic functions and current references are variant-specific.

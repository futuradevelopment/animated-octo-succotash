# P1760: Altima overrun-clutch solenoid circuit response is abnormal

P1760 in the 2001 Nissan Altima automatic-transmission manual identifies an improper voltage drop while the TCM attempts to operate the overrun-clutch solenoid. This is a circuit observation; it does not establish that the clutch friction elements have failed mechanically.

## The command depends on several inputs

Nissan describes overrun control as responding to the park/neutral switch, overdrive switch, vehicle speed and throttle position. The solenoid is therefore not expected to have one fixed state under every operating condition. Compare electrical behavior with the requested operation rather than treating a momentary inactive state as failure.

The stated reference distinguishes operating and non-operating voltage states. Those values belong to the documented circuit and should not be used to power an unknown solenoid directly.

## Isolate the failure before selecting a repair

The diagnostic sequence checks the solenoid-related resistance through the terminal-cord assembly, then examines the supply/control path to the TCM. A failed measurement can involve the cord wiring or the valve, so the code does not select one of them automatically.

If the fault remains after the confirmation routine, Nissan directs further TCM input/output and terminal-connection inspection. That is a later diagnostic branch, not an immediate controller-replacement instruction.

Verification requires operation in the specified driving state on a suitable level road. A stationary cleared-code check cannot demonstrate that the operating command was exercised. Keep the circuit findings and the confirmation outcome together when documenting the repair.

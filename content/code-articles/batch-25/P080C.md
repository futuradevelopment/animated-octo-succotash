# P080C: skip-shift low or open feedback is checked while off

P080C concerns the skip-shift solenoid control circuit in the cited 2010 GM manual-transmission table. Its strategy checks for an open or shorted-low circuit while the device is commanded off. That command-state detail is essential to interpreting the result.

## The wrong command state can hide the distinction

P080D, the neighboring high-circuit branch, is evaluated with the device commanded on. A measurement obtained in one state should not automatically be compared with the other branch's expectation. Retain the command alongside the circuit reading.

For P080C, GM describes disagreement between the driver's requested state and actual control-circuit state. The summary does not specify a connector, test-point voltage or a uniquely failed component, so the electrical category must be followed by the matching service diagnosis.

## Enable conditions explain a non-returning code

The row requires qualified run/crank voltage and a running engine above its minimum speed. It also applies a repeated-sample criterion. Clearing the result and checking with the engine stopped does not demonstrate that the off-state operating monitor has evaluated successfully.

The manual-transmission restriction is explicit. Do not apply this skip-shift description to an unrelated automatic-transmission selector issue merely because a generic scanner supplies similar wording.

Document the command state, supply condition and demonstrated circuit defect. A skip-shift bypass accessory or improvised jumper would change the monitored circuit and obscure the original evidence rather than establish a proper repair.

## Application limits

Document-level 2010 GM diagnostic table; per-code vehicle/engine/calibration applicability not established.

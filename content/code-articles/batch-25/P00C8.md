# P00C8: fuel-regulator supply integrity is tested outside device control

P00C8 identifies the fuel-pressure regulator solenoid supply-voltage control circuit/open branch in the cited 2010 GM diagnostic table. Its purpose is to check electrical integrity during operation, rather than to establish that rail pressure is mechanically too low.

## Separate the supply branch from neighboring faults

The same page assigns a short-to-ground branch to P00C9 and a short-to-power branch to P00CA. Retaining the exact code therefore matters: the three results should not be collapsed into an unspecified fuel-pressure failure.

The P00C8 criteria sentence is terse and does not provide a terminal voltage that independently proves an open wire. The safe conclusion from this summary is the monitored supply-circuit category. A wiring diagnosis still needs the applicable vehicle diagram and driver test.

## A commanded service test changes monitor availability

The row requires adequate powertrain-relay voltage and engine rotation, and excludes pump device-control operation. It also qualifies code-clear and device-control transitions. An active service-tool command is therefore not automatically equivalent to the conditions under which this diagnostic evaluates normal operation.

The detection uses a failed-sample count rather than one instantaneous reading. A technician should record supply condition, control mode and whether the monitor was actually enabled before interpreting a non-returning code.

This table does not identify a failed pump, regulator or ECM. Fuel-pressure hardware should not be opened on the strength of this electrical classification alone; confirm the circuit evidence using the vehicle-specific procedure.

## Application limits

Document-level 2010 GM diagnostic table; per-code vehicle/engine/calibration applicability not established.

# P1706: Altima park-neutral input fails to change during use

P1706 on the 2001 Nissan Altima concerns a park/neutral-position input that fails to change as expected during starting and driving. The controller needs to distinguish neutral or park from a driving position; the diagnosis is about that state information, not proof of an internal gearbox failure.

## Compare the indicated state with selector position

Nissan's scan reference is ON in neutral and, for automatic models, park. Other positions should report OFF. A signal that stays fixed across those positions is therefore more useful evidence than simply knowing the code is stored.

The manual distinguishes manual and automatic applications. On the automatic circuit, the diagnostic path includes the connection from the switch to the TCM and from the TCM to the ECM. A correct switch signal at one point does not establish that the engine controller receives it correctly.

## A stationary check has a limited conclusion

The overall function check can verify signal switching, but Nissan notes that it may not confirm the first-trip DTC. The separate confirmation procedure requires a warmed engine and specified driving conditions. These checks answer related but different questions.

For an automatic vehicle, document the switch supply, signal state, inter-module wiring findings and final confirmation result. For a manual vehicle, use its separate circuit branch. Do not transfer automatic connector information to the manual version. Testing must preserve normal starting and gear-selection safeguards; a fixed substitute park signal would conceal the fault instead of diagnosing it.

# P0532: A/C pressure-sensor low voltage is an electrical result

P0532 in the cited GM 4.8L/L20 diagnostic table concerns low voltage on the air-conditioning refrigerant-pressure sensor circuit. The controller compares sensor voltage with a five-volt reference and detects a value below the documented low fraction.

## Low signal and low refrigerant are different findings

The monitor does not directly weigh the refrigerant charge. Its result establishes that the electrical pressure representation is outside the accepted range. Adding refrigerant solely because the code says “pressure” would skip the circuit diagnosis and could create a separate problem.

The opposite electrical branch is P0533. Keeping the exact polarity in the repair record is useful when a connection fault changes the signal from one extreme to the other. The summary does not identify which wire, connector or sensor element caused the low result.

## Configuration and persistence qualify the result

The row has a diagnostic-enable condition and an A/C pressure-sensor presence/configuration condition. It samples repeatedly at a 25-millisecond interval and specifies a failure count. A single value taken immediately after clearing memory does not represent the whole evaluation.

The sensor-presence wording refers to information learned from the body controller. Confirm the applicable vehicle configuration rather than assuming every vehicle using this engine has the same sensing arrangement.

Use the correct circuit test to distinguish the sensor from its supply and signal path. Refrigerant recovery, charging or line opening requires the appropriate service equipment and should follow a demonstrated refrigerant-system finding, not this electrical code alone.

## Application limits

2015 GM 15OBDG07 ECM diagnostic table, 4.8L/L20 section. Exact vehicle and A/C configuration are not established by this document alone.

# P04C3: fuel-door lock position has an invalid electrical reading

P04C3 in the cited GM hybrid table concerns the fuel-fill door lock-position sensor/switch circuit. Its strategy identifies incorrect circuit resistance through an invalid reported-position reading. This channel describes the lock, not the separate position of the fuel door itself.

## Invalid feedback undermines movement diagnosis

The lock and unlock performance rows use position changes to judge success. P04C3 appears among their inhibiting faults because invalid position feedback prevents a clean assessment of movement. A performance code that does not return while P04C3 is active is therefore not evidence that the lock works correctly.

The table requires repeated invalid samples with the diagnostic enabled. That persistence requirement distinguishes a recorded fault from one brief display update during operation.

## The interval is not a usable test specification here

The printed threshold uses an inequality arrangement that differs from the corresponding door-position and request-switch invalid bands. Its intended lock-position interval remains unresolved. This article does not silently reverse the sign or offer a guessed numerical pass/fail range.

The supported next diagnostic question is whether the lock-position circuit supplies a valid, stable state under the matching vehicle procedure. That requires the correct signal identification and current service specification, rather than a borrowed threshold from another channel.

Record the exact code, reported lock state and any associated low/high faults. The document establishes a feedback-validity concern but does not prove that the actuator or complete door mechanism needs replacement.

## Application limits

Document-level 2015 GM diagnostic table; per-code vehicle/engine/calibration applicability not established.

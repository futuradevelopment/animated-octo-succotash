# U0134: brake controller did not receive a usable rear-steer status message

U0134 in the cited 2020 GM electronic-brake-controller table concerns the active-rear-steer status message. The receiver detects either a message absent for 250 milliseconds or a message shorter than the defined format.

## Missing communication is not always total silence

The undersized-message branch is important. A module may be communicating on the network while this particular status frame remains unusable. Seeing some traffic or successfully identifying a module with a scanner does not prove that the required rear-steer status message arrived correctly.

GM lists the signal source, transmitting module, bus wiring and receiving module as investigation categories. The code alone does not isolate the rear-steer controller as defective.

## Power transitions qualify the check

The monitor is suppressed during an initial period after power-mode transitions, at low supply voltage, during cranking and while a bus-off failure is detected or latched. A communication result observed during those conditions needs context before it is compared with the normal enabled monitor.

The row is emissions-neutral and does not illuminate the MIL. That classification does not certify steering or brake functionality; it only describes emissions-lamp behavior.

A useful diagnostic record identifies the EBCM as receiver, the rear-steer status frame, supply and power-mode conditions, and any broader network faults. Steering-related physical tests and module configuration should follow the matching vehicle procedure. No model or active-rear-steer installation is inferred from this multi-application document alone.

## Application limits

Document-level 2020 GM diagnostic table; per-code vehicle/engine/calibration applicability not established.

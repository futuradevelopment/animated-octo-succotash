# P1447: Altima purge monitoring depends on throttle-state information

P1447 in the 2001 Nissan Altima manual is a purge-flow monitoring result. During non-closed-throttle operation, the purge valve should expose the EVAP pressure sensor to intake vacuum. The controller evaluates whether the resulting pressure drop is adequate.

## A throttle-switch fault changes the starting point

When P0510 accompanies P1447, Nissan directs diagnosis of P0510 first. The closed-throttle information helps establish when purge behavior should be evaluated. A faulty state signal can therefore undermine an otherwise reasonable-looking purge test.

The listed possibilities include a purge valve stuck closed, blocked ports or tubing, disconnected hoses, a cracked canister and a pressure-sensor problem. A missing pressure response can arise because vacuum never reached the sensor or because the sensor did not report it correctly.

## Test movement and response separately

The component procedure uses an active purge command and observes engine response, then checks the valve's air passage if required. The pressure sensor has a separate controlled-pressure inspection. These tests separate the actuator from the measurement used by the monitor.

Nissan's work-support confirmation must progress from testing to completed under the stated temperature and driving conditions. Waiting indefinitely in a test screen is not a successful result.

Record the throttle-switch status, commanded valve behavior, pressure response and completed monitor outcome. Use calibrated EVAP test equipment and the full manual's limits; an improvised compressed-air test can damage components and does not reproduce the documented diagnosis.

# P1126: the 2001 Maxima thermostat warm-up diagnosis

P1126 in the 2001 Nissan Maxima factory manual is a thermostat-function diagnosis. The engine has operated long enough for coolant temperature to rise, but the expected temperature has not been reached. A thermostat stuck open or leaking at its seal is one documented explanation.

## Identify the vehicle before using the number

This article applies to the 2001 Maxima procedure. Manufacturer-specific P1 codes cannot safely be interpreted from the number alone. The exact model, year and controller must therefore accompany the scan result.

Within this warm-up diagnosis, Nissan also lists the coolant-temperature sensor. That alternative matters: the controller sees the sensor's report, so an inaccurate report can resemble inadequate physical warm-up. A useful diagnosis separates the observed temperature progression from the electrical sensor inspection.

## Follow the sequence, not a universal time limit

The published confirmation procedure uses a cool-enough starting condition and sustained driving; its starting temperatures and operating conditions belong to this vehicle-specific test. They are not universal thermostat-opening specifications.

Nissan's procedure includes thermostat replacement within its prescribed workflow and then directs a returning fault to coolant-temperature-sensor resistance inspection. A repair discussion should make that sequence explicit instead of presenting P1126 as conclusive evidence that any one part has failed.

Document the initial coolant reading, warm-up behavior, cooling-system findings and post-repair result. Work on a hot, pressurized cooling system requires the precautions in the full service manual; the diagnostic code itself does not authorize opening the system while hot.

## Documented application

2001 Nissan Maxima factory EC manual, thermostat-function procedure. This meaning is limited to the documented model-year application.

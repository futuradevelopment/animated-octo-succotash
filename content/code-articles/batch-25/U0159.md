# U0159: parking-assist braking-request message is late

U0159 in the cited 2020 GM brake-system-control table concerns a missing automatic-parking-assist braking-request message. The receiver expects the designated request frame from the parking-assist controller and detects its absence beyond 250 milliseconds when communication prerequisites are satisfied.

## Identify the function of the missing message

The monitored frame carries an autonomous braking request associated with parking assistance. This is more specific than a general complaint that parking sensors do not beep. The row does not diagnose an individual ultrasonic sensor or establish that every parking-assist function has failed.

A module can remain identifiable on a scanner while a required application message is missing. Successful access to the sender is therefore useful evidence, but not proof that this particular request arrived on time.

## The code does not select the failed module

The summary names the transmitting function and receiving controller context; it does not provide a complete wiring or module-isolation tree. Appropriate diagnosis should retain related network codes and verify the relevant communication conditions before assigning a component failure.

The result is classified as emissions-neutral with no MIL. That describes the engine-warning-lamp response, not the availability of automatic parking or braking assistance. Driver warnings and the vehicle-specific procedure remain relevant.

For verification, establish that the required frame is received under the applicable enabled conditions. Clearing U0159 or demonstrating one normal parking-sensor reading does not show that the braking-request communication has recovered.

## Application limits

Document-level 2020 GM diagnostic table; per-code vehicle/engine/calibration applicability not established.

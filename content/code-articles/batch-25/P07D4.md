# P07D4: normal-mode request remains active in the MYB monitor

P07D4 is the transmission mode-switch F diagnosis in the cited GM MYB-specific summary. This row names the normal-mode switch and detects a true input persisting for 600 seconds under the monitor's operating conditions.

## The word normal does not make the result harmless

“Normal” is the name of the mode input. The fault concerns how that input behaves over time, not whether normal driving mode is a valid selection. A legitimate mode selection and a signal that remains asserted unexpectedly must be distinguished using the vehicle's control design.

The source does not establish that a particular dashboard button is stuck. It supplies the controller-level mapping, which must be matched to the actual vehicle before electrical tests or parts decisions.

## Monitor completion needs sustained operation

The row qualifies ignition voltage and engine speed, including a preliminary time within the permitted speed range. An immediate post-clear scan cannot reproduce the full long-duration check. Preserve how long the system was observed and whether those conditions remained satisfied.

GM categorizes this result without MIL illumination. The absence of an engine warning lamp is therefore not a useful pass criterion for the mode input.

For a repair discussion, identify the normal-switch data state and compare it with the driver's action under the proper service procedure. The shared timing with other mode inputs does not turn P07D4 into a diagnosis of those other switches; retain its specific channel.

## Application limits

2015 GM 15OBDG06 TCM MYB unique section. The document maps switch F to normal mode; no specific vehicle or physical switch location is inferred.

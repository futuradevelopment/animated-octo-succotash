# P0110: Maxima has electrical and temperature-comparison branches

P0110 in the 2001 Nissan Maxima manual has two diagnostic paths. One detects excessively high or low intake-air-temperature sensor voltage. The other checks whether that voltage is reasonable compared with the coolant-temperature signal.

## A normal-looking value may still be wrong

The sensor is a thermistor in the air-duct housing. Its resistance falls as intake temperature rises. An obvious extreme electrical reading can support the first branch, while a reading inside the display's normal range can still fail the comparison branch.

This distinction explains the factory test order. Nissan first attempts the short ignition-on electrical confirmation. If that does not reproduce the first-trip code, it calls for the temperature-qualified driving procedure. Passing the first check therefore does not establish that the second monitor has passed.

## Follow the circuit before replacing the sensor

The diagnostic sequence examines the supply and ground paths, including the relevant harness connections, before checking sensor resistance against temperature. If those checks pass, the procedure directs attention to intermittent faults.

A useful diagnostic record includes intake and coolant readings together, the starting thermal condition and which confirmation branch actually ran. Comparing an intake reading after a hot soak with an unrelated reference from a cold vehicle can obscure the issue.

The document's sensor location, resistance data and driving conditions belong to this Maxima application. They should not be transferred to a vehicle where the temperature element is integrated into a different assembly.

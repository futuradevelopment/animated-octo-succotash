# P1402: Altima EGR flow is detected when no flow is requested

P1402 in the 2001 Nissan Altima manual means EGR flow has been detected during conditions that do not call for it. The diagnosis uses the EGR-temperature sensor as evidence of that unwanted flow.

## A warm engine can miss the diagnostic window

Nissan explains that the evaluation ends as coolant reaches its specified warm-up range. The confirmation procedure therefore starts with a sufficiently cool engine and checks both coolant and EGR-temperature information before running work support.

This makes test preparation important. Attempting the routine repeatedly on an already warm engine does not establish that an intermittent EGR problem has disappeared. The manual specifically calls for natural cooling when the starting readings are outside range; artificial cooling can distort the result.

## Unwanted flow has several possible explanations

The documented possibilities include the EGR control solenoid, a leaking or stuck-open EGR valve, the EGR-temperature sensor and the back-pressure transducer. The diagnostic sequence begins with vacuum-hose condition and routing, then distinguishes the control components and temperature sensing.

A high temperature indication alone does not uniquely select the EGR valve. The technician needs evidence that the command, vacuum control and temperature report agree with the suspected failure.

Nissan also distinguishes enhanced work support from its generic-scan-tool confirmation route. Record which method was used and whether the monitor actually completed. These conditions belong to this historical Altima system and should not be generalized to electrically operated EGR systems on unrelated models.

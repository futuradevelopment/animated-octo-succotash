# P080D: skip-shift high feedback is evaluated during the on command

P080D is the high-circuit diagnosis for the skip-shift solenoid in the cited 2010 GM table. The controller tests this branch while the device is commanded on, comparing the expected driver state with the actual circuit state.

## Keep the on-state test separate

The paired P080C strategy checks low or open behavior with the device commanded off. The two codes therefore describe different electrical circumstances. Combining them into a generic “skip-shift not working” complaint loses information that can determine the correct test branch.

A command shown as on is not proof that the solenoid received the expected electrical condition. The monitor exists to detect that discrepancy. Conversely, the code does not demonstrate a mechanical gearbox defect or prescribe a particular solenoid replacement.

## Verify under the monitor's conditions

The row requires a qualified run/crank supply and engine speed above 600 rpm, then evaluates a failed-sample window. A normal-looking value after clearing memory is incomplete evidence if the device has not been commanded into the state used by this check.

The table specifically limits this application to manual transmission. Physical wiring and driver polarity still need confirmation from the vehicle-specific service information.

A technician should preserve the on-command event, the observed circuit response and any companion low/open result. Repair verification needs an actual successful evaluation under those conditions. Removing the skip-shift function or substituting a bypass is not evidence that the original circuit fault has been located.

## Application limits

Document-level 2010 GM diagnostic table; per-code vehicle/engine/calibration applicability not established.

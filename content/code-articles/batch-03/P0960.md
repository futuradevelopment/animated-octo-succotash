# P0960: solenoid A open circuit requires transmission-specific mapping

P0960 is pressure-control solenoid A control circuit open. The cited TCM table covers several architectures: different clutch-control assignments in eight-, nine- and ten-speed transmissions, plus the CVT secondary-pulley solenoid. The letter A alone does not identify a universal physical part.

## What the controller detects

A measured circuit voltage outside controller-specific limits indicates an open condition, with a design specification above 200 kilohms between signal and controller ground. This is an electrical test, not a measurement that pressure is below the requested value.

Failure must exceed 0.3 second within a sample period exceeding half a second. Battery voltage must remain above 9 and below 32 volts for more than one second. The relevant mapped high-side driver must also be on; an unmapped/no-driver configuration disables the test.

## Why mapping changes verification

Identify the exact transmission and solenoid assignment before connecting this code to a clutch or pulley complaint. The table's architecture list does not prove that any particular vehicle uses all those options.

A valid verification requires the correct solenoid supply path active and the open-circuit monitor passing under its power-mode conditions. Observing a successful shift or normal idle pressure is not a substitute for this electrical result. Use the applicable circuit procedure to distinguish the possible causes; the source does not identify a failed winding, connector or controller from the code alone, nor authorize a powered resistance test.

# P058E: the battery sensor reports an excessively high internal temperature

P058E is the battery-monitor high-temperature diagnostic. The cited BCM implementation evaluates raw ASIC temperature reported by the intelligent battery sensor, with a threshold above 120 degrees Celsius. The ECM example calls the monitored value raw temperature 2.

## Identify which temperature is involved

This is an internal sensor-temperature report, not a direct coolant-temperature or battery-capacity measurement. The code alone does not prove that the complete battery is physically at the reported temperature. The distinction matters when deciding which independent observations are needed before interpreting the reading.

The BCM continuous test requires four failing seconds within five seconds. The ECM table uses four failed samples out of five. Do not convert one controller's sampling description into another controller's fixed timeout.

## A stored event can surface after wakeup

The BCM source describes up to twenty-four sleep-time temperature samples, taken every thirty minutes while LIN is off, followed by a historical check on wakeup. Live temperature may have changed by the time the code is read. Compare the historical result with current raw temperature and the wakeup sequence rather than assuming they represent the same moment.

The test also depends on valid communication, adequate supply voltage and an ambient-temperature range. Verification requires a passing relevant test under those conditions. Avoid touching or disturbing a potentially hot battery assembly merely to corroborate a PID; use the vehicle-specific professional diagnostic procedure.

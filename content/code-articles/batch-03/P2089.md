# P2089: cam-actuator high input must be read with driver architecture

P2089 is bank-one intake camshaft actuator control circuit high. The two cited sources use different output-driver architectures, which changes the command state that makes a high voltage diagnostically meaningful.

## High-side and low-side examples differ

The 03A strategy describes a high-side driver and a high/short-to-power condition while it is off. However, its enable column says the output is commanded on. That internal contradiction leaves the exact state requirement unresolved for that example.

The 07A Part 2 page explicitly describes a low-side driver with high voltage during its on state. That is a different architecture, not proof that the 03A off-state description can simply be overwritten. The 07A file-to-model mapping is unresolved; no Corvette, engine or model applicability is inferred from it.

## What remains useful

Both examples support an electrical short-to-power interpretation of the actuator-control circuit. Neither establishes an overadvanced camshaft angle or proves a mechanical phaser failure. The 03A decision uses twenty failed samples in twenty-five; the 07A example lists a one-second check with different prerequisites.

Identify the actual controller architecture and consult its exact procedure before judging circuit voltage against command state. Verification must show the appropriate high-circuit test passes. The source conflict is retained for review, and this summary provides no powered probing instructions, physical bank location or blanket actuator-replacement remedy.

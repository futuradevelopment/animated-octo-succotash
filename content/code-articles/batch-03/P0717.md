# P0717: input speed stays low when operating conditions imply activity

P0717 is the transmission input-speed no-activity diagnostic in the cited TCM. It evaluates a low raw input-speed signal against operating conditions in which powertrain torque should be available at the drive wheels.

## Low means low in context

The ordinary displayed threshold is below 200 rpm, with a separate 300-rpm entry for the specified shared input/output sensor-supply condition. Failure must persist more than four seconds. A stopped transmission reading near zero is therefore not enough to reproduce the diagnostic.

The monitor relies on gear, output speed, accelerator and torque conditions. It also excludes relevant output-speed faults, service fast-learn activity and other input-speed test failures. Those supporting signals must be credible before the input-speed rationality conclusion is useful.

## Distinguish sustained loss from repeated drops

The source describes possible open-circuit, sensor-internal and controller-internal failure modes, without assigning likelihood. It also notes a race with P0716 after a sudden drop. Repeated recoveries favor a different event pattern from a signal that remains low; which code appears first depends on the actual sequence.

Record the raw input and output speed history, attained gear and companion-code status. Verification should demonstrate valid input-speed activity through the appropriate enabled conditions, not merely a nonzero reading at one moment. The table does not provide a universal sensor replacement, transmission teardown instruction or proof that an internal mechanical clutch has failed.

## Source and applicability

Documented monitors in gm-2025-03a, model year 2025. These are module/calibration examples; vehicle, engine and transmission applicability must be confirmed independently. [GM 2025-03a, page 1100](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=1100).

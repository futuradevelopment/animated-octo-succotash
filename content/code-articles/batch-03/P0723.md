# P0723: output-speed intermittency is counted as repeated drop events

P0723 detects repeated unrealistic decreases in raw transmission output speed. The cited TCM does not simply flag every brief low value; it requires a qualifying drop, inadequate recovery for the event timing and enough repeated failure events.

## Drop thresholds depend on configuration

The displayed logic includes a 600-rpm drop threshold in specified branches, while another branch derives the threshold from wheel-speed use and output speed. Four-wheel-drive low state also affects the selection. It would be incorrect to apply 600 rpm universally without confirming those configuration conditions.

The event logic lists more than 1.5 seconds of failure before advancing an event count, with the count exceeding five for the shown decision. Stable four-wheel-drive low state for more than three seconds is among the prerequisites, and related electrical faults can inhibit the test.

## Recovery is diagnostically important

The source explains that a signal which drops and stays low stops creating additional drop events. In that case the no-activity code can set before P0723. Repeated recovery and loss therefore materially change interpretation even if both cases show a low speed at the instant of scanning.

Capture a time history with output speed, relevant wheel-speed information and driveline state. Verification should reproduce the applicable enabled conditions without recurring drop events. The source establishes signal behavior, not a particular failed sensor or a mechanical slip diagnosis; use the exact transmission procedure before assigning a repair.

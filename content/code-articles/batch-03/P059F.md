# P059F: grille-shutter performance uses a retry strategy

P059F means the active grille shutter has not achieved the requested position in the documented GM strategy. The monitor also considers an indeterminate position response or shutters reported as not initialized. It is broader than an assumption that a vane is simply stuck closed or open.

## Initial disagreement is only the first stage

The controller first recognizes a suspect position condition after a command latency delay. One criterion is a commanded-versus-reported position difference greater than five percentage points. A second stage then makes repeated attempts to reach the requested position, and the code sets when the calibrated unsuccessful-retry threshold is reached.

The two cited tables give different diagnostic-delay counts, 129 and 109. Neither value should be presented as a universal number of seconds or a physical obstruction size. The source description also says retries continue until the requested position is reached or the trip ends.

## Useful diagnostic observations

Record commanded position, returned position and initialization status together. An indeterminate response is diagnostically different from a valid position that consistently misses the command. Also distinguish a first delayed movement from repeated failures after the retry sequence.

These are performance observations, not proof that the actuator itself needs replacement. The tables describe enabled operation with relevant power and wake states, including some key-off conditions. Treat unexpected commanded movement as possible and use the applicable service procedure before inspecting the mechanism. Successful verification should include the achieved command and completed diagnostic, not appearance alone.

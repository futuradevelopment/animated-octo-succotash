# P0970: solenoid C circuit low is not a measured low-pressure verdict

P0970 is the low control-circuit fault for pressure-control solenoid C. The documented electrical signature corresponds to less than 0.5 ohm between signal and controller ground, evaluated through controller-specific voltage thresholds.

## Why the C assignment matters

The source's CVT example maps C to line-pressure control, whereas its geared-transmission examples map C to particular clutch circuits. A generic line-pressure description would therefore be incomplete for the whole row. Confirm the installed transmission and its actuator map before interpreting the physical effect.

Even in the CVT example, this code does not measure line pressure. It indicates an electrical fault signature, which must be distinguished from the separate commanded-versus-measured pressure performance diagnostic.

## Qualify the result

The monitor requires more than 0.3 second of failure in a sample period exceeding 0.5 second. The appropriate high-side supply must be on, and battery voltage must be between 9 and 32 volts for more than one second under an allowed power mode.

Record the supply state and circuit status along with any pressure complaint. A disabled supply can prevent evaluation, so no recurrence immediately after clearing is not equivalent to a verified pass. Use the exact circuit procedure to resolve the cause and demonstrate a passing monitor. The table does not provide a safe powered resistance test or uniquely identify the solenoid, wiring or controller as the failed component.

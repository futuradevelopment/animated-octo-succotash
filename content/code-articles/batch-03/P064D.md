# P064D: bank-one oxygen-sensor processing can fail internally

P064D identifies bank-one oxygen-sensor processor performance in the cited wide-range air/fuel sensor implementation. The engine controller monitors two failure counters received from the sensor-interface ASIC: controller status and measurement validity.

## Two counters, either sufficient

The source sets the diagnostic when either counter reaches 128 failed samples out of 160, sampled every twenty-five milliseconds. The two counters should not be added together to invent a combined failure threshold. A measurement-validity problem and an internal controller-status problem are separate paths to the same code.

Evaluation requires engine-run or auto-stop state, completed heater warmup and more than twenty seconds since powerup for the circuit diagnostic. A cold sensor immediately after switching on does not reproduce the full enabled context.

## Distinguish processing from mixture

The source says these faults can affect closed-loop fuel control. It does not define P064D as a lean or rich exhaust reading, nor does it prove the sensing element itself is defective. An unusual mixture-related PID may be a consequence of invalid processing rather than independent confirmation of a combustion problem.

Record ASIC status or measurement-validity detail when the tool exposes it, together with heater and elapsed-time conditions. Verification should establish a passing enabled processing monitor, not merely an apparently normal oxygen-sensor value. This article uses the clear 03A wide-range-sensor example; no vehicle applicability is inferred from the separate unresolved 07A file mapping.

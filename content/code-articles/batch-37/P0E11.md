# P0E11: High generator supply voltage and temporary hybrid shutdown

P0E11 describes generator inverter power supply A circuit high. Mazda's M Hybrid PCM uses it to report that the integrated starter generator has stored P0E11 for an increase in its supply voltage.

## The originating record is essential

The PCM page does not define a universal overvoltage limit. It directs the technician to retrieve ISG DTCs and diagnose the fault in the originating module. This matters because a high supply report can only be interpreted correctly with the generator's own detection conditions and vehicle-specific electrical architecture.

The factory procedure also distinguishes an active ISG fault from a PCM record left after a past event. Capture both modules' results before clearing anything. If the ISG has no corresponding DTC, the historical-record branch is different from a present high-voltage fault that returns immediately.

## Temporary protective action is not a repair

For this code, the PCM page describes temporary stops of conventional generation, i-stop, regenerative braking, motor assistance and non-generation control. The wording matters: a function becoming available again after conditions change does not establish that the underlying event has been explained.

Mazda's confirmation uses its key-on, engine-off self-test and a pending-code check. Persistent recurrence also requires communication assessment before a final controller conclusion. Professional investigation should establish the actual high-voltage event in the proper module; the summary code supplies neither a safe operating assurance nor instructions for probing the generator's internal electronics.

# P2226: Internal barometric sensor communication or memory fault

P2226 is broadly described as a barometric pressure sensor circuit code. Mazda's SKYACTIV-G implementation is more specific: the BARO sensor is built into the PCM, and the monitor evaluates its internal communication and nonvolatile memory.

## Not an external pressure hose diagnosis

The documented triggers are an error between the BARO sensor and the PCM processor, or a memory error within that sensor. Detection uses a five-second period with battery voltage between 10.5 and 16 V. This source therefore does not support beginning with a search for an external BARO sensor hose or replacing an unrelated manifold sensor.

On detection, the controller substitutes 101.32 kPa for engine-control barometric pressure. That fixed value is a fail-safe input; it should not be interpreted as a successful measurement of the vehicle's actual altitude or atmospheric conditions.

## Why the component location changes the decision

Mazda's procedure calls for the applicable BARO sensor inspection and references PCM service when a fault is confirmed. The sensor's integrated location explains that routing, but P2226 alone is not evidence that every controller function has failed.

Preserve the original snapshot and check applicable service information before reaching a controller decision. Confirmation includes the prescribed key-on or running self-test and inspection for recurrence. The manual also calls for communication assessment if the same pending fault persists. These limits belong to this documented Mazda monitor and should not be exported unchanged to another make.

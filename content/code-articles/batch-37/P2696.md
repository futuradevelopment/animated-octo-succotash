# P2696: Injector data fault recorded as repeated internal-memory write errors

P2696 is cataloged as injector data incompatible. Mazda's SKYACTIV-D diagnostic page describes a repeated memory-write error in the fuel-injector system.

## A data fault does not establish poor fuel delivery

The PCM must detect the write error four consecutive times. The monitor also excludes specified injector, fuel-pressure sensing and LIN communication faults. That exclusion matters: a data-handling DTC should be interpreted after the supporting communication and injector records are known, rather than as proof of a blocked nozzle or low rail pressure.

The battery-voltage wording in the source includes a range followed by “or more,” so this article does not reconstruct a precise supply enable limit from that sentence. The supported diagnostic content is the repeated write failure and the related-fault exclusions.

## Controller routing and confirmation

The listed possible cause is the PCM. This is a narrow source-specific conclusion, not a reason to replace a controller without confirming the vehicle definition, service information and recurrence. Mazda inhibits EGR and DENOx/DESOx, restricts torque and, on automatic-transaxle vehicles, limits engine/transaxle integration control.

Its confirmation uses an ignition-on waiting period followed by repeated ignition-off waiting and ignition-on cycles. This emphasizes persistent data behavior across controller operation rather than a simple road-load test. Preserve the code and module history before erasure, and use the exact factory programming and diagnosis procedure for any subsequent controller decision.

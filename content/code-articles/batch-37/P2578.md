# P2578: Supercharger clutch command and rotation disagree

P2578 is cataloged as a turbocharger/supercharger speed-sensor circuit code. Mazda's SKYACTIV-X page instead centers on the relationship between clutch control and measured rotation; the exact definition correspondence remains unresolved. The manual describes it as a clutch circuit malfunction, but its detection logic includes mechanical and speed-sensor possibilities.

## More than one correlation can fail

The PCM compares clutch current with measured speed and with speed expected from the drive ratio. A commanded clutch that does not engage, a slipping clutch or unreliable speed information can create a mismatch. The page does not publish the numerical current and speed limits.

Mazda checks P056E for the cold-related branch and P25EC/P25ED for clutch electrical faults before proceeding. This separates a possible freezing condition or a direct control-circuit failure from the broader performance diagnosis.

## Use pressure and speed evidence together

The factory tests examine SUPER_CHARGER_RPM, manifold pressure and supercharger inlet pressure under controlled commands. These observations help distinguish actual lack of boost-producing rotation from a sensor that falsely reports little or no speed. The wiring branch includes the F12 15 A fuse and speed-sensor supply, signal and ground.

Boost and EGR are inhibited after detection. Active command tests and moving supercharger components require professional handling using the exact procedure. Confirmation includes the prescribed raised-speed operating condition and a recurrence check. The code alone is insufficient to choose a complete supercharger over a sensor or circuit repair.

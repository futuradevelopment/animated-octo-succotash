# P009D: Fuel relief-valve high control input and cross-circuit faults

P009D describes high input in the fuel-pressure relief control circuit. Mazda's SKYACTIV-D page evaluates the drive-current control switch while the valve operates with battery voltage between 10 and 16 V.

## High control input is not a measured rail-pressure limit

The monitored operating amount reaches or exceeds the source's specified value, but the page does not publish that numerical value. This is a control-circuit diagnosis. It should not be confused with a direct statement that fuel pressure exceeds a particular pressure threshold.

Mazda's cause list emphasizes a short between the positive and negative relief-valve control circuits, along with valve connection trouble, an internal valve fault and the PCM. That differs from automatically assuming that every high-input code means a wire shorted to battery power.

## The circuit relationship changes the repair

The sequence checks the valve and PCM connections, then whether the two control paths are shorted together, before evaluating the valve itself. A cross-circuit problem can prevent the expected drive behavior even if each wire appears connected to its endpoint.

The stated fail-safe inhibits i-stop. Repair confirmation exercises the warmed fuel-control system through the specified operating cycle before checking recurrence. High-pressure diesel service requires the proper professional depressurization and electrical precautions. Do not use the DTC as an instruction to bypass the relief valve or test it by opening a pressurized fuel connection.

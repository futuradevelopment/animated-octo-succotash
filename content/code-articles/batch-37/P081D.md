# P081D: Neutral-input error forwarded from the PCM to the BCM

P081D describes a neutral-input circuit fault. In this Mazda BCM application, the full code P081D:29 means the body module has received a neutral-sensor error report from the PCM for at least one minute.

## The receiving module may not be the cause

The detection condition concerns a message from another controller. Mazda consequently lists PCM DTCs, the neutral sensor, the PCM and the BCM as possible causes. A BCM record alone does not establish a fault in a wire attached directly to the BCM.

The prescribed response performs control with the neutral signal treated as off. That fallback is not an independent measurement of the transmission's actual neutral state. Both the module identity and the :29 suffix should be retained when comparing scan results.

## Follow the source of the error

The factory flow rechecks the BCM, reads the PCM for relevant DTCs and evaluates the neutral sensor. Its repeatability assessment includes ignition on for at least one minute, matching the sustained-message nature of the fault. An immediate recheck after erasure may therefore be too early to recreate the detection condition.

Professional verification must secure the vehicle and use the exact neutral-sensor procedure. Record whether the originating PCM fault remains present, not just whether the receiving BCM code clears. That distinction helps prevent unnecessary BCM replacement for an unresolved sensor or PCM-side problem.

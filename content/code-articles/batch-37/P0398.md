# P0398: Cylinder 1 pressure sensor signal above its electrical limit

P0398 reports high input from cylinder pressure sensor number 1. Mazda's SKYACTIV-X limit is a PCM input above 4.84 V for five seconds.

## Interpret the voltage before the pressure

An electrical high code does not prove excessive cylinder pressure. The source lists a signal short to a power source and an open sensor ground, as well as sensor, connector and PCM faults. A missing ground can therefore create the same diagnostic result as unwanted power on the signal line.

Mazda first checks for companion high-input faults P03A2, P03AC and P03B6. Their presence redirects the procedure toward PCM-connection inspection. That branch is useful when several cylinder-pressure readings are affected, because a wider electrical problem should be considered before replacing multiple sensors.

## Component tests remain separate

The isolated-sensor branch includes connection and resistance checks. The subsequent circuit investigation distinguishes the powered-signal path from ground continuity, followed by a sensor function check. These tests support different conclusions; the code alone identifies none of them conclusively.

The documented fail-safe inhibits EGR and SPCCI, stops combustion feedback and retards ignition timing. Once a cause is corrected, Mazda uses a key-on or running self-test and checks whether the pending DTC returns. The high-input limit is specific to this source and should not be used as a general combustion-pressure specification.

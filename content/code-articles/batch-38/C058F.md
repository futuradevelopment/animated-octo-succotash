# C058F: An engine-control error reported by Mazda's brake controller

The catalog heading for C058F is regeneration torque performance. In the cited Mazda DSC procedure, C058F:64 is stored when the brake controller receives a PCM signal indicating that engine control cannot be implemented. The reporting module and the origin of its evidence are different.

## A brake-controller code with an upstream cause

Mazda lists PCM DTCs and a PCM malfunction as possible causes. The first diagnostic decision is to read the PCM. If it has codes, their own procedures take priority. This ordering matters because work on the hydraulic unit would not address an engine-control fault that the brake controller is merely reporting.

The source does not define a measured regeneration-torque error, a torque threshold or a particular failed engine component. A general description of regenerative braking must not be substituted for this application's actual detection statement.

## What a returning code means

After the underlying diagnosis, the prescribed verification checks whether the DSC's pending C058F returns. Continued recurrence leads to CAN diagnosis and reconsideration of the PCM path. Other DTCs are also checked before completion.

The diagnostic inference is that a functioning communication link can carry an error-status message: receiving bad operating status is not automatically the same as losing communication. Keep the PCM fault record and the DSC report together when discussing the case with a technician. This page explains routing and verification; it does not justify replacing either controller solely from the C058F label.

Scope: Mazda3 01/2019 onward manual d9n1-1a-22d_ver10, in the controller and equipment variant named by the source. Confirm vehicle applicability before using its diagnostic path.

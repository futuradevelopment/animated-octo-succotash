# B0053: The left-rear buckle code identifies an ESU input path

For this Mazda BCM implementation, B0053:11 concerns the left-hand rear buckle switch. The electrical supply unit, or ESU, detects a short to ground on that input twice consecutively. The catalog's second-row-left seat-belt description identifies the seating position, while Mazda's page identifies the module that observes the fault.

## The source's precondition is important

The detection condition is specified with the rear left buckle switch removed. This is a diagnostic setup in the workshop procedure, not an instruction to disconnect a restraint component at home. It also prevents interpreting the code as merely evidence that a rear passenger has not fastened a belt.

The possible causes are an ESU connection problem, a shorted buckle signal circuit, the ESU or the BCM. This does not establish a failed buckle mechanism. The source directs the technician through the ESU connector and signal circuit before the repeatability-based controller branch.

## Distinguish one input from the reporting controller

A BCM scan can contain a fault whose electrical origin is at the ESU. That distinction is particularly useful if several rear buckle complaints appear together: the complete fault record should be compared before assigning several separate parts. The page alone does not prove a common cause.

Verification checks the recurring pending code and other DTCs, with CAN diagnosis where directed. Work around seat-belt and restraint equipment requires the correct service procedure. Keep the left-rear identity and :11 suffix intact through diagnosis and repair documentation.

Scope: Mazda3 01/2019 onward manual d9n1-1a-22d_ver10, in the controller and equipment variant named by the source. Confirm vehicle applicability before using its diagnostic path.

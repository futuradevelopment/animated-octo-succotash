# C0089: A traction-control switch held active for more than ten seconds

SAIC C0089:64 describes a traction-control-disable switch error. With the start switch on, the monitor sets when the input reports the switch pressed for more than ten seconds. This gives the code a practical distinction: a prolonged valid-looking input can trigger it without proving a failed control module.

## First distinguish operation from an electrical fault

The source explicitly considers the switch being held too long before moving to harness, supply, switch and controller causes. The diagnostic sequence likewise starts by deciding whether the switch was operated in that manner. A remembered operating event is useful context, though it does not excuse a code that recurs without the input being held.

The documented effect is loss of auto-hold function. It is therefore possible for a switch associated with traction control to accompany a complaint about another brake-system feature. The page does not establish that the physical parking brake has failed.

## What clearing and history mean

The current condition can clear in the next ignition cycle when its setting criteria are absent; history has a separate 40-cycle aging rule. Those are status rules, not a guaranteed repair from cycling power.

The later procedure considers the circuit, switch, IBS software and controller context. A qualified technician should confirm the input state and the reason it stays active before replacing a module. Brake-related function checks should follow the applicable service procedure rather than an improvised road exercise.

This interpretation is limited to the cited MG4 UK manual revision; it does not establish applicability to every MG4 build or another manufacturer.

# C0048: Mazda's brake-stroke fault can summarize several records

C0048 describes the brake-booster travel-sensor family. Mazda's SKYACTIV-G M Hybrid PCM implementation uses C0048:00 to summarize faults associated with the stroke sensor in the electronically controlled brake unit. It is therefore a useful example of why a five-character DTC is only the beginning of a diagnosis.

## More than one possible originating code

The PCM report can be triggered by C0048:28, C0048:62, U102C:41 or U102C:49 in the brake unit. The source lists these together; it does not say that every one represents the same failed part. Keeping the complete originating code prevents an electrical, internal or signal-specific finding from being flattened into the generic travel-sensor label.

Both i-stop and regenerative braking are inhibited under this PCM fault response. That establishes an interaction with hybrid operation, but it is not evidence of a generator or battery failure.

## Where the workshop decision starts

The procedure records the event data, considers applicable service information and reads the brake controller. If a brake-unit DTC is present, its own diagnostic procedure governs the repair decision. If the PCM alone retains the record, Mazda recognizes that it may describe a past malfunction.

Verification checks for a returning pending PCM code and other faults. A recurrence can require CAN diagnosis rather than immediate sensor replacement. The cited PCM chapter supplies no safe standalone stroke-sensor adjustment or hydraulic test. Diagnosis involving brake actuation belongs with a qualified technician using the exact brake-unit procedure.

Scope: Mazda3 01/2019 onward manual d9n1-1a-22d_ver10, in the controller and equipment variant named by the source. Confirm vehicle applicability before using its diagnostic path.

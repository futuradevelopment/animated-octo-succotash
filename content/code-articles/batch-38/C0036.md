# C0036: A left-rear tone-wheel code reported through Mazda's PCM

C0036 is cataloged as a left-rear tone-wheel code. In the cited Mazda M Hybrid PCM chapter, C0036:00 is generated because the electronically controlled brake unit has stored C0036:07. The chapter describes the affected location as the left-rear ABS wheel-speed sensor. Those two descriptions should be kept together rather than turning either into a component replacement order.

## A report from another controller

The PCM is not described here as directly measuring the wheel's sensor wiring or the tone wheel. Its evidence is the brake unit's stored diagnostic result. That makes a scan capable of reading the electronically controlled brake unit essential to interpreting this version of C0036.

Mazda disables i-stop and regenerative braking in response. An unavailable hybrid function can therefore be downstream of the wheel-speed fault. It does not, by itself, identify a failure inside the hybrid power source.

## Current fault versus historical record

The source explicitly allows for a PCM record remaining when the brake unit no longer has the related DTC. Its diagnostic sequence preserves the snapshot, checks applicable service information and follows any actual brake-unit code. Repair completion includes checking whether the PCM's pending report returns; recurrence also introduces CAN diagnosis.

The useful distinction is between the PCM's summary and the brake unit's original evidence. The cited page does not supply a tone-wheel inspection specification, air-gap value or sensor resistance test. Those details must come from the applicable brake procedure, performed under workshop safety controls.

Scope: Mazda3 01/2019 onward manual d9n1-1a-22d_ver10, in the controller and equipment variant named by the source. Confirm vehicle applicability before using its diagnostic path.

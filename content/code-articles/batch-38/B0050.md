# B0050: The driver buckle switch is monitored through Mazda's dash unit

B0050 is the driver seat-belt sensor family. Mazda's B0050:11 BCM procedure identifies a short to ground in the driver-side buckle-switch circuit. Although the code is read through the body controller, the detection statement assigns the electrical observation to the dash electrical supply unit.

## A particular test condition matters

The source specifies two consecutive detections and states that the driver buckle switch is removed as a precondition. That is a workshop diagnostic condition, not a claim that ordinary driving with an unfastened belt sets this electrical code. It also is not an instruction for an owner to remove a buckle.

Mazda lists the dash-unit connector, the switch signal circuit, the dash unit and the BCM as possible sources of the problem. The buckle name in the catalog therefore does not mean the buckle assembly is automatically defective.

## Where the procedure directs attention

The factory sequence evaluates the dash-unit connection and the signal path before judging the dash unit by repeatability. If the condition persists through the prescribed repair verification, the BCM remains a later possibility. Network diagnosis is included in the returning-code branches.

This division between detecting module and reporting module is useful when discussing a repair estimate: evidence should show why the input path or a controller was implicated. Seat-belt and nearby restraint components must be handled under the appropriate service procedure. Keep the full :11 code and any related faults rather than treating a seat-belt warning as a complete diagnosis.

Scope: Mazda3 01/2019 onward manual d9n1-1a-22d_ver10, in the controller and equipment variant named by the source. Confirm vehicle applicability before using its diagnostic path.

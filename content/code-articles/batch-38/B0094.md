# B0094: A center crash-sensor fault needs the SAS subcode

B0094 identifies the center frontal restraint-sensor family. Mazda calls the component the center crash-zone sensor and uses several suffixes to explain what the SAS controller has detected. This is a sensor input to the restraint system, not a record proving that an airbag has deployed.

## Different suffixes change the evidence

The :87 variant concerns signal reception, while :96 identifies an internal sensor malfunction. Mazda's :11 description includes a short to ground or supply, and its :13 description includes an open circuit or supply short. Those source-specific definitions should be retained rather than importing a simplified suffix description from another manufacturer.

The possible causes include the sensor connector, signal wiring, the sensor and the SAS module. A missing sensor message therefore does not automatically establish a failed sensor. The circuit and its connections can interrupt the same evidence.

## A safe diagnostic boundary

The factory procedure evaluates the connection and signal path before its component decision, then checks whether the same pending DTC returns. It also distinguishes the applicable standard or two-step deployment system. A meaningful workshop report should state which suffix was present and what evidence isolated the problem.

Mazda warns that restraint-system inspection performed from detection conditions alone can cause injury. Do not probe the crash-sensor or deployment connections, simulate a crash input or disassemble SRS components from this overview. The appropriate next step is qualified restraint-system diagnosis using the complete fault record and the correct vehicle-specific procedure.

Scope: Mazda3 01/2019 onward manual d9n1-1a-22d_ver10, in the controller and equipment variant named by the source. Confirm vehicle applicability before using its diagnostic path.

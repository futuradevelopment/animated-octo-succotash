# U0079: Mazda maps the bus-G code to CAN bus No.7

The generic U0079 title calls this control-module communication bus G off. Mazda's BCM procedure identifies the affected network as CAN bus No.7 and uses the complete code U0079:88. Keeping the manufacturer's network name avoids assuming that the catalog letter corresponds directly to a connector pin or physical location.

## This is a network-segment finding

The detection statement is a BCM determination of a communication-line malfunction on that bus. The page lists the communication line as the possible cause and sends diagnosis to the multiplex/CAN troubleshooting procedure. It does not identify one particular peripheral as failed.

That distinction changes what evidence is useful. A complete module scan and the correct vehicle network map can show which communication relationships are affected. A single missing module name on a generic scan is insufficient to decide that it caused the bus fault.

## Limits of the short procedure

The DTC page provides no terminal measurements, bus resistance, isolation order or verified symptom list. Those details must come from the referenced CAN diagnosis and the exact vehicle equipment. It would be unsafe and technically unsupported to attach a generic network-probing recipe to this code.

The diagnostic interpretation is therefore deliberately bounded: the BCM has found a problem on the documented segment, and the factory directs a network-level investigation. Preserve other communication codes before any reset so the original pattern remains available. A module replacement should follow evidence from that investigation rather than the bus-G label alone.

Scope: Mazda3 01/2019 onward manual d9n1-1a-22d_ver10, in the controller and equipment variant named by the source. Confirm vehicle applicability before using its diagnostic path.

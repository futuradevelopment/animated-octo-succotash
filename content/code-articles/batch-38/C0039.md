# C0039: Interpreting Mazda's right-rear tone-wheel report

In this Mazda M Hybrid application, C0039:00 is a secondary PCM record. The condition is very specific: the electronically controlled brake unit has stored C0039:07. The general catalog calls C0039 a right-rear tone-wheel fault, while this PCM page labels the location as the right-rear ABS wheel-speed sensor.

## Why the reporting module matters

The distinction prevents a misleading diagnosis from a basic engine-only scan. This page contains no direct sensor-circuit test because its monitor observes another controller's fault report. The original :07 code, its status and the brake-unit evidence are needed before choosing a wheel-end diagnostic procedure.

The PCM response includes suspending both i-stop and regenerative braking. Consequently, the appearance of multiple unavailable functions need not mean several unrelated components have failed. They can reflect the system's response to one brake-unit report.

## Evidence to retain

Mazda starts by recording freeze-frame or snapshot information and checking related service information. The next decision is whether the brake unit currently stores a relevant DTC. A code that exists only in PCM history is treated differently from an active brake-unit finding. After the prescribed repair verification, a returning pending PCM code calls for CAN assessment as part of the diagnostic path.

This source supports the routing of diagnosis, not a claim that the right-rear tone wheel must be replaced. Physical brake and wheel-speed checks should be selected from the correct vehicle procedure and left to a suitably equipped technician.

Scope: Mazda3 01/2019 onward manual d9n1-1a-22d_ver10, in the controller and equipment variant named by the source. Confirm vehicle applicability before using its diagnostic path.

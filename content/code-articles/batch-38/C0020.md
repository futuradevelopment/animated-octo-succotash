# C0020: The pump-motor subcode separates command and feedback faults

Mazda's DSC hydraulic unit/control module uses several C0020 subcodes for the ABS pump motor and pump relay. Although the catalog calls the family ABS pump motor control, the complete code describes different observations of the same controlled system.

## What the suffix adds

C0020:11 concerns relay feedback that disagrees with an ON command. With :12, the motor-monitor signal disagrees with an OFF command. The :13 version records insufficient relay voltage while the relay is commanded on. The :49 branch identifies a pump-motor drive-circuit malfunction, whereas :71 concerns a voltage decrease detected after motor operation.

That timing matters. An abnormal response after operation is different evidence from a command that never obtains the expected relay voltage. None of these observations alone establishes whether the external supply, ground, connection or internal unit is responsible.

## The diagnostic division

The factory path first uses the supported pump simulation to determine whether the motor operates. If it does not, the next evidence comes from the DSC connector, supply circuit and ground circuit. The source lists both external circuit faults and internal pump or relay problems as possible causes.

These are controlled workshop checks on a braking system, not instructions to power a pump manually. A technician must also complete the prescribed verification and consider network faults if the pending code returns. The code is evidence of a command/feedback problem; the failed component is the conclusion of the procedure, not part of the code itself.

Scope: Mazda3 01/2019 onward manual d9n1-1a-22d_ver10, in the controller and equipment variant named by the source. Confirm vehicle applicability before using its diagnostic path.

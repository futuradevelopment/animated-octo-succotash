# C003B: A right-rear wheel-speed circuit finding in SAIC's IBS

The C003B catalog family is right-rear wheel-speed sensor supply. In SAIC's IBS table, C003B:14 is described as parasitic resistance to ground on the right-rear sensor signal line. The diagnostic detail is an unwanted electrical path, not a confirmed damaged tone ring.

## Retain the source's circuit distinction

The table separates this signal-line code from other right-rear return-line, open-circuit, implausibility and sensor-type codes. Those neighboring entries establish that C003B is not a catch-all for every missing wheel-speed reading.

The setting paragraph uses different wording, calling the relevant line a sensor ground wire, and specifies a 140-millisecond detection interval. Because the table and paragraph differ, this article does not turn the label into a pin assignment. The correct brake wiring diagram must identify the actual circuit before a technician tests it.

## Why a sensor is not the only candidate

The shared procedure considers harness and connectors, then the corresponding wheel-speed sensor, followed by IBS software and hardware. The source identifies ABS being disabled for this group. It also describes diagnostic-command clearing for this electrical subgroup, unlike some motion-dependent recovery conditions elsewhere in the table.

Preserve the full :14 record and the right-rear identity. A workshop should establish the electrical fault and its correction through the proper procedure. This overview provides no brake-circuit probing or road-test instructions and does not make a sensor purchase the default response.

This interpretation is limited to the cited MG4 UK manual revision; it does not establish applicability to every MG4 build or another manufacturer.

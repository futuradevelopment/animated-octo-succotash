# B0091: The left B-pillar sensor has separate invalid-data and missing-message codes

SAIC uses B0091 for the left B-pillar side-impact sensor in the cited SDM procedure. The sensor sends acceleration information that the restraint controller evaluates. The diagnostic suffix tells whether the problem concerns internal electronics (:49), configuration (:56), invalid data (:86) or missing communication (:87).

## Message quality is not the same as message absence

The :86 variant includes sensor deviation and acceleration information judged too high or low. The :87 condition includes communication or short-circuit findings within a 200-millisecond observation window. A report that only says left-side sensor fault discards this useful distinction.

The source describes a defined sensor mounting arrangement. That supports checking the correct component application through the workshop procedure, but it is not an instruction to move, loosen or strike the sensor to see whether the code changes.

## The connection remains a possible cause

The diagnostic sequence considers the SDM-to-sensor harness and connection, the sensor and then the SDM. An internal-sensor label in one suffix does not justify applying that diagnosis to all B0091 variants. Configuration wording in the table is repetitive, so no detailed coding algorithm is inferred here.

Restoration of the signal and historical clearing are separate events. A qualified SRS technician should establish the original fault type and verify the repaired input while retaining other restraint records. This overview supplies no sensor probing or deployment test and makes no airbag-availability promise from a single DTC.

This interpretation is limited to the cited MG4 UK manual revision; it does not establish applicability to every MG4 build or another manufacturer.

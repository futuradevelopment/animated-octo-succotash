# C051A: A left-rear sensor compatibility finding in Mazda's DSC

C051A belongs to the left-rear mechanical wheel-speed sensor family. In Mazda's cited DSC chapter, the complete C051A:95 code identifies an unexpected ABS sensor type at the left rear. The diagnostic target is consequently compatibility with the vehicle's equipment, rather than a generic assumption that road debris has disturbed the signal.

## Two supported possibilities

The source names a left-rear sensor different from the vehicle specification and a DSC hydraulic unit/control module malfunction. It does not rank these by likelihood. It also supplies no wheel-speed waveform limit or mechanical clearance on this page.

That combination makes exact part identification useful evidence, particularly after rear sensor replacement. It also means that observing a plausible speed value cannot, on its own, settle the controller's separate type check. This is an interpretation of the stated monitor, not a substitute test proposed by Mazda.

## What verification contributes

The procedure determines whether the same pending code recurs, includes CAN diagnosis in the recurrence branch and then follows the specified sensor repair route. A repeat after the prescribed work can move the diagnosis toward the DSC controller. Other DTCs are checked at completion.

The location must remain left rear throughout the diagnosis; the related corner-specific codes are not interchangeable part assignments. A technician should verify the full code and equipment configuration before selecting service information. Because the affected system participates in braking control, physical checks and repair verification should remain within a properly equipped workshop.

Scope: Mazda3 01/2019 onward manual d9n1-1a-22d_ver10, in the controller and equipment variant named by the source. Confirm vehicle applicability before using its diagnostic path.

# U031A: The body controller has received a transmission error signal

U031A is broadly titled software incompatibility with the transmission range control module. Mazda's BCM page for U031A:82 identifies a CAN error signal received from the transmission control module. The source therefore supports a transmission-status investigation, not an immediate diagnosis of a range sensor or software-version mismatch.

## Read the TCM's own evidence

The procedure verifies whether the same pending BCM DTC returns and then scans the TCM. If a transmission DTC is present, its procedure takes priority. The manual references several transmission families, so the vehicle's installed transmission must determine which diagnostic table is appropriate.

Possible causes include stored TCM faults, the TCM and the BCM. The reporting body controller is not automatically the failed module, and the presence of an error message is not identical to total loss of transmission communication.

## Recurrence controls the later branches

If the BCM continues receiving the error after the relevant checks, Mazda directs CAN diagnosis before the TCM-related repair branch. Further verification considers the BCM only after the prescribed work. The sequence is evidence against replacing a transmission assembly based solely on a shortened U031A display.

Keep the :82 suffix, module identity, transmission type and original TCM codes in the repair record. This page provides no selector adjustment, firmware package or range-sensor electrical threshold. Those details must come from the correct transmission procedure. A complete repair conclusion should explain the originating fault and confirm that the receiving BCM no longer repeats its error report.

Scope: Mazda3 01/2019 onward manual d9n1-1a-22d_ver10, in the controller and equipment variant named by the source. Confirm vehicle applicability before using its diagnostic path.

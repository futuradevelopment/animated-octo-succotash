# B0005: Ford's collapsible-column deployment loop needs more than a cleared code

The 2011 Ford Flex procedure defines B0005 as collapsible steering-column deployment control. The restraints control module monitors that deployment loop for abnormal resistance, unexpected voltage, a ground short or a component fault. This belongs to the restraint system, not ordinary steering-column adjustment.

## Why the resistance data still matters when the code disappears

Ford explains that the controller combines deployment-loop resistance with an age correction factor. Small changes in terminal fit or temperature can make a fault intermittent. The procedure consequently requires the diagnostic resistance parameter to be within its desired range even if no on-demand DTC is present at that moment.

That is stronger evidence than simply clearing memory and observing an extinguished warning lamp. It also prevents treating a historical record as proof of a presently failed column assembly.

## Current and continuous-memory records follow different branches

The first test distinguishes a code returned during an on-demand self-test from one retained only in continuous memory. The procedure then separates wiring, connections, the collapsible column and the RCM through controlled diagnosis.

A qualified SRS technician must perform that work. The diagnostic parameter is controller-reported information, not permission to probe a deployment device. Ford also cautions that physically similar restraint parts can be incompatible. A supported repair must establish the correct component application, resolve the original fault and complete the restraint-system checks rather than rely on a replacement or reset alone.

Scope: 2011 Ford Flex FWD V6-3.5L; Pinpoint Test D: DTCs B0005:11, B0005:12, B0005:13 and B0005:1A. The cited failure types and controller logic should not be generalized to other Ford vehicles without the matching service procedure.

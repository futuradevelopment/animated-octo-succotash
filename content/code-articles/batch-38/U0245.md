# U0245: The body controller waits two seconds for front-infotainment data

SAIC's BCM procedure defines U0245:87 as lost communication with the front infotainment control module, or FICM. With ignition on and CAN communication active, the BCM sets the code if the specified FICM frames do not arrive within two seconds.

## Missing data is a specific relationship

A radio or screen can have local functions while a required vehicle-network message is missing. Conversely, a completely unresponsive infotainment system may have a supply or connection problem rather than an internal processor failure. The code establishes the missing relationship at the BCM; it does not choose the failed part.

The source describes substitution of a default signal value after the fault. It does not identify one guaranteed user-visible symptom, so a complaint about sound, display or controls should be retained as separate evidence.

## What the diagnostic order contributes

The factory sequence checks network integrity, the FICM–BCM connection path, the FICM and finally the BCM. Its cause list includes wiring and both modules. Software assessment is conditional on the relevant findings, not a blanket instruction to install an update.

Current recovery requires one hundred consecutive corresponding frames, and history has a separate forty-ignition-cycle rule. A brief reconnection therefore should not be described as a completed repair without the required verification. Preserve the :87 suffix, module records and symptom timing so a technician can identify the actual interruption and confirm its correction.

This interpretation is limited to the cited MG4 UK manual revision; it does not establish applicability to every MG4 build or another manufacturer.

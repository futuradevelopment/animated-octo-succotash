# C0045: The linear-actuator pressure offset check in Mazda's brake unit

C0045 is broadly a brake pressure sensor B code. Mazda's electronically controlled brake-unit procedure specifies C0045:28 as a problem with the offset of the brake-fluid pressure signal on the linear-actuator side. The measured quantity is therefore the signal's offset, not simply whether pressure rises during braking.

## Why the location matters

The manual explicitly identifies the linear-actuator side. Substituting a different brake-pressure reading because it looks plausible would not establish that this particular channel is correct. The page does not publish the acceptable offset value, so no numerical pass/fail limit should be inferred from the general code title.

Mazda lists a malfunction within the electronically controlled brake unit, specifically its pressure sensor, and provides no separate external wiring diagram for this diagnostic page. That scope differs from a generic open-circuit troubleshooting guide.

## The decision is conditional on recurrence

The source checks whether the same pending code returns after the prescribed diagnostic clearing step. If it does, CAN diagnosis precedes the unit-level repair branch. A nonrecurring record proceeds to checking other DTCs rather than automatically condemning the brake unit.

This is an explanation of the monitor and its decision boundary. It does not provide a sensor calibration adjustment, hydraulic pressure test or authorization to open the assembly. A qualified brake technician must establish the applicable equipment, preserve the original fault evidence and perform the complete factory verification before a repair conclusion is justified.

Scope: Mazda3 01/2019 onward manual d9n1-1a-22d_ver10, in the controller and equipment variant named by the source. Confirm vehicle applicability before using its diagnostic path.

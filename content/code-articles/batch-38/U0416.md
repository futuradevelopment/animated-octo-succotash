# U0416: Invalid brake data and missing brake data are different lighting faults

Mazda U0416:29 in the auto-leveling controller concerns an error signal received from the brake system. Without M Hybrid the sender is the DSC hydraulic unit/control module; with M Hybrid it is the electronically controlled brake unit. This source explicitly provides both equipment branches.

## The headlamp actuator stops as a response

The auto-leveling actuator remains at its position when the fault is determined. That consequence can explain a leveling complaint without establishing that the actuator itself failed. The code's evidence is the received error status, not a direct mechanical measurement of the headlamp.

The distinction from lost communication matters. An error message is arriving, so the first diagnostic direction is to inspect the originating brake module for DTCs. Mazda's procedure follows any such brake fault before judging the leveling controller.

## What completion should verify

The later branches use recurrence and CAN diagnosis to distinguish the brake controller from the auto-leveling module. A successful repair needs the receiver's pending-code check as well as the originating-system assessment. Clearing only one module can conceal whether the status report is still being generated.

Preserve the :29 suffix and the hybrid-equipment identification when selecting the source procedure. The page does not publish an angle adjustment or a universal headlamp calibration remedy. A qualified workshop must use the original brake evidence and the correct lighting procedure, with safety controls for any brake-system work, before reaching a component replacement conclusion.

Scope: Mazda3 01/2019 onward manual d9n1-1a-22d_ver10, in the controller and equipment variant named by the source. Confirm vehicle applicability before using its diagnostic path.

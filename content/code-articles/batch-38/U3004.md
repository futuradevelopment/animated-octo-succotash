# U3004: The BCM is checking accessory-relay output voltage

U3004 is the accessory-power relay family. In Mazda's BCM procedure, U3004:11 is set when the monitored ACC relay output voltage is below the expected standard. The page does not publish a numerical voltage limit, so an exact threshold should not be invented from the code title.

## A relay label covers more than the relay

Mazda lists the ACC relay, BCM connector, a short to ground in the relay signal circuit and the BCM as possible causes. The low observed output can consequently result from a problem in the controlled circuit or its connection rather than an automatically failed relay.

The first diagnostic branch checks whether the same pending DTC returns. A historical record that does not recur moves differently through the procedure from a current low-output finding. Preserving the original scan before clearing it helps maintain that distinction.

## What narrows the decision

For a recurring code, the factory sequence assesses the relay, then the BCM connection and the signal circuit. The controller decision is conditional on those findings and on completion verification, including CAN diagnosis where directed.

This source does not establish which individual accessory will stop working, nor does it provide a bypass procedure. A technician should connect any reported accessory symptom to the actual circuit evidence instead of treating every radio or outlet complaint as confirmation of U3004. Repair verification requires the correct output behavior and fault status, not merely an accessory turning on once after a reset.

Scope: Mazda3 01/2019 onward manual d9n1-1a-22d_ver10, in the controller and equipment variant named by the source. Confirm vehicle applicability before using its diagnostic path.

# C0042: Separate a brake-pedal circuit fault from missing zero calibration

In the cited SAIC gateway chapter, C0042 describes brake-pedal position sensor circuit A. The sensor is connected to the BCM by wiring, and its learned released-pedal voltage provides the zero reference. The code therefore concerns both an electrical input and the reference used to interpret it.

## The failure type changes the question

C0042:14 identifies a signal below 0.5 volts; :15 identifies a signal above 4.5 volts. The :1C variant concerns a voltage outside the range representing pedal travel. By contrast, :54 means zero-position learning has not been completed. A missing learned reference is different from a proven shorted signal wire.

The source describes a default pedal-position value of 100 percent after the fault. That is a substituted control value, not evidence that the physical pedal is fully depressed.

## Use the appropriate diagnostic branch

For missing calibration, the procedure first considers correct sensor installation and completion of the learning process. Other supported possibilities include the signal circuit, sensor, body controller and gateway. The code does not select one part without those distinctions.

These figures explain the controller's monitor; they are not instructions to probe a brake-sensor connector or perform a calibration at home. A qualified brake technician should retain the full failure type, establish installation and data validity with the appropriate procedure, and confirm that the setting condition is no longer present after repair.

This interpretation is limited to the cited MG4 UK manual revision; it does not establish applicability to every MG4 build or another manufacturer.

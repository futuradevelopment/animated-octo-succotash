# U0224: The rear-left window has its own communication timeout code

In SAIC's window-motor diagnostic table, U0224:87 is specifically the left-rear motor. The BCM sets it when the expected frame from that motor is missing within the specified time. The table does not publish a universal timeout in seconds.

## Preserve the corner-specific assignment

U0222 through U0225 share a procedure, but the code identities distinguish driver, front passenger, rear left and rear right. Applying the front-passenger repair path to U0224 would lose the exact node named by the source.

The monitor is described with ignition on and normal LIN1 communication. Although the subsystem paragraph emphasizes the front motors, the U0224 setting row explicitly names the left-rear motor. This article does not infer additional wiring routes or pin assignments beyond that documented row.

## Why a stationary window is incomplete evidence

The listed response includes disabled regulator functions and a substituted signal. The inability to move the window can consequently be a control response, not proof of a seized regulator. The supported causes include the appropriate harness or connector, motor and BCM.

The shared procedure evaluates those categories in that order. Communication recovery requires one hundred consecutive expected frames, while history uses a separate forty-cycle rule. A technician should keep other window or LIN faults with this record to determine whether the loss is isolated. No motor bypass or forced-glass procedure is justified by this communication code.

This interpretation is limited to the cited MG4 UK manual revision; it does not establish applicability to every MG4 build or another manufacturer.

# U0339: The driver-door supply unit behind Mazda's body-module-B label

The broad U0339 description is software incompatibility with body control module B. Mazda's actual BCM procedure identifies the sender as the driver's door electrical supply unit. U0339:82 means the BCM received a CAN error signal from that unit.

## The manufacturer name resolves the component identity

Body module B is not a sufficient physical description for this application. The source's driver-door identity is the useful diagnostic distinction. It prevents a generic label from being used to select an unrelated body controller or an assumed second central BCM.

The documented alternatives are the door electrical supply unit and the BCM. The page does not specify which window, mirror or lock function must be affected, so such symptoms should be recorded as observations rather than asserted as inevitable effects of this code.

## What recurrence can establish

The procedure first checks whether the same pending report returns. A recurring condition leads through CAN diagnosis before the door-unit decision. Continued recurrence after the prescribed verification can then require reassessing the BCM. This is not a blanket instruction to replace or reprogram both modules.

A technician should retain the :82 suffix, the reporting module and any accompanying door or network faults. Receiving an error status differs from receiving no door message, and it does not independently prove a software mismatch. The factory procedure and exact vehicle equipment must govern any connection checks, component selection and required setup after a supported repair.

Scope: Mazda3 01/2019 onward manual d9n1-1a-22d_ver10, in the controller and equipment variant named by the source. Confirm vehicle applicability before using its diagnostic path.

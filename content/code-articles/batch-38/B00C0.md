# B00C0: A high occupant-sensor signal can come from an open return

On the documented 2011 Ford Flex, B00C0 identifies occupant-classification weight-sensor bolt A and its circuit. The occupant classification module stores the specific fault and informs the RCM, which can then store B00A0:09 and request the warning lamp. Those records can describe one fault chain rather than two failed controllers.

## The short-to-battery label has an important alternative

Ford defines :12 by an excessively high signal and explicitly notes that an open sensor-return circuit can also produce it. The label therefore does not prove that the signal wire is physically touching battery supply. The :13 and :1A variants separately concern an open/high-resistance indication and resistance below the specified threshold.

The manual states that these are three-wire sensors that cannot be tested as components with a multimeter. The controller's detection values should not be converted into a DIY sensor resistance test.

## Preserve the actual diagnostic status

The procedure distinguishes a fault returned on demand from one retained only in continuous memory. It evaluates seat wiring and connections before its component decisions and requires both occupant-classification and restraint-system checks at completion.

A qualified SRS technician should retain the exact A-sensor suffix and the related RCM record. Matching component application matters even when parts look alike. This overview gives no connector-probing, load-substitution or coding-bypass instructions.

Scope: 2011 Ford Flex FWD V6-3.5L; Pinpoint Test Y: DTCs B00C0:12, B00C0:13 and B00C0:1A. The cited failure types and controller logic should not be generalized to other Ford vehicles without the matching service procedure.

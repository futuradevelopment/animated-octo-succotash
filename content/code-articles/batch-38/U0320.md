# U0320: The PCM's steering-module error needs EPS evidence

U0320 is commonly titled software incompatibility with the power-steering control module. In Mazda's SKYACTIV-G PCM procedure, U0320:00 instead identifies an EPS control-module error involving the CAN path or an internal EPS malfunction. The detailed source does not reduce the diagnosis to software programming.

## Separate the reporter from the steering controller

The PCM stores this record, but Mazda's diagnostic sequence reads the EPS controller itself after checking related PCM faults. An EPS DTC can explain the originating problem more precisely than the PCM's summary. This makes a full-module scan materially more useful than a basic engine-code reader for this case.

The possible-cause list includes connections at both controllers, the communication line, CAN drivers and the controllers themselves. Those alternatives are evidence against treating the words power steering as a direct instruction to replace a steering assembly.

## What constitutes a supported next decision

The source examines EPS and PCM connections and then verifies whether the same pending report returns. On recurrence it calls for CAN diagnosis before the later PCM decision. It does not provide a universal steering calibration, steering-angle reset or firmware-update recipe for U0320.

The exact :00 variant and applicable SKYACTIV-G configuration must be established. Steering-system diagnosis and any physical work should be performed by a qualified technician. A communication error or warning cannot establish safe steering assistance from this code alone, and an erased record is not a substitute for the factory completion checks.

Scope: Mazda3 01/2019 onward manual d9n1-1a-22d_ver10, in the controller and equipment variant named by the source. Confirm vehicle applicability before using its diagnostic path.

# U0336: A PCM restraint-module error requires the SAS fault record

For Mazda's cited SKYACTIV-G PCM, U0336:00 describes an SAS control-module error. The generic catalog's software-incompatibility title is broader than the actual procedure, which includes a CAN-line problem between SAS and PCM or an internal SAS malfunction.

## Why the restraint scan matters

The PCM is the reporting controller here. Mazda checks its other codes, then reads the SAS module for restraint-specific DTCs. If the SAS has a fault, that procedure takes priority. A summary in the engine controller cannot reveal which deployment circuit, sensor or internal condition may have caused the restraint system to report an error.

The source also names connector faults at SAS and PCM, CAN driver errors and either module as possible causes. No particular airbag component, software release or coding correction is established by the U0336 record alone.

## Keep the diagnosis at the right level

The procedure evaluates the relevant connections and uses recurrence during prescribed verification to decide whether further CAN diagnosis is required. Its later controller branch is conditional on that work, not an immediate instruction to replace the module named in the catalog.

A complete scan should retain the :00 suffix, module identities and any related SAS records. Because the investigation touches restraint equipment, connector handling and electrical tests require the manufacturer's SRS precautions and a qualified technician. This explanation provides no deployment-circuit probing or coding bypass. It describes how the factory routes the evidence from the PCM summary to the system that generated it.

Scope: Mazda3 01/2019 onward manual d9n1-1a-22d_ver10, in the controller and equipment variant named by the source. Confirm vehicle applicability before using its diagnostic path.

# C0035: The right-front sensor supply family includes an unwanted ground-path fault

SAIC's IBS table assigns C0035:14 to parasitic resistance to ground on the right-front wheel-speed sensor signal line. The generic C0035 title is sensor supply, so the complete failure type is needed to describe this particular electrical condition.

## Compare the correct rows

The same table separately identifies right-front mechanical, open-circuit, invalid-signal, erratic-signal and sensor-type faults. C0035:14 must not be silently substituted for one of those. Its detection is an unwanted electrical relationship, not simply a low displayed wheel speed.

The setting paragraph gives a 140-millisecond observation and calls the line a ground wire, while the description row says signal line. The terminology is inconsistent enough that no terminal assignment should be inferred from the excerpt. The source's vehicle wiring diagram is necessary to resolve the physical circuit.

## The shared checks have a specific corner

The procedure examines wiring and connections before the corresponding sensor, followed by software and IBS assessment. It lists ABS disablement for the group. The recovery entry for this subtype uses a diagnostic command rather than the rolling-speed comparison used for several adjacent signal faults.

A workshop should preserve the right-front location and :14 suffix, establish the actual circuit evidence and verify that evidence after repair. Replacing a wheel bearing merely because the code belongs to a wheel-speed family would not follow this source. This overview provides no brake-network probing or fault-reproduction driving instructions.

This interpretation is limited to the cited MG4 UK manual revision; it does not establish applicability to every MG4 build or another manufacturer.

# U0236: A column-lock message timeout seen by the instrument pack

In the cited SAIC instrument-pack procedure, U0236:87 means a specified electronic steering-column-lock message has not arrived within two seconds. The instrument pack is the receiver. The code does not directly measure the lock's mechanical position or prove that the column lock has jammed.

## The enabling conditions narrow the event

The monitor operates with ignition on and communication enabled for more than one second, provided the listed supply and bus-off faults are absent. A loss caused by a broader network problem should therefore be assessed in the context of those other records.

The table identifies the ESCL as the missing sender. This coherent instrument-pack procedure is used here rather than another page in the compilation whose setting paragraph names the BCM despite a column-lock heading.

## Distinguish communication recovery from a repair conclusion

One hundred consecutive valid frame receptions satisfy the communication recovery condition. Historical clearing follows forty failure-free power cycles. Neither rule demonstrates why the interruption occurred.

The source directs a network integrity check, assessment of the IPK-to-module communication path and then controller evaluation. Harness, connections, the column-lock module and instrument pack remain supported possibilities. A technician should retain the complete :87 code and related faults before deciding whether any component needs replacement. This overview provides no bypass, forced-unlock procedure or reassurance about steering-lock operation from a network record alone.

This interpretation is limited to the cited MG4 UK manual revision; it does not establish applicability to every MG4 build or another manufacturer.

# B0055: The right-rear buckle fault is more specific than a belt reminder

Mazda uses B0055:11 for the right-hand rear buckle-switch circuit in the BCM diagnostic system. The ESU detects a short to ground twice consecutively. Thus the fault has both a precise seating position and a precise electrical observation; it is not a general statement that a rear passenger's belt is unfastened.

## Do not lose the diagnostic setup

The source specifies a removed rear-right buckle switch as the precondition. That belongs to the controlled diagnostic procedure. Removing or probing a buckle is not an owner-level test supplied by this article, especially where restraint wiring is nearby.

The page lists the ESU connection, a grounded signal circuit, ESU malfunction and BCM malfunction. These alternatives explain why a code bearing the buckle's name can ultimately involve wiring or an input controller instead of the mechanical latch.

## Interpreting a workshop finding

Mazda's sequence checks the ESU connector and signal path before its repeatability assessment of the ESU. The BCM is considered later if the code survives the specified repair verification. CAN diagnosis forms part of the returning-code branches, and other DTCs are checked at completion.

The useful questions are whether the complete :11 code recurred, which portion of the right-rear input path was proven abnormal, and whether the final check found related faults. The code does not publish a seat-belt replacement interval, a universal switch resistance or a reason to bypass the reminder. Qualified service should use the exact equipment-specific procedure.

Scope: Mazda3 01/2019 onward manual d9n1-1a-22d_ver10, in the controller and equipment variant named by the source. Confirm vehicle applicability before using its diagnostic path.

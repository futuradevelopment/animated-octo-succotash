# U0215: A driver-door switch pack with a two-second LIN timeout

SAIC's BCM procedure uses U0215:87 for the driver-door switch pack, also called the driver-door combination switch. The switch communicates with the BCM over LIN. With ignition on and LIN1 operating normally, the fault sets if its specified frame is absent for two seconds.

## The switch pack and window motor are different nodes

This code identifies the command-input assembly, not the motor that moves a window. A complaint about window operation could involve either part of the chain, so the full scan matters before assigning a motor or regulator repair.

The source describes use of a default signal value after communication is lost. It does not specify every disabled door function. Symptoms should therefore be recorded alongside the DTC rather than inferred from the switch pack's name.

## A network-aware diagnostic sequence

The factory path checks the switch-to-BCM harness and connectors, then the switch assembly and then the BCM. Both wiring and module explanations remain possible. The normal-LIN1 enabling condition also makes any broader bus record important context.

Communication recovery requires one hundred consecutive expected frames; historical aging requires forty failure-free ignition cycles. Those are different from proving the cause was repaired. A technician should establish the reason the switch stopped reporting and verify that the signal remains available. Replacing a window motor because a door switch code is present would not follow this source's identified diagnostic target.

This interpretation is limited to the cited MG4 UK manual revision; it does not establish applicability to every MG4 build or another manufacturer.

# C0034: Why Mazda's PCM repeats a right-front wheel-speed fault

On the documented SKYACTIV-G Mazda M Hybrid system, C0034:00 in the PCM is a report about the electronically controlled brake unit. The PCM stores it when that unit has one of several right-front wheel-speed faults. Reading only the engine controller therefore loses the more specific evidence.

## The detail lives in the brake unit

The triggering list includes C0034 with suffixes :07, :15, :19, :29, :2F, :37 and :64, plus C0519:95. These are deliberately grouped under the PCM's :00 report. A sensor electrical problem and the separately identified C0519 sensor-type problem can consequently lead to the same PCM display. The five-character code cannot select between them.

Mazda identifies inhibition of i-stop and regenerative braking as responses to this report. Those responses explain why a wheel-speed problem may have consequences beyond a wheel-speed display; they do not demonstrate that the starter-generator itself has failed.

## What changes the diagnosis

The factory procedure preserves the event snapshot and then reads the brake unit's DTCs. Its specific fault procedure takes priority. The manual also distinguishes an old PCM record with no corresponding brake-unit fault from a currently recurring problem. A persistent pending PCM report after the prescribed verification leads to network diagnosis before controller replacement is considered.

This is a brake-system diagnosis for a qualified technician. Replacing the right-front sensor solely because an engine scan shows C0034 skips the decision that this particular monitor was designed to make.

# U010F: The A/C module timeout is separate from a short reply failure

In SAIC's BCM chapter, U010F:87 is a lost-communication fault for the air-conditioning control module. The source requires ignition on and normal CAN3 communication, then sets the code if the expected A/C frame is absent for two seconds.

## Do not merge neighboring diagnostic timers

The same page contains B1715, a separate failure to receive an automatic-A/C reply within 250 milliseconds. That shorter value is not the U010F timeout. The two records can concern the same broad system while describing different communication checks.

After U010F, the source says the system uses a default signal value. It does not establish a refrigerant leak, compressor defect or particular cabin-temperature symptom. A network fault and an A/C cooling-performance complaint require evidence linking them.

## The connection path precedes a module decision

The documented diagnostic sequence assesses the A/C-module-to-BCM harness and connectors, then the automatic-A/C controller, then the BCM. Software or hardware decisions are conditional on those checks. A module appearing in the code title is therefore a diagnostic endpoint, not an automatic replacement.

The current fault recovers after one hundred consecutive expected frames, with a separate forty-failure-free-ignition-cycle history rule. A technician should retain the complete suffix and both modules' faults, establish whether the two-second loss repeats, and verify stable communication after the supported repair rather than relying on one successful climate-control command.

This interpretation is limited to the cited MG4 UK manual revision; it does not establish applicability to every MG4 build or another manufacturer.

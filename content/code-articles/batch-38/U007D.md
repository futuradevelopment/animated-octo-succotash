# U007D: A Mazda bus fault on the diagnostic-connector path

U007D is generically described as control-module communication bus K off. Mazda's BCM page identifies the relevant path more concretely: the CAN connection between the body control module and DLC-2, the diagnostic connector. The full code is U007D:88.

## Why diagnostic access belongs in the interpretation

This is not a statement that one named engine, brake or lighting module has disappeared. The monitored communication segment includes the diagnostic connection itself. A limited or unsuccessful scan must therefore be interpreted with awareness that access to vehicle information can be part of the fault under investigation.

The source lists a CAN communication-line malfunction and directs the technician to the multiplex communication diagnostic flow. It does not establish that the scan tool caused the fault, nor that a particular module must be replaced.

## Use the actual network procedure

The short code page supplies no terminal allocation, resistance threshold or connector-isolation order. Those details depend on the vehicle-specific CAN procedure. Substituting generic bus-K pin assignments would create unsupported precision and could direct testing to the wrong circuit.

Useful retained evidence includes the full BCM record and which diagnostic communication functions were available when it was captured. A technician should then use the appropriate network topology to distinguish the diagnostic path from faults on other segments. Clearing a code or reconnecting a scanner may change symptoms without establishing the underlying cause. The source supports a network-level investigation of this defined path, not an automatic BCM replacement.

Scope: Mazda3 01/2019 onward manual d9n1-1a-22d_ver10, in the controller and equipment variant named by the source. Confirm vehicle applicability before using its diagnostic path.

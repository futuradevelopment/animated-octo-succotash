# U0180: A lighting-module timeout described in the SAIC BCM table

SAIC's BCM description row identifies U0180:87 as lost communication with the automatic-lighting controller, labeled AFS/DHL. The subsystem text says the BCM communicates with other modules through the gateway. The relevant monitor requires ignition on and normal CAN communication, then detects a missing expected frame within two seconds.

## The reliable distinction is a message timeout

This is a communication record rather than a bulb, aiming or headlamp-motor test. The table describes use of a default signal value after the loss. It does not establish which physical lighting function must fail on every vehicle.

Recovery requires one hundred consecutive corresponding frames, while historical clearing follows forty failure-free ignition cycles. A momentary return of lighting operation is not the same as explaining or repairing the interruption.

## Do not import the neighboring seat-module instructions

The page groups U0180 with a seat-control communication code, and several later repair steps name the driver-seat module. Those seat-specific steps are not reliable evidence for repairing the lighting system and are not adopted here.

The supported use of this page is therefore a narrowly scoped monitor explanation: identify the reporting BCM, the fitted automatic-lighting module, gateway context and timeout status. A technician must obtain the correct lighting-network procedure before making a component decision. This article does not use the grouped page to recommend replacing a seat module, gateway or headlamp assembly.

This interpretation is limited to the cited MG4 UK manual revision; it does not establish applicability to every MG4 build or another manufacturer.

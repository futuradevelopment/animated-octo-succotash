# U0122: A brake-controller communication fault can stop headlamp leveling

U0122 describes lost communication with vehicle dynamics control. In the cited non-M-Hybrid branch of Mazda's auto-leveling procedure, the reporting controller is the headlamp auto-leveling module and the missing sender is the DSC hydraulic unit/control module.

## Why a lighting complaint can have a brake-network code

The documented response is to stop the headlight-leveling actuator at the position it occupied when the malfunction was determined. The source does not say the actuator motor is broken. It describes a control response to unavailable information from another system.

This makes the reporting module important. Reading U0122 from a lighting controller does not itself prove the DSC is completely inoperative; it establishes that this receiver lacks the expected CAN message. The communication relationship must be investigated through the correct network procedure.

## Avoid replacing the visible symptom

Mazda lists the CAN line between DSC and the auto-leveling module and refers diagnosis to its multiplex communication flow. The DTC page provides no actuator position test, message-timeout value or headlamp replacement rule.

Keep the complete :87 code and other module records before resetting the system. A broader scan can preserve the distinction between a sender-side problem and a path or receiver problem, while the vehicle wiring information establishes the actual topology. This explanation is limited to the source's non-hybrid branch. Brake-network and headlamp-leveling work should follow the appropriate workshop procedures; restored movement alone does not document why communication was lost.

Scope: Mazda3 01/2019 onward manual d9n1-1a-22d_ver10, in the controller and equipment variant named by the source. Confirm vehicle applicability before using its diagnostic path.

# U0231: Rain and light functions share the sensor behind this code

SAIC's U0231:87 concerns the rain/light sensor, which supplies information for automatic wiping and automatic lighting. The source describes optical rain detection at the windscreen and ambient-light sensing as related inputs provided by the same assembly.

## The code monitors messages, not rainfall accuracy

With ignition on and LIN2 communication normal, the BCM sets U0231 if the expected sensor frame does not arrive within two seconds. That is a communication criterion. It does not by itself establish that windscreen contamination, rain intensity or optical calibration caused the problem.

The documented response is use of a default signal value. The page does not guarantee a particular wiper speed or headlamp state after the fault, so those behaviors should be recorded as observed symptoms rather than asserted as universal consequences.

## Follow the sensor's actual network path

The procedure checks the sensor–BCM harness and connection before assessing the sensor and BCM. This preserves a wiring explanation alongside the possibility of a failed sensor assembly. The normal-LIN2 precondition also makes broader network records relevant to interpretation.

Recovery requires one hundred consecutive corresponding frames; history ages after forty failure-free power cycles. A technician should confirm that the expected messages remain available after a supported repair. Replacing a windscreen or sensor solely because automatic wiping behaves oddly is not supported by the code, and one successful automatic-light response is not complete communication verification.

This interpretation is limited to the cited MG4 UK manual revision; it does not establish applicability to every MG4 build or another manufacturer.

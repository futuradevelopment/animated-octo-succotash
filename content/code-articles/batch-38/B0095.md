# B0095: The right-front impact-sensor code has four distinct meanings

B0095 is the right frontal restraint-sensor family. SAIC's SDM page identifies the right-front impact sensor and defines :49 as an internal electronic fault, :56 as a sensor-type mismatch, :86 as invalid transmitted data, and :87 as lost communication.

## Data validity differs from communication availability

For :86, the controller detects sensor deviation or acceleration information outside its expected range. For :87, it detects short-to-supply, short-to-ground or communication failure within the stated 200-millisecond observation. These variants should not be merged into a general claim that the sensor has disappeared.

The sensor supplies acceleration information for the SDM's deployment calculation. This code is a diagnostic assessment of that input; it is not a crash-severity measurement that an owner can use to judge whether airbags should have deployed.

## Scope the repair to supported evidence

The procedure assesses the right-front sensor connection path, the sensor and the SDM. The configuration paragraph and deployment-response wording contain awkward duplicated language, so this article does not derive a detailed airbag-availability promise from them. The warning indicator and the need for qualified diagnosis remain clear.

History aging is separate from restoration of the sensor signal. A technician should retain the complete suffix and related restraint records, confirm correct sensor identity and determine whether the fault is electrical, internal or data-related. Do not test an impact sensor by striking it, probing SRS connections or improvising a substitution.

This interpretation is limited to the cited MG4 UK manual revision; it does not establish applicability to every MG4 build or another manufacturer.

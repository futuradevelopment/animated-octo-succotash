# U0223: The front-passenger window motor is a communicating node

SAIC assigns U0223:87 to the front-passenger window motor. The BCM communicates with the front window motors over LIN, and this code sets when the expected front-passenger motor frame is not received within the defined interval. The page does not supply a numeric timeout.

## A communication failure is not a jam diagnosis

The source identifies loss of window-regulator function and use of a default signal value as responses. A window that does not move may therefore be disabled by the control strategy. Its lack of movement alone does not prove that the regulator mechanism is mechanically stuck.

The listed alternatives are the relevant harness or connection, the motor and the BCM. The motor in this description is also a communication participant, so a parts decision requires more than confirming that the glass remains stationary.

## Keep the door identity and network context

The shared procedure covers four window positions but gives each its own code. For U0223 the target remains front passenger. It checks that motor's connection path before the motor and BCM branches, with ignition on and LIN1 operating normally as monitor conditions.

Recovery needs one hundred consecutive frames; history follows forty failure-free power cycles. A technician should compare the complete window-code pattern before deciding whether a fault is local or shared, then verify the appropriate message path. The source does not authorize forcing the glass, bypassing controls or replacing a regulator solely from U0223.

This interpretation is limited to the cited MG4 UK manual revision; it does not establish applicability to every MG4 build or another manufacturer.

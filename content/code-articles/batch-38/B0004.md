# B0004: The knee-airbag circuit and its failure-type suffix

Mazda B0004 covers the driver-side knee airbag in this SAS control-module procedure. The complete suffix separates shorts to ground or supply, an open or high-resistance path, low resistance, and a short involving another airbag circuit. The base code alone cannot identify which condition was detected.

## The knee-airbag connection is a specific diagnostic location

The source starts with the knee-airbag connector and considers deployment wiring, the module and the SAS controller. Unlike a steering-wheel inflator diagnosis, this page does not make the clock spring the named possible cause. Borrowing a familiar steering-wheel-airbag repair from another code would therefore miss the source's actual circuit scope.

The :19 variant is particularly different from an ordinary open circuit: Mazda associates it with contact between this deployment circuit and another airbag circuit. The technician needs the full restraint fault record to evaluate that distinction.

## Limits of a code explanation

The manual's electrical detection information is not a safe DIY measurement specification. Mazda explicitly warns that using detection conditions instead of its approved inspection procedure can cause injury or damage. Proper isolation and the correct equipment-specific SRS procedure are required before handling components.

A supported repair conclusion should explain whether a connector, harness or component finding was established and whether the same pending DTC returned during completion checks. The source supports those diagnostic distinctions; it does not make the knee-airbag module an automatic replacement merely because B0004 appears on a scan tool.

Scope: Mazda3 01/2019 onward manual d9n1-1a-22d_ver10, in the controller and equipment variant named by the source. Confirm vehicle applicability before using its diagnostic path.

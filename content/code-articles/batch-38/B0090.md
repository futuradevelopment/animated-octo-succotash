# B0090: A left-front impact-sensor fault is more than one failure mode

The cited SAIC SDM table assigns B0090 to the left-front impact sensor. Its :49 variant is an internal electronic fault; :56 concerns type mismatch; :86 identifies invalid transmitted data; and :87 concerns communication loss. Keeping the suffix is essential before discussing a repair.

## A sensor can communicate and still provide invalid data

The :86 description includes sensor deviation and acceleration values judged too high or low. The :87 description instead includes short or communication failures observed within 200 milliseconds. This difference changes whether the evidence concerns message content or availability.

The source locates the front impact sensor on the front bumper bracket and explains that it sends acceleration information to the SDM. That location is application-specific and is not a direction to remove a sensor or bumper from this overview.

## Evaluate the path before the part

The workshop procedure considers harness and connector condition before the left-front sensor and the SDM. It therefore supports more than one possible cause. The source's type-mismatch wording is internally repetitive, so an exact configuration-state algorithm is not inferred from it.

A qualified SRS technician should preserve the code, confirm the correct sensor application and distinguish current failure from historical aging. The forty-cycle history rule is not a repair method or a reason to defer a restraint warning. No direct sensor probing, impact simulation or airbag-availability assurance is provided here.

This interpretation is limited to the cited MG4 UK manual revision; it does not establish applicability to every MG4 build or another manufacturer.

# U0328: A steering-angle error signal received by Mazda's BCM

In Mazda's BCM procedure, U0328:82 means an error signal has been received over CAN from the steering-angle sensor. The generic software-incompatibility title should not be interpreted as proof that the sensor merely needs a reset or a firmware update.

## Message content and communication loss are different

The stated condition is receipt of an error message. The page's possible causes are the steering-angle sensor and the BCM; the recurrence branch also requires CAN diagnosis. A generic lost-communication explanation would discard the particular evidence this monitor reports.

The source does not give a steering-angle offset limit, calibration position or learning procedure for this code. Those values cannot be inferred from the sensor's name. Any calibration decision needs the applicable vehicle service information and the actual fault findings.

## How the diagnosis remains conditional

Mazda checks whether the pending code repeats, assesses the network where directed and follows the sensor-related branch only under the stated conditions. If the error continues after the prescribed work, the BCM remains a later possibility. Other DTCs are checked at completion.

The useful repair evidence is therefore the full :82 record, repeatability and the reason the sender or receiver was implicated. A steering-angle signal is used by safety-related vehicle systems, so physical inspection and verification should remain with qualified personnel. Turning the steering wheel or clearing memory without the specified procedure is not proof that this error-status condition has been corrected.

Scope: Mazda3 01/2019 onward manual d9n1-1a-22d_ver10, in the controller and equipment variant named by the source. Confirm vehicle applicability before using its diagnostic path.

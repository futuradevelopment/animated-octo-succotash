# C0614: The right parking-brake actuator's internal control check

The generic C0614 title says right park-brake actuator stuck on. SAIC's cited IBS procedure assigns the :49 variant to an internal right-actuator control-circuit failure. The source-specific detection is a control mismatch, so the generic title must not be treated as a verified mechanical condition.

## What the controller compares

The monitor runs when the electronic parking brake is applied or released. It uses redundant current and voltage observations during activation and also checks for internal-component faults during passive testing. These are controller observations of actuator control, not a direct statement that the caliper cannot release.

The manual groups this code with other parking-brake actuator faults for disabling two named control functions. It does not provide a safe-driving conclusion, and this article does not expand those abbreviations into an unsupported effect list.

## The shared diagnostic path still needs evidence

The associated procedure checks related circuits and the motor before considering IBS software and hardware. A motor or harness problem remains an alternative to an internal control-unit fault. The code's :49 suffix and the right-hand location should be preserved throughout that assessment.

Parking-brake actuation and electrical testing belong in a qualified workshop using the complete procedure. Do not energize an actuator manually or force a release based on this explanation. Verification must establish normal actuator behavior and the correct diagnostic status rather than relying on the broad stuck-on catalog wording.

This interpretation is limited to the cited MG4 UK manual revision; it does not establish applicability to every MG4 build or another manufacturer.

# C0077: Check actual cold tire pressure before blaming the BCM

C0077:00 in the Mazda BCM indicates detected low tire pressure. Unlike a communication or sensor-circuit fault, this page starts with the possibility that the monitored physical condition is real. The source also lists the BCM as a possible cause, but that does not make an electronic failure the first conclusion.

## The pressure comparison must use the right reference

Mazda directs inspection with the tires cold and comparison against the applicable wheel-and-tire specification. The DTC page does not supply one pressure value for every wheel size or vehicle configuration. A universal number taken from a generic code explanation would therefore be inappropriate.

The procedure first checks whether the pending DTC returns, then assesses actual pressure. If pressure is outside specification, the physical condition is corrected before the completion check. This order separates a current low-pressure condition from a historical record or a persistent reporting problem.

## What clearing the code cannot establish

Erasing memory does not add air or identify why pressure was low. Equally, a returning code after verified correct pressure does not by itself prove that a particular wheel sensor is faulty; the source's later path includes CAN diagnosis and reassessment before the BCM decision.

Keep the measured cold pressures, the vehicle's specified values and the complete fault record together. Any tire damage or recurring loss requires appropriate tire service rather than repeated code clearing. This article explains the documented BCM decision path without inventing an inflation specification or promising that the vehicle is safe to drive.

Scope: Mazda3 01/2019 onward manual d9n1-1a-22d_ver10, in the controller and equipment variant named by the source. Confirm vehicle applicability before using its diagnostic path.

# C0046: Pressure-sensor temperature channels can set C0046 in SAIC's IBS

The generic C0046 title refers to brake pressure sensors A and B. In SAIC's IBS procedure, C0046:26 and :27 concern the pressure sensor's T1/T2 channels. The page gives temperature-coded limits: the low variant is below minus 64 degrees C, and the high variant is above 191 degrees C.

## Do not read these numbers as hydraulic pressure limits

The same procedure contains P1/P2 pressure values for other codes. C0046 uses T1/T2 instead. Mixing those rows would convert a temperature-channel monitor into an invented brake-pressure specification.

The monitor assumes normal sensor voltage. Thus the specified detection is not simply a general low vehicle-battery condition. The source says functions other than EBD, ABS and EDC are disabled for C0046, but that listed response is not a declaration that driving remains safe.

## What the source can support

The common diagnostic section checks IBS software status and the unit itself, with broader sensor and connection causes discussed for the group. It does not provide an external temperature-sensor replacement procedure for C0046 alone.

A qualified brake technician should retain which suffix occurred and confirm the relevant T1/T2 information before interpreting any component claim. This article gives the monitor's coding distinction, not a pin-probing method or a hydraulic test. Repair verification must use the applicable unit procedure and its recovery criteria, not a pressure value borrowed from an adjacent DTC.

This interpretation is limited to the cited MG4 UK manual revision; it does not establish applicability to every MG4 build or another manufacturer.

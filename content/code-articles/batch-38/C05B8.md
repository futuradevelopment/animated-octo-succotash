# C05B8: A motor-position signal fault during a brake-system test

C05B8 is cataloged as brake-booster motor A position-sensor supply circuit/open. SAIC's cited :02 row instead names a system-execution failure in a feedline and flush test, and its setting statement identifies an incorrect motor-position sensor signal. This narrower source must not be rewritten as proof of an open supply wire.

## Test context changes the interpretation

The group runs after system initialization. For this code, the specified recovery involves a successful ART-M recovery test, after which the relevant functions and driver warning can recover. A generic ignition-cycle reset is not the documented verification criterion.

The source lists EBD and ABS as disabled for the group containing C05B8. Those are meaningful control consequences, but they do not reveal whether the originating fault is a sensor signal, motor problem or control-unit issue on a particular vehicle.

## Keep the diagnostic sequence conditional

The shared procedure considers circuit and connection condition, then the motor, then software status and the IBS unit. This ordering retains alternatives that a supply-circuit title alone might obscure. The exact :02 failure type and the service-test circumstances are useful repair-history details.

The page does not publish a position-sensor supply voltage, terminal assignment or manual actuation method. A qualified brake workshop must identify the applicable test and perform it under the full safety procedure. This overview explains the reported test failure without instructing hydraulic operation, energized probing or a speculative component replacement.

This interpretation is limited to the cited MG4 UK manual revision; it does not establish applicability to every MG4 build or another manufacturer.

# U0292: The BMS is missing secondary-axle motor-controller data

The catalog calls U0292 lost communication with drive motor control module B. In the cited SAIC BMS table, U0292:87 identifies the secondary-axle motor controller, abbreviated SAC. The BMS sets it when the expected SAC frame is absent for two seconds.

## Confirm this implementation before using the code

Other sections of the compilation use different motor-controller names for U0292. This article uses only the BMS/SAC procedure on physical pages 636–637. It does not establish that every MG4 build has a secondary driven axle.

The monitor requires ignition on, normal battery voltage and absence of the specified U0073:88 and U0074:88 bus-off codes. Those conditions make a broader bus failure diagnostically different from a missing SAC message on an otherwise enabled network.

## The receiving controller is not automatically defective

The source considers communication harness and connections, the relevant motor controller and BMS/EDM causes. Its sequence starts with network integrity before module assessment. Recovery requires SAC frames for 200 milliseconds, while history clears only after a separate sequence of failure-free cycles.

The useful evidence is the full :87 record, vehicle equipment and associated network or motor-controller faults. A communication DTC does not authorize opening the battery or testing energized motor circuits. A qualified high-voltage workshop should follow the complete service procedure and verify the message path after a supported repair.

This interpretation is limited to the cited MG4 UK manual revision; it does not establish applicability to every MG4 build or another manufacturer.

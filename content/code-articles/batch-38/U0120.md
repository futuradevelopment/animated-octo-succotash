# U0120: How Mazda times a lost starter-generator message

On the documented SKYACTIV-G Mazda M Hybrid system, U0120:00 concerns communication between the PCM and the integrated starter-generator, or ISG. Mazda specifies a communication error lasting at least five seconds after the ignition-on precondition has been satisfied for 1.5 seconds.

## The response depends on when communication is lost

The fault inhibits automatic engine stop through i-stop. If detected before hybrid operation, the source says the vehicle's 12-volt electrical loads are supplied by the battery. If detected during or after hybrid operation, motor assistance is inhibited. This timing explains why the same communication code can accompany different operating circumstances.

The code is not a direct measurement of generator output or belt condition. The listed possibilities include the communication path, MAIN and electric variable valve-timing relays, ISG connections and supply, the ISG itself and the PCM.

## Why power checks precede a generator conclusion

Mazda's procedure considers other PCM codes and the relevant relays before checking the ISG connection and power-supply path. A module without its required supply cannot communicate normally, so loss of messages does not uniquely identify a failed communication transceiver.

Repair verification checks recurrence under the prescribed diagnostic conditions and includes CAN assessment if necessary. Hybrid electrical work requires the appropriate workshop qualification and safety procedure. This overview supplies no live-circuit probing or generator-disassembly instructions; the supported conclusion is a timed loss of communication, with the failed part still to be established.

Scope: Mazda3 01/2019 onward manual d9n1-1a-22d_ver10, in the controller and equipment variant named by the source. Confirm vehicle applicability before using its diagnostic path.

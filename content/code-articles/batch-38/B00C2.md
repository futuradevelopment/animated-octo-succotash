# B00C2: The occupant-classification C circuit must stay distinct from the general RCM report

The documented 2011 Ford Flex uses B00C2 for occupant-classification weight-sensor bolt C and its circuit. The occupant classification module records the detailed code, while the RCM can store B00A0:09 after receiving the fault message. The two controllers therefore provide different levels of the same diagnostic evidence.

## The circuit identity matters

Sensor C has its own fault family; a result from sensor A or B is not a substitute. The :12, :13 and :1A suffixes distinguish a high signal, an open/high-resistance indication and a below-threshold resistance indication. Ford notes that the high-signal variant can also result from an open return.

This prevents a literal short-to-battery description from becoming an unsupported wiring conclusion. It also makes the exact sensor identity useful after seat or harness work.

## Verification requires more than a warning reset

The procedure first distinguishes on-demand faults from continuous-memory-only records, then evaluates the seat wiring and connections. Completion includes the occupant-classification and restraints controllers, so clearing only the broader RCM code loses part of the evidence.

Ford expressly says the three-wire weight sensors cannot be tested as components with a multimeter. A qualified SRS technician must use the prescribed diagnostic method and correct component application. This explanation provides no sensor probing, simulated load or configuration workaround. The repair conclusion should identify the original C-circuit defect and demonstrate that the complete restraint check passes afterward.

Scope: 2011 Ford Flex FWD V6-3.5L; Pinpoint Test AA: DTCs B00C2:12, B00C2:13 and B00C2:1A. The cited failure types and controller logic should not be generalized to other Ford vehicles without the matching service procedure.

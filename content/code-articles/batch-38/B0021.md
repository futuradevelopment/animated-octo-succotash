# B0021: The left-curtain circuit needs the complete failure type

SAIC's SDM table identifies B0021 as the left curtain-airbag deployment path. The curtain assembly is connected through the body harness. The source distinguishes short-to-ground (:11), short-to-battery (:12), low resistance (:1A), high resistance (:1B) and incompatible configuration (:56).

## The controller is monitoring a circuit, not predicting crash protection

An electrical fault can originate in the harness or connection as well as the curtain assembly or SDM. The procedure evaluates those possibilities in sequence. The code by itself does not show that an airbag has fired, nor establish which restraints would deploy in a future collision.

Configuration is checked against the detected deployment circuit within six seconds after power-on. That is different from an isolated resistance measurement. The manual's :56 clearing entry does not provide an ordinary recovery condition, so repeated resets should not be presented as a configuration remedy.

## Keep interpretation separate from dangerous testing

The source supplies resistance regions as part of the controller's detection description. They are not instructions to place a meter across a curtain-airbag connector. Likewise, a stated component location is not authorization to remove trim or handle the deployment unit.

A qualified restraint technician should retain the suffix, original fault status and relevant repair history, then verify the supported defect under the full SRS procedure. Historical aging after failure-free cycles is a memory-management rule. It does not replace correcting the cause or proving out the complete restraint system after the repair.

This interpretation is limited to the cited MG4 UK manual revision; it does not establish applicability to every MG4 build or another manufacturer.

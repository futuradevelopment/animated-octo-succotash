# C057E: The brake-control bridge temperature signal must be plausible

C057E belongs to the brake-booster temperature-sensor correlation family. In SAIC's IBS chapter, the :64 variant identifies an implausible bridge-temperature sensor reading. The documented monitor evaluates whether the reported temperature makes sense; the page does not provide a universal over-temperature threshold for this code.

## Plausibility is different from overheating

A temperature value judged irrational is not automatically evidence that the motor or brake assembly actually overheated. The nearby table has a separate over-temperature code for bridge, capacitor and motor conditions. Borrowing that code's recovery temperatures would misstate C057E.

For C057E:64, the source requires two consecutive successful monitoring cycles for recovery. A single normal-looking reading after a restart therefore does not reproduce the complete documented recovery requirement. This statement describes the controller logic, not a request to conduct driving cycles with a brake fault.

## What diagnosis can conclude

The shared procedure covers related circuits, motor condition, IBS software and the control unit. Those group-level checks do not isolate the bridge-temperature sensor as a separately replaceable part. The exact equipment and applicable service information must determine that question.

The source lists no functional disablement specifically for C057E, but that does not establish safe operation or rule out accompanying faults. A qualified workshop should retain the full :64 record, compare related temperature or motor-control codes and verify successful monitoring after the supported repair. No energized bridge-circuit testing is provided here.

This interpretation is limited to the cited MG4 UK manual revision; it does not establish applicability to every MG4 build or another manufacturer.

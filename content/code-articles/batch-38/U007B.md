# U007B: A ten-second bus-off finding on Mazda's CAN No.4

U007B is generically called control-module communication bus I off. Mazda's VCM procedure maps U007B:88 to CAN bus No.4 and specifies that the bus-off condition lasts ten seconds. That manufacturer-specific segment name is more useful than assuming the catalog letter is a physical wiring label.

## The source includes both network and module causes

The listed possibilities are the CAN No.4 line, modules connected to it, the vehicle control module and the BCM. Mazda notes that the VCM is built into the body control module. This integration matters when discussing module identity and replacement: the two names do not necessarily describe two separately replaceable boxes.

The code does not identify which connected module initiated the network problem. A bus-off report is evidence of a segment-level communication failure, not a complete component diagnosis.

## What should guide the next step

Mazda sends this DTC directly to its multiplex/CAN diagnostic flow. The page provides neither terminal values nor an isolation order, and it does not define the fail-safe behavior locally. Those details must be obtained from the referenced vehicle-specific information.

Preserving the complete network scan before resets helps retain which relationships were affected. A technician can then use the actual topology and factory procedure to evaluate the line and participating modules. Replacing the BCM simply because it contains the reporting VCM would skip the other documented causes and would not, by itself, establish that the communication fault has been repaired.

Scope: Mazda3 01/2019 onward manual d9n1-1a-22d_ver10, in the controller and equipment variant named by the source. Confirm vehicle applicability before using its diagnostic path.

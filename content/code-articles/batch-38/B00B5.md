# B00B5: The seat-track sensor is part of Mazda's restraint strategy

Mazda's B00B5 procedure concerns the driver seat-track position sensor used by the SAS restraint controller. The source identifies this sensor as a distinguishing feature of the two-step deployment system; the standard deployment system does not have it. Vehicle equipment is therefore part of interpreting the code.

## The fault is about the sensor circuit

The :11, :12 and :13 suffixes describe a ground short, supply short and open circuit respectively. The :1D version concerns current outside the expected range. These findings concern the electrical information reaching the controller, not a statement that the seat mechanism itself is jammed.

Mazda's first diagnostic decision uses the D_SP_S_FLT data item. Its result separates an indicated sensor-circuit problem from the controller assessment branch. This is more specific than looking only at whether the seat can slide or whether a generic scanner shows a seat position.

## What the technician must distinguish

The source includes the sensor connection, signal circuit, sensor and SAS control module among possible causes. Its later verification checks for a returning pending DTC after the prescribed work. An observation that the connector is present is not the same as establishing that the monitored circuit is healthy.

Because this input belongs to restraint deployment control, connector handling and circuit diagnosis require the SRS service procedure. This explanation does not provide pin measurements or a bypass. Preserve the complete suffix and equipment configuration for a qualified technician rather than treating B00B5 as an ordinary power-seat fault.

Scope: Mazda3 01/2019 onward manual d9n1-1a-22d_ver10, in the controller and equipment variant named by the source. Confirm vehicle applicability before using its diagnostic path.

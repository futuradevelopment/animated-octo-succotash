# C0518: Mazda's left-front wheel-speed sensor type check

The generic label for C0518 is a mechanical left-front wheel-speed sensor fault. Mazda's C0518:95 DSC procedure is more specific: the controller detects a sensor type different from the one expected for the vehicle's equipment. This is an equipment-compatibility finding, not a published air-gap or wheel-bearing test.

## Why recent parts history matters

Mazda lists an unsuitable left-front ABS sensor among the possible causes. If the fault appeared after sensor work, confirming the installed part against the exact vehicle specification is therefore directly relevant. Matching a connector or obtaining a wheel-speed reading is not the same as proving that the sensor type satisfies this check.

The source also lists the DSC hydraulic unit/control module. That alternative prevents the detected mismatch from being treated as conclusive proof that the newly installed sensor is wrong.

## The factory path is based on repeatability

The procedure checks whether the same pending DTC returns. On recurrence it introduces CAN diagnosis before following the sensor repair branch; further recurrence after the prescribed work can lead to the controller branch. The final check also looks for other DTCs.

The distinguishing information to preserve is the complete :95 suffix and left-front location. A generic mechanical-code explanation that immediately proposes cleaning a tone ring misses the condition Mazda actually documents here. Inspection and verification belong with a qualified brake-system technician, using the correct equipment variant and factory procedure rather than an assumed universal sensor specification.

Scope: Mazda3 01/2019 onward manual d9n1-1a-22d_ver10, in the controller and equipment variant named by the source. Confirm vehicle applicability before using its diagnostic path.

# C0032: The left-front wheel-speed supply code has a specific electrical subtype

C0032 is the left-front wheel-speed sensor supply family. SAIC's :14 table entry describes parasitic resistance to ground on the left-front sensor signal line. This identifies an electrical-path problem within the wheel-speed system rather than a measured speed disagreement among wheels.

## Why the complete code matters

The same source gives other codes for a missing signal, mechanical error, erratic data and an incorrect sensor type. Applying one of those diagnoses to C0032 would discard the distinction made by the primary table. A plausible speed reading during one observation also does not prove the unwanted electrical path is absent intermittently.

The setting paragraph specifies a 140-millisecond confirmation and uses the phrase ground wire, whereas the table says signal line. That wording discrepancy prevents a reliable terminal-level instruction from this excerpt. It must be resolved against the exact circuit information before testing.

## A shared procedure with a corner-specific target

SAIC uses a common diagnostic sequence for this wheel-speed group: connection and harness evidence, the corresponding sensor, then IBS software and hardware. The affected corner here remains left front. The group lists ABS as disabled, and the electrical subtype has diagnostic-command clearing provisions.

This is a monitored-circuit explanation for a technician, not a recommendation to drive until a wheel-speed comparison changes. Preserve the :14 suffix, original module record and relevant electrical history, then verify the supported repair under the factory brake-system procedure.

This interpretation is limited to the cited MG4 UK manual revision; it does not establish applicability to every MG4 build or another manufacturer.

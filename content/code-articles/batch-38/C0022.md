# C0022: A solenoid-family code that Mazda uses for calibration mismatch

C0022 is broadly cataloged as a brake-booster solenoid code. The cited Mazda DSC procedure defines C0022:56 much more specifically: the hydraulic control module finds that inlet-solenoid calibration data in internal memory disagree with the data initialized when ignition is switched on.

## The relevant comparison is internal

This is not presented as an external solenoid-wire continuity monitor. The page lists an internal DSC hydraulic unit/control module malfunction as the possible cause and marks both wiring and connector diagrams as not applicable to this procedure. That matters when evaluating a generic scan-tool description that suggests simply checking a brake-booster solenoid.

The disagreement concerns two calibration representations inside the control strategy. A code alone does not reveal which value is wrong, and the source provides no customer adjustment or relearning shortcut to correct it.

## What the prescribed decision establishes

Mazda's short diagnostic path uses repeatability: after the recorded fault is cleared through the proper diagnostic procedure, the workshop checks for the same pending code. A repeat occurrence leads to the specified unit-level repair decision. If it does not recur, the procedure continues by checking for other DTCs.

This is a source-scoped monitor explanation, not a general rule that any C0022 requires a hydraulic unit. Confirm the :56 suffix, the reporting DSC module and the applicable vehicle equipment first. Brake-unit work requires the factory safety and completion procedures; guessing from the generic solenoid name bypasses the actual calibration finding.

Scope: Mazda3 01/2019 onward manual d9n1-1a-22d_ver10, in the controller and equipment variant named by the source. Confirm vehicle applicability before using its diagnostic path.

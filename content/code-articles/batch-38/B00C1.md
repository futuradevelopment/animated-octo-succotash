# B00C1: Sensor B can explain a general occupant-classification warning

Ford's cited Flex procedure assigns B00C1 to occupant-classification weight-sensor bolt B. The occupant classification module reports this specific fault to the restraints controller, which can store the broader B00A0:09 record. Reading only the RCM can therefore omit the sensor-level evidence.

## A complete suffix prevents a misleading diagnosis

The :12 variant concerns a signal judged too high, and Ford notes that an open return can cause it. The :13 variant concerns an open/high-resistance indication; :1A concerns resistance below the monitor's threshold. The same sensor name consequently covers different electrical observations.

The source does not authorize direct multimeter testing of the three-wire sensor itself. The diagnostic values explain what the module evaluates, not how to improvise a measurement at a restraint connector.

## Why a memory-only code is handled differently

Ford's first decision is whether the DTC returns during the on-demand self-test. A continuous-memory-only record is treated as intermittent. The later procedure cautions against installing new SRS components when the original fault has become intermittent without the required supporting evidence.

The technician must evaluate the B-sensor connection path, preserve the original status and check both OCSM and RCM at completion. This is qualified restraint-system work. A general airbag warning or a physically similar replacement sensor does not establish the correct repair, and no probing or bypass method is supplied here.

Scope: 2011 Ford Flex FWD V6-3.5L; Pinpoint Test Z: DTCs B00C1:12, B00C1:13 and B00C1:1A. The cited failure types and controller logic should not be generalized to other Ford vehicles without the matching service procedure.

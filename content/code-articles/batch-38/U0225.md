# U0225: The right-rear window-motor communication record

U0225:87 is the right-rear window-motor entry in SAIC's shared BCM window procedure. Its setting condition is the absence of that motor's specified data frame within the configured period. The source gives the node identity but no numerical timeout.

## Keep a rear-right fault separate from other doors

The same table assigns different codes to the other three windows. The shared diagnostic sequence does not make their parts or wiring interchangeable. A repair assessment should identify the right-rear path explicitly and retain the full :87 failure type.

The listed conditions include ignition on and normal LIN1 communication. The source's short subsystem description focuses on the front motors, so this article does not use it to invent a rear-door connector route. Exact wiring must be confirmed from the applicable diagram.

## Disabled motion does not isolate the failed part

The procedure lists window-regulator disablement and default signal use as control responses. Missing movement can therefore be a consequence of communication protection. Harness or connector trouble, the relevant motor and the BCM are all supported possibilities.

The factory path checks those categories before a final module decision. Recovery requires one hundred consecutive corresponding frames, whereas history follows a separate forty-power-cycle rule. A technician should verify the right-rear node's communication after the actual defect is corrected. A brief return of glass movement is useful observation, but it is not an explanation of the original network interruption.

This interpretation is limited to the cited MG4 UK manual revision; it does not establish applicability to every MG4 build or another manufacturer.

# B0002: Why the second driver-airbag inflator needs its own fault record

B0002 in this Mazda SAS procedure refers to driver-side airbag inflator No.2. It must remain distinct from the first-inflator circuit, even though both belong to the steering-wheel airbag assembly. The manual's equipment notes distinguish the two-step deployment system using the seat-track position sensor.

## Preserve the failure type

The supported suffixes identify ground short (:11), power short (:12), open or excessive resistance (:13), a short to another airbag circuit (:19), or low resistance (:1A). These findings cannot be safely collapsed into a general statement that the airbag has failed.

The possible-cause list includes the clock spring, its connector, deployment wiring, the No.2 inflator connection, the airbag module and the SAS controller. Because the source covers an entire deployment path, the component named in a scan-tool label is not necessarily the failed component.

## What a useful repair explanation should show

A workshop diagnosis should retain which circuit was involved, which suffix returned and what evidence distinguished wiring or connection trouble from an assembly fault. Mazda's procedure checks those categories before its final recurrence verification. A successful clear without the prescribed follow-up is not the same as confirming a repair.

The manual warns that detection-condition values must not be used as an improvised test procedure. Airbag circuits are pyrotechnic systems: leave connector handling, circuit isolation and component decisions to a qualified SRS technician. This overview deliberately provides no inflator probing or substitute-load instructions.

Scope: Mazda3 01/2019 onward manual d9n1-1a-22d_ver10, in the controller and equipment variant named by the source. Confirm vehicle applicability before using its diagnostic path.

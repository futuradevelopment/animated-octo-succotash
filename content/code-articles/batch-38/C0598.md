# C0598: Several service-test failures share the brake-module-B code

C0598 broadly names brake-system control-module B performance. SAIC's IBS table separates four useful variants: :02 is a service-test execution failure, :07 a mechanical test failure, :73 a front outlet actuator stuck closed, and :97 an incomplete pressure-reduction test.

## The test result needs its failure type

The :02 condition concerns a pressure-buildup test failing or timing out. For :07, the source identifies a stuck relief valve or an obstructed supply path during the test. The :73 monitor evaluates an isolation valve during pressure recovery. The :97 variant concerns a test that has not completed across the specified ignition-cycle circumstances.

An incomplete test and a demonstrated stuck valve are different evidence. Replacing the same assembly for both without establishing why the test failed would discard the manual's distinctions.

## Configuration and supply remain part of the investigation

The shared diagnostic path considers completed controller configuration, software status, battery condition and related circuits before its IBS decision. The source's wording for the test alternates between feeder/flush and flash, so this article does not infer an undocumented service command from that label.

The exact code suffix and the operation being performed when it appeared are essential workshop records. Brake-system test execution requires qualified personnel and the full service instructions. No hydraulic activation sequence is provided here. Verification must demonstrate the required test outcome for the specific variant, not merely erase the generic C0598 record.

This interpretation is limited to the cited MG4 UK manual revision; it does not establish applicability to every MG4 build or another manufacturer.

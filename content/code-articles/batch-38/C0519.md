# C0519: The right-front sensor can be the wrong type without a simple open circuit

For the Mazda DSC system covered by this source, C0519:95 means the right-front ABS wheel-speed sensor type does not match the controller's expected type. The general C0519 catalog heading says mechanical wheel-speed sensor fault, but it does not capture this application's equipment check.

## What the code does and does not establish

The documented alternatives are a right-front sensor unsuitable for the vehicle equipment or a DSC hydraulic unit/control module malfunction. The page does not give a resistance value, supply-voltage threshold or damaged-tone-wheel criterion. It would therefore be misleading to turn this code into one of those tests.

A useful interpretation is to retain the part identity and repair history alongside the full code. Recent replacement is relevant because the source explicitly allows an incorrect sensor type. It is not evidence that every sensor fitted shortly before a fault is defective.

## Keep the repair decision conditional

Mazda first establishes whether the pending code repeats. The subsequent branch includes CAN diagnosis and a sensor-related repair decision. If the condition persists through the prescribed verification, the controller remains a possibility; replacing successive sensors without confirming specification does not resolve that distinction.

This code can also appear in a broader vehicle fault record, so the reporting module matters as much as the suffix. The cited explanation applies to the DSC's :95 procedure. Brake-system checks and any resulting component work should be performed with the matching Mazda service information and appropriate workshop safeguards.

Scope: Mazda3 01/2019 onward manual d9n1-1a-22d_ver10, in the controller and equipment variant named by the source. Confirm vehicle applicability before using its diagnostic path.

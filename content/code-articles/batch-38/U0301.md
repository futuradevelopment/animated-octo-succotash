# U0301: Mazda's BCM can report an error received from the PCM

U0301 is cataloged as software incompatibility with the ECM or PCM. The Mazda BCM procedure for U0301:82 describes receipt of a CAN error signal from the PCM. It does not say that every occurrence requires new software or an engine-controller replacement.

## An error message is not the same as no message

The BCM has received information identifying an error. Mazda consequently lists stored PCM DTCs, PCM malfunction and BCM malfunction as the relevant possibilities. The first useful distinction is whether the PCM itself has a more specific fault record.

After confirming that the BCM's pending code repeats, the factory procedure reads the PCM and follows any applicable powertrain DTC. The source links different engine families; those references provide diagnostic routing, not proof that all engine variants have an identical underlying fault.

## A conditional controller decision

If no originating code explains the report and it continues to recur, the procedure includes CAN diagnosis before its controller-related branches. Subsequent verification still checks the BCM and other faults. A bare U0301 is therefore not adequate evidence for replacing both modules or applying speculative programming.

This explanation uses the BCM :82 page specifically. Another retrieved Mazda page under U0301 contains conflicting brake-temperature wording and is not used to infer that condition here. Preserve the full suffix and reporting module when selecting service information. A qualified technician should establish the original PCM evidence and verify that the receiving BCM no longer reports the error after the supported repair.

Scope: Mazda3 01/2019 onward manual d9n1-1a-22d_ver10, in the controller and equipment variant named by the source. Confirm vehicle applicability before using its diagnostic path.

# P2C15: Exhaust profile sensor A circuit high is judged with the driver off

P2C15 concerns the exhaust profile-position sensor A circuit being electrically high during an off command. The GM description classifies this as a short toward power. An on-state voltage, even if numerically similar, does not reproduce that command-to-signal contradiction.

## The off state defines the comparison

Controller-specific voltage limits represent impedance below 0.5 Ω toward controller power. The source does not supply a universal connector-voltage expectation, and the criterion is not a measurement of profile-pin extension.

The related low-circuit monitor P2C14 uses the output-on state. Keeping those command conditions separate prevents a static measurement from being used as evidence that both tests passed. Command transitions can contain the information a final snapshot lacks.

## Confirm the qualified sample pattern

Supply above 11 V, diagnostic enablement and ignition in crank or run are required. The monitor needs four failed reports out of five samples, with one-trip reporting listed independently. A solitary power-up excursion is not automatically equivalent to the recorded failure.

Preserve exhaust-channel A identity, off command and electrical status. The camshaft B label in the generic description refers to the exhaust system here; it must not be confused with sensor channel B. The table cannot identify the source of the unwanted power path or justify replacing a camshaft assembly. Localization needs the matching electrical procedure.

# U0613: Intake-air temperature sensor 2 and shared communication events

U0613 means lost communication with intake-air temperature sensor 2, bank 1 in the generic dictionary. Its appearance at the bottom of one GM source page is not merely an incidental reference: the complete row explicitly joins it to U0611, and the next page repeats that pairing for additional interface events.

## Read the complete event before assigning a sensor

The three shared paths concern the communication event and line-high or line-low events. They establish that U0613 participates in intake-temperature communication diagnostics. They do not identify a connector pin, demonstrate a particular sensor's physical position, or give a resistance value for a thermistor.

The source describes absent frames in its strategy column but describes wrong data length in the criteria column. That inconsistency remains unresolved. A line-high event name is therefore insufficient evidence to conclude that a specific wire is shorted to battery, just as a line-low name alone is insufficient to prove a short to ground.

## Gather evidence that can separate the paths

Keep the full scan-tool failure subtype and paired U0611 record, if present. Compare the communication flags with the validity of the temperature data. Confirm the installed system's definition of sensor 2 before testing a component selected only by its generic number.

The shared table uses an ignition-on enable context and two-trip reporting, with other basic conditions referenced elsewhere. It supplies no dependable timeout for these rows. A useful next diagnostic step is resolving interface status and sensor mapping with matching service information; replacing a temperature sensor or applying a neighboring row's time limit would skip those necessary distinctions.

# U0665: Bank 2 fuel-rail pressure sensor SENT signal loss

U0665 denotes lost communication with the bank 2 fuel-rail pressure sensor. The complete GM rows pair it with U101C and describe two SENT signal-loss paths. One detects loss with the signal line high; the second detects loss with the line low. Reading both pages prevents treating the code as a single unspecified pressure problem.

## Signal loss is distinct from incorrect pressure data

Each path uses a 0.5-second criterion, with one-trip behavior shown for the shared row. The high-level path requires the low-level loss condition to be false, while the low-level path requires the high-level condition to be false. This separates the interface's reported failure modes; it does not independently identify the damaged wire or component.

The neighboring P312B row evaluates raw pressure data outside its allowed range. Separate U13D2/U13D3 rows handle protocol errors while line-loss conditions are absent. Those distinctions matter: an implausible pressure value, malformed communication, and unavailable signaling are different diagnostic observations.

## Keep the source limits visible

The original table prints the enable condition “Ignition is on” as false, including German FALSE wording in some cells. That unusual enable remains unresolved and should not be rewritten as an ordinary key-on test. Other enable and inhibit tables also apply.

Collect the high/low failure subtype, paired U101C status, and whether bank 2 pressure data is valid. Confirm the bank and sensor wiring in the applicable service information. U0665 alone does not demonstrate low fuel pressure, justify replacing a pump, or call for opening a pressurized fuel connection.

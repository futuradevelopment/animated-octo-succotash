# P2B35: The intake profile circuit-high row contains conflicting command wording

P2B35 is the high electrical classification for the intake camshaft profile-actuator drive circuit. The GM strategy text describes detecting a short to power while the driver is off. However, the same row’s enable column says that the output is commanded on. Those statements cannot be silently combined into one unambiguous test instruction.

## Keep the conflict visible

The documented fault classification is an unintended power path, with controller-specific voltage thresholds representing low impedance toward controller power. The summary does not provide enough consistent command-state information to choose a universal waveform test from this row alone.

This limitation does not make the code a mechanical cam-timing diagnosis. It remains a driver-circuit classification, and a high electrical result should not be interpreted as excessive valve lift or an advanced camshaft position.

## Use the undisputed qualification information

The row requires supply above 11 V, ignition in crank or run and diagnostic enablement. Its sample rule is four failures out of five, with one-trip reporting. These facts distinguish an eligible repeated result from a solitary voltage observation.

Preserve the exact controller, actual command state and electrical fault subtype. Resolve the on/off wording with the matching service information before deciding what signal should be present at a connector. The code and this incomplete table do not identify a failed actuator, wire or controller for replacement.

# U010C: Turbo-control communication uses separate message timeouts

U010C concerns loss of expected messages from the turbocharger boost-control module in the documented GM network. The receiving controller evaluates message availability; it is not directly measuring boost pressure, actuator travel or turbocharger shaft condition.

## Identify which message failed to arrive

The source lists different timeouts for two messages: $099 exceeds ten seconds, while $499 exceeds 9.2 seconds. Those distinct timers show why a broad “module offline” interpretation can conceal useful message-level detail. The code does not require every possible turbo-related parameter to be absent.

The general enable conditions must mature for at least five seconds. The diagnostic also requires appropriate communication requests, normal transmission on the relevant bus and absence of that bus’s bus-off fault. A network that is deliberately asleep or already disabled is not the same situation as an eligible missing-message test.

## Preserve power mode and network context

Battery, ignition, cranking and accessory-mode qualifications differ across the described controller conditions. Do not replace those branches with a universal assumption that any key-on silence proves module failure.

Record the receiving module, missing message, power mode and related network faults. U010C does not locate a disconnected wire or prove that the turbo-control module itself is defective. A matching network and power-supply procedure is required before treating the communication result as a component or turbocharger replacement diagnosis.

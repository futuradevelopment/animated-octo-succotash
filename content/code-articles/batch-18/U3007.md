# U3007: Brake-controller input power B and redundant-supply faults

U3007 has the generic description control-module input power B circuit/open. The cited GM electronic brake controller assigns its input-power-2 code to several supply-monitoring functions. These include motor-test availability, hydraulic-valve supply, wheel-speed-sensor supply, and redundant-power operation. There is no single voltage threshold that explains every U3007 record.

## Distinguish a severe common drop from one weak feed

One hard-undervoltage path requires both UB_VR and UBB below 6.2 volts for 0.2 seconds. A different redundant-supply path detects UBVR below 6.2 volts while UBB stays above 9 volts, qualified for only 0.01 seconds. Those conditions describe materially different electrical situations.

Another hydraulic path uses a 9.6-volt threshold with alternative supply logic and a one-second duration. Motor-test and wheel-speed-sensor checks have their own initialization or test-status requirements. Borrowing the fastest duration or lowest voltage and applying it to the whole code would hide these distinctions.

## Read the failure detail before blaming a component

Keep the internal failure word, supply values, initialization state, and vehicle operating conditions with the scan report. The fast driving-related undervoltage path includes speed and cranking qualifications, whereas an initialization-only test concerns a different operating window. All listed paths require ignition on and use Type B, two-trip behavior.

The published internal names do not directly identify external connector terminals. Match UBVR and UBB to the vehicle's wiring before testing supply integrity. An intermittent supply event can be absent from a later resting-voltage measurement. U3007 alone neither proves an open circuit nor establishes that replacing the brake controller will correct the recorded condition.

# U062F: Coolant pump C missing its low-temperature-loop LIN response

U062F is lost communication with coolant pump C in the generic dictionary. The cited GM controller identifies the device more specifically as the low-temperature coolant-loop pump. That documented role is useful, but it does not establish where the pump is mounted on every vehicle carrying this code.

## The monitored quantity is response age

The expected LIN response is CWP_Rsp_25_C02. Failure occurs when it has not arrived for at least 2,500 milliseconds, while the diagnostic executes in a 500-millisecond loop. This is a communication timeout. It is not an underspeed limit, a commanded-current comparison, or a coolant-flow measurement.

Those distinctions prevent a common diagnostic shortcut: a missing response does not prove that the pump rotor has stopped. Equally, a communicating pump is not automatically delivering adequate circulation. Communication availability and pumping performance require separate evidence.

## Interpret the timeout in the right power state

The LIN channel must be enabled and initialized, and the pump slave must be configured as present. Additional conditions qualify for at least five seconds. The table requires battery voltage above 11 volts and provides different Run and Accessory branches, including controller shutdown status on the continuation page.

Record whether the problem affects only this response or several devices, along with the controller's power mode and pump communication status. Use the matching wiring and service procedure to establish which device the generic letter C denotes. The source lists Type B, two-trip behavior. A stored U062F alone does not justify substituting the shorter timeout or component identity of a different engine-coolant-pump code.

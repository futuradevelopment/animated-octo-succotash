# P015D: Bank 2 upstream oxygen sensor delayed lean-to-rich response

P015D reports delayed lean-to-rich response from bank 2, sensor 1 in the documented GM configuration without a wide-range air-fuel sensor. This monitor accompanies a downstream-sensor test that commands enrichment. Its result concerns the sensor's response to that controlled fuel change, rather than a universal requirement that the signal always remain rich.

## Three observations can establish a failed response

The primary method normalizes the transition delay for operating conditions and filters it using an exponentially weighted moving average. Its failure threshold is above 0.68 seconds, with a repass threshold below 0.60 seconds and a 0.20 filter coefficient.

The secondary method instead detects accumulated lean-to-rich test time above 2.5 seconds while upstream voltage remains below 450 millivolts. The table also lists upstream output below 750 millivolts at the end of the catalyst-rich stage as a failure condition. These are distinct observations; the normalized delay is not interchangeable with raw elapsed time.

## Check that the prerequisite test passed

The source explicitly requires the P015C test to be complete and passed. Relevant oxygen-sensor, fuel-trim, misfire, and other faults inhibit operation. Heater readiness, closed-loop control, airflow, and thermal conditions are also part of the four-page enable list.

A missing P015D result can therefore reflect an unmet prerequisite rather than proof of a healthy lean-to-rich response. Record completion status, enrichment-stage data, and accompanying faults before clearing memory. The source allows extra tests during its fast-initial or rapid-response modes despite the usual once-per-trip schedule. It does not justify replacing the sensor solely because a generic scanner shows a lean voltage outside the qualified test.

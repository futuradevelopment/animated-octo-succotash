# U0424: HVAC data integrity failures received by the body controller

U0424 means the receiving controller cannot trust information arriving from the HVAC control module. The documented GM body-controller monitor checks protected communication fields. It does not measure refrigerant pressure, outlet temperature, or compressor output, so those mechanical tests cannot by themselves explain this code.

## Different integrity checks have different thresholds

The table spans three pages and lists numerous HVAC signals. Alive rolling-counter entries generally require eight failed samples within ten samples. The checksum entries use fourteen failures within eighteen samples. Applying one threshold to every listed message loses a real distinction in this monitor. A rolling counter checks message progression; checksum or protection checks concern the integrity of the received content.

The task executes in a 10-millisecond loop, but that schedule is not a universal timeout for an absent module. U0164 addresses missing HVAC communication in the same document. U0424 instead concerns data that fails an integrity check.

## Capture the conditions at the receiving module

The monitor waits at least 5,000 milliseconds after a power-up reset, running reset, or voltage recovery. Its additional conditions must remain satisfied for at least 3,000 milliseconds: an active partial network, Run power mode, battery voltage above 11 volts, and a manufacturer enable counter of zero.

A useful diagnostic record identifies the reporting controller, affected integrity field, accompanying communication faults, and supply history. Compare those details before condemning the HVAC module. The source assigns Type B, two-trip behavior; it does not identify a failed physical component or prescribe replacement from U0424 alone.

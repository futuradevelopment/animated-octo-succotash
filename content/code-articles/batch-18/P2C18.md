# P2C18: The exhaust B-channel low fault requires an on-state electrical check

P2C18 concerns the exhaust profile-position sensor B circuit’s low electrical classification. GM describes a driver voltage result consistent with a short toward ground while the output is on. The code does not directly describe a low physical position or a profile pin that failed to extend.

## Keep circuit type and channel identity together

The classification corresponds to impedance below 0.5 Ω toward controller ground through the module’s own voltage limits. P2C16 represents the open condition for this channel, while P2C19 evaluates the high condition under an off command. Those distinctions matter when a scan report contains several profile-related faults.

The generic description’s camshaft B designation identifies the exhaust system in this table. Sensor B is a separate channel label; neither is a verified physical-cylinder assignment.

## Confirm an eligible repeated observation

Supply must exceed 11 V, ignition be in crank or run and the diagnostic and on command be active. Four failed samples out of five establish the result. The one-trip reporting class does not mean that any single low reading proves a completed fault.

Preserve command, supply and electrical status before interpreting a lack of movement mechanically. The published impedance is not a connector test instruction. The source cannot identify where the ground path is located or select a sensor, harness or controller for replacement; the correct circuit procedure must establish that.

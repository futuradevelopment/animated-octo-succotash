# U0164: HVAC communication loss is checked after reset and network recovery

U0164 records missing communication from the HVAC control module in this GM body-controller monitor. Several HVAC messages are supervised, so the meaningful evidence is which expected message failed to arrive and under what network state. A climate-control complaint alone does not establish the monitored communication condition.

## Allow for reset and eligibility delays

The source requires at least five seconds after power-up, reset or recovery from an under/overvoltage condition. The remaining general enables must also have been satisfied for at least three seconds. Those intervals are separate from the listed 12.5-second message timeouts.

A silent module during reset recovery cannot automatically be treated as a failed eligible message test. The relevant bus must request full communication, allow normal transmission and not have its bus-off fault active.

## Keep the message and power mode together

The table applies the 12.5-second timeout to a range of HVAC message identifiers, including $588. It also distinguishes run and accessory conditions and whether shutdown is impending. Those states can change whether silence is expected or diagnosable.

Preserve the receiving module’s record, the missing-message identity, supply history and network faults. The code does not identify a refrigerant problem, prove a failed HVAC panel or locate a broken wire. Vehicle-specific power and network checks must separate an unavailable transmitter, communication path and operating-state explanation before a component is selected.

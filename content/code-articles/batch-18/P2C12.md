# P2C12: Exhaust camshaft sensor A must not be confused with intake sensor B

P2C12’s description contains two different labels: the B camshaft designation and position sensor A. In this GM table, the monitored system is the exhaust camshaft profile mechanism and its A position-sensor channel. Confusing the camshaft letter with the sensor letter could direct an investigation to the wrong circuit.

## The row describes electrical integrity under power

The controller compares voltage with its own open-load thresholds while the output is on. The listed classification represents impedance above 200 kΩ toward controller ground. This is not a direct test of exhaust-pin travel or cam timing.

The adjacent P2C13 performance monitor evaluates an unexpected Hall-state sequence. Thus, a circuit-open result and a present-but-implausible movement signal remain separate kinds of evidence even though they concern the same functional channel.

## Verify the intended output and operating state

The output must be commanded on, supply above 11 V, ignition in crank or run and diagnostic enablement active. Four failures out of five samples establish the stated result; one-trip reporting is a different layer of confirmation.

Preserve the exhaust system identity, A channel and actual on command before comparing electrical readings. The table does not provide a physical sensor location or identify which part of the path is interrupted. The applicable circuit procedure is needed before replacing a sensor, actuator or controller.

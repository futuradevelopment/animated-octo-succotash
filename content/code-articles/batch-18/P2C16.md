# P2C16: Exhaust profile-position sensor B is checked for an energized open path

P2C16 concerns the exhaust profile-position sensor B circuit’s open classification. The GM row evaluates the associated driver while its output is powered on. That electrical-integrity test is distinct from checking whether an exhaust profile pin completed the expected movement.

## Identify the correct B designation

This code uses B both in the camshaft designation and in the sensor-channel designation. The table describes the exhaust camshaft system and its B position channel. Those labels identify the function, but do not themselves provide a physical sensor position or cylinder number.

Voltage is compared with module-specific open-load limits corresponding to impedance above 200 kΩ toward controller ground. The adjacent P2C17 performance row instead watches the legitimacy of a Hall-state sequence. A missing drive path and an implausible movement report should not be collapsed into one diagnosis.

## Verify the on-state result

The output must be commanded on, supply above 11 V, ignition in crank or run and the diagnostic enabled. Four failures out of five samples produce the stated result, while reporting is classified separately as one trip.

Useful evidence preserves channel B’s electrical status and command rather than relying only on a decoded position. The source does not establish where the open path lies or which component failed. The correct wiring and driver procedure must localize the interruption before a repair decision is made.

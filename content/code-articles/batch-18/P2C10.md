# P2C10: Intake profile sensor C has an off-state power-short check

P2C10 concerns high electrical behavior associated with intake profile-position sensor C. The GM strategy evaluates the circuit with the output commanded off and classifies the result as a short toward power. The diagnosis therefore depends on what the controller was asking the output to do.

## A powered reading answers a different question

The published voltage thresholds are specific to the controller and represent impedance below 0.5 Ω toward its power supply. They are not supplied as a universal sensor-connector voltage specification. The important contradiction is power-like behavior remaining during the off command.

P2C0F’s low-circuit check uses the opposite, on-state condition. A trace that shows only energized operation cannot conclusively verify both tests. Retain the transition to off and the electrical response after it.

## Match the repeated result to its enable state

Supply above 11 V, ignition in crank or run and diagnostic enablement are required. The row calls for four failed reports out of five samples, while one-trip reporting is specified separately. An isolated transient does not replace this sampling context.

The C designation identifies the monitored intake channel, not a cylinder location or connector number. The source does not establish where unwanted voltage enters the circuit or whether the sensor-associated path, wiring or controller is defective. A matching service procedure must localize the electrical condition before the code is used to select a component.

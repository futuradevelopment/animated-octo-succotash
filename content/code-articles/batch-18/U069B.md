# U069B: Exhaust-temperature sensor 4 SENT communication faults

U069B identifies lost communication with exhaust-gas temperature sensor bank 1, sensor 4. Both cited GM tables describe the same SENT communication monitor. It looks for interface faults that can result from a disrupted signal or sensor-internal communication problems; it does not directly compare exhaust temperature against an overheating threshold.

## Fault status and message age are alternative paths

The criteria allow either a message-fault count above zero or an excessive message age. The published age value is greater than 100 seconds, with the unit printed explicitly as seconds. This should not be silently changed to milliseconds merely because the diagnostic task runs every 100 milliseconds.

Qualification requires nineteen failed samples within twenty-five samples. Message age, sample frequency, and the failure window describe separate parts of the logic. A protocol fault can satisfy the first branch without waiting for the age branch. The diagnostic is Type A with one-trip behavior.

## Confirm initialization and module association

The monitor must be enabled by calibration, Run/Crank status active, actual cranking absent, and the run/crank input in range. The diagnostic system must remain enabled, and a calibrated sensor-initialization delay must have elapsed. That delay is not numerically specified in the row.

The source also describes an accompanying code associated with whichever sensor module contains the EGT connection. Preserve that module record and the specific communication fault before selecting a sensor. An unavailable temperature signal is not proof of excessive exhaust heat or a failed particulate filter. Establish the sensor and module mapping using the applicable service information.

## Source and applicability

2025 GM 25OBDG04A, 25OBDG06C documented monitor only. Vehicle, engine and calibration applicability must be confirmed from the matching service information; no model fitment is inferred.

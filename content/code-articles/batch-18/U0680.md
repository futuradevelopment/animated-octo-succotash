# U0680: Barometric pressure sensor B communication events

U0680 has the generic description lost communication with barometric pressure sensor B. In the cited GM implementation, the relevant rows identify bank 2 and separate line-high and line-low communication events. That pairing is useful for interpreting fault detail, but the generic letter B alone does not identify a mounting position or connector.

## Two line events share the same reporting code

The line-high row begins on one page and the line-low row follows on the next. Both show a 1.5-second duration and two-trip behavior. Their frame names include the bank 2 identifier. These are not pressure-difference thresholds and should not be interpreted as evidence that atmospheric pressure itself is too high or too low.

The original table describes a missing frame in the strategy column while describing wrong data length in the criteria column. This unresolved wording prevents a more specific claim that U0680 always proves either total absence of signaling or a particular malformed-message defect.

## Resolve interface detail before comparing pressure

Save the event subtype, bank identifier, pressure-data validity, and accompanying powerstage or communication codes. The neighboring U1371 entry concerns a bank 2 barometric sensor powerstage fault and has its own duration; it should not be substituted for U0680's communication row.

The shared enable area references ignition status and additional basic-enable conditions. Its printed voltage notation is unclear, so this article does not turn it into a numeric supply test. Matching service information is needed to establish the exact interface checks. A pressure reading that appears implausible during communication failure is not, by itself, a reason to replace a pressure sensor.

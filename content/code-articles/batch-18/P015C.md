# P015C: Bank 2 upstream oxygen sensor delayed rich-to-lean response

P015C indicates delayed rich-to-lean response from bank 2, sensor 1. The cited GM monitor applies to the documented configuration without a wide-range air-fuel sensor. It runs with an intrusive downstream-sensor test that commands fuel cutoff; the code therefore describes response during a controlled diagnostic event, not simply a low sensor voltage at idle.

## The calculated delay and timeout are different tests

When the upstream signal crosses the required threshold, the controller normalizes response time using airflow, engine speed, barometric pressure, and intake temperature. It filters that result with an exponentially weighted moving average using a 0.20 coefficient. Failure occurs above 0.68 seconds in that normalized result; the repass threshold is below 0.60 seconds.

If the expected transition does not occur, the secondary path checks accumulated test time above 3.2 seconds while upstream voltage remains above 100 millivolts. The primary calculation uses the transition below 450 millivolts. These thresholds serve different branches and should not be collapsed into one stopwatch test.

## A valid monitor needs a prepared system

The complete enable list spans four pages. It includes heater operation, learned heater resistance, closed-loop status, voltage above 10 volts, and numerous fault exclusions. Fuel control, airflow, and catalyst-temperature conditions also constrain the intrusive event.

Usually one test runs per trip, but the documented fast-initial and rapid-response features can allow multiple tests after memory clearing or a changed result. Save the monitor result and relevant fuel-control faults before clearing codes. P015C does not independently prove a worn sensor, an exhaust leak, or a failed catalyst; those possible explanations need evidence from the applicable diagnostic procedure.

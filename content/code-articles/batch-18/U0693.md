# U0693: Humidity sensor SENT error reports

U0693 carries the generic description lost communication with the humidity sensor. The documented GM implementation is more specific: it has two paths for a sensor-reported maximum error and minimum error on the bank 1 SENT interface. Those reported error states are the actual evidence available from this table; the code title alone should not replace them with an assumed complete network outage.

## Error flags are not humidity percentages

Each path tests whether its corresponding reported error is true, with a one-second duration and two-trip behavior. The table does not give a relative-humidity percentage that triggers either path. Calling the maximum flag proof of excessively humid intake air would therefore add an unsupported physical interpretation.

The neighboring U13D5 row addresses invalid data from the humidity sensor and is paired with an air-temperature invalid-data code. This separates sensor-reported maximum/minimum errors from another received-data failure. The adjacent air-temperature thresholds also belong to different codes and cannot define U0693.

## Keep the interface status with the measured values

Ignition must be on, battery voltage must exceed 9 volts, and the referenced basic-enable conditions must be met. Record whether the maximum or minimum error path is active, whether humidity data remains valid, and whether the associated temperature interface has faults.

Confirm the sensor's integration and wiring from the matching vehicle information; the source does not establish a universal standalone humidity-sensor location. A displayed humidity value during an error may be insufficient for diagnosis. Resolve the reported status and interface operation before attributing the code to weather conditions or selecting a replacement part.

## Source and applicability

2025 GM 25OBDG07A Part 1 documented monitor only. Vehicle, engine and calibration applicability must be confirmed from the matching service information; no model fitment is inferred.

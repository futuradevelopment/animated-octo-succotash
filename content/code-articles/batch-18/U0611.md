# U0611: Intake-air temperature sensor 1 communication faults

U0611 identifies lost communication with intake-air temperature sensor 1, bank 1 in the generic code dictionary. The cited GM table groups U0611 with U0613 in several communication rows. The shared entries describe a common communication event, a line-high event, and a line-low event associated with the intake-temperature sensor interface.

## A communication failure is not a temperature threshold

None of these rows provides an air-temperature limit that defines U0611. That separates the fault from a sensor reading outside its plausible thermal range. The relevant evidence is the status of the communication interface and its event detail, rather than how hot or cold the displayed intake temperature happens to be.

The original table has an unresolved wording inconsistency: the strategy says a frame is not received, while the criteria column says a wrong data-length condition is received. Its common enable column specifies ignition on and refers to separate basic-enable tables. Two-trip behavior is shown, but a reliable numeric maturation interval is not supplied for these particular rows.

## Preserve the paired-code context

Record whether U0613 is stored with U0611, which high/low or communication event is reported, and whether the temperature display is marked invalid. The source's grouping does not prove that sensor 1 and sensor 2 are separately replaceable devices, share a housing, or occupy particular physical locations.

Confirm the vehicle's interface mapping and failure subtype before circuit testing. Do not borrow the timing of the adjacent suspension-module row or the fuel-tank rows. Those entries describe other messages, and applying their limits would create an unsupported test for U0611.

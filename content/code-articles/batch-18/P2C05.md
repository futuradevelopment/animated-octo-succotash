# P2C05: Intake profile-position sensor A has a driver-level circuit check

P2C05 concerns the intake camshaft profile-actuator position sensor A circuit in the cited GM row. Although the title names a position sensor, the published monitor describes a controller-driver electrical test performed while the output is powered on. It should not be rewritten as a simple mechanical position-error check.

## Identify which evidence the controller evaluates

Voltage is compared with implementation-specific limits representing an open circuit. The row associates that result with impedance above 200 kΩ toward controller ground. This is an electrical classification, not proof that the profile mechanism moved to an incorrect endpoint.

The source explicitly requires the output to be commanded on. A normal-looking signal captured while that output is off therefore does not reproduce the stated monitor, even if the same scan-tool parameter is displayed.

## Keep the test’s operating conditions

Diagnostic enablement, supply above 11 V and ignition in crank or run are required. Four failures among five samples establish the result, with one-trip reporting listed separately. The sample rule should not be replaced by a conclusion from a single disconnected reading.

Useful evidence retains channel A, the command state and driver status. The table does not provide a physical sensor location or connector identity, nor does it distinguish a sensor-associated circuit interruption from wiring or controller issues. A matching service procedure is needed before localizing the open result or making a component decision.

## Source and applicability

2025 GM 25OBDG03B documented monitor only. Vehicle, engine and calibration applicability must be confirmed from the matching service information; no model fitment is inferred.

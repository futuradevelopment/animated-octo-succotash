# U0672: Engine coolant pump LIN communication timeout

U0672 means the engine controller is not receiving the expected communication from the engine coolant pump. The cited GM monitor checks the LIN response MWP_Rsp_0F_C05. Because this is an interface-availability check, it does not establish actual coolant flow or mechanically confirm that the pump is stalled.

## Response timeout and pump speed are different evidence

The missing-response threshold is at least 250 milliseconds. The LIN communication diagnostic executes in a 500-millisecond loop, and the source assigns Type A, one-trip behavior. A response-age limit should not be confused with the task's execution interval or converted into a universal time to illuminate a warning.

If speed data is unavailable when the response disappears, that is not an independently measured zero-rpm result. Preserve whether the scan tool marks speed invalid, substitutes a value, or still receives another pump status. This helps separate data loss from an actual measured speed deviation.

## Evaluate the expected communication window

The controller must have the diagnostic and LIN channel enabled, the LIN module initialized, and the slave configured as present. Relay-state checks also apply. The listed power and voltage conditions qualify for at least five seconds, with battery voltage above 11 volts and separate Run and Accessory requirements continued onto the next page.

Record the power mode, supply interruption history, and other LIN-device faults before isolating the pump. The generic code does not identify a connector or distinguish every possible wiring fault. Use the matching system diagram and controller failure detail to decide whether the loss concerns one device or a broader communication or power problem.

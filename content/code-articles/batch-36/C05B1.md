# C05B1: The documented rear brake circuit fails a leak assessment

The generic C05B1 description names brake hydraulic circuit D leak. The 2018 GM BSC1 table labels its implementation “ABS rear hydraulic circuit leak detected.” That rear-circuit mapping is source-specific and must be confirmed for the vehicle.

## Pressure behavior is the evidence

One branch calculates leakage from the rear-axle pressure sensor and uses a threshold above 0.6 milliliters per second. Its prerequisites include standstill, rear by-wire operation, system voltage above 9.6 V, a bounded rear-pressure range and a relatively steady target-pressure command. The table also has a separate master-cylinder/rear-pressure comparison branch.

These conditions matter because a changing brake demand or a different operating mode is not the same test. The code represents a monitored hydraulic inconsistency; it does not tell the reader where fluid is escaping or establish that an externally visible leak must exist.

## Preserve the operating mode

Record the branch-related pressure evidence, command stability and brake-controller faults for professional diagnosis. A fluid-level observation alone cannot reproduce the pressure calculation. Likewise, an apparently normal pedal on a later occasion does not invalidate the stored hydraulic finding.

Brake hydraulic diagnosis requires a qualified technician using the correct vehicle procedure. This article provides no pedal-loading test, road test or hydraulic disassembly instructions. Verification must establish the required hydraulic integrity and monitor result after repair; C05B1 alone cannot support a safe-driving judgment or a specific component replacement.

## Source and applicability

This explanation follows the documented GM monitor, not a verified application to every vehicle with this code. Confirm the vehicle, reporting module and calibration in current service information.

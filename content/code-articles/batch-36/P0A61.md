# P0A61: Drive motor A phase V has too little current under command

P0A61 identifies drive motor A phase V current low. In the 2018 GM MCP1A table, the controller evaluates sensed V-phase current for an open-circuit response when the electrical phase is near its expected current peak.

## Demand and timing qualify the finding

The documented failure threshold is below 9 A for 0.4 seconds within a 0.6-second window. The drive must be in Run with normal PWM, inverter voltage above 50 V and no active discharge. A ±30-degree phase-axis window and squared commanded current above 900 A² further qualify the test. Reporting is Type A, one trip.

A small current when torque/current demand is low does not reproduce those conditions. The threshold also cannot be applied indiscriminately to an instantaneous reading elsewhere in the electrical cycle.

## A phase-specific result is not a whole-motor verdict

Preserve motor A's identity, V-phase status and the command that existed when the fault set. The code indicates inadequate sensed response under the documented conditions; it does not by itself select a replacement motor or prove a particular cable is open. The vehicle procedure must distinguish the power and sensing paths.

Repair confirmation should include an eligible V-phase evaluation and the manufacturer's required system checks. Clearing the fault while the inverter remains inactive provides little evidence. High-voltage drive circuits require qualified service; this source supplies no live-probing or external-energization procedure.

## Source and applicability

This explanation follows the documented GM monitor, not a verified application to every vehicle with this code. Confirm the vehicle, reporting module and calibration in current service information.

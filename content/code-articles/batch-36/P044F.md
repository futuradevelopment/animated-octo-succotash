# P044F: AIR valve voltage high when commanded on

For P044F, the 2015 GM ECM checks the secondary air injection solenoid's low-side driver while it is commanded **on**. The failure is voltage remaining high in that state, which the table characterizes as a short-to-power circuit condition.

## Why the command matters

A low-side output normally has a different electrical state when activated than when inactive. The useful diagnostic observation is the disagreement between the commanded state and feedback, not the word “high” by itself. P044F therefore calls for the applicable control-circuit diagnosis; it is not, by itself, an airflow measurement or confirmation that the valve is mechanically stuck.

The documented test needs at least 11 V at the powertrain relay. Twenty failed evaluations among 25 samples, with samples 250 milliseconds apart, meet its listed failure requirement. GM classifies this implementation as Type B, two trips.

## Evidence to preserve

Record whether the driver was on when the fault became current and whether relay voltage satisfied the enable condition. Compare that information with the correct schematic and any other driver faults. A static voltage obtained with the command off cannot reproduce the condition described by this monitor.

After a circuit correction, verification should show that feedback follows an eligible on command and that the relevant diagnostic has actually run. Simply deleting the stored code provides neither observation. The table supplies monitor logic, not a universal component replacement decision or pin-by-pin repair procedure.

## Source and applicability

This explanation follows the documented GM monitor, not a verified application to every vehicle with this code. Confirm the vehicle, reporting module and calibration in current service information.

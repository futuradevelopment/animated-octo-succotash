# P0A67: Drive motor B phase U current is low under active demand

P0A67 identifies drive motor B phase U current low. The 2018 GM MCP1B table evaluates that motor's U-phase response, which must not be confused with the same phase designation on drive motor A.

## The qualified operating condition

The monitor uses a threshold below 9 A for 0.4 seconds in a 0.6-second window. The drive is in Run, the inverter uses normal PWM, voltage exceeds 50 V and active discharge is excluded. Evaluation is restricted to a ±30-degree phase-axis window with squared commanded current above 900 A².

These conditions make an unexpected lack of current meaningful. A low value while no substantial current is requested, or during a different part of the electrical cycle, is not the documented failure. GM lists Type A, one trip.

## Why source identity is part of diagnosis

Preserve the reporting motor controller, phase and command state. A generic scan display that omits motor A/B context can send inspection to the wrong drive unit. The code itself does not prove which motor, inverter, connection or sensing component needs replacement.

A qualified high-voltage technician should follow the application-specific electrical diagnostic. Confirmation requires an acceptable U-phase response during the prescribed eligible test and the required system checks. This article does not provide access instructions for active phases or authorize external power application; clearing a stored code without operating the monitor is insufficient verification.

## Source and applicability

This explanation follows the documented GM monitor, not a verified application to every vehicle with this code. Confirm the vehicle, reporting module and calibration in current service information.

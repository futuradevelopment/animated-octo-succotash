# P24F0: Wake-up output voltage is low during an on command

P24F0 means control-module wake-up circuit low. In GM's 2018 HPC2/BSM table, this output is monitored when the wake-up command is **on** and the diagnostic is enabled.

## The low threshold belongs to the active state

The listed failure criterion is control voltage at or below 5.52 V. The test requires 480 failed samples out of 560, with a sample every 12.5 milliseconds and a seven-second evaluation. Reporting is Type A, one trip.

An output reading near ground while its command is off is not equivalent to this fault. The useful diagnostic evidence is the requested on state together with the unexpectedly low feedback. The monitor does not itself identify which downstream module failed to wake or which component caused the low response.

## What to establish next

Preserve the requested wake-up state and the timing of associated communication faults. The applicable wiring diagram can show which modules and connections belong to the output; their identity cannot be inferred from P24F0 alone. A responding module does not necessarily prove that every branch of a shared wake-up circuit is healthy.

Verification should include an eligible on-state circuit assessment and the manufacturer's required wake-up sequence after repair. Clearing fault memory or testing only with the vehicle already awake misses the monitored transition context. This explanatory table supplies no connector pinout and does not authorize applying external power to the wake-up line.

## Source and applicability

This explanation follows the documented GM monitor, not a verified application to every vehicle with this code. Confirm the vehicle, reporting module and calibration in current service information.

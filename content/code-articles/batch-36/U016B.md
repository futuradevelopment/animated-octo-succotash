# U016B: Electric A/C compressor messages are missing

U016B identifies lost communication with the A/C compressor control module. The 2015 GM HCP2 table specifically watches messages from the **electric** A/C compressor control module on Bus A. The code reports missing information; it does not establish a seized compressor or a refrigerant fault.

## When the timeout counts

This implementation needs the controller on, Bus A communication enabled for more than two seconds and battery voltage above 10.2 V. Missing messages for at least 500 milliseconds meet its timeout criterion. The diagnostic runs on a 10-millisecond loop and can pass 10 milliseconds after receiving a message from the supervised source. Its listed reporting type is B, two trips.

A message returning can therefore change the monitor result quickly even though a historical DTC remains stored. Distinguish that recovered state from a fault that is still current when investigating an intermittent complaint.

## Separate the compressor from its communication path

A useful next decision is whether other Bus A sources remain visible and whether the compressor module had its required supply and operating state. That comparison helps distinguish a source-specific problem from wider network loss; the timeout itself cannot choose between them.

Preserve supply-voltage and communication context before clearing. Confirm recovery through repeated expected messages under eligible conditions, not merely the disappearance of a warning. Electric-compressor power circuits belong to qualified high-voltage service; this communication table is not an instruction to probe or disconnect them.

## Source and applicability

This explanation follows the documented GM monitor, not a verified application to every vehicle with this code. Confirm the vehicle, reporting module and calibration in current service information.

# U01A2: Module C cannot be reached after battery-chain recovery

U01A2 identifies lost communication with hybrid/EV battery interface control module C. In the 2018 GM HPC2/BSM table, interface communication runs on a UART daisy chain supervised by the battery systems module.

## Why several missing modules may share one cause

The source states that a break anywhere in the chain can disrupt communication. After U179C fails, the controller invokes an internal loopback arrangement to attempt recovery. U01A2 fails if C is the first interface in that sequence that cannot be brought back into communication.

The listed assessment is 4.5 seconds and Type A, one trip. A successful recovery with C, or U179C passing, provides a stated pass path at 100 milliseconds. This explains why current availability and stored history need to be distinguished.

## Interpret C as a diagnostic identity

The code does not prove that all modules beyond C failed independently or that C's electronics are definitively defective. Retain U179C status and the complete availability pattern; the vehicle-specific procedure must identify the physical chain and relevant connections.

The recovery mode is performed internally by the system. It is not a service instruction to short, bridge or reroute pack wiring. A trained high-voltage technician should follow the prescribed diagnosis and repair process. Confirmation requires valid restored interface data and the applicable recovery checks, not merely the deletion of U01A2 from scan memory.

## Source and applicability

This explanation follows the documented GM monitor, not a verified application to every vehicle with this code. Confirm the vehicle, reporting module and calibration in current service information.

# U007A: Bus H has entered the CAN bus-off state

U007A means control module communication Bus H off. In the 2015 GM HCP2/VICM table, the monitored event is the CAN controller interface entering a bus-off condition. GM associates that state with a shorted CAN condition; the DTC does not identify a particular failed remote module.

## A network state with enable conditions

The controller must be on, and Bus H communication must have been enabled for more than two seconds. The row requires five failed samples out of five on a one-second diagnostic loop and lists Type A, one-trip reporting.

Those details distinguish U007A from a named-module timeout. A missing message identifies an absent source; bus-off identifies a state of the local CAN interface. The distinction changes which network evidence is relevant. Establish which physical network is called Bus H in the applicable vehicle and which module recorded the event before interpreting a generic scanner description.

## Comparing the evidence

A technician can compare the reporting module's network state with faults recorded elsewhere on that same bus. Multiple lost-message codes may be consequences of communication loss rather than independent module failures. That is an interpretation to investigate, not a conclusion the code proves.

Capture the initial fault record before resets obscure the event. Verification needs the relevant interface to remain communicating after its enable period. The source provides no universal connector, termination-resistance value or safe way to bridge network conductors, so those details must come from the actual vehicle procedure.

## Source and applicability

This explanation follows the documented GM monitor, not a verified application to every vehicle with this code. Confirm the vehicle, reporting module and calibration in current service information.

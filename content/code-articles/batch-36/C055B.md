# C055B: ABS pump supply drops relative to the internal reference

C055B identifies ABS pump motor supply voltage circuit A low. The 2018 GM BSC1 table evaluates motor-relay supply voltage relative to an internal supply reference, rather than using a single generic battery-voltage cutoff.

## A brief recovered voltage can still leave a fault

The documented ratio threshold is below 0.4. One branch monitors pump actuation, with ignition on and additional speed conditions, and lists a 0.01-second assessment. Another supply-line branch lists 0.2 seconds with ignition on. The table classifies the result as Special Type C.

GM explains that the relevant hardware register bit is retained through the ignition cycle even if voltage recovers. Therefore, normal voltage observed later does not by itself refute an earlier supply interruption. The description discusses possible inline resistance or undervoltage, without proving a specific cable or relay has failed.

## What changes the next check

Preserve the pump state, original supply-fault status and any recorded voltage context. An unloaded battery reading is not equivalent to the ratio observed during pump operation. The applicable procedure must distinguish supply-path behavior from a pump or controller conclusion.

A qualified brake technician should perform the required electrical and functional checks. Verification must address the original supply condition and prescribed fault-state recovery, not just clear memory. No road-speed test, relay bypass or live-circuit probing procedure is authorized by this explanation, and the code alone cannot establish safe braking.

## Source and applicability

This explanation follows the documented GM monitor, not a verified application to every vehicle with this code. Confirm the vehicle, reporting module and calibration in current service information.

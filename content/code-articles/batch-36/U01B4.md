# U01B4: Brake control module B messages are missing on the main bus

U01B4 identifies lost communication with brake system control module B. The 2018 GM table's ECM section labeled “CT6 Unique” monitors that controller on the main high-speed bus, identified in its enable conditions as Bus A.

## A specific missing message

The row watches message $4FB and uses a ten-second absence criterion. The diagnostic runs on a 12.5-millisecond loop and is classified Type B, two trips. It requires normal Bus A transmission, no current-key-cycle U0073 bus fault, and inactive device-control and high-voltage virtual-network-management states.

The table provides distinct ignition and off-cycle enable paths with different voltage and timing requirements. Consequently, a module's silence during an arbitrary sleep or transition state is not automatically equivalent to the fault. Preserve the power mode and network state rather than interpreting a bare timeout label.

## Separate a missing source from a broken whole bus

Check which module recorded U01B4 and whether other expected sources remain available on the same network. The code does not prove that the brake controller itself is defective; its supply, operating state and communication path still require the vehicle-specific diagnostic.

Confirmation should show the required messages returning under eligible conditions and resolution of the originating cause. This table does not establish a universal model fitment, connector or termination-resistance test. Brake-related operation and network repairs require appropriate professional service, without a safe-driving assurance from the DTC alone.

## Source and applicability

This explanation follows the documented GM monitor, not a verified application to every vehicle with this code. Confirm the vehicle, reporting module and calibration in current service information.

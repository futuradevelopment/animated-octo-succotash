# P0531: A/C pressure response can fail while voltage stays in range

P0531 is an A/C refrigerant pressure sensor range/performance code. In the 2015 GM electric-compressor implementation, the controller looks for a high-side pressure signal that is stuck or biased **within** its electrical range. A plausible-looking voltage can therefore coexist with this code.

## Pressure response, not one snapshot

The engaged test compares measured pressure change with predicted pressure change. Its prediction incorporates ambient temperature, coolant temperature, vehicle speed and fan speed. The ratio is weighted and filtered rather than judged from one instantaneous pressure reading. Compressor speed must exceed 300 rpm for the documented engaged test.

That structure gives a technician two separate questions: did the pressure signal respond, and were the model's other inputs and operating conditions credible? The code alone cannot answer either question or establish a refrigerant charge quantity. The table also inhibits the test for specified pressure-circuit, compressor-operation and communication fault groups; those faults can prevent a meaningful performance result.

## Clearing changes test history

The source describes a fast initial-response sequence after a memory reset or code clear, with two such tests required before reporting. A short observation immediately after clearing is consequently weak evidence of a repair.

Review pressure response alongside compressor operation and the supporting inputs, using the applicable A/C service procedure. Refrigerant handling and electric-compressor electrical work require appropriate equipment and training. This monitor explanation supplies no charging specification or high-voltage probing procedure.

## Source and applicability

This explanation follows the documented GM monitor, not a verified application to every vehicle with this code. Confirm the vehicle, reporting module and calibration in current service information.

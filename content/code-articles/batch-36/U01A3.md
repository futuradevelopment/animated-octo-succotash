# U01A3: Battery interface D remains unavailable in the recovery sequence

U01A3 means lost communication with hybrid/EV battery interface control module D. GM's 2018 monitor supervises a UART daisy chain between the battery systems module and its interface modules, so the communication topology is central to the finding.

## A recovery result, not just a missing name

Following U179C, the controller attempts an internal communication-loopback mode that bypasses the normal chain. It identifies the first module that cannot be recovered; U01A3 corresponds to D in this table. The failure time is listed as 4.5 seconds, with Type A, one-trip reporting.

A recovery that restores D or a passing U179C result can produce a pass, listed at 100 milliseconds. Returning communication does not erase the diagnostic value of a historical interruption.

## What to retain

Save the original interface availability pattern, U179C state and recovery status. A single chain interruption can remove data from several interfaces. That possibility is directly supported by the architecture and should be investigated before treating every unavailable module as a separate replacement.

The D designation must be mapped using the actual pack documentation. The monitor does not identify a universal connector location or prove an internal module defect. Qualified high-voltage service is required for physical investigation. Do not imitate the controller's loopback through manual wiring changes. Verify valid data restoration and the prescribed diagnostic results after the underlying cause is corrected.

## Source and applicability

This explanation follows the documented GM monitor, not a verified application to every vehicle with this code. Confirm the vehicle, reporting module and calibration in current service information.

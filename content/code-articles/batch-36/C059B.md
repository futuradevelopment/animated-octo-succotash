# C059B: Brake pressure sensor B fails its test-pulse check

C059B names brake pressure sensor B missing calibration. The 2018 GM BSC1 table's criterion specifically evaluates the rear-left pressure sensor test pulse, with limits above 110 percent or below 90 percent. Its surrounding prose also contains a master-cylinder reference, so physical sensor identity must be verified in the vehicle's service information rather than inferred from that inconsistent sentence.

## A self-test response, not simply brake pressure

The test requires pressure-sensor offset compensation to have completed at least once. Other stated conditions include low master-cylinder pressure, inactive traction/ABS/vehicle-dynamics interventions, pump off, brake-light switch off and time since the previous test pulse above 30 seconds. The row lists immediate failure recognition with Type A, one-trip reporting.

These details show why “missing calibration” should not be reduced to a blind instruction to repeat a calibration routine. The controller is evaluating a sensor test response within an already qualified state.

## What needs professional confirmation

Preserve the calibration history, test status and related sensor faults. A plausible static pressure value alone does not validate the test-pulse response. The appropriate brake procedure must confirm sensor identity and determine why the response fell outside its limits.

Qualified brake service must perform calibration, electrical and functional verification. This summary supplies no road test or direct sensor stimulation procedure. Clearing the code cannot substitute for a successful prescribed self-test and brake-system assessment.

## Source and applicability

This explanation follows the documented GM monitor, not a verified application to every vehicle with this code. Confirm the vehicle, reporting module and calibration in current service information.

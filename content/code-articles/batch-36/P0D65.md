# P0D65: Battery fan enable voltage stays low when enabled

P0D65 is a hybrid/EV battery cooling-fan enable circuit low code. In the 2018 GM table, the controller checks whether the enable output has a short-to-ground response while cooling-fan enable is true.

## The command establishes why low voltage is abnormal

The listed failure criterion is enable-circuit voltage below 5.35 V. The monitor needs system voltage above 10.2 V and 16 failures out of 20 samples at 250-millisecond intervals. Its five-second evaluation is classified Type B, two trips.

A low enable-circuit voltage with the command off does not reproduce this finding. Likewise, this code does not directly measure fan feedback frequency or airflow. It identifies an electrical condition in the enable path that must be diagnosed with the correct circuit information.

## What to compare before selecting a repair

Record supply voltage, enable command and feedback together. Compare any fan speed or temperature codes without assuming they identify additional independent defects; a missing enable can affect downstream behavior, but the table alone cannot establish the complete causal chain.

Confirmation should demonstrate appropriate enable feedback when requested, then the fan's required operating checks. Clearing the code or observing the fan once under another condition is incomplete. The source does not provide connector pins, resistance limits or a mandatory replacement component. Use vehicle-specific procedures and qualified personnel where access involves protected hybrid-battery components.

## Source and applicability

This explanation follows the documented GM monitor, not a verified application to every vehicle with this code. Confirm the vehicle, reporting module and calibration in current service information.

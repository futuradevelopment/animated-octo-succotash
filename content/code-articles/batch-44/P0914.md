# P0914: Passat DSG selector-message diagnosis and plausibility

P0914 has a generic gear-shift-position circuit title, but the Passat 2015 DQ-250 6F table describes several selector diagnostic mechanisms. One detects a timeout in a question-and-answer exchange: a timeout exceeding 100 milliseconds increments an event counter. The table lists 300 milliseconds for this monitoring branch, with the selector messages available and no selector-message failure.

## Reading the selector's diagnostic information

A second branch checks selector-position plausibility. It compares position with its inverse encoding and rejects initialization, error, or invalid position values. Its conditions include no bus-off or relevant CAN-message failure, more than 1,100 milliseconds since reset, and terminal 15 above 9 volts for more than 1,100 milliseconds. The monitoring entry for this branch is 1,000 milliseconds.

A further question-and-answer failure branch is listed with 1,500 milliseconds. These are separate checks, not three delays to add into one universal P0914 timer. The table's two-driving-cycle MIL schedule also differs from the individual diagnostic timing.

This source therefore does not justify reducing P0914 to a single analog position-sensor voltage fault. A technician needs the selector's communicated state, consistency information, reset context, and diagnostic-response results. Companion CAN faults can change whether the intended check is valid.

The cited material is a monitor table rather than a selector replacement instruction. Use the actual DQ250 service procedure and full vehicle scan to locate the fault. Do not manipulate selector wiring or force gear engagement to recreate it. Preserve event data so communication availability, invalid position information, and failed diagnostic response can be distinguished.

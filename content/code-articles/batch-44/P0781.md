# P0781: Passat DQ250 first gear does not disengage

In the Passat 2015 DQ-250 6F transmission table, P0781 means first gear remains engaged despite a command to disengage. It is not simply a generic report that a 1–2 shift felt rough. The monitor uses the first-gear shift-fork position relative to a synchronizing point established by basic adjustment.

## Disengagement evidence for first gear

The fault criterion places the fork beyond that synchronizing point plus 10 percent while the shift-fork valve 2 command is at least 5 percent. The enabling configuration includes safety valve 1 commanded at least 20 percent, multiplexer position 0, requested main pressure above 2 bar, and no main-pressure-loss condition. Volkswagen lists 6,000 milliseconds of monitoring and a two-driving-cycle MIL schedule.

Electrical and operating prerequisites are also present: terminal 15 above 4 volts, battery voltage above 9 volts, and engine speed above 600 rpm, each for more than 500 milliseconds. These conditions explain why a static code scan alone cannot reproduce the monitor. They are calibration conditions, not instructions for an owner road test.

The learned reference matters diagnostically. A technician should review commanded disengagement, reported fork position, basic-adjustment context, and hydraulic prerequisites together. The row does not identify one failed solenoid, prescribe transmission replacement, or provide a universal fork-distance measurement.

Use the correct DQ250 service procedure to investigate the failed response and any companion pressure or electrical faults. Do not force shifts or continue a hazardous drive to reproduce the condition. The article is limited to this documented 2015 six-speed DSG monitor; other transmissions can implement the same generic code differently.

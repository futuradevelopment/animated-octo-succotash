# P26F6: Passat coolant-pump C control short to supply

Volkswagen's Passat CVCA2016 P26F6 entry identifies an electric coolant-pump control circuit shorted to battery supply. The output-driver diagnostic is evaluated for 480 milliseconds, with a two-driving-cycle MIL schedule. The code is about the control circuit, so high does not establish high coolant temperature, excessive pump speed, or excessive system pressure.

## Supply-short evidence and the V488 reference

The row gives no numerical voltage threshold and leaves the secondary enabling-condition cell blank. A technician should not transfer a voltage limit or on/off requirement from another pump code without supporting vehicle information.

The source directs the fault to heater support pump V488. However, the linked checking section is jointly titled V467/V488 and uses V467 in its detailed electrical steps. Exact pump and connector applicability therefore remains unresolved in this source alone. Current wiring and service information must settle the identity before testing or ordering a component.

The shared diagnostic structure checks supply and the ECM control path before the pump replacement branch. A verified external short to supply and an internally failed pump are different findings, even if either can affect control. Document the actual defect and the response after repair.

Avoid bridging control wiring or improvising a power feed. Cooling-system work also requires attention to hot pressurized fluid and moving equipment. A qualified workshop should confirm the relevant component, apply the proper electrical test, and verify that P26F6 no longer returns. The unresolved procedure naming is a reason for careful source matching, not an automatic recommendation to replace both pumps.

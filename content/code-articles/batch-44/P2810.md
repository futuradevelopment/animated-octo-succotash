# P2810: Jetta 09S solenoid G current-feedback monitor

P2810 belongs to the separate 2020 AQ300-8F eight-speed 09S transmission table in Volkswagen's Jetta manual. It identifies pressure-control solenoid G, designated SL6. This transmission-specific mapping must not be transferred to the engine table or to a different gearbox using the same generic code.

## Requested and measured solenoid current

The shared linear-solenoid monitor checks whether feedback current is stuck by comparing requested and measured current. Its criterion is a summed difference greater than 10,000. The source does not give an engineering unit or scaling for that sum. Describing it as 10,000 milliamps, or converting it into a resistance limit, would invent information.

The table lists 100 milliseconds of monitoring, continuous evaluation and MIL illumination after two driving cycles. Its compressed enabling-condition cell includes supply voltage above 10.5 V, the main solenoid switch on and an input A/D value below 1,333 mA. Because the layout compresses several labels and values, the exact input interpretation should be checked in current transmission diagnostic information before applying it as a standalone test specification.

The useful conclusion is a discrepancy in SL6 current control or feedback under enabled conditions. It does not by itself prove a hydraulic blockage, worn clutch or failed transmission controller. Diagnosis should preserve requested and actual current, supply conditions and related solenoid faults, then follow the correct 09S electrical procedure.

Professional transmission service should resolve the current-feedback branch without improvised direct solenoid energization. The undocumented sum scaling and compressed source layout remain review limitations. Repair verification should demonstrate normal commanded-current tracking and no recurrence of the original code in the applicable transmission monitor.

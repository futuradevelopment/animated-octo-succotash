# P0D99: MX-30 positive quick-charge temperature sensor circuit

The generic P0D99 label names a battery charger coupler temperature-sensor circuit. Mazda assigns this code to the positive-side QBC temperature sensor in the MX-30 electric charging-port system. It is a circuit-malfunction diagnosis, not a published overtemperature threshold. The page supplies neither a temperature limit nor a detection timer.

## Positive-terminal temperature circuit evidence

The source identifies common connector C-56 and the charge port-electrical supply unit connection as initial inspection points. It then distinguishes several electrical failure modes: a signal short to ground, a signal or ground-path short to supply, and an open signal or ground circuit. These possibilities explain why a temperature-related code cannot by itself establish that the coupler actually overheated.

Only after those connection and circuit checks does Mazda call for the dedicated QBC temperature-sensor inspection. Its outcome controls the assembly decision. A sensor that passes points toward the charge port-electrical supply unit; a sensor that fails points toward the charge port assembly. The source does not provide a separate replaceable sensor part or a universal resistance specification on this page.

Snapshot data should be retained before clearing. Post-repair recurrence of the same pending code triggers CAN diagnosis and a repeated sequence before the PCM branch. Other DTCs also require review.

The charging context, current fault status, and actual circuit or sensor findings are the useful evidence to request from the workshop. Do not bridge a temperature-sensor circuit to make charging continue. The manual flags high-voltage hazards around these parts, so inspection and assembly replacement require trained personnel and the full safety procedure.

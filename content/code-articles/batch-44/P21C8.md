# P21C8: Passat reductant relay short-to-ground indication

The Passat CVCA2016 P21C8 row identifies a short-to-ground indication in the SCR power-relay control circuit. It evaluates the output-driver diagnostic signal while relay power state is off. Volkswagen lists 500 milliseconds of monitoring and a two-driving-cycle MIL schedule. The page does not publish a specific voltage threshold.

## Relay circuit evidence before replacement

This explanation uses the 2016 row because the 2015 table presents different, broader transition-delay wording under the same code. Those descriptions should not be merged into a universal monitor. Confirm the model year, software, and current service information before applying the threshold or test path.

The source directs the fault to the reducing-agent metering delivery-unit procedure, which includes relay J963 and the supply and control connections serving GX19. The diagnostic sequence checks electrical paths before condemning the delivery assembly. That is important because the generic control-circuit-low title does not establish a failed tank heater, pump, or fluid-quality sensor.

The service record should identify the exact relay-control defect and the state in which it was observed. A short-to-ground driver report is different evidence from a relay that merely changes state slowly, even though both can affect SCR power availability.

Use the proper wiring diagram and approved test equipment. Bypassing the relay to keep the dosing system powered can defeat the intended diagnostic conditions and is not an owner repair. After the actual defect is corrected, controlled recurrence verification and readiness checks establish whether the electrical problem has been resolved.

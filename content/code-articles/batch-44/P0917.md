# P0917: Veloster shift-position high signal versus motor power

Hyundai describes P0917 as gear-shift-position circuit high on the 2012 Veloster DCT. Its general information says the output voltage is above the usable range. The detecting-condition image requires ignition on and an out-of-range event lasting more than six seconds on three occasions. It does not state a numeric high-voltage fault threshold.

## Position feedback differs from motor supply

The high-circuit description should not be confused with excessive motor supply or a measured overcurrent. The associated procedure examines Hall-position feedback: approximately 5 V supply, signal-check references of approximately 3–6 V, and a ground reference near zero under the specified disconnected-connector conditions. Those values describe electrical tests, not the monitor's undisclosed trigger calibration.

Hyundai's scan-tool check observes shift-motor current, voltage and speed across operating states. If the present data follow the reference, its decision branch considers an intermittent connection or a previously repaired event retained in memory. Otherwise, diagnosis continues through connector and harness checks. This distinction prevents a single normal reading from being treated as proof that the historical high-signal event was imaginary.

The final electrical branch allows a known-good shift motor only after the preceding circuit checks, with replacement dependent on the fault being corrected. A TCM-related branch is likewise conditional. The code does not authorize replacing either component immediately.

The documented fallback fixes the gear, so qualified service should preserve the fault evidence and assess the vehicle's actual operating condition. Repair confirmation requires the relevant enabled operation and a repeat DTC check. Avoid improvised actuator energization or probing around moving mechanisms; accurate diagnosis depends on the correct circuit identification and controlled testing.

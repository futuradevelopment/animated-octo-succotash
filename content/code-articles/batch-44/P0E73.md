# P0E73: MX-30 charging-control signal frequency too high

For the MX-30 electric onboard charger, P0E73 detects excessive frequency in the charging-status control signal coming from the charging equipment. The source states that charging stops. It does not publish the upper-frequency limit, tolerance, or minimum duration, and it should not be interpreted as excessive AC mains frequency.

## The high-frequency charging-control boundary

The specific prerequisite is P0CF6. If that related signal fault is present, Mazda follows its troubleshooting before making the final P0E73 decision. This is a different dependency from the low-frequency chart and helps explain why a complete charger scan matters more than the isolated code title.

Before that branch, the workshop preserves the snapshot and compares behavior with equipment other than the original equipment. A fault that remains historical can support an equipment-specific event; a current recurrence requires continued diagnosis. The manual labels this comparison quick charging, so the exact applicable charging setup must be confirmed from the full service information.

If P0E73 remains current after the related-code assessment, CAN diagnosis and a repeated diagnostic sequence precede the onboard-charger replacement branch. The chart requires continued recurrence with communication normal rather than treating the first stored event as proof of charger failure. Other DTCs are checked at completion.

Useful evidence includes the equipment identity, P0CF6 status, and whether the signal fault returned as current. Do not alter pilot wiring or use an assumed universal frequency threshold as a Mazda pass/fail limit. Qualified personnel should manage charging reproduction and any high-voltage component access using the complete safety procedure.

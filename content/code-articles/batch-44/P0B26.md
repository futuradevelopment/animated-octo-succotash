# P0B26: MX-30 module-one cell overcharge evidence

For the Mazda MX-30 Electric, P0B26:00 points to cell overcharge in high-voltage battery module No.1. The generic battery-A voltage-high description becomes a specific module and per-cell decision in this factory procedure.

## The threshold belongs to a cell measurement

Mazda sets the monitor when any cell in module one measures at least 4.35 V through the main voltage sensor, or at least 4.36 V through the sub voltage sensor, for 0.5 seconds. The alternatives are joined by an either-condition rule; the chart does not require both sensing paths to exceed their respective limits.

These are not whole-pack voltage specifications. A total battery-voltage display cannot, by itself, establish whether the individual cell condition occurred. Likewise, the code does not state that every cell in module one is overcharged. Its trigger can be one qualifying cell.

## Retain the conditions behind the finding

Snapshot data is the first diagnostic evidence requested. Mazda then calls for a controlled reproduction of the recorded operating conditions and a check for the same pending BECM code. That is a professional verification task, not a suggestion to continue operating a vehicle to provoke an overcharge warning.

If the fault returns, the prescribed decision path checks CAN communication before reaching the high-voltage battery replacement branch. The chart lists internal battery malfunction as a possible cause but does not provide an external connector test for this entry.

## Keep the scope of the diagnosis clear

P0B26 identifies the module-one high-voltage observation; it does not independently explain why that reading became excessive. The technician must retain the sensor path, cell information and other DTCs rather than infer a charger failure from this code alone. Final verification includes checking for additional faults under the vehicle’s proper EV service precautions.

# P2532: MX-30 PCM power input stays on against BCM off status

For the MX-30 electric system, P2532 records disagreement about main-power state. The PCM detects an on state at its AN terminal while the body control module sends an off-state message over CAN. This explains the generic run-position-circuit-high label without assuming excessive traction-battery voltage or an ordinary keyed ignition switch.

## An active power input against an off status

The distinction between the two information paths drives diagnosis. A BCM fault can compromise the reported state, while a relay or supply-circuit defect can keep the physical PCM input active. Mazda checks BCM DTCs first, then IG1 relay No.1, PCM connector condition, and a short to supply in the PCM power circuit. The page supplies no numeric input threshold or persistence timer.

This is a narrower electrical pattern than simply having a weak auxiliary battery. The source's listed causes do not justify replacing the battery from P2532 alone. Likewise, the code is insufficient to declare the PCM faulty before the relay, connector, and supply path have been evaluated.

The snapshot should be retained before clearing. Repair verification asks whether the same pending code returns under the relevant recorded conditions. If it does, Mazda requires CAN communication diagnosis and another diagnostic pass. The PCM replacement branch applies only after normal communication and continuing recurrence. A final scan checks additional faults.

Ask the workshop which side of the comparison was incorrect: the physical power input or the communicated state. That evidence is more useful than a parts list. Do not bypass power-control relays or assume that a dashboard off state proves every related circuit is de-energized.

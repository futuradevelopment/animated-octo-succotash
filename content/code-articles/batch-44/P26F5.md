# P26F5: Passat coolant-pump C short-to-ground monitor

The Passat CVCA2016 table describes P26F5 as an electric coolant-pump control circuit shorted to ground. The monitor uses output-driver diagnostics, runs for 4.0 seconds, and has a two-driving-cycle MIL schedule. Its duration is materially different from the shorter open-circuit and high-circuit entries in the same table.

## Ground-short evidence and the V488 reference

The source does not publish a low-voltage trip value or a separate enabling state. The generic circuit-low wording therefore should not be converted into a guessed voltage measured at any convenient pump terminal. It also does not mean low coolant level or low pump speed.

There is a source-mapping issue: the DTC row directs diagnosis to heater support pump V488, but the combined V467/V488 procedure uses V467 in its detailed connector and replacement steps. The technician must resolve the actual component and wiring before applying those instructions. This remains a review item rather than an assumed shared pinout.

The referenced diagnostic approach distinguishes power supply and wiring integrity from the pump assembly. A grounded control path can require a harness repair; the code alone cannot establish an internal pump short. Preserve the fault context, relevant electrical findings, and whether the condition persists after correction.

Do not apply power to a suspected shorted circuit or force the pump to run as a workaround. Qualified service should use the correct wiring diagram and cooling-system precautions, then perform recurrence verification and the necessary readiness checks. A four-second detection criterion is a monitor specification, not an instruction to deliberately create the fault.

# P0919: Passat DSG receives an undetermined selector position

For the Passat 2015 DQ-250 6F transmission, P0919 evaluates an error indication carried in the selector-lever CAN message. The fault criterion is a flag stating that the selector position cannot be determined. The message itself must not have a communication failure. This is a distinction between unavailable communication and a received message reporting unusable position information.

## An undetermined position needs context

Volkswagen lists 20 milliseconds of monitoring and a two-driving-cycle MIL schedule. Enabling conditions include terminal 15 above 4 volts for more than 500 milliseconds, battery voltage above 9 volts for more than 500 milliseconds, and engine speed above 500 rpm. The short monitoring interval is not a safe duration for forcing an uncertain engagement.

The generic position-control-error title might suggest that a transmission actuator failed to move. This particular row instead points first to the selector's reported error status. It does not supply a motor-current limit, an analog sensor voltage threshold, or a mechanical shift-fork tolerance.

A useful diagnostic record captures the reported selector state, the error flag, supply conditions, and companion DTCs. Because normal message availability is a prerequisite, communication faults should be assessed in their own context rather than assuming that every position error is a missing CAN signal.

The monitor table does not prescribe a selector, mechatronic unit, or complete transmission replacement. Qualified service should use the applicable DQ250 procedure to determine why position was reported as undetermined and confirm the repair. Avoid forcing gear selection or bypassing interlocks when the system cannot establish the commanded position.

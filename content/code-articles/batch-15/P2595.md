# P2595: Bank-two turbo-speed low requires an unchanging pulse signal

P2595 is the low-state electrical check for the bank-two turbo-speed input in this GM file. The line must be low while pulse-time and pulse-number differences remain zero. That combination matters because an ordinary pulse waveform also spends time at a low logic level.

## When the check is eligible

The row requires at least 50 counts of the combined condition, an engine speed above 1,500 rpm and supply voltage at or above 9 V. It also explicitly requires the boost-control-active flag to be false. Failure confirmation is listed as 500 ms, with two-trip reporting.

A test made during active boost control is therefore not automatically comparable to this documented monitor window. Nor does a dashboard or scan-tool rpm value alone show whether the input is electrically stuck.

## Interpret the missing information

The diagnostic question is whether bank two provides successive pulses when this controller expects to evaluate them. Retain input state, pulse progression and eligibility together. If the system never enters the required state, a non-returning code has limited value as a verification result. The source establishes the electrical symptom but supplies no pinout or isolation sequence for identifying the failed circuit element.

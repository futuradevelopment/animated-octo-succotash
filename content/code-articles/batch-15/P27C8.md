# P27C8: Valve-three circuit high can be retained from a shutdown test

For P27C8, the source identifies synchronizer actuation valve three. During operation, its electrical diagnostic checks a supply-dependent output voltage and disagreement between requested current and an estimated current derived from driver behavior. A fixed voltage alone is therefore an incomplete account of this DTC.

## A second route occurs at shutdown

The controller also tests for an unwanted connection between low-side outputs by activating them one at a time. A reciprocal fault pattern when the two commands exchange states indicates coupling. That result is written to nonvolatile memory and reported at the following startup.

A code noticed immediately after starting may therefore describe a previous shutdown event rather than a continuously high valve-three signal at that moment.

## Preserve which route failed

Keep the active-output diagnostic status or retained shutdown-pair information with the code. A normal energized-current trace does not necessarily clear the cross-circuit route, while a clean shutdown result does not by itself explain an earlier active current-estimation failure. The source’s generic solenoid-P name requires controller-specific mapping. Applicable service information is needed to identify the circuits and isolate the defect; the code does not reveal a specific neighboring wire or failed part by itself.

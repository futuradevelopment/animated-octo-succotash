# P2775: An upshift paddle can be electrically plausible yet between valid states

P2775 is the upshift-paddle plausibility check in this transmission table. The input must lie outside **both** the accepted pressed-state window and the released-state window. A voltage can therefore be unsuitable for identifying a switch state without necessarily being at an extreme electrical limit.

## Distinguish plausibility from a stuck switch

The source requires the invalid-state condition for two seconds and no separate electrical fault on the paddle-plus input. This differs from the neighboring stuck-paddle strategy, which times how long the signal stays in the pressed window. P2775 is about failing to fit either legitimate state, not simply holding the paddle too long.

## Capture the state transition

A useful verification records the analog input through release and operation, together with whether the controller recognizes a valid state. Looking only at a final on/off indication can hide an interval spent between windows. The routine also requires normal application operation, rather than error or bypass mode.

Exact voltage windows are referenced through the source’s attachments and are not guessed here. Match the calibration’s service data before applying numerical boundaries. This monitor does not by itself locate a switch, connector or controller defect; it explains why the input’s state interpretation was rejected.

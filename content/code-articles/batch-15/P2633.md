# P2633: Tank-transfer pump circuit-low evidence comes from the tank module

P2633 is described in this GM file as a low-voltage diagnostic for the tank-transfer pump. The relevant input is the fuel tank zone module’s short-to-ground diagnostic signal. It should not be read as a measured low fuel-pressure result merely because the component is a pump.

## Command state changes the interpretation

The row provides two accepted diagnostic-state values. One is evaluated directly; the other is paired with the transfer pump being active. Module crank voltage must be below 14.52 V, with the listed inhibit conditions satisfied. The failure interval is 500 ms and reporting is two-trip.

The active-state branch makes the pump command important evidence. Seeing the code with the pump currently inactive does not establish what state existed when the controller evaluated it.

## Build a useful event record

Retain the tank module’s diagnostic status, activation state and voltage at the same event. This distinguishes a controller-reported circuit-low problem from assumptions about mechanical pumping performance. Applicable service information is needed to identify the specific transfer circuit and isolate it safely. The summary does not prescribe opening fuel lines or replacing a pump, and it does not prove which circuit element created the short-to-ground report.

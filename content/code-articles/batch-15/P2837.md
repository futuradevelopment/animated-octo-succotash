# P2837: Rod-two consistency uses independent gear evidence before blaming position

P2837 is the position-consistency code for rod two in this GM transmission. During engagement, speed evidence can indicate a completed gear engagement while the rod reading remains more than 1,100 micrometres from its learned engaged position. The source requires adequate commanded force and no electrical position-sensor fault before interpreting this mismatch.

## A static disagreement needs corroboration

When no outside force acts on the rod, the controller also checks learned position tolerance bands. A reading outside them becomes suspicious, then speed information is independently checked against engine and driven-wheel references. The static confirmation interval is 500 ms.

This matters because a position signal should not be condemned merely for disagreeing with an unreliable speed reference.

## A frozen value is tested another way

An integrity routine attempts small rod-two movements in both directions. It combines absent motion with a successful complementary rod-one test through a shared valve path. That alternate response helps distinguish stuck feedback from an actuation valve that cannot move anything.

Preserve which diagnostic branch failed, its learned positions and the confirming signals. A normal-looking position after clearing the code does not verify all three routes. Vehicle-specific service information is required for intrusive tests and component isolation.

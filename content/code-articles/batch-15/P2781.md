# P2781: A downshift input-high fault concerns voltage, not a held paddle

P2781 identifies an electrically high downshift-paddle input in the cited GM controller. The source lists a threshold above 4,774 mV, 30 mV hysteresis and a confirmation time of at least 150 ms. This is a voltage-window check, not a timer measuring how long the driver holds the paddle.

## Supply conditions affect the result

The monitor operates with battery voltage above 8.75 V and below 18 V. The engine must not be cranking and the key state must not be stop. P0882 and P0883 disable evaluation. Those prerequisites should accompany any conclusion that a later test has passed.

## Keep the input and command distinct

A downshift command can be valid even though the high electrical limit is never approached; the two concepts are not interchangeable. Verification should retain raw TAPDN voltage during release and operation, together with monitor status. A normal recognized switch state observed later cannot rule out an earlier high-voltage interval.

The source does not establish a universal paddle connector or component location. Apply the vehicle’s circuit information to distinguish a switch issue from wiring or controller-input behavior. The code reports what the input did, rather than proving which component must be replaced.

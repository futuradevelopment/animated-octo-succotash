# P27D7: Valve-five low-circuit classification must be separated from stuck-off behavior

P27D7 is the circuit-low diagnostic for synchronizer actuation valve five in this controller. The source uses the driver’s short-to-ground classification for its monitored output node. It does not infer this electrical condition merely because rod five failed to move.

## Operating state affects interpretation

The row describes evaluation during solenoid actuation with internal switching-time conditions. The DTC interval is at least 150 ms. An isolated voltage value, without knowing how the driver was commanded, loses the context needed to compare it with the monitor.

Battery voltage must be above 8.75 V and below 18 V. The system must be outside safe state, the engine not cranking and the key not in stop. Supply faults P0882 and P0883 inhibit the routine.

## Build separate electrical and hydraulic evidence

Retain valve-five driver status, command and controller voltage before deciding whether a hydraulic symptom shares the same cause. The separate stuck-off monitor uses rod motion and current-profile evidence, which this low-circuit code does not replace. Vehicle-specific service documentation must identify the actual circuit and safe measurement procedure. The source does not isolate a coil, connection, harness or output-stage defect solely from the DTC.

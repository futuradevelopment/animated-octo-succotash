# P2671: Supply B high is a shutdown switch test in this controller

The P2671 monitor in this transmission table tests high-side output two after it is disabled during powerdown. A voltage above 70% of battery voltage is the listed shorted-switch criterion. This differs from the related open-load check, which uses a different test configuration and threshold.

## Timing explains an apparently normal startup

The controller saves the shutdown failure in nonvolatile memory and reports it at the next startup. Finding a normal value after the code appears does not establish that the earlier shutdown test passed. The relevant interval is at least 60 ms, with battery change during the test below 1.5 V.

The source also restricts supply voltage and disables the check for P0882 or P0883. These conditions affect whether a follow-up shutdown can provide meaningful confirmation.

## Evidence to keep

Record the HSO2 shutdown-test result and whether the output was actually disabled during the observation. A high voltage while an output is intentionally powered is a different condition. The code identifies a high-side switch-path failure class in this calibration, not a universal actuator location. Applicable service information is necessary to distinguish the output stage from its connected circuit before selecting a repair.

# P2809: Differential valve stuck-on requires pressure despite a zero-current command

P2809 is the hydraulically stuck-on classification for the limited-slip differential pressure-control valve in this source. Repeated current-profile failures establish that valve response is abnormal; pressure during a controlled recovery stage determines which stuck direction is indicated.

## Pressure must match the commanded state

The routine sets the redundant shutdown valve hydraulically on while commanding zero current to the pressure-control valve. A differential pressure of at least 4 bar persisting for more than 500 ms, with three failed profile checks, supports the stuck-on result. Pressure-sensor drift and shutdown-valve stuck faults must be absent.

This is not simply a rule that any pressure above 4 bar is abnormal. The command arrangement and recovery-stage eligibility make that value meaningful.

## Verification uses combined evidence

Retain the recovery request, valve commands, measured pressure and current-profile history. A normal pressure during an unrelated drive condition cannot substitute for this test, and one failed profile alone does not supply the full classification. The source’s generic solenoid-G label is narrowed to this differential valve only within the cited implementation. Hydraulic testing and component isolation require the applicable service procedure; the table does not prescribe a universal replacement or manual valve-actuation sequence.

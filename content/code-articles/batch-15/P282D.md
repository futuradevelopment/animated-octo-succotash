# P282D: Selector pilot open-load is an off-state electrical check

P282D identifies an electrical open-load condition on the selector pilot valve in this controller. While its low-side output is off, the connected load should pull the monitored node toward battery supply. The driver’s ability to regulate the node low using a small current indicates the expected load path is missing.

## Use the pilot-valve interval

The source requires more than 5 ms of output-off time and at least 100 ms of fault confirmation. That 100 ms interval belongs to this pilot-valve row; it should not be replaced with the 150 ms value printed for several neighboring synchronizer valves.

The system must be outside safe state and have suitable supply conditions. P0882 and P0883 disable the check, so supply-related inhibition limits what a non-returning fault can demonstrate.

## Electrical and hydraulic evidence differ

This DTC does not establish that the selector spool is mechanically stuck. It assesses a circuit response under a defined off command. Preserve driver open-load status and command timing, then use the specific transmission circuit information to identify the pilot path. The generic solenoid-K name supplies no universal pinout or proof that the pilot coil, connector, harness or output stage is the failed component.

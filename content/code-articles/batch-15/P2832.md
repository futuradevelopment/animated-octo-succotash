# P2832: Rod-one plausibility is checked against speed evidence and alternate actuation

P2832 is the consistency monitor for rod-one position in this transmission. During engagement, the controller compares position with a learned engaged location while speed sensors indicate the gear has engaged. The source requires sufficient commanded force and no electrical position-sensor fault before interpreting the disagreement.

## Several checks share the code

A static branch evaluates position outside learned tolerance bands when no external rod force is present. It then validates speed evidence by comparing clutch speed with engine speed and output speed with driven-wheel information. This helps avoid blaming position feedback when the supposedly independent reference is unreliable.

An integrity branch commands small rod-one movements in both directions. If movement remains at or below 100 micrometres, an alternate test must show rod-two movement through a shared valve path. That corroboration helps distinguish a stuck feedback value from a valve that cannot actuate.

## Preserve which branch failed

Keep the learned positions, gear and speed evidence, force commands and completed integrity cases. A single plausible position display does not verify every route. The source does not make P2832 a universal instruction to replace a fork-position sensor; the applicable service procedure must resolve the specific failed comparison and component.

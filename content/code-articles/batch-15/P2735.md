# P2735: A clutch-lubrication valve fault uses repeated current-profile checks

Although the generic P2735 title refers to pressure-control solenoid F intermittent behavior, this GM transmission table uses it for a stuck clutch-lubrication valve. The controller repeatedly performs a current-profile check and looks for a consistent failure pattern. The article’s interpretation is limited to that documented implementation.

## Conditions that make the check meaningful

Transmission oil must be at least 60°C. The clutch must be closed, actuation stable and no electrical fault present for the lube valve. Adaptation, synchronizer shifting and microslip functions must not be active. The cooling-flow target must be below 5.5 litres per minute, with zero cooling flow permitted for both clutches.

These are specific opportunities for testing; a cold or actively shifting drive does not automatically repeat the monitor.

## Repeated results, not one current sample

At least five failed profile checks confirm the fault. The source changes repeat intervals according to whether previous results were successful or failed, so elapsed time alone is not a reliable count of completed checks.

Preserve the profile-test history and eligibility states. A single current value cannot substitute for the profile outcome. The table supports a stuck-valve diagnosis in this calibration but does not provide a universal hydraulic repair or component-replacement procedure.

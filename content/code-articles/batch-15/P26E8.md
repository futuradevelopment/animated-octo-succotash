# P26E8: Supply D circuit low includes a high-current failure branch

The P26E8 row monitors transmission high-side output eight. It accepts either voltage below 40% of battery voltage or measured current above 5 A as a failure. The second branch is important: a circuit-low label can summarize excess-current evidence even when a later voltage snapshot appears normal.

## Establish whether the monitor was enabled

The controller requires a successful shutdown-path test. Battery voltage must lie above 8.75 V and below 18 V, the engine must not be cranking and the key state must not be stop. P0882 and P0883 inhibit the check. The listed confirmation period is at least 60 ms.

A startup or supply disturbance outside that window is not automatically the same event as an eligible HSO8 fault.

## Preserve the two branches

Useful diagnostic data includes HSO8 voltage, current feedback and the prior path-test status. Looking only for a continuously low voltage can overlook a transient overload classification. The current figure is a monitor threshold, not a service instruction to force the circuit to that value. Identify the exact output and connected load using the vehicle’s service information. The source does not determine which component created the fault or provide a universal replacement recommendation.

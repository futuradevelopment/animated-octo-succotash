# P27D5: Valve-five open-load remains an electrical off-state test

P27D5 maps to synchronizer actuation valve five’s electrical open-load check. With the low-side output off, the load should pull the monitored node toward the supply. The driver uses a small diagnostic current to test whether the node can instead remain in its defined low window, indicating an absent load path.

## Read across the page boundary

Page 928 begins the row; page 929 continues its voltage window, off-time and confirmation requirements. The output must have been off for more than 5 ms, and the fault must meet at least 150 ms confirmation. Ignoring the continuation would omit key conditions.

The controller must be outside safe state with eligible supply voltage. P0882 and P0883 disable this test. Hydraulic motion is not its measured criterion.

## Avoid the wrong inference

A rod-five movement failure can motivate further diagnosis but does not independently prove an open valve-five circuit. Conversely, a successful energized command does not repeat the off-state test. Retain driver open-load status and command timing, then use the applicable wiring information to isolate the path. The generic solenoid-S label does not supply a universal connector or identify the failed component by itself.

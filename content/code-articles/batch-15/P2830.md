# P2830: Selector pilot high can originate in a shutdown cross-output test

P2830 maps to the selector pilot valve in the cited transmission. Active monitoring evaluates a supply-dependent driver voltage and estimated-current disagreement. The same code also covers a shutdown test for an unwanted connection to another low-side output.

## Why a startup code may describe powerdown

During shutdown, outputs are activated one by one. A reciprocal ground-like fault response when the pilot output and another output exchange on/off states supports cross-circuit coupling. The result is retained in memory and reported at the next startup. This route uses the pilot’s 100 ms confirmation interval.

A high or normal voltage observed during later running does not reconstruct that paired shutdown test.

## Keep the two diagnostic routes distinct

Preserve whether the record came from active driver evaluation or the retained cross-output sequence. For the latter, information about the paired channel matters; the generic solenoid-K title cannot identify it. A normal current trace under one command does not clear all routes to this DTC. Applicable service documentation is needed to map the pilot circuit and isolate the fault. The summary does not prove a specific bridge, defective coil or failed controller output.

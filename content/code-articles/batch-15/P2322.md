# P2322: Reading an ignition circuit-high code without guessing the cylinder

The P2322 row in GM’s 2025 file describes a primary ignition low-side output that remains high during an on command. This is the source’s short-to-power classification. It is a command-dependent electrical finding, not a direct test of the spark plug or combustion quality.

## Conditions behind the stored result

Ignition must be synchronized, engine speed must exceed 1,400 rpm and the ignition counter must advance sufficiently. The table specifies a 0.4-second interval and two-trip reporting. These details mean a stopped-engine voltage reading, even if high, does not establish the same result.

A meaningful verification distinguishes whether the output is high throughout the commanded active interval or only outside it. The latter observation would require a different interpretation. Use the applicable service method rather than improvising access to an operating ignition circuit.

## Resolve the source disagreement

The catalog title identifies coil H; this GM table identifies coil F. That discrepancy remains unresolved and prevents a trustworthy physical-coil recommendation here. Confirm the vehicle calibration and wiring assignment before selecting a circuit. The article deliberately preserves the electrical finding without inventing a cylinder mapping or treating the code as proof that a replacement coil will repair the fault.

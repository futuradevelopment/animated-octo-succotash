# P27D2: Valve-five stuck-on uses a larger single-rod movement criterion

The P27D2 criteria concern synchronizer actuation valve five and rod five. They list unintended rod displacement of at least 4,000 micrometres within 200 ms of a selector-target change, while rod-five force target is zero. This differs from the paired-rod movement and relaxation criteria used for other valves in the same file.

## Use the actual criteria, not a copied pattern

Both hydraulic-on and hydraulic-off selector targets appear as alternative cases. The source requires no electrical fault for rod-five position or valve five and excludes application error and bypass states. The movement must therefore occur without an intended rod-force request in a valid diagnostic state.

The narrative still discusses relaxation of another rod, but the explicit P27D2 criteria name only rod five. That inconsistency remains flagged; this article does not invent a second rod or apply another valve’s 125-micrometre relaxation test.

## Verification focus

Preserve selector timing, rod-five position and its zero-force command together. A later stationary position cannot show the unintended transition. Applicable service information must resolve the exact implementation before intrusive operation. The monitor’s hydraulic classification does not alone identify the specific failed internal part.

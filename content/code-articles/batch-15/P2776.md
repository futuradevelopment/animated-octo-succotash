# P2776: Upshift input low needs a calibration check before applying the number

The P2776 electrical monitor checks the upshift-paddle analog input against a lower working limit. Its row prints 2,519 mV with 30 mV hysteresis and a 150 ms confirmation period. However, the same document elsewhere lists a pressed-state window beginning at 2,200 mV. That overlap is retained as a source-review issue, not silently repaired.

## What remains useful

The supported distinction is between an electrical-low classification and a logical plausibility fault. P2776 evaluates the input voltage directly; the separate P2775 monitor asks whether the value fits a valid pressed or released state after electrical faults are excluded.

The low check requires suitable controller battery voltage, no cranking and a non-stop key state. P0882 and P0883 disable it, so a supply fault can affect whether a verification attempt is eligible.

## Do not turn the conflict into a repair instruction

Record the input, supply status and exact calibration. Resolve the applicable voltage boundaries in current vehicle service information before judging a measured value near the disputed region. The summary does not justify replacing the paddle from its generic title, nor does it prove whether a switch or another circuit element pulled the input low.

# P282F: Selector pilot circuit low uses driver evidence, not rod movement

P282F is the circuit-low monitor for the selector pilot valve in this transmission. The driver reports a short-to-ground classification after evaluating its output node during the documented switching conditions. A selector routing fault or an unresponsive rod does not independently establish that electrical result.

## The pilot’s timing matters

The listed confirmation interval is at least 100 ms. Several neighboring valve monitors use longer intervals, so their timing should not be copied into this diagnosis. The source also requires the system outside safe state, valid battery voltage, no cranking and a non-stop key condition.

P0882 and P0883 disable the monitor. If the controller is dealing with an ineligible supply state, absence of a fresh P282F is not a completed verification.

## Evidence for the next decision

Retain pilot-valve command, driver fault status and supply context on the same event. That establishes whether the electrical-low classification returns before attempting to explain a hydraulic symptom with it. Applicable service information must identify the actual circuit and permitted measurement method. The source’s solenoid-K mapping is implementation-specific and does not identify a universally replaceable component from the code alone.

# P2579: Turbo-speed plausibility is a difference test, not overspeed

P2579 is a plausibility check in the cited GM monitor. It compares the current turbo-speed value with a version whose rate of change has been limited. The listed failure is an absolute difference above 250,000 rpm, evaluated with engine speed above 1,000 rpm and a 50 ms interval.

## What the comparison means

This is different from asking whether actual turbo speed exceeds a maximum. A rate-limited reference responds differently to abrupt changes; disagreement with it identifies signal behavior that the plausibility check rejects. Do not translate the difference threshold into a normal operating-speed specification.

An informative record keeps the current speed, filtered reference and engine speed together. A single speed value cannot show whether the comparison failed, while a successful observation outside the enable window is not proof of monitor completion.

## Bank identity requires review

The generic title identifies sensor A. The GM row labels its compared signal bank 2, while the companion P2594 row names bank 1. The relationship between generic sensor letters and these source-specific bank labels is not established; the naming difference alone does not prove an error. Resolve the actual calibration and sensor mapping before locating hardware; the monitor does not itself prove that the sensor needs replacement.

# P27B9: Shift solenoid two stuck-off is checked with controlled rod movements

The generic solenoid-N performance code P27B9 corresponds to shift solenoid two hydraulically stuck off in this transmission table. The controller’s integrity routine commands small rod movements; it is not intended to engage or disengage complete gears during the test.

## Why two rods and another valve matter

The tested pressure valve is exercised with opposite selector states for rods one and two. Movement at or below 100 micrometres across the relevant test cases supports a failure to actuate. The continuation then requires movement above 100 micrometres through an alternative valve path to validate position-sensor operation.

That comparison is essential. No movement from one test alone cannot distinguish an ineffective valve from feedback that fails to report motion.

## The routine must actually run

The integrity sequence is triggered by recovery logic or a startup disagreement between retained gear state and sensor evidence. A normal drive that never executes the sequence is not a repeat of its diagnostic tests.

Preserve which cases completed and which alternate movement verified the sensor. The result supports a hydraulic stuck-off classification for this calibration, but the summary is not an instruction to command intrusive transmission movements manually or replace a solenoid without the applicable service procedure.

# P283C: Rod-three consistency is tied to the even-clutch speed references

P283C identifies rod-three position inconsistency in the cited transmission. Its dynamic engagement branch compares the sensor with a learned engaged position while speed signals indicate the gear has engaged. A disagreement greater than 1,100 micrometres is evaluated only with adequate force request and without an electrical sensor fault.

## Validate the reference before condemning the sensor

The static branch checks learned tolerance bands with no outside rod force. It then verifies even-clutch speed against engine speed and output speed against driven-wheel information. The source lists a 500 ms out-of-limits interval, making the independent-reference check part of confirmation rather than an optional observation.

## A second path checks for frozen feedback

The integrity routine attempts small rod-three moves in both directions. If motion remains no greater than 100 micrometres, a complementary rod-four movement through a shared valve must demonstrate that the actuation path can work. That comparison helps separate stuck position feedback from a valve failure.

Preserve the actual branch, learned locations, force commands and confirming speed or alternate-rod evidence. A single plausible rod position cannot verify every route. The generic fork-C label is not a universal component location; intrusive tests and final isolation require the relevant transmission service procedure.

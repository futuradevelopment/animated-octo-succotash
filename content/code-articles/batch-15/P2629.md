# P2629: The upstream bank-two oxygen sensor’s compensation path is open

P2629 concerns the bank-two upstream wideband oxygen sensor’s compensation-resistor path in the cited GM strategy. The controller calculates a parallel resistance between named sensor interface lines and flags a value above 240 ohms as an open-path finding. That is different from diagnosing the air-fuel mixture as lean or rich.

## The sensor must be ready for this check

The monitor requires the upstream sensor to be heated. The source accepts either ceramic temperature above 790°C or completion of its heating-up phase. It also requires the requested switch-on mode and a sensor-interface verification history, with no aborted last packet transfer.

Those prerequisites matter: a cold sensor measurement does not directly reproduce this operating-state calculation. The listed fault interval is 0.01 seconds, with two-trip reporting.

## Interpret the calculated value carefully

The 240-ohm figure is a controller-calculated parallel path, not a universal instruction to disconnect the sensor and measure every terminal with an ohmmeter. Appropriate service information must define the relevant circuit and permitted test method. Preserve heater readiness, interface mode and the open-path status together. The DTC supports a compensation-circuit concern but does not establish a fuel-trim repair or identify the sensor alone as the proven failed part.

## Document scope and source

# P2779: Downshift plausibility rejects a value that fits neither switch state

P2779 is the downshift-paddle plausibility monitor in this GM transmission file. Its failure requires the analog input to be outside the accepted pressed window and outside the released window. The issue is an unrecognizable switch state, not merely a command to shift down.

## The electrical check comes first

The routine requires no separate electrical fault for the paddle-minus input. That allows it to evaluate values that may avoid an extreme circuit-high or circuit-low fault yet still fail the state windows. The confirmation period, continued onto the next page, is two seconds.

The source also requires normal application operation, with neither error nor bypass state active. Those conditions matter when a fault disappears after a controller reset without a completed reevaluation.

## Observe more than the final state

A useful record follows the analog value and recognized switch state during operation and release. A brief state display can miss a sustained intermediate value. The source references calibration-specific windows, which are not invented here.

P2779 should also be distinguished from the separate monitor for a paddle remaining pressed too long. Applicable service data is needed to determine why the input cannot represent either valid state and to isolate the circuit before replacing a component.

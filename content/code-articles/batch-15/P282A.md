# P282A: Selector pilot stuck-on needs both wrong-route movement and a failed profile

For P282A, the selector is commanded hydraulically off but the integrity test sees movement consistent with the on routing. The intended rod travels no more than 100 micrometres, while the complementary rod moves beyond that boundary. This establishes a selector-mechanism problem, not yet the identity of the component responsible.

## The current-profile result narrows the diagnosis

The source uses repeated failed pilot-valve current-profile checks to assign the problem to the selector pilot valve. That distinction matters because a selector spool can create a similar routing symptom. The routine requires cooler-out temperature of at least 40°C and valid synchronizer integrity operating conditions.

One confirmation-counter label in the row says stuck off despite the stuck-on heading and hydraulic-off target. That wording remains a source-review issue rather than being silently rewritten.

## What a complete record contains

Preserve the selector command, both rod responses and profile outcomes. No single position trace or generic stuck-solenoid title supplies the whole conclusion. The routine is an intrusive controller diagnostic with small commanded movements, so the summary is not a substitute for the vehicle-specific procedure. It explains how the controller distinguishes the pilot from other selector components without prescribing an automatic replacement.

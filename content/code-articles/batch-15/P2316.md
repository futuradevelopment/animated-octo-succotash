# P2316: Why ignition-driver high is judged during an on command

P2316 is not simply an instruction to replace the coil named in a generic scan description. GM’s cited row detects a high primary-driver signal during the on state and classifies that response as a short toward power. The command supplies the context that makes a high reading abnormal.

## Evidence that changes interpretation

The controller waits for synchronized ignition and an engine speed above 1,400 rpm. It also checks ignition-counter advancement, so a static key-on observation does not exercise the complete monitor. The table gives a 0.4-second failure interval and two-trip reporting.

When reviewing a recorded event, distinguish the commanded on period from surrounding off periods. A signal that is high only when the driver is off does not demonstrate this documented fault. Likewise, a misfire description alone does not establish the required electrical response.

## A naming discrepancy limits location advice

The generic code title says coil F, while the source row identifies coil E. Both cannot be treated as an unqualified cylinder instruction. Keep the code, module identity and source calibration together, then resolve the physical circuit using applicable service information. This monitor classifies the observed driver behavior; it does not isolate a harness, coil or controller as the failed part.

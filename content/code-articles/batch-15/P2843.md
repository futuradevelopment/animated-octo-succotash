# P2843: Rod-four circuit high has two distinct digital-signal routes

P2843 concerns rod-four position feedback in the cited transmission. The source detects either no pulses with the input above 3.5 V or duty cycle above 92%. It lists a 150 ms confirmation interval. Neither branch is a direct claim that the mechanical fork is too high or has travelled too far.

## Distinguish a static line from a distorted pulse train

The first route needs missing transitions as well as the high electrical state. The second can fail even while pulses continue. A single voltage sample or averaged reading cannot reliably identify which pattern occurred.

The VREF2 enable fields in this source print above 5.5 V and below 4.5 V simultaneously. That contradiction remains flagged, with no assumed reversal of the limits. The inhibit list includes P0652/P0653 and P0882/P0883.

## Verification preserves channel and supply context

Record rod-four pulse activity, duty cycle and reference-supply status together. A later normal position display does not prove the original waveform was valid. Use the vehicle’s calibration-specific service information to resolve supply eligibility and the permitted test method. The code classifies an electrical symptom but cannot alone identify the sensor, harness or controller input as the failed part.

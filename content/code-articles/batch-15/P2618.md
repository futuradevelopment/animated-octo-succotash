# P2618: Replicated crank output low is different from a crank-sensor input fault

P2618 refers here to the **replicated crankshaft output**, not directly to the crankshaft sensor’s incoming signal. GM’s monitor uses a power-stage report that the replicated output is shorted to ground. That distinction can change which circuit a technician investigates.

## The output report is the evidence

The row lists a one-second confirmation interval and two-trip reporting, subject to the controller’s basic enable conditions. It does not describe a missing-tooth analysis, crank-to-cam alignment check or direct measurement of engine timing. Treating P2618 as proof of a failed crankshaft sensor would exceed the evidence.

The adjacent P2619 entry reports the opposite electrical fault class on the replicated output. Neither code provides a universal connector location in this summary.

## Follow the signal direction

Useful diagnostic records identify the module that set the code, the replicated-output status and whether its fault report persists during an eligible check. An apparently good engine-speed display may coexist with an output-path problem, because displaying speed and distributing a replicated signal are different functions.

Confirm the relevant output circuit and its receiving system through vehicle-specific service information. The monitor tells you what the driver reported, but it does not isolate an external short, connected load or internal output-stage defect.

# P2746: Clutch-two speed plausibility needs pressure and slip context

P2746 is used here for clutch-two speed-sensor consistency. One branch compares that sensor with engine speed while clutch two is fully closed. An absolute difference of at least 150 rpm lasting 1,100 ms is the listed failure criterion for that branch.

## Why pressure control matters

The comparison is enabled only with no electrical speed-sensor fault, no microslip function and satisfactory even-clutch pressure control. The source also limits the difference between pressure request and target. These prerequisites matter because genuine clutch slip would otherwise resemble a sensor disagreement.

A second branch compares the sensor with speed derived from the output and engaged gear. It requires agreement between gear-position evidence and the logical gear, plus output-speed consistency with wheel-speed information. This is a cross-check among independent signals, not a conclusion drawn from one rpm display.

## Preserve the qualifying conditions

Record engine, clutch-two and output-speed information with clutch state and pressure-control status. A disagreement during an intentional slip phase is not the same evidence as the closed-clutch branch. The source explains how the controller rejects inconsistent information; it does not prove that a speed sensor is defective without verifying the conditions that exclude actual mechanical slip.

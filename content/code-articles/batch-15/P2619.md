# P2619: Why a crankshaft output-high fault does not prove lost timing

The P2619 strategy in this GM file monitors a replicated crankshaft signal output. The trigger is the output stage reporting a short to battery. This is an electrical report from a signal-distribution path, not a calculation showing that the crankshaft and camshaft have lost mechanical alignment.

## Conditions in the source

The row requires ignition on and lists a one-second interval with two-trip reporting. Battery eligibility is also present in the source, but the extracted comparator glyph is not used here as a numeric workshop specification. The supported event remains the driver’s short-to-battery status.

## Avoid investigating the wrong side

A crankshaft speed value can still be available while a replicated-output circuit has a problem. Accordingly, a normal rpm display does not alone clear this output fault, and the code does not automatically condemn the original crank sensor.

Record the reporting controller and replicated-output diagnostic state. Then use the applicable wiring and service information to establish where that output goes and how it is tested. The summary gives no universal pin number or component-isolation sequence. A circuit-high classification narrows the type of electrical behavior, but does not prove which component or connection caused it.

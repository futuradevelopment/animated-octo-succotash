# P2596: Separating a static high turbo-speed input from valid pulses

A high speed-sensor logic level is not inherently faulty. For P2596, the GM monitor also requires zero change in pulse timing and pulse count, so the finding concerns a bank-two input that is not progressing as a pulse signal.

## Conditions behind the classification

The controller counts at least 50 occurrences of the combined condition. The engine must exceed 1,500 rpm, battery voltage must reach at least 9 V and the boost-control-active flag must be false. These conditions are part of interpreting the event, rather than optional context to discard after reading the DTC.

The source prints 655350 ms in the timing field. Its intended calibration meaning is not resolved here, so it is not used as a workshop waiting instruction. The article retains a source-review flag for that detail.

## Verification focus

An appropriate record distinguishes a static high signal from a healthy waveform sampled during its high phase. Observe pulse progression and controller eligibility together using the vehicle-specific service method. The code does not establish the physical sensor location from the generic letter alone, nor does it identify a sensor, harness or module as the proven repair.

# P21F7: Bank-two rich adaptation is a control limit, not a parts verdict

## Read the correction in the correct operating mode

Audi defines P21F7 in this CREC table as system-B multiport fueling too rich on bank two away from idle. The adaptation value reaches negative twenty-five percent or less, with a twenty-second observation period. The engine must meet warm, stable part-load qualifications, including the specified fuel-flow and speed windows.

The negative value describes the controller's corrective response. It does not directly establish a leaking injector, failed pressure regulator or inaccurate oxygen sensor. Those possibilities need evidence from their respective checks rather than a conclusion drawn from the sign of adaptation alone.

## Retain the bank-two diagnostic path

The source refers to pressure and residual-pressure checks, B-circuit injectors, G247 and the bank-two oxygen-sensor paths GX11 and GX8. These references make the physical bank and the active fueling system relevant when selecting scan data and workshop tests.

The table's continuation contains unavailable purge-related values, so this article remains marked for review of the incomplete eligibility detail. It does not offer a fabricated full drive-cycle recipe or substitute thresholds from a different engine.

Record the original operating data and related mixture or pressure faults before clearing memory. A qualified technician should evaluate fuel delivery and feedback using the correct high-pressure and fire precautions. Verification requires acceptable bank-two correction after the applicable control and monitoring events; a temporarily reset adaptation value is not evidence that the rich condition has been repaired.

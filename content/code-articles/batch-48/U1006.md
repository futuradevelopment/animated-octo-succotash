# U1006: The front NOx sensor module stops sending messages

## Both the startup and voltage conditions matter

In the CPNA/CPNB table, U1006 concerns missing communication from NOx sensor one, identified as the front sensor. The controller must be more than 500 milliseconds past ignition-on, with battery voltage between 9.5 and 16.5 volts. The missing-message condition is observed for more than 500 milliseconds.

The startup qualification and missing-message observation are separate entries. They should not be compressed into an assumed universal one-second timeout. The table lists continuous checking and a two-driving-cycle lamp response for this calibration.

## Missing information does not measure exhaust chemistry

A lack of messages cannot establish the actual NOx concentration or prove poor catalyst performance. The code identifies the sensor-module communication path. Audi refers diagnosis to the NOx control-module procedure covering J583 and J881; the front/rear identity must remain attached to the actual installed arrangement.

Preserve related voltage, sensor-module and network faults before clearing memory. A technician should verify the correct module, its supply and communication path using current vehicle information rather than replacing a sensing assembly solely from the word “NOx.”

After repair, confirmation should demonstrate stable messages from the intended front module under eligible startup and voltage conditions. A working rear sensor or a scan tool that connects to the engine controller does not prove that the missing front-sensor exchange has been restored.

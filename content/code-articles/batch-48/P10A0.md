# P10A0: The supercharger bypass actuator has two electrical fault branches

## The monitor is broader than a single short-circuit label

In the CREC table, P10A0 covers the supercharger bypass actuator. One branch watches recirculation-flap output current against a calibrated limit shown in the 9.3–15.0-amp range. Another identifies duty cycle beyond positive or negative 95 percent when flap-position adaptation is inactive. The monitor uses half a second and a two-driving-cycle lamp schedule.

The second branch matters because a command near its control limit is a different observation from excessive current. Neither branch, by itself, locates an external short or proves that the complete supercharger must be replaced.

## Use the correct J808 assembly information

The table directs diagnosis to control-valve control unit J808. The companion section identifies its motor and position-feedback functions, but its general description uses turbocharger/wastegate wording despite this supercharger-bypass application. That inconsistency is retained as a source-review flag; it is not reproduced as a claim about CREC hardware.

A technician should preserve related flap-position and adaptation codes, verify the installed assembly and use the matching circuit information to compare command, current and feedback. A numerical current range from the table is not a universal bench-test specification.

After the underlying cause is corrected, verification must distinguish restored electrical response from merely clearing the code. Both actuator control and believable position feedback matter to the bypass function, while the exact test conditions depend on the active monitor branch.

# P148B: Current continues when SCR heater circuit one is off

## The off command is central to this fault

P148B describes an output-stage problem in SCR heater circuit one in Volkswagen's CRUA/DEJA table. The diagnostic condition is heating activity while the circuit is switched off, with current above 200 milliamps. The table requires the SCR heating command to be off and observes the condition for 500 milliseconds.

This is the opposite of an assumption that every reducing-agent heater fault means a heater failed to warm. Here the controller is looking for activity that should have stopped. The strategy names an external short to positive, but the fault record alone does not locate the short or prove a particular assembly must be replaced.

## Evaluate command and response separately

Useful evidence includes the controller's requested state and the measured feedback at the same event. Testing only whether the heater can turn on would not answer the unwanted-current question. The correct circuit-one wiring and control-module arrangement must be identified on the actual vehicle.

The linked J891 procedure checks supply and wiring before a component decision, but later mixes J891 and J880 terminal references. That source issue is retained as a review flag, so a technician should obtain the matching diagram rather than use a copied connector sequence.

Avoid bypassing the heater controller to reproduce a fault. After repair, confirmation should establish that the circuit remains inactive when commanded off and that the original output-stage condition does not return under eligible monitoring.

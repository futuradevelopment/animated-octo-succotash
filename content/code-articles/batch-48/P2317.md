# P2317: Coil F has its own open-circuit monitoring channel

## Identify the correct coil before interpreting the voltage window

P2317 is the CREC ignition-coil F secondary-circuit entry. Audi's diagnostic column identifies coil six with power output stage N324. The strategy monitors an off-state output-voltage window associated with an open-circuit condition; its hardware-dependent limits are not a universal coil-resistance specification.

The check lasts 0.8 seconds with engine speed above 512 RPM, coolant above negative 30°C and engine-stop operation inactive. Consequently, a static key-on observation cannot reproduce all of the conditions used by the controller.

## Keep the supply, command and ignition result separate

The referenced coil procedure establishes supply and controller wiring before evaluating the drive signal. That sequence helps distinguish an electrical-path fault from a conclusion about the spark plug or combustion. A coil that looks intact externally can still require circuit diagnosis, while a code naming a coil does not automatically prove the coil is the failed part.

Use the actual vehicle's cylinder and connector identification; the letter F is not a safe substitute for a verified component location. Retain related misfire information and compare it with the circuit evidence rather than treating either record in isolation.

Ignition testing requires qualified precautions against high voltage and accidental contact with moving parts. Repair verification should show that the N324 control path operates correctly and that P2317 does not return during the qualified running monitor. Merely clearing the warning does not evaluate that electrical event.

# P308D: Fuel-pump speed feedback is carried in a diagnostic message

## The label does not publish a minimum pump speed

Audi's CREC P308D entry is headed as fuel-pump speed too low. Its strategy receives fuel-pump diagnostic information over the communication path and lists either a sensor short-to-positive failure or RPM-deviation feedback of at least 2.0 in an unspecified dimensionless scale. The engine must be on, and the observation lasts 2.4 seconds.

The 2.0 value is not given as pump RPM. It should not become an invented minimum speed specification or be interpreted as direct proof of low fuel pressure. The row describes the information used by the controller to recognize the fault, while the physical delivery problem still needs to be established.

## Follow the report to the fuel-delivery system

Audi directs diagnosis to fuel delivery unit GX1. A technician should preserve related pump, pressure and communication codes and inspect the relevant command and feedback information. The short-to-positive branch is particularly useful context when a shortened scan description suggests only a slow mechanical pump.

Use the correct installed pump and control-module information before selecting electrical or pressure tests. Fuel-system work requires fire and pressure precautions; an externally powered pump or an opened fuel line is not a substitute for the factory diagnostic sequence.

Confirmation should show normal pump feedback during engine operation and no return of the original message-based condition. A successful engine start alone does not verify the complete monitored relationship, and a code title cannot establish which assembly needs replacement.

# P309D: The hybrid clutch does not separate engine and motor as expected

## Two operating checks can produce the code

Volkswagen's CGFA P309D entry concerns insufficient separation when the hybrid clutch is disengaged. One branch detects combustion-engine speed above 60 RPM while electric drive is requested and the clutch is open. A second branch evaluates engine drag at the adaptation touch point, also above 60 RPM, with drive-motor speed above 500 RPM and clutch adaptation completed.

Both branches list a 0.4-second observation, but their operating contexts differ. The first asks whether the engine remains driven despite an open-clutch request. The second concerns the behavior of an adapted touch point. They should not be compressed into a generic “replace clutch” conclusion.

## Preserve command, speeds and adaptation state

The table directs diagnosis to the appropriate hybrid repair information. A technician needs the actual requested clutch state, engine and motor speed evidence, and relevant clutch-control faults to establish which branch is involved. The five-character code does not supply those details by itself.

This work belongs with a qualified hybrid technician using the required high-voltage isolation and movement precautions. Do not force electric-drive operation or bypass a clutch command to reproduce the condition.

After the cause is addressed, confirmation should verify the intended separation and the relevant adaptation behavior through the factory procedure. A warning cleared while the vehicle is stationary does not demonstrate that either speed-based functional check has passed, and the row supplies no universal mechanical wear limit.

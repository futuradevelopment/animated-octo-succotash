# P13E0: Cylinder-one pressure timing disagrees with crank angle

## This is a timing-plausibility measurement

P13E0 links cylinder-one pressure feedback to the engine's rotational reference. Volkswagen's CRUA/DEJA table describes a pressure-derived top-dead-centre position outside ±1.8 crank-angle degrees. The check runs during fuel cut with coolant temperature above 59.96°C and uses forty revolutions. The listed lamp response is two driving cycles.

A sensor can therefore trigger this code without simply reporting an excessively high or low voltage. The issue is where the pressure event appears relative to the engine position reference. That is a different question from whether a glow plug heats correctly or whether the cylinder has adequate compression.

## Both sides of the comparison matter

The diagnostic column names pressure-sensing glow plug QX1 and engine-speed sensor G28. The G28 procedure explains that its signal supplies engine speed and crankshaft reference marks. These two references make it inappropriate to assign the fault exclusively to the glow plug from the code alone.

Preserve related pressure-sensor, crankshaft-signal and timing faults so the technician can determine which information is reliable. Check the actual engine's circuit and component identities before selecting tests. This monitor does not by itself prove that the timing drive has moved or that a mechanical timing adjustment is required.

Confirmation needs the warm fuel-cut event identified by the table. Ordinary idle operation supplies neither the same operating mode nor a sufficient basis for declaring the pressure-to-crank relationship correct.

# P007A: The first manifold-temperature channel fails its internal check

## The sensor-signal failure is the supported conclusion

Audi's CREC P007A row describes an internal hardware check of the intake-manifold temperature sensing channel. The criterion is a sensor-signal failure lasting half a second. The diagnostic destination is intake-manifold temperature sensor G72 together with charge-air pressure sensor G31.

The generic code label refers to the bank-one charge-air-cooler temperature-sensor circuit. For this application, the manufacturer's component reference is the useful way to select the correct assembly. It should not be confused with the separate second-sensor G430/G447 path used by another CREC entry.

## Do not turn a circuit code into an overheating diagnosis

The row does not specify an air-temperature limit, a resistance curve or a coolant-flow threshold. A workshop must use the matching component procedure and wiring information rather than interpreting P007A as proof that the charge air is too hot.

Preserve related pressure-sensor and temperature faults and confirm that the diagnostic tool is displaying the intended channel. A reading from an upstream air sensor may be valid while the manifold channel remains faulty; the code's identity must remain attached to the evidence.

After repair, confirm that the correct sensing path provides believable information and that the internal-failure monitor does not return. Replacing a cooling-system part, observing one normal temperature value or erasing the warning is not equivalent to verifying the circuit and sensor function described by this table.

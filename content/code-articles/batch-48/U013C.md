# U013C: Accelerator-pedal information is missing from a monitored channel

## Preserve both pedal-channel identities

Audi's CREC U013C entry concerns lost communication with the accelerator-pedal module. Its strategy lists missing received messages for pedal-position sensor one and sensor two as separate branches. Each is shown with a 0.1-second monitoring period and a two-driving-cycle lamp schedule.

The row does not identify which branch occurred from the five-character code alone. A technician should retain the complete diagnostic record and related pedal-position faults rather than assuming that both sensing channels or the entire pedal assembly have failed.

## Missing data is not the same as an implausible pedal value

This monitor concerns absent information. It should be distinguished from a separate code that receives data but rejects it as implausible. The diagnostic column refers to the CAN terminal-resistance procedure, which depends on the actual vehicle network arrangement and prescribed connection state.

Use the correct factory information to identify the participant, supply and communication path. Do not bridge pedal-sensor terminals, defeat a throttle safeguard or rely on a universal resistance value at arbitrary network pins. Accelerator-control faults require professional diagnosis; a vehicle with unreliable throttle response should not be used for an improvised road test.

After the cause is corrected, verification should demonstrate stable receipt of the expected pedal information and no recurrence of either relevant missing-message branch. A scan tool merely connecting to the engine controller does not establish that every pedal-related message is present and valid.

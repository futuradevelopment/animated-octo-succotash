# U10C2: The rear NOx module is missing from the expected exchange

## A missing message has a defined voltage window

U10C2 is the CPNA/CPNB rear NOx-sensor module no-communication entry. Audi lists no messages from sensor two as the criterion, after more than 500 milliseconds since ignition-on and with battery voltage between 9.5 and 16.5 volts. The missing-message observation itself is longer than 500 milliseconds.

These are separate qualifications, not a universal timeout that can be applied to every NOx module. The table also distinguishes this absent-message condition from U10C1, where data arrives but is implausible.

## Verify the rear module's power and communication context

The diagnostic reference covers the J583/J881 NOx control modules. The installed vehicle information must establish which assembly is the rear participant and how its supply and communication paths are arranged. A missing module report does not independently prove a failed sensing element or a catalyst problem.

Preserve the full network record and the rear module's related faults where accessible. A technician should evaluate the relevant electrical conditions before replacing components. A normal front-sensor reading cannot establish that the rear module is communicating.

Once the actual cause is corrected, confirmation should show sustained receipt of the expected rear-module messages through the eligible startup and voltage conditions. Merely reconnecting a scan tool or clearing the code from the engine controller does not demonstrate that the original missing-message event has been resolved.

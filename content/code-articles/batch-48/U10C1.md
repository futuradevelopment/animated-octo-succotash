# U10C1: The rear NOx module returns implausible data

## Keep the rear channel distinct from the front one

In the CPNA/CPNB table, U10C1 identifies implausible information from NOx sensor two, described as the rear sensor module. The monitor is qualified after more than 500 milliseconds since ignition-on and with battery voltage between 9.5 and 16.5 volts. The observation period is sixty milliseconds.

The code concerns data that has been received but is not considered plausible. It should not be treated as the rear module's lost-communication code or as a direct measurement of excessive NOx. The front and rear channels may have related diagnostic context, but they are not interchangeable test points.

## Establish the module state behind the message

Audi refers to the NOx control-module checking procedure covering J583 and J881. A technician must match the rear sensing path to the actual installed arrangement and retain the module's own faults, power-supply information and related communication records.

A sensor value displayed by a scan tool does not prove that all status information sent by that module is valid. Likewise, replacing an emissions-treatment component would not address an unresolved data-quality condition merely because the message involves NOx sensing.

After the cause is repaired, verification should show stable, plausible information from the intended rear module under eligible startup and voltage conditions. Successful communication with the front sensor or an erased warning is not evidence that the rear channel's sixty-millisecond plausibility check has passed.

# P2314: Coil E is checked through an off-state electrical signature

## The title and measured signal are different levels of description

The CREC table labels P2314 as an ignition-coil E secondary-circuit fault, while its strategy describes an open-circuit check using output voltage in the off state. The row identifies hardware-dependent lower and upper voltage boundaries and observes the condition for 0.8 seconds.

Eligibility includes engine speed above 512 RPM, coolant above negative 30°C and inactive engine-stop operation. The diagnostic column identifies ignition coil five with power output stage N323. This is more precise than assuming that every generic “coil E” description has the same physical location across vehicles.

## Verify the coil circuit before treating the title as a spark test

The low-voltage figures in this monitor are not secondary ignition-voltage measurements. Audi's component procedure separately checks the coil's supply, its controller connection and the drive signal using the specified workshop method. Those steps distinguish the electrical control path from simply observing whether the engine runs roughly.

Preserve related misfire and coil faults and match N323 to the installed engine's wiring. Testing an ignition circuit involves high voltage and moving-engine hazards; improvised spark gaps or touching a coil during cranking are not appropriate diagnostic shortcuts.

After the cause is corrected, confirmation should include normal control-circuit behavior and absence of the original monitor result under eligible running conditions. A replacement spark plug or erased code alone does not establish that the off-state electrical signature has returned to normal.

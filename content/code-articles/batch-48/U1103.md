# U1103: Production mode is an active configuration flag

## Start with configuration rather than component replacement

U1103 indicates that the engine controller is in production mode in Volkswagen's CRUA/DEJA table. The row describes the mode as activated through the diagnostic tester and records the fault during controller shutdown. Conditions include engine speed zero, vehicle speed below 5 km/h and a limited distance since initial vehicle startup.

This is a deliberate configuration state. It is not a sensor-voltage failure or evidence that the controller's hardware is damaged. A workshop should determine why the mode is active and whether the vehicle's delivery or post-repair configuration is complete.

## Use the correct mode-deactivation procedure

The source says a factory scan tool can deactivate the mode. It also mentions automatic deactivation after the first one hundred miles, while its enable-condition distance is expressed as less than two hundred kilometres. These are printed as different statements, so they should not be combined into a newly calculated universal mileage rule.

Record the exact configuration state and any recent module or delivery work. Simply driving farther or clearing fault memory is not a substitute for checking whether the intended mode has been disabled according to the matching factory procedure. Any unrelated warning or operating problem still requires its own diagnosis.

Verification should include the reported mode and the relevant shutdown event. A warning-free idle does not demonstrate that a configuration flag has changed. The interpretation here is limited to the cited Volkswagen table; identical code characters in another manufacturer namespace may carry a different meaning.

# P10A7: A changed bypass rest position triggers the adaptation code

## The observed change is narrower than the title

Audi's CREC P10A7 description refers to a soiled intake-air regulating flap. Its actual strategy monitors the supercharger bypass adaptation, and the stated fault is detection of a changed limp-home position. The table gives a 0.01-second, once-per-driving-cycle check and a two-driving-cycle lamp schedule.

That evidence does not measure deposits or prove that cleaning is the required repair. The controller has recognized a change in a learned position. Mechanical condition, feedback accuracy and adaptation history can only be separated by the relevant diagnostic procedure.

## Preserve learning history before intervening

Record related position-voltage and actuator faults and note any recent work on the assembly. Repeatedly resetting adaptation without preserving the original state can remove useful context without resolving its cause. A workshop should confirm the installed J808 assembly and the current adaptation process before deciding what action is appropriate.

The source's J808 general description includes turbocharger/wastegate wording inconsistent with the supercharger-bypass strategy. This article remains marked for review for that application language and does not turn it into a physical description of the CREC mechanism.

Avoid forcing the flap or spraying chemicals into an unverified assembly because the code title says “soiled.” Repair confirmation should show an accepted, stable learned position during the relevant event. A briefly normal running engine does not prove that this once-per-cycle adaptation check has passed.

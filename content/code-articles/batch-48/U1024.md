# U1024: The communication path reports an error bit

## The monitor reports a communication error state

U1024 is the communications-bus fault entry in Audi's CPNA/CPNB table. Its criterion is an error bit set after more than 500 milliseconds of communication time following terminal-15 activation. The listed observation period is 500 milliseconds, with continuous checking and a two-driving-cycle lamp schedule.

The row does not identify a particular wire break, failed module or a measured resistance outside range. It reports the network's diagnostic state. Assigning the fault to the last module named by a scan tool would add a conclusion that the source does not support.

## Use the correct model-specific network procedure

Audi directs the reader to its CAN terminal-resistance procedure for the A6, A7 and A8 application. The manual also contains a separate Q5 procedure elsewhere, so a vehicle family listed on the document cover is not permission to copy one model's connection sequence to another.

Preserve the full communication scan and related supply faults, then have a technician identify the relevant network segment and module arrangement. Resistance measurements depend on the circuit's prescribed power and connection state; an arbitrary reading at convenient pins is not an equivalent diagnostic test.

After the underlying issue is repaired, verification should show that the communication error state remains clear through the applicable startup event. Erasing U1024 or successfully contacting one controller does not establish that the complete monitored exchange is operating correctly.

# P199C: A coolant-control positive-short code with mismatched naming

## Separate the electrical result from the component label

Volkswagen's CRUA/DEJA P199C row describes a short to positive in the cylinder-head coolant-control circuit. The fault signal comes from the output driver while its commanded state is on. The monitor uses 480 milliseconds and lists a two-driving-cycle malfunction-lamp response.

The source's component naming is not fully consistent. The code description and strategy call it a coolant pump, while the diagnostic column directs the reader to cylinder-head coolant valve N489. That mismatch is retained as a source-review flag rather than silently choosing a different component name.

## Resolve the valve/pump identity before testing

The linked N489 section describes a mechanically coupled rotary slide valve used to regulate coolant flow. It includes an electrical checking sequence, but those details should not be applied to an unrelated pump simply because the code's label says “pump.” The exact vehicle diagram and current factory procedure must establish the intended circuit.

The clear monitor distinction is an on-state positive-short report. It does not, by itself, identify a stuck coolant valve, overheating engine or failed controller. Preserve related P199-series faults and the operating record so a technician can evaluate the command and feedback together.

After the correct circuit is identified and repaired, confirmation should show that the original electrical indication stays absent during the relevant command. A temperature change alone cannot establish that the output-driver fault has been resolved.

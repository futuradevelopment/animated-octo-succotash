# P199D: A commanded-on coolant circuit reports a ground short

## The command state distinguishes the monitored event

The CRUA/DEJA P199D entry uses the output driver's diagnostic signal to identify a short-to-ground condition. The row explicitly qualifies the check with the output driver on, gives a 480-millisecond monitoring period and lists the malfunction lamp after two driving cycles.

The fault therefore concerns an electrical response during a requested operating state. It is not direct proof of inadequate coolant flow or a stuck mechanism. The table supplies no universal resistance value that independently locates the short.

## Keep the inconsistent component names visible

The description refers to a cylinder-head coolant pump, while the diagnostic destination is coolant valve N489. The separate N489 section describes a rotary slide valve controlling coolant flow. Because those labels could send someone to different hardware, this article remains marked for source review.

A technician should match P199D to the installed engine's wiring and current component identification before taking measurements. Retain related electrical faults and compare the commanded state with the returned driver indication. Do not transfer a valve's terminal layout or resistance check to an auxiliary pump based on a generic code description.

Once the correct circuit and cause are established, verify operation through the relevant on-state check. Clearing the warning, observing normal coolant temperature or hearing a pump operate elsewhere does not demonstrate that this ground-short report has been corrected.

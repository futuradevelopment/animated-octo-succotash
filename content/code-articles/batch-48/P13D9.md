# P13D9: Cylinder-four pressure plausibility needs the full row

## Read beyond the first page

In the CRUA/DEJA manual, P13D9 is assigned to the cylinder-four pressure sensor and QX4. The first part of the entry gives an electrical-range fault below 0.33 volts or above 3.09 volts with the engine running, a 1,000-revolution monitor and a two-driving-cycle lamp schedule.

The entry continues onto the following physical page. That layout matters: stopping at the page break can make a multi-part plausibility monitor look like a simple voltage-only code. The neighboring cylinder entries also evaluate pressure variation, offset and agreement with calculated pressure.

## Confirm the intended pressure channel

The source's continued pressure-comparison wording contains copied sensor numbering. Because that detail can affect which channel and limits a technician uses, this article remains marked for review. It does not silently turn another cylinder's wording into a verified cylinder-four test specification.

The clear starting identifiers are P13D9, cylinder four and QX4. A technician should match those to the installed engine and obtain the correct complete factory procedure before using the detailed pressure-comparison branches. The pressure-sensing glow plug should not be confused with a conventional heater-only diagnosis.

Retain the operating conditions and any related pressure-sensor faults. A normal key-on voltage does not establish correct combustion-pressure behavior, and erasing the code does not prove that the long running monitor has completed successfully. The evidence must follow the actual channel through the applicable diagnostic event.

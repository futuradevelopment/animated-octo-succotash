# P2013: Bank-two runner control reports a high driver condition

## The high-circuit label refers to a driver result

Audi's CPNA/CPNB P2013 row identifies intake-manifold runner control circuit high on bank two. The strategy uses a power-stage diagnostic signal shown in an 8–18-amp range while the power stage is on. It observes the condition for 480 milliseconds and lists a two-driving-cycle malfunction-lamp response.

This is not a runner-position voltage limit or a measured airflow threshold. The current range is presented within the controller's diagnostic strategy; it is not a universal current draw to reproduce by applying external power to the actuator.

## Confirm the bank and the actual actuator circuit

The diagnostic column points to the intake-flap motor checking procedure V157. A technician should identify the actual bank-two control arrangement from the installed vehicle's documentation and preserve related position or actuation faults before interpreting the high-driver report.

The code alone does not distinguish a wiring problem from an actuator or output-stage issue. It also does not prove that the manifold runner is mechanically stuck open. The requested state, electrical feedback and any position information need to be evaluated as separate evidence.

Do not force the linkage or bridge motor terminals to imitate the monitored event. After repair, confirmation should show normal response during the applicable on-state command and no return of the original driver condition. An engine that idles smoothly after codes are cleared has not necessarily exercised this specific bank-two electrical check.

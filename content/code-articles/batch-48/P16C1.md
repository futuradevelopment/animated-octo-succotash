# P16C1: An open-circuit report from the heater-support pump

## The code concerns the electrical loop

Volkswagen's P16C1 entry describes an open circuit for heater-support coolant pump V488 in the CRUA/DEJA application. The engine controller receives an output-driver diagnostic signal and observes the condition for 480 milliseconds. The table schedules the malfunction lamp after two driving cycles.

An open-circuit report does not identify a broken wire's location, prove the pump rotor is seized or establish a coolant-flow rate. Those are separate questions. The same manual contains different codes for V488 dry running, locking, overheating and low speed, which should not be substituted for the specific P16C1 report.

## Check supply and continuity as separate evidence

The linked checking sequence establishes battery voltage at the pump connection and examines the path back to the engine controller. The branch for an unsatisfactory wiring result includes open or high-resistance paths and damaged connectors. This is more discriminating than judging the pump only by whether it makes noise.

A technician should preserve the original fault and any companion codes, identify the correct V488 connector and test according to the required circuit state. Continuity testing on an energized circuit or bridging an unknown control terminal is not an appropriate shortcut.

Repair confirmation should demonstrate both normal requested pump operation and absence of the original electrical report. Filling coolant or clearing memory without resolving an open electrical path would not address the condition described by this monitor.

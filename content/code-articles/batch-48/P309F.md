# P309F: The hybrid clutch slips despite a closed command

## The relevant condition is commanded engagement

In the Touareg Hybrid CGFA table, P309F concerns clutch slip while the clutch is engaged. Hybrid drive must be requested and the electric clutch closed. The monitor compares combustion-engine speed with drive-motor speed and identifies a difference above a calibrated 200–300 RPM range under the stated torque conditions.

The observation lasts one second, with continuous monitoring and a two-driving-cycle lamp schedule. The range belongs to the controller's full- or reduced-torque evaluation; it should not be converted into one universal slip limit for every hybrid operating mode.

## Validate the speed relationship and the command

The code establishes an unexpected speed difference during requested engagement. It does not independently identify friction wear, an actuator defect or an erroneous speed signal. Preserve the clutch-control record and related motor or engine-speed faults so the technician can determine whether both sides of the comparison are reliable.

Volkswagen refers further diagnosis to the appropriate hybrid repair manual. A qualified technician should use that procedure with the required precautions against high voltage and unintended movement. An improvised road-load test or forced clutch command is not an appropriate substitute.

After repair, verification should show the intended engine-to-motor relationship during the eligible closed-clutch event. A smooth idle, a successful electric-only movement or an erased code does not exercise this specific engaged-clutch comparison. The monitored command and torque context must remain attached to the speed evidence.

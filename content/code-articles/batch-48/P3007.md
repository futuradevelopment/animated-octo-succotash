# P3007: The camshaft signal is absent for two crank revolutions

## The crankshaft supplies the observation clock

Volkswagen's CRUA/DEJA P3007 entry concerns camshaft position sensor G40. With terminal 15 on and the engine cranking or running, the controller looks for an absence of camshaft signal edges over more than two crankshaft revolutions. The table lists a two-revolution monitoring period and a two-driving-cycle lamp schedule.

This is a missing-signal criterion. It differs from a comparison that finds a camshaft signal present but incorrectly phased relative to the crankshaft. The code alone therefore does not establish that a timing drive has stretched, jumped or needs mechanical adjustment.

## Establish whether a usable G40 signal reaches the controller

The diagnostic column directs the technician to the G40 checking procedure. The useful starting record includes whether the code appeared during starting or while running, together with any crankshaft, supply or timing-related faults. Those details help determine which signal evidence is available before a mechanical conclusion is drawn.

Use the correct sensor and circuit identification for the installed engine. A generic camshaft-code description cannot supply the appropriate connector terminals or voltage specification. Electrical testing around a cranking engine must be carried out with proper workshop precautions and control of moving components.

After the underlying cause is repaired, confirmation should demonstrate that the controller receives the expected camshaft activity during the relevant cranking or running event. Erasing memory with the engine stationary cannot exercise a monitor whose observation is counted in crankshaft revolutions.

# P10A4: The bypass flap fails its learned rest-position check

## The stored position is the object of the check

In the CREC table, P10A4 concerns the supercharger bypass flap's adaptation limits. The monitored limp-home position is outside 60.01–88.0 degrees. One branch runs as an event-based check after ignition-on with suitable temperature conditions; another follows a changed stored position and uses a 0.01-second observation.

The changed-position branch requires the vehicle stationary, engine speed at or below 64 RPM, coolant between 6°C and 105°C, and suitable intake temperature. These qualifications distinguish a learned-stop evaluation from a simple running boost-pressure comparison.

## A mechanical label does not identify the repair

The code title says mechanical malfunction, but the diagnostic evidence is a learned position outside its allowed range. It does not independently prove a seized flap, contamination or a failed motor. Position feedback, adaptation history and the actual mechanism need to be considered together.

The table references J808. Its companion description uses turbocharger/wastegate language despite the supercharger-bypass strategy, so the article remains source-review flagged for that mismatch. The correct CREC assembly and adaptation procedure must be verified before a technician interprets the limits.

Preserve related electrical and position-sensor codes rather than repeatedly clearing learned values. An adaptation routine is not a substitute for correcting a defective circuit or mechanism. Confirmation should establish that the intended rest position is learned and accepted under the proper event conditions, not merely that the flap moves.

# U0141: The missing body-module message needs the correct identity

## What the communication monitor detects

Audi's CREC U0141 entry describes a missing message from the body-control system. The check becomes eligible more than 500 milliseconds after ignition-on and observes the missing-message condition for one second. The malfunction-lamp schedule is two driving cycles.

There is an identity mismatch within the row: the code title names body control module A, while the strategy and communication path name BCM2. This article retains a source-review flag rather than silently declaring those labels interchangeable on every Q7 configuration.

## Identify the participant before selecting network tests

The diagnostic column refers to the CAN terminal-resistance procedure. That procedure describes a particular network topology and connection state, not a universal resistance test at any convenient diagnostic pins. The correct vehicle diagram must establish which module and network segment correspond to the stored fault.

Preserve the complete network scan and related supply or communication faults before clearing memory. A module that does not send the expected message is not automatically defective; the code identifies missing information, while its cause still needs circuit and module-state evidence.

A technician should resolve the module-A/BCM2 naming against the current factory information, then verify communication under the specified startup conditions. Erasing the code or successfully contacting a different body module does not establish that the originally missing message is available. No body-controller replacement is justified solely by this row.

# U1034: The front NOx module sends implausible information

## The message arrives but fails plausibility

Audi's CPNA/CPNB U1034 entry concerns implausible data from NOx sensor one, the front module. The check becomes eligible more than 500 milliseconds after ignition-on and with battery voltage between 9.5 and 16.5 volts. The invalid-data observation lasts sixty milliseconds.

This differs from U1006, which concerns absent messages from the same front sensing path. A module can be visible on a diagnostic network while sending data that the receiving controller cannot use. Presence and plausibility therefore require separate confirmation.

## Trace the invalid information without assuming an emissions failure

The row does not state a NOx concentration threshold or prove that the exhaust-treatment system is ineffective. It identifies a data-quality problem associated with the sensor module. Audi directs diagnosis to the J583/J881 NOx-module procedure, with the actual front-sensor identity to be verified on the installed vehicle.

Preserve the module's own faults and any accompanying supply or communication records. A technician should establish whether the returned information, module state and electrical conditions match the factory procedure before deciding on a component repair.

Do not interpret a single displayed NOx value as proof that the monitor has passed. After repair, the front module's information must remain both available and accepted as plausible under the relevant conditions. Clearing the engine-controller warning alone does not establish that the originating data-quality fault has been corrected.

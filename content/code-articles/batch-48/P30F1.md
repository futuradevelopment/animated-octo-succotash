# P30F1: A fuel-injection service mode remains selected

## The fault describes an operating mode selection

P30F1 is the CREC operator-mode selection active entry. The strategy checks whether direct-injection service mode or multiport-injection service mode is active. The row lists an engine-controller keep-alive condition, fuel present, engine speed zero and an early-life trip-distance qualification.

The two mode branches have different printed monitoring times: ten seconds for the direct-injection service-mode branch and ten milliseconds for the multiport branch. They should not be collapsed into one generic duration. The table lists the check once per driving cycle and a one-driving-cycle lamp schedule.

## Confirm the selected mode before diagnosing hardware

This record does not, by itself, establish an injector, fuel pump or pressure-sensor failure. A technician should determine whether a service function was intentionally selected and whether the vehicle has been returned to its normal configuration after diagnostic or production work.

The source sends the reader to the appropriate repair manual rather than providing a universal deactivation sequence. Preserve the original state and any related faults before clearing memory. Guessing a sequence of ignition cycles or replacing a named fuel-system component would not address the configuration question.

Verification should include the reported service mode and the relevant controller keep-alive event. An engine that runs normally after a restart may still have diagnostic information requiring review. The interpretation is specific to this CREC factory table and should not be generalized to other manufacturers' use of P30F1.

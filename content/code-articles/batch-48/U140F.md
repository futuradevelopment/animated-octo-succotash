# U140F: Excess voltage can restrict the reducing-agent controller

## The restriction has a lower threshold than the high-supply code

In the CPNA/CPNB table, U140F identifies reducing-agent control-module function restriction due to excessive voltage. The criterion is supply above sixteen volts with ignition on, observed for more than 500 milliseconds. The table lists continuous checking and a two-driving-cycle lamp response.

The separate U140D high-supply entry uses 16.5 volts. These are distinct thresholds in the cited calibration. A restricted-function report should therefore not be dismissed solely because a recorded value has not crossed the higher U140D boundary.

## Investigate the supply condition behind the restriction

The factory reference directs diagnosis to J880. Preserve related voltage, communication and emissions-control faults, then have a technician evaluate the actual module supply path and the broader electrical context using the correct vehicle information.

The code does not prove that a particular dosing component is mechanically defective or that the controller itself created the high voltage. It also does not describe a software setting that should simply be disabled. The underlying supply problem must be understood before the restriction can be considered resolved.

Do not bypass the controller's restricted state to force operation. After repair, confirmation should show stable supply and appropriate function under the factory procedure, with no return of the excessive-voltage condition. Erasing fault memory or observing one acceptable voltage after the event does not demonstrate that the original electrical cause has disappeared.

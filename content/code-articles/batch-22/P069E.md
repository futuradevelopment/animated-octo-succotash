# P069E: The ECM is forwarding a fuel-controller fault request

P069E is a request-reporting code in this GM ECM table. The ECM monitors whether the fuel-pump control module has requested malfunction-indicator illumination because that module detected an emissions-related fault. P069E alone does not identify which fuel-system measurement or output failed.

## Follow the fault back to its origin

The table evaluates the request continuously after more than three seconds have elapsed since powerup. The deciding condition is an emissions-related DTC set in the fuel-pump controller. Consequently, an ECM-only code read can omit the diagnostic information needed to explain the request.

Obtain the originating controller's stored and current codes, status information and event data before clearing anything. A pump-current fault, pressure-control problem or internal controller fault would need its own evidence; none can be selected from this forwarding code alone.

## Lamp reporting is not a component test

The row includes a “MIL: NO” notation alongside the request-monitor description. Treat that as the report's own lamp-classification notation, not proof that the driver's lamp must be off when the originating module has requested illumination.

Record which module reported each code and whether communication with the fuel controller is available. If its detailed records cannot be retrieved, that is a diagnostic limitation to resolve, not a basis for replacing the pump. The document supplies no fuel-pressure or electrical bypass procedure; any fuel-system intervention should follow the correct vehicle service instructions.

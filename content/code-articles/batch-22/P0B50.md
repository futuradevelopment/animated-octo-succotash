# P0B50: Block-five rationality continues across a page boundary and includes block six

P0B50 is block-five voltage rationality in this GM battery-controller document. Its failure calculation includes both block five and block six, each scaled by twenty before comparison with pack voltage. The row's enable conditions continue onto the next physical page.

## Both scaled mismatches must be present

The absolute difference for each block-to-pack calculation must exceed 70V. The conditions are joined by AND, so neither a single block-five mismatch nor a direct difference between the two blocks is the complete test.

Block five must be valid, and the named block/pack circuit faults and controller-performance fault must be inactive. The continuation specifies run mode and more than 200ms after contactor closure. The decision uses 160 failing samples within 170 at 100ms intervals.

## Avoid losing the continuation

Record block five, block six, dedicated pack voltage and contactor timing together. Reading only the first page could omit operating conditions that determine whether the monitor could run. A pack total calculated from block inputs may also differ from the independent reference this test expects.

No physical sense-wire map or battery replacement decision is supplied. A qualified high-voltage technician must use the applicable service information to identify the failed measurement path. Pack access requires approved isolation and verification, and this monitor equation is not a live-probing procedure.

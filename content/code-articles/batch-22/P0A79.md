# P0A79: Motor-B inverter performance reports a power-switch protection status

P0A79 is the motor B inverter-performance code in this GM hybrid document. The strategy specifically checks an IGBT desaturation fault status. That gives the broad word “performance” a concrete electrical meaning rather than making it a generic report of weak propulsion.

## The status originates in power-switch monitoring

The source describes a high-side or low-side phase device reporting an overdriven condition. Wakeup must be on, and a single failing task count can register the event at approximately 2.08ms. A scan tool may preserve the resulting code without displaying the brief internal event itself.

The adjacent P0C0E row checks IGBT bias or power-supply failure. It is a separate monitor, so a P0A79 record should not automatically be described as missing inverter power. Motor A's P0A78 also belongs to a different controller identity.

## Preserve the reporting controller and companions

Record motor B module identification, the available inverter-status detail and accompanying current, voltage or supply codes. The broad DTC does not identify a particular phase device or establish that a complete inverter assembly must be replaced.

The table offers no internal semiconductor test, approved measurement connection or completed repair decision. A trained high-voltage technician must use the correct motor B inverter service procedure and prescribed isolation. Do not open energized power electronics or deliberately reproduce an overdriven switching state to test the code.

# P023F: Low pump current matters only with the pump commanded

The fuel-system controller's P023F monitor looks for an electrically open fuel-pump control circuit. In this implementation the important evidence is very low current while a meaningful pump command is present, rather than fuel pressure alone.

## Read current alongside duty cycle

GM's table pairs pump current at or below 0.5A with duty cycle above 20%. It evaluates 72 failing samples in an 80-sample window, with a 12.5ms sampling interval. A zero-current reading while the controller is intentionally requesting no pump output would not establish that combination.

The enable section includes run/crank or controller/communication activity and a run/crank voltage window above 9V and below 18V. Those conditions help distinguish an active output test from an observation made while the system was asleep or its supply was unsuitable.

## Separate command availability from output response

Capture pump duty request, reported current and supply state together. The adjacent P025A monitor checks disagreement in the enable-control request; it is a separate question from whether current flows after the output is requested. Retaining companion codes helps avoid treating an unavailable command as a failed pump response.

The document provides no connector pinout, fuel-pressure specification or proof that the pump itself must be replaced. A technician needs the correct vehicle procedure to distinguish an open load path from controller or connection faults. Fuel-system and electrical work must follow the applicable isolation and fire-prevention procedures, without bypassing the controller to reproduce this monitor.

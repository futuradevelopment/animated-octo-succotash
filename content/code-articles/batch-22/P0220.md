# P0220: A secondary throttle processor can reject a signal that the primary accepts

P0220 has a particularly useful qualification in this GM document: the secondary processor detects a throttle-position sensor 2 circuit problem while the primary processor considers the sensor in range. A normal-looking primary throttle reading therefore does not by itself contradict the stored code.

## Two views of one throttle input

The secondary evaluation watches for a TPS2 voltage below 0.25V or above 4.59V. The monitor describes continuous or intermittent electrical faults and uses both a failing-sample count and a consecutive-count route. A brief disagreement can consequently matter even when a slow scan-tool display looks steady.

The row also requires the absence of a five-volt reference error. Its power-enable wording includes an exception when reduced power is present, so the listed supply threshold should not be turned into an unconditional rule for every event.

## Preserve the disagreement

A useful diagnostic record separates primary and secondary throttle information, associated reference-voltage codes and reduced-power status. If the available tool exposes only one processor's interpretation, acknowledge that limitation instead of assuming both processors saw the same value.

This source does not distinguish a damaged sensor from wiring, internal input circuitry or another cause through a completed repair test. It supports investigating the differing input paths using the matching throttle-control service information. Avoid forced throttle movement or improvised probing around an energized actuator; the code definition is not an actuator test procedure.

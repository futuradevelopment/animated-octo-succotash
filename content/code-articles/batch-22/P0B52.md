# P0B52: The block-five upper sensing limit does not depend on block six

P0B52 rejects a block-five voltage indication above 23V in this GM battery controller. The row is a single-channel upper-limit check. Block six is involved in other nearby monitor logic, but a high block-six value is not listed as a requirement for this code.

## Preserve the actual test boundaries

The source requires battery-controller run mode, an acceptable low-voltage supply and no controller-performance fault. Fifteen failing samples within twenty, taken at 100ms intervals, form the documented failure decision.

P0B50 instead compares scaled block-five and block-six readings with pack voltage, while P0B51 checks a pair of low values. Those related codes are not alternate names for the same test; they ask different questions about the measurement system.

## Retain a channel-specific event record

Save block five's reading and identity, the dedicated pack voltage and relevant companion codes. A display showing only the maximum block voltage can hide which channel was responsible at the original event. No universal physical module location follows from the block number.

The table does not prove overcharging, a damaged cell group or a failed sensor board. The matching service procedure must establish the cause. Any pack investigation requires trained high-voltage personnel, prescribed isolation and verified safe access. The 23V calibration threshold is neither a charging target nor an instruction for a direct energized measurement.

# P07A7: Clutch-three release is evaluated against mode-two torque behavior

P07A7 reports friction element C stuck on in this GM hybrid-transmission strategy. The table identifies the element as C3 and evaluates its behavior in mode two. It is not a general wear indication and does not mean that every low C3 slip reading is abnormal.

## The controller expects a different motion relationship

The failure combination includes C3 slip at or below 80rpm, slip acceleration at or below 30rpm/s and excess C3 torque above 140Nm for the specified preliminary interval. The common enable condition requires input speed to deviate from its profile by more than 200rpm.

The complete failure decision is listed as 4.5 seconds. C1's neighboring stuck-on entry uses a higher excess-torque threshold, so substituting the other clutch's calibration would change the interpretation.

## Confirm which state the data describes

The pass row uses C3 slip above 45rpm for 0.375 seconds in the listed operating states. Record the actual range or mode with the slip value; a reading taken in another state does not establish either failure or recovery as defined here.

The source describes a controller inference about unintended coupling, not an inspection proving physical seizure. Pressure routing, hardware and control causes require the appropriate vehicle-specific diagnostic procedure. A trained hybrid-transmission technician should handle any dynamic or internal testing, using prescribed precautions rather than manually forcing clutch commands.

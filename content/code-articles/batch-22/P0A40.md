# P0A40: Motor-A resolver performance checks a different signal extreme

P0A40 concerns degraded angle-signal information in motor A's resolver circuit. In the cited GM table, the relevant sine or cosine signal exceeds 4.0V. This is a different criterion from P0A3F's low-signal or converter-error diagnosis.

## Initialization precedes evaluation

The monitor waits for a 500ms resolver-initialization interval. Its decision uses 420 failing counts within 500 at the controller's high-rate task interval. A generic scan-tool update rate may not expose the brief signal behavior underlying that internal result.

A separate row covers internal tracking error in degrees. The performance code here should not be redefined as that tracking test, and neither criterion alone identifies a physical resolver mounting problem.

## Preserve the form of the evidence

Record motor A controller identification, resolver diagnostic status and any available sine/cosine or angle-quality information. If the tool exposes only a calculated position, acknowledge that it may hide the raw signal condition used by this monitor. Companion position codes help distinguish which checks actually failed.

The source provides no connector layout, acceptable oscilloscope setup or prescribed replacement decision. Its signal threshold is a description of controller logic, not permission to probe energized inverter wiring. A trained hybrid technician needs the vehicle-specific resolver procedure and high-voltage isolation requirements before investigating the physical circuit or confirming a repair.

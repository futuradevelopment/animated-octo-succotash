# P0969: Solenoid-C performance is an electrical status check in this table

P0969 is labeled pressure-control-solenoid C system performance in this GM transmission table. The actual strategy evaluates the PCS3 electrical status for an invalid control-circuit voltage. It should not automatically be interpreted as a measured hydraulic-pressure error.

## Read the status criterion behind the title

Failure is based on the hardware input/output circuitry reporting an out-of-range electrical condition for four seconds within a five-second window. That is different from the adjacent low-voltage and high-voltage circuit classifications, which use shorter electrical-fault decisions.

The source also refers to common electrical enable conditions. A pressure command or shift complaint alone does not establish that PCS3's electrical monitor was enabled or that its hardware status failed.

## One prerequisite needs confirmation

The P0969 row names P0965 in its “not failed this key on” condition, although P0965 is the neighboring PCS2 performance entry. That may be intentional interaction or a copied reference; this document alone does not resolve it. Do not replace the printed code with a guessed alternative.

Capture the PCS3 command, available electrical status, supply conditions and companion solenoid codes. The table supports tracing an electrical command-response problem but supplies no universal solenoid replacement, connector pinout or hydraulic test point. Those require the matching transmission service information and professional hybrid-system precautions before invasive testing.

Preserve the distinction between electrical feedback and hydraulic response in the record.

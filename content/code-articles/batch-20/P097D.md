# P097D: Solenoid D open-circuit reporting has a specific architecture mapping

P097D is the D-channel open-circuit entry in Ford's architecture tables, represented in detail as P0765_13. The general monitor uses P0765 for the open category. Understanding that mapping prevents different scanner presentations from being mistaken for separate component failures.

## Scope the code to the identified transmission

Ford's 8F24 section carries the D open, ground, power and functional categories in its continuation table. The mapping is documented for that architecture; it is not a universal physical D-solenoid location or a vehicle-fitment claim.

Electrical monitoring is continuous and uses smart-driver fault feedback, with a typical 1.5-second persistence criterion in the general summary. The functional failed-off/on entries P0766/_7F and P0767/_7E use response events instead. An incorrect functional state therefore does not independently locate the open electrical path.

## Verify the path described by the report

Preserve the full suffix, D command, driver status and any simultaneous supply-related results. A current normal response cannot show where an earlier circuit interruption was present. If a tool translates the result to P0765_13, keep the original module context rather than treating the translation as new evidence.

The source does not provide a connector pinout, resistance target or replacement instruction. The matched electrical procedure must isolate the load, wiring or driver evidence before a solenoid or valve-body repair is justified.

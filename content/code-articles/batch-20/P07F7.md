# P07F7: Tenth-gear ratio evidence must include stability and repeated failure

P07F7 is Ford's general incorrect tenth-gear ratio entry. It compares the expected commanded relationship with speed evidence. It does not independently establish whether the disagreement comes from the control state, an input problem or the transmission's mechanical response.

## Do not judge the ratio during an unconfirmed transition

The typical forward-gear window requires adequate torque, throttle and speeds, an established forward selector state and more than half a second without shifting. These conditions make a held tenth-gear interval more useful than a screenshot captured while the ratio is still changing.

Ford describes an error above 30 rpm for over 2.5 seconds, recurring six times across key cycles without detected solenoid faults. The criterion combines persistence with repeated observations. A brief peak or a single subsequent pass does not represent that complete history.

## Preserve enough information to select the next test

Record the exact transmission, commanded gear, shift status and relevant shaft-speed signals. If a signal is implausible or a solenoid electrical diagnostic has failed, establish how that affects the ratio evidence before declaring an internal tenth-gear defect.

The summary lists this code within a general monitoring family; it does not provide a universal component assignment or a vehicle fitment list for the reader's car. A successful later drive also cannot prove which earlier fault path was corrected. Verification and repair decisions require the matched transmission's diagnostic procedure and eligible operating evidence.

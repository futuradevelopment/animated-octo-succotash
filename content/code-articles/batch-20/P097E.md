# P097E: Use the E-channel open-circuit mapping without guessing a valve location

P097E is the shift-solenoid E open-circuit identifier in Ford's architecture tables, paired with P0770_13. The general monitor names P0770 as the open category. Retaining that detailed mapping is more informative than a broad description of an E-solenoid problem.

## Architecture and failure type both matter

The cited tables include this E mapping within specified transmission sections, including the 8F57 continuation. They list E ground and power shorts separately from the functional failed-off and failed-on categories. The component letter alone cannot select a universal hydraulic path or physical valve position.

Ford's general electrical criterion uses continuous smart-driver fault feedback with a typical 1.5-second persistence interval. Its functional response strategy uses transitions and an event filter. A later successful E-related function does not locate an earlier electrical discontinuity.

## Preserve the original representation

Record the module, suffix, E command and electrical status. If another scanner displays P0770_13, retain the documented relationship rather than counting a second failed component. Simultaneous supply or other channel codes should remain attached to the same event history.

The summary provides no universal E resistance specification or connector layout. Verification must use the actual transmission's circuit procedure to determine which path produced the open-circuit report. The identifier mapping does not itself prove that the solenoid, harness or controller requires replacement.

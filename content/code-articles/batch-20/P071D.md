# P071D: Manual-override input consistency is separate from a high or low signal

P071D is broadly described as a transmission mode-switch B circuit in the generic dictionary. Ford's TR9070 table gives a more specific role: consistency of the manual-override switch input. The exact transmission therefore matters before the code is mapped to a physical switch.

## An in-window signal can still need a consistency check

The table separates P071D from P071E and P071F, which are the manual-override input's out-of-window low and high categories. That distinction means a voltage that avoids a simple range fault does not by itself establish that the input is consistent with the controller's expected state.

The source does not publish the complete consistency algorithm or a numeric legal-state window here. Those missing values should not be invented from the neighboring codes.

## Do not confuse manual override with a shift paddle

The same page lists upshift and downshift paddle inputs in separate diagnostic rows, with their own stuck, illegal-voltage and out-of-window codes. The manual-override classification cannot automatically be assigned to one of those paddles just because both affect manual shifting.

Preserve the full module result and available input-state information, then use the matching TR9070 procedure to establish the consistency comparison. The table does not identify a failed switch, connector or controller and supplies no universal external activation test. The useful evidence is the specific input role and failure category, bounded to this architecture.

# P071E: Manual-override input low is not the same as a consistency fault

P071E is the low category for the manual-override switch input in Ford's TR9070 table. The generic mode-switch B title is less specific than that documented role. The transmission identity must remain attached to the interpretation before choosing a component location.

## The source identifies an out-of-window result

Ford lists P071E as out-of-window low, P071F as out-of-window high and P071D as consistency. A low-range classification therefore differs from an input that may remain within its electrical window but fails a consistency assessment.

The summary does not give the numeric low boundary or explain the circuit's pull-up, switch resistance or connector assignment. Treating the word low as a universal zero-volt test would add an unsupported specification.

## Keep the control input distinct from paddle channels

The same page separately describes upshift and downshift paddle inputs and their own diagnostic categories. A manual-override fault is not automatically a fault in one specific paddle. Preserve the original module code and any available manual-override state data.

A useful verification must follow the matched circuit procedure to determine why the input was classified below its allowed window. A later legal input value cannot locate the earlier condition. The table does not prove a failed switch, wire or controller, and it does not justify bypassing or externally powering an unknown transmission-control input.

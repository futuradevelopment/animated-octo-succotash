# P0771: Solenoid E failed-off functionality can remain relevant after a good event

P0771 identifies shift solenoid E as functionally failed off in Ford's monitor. It is a result about the expected response to control activity. An apparently normal electrical signal at one later moment does not establish that the functional monitor completed successfully.

## Understand how good and bad events contribute

The documented functional check occurs around off-to-on transitions. Its typical filter rises by three for a bad event and falls by one when a clutch is correctly positioned during a non-shifting observation. Reaching nine produces the stored result.

Ford gives different approximate observation durations for shifting and non-shifting events. Therefore, a useful recording includes the operating phase and response over time. Merely waiting for a fixed interval after clearing a code does not demonstrate that an eligible E-channel event occurred.

## Keep the fault categories separate

P0771 is represented as P0770_7F. The architecture table's E open-circuit entry uses P097E/P0770_13, and P0772/_7E describes failed-on functionality. Those distinctions survive even if a scanner describes all three as a shift-solenoid problem.

Record requested state, observed response and current electrical diagnostic status together. The source does not assign a universal E-controlled clutch or identify a seized valve. Once the functional contradiction is established, the exact transmission procedure must determine which mechanical, hydraulic or electrical evidence explains it rather than treating the code as a part order.

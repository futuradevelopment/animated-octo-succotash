# P0986: An E-channel power-short report is not identical to failed-on functionality

P0986 is the short-to-power classification for shift solenoid E in Ford's cited tables. Its P0770_12 representation distinguishes it from P0772/P0770_7E, the functionally failed-on category. Keeping both identifiers intact prevents a short scanner label from collapsing different diagnostic branches.

## Know what produced the result

The electrical strategy is continuous and evaluates smart-driver fault feedback. Ford lists a typical 1.5-second electrical persistence criterion. Functional monitoring instead uses control transitions and repeated response events, so a hydraulic state does not directly reproduce the electrical check.

A high circuit description also does not supply a universal terminal-voltage limit. The command state and exact circuit design are necessary to interpret an external reading. The summary provides a failure classification, not a complete pin-level test.

## Verify the reported path

A useful record aligns E command, driver status and any related supply or channel faults. If the function later appears normal, that observation cannot identify where the earlier power-path fault existed. If functionality remains wrong, the electrical evidence still needs isolation rather than an assumed mechanical explanation.

The source does not map E to one clutch or valve position across transmissions. Use the applicable electrical procedure to distinguish the load, wiring and output-stage evidence before deciding which component, if any, requires repair.

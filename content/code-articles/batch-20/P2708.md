# P2708: A functionally failed-on F result is judged against the requested state

P2708 identifies shift solenoid F as functionally failed on in the cited Ford strategy. The decisive question is whether the observed response matches the intended operating state, not simply whether electrical activity exists on the F channel.

## Preserve the accumulated response evidence

Ford uses a functional event filter that adds three for each bad event and removes one for a correct non-shifting clutch state. Nine counts reach the documented storage threshold. The monitor's history can therefore remain relevant even when the latest observation appears correct.

The source distinguishes transition-related functional checks from continuous electrical monitoring. Their different timing and counting descriptions should not be blended into one universal F-solenoid test.

## Read the specific failure type

P2708 is paired with P2706_7E. The source separately places P097F/P2706_13 in the open-circuit category and P2707/_7F in the failed-off category. The electrical short identifiers vary across architecture tables, so retain the original module representation rather than guessing an alias from the component letter.

A useful capture aligns the requested F activity, observed function and electrical status at the same moment. The source does not identify a particular clutch, valve location or internal leakage path. Verification needs the matched transmission's procedure to determine why the functional state was wrong, without turning the code itself into a component-replacement verdict.

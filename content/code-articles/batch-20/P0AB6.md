# P0AB6: Active mount B open-circuit evidence belongs to the B control path

P0AB6 is Ford's open-circuit category for active engine mount B. The document groups the B control under bank 2 and shows P0AB6_13 as the detailed identifier. It does not establish that B always occupies one particular physical side on every vehicle.

## The monitor reports an electrical path condition

Ford describes a fault reported by the low-level driver and matured by PCM strategy. The check runs continuously, with five seconds listed to register a malfunction. This is not a published test of mount displacement, damping force or vibration amplitude.

B circuit low and circuit high have separate entries, P0AB7 and P0AB8. The A control has its own code family. Retain those distinctions so a short scanner label does not direct testing toward the wrong channel or failure class.

## Verify the correct control before selecting a part

Useful evidence includes the full code, reporting module and available B-control command or status data. A mechanical complaint does not independently demonstrate circuit continuity, and normal isolation performance at a later moment does not locate a former open path.

The summary does not provide a universal connector terminal, resistance target or external actuation procedure. The matching vehicle circuit information must map the B designation to the actual component and isolate the electrical condition. Replacing a mount solely because the generic code names it would go beyond the source's evidence.

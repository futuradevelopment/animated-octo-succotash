# P2748: Intermediate-speed B intermittency is distinct from its noise and dropout checks

P2748 is the intermittent intermediate-shaft speed B circuit entry in Ford's summary, shown as P2745_1F. It should remain a specific electrical classification rather than being reduced to an undifferentiated statement that intermediate speed was incorrect.

## Do not borrow a different monitor's event count

The document assigns noise, dropout and plausibility to separate detailed representations in the P2745 family. Its spike and dropout thresholds describe those dynamic strategies, not a published P2748 intermittency counter. Using them as a universal test for this code would change the source's meaning.

Ford also distinguishes electrical checks that can run without vehicle movement from comparisons that need credible speed and commanded-gear information. A later smooth speed trace cannot prove that the earlier electrical interruption did not occur.

## Confirm that the B channel is the one being examined

The general section describes two intermediate sensors in the ten-speed arrangement and one in the listed eight-speed design. The actual transmission must therefore determine the sensor mapping. A generic B label is insufficient for choosing a physical component.

Useful evidence includes the full suffix, status changes and the signal history around the event. The summary does not locate an intermittent connection or provide a universal pin test. Verification needs the correct electrical procedure while keeping B's intermittent category separate from its functional speed interpretations.

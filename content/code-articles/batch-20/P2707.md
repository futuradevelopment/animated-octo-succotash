# P2707: Solenoid F failed-off monitoring evaluates response history

P2707 is Ford's functionally failed-off result for shift solenoid F, paired with P2706_7F. It describes the expected functional state not being achieved during control activity. It is not an electrical open-circuit measurement.

## Use the controller's event context

The general functional monitor operates around off-to-on transitions. Its example filter gains three for a bad event and loses one when a clutch is correctly positioned during a non-shifting observation. Reaching nine stores the result. One correct response after the fault can therefore coexist with a meaningful earlier failure history.

Ford distinguishes approximately one second for a shifting event from 2.5 seconds for a non-shifting event. Those times describe the controller's observation, not an external solenoid activation instruction.

## Keep the F failure categories distinct

P097F/P2706_13 is the open-circuit entry, while P2708/_7E is functionally failed on. The F short-circuit displayed identifiers vary between the document's general and architecture tables, making the complete code and suffix especially useful. The P2707 failed-off category itself is consistently identified in the cited tables.

Record the requested transition, observed response and electrical fault status together. The source does not establish a universal F-controlled clutch or name a defective valve. The exact transmission procedure must identify why the requested functional result was absent before a mechanical or electrical replacement is justified.

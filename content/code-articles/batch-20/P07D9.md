# P07D9: Eighth-gear ratio evidence requires a held gear and reliable speed inputs

P07D9 is the incorrect eighth-gear ratio entry in Ford's general transmission monitor. The controller's comparison depends on commanded gear and credible speed information; the code does not identify one universal eighth-gear clutch or solenoid.

## Confirm the conditions that make the ratio meaningful

Ford's typical forward-gear check requires positive torque, minimum throttle and shaft speeds, a sufficiently established forward selector state and more than half a second without shifting. A capture centered only on the transition into eighth may omit the actual evaluation window.

The described failure is a commanded-ratio error greater than 30 rpm for more than 2.5 seconds, repeating six times across key cycles without detected solenoid faults. This combines magnitude, persistence and history. One brief mismatch is not the entire criterion, and one later normal event does not describe all earlier observations.

## Avoid borrowing a different transmission's gear-state map

The same document contains a TR9070 unknown-state table covering seven forward gears. That table cannot establish the meaning of an eighth-gear state or component assignment for P07D9. The applicable transmission must be identified before using architecture-specific supporting information.

Record commanded eighth gear, actual shift phase, relevant speeds and companion electrical faults. If the inputs are unreliable, a mechanical ratio conclusion is incomplete. The summary supports an evidence comparison, while exact thresholds and repair decisions remain tied to the matching transmission calibration and service procedure.

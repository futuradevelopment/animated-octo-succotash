# P097C: The C open-circuit mapping must not be confused with C functional failure

P097C is the open-circuit identifier for shift solenoid C in Ford's architecture table, paired with P0760_13. The general monitor calls the same open category P0760. The useful link is the documented control channel and failure suffix, not an assumption that every display format is universally interchangeable.

## Identify the architecture that owns the mapping

The 8F57 section explicitly places P097C/P0760_13 in its C open-circuit cell. It separately lists ground, power and functional failed-off/on categories. That table scope should be retained when selecting the applicable service information, without inferring vehicle fitment from the gearbox name alone.

The general electrical strategy uses smart-driver feedback continuously, with a typical 1.5-second persistence criterion. Functional C response is tested by a separate event-based method. A gear-ratio observation therefore cannot alone verify the electrical open-path report.

## Preserve the original failure evidence

Record the module identifier, suffix, C command and circuit status. A later normal shift can describe present operation but cannot locate the earlier interruption. If another scanner reports P0760_13, keep that relationship rather than treating the translated result as a separate failed component.

The source gives no universal connector terminal or resistance specification for C. A justified repair requires the exact circuit procedure to isolate the reported electrical path; neither the mapping nor the component letter proves which part is defective.

# P0705: An invalid range pattern is different from a bad PWM frequency

P0705 concerns the transmission range input, but Ford's summary does not describe every range sensor as a simple voltage sensor. It assigns this code to an invalid digital pattern or a general range-sensor fault. Establishing whether the vehicle uses digital, analog or pulse-width-modulated inputs is therefore the first interpretation decision.

## A combination can be wrong even when individual signals exist

For the digital example, the controller checks digital input patterns and, on applicable designs, analog-circuit faults. A separate four-bit implementation uses its own pattern-recognition interval. A signal that switches when the lever moves is not sufficient evidence that the complete combination represents a legal range.

The summary distinguishes pattern recognition from analog-fault monitoring. It lists up to 30 seconds for recognition and two seconds for analog faults, while its example thresholds include shorter architecture-specific intervals. Those values should not be combined into one universal P0705 timer.

## Preserve the representation the controller actually uses

A useful record includes the selected position, decoded range and individual input pattern. A discrepancy that appears only at one position requires that pattern to be captured, rather than replacing it with a single averaged reading.

P0706 belongs to an out-of-range PWM frequency in the same summary. Using its frequency criterion to diagnose a digital P0705 would test a different representation. The document supplies no connector layout or adjustment procedure; those must come from the matching transmission information before hardware is condemned.

# P0706: A plausible selector position can still carry the wrong signal frequency

P0706 is assigned to an out-of-range frequency from the transmission range sensor's A channel in the cited Ford tables. The duty cycle may still decode into an apparently sensible selector position. That does not establish that the pulse train meets the controller's frequency requirements.

## Separate timing from encoded position

Ford's general range-sensor section gives a 100–175 Hz example frequency window. The architecture tables for the listed rear-wheel-drive transmissions and 8F35/8F40 instead describe 125 Hz with a 25 Hz allowance. These are documented variants, so the exact transmission and calibration must determine which limit applies.

The same tables assign duty-cycle extremes to other codes and a disagreement between the two channels to P2805. Frequency, duty cycle and channel correlation are three different checks; passing one does not imply that the others passed.

## What a useful capture contains

Retain frequency and duty cycle together with range A, range B and the requested selector position. A scan value showing only the decoded gear can conceal the timing defect. If the frequency is now normal, note whether the original event occurred during a particular selector transition or power state rather than treating the current value as a reproduction.

The source identifies a monitoring failure, not a failed sensor or an adjustment error. It does not provide a universal pin test. Verification needs the applicable range-sensor procedure and its reporting format, including the P0705_38 representation used in these tables.

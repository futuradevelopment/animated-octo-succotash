# P0999: Confirm the F-channel high-circuit identifier before applying a test

P0999 is listed as shift solenoid F's short-to-power result in Ford's general table, paired with P2706_12. The architecture table instead puts P2710 in that cell, while other pages use a different suffix for P2710. This is a real mapping limitation, not a reason to guess a universal alias.

## Separate the electrical category from the code display

For the general P0999 branch, the documented evidence is a power-short electrical classification. Ford describes continuous smart-driver monitoring and a typical 1.5-second persistence criterion. That differs from F's functionally failed-on result P2708/_7E, which uses response-event monitoring.

A circuit-high result is not itself a universal connector-voltage specification. Command state and the applicable circuit design remain necessary to interpret an external measurement.

## Resolve the reporting scheme first

Preserve the full controller code, failure suffix and transmission identity. If a scanner translates the result, retain the original representation where available so the service definition can determine which electrical branch actually applies.

A current normal F response cannot locate an earlier power-path event, and a functional problem does not independently identify the electrical cause. The source does not supply a universal F-solenoid location or replacement. The documented code-mapping difference remains flagged until matched service information resolves it for the vehicle.

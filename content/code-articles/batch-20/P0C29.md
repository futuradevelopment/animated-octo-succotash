# P0C29: The pump performance category combines current and speed evidence

P0C29 is Ford's combined auxiliary transmission-fluid pump current-and-speed out-of-range report when paired with P0C29_92. That combination is more specific than a broad description of driver-circuit performance. Both types of operating information matter to the documented category.

## The base identifier can appear with different details

The same table uses P0C29_B1 and _B2 for the overspeed or underspeed representations associated with P0B0D. It also uses _4B for an overtemperature report. A scan result reduced to the base P0C29 family can therefore conceal which operating condition was actually reported.

Undercurrent and overcurrent alone have their own displayed codes. The combined _92 category should not be inferred merely because one current-related fault exists, nor should it be silently rewritten as a simple speed error.

## Keep communication quality separate

Ford separately monitors the feedback signal's frequency and duty cycle. A well-formed waveform does not establish that the operating status encoded in it is normal. Conversely, an invalid feedback signal requires its own investigation before decoded data is interpreted uncritically.

Preserve the full suffix, pump command and available current/speed reports. The source gives no universal numeric combined-performance boundary or proof of a defective driver module. The matching pump-control procedure must resolve the specific operating report before component replacement is justified.

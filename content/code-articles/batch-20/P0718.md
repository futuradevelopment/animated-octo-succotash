# P0718: Intermittent turbine-speed circuitry is not the same as noisy speed data

P0718 labels an intermittent turbine-speed circuit in Ford's transmission summary, with P0715_1F shown as the corresponding detailed representation. It should be preserved as that specific result rather than reduced to a generic statement that the input speed is wrong.

## Do not borrow another monitor's threshold

The document separately assigns erratic speed to P0715_2F and plausibility to P0715_64. Its example erratic-speed strategy counts large turbine-speed spikes; those spike counts are not published as the P0718 electrical-intermittency threshold. Treating them as interchangeable would create a test the source does not specify.

For the described eight- and ten-speed architectures, electrical speed-sensor diagnostics can operate without vehicle movement. Dynamic plausibility checks instead depend on driving under power and comparison with other speed information. Those different operating opportunities explain why a circuit result and an otherwise reasonable moving speed trace can coexist.

## Preserve the interruption, not only the average

A diagnostic recording should retain the complete code, status and signal history around the interruption. An averaged speed trace may look smooth while a brief electrical status change is missed. Compare the event timing with the controller's circuit classification before interpreting every speed jump as a mechanical slip.

The summary does not state a universal P0718 recurrence count or locate a defective connection. Verification therefore needs the matching electrical procedure and a record showing whether the original intermittent condition returned under comparable circumstances.

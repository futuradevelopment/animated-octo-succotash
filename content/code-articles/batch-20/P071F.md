# P071F: Manual-override input high needs the correct input mapping

P071F is Ford's TR9070 out-of-window high result for the manual-override switch input. This is a specific input role in the cited architecture, rather than proof that every generic transmission mode-switch B code refers to the same physical control.

## A range result differs from input consistency

The table gives separate manual-override categories for low, high and consistency: P071E, P071F and P071D. A high-range classification is not simply a failure to perform a requested manual shift. It is an electrical input-state result whose actual boundary must come from the applicable procedure.

Ford does not publish that numeric high boundary, connector pin or resistance network in this summary. A high reading cannot be interpreted correctly without the matched circuit definition and operating state.

## Avoid substituting a paddle input

The page separately lists upshift and downshift paddle inputs, with different diagnostic identifiers. Those rows show why a manual-override result should not be assigned to one paddle by name alone.

Preserve the full module report and available manual-override status, including when the out-of-window condition appeared. A normal current input cannot locate an earlier high-state event. The source does not identify the switch, harness or controller as defective and provides no universal external test. Verification must establish the correct input mapping and isolate the reported condition.

# P097A: The architecture table maps this to solenoid A’s open-circuit branch

P097A is the open-circuit entry for shift solenoid A in Ford's cited architecture table, paired with P0750_13. The general solenoid section uses P0750 for the open category. These are reporting representations of the documented A control path, not evidence of two different defective solenoids.

## Match the architecture before translating the code

The page groups this mapping under the listed 6R80, 6R140, 10R60 and 10R80 transmission architectures. That is gearbox-level documentary scope; it does not establish the reader's vehicle, model year or connector arrangement without further identification.

The general electrical strategy uses continuous smart-driver fault feedback, with a typical 1.5-second persistence criterion. Functional A failed-off and failed-on categories are separately represented by P0751/_7F and P0752/_7E, so a response problem should not replace the open-circuit interpretation.

## Verify the electrical path rather than ordering a part

Preserve the original module code, suffix, A-channel command and circuit status. If another scanner displays P0750_13, retain that mapping rather than counting it as a new independent failure. A later successful shift cannot locate an earlier interruption.

The summary gives no universal A-solenoid resistance, position or pinout. The applicable circuit procedure must determine whether the load, wiring or driver accounts for the reported open path. The code mapping itself does not justify a replacement.

# P0765: Solenoid D open-circuit evidence requires the exact reporting format

P0765 is the shift-solenoid D open-circuit entry in Ford's general monitor. It is an electrical report, not a conclusion that the D-controlled hydraulic function is mechanically stuck. Keeping that boundary intact prevents a short component label from becoming a replacement diagnosis.

## The electrical and functional monitors run differently

The electrical check runs continuously and uses a smart driver's fault feedback, with a typical 1.5-second persistence criterion. Functional monitoring instead evaluates transitions and accumulates good or bad responses. A test capture should show which of those evidence streams is actually being examined.

Ford's architecture table places P097D alongside P0765_13 in the D open-circuit cell. It lists P0766/_7F and P0767/_7E as separate failed-off and failed-on results. The complete module code and suffix therefore matter when the generic display uses a different open-circuit identifier.

## Avoid an unsupported hardware assignment

A useful record retains D-channel command, electrical status and simultaneous faults affecting the control supply. A later successful D-related function does not locate an earlier discontinuity. Likewise, a current poor shift does not identify the open circuit's origin.

The summary does not establish a universal D-solenoid position, connector pin or clutch assignment. Some architecture tables use related base identifiers in other control functions, making exact transmission identification especially important. The applicable electrical procedure must isolate the reported path before component replacement is justified.

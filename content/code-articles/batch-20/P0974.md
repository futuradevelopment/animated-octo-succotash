# P0974: A solenoid A circuit-high report differs from a functionally failed-on result

P0974 is Ford's short-to-power electrical category for shift solenoid A, represented as P0750_12. It should not be treated as a synonym for the separate functionally failed-on code P0752. The two results describe different evidence collected by the controller.

## Distinguish the source of the fault report

Electrical diagnostics run continuously and use smart-driver feedback. The general description gives a typical 1.5-second persistence threshold for an electrical fault report. Functional monitoring instead observes control transitions and accumulates unsuccessful response events.

A high signal without its commanded state is incomplete evidence. The summary supplies a driver-classified fault, not a universal connector-voltage instruction. It does not say that any measured voltage on A during an energized command proves a short.

## Keep the architecture and failure type together

The cited transmission table places P0974/P0750_12 in the power-short column and P0752/P0750_7E in the failed-on column. Preserve that distinction when a scanner uses a short description that sounds like excessive actuation in both cases.

Record command, driver status and simultaneous supply or other channel faults. A later successful shift cannot identify the origin of the earlier electrical classification. The source does not locate the power path or assign a universal clutch to A. The applicable electrical procedure must resolve the circuit evidence before a solenoid or controller replacement is warranted.

# P0770: Solenoid E open-circuit monitoring is based on driver evidence

P0770 is Ford's general open-circuit code for shift solenoid E. The source places it in an electrical diagnostic category, separate from E's failed-off and failed-on functional results. That separation determines what a useful verification must actually observe.

## Identify the electrical reporting path

The general monitor uses smart-driver fault feedback and lists a typical 1.5-second electrical persistence criterion. Electrical monitoring is continuous; functional testing occurs around solenoid transitions and uses a different event filter. A shift-quality observation alone does not verify the open-circuit branch.

The architecture table pairs P097E with P0770_13 for the E open-circuit classification. Ground and power shorts have their own detailed entries. Capture the full module code and failure suffix before choosing a test based on the shorter generic display.

## What the code leaves unresolved

A useful diagnostic record retains E-channel command, circuit status and any simultaneous faults affecting the control supply. If the transmission later responds normally, that does not show where an earlier electrical discontinuity occurred. If the response remains wrong, it still does not locate the open path by itself.

The letter E is not a universal physical valve location or connector terminal. The summary supplies no resistance value or replacement instruction for every transmission. The applicable electrical procedure must separate the load, wiring and driver evidence before a component or internal hydraulic repair is justified.

# P0982: A low D-channel circuit report belongs to the ground-short branch

P0982 is the circuit-low code for shift solenoid D in the generic dictionary. Ford's monitor identifies it as a short-to-ground classification and shows P0765_11 as the detailed representation. The code does not measure low fluid pressure directly.

## Driver feedback supplies the electrical evidence

The general electrical monitor runs continuously. Ford's typical threshold is a smart-driver fault report lasting 1.5 seconds. Its functional state monitoring uses transitions and an event counter, which should not be presented as the electrical persistence rule for P0982.

P0766/P0765_7F is the separate D failed-off functional result. A missing expected response and a ground-side electrical classification are different findings, even when both help organize the investigation.

## Avoid an unsupported physical mapping

Save the exact transmission identity, full code and suffix, D-channel command and electrical status. A normal reading captured after the event cannot identify an earlier grounding path. A poor shift does not locate that path in a load, harness or driver either.

The letter D does not establish one physical solenoid position across the Ford architectures in this document. The summary does not supply a pinout or resistance specification. Verification should follow the applicable circuit procedure and establish whether the reported electrical condition recurs before a component or internal transmission repair is selected.

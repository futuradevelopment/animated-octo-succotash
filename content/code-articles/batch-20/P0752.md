# P0752: A failed-on solenoid A result must be read against the intended state

P0752 is Ford's functionally failed-on classification for shift solenoid A in the cited monitor. The important evidence is an incorrect functional state relative to control activity. Finding that a solenoid was energized at some point is not, by itself, evidence that it remained functionally on when that state was wrong.

## The fault is built from events

Ford separates continuous electrical checks from functional monitoring during solenoid transitions. The functional filter adds three for a bad event and subtracts one when a clutch is in the correct state during a non-shifting observation. A value of nine triggers the documented result.

The example event duration differs between shifting and non-shifting conditions. A verification capture therefore needs the actual operating phase, not only an elapsed time after starting the engine. A single correct observation may reduce the filter without demonstrating that every earlier failure has disappeared.

## Do not confuse state evidence with a power short

The same solenoid A table assigns P0974/_12 to a short-to-power circuit classification and P0752/_7E to the functional failed-on result. These outcomes can prompt different diagnostic branches even though both may sound like excessive actuation in a brief scanner description.

Preserve the requested state, observed response and any electrical faults together. The source does not identify a universal hydraulic path or prove a mechanically stuck valve from P0752 alone. Further testing must use the exact transmission's functional and electrical information.

# P0977: A high B-channel circuit code must remain separate from functional sticking

P0977 is the short-to-power electrical result for shift solenoid B in Ford's cited tables. The detailed representation P0755_12 preserves that classification. It is not the same result as P0757/P0755_7E, which describes functionally failed-on behavior.

## Electrical status and functional response answer different questions

The general electrical check is continuous and uses smart-driver feedback, with a typical 1.5-second persistence requirement. Functional checking uses transitions and repeated response events. A hydraulic state observation alone does not reproduce the electrical feedback criterion.

The term high also does not establish a universal external voltage limit. A useful measurement needs the command state and the applicable circuit specification; the monitor summary does not provide a pin-level procedure for every B-channel implementation.

## Retain evidence before assigning a cause

Preserve the full reporting module and suffix, command history, electrical status and simultaneous channel faults. If the B function looks normal after the event, that can describe present operation but cannot locate the earlier power-path classification. If the function remains wrong, it still does not prove that a particular valve is mechanically stuck.

Ford's table identifies a channel and failure category, not a universal clutch assignment or connector position. The matching electrical procedure must distinguish the load, wiring and driver evidence. A component replacement cannot be supported solely by translating circuit high into a mechanical failed-on diagnosis.

# P0767: Solenoid D failed-on evidence should not be renamed as a power short

P0767 is a functionally failed-on result for shift solenoid D in Ford's summary. It indicates that the observed functional state disagreed with the intended control outcome. It does not alone establish the voltage or current path responsible for that disagreement.

## Read the result as accumulated functional evidence

The source evaluates functionality around control transitions and uses an example filter that increments by three for each bad event. A correct non-shifting clutch state decrements it by one, with nine counts reaching the storage boundary. The latest observed response may therefore be only part of the evidence.

Electrical checking follows a separate continuous strategy. Ford lists different timing descriptions for electrical fault persistence and for shifting versus non-shifting functional observations. Mixing those intervals would obscure which check a recording actually verifies.

## Preserve the distinction from D-circuit high

P0767 is shown with P0765_7E. In the same architecture table, P0983/P0765_12 represents a short-to-power electrical classification on D. A functional failed-on result and a power-short report should remain separate findings even if both are present.

For a useful next diagnostic decision, align the commanded state, observed function and any electrical flags. The summary cannot identify a universal D-controlled clutch or justify replacing a valve body. Matching the transmission and applying its specific procedure is necessary to resolve the cause of the functional contradiction.

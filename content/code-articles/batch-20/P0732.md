# P0732: Second-gear ratio errors need timing and repeat-count context

P0732 points to second gear's expected speed relationship in Ford's general ratio monitor. The source makes duration and repetition important: the reported fault is not established by any brief departure from an ideal ratio while the transmission is changing state.

## Evaluate a sustained, eligible event

The documented forward-gear check waits until shifting has stopped and applies minimum torque, throttle and speed conditions. Its typical failure is a commanded-ratio error greater than 30 rpm for more than 2.5 seconds. Six such events across key cycles are required in this example, with no detected solenoid faults.

Consequently, a recording should show whether second gear was actually commanded and held under eligible conditions. A trace containing only the second-gear transition omits the stable interval on which the described judgment relies.

## Keep different failure categories separate

Ford's TR9070 architecture lists P0732 as an unknown second-gear state. That table separately uses P074A for inability to engage second and P072D for inability to disengage it. Neither the generic title nor a description of a rough shift resolves that distinction by itself.

Retain the full module identification, shaft-speed evidence and companion codes. If a speed signal is implausible or an electrical solenoid fault is active, confirm the relevant diagnostic branch before attributing the result to internal friction elements. The monitor summary supports a structured evidence comparison; it does not provide a universal second-gear component replacement.

# P0774: Intermittent E-channel circuitry needs its own event evidence

P0774 is the intermittent circuit classification for shift solenoid E in Ford's general table, represented as P0770_1F. The failure type explains why a later normal reading is not enough to reconstruct the original event.

## Select the electrical branch deliberately

Ford describes electrical checking as continuous and uses smart-driver fault feedback with a typical 1.5-second criterion. Functional monitoring is different: it evaluates state changes and accumulates event counts. The source does not specify that functional counter as the dedicated recurrence rule for P0774.

The E-channel entries distinguish intermittent circuitry from a persistent open circuit and from shorts toward ground or power. Retaining the suffix prevents a simplified component label from concealing that distinction.

## Correlate timing without inventing a cause

An informative capture includes the electrical status change, commanded E activity and simultaneous supply or other channel faults. A coincident shift disturbance can show when the interruption mattered, but cannot locate it inside a connector, load or controller by itself. Normal function after the event is similarly incomplete evidence.

The monitor description does not provide a universal manipulation test, terminal assignment or resistance limit. Verification must use the applicable electrical procedure and comparable operating conditions. P0771 and P0772 continue to describe separate functional categories, so their presence should be recorded as additional evidence rather than used to overwrite the intermittent classification.

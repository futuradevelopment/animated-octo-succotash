# P0981: The Ford table associates this with an electronic one-way-clutch control

P0981 is described as shift-solenoid D circuit range/performance in the generic dictionary. Ford's 8F57 and 8F24 tables instead place P0981/P0765_67 in an electronic one-way-clutch high-side-control row. The exact architecture and failure representation are therefore essential before assigning a physical D solenoid.

## Preserve the published table ambiguity

The original PDF places the entry under a column headed short to power, but does not explain the _67 representation or provide a dedicated monitor criterion in that row. This article does not silently convert that placement into a universal power-short diagnosis.

The table separately lists the one-way clutch's failed-off result as P1A02. It also has ordinary D-channel open, low, high and functional rows. Those separate entries show why the broad generic title alone cannot determine which control function the module is reporting.

## Resolve the function before choosing measurements

Retain the full controller code, suffix and actual transmission identity. The applicable service definition must establish whether the report belongs to the electronic one-way-clutch control and what comparison or electrical path it evaluates.

The summary supplies no numeric threshold, connector pin or universal test for P0981. It does not prove that the clutch mechanism, a D solenoid or the controller is defective. The useful documented distinction is the architecture-specific control role, while its incomplete failure mapping remains explicitly flagged.

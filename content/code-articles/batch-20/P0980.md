# P0980: Solenoid C circuit high is not proof that the C function is stuck on

P0980 is Ford's short-to-power electrical classification for shift solenoid C, shown with P0760_12. The same source separately labels P0762/P0760_7E as functionally failed on. Those results should not be merged into one diagnosis merely because their brief descriptions sound related.

## Interpret the driver result before a hydraulic conclusion

The general electrical strategy runs continuously and uses smart-driver fault feedback. Its typical criterion requires the fault report for 1.5 seconds. Functional evaluation uses an event-based response filter instead, so a mechanical observation does not reproduce the electrical monitoring rule.

A high voltage reading also needs its command context. The summary does not specify a universal external terminal voltage for every C-channel design. Its documented fact is the driver's power-short classification, not a complete connector test.

## What to preserve for verification

Retain the full code, command state, electrical status and other faults from the same event. A later correct shift can show current function without proving where an earlier electrical path existed. An ongoing response problem likewise cannot identify the harness, load or output stage by itself.

The C designation is not an evidenced universal clutch or valve location. A justified next step uses the exact transmission's electrical procedure to isolate the reported path, while keeping the functional failed-on category separate if it is also present.

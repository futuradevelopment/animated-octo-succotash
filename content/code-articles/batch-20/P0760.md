# P0760: An open solenoid C path is not established by a poor shift alone

P0760 belongs to shift solenoid C's open-circuit branch in Ford's general description. It identifies an electrical control-path result. A poor shift or an unexpected clutch response may be relevant context, but neither alone demonstrates the electrical condition classified here.

## Look for the driver-reported event

The monitor is continuous for electrical faults. Ford's typical criterion is smart-driver fault feedback persisting for 1.5 seconds, whereas functional testing takes place around solenoid transitions and uses event accumulation. These monitoring methods should remain separate when choosing evidence.

The transmission architecture table shows P097C with P0760_13 in the C open-circuit cell. It uses other codes for ground and power shorts. Retaining the detailed failure representation helps avoid treating every C-channel fault as an undifferentiated solenoid failure.

## Follow the evidence toward the correct procedure

An informative record includes driver status, commanded activity and whether other supply or channel faults occurred together. A successful shift after the event does not isolate an earlier open path. Conversely, a failure to achieve a gear ratio does not identify the electrical discontinuity's physical location.

The letter C does not specify one universal connector terminal or clutch arrangement across Ford transmissions. The summary provides no resistance target and no justified replacement. Use the exact transmission's circuit procedure to establish whether the load, wiring or driver path accounts for the reported event before making a mechanical conclusion.

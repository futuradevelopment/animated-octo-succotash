# P0759: Solenoid B intermittency should remain distinct from a sticking diagnosis

P0759 is Ford's intermittent circuit entry for shift solenoid B, with the detailed representation P0755_1F. The result describes an electrical classification that may not be present when the vehicle is inspected. A normal current reading at a later time therefore has limited power to explain the stored event.

## Identify which monitor supplied the evidence

The general table separates B-channel open circuit, low or high circuit faults, intermittency and failed-on/off functionality. Electrical checks run continuously, using smart-driver fault feedback. Functional checks are event based and observe state changes during control activity.

Ford gives a typical electrical persistence criterion of 1.5 seconds, but does not publish a dedicated P0759 dropout waveform or recurrence count in this summary. Borrowing the functional filter's three-count increments would falsely convert a different strategy into an intermittency specification.

## Preserve the moment the classification changed

Capture the full code, failure suffix, command state and circuit-status history. If a shift disturbance occurs at the same time, retain that timing as evidence; it does not by itself identify the interruption's location. A mechanical response after the circuit recovers cannot show which connection or driver path was involved.

Verification needs the applicable electrical procedure and comparable operating circumstances. The source does not justify a universal connector-motion test or tell the reader to replace the valve body. P0756 and P0757 remain separate functional results even when they accompany the intermittent code.

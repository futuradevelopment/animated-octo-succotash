# P2758: Converter-clutch stuck-on evidence requires an off command

P2758 is Ford's functionally stuck-on torque-converter clutch result. The key contradiction is low slip while the clutch is commanded off. Low slip during a legitimate lockup command is not the condition described by this monitor.

## Compare slip with command and torque

The cited gasoline summary gives a typical stuck-on event when converter slip is below 20 rpm with the converter commanded off and input torque above 60 Nm. It also states that the condition must occur in multiple gears before the code is set. A single low-slip snapshot without those conditions is incomplete evidence.

Electrical converter-clutch diagnostics run separately. Their command-versus-driver-feedback check does not directly establish the mechanical release behavior represented by P2758/P0740_7E.

## Record a release failure rather than assuming one

A useful capture includes clutch command, input torque, relevant speeds and the gear in which the observation occurred. If command remains on, that does not reproduce the off-command contradiction. If speed information is unreliable, the slip conclusion needs verification before a mechanical cause is assigned.

The summary does not prove that the converter itself, a particular solenoid or a hydraulic valve is defective. It also does not provide a universal road-test maneuver. The matching transmission procedure must confirm the failed release behavior and isolate its cause using the documented operating context.

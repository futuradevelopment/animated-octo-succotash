# P0744: A published code-mapping conflict changes the diagnostic branch

P0744 is described as intermittent converter-clutch circuitry in the generic dictionary, but Ford's cited summary pairs it with P0740_12 and calls it a short-to-power result. That inconsistency is significant: an intermittent event and a specifically classified power short do not establish the same fault path.

## Check the detailed identifier

In the same document, P2760/P0740_1F represents circuit intermittency, and the architecture table uses P2770/P0740_12 for the power-short classification. A reader should preserve the full module report and failure suffix rather than treating all three displayed codes as aliases.

The documented converter-clutch electrical check evaluates whether output-driver feedback matches the commanded state. Mechanical lockup monitoring uses speed slip and operating conditions instead. A good slip trace cannot certify that the electrical event described by the module never occurred.

## Verify the branch before choosing measurements

If the applicable service definition confirms an intermittent circuit failure, evidence must capture the interruption and its command context. If it confirms the power-short classification, the electrical procedure must investigate that reported path. This is a choice between documented failure categories, not a claim that one universal harness measurement distinguishes every implementation.

The source conflict remains unresolved for the reader's particular vehicle. No connector location, voltage test or replacement is inferred from the generic title. The correct next step is to establish the transmission's actual definition and retain event timing before interpreting a current normal reading.

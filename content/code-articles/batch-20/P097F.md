# P097F: Solenoid F open-circuit reporting has a stable failure-type identifier

P097F is the shift-solenoid F open-circuit classification in Ford's general monitor and architecture tables. The detailed identifier is P2706_13. This electrical branch should be preserved even when neighboring F-channel failure categories use different displayed codes across tables.

## An open-path report is different from a failed response

Ford's general electrical check uses smart-driver feedback continuously and lists a typical 1.5-second persistence criterion. Functional failed-off and failed-on monitoring instead observes control transitions and accumulated response events. The open-circuit result does not directly measure whether a hydraulic valve moves freely.

The F functional entries are P2707/_7F and P2708/_7E in the cited architecture table. They identify separate results, rather than proving where an open circuit is located. A normal functional response after an electrical interruption returns is also incomplete evidence about the earlier event.

## Avoid importing a neighboring fault definition

Record the full module result and suffix, not just the F component label. The electrical procedure for the specific transmission must establish the load and driver path associated with this representation. No universal physical F-solenoid position is provided in the summary.

Useful verification connects commanded activity, driver status and any related supply faults. The source gives no general resistance value or justified valve-body replacement. Isolating the actual open-path evidence is necessary before turning the code into a particular component diagnosis.

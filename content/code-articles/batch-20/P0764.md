# P0764: Intermittent solenoid C circuitry needs the complete failure report

P0764 denotes intermittent shift-solenoid C circuitry in the Ford general table. Its P0760_1F representation preserves the failure type that a brief scanner description may omit. That distinction matters when the current circuit reading looks normal.

## Continuous electrical monitoring differs from a shift-event check

Ford's electrical strategy uses smart-driver feedback and lists a typical 1.5-second electrical fault criterion. Its separate functional strategy counts responses around control transitions. The document does not assign that functional count-up/count-down logic as the threshold for P0764 intermittency.

The C-channel list also distinguishes open circuit, ground short and power short. An intermittent classification should not be automatically rewritten as one of those more specific paths without the controller's detailed report and the applicable diagnostic definition.

## Preserve timing before deciding what failed

Record the command and circuit status around the event, together with any other channel or supply faults. A later smooth shift cannot show whether the earlier interruption arose in a load connection, harness or driver. A coincident mechanical disturbance is useful timing evidence but is not a location test.

Verification should attempt to establish whether the reported electrical condition returns under comparable operation using the correct service procedure. The summary provides no universal resistance limit, pinout or manipulation test. P0761 and P0762 remain distinct functional categories, even when their appearance alongside P0764 helps organize the wider investigation.

# P0762: A solenoid C failed-on result is a functional-state contradiction

P0762 reports functionally failed-on behavior for shift solenoid C in Ford's cited monitor. The relevant contradiction is between the intended control outcome and the observed functional state. The code alone does not establish that a wire is held at battery voltage.

## Functional evidence uses an event filter

Ford separates electrical monitoring, which runs continuously, from functional evaluation during solenoid transitions. The latter uses a filter that adds three per bad event and subtracts one for a correct non-shifting clutch state. Nine counts mature the documented result.

A later correct observation can reduce that filter without explaining all prior failures. When reviewing a recording, preserve whether the event happened during a shift or a non-shifting state, because the example observation durations differ.

## Distinguish failed-on behavior from a power-short report

The architecture table assigns P0762 to P0760_7E and the C-channel power short to P0980/P0760_12. Those identifiers distinguish functional evidence from an electrical path classification. They are not interchangeable merely because a short might be one possible issue investigated by a vehicle-specific procedure.

A useful diagnostic capture connects command state, measured response and electrical status at the same time. The monitor description does not identify a specific stuck valve, clutch or internal leak. It establishes which type of evidence must be resolved before the matching transmission's tests can support a replacement decision.

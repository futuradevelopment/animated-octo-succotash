# P0736: Reverse needs its own diagnostic scope rather than a forward-gear threshold

P0736 is the reverse-gear entry in Ford's ratio-code list. However, the numerical operating window printed immediately after that list is explicitly for forward gear. Applying its forward selector requirement to a reverse complaint would silently extend the source beyond what it states.

## Know what the published example does and does not cover

The general ratio section identifies turbine, output and wheel-speed information as relevant to the monitor. It also describes repeated events across key cycles. Its detailed forward-ratio threshold and forward-range entry conditions are useful context for how ratio diagnostics operate, but they are not a verified universal reverse test limit.

This distinction changes the diagnostic record needed: preserve the commanded reverse state, actual relevant speeds and the full controller result, then use the reverse-specific procedure for that transmission. A forward-drive check cannot substitute for evidence of the reported reverse condition.

## Reverse state has dedicated companion codes

Ford's TR9070 table labels P0736 as unknown reverse-gear state. The same table gives P073E for failure to engage reverse and P072B for failure to disengage it. An unknown state therefore does not establish which of those actions failed.

The missing reverse-specific numerical criterion in this summary is an evidence limit, not a reason to invent one. The article cannot identify a failed reverse clutch or linkage from the code alone. Confirm the applicable diagnostic branch and sensor credibility before interpreting the result as a particular mechanical defect.

# P0761: Solenoid C failed-off monitoring weighs unsuccessful and successful events

P0761 is the functionally failed-off classification for shift solenoid C. It describes a failure to achieve the expected functional state, rather than a direct continuity measurement. A circuit that appears electrically valid can still require a functional investigation.

## Understand the history represented by the code

Ford's functional monitoring is associated with off-to-on transitions. A bad event increases its example filter by three, and a correct non-shifting clutch state reduces it by one. The fault boundary is nine. This makes the history of responses more informative than one later snapshot.

The observation interval also depends on operating phase: approximately one second during a shift and 2.5 seconds for a non-shifting event in the example. These figures describe controller monitoring, not a command to hold an unknown solenoid externally for that time.

## Keep C-channel identifiers specific

The source pairs P0761 with P0760_7F. The C open-circuit entry is separately represented by P097C/P0760_13, while P0762/_7E indicates failed-on functionality. A generic scanner component label can hide these distinctions if the complete code is discarded.

For verification, retain the requested transition, the response used by the transmission and current electrical fault status. If the evidence does not show an eligible event, it cannot demonstrate completion of the functional check. The summary does not assign one universal clutch or hydraulic passage to C; that mapping and any repair decision require the applicable service information.

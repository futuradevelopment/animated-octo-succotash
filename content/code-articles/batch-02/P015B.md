# P015B: Upstream wide-range sensor delay when enrichment starts

P015B is the Bank 1 upstream wide-range oxygen-sensor lean-to-rich delay diagnostic described by this GM table. It runs with the intrusive rear-sensor enrichment tests. Its subject is the measured air/fuel response to added fuel, not a rear oxygen sensor's ordinary voltage amplitude.

## How a failure is recognized

A completed transition produces a normalized delay that feeds an exponentially weighted moving average. The cited failure threshold is above 0.50 seconds, with repass below 0.42 seconds. A different route checks an incomplete response: accumulated time above 4.5 seconds while measured equivalence ratio remains below 1.000. The table also includes a check of equivalence ratio at the end of the catalyst-rich stage.

These alternatives explain why both the shape of the response and whether it reaches the intended state matter. A single final rich value does not reveal the delay that preceded it.

## The preceding test is relevant

The source explicitly requires P015A to be complete and passed. That makes the opposite-direction test useful context when diagnosing P015B. Multiple sensor, fuel-trim and misfire faults are also inhibitors, so apparent silence from this monitor can reflect an unmet prerequisite.

For verification, record enrichment state, upstream equivalence ratio and the completed diagnostic result. The allowed airflow behavior during this test is restricted; a rapidly changing load can prevent a representative result. These observations support a targeted response investigation, while the actual circuit or component repair must come from the applicable vehicle procedure.

## Source and applicability

This explanation is limited to the 2025 GM 25OBDG03A monitor on [page 186](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=186), [page 187](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=187), [page 188](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=188). Its thresholds are calibration examples, not universal specifications. Confirm the vehicle, engine and controller procedure before applying them.

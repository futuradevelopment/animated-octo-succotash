# P013B: How the rear oxygen sensor is judged during enrichment

The cited GM implementation of P013B tests Bank 1 Sensor 2 for a slow lean-to-rich response. It is the sixth stage of a rear oxygen-sensor diagnostic sequence. The controller deliberately increases delivered fuel and observes sensor voltage together with accumulated airflow.

## A rising voltage can still fail

The primary evaluation measures the transition between lower and upper voltage limits, normalizes the response to airflow, and filters the resulting integral. The published failure and repass limits are above 8 and below 6 diagnostic units respectively. If a complete transition is unavailable, a second method uses a 30-gram airflow threshold between 350 and 600 millivolts.

A sensor that eventually reports rich is therefore not necessarily fast enough. Conversely, the filtered result cannot be reconstructed reliably from one ordinary idle snapshot.

## Sequence and abort conditions matter

Earlier rich-to-lean, stuck-signal and lean-to-rich-delay tests must pass before this stage. The source also says the enrichment test aborts if base commanded equivalence ratio leaves its permitted window. An interrupted test is different from a measured slow response.

For diagnosis, preserve the individual monitor outcomes and compare the downstream trace with commanded enrichment and airflow. Confirm heater learning is valid and review inhibiting fuel-trim or misfire faults before drawing a sensor conclusion.

Following corrective work, verify that this final stage actually completes. Clearing memory can activate a faster initial-response mode with multiple tests per trip, so the number of observations may differ from the usual once-per-trip description.

## Source and applicability

This explanation is limited to the 2025 GM 25OBDG03A monitor on [page 174](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=174), [page 175](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=175), [page 176](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=176). Its thresholds are calibration examples, not universal specifications. Confirm the vehicle, engine and controller procedure before applying them.

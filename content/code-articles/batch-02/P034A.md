# P034A: Unexpected crankshaft position during a hybrid auto-start

P034A concerns crankshaft start position. The cited GM monitor is specifically described for hybrid auto-start events, checking whether the crankshaft begins rotating in the position the controller expects. This scope should not be generalized to every conventional starter event.

## Samples are auto-starts, not milliseconds

The table includes a path for an error greater than one crankshaft-wheel tooth, with two failures out of three samples. A second path concerns an error of at least one tooth and uses four failures out of five samples. Each sample occurs at an auto-start while position is being verified.

That sampling structure matters when assessing an intermittent report. One ordinary restart after clearing does not necessarily exercise the same event or provide enough qualifying observations. The actual hybrid auto-start sequence is the relevant operating context.

## Position verification requires a valid reference

The source lists active crank-sensor faults as an inhibitor. Before treating the code as proof of incorrect mechanical timing, establish that crankshaft sensing and the position-verification state are valid.

Preserve the auto-start history, position error if available and related crankshaft faults. Use the vehicle-specific hybrid diagnostic procedure to determine why expected and observed position diverged. The table gives no mechanical adjustment or component replacement instruction. Verification requires eligible auto-start position checks to pass. Hybrid system intervention should remain within the approved professional procedure rather than improvised start-stop testing.

## Source and applicability

This explanation is limited to the 2025 GM 25OBDG03A monitor on [page 269](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=269). Its thresholds are calibration examples, not universal specifications. Confirm the vehicle, engine and controller procedure before applying them.

# P0454: An apparent refueling event caused by an unstable pressure signal

P0454 identifies intermittent fuel-tank pressure information in this GM strategy. Its special context is an ELCP leak test running hours after shutdown: an abrupt vacuum change can look like refueling and cause the leak sequence to stop.

## The controller checks whether refueling was real

After the apparent event, a rationality test looks for a persistent fuel-level change. Confirmed refueling produces a passing sample. If the pressure event is not supported by the required sustained level change, the sample indicates an intermittent pressure-signal problem.

The cited abrupt-change definition includes a vacuum change above 112 Pa over one second, with an additional short-interval restriction. The follow-up can take as long as 600 seconds, and a two-of-three failed-sample decision is used. These are event samples, not three consecutive ordinary voltage readings.

## Diagnosis needs the event pair

Record both pressure and fuel-level histories, together with actual refueling information. A pressure jump by itself cannot distinguish a legitimate tank event from unstable sensing. Equally, an aborted leak test should not be reported as a leak failure when it was diverted into this refueling check.

The monitor is limited by shutdown timing, temperature, fuel level and related sensor/module faults. Verification requires a valid leak-test opportunity and a rational pressure/level relationship. The source supports investigating the intermittent signal path but does not prove a pressure sensor replacement is the only repair.

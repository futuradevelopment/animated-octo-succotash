# P043F: Too little reference vacuum in an EVAP leak-detection check

The cited GM P043F monitor checks the ELCP reference orifice for apparent high flow. With the pump operating across its 0.020-inch reference opening, vacuum below the applicable minimum can indicate a missing reference orifice or inadequate pump flow. The code does not directly locate a leak elsewhere in the fuel system.

## Why both reference measurements matter

A first three-second averaged reading follows a 60-second measurement period; the second follows a 30-second period. Their minimum limits are calibration-table values. A failed reference reading terminates the sequence, while a good first reading alone does not yet produce the final pass.

That makes sequence status important. A monitor that stopped between the checks is not equivalent to a reference system that completed and passed.

## Reproduce the actual opportunity

The table uses propulsion-off wake-up windows several hours after shutdown. It also limits fuel level, ambient pressure and temperatures, and requires adequate relay voltage. Refueling detection, key-up and device control can abort testing. Associated pressure, pump, switch and communication faults can inhibit it.

Preserve the reference-vacuum results and abort reason before selecting a repair. Because pump flow and reference restriction both affect the measurement, the label alone cannot establish which hardware is defective. Verification needs both reference checks to complete successfully before the system's subsequent leak result is considered trustworthy.

## Source and applicability

This explanation is limited to the 2025 GM 25OBDG03A monitor on [page 280](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=280), [page 281](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=281). Its thresholds are calibration examples, not universal specifications. Confirm the vehicle, engine and controller procedure before applying them.

# P0443: Purge-valve open-circuit logic in a row marked disabled

P0443 is the EVAP purge-control circuit code. The cited GM row describes an open-circuit diagnostic for the canister purge solenoid's low-side driver, but its enable column explicitly says the diagnostic is disabled. This page therefore explains the defined logic without proving that this exact calibration executes it.

## The documented electrical principle

The controller evaluates output voltage while the driver is off. An unexpected off-state response is interpreted as an open circuit, with an internal specification corresponding to impedance above 200 kΩ between output and controller ground.

The row also lists relay voltage above 11 volts and a 20-of-25 failure counter at 250 milliseconds per sample. These details belong to the described monitor and should not override the disabled status or be treated as universal workshop specifications.

## Paired codes need controller context

The source notes that P0458 may also set on some controllers. That overlap means an open and low-circuit report need not establish two separate defects. Confirm which purge diagnostic is enabled in the actual vehicle and what driver implementation it uses.

Then distinguish the electrical command path from actual vapor flow; P0443 is not itself a leak or purge-flow measurement. Verification must use the vehicle's active circuit monitor and approved procedure. This source alone cannot support an exact retest schedule or a purge-valve replacement recommendation for an unidentified vehicle.

## Source and applicability

This explanation is limited to the 2025 GM 25OBDG03A monitor on [page 285](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=285). Its thresholds are calibration examples, not universal specifications. Confirm the vehicle, engine and controller procedure before applying them.

# P0442: A small EVAP leak judged against a measured reference opening

P0442 is a small-leak diagnostic. In this GM ELCP vented-fuel-system strategy, the controller compares tank vacuum with vacuum produced across a 0.020-inch reference orifice. The monitored system extends between the fuel cap and purge solenoid; the code does not identify which point leaks.

## The reference comparison is central

The documented failure occurs when tank vacuum remains below the second reference-orifice vacuum measurement for 800 seconds. This is not a universal static pressure threshold. The reference pump/orifice checks must be valid, and P043E/P043F fault status can prevent a trustworthy leak test.

A successful pressure-sensor reading alone therefore cannot establish that the leak monitor was eligible or that its reference was sound.

## Why a short drive may not retest it

The test runs during scheduled propulsion-off wake-up periods several hours after shutdown. Fuel level must lie between ten and ninety percent, with suitable ambient pressure and temperatures. Key-up, refueling detection, service-bay testing and device-control activity can interrupt the sequence.

Record completion or abort status along with the reference and tank measurements. The long vacuum comparison and shutdown schedule explain why clearing the code and restarting is weak verification. Follow the vehicle-specific leak-location procedure to find the actual loss path, then confirm a completed passing monitor. The source does not justify replacing a cap or canister solely because P0442 is present.

## Source and applicability

This explanation is limited to the 2025 GM 25OBDG03A monitor on [page 282](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=282), [page 283](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=283), [page 284](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=284).

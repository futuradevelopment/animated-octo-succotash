# P0453: Fuel-tank pressure voltage exceeds the permitted signal range

P0453 is the circuit-high diagnostic for the fuel-tank pressure sensor. In the cited GM FTZM/ELCP arrangement, the controller fails readings above 4.85 volts, or 97 percent of reference. Its stated ordinary signal interval is 0.5 to 4.5 volts.

## A high electrical signal is not necessarily high tank pressure

The code describes an output outside the intended voltage range. The page's pressure-conversion notation is not needed to identify that electrical condition and should not be used to infer a universal pressure direction. Diagnose signal validity before concluding that the tank is physically overpressurized or under excessive vacuum.

The test is continuous whenever the controller is awake, with 640 failures out of 800 samples at 12.5 milliseconds per sample. It is not confined to a conventional engine-running inspection.

## Retain communication and wake-state context

An active EVAP sensor communication fault inhibits this range evaluation. Record whether the controller received valid data, the raw voltage and when the module was awake. An invalid message and a valid message containing an extreme value call for different diagnostic branches.

Use the vehicle-specific circuit procedure to locate the high-signal condition. The table does not identify a replacement sensor or control module from the code alone. Verification should establish valid communication and a completed high-range test without renewed failures, including the relevant wake condition when an intermittent event occurred off cycle.

## Source and applicability

This explanation is limited to the 2025 GM 25OBDG03A monitor on [page 291](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=291). Its thresholds are calibration examples, not universal specifications. Confirm the vehicle, engine and controller procedure before applying them.

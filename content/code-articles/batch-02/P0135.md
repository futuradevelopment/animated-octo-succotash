# P0135: What the upstream oxygen-sensor heater current test measures

P0135 identifies the Bank 1 Sensor 1 oxygen-sensor heater circuit in the generic dictionary. The cited GM implementation checks heater performance by measuring current through its low-side driver. It compares that current with an expected operating range; it does not diagnose exhaust mixture directly.

## Current, command and timing

The published expected interval is above 0.1 and below 4.3 amperes. The monitor counts samples outside that interval. Its heater warm-up delay must finish, system voltage must exceed 10.5 volts, and heater duty cycle must be greater than zero. Relevant enabling conditions must persist for more than 120 seconds. The table describes two tests per trip and Type B, two-trip reporting.

These conditions change how a measurement should be interpreted. Zero current while heating is not commanded is different from zero current during the enabled test. Likewise, a reading taken immediately after starting cannot simply be compared with the warm, enabled monitor.

## A useful diagnostic record

Capture heater command, supply voltage, measured current if available, and the code's current or historical status together. The source identifies coolant-temperature fault status as an inhibitor, so an unresolved temperature input can prevent a valid rerun.

The diagnostic implication is to establish whether commanded heating produces the expected electrical response. The table alone does not separate an internal heater problem from its supply, wiring or driver. Use the vehicle-specific circuit procedure to make that distinction, then verify an actual completed heater test rather than treating a cleared code as proof.

## Source and applicability

This explanation is limited to the 2025 GM 25OBDG03A monitor on [page 167](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=167). Its thresholds are calibration examples, not universal specifications. Confirm the vehicle, engine and controller procedure before applying them.

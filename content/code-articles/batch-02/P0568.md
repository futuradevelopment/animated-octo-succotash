# P0568: Cruise set command stays active beyond its permitted duration

The cited GM P0568 monitor evaluates a cruise-control set input that remains continuously applied. The body controller communicates an analog input in the set range, and the engine controller judges how long that decoded state persists. This differs from a complaint that cruise simply will not hold a selected road speed.

## Observe the state after release

The failure interval is more than 89 seconds of applied set state within 99 seconds. A scan record showing set still active after the control is released is therefore more relevant than a single snapshot captured during an intentional press. The diagnostic must also be enabled in the engine controller.

Because the test concerns a recognized set range, an invalid voltage between switch ranges represents a different input problem. Preserve raw and decoded information where the applicable scan system provides both.

## The default action is latched for the key cycle

Once P0568 fails, the source says cruise is disabled and disengaged for the remainder of that key cycle regardless of later switch status. A recovered input with cruise still unavailable does not necessarily mean a second fault has developed.

Use the vehicle-specific switch and module-data procedure to locate the cause. Verification should establish that set releases correctly and the relevant monitor completes successfully after correction. The Type C, one-trip classification has no emissions malfunction-lamp request; an unlit lamp does not prove the cruise command path is healthy.

## Source and applicability

This explanation is limited to the 2025 GM 25OBDG03A monitor on [page 336](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=336). Its thresholds are calibration examples, not universal specifications. Confirm the vehicle, engine and controller procedure before applying them.

# P0267: Cylinder 3 injector output remains low during its off-state check

P0267 identifies circuit-low behavior for cylinder 3's injector. The cited direct-injection monitor checks the low-side driver's feedback for a short to ground while the output is powered off. It is designed to identify an electrical state that conflicts with the command.

## What the diagnostic window means

The table specifies ten failures out of twenty samples at 100 milliseconds per sample. The controller's short-ground criterion corresponds to a signal at or below one volt relative to controller ground. Battery voltage must be at least 11 volts and P062B status must not inhibit the test.

These details make two observations useful: whether the low value occurs in the off state, and whether supply/driver prerequisites were valid. A low value during an intended injection command cannot be interpreted with the off-state rule alone.

## Keep the cylinder label separate from the cause

The code identifies the monitored cylinder 3 circuit, but the page does not define cylinder 3's physical location on every engine represented by the larger document. Nor does it show whether an injector, harness connection or controller element creates the low feedback.

Apply the correct engine's electrical diagnostic method to localize the condition. Verification should include the completed low-side off-state test, rather than only checking for an immediate code return after clearing. Direct-injection driver and fuel-system work requires the approved service procedure.

## Source and applicability

This explanation is limited to the 2025 GM 25OBDG03A monitor on [page 230](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=230). Its thresholds are calibration examples, not universal specifications. Confirm the vehicle, engine and controller procedure before applying them.

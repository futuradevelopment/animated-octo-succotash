# P0187: Second fuel-temperature channel low, with a source-label conflict

P0187 is the generic Fuel Temperature Sensor B circuit-low code. The cited GM row's heading and strategy identify SENT fuel-rail temperature sensor 2. It describes counting digital readings that fall below the channel's lower range limit.

## What is supported and what remains uncertain

The page specifies 50 failing observations out of 62, sampled every 100 milliseconds, and Type B, two-trip reporting. It also names P126F internal errors and P128D temperature-message errors as active or pending conditions that inhibit the range diagnosis. Those identifiers distinguish this row's diagnostic context from the first temperature channel.

However, the measured-variable column calls the input “Sensor 1” even though the heading and explanation say sensor 2. This apparent copy error remains unresolved. The printed raw threshold is therefore not presented here as a verified service specification for sensor 2.

## Useful diagnostic interpretation

Identify the second temperature channel and its actual message definition in the applicable service information. Record its raw data, decoded value and internal/message status. A communication failure, an internal sensor error and a valid but out-of-range payload are separate evidence paths.

Successful verification requires a completed range monitor with valid messages, rather than a believable temperature display alone. This article supports the sensor-2 low-range monitoring principle but deliberately leaves the disputed variable mapping for source review before any numeric circuit judgment or component replacement.

## Source and applicability

This explanation is limited to the 2025 GM 25OBDG03A monitor on [page 200](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=200). Its thresholds are calibration examples, not universal specifications. Confirm the vehicle, engine and controller procedure before applying them.

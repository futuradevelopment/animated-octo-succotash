# P0522: Oil-pressure sensor output below its reference-relative range

P0522 is the engine-oil pressure sensor circuit-low code. The cited GM monitor compares the sensor's electrical output with its reference and uses a lower boundary below five percent. This electrical-range result does not independently establish actual oil pressure.

## Running-speed hysteresis affects eligibility

The page enables the test above 400 rpm and disables it below 350 rpm. Those separate thresholds prevent the monitor from repeatedly switching state around one speed boundary. They also mean a stopped-engine voltage check is not the same as an eligible running test.

The sensor must be configured in use and the diagnostic enabled. The counter requires 1,280 failures out of 1,600 samples, evaluated every 3.125 milliseconds, with Type B reporting.

## Keep electrical and lubrication evidence separate

A low converted pressure from the same suspect signal is not an independent confirmation that pressure is physically low. Conversely, the circuit code should not be used to dismiss a genuine oil-pressure warning. Preserve raw signal information, engine speed and the warning condition.

The printed formula formatting is not used here to derive a universal voltage conversion. Apply the correct vehicle circuit procedure and, where needed, the approved mechanical pressure test to distinguish signal failure from a lubrication problem. Verification should confirm valid pressure evidence and a passing eligible circuit-low monitor. Do not run an engine with an active pressure warning solely to accumulate test samples.

## Source and applicability

This explanation is limited to the 2025 GM 25OBDG03A monitor on [page 329](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=329). Its thresholds are calibration examples, not universal specifications. Confirm the vehicle, engine and controller procedure before applying them.

# P0141: Rear oxygen-sensor heater performance and a published-table limitation

P0141 identifies the Bank 1 Sensor 2 oxygen-sensor heater circuit. The cited GM page describes a single-bank-exhaust heater-performance monitor that measures current through the low-side driver and compares it with the expected behavior of the released sensor.

## What the source reliably establishes

The diagnostic depends on heater warm-up being complete and system voltage exceeding 10.5 volts. Relevant enabling conditions must remain satisfied for more than 120 seconds. It uses sample and failure counters, runs up to two tests per trip, and is classified as Type B with two-trip reporting.

This makes command and timing important. Heater current measured before the test is enabled cannot, by itself, explain a stored performance failure. Heater performance is also separate from the oxygen-content signal used to judge exhaust mixture.

## Why no amperage specification is given here

The published threshold is printed as an impossible chained inequality, and the enable column names the Bank 1 Sensor 1 duty cycle despite the row being for Sensor 2. Those inconsistencies are unresolved. This article intentionally does not reverse the inequality, invent a corrected current range, or treat the named duty-cycle input as confirmed for every application.

Use the applicable service procedure to establish the correct heater command, current limits and circuit identification. Preserve measured current, supply voltage and test status so they can be compared with that verified specification. A passing completed heater diagnostic is the useful confirmation after repair. This source supports the monitoring principle, but its conflicting details require review before numeric workshop use.

## Source and applicability

This explanation is limited to the 2025 GM 25OBDG03A monitor on [page 182](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=182). Its thresholds are calibration examples, not universal specifications. Confirm the vehicle, engine and controller procedure before applying them.

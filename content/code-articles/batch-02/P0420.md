# P0420: Catalyst oxygen storage measured through a controlled mixture change

The cited GM P0420 implementation is a legacy intrusive Bank 1 catalyst-efficiency monitor. It estimates oxygen-storage behavior by creating a rich condition followed by lean operation during deceleration fuel cut-off. The diagnostic is not simply a rule that the rear sensor must never switch.

## Response delay becomes a normalized result

The raw oxygen-storage calculation uses rear-sensor response time minus front-sensor response time. It then compares that result with calibrated passing and failing reference values dependent on temperature and exhaust flow. A normalized ratio below 0.38 is the published failure boundary for this monitor, with a 0.10 moving-average coefficient.

This means sensor response validity matters. A slow or faulty oxygen sensor can undermine the information the catalyst test needs, and the table lists relevant sensor fault bundles as inhibitors.

## A valid test has specific conditions

The strategy attempts testing during valid deceleration events, normally one to three times per trip, with additional rapid-response behavior under specified conditions. It requires controlled airflow, predicted catalyst temperature below 900°C and established rich sensor states before the lean transition.

Review the completed catalyst result, upstream/downstream response and test eligibility together. The code does not establish a physical converter defect from one idle graph. Verification should demonstrate a completed passing oxygen-storage test with valid sensors under the applicable calibration. The document is a monitor description, not a universal catalyst replacement procedure.

## Source and applicability

This explanation is limited to the 2025 GM 25OBDG03A monitor on [page 276](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=276), [page 277](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=277).

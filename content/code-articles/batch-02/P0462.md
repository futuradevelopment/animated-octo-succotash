# P0462: Low fuel-level sender data received through the tank module

The cited GM P0462 monitor applies to a fuel float connected to a Fuel Tank Zone Module. It detects a primary fuel-level sender output below ten percent of the five-volt range. The code represents an out-of-range low signal, not merely a low amount of fuel.

## Data availability is part of eligibility

The source requires the level sensor to be initialized, its data to be available and relevant communication faults to be absent. These requirements separate a valid message carrying a low sender value from a module that has not initialized or cannot deliver trustworthy information.

The monitor counts forty failing samples out of fifty at 250 milliseconds per sample and uses Type B, two-trip reporting. A normal gauge indication later does not rule out an earlier counted electrical excursion.

## Follow the module-connected architecture

Confirm the sender's connection route before deciding where to test. This page does not describe a float wired directly to the engine controller, and its voltage-range percentage should not be imported into another architecture without verification.

Save the raw sender percentage, initialization status and communication condition together. The supported next question is why a valid signal falls below its allowed electrical range. Use the applicable tank-module circuit procedure to locate the cause. Verification requires an initialized, communicating system and a completed passing low-range test, not only a changed fuel-gauge needle.

## Source and applicability

This explanation is limited to the 2025 GM 25OBDG03A monitor on [page 300](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=300). Its thresholds are calibration examples, not universal specifications. Confirm the vehicle, engine and controller procedure before applying them.

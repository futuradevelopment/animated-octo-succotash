# P043E: Excess vacuum across the EVAP pump's reference orifice

P043E concerns low flow through the leak-detection reference orifice in the cited GM ELCP vented-fuel-system strategy. The pump creates vacuum across a 0.020-inch reference opening. Excessive reference vacuum can indicate a plugged orifice or unusually high pump flow, according to the source.

## The reference is checked twice

The first evaluation averages vacuum over three seconds after a 60-second measurement period. A second reference evaluation uses another three-second average after 30 seconds. The permitted limits are in supporting tables. Failure at either reference check ends the leak-test sequence.

Passing the first check does not immediately report a full pass; the second must also succeed. That is a useful distinction when a service record shows an unfinished reference test rather than a confirmed reference fault.

## Conditions explain delayed completion

The monitor runs during scheduled propulsion-off wake-up periods several hours after shutdown. Fuel level, temperatures, ambient pressure, relay voltage and communication status must be suitable. Key-up, refueling detection or device control can interrupt the sequence.

Record the first and second reference results and whether the sequence aborted. This is a reference-system diagnostic, so assuming a loose fuel cap from the EVAP label alone misses its target. Verify the complete reference sequence before relying on subsequent leak-test results. The page does not identify a particular orifice-cleaning or pump-replacement procedure.

## Source and applicability

This explanation is limited to the 2025 GM 25OBDG03A monitor on [page 278](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=278), [page 279](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=279). Its thresholds are calibration examples, not universal specifications. Confirm the vehicle, engine and controller procedure before applying them.

# P0222: Throttle-position channel 2 below its reference-relative range

The generic P0222 name combines throttle and pedal terminology, but the cited GM row specifically monitors throttle-position sensor channel 2, or TPS2. It detects continuous or intermittent low/open circuit behavior by evaluating the signal as a percentage of its reference voltage.

## The reference is part of the diagnosis

The threshold is below five percent of reference, with the table defining 100 percent as 5.0 volts. The monitor only runs when run/crank voltage exceeds 6.41 volts and the fourth five-volt reference circuit has no relevant P06A3 fault.

This creates two distinct questions: is TPS2 itself low, and is the reference supporting that judgment valid? A reference fault can affect the test's eligibility, so it should not be treated as unrelated background information.

## Intermittent and continuous paths

The controller uses both a sampled-count path and a continuous-count path at 3.125 milliseconds per count. A brief event may therefore be significant even if a slower scan display appears stable. The source lists Type A, one-trip reporting.

Preserve TPS2, supply/reference status and fault timing together. Use the vehicle-specific electronic-throttle procedure to identify the circuit and distinguish an open from a low short; the code alone does not select a component. Verification should establish that the low/open monitor completes with a valid reference. Do not infer a pedal-sensor location from the broad dictionary title.

## Source and applicability

This explanation is limited to the 2025 GM 25OBDG03A monitor on [page 213](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=213). Its thresholds are calibration examples, not universal specifications. Confirm the vehicle, engine and controller procedure before applying them.

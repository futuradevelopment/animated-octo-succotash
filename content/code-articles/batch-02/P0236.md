# P0236: Boost-sensor plausibility across several airflow models

P0236 is a boost-pressure sensor performance code in the cited single-turbo GM strategy. It can detect a signal stuck within its normal electrical range. The controller uses an intake-flow rationality diagnostic that compares measured values with models built from airflow, manifold pressure and throttle position.

## One disagreement is not the whole decision

The table lists multiple model residuals, including a boost-pressure-model difference above 30 kPa. However, P0236 is assigned through a combination-of-failures matrix. It is not justified to treat any one listed residual as a standalone universal P0236 trigger.

A separate correlation uses manifold pressure under high-airflow conditions and ambient pressure under low-airflow conditions. Each state must persist for more than 1.5 seconds before its comparison is valid. That explains why comparing boost pressure with manifold pressure at an arbitrary load may be misleading.

## Useful diagnostic direction

Record the relevant measured pressures, airflow, throttle information and available model results in the same operating state. Confirm the inputs are valid: circuit faults in these related sensors can inhibit the performance evaluation.

For verification, use the applicable failure matrix and confirm the rationality monitor completes. An electrically in-range boost reading is not sufficient, because detecting plausible but incorrect values is the point of this test. The page does not establish which physical component caused the model disagreement or authorize automatic boost-sensor replacement.

## Source and applicability

This explanation is limited to the 2025 GM 25OBDG03A monitor on [page 218](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=218), [page 219](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=219), [page 220](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=220). Its thresholds are calibration examples, not universal specifications. Confirm the vehicle, engine and controller procedure before applying them.

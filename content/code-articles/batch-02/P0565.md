# P0565: Momentary cruise on/off input remains applied too long

P0565 identifies a cruise-control on-signal problem. The cited GM monitor applies specifically to a momentary on/off switch architecture. It detects a decoded on/off input that remains applied longer than expected, rather than treating a maintained-switch design as inherently faulty.

## The cited timing is calibration-specific

This 25OBDG03A row uses more than twenty seconds in the applied state within a 25-second observation period. The body controller communicates the analog input's decoded range to the engine controller, where the CAN cruise-switch diagnostic must be enabled.

A continuously applied valid on/off range is different from voltage between recognized switch ranges. Capture the decoded state over time, not only a brief voltage snapshot. That helps distinguish a retained command from an input that is electrically invalid.

## Recovery may wait for a later key cycle

Once the monitor fails, the documented default action disables and disengages cruise for the rest of the key cycle even if the input later appears normal. Persistent cruise unavailability after signal recovery is therefore consistent with the stated control action.

Use the applicable momentary-switch and module-data procedure to locate the reason for the retained command. Verification should confirm the on/off state releases correctly and the monitor passes after correction. Do not extrapolate this timing to other controller calibrations. The row is Type C with no emissions malfunction-lamp request, so lamp status alone does not verify cruise-switch health.

## Source and applicability

This explanation is limited to the 2025 GM 25OBDG03A monitor on [page 334](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=334). Its thresholds are calibration examples, not universal specifications. Confirm the vehicle, engine and controller procedure before applying them.

# P0182: Low digital fuel-temperature data on the first SENT channel

The generic P0182 title refers to Fuel Temperature Sensor A circuit low. The cited GM monitor is more specific: it evaluates the first fuel-rail temperature channel carried by a SENT digital sensor. It compares the digital read value with a lower limit of 145.

## A digital limit is not a temperature reading

The threshold is a raw digital value, not 145 degrees and not a voltage specification for a meter. The controller accumulates low-value failures and reports the result after the defined count. The table specifies 50 failing samples out of 62 at 100 milliseconds per sample, with Type B, two-trip reporting.

This changes the first diagnostic question. An out-of-range payload must be distinguished from a message that was not communicated correctly. SENT communication faults, internal-error P126E and message-error P128C are listed as prerequisites that can inhibit the temperature range check.

## Evidence and verification

Save the temperature-channel raw value if available, the decoded temperature and the associated message status. A normal decoded value after a code clear does not establish that the earlier payload was valid, especially if communication or internal errors remain unresolved.

Use the applicable sensor and controller procedure to identify the physical circuit and permitted tests. The monitor page provides no universal pinout or resistance specification. Confirmation consists of valid SENT data and a completed range test that no longer accumulates low-channel failures, not merely a change in the displayed temperature.

## Source and applicability

This explanation is limited to the 2025 GM 25OBDG03A monitor on [page 198](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=198). Its thresholds are calibration examples, not universal specifications. Confirm the vehicle, engine and controller procedure before applying them.

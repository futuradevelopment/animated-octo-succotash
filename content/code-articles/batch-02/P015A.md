# P015A: Upstream wide-range sensor delay during a rich-to-lean change

P015A concerns delayed rich-to-lean response from the Bank 1 upstream wide-range air/fuel sensor in the documented GM strategy. The controller runs this test alongside intrusive rear-sensor testing that commands fuel cut-off. It evaluates measured equivalence ratio rather than applying a conventional rear-sensor voltage-switching rule.

## Processed delay versus a timeout

When the sensor completes the transition, the primary method normalizes response time for operating conditions and updates a filtered result. The published failure limit is above 0.50 seconds of normalized moving-average delay; repass is below 0.42 seconds. The filter coefficient is 0.20.

A separate path catches a response that does not reach the required state: more than four seconds of accumulated test time with measured equivalence ratio still above 0.300. This fallback should not be confused with the filtered half-second limit. They represent different ways of evaluating the same transition.

## Diagnostic implications

Capture equivalence ratio, fuel-cut status and monitor results together. The source requires a warmed sensor and engine, closed-loop prerequisites, and specific speed, airflow and catalyst-temperature conditions. Therefore, an ordinary idle observation is not equivalent to this diagnostic.

Related oxygen-sensor, misfire and fuel-trim faults can inhibit the test. Resolve their meaning before interpreting a missing P015A result. After repair, confirm the relevant response test completes; memory clearing can temporarily allow additional tests per trip and alter the way the filtered result converges. The table provides no direct instruction to replace the sensor based on the code alone.

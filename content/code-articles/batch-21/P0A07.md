# P0A07: Hybrid coolant-pump feedback is checked in the off state

P0A07 is evaluated with the coolant pump commanded off in GM's BAS hybrid summary. The controller compares a returned echo-back signal with the low-side-driver output. The purpose is to identify an electrical control disagreement, not to conclude directly that coolant circulation is excessive or inadequate.

## An off-state result answers a different question

The adjacent P0A06 row is qualified by a pump-on condition. A pump that appears to operate when requested does not automatically prove that the off-state feedback is correct. Both the intended command and the returned status are necessary to interpret the recorded fault.

The table uses four 80-millisecond observations and lists a 320-millisecond evaluation while the controller is awake. These are internal monitoring details, not instructions to cycle or electrically bypass the pump.

## Printed high and low descriptions need confirmation

The source combines conflicting high/low wording in this row. Its circuit description does not justify choosing a universal connector-voltage diagnosis. The exact vehicle service information must resolve that mapping before electrical testing.

Preserve the command state, controller status and companion cooling or electrical faults. Hybrid-system testing should follow the specified professional procedure. Verification needs a correct off-state feedback result and completed monitoring, together with any prescribed cooling-function check. Clearing P0A07 or seeing the pump run briefly does not establish that the original off-command disagreement is resolved.

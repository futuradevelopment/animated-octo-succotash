# P0412: Secondary-air valve circuit feedback versus command

P0412 is an electrical-integrity check of the secondary-air solenoid circuit in GM's group 07 summary. The controller watches whether the observed circuit state matches the output-driver command. That is a different question from whether the pump produces enough air or whether air reaches the exhaust.

## Identify the controlled component correctly

The same page assigns P0418 to the pump control circuit. P0412 concerns the solenoid channel. Keeping those channels separate prevents a pump-related assumption from replacing evidence about the valve-control circuit.

The published test operates with system voltage above 10 and below 18 volts. It uses 50 failing samples out of 63, in a 250-millisecond loop. A brief manual observation without the command state or supply context cannot reproduce that repeated feedback comparison.

## Electrical success is not flow success

A solenoid circuit can pass its electrical check while another part of the air system has a flow problem. Conversely, a valve that happens to be in a useful position at one moment can still have intermittent control feedback. Preserve both circuit and flow-related codes rather than treating them as interchangeable.

Use the vehicle-specific circuit procedure to identify where command and feedback separate. The source supplies no universal connector pinout or automatic replacement decision. Verification should include completion of the valve-circuit monitor and, where required by service information, the separate air-system functional check.

# P3400: Cylinder deactivation does not produce the expected pressure behavior

P3400 is a cylinder-deactivation performance check for AFM applications in GM's group 07 summary. The controller compares measured manifold pressure with a model and considers the difference between a previous all-cylinder event and the current state. The code therefore concerns whether the expected deactivation behavior occurred, not merely whether a solenoid received an electrical command.

## Deactivation must first be permitted

The source lists extensive enable conditions involving engine and oil temperatures, operating state, gear selection and time since a previous deactivation event. Oil-pressure and transition-related conditions continue onto the following page. A vehicle remaining in all-cylinder mode because those prerequisites are not met has not necessarily failed this monitor.

The diagnostic also counts repeated residual failures rather than declaring a fault from one transition. Preserving the requested mode and qualification state is consequently important when reviewing a complaint.

## One printed formula cannot be used literally

The table includes an absolute-value expression compared with a negative bound. That is not a usable mathematical pass/fail instruction. This article does not silently repair the formula or invent a replacement threshold.

Use the exact engine calibration and service procedure to distinguish a performance failure from an inhibited deactivation request. The code does not identify a particular lifter, oil passage or solenoid as failed. Verification should demonstrate the expected mode response and completed monitoring under qualified conditions, rather than just clearing the code.

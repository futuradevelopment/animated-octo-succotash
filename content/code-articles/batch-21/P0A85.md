# P0A85: Fan control feedback stays high despite a lower command

The P0A85 strategy in GM's BAS hybrid table checks fan-control feedback above 95 percent while the fan is on and the command remains below 80 percent. The command qualification is crucial: a high feedback value is not interpreted in isolation.

## Compare the requested and returned control levels

A feedback value near full scale can be inappropriate when the controller requested a lower level. The source therefore pairs the returned control feedback with the commanded level. It does not directly classify the fan as physically stuck at a particular speed.

The separate P0A83 stuck-on check uses speed feedback under an off command. Keeping that distinction prevents a control-signal disagreement from being automatically described as continuous fan rotation.

## Qualified persistence supports the decision

The energy-storage controller must be in Run or Service with system voltage inside the documented window. The failure counter requires 188 of 250 observations, sampled every 20 milliseconds. A momentary mismatch during a transition is not necessarily the same recorded pattern.

Preserve command, control feedback and speed feedback as separate evidence. Use the applicable vehicle circuit procedure to identify the source of the high returned control signal. Verification should demonstrate that feedback follows the lower commanded level and that monitoring completes. Clearing P0A85 or seeing the fan cool the battery once does not establish that the control-feedback disagreement is corrected.

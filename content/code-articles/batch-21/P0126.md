# P0126: Coolant warm-up judged against a temperature model

Although P0126 is commonly labeled insufficient coolant temperature, this GM group 05 monitor compares the sensor with a calculated coolant-temperature model. The model is based mainly on airflow, with corrections for intake temperature, engine speed and starting coolant temperature.

## The model defines the comparison point

The check occurs when modeled coolant reaches 25°C. At that point, the published failure limits are measured coolant below 20°C or above 100°C. The upper limit is a useful reminder that this implementation also detects an implausible mismatch; the code is not simply a command to replace a thermostat that seems too cold.

The table requires a running engine and starting coolant above −7°C. It lists a 300-second evaluation and once-per-driving-cycle operation. Those qualifications explain why prolonged idling or a different starting temperature may not reproduce the stored result.

## Interpret the inputs together

A diagnostic record should connect coolant behavior with starting conditions and the airflow information used by the model. A plausible-looking temperature reading can still disagree with the modeled warm-up state. Conversely, an inaccurate input to the model can affect the comparison without proving a cooling-system component has failed.

Use the applicable service procedure to separate temperature-sensor accuracy from actual warm-up performance. After repair, confirm that this specific monitor completed successfully under qualified conditions. An erased code or an uncompleted monitor cannot demonstrate that the model and measured temperature now agree.

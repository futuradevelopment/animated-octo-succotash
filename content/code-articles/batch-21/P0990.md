# P0990: Pressure switch E fails to confirm pressurization

P0990 is the pressurized-state counterpart of the switch E check in GM's group 03 transmission table. The controller expects the switch to report pressure when the CBR1/C456 hydraulic condition reaches the specified high level.

## The continuation page supplies the actual decision

The first page lists pressure at or above 700 kPa. The following page explains that a table-based hydraulic delay must expire before switch state is judged. If the switch does not indicate pressurized afterward, the controller increments a failure counter; the listed threshold is 15 failing counts.

Reading only the generic high-circuit title would miss both the hydraulic expectation and the delay. A switch state observed during an unfinished pressure transition cannot be treated as the completed diagnostic result.

## Determine whether the state or its report is wrong

The monitor requires suitable fluid temperature, voltage and engine speed and excludes specified temperature, solenoid and range faults. Those prerequisites need to be restored before lack of a returning code can count as verification.

Preserve the expected pressure state, switch indication and related faults. Follow the matching transmission procedure to separate hydraulic behavior from switch or circuit reporting. P0990 alone does not choose a replacement part. Verification should demonstrate the correct pressurized indication after the prescribed delay and successful monitoring, not merely an empty code list immediately after clearing.

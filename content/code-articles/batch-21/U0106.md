# U0106: Engine and glow-plug controllers lose expected messages

U0106 identifies lost communication between the engine controller and glow-plug control module in GM's Duramax summary. The documented strategy has two directions: the engine controller can miss the glow-plug module's message, or the glow-plug module can miss an expected engine-controller message.

## Determine which message path failed

The table names different message identifiers for the two paths. That distinction matters because a generic scan-tool label may show only the module relationship, without revealing which controller stopped receiving the expected information.

The monitor operates with ignition on and uses a ten-second monitoring interval with checks every 160 milliseconds. A module that responds briefly during a later scan has not necessarily demonstrated continuous delivery of the messages required by this test.

## Communication loss is not a glow-plug element diagnosis

The code does not directly identify a failed glow plug or prove that the glow-plug control module itself needs replacement. Its evidence concerns expected communication. Module power, network behavior and the detailed originating fault record must be evaluated through the applicable service procedure.

Preserve both controllers' records and any accompanying supply or network codes before clearing them. Verification should establish reliable communication in both relevant directions and successful completion of monitoring. An engine that starts normally on one occasion or a code that has merely been erased does not prove the original message-loss condition is resolved.

## Source and applicability

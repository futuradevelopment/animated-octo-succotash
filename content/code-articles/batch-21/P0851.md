# P0851: Engine and transmission controllers disagree about Park or Neutral

In GM's Duramax summary, P0851 is detected by comparing two park/neutral status paths. The transmission controller broadcasts Park or Neutral over GMLAN, while the engine controller's directly sensed switch input disagrees. The generic circuit-low name alone does not explain that comparison.

## Two status sources are needed

A diagnostic record should preserve both the transmission message and the engine controller's sensed position. A single scan-tool label for gear position may show only one of those sources and conceal the disagreement that triggered the code.

The monitor requires ignition on, battery voltage within its documented range and no active transmission-communication fault or opposite-direction P0852 fault. The condition must persist for one second. If communication is lost, absence of a new P0851 does not prove the two positions agree.

## Status disagreement is not a complete range-switch diagnosis

The code does not establish which input path is inaccurate or prove a specific switch adjustment. Use the exact vehicle's circuit and range-status procedure before selecting a component or changing an adjustment.

Preserve the original status combination and companion codes. Verification should demonstrate agreement between the two monitored paths under the relevant operating states and successful completion of the diagnostic. A correct dashboard gear indication or an erased fault list cannot independently establish that both the engine and transmission controllers now receive consistent park/neutral information.

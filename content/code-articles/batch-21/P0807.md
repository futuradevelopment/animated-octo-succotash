# P0807: Low clutch-pedal sensor signal relative to its reference

P0807 identifies a continuous low or open clutch-position sensor circuit in GM's GMDAT summary. The threshold is expressed as less than five percent of the sensor reference voltage. That relative threshold should not be replaced by a guessed fixed voltage without confirming the actual circuit specification.

## The reference circuit is part of the interpretation

The continuation page lists a reference-voltage fault as an inhibiting condition. A faulty reference can undermine the meaning of the pedal signal itself. Investigating a companion reference fault is therefore different from assuming that the pedal sensor independently failed.

The controller evaluates 200 failures in 250 samples using a 25-millisecond loop. The engine must not be cranking and the system voltage must satisfy the documented minimum. One low observation during an unqualified power transition is not automatically the same pattern.

## Separate circuit level from pedal performance

The neighboring P0806 check asks whether pedal position agrees with in-gear evidence. P0807 instead identifies the electrical low direction, including an open circuit. A sensor can fail one type of check without establishing the other.

Record the signal and reference-fault context before following the vehicle-specific circuit procedure. The summary does not identify a connector pin or automatic part replacement. Verification should show a credible pedal signal and completed circuit monitoring under qualified conditions; simply clearing the code cannot establish either.

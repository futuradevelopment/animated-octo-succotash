# P0501: An implausibly high vehicle-speed report in a manual-transmission example

The GM group 02 P0501 entry is a high-range plausibility check of vehicle speed for a manual-transmission application. It concerns what the controller believes the speed to be. It does not establish that the vehicle physically travelled at the reported value.

## This implementation tests the reported range

The source lists a reported speed above 171.9 mph sustained for two seconds. That figure is a diagnostic ceiling in this calibration, not a road-test target or a general threshold for all P0501 implementations. There is no reason to attempt to reproduce such a reported value by driving at high speed.

A stored speed far beyond plausible operation points the investigation toward the validity and interpretation of the speed information. The code itself does not distinguish a sensor problem from the signal path or controller processing.

## Preserve evidence before it disappears

Useful records include the vehicle-speed value associated with the fault and whether other available speed references agreed at that time. A normal display during a later parked check does not exclude an intermittent implausible report.

Confirm the exact transmission and controller definition before using this example. Other implementations can use different performance comparisons under the same generic code. Verification should establish credible speed reporting and successful completion of the applicable monitor under ordinary, safe operating conditions. An erased code alone does not show that the original out-of-range report has been eliminated.

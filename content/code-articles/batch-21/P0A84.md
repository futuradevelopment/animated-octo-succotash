# P0A84: Battery fan control feedback remains below its valid level

P0A84 is the low fan-control feedback check in GM's BAS hybrid summary. With the fan state on, the controller evaluates control feedback below five percent. This monitored quantity is distinct from the fan-speed feedback used by the stuck-off diagnostic.

## Control feedback and rotation are separate evidence

The nearby P0A82 entry checks whether speed feedback appears absent during an on command. P0A84 instead concerns the control-feedback channel. A fan that physically turns may still have an unreliable monitored control signal, and a low control-feedback code alone cannot establish exactly how fast the fan rotated.

The test runs with the energy-storage controller in Run or Service and system voltage above nine and below eighteen volts. It uses 188 failures within 250 samples at 20-millisecond intervals. Those qualifications make the diagnosis more specific than one low observation during startup.

## Preserve the correct parameter identity

Record the command, control feedback and speed feedback separately where available. The summary does not provide a universal connector voltage or identify which component caused the low feedback. The generic circuit-low label must be interpreted through the actual vehicle's fan-control arrangement.

Follow the matching service procedure, then verify valid control feedback and completed monitoring under the on-command condition. A cleared code list or a fan heard running briefly does not prove the monitored control-feedback path has been restored.

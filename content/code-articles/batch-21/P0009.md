# P0009: Bank 2 timing alignment needs a bank-level comparison

The documented P0009 monitor examines Bank 2 as a timing system. GM groups its description with that bank's idler sprocket and evaluates the adapted angles of both cams. A valid electrical signal can still describe an incorrect mechanical relationship, so a normal-looking sensor voltage alone cannot settle this code.

## Separate bank alignment from one cam

The adjacent P0018 and P0019 entries concern individual Bank 2 intake and exhaust cam alignment. P0009's paired-cam comparison gives a reason to examine whether both learned offsets follow the same pattern. The source does not identify a particular failed part, and it does not justify replacing both sensors because both positions are involved.

This is an adapted-angle monitor. Its prerequisites include the absence of cam sensor and cam control circuit faults. The table also requires adaptation cycles before the evaluation can mature. Those conditions matter when interpreting a recently reset controller or an incomplete post-repair check.

## Evidence to carry into diagnosis

Preserve the original Bank 2 code combination and compare the individual cam information with the bank-level result. Confirm completion of the applicable adaptation and monitor using vehicle-specific service information.

The source's merged threshold row leaves the relationship between its positive and negative angle limits unclear. This article therefore supplies no workshop timing tolerance. A fresh stored code with valid adaptation is more informative than assuming success merely because memory was cleared.

# P1133: Bank 1 oxygen-sensor switching is evaluated over a qualified window

GM's group 07 P1133 monitor evaluates switching activity of Bank 1 Sensor 1. It counts qualified rich-to-lean and lean-to-rich behavior, using half-cycle and slope-time criteria. The presence of an occasional voltage change is therefore not enough to establish that the sensor passes.

## The test needs suitable fuel-control conditions

The sample window is 70 seconds in this implementation. The continuation page requires closed-loop operation, suitable airflow and engine speed, a warmed sensor and valid heater learning. Misfire, fuel-system and related sensor faults can inhibit the test or invalidate its context.

These qualifications explain why a sensor waveform captured during a cold start or a different fueling state cannot be compared directly with this monitor's switching limits. The source refers to supporting threshold tables rather than providing one universal switching rate.

## A slow-looking signal is not a complete diagnosis

The diagnostic observes sensor response within a controlled operating context. It does not prove from the code alone whether the sensing element or another condition affecting the measured exhaust response is responsible. Preserve companion faults and the qualified operating state before selecting a repair.

The source also describes a new-vehicle delay feature that cannot be re-enabled in service; do not invent a reset routine for it. Verification requires a completed qualified switching test. Clearing P1133 or seeing several transitions on a scan tool does not establish that the full monitor passed.

## Source and applicability

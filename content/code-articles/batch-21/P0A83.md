# P0A83: Battery cooling-fan speed persists after an off command

GM's BAS hybrid P0A83 monitor identifies a fan-stuck-on condition through speed feedback. The fan state is off, yet speed feedback remains above the documented five-percent threshold. The command state is essential; the same feedback while the fan is intentionally on would not establish this fault.

## Repeated feedback is different from one observation

The source accumulates 188 failing observations in 250 samples, taken every 20 milliseconds. It qualifies the test with the energy-storage controller in Run or Service and system voltage within its operating window. An isolated observation without those conditions cannot reproduce the complete decision.

This check uses fan-speed feedback rather than the separate fan-control feedback used by the circuit monitors. Knowing which parameter a diagnostic tool displays avoids confusing command-related electrical information with evidence of rotation.

## Confirm both the requested state and the reported response

The code does not prove that a relay is welded or that a particular electronic component failed. It reports disagreement between the intended off state and the speed indication. The exact vehicle procedure is needed to distinguish actual continued rotation from inaccurate feedback.

Preserve the off command, speed feedback and companion faults. Verification should show the correct response when the fan is expected to stop and successful monitor completion. Clearing the code or observing normal cooling under an on command leaves the original off-state disagreement untested.

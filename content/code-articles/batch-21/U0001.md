# U0001: The transmission controller reports a CAN bus-off state

U0001 is the high-speed CAN bus check in GM's GMDAT transmission summary. The controller monitors the CAN hardware's bus-on/bus-off state and identifies a bus-off condition. That is different from merely failing to receive one expected message from a particular module.

## Bus state and missing messages are distinct evidence

The same page separately assigns U0100 to missing engine-controller messages. U0001 concerns the broader communication state reported by the CAN controller. When both are present, the bus-state fault can change how individual missing-message codes should be interpreted.

The source uses repeated bus-off indications and a qualified diagnostic state. A scan tool that connects successfully at a later moment does not prove that the bus remained available during the original event.

## Record the network pattern before clearing it

Preserve which modules responded, which reported bus-off and which recorded only missing messages. That pattern is more useful than replacing a named module solely because it appears in a secondary communication code.

The summary does not identify the faulty wire, connector or module from U0001 alone, and it does not provide a universal resistance-test procedure. Use the exact vehicle network diagram and diagnostic process. Verification should establish stable communication and completed monitoring under the conditions associated with the failure. An erased code list or one successful scan-tool connection cannot demonstrate that an intermittent bus-off problem is corrected.

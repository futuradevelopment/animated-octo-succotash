# P0385: Missing low-resolution crank pulses despite other timing signals

In this GM group 09 implementation, P0385 concerns the low-resolution crankshaft signal identified as sensor B. The controller compares that signal with medium-resolution crank pulses and a camshaft reference. The code therefore describes missing information in a multi-signal timing system, not merely an engine that is stationary.

## Other pulses establish the expectation

The failure description requires medium-resolution and cam evidence while the low-resolution pulse count remains zero. That relationship explains why checking each signal independently may overlook the actual diagnostic question: did the expected low-resolution events accompany the other timing events?

The listed prerequisites include engine running time and engine-speed information. The monitor accumulates 40 failures in 50 samples, with evaluation tied to the relevant signal interrupts and the cam check. This is a recognized pattern of missing pulses rather than one instantaneous observation.

## Keep absence separate from an incorrect count

The neighboring P0386 strategy addresses a low-resolution count that is present but inconsistent. That distinction can guide whether the service procedure investigates complete signal loss or waveform/pattern plausibility.

Preserve companion timing codes and the available synchronization record. The summary does not establish a sensor location, connector pin or automatic replacement decision. After work, verify that the expected timing signals are consistently recognized together and that the applicable monitor completes. A single successful start does not demonstrate correction of an intermittent missing-signal condition.

# P1134: Rich-to-lean and lean-to-rich transition times differ

P1134 concerns the relationship between rich-to-lean and lean-to-rich response times for Bank 1 Sensor 1 in GM's group 09 summary. The sensor can still switch while its transition timing fails the documented comparison. That distinguishes this check from merely asking whether the signal changes at all.

## Directional response is measured over time

The table uses a 90-second sample period and a signed transition-time difference. This makes the direction and duration of response relevant, rather than just the number of visible peaks on a scan-tool graph.

Closed-loop fueling, valid heater information and suitable engine conditions qualify the test. Intrusive fuel, air, idle and EGR tests must not be active, and relevant sensor or misfire faults must be absent. A waveform collected during those excluded conditions cannot be treated as the same diagnostic evaluation.

## One published temperature field is unsuitable as a test limit

The source contains a placeholder-like heater-temperature range that is not usable as a practical operating specification. This article does not repeat it as a workshop limit. The exact calibration procedure remains necessary for numerical diagnosis.

Preserve the timing behavior in both directions and the fuel-control context. The code does not automatically identify a sensor replacement. Verification should show completed transition-time monitoring under qualified conditions, not simply a cleared fault or a signal that visibly oscillates after the engine warms.

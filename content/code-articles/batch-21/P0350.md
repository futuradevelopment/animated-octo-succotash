# P0350: Ignition control feedback fails to match the command

GM's group 09 P0350 monitor checks the ignition-control circuit while the engine is running or cranking. It compares the commanded output-driver state with the state reported by the circuit. This is electrical-control evidence, not a direct test of spark quality inside a cylinder.

## The cylinder mapping is specific

The description names cylinder 1 and, for the documented V6 waste-spark arrangement, cylinders 1 and 4. That pairing belongs to this source's configuration. It must not be applied to a different engine simply because the scan tool displays P0350.

The test is inhibited when P1350 is active. A missing new P0350 in the presence of that companion fault is therefore not proof that the ignition circuit has recovered. The recorded fault order and current monitor status are useful parts of the diagnostic evidence.

## Repeated disagreement rather than one event

The published counter requires 90 failures in 100 samples at a 100-millisecond rate. An isolated voltage observation cannot substitute for the controller's repeated command-versus-feedback comparison.

A service investigation should establish the correct ignition architecture, the monitored control channel and whether its feedback follows the command. The summary does not distinguish a coil defect from wiring or driver problems by code alone. Verify the applicable circuit monitor after correction, and use the vehicle's prescribed ignition test method rather than improvised high-voltage probing.

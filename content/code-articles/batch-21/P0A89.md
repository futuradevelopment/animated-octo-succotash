# P0A89: High current-sensor voltage differs from actual overcurrent

The P0A89 check in GM's BAS hybrid table evaluates auxiliary power-module current-sensor voltage above 4.5 volts. It runs while the module is awake, with a listed one-millisecond detection interval. This is a sensor-circuit range decision, not automatically a measurement of excessive real current.

## Separate the sensor limit from protection logic

The source lists a distinct overcurrent diagnostic with its own hardware and software criteria. P0A89 should therefore not be substituted for that protection code. A sensor at an electrical extreme can produce an unreliable current interpretation even when the actual circuit current has not been established.

The neighboring P0A87 check instead tests plausibility during current-limit operation. A high-circuit fault and a current-limit performance mismatch require different evidence and may block different diagnostic conclusions.

## Confirm the signal before using its amperage

Preserve the originating controller's records and related voltage or current faults. A displayed current value cannot be trusted simply because the scan tool expresses it in amperes; its underlying sensor circuit must be valid.

Follow the specific hybrid power-module diagnostic procedure using appropriate professional methods. The summary does not identify a failed sensor, wire or module from the code alone. Verification should demonstrate a valid signal and completed monitoring, plus any separate power-function checks required by service information. Clearing P0A89 does not prove the high electrical condition is resolved.

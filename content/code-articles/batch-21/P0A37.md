# P0A37: Generator temperature compared with other electronics after cooling

GM's BAS hybrid P0A37 strategy compares motor-generator temperature with the average of four other temperatures in the power electronics. The source uses two inverter temperatures, an auxiliary power-module temperature and board temperature. This is a correlation check across the cooled system, not a direct overheating diagnosis.

## The eight-hour soak is part of the test

The engine-off time must exceed 480 minutes. After that qualified cooling period, the published absolute difference threshold is 30°C. A comparison taken immediately after operation would not reproduce the source's assumption that the monitored assemblies have had time to cool.

The check excludes motor overtemperature and generator-temperature low/high circuit faults. Those conditions must be understood before treating an in-range correlation result as reliable evidence.

## An average does not identify the inaccurate input

A disagreement can involve the generator reading or the temperatures used in the reference average. The code alone does not establish which individual sensor is biased. Preserve the complete temperature set and soak history rather than replacing the generator sensor from its name alone.

Use the appropriate hybrid diagnostic procedure to assess signal credibility safely. Verification should include a completed qualified-soak comparison after related circuit faults are addressed. Matching temperatures during one arbitrary operating moment, or an erased P0A37, cannot demonstrate that the original cooled-system correlation check now passes.

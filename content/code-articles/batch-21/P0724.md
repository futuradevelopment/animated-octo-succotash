# P0724: Brake signal stays active during repeated acceleration

P0724 is the high-direction brake-switch plausibility code in GM's group 06 summary. The controller evaluates repeated acceleration while the brake indication remains active. This implementation therefore uses a relationship between operating behavior and switch state, rather than a published universal high-voltage threshold.

## The active state needs operating context

The documented pattern is four increases from approximately 2 mph to 25 mph within a specified time window, with the engine running and the brake signal active. These are monitor criteria, not road-test instructions. Diagnostic equipment and the approved service procedure should be used to examine the original event safely.

The opposite P0719 strategy evaluates an inactive signal during repeated deceleration. Keeping those patterns separate helps identify whether the controller saw an input that appeared stuck active or one that failed to indicate braking.

## A brake lamp check is only part of the evidence

The code does not prove a hydraulic brake problem or establish brake-system safety. It concerns the controller's brake-status information. A single correct lamp response may not demonstrate that every monitored signal path is reliable.

Preserve the brake status, speed history and companion faults. Confirm the vehicle's exact switch arrangement before testing or adjustment. Verification should show correct release and activation recognition plus completed plausibility monitoring. Erasing P0724 without checking the monitored status can leave the original disagreement unresolved.

# P006D: BARO disagreement depends on the age of its estimate

GM's documented P006D strategy compares the barometric pressure sensor with a calculated barometric estimate. The estimate can come from part-throttle calculation or unthrottled supercharger inlet pressure. The entry explicitly concerns supercharged applications, so its details should not be transferred automatically to every turbocharged vehicle carrying the generic code.

## Two thresholds answer different questions

The allowed difference changes with distance since the last estimate update. In this table, a difference above 15 kPa is evaluated when that distance is no more than 23 kilometres; beyond 23 kilometres, the threshold is 20 kPa. A single pressure mismatch therefore lacks context unless the estimate's update history is known.

The test also uses repeated observations: 20 failing samples out of 25, with a sample every 250 milliseconds. An isolated transient is not equivalent to that documented failure pattern.

## Compare the inputs behind the comparison

Several pressure, airflow, throttle and temperature fault states prevent this evaluation. Investigating a companion circuit fault first can explain why the correlation monitor has not run, rather than suggesting the correlation problem has repaired itself.

For a useful diagnostic record, retain the measured BARO value, available estimated-pressure information and related sensor faults under the conditions of failure. A disagreement does not by itself identify which input is wrong. Verify the applicable monitor completes after any repair instead of judging it from a cleared code list alone.

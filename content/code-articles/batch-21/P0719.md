# P0719: Brake-switch status fails to match repeated deceleration

GM's group 06 P0719 implementation checks the plausibility of the brake-light-switch signal. It watches for repeated deceleration while the brake indication remains inactive. That is a behavior-based check, not a universal connector-voltage measurement.

## Repeated events provide the context

The table describes four decreases from roughly 25 mph to 2 mph within a defined time window, with the engine running and the brake signal inactive. Those values describe the recorded monitor logic, not a request to perform repeated braking manoeuvres on public roads.

The key distinction is agreement between vehicle movement and the reported switch state. A switch that changes correctly during one stationary pedal press may still have intermittent behavior that was absent during the original events.

## Do not infer hydraulic brake condition

P0719 concerns electrical status used by the controller. It does not, by itself, evaluate hydraulic braking or establish that the vehicle is safe to drive. Any changed braking behavior needs its own appropriate assessment.

Preserve the brake-status information and associated speed history where available. Confirm the exact vehicle implementation before using a circuit-low label to choose an electrical test. Verification should demonstrate reliable switch-state recognition and completion of the applicable plausibility check under a prescribed service procedure. Clearing the code or observing brake lamps once does not prove every monitored brake-status path is correct.

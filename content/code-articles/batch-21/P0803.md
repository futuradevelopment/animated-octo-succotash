# P0803: Skip-shift solenoid command does not match circuit state

P0803 concerns the skip-shift solenoid control circuit in GM's group 07 manual-transmission example. The controller compares the output-driver command with observed circuit voltage. It is an electrical integrity check, not a general diagnosis of difficult manual gear selection.

## The intended state determines the expected voltage

The source states that circuit voltage should be low during operation and near battery positive when off. A measurement has meaning only when paired with the commanded state. Seeing a high voltage on an intentionally inactive channel does not by itself reproduce the fault.

The monitor requires engine speed above 600 rpm and a run/crank voltage between 11 and 18 volts. It accumulates 20 failures in 25 samples at 250-millisecond intervals. These are the documented conditions for repeated command-versus-feedback disagreement.

## Do not infer a mechanical transmission repair

The code does not identify an internal gear defect or prove which electrical component is responsible. The source's manual-transmission scope also matters; the same generic code cannot establish that every vehicle has this exact skip-shift arrangement.

Record the solenoid command and available feedback, then use the matching vehicle circuit procedure. Verification should show the expected electrical response under the relevant commands and successful completion of monitoring. A driver reporting that shifting feels normal, or a code that has simply been cleared, does not establish that the monitored output path is reliable.

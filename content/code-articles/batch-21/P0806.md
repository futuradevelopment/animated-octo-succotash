# P0806: Clutch position conflicts with evidence that the vehicle is in gear

The P0806 strategy in GM's GMDAT summary detects a clutch-position signal stuck in a range suggesting the vehicle is not in gear when other evidence says it is. It is therefore more than a simple high- or low-voltage test of the pedal sensor.

## Gear evidence provides the contradiction

The controller uses the engine-speed-to-vehicle-speed relationship to confirm an actual gear. The check also requires sufficient engine torque and vehicle speed, and excludes the relevant low-range transfer-case condition. Those prerequisites make the disagreement meaningful.

The published filtered position-error threshold is five percent for this implementation. Other GM documents use different calibrations, so that value must not become a universal pedal-adjustment specification.

## Invalid reference signals can prevent the test

Clutch-sensor circuit faults, crank information faults and transmission-output-speed errors inhibit this performance comparison. If a reference input is unreliable, the controller cannot make the same in-gear judgment. An incomplete monitor in that state is not a passing result.

Preserve pedal position, gear-related speed evidence and companion faults together. The summary does not prove whether the problem is sensor accuracy, learning, wiring or physical pedal operation. Use the exact service procedure to distinguish those possibilities. Verification should establish credible clutch information during qualified in-gear operation and completed monitoring, not merely a plausible voltage while the vehicle is stationary.

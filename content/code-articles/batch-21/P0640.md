# P0640: Intake-heater control response while heating is commanded off

P0640 is an intake-air heater switch/control-circuit check in GM's Duramax summary. The glow-plug control module evaluates a digital response associated with a heartbeat signal. The documented test occurs with the intake-air heater commanded off.

## An off-state test can reveal a control fault

The source describes a high response while the heartbeat signal is active as the failure condition. This does not mean that the controller directly measured inadequate intake heating. The distinction matters because a warm intake reading or a heater that sometimes operates cannot establish that the monitored off-state response is correct.

The failure must persist for 650 milliseconds, and the test is conducted every two seconds. These timings belong to the documented electronic check; they are not instructions to energize the heater manually or bridge its high-current control circuit.

## Preserve the command and response relationship

A useful diagnostic record identifies heater command status, the relevant controller faults and the response evidence available through the prescribed diagnostic equipment. The code alone does not establish which switch, wiring segment or controller element is defective.

Use the exact vehicle's heater and glow-plug-controller service procedure. High-current heater circuits require the specified testing method. Verification should demonstrate a correct control response and completed monitoring under the required off-command condition. Clearing P0640 or judging intake warmth alone leaves the actual electrical-response question unanswered.

# P00B6: Cold-start comparison of radiator and engine temperatures

P00B6 compares engine coolant temperature with radiator coolant temperature after an engine-off soak in this GM GMDAT monitor. It is a correlation check, not a direct measurement of coolant flow. The documented evaluation is limited to a valid cold start after more than eight hours off.

## A cold engine is not the only prerequisite

The controller uses intake temperature as part of its interpretation. One failure route applies an intake-temperature-dependent threshold; another looks for a coolant-sensor difference above 20°C when a block heater has not been detected. Extended cranking has its own associated criterion. These separate routes make the original starting conditions useful evidence.

Block-heater recognition can abort the diagnostic. Therefore, an incomplete monitor after using a heater is not automatically evidence of a wiring defect or a successful repair. The source also lists sensor-circuit faults and invalid engine-off timing among the conditions that prevent meaningful evaluation.

## Preserve the startup evidence

Record the radiator, engine-coolant and intake temperatures at power-up, the soak history and whether the monitor aborted. Comparing only warmed-up readings can miss the condition that triggered this check.

A reasonable next diagnostic distinction is whether one input is electrically faulty or both inputs remain plausible but disagree after the qualified soak. The code alone cannot identify the inaccurate sensor. Verify using the applicable cold-start monitor rather than treating an immediate restart without a code as confirmation.

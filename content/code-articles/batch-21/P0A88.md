# P0A88: Low power-module current-sensor signal is not low charging current

P0A88 is the low-circuit check for the auxiliary power-module current sensor in GM's BAS hybrid summary. Its published criterion is sensor voltage below 0.5 volts while the module is awake. The listed detection interval is one millisecond.

## The code concerns the sensor signal

A low electrical signal is not the same as proving that the module delivered too little charging current. The controller is checking whether the sensor output remains within its valid electrical range. Interpreting the reported amperage requires first establishing that the sensor signal is credible.

The same page gives P0A87 a separate current-limit performance comparison and P0A89 the opposite electrical direction. Those distinctions matter when deciding whether the problem is signal range or an in-range reading that disagrees with the operating mode.

## Preserve the originating module evidence

Record the sensor-related fault and any relevant power-module status before clearing memory. A normal low-load current display after the event cannot independently establish that the circuit stayed valid when P0A88 set.

The summary supplies no universal connector pins, sensor location or replacement decision. Use the exact hybrid service procedure and appropriate professional test equipment; do not improvise high-current loading or power-electronics probing. Verification should show a credible sensor signal and completed circuit monitoring. An erased code or a battery that charges on one occasion does not establish that the electrical low condition has been corrected.

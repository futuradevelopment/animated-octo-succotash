# P0337: Crank position found and then lost during a drive cycle

The generic P0337 description refers to a low crankshaft-position circuit. In GM's 2009 group 05 summary, the diagnostic description focuses on position being found and then lost twice in the same driving cycle. That is more specific evidence than simply seeing zero engine speed after the engine has stopped.

## Loss after recognition is the important sequence

A controller that never recognizes position and one that recognizes it before repeatedly losing it have different diagnostic histories. Preserve that sequence when reviewing a no-start, interruption or intermittent running complaint. The code alone does not establish which physical component interrupted recognition.

The source places this check beside a separate crank-sensor activity and cranking-output strategy. Combining those rows into one assumed voltage test would erase the distinction between initial signal recognition and subsequent loss.

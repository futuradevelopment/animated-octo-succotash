# U0669: low-pressure EGR differential-pressure sensor loses SENT data

The generic U0669 name is EGR sensor D lost communication. This GM row identifies the actual input as the low-pressure EGR differential-pressure sensor using SENT. That is different from the low-pressure EGR valve-position interface monitored elsewhere in the same file.

## Pressure-data age is the central distinction

The source lists two failure routes: a hardware message-error indication, or more than 6.25 milliseconds since the last valid SENT pressure value. Unlike the neighboring position-sensor rows, this row does not require a steady-high or steady-low status in its printed age branch.

The pressure sensor must be configured as present and the diagnostic enabled. The engine must be outside cranking, powertrain relay voltage above 11 volts and no diagnostic reset or end-of-trip inhibition active. Persistence is 480 failing counts out of 600 samples at a 6.25-millisecond task rate.

## Do not infer EGR flow from unavailable pressure

A frozen or default differential-pressure display during U0669 is weak evidence about actual recirculated-gas flow. Establish fresh valid pressure messages before using the sensor to judge restriction, flow or valve behavior. A responsive valve-position signal cannot verify this separate pressure interface.

Verification requires valid SENT pressure updates and a completed communication monitor under qualified operation. The code does not identify a blocked pressure passage, failed valve or particular wiring fault. Those possibilities need their own evidence and the exact vehicle's service procedure.

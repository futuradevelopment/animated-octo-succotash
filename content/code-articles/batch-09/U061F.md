# U061F: exhaust temperature sensor 1 loses valid SENT communication

U061F is lost communication with bank 1 exhaust gas temperature sensor 1. The cited strategy uses the SENT interface: a positive message-fault indication or excessive message age can produce the failure. The source lists message age above 100 seconds; that printed unit is retained rather than silently converted to milliseconds.

## Initialization must finish first

The sensor's calibrated initialization delay must have elapsed. Run/crank must be active and within range, the engine must be out of cranking and the diagnostic system enabled. The monitor counts 19 failing observations out of 25 with a 100-millisecond function task.

This makes an initially unavailable temperature after power-up different from an established communication failure after the allowed initialization period. It also means the sample-task period and the message-age threshold are separate quantities.

## Follow the sensor and interface module together

The strategy describes harness problems and internal sensor faults that disable the SENT signal or corrupt the protocol. It also states that a related module diagnostic can accompany the sensor code depending on which interface module serves sensor 1. That pairing can help narrow the affected communication path without proving the sensor element is defective.

Verification should show fresh, valid sensor-1 messages after initialization and a completed monitor. A displayed exhaust temperature alone is inadequate if it is substituted or stale. The code does not indicate actual exhaust overtemperature, and the table supplies no component location or hot-exhaust disassembly procedure.

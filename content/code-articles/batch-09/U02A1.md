# U02A1: NOx sensor C ten-second message-loss supervision

U02A1 reports loss of communication with NOx sensor C. In this GM ECM monitor, the watched messages are $0C0, $0C2, $28D, $295 and $593. Each listed failure comparison requires the message to be absent for more than 10,000 milliseconds.

## Do not borrow another sensor's timing

Other NOx sensor monitors can use shorter or mixed timeout windows. This sensor-C row uses the ten-second value for all five listed messages. A brief interruption seen in a trace and a confirmed U02A1 event therefore should not be treated as interchangeable without reviewing the actual duration and monitor state.

The diagnostic executes every 12.5 milliseconds after the general conditions have held for at least five seconds. Normal CAN transmission and full communication are required; the relevant bus-off condition must be inactive. If the messages use a sensor bus, its relay must be on.

## Identify the absent information

Determine whether the five-message group disappeared together or only one required message ceased. That distinction can guide investigation toward shared availability versus message-specific configuration or reception. It does not by itself identify a failed component.

Verification should observe the complete expected sensor-C stream for long enough to cover the timeout periods under valid power and network conditions. A plausible NOx concentration on a scan tool is insufficient if it is stale or substituted. The source does not locate sensor C universally within every exhaust layout or diagnose catalyst conversion efficiency from this communication code.

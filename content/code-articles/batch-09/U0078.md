# U0078: CAN 9 bus-off counted over a sliding sample window

The selected GM body-controller table maps U0078 to CAN 9, despite the generic communication-bus-F title. It counts bus-off observations rather than waiting for a single module's message to time out. The failure criterion in this calibration is at least ten counts in a sliding window of 50 samples.

## The sample window is calibration-specific

The diagnostic runs in a 10-millisecond loop. Its general enablement includes at least five seconds since power-up, reset or recovery from a voltage condition, plus three seconds with the required communication and power conditions satisfied. The CAN channel must request full communication and normal transmission must be enabled.

Another supplied GM file uses a different bus-off count for U0078. This article intentionally applies the ten-count rule only to the cited 25OBDG04B body-controller row; neither count is a universal definition of the code.

## Diagnose the channel event

A bus-off condition can explain multiple downstream timeout codes. Establish the CAN 9 operating state and timing before treating every missing sender as an independent failed module. Check whether the event occurred after the controller's recovery qualification, since a momentary power-state transition is not the same enabled observation window.

Verification requires stable channel operation after the specified startup/recovery conditions and a completed bus-off monitor. The code does not provide a wiring location, termination-resistance specification or authorization to replace the body controller. Exact network topology must come from the applicable vehicle information.

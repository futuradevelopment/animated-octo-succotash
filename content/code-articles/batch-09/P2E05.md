# P2E05: gear-lever sensor 2 internal-error detection

P2E05 concerns the second gear-lever position sensor path. In this GM table, it detects an internal error in SENT2 when the measured Alpha2/Beta2 value reaches at least 99.84%. The generic sensor-B range/performance title does not explain that internal-error mechanism by itself.

## Separate the second channel from the first

The row excludes lost-communication and invalid-data faults assigned to the sensor-2 interface, including U1194/U1196 and U13E1/U13E3. Their absence is a prerequisite for this performance check. Consequently, a missing sensor-2 stream is not equivalent to receiving an internal-error-associated value over an otherwise usable stream.

The diagnostic calibration must be enabled. The listed decision requires 160 failures out of 200 samples, but no sample period is given; converting that count to an elapsed-time requirement would be unsupported.

## Interpret the near-full-scale result carefully

The table identifies the extreme position value as part of detecting a sensor-internal error. It does not establish that the driver physically moved the lever to a 99.84% position. Capture both Alpha2/Beta2 and their validity states before treating the number as mechanical position.

A useful verification confirms a healthy second-channel stream, plausible reported movement and completion of the internal-error monitor. Comparison with sensor 1 can provide context, but this row does not publish a cross-channel correlation threshold. Component replacement or gear-selection safety cannot be concluded from P2E05 alone.

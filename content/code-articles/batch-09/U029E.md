# U029E: post-catalyst NOx sensor B communication timing

The cited GM table identifies NOx sensor B as the post-catalyst sensor. U029E monitors its CAN message arrival, not the amount of NOx passing through the catalyst. Four messages, $0A4, $0B2, $0B6 and $0B8, use timeout limits above 1,025 milliseconds.

## The slower messages also count

The remaining listed windows differ: $28B exceeds 1,137.5 milliseconds, $297 exceeds 1,700 milliseconds, $592 exceeds 7,450 milliseconds and $294 exceeds 10 seconds. A trace showing frequent concentration updates may therefore still miss another required part of the sensor's information stream.

The receiver evaluates in a 12.5-millisecond loop with full communication requested and normal CAN transmission enabled. Qualified general conditions must hold for at least five seconds. The relevant bus-off fault must be absent, and a sensor-bus arrangement requires the relay on.

## Avoid a premature catalyst conclusion

If the downstream NOx value becomes frozen or disappears, establish whether fresh sensor-B messages are being received before interpreting the value as catalyst performance. U029E does not establish that downstream NOx is high or that the catalyst is ineffective.

Verification should cover both the rapid and slow message periods after the sensor and network are qualified. An intermittent dropout may appear only in one message group. The table supports the post-catalyst designation for this monitor, but not an exact physical sensor location or replacement part across every model using the code.

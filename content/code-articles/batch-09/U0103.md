# U0103: gear-shift module response missing on LIN bus 2

Although U0103 is often described simply as lost communication with gear-shift control module A, this implementation uses LIN bus 2. The monitored response is ESMRsp, and the documented timeout is at least 500 milliseconds without that response.

## The LIN slave must be expected

The LIN channel must be enabled, the LIN module initialized and the slave calibrated as present. The diagnostic must also be enabled. These requirements distinguish a missing expected device from a configuration that does not include the module at all.

The table describes a 500-millisecond communication execution loop and requires the applicable power conditions to have been satisfied for at least five seconds. Power-mode transitions and run/crank supply qualifications therefore matter when interpreting a stored event.

## A missing response is not a gear-position verdict

U0103 establishes absence of the response at the receiver. It does not prove that the lever sensor is inaccurate, that the requested gear was mechanically engaged or that the entire transmission controller failed. Determine whether the expected LIN response is absent while the slave should be awake and supplied, then follow the exact network and supply procedure.

Verification should show repeated ESMRsp reception with the correct slave configuration and valid operating power mode. Merely accessing the engine controller with a scan tool says little about this separate LIN exchange. Any remaining gear-selection complaint requires its own position and actuation evidence after communication is restored.

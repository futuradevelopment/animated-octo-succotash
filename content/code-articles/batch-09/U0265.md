# U0265: front-camera protected burst messages are missing

U0265 is generic lost communication with image-processing sensor A. This GM table identifies the sender as the front camera and monitors ten protected FCODP burst messages. Each has a missing-message threshold above 0.25 seconds.

## Ten bursts make up the expected stream

Communication is not proven merely because one camera-related value updates. The receiver expects the required burst sequence, and a partial operational stream can still fail a monitored-message condition. A successful diagnostic-session connection is similarly different from healthy recurring traffic.

The monitor needs an active participating partial network, supply between 9 and 16 volts and diagnostic enablement. Transport mode, the first five seconds following reset or voltage recovery and bus-off conditions are excluded. The table states that adaptive cruise is disabled when this timeout fault is detected.

## Interpret a camera complaint accurately

This diagnosis does not evaluate lens cleanliness, lane-recognition accuracy or camera alignment. First establish whether the operational burst messages arrive. If they do not, compare the camera's message pattern with wider network and reset events before assigning the fault to an optical component.

Verification requires the complete expected front-camera burst stream under the monitor's enabled conditions. Image recognition and calibration checks remain distinct if the service procedure calls for them. The generic sensor-A designation does not prove applicability to every front camera, and the source provides no universal mounting, pinout or replacement instruction.

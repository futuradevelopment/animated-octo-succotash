# U023D: left-front short-range radar burst timeout

The U023D monitor in this EOCM3 table watches the left-front short-range radar. Six protected SRRLFODP burst messages are listed, each with a timeout above 0.20 seconds. The code identifies a missing operational data stream at the receiver, not an object-detection accuracy result.

## Left-front identity is part of the diagnosis

The sender designation matters when a vehicle has several radar units. A healthy right-front radar response does not demonstrate that the left-front protected burst stream is present. Likewise, a one-time diagnostic response from the left unit does not establish that all six recurring bursts arrive on time.

The monitor operates with supply between 9 and 16 volts and an active participating partial network. It excludes transport mode, the first five seconds following reset or voltage recovery and active bus-off conditions. Detection results in adaptive-cruise disablement according to the table.

## Preserve the message pattern

Determine whether the full left-front sequence is missing or particular bursts are intermittently late. Compare that pattern with other network events before concluding that the radar itself is defective. Absence of the stream and a valid stream containing no detected objects are fundamentally different observations.

Verification requires timely restoration of the expected left-front burst sequence after the receiver is qualified. Any radar alignment or assistance-system validation remains a separate professional task. The source does not identify a physical mounting location beyond its left-front designation or justify replacing the sensor solely from U023D.

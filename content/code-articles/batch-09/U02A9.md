# U02A9: charge-air cooler pump LIN response missing

U02A9 is a communication diagnosis for the charge-air cooler electric coolant pump. This implementation expects the LIN response CWP_Rsp and fails when it is absent for at least 2,500 milliseconds. The listed communication execution loop is 500 milliseconds.

## The pump must be present and expected to answer

The diagnostic and LIN channel must be enabled, the interface initialized and the slave configured as present. Relay-power conditions also qualify the test. The general operating power requirements must hold for at least five seconds before the documented evaluation applies.

The table prints the powertrain-relay feedback enable as disabled, which is a configuration detail rather than a statement that the entire U02A9 diagnostic is disabled. The diagnostic's own enable is expressly listed as enabled. Those two fields should not be confused.

## Lost feedback is not measured underspeed

Without fresh pump responses, a speed display can be stale or unavailable. U02A9 does not itself establish that the pump is turning too slowly, that coolant is aerated or that the pump is mechanically seized. Establish the response path and expected supply state before evaluating speed-performance evidence.

Verification needs repeated CWP_Rsp messages within the timeout while the configured pump is awake and the LIN channel qualified. Restoring a single response does not prove sustained operation, and restoring communication does not alone confirm coolant circulation. Any remaining thermal complaint needs separate pump and cooling-system evidence.

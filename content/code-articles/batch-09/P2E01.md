# P2E01: gear-lever sensor 1 reports an internal error through SENT

P2E01 is labeled gear-lever position sensor A range/performance in generic descriptions. The cited GM strategy calls it sensor 1 performance and identifies an internal error in SENT1. Its measured Alpha1/Beta1 position criterion is at least 99.84%.

## The extreme value is diagnostic information

Because the strategy explicitly describes internal-error detection, this near-full-scale value should not automatically be interpreted as a real lever angle or an ordinary end-of-travel position. The exact signal definition matters. The table does not provide a mechanical lever position corresponding to 99.84%.

The monitor requires the diagnostic calibration enabled and no listed lost-communication or invalid-data faults in the sensor-1 channels. Those exclusions distinguish an internal fault reported over a usable interface from an interface that cannot deliver trustworthy data at all. Confirmation uses 160 failed observations out of 200 samples; the row does not specify a sample interval.

## Focus on the first sensor path

Preserve Alpha1 and Beta1 values together with SENT1 communication and validity status. A valid stream carrying the error-associated value warrants a different investigation from a missing stream or corrupt data. Do not transfer sensor-2 fault identifiers to this sensor-1 diagnosis.

Verification should demonstrate valid first-channel position data without the internal-error indication and a completed monitor. The code does not establish which part of a shifter assembly requires replacement, nor does it certify that the selected gear is safe solely because an error value disappears.

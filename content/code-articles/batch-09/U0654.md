# U0654: diesel intake throttle position SENT data becomes unusable

The generic U0654 title refers to diesel intake air flow A position sensor. The cited strategy calls the monitored input throttle SENT position. It is therefore a position-feedback communication check, not a direct airflow measurement or a comparison with mass-airflow sensor output.

## Four kinds of interface evidence

The source evaluates stale valid-position information above 6.25 milliseconds with steady-low status, the same age with steady-high status, a message-error flag, and updated counters with valid data still too old. An electrically active line can thus fail to deliver acceptable position information.

The diagnostic accumulates 480 failing counts out of 600 samples at a 6.25-millisecond task rate. It requires test enablement, engine operation outside cranking, relay voltage above 11 volts and no diagnostic reset or end-of-trip inhibition.

## Interpret airflow complaints cautiously

If the throttle position appears fixed during U0654, first establish whether that value is fresh. A stale feedback value cannot distinguish a moving throttle from a stuck one. Similarly, a measured airflow change does not by itself validate the SENT communication path.

Verification should show consistently fresh decoded throttle positions under the applicable operation while the communication monitor completes. Any remaining airflow or tracking discrepancy should then be evaluated using valid data. The table does not establish a motor fault, throttle contamination or a replacement requirement from this code alone.

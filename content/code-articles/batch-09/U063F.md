# U063F: coolant flow valve SENT position stream fails protocol checks

U063F is the communication diagnosis for the coolant flow control valve position sensor. The GM monitor recognizes several routes: message age above 6.25 milliseconds with a steady-low input, the same age with a steady-high input, a positive SENT message-fault indication, or an updated pulse counter without a sufficiently fresh valid message.

## Pulses are not necessarily valid position data

The last condition is particularly useful. Electrical activity at the input does not prove the controller has decoded a valid position message. A signal can contain pulses while its usable position data remains stale. Likewise, a steady input must be interpreted with message age rather than as a physical valve position.

Confirmation uses 80 failures out of 100 samples at a 6.25-millisecond rate. Relay voltage must exceed 11 volts, cranking must be absent and the diagnostic enabled.

## Separate communication from tracking

When U063F is active, compare desired position with actual feedback cautiously because the actual value may no longer update correctly. Establish valid protocol reception before concluding that an apparent position error proves a stuck valve. The source identifies communication failure, not the specific harness, sensor or controller element responsible.

Verification should demonstrate fresh valid SENT positions through relevant valve operation and a completed communication monitor. Passing a raw-value range check alone is insufficient if the data is stale, and observed mechanical motion alone does not validate the position stream.

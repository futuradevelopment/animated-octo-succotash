# U02A3: particulate sensor messages are absent rather than implausible

The U02A3 monitor checks communication with the particulate matter sensor. It watches messages $3AD, $3AE and $3AF, each with a timeout above 10,000 milliseconds. The code concerns absence of those messages at the ECM, not a measured soot level or a direct judgment of particulate-filter efficiency.

## Sensor availability comes first

The controller requests full CAN communication and requires normal transmission enabled. General operating conditions must hold for at least five seconds, and the relevant bus-off fault must not be active. Where the sensor bus is used, its relay must be on. The diagnostic itself executes in a 12.5-millisecond loop.

These conditions distinguish a sensor expected to report from one intentionally unpowered or unavailable during a network transition. If several sensor-bus devices disappear together, the shared event deserves attention before each device is treated as independently defective.

## Three messages, not one display value

Check whether all three messages are missing or whether one part of the operational stream has stopped. A live diagnostic connection or a single displayed soot parameter does not prove that all required periodic broadcasts arrive. Conversely, a low particulate reading does not invalidate a communication timeout if the reading is stale.

Verification should demonstrate regular receipt of $3AD, $3AE and $3AF beyond their timeout windows with the monitor enabled. Internal sensor performance, regeneration behavior and filter efficiency require separate evidence once communications are restored.

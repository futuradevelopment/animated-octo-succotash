# U0601: digital filter-pressure sensor SENT communication fails

U0601 is generic lost communication with particulate-filter pressure sensor A. The cited GM strategy is specific to a digital differential-pressure sensor using SENT. It evaluates digital fault information and message age rather than a CAN timeout from a separate control module.

## Two routes to the communication result

The table lists a digital sensor message-fault value above zero as one route. Another is sensor message age above the published 12.50-second threshold. It also describes internal sensor faults that switch the SENT signal off or cause protocol communication faults. These are possible mechanisms, not proof that the sensor electronics are the cause of every event.

Confirmation uses 158 failed samples out of 200 at a 12.5-millisecond task interval. The monitor requires active run/crank supply, ignition within range and no diagnostic reset; the engine must not currently be cranking.

## Missing data is not filter restriction

A pressure display during this fault may be unavailable or substituted. Establish valid SENT communication before using the reported pressure to assess filter restriction or exhaust flow. Distinguish a protocol error with ongoing pulses from a stale message age because the next interface check can differ.

Verification requires fresh, valid digital pressure messages and a completed loss-of-communication monitor. The table supplies no universal pressure limit, sensor pinout or instruction to replace the filter. Its stated age and sample timing are controller criteria and should not be transplanted to another sensor architecture.

## Source and applicability

Documented 2025 GM gm-2025-04b monitor only; vehicle, engine and controller applicability must be established separately. [GM monitor table, PDF page 981](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG04B.pdf#page=981).

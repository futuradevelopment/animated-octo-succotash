# U0659: left-front temperature actuator response missing on LIN

U0659 refers to the left-front temperature actuator in the climate system. The BCM expects AHDA03_Rsp_PDU on LIN and records a missing response at or beyond 11,500 milliseconds. The listed LIN execution loop is 600 milliseconds.

## The left-front slave is explicitly configured present

The source lists the diagnostic enabled, LIN channel enabled and slave-presence calibration true. It also requires the LIN module initialized. That matters because a device absent by design should not be diagnosed using the same assumptions as an expected actuator that stops answering.

Startup, reset or voltage recovery requires at least five seconds, followed by the applicable three-second power-condition qualification. The continuation addresses off-key behavior and impending shutdown; a timeout observation must be interpreted within the correct power state.

## Communication does not directly measure cabin temperature

A warm or cold left-side vent complaint may prompt investigation, but U0659 itself establishes lack of the actuator's response. It does not prove a blend door is mechanically jammed, identify refrigerant performance or show the actuator's actual position.

Verification should demonstrate repeated AHDA03 responses within the timeout while the configured slave is awake and the LIN channel qualified. Commanded temperature changes can provide functional context, but the response stream must itself be checked. The table supplies no universal actuator-access location, calibration sequence or replacement instruction.

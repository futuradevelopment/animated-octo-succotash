# U0404: wrong-length range-selector messages in a documented calibration

U0404 is often described as invalid data from gear-shift control module A. In the selected 25OBDG07A Part 2 implementation, the concrete failure is a wrong data-length code in a received transmission range-selector frame. The watched frames are SIB_General_Info_2_S1 and SIB_General_Info_S1.

## Frame length is the deciding property

The table lists a one-second requirement with ignition on and the basic enable conditions satisfied. It does not describe a physical lever-angle comparison or a hydraulic transmission failure. A frame can arrive on time yet have an unexpected length, so ordinary communication availability does not exclude this mechanism.

On the same page, U18D2 separately supervises elapsed time since those frames last arrived. That verified distinction helps interpretation: U0404 in this calibration rejects frame structure, while the adjacent timeout diagnosis concerns absence.

## Match software and message expectations

Review which frame has the unexpected length and confirm that sender/receiver configuration matches the applicable vehicle information. A mismatch in expected message structure is useful evidence, but this table does not establish its cause or authorize a particular software update.

Verification needs both frames arriving with the expected length during enabled monitoring. Correct-looking gear text on a display is not a substitute for checking the frame property. Other GM implementations use counter and checksum mechanisms for the same generic code; this article's length-specific explanation is intentionally limited to the cited file, whose model mapping remains unresolved.

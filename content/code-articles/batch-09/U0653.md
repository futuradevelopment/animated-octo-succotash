# U0653: low-pressure EGR position sensor C communication failure

U0653 is assigned to low-pressure EGR position feedback in the cited table, despite the generic EGR-sensor-C title. The strategy checks the SENT protocol, including message errors and the age of the last valid position.

## Electrical state and message age work together

A valid-message age above 6.25 milliseconds can fail when the protocol is steady high or steady low. The continuation adds a condition in which position counters update but the valid message remains too old. That is a useful distinction between mere interface activity and accepted sensor data.

The low-pressure EGR SENT sensor must be configured as present. The monitor requires calibration enablement, no engine cranking and relay voltage above 11 volts. Its persistence rule is 480 failed counts out of 600 at a 6.25-millisecond task rate.

## Keep the low-pressure circuit distinct

On an engine with multiple EGR paths, healthy high-pressure EGR feedback does not validate the low-pressure sensor stream. Identify the mapped low-pressure interface and compare its protocol status with the actual position trace. Stale feedback can mimic a valve that does not respond.

Confirmation should demonstrate fresh valid low-pressure EGR positions and completion of this communication check. Flow-performance or valve-tracking complaints need separate evaluation after trustworthy feedback returns. The source does not supply a universal component location or justify replacing an EGR valve solely because the communication code is stored.

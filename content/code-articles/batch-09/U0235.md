# U0235: long-range radar protected bursts are missing

U0235 is a lost-communication diagnosis for the long-range radar in this EOCM3 table. The receiver monitors six protected LRRODP burst messages, each with a timeout above 0.25 seconds. The generic front-distance-sensor title should not be used to select a physical sensor location without the vehicle's network information.

## Missing bursts are not obstructed radar measurements

This row checks whether data arrives. It does not evaluate target accuracy, radar alignment or whether the sensor's view is blocked. Those conditions may require separate diagnostics even when communications remain healthy.

The monitor requires an active participating partial network and supply between 9 and 16 volts. It excludes transport mode, the first five seconds after reset or voltage recovery and an active bus-off condition. The source states that adaptive cruise is disabled when the fault is detected. Its enable-variable name appears inconsistent with the DTC, so that identifier is not treated as independent applicability evidence.

## Useful next evidence

Determine whether all six bursts disappeared or only part of the burst sequence failed to arrive on schedule. A successful diagnostic-session connection does not guarantee that the operational burst messages are present. Also compare timing with bus-off and reset records before attributing the event to radar hardware.

Verification requires the complete expected burst stream within its timing limit after qualification. Restored communication alone does not prove correct radar alignment or certify assistance-system function; those checks follow the applicable professional procedure.

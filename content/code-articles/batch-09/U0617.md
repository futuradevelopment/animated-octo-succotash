# U0617: coolant bypass valve C SENT data becomes stale

U0617 concerns lost SENT communication with the engine coolant bypass valve C sensor. The table evaluates combinations of message age, pulse-count behavior and voltage at the SENT input. It is a sensor-interface diagnosis, not a direct measurement of coolant flow through the valve.

## Stale data and input level are evaluated together

The source lists message age above 6.25 milliseconds together with pulse-count delta above zero as one condition. Other conditions combine that same stale-age threshold with a SENT-pin voltage above or below controller-specific limits. Those voltage limits are not published as universal connector values.

The diagnostic requires run/crank ignition within range, engine not cranking and an enabled engine diagnostic system. Its listed persistence is four seconds out of a five-second window. A momentary stale sample alone does not describe that full decision.

## A source inconsistency remains

The first condition says a failure is recorded while hardware message faults equal “No Fault,” which conflicts with the surrounding diagnosis. This article does not silently reverse that expression or turn it into a repair rule; the unresolved condition is retained for source review.

Useful evidence includes fresh-message age, pulse activity and the input's qualified electrical state. Verification should demonstrate valid SENT updates throughout the applicable monitor window using the vehicle-specific procedure. A valve that moves mechanically does not prove its position-data interface is healthy, and this code alone does not identify a failed valve assembly.

## Source and applicability

Documented 2025 GM gm-2025-04b monitor only; vehicle, engine and controller applicability must be established separately. [GM monitor table, PDF page 984](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG04B.pdf#page=984).

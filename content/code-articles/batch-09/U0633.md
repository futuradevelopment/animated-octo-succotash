# U0633: cooling fan 2 fails to return its LIN response

U0633 is the cooling fan 2 LIN communication-failure monitor. The cited ECM table expects CFM2_RSP on LIN bus 1 and uses a timeout of at least 2,500 milliseconds. Its LIN communication execution loop is 500 milliseconds.

## A fan command is not a fan response

The diagnostic requires an enabled and initialized LIN channel, the fan slave configured as present and the diagnostic enabled. It also qualifies engine-running operation or fan-operation enablement received over CAN with the propulsion system active. That distinction matters on systems where cooling-fan operation is coordinated across controllers.

General power conditions must hold for at least five seconds. The continuation also addresses accessory/off-key and impending-shutdown conditions, so silence during deliberate shutdown should not automatically be treated as the same operating fault.

## Communication before speed performance

Determine whether the expected response disappears while the fan is expected to participate. A fan that visibly rotates may still fail to return data; conversely, no valid speed data does not prove the motor is physically stopped. Missing response and underspeed are different monitor mechanisms.

Verification requires repeated CFM2_RSP reception within the timeout under qualified operation, followed by separate fan-performance checks if needed. A successful scan-tool connection to the ECM does not validate this subordinate LIN exchange. The source does not identify a failed fan motor, wiring location or replacement controller solely from U0633.

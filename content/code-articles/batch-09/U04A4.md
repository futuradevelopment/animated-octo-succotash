# U04A4: particulate sensor data fails counter and protection checks

U04A4 is invalid data received from particulate matter sensor A. This monitor requires the relevant frame to be present, then checks rolling counters, protection values and checksums. Its monitored content includes sensor status, electrode current and supply voltage, heater duty cycle, electrode temperature and sensor-control-unit information.

## One sensor exposes several protected measurements

The listed fields use three failures out of ten samples. The continuations add heater resistance, regeneration-related temperature, diagnostic status and other sensor information. A valid current reading alone therefore does not prove that every monitored sensor message passes.

The ECM evaluates every 12.5 milliseconds after five seconds of qualified conditions, including battery voltage at least 11 volts and no pending accessory-to-off transition. This is different from a timeout in which the sensor's messages never arrive.

## Do not confuse an error flag with a corrupted error message

The monitor can validate protection around internal or external error information as well as around measurements. A protection failure in an error-status message is not automatically proof that the underlying sensor error itself is asserted. The integrity issue must be resolved before relying on that content.

Verification should cover the affected status and measurement fields at the receiving ECM with acceptable counter progression and protection. The code does not directly establish filter efficiency, soot concentration or an internal processor failure. Those conclusions require their own valid sensor evidence after the communication-integrity problem is addressed.

# U0585: grille shutter A initialization-status counter is invalid

U0585 is invalid data received from active grille air shutter module A. The cited ECM row identifies the monitored field as ACM initialization-status ARC. The fault rule is three rejected observations out of ten samples.

## Initialization status and physical position differ

The controller is validating the message's alive rolling count, not directly checking whether the shutter blades reached an angle. A status value that appears plausible can still come from a stream with improper counter progression. The source requires the frame containing the protection information to be present, so this is not simply a no-response timeout.

The monitor executes every 12.5 milliseconds after five seconds of qualified conditions. Battery voltage must be at least 11 volts and no accessory-to-off transition may be pending.

## Use the module-A stream

Confirm that the reported code and counter belong to shutter module A before comparing with another shutter assembly. A healthy second shutter's status does not verify this channel. Preserve the initialization-status data and its counter together to distinguish an actual status report from an invalidly repeated message.

Verification should demonstrate valid counter progression at the ECM while the shutter module is expected to communicate. Mechanical movement may need a separate check if a shutter complaint remains. The table does not establish a jammed blade, failed motor, initialization procedure or replacement requirement from U0585 alone.

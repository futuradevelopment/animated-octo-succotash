# U0650: exhaust pressure valve position feedback loses valid SENT updates

U0650 monitors the exhaust throttle valve's SENT position interface. The documented failure can be stale valid-position information above 6.25 milliseconds with steady-low or steady-high protocol status, a message error, or updated position counters while the last valid position remains too old.

## A position display can outlast its valid message

These branches distinguish a stuck electrical level from traffic that does not decode into usable position. Both can leave the controller without trustworthy valve feedback. A scan-tool position that remains constant therefore cannot, by itself, prove the exhaust valve physically stopped moving.

The table requires 480 failing samples out of 600 at a 6.25-millisecond task rate. The engine must be out of cranking, powertrain relay voltage above 11 volts and the diagnostic enabled without reset or end-of-trip inhibition.

## Establish feedback before judging exhaust restriction

Compare protocol status and message age with requested valve operation. If pressure or position performance codes accompany U0650, determine how the loss of valid feedback affects their interpretation before selecting a mechanical repair. The communication code does not directly establish an exhaust restriction or broken linkage.

Verification should show fresh, accepted valve-position updates throughout applicable operation and a completed monitor. A temporarily restored pulse train is not sufficient if message validity still fails. The source supplies no universal SENT pin voltage or procedure for probing a hot exhaust actuator.

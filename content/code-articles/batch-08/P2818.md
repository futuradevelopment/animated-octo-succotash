# P2818: GR10 torque-converter clutch remains coupled when commanded off

P2818 is the hydraulically stuck-on code for torque-converter control in this GR10 section. The controller evaluates two situations: low-speed shifts into a driving range and a separate non-garage-shift condition associated with possible engine stall. TCC command must be off for the listed assessments.

## Low slip needs supporting evidence

The garage-shift branch checks absolute converter slip below 35 rpm together with engine-speed shortfall or decline and torque conditions. The other branch uses slip below 30 rpm, torque above 70 Nm and either substantial speed shortfall or rapid engine deceleration. Low slip alone is therefore not the complete test.

Fault timing is mapped to engine-speed behavior. The supporting garage-shift table ranges from 0.250 to 0.100 seconds across its listed speed-change values; additional counters and qualification apply. Reporting is Type A, one trip.

## What to preserve

Retain commanded TCC state, engine and turbine speeds, torque and shift phase. Near-zero slip while lock is intentionally commanded is different from unwanted coupling with the command off. Electrical or speed-sensor faults can also prevent a valid result.

The continuation includes a branch with a placeholder-like reverse-speed value, so it is not a safe standalone drive procedure. Professional verification should follow the applicable service instructions without deliberately provoking a stall or unintended deceleration. The code does not establish a particular replacement part.

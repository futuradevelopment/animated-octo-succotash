# P241F: low-pressure EGR cooler efficiency below its threshold

P241F is a cooling-performance monitor for the low-pressure EGR cooler. The generic name calls it cooler B; the GM heading uses EGR 2 cooling system performance. Its efficiency calculation compares the exhaust-temperature drop across the cooler with the difference between inlet exhaust and inlet coolant temperatures.

## A normalized cooling result

Samples receive a correction dependent on EGR flow before averaging. The documented failure threshold is efficiency below 40%, after 200 samples have been collected on a 100 ms task. Reporting is Type B, two trips. This is not a simple maximum outlet-temperature test.

The inlet exhaust-to-coolant temperature difference must be between 120°C and 300°C. Valid EGR flow, sufficient estimated coolant flow, operating-speed limits and valid temperature sensors are additional prerequisites. Those conditions ensure the calculation has a meaningful thermal reference.

## What to compare next

Review inlet exhaust, outlet exhaust and inlet coolant information together. An outlet temperature alone cannot reproduce the ratio. Likewise, an invalid flow estimate can prevent a credible efficiency assessment even if the temperature signals appear reasonable.

Verification needs a completed average under qualified flow and temperature conditions. The code supports a cooling-efficiency concern, but the summary does not identify a particular blockage, coolant leak or failed valve. Component diagnosis should follow the exact vehicle procedure, including appropriate precautions around hot cooling and exhaust systems.

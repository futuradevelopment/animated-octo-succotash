# P23C6: coolant bypass valve C motor driver overcurrent

P23C6 is generically described as excessive driver current or temperature. The cited GM row specifically documents motor-current monitoring for coolant bypass valve C. It checks current while the H-bridge is energized and uses the driver's overcurrent status.

## What the numerical entry means—and does not mean

The threshold cell prints “8.1 A < X < 12.8 A” beside the controller-specific overcurrent description. It does not clearly define a universal fixed trip current or a safe normal operating range. The supported interpretation is an energized-driver overcurrent diagnosis; the exact applicable limit needs calibration confirmation.

The monitor requires valid run/crank, no engine cranking, an enabled diagnostic system and a determinate driver status. The condition is evaluated for two seconds within a five-second window. Reporting is Type B, two trips.

## Diagnostic direction

A motor-command observation without current or driver-status evidence does not establish this fault. Conversely, the code alone cannot distinguish a mechanical load problem from an electrical or driver problem. Preserve the command, current-related data and driver status where available, then follow the specific service test. Verification must include the energized operating state that invokes the monitor. A key-on check with an inactive H-bridge leaves the documented overcurrent test unanswered.

# P2733: GR10 clutch C6 fails to release during a shift

P2733 is the stuck-on diagnosis for pressure-control solenoid F in this GR10 section. It concerns C6 hydraulic release. The monitor assumes functional electrical control and asks whether the off-going clutch still holds torque after pressure should have been removed.

## The release signature

C6 slip remains below the expected release threshold: below 50 rpm for the listed power-down and other shift branches, or below 100 rpm for garage shifts. Shift-dependent base timers, additional offsets and hydraulic exhaust allowances govern reporting. The source assigns Type A, one trip.

The supporting closed-throttle lift-foot-upshift table gives different exhaust delays with fluid temperature, including 1.6 seconds at −40°C and 0.85 seconds at 30°C. Applying one timing value to every shift would ignore that dependency.

## Using the result

Compare the release request with C6 slip after its permitted exhaust interval. Near-zero slip is only suspicious in this context because the clutch is supposed to stop holding. Valid shaft-speed signals and absence of competing electrical or performance faults are prerequisites.

This is the opposite hydraulic behavior from P2732's excessive slip after application. A correct resistance reading does not prove that C6 releases hydraulically. Verification should use the qualified release monitor through the applicable professional procedure; the source does not establish a particular valve-body or clutch repair from the code alone.

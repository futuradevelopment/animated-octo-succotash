# P23C1: NOx sensor 3 sensing cavities fail an afterrun self-test

P23C1 concerns sensing-element integrity in the NOx sensor after the second catalyst. The source describes detecting restricted measurement cavities that could reduce sensitivity. It changes internal current setpoints, raises oxygen in the second cavity to a target and compares the resulting response with a stored new-sensor reference.

## A filtered internal comparison

The response-to-reference ratio fails above 125% or below 75%, after exponentially weighted processing. The row lists Type A, one-trip reporting and a 500 ms task. It permits additional tests in specified filter-response modes, so the number of available tests is not fixed across every state.

Driving prerequisites must first be achieved, after which the ECM requests the test at key-off. Valid sensor communication, electrical health, heater state, exhaust conditions and supporting aftertreatment signals all matter.

## Confirmation needs the afterrun event

An apparently accurate running NOx reading is not a completed cavity-integrity test. Check whether the afterrun request and result occurred before deciding that work has been verified. The continuation contains questionable temperature units and idle-speed values; this article does not turn those cells into driving instructions. Use the exact calibration's service procedure to qualify the test. The code identifies an abnormal self-test response, but the table alone cannot prove where a restriction is located or authorize a specific replacement.

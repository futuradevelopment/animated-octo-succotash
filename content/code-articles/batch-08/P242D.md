# P242D: exhaust temperature sensor 3 above its electrical range

P242D checks the upper input range of exhaust gas temperature sensor 3. The GM monitor supports an analog sensor and a digital thermocouple system. The analog criterion is resistance above 100 million ohms; the digital criterion is a raw temperature above 1,289.85°C.

## An input fault is not automatically an overheating event

The source frames these limits as electrical-failure detection. For digital hardware it specifically discusses the wiring between the module and probes. A displayed extreme temperature should therefore be assessed for signal validity before being treated as a trustworthy physical exhaust temperature.

The monitor requires valid supply and run/crank, no cranking, no diagnostic reset, no communication loss and completion of sensor initialization. Its counter is 19 failures out of 25 samples at a 100 ms task rate. Reporting is Type A, one trip, unlike the Type B low-range entry.

## Confirmation

Establish the installed sensing architecture before comparing any measurement with the relevant limit. A resistance value and a digital temperature are not interchangeable test results. After diagnosis, confirm that the upper-range test completes with valid input and communication. The summary provides no probe pinout or universal replacement conclusion, and it does not justify physically approaching a potentially hot exhaust to investigate the code.

## Source and application limits

This explanation covers the cited 2025 GM monitor. Confirm the vehicle and calibration in its service information before applying these limits; inclusion in this file does not establish model compatibility.

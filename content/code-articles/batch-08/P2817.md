# P2817: GR10 torque-converter clutch fails to achieve commanded coupling

P2817 is pressure-control solenoid H performance/stuck off. In this 25OBDG04B GR10 entry, H controls the torque-converter clutch. The monitor detects a hydraulic failure to achieve commanded coupling, rather than an electrical open circuit.

## Lock and controlled slip are different comparisons

In lock mode, converter slip is engine speed minus transmission input speed; the documented failure boundary is above 130 rpm. In controlled-slip mode, the controller instead compares actual slip with commanded slip and uses a calibrated error threshold. Applying the lock-mode number to all controlled-slip operation would misread the strategy.

A qualified failure must last more than four seconds before incrementing the counter, which must exceed three. The update rate is 25 ms and reporting Type A, one trip. Commanded pressure above 500 kPa for more than two seconds, available hydraulic pressure, suitable operating conditions and valid speed signals are among the gates.

## Useful interpretation

Record TCC mode, target slip, actual slip and pressure command together. Slip can be intentional in controlled-slip mode, so its mere presence does not prove a stuck-off valve. Electrical and speed-sensor faults can invalidate this hydraulic assessment.

Verification requires the appropriate qualified coupling test through the service procedure. The summary does not prove whether the ultimate problem is the control valve, converter or another hydraulic component, and its GR10 mapping must not be generalized to another controller.

# P23B5: NOx sensor 3 heater resistance misses its target

P23B5 evaluates heater-sense performance for NOx sensor 3. It compares measured heater resistance with target resistance using a normalized difference. This is an operating-performance check, separate from the explicit open and short diagnoses for HTemp.

## Delays are part of the test

The cited calibration requires more than 200 seconds after the sensor supply reaches its stated range above 10.8 V and more than 200 seconds after dewpoint. It also lists more than five seconds after overrun, valid communication and the appropriate combustion mode. The fault counter is 125 failures out of 250 samples at 25 ms intervals. Unlike the sensor-2 performance entry, this row is Type A, one trip.

The printed ±0.06 inequality presentation conflicts with the out-of-range narrative. It is therefore unsuitable as an unqualified workshop pass/fail formula.

## What establishes a useful result

A brief warm-up or cold resistance reading cannot reproduce the qualified operating comparison. Review actual and target heater information where the vehicle exposes it, and establish that the lengthy prerequisites were satisfied. An unrun monitor is not a passing monitor. Obtain calibration-specific clarification for numerical limits before condemning hardware; this summary supports the comparison mechanism and timing but leaves the exact inequality unresolved.

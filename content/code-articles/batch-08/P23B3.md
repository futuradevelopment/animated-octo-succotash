# P23B3: NOx sensor 3 heater control is shorted high

P23B3 belongs to the heater-control circuit of the NOx sensor after the second catalyst. The source explicitly describes a power short at the control pin. This is a different failure mode from an open load, a ground short or an out-of-target heater resistance.

## Fault recognition

The controller requires sensor supply above 9.90 V, relay voltage above 11 V and the bus relay commanded on. Dewpoint must be reached and CAN communication and data validity must be intact. Reporting uses 80 failed samples out of 160 on a 25 ms task, with Type B, two trips.

Because the criterion is a reported electrical condition, an unusually hot sensor is not sufficient evidence for this code. Conversely, an apparently normal concentration display does not disprove a control-pin fault.

## A focused verification

Identify the control path and compare the recorded fault with the vehicle's circuit test. Do not confuse it with the HTemp sense circuit, which has its own high-voltage code P23B9. Confirm the result only after the sensor reaches the prerequisites and the heater-control check completes. A scan taken before dewpoint can leave the check untested. The source supports this distinction and timing, but does not provide an external probe specification or a universal failed-part conclusion.

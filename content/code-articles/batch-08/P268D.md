# P268D: cylinder 2 injector adjustment record is missing

The documented P268D condition concerns cylinder 2's end-of-line injector adjustment data. Its monitored record is identified as DID $61. Although the generic label says data incompatible, this row explicitly describes data that has not been programmed.

## Distinguish data state from injector operation

The controller's pass criterion is successful programming of that EIA code. It does not compare fuel pressure, combustion balance or an injector electrical waveform in this monitor. Ignition on and calibration permission are prerequisites, with production/development state qualifications in the source. Reporting is Type A, one trip; no numerical delay is supplied.

## Useful decisions after the code appears

Confirm the cylinder-2 record rather than assuming that all cylinder records were written because one programming operation was attempted. The neighboring codes address separate cylinder records, so a successful entry for cylinder 1 does not satisfy the cylinder-2 check. This is a diagnostic inference from the per-cylinder record structure, not a prescribed reprogramming sequence.

Use the correct injector adjustment information and manufacturer-approved procedure; do not copy another cylinder's value to remove the warning. Verification should establish that the controller reports cylinder 2's EIA data successfully programmed and completes the corresponding monitor. The source does not justify injector replacement, identify a physical cylinder location or supply a generic coding command.

This explanation covers the cited 2025 GM monitor.

# P22B7: NOx sensor 2 oxygen signal above its reporting ceiling

P22B7 carries the generic label oxygen-sensor pumping-current trim circuit high. The GM monitor explains it as an oxygen signal exceeding its physical maximum, with a threshold above 29.00%. Its context is bank 1 sensor 2 and the NOx-sensor oxygen signal family, rather than a specified external-wire voltage.

## The actual check

The source lists 100 failures out of 200 samples on a 25 ms task and Type B, two-trip reporting. It names engine running, suitable system voltage, a fully operative sensor, exhaust pressure and no active exhaust brake among the secondary conditions. Several numerical enable cells are blank in this row, so neighboring-code values should not be silently substituted.

## What the result can establish

An above-ceiling oxygen signal is evidence that the reported measurement is outside this monitor's accepted range. It does not by itself identify a failed catalyst, establish a real exhaust oxygen concentration, or tell a technician which terminal has high voltage.

For a meaningful review, retain the oxygen-percent parameter and the sensor's validity state at the event. Then confirm that the relevant monitor completed after diagnosis. A normal NOx concentration alone does not verify this oxygen check, and a test performed while exhaust-brake or sensor-readiness conditions prevent monitoring is inconclusive. Vehicle-specific service information is needed for the omitted enable values and any electrical testing.

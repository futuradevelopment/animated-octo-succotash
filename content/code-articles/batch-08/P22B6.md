# P22B6: NOx sensor 2 oxygen signal below its reporting floor

The generic name for P22B6 refers to an oxygen-sensor pumping-current trim circuit. In the cited GM implementation, the actual decision checks the oxygen concentration signal associated with NOx sensor 2. The failure threshold is below −6.00%, not a published pump-current or harness-voltage limit.

## What the negative threshold means

This is a signal-validity boundary. It should not be read as a physically meaningful negative oxygen content or a target for normal exhaust. The controller checks for 100 failures out of 200 samples at a 25 ms task rate. The row is Type B with two-trip reporting.

Engine operation, system voltage above 11 V, a fully operative sensor and an enabled combustion mode qualify the test. An invalid NOx sensor 2 condition prevents it from being accepted.

## A useful diagnostic approach

Verify which scan parameter is being displayed: the raw or processed oxygen signal and the NOx concentration are different measurements from this sensor system. A low NOx ppm value does not satisfy the oxygen-percent failure criterion. Also check readiness before treating an absent code as a passing measurement-range test. The summary does not provide a pin-voltage conversion or a procedure for adjusting pump current; applying a generic oxygen-sensor voltage test could therefore answer the wrong diagnostic question.

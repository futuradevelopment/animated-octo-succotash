# P2732: GR10 clutch C6 slips despite its commanded application

P2732 is a hydraulically stuck-off performance diagnosis for pressure-control solenoid F. This GM section maps it to the GR10 C6 clutch. The source explicitly distinguishes hydraulic failure from an electrically nonfunctional solenoid.

## The test occurs after application

C6 slip above 200 rpm is the failure evidence. The monitor runs after a shift is complete or steady-state gear is established, with the clutch mapped to line pressure and fully applied. Failure time must exceed one second before the count increments, and the fault count must exceed two. The task rate is 6.25 ms; reporting is Type A, one trip.

Input, output and intermediate shaft-speed signals support the calculated clutch slip. Relevant electrical and speed-sensor faults can disable the check. Service fast learn, cleaning procedures and certain higher-priority deceleration-protection states also affect eligibility.

## What makes the observation useful

Slip during an unfinished shift is not equivalent to sustained slip after C6 should carry torque. Preserve clutch state, shift-complete status and speed validity before interpreting the number. Electrical continuity alone does not verify hydraulic capacity, while an invalid speed signal undermines the slip evidence.

Confirmation requires a completed eligible C6 application assessment under the prescribed service procedure. The code establishes a failure to maintain expected holding behavior, but it does not prove which internal hydraulic or friction component requires repair.

# P2690: cylinder 5 injector adjustment data is absent

P2690 is the cylinder 5 injector-data entry in this GM source. It monitors the EIA, or end-of-line injector adjustment, record associated with DID $64. The failure criterion is missing programming, despite the broader generic description of data incompatibility.

## Scope of the check

With ignition on and the calibration's eligibility conditions met, successful EIA programming produces a pass and unsuccessful or absent programming produces a fail. The source describes production and development controller gating. It lists Type A, one trip, with no separate setting-time value.

## What can and cannot be concluded

This code addresses a cylinder-specific data record. It does not establish injector leakage, poor atomization or a combustion fault, and the presence of a cylinder-5 entry in a large diagnostic file does not establish a particular engine's applicability. Confirm that the vehicle actually uses this monitored record before acting.

The useful next evidence is programming status and the correct adjustment information for the installed injector in the correct cylinder position. Do not treat the DID as a universal command or substitute a neighboring cylinder's record. Verification requires successful storage recognized by the controller and a completed cylinder-5 monitor. Separate mechanical symptoms need separate testing because this table supplies no fuel-delivery performance criterion.

## Source and application limits

This explanation covers the cited 2025 GM monitor.

# P268E: cylinder 3 injector adjustment data is unprogrammed

P268E belongs to cylinder 3 injector data. The GM strategy checks the end-of-line injector adjustment code, identified in the row as DID $62, and fails if that record has not been programmed. This is narrower than a general statement that the installed injector is mechanically incompatible.

## What a passing result requires

The source defines success as successful programming of the EIA code. It lists ignition on, calibration enablement and controller production/development qualifications. Type A, one-trip reporting applies, without a specified sample counter or duration.

## Reading the service evidence

A programming tool's connection to the vehicle is not the same evidence as a successfully stored cylinder-3 record. Review the completion result and the supported record status using the applicable service process. Likewise, acceptable engine operation does not independently satisfy this data-presence test.

The DID identifies the record in this documented controller; it should not be generalized into a raw write instruction for another calibration. Confirm cylinder numbering and the correct injector-specific adjustment data before any authorized coding. Verification should be based on the resulting cylinder-3 data check, not simply DTC clearing. No injector-flow limit, physical location or parts-replacement conclusion is supplied by this monitor, so separate electrical or mechanical complaints require their own evidence.

## Source and application limits

This explanation covers the cited 2025 GM monitor.

# P2463: DPF soot estimate reaches the service-regeneration range

P2463 is documented as a clogged-DPF condition requiring service regeneration evaluation. The monitored quantity is a soot estimate derived from differential pressure with a configurable correction block. It is not a direct weighing of soot and should not be equated with one pressure reading.

## State changes the threshold

The cited threshold is above 130% during the soot-loading state and above 150% outside that state. The counter is 120 failures out of 150 samples on a 100 ms task. Reporting is Type A, one trip. These percentages belong to the calibrated soot model, not a universal filter-volume scale.

Valid pressure, temperature, airflow, ambient-pressure and exhaust-flow information qualify the calculation. The continuation requires low icing risk in the pressure pipes and a valid pressure-based model for at least five seconds, among other operating conditions.

## What verification must establish

Review the modeled loading, filter state and the validity of the inputs before choosing a regeneration procedure. An invalid pressure path can compromise the very estimate used for the decision. The code alone does not establish that a forced regeneration is permissible or that it will resolve the underlying condition.

Follow the vehicle's professional service procedure for hot-exhaust regeneration decisions. Confirmation should include a credible loading estimate and a completed monitor afterward, rather than relying only on extinguishing the warning lamp.

## Source and application limits

This explanation covers the cited 2025 GM monitor.

# P2723: CVT torque-converter clutch does not achieve its requested coupling

P2723 is the hydraulically failed-off torque-converter-control solenoid diagnosis in the reviewed GM CVT-specific row. The generic pressure-control-solenoid-E title should not be used to apply these CVT limits to unrelated transmissions.

## Lock and controlled slip are different targets

In lock mode, the controller expects near-zero converter slip; the documented failure boundary is slip above 130 rpm. In controlled-slip mode, it evaluates deviation from the commanded slip target using a supporting calibration table.

A nonzero slip reading is therefore not automatically a fault: the intended operating mode determines whether nonzero slip is expected. Recording mode and target alongside actual slip is essential to interpreting the evidence.

## Performance testing requires valid inputs

The monitor excludes solenoid circuit faults P2727, P2729 and P2730, relevant speed-sensor faults, range-sensor faults and loss of ECM communication. The continuation also includes a commanded-pressure qualification above 800 kPa for more than two seconds.

The failure must persist beyond 2.5 seconds before an event is counted, and more than three events are required, with a 25-millisecond update rate. One transient during a mode transition is not equivalent to that accumulated result.

Verification should confirm the correct CVT application, valid speed inputs and acceptable converter response in the requested mode. A failed hydraulic result does not isolate the solenoid from all other hydraulic or clutch causes. The source lists Type A, one-trip behavior but no universal parts recommendation.

## Source and applicability

These limits describe the stated monitor and require vehicle, hardware and calibration confirmation.

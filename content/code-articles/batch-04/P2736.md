# P2736: Solenoid F has an open circuit, with function determined by transmission type

P2736 is the pressure-control-solenoid-F open-circuit diagnosis in the reviewed GM table. Solenoid F has especially different roles across the listed transmissions: clutch control in the 9- and 10-speed variants, line-pressure control in the 8-speed, and binary-pump control in the CVT.

## The electrical code does not identify one universal function

The source names 9-speed C6789/SOWC CBR1 and 10-speed C45678910R clutch mappings. Those should not be substituted for the line-pressure or binary-pump mapping when diagnosing another transmission.

The controller evaluates circuit voltage and uses an open-circuit design specification above 200 kilohms to controller ground. A failure must last more than 0.30 second within a sample interval longer than 0.50 second; the update rate is 6.25 milliseconds.

## Check whether the path was supplied

The mapped high-side driver must be on. Battery voltage must remain between 9 V and 32 V for more than one second, with an applicable run/crank or accessory condition present. A disabled supply path is not itself proof of an open solenoid circuit.

Use the correct transmission's electrical procedure to interpret the signal and identify the failed path. The impedance figure is a detection specification, not a live resistance-test instruction.

Verification requires acceptable electrical behavior and a completed enabled test without recurrence. This Type A, one-trip fault does not directly establish clutch slip, inadequate line pressure or binary-pump hydraulic failure, despite the functions associated with the different variants.

## Source and applicability

Keep the stated transmission function and source calibration separate from other applications. [GM diagnostic table, PDF page 1185](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=1185).

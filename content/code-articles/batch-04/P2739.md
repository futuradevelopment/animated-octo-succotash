# P2739: Solenoid F circuit-high diagnosis needs care with conflicting source columns

P2739 is labeled pressure-control-solenoid-F circuit high, and the reviewed GM strategy text describes a short to voltage. However, both reviewed 2025 files contain contradictory malfunction and threshold columns that describe a ground short.

## Do not turn copied wording into a test specification

Because the fault direction and threshold wording conflict, the ground-referenced impedance in these rows is not presented here as a verified P2739 test limit. The applicable vehicle service procedure must resolve the circuit-high detection criterion before detailed electrical testing.

The timing also differs between sources. File 25OBDG03A lists failure beyond 0.06 second in a sample period above 0.13 second; 25OBDG04B lists more than 0.30 second within more than 0.50 second. This reinforces the need to keep calibration variants separate.

## What the sources consistently establish

The code belongs to solenoid F's electrical control path, with transmission-specific mappings to clutch control, 8-speed line-pressure control or the CVT binary pump. Battery and power-mode eligibility and an enabled mapped high-side driver are required. Both rows classify the response as Type A, one trip.

Identify the transmission and reporting calibration, preserve supply-driver state and investigate the high-circuit description using the correct electrical information. The code does not independently demonstrate high hydraulic pressure or a mechanically stuck actuator.

Verification should demonstrate the correct circuit behavior and a completed monitor without recurrence. These summary tables do not establish the failed component or justify a solenoid replacement.

## Source and applicability

Keep the stated transmission function and source calibration separate from other applications.

# P2724: CVT torque-converter clutch remains coupled when release is expected

P2724 identifies a hydraulically stuck-on torque-converter-control actuator in the reviewed GM CVT monitor. The strategy looks for converter slip falling sharply toward zero and remaining low when the clutch should be released.

## Low slip is only abnormal in the right mode

The documented enable sequence includes torque-converter-clutch mode off. One failure condition uses absolute filtered slip below 18 rpm, with additional speed, torque and transition conditions. Near-zero slip during an intentional lock command would have a different meaning.

The source's moving-vehicle branch uses speed above 2.49 mph and below 27.96 mph and excludes reverse for that branch. Its broader continuation includes additional state logic, so those limits should not be treated as a complete reproduction procedure.

## Protective activity affects the observation

The monitor description warns that a stuck-on clutch can contribute to engine stalling. It describes neutral and pump-default overrides used for stall protection; these must be inactive for the listed failure evaluation. Command changes during protection can therefore alter the slip evidence.

Relevant solenoid, speed-sensor, range and communication faults also inhibit evaluation. Failure counting depends on calibrated base and offset times, followed by more than six counted events.

Verification belongs in an appropriate professional transmission diagnostic procedure, with mode, slip and protection status considered together. The code does not certify driving safety or identify the sole failed hydraulic component. The documented response is Type A, one trip.

## Source and applicability

These limits describe the stated monitor and require vehicle, hardware and calibration confirmation.

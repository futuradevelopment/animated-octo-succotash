# P2119: Throttle does not return to its de-energized default position

P2119 concerns throttle return after the electronic throttle motor is de-energized in the reviewed GM calibration. The controller checks whether both normalized throttle-position signals agree that the plate remains outside its permitted default window.

## What makes this test different

The source evaluates paired upper or paired lower limits: both position channels must indicate the same out-of-window direction. A disagreement between the two sensors is therefore not the same evidence as both sensors reporting an incorrect rest position.

The listed signals are percentages of a five-volt reference, not ordinary throttle-opening percentages. Their normalization and narrow limits belong to this controller implementation. Comparing a generic scan tool's displayed opening percentage directly with these values could produce a misleading conclusion.

## Timing and operating state

Several situations can de-energize the motor, including power-up default learning, default-throttle authority, low relay voltage, shutdown and battery-saving operation. Record which situation was active rather than assuming the code was evaluated during acceleration.

The failure duration also changes with motor-command state. The table lists about 0.497 second when the command is STOP in the specified default or shutdown condition, versus five seconds when it is not STOP. An observation made too early may precede the actual test decision.

After a repair, verification needs an applicable de-energized default-position check with the appropriate timing. P2119 alone does not distinguish mechanical resistance from electrical control or sensing problems, and it does not justify manually forcing an electronic throttle plate.

## Source and applicability

This explanation is limited to the documented 2025 GM monitor; its thresholds are not universal vehicle specifications. [GM diagnostic table, PDF page 596](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=596).

# P2720: Solenoid D control circuit indicates a ground short

P2720 identifies a short-to-ground signature in pressure-control solenoid D's circuit in the reviewed GM transmission monitor. It is an electrical diagnosis; it does not measure clutch holding pressure or establish that a clutch is mechanically stuck.

## The letter D has transmission-specific mappings

The source associates this row with the 9-speed C4 clutch, 10-speed C23467810R clutch, 8-speed C23468 clutch, or CVT input clutch. Select the actual transmission architecture before deciding which circuit the code identifies.

The driver compares circuit voltage with its accepted range, using a design specification below 0.5 ohm between signal and controller ground for the ground-short signature. Failure must exceed 0.30 second within a sample period exceeding 0.50 second; evaluation updates every 6.25 milliseconds.

## Enabled supply matters

The mapped high-side driver must be on. Battery voltage must be between 9 V and 32 V for more than one second, with an applicable run/crank or accessory condition. An observation made with the actuator supply intentionally disabled does not recreate that context.

Use the appropriate service procedure to distinguish the signal circuit, connected solenoid and driver. The threshold is a controller detection specification and should not be treated as a live resistance-testing instruction.

A useful verification establishes correct electrical response and no recurring fault through an enabled evaluation. The source lists Type A, one-trip behavior without proving that the valve body, solenoid or transmission assembly requires replacement.

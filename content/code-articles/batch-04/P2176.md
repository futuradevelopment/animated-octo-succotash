# P2176: Minimum throttle position was not learned after repeated attempts

P2176 means the controller did not establish minimum throttle position in the reviewed GM learning routine. It is a learning-result fault, not simply another name for a low throttle-position signal.

## The stored-learning state matters

The monitor operates when minimum-position learning is active and no previous minimum values are stored in long-term memory. A vehicle that already has valid stored values is therefore in a different diagnostic situation from one attempting its initial learning sequence.

During learning, the controller checks for throttle position above 11.48% of the five-volt reference scale together with more than 10 learning attempts. These are internal learning-attempt counts, not an instruction to perform a fixed number of manual ignition cycles.

## Conditions for a meaningful verification

Run/crank voltage must exceed 6.41 V, and the row lists a two-second decision time. Supply condition and active learning status should be retained when interpreting a failed attempt. A later normal-looking throttle reading does not demonstrate that the minimum value was actually accepted and stored.

Use the applicable vehicle procedure to determine why the throttle sensors remain outside the learning window and to confirm that learning completes. This source is not a relearn procedure and does not prescribe battery disconnection, pedal sequences or manual plate movement.

The documented response is Type A, one trip. Successful verification requires an accepted learned minimum and no recurring fault under the monitor's conditions, rather than simply erasing the diagnostic record.

## Source and applicability

The thresholds and component mapping apply only to the documented monitor, pending vehicle and calibration confirmation. [GM diagnostic table, PDF page 609](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=609).

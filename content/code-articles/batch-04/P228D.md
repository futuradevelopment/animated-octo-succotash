# P228D: Fuel rail pressure stays above the requested target

P228D identifies excessive high-side fuel pressure relative to the controller's request in the reviewed GM direct-injection system. It reports a control-performance result rather than directly identifying a mechanically failed regulator.

## Negative error means pressure is too high

The diagnostic defines pressure error as desired minus measured pressure. For this code, measured pressure exceeds the target, so the error is negative. Keeping that sign convention clear prevents a scan-data plot from being interpreted in the wrong direction.

The high-pressure limit is supplied by a supporting calibration table. The main row does not support one fixed overpressure number for every engine condition. It requires 10 seconds of failing evidence in a 12.5-second window.

## Distinguish a valid test from an inhibited one

Monitoring requires at least 11 V battery voltage, low-side pressure above 0.275 MPa, a running rather than cranking engine, and the low-side pump operating. Relevant sensor and circuit faults must be absent. Injector-flow testing and specified device-control commands are excluded.

A service-commanded pressure event therefore may not correspond to the normal onboard decision. Confirm both requested and measured rail pressure, signal validity and diagnostic enable status before attributing a discrepancy to a particular hydraulic component.

Use the applicable professional high-pressure fuel procedure for diagnosis and verification; this summary does not provide depressurization or probing instructions. A successful repair should restore sustained target tracking and allow the monitor to complete without recurrence. The source documents Type A, one-trip behavior.

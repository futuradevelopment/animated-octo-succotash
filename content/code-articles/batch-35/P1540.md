# P1540: Subaru vehicle-speed signal malfunction 2

In Subaru's 2001 Forester SOHC diagnostics, P1540 is vehicle-speed sensor malfunction 2. The “2” in the title is not enough information to order a second sensor. The factory flow chart determines which part of the speed-information path deserves attention.

## Two observations narrow the problem

First, Subaru checks whether P0720 is also recorded. If it is, the procedure points to the front vehicle-speed sensor signal circuit in the automatic-transmission diagnostics. That companion fault changes the next test and should not be ignored while working only from the engine-controller code.

Without P0720, the next question is whether the speedometer operates normally. An abnormal speedometer directs attention to the speedometer and vehicle-speed sensor. A normal display moves the investigation toward the wiring between the combination meter and ECM.

## A working gauge does not prove the ECM receives speed

The final branch assesses continuity of the meter-to-ECM circuit and connector contact. This explains how the dashboard can indicate vehicle speed while the engine controller still reports a problem with its received signal. Conversely, replacing the ECM-side wiring would not be the first choice when the speedometer itself is already malfunctioning.

The source gives the exact circuit for its documented configuration; connector details must be matched to the actual vehicle. After correction, Subaru calls for memory clearing and inspection mode. A useful repair record includes speedometer behavior, the original P0720 status, and confirmation that the ECM's speed information now agrees with vehicle operation.

# P1089: Subaru right TGV high-input diagnosis

P1089 is the right-hand tumble generator valve position sensor high-input fault in the 2001 Forester turbo manual. Subaru labels this sensor number 1. It monitors feedback from the valve assembly; the code is not a direct verdict about deposits or a mechanically jammed valve.

## Why the ground circuit comes first

With a persistent live reading above 4.9 V, the factory sequence checks the sensor's ground connection. The right sensor's ground must be evaluated on its own circuit. A poor return path can distort feedback even though the component still has a supply.

The next branch evaluates voltage at the disconnected signal circuit. Excessive voltage there leads the chart toward a battery-voltage short and possible controller damage. If that external problem is absent after the specified checks, the assembly becomes the repair candidate. This order prevents a sensor replacement from masking an uncorrected harness problem.

## A recovered signal is useful evidence

If the current reading is no longer above the high-input comparison, Subaru describes the circuit as normal at the time of testing and identifies connector contact as a possible intermittent cause. Record that finding instead of treating an unrepeated historical code as proof of permanent failure.

Subaru's after-repair instruction is to clear memory and perform inspection mode. Verify the feedback on the right bank through that routine. P1087 concerns the opposite bank, so a left-side repair or a left-position data reading does not by itself demonstrate that the P1089 circuit is fixed.

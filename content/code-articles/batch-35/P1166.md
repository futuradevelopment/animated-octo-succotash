# P1166: Honda A/F heater command and feedback disagree

P1166 is an electrical fault in air/fuel ratio sensor 1's heater system in Honda's Advanced Diagnostics collection. The heater brings the sensing element into a stable operating condition when exhaust heat alone is insufficient. This code concerns heater control, not a direct measurement of a rich or lean mixture.

## The collection contains two different strategies

The CVT-labeled description evaluates combinations of heater voltage and current while the heater is commanded on and off, including an excessive-current condition. The other description monitors a heater return signal against the ECM command for at least five seconds.

These are distinct implementations. A current threshold from the CVT page should not be combined with the return-voltage logic from the other page to create a new universal test. Battery-voltage and temperature enable conditions also differ between the listed variants.

## Command state gives the reading meaning

A heater signal cannot be judged independently of whether the ECM is requesting heating. The return-check version specifically detects feedback inconsistent with the commanded state. The CVT version likewise interprets voltage and current as a combination rather than declaring a component failed from one isolated number.

Both descriptions classify the fault as capable of illuminating the MIL in one drive cycle under their enable conditions. Use the actual vehicle's heater-circuit procedure to distinguish wiring, supply, control and sensor-assembly causes; the monitor pages alone do not select a part. Confirm that the appropriate heater test operates normally after repair, rather than treating a cleared code as completion.

# P1305: Lexus RX300 coil 2 igniter circuit fault

Lexus assigns P1305 to ignition coil with igniter number 2 in the RX300 RM785E manual. The detection condition is missing IGF ignition confirmation while the engine runs. The numeral in the code mapping identifies a particular coil circuit; it is not simply a general bank-2 mixture complaint.

## Spark presence changes the next diagnostic branch

The shared factory procedure begins with a spark/plug assessment. Where spark exists, it investigates the IGT command and IGF confirmation wiring and the controller-side confirmation circuit. Where spark is absent, it follows a different path through command-signal behavior and coil power supply.

This separation matters because a functioning spark does not automatically prove that its confirmation reaches the ECU. Conversely, absent spark does not establish a failed coil before command and supply are verified.

## A shared procedure still requires the correct channel

P1300 selects coil 1, P1305 selects coil 2, and other codes identify the remaining coils. The manual applies common diagnostic logic to distinct IGT paths. A satisfactory check of another cylinder cannot clear the number-2 command conductor or igniter from investigation.

The source identifies wiring, coil/igniter and ECU possibilities, without assigning probabilities. Avoid ordering a module solely from the code title. Professional ignition testing is needed because operating coils generate hazardous voltage.

After the established fault is corrected, confirm normal ignition and credible IGF behavior under the original conditions. Clearing the code or eliminating one rough-running symptom is incomplete verification if the confirmation fault returns.

# P1349: Lexus RX300 bank-1 variable valve timing does not respond

Lexus's RX300 RM785E P1349 procedure concerns bank-1 variable valve timing that does not change appropriately or remains fixed after warm-up within the stated engine-speed range. The ECU controls an oil-control valve, which directs pressure to the VVT mechanism to alter camshaft phase.

## Several layers can prevent the response

The factory sequence first checks base valve timing. It then assesses oil-control-valve operation and its electrical drive, the VVT controller assembly, and blockage in the valve/check-valve/oil-pipe path. Those are different causes of an absent timing response; replacing an OCV from the code alone skips the other branches.

The document also discusses a temporary foreign object in the oil path that can cause a fault before normal operation returns. That note supports checking whether the condition is present now. It does not prove that every stored P1349 will cure itself or justify ignoring a repeatable failure.

## Use reliable confirmation rather than an ambiguous copied step

The transcription's active-test speed wording is inconsistent with another OCV section, so this explanation does not reproduce that wording as a test recipe. Follow the correct current procedure for the actual vehicle's commanded response.

After the diagnosed repair, the source calls for a simulation and code recheck. Verification should show responsive timing control and no recurrence under the relevant conditions. Base timing, hydraulic service and electrical actuation require suitable professional procedures; a cleared code alone cannot establish a repaired VVT system.

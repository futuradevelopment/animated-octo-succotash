# P1511: Subaru idle-air signal 1 high input

In Subaru's 2001 Forester SOHC diagnostics, P1511 means idle-air control solenoid valve signal 1 circuit high input. Its page directs the technician to the shared high-input procedure, which separates a common grounding problem from the individual signal line.

## The code combination changes the first check

The procedure asks whether P1511, P1513, P1515 and P1517 appear together. With all four high-input reports present, Subaru checks the ECM ground circuit before proceeding. Four affected outputs can therefore be evidence of a common connection problem rather than four independently failed valve windings.

For the individual signal-1 path, the next branch evaluates voltage with the idle-air valve disconnected in the specified state. Excessive voltage directs attention to a battery-voltage short in the ECM-to-valve harness. The published repair endpoints then address possible ECM damage; they do not amount to proof that a valve replacement alone is sufficient.

## High input is a specific electrical complaint

P1510 is the low-input counterpart for signal 1 and follows a different supply/continuity sequence. Do not apply that chart solely because both codes mention the same idle-air assembly.

The source lists unstable idle and stalling for this circuit family. Electrical checks require matching wiring and correct isolation, especially before concluding that the ECM is faulty. After correction, Subaru calls for memory clearing and inspection mode. Retain the original combination of codes so a repaired common ground can be assessed against all affected channels.

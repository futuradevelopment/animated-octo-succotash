# P1298: Honda S2000 electronic-load signal high

Honda's S2000 P1298 procedure addresses high voltage in the electronic load detector circuit. It begins by confirming the fault with the engine running and headlights on. If the code does not return, Honda identifies loose terminals or poor contact at the ELD/ECM as the intermittent branch.

## A high report still requires power and ground checks

For a repeatable fault, the chart first verifies the ELD's supply from the ACG fuse circuit. It then checks the signal conductor's continuity and the detector's ground path. Those branches distinguish missing supply, an open signal wire and an open ground before the detector is condemned.

This is an important diagnostic distinction: “high signal” does not mean the entire electrical system has excessive charging voltage. It describes the input condition detected in this particular circuit.

## The final load-response test separates components

After the external circuits pass, Honda observes whether the signal voltage drops as the headlights are switched on. Failure to change leads to the ELD endpoint. A response that changes as expected leads instead to a known-good ECM comparison before replacing the original controller.

The complete procedure uses controlled connector isolation and test connections, which should be performed with the correct vehicle information and suitable electrical competence. Do not substitute a generic battery test for the circuit checks. Verify the completed repair with the specified load response and code confirmation, including any intermittent connection that originally made the fault difficult to reproduce.

# U3501: GM control-module input A voltage low

The cited GM BSC2 table defines U3501 as control-module input power A circuit low. It contains two distinct checks under that code, making a single blanket battery-voltage explanation incomplete.

## Two low-voltage observations share the code

One branch monitors CAN supply voltage below 7.5 V for a short interval while software is running. Another examines an ECU supply measurement below 4.9 V when the hardware has not switched off as expected. The second branch concerns consistency between the measured supply and hardware shutdown behavior, not simply a weak battery reading.

These thresholds describe the cited controller implementation. They should not be applied as universal acceptable battery limits or as justification to continue operating a vehicle with brake-system warnings.

## Preserve the event before selecting a repair

The code does not identify which branch occurred from its name alone. Relevant controller data, related supply faults and the conditions of the event are needed to decide which circuit or operating state to investigate. The table provides monitor logic rather than a complete test sequence or an instruction to replace the module.

GM classifies these branches as Special Type C and includes a key-on waiting pass check. That classification should not be translated into a universal promise about warning-lamp behavior on another vehicle.

Qualified service should establish the actual supply or consistency fault. After repair, verify the affected input under the original conditions as well as the applicable diagnostic pass state; a normal voltage measured after the event may miss an intermittent dropout.

# P1672: Honda A/T FI data failure: why the shared circuit test matters

## What the factory chart actually distinguishes

The NSX source calls P1672 a failure in A/T FI data line B, while its P1671 heading describes no signal. Both codes lead to the same manufacturer diagnostic tree. The available chart does not give separate waveform limits or timing thresholds that would explain the exact internal distinction. It would therefore be misleading to claim that P1672 necessarily proves corrupted data, a short to power or an internal TCM failure.

The documented system uses separate engine and automatic-transmission controllers. The mirror's 1998 NSX 3.2L index is not proof of transmission compatibility; use this explanation only after matching that controller arrangement to the vehicle's actual service information.

## Do not stop after checking the data conductor

The common diagnostic path checks the ATSDLB connection for an interruption and for unintended grounding. It then examines the TCM ignition supply and ground references. The voltage checks use two designated connector pairs, 12/13 and 25/26, and expect battery voltage under the manual's test conditions.

If the supply check fails, the repair branches include the wiring to the under-dash fuse box and the ground path to G101. The source specifically notes that an IG1 supply short can blow the No. 5, 15 A fuse. That observation identifies a supply fault to investigate; installing successive fuses does not establish a repair.

## Interpret the substitution result carefully

With the circuit checks satisfied, the chart compares a known-good TCM before moving to an ECM comparison. A code that disappears with the comparison TCM supports replacing the original unit. Persistence sends the diagnosis onward instead of proving that both controllers need replacement.

If the initial one-minute idle confirmation produces neither code, the manual treats the fault as intermittent and identifies C493 and ECM connections for inspection. Preserve whether the fault returned, which circuit measurements passed and what changed during comparison; that evidence is more precise than expanding the word “failure” into an unsupported diagnosis.

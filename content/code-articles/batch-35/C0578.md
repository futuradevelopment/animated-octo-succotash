# C0578: GM left-rear brake-pressure zero offset

GM's cited BSC1 table defines C0578 as left-rear brake-pressure sensor circuit performance. Its monitored condition is the sensor's zero-point compensation, rather than simply excessive pressure while the driver is braking.

## Zero pressure must be assessed at the right moment

The system adjusts the pressure-signal offset to compensate for drift when the brake pedal is not applied. This variant detects measured pressure beyond approximately ±1,500 kPa during that assessment. Its enable conditions also include accelerator application, vehicle movement and sufficient system voltage.

Those conditions change interpretation. A high pressure reading during an ordinary brake application is not the same evidence as an implausible offset with the brake released. The code concerns whether the zero reference can be compensated within the allowed range.

## Distinguish performance from a circuit extreme

Adjacent codes on the source page describe separate high- and low-voltage faults for the same sensor. C0578 instead evaluates the pressure zero point. Replacing a sensor from a generic electrical-high diagnosis would skip the actual performance question.

The table explains detection but does not establish a specific vehicle fitment or a complete hydraulic repair procedure. Brake-pressure plausibility and any accompanying warnings require qualified diagnosis with the correct system information. Do not open hydraulic lines or improvise sensor probing from this monitor summary.

Verification should show a credible released-pedal pressure reference under the applicable conditions after the established repair. A cleared code while the vehicle remains stationary cannot, by itself, prove this movement-enabled offset check passed.

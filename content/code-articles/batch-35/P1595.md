# P1595: Subaru transmission diagnostic signal low

P1595 is low input on the automatic-transmission diagnosis signal circuit in Subaru's 2001 Forester SOHC manual. The code concerns a signal shared between the engine and transmission controllers, so an engine-only fault scan can miss important evidence.

## A low line is not automatically a failed TCM

The first test asks whether the ECM-side signal remains below 1 V. If it does not, Subaru treats the fault as absent at that moment and points toward poor contact at the ECM or TCM connector.

For a present low signal, the procedure isolates the controllers and checks the intervening harness for a ground short. It then evaluates the ECM-side output with the prescribed connection state. These branches separate a grounded wire from a connection or controller-side problem before reaching the transmission-controller decision.

## Read the transmission faults before replacement

A later step explicitly reads automatic-transmission trouble codes. If any are present, their diagnostic procedures take priority; the TCM replacement endpoint follows the alternate result. This ordering means a technician should retain the transmission code list, not conclude that P1595 is the complete diagnosis.

The source describes detection over two consecutive faulty driving cycles. After correcting the established wiring, connector or controller-related problem, Subaru requires memory clearing and inspection mode. Confirm both the signal behavior and the relevant transmission fault status. A recovered voltage during one stationary measurement cannot by itself rule out an intermittent connector problem.

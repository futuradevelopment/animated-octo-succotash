# U3505: GM control-module input B voltage low

GM's BSC2 table assigns U3505 to control-module input power B circuit low. Its rows span two source pages and evaluate several supply measurements and performance states. Reading only the first row would omit part of the diagnostic meaning.

## A long drop and a short dropout differ

One branch checks a voltage-sensor measurement below 6 V over a 30-second interval. Another monitors battery supply below 9.3 V over 90 seconds. Further branches assess a driver-module voltage below 6 V and reduced-performance conditions at lower supply levels over much shorter intervals.

These are separate monitored situations. A fault may therefore need investigation for a brief dropout even if the battery was never observed low for a minute and a half. The code label alone does not identify which duration or supply path was involved.

## Confirm the relevant supply path

The source is a diagnostic summary, not a universal battery-replacement instruction. The actual vehicle procedure must establish whether an external supply, connection, controller measurement or other documented cause produced the low-input evidence. Related voltage and communication faults should be preserved for that assessment.

The table uses a Special Type C classification and gives a 90-second key-on pass check. Passing that check after memory clearing cannot rule out a dropout confined to the original operating conditions.

Qualified brake-system service is appropriate when warnings or assistance changes accompany the code. Verification should demonstrate stable power at the affected input and completion of the applicable monitor after the established repair.

# P1164: Honda A/F sensor performance during deceleration

Honda's P1164 monitor evaluates air/fuel ratio sensor 1 during closed-throttle deceleration. The controller expects a particular response to the oxygen concentration under that condition and detects excessive deviation toward either side of the normal characteristic.

## This is not a heater-circuit verdict

The sensor provides a signal used for fuel-feedback control, while P1164 assesses its range/performance. A heater electrical fault has its own diagnostic path. Honda's enable table excludes active sensor/heater and other relevant faults for the stated variants, so their status can determine whether this monitor is eligible to run.

The source requires a warmed engine and a defined deceleration condition after sufficient running time. A single reading at idle is not the same test. It also publishes different limits for manual-transmission and CVT variants, making a universal voltage threshold inappropriate.

## Scan-tool scaling needs special attention

Honda explicitly warns that the scan-tool presentation has the opposite relationship to oxygen concentration from the raw-signal characteristic shown in its graph. A technician must identify the displayed parameter and scaling before calling a reading rich or lean. Comparing a scan value directly with a raw graph can reverse the interpretation.

The documented monitor runs once per qualifying cycle and uses two faulty cycles for MIL illumination. Verification should establish that the relevant deceleration test completed, with the correct sensor parameter interpreted for the actual variant. The monitor description explains detection but does not prove that sensor replacement is the only repair.

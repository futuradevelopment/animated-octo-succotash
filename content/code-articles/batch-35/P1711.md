# P1711: Subaru torque-control signal 1 circuit fault

P1711 identifies engine torque-control signal 1 circuit malfunction in the 2001 Forester SOHC manual. Subaru lists excessive shift shock as a possible symptom. That association connects the engine/transmission coordination circuit to the complaint without proving that an internal transmission component has failed.

## High and low electrical branches diverge

The procedure first evaluates the ECM input. A value in the high branch is checked for battery-voltage intrusion before ECM connector contact and the controller endpoint are considered. If the input is not high, Subaru instead isolates the ECM–TCM harness and checks continuity and a short to ground.

This split matters: a signal held high by external power requires a different correction from a broken or grounded line. The same P1711 code does not select the failed component until those observations are made.

## Signal 1 must remain distinct from signal 2

P1712 is the separate torque-control signal 2 circuit. The two procedures have similar logic but use different controller paths. A satisfactory test of signal 2 therefore cannot clear the signal 1 wiring from suspicion.

After the harness checks, connector contact at the relevant controller determines whether the factory procedure proceeds to a module replacement endpoint. These are conditional decisions, not a recommendation to replace both modules. Subaru specifies two consecutive faulty driving cycles, then memory clearing and inspection mode after correction. Verify the original shift complaint and the repaired signal path together.

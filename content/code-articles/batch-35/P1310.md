# P1310: Lexus RX300 coil 3 command and feedback fault

P1310 is the number-3 igniter circuit malfunction in Lexus's RX300 RM785E service manual. This direct-ignition system uses one coil for each cylinder and separate ECU ignition commands, with an ignition-confirmation return to the ECU.

## The ECU reports missing confirmation

The documented detection condition is absence of IGF while the engine is running. That is information about what the ECU receives, rather than a direct measurement of spark-plug condition. An interrupted confirmation circuit can therefore matter even when a spark is observed during testing.

The diagnostic tree checks actual spark, distinguishes IGT command wiring from IGF feedback wiring, and assesses coil supply in the applicable branch. The controller and coil/igniter replacement endpoints follow those checks; they are not automatic consequences of P1310.

## Channel identification prevents a misleading repair

The source explicitly maps P1310 to coil/igniter 3. The shared table also covers five other coils, each with a different code. Testing the wrong IGT channel can produce a normal result that says little about the reported circuit.

Use the correct vehicle wiring and professional high-voltage precautions. The source's diagram and confirmation procedure are more authoritative than a generalized description copied from another manufacturer that uses P1310 differently.

Preserve freeze-frame conditions, repair the demonstrated path or component and verify both spark operation and valid confirmation. A smooth idle after parts substitution is useful observation, but it cannot replace checking whether the original ignition-confirmation fault has stopped recurring.

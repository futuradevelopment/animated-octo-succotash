# P1097: Subaru left TGV actuator overcurrent

P1097 is the overcurrent fault for tumble generator valve actuator circuit number 2 in Subaru's 2001 Forester turbo manual. This is the left-side actuator system, not the left position sensor's high-input code P1087.

## The circuit check changes the repair choice

Subaru's procedure disconnects the actuator and compares the voltage on each actuator conductor with a 5 V boundary under the prescribed conditions. Excessive voltage directs attention to a battery-voltage short between the ECM and actuator. The alternative branch reaches replacement of the tumble generator valve assembly.

The practical distinction is external electrical damage versus the assembly as the remaining repair candidate. The word “overcurrent” alone cannot tell an owner which branch applies. A damaged wire touching a power supply must be corrected before a replacement component can be expected to operate normally.

## Keep companion faults in their proper order

The left-system stuck-position charts P1092 and P1093 explicitly prioritize this electrical code when it accompanies them. A valve that fails to move while its actuator circuit is faulty has not yet been shown to suffer an independent mechanical obstruction.

The source does not prescribe a generic cleaning treatment or a direct battery-powered actuator test for P1097. Correct connector identification and the specified isolation are essential for electrical diagnosis. Subaru then requires memory clearing and inspection mode after the repair. Successful verification should address both the actuator fault and any stuck-position report that originally depended on it.

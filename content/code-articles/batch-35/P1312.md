# P1312: Subaru exhaust-temperature circuit malfunction

The 2001 Forester turbo manual defines P1312 as exhaust-gas temperature circuit malfunction. It is a diagnostic-system report, so it should not be read as proof that the exhaust is currently overheated or that the temperature sensor is automatically defective.

## Three companion codes control the next step

Subaru first asks whether P0545, P0546 or P1544 is also displayed. The first two concern exhaust-temperature circuit low/high input, while P1544 concerns detected high exhaust temperature. If one accompanies P1312, the chart directs diagnosis to that specific fault and says a separate P1312 investigation is unnecessary at that point.

When those companion codes are absent, the short chart reaches exhaust-temperature sensor replacement. That is a conditional factory endpoint. An isolated P1312 and a P1312 accompanied by a voltage fault do not carry the same diagnostic next step.

## Preserve the full fault record

Clearing the engine-controller memory before noting the companion codes can remove the information that determines this priority. Record the full list and whether the fault is current. The chart states detection occurs at fault recognition, rather than requiring two consecutive faulty driving cycles.

Exhaust parts can remain extremely hot after shutdown. Sensor or harness access should follow the correct service procedure once safe conditions are established. After the diagnosed repair, Subaru requires memory clearing and inspection mode. Confirmation needs to address the original fault group, including any electrical or overheating-related code that took priority over P1312.

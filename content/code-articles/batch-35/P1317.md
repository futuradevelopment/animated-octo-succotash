# P1317: Honda spark-voltage detection: the RL right-bank circuit

## Use the RL bank identification

Honda's general P1317 dictionary description refers to the rear bank. The 2000 Acura RL manufacturer chart instead identifies the right bank, Bank 1. Use that vehicle-specific identification when locating the circuit; a dictionary orientation is not a substitute for the correct engine diagram.

The chart also establishes diagnostic order. When P1318 or P1319 accompanies P1317, investigate those detection-module reset faults first. This matters because a fault affecting the module's reset circuit can change how its separate detection-signal complaint should be investigated.

## Separate the signal conductor from its ground supply

On this RL, the right-bank detection signal is the yellow MFPLSR conductor connecting PCM terminal F4 with terminal 3 of the eight-pin detection-module connector. The factory sequence isolates both ends before looking for an unwanted connection to body ground, then checks continuity between the endpoints. A conductor can fail either test for a different reason: grounding and interruption are separate faults.

The next branch checks the module's own ground path. Its right-bank ground uses terminal 1, and the repair branch identifies ground point G202 on the right side of the engine compartment. Passing the signal-wire tests therefore does not finish the electrical diagnosis.

## What justifies replacing a module

Only after those circuit checks does the chart use a known-good spark-voltage detection module for comparison. PCM substitution comes later if the complaint persists. That order does not support replacing the PCM simply because it stored the code.

If the warm-engine confirmation does not reproduce P1317, the manual directs attention to connectors C451, C214 and the PCM. Record an intermittent result as such. These are module-circuit investigations; the code is not permission to probe ignition high voltage with an ordinary meter.

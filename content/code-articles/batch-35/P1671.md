# P1671: Honda A/T FI data line B: diagnosing a missing signal

## Identify the communication system in the source

The Acura NSX material describes P1671 as no signal on A/T FI data line B. Its diagram connects a separate transmission control module, or TCM, to the engine control module. This is a documented automatic-transmission communication circuit, not a generic label for a failed shift solenoid.

The mirror files this chart under a 1998 NSX 3.2L index, but the chart's TCM-based architecture is the relevant evidence. That index label does not establish automatic-transmission compatibility for a 3.2L car. Match the actual transmission and service edition before applying the terminal references.

## Check whether the data path is physically intact

The factory confirmation checks whether P1671 or P1672 returns after the prescribed reset and one minute at idle. If neither returns, the chart directs inspection of TCM connector C493 and the ECM connections for an intermittent problem.

For a returning fault, the first circuit is the light-green/yellow ATSDLB conductor. The illustrated path runs between ECM terminal F21 and terminal 19 of the TCM connector. One branch checks continuity along that path; a separate branch isolates the controllers and checks whether the conductor is unintentionally grounded. An intact wire and an isolated wire answer different diagnostic questions.

## A powered controller is necessary for communication

The following stage verifies battery voltage across the TCM's specified ignition-feed and ground pairs. Failure directs attention to the under-dash supply wiring and ground G101. A missing message therefore does not by itself establish that the data conductor is broken.

Only after these checks does the chart substitute a known-good TCM, followed by ECM comparison if required. The ECM branch references immobilizer information, so controller swapping is not a casual owner test. Ask whether the repair corrected the data path, restored controller power or changed the result through a controlled module comparison.

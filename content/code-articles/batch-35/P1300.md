# P1300: Lexus RX300 ignition confirmation missing for coil 1

For the RX300 RM785E application, P1300 identifies the number-1 ignition coil/igniter circuit. Lexus detects absence of the ignition-confirmation signal, IGF, while the engine is running. This manufacturer-specific meaning differs from a generic misfire interpretation sometimes attached to the same code elsewhere.

## Command and confirmation are separate signals

The ECU sends an IGT command for each cylinder. The igniter switches the coil's primary current and returns IGF confirmation. A missing return does not, by itself, prove whether the command failed to arrive, the igniter did not respond or the confirmation path was interrupted.

The factory procedure first distinguishes whether spark is present, then branches through the appropriate IGT and IGF wiring checks. A spark-present case can still need investigation of the confirmation circuit. The no-spark branch also evaluates command behavior and coil power supply before reaching component replacement.

## Keep number 1 distinct from the other coils

The manual explicitly assigns P1300 to coil/igniter 1. Its shared diagnostic tree covers six individually identified circuits, not one interchangeable bank-wide coil. Use the correct wiring diagram and cylinder identification.

High-voltage ignition testing requires appropriate professional equipment and precautions; do not handle exposed ignition components while operating. Preserve freeze-frame data, correct the demonstrated circuit or component fault, and confirm both ignition operation and the return of valid confirmation. A new spark plug alone is not proof that the missing-IGF complaint is resolved.

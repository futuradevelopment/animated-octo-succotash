# P1712: Subaru torque-control signal 2 circuit fault

The 2001 Forester SOHC manual assigns P1712 to engine torque-control signal 2 circuit malfunction. It lists excessive shift shock as a possible symptom, but the diagnostic procedure concentrates on the electrical communication path between the engine and transmission controllers.

## Establish which electrical state has failed

Subaru checks the ECM-side input and separates a high-voltage branch from a lower-signal branch. Excessive voltage can indicate an unwanted battery connection. In the other branch, the procedure checks the isolated inter-controller harness for an open conductor and for a ground short.

A controller replacement decision appears only after the relevant voltage, continuity and connector-contact checks. That sequence prevents interpreting a harsh shift and P1712 as automatic proof of either an internal transmission defect or a failed TCM.

## Similar code, separate conductors

P1711 concerns torque-control signal 1; P1712 concerns signal 2. The manual assigns them different controller terminals. Although their decision trees resemble each other, testing the first circuit does not establish that the second has continuity or insulation.

Use the matching diagram and specified connection states to investigate the affected path. The source requires two consecutive faulty driving cycles for detection, followed by memory clearing and inspection mode after repair. A useful confirmation includes restored signal behavior and reassessment of the original shift shock. If harsh shifts remain after the electrical fault is resolved, the code alone cannot explain the remaining complaint.

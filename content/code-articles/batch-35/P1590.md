# P1590: Subaru automatic-transmission neutral signal high

P1590 is high input in the neutral-position switch circuit for the automatic-transmission model in Subaru's 2001 Forester SOHC manual. Subaru lists irregular idle as a possible symptom and requires two consecutive faulty driving cycles for detection.

## The expected state depends on selector position

The chart first checks for P0705 and directs diagnosis there if present. It then compares the ECM signal in Park/Neutral with its state in the other selector positions. The specified signal is low in Park/Neutral and approximately 5 V outside them. A value cannot be judged correctly without knowing the selector position at the time.

For a persistent abnormality, the procedure separates a battery-voltage short, interrupted signal continuity and the inhibitor-switch ground path. The ground checks include the starter-related return path in this application, so testing only the switch contacts would leave part of the circuit unassessed.

## Mechanical selection can create an electrical mismatch

After the wiring and switch checks, Subaru examines the selector cable connection. A switch that can change state on the bench does not prove that the installed linkage places it correctly for the driver's selection.

These checks require securing the vehicle and following the correct transmission procedure; they are not a reason to bypass the inhibitor switch. Verify the repair in both neutral/park and selected-gear states, then complete Subaru's memory-clear and inspection routines. A normal idle alone is not evidence that the position signal has recovered.

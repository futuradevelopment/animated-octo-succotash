# P1607: Honda internal ECM self-check failures

P1607 is an internal ECM circuit malfunction in Honda's Advanced Diagnostics collection. The document contains both a CVT-labeled description and a broader description with additional self-checks. A single generic “computer failure” label hides that distinction.

## Several internal checks can lead to one code

The CVT page describes loss of a backup-processor monitor signal or abnormal air/fuel-processor communication. The broader page also includes repeated EEPROM data abnormalities and an abnormal immobilizer-circuit output. Those are separate internal observations, not four components the code proves have failed together.

Their detection timing differs. For example, the backup-processor condition lasts at least five seconds, while the EEPROM condition depends on repeated abnormal reads within a time window. Copying one timing value into every P1607 diagnosis would misrepresent the source.

## An internal label is not a complete replacement procedure

These pages explain what the controller monitors with ignition on; they do not replace the vehicle's electrical and module-service procedures. The applicable variant must be established before deciding how to confirm the failure, service the ECM or handle immobilizer-related requirements.

The listed strategies can illuminate the MIL in one qualifying drive cycle and save fault data. Preserve the full scan record before clearing memory. After the actual cause is established and corrected, verify that the relevant self-check completes without recurrence. The presence of an immobilizer branch in this collection does not mean every P1607 vehicle has that branch, or that bypassing security functions is an appropriate diagnostic step.

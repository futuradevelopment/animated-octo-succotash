# P1297: Honda S2000 electronic-load signal low

P1297 is low voltage in the electronic load detector circuit in the cited S2000 service procedure. Honda verifies the report with the engine running and the headlights switched on, making the electrical-load condition part of the initial assessment.

## A code that does not return suggests an intermittent path

If P1297 is absent during the prescribed confirmation, the manual points to poor connections or loose terminals at the ELD and ECM. A stored fault therefore does not automatically establish a permanently failed load detector.

When the fault returns, the chart examines the disconnected ELD signal circuit. An approximately 5 V result leads to the ELD repair branch. If that expected voltage is absent, Honda isolates the ECM connection and checks whether the signal conductor is shorted to ground.

## Module substitution is a later diagnostic step

A demonstrated ground short calls for wiring repair. Only after that possibility is excluded does the procedure use a known-good ECM comparison to establish whether the original controller is responsible. This conditional sequence is more informative than replacing either electronic component solely from the code title.

Use the matching S2000 year diagram and connector procedure; arbitrary jumpers or direct voltage application can damage a controller input. After the established repair, repeat the specified loaded confirmation and check for intermittent terminal behavior. A satisfactory result includes the ELD signal responding as intended, not simply a fault memory that has just been reset.

# U350A: GM control-module input C voltage high

U350A is control-module input power C circuit high in GM's cited BSC2 table. This variant evaluates the reading identified as voltage sensor 2, rather than treating every control-module supply as one interchangeable circuit.

## Movement is part of the documented criterion

The row combines a voltage-sensor-2 value above 19.8 V with vehicle speed above 4 mph and a 90-second qualifying period. These details matter when comparing a workshop observation with the original event. A stationary key-on check does not reproduce the same movement-dependent assessment.

The high value is a calibration-specific detection limit. It is not an acceptable operating target or a general recommendation to apply such voltage during testing.

## The pass condition also differs from a quick reset

The table describes a straight-ahead travel condition for passing the monitor. That is evidence that this particular diagnosis cannot be fully verified by erasing the code while the vehicle remains parked. Any dynamic confirmation must follow the actual vehicle procedure and be appropriate to its brake condition.

The monitor row does not prove an external charging-system fault, a failed sensor or a damaged motor driver. Qualified diagnosis must establish the relevant power path and inspect related faults before selecting a repair.

GM gives this variant a one-trip Type A classification. Because the source is a brake-control table, warning lamps or altered brake assistance require professional assessment. Confirm stable input-C measurement and successful monitoring after repair; scan-tool communication alone is insufficient evidence.

## Source and applicability

GM 2018 18OBDG02 Hybrid Diagnostics, BSC2 brake-system monitor table; document-level example only, vehicle/calibration fitment not established. The [manufacturer service document](https://gsi.ext.gm.com/gmspo/mode6/pdf/2018/18OBDG02%20Hybrid%20Diagnostics.pdf#page=1737) is hosted by the manufacturer. Its diagnostic instructions take precedence over a general code dictionary.

# P1146: Subaru pressure-sensor performance reads high

P1146 is a pressure-sensor range/performance problem described as high input in Subaru's 2001 Forester SOHC manual. Unlike a simple assumption that every high reading means a shorted wire, this procedure evaluates whether intake pressure agrees with the operating conditions.

## Check what could make pressure genuinely wrong

The factory sequence first gives priority to P0107, P0108 or P1112 if present. It then checks the intake system for holes, disconnected hoses and loose fasteners. That branch recognizes that an abnormal pressure reading can reflect the air path itself, not only a failed sensor.

The next assessment compares pressure with the engine off and at a warmed, unloaded idle. These are different physical conditions: an engine-off reading should not be judged against an idle specification. The source supplies particular ranges for this application; they should not be exported to every altitude or engine calibration.

## Throttle data is part of the decision

The later branches evaluate the throttle-position indication at fully closed and fully open positions. An inaccurate throttle input can change how a pressure-performance complaint is interpreted. The table distinguishes adjustment or replacement of the throttle sensor from the intake temperature/pressure sensor assembly.

Subaru specifies two consecutive faulty driving cycles for detection and requires its inspection procedure after repair. Preserve the related code list and the conditions of the pressure measurements. A single cleared warning lamp does not establish that the pressure/throttle relationship has become credible.

# P1319: Honda right-bank reset fault: distinguish reset and signal circuits

## Distinguish P1319 from the neighboring signal code

The 2000 Acura RL procedure assigns P1319 to the right-bank, Bank 1, spark-voltage detection module reset circuit. P1317 concerns that bank's detection-signal circuit. The signal-code chart gives a simultaneous P1319 priority, so the two stored codes should be interpreted together rather than treated as independent reasons to replace components.

Honda's general dictionary describes P1319 using a rear-bank label. The RL source uses right bank. Confirm the engine's bank arrangement from its service information before identifying the connector or ordering anything.

## Follow the asterisk branches for the right bank

The shared P1318/P1319 chart marks P1319's terminal choices with an asterisk. Its blue PHRSTR conductor connects PCM F3 with terminal 2 at the detection module. That differs from the left-bank circuit printed alongside it. Reading the unstarred terminal numbers would test the wrong branch.

The source separates an unwanted ground on this reset conductor from a break along its length. Both checks precede component substitution. It then checks the right-bank ignition supply at module terminal 4, using body ground as the voltage reference. A missing feed directs diagnosis toward the supply from the under-dash ECU/PCM fuse circuit.

## Establish whether the fault is present now

A warm-engine idle check follows the specified reset procedure. If P1319 does not return, the factory path calls for inspecting connections at C451, C214 and the PCM. That result means the condition was absent during confirmation; it does not prove an intermittent connection has repaired itself.

When the code remains and the circuit checks pass, the chart compares a known-good detection module before considering the PCM. This sequence makes the measured circuit results and the response to substitution more useful than the code's wording alone. Connector views and ignition-state instructions must come from the matching RL manual.

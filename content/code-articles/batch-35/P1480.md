# P1480: Subaru cooling-fan relay high input

P1480 is cooling-fan relay 1 circuit high input in the 2001 Forester SOHC manual. Subaru lists improper radiator-fan operation and overheating as possible symptoms. The description concerns relay control; it does not establish that the fan motor itself has failed.

## Commanded operation separates an intermittent fault

The procedure observes the ECM output while the radiator-fan relay is commanded. A switching output sends the diagnosis toward an intermittent ECM connection rather than a permanently failed control circuit. That is a useful distinction when the fan happens to work during the workshop visit.

If the output does not behave correctly, the next branch removes the relevant relay loads and checks for unwanted battery voltage in the control path. Subaru then evaluates the main fan relay and, on the applicable air-conditioned configuration, the sub-fan relay. An electrical short in either relevant load can alter the controller repair decision.

## Avoid replacing the controller without the preceding tests

Some factory endpoints include controller replacement after a demonstrated wiring or relay fault. Those endpoints are conditional; the code by itself is not an instruction to install an ECM. Leaving the original external fault uncorrected could compromise the repair.

Fans can operate unexpectedly, so keep hands and tools clear and use the specified service procedure. If the engine is overheating, stop operating it and arrange diagnosis. After correction, verify actual commanded fan operation as well as Subaru's required memory-clear and inspection routines.

# U3502: GM control-module input A voltage high

U3502 identifies control-module input power A circuit high in GM's cited BSC2 table. This implementation monitors the supply identified as CAN supply voltage. It is a power-quality diagnosis even though its code begins with the network-related letter U.

## The monitored supply is specific

The documented threshold is above 16 V for approximately 0.09 seconds while software is running. That observation concerns the supply measured by this control system, not necessarily a sustained voltage at every point in the vehicle.

The brief qualifying interval matters for intermittent events. A normal battery reading taken later does not demonstrate that the monitored input never exceeded its limit. The actual diagnosis should preserve the operating record and evaluate the relevant supply path with the vehicle-specific procedure.

## High power is not missing communication

The table does not say the module stopped receiving messages, nor does it identify a failed CAN conductor. A wiring, charging or module conclusion requires additional evidence; the monitor row alone does not select a replacement component.

GM assigns a two-trip Type B classification to this variant and provides a key-on waiting check for its pass condition. That check is diagnostic context, not a guarantee that intermittent overvoltage cannot recur under the original conditions.

Because this source section covers brake control, any accompanying brake warnings require qualified assessment. Repair verification should address the original high-supply event and confirm stable input power, not merely clear a network-prefixed code or observe temporary scan-tool communication.

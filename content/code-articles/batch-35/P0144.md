# P0144: Honda third oxygen sensor stays high in lean burn

P0144 identifies a high-voltage condition for the third heated oxygen sensor in Honda's documented manual-transmission lean-burn strategy. This sensor is downstream of the NOx-adsorbing catalyst and provides evidence for that catalyst's diagnosis.

## High must be interpreted against commanded operation

The monitor expects the third sensor to indicate the lean side during lean-burn operation. If it stays high instead, Honda identifies sensor failure or a circuit short as possible explanations. The code therefore describes an inappropriate response to a known operating state, rather than proving that the engine is generally running rich.

The source gives a 2.50 V high-side criterion for this particular strategy. That value should not be compared casually with the familiar output range of a different oxygen-sensor system or a differently scaled scan parameter.

## An arbitrary road trip may not test the repair

The monitor requires a warmed engine and catalyst, a qualifying load/speed window, sufficient lean-burn operation and other prerequisites. Its table also includes an IMA battery state condition. Failure to reset after a brief idle does not demonstrate that those conditions were met.

P0143 checks the opposite response during enrichment; the two codes are related but not interchangeable. This variant uses two qualifying faulty cycles for MIL confirmation. After the correct sensor/circuit diagnosis and repair, verify lean response in the appropriate monitor and preserve its completion status. A new downstream sensor or a cleared code is not independent proof that the original high-response fault is resolved.

# P1701: Subaru cruise-set signal to the transmission

The 2001 Forester SOHC manual identifies P1701 as a cruise-control set-signal circuit malfunction for the automatic transmission. Manufacturer context is essential: a P1701 description from another brand may concern an entirely different system.

## The signal crosses two controllers

Subaru first checks continuity between the cruise-control module and transmission controller. It then checks the same path for an unwanted connection to ground. These tests establish whether the transmission controller can receive the cruise-set information through intact wiring.

The next branch evaluates the received signal during commanded cruise operation. If the expected input is missing, the procedure points toward the cruise-control command-switch circuit. If it arrives correctly, connector contact at the TCM is examined before its replacement endpoint. A transmission-side code can therefore originate upstream in cruise command circuitry.

## Dynamic testing needs the proper facility

The factory chart includes a controlled rotating-wheel test and specifically addresses AWD support. That is professional workshop work, not a driveway check or a reason to run one axle of an AWD vehicle on ordinary stands. This article explains the diagnostic decision without reproducing that hazardous setup.

The printed measurement row also mislabels a voltage check as resistance, so use correct current service information for instrumentation. Subaru specifies two consecutive faulty driving cycles and its memory-clear/inspection routines after repair. Confirm the cruise-set signal path, not merely that the cruise dashboard switch illuminates.

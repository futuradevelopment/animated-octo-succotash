# P1591: Subaru automatic-transmission neutral signal low

The 2001 Forester SOHC automatic-transmission procedure defines P1591 as neutral-position switch circuit low input. It shares the position circuit with P1590, but the failed electrical direction is different.

## Judge the signal in the correct gear state

Subaru first gives priority to P0705 when it accompanies this code. The next comparison is made outside Park and Neutral, where the documented ECM input should be between 4.5 and 5.5 V. If that state is present during inspection, the manual recognizes that the fault has returned to normal at that time.

A persistently low signal sends diagnosis toward short-to-ground checks. The procedure separates the ECM-to-transmission harness from the transmission-to-inhibitor-switch section, instead of treating all wiring as one undifferentiated component. This isolation helps identify where the unwanted ground connection exists.

## Switch and cable checks answer different questions

The chart also checks that the inhibitor-switch path is open outside Park/Neutral and inspects the selector cable connection. A switch fault and incorrect mechanical actuation can both prevent the expected state, but they require different repairs.

Subaru lists irregular idling as a possible symptom and describes detection over two consecutive faulty driving cycles. Secure the vehicle and use the appropriate service procedure when checking selector states. Verification should demonstrate the correct state change across positions, followed by the specified memory-clear and inspection routines; immediate code deletion alone cannot confirm an intermittent low-input fault is repaired.

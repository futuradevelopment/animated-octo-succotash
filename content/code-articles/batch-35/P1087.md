# P1087: Subaru left TGV position signal reads high

In the 2001 Forester turbo diagnostic section, P1087 is high input from the left-hand tumble generator valve position sensor, identified as sensor number 2. The adjective “high” describes the electrical feedback value; it does not prove that the intake valve is physically stuck open.

## What changes the repair decision

The first branch asks whether the live signal exceeds 4.9 V. If it does not, Subaru treats the circuit as having returned to normal and calls attention to intermittent contact at the sensor, ECM and intermediate connections. Reproducing the electrical symptom matters more than buying a valve from the stored code description.

When the high value persists, the chart checks the sensor ground path before evaluating unwanted voltage on the signal wire. A missing ground can make a sensor report incorrectly. Conversely, excessive voltage remaining in the disconnected harness points toward a wiring fault and possible consequential controller damage, rather than proving that a newly fitted sensor would help.

## Interpret the repair endpoint carefully

Valve-assembly replacement appears after the preceding circuit checks. It is not the first instruction for every P1087. Connector identification and disconnected-circuit tests belong with the matching wiring information and competent electrical diagnosis; the left and right banks must not be confused.

The manual calls for clearing memory and running inspection mode after repair. A useful confirmation includes a sensible left-position signal and absence of the same high-input fault during that verification, not merely an extinguished warning lamp immediately after clearing.

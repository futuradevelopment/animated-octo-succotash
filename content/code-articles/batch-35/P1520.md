# P1520: Lexus RX300 brake-switch signal remains applied

P1520 is a stop-light switch signal malfunction in the RX300 RM785E manual. The engine ECU uses the STP brake-applied input partly to modify fuel-cut control. The source describes a signal that fails to turn off after repeated qualifying driving/braking events, with two-trip detection logic.

## Lamps and ECU data answer different questions

Lexus first checks whether the stop lamps illuminate and extinguish normally as the pedal is pressed and released. Abnormal lamp operation directs diagnosis toward the stop-lamp circuit.

If the lamps behave correctly, the next step checks the STP signal seen by the engine ECU. It should indicate applied with the pedal depressed and released when the pedal is released. A normal lamp does not independently establish that the engine controller receives the correct state through its branch of the circuit.

## An intermittent result is a documented possibility

A correctly changing STP input during inspection leads the chart toward intermittent-problem investigation. An incorrect input calls for the wiring and connector between the switch and ECU to be assessed before the controller endpoint.

Preserve freeze-frame conditions and verify both sides of the applied/released transition. Do not bypass the switch or assume an engine-controller code means the brake lamps are unimportant. Brake-lamp faults affect signaling to other drivers and need prompt correction.

After the established repair, confirm normal lamp operation and ECU input together, then complete the appropriate diagnostic check. Merely clearing P1520 cannot prove the stuck-applied condition has been resolved.

# P1367: Honda TDC sensor 2 no-signal monitor

Honda's P1367 monitor reports no signal from top-dead-center sensor 2. The described rotor and pickup-coil arrangement generates pulses as the engine turns, providing the ECM with cylinder timing information for fuel injection.

## What the controller must fail to see

The source identifies a sequence of 37 missed TDC pulse checks as its malfunction criterion. It monitors continuously while the engine is running, subject to the listed timing-fault prerequisites. This is a sustained missing-signal assessment, not a measurement of spark-plug condition or a direct cylinder-compression test.

P1366, by contrast, evaluates an abnormal relationship between crank and TDC pulses. That code distinction helps preserve the character of the original failure: signal absence and signal corruption are different observations even when they involve the same sensor family.

## Do not infer the physical repair from the code alone

The monitor page explains the ECM's detection but gives no universal pinout, component location or proof that the pickup coil itself is defective. The vehicle-specific procedure must establish whether the expected pulses are generated and reach the controller. Sensor 2 must also be distinguished from the sensor-1 P1362 circuit.

Honda classifies this variant as a one-drive-cycle MIL fault. Preserve the freeze-frame and other timing codes before clearing memory. Following the diagnosed repair, verify a reliable sensor-2 pulse stream and a completed monitor under suitable operating conditions. Merely starting the engine or deleting the code cannot demonstrate that the original missing-pulse condition is resolved.

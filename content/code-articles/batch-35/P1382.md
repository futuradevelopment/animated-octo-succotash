# P1382: Integra cylinder-position sensor signal missing

P1382 identifies a missing cylinder-position sensor signal in the cited 1998 Integra service procedure. This application groups the CYP diagnosis with crankshaft and top-dead-center sensor checks in the distributor-related sensor assembly.

## Test the sensor and complete path separately

The factory sequence confirms whether the fault returns after reset and engine operation. If it does not, poor connections or loose wiring at the sensor connection and ECM become the intermittent branch.

For a repeatable fault, the chart checks the indicated sensor's resistance and isolation from ground. It then assesses the same circuit from the ECM end after the specified reconnection/disconnection steps. Comparing those locations distinguishes an internal sensor problem from an open or short in the intervening wiring.

## Shared diagnostic logic does not merge sensor identities

The CKP, TDC and CYP signals use separate circuit identification in the table. P1382 selects CYP; a passing resistance check on TDC does not demonstrate that the cylinder-position path is sound. The distributor-housing repair endpoint applies only after the sensor-specific test result supports it.

The ECM substitution branch comes after the sensor and wiring assessments. This is a conditional verification step, not an instruction to replace the controller from P1382 alone.

Use matching service information and avoid operating ignition-component exposure during testing. After correction, confirm recovery of the correct cylinder-position signal and absence of the original fault. A normal start or idle alone cannot prove that an intermittent CYP connection will remain reliable.

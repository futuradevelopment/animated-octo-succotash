# P1162: Honda A/F sensor circuit fault: separate signal wiring from the sensor

## What the Civic HX procedure establishes

Honda identifies P1162 as an air/fuel ratio sensor 1 circuit malfunction in the 2002 Civic HX procedure. The circuit label describes the signal path used by the controller; it does not establish that the engine is running lean or that the exhaust sensor must be replaced immediately. A disconnected wire and a sensor defect can lead to different branches of the same diagnostic chart.

The first confirmation allows the engine to run for at least two minutes after the specified reset. If the code does not recur, Honda directs attention to intermittent connections at the sensor and engine controller. A brief start followed by an empty fault list does not reproduce that confirmation interval.

## How the electrical branches differ

The documented signal-voltage check expects 2.5–3.0 V on each of two controller signal paths, measured against the specified controller ground. That range belongs to this application and test state. It should not be applied to an unrelated oxygen sensor or interpreted as a universal exhaust-mixture voltage.

With the expected voltage present, the next branch isolates the sensor and controller and verifies the paired signal wiring. An open path calls for wiring repair; verified continuity permits the chart's sensor-replacement conclusion. When voltage is outside the expected range, the isolated wiring is checked for an unwanted connection to ground before the sensor is condemned.

## What to record for repair

Useful evidence includes whether P1162 returned after the full confirmation, the two measured signal voltages, and whether a fault follows the harness isolation tests. Connector identification and the prescribed test connections require the matching wiring diagram. Do not apply external voltage to the sensor signal terminals. This source provides an electrical diagnosis, not a reason to alter fuel trim or replace ignition parts.

# P1094: Subaru right TGV actuator open circuit

P1094 is an open-circuit fault for tumble generator valve actuator circuit number 1 in the 2001 Forester turbo manual. This is the right-side actuator circuit. It is distinct from P1088/P1089, which describe that valve's position-sensor feedback.

## Continuity is the first decision

Subaru checks both conductors between the engine controller and actuator with the relevant components disconnected. The specified continuity branch uses a resistance below 1 ohm. Failure of that test directs the repair toward an open harness path or poor connection, rather than toward an immediate intake-valve replacement.

When the conductors pass, the next branch examines contact at the actuator connector. A good wire reading does not prove that the mating terminal maintains contact when assembled. Only after the connector check does the chart arrive at replacing the valve assembly.

## What an open-circuit code cannot prove

The code does not establish a dirt-bound valve or a failed position sensor. A mechanical stuck-open or stuck-closed report may accompany an actuator circuit that cannot operate, so resolving this electrical fault can be necessary before interpreting the position complaint.

Use the matching diagram to identify the right actuator conductors; this two-wire actuator path must not be confused with the position-sensor wiring. Resistance checks require the isolation specified by the manual, not probing a powered circuit. After repair, Subaru requires memory clearing and inspection mode, with confirmation that actuator control and the original fault report have recovered.

# P1793: Honda MAP signal at the transmission controller

P1793 is a manifold absolute pressure sensor circuit problem in Honda's transmission-control monitor description. The MAP sensor produces lower voltage at high vacuum and higher voltage as manifold pressure rises. The diagram shows its information reaching both engine and transmission controllers.

## A transmission code can originate in an engine-sensor path

The TCM uses MAP information with throttle position and other data to evaluate engine load. The documented electrical criterion is a signal at or below 0.2 V or at or above 4.5 V lasting at least ten seconds. The monitor runs continuously with ignition on.

This means P1793 can represent either an excessively low or excessively high received value. The code is not a direct report of a gear, clutch or hydraulic-pressure failure. It also does not prove that the sensor itself is defective: the input path into the TCM must be assessed with the correct procedure.

## Keep pressure and vacuum interpretations consistent

A closed throttle normally corresponds to lower manifold absolute pressure, while a more open throttle generally raises it. Confusing vacuum magnitude with absolute pressure can reverse the expected direction of the sensor signal. Use the correct scan parameter and units when comparing controller data.

The source classifies this variant as a one-drive-cycle MIL fault with a blinking D indicator. Preserve the original operating data before clearing it. Repair confirmation should demonstrate credible MAP information at the transmission controller and successful monitoring, rather than relying solely on an engine-controller reading or an extinguished indicator.

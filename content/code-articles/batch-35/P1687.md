# P1687: Integra A/T–FI signal B high input

P1687 is high input on the automatic-transmission/fuel-injection signal B circuit in the cited 1998 Integra service manual. Its AFSB line is separate from AFSA, the signal-A line monitored by P1681/P1682.

## The first decision is whether the event returns

Honda confirms the report after operation involving several transmission upshifts and downshifts. If the fault is absent, the manual points to intermittent connections at the TCM and ECM. This branch is relevant when a warning was reported earlier but the circuit appears normal during a stationary inspection.

When the fault returns, the shared A/B procedure checks the selected line for a ground short and then an open between controllers, with the required connections isolated. The page does not give a universal high-voltage number or instruct replacing a sensor from the code label.

## Keep the failed direction and line in the record

P1686 concerns low input on the same B line, while P1687 preserves the high-input direction. Both use common factory diagnostic logic, but recording the original direction and any companion codes retains evidence that can matter when an intermittent connection changes state.

The later ECM comparison is conditional on preceding circuit results. It is not proof that an otherwise normally shifting transmission needs a new controller.

After repairing the demonstrated wiring, contact or controller-related fault, repeat the correct operating confirmation safely. A cleared memory and one normal shift cannot independently establish reliable AFSB signaling over the conditions that originally produced P1687.

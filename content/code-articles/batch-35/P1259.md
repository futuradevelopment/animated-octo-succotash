# P1259: Honda VTEC command and oil-pressure feedback

Honda's P1259 description compares the VTEC solenoid command with feedback from the oil-pressure switch downstream of that valve. The system changes the hydraulic state of the valve-timing mechanism; a disagreement between commanded operation and reported pressure causes the fault.

## The switch logic is easy to misread

In the documented arrangement, the pressure switch is on during the low-VTEC state and off during the high-VTEC state. “Switch on” therefore does not mean that high-lift operation has been confirmed. When the solenoid is commanded on but the pressure switch remains on, the controller judges that the low state persists.

The opposite mismatch is also monitored: with the solenoid commanded off, a pressure switch that remains off suggests the high state persists. Both directions can produce P1259. The code alone does not reveal which mismatch occurred unless the operating data is examined.

## Separate detection logic from a parts diagnosis

The source describes a hydraulic command/feedback discrepancy, not a guaranteed failed solenoid or pressure switch. The vehicle-specific repair procedure must establish whether the command, hydraulic response or feedback is incorrect. The catalog adds “Rear Bank 1,” while these monitor pages identify no bank. That applicability qualifier remains unresolved; this article does not assign a bank or model from it.

The published variant requires at least five seconds under qualifying conditions and one drive cycle for MIL illumination. Engine speed, temperature and supply conditions control eligibility. Repair confirmation should compare command and switch response through the relevant operating states, using a safe service procedure rather than an improvised high-rpm road test.

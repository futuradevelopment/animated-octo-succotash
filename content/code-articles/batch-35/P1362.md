# P1362: Honda TDC sensor 1 signal missing

Honda defines P1362 as no signal from top-dead-center sensor 1 in the cited Advanced Diagnostics page. The described sensor uses a rotor and pickup coil; changing magnetic flux produces timing pulses that the ECM uses for fuel-injection synchronization.

## Missing pulses are the actual evidence

The published malfunction criterion is absence of the expected TDC pulses on 37 successive checks. That is different from an occasional extra or misplaced pulse. The monitor runs continuously with the engine running under its listed conditions, and it can illuminate the MIL in one qualifying drive cycle.

This description does not identify a particular external cause. A sensor, its circuit and the conditions needed to produce or deliver its signal must be evaluated using the actual vehicle procedure. The code is evidence of what the ECM did not receive, not proof of one failed part.

## Other timing faults affect interpretation

The enable conditions exclude active crankshaft-position and TDC faults. Preserve the complete timing-related code list before clearing memory, since it can explain why a particular monitor does or does not execute. A successful engine start alone does not demonstrate that every timing input is functioning correctly.

The source names sensor 1 specifically. Do not apply its identity to sensor 2 merely because P1367 has a similar no-signal description. After repair, verify restoration of the correct pulse stream and completion of the relevant monitor. The collection does not establish universal model fitment or a common sensor location.

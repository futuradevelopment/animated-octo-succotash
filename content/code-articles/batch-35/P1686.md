# P1686: Integra A/T–FI signal B low input

The 1998 Integra factory procedure defines P1686 as low input in automatic-transmission/fuel-injection signal B. It identifies the affected dedicated line as AFSB, which must be distinguished from signal A even though both appear in the same flowchart.

## Confirm the fault during relevant transmission operation

Honda's initial verification includes repeated upshifts and downshifts after the specified reset. If P1686 does not recur, the chart identifies poor connection or loose wiring at the ECM and TCM as the intermittent direction. The absence of a code at idle alone is not equivalent to that confirmation.

For a persistent report, the procedure isolates the controllers and checks the B-signal conductor for an unwanted ground path and interrupted end-to-end continuity. Those observations can establish an external wiring repair before a controller becomes a candidate.

## Low input does not prove internal transmission damage

P1686 describes the electrical state of a coordination signal. It does not measure clutch wear, hydraulic pressure or gear condition. A mechanical overhaul would require independent diagnostic evidence.

The source provides a known-good ECM comparison only after the relevant wiring checks. It does not support treating every low-input report as a failed ECM or using the signal-A terminal assignments on the B circuit.

After correction, verify the AFSB path and repeat the appropriate operating confirmation under safe conditions. Preserve any accompanying A/B faults so that an intermittent shared connector problem is not overlooked when one code temporarily disappears.

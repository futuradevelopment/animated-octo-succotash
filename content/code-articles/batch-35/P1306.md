# P1306: Honda cylinder-six misfire: follow the fault before choosing a part

## P1306 identifies a cylinder, not a failed component

The RL KA9 factory procedure associates P1306 with misfire detected in cylinder 6. Its explanation describes spark-plug voltage sensing built into the ignition coil as part of misfire detection. The diagnosis therefore depends on both combustion and the system observing it; a cylinder number alone does not establish a bad coil.

The manual gives companion spark-voltage-detection faults P1316 through P1319 priority over a misfire diagnosis. It also lists relevant fuel, MAP, EGR and position-sensor faults to address first. Preserving that code combination and freeze data can prevent an observation-system fault from being treated as a cylinder-six parts failure.

## Look for a fault that changes cylinders

The confirmation procedure attempts to reproduce the operating conditions recorded in freeze data. Its component comparisons ask whether the misfire moves when the suspect coil or spark plug is exchanged with another cylinder. A moving fault supports the exchanged component; a fault remaining on cylinder 6 calls for the next branch. The technician must keep a record of the original positions so that a changed code is interpreted correctly.

Injector diagnosis starts with operation and circuit checks, then uses a controlled component comparison where appropriate. Fuel-system disassembly and ignition-component work belong with a trained repairer following pressure-release and electrical precautions.

## When the fault stays on cylinder six

The later chart checks wiring among the controller, ignition control module, coils, power supply and spark-voltage-detection module. It then considers ignition-control-module substitution and cylinder-condition checks, including compression and leak-down. These are evidence-driven branches, not a recommendation to replace all those parts.

Ask which observation identified the repair: a moved misfire, a measured circuit defect or a cylinder-condition result. A flashing malfunction lamp during active misfire deserves prompt attention because the source associates that indication with catalyst-damaging misfire.

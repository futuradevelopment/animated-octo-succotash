# P1167: Honda A/F heater fault and the P1162 diagnostic priority

## Read the companion code first

The Civic service manual names P1167 as an A/F sensor 1 heater circuit malfunction, but its decision tree does more than check a heater fuse. It explicitly gives P1162 priority when both codes are stored. Resolving the companion sensor-circuit fault first prevents a heater diagnosis from being based on an already faulty sensor signal path.

For P1167 itself, the manual confirms recurrence after starting the engine and waiting at least 80 seconds following the specified controller reset. If the code remains absent, the listed inspection points are the A/F sensor relay, sensor connector and engine controller terminals. That intermittent branch matters: a code which is currently absent does not prove that a replacement sensor corrected anything.

## Why the signal wiring is tested

When P1167 returns, the factory procedure switches the ignition off and isolates both the four-terminal sensor connection and the engine controller. Its prescribed continuity test checks the two sensor signal conductors as a complete path. If that path is open, the repair is directed at wiring between the sensor and controller. If the required continuity is present, the chart directs sensor replacement.

This explains why a heater-related code name is insufficient to choose a part. The exact application, any P1162 companion fault and the tested wiring condition determine the next step. The isolated connector test is a technician procedure; its temporary test connections should not be improvised on an energized circuit.

## A useful completion check

Ask the repairer to record the initial code combination and which branch failed before clearing evidence. After the identified fault is corrected, repeat the matching confirmation and check for a returning code. The 80-second interval is a source-specific test condition, not a general guarantee that every vehicle has completed its oxygen-sensor readiness monitor.

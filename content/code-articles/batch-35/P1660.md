# P1660: Integra automatic-transmission check-line fault

In the cited 1998 Integra manual, P1660 is a fault in the automatic-transmission/fuel-injection data line. The procedure names the dedicated ATCHK connection between the transmission controller and engine controller. This is not a generic mechanical-transmission diagnosis.

## Reproduction determines whether to pursue an intermittent connection

Honda first resets the ECM and observes whether P1660 returns after a specified idle period. If it does not, the manual directs attention to loose wires or poor connections at the TCM and ECM. A stored event can therefore require connection investigation even when communication appears normal during the visit.

For a repeatable fault, the chart checks the ATCHK conductor for an open and then, with the relevant controllers isolated, for an unwanted ground connection. Those tests distinguish two external wiring problems before assessing the controllers themselves.

## A powered module is a prerequisite

The next portion evaluates TCM ignition power and ground paths, including the applicable fuse-fed circuit and ground point. Loss of a controller's power or return path can undermine its data signal without proving that its internal electronics failed.

Only after those checks does the procedure compare known-good controller operation. Do not substitute modern CAN termination tests for this dedicated line simply because two modules exchange information.

After the established fault is repaired, repeat the appropriate confirmation and verify stable controller communication. Clearing the code or observing ordinary shifts once does not establish that the ATCHK circuit and TCM supplies are reliable.

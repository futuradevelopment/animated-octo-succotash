# P1442: Subaru fuel-level performance problem 2

The 2001 Forester SOHC manual defines P1442 as fuel-level sensor circuit range/performance problem 2. This is a fuel-level measurement diagnosis in that source; it should not be reinterpreted as an evaporative leak solely because another manufacturer uses P1442 differently.

## The other fuel-level codes determine priority

Subaru's short diagnostic chart first asks whether P0461, P0462 or P0463 is also displayed. If one is present, its specific diagnosis takes priority and the manual says a separate P1442 investigation is unnecessary at that stage. That prevents treating related reports as unrelated failures requiring several independent repairs.

If those companion codes are absent, the chart reaches a repair branch involving both the main fuel-level sensor and the fuel sub-level sensor. The existence of two specified sensing components is important: “fuel sender” should not be assumed to identify one interchangeable part without the vehicle diagram and parts information.

## Keep the limits of this short procedure visible

The page does not provide a universal sender-resistance specification, a fuel-gauge calibration method or proof that every inaccurate gauge has this fault. Its detection statement requires two consecutive driving cycles with the fault. A code cleared immediately after service is therefore incomplete evidence of verification.

Accessing fuel-tank sensing components involves fuel and vapor hazards and belongs with the applicable professional service procedure. After the documented repair, Subaru calls for memory clearing and inspection mode. Confirm the relevant fuel-level behavior and related fault status, rather than assuming an emissions leak test verifies this particular code.

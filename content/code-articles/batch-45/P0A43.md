# P0A43: Toyota motor-resolver intermittency alongside power faults

Toyota maps SAE P0A43 to P0A3F1F for the Corolla HV traction-motor resolver. The detailed condition is an electrically detected short between resolver-phase signal lines while one of several named voltage or current faults is stored. This is more specific than interpreting the word intermittent as any occasional position-sensor dropout.

## Preserve the companion-fault context

The qualifying list includes P0C7917, P0E5717 and P0D3319, among others. The resolver event therefore needs to be read alongside the complete motor-generator fault record. A shortened report containing only P0A43 loses information that Toyota uses to describe this event.

The individual P0A3F1F row specifies one-trip detection but no MIL or master-warning request from that entry. Other faults may still illuminate warnings. The adjacent P0A3F16 phase-short entry has a different SAE mapping and warning behavior; its general monitor description should not overwrite the more specific intermittent row.

## Resolve causes in the documented order

Toyota identifies the inverter, motor MG2 within the hybrid transaxle, and their resolver wiring or connectors as possible fault areas. Its priority tables place applicable insulation faults ahead of processing and reference-power faults. This guards against treating the resolver code as an independent failed-motor verdict.

The procedure then evaluates the inverter connection and the dedicated motor-resolver circuit. Inverter replacement is reached only after the preceding resolver inspection is normal. Toyota also cautions that diagnostic vibration or heat checks can themselves cross a detection boundary, so recorded test-induced events need proper evaluation.

Repair confirmation uses the prescribed operating pattern and All Readiness judgment. That professional verification, including high-voltage precautions, cannot be replaced by a successful restart or by the absence of a warning lamp.

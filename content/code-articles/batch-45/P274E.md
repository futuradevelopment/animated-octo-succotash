# P274E: Toyota transaxle temperature signal intermittently changes

## Repeated unusual changes trigger this monitor

In the cited Corolla HV manual, SAE P274E corresponds to Toyota P274A1F. Toyota describes **repeated unusual changes in transmission-fluid temperature sensor C output**, calling the behavior hunting. The code concerns the consistency of a reported temperature, not proof that the transaxle fluid repeatedly overheats and cools.

The intermittent variant uses one-trip detection, with MIL and master-warning indications. Its neighboring range/performance variant P274A1C maps to P274B and uses different logic. Keeping the suffix avoids confusing an unstable signal with a long-soak plausibility comparison.

## The order of checks is specific

Toyota first checks the engine system for P261029, an engine-off timer fault, and then checks for direct temperature-circuit faults P274A11 or P274A15. Those codes are addressed through their own charts before the intermittent procedure continues.

The next stages inspect the inverter connector and the temperature-sensor connector for secure connection and sound contacts. If both are normal, Toyota inspects the transaxle's temperature sensor. A failed sensor result leads to hybrid transaxle replacement; a normal sensor result leads to harness/connector repair. The page does not justify immediate replacement of either assembly from P274E alone.

## Use the intermittent confirmation sequence

P274A1F has a separate confirmation: the prescribed ignition-off interval and ignition-on observation, followed by Motor Generator All Readiness. It does not use the five-hour soak required for P274A1C. NORMAL is a completed pass; INCOMPLETE requires another valid judgment. Record the unstable readings and full fault set before clearing them. Physical inspection near the inverter and transaxle requires qualified hybrid service and the manufacturer's safety procedure.

# P0D32: Honda DC/DC converter overtemperature depends on the detecting module

## The detecting module selects the procedure

Honda supplies two P0D32 troubleshooting variants: identifier **1025 is detected by traction-motor control**, while **417 is detected by the battery condition monitor module**. Both describe DC/DC converter overtemperature, but their verification procedures differ. A generic scanner showing only P0D32 loses that distinction.

For the battery-monitor variant, the converter reports that it stopped output for overheating protection. The monitor detects that information persisting for at least two seconds with the specified supply condition. Its warning is the 12 Volt Charging System indicator; the advanced page says the MIL and POWER SYSTEM indicator remain off for that variant.

## Cooling faults must be considered on the battery-monitor branch

Possible causes include coolant-pump or radiator-fan circuit problems, coolant-pipe leakage or restriction, and internal converter or monitoring faults. Honda's verification uses a controlled 750-second accessory-load sequence. If the code repeats, the procedure checks the PCU coolant circuit. A normal inspection leads to PCU replacement; an abnormal result directs cooling-fan-control troubleshooting.

The motor-control variant uses a different power-cycle verification and directs PCU replacement if its P0D32 repeats. The longer battery-monitor procedure must not be silently substituted for it, or omitted when identifier 417 applies.

## Document what was actually confirmed

Save the detecting-module identity, detailed identifier and freeze information before clearing. A non-repeat result is treated as intermittent, with the original conditions reviewed. The individual extracts do not establish exact model-year revision, so confirm applicability. Loaded operating checks and all PCU service require professional hybrid precautions and a qualified workshop.

# P2245: Honda detects a grounded air/fuel-sensor reference circuit

## Low refers to an electrical reference

Honda defines P2245 as an **air/fuel sensor 1 reference-voltage circuit low-voltage** fault. This sensor is installed in the exhaust manifold and provides information used for fuel control. The monitored circuit is its VCENT reference line.

The PCM's self-diagnosis detects a short to ground and stops the sensor heater. The advanced diagnostic page specifies that the condition persists for at least **five seconds** while the engine runs, with auxiliary voltage of at least 9 V. Two-drive-cycle MIL logic applies.

## Heater shutdown is part of the response

The source lists a sensor failure, a grounded VCENT wire and a PCM problem among possible causes. Heater operation stopping during the fault does not independently establish that the heater is defective: stopping it is part of the controller response described for this reference-circuit problem.

Likewise, the word “low” does not prove that the engine is running lean or rich. It identifies the electrical fault category. Mixture diagnosis based only on a sensor whose reference circuit is faulty would overlook the condition that generated the code.

## The source does not authorize a one-step replacement

This extract provides detection criteria and a warmed-engine confirmation pattern, but no complete circuit-isolation repair chart. Preserve the original snapshot, pending or confirmed status and associated sensor codes. A technician should then use the applicable wiring and troubleshooting information to distinguish the sensor, reference wiring and PCM branches.

Match the third-generation Insight extract to the exact vehicle before using its thresholds. Work around the exhaust sensor requires attention to hot components, and electrical testing should follow Honda's specified connector and power-state precautions.

# P0C59: Toyota rear resolver sine signal intermittent open

## The companion-code condition is part of the meaning

For the cited Corolla HV, Toyota P0C551F maps to SAE P0C59. The monitor detects an **open in the rear-motor resolver sine-phase circuit** while P0C7917, P0E5717, P0D3319, P1C5D19, P1C5F19 or P1C5E19 is stored. This qualification distinguishes it from the ordinary open variant P0C5513, mapped to P0C55.

Rear motor MGR is drive motor B, while the sine signal is resolver circuit A. Neither label should be dropped when translating a scan report into a repair description. The inverter, rear motor/transaxle and connecting wiring remain possible locations.

## Warning behavior and diagnostic priority

The specific P0C551F row uses one-trip logic without directly commanding the MIL or master warning. Other faults can still produce warnings. Toyota's broad shared monitor description should not override that more precise row.

The factory priority order addresses insulation faults, then relevant control, communication and power-reference faults. The subsequent procedure checks the inverter connector and then the rear-motor resolver circuit. An insecure connector is secured; defective contacts or contamination require harness/connector repair. Only normal preceding inspection results lead to inverter with converter assembly replacement.

## Verification needs operating context

Toyota cautions that vibration or heat used during inspection can cross a detection boundary. A reproduced fault should therefore be interpreted alongside the test conditions and original companion faults. The prescribed professional operating sequence concludes with All Readiness; INCOMPLETE needs another qualifying sequence. Controlled vehicle movement and high-voltage work belong to a qualified hybrid workshop, particularly when a resolver problem may disturb smooth driving.

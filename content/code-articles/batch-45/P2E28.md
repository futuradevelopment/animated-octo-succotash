# P2E28: Ariya excitation-current fault separates rotor and inverter causes

## Excitation current is the monitored function

The Ariya front-inverter procedure defines **P2E28-01** as a drive-motor A excitation-current sensor fault. Its detection table says excitation-module current is not flowing normally while in READY, with a diagnosis delay within one second.

Nissan lists the front inverter and front traction motor as possible causes and stops front-motor control under the fault. The page does not publish a specific current threshold, so the code should not be converted into an invented ampere limit or a claim that a particular current sensor has conclusively failed.

## The repair tree separates connections from components

The first diagnostic step checks for companion MOTOR CONTROL faults and gives higher-priority codes precedence. Only after that does the procedure inspect the excitation-circuit connections.

If the connections are sound, the next branch evaluates rotor-coil resistance using the linked component-inspection procedure. A passing rotor result directs inverter replacement; a failing result directs front-motor replacement. The distinction depends on the actual rotor test, not on the generic title's use of the word “sensor.”

The code page references that resistance test but does not display its normal range. No numerical rotor specification is inferred here from another suffix or a different vehicle.

## Confirmation requires more than deleting the code

Nissan's confirmation includes READY operation and a controlled low-speed movement before the fault check. It also specifies an undisturbed shutdown between attempts because automatic accessory power can wake the vehicle.

Preserve the suffix and all companion faults before clearing. Excitation-circuit access involves removal and high-voltage components, so diagnosis belongs to trained EV personnel using the exact VIN-specific isolation, inspection and installation procedures.

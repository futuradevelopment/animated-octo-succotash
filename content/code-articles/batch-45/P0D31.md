# P0D31: Toyota inverter VH sensor intermittent fault

## An intermittent measurement with defined companions

For this Corolla HV, P0D31 corresponds to Toyota P0D2D1F. The inverter's boosted-voltage sensor, designated **VH**, sends an excessively high or low signal while one of six named electrical faults is stored. Toyota lists P0C7917, P0E5717, P0D3319, P1C5D19, P1C5F19 and P1C5E19 as the qualifying companions.

The sensor's normal output represents changes in boosted high voltage through a 0–5 V signal. That description should not be confused with an exact malfunction threshold, which the source does not publish. Nor does a sensor signal at an extreme prove that the traction battery reached the corresponding physical voltage.

## Reading the individual detection row

P0D2D1F uses one-trip logic but does not itself command the MIL or master warning. Companion faults can still create warnings. Toyota's shared monitor overview uses broader MIL language; the specific intermittent-code row provides the narrower indication for this variant.

The listed trouble area is the inverter with converter assembly. The page's actual procedure is a direct assembly-replacement step for the confirmed matching fault, without a separate sensor-service branch. A complete Toyota scan record is therefore essential before applying that conclusion; the companion-code condition is part of the diagnosis.

## Verification and scope

Toyota uses its specified off/READY sequence and Motor Generator All Readiness to confirm recovery. An INCOMPLETE result is not evidence of a successful repair, even if the warning has cleared. Preserve the initial detailed code and companion faults for review. Inverter replacement requires professional high-voltage precautions, and this model-specific instruction should not be generalized to every vehicle carrying P0D31.

# P0E71: Toyota generator torque does not match its command

## A generator torque discrepancy

Toyota P0E7100 maps to SAE P0E71. The monitor finds an excessive difference between **requested and monitored generator MG1 torque**. Toyota describes a problem in torque execution or its monitoring, so the code is not standalone proof of a mechanically failed generator.

The listed areas include the inverter, transaxle, generator motor cable, control ECU and wiring; rear-motor components are additionally relevant on 4WD. One-trip logic commands the MIL and master warning. The page does not publish the exact torque difference or persistence time that triggers detection.

## Freeze frame and drive configuration guide the path

Toyota begins with diagnosis-related information and freeze frame. U11B300/U11B387 communication information takes its own diagnostic branch. If that information is absent but Emergency Shutdown Signal was ON, the chart redirects to P321E9F.

The remaining path checks the inverter connector, shutdown-signal circuit, generator high-voltage circuit and front-motor high-voltage circuit. It then distinguishes 2WD from 4WD: the latter needs an additional rear-motor high-voltage circuit check. Inverter assembly replacement is the endpoint after those required checks, rather than an immediate conclusion from the torque code.

## A model-appropriate confirmation

The source supplies separate normal-judgment patterns depending on whether battery-charge mode can be selected. Both require qualifying operation with the engine running before Motor Generator All Readiness is assessed. Those operating checks belong in a controlled professional diagnosis, not an owner attempt to reproduce a powertrain fault. A completed NORMAL result verifies recovery; INCOMPLETE requires another valid sequence. Preserve the full fault record and freeze frame, and follow the manufacturer's high-voltage precautions for every physical circuit inspection.

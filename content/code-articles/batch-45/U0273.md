# U0273: Ariya charging-status indicator loses its LIN connection

## Nissan identifies a charging indicator, not a headlamp unit

The catalog describes U0273 as lost communication with lighting-driver control module A. Nissan's Ariya **U0273-87** procedure instead identifies a communication error between the VCM and the **charging-status indicator over LIN**. This draft remains **needs-review** until the catalog-to-component naming is reconciled in applicable service information.

The monitor runs with the power switch on and requires the communication error for more than **four seconds**. The source lists the LIN line, charging-status indicator and VCM as possible causes. It does not identify the vehicle's main CAN bus as the circuit being tested for this code.

## The line is checked before replacing the controller

The factory diagnostic tree first checks continuity of the LIN connection between the VCM and charging-status indicator. A failed line check leads to repair of the affected wiring or connection.

When that check passes, the displayed procedure replaces the charging-status indicator and repeats confirmation. Only if U0273-87 returns does it direct VCM replacement. That order is important: the initial lost-message result does not independently condemn the VCM.

## Preserve the network and component identity

Record the reporting module, detailed suffix and indicator behavior before clearing. Nissan's preparation includes a 12-volt battery voltage of at least 11 V and an undisturbed shutdown interval. Automatic accessory wake-up from door activity can interrupt that interval.

The source names no additional protective action for this code, but that does not establish charging or driving suitability. Verify the exact Ariya configuration, resolve the lighting-driver terminology and use the manufacturer's charging-system and connector precautions for professional diagnosis.

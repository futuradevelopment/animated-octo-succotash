# P274D: Toyota transaxle temperature sensor C circuit high

## High circuit signal can look like very cold fluid

For the documented Corolla HV, P274D is the SAE equivalent of P274A15. Toyota detects an **open circuit or short to auxiliary-battery voltage in transmission-fluid temperature sensor C**. The sensor is a thermistor whose resistance changes with fluid temperature.

Toyota associates a Data List reading of **−40°C** with this open/high electrical condition. That display should not be accepted as the actual oil temperature. Conversely, the ground-short variant can display 215°C. The apparently opposite relationship between signal category and displayed temperature is why preserving the detailed code and scan data is useful.

## The factory flow distinguishes the fault location

The detection table specifies one trip, with both MIL and master warning. Potential areas include the sensor inside the hybrid transaxle, its wiring/connectors and the inverter with converter assembly.

Toyota checks both relevant connectors before evaluating the live temperature. A value that matches actual temperature takes a harness/connector repair branch. A persistent extreme value leads to the sensor inspection, followed by harness testing if the sensor passes. The published sensor resistance range is 1.3–94 kΩ under the specified test conditions. A failed sensor test directs transaxle replacement; normal sensor and harness results point to the inverter. Merely seeing P274D does not choose among these parts.

## Repair verification

After the cause is addressed, Toyota uses the stated ignition timing and Motor Generator All Readiness. A completed NORMAL judgment verifies recovery; clearing memory or obtaining INCOMPLETE does not. Professional testing must use the exact connector diagram and factory isolation precautions. The low-voltage sensor circuit is connected to equipment in a high-voltage hybrid powertrain.

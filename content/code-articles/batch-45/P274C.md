# P274C: Toyota transaxle temperature sensor C circuit low

## A ground-short indication, not measured overheating

Toyota maps P274A11 to SAE P274C. In this Corolla HV, the **transmission-fluid temperature sensor C circuit is shorted to ground**. Its thermistor resistance normally falls as fluid temperature rises, but an electrical short can produce a misleading temperature indication.

The factory Data List clue is particularly useful: Toyota associates a displayed Transaxle Oil Temperature of **215°C** with a short to ground. That extreme display is a circuit diagnostic clue, not evidence that the oil actually reached 215°C. The corresponding open/high circuit fault has a different detailed code and may display −40°C.

## Several components can produce the result

One-trip detection applies, with MIL and master-warning indications. The possible areas are wiring/connectors, the inverter with converter assembly, and the temperature sensor within the hybrid transaxle.

Toyota first checks the inverter and sensor connectors for secure engagement, contact damage and contamination. It then compares the scan temperature with the actual condition. If the extreme reading persists, the professional procedure checks the sensor and then the harness. The sensor test specifies 1.3–94 kΩ under the stated disconnected, ignition-off conditions. A failed sensor check leads to transaxle replacement; a harness defect leads to harness repair; passing sensor and harness checks leads to the inverter. Those outcomes are not interchangeable.

## Confirming the selected repair

Toyota's prescribed power-cycle timing and All Readiness result verify the monitor afterward. INCOMPLETE is not a pass. Save the full code and displayed temperature before clearing them. The connector and resistance tests require the exact factory connector information and hybrid safety precautions; owners should not access the inverter or transaxle connections to reproduce them.

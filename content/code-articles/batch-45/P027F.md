# P027F: Honda cold-start commanded-rich diagnosis and catalog mismatch

## The Honda-specific definition needs review

The catalog labels P027F as cold-start fuel-injection quantity A above expectation. Honda's cited extracts instead identify **cold-start air/fuel-ratio control system command rich**. This draft remains **needs-review** until that definition difference is reconciled. The source does not identify an injector A that is proven to deliver excess fuel.

Honda's monitor compares commanded mixture with the target during quick warm-up operation. It uses a stopped vehicle, released accelerator and closed throttle, with the stated coolant-temperature conditions. The advanced page specifies at least seven seconds of detection and two-drive-cycle MIL logic. Its numeric mixture-ratio convention should be verified before interpreting it as a physical air/fuel measurement.

## The repair branch requires cold verification

The troubleshooting procedure first waits for coolant temperature of 25°C or less, then uses the prescribed maintenance-mode cold start and checks for pending or confirmed P027F. If the code does not return, Honda treats the event as intermittent and reviews the original snapshot.

If it does return, the page directs review of authorized service information or substitution of a known-good PCM. The original PCM is replaced only if the fault disappears with that substitution. That is a conditional diagnostic result, not permission to replace a PCM from the initial code alone.

## Preserve the unresolved boundary

Record the cold-start conditions and full fault set before clearing. Publication or vehicle use requires checking the exact Honda calibration and the catalog terminology. The source's commanded-mixture description should not be silently rewritten as an injector-flow test. Software review, module substitution and hybrid maintenance-mode operation belong to a qualified repair facility.

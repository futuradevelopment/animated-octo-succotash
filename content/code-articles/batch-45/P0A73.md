# P0A73: Honda generator phase V current-sensor signal low

## The low value is a sensor output voltage

Honda defines P0A73 as **generator-motor phase V current low**. The PCU uses phase-current sensor signals to control generator output. Its specific monitor detects the V-phase current sensor output below **0.14 V for at least 290 milliseconds**. This is not a measured current limit in amperes and does not prove that a generator winding carries too little current.

The monitor runs continuously when the stated enable condition is met, including 12-volt supply of at least 8 V. Honda lists an internal PCU failure as a possible cause, while explicitly noting that its possible-cause list is not exhaustive.

## Pending and confirmed faults have different significance

The advanced diagnostic page specifies two drive cycles. A first qualifying failure stores a pending DTC in the motor control module. If the condition returns in the next qualifying cycle, the MIL illuminates and confirmed code and freeze data are stored. The monitor table also identifies the POWER SYSTEM indication.

The page documents detection and clearing behavior, not a step-by-step component replacement decision. Its possible-cause entry should therefore not be presented as a factory instruction to replace the PCU without the applicable troubleshooting procedure. Other phase-current codes also require their own signal-channel identification.

## What the evidence supports

Preserve pending/confirmed status, voltage-related data and the complete scan record before clearing. Honda states that the MIL can clear after three consecutive qualifying trips without recurrence, which is different from merely deleting the code with a scanner. Match this third-generation Insight extract to VIN-specific information. Any physical access to the PCU or generator circuits requires trained hybrid personnel and the manufacturer's electric-powertrain precautions.

# P0E35: Toyota pre-boost voltage sensor intermittent indication

## VL is the voltage before boosting

For the cited Corolla HV, P0E35 maps to Toyota P0E311F. The motor generator control ECU monitors **pre-boost high voltage, VL**, through a sensor in the boost converter. This variant detects the sensor signal stuck low or high while P0C7917, P0E5717, P0D3319, P1C5D19, P1C5F19 or P1C5E19 is stored.

VL must not be confused with the separate boosted-voltage VH measurement. Neither label turns this code into a direct diagnosis of the auxiliary battery. The detailed suffix and companion faults identify which measurement and detection context apply.

## The source requires a broader code check

The individual intermittent row uses one-trip logic without directly commanding the MIL or master warning. Other stored faults may still create warnings. Toyota withholds the precise sensor thresholds and monitor duration.

This procedure specifically warns that positive or negative battery-contactor circuit faults P0AD915 and P0ADD15, or high-voltage power-resource fault P1C8449, can accompany the underlying problem. Those listed faults are diagnosed first, followed by an attempt to reproduce the symptoms. The actual flow checks both Hybrid Control and Motor Generator trouble codes and sends relevant results to their system charts. Only the branch without the listed competing faults reaches inverter with converter assembly replacement.

## Confirmation after the cause is corrected

Toyota checks the result with its specified ignition-off/READY timing and Motor Generator All Readiness. INCOMPLETE means the judgment has not finished, rather than that the fault is cured. Preserve the complete scan record before clearing. Contactors, boost converters and inverter circuits require professional high-voltage procedures; this description is not an instruction to access them.

# P030A: Ariya compares wired and CAN power-switch signals

## Nissan compares two versions of the same request

The Ariya front-inverter procedure uses **P030A-62** when the hardwired power-switch signal differs from the power-switch information received over CAN. Detection occurs at inverter start or in READY, with a stated delay within two seconds.

Although the catalog calls the base code an ignition A control circuit/open fault, this Nissan suffix is a signal-comparison diagnosis. On this electric vehicle, “ignition” does not direct the technician to spark plugs or ignition coils. An open wire is only one possible explanation for disagreement between the two inputs.

## Communication is checked before the inverter

Nissan's repair chart starts with CAN communication, then checks the front-inverter connector seating and terminals for water, corrosion or damage. The hardwired power-switch supply is checked against its specified **9–16 V** range.

If that supply is wrong, the chart investigates the path through the IPDM E/R, wiring continuity, a short to ground and the relevant power-switch supply fuse. If the earlier checks pass, it reconnects the inverter and repeats the confirmation. Inverter replacement is the outcome only when the detailed code persists in that final branch.

## Preserve the suffix and wake-up conditions

Record P030A-62, the reporting module and any CAN faults before clearing. Nissan requires its shutdown interval between confirmation attempts and warns that door or lock activity can wake automatic accessory power. Repeated scans without respecting that state sequence may not reproduce the intended check.

This explanation is limited to the cited Ariya front-inverter procedure. A trained EV technician should use VIN-specific wiring information and the manufacturer's precautions for inverter access or replacement.

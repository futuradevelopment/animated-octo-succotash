# P0A90: Toyota drive motor A performance and magnetic-force monitoring

## What this Toyota performance monitor detects

Toyota maps P0A9000 to SAE P0A90. In the cited Corolla HV, the motor generator control ECU detects a **reduction in the magnetic force of MG2**, drive motor A. Its monitor description includes demagnetization or a same-phase short-circuit condition. That describes the monitored performance problem; it does not independently establish that the rotor magnets are the failed part.

Toyota lists several possible areas: the hybrid transaxle, motor cable, inverter, low-voltage connections and hybrid vehicle control ECU. The one-trip fault commands the MIL and master warning. Exact performance thresholds and detection duration are not published.

## Freeze-frame information changes the diagnostic route

The procedure first reads diagnosis-related information and freeze frame. U11B300/U11B387 communication information redirects diagnosis to its own chart. If that information is absent but Emergency Shutdown Signal was ON, Toyota redirects to P321E9F. These branches must be considered before condemning MG2.

Controlled operating checks then distinguish P0A9000/P0BFF1D from other newly reported faults. The remaining path examines the inverter connector, shutdown-signal circuit and motor high-voltage circuit. Only after those checks are normal does Toyota direct replacement of the hybrid transaxle assembly. A loose or damaged connector has its own correction branch earlier in the flow.

## Confirmation and workshop limits

Toyota's final normal-judgment pattern requires qualifying vehicle operation followed by All Readiness. A cleared warning or an INCOMPLETE result is not equivalent to a completed NORMAL judgment. Keep the original fault set and freeze frame intact for diagnosis. The operating tests and high-voltage circuit inspections require a qualified hybrid workshop; this performance code is not a reason for an owner to reproduce acceleration tests or probe motor cables.

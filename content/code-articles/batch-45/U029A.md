# U029A: RAV4 cannot receive battery sensor module messages

## The sensor sends battery information to hybrid control

For the specified 2020 RAV4 HV, Toyota documents **U029A87** when the hybrid control ECU cannot correctly receive serial messages from the battery voltage sensor. That sensor reports battery voltage, current, temperature and cooling-fan frequency. Toyota describes this communication as one-way: the control ECU does not send messages back to the sensor.

This matters because a missing-message code does not prove a failed control ECU or justify applying generic CAN resistance rules. The source identifies the hybrid control ECU, battery voltage sensor and wiring/connectors as possible areas. One-trip detection commands the MIL and master warning.

## Connectors and supply come before replacement

Toyota first records the complete hybrid fault set and freeze frame; other codes send diagnosis to their relevant charts. It then checks intermediate connectors AN2 and NN11 for engagement, damage and water or foreign material.

The sensor supply must meet the specified 11–14 V range in the professional test. Toyota explicitly calls for checking fuse seating, connector and harness condition even if a single voltage reading is normal, because the supply fault may be intermittent. Further stages test the serial harness and then the control ECU's signal circuit. Only after those results does the flow select sensor replacement or hybrid-control-ECU replacement.

## Confirming communication recovery

The factory sequence includes an ignition-off wait and at least two minutes at ignition ON before Hybrid Control All Readiness. NORMAL is a completed pass; INCOMPLETE requires another qualifying sequence. This source is narrowly scoped to the listed June–August 2020 production range, 2WD and nickel-metal-hydride battery. Professional high-voltage precautions still apply when accessing its low-voltage battery connectors; the article does not provide owner probing instructions.

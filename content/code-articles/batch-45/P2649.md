# P2649: Honda VTEC high return can result from an open circuit

## A high return does not automatically mean a power short

Honda defines P2649 as a **rocker-arm oil-control solenoid circuit high-voltage** fault. The command is low or off, but the return remains high for at least **two seconds**. The advanced page specifies continuous monitoring with auxiliary voltage of at least 10 V and one-drive-cycle MIL behavior.

Its possible causes include an open VTS circuit, a solenoid fault, an open solenoid ground and a PCM problem. The word “high” describes the observed return state; assuming a short to battery voltage would miss the open-circuit branches in this procedure.

## The diagnostic order narrows the electrical cause

Honda first runs the warmed-engine HDS VTEC test. A normal result is treated as intermittent, with connector and snapshot review. A reproduced failure leads to a disconnected solenoid resistance measurement with the vehicle off.

The specified room-temperature resistance is **13.9–16.9 ohms**. A failed resistance check leads toward oil-control-valve replacement. If resistance is correct, the chart checks the solenoid ground path to G102 and VTS signal continuity. An open circuit is repaired before considering a control-module fault.

When those circuits pass, the remaining branch uses authorized service information or a known-good PCM substitution. Replacement depends on the outcome, rather than the original code alone.

## Document the actual failed branch

Keep the original fault data and the test results that distinguish coil resistance, ground continuity and signal continuity. A “high circuit” scanner label supplies none of those results by itself.

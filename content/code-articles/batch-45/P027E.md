# P027E: Honda cold-start commanded-mixture monitor needs definition review

## The Honda description differs from the catalog label

This draft is marked **needs-review** because the catalog describes P027E as cold-start fuel-injection quantity A below expectation, while the Honda diagnostic extract calls it **cold-start air/fuel-ratio control command lean**. The source supports the Honda monitor described here; it does not establish a separately identified injector A or prove low delivered fuel quantity.

Honda compares the commanded mixture with its target while the quick warm-up system operates after a cold start. The enabled state includes a stopped vehicle, released accelerator, closed throttle and coolant within the source's specified temperature window. Detection lasts at least seven seconds and uses two drive cycles before confirmed MIL behavior.

## A command-monitor fault is not a measured-fuel verdict

The advanced page lists PCM internal-circuit failure as a possible cause. It provides a numeric comparison between commanded and target mixture, but the ratio convention and its lean/rich direction should be verified in current service information before using that value for diagnosis. No injector replacement test or fuel-pressure specification is supplied in this extract.

Honda's confirmation begins with coolant cooled to 25°C or less and a qualifying cold-start observation. That is different from assuming a warmed-up idle check exercises the same monitor.

## What remains to be verified

Before publication or repair use, resolve the catalog-to-Honda definition difference and match the exact model-year calibration. Preserve pending/confirmed status, coolant temperature and the original snapshot. The available source documents monitor logic and confirmation, not a full component-isolation repair chart. A technician should consult the applicable factory troubleshooting information before selecting a PCM, injector or fuel-system repair.

# P272C: Honda park-pawl driver high input during initial learning

## Initial learning exposes the high input

Honda defines P272C as a **park-pawl actuator driver circuit high-voltage** condition. The driver operates the mechanism that engages and releases Park. During initial learning, it monitors the MAU, MAV and MAW phase inputs.

The advanced diagnostic page detects an input of **4.22 V or greater for at least 64 milliseconds**, with auxiliary voltage of at least 10.5 V. This identifies an electrical input condition during the learning sequence; it does not measure how securely the pawl holds the vehicle.

## The warning behavior differs from an engine MIL

Honda specifies one-drive-cycle detection with the MIL off and the shift-position indicator blinking. An absent engine warning lamp therefore does not contradict this documented fault. The confirmation pattern switches the vehicle on for at least ten seconds so the relevant initialization can occur.

Possible causes include an open actuator-driver ground, a U-, V- or W-phase line shorted to power, and an internal driver fault. The high-input label does not distinguish those possibilities by itself.

## Keep electrical diagnosis separate from vehicle restraint

The source is an advanced monitor description. It provides thresholds, possible causes and confirmation behavior, but no complete replacement decision tree. Preserve the code and initialization circumstances, then use the applicable wiring and park-pawl troubleshooting procedure to determine the failed branch.

Because this system controls Park engagement, a trained technician should secure the vehicle using the manufacturer's service precautions before testing. Do not force the actuator or treat an extinguished indicator as proof that the parking mechanism is reliable. Verify VIN-specific applicability for this third-generation Insight extract before applying its numerical limits.

# P04F1: Honda separates low purge flow from a valve stuck open

## A missing pulse starts a two-stage diagnosis

Honda's P04F1 means **EVAP system low purge flow**. The first check expects purge-valve pulses to appear in the fuel-tank pressure signal. Missing pulses can indicate inadequate flow or a valve stuck open, so the controller performs another check after the engine stops.

During that second check, a pressure movement from vacuum toward atmospheric pressure supports the separate stuck-open diagnosis. Little pressure fluctuation instead supports P04F1. The advanced page specifies leak-check-module pressure output below **0.2 kPa for at least ten seconds**, with two-drive-cycle MIL logic.

## The factory chart investigates the path

Honda's troubleshooting starts with its HDS function test. A normal result sends attention to intermittent connections and the recorded event. A failed result leads to inspection of the purge line between the throttle body and canister for incorrect installation, blockage or damage.

Further prescribed tests distinguish a purge-valve problem from restricted plumbing, an unresponsive fuel-tank pressure sensor, a blocked port and a leak-check-module problem. Those branches matter because the same low-flow result can arise without the purge valve being the failed part. The source includes tightly limited vacuum tests; these should be performed with the specified equipment and limits by a trained technician.

## Preserve the operating context

The monitor requires a warmed engine, a period of low load and a stabilized period after engine shutdown. Record those conditions and the complete EVAP fault set before clearing anything. A fuel-cap replacement is not established by this purge-flow code. Use the applicable Insight procedure and VIN-specific information to verify which branch actually fails before selecting a component.

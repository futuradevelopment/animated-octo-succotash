# P0C02: Toyota rear-motor current does not follow its command

## A commanded-current mismatch at low speed

Toyota maps P0C021D to SAE P0C02. The documented Corolla HV monitor detects that **rear-motor current does not flow as commanded**, with detection occurring while stopped or at low speed. Rear motor MGR is drive motor B. This is a system-performance result, not a specific diagnosis of a bad current sensor.

Toyota lists a broad group of possible areas, including the inverter, rear motor assembly, motor cables, hybrid control ECU and connecting circuits. It also warns that a problem arising after cable disconnection/reconnection warrants checking that work. One-trip detection applies, with MIL and master-warning indications.

## Related information narrows the repair

The first procedure branch sends a P0A9100 result to the rear-motor performance chart. Next, diagnosis-related communication information U11B300/U11B387 or an ON Emergency Shutdown Signal can redirect the investigation to communication or P321E9F diagnosis.

If those branches do not apply, Toyota checks the inverter connector, shutdown-signal circuit, rear-motor high-voltage circuit, generator high-voltage circuit and front-motor high-voltage circuit. Inverter replacement is the endpoint only after the preceding inspections are normal. The presence of rear-motor wording therefore does not justify skipping other circuits that the manufacturer includes.

## Verifying the current-control monitor

Toyota's confirmation uses repeated controlled starts and low-speed operation followed by All Readiness. A completed NORMAL judgment verifies recovery; an INCOMPLETE result does not. The exact malfunction threshold is not published, so a generic current number should not be presented as Toyota's limit. Save freeze frame and the full code set before clearing, and leave operating tests and high-voltage inspections to a qualified hybrid workshop.

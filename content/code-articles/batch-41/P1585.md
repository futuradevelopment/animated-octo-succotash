# P1585: Cadillac cruise-inhibit output voltage conflicts with its command

The 2000 Cadillac Eldorado P1585 procedure concerns the PCM output that controls cruise inhibition. An output-driver module supplies a ground path when commanded on and monitors whether the circuit's electrical state agrees with that command. The fault is an improper output condition, not simply the fact that cruise control was cancelled.

## Both commanded states provide evidence

The diagnostic runs with the engine operating and system voltage between 8 and 16 V. An improper voltage on the cruise-inhibit output must persist for at least ten seconds. GM illustrates the mismatch as low voltage when commanded off or high voltage when commanded on.

That distinction prevents an isolated voltage observation from being interpreted without the corresponding command. It also separates the circuit fault from an information code describing a legitimate reason to inhibit cruise.

## Supply and unwanted voltage are separate checks

The test description discusses expected ignition-feed voltage with the PCM disconnected and a separate check for a short to voltage. Those are professional circuit-test distinctions, not permission to disconnect or jumper an unidentified cruise-control wire. The actual wiring and connector procedure must match the vehicle.

The PCM stores failure-record conditions without requesting the malfunction lamp. A lack of an engine-warning indication therefore does not resolve an intermittent output fault. Review the recorded command and operating conditions before a replacement decision. This source does not establish that the cruise module or PCM is defective from P1585 alone.

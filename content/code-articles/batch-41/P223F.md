# P223F: GM derives bank 2 sensor-element temperature from reference resistance

GM's P223F monitor in 24OBDG03B Part 1 evaluates the reference-cell resistance of the bank 2 wide-range air/fuel sensor. The controller converts that resistance into sensor-element temperature using its released sensor specification. This inferred temperature is not an exhaust-gas or engine-coolant temperature reading.

## The resistance test has a temperature interpretation

The listed failure boundaries are below 700 °C or above 1,000 °C for the converted reference-cell temperature. The decision requires 128 failed samples out of 160, sampled every 25 ms. A numerical temperature limit in this row consequently describes the controller's resistance-based calculation, not a target for externally heating a sensor.

The source identifies the non-E80 Continental ATIC142 implementation. It does not establish that the same conversion or limits apply to every vehicle carrying the generic code. A resistance measurement interpreted with a different sensor specification could lead to the wrong conclusion.

## Warmup and valid electronics are essential

The electronics must be ready and report valid measurement status, with heater warmup complete and an additional delay exceeding 20 seconds. The specified bank 2 heater faults must be absent. The row lists run or auto-stop among its operating conditions.

These enables separate an eligible resistance-range failure from a sensor that has simply not reached its monitored operating state. GM assigns Type B, two-trip indication to this entry. Diagnosis should establish the correct sensor and controller strategy and follow vehicle-specific instructions; the summary supplies neither a connector-level resistance test nor a reason to replace an oxygen sensor solely because this code is stored.

# P0905: Select-stroke performance depends on the sensor transfer curve

## What the range/performance description means here

Toyota's MR2 sequential-manual P0905 page concerns the select stroke sensor reporting a value outside its expected standard. This sensor belongs to the gear-shift actuator system. The listed trouble areas are the sensor, its circuit and the transmission control ECU. The page does not give a universal in-vehicle signal-voltage threshold for setting the code.

The first diagnostic step checks the harness and connectors between the sensor and ECU for open or short circuits. The following component test examines output voltage at specified sensor angles. A circuit that passes continuity is therefore only one part of the investigation: the sensor must also produce the correct position-dependent response.

## Test voltage belongs to a defined setup

The component table specifies a 4.5-volt test supply and two angular positions. Output is high at 44.8 degrees and low at 135.5 degrees; the page also provides a supply-adjusted formula. Those are bench-test relationships, not permission to connect battery voltage to the installed sensor. A technician must use the actual connector orientation and complete removal procedure.

## Source-review limitation

The final reproduced step is headed as initial learning of the transmission ECU, but its explanatory sentence refers to checking after ECU replacement before another replacement branch. That sequence is ambiguous. This article therefore needs review, and the current Toyota procedure should resolve the learning/replacement order before a controller is condemned.

Preserve freeze-frame data and the failed circuit or transfer-curve result. Establishing which part of the measurement chain is wrong provides stronger repair evidence than repeating learning or replacing the ECU from the code label alone.

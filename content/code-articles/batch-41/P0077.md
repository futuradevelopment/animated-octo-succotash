# P0077: Excess bank 1 current during a very small duty command

## The command is small, but the current is not

For this Subaru application, P0077 identifies an electrical inconsistency in the bank 1 oil switching solenoid circuit. The factory description calls it a short-circuit diagnosis: current remains large even though output duty is small. It does not mean the intake valves have necessarily stayed in their high-lift position.

The abnormality figure defines the relationship precisely. Duty below 7 percent and control current of at least 0.465 ampere must coexist for 2,000 milliseconds. The battery enable threshold is 10.9 volts. Diagnosis runs continuously when enabled, and the stated MIL response follows qualification of the malfunction.

## Keep the low-command evidence

A captured current value is useful only alongside the duty command. Elevated current while the controller requests normal operation is not the same observation as substantial current at less than seven percent duty. Preserve both values and the electrical supply condition before clearing the fault. A circuit inspection should follow the bank-specific wiring and driver procedure; the monitoring table alone does not distinguish a harness short from an actuator or controller problem.

## Recovery uses tracking accuracy

For a normality judgment, Subaru requires the absolute difference between target and actual solenoid current to fall below 0.08 ampere for 2,000 milliseconds. The normality table here does not include the minimum target-current condition printed for the companion low-current diagnosis. Do not silently import that extra condition from a nearby code.

After repair, confirm controlled current tracks its command within the documented test conditions. Avoid bypassing the driver or powering the valve directly as a substitute for a commanded-system check. This source establishes the diagnostic comparison, not a universal bench-test specification.

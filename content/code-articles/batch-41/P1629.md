# P1629: GM does not receive the correct fuel-enable signal during starting

The cited 1996 Buick Riviera procedure describes P1629 in a PASS-Key II theft-deterrent system. After recognizing the proper key-resistor input, the theft-deterrent module supplies a fuel-enable signal. The PCM checks that signal during cranking before allowing fuel delivery.

## Separate cranking from authorization to run

The diagnostic requires a starting attempt, absence of P1626 and an incorrect fuel-enable signal lasting longer than two seconds. The source states that the engine will not start while that condition remains. It also explains that a problem affecting inputs to the theft-deterrent module can disable the starter itself.

Those are different outcomes: an engine that cranks without authorization to fuel is not the same electrical complaint as a starter that does not operate. P1629's recorded circumstances help identify which part of that distinction applies.

## Preserve the record for the correct system diagnosis

GM stores failure-record information without requesting the malfunction lamp. The diagnostic aids include connection and harness faults between the PCM and theft-deterrent module, and recommend reviewing the recorded mileage to understand intermittent recurrence.

The code does not prove that the key, theft-deterrent module or PCM must be replaced. Confirm the exact PASS-Key system and use authorized professional diagnosis and any required programming. This description does not provide a bypass method; preserving the intended authorization function is part of a correct repair. A code-clear operation alone does not restore a missing or incorrect enable signal.

# P0543: GM detects an open intake-heater circuit through biased feedback

For the 2001 Chevrolet K 2500 6.6-litre diesel, the cited P0543 procedure describes two biased diagnostic circuits associated with the intake-air heater. The expected circuit state changes when the relay is switched: low when off and high when on. The monitor uses that relationship to identify an open-circuit condition.

## An intermediate voltage has meaning in the off state

The listed fault pattern includes heater-line voltage between 3.8 and 8.1 V with the relay off, together with a relay-on reading within 0.5 V below battery voltage. The latter describes proximity to battery voltage; it does not mean the heater line should measure less than 0.5 V.

Command state is therefore inseparable from the voltage observation. An intermediate biased reading with the relay off has a different meaning from the same number during a powered test. The code does not simply declare that the intake air failed to become warm.

## Verify that the diagnostic was enabled

The system-voltage window is 10 to 18 V. The source permits the cold running branch below 23 °C intake-air temperature, or an ignition-on, engine-off branch exceeding three seconds with coolant below 49 °C. These are alternative operating branches.

The procedure describes malfunction-lamp illumination after a second consecutive failing cycle. It does not establish that the heater element alone is defective. Confirm the circuit layout and use the matching professional diagnostic procedure; a biased monitoring circuit should not be bypassed or loaded using an improvised test.

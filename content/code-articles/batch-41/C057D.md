# C057D: GM temperature sensor B fails a change-between-samples test

C057D is the intermittent or erratic member of GM's second EBCM temperature-sensor family in 24OBDG03A Part 1. Its evidence is the relationship between consecutive temperature samples, not a confirmed loss of a brake-booster component.

## A valid input can still change implausibly

For this monitor, the diode-temperature input has already passed its input-validation condition and the module's power switch is on. The controller then compares the current measured temperature with the value saved during the preceding loop. A change exceeding 20 °C in absolute magnitude is the listed failure boundary. The row gives 200 ms for fault maturation.

Input validation and an erratic-signal test serve different purposes. Acceptance of a reading for processing does not prove that its movement relative to the previous reading is believable. Conversely, the 200 ms entry is not permission to assume a particular sampling frequency: the table does not state one for this comparison.

## Separate the family members

The adjacent second-channel rows use voltage boundaries for low or high input. C057D instead concerns a temperature step, so applying an adjacent code's voltage limit as its sole pass criterion would miss what this row measures. The controller lists circuit-board, conversion and microcontroller faults among its possibilities, alongside an out-of-range temperature.

Those possibilities are diagnostic starting points, not a component-replacement verdict. The published table contains no external connector measurement procedure and no instruction for accessing internal brake electronics. Correct module identification and the vehicle-specific professional procedure remain necessary. GM assigns a Type B indication to this documented monitor; the code alone cannot establish that the vehicle's braking functions are available.

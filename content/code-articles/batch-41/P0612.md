# P0612: GM injection-module relay feedback does not match its command

The 2005 Chevrolet Silverado 6.6-litre diesel procedure explicitly identifies P0612 as the fuel-injector control-module relay-control circuit. Its circuit description calls this the ignition-relay control path. Keeping those labels together helps identify the actual system rather than assuming an unrelated relay from the word ignition alone.

## The controller compares feedback with requested state

With ignition on, the ECM continuously monitors the circuit. The listed setting condition is feedback voltage disagreeing with the output state for more than one second. The description also calls attention to excessive voltage on the control path.

This is a command-versus-feedback diagnosis. It does not directly establish an injector-coil failure, rail-pressure problem or failed injection module. A relay-control fault and the loads supplied by that relay are related but distinct parts of the system.

## Starting behavior can help classify an intermittent event

The diagnostic aids associate an engine that still starts with an intermittent short-to-power condition on this control circuit. That observation should guide professional investigation in the exact application, rather than becoming a universal conclusion for every vehicle reporting P0612.

The procedure stores failure information on the first failed cycle and requests the malfunction lamp on a second consecutive failing ignition cycle, updating freeze-frame information then. Preserve those records before clearing the fault. Confirm the relay circuit and applicable service procedure before testing high-current injection-system electronics; the code alone does not authorize replacing the ECM or FICM.

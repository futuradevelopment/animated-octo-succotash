# P1652: Cadillac monitors the suspension lift-and-dive control output

The P1652 meaning in the 2000 Cadillac Eldorado factory procedure is the suspension lift-and-dive control output. This matches the chassis-pitch context of the catalog entry. It must not be combined with older GM procedures that reuse the same number for a vehicle-speed output circuit.

## Identify the monitored output before diagnosing

The PCM uses output-driver modules to control several functions. Each driver supplies a ground path when its controlled output is commanded on, and the module can diagnose individual output circuits. For P1652, the relevant output is the suspension lift/dive function.

The monitor requires the engine to be running and system voltage between 8 and 16 V. An electrical state inconsistent with the commanded driver state must remain for at least ten seconds. The code is consequently an output-circuit result; it does not directly measure body movement or prove that the vehicle pitched excessively.

## A stored record can exist without a malfunction lamp

The source says the PCM retains failure-record conditions without requesting the malfunction indicator lamp. It also gives a separate history-clearing policy. Those features make the saved operating context important when the circuit appears normal during a later inspection.

The procedure's summary does not provide a universal connector location or establish which module or wire failed. Confirm the exact Cadillac controller and suspension equipment, then follow its professional electrical diagnosis. Using a same-number procedure from a different GM application could lead to testing an unrelated circuit.

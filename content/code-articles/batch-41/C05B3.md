# C05B3: GM brake-control temperature channel C has low feedback

In GM's 24OBDG03A Part 1, C05B3 belongs to the third internal temperature-sensor channel of the electronic brake control module. Its low-input description concerns diode-feedback voltage. It does not directly report a particular coolant, brake-fluid or ambient temperature.

## Read the electrical boundary correctly

The fault criterion is feedback below 0.7 V, with 60 ms listed for maturation. The monitor requires the power switch to be on and the diode-temperature input-validation condition to be true. The surrounding row describes a monitored temperature range from minus 40 to 150 °C, but gives no voltage-to-temperature conversion for this code.

That missing conversion matters. The word low should not be translated into an unsupported claim that the physical assembly is cold. Nor should the voltage be treated as a target to apply to an unidentified external connector. These are internal monitor parameters within the stated EBCM document.

## What this result can narrow

The code directs attention to the low-feedback branch, rather than the third channel's high-input, abrupt-change or correlation branches. GM's listed possibilities include temperature outside the intended range, a circuit-board defect, analogue-to-digital conversion trouble and a microcontroller problem. The row does not distinguish among those possibilities by itself.

An appropriate diagnosis consequently starts with confirmation that this exact module strategy applies, then follows its service information. The summary is not an internal-controller repair guide and does not justify replacing a separately named booster sensor without that identification. It classifies the fault indication as Type B. A code reading or its subsequent absence cannot independently demonstrate that braking performance has been restored.

# C05B6: GM checks temperature-channel C agreement with the controller die

GM describes C05B6 as a correlation failure for the third EBCM temperature-sensor channel in 24OBDG03A Part 1. The comparison uses both the channel's measured temperature and the microcontroller die temperature. Neither value can be interpreted as the entire test on its own.

## The amount of disagreement matters

The source sets the failure boundary at an absolute difference of at least 50 °C, with a 60 ms maturation entry. Power must be switched on and the diode-sensor input-validation condition must be true. These conditions describe when the controller can judge the relationship between the two readings.

A technician examining this fault needs the relationship, not merely confirmation that one displayed temperature falls inside an expected everyday range. The code does not state which of the two observations is wrong. It also does not, by itself, establish an excessive physical temperature in a named external brake component.

## Use the correct monitor within the family

The third channel has separate low-voltage, high-voltage and erratic-signal entries. Passing one of those comparisons does not necessarily resolve a disagreement with the die-temperature measurement. This explains why substituting a neighboring code's electrical limit for the C05B6 correlation criterion can produce a misleading conclusion.

The table lists potential board, analogue-conversion and microcontroller faults, as well as a temperature-range problem. It gives no internal repair procedure and no basis for choosing a replacement from the code name alone. Exact EBCM and calibration identification must precede the applicable professional diagnostic routine. GM classifies this row's indication as Type B; a code-clear operation is not an independent check of brake-system function.

# P0083: Bank 2 circuit-high diagnosis compares current with duty

## Identify what the controller actually observed

The cited Subaru P0083 description concerns the bank 2 oil switching solenoid's electrical behavior. Its short-circuit monitor looks for control current at least 0.465 ampere while output duty is below 7 percent. The combination must persist for 2,000 milliseconds; a current value without its associated command cannot establish the condition.

The diagnosis is continuous with battery voltage at least 10.9 volts. Subaru specifies MIL illumination once the malfunction is detected. Those details help distinguish a presently reproducible fault from a historical event, but they do not name a failed component. A controlled-circuit short, an actuator electrical problem and a driver fault require the vehicle's circuit checks to separate them.

## Avoid confusing two kinds of feedback

This code uses electrical current, rather than the diagnostic oil-pressure switch used for valve-lift performance. A switch that reports an unexpected lift mode therefore does not directly prove the high-current condition. Keep the current-control investigation attached to bank 2 and use the correct connector identification; the bank 1 companion code has its own location even though its monitoring strategy is similar.

## Check tracking after the repair

The normality criterion is an absolute difference below 0.08 ampere between target and actual solenoid current, sustained for 2,000 milliseconds. In this source, that recovery table has no additional minimum target-current line. A technician should verify stable tracking through the specified controller test rather than add a condition from a different DTC.

Save the original command/current relationship, inspect the circuit using approved electrical methods, and repeat an enabled evaluation after repair. The code alone does not justify opening the engine or replacing a valve-lift mechanism.

# P2726: Pressure-control E leads to N233 and a defined controller branch

## The fifth regulator has a different component identifier

Volkswagen maps P2726, pressure-control solenoid E intermittent, to pressure regulating valve 5, N233. The preceding regulators use N215 through N218, so assuming a consecutive component number would point to the wrong part. The factory mapping is the bridge between the generic DTC letter and the actual transmission circuit.

N233 is included in the common regulator-valve test. After checking the 16-pin connector for corrosion or water ingress, the technician measures the valve using its designated terminal pairings. The resistance criterion is 6–8 ohms at approximately 20°C, and the manual notes increasing resistance at higher temperatures.

## A module decision requires the wiring branch

When valve resistance is acceptable, the procedure continues to the corresponding wiring at the TCM test interface. It specifies no more than 1.5 ohms for wire continuity and an open-circuit indication when checking for unintended connections between wires. Only after no wiring malfunction is found does this chart reach its TCM replacement branch.

The referenced replacement procedure preserves the original calibration identification, checks the replacement's identity, and requires coding and readiness work. Substituting a controller without completing those requirements is not the documented repair.

## Preserve evidence of the intermittent condition

The P2726 row does not publish the elapsed failure time or current threshold that set the code. Record the operating circumstances and any connector or harness defect before disturbing it. A qualified technician should use the specified isolated test setup and verify the repaired circuit afterward. The stored code identifies the N233 investigation; it does not prove that N233 or the TCM must be replaced.

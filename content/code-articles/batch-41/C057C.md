# C057C: GM compares brake-control sensor B with microcontroller temperature

The range/performance wording associated with C057C becomes more specific in GM's 24OBDG03A Part 1: the second EBCM temperature channel is compared with the microcontroller's own die-temperature measurement. This is a correlation test between two observations.

## Why a reasonable-looking value can fail

GM specifies an absolute disagreement of at least 50 °C between the measured channel temperature and the microcontroller temperature. The row lists 60 ms for maturation. The power switch must be on and the diode-temperature input-validation condition must be true before this comparison is relevant.

A channel can therefore produce a number that looks ordinary on its own while still disagreeing excessively with the second measurement. Equally, this criterion does not require proof that both measurements are too hot. It evaluates their separation. The distinction matters when interpreting a saved fault alongside a later, apparently normal temperature display.

## Do not substitute a neighboring comparison

The same table contains low-input, high-input and erratic checks for this sensor family. Those checks answer different questions. A voltage inside an adjacent row's limits does not, by itself, satisfy the 50-degree correlation criterion. The source also contains other die-temperature comparisons with different thresholds; they should not be transferred to C057C merely because both descriptions mention temperature.

The listed possibilities include board, conversion and microcontroller problems as well as temperature-range issues. The summary neither ranks those possibilities nor provides an internal repair method. A professional diagnosis needs the applicable EBCM procedure and calibration. GM records a Type B indication for this row; it is not a brake-system functionality test or a reason to dismantle the controller.

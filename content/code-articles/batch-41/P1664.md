# P1664: GM skip-shift indicator voltage fails to follow the lamp command

The 1996 Pontiac Firebird P1664 procedure concerns the skip-shift lamp. Ignition voltage supplies the indicator, while the PCM illuminates it by grounding the control circuit. The controller monitors a fault line associated with that output driver.

## Test the command-response relationship

Above 600 rpm, an electrical state that disagrees with the driver command must persist for at least five seconds. The expected control voltage is low with the lamp commanded on and high when commanded off. Both states matter; seeing the lamp illuminate once does not establish that its off-state control is correct.

This is an indicator-circuit monitor. It does not directly assess whether the transmission's skip-shift mechanism moved or whether a driver selected the intended gear. A lamp-control code should therefore not be turned into a transmission-replacement recommendation.

## Intermittent history can guide the investigation

GM stores the code and failure-record conditions without requesting the malfunction indicator lamp. The diagnostic aids recommend comparing the recorded operating circumstances and pass/fail history when the condition cannot be reproduced immediately.

The test description specifically calls for exercising both lamp commands. It also says PCM failure is extremely unlikely after circuit and connection checks, keeping the controller from becoming the default suspect. Use the exact professional procedure for the identified vehicle and indicator circuit. An unlit malfunction lamp is consistent with this strategy and does not demonstrate that the skip-shift indicator's electrical problem has cleared.

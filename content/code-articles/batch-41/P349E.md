# P349E: GM evaluates cylinder 7 deactivation through pressure-pattern evidence

A cylinder-deactivation performance code need not be a direct report from a valve-position sensor. For P349E, GM's 24OBDG03B Part 1 describes filtered, normalized manifold pressure as evidence that cylinder 7's exhaust valve did not deactivate when commanded. The accompanying description says both intake and exhaust operation continue, defeating the intended skipped cycles.

## Count eligible opportunities

GM lists 22 failures within 25 opportunities and sampling every 90 crankshaft degrees. These are crank-angle observations, not a fixed number of elapsed seconds. Engine speed would affect elapsed time, so the table should not be turned into an invented universal time limit.

The firing fraction must be stable and no greater than 0.95. Air per cylinder must exceed 120 mg, transmission gear must exceed the listed calibration value, and the manifold-pressure/barometric-pressure branch requires a ratio from 0.30 to 0.95 or a zero firing fraction. This combination restricts when the pressure comparison has diagnostic meaning.

## A pressure result is not a parts verdict

The row's narrative describes pressure greater than a threshold, but its threshold cell uses a less-than expression. Because these disagree, the article is marked for source review. Neither direction is selected as a repair-test specification here.

This limitation does not erase the useful distinction between commanded deactivation and the pressure response that should follow. It does prevent a confident numerical pass/fail instruction from this table alone. Confirm the exact controller, calibration and corrected service procedure before interpreting the comparison. The source does not supply cylinder-location information or establish which mechanical or electrical part caused the observed behavior.

# P1826: Cadillac internal-mode-switch circuit C requires careful state interpretation

The 2005 Cadillac DeVille P1826 procedure identifies the transmission internal-mode-switch C circuit as high voltage. The switch is connected to the manual-valve mechanism and supplies four position inputs to the PCM: A, B, C and parity. An open contact reads high; a contact closed to ground reads low.

## A gear indication is a combination of inputs

The four electrical states tell the controller which selector position is present and influence both engine controls and shift patterns. A circuit-C fault therefore needs interpretation within the complete switch pattern. A high C input alone should not be assigned an invented selector position without the applicable state table.

The source's test description separates a problem inside the transmission from an external one, then distinguishes engine harness/PCM and transmission harness/switch branches. Those distinctions are useful before deciding which assembly requires investigation.

## The printed setting description is unresolved

The narrative says an intermediate D2-to-D1 state while moving causes the fault, whereas the setting-condition section says park indicated for two seconds. Those are not equivalent descriptions. This article is marked for source review and does not select one as the definitive trigger.

The document also describes maximum line pressure, a D4 shift pattern and frozen adaptations as default actions. Confirm the corrected controller-specific procedure before relying on those details or performing a test. The code does not prove that the entire transmission is mechanically defective; it identifies an electrical position-reporting problem whose exact published criterion needs clarification.

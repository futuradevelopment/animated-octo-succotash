# P0608: GM vehicle-speed output disagrees with its commanded electrical state

The cited GM P0608 procedure describes a vehicle-speed output created by switching a ground circuit at the same frequency as the controller's speed input. The controller monitors the output voltage and compares it with the requested driver state. This places the diagnostic downstream of the original vehicle-speed input.

## Input data and output integrity are different questions

The monitor runs above 400 rpm with ignition voltage greater than 6 V and below 18 V. It sets when commanded and actual output-circuit states disagree for at least five seconds. A plausible speed value elsewhere in diagnostic data therefore cannot, by itself, prove that this output circuit is functioning.

Conversely, the output fault is not sufficient evidence to replace the original speed sensor. The source's test concerns an electrical state relationship at the controller output, not a direct measurement of sensor accuracy or wheel rotation.

## Intermittent evidence can outlast the condition

The procedure records failure conditions and directs attention to intermittent electrical connections, including connector sealing and water intrusion. It distinguishes a current fault from a history record: the current state can clear when the condition disappears, while history retention follows the specified warmup-cycle policy.

That distinction makes saved failure information useful even if the output appears normal during a later inspection. Confirm the indexed vehicle's actual controller and circuit before professional testing. The source provides no universal destination, pin assignment or replacement verdict for every vehicle using P0608.

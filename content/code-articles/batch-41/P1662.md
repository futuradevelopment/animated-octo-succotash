# P1662: GM monitors the stepper-cruise inhibit driver for an electrical mismatch

The 1996 Buick Riviera procedure maps P1662 to output-driver module C, output 2, which controls the stepper-motor cruise system's inhibit circuit. The driver provides a ground path when commanded on and can diagnose its individual output. This specific circuit identity matters more than a general cruise-control complaint.

## A persistent improper voltage triggers the code

The listed conditions are ignition on and an improper voltage on that inhibit-control output for at least 30 seconds. The source is evaluating circuit behavior, not merely recording that the controller intentionally cancelled cruise because another condition required it.

A driver command and the corresponding circuit voltage must therefore be interpreted together. A voltage seen without its requested state does not reproduce the documented fault test. The procedure's output identification also prevents a same-number code from another GM controller being treated as interchangeable.

## The diagnostic branches separate load and wiring faults

The test description distinguishes expected ignition-feed voltage, a shorted load or short to supply, an output that opens during operation and a circuit short to voltage. Connector and harness intermittents are also considered. These are professional test distinctions, not a basis for bypassing the inhibit signal.

GM stores failure-record data without requesting the malfunction lamp. Review those conditions and confirm the exact cruise and PCM arrangement before testing. The code does not independently establish a defective cruise module, nor does clearing it verify that the monitored output responds correctly.

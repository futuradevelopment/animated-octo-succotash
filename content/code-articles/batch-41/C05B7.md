# C05B7: GM flags a sudden change in temperature channel C

An erratic-temperature code can be present even when the value seen during a later inspection looks believable. C05B7 illustrates that distinction: GM's 24OBDG03A Part 1 EBCM monitor compares the third channel's current temperature with its stored previous-loop value.

## The event is a step between readings

The listed fault boundary is an absolute temperature change greater than 20 °C. GM gives 200 ms as the maturation time. The comparison requires the power switch to be on and the diode-temperature input-validation condition to be true.

Because the source does not specify the interval between those two samples, it does not support converting this threshold into degrees per second. Likewise, the 200 ms maturation entry should not be assumed to be the sampling interval. Keeping these quantities separate avoids inventing a diagnostic rate from two different parts of the row.

## What a later stable display cannot show

The low and high members of the third-channel family examine feedback-voltage boundaries, while a correlation member compares temperature with the microcontroller die. C05B7 examines a different relationship: the change over successive observations. A present-time value alone cannot reconstruct that earlier relationship.

The summary identifies circuit-board, conversion, microcontroller and temperature-range problems as possible explanations. It does not determine the responsible part or provide an external probing test. Matching the vehicle's EBCM strategy and using its professional service procedure is essential before translating this code into repair work. The documented indication is Type B. Neither a momentarily stable number nor an erased fault proves that the brake system's functions have been verified.

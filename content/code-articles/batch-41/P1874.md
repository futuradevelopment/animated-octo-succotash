# P1874: GM stator-switch hot-mode verification needs corrected source criteria

The P1874 page for the 1996 Chevrolet Impala SS describes a torque-converter stator temperature switch that should close when sufficiently hot. The surrounding narrative concerns failure to report hot mode at a high transmission temperature. However, several printed details conflict, so this article retains a source-review flag.

## The circuit description still identifies the system

The switch is normally open, uses a single lead and grounds through the transmission cooler pipes. Its stated hot closure threshold is 164 °C. The PCM uses the resulting signal to decide whether cooling-related action is needed. These facts distinguish the switch from the separate continuously varying fluid-temperature sensor.

The diagnostic aids call attention to connector integrity and the cooler-pipe ground path. That is useful system context, but it does not by itself prove that a particular switch or wire failed.

## Do not silently repair the printed logic

Although the page is headed P1874, its explanatory paragraph names P1873. The narrative describes a missing hot indication at high temperature, while the setting-condition list prints fluid temperature below 140 °C. This article does not reverse that inequality, substitute the code number or offer the printed values as a reliable acceptance test.

The unresolved criteria require corrected service information for the actual controller. The page's no-lamp, shift-adaptation and default-hot-mode statements should likewise be verified before relying on them for this application. Until that clarification, the supported interpretation is limited to the stator-switch circuit and the need to reconcile its report with temperature evidence.

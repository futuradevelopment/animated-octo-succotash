# P1573: GM engine control stops receiving brake-controller serial data

In the 1996 Buick Riviera procedure, P1573 means the PCM has not received expected information from the electronic brake and traction-control module. The modules communicate over the UART serial-data circuit. This is a communication-path diagnosis, not a direct report that a wheel-speed sensor has failed.

## A short interruption can create a record

The listed setting interval is 0.5 second of PCM-to-brake-controller communication error. A connection can therefore fail briefly and appear normal during a later inspection. GM stores failure-record conditions without requesting the malfunction lamp and explicitly distinguishes those records from freeze-frame data.

The source recommends using the retained mileage and failure history to understand how often the event occurs. An unlit lamp or currently updating display cannot reconstruct whether data were available at the time of the stored fault.

## Establish whether the module can communicate

The test description first considers the brake controller's ability to transmit and whether its serial-data path is open. Diagnostic aids identify connections, an open or ground short in the data circuit, and harness damage as possible causes. Watching whether brake data stop updating can help a professional isolate an intermittent path problem.

The procedure does not make module replacement the first conclusion. Confirm the exact UART architecture and applicable wiring information before testing; later network systems may use different strategies. P1573 establishes missing expected communication in this application, not the failed component or the availability of brake-system functions.

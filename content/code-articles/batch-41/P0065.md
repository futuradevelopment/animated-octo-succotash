# P0065: Subaru air-assist diagnosis separates valve operation from restricted airflow

The 2002 Subaru Outback 2.5-litre procedure identifies P0065 as an air-assist injector-solenoid malfunction. The air-assist system is distinct from simply energizing a fuel injector. Subaru's diagnostic chart separates valve operation, bypass airflow and injector restriction instead of treating the code as an automatic injector-replacement instruction.

## A valve that operates does not prove the air path is clear

The chart first considers other stored faults, then checks whether the air-assist solenoid operates in the specified test mode. Subaru also permits operation through its Select Monitor valve-check function. An operating sound advances the investigation; it does not finish it.

The next branch examines the bypass hoses for damage or obstruction. Only after that does the chart consider an obstructed injector. This sequence explains why an electrical click can coexist with a performance problem: an actuator can move while the required air path remains restricted.

## Keep the symptoms and confirmation separate

The source lists irregular idle and stalling as possible symptoms and specifies two consecutive failing driving cycles for detection. Those symptoms support the complaint history, but neither uniquely identifies the air-assist system.

Professional diagnosis should use the exact vehicle's test mode and appropriate clean, safe airflow-inspection equipment. The older chart's mouth-blowing instruction is not reproduced as a recommended practice here. After a justified repair, Subaru requires the specified memory-clear and inspection modes. Erasing the code without confirming valve operation and airflow does not demonstrate that the original performance problem was resolved.

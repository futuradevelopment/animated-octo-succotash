# P0942: Hydraulic pressure behavior separates the MR2 pump branches

## More than one pressure failure can set the code

For the MR2 sequential transmission, P0942 concerns the hydraulic pressure unit. Toyota lists several qualifying behaviors: an excessively long pressure-changing period, pressure remaining below 35 bar without further increase, an implausibly rapid increase of at least 10 bar within 0.1 second, or no pressure change across a gear shift. These represent different observations; they should not all be described as a weak pump.

The possible causes include the accumulator pressure sensor, motor pump, accumulator, relay and fuse, electrical paths, and actuator hoses. A pressure-related code therefore still requires electrical and leakage checks.

## First distinguish a nonrunning pump from abnormal pressure

The chart begins with sequential-transmission fluid leakage, then uses the scan-tool motor-relay active test to check pump operation. The nonoperating branch checks the fuse, relay and power/ground wiring. The pressure branch reads accumulator pressure during pump operation and with the pump stopped, then observes its response to changing the selector.

The table expects pressure to rise by approximately 4–5 bar per second with the pump operating. It also describes pressure decay and a decrease during a shift. Capturing that sequence is more useful than recording one isolated pressure value.

## Treat the hydraulic unit as stored-energy equipment

Have a technician perform the active tests and any hydraulic work using Toyota's depressurization procedure. Do not loosen a hose to determine whether pressure exists. Preserve the failing pressure pattern and motor-command status before replacing the HPU. The controller is a later diagnostic branch after the preceding tests and verification of the assembly response.

# P2018: Runner-position diagnosis gives sensor supply faults priority

## An intermittent label still has a specific observed signal

The cited Mitsubishi engine-control procedure describes P2018 as an intermittent bank 1 intake-manifold-runner position-sensor circuit fault. Its detection row identifies an excessively low sensor voltage reaching the ECM while the engine idles. The row does not publish a numerical voltage threshold or a delay time, so those values must not be inferred from a neighboring DTC.

The source gives P06B0 priority when it accompanies P2018. This matters because diagnosing an individual position sensor before resolving its supply-related fault could lead to a replacement that leaves the real cause intact.

## Separate supply, return and signal

The diagnostic procedure first checks the sensor's approximately five-volt supply across its designated supply and return terminals. A separate measurement to chassis ground helps distinguish the supply path from the return path. Subsequent branches inspect ECM grounds, the sensor's ground connection and the input-signal circuit, including unwanted connections to power or ground.

Only after those checks does the procedure address an intermittent incident and reach its intake-manifold assembly replacement branch. A low input therefore does not immediately establish a failed manifold mechanism.

## Confirm with the documented operating conditions

The confirmation test requires more than 11 volts at idle and checks first-trip DTC information after ten seconds of idling. If the test has already been run, the source specifies an ignition-reset sequence before another attempt. Preserve the original codes and supply measurements before clearing evidence.

A technician should follow the matching connector drawings and isolation steps. The fail-safe description includes a runner motor switched off and changes to other engine-control functions, so secondary operating changes should be interpreted in that context rather than treated as unrelated component failures.

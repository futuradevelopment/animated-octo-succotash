# P1873: GM rejects a hot stator-switch report when transmission fluid is cool

P1873 in the 1996 Chevrolet Impala SS procedure concerns disagreement between the torque-converter stator temperature switch and the measured transmission-fluid temperature. The switch is normally open and closes at the documented hot threshold, pulling its signal to ground.

## The fault is an implausible hot indication

The procedure sets the code when the switch reports hot mode while fluid temperature is below 60 °C for five seconds, provided the listed temperature-sensor circuit faults are absent. The switch's stated closure threshold is 164 °C. The diagnostic is therefore looking for an inconsistency, not merely announcing that the transmission has become hot.

A low circuit signal in this context represents the switch's hot indication. It should not be confused with a low physical temperature measurement. Both the switch report and the separate fluid-temperature information matter to the comparison.

## The ground path is part of the design

GM describes a single-lead switch that grounds through the transmission cooler pipes. Its diagnostic aids specifically call for checking that ground path when the switch and external wiring are satisfactory. A conventional two-wire-sensor assumption would miss this feature.

The source classifies the fault as Type D, freezes shift-adaptation updates and does not request the malfunction lamp. Professional diagnosis should confirm the switch circuit and temperature evidence using the matching procedure. The code alone does not establish a defective switch, and lack of a warning lamp does not resolve the recorded plausibility failure.

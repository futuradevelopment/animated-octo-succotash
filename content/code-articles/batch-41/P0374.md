# P0374: GM diesel injection control loses its high-resolution timing reference

In the cited 2001 Chevrolet 6.6-litre diesel procedure, the ECM reproduces the crankshaft-position signal on an engine-speed circuit to the fuel-injection control module. P0374 concerns that received timing reference. The path from the original sensor through one controller to another matters when interpreting a no-pulse description.

## Why starting can be affected

During cranking, the injection module controls the injectors using the ECM's engine-speed signal. Once the engine is running, it monitors that signal together with injection requests. The source states that loss of the high-resolution signal can prevent starting.

The fault can set when the injection module receives injection requests without the crank-reference signal, or when the ECM-provided signal is invalid. Cranking or running enables the diagnostic. A no-start complaint is therefore relevant evidence, but the code alone does not prove that the original crankshaft sensor is defective.

## Distinguish the signal's origin from its destination

The sensor, ECM processing, inter-module circuit and receiving module are different parts of the described route. The service summary does not authorize replacing one of them without investigating the actual signal path. The injection module also uses the reference for injection-current control and high-voltage recharge, which explains why it needs valid timing information.

The procedure describes a second consecutive failure cycle for malfunction-lamp illumination and records operating conditions. Preserve that information and confirm the exact controller arrangement before professional electrical testing. High-voltage injection electronics require the applicable equipment and precautions; an ordinary code reading does not establish a safe probing method.

# P1200: GM injector-driver diagnostics identify an electrical control fault

The 1996 Buick Riviera procedure describes P1200 as an injector-circuit fault detected by the PCM's general FET driver. That driver can identify an electrical malfunction involving an injector ignition feed or control circuit. The code should not be confused with unrelated meanings assigned to the same number by other controllers.

## Locate the affected circuit before selecting a part

The setting condition is an incorrect injector-control voltage persisting for more than five seconds. This is electrical evidence; it does not directly measure fuel spray, leakage or delivered fuel quantity. A misfire may help identify the affected cylinder without establishing the exact electrical cause.

GM specifically points to misfire-history counters when P0300 is also present. A cylinder with unusually high recorded activity can focus the injector-circuit investigation. Those counters are supporting evidence, not proof that every misfire is caused by an injector.

## Feed and control paths are separate branches

The test description distinguishes ignition-feed faults, a control circuit shorted to ground and an open control circuit. The diagnostic aids add connector and harness integrity. This explains why replacing the injector without checking its electrical paths could leave P1200 unresolved.

The cited strategy requests the malfunction lamp on the first failing trip and, when traction control is equipped, can disable that function. Preserve the recorded operating conditions before professional testing. The source also requires programming if PCM replacement is ultimately justified; the code itself does not establish that replacement is necessary.

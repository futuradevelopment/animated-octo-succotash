# P26C1: GM coolant bypass valve D misses its commanded position

GM's 24OBDG03A Part 1 names P26C1 as a range/performance fault for engine coolant bypass valve D, identified in this row as HEAT-BRV. The monitored quantity is positional tracking. A valve that moves, but fails to reach the required position promptly, can still satisfy the fault description.

## Give the target time to settle

The source requires active closed-loop position control, a stable desired-position gradient and an inactive anti-sticking routine. The diagnostic system must be enabled, the engine must not be cranking, and run/crank ignition conditions must be valid. Specified position-sensor and H-bridge fault conditions must also be absent.

Within those conditions, an absolute target-to-actual difference greater than 12 degrees is the listed threshold. The fault must occupy eight seconds of a ten-second window. An instantaneous mismatch while a target is deliberately moving is therefore not the same evidence as the stabilized comparison described here.

## Interpret performance without assuming a part failure

GM describes a slow or stuck part as the kind of behavior this strategy detects. The table does not turn that observation into a universal replacement instruction, identify a connector test, or specify which vehicle carries every row in this multi-application file.

The coolant enable branch requires a valid engine-outlet coolant value above minus 39 °C, or the stated OBD coolant-enable criterion. Those alternatives should be retained when deciding whether a test actually ran. The row classifies the fault as Type B, two trips. Confirm the exact valve system and calibration through the vehicle's service information before applying these limits or carrying out work on a hot cooling system.

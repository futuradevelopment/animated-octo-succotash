# P2405: An EVAP pump reference-current fault is not a measured tank leak

## Understand the reference stage

For the cited RX-8 EVAP system, P2405 is associated with the leak-detection pump sense circuit reading low. The PCM monitors pump load current during the evaporative leak test. This particular fault occurs when current is below specification while the controller obtains the reference current value. It therefore concerns the validity of the pumping/reference operation, rather than independently proving a leak at the fuel cap or tank.

Mazda lists a pump malfunction and a detached orifice among the possible pump-related causes, followed by a PCM fault. The source does not provide a numerical current limit on this DTC page. A voltage or current specification borrowed from another model would not make this diagnosis more reliable.

## Preserve the EVAP evidence

The procedure first saves freeze-frame information and EVAP diagnostic-monitor test results, then checks relevant service information. It directs an inspection of the leak-detection pump using the separate component procedure. Replacement follows a failed inspection; the mere presence of P2405 is not the inspection result.

This is an intermittent EVAP monitor. A first failure can produce a pending code, while the documented MIL response ordinarily needs two consecutive failing drive cycles; an already stored matching malfunction changes that response. An ignition restart without a completed EVAP test is consequently weak repair evidence.

## Use the appropriate verification route

Mazda verifies with its scan-tool evaporative-system test. Where that function is unavailable, the chart specifies its defined Drive Mode 6 and a pending-code check. Use the full vehicle-specific instructions for that drive mode. PCM replacement is a later branch after pump assessment and a repeated matching fault, not the starting point of the repair.

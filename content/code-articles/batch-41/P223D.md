# P223D: GM checks bank 2 oxygen-sensor pump current during fuel cut

The P223D row in GM's 24OBDG03B Part 1 concerns a bank 2 wide-range air/fuel sensor using the listed non-E80 Continental ATIC142 strategy. It evaluates pump current during deceleration fuel cut. A code description alone does not establish that another controller uses this same strategy.

## Several current regions can indicate failure

GM describes the monitor as detecting open pump-current, reference-cell or reference-ground circuits. The row defines three current regions: above 5 mA, between minus 0.30 and plus 0.30 mA, and below minus 0.10 mA. These regions overlap; they should not be presented as three mutually exclusive diagnoses.

Each region has its own count-based decision: 128 failed samples out of 160, with 25 ms between samples. Any qualifying region can establish the failure. The current value therefore needs its operating context and persistence, rather than being interpreted as an isolated measurement.

## Heater readiness precedes the comparison

The sensor electronics must report valid measurements and controller readiness. Heater warmup must be complete, the additional diagnostic delay must exceed 20 seconds, and the specified bank 2 heater faults must be absent. The row also identifies run or auto-stop operation and calibrated deceleration-fuel-cut conditions.

Those prerequisites explain why a cold sensor reading is not an equivalent test. The document classifies this monitor as Type B, two trips, but gives no universal connector procedure or sensor replacement verdict. Confirm the actual controller and applicable service instructions before testing. This source supports a pump-current circuit strategy; it does not identify one failed wire merely from P223D.

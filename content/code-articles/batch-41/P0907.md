# P0907: A short-type select-position fault needs circuit isolation

## Circuit high does not specify a failed controller

Toyota's MR2 sequential-manual P0907 row associates an out-of-standard select stroke value with a short in the select-sensor circuit. The listed possibilities include the sensor, its wiring and the transmission ECU. A reported high signal is therefore evidence to investigate the circuit, not a sufficient reason to replace the controller.

The factory chart first observes select-stroke response through an active test. It then uses a resistance branch, checks the sensor-to-ECU harness for open or short circuits, and examines the sensor's position-dependent voltage response. Preserving the actual response before unplugging components helps distinguish a persistent fault from one disturbed by connector handling.

## Sensor output must be interpreted with position

In the component check, the source specifies a high output at one angular position and a low output at another under a defined 4.5-volt supply. This makes a standalone high-voltage reading inconclusive without the sensor angle and circuit conditions. The bench relationship is not the published voltage threshold for setting P0907; the DTC table does not supply such a threshold.

## Review the active-test limits before using them

The reproduced target-stroke figure contains inconsistent millimeter/inch pairs, including the stated change in stroke. This article retains a needs-review flag rather than silently correcting those acceptance values. Obtain the current Toyota test specification before using that branch to condemn parts.

Have a technician complete the confirmed circuit and component tests with the vehicle secured. Avoid improvised power application or hydraulic-actuator movement. A useful final record identifies the short-type fault actually found and demonstrates restored select-position tracking, rather than relying only on the absence of a warning after code clearing.

# P2B06: GM tests the opening signature of cylinder 7 injection pulses

P2B06 is the cylinder 7 member of GM's injection-pulse performance strategy in 24OBDG03B Part 1. The shared family logic asks whether the injector's moving element responded to a commanded pulse. The cylinder number selects the monitored event; it does not imply a different diagnostic principle from the neighboring cylinder entries.

## Missing movement has an electrical signature

The controller measures coil-voltage feedback across the enable and command wires. It uses that feedback to calculate an opening magnitude associated with pintle or armature movement. The fault criterion concerns an absent opening indication or a calculated magnitude beyond the calibrated missing-pulse boundary.

That mechanism explains why command data and response data must be distinguished. A command can exist without the expected movement signature. Conversely, this source does not measure the delivered fuel quantity directly or identify the physical cause of an unsuccessful opening event.

## Use event counts in their intended context

GM lists 50 to 100 samples and cylinder-event sampling. The monitor operates continuously when its small-pulse diagnostic-enable condition and feedback-data-ready condition are satisfied. Those counts are not a fixed number of seconds and do not provide a universal engine-speed requirement.

The supporting table describes an internal opening-magnitude calibration against rail pressure. Its values should not be repurposed as an external injector supply specification. The documented indication is Type B, two trips. Exact vehicle and controller information remains necessary for a professional test plan, including pressure and electrical precautions. The summary supplies no cylinder-location diagram and no automatic injector-replacement instruction.

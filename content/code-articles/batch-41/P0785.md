# P0785: GM compares 3–2 shift-solenoid feedback with the requested state

The Powertrain Diagnosis procedure indexed for the 2000 Chevrolet K Tahoe 5.3-litre application describes P0785 as a 3–2 shift-solenoid circuit fault. The solenoid influences the timing between release of the 3–4 clutch and application of the 2–4 band, while the PCM monitors its electrical command and feedback.

## An electrical mismatch is the setting evidence

In this specific PCM procedure, system voltage must be between 8 and 18 V, engine speed must exceed 450 rpm for five seconds, and fuel cutoff must be inactive. The code sets after five seconds of feedback remaining high with an on command, or low with an off command.

Those comparisons establish a circuit-control problem rather than directly measuring clutch or band wear. The test description separates the solenoid's voltage supply, the ground-control path and combined harness/solenoid resistance.

## Keep different controller procedures separate

The same model index also contains a VCM transmission-diagnosis variant with different voltage and indication details. This article follows the named PCM Powertrain Diagnosis page; it does not merge those limits into one universal test.

The cited PCM strategy requests the malfunction lamp on a second consecutive failing trip and commands changes including maximum line pressure, inhibited converter-clutch engagement and frozen shift adaptations. Those defaults can influence the later driving complaint. Confirm the actual controller and transmission before professional diagnosis. The code does not justify replacing the entire transmission or bypassing the monitored solenoid circuit.

# P0226: bank-2 throttle position checked against redundant evidence

P0226 is a rationality check for throttle-position sensor 1 on bank 2 in this source. The generic throttle/pedal sensor C label does not mean that this documented implementation is an accelerator-pedal test.

## The controller uses more than one comparison

One branch compares the relative angles calculated from throttle sensors 1 and 2. The table gives a calibration-dependent difference above 5 to 6.25 percent for at least 0.14 second. It also compares sensor-1 angle with an air-charge-derived value, using a threshold above 9.02 percent for at least 0.28 second.

Further branches involve combined disagreement and main air-charge sensor errors. Their continuation includes mixed bank labels, so this summary does not turn those formulas into a universal independent test.

## Why this matters diagnostically

Two throttle sensors agreeing with each other does not necessarily settle a comparison against modeled air charge. Conversely, an unreliable air-charge input changes how that third comparison should be interpreted. Preserve the participating values and any associated validity flags, not just one throttle percentage.

Drive or post-drive states and safety-cutoff conditions govern eligibility. One-trip reporting is listed. Verification should identify the failing rationality branch and show that it completes with valid inputs under the correct vehicle procedure; the base code does not select a throttle-body replacement.

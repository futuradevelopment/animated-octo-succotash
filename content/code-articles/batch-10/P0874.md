# P0874: system-pressure sensor zero-offset assessment

P0874 is described here as system-pressure-sensor drift outside its allowed window. The documented test is more specific than the catalog’s intermittent pressure-sensor C circuit label.

## The raw reading is judged at expected zero

The controller evaluates the absolute raw system-pressure measurement when the system’s zero-pressure condition applies. The allowable drift window and definition of that condition are supplied by referenced attachment tables, so no fixed pressure limit is inferred from this page.

The enable list requires controller awake time above 20 milliseconds, acceptable application state, no code-clear event, and an electrical sensor diagnostic that indicates okay. These conditions separate offset assessment from a simple electrical high/low fault.

## Different questions need different evidence

A normal electrical-range test does not prove the sensor’s zero offset is correct. Likewise, a nonzero reading while the hydraulic system is actively pressurized is not evidence of the zero-state error this monitor seeks.

For verification, preserve the raw reading and proof that the correct zero-pressure state was established. The page contains awkward sample-validity and clutch-versus-system wording, so this article does not reconstruct a complete service sequence from it. Use the applicable professional diagnostic to confirm a completed drift check; the code alone does not prove actual residual pressure or identify a failed hydraulic component.

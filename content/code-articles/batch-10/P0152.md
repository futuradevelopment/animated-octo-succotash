# P0152: bank-2 upstream oxygen interface short-to-battery check

P0152 is documented as a short-to-battery check on the bank-2 sensor-1 oxygen-sensor interface. Its high-voltage criterion concerns the interface lines, not a declaration that the engine mixture is rich.

## What the interface reports

The examined path checks RE, IPE, APE, and MES lines while the CJ135 interface is in IDLE mode. A voltage above a calibrated 9.1- to 10.3-volt threshold on at least one line constitutes the fault evidence. The controller reads this information from the accessed diagnostic register.

The register must be valid and the last packet transfer must not be aborted. Battery voltage and timing conditions also apply. A communication failure that prevents a trustworthy diagnostic-register read is therefore different from a valid high-voltage finding.

## Practical interpretation

The 9.1- to 10.3-volt range is not the expected operating output of an ordinary narrowband oxygen sensor. Applying that number to a different sensor design would confuse the electrical diagnostic with mixture sensing.

The table gives a 0.5-second detection interval and two-trip reporting for this path. Verification should confirm the appropriate bank-2 wire test completes with a valid interface report. The source does not identify the affected physical pin or select a replacement part; those decisions require the correct circuit-level service information.

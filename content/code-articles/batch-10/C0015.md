# C0015: right-front outlet-valve driver monitoring

C0015 identifies right-front outlet control in the documented brake controller. Its table contains several electrical driver checks, so it should not automatically be interpreted as a hydraulic blockage at that wheel.

## Several paths can produce the same code

The continuous general-driver branch evaluates feedback for excess coil current, output-stage temperature, lost power ground, and lost freewheeling operation. Another branch evaluates PWM or switching-feedback failures while the valve supply exceeds its required level. These branches have a listed 0.03-second qualification time.

A separate silent valve-driver test checks the circuit cyclically, with a 20-second interval. Its enabling conditions include operation outside valve control, adequate relay supply, and no hydraulic request. A fault that appears during this test need not have occurred during a driver-requested brake application.

## How this changes diagnosis

The useful next distinction is the failing driver test or feedback state, not merely the base code. A current-feedback fault and a switching-comparison fault describe different observations even though they share C0015. The table lists Type A, one-trip reporting, but provides no universal component-replacement instruction.

Brake diagnosis should use the correct professional procedure and test equipment. Verification must address the branch that originally failed, including the silent test if applicable. Absence of a fault during an ordinary brake application does not establish that a cyclic electrical test has completed.

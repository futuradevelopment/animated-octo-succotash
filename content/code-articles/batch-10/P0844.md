# P0844: clutch-1 pressure sensor offset at expected zero pressure

P0844 is implemented in this table as a clutch-1 pressure-sensor drift-out-of-window check. The catalog’s intermittent-circuit label does not capture the specific offset assessment described by the source.

## A zero-pressure opportunity is required

The controller examines the absolute raw clutch-1 pressure while its zero-pressure condition should apply. If the raw offset exceeds the calibrated drift window, the sensor is diagnosed faulty. The numerical window and zero-pressure definition are delegated to attachment tables rather than given as a universal pressure value here.

The controller must have been awake for more than 20 milliseconds, the application must be outside error and bypass states, no code-clear event may be active, and the electrical pressure-sensor diagnostic must indicate okay.

## Why an electrical pass is not a complete pass

A sensor can satisfy electrical high/low limits yet have an excessive zero offset. Conversely, a nonzero reading when hydraulic pressure is legitimately present is not the zero-state error this test describes.

Verification should establish the correct zero-pressure condition and a completed drift assessment using the applicable calibration. The page’s sample-validity Boolean wording needs care and is not expanded into a reconstructed test sequence here. The code does not by itself prove clutch slip or authorize adjustment of a sensor offset without the correct service procedure.

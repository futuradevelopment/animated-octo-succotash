# P000B: bank-1 exhaust camshaft misses its response window

P000B monitors slow response of the bank-1 outlet, or exhaust, camshaft in the cited calibration. Its B designation should be interpreted with that explicit source identification rather than used to guess a connector location.

## What the controller needs to observe

During a monitoring cycle, the actual angle has not reached its target within the allowed time. The table uses more than one second and an angle-related criterion above three crankshaft degrees, with at least four qualifying events. It refers to the outlet-camshaft lookup table rather than the intake-camshaft table.

The outlet camshaft governor on bank 1 must be operating in closed loop. This matters because a position trace collected during a mode in which the governor is not regulating the cam does not recreate the documented test.

## Reading the fault in context

The event counter makes repeated unsuccessful movements more significant than one isolated reading. Also, the target stored at the beginning of monitoring is part of the comparison; comparing actual angle to a later, changed request can obscure what failed originally.

The source lists two-trip reporting and additional operating and inhibition conditions. A useful confirmation records the relevant bank-1 exhaust request, its time-dependent response, and completion of the diagnostic. It does not assume that any particular actuator, oil-control component, or timing part must be replaced solely because this performance code is present.

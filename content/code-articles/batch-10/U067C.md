# U067C: why the cooling-fan 3 LIN response is missing

U067C identifies a missing cooling-fan 3 response in the documented GM LIN communication monitor. The controller waits for the CFM3_Rsp message; the table gives a loss threshold of at least 2,437.50 milliseconds and a communication task running every 500 milliseconds.

## What must happen before it can fail

The LIN channel must be enabled, its module initialized, and the slave configured as present. The row also requires the engine to run or the specified fan-operation request and active propulsion condition. Several power-state and supply conditions must have been satisfied for five seconds. A fan that has not been configured into this network is therefore different from a configured fan that stops answering.

## Interpreting a recorded fault

Missing communication does not directly establish that the fan motor cannot turn or that engine temperature is excessive. The useful distinction is between an absent response and a valid response reporting another condition. Review the recorded operating state and whether the configured device answered when this monitor was eligible to run.

The table assigns Type B, two-trip reporting. A single successful response after a restart is narrower evidence than completion of the applicable communication diagnostic. Verification should establish sustained message availability during the enabled fan operating conditions, using the correct vehicle procedure.

## Documentation and applicability

This explanation is limited to the cited sections of GM’s 2025 25OBDG04B file. The file does not establish that this monitor or calibration applies to every vehicle; confirm the reporting module and vehicle-specific service information.

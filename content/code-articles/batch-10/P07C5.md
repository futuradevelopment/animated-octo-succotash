# P07C5: odd-clutch speed input voltage below range

P07C5 monitors the average voltage at the odd-clutch speed-sensor input in the cited transmission. It is an electrical low-range check, separate from assessing whether the measured shaft speed agrees with another speed reference.

## Signal and supply have different limits

The input threshold is below 980 millivolts, with 20 millivolts of hysteresis and a 300-millisecond confirmation period. Sensor supply VSS1 must be above 8.25 and below 10 volts. Battery voltage must be above 8.75 and below 18 volts.

The engine must not be cranking and key status must not be Stop. P0882 and P0883 disable the diagnostic. These conditions mean the low signal is judged only when the supplying electrical environment meets the monitor’s prerequisites.

## What not to infer

A circuit-low code is not the same as a zero-rpm reading from a stationary shaft. The monitor compares average input voltage with an electrical range boundary; it does not declare the shaft faulty for rotating slowly.

Verification should establish a passing input-voltage diagnostic while VSS1 and battery conditions remain eligible. The generic intermediate-shaft-sensor A label requires correct vehicle mapping before choosing a connector or test point. The table does not prove a failed sensor element or supply a universal waveform specification for other transmission speed sensors.

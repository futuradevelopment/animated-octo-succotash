# U0696: when a downstream pressure sensor stops communicating

U0696 covers loss of communication from the downstream relative-pressure sensor in this GM table. The catalog’s particulate-filter pressure sensor C label is broader than the source’s description, so sensor location and naming require the vehicle-specific diagram.

## What is actually monitored

This is a digital SENT monitor. It can fail when the downstream sensor reports message faults or when message age exceeds the documented limit. The table prints a message-age threshold above 12.50 seconds and separately specifies 158 failed samples out of 200, evaluated in a 12.5-millisecond task. Seconds and milliseconds serve different purposes here; confusing them would substantially change the interpretation.

The enable conditions require calibration permission, active Run/Crank, valid Run/Crank ignition, no diagnostic reset, and an engine that is not in crank mode. Thus an observation made while cranking cannot by itself verify this particular running monitor.

## Reading the result

The fault does not report a measured filter restriction. It reports that usable pressure communication was lost. The source mentions internal sensor faults that stop SENT or corrupt its protocol, but it does not identify which part failed on a particular vehicle.

Type A, one-trip reporting is listed. Verification should distinguish restored message continuity from a pressure reading retained from an earlier sample, and should show that the enabled monitor completed without its communication-failure criteria.

## Documentation and applicability

This explanation is limited to the cited sections of GM’s 2025 25OBDG04B file. The file does not establish that this monitor or calibration applies to every vehicle; confirm the reporting module and vehicle-specific service information.

# P0879: limited-slip differential sensor drift at zero pressure

P0879 is a limited-slip differential pressure-sensor drift check in the cited transmission table. The implementation evaluates zero offset, despite the catalog’s broader intermittent pressure-sensor D circuit wording.

## The zero state defines the test

The controller checks the absolute raw differential-pressure reading when the defined zero-pressure condition is present. An offset beyond the referenced drift window is the failure evidence. The table points to attachments for both the window and the qualifying zero-pressure state, so it does not establish a universal allowable offset in bar here.

Controller awake time must exceed 20 milliseconds. Electrical pressure-sensor diagnosis must be okay, the application must be outside error and bypass states, and no code-clear event may be active.

## Offset differs from step-response consistency

The neighboring P0876 procedure tests response at commanded pressure steps. P0879 asks whether the raw baseline is acceptable when pressure should be zero. A sensor can require both assessments; success at one operating point does not establish the result of the other.

Verification should document the correctly established zero-pressure state and a completed drift assessment using the applicable calibration. The page’s sample-validity flag wording is not expanded into a guessed procedure. The code does not prove intermittent wiring loss, actual pressure trapped in the differential, or the need for a particular replacement component.

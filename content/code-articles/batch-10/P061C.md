# P061C: internal engine-speed calculation versus measured speed

P061C checks engine-speed plausibility inside the controller by comparing a calculated functional-monitoring value with measured speed. Its internal-control-module title does not by itself prove that the entire ECU has failed.

## A comparison needs valid synchronization

The first branch uses a difference of at least 320 rpm for 0.08 second. Engine synchronization must be active and not lost, the speed signal must be valid, and the high-resolution calculated speed must meet the documented minimum operating criterion.

The source also describes a separate branch for an invalid angle-counter-derived speed signal, with a 0.52-second debounce. Its gradient wording is less clear than the main comparison, so it is not converted here into a standalone rate-of-change specification.

## What evidence distinguishes the paths

A disagreement between two valid speed calculations is different from an explicitly invalid speed signal. Preserve synchronization, validity status, and both available speed quantities before interpreting the base code as a hardware replacement instruction.

One-trip reporting is listed. Verification should demonstrate completion of the relevant internal plausibility check under valid synchronization, or resolution of the invalid-signal branch if that was responsible. A steady dashboard tachometer alone does not test agreement between the controller’s internal calculations. The source supplies monitoring behavior, not a universal programming or ECU-replacement remedy.

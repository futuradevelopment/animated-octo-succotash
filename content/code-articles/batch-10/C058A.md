# C058A: brake-booster motor position plausibility

C058A concerns the plausibility of brake-booster motor A position-sensor information in the cited controller. Several internal comparisons can produce the code; it is not limited to a signal that is electrically absent.

## Three kinds of inconsistency

One branch looks for implausible angle changes by comparing filtered and unfiltered motor speed. The table sets the absolute difference threshold above 711.2 radians per second and describes immediate detection with ignition on.

Another branch evaluates a ratio involving the rotor-position-sensor vector length and summed signals, with a 0.01-second qualification. A third compares one sensor signal line against the other three using a dynamic threshold, qualifying in 0.0025 second. The source references formulas without supplying enough detail here to recreate those latter comparisons as standalone measurements.

## Why the failing branch matters

A rapid angle jump, a vector relationship problem, and disagreement among redundant signals are different observations. A single plausible position displayed later does not disprove a brief inconsistency that was captured by the faster internal checks. Identify the available failure detail before interpreting the base code as a defective motor or sensor.

The table lists Type A, one-trip reporting. Verification should demonstrate normal position plausibility under the applicable professional brake-system procedure and establish which internal check passed. The published monitor summary is not a safe substitute for a wiring diagram or a booster-disassembly procedure.

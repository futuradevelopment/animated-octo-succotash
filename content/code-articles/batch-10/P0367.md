# P0367: bank-1 exhaust camshaft signal lost at low level

P0367 identifies a missing-edge condition on the bank-1 exhaust camshaft sensor with the signal low. The source calls this the outlet camshaft, providing the relevant interpretation of sensor B within this documented monitor.

## A revolution-based check

At least four crankshaft revolutions must occur while no new camshaft edges are detected. The signal level at the transition to no signal is shown as zero. Ignition is on, the crankshaft reference gap is detected, and reverse rotation is excluded.

The zero is a signal-state description in this table, not a published analog-voltage tolerance for every connector. Applying it as a universal exact-zero-volt measurement would add detail the source does not supply.

## Missing edges differ from bad timing patterns

The adjacent P0366 entry evaluates camshaft pattern rationality, including segment length and sequence. P0367’s evidence is more specifically a signal that has stopped at the low state. A timing-pattern diagnosis should not be assumed from the circuit-low label alone.

The table specifies one-trip reporting and common enable/inhibit requirements. Verification should confirm continuing exhaust-camshaft edges relative to a valid crankshaft reference on bank 1. The code does not select a sensor, harness, or mechanical timing repair without the corresponding vehicle-specific diagnostic procedure.

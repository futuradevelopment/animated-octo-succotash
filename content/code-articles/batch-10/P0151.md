# P0151: bank-2 upstream sensor wire short-to-ground monitoring

P0151 is a low-signal code whose documented implementation checks the bank-2 upstream wideband oxygen-sensor wiring. The cited path uses internal sensor-interface voltage monitoring rather than the familiar narrowband mixture-voltage interpretation.

## Interface state matters

In the examined path, the CJ135 interface operates in IDLE mode and checks the RE, IPE, APE, and MES sensor lines. A line voltage below −0.15 volt is treated as short-to-ground evidence. The table lists a 0.5-second detection interval and two-trip reporting.

A valid interface diagnostic register and an un-aborted packet transfer are required. The bank-2 oxygen-processor and associated serial-interface faults must also be absent. These prerequisites matter because an untrustworthy interface report cannot serve as the same evidence as a valid wire diagnosis.

## What the result supports

A circuit-low report here is not proof of a lean exhaust mixture. It concerns the sensing interface and its connected lines. The negative threshold is an internal diagnostic specification; it should not be translated into a connector-pin test without the correct wiring and service information.

Verification should establish a valid, completed wire-diagnostic result in the applicable interface state. A normal-looking lambda display after restart is useful context but does not by itself verify that the same short-to-ground path passed.

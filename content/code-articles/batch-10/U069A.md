# U069A: exhaust-temperature sensor 3 message loss

U069A identifies lost communication with exhaust-gas-temperature bank 1 sensor 3 in the cited table. The monitor evaluates the digital SENT message rather than deciding whether the exhaust temperature itself is too high.

## Message faults and initialization

Two kinds of evidence are listed: communication faults and an aged message. The description allows both interruption of the SENT signal and protocol errors, and says that related module faults depend on the module to which the sensor connects. A second communication code therefore needs to be interpreted in that connection context.

This diagnostic waits for a calibratable sensor-initialization delay. It also requires its calibration enable, active Run/Crank and a non-cranking engine. A sensor still initializing immediately after power-up is not equivalent to a sensor that becomes silent after the monitor is enabled.

## Confirmation and limits

The table gives 19 failed samples from a 25-sample group, a 100-millisecond function task, and Type A, one-trip reporting. It separately prints a message-age threshold above 100 seconds. That unusually long printed value should be confirmed against the vehicle’s applicable service data before being used as a timeout test.

Verification should establish fresh, correctly formed messages after initialization and show the monitor passing in its enabled state. A retained temperature value alone does not demonstrate that the sensor is still communicating, and this table does not authorize a sensor replacement solely from the code.

## Documentation and applicability

This explanation is limited to the cited sections of GM’s 2025 25OBDG04B file. The file does not establish that this monitor or calibration applies to every vehicle; confirm the reporting module and vehicle-specific service information.

# P074C: fourth-gear engagement exceeds speed or state limits

P074C identifies repeated failure to engage fourth gear in the documented transmission. The monitor checks whether the synchronizer’s speed relationship and the engagement state sequence permit the intended gear to be established.

## Distinguish the stage that failed

The initial differential-speed test compares speed with a calibrated maximum plus 250 rpm. Later in the sequence, another state-specific differential-speed limit applies. A separate branch detects an unmet transition condition after the state’s calibrated timeout.

Those three branches should not be summarized as “250 rpm too much slip.” The source delegates the base limits and state timeouts to attachment tables. The 250-rpm value is only an offset in the initial comparison.

## Confirmation depends on repeated attempts

Fourth-gear engagement must be requested and active, system pressure must exceed 4.5 bar, and the application must be outside error and bypass states. At least four failed attempts confirm the code.

Preserve the failure stage and associated speed data before selecting a repair. A timed-out state and excessive initial differential speed can lead to the same code while requiring different investigation. Verification should demonstrate successful fourth-gear engagement through the proper service sequence. The monitor does not prove a particular synchronizer, actuator, or hydraulic component is defective, and its retry logic is not an instruction to force shifts.

# P0867: transmission pressure fails to build with pump power available

P0867 identifies failure to build minimum transmission system pressure in the cited monitor. It is a performance check made when the controller expects hydraulic power to be available.

## The pressure floor is conditional

The documented failure threshold is measured system pressure below 4 bar for 2,000 milliseconds. The system-pressure sensor must have no electrical fault. Hydraulic power must be available from the main pump, or a target speed must be requested from the auxiliary pump.

The application must not be in bypass state, and the diagnostic is disabled during the specified auxiliary-pump priming mode. A low pressure reading while the pump is not expected to supply pressure is therefore different from the enabled failure.

## Useful interpretation

This code checks failure to establish a minimum pressure, not simply a difference from a changing target. Compare the pump-power/request state with pressure and the sensor’s electrical validity. The code alone does not prove that a particular pump is physically defective.

Verification should show pressure building appropriately when the same hydraulic availability conditions exist and the no-pressure monitor completes. A pressure value taken after the event without pump-state context is incomplete evidence. Transmission hydraulic testing should follow the correct professional procedure; the published four-bar threshold is not a universal service-pressure specification.

# C053E: a brake-pressure signal at its minimum value

C053E identifies a brake-pressure sensor out-of-range-low condition in the GM table. Although the catalog describes a low circuit, this implementation checks the pressure value reported by the DS10 sensor, not a published analog-voltage threshold.

## What the row actually says

The failure criterion is a measured pressure value equal to −1,480 kPa, described as the sensor’s minimum value. Ignition must be on, and the condition qualifies for 0.960 second. The diagnostic runs continuously and carries Type A, one-trip reporting.

A minimum representable value should not be treated automatically as a real hydraulic pressure measurement. The row establishes that the controller regards this endpoint as a fault condition; it does not prove that the brake circuit physically developed that negative pressure.

## Separate range from performance

The neighboring C053D entry addresses offset and an internal sensor error. That distinction matters: C053E’s endpoint test is narrower than a general accuracy assessment. A reading that leaves the minimum endpoint may satisfy this range criterion without establishing that the sensor’s offset is correct.

Useful verification therefore includes the result of the specific low-range monitor and the appropriate related pressure-sensor checks in the vehicle’s service procedure. This is brake-system information for professional diagnosis; it is not a procedure for opening hydraulic lines or applying pressure to a sensor.

## Documentation and applicability

These details describe the monitor in GM’s 2025 25OBDG07A Part2 file. Its application-matrix filename does not match the download index, so model and engine applicability remain unresolved. Use the vehicle’s correct service information before applying these calibration details.

# C0506: right-front wheel-speed signal current is too low

C0506 is the right-front wheel-speed-sensor circuit/open code in the cited brake table. The controller infers an interrupted circuit or short to ground from the signal-line current; it is not directly measuring wheel slip.

## A current threshold with prerequisites

The documented failure threshold is below 0.0038 ampere, or 3.8 milliamperes, for 0.120 second. The monitor runs with ignition on. It also requires completion of the wheel-sensor undervoltage checks without the specified undervoltage faults being logged at all four corners.

That prerequisite prevents the low-current result from being interpreted without considering sensor supply conditions. The neighboring undervoltage codes appear as enabling prerequisites in this row; they are not alternative names for C0506.

## Diagnostic interpretation

An open path and a grounded path are both supported categories in the source description. The base code alone does not distinguish them, nor does it establish that the sensor element must be replaced. Information about signal-line current and the status of the prerequisite tests is more directly relevant than a single wheel-speed value.

The table lists continuous monitoring and Type A, one-trip reporting. Verification should show that the current-related check passes after all required supply checks have completed. Brake-system electrical testing requires the correct vehicle procedure; the threshold here is explanatory evidence, not a pinout or authorization to probe an unidentified circuit.

# P0304: cylinder-4 misfire after startup qualification

P0304 is the cylinder-4 misfire code in this source’s multi-path combustion monitor. Its startup and post-start checks use different stages of engine operation even though they share the same base code.

## Startup delay is part of eligibility

The first path examines the initial 1,000 crankshaft revolutions. Its shown conditions require completion of the combustion delay after engine start. The table describes that qualification using engine speed above 650 rpm for at least eight combustions, alongside valid calculated segment timing.

The startup total-count criterion is above 120, with cylinder attribution based on ten percent of total misfires. After the first frame, the later emissions path uses 1,000-revolution frames and a four-frame counter. Those details explain why reading a counter immediately after a restart may capture only part of the diagnostic sequence.

## Verification should cover the original phase

A startup-only problem can disappear before a later observation is made. Preserve the original operating phase and temperature context rather than assuming a normal warm-engine sample disproves the stored result.

The continuation also contains a weighted catalyst-damage branch, and the row specifies two-trip reporting. A proper confirmation establishes that the relevant cylinder-4 monitoring path completed without its failure criteria. The monitor attributes combustion behavior; it does not identify which fuel, ignition, or mechanical component caused that behavior.

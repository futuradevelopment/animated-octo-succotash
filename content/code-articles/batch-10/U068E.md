# U068E: SENT communication failure and an EGR sensor-label mismatch

U068E is documented here as a SENT communication failure involving exhaust-gas-recirculation temperature sensor 1. The catalog calls the code “Lost Communication With EGR Temperature Sensor B”; that lettering cannot be used to rename or locate the numbered sensor in this source.

## The evidence the controller evaluates

The monitor looks for message faults or excessive message age. Its description covers a SENT signal that stops and protocol faults associated with the sensor or wiring. It also explains that associated module codes depend on which module receives the temperature sensor. Consequently, companion communication codes can describe the same signal path rather than independent failed sensors.

The table specifies 19 failed samples out of 25, with a 100-millisecond task, and Type A, one-trip reporting. Those sample counts describe fault confirmation; they are not the same as the message-age threshold. The excerpt’s message-age unit and some crank-enable labels are not sufficiently clear to turn into a universal timeout or reproduction procedure.

## Useful diagnostic distinction

A missing digital temperature message is different from a plausible message carrying an unexpectedly hot or cold value. Establish the receiving module, the exact sensor identification, and whether communication faults or stale data triggered the monitor. Verification needs a fresh, valid SENT message stream under the correct vehicle’s enable conditions, not merely a believable temperature shown once on a scan display.

## Documentation and applicability

This explanation is limited to the cited sections of GM’s 2025 25OBDG04B file. The file does not establish that this monitor or calibration applies to every vehicle; confirm the reporting module and vehicle-specific service information.

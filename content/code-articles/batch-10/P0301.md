# P0301: cylinder-1 misfire evidence across different observation windows

P0301 identifies cylinder-1 misfire in a monitor with separate startup, later emissions, and catalyst-damage paths. The cylinder number identifies the attributed combustion contribution; it does not identify an ignition coil or injector as the cause.

## Startup counts have a defined frame

The startup path uses the first 1,000 crankshaft revolutions. The table lists total misfire counts above 120 and a cylinder-1 attribution comparison against ten percent of the total count. The later emissions path also uses 1,000-revolution frames and lists a four-frame counter.

These counters are tied to crankshaft rotation, not a fixed number of seconds. A brief observation at idle and an equal-length observation at higher speed therefore do not contain the same number of monitored revolutions.

## Keep the catalyst path separate

The continuation describes a weighted catalyst-damage counter above 3,000 and a cylinder attribution based on twenty percent of the exhaust-bank weighted total, using a shorter 200-revolution frame. Weighted counts are not interchangeable with the ordinary misfire counts in the emissions path.

The table lists two-trip reporting and operating/inhibition requirements. Verification should establish which path failed and that an eligible subsequent observation completed. Correct physical cylinder identification and cause-finding require the vehicle’s service information; the code alone does not justify replacing a particular ignition component.

## Documentation and applicability

These details describe the monitor in GM’s 2025 25OBDG07A Part2 file. Its application-matrix filename does not match the download index, so model and engine applicability remain unresolved. Use the vehicle’s correct service information before applying these calibration details.

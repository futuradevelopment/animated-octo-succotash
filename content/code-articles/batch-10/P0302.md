# P0302: cylinder-2 attribution is not a single-component diagnosis

P0302 reports misfire attributed to cylinder 2 in the documented engine monitor. Its detection logic considers both the engine’s total misfire activity and cylinder 2’s share within the same observation frame.

## Read the counts together

The startup frame spans 1,000 crankshaft revolutions. The source gives an engine-total threshold above 120 counts and a cylinder-specific comparison using ten percent of total misfires. A count shown for cylinder 2 without the corresponding frame and total is therefore incomplete evidence about the monitor’s decision.

A later emissions path operates after the first startup frame. Its eligibility includes valid calculated engine-position segment time and a completed combustion delay, while overrun/fuel cutoff and zero-torque detection are excluded in the shown logic.

## Why the operating mode matters

Combustion that has intentionally been cut off should not be evaluated as though it were a failed normal combustion event. The enable conditions are part of how the controller separates those states. A clear-looking counter in an inhibited mode is not a demonstrated monitor pass.

The continuation also introduces a distinct weighted catalyst-damage path, and the row lists two-trip reporting. Verification should retain frame identity, cylinder-2 activity, and diagnostic execution status. The table establishes misfire attribution but does not select an injector, spark plug, coil, or mechanical repair.

# C055D: a documented brake-circuit compliance mismatch

C055D is labeled brake hydraulic circuit B leak in the catalog, but the cited GM row describes excessive compliance, level 2, and names circuit 1. Those labels should remain distinct until the correct vehicle documentation resolves the circuit mapping.

## The measured evidence

The monitor calculates leakage from pressure sensor 2 and plunger position. Its circuit-1 branches use a calculated rate above 500 cubic millimetres per second. They operate when the system is in circuit-separation state and braking has been requested by the driver or an external source.

The listed qualification interval is 0.100 to 0.500 second, with continuous monitoring and Type A, one-trip reporting. A calculation made in this particular hydraulic state is not interchangeable with an observation made while the system is idle or fully connected.

## What the code does not locate

Calculated leakage is evidence of a pressure-and-displacement relationship. It is not a visual identification of an external fluid leak or a failed seal. The adjacent C055E row names circuit 2, which further illustrates why the generic B label should not be translated into a physical brake circuit without confirmation.

A qualified brake technician should establish the correct circuit naming and investigate using the applicable hydraulic diagnostic procedure. Verification needs a completed assessment in the required system state, not simply disappearance of the stored code after clearing.

## Documentation and applicability

These details describe the monitor in GM’s 2025 25OBDG07A Part2 file. Its application-matrix filename does not match the download index, so model and engine applicability remain unresolved. Use the vehicle’s correct service information before applying these calibration details.

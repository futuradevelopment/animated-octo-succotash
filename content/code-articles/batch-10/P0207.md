# P0207: injector-circuit code with a source cylinder mismatch

P0207 is cataloged as cylinder 7 injector A circuit, but the supplied GM row describes cylinder 6. That contradiction prevents this source from being used to assign the fault to a physical injector or publish cylinder-specific repair instructions.

## What the row still explains

The row describes low-side injector-driver short-circuit monitoring. Low voltage while the driver is off is interpreted as a ground short; high voltage while it is on is interpreted as a short to injector supply. It lists two qualifying events and one-trip reporting for that electrical strategy.

These are command-dependent judgments. The same voltage cannot be classified without knowing whether the driver was meant to be on or off. The electrical strategy also differs from a mechanical injector-leak diagnosis, even when both could appear in an injector-related discussion.

## Required resolution before application

Obtain the complete fault identity and the correct vehicle’s injector-circuit documentation. The source’s cylinder label must be resolved before identifying a harness branch, selecting a test point, or replacing an injector. Its implausible printed upper battery-voltage bound is also omitted here.

Verification needs a correctly mapped, completed injector-circuit test, rather than disappearance of a generic code description. High-pressure injection work requires qualified procedures and equipment. This draft remains flagged for source review because the fundamental code-to-cylinder mapping is inconsistent.

# P0153: bank-2 upstream oxygen response uses several timing tests

P0153 covers slow response of the bank-2 upstream oxygen sensor in a monitor that separates delay time from transition time. It also distinguishes step-response measurements from an identification-based analysis.

## One code, several response limits

For the step-response branch, the table gives arithmetic-average delay limits above 0.38 second and transition limits above 0.4 second, in either lean-to-rich or rich-to-lean direction. Its identification branch uses different limits: above one second for delay or 1.5 seconds for transition after a pattern has been detected.

Those limits should not be mixed. A result from the identification method cannot be judged against the smaller step-response threshold without knowing which measurement the controller produced.

## Eligibility and confirmation

The continuation requires appropriate lambda control, sensor readiness, and absence of conditions such as active fuel cutoff or certain faults that disrupt control. Gear-change and operating-stability conditions also shape the measurement opportunity. The table identifies one-trip/EWMA reporting.

For diagnosis, retain both the measurement method and response direction. A displayed average that lacks those labels is insufficient to explain which branch failed. Verification should demonstrate a completed eligible response test with the correct method-specific limits. The monitoring summary does not establish a particular contaminant, wiring defect, or replacement remedy as the cause of slow behavior.

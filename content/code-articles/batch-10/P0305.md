# P0305: cylinder-5 misfire rates and cold-start eligibility

P0305 identifies cylinder-5 misfire in the documented monitor. The source distinguishes the first 1,000 crankshaft revolutions from later emissions assessment and a separate catalyst-damage calculation.

## Temperature can delay meaningful monitoring

The enable logic compares coolant temperature at engine start with the documented −12.04°C boundary. For a colder start, it describes monitoring becoming enabled when coolant exceeds that boundary. Zero-torque detection and overrun/fuel cutoff must also be inactive.

Consequently, no recorded cylinder-5 activity during an excluded cold period is not proof that the monitor completed. Execution status and the temperature history are needed to interpret a quiet counter.

## Count types should remain distinct

The emissions paths use a total-count threshold above 120 and a cylinder attribution based on ten percent of total misfires. The catalyst path uses a weighted bank counter above 3,000 with a twenty-percent cylinder attribution and 200-revolution frame. These quantities serve different diagnostic purposes.

Two-trip reporting is listed. Verification should show the applicable cylinder-5 path completing after its temperature and combustion-state prerequisites are met. The code does not establish a cylinder location or a failed ignition component, and the table provides no basis for a universal parts-replacement sequence.

## Documentation and applicability

These details describe the monitor in GM’s 2025 25OBDG07A Part2 file. Its application-matrix filename does not match the download index, so model and engine applicability remain unresolved. Use the vehicle’s correct service information before applying these calibration details.

# U3003: module supply voltage outside its allowed window

U3003 reports a supply-voltage condition at the module that stores it. The cited radar and sensing-and-diagnostic-module tables use low and high voltage branches, rather than identifying a battery failure by themselves.

## Threshold and operating state

Both tables list a low threshold below 9.0 volts and a high threshold above 16.0 volts, each with a stated ±0.5-volt tolerance. The condition is evaluated for three seconds after Run mode has existed for more than five seconds, with an applicable partial network active and the diagnostic enabled.

A low-voltage subtype and a high-voltage subtype require different explanations. Likewise, a module’s measured supply is not automatically identical to a battery-terminal measurement taken later. The useful evidence is the affected module’s voltage and operating state when the fault qualified.

## Fault storage is not the same as loss of function

The radar section describes disabling adaptive cruise control or discontinuing use of radar data. The SDM section makes a more specific distinction: the low-voltage code can set around 9 volts, while stopping transmissions is described near 5 volts or when CAN messages can no longer be sent. These are different events, not competing code thresholds.

Verification should confirm the module supply remains acceptable during the applicable network and Run conditions. Restraint-system work belongs with qualified service personnel; this monitor summary is not a probing or disassembly procedure.

## Documentation and applicability

This explanation is limited to the cited sections of GM’s 2025 25OBDG04B file. The file does not establish that this monitor or calibration applies to every vehicle; confirm the reporting module and vehicle-specific service information.

# P0430: bank-2 catalyst oxygen-storage assessment

P0430 evaluates bank-2 catalyst efficiency using a filtered, normalized, corrected oxygen-storage-capacity result. The cited failure threshold is below 1 for that normalized quantity, not a universal raw oxygen-sensor voltage limit.

## Sensor response affects the calculation

The source starts from measured oxygen storage and applies corrections that include secondary oxygen-sensor performance information and response-time correction maps. It also identifies a borderline oxygen-storage capacity of 0.1 gram. A raw measured storage value therefore is not interchangeable with the final normalized diagnostic result.

Primary commanded lambda must be 1, the engine must run, and deceleration fuel cutoff must be inactive for the stated period. Speed, flow, temperature, and stability windows also qualify the test.

## The sample history matters

The table distinguishes initialization/step-change modes, which use three samples over two trips, from stabilized mode, which uses one sample per trip. It labels reporting one-trip/EWMA. That combination should not be simplified into a claim that every new P0430 decision requires exactly one drive.

Verification should establish valid upstream/downstream sensor assessment, the catalyst monitor’s operating window, and its completed corrected result. The code reports an efficiency assessment; this table alone does not determine why it failed or prove that catalyst replacement is the appropriate repair.

## Documentation and applicability

These details describe the monitor in GM’s 2025 25OBDG07A Part2 file. Its application-matrix filename does not match the download index, so model and engine applicability remain unresolved. Use the vehicle’s correct service information before applying these calibration details.

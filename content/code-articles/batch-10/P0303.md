# P0303: cylinder-3 misfire and weighted catalyst assessment

P0303 identifies misfire assigned to cylinder 3, with separate emissions and catalyst-damage assessments in the source. The presence of a cylinder-specific code does not mean all recorded events occurred on that cylinder alone.

## Attribution and severity use different quantities

The emissions paths reference total misfire counts above 120 and a cylinder-3 share above ten percent of the engine total in a 1,000-revolution frame. The later path also uses a four-frame counter.

The catalyst-damage path instead compares weighted exhaust-bank counts with a 3,000-count threshold and uses twenty percent of the weighted bank total for cylinder attribution. Its normal frame is 200 revolutions. A weighted count is a diagnostic quantity and should not be described as an identical number of ordinary missed combustion events.

## Choosing the useful follow-up

Record whether the fault arose in the initial startup interval, the later emissions assessment, or the catalyst-oriented branch. That distinction changes which operating history should be preserved and recreated during professional verification.

The table lists two-trip reporting and requires valid operating conditions and engine-position information. Verification should establish a completed pass of the relevant path while observing cylinder-3 contribution. It does not follow from this code that a particular cylinder-3 ignition part failed, and physical cylinder location cannot be inferred from the unresolved file applicability.

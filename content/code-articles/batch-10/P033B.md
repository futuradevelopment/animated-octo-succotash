# P033B: knock-sensor D reference-signal plausibility

P033B is a reference-signal rationality check for knock sensor 4 in the cited table. Unlike a simple circuit-high code, it evaluates a normalized reference level used by knock control.

## A calibrated reference, not a DC limit

The table gives an upper reference threshold ranging from 0.67109 to 2.5 volt-milliseconds through a lookup table, together with a diagnostic debounce counter above 30. The units describe an integrated reference quantity, so the values should not be used as ordinary DC-voltage limits at a connector.

The enable conditions include coolant temperature at engine start above 34.96°C, active knock control, and charge/load-dynamic conditions. The page also describes completion of engine start, absence of fuel cutoff, and operating-mode restrictions in the shared logic.

## Why context changes the result

A reference value that is acceptable at one calibrated operating point can be excessive at another. The full lookup and qualifying control state are therefore needed to judge a specific number. A stable idle observation is not automatically a completed reference-rationality test.

The row lists a 0.1-second time column and two-trip reporting, but the explicit debounce counter remains part of the logic. Verification should demonstrate completion of this reference assessment with the appropriate calibration, rather than substituting a simple high/low circuit check.

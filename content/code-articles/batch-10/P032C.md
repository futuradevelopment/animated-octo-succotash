# P032C: knock sensor C low filtered output

P032C is a low-circuit diagnostic for knock sensor 3 in the cited table, corresponding to the catalog’s sensor C label. The monitor interprets a low filtered output as short-to-ground evidence rather than measuring excessive combustion knock.

## Event count and sampling interval

The threshold is below 0.2 volt with engine speed above 500 rpm. The row specifies three qualifying events and two-trip reporting. It also states that the check runs every 15 to 120 seconds as a function of engine speed and uses a low-pass filter gain of 0.5.

Three events therefore do not mean three seconds. A short observation may fail to include the required repeated diagnostic opportunities, especially at an operating point with a longer interval.

## Keep electrical and reference checks separate

The same page lists an open-load test and a reference-signal rationality test under different codes. Those checks use different counters and operating requirements. A normal knock-control response alone does not prove that this particular low-output diagnostic passed.

Verification should establish that the sensor-3 low-circuit test completed with acceptable filtered output at an eligible speed. The table identifies a ground-short pattern but does not specify a pinout or prove whether the sensor, wiring, or interface caused that pattern.

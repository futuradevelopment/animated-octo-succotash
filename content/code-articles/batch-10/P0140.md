# P0140: bank-1 downstream no-activity and continuity checks

P0140 is cataloged as no activity from bank-1 oxygen sensor 2, but the cited table explains specific continuity and resistance checks behind that result. It should not be reduced to “the voltage did not switch” without examining the test path.

## Loaded voltage and internal resistance

One path applies three load pulses and evaluates the mean difference between loaded and unloaded sensor voltage. Fault suspicion must first exist while the sensor output remains in the documented intermediate voltage band, and the sensor must meet its operating-readiness conditions.

The second path checks internal sensor resistance above 40,000 ohms when exhaust temperature at the sensor exceeds 600°C. The source describes this path as plausibility detection for an interrupted ground wire. That thermal prerequisite matters because resistance observed outside the specified state does not reproduce the monitor.

## Diagnostic consequences

A steady midrange signal can trigger further continuity testing rather than directly proving a mixture condition. Likewise, the interrupted-ground interpretation belongs to the hot-sensor resistance path, not every instance of the generic no-activity label.

Two-trip reporting is listed. Verification should establish the sensor’s readiness and the outcome of the relevant continuity or resistance monitor using the proper service procedure. The table’s loaded-voltage threshold is not a normal oxygen-sensor output specification and should not be applied as one during an unrelated live-data check.

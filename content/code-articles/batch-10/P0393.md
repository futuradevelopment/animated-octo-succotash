# P0393: bank-2 exhaust camshaft signal lost at high level

P0393 monitors the bank-2 exhaust camshaft signal for a high-level no-signal condition. The controller detects that expected new edges have stopped while the input remains permanently high.

## The crankshaft provides the observation interval

The documented criterion uses at least four crankshaft revolutions. Ignition must be on, the crankshaft signal’s reference gap must be detected, and backward engine rotation must not be detected. These prerequisites distinguish a qualified missing-cam-signal event from an arbitrary static reading.

The time required to complete four revolutions depends on engine speed. A fixed-duration recording can therefore contain enough evidence at one speed but too little at another. Retaining revolution or synchronization context improves interpretation.

## Verification and channel identity

The source explicitly names the outlet camshaft on bank 2. The neighboring low-state and rationality codes examine different failure signatures, so a circuit-high result should not be rewritten as a generic timing-correlation fault.

One-trip reporting is listed. Verification should show sustained, correctly attributed bank-2 exhaust-cam edges while the crankshaft reference remains valid and the monitor is enabled. The presence of the code does not prove a particular electrical short or a mechanical timing problem; those causes require the applicable circuit and signal tests.

# P01E5: coolant sensor 3 low electrical input

P01E5 monitors a low electrical input from coolant-temperature sensor 3 in the cited table. The source associates the measured temperature channel with the auxiliary-radiator outlet; that is a documentation label, not a verified location for every vehicle using this code.

## Voltage, not directly coolant temperature

The failure threshold is sensor voltage below 78.8 millivolts, with ignition on and a listed 0.1-second detection interval. Basic enable conditions apply, and two-trip reporting is specified.

A circuit-low result cannot be interpreted simply as coolant that is too cold. The monitored quantity is the electrical signal, and the table does not publish the complete temperature-to-voltage relationship needed to turn that limit into a physical temperature.

## Handle the duplicate labels carefully

The same page also places P2184 against an apparently identical sensor-3 low-voltage description. That duplication means the page should not be used to infer that the two catalog codes are universally interchangeable or connected to the same physical sensor in every application.

Verification should identify the actual temperature channel and reporting module through the correct service data, then demonstrate completion of its signal-low monitor with an acceptable input. A believable temperature displayed once is weaker evidence than a successful electrical-range test. The table does not specify a component replacement or establish why the input became low.

## Documentation and applicability

These details describe the monitor in GM’s 2025 25OBDG07A Part2 file. Its application-matrix filename does not match the download index, so model and engine applicability remain unresolved. Use the vehicle’s correct service information before applying these calibration details.

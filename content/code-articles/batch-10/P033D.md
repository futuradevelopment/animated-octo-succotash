# P033D: knock circuit high with an unresolved sensor label

P033D is cataloged as knock/combustion-vibration sensor D circuit high, but the supplied GM row calls the channel knock sensor 3. This mismatch must be resolved before assigning the code to a physical sensor.

## What can still be read reliably

The row describes a short-to-battery check using filtered output above 4.7 volts with engine speed above 500 rpm. It lists three events and two-trip reporting. The periodic schedule is 15 to 120 seconds depending on engine speed, with a stated low-pass filter gain of 0.5.

These details distinguish the electrical test from the reference-level rationality check on the following page. They also show that three qualifying events are not a fixed three-second timer.

## What remains unsuitable for application

The surrounding P033C and P033A rows repeat the sensor-3 wording, while the subsequent reference check names sensor 4. This pattern supports flagging an inconsistent channel label rather than silently selecting one interpretation.

Use the correct vehicle’s DTC and wiring information to establish the monitored channel. Verification then needs a completed high-circuit test for that confirmed channel.

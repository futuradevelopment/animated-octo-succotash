# P2102: throttle motor driver reports a short-to-ground condition

P2102 identifies a throttle-motor driver short-to-ground report in this GM 2010 table. The source describes the driver's electrical fault detection, rather than a comparison between desired and actual throttle-blade angle. That difference changes which evidence is relevant to the diagnosis.

## Preserve the driver fault classification

The malfunction criterion is the motor driver reporting a short to ground. The adjacent P2103 row instead reports a short to power. Those are separate electrical classifications; an unqualified statement that the throttle did not move does not establish either one.

The table assigns one-trip Type A and describes continuous evaluation in the main processor. Its timing cell uses implementation counter notation rather than a clearly documented ordinary elapsed-time limit. This article does not convert that notation into a guessed number of seconds or an external test instruction.

## Distinguish detection from component isolation

A technician should retain the exact driver code and associated throttle electrical records before using the vehicle-specific circuit procedure. The code does not say whether the reported condition originated in the motor, harness, connector or control electronics.

It also does not justify cleaning or replacing a throttle body solely because the word throttle appears in the description. The parameter row supplies no pinout, resistance test or mandatory replacement. Electronic throttle systems affect engine control, so verification must use the correct professional service procedure and its safety precautions. A cleared record alone does not demonstrate that the original electrical condition has been resolved.

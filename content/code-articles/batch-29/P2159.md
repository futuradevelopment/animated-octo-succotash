# P2159: signal-two speed is outside its documented upper range

P2159 is the range check for vehicle-speed signal 2 in this GM 2009 example. The monitored event is a reported speed beyond the calibrated upper boundary. It does not by itself establish that the vehicle physically reached that speed.

## A range fault is different from a frozen value

The table gives a value above 170.9 mph for three seconds as the range-failure condition. P2158, by contrast, evaluates an unchanged raw signal within a specified operating range. A frozen but in-range signal and an excessive reported value are therefore not the same diagnostic event.

The document also assigns a separate code to disagreement between speed signals 1 and 2. That comparison should not be used as a substitute for P2159's own high-range criterion, even if related records are present together.

## Identify the report before diagnosing hardware

A technician should preserve the exact speed-channel identity, controller and event data. The parameter sheet does not map signal 2 to a universal wheel sensor or provide a connector pinout. The appropriate vehicle documentation must establish where the reported information originates.

The code does not alone prove a defective sensor, tone wheel or communication module. It supplies a range observation that needs further circuit and data-path diagnosis. No high-speed road test is implied: the numerical boundary is a controller plausibility limit, not a recommended speed or a safe method for reproducing the fault.

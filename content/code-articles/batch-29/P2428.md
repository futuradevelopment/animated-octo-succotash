# P2428: exhaust protection checks both temperatures and temperature differences

P2428 is an excessive-exhaust-temperature diagnostic intended to protect the particulate filter in this GM calibration. The table defines several alternative failure paths. It is therefore not a single universal threshold applied to one unspecified exhaust sensor.

## The controller checks individual and relative values

The source includes separate high-temperature limits for the oxidation-catalyst upstream, oxidation-catalyst downstream and particulate-filter downstream measurements. It also evaluates the difference across the oxidation catalyst and the difference between the later monitored locations.

The listed failure must persist for six seconds, with evaluation at a 0.1-second rate when the general enabling and inhibition conditions are satisfied. A technician must identify which alternative condition was actually present; a lone temperature reading can miss an excessive difference between otherwise plausible reports.

## Establish whether the thermal evidence is trustworthy

Preserve all relevant temperature traces and operating-state information. A reported overtemperature can require checking measurement validity as well as the physical exhaust process. The code alone does not prove that the particulate filter is blocked or that a particular sensor must be replaced.

The parameter table is not an instruction to initiate regeneration or to keep operating until a fault returns. Those decisions require the applicable vehicle procedure and the actual thermal condition. Exhaust components can present serious heat hazards, so professional diagnosis and repair verification must use the correct service controls rather than treating the printed calibration limits as safe handling temperatures.

## Source and applicability

GM 2015 15OBDG04 Engine Diagnostics, cited exhaust-temperature protection monitor only. Document-level evidence does not establish per-code vehicle, engine or wiring applicability.

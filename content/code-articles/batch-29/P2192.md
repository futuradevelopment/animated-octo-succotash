# P2192: rich correction uses the lower multiplicative boundary

P2192 corresponds to the lower side of the multiplicative fuel-correction range in this GM 2009 example. The broad code description is rich operation at higher load, but the controller's documented evidence is a correction factor below its calibration boundary.

## Do not substitute the idle-adaptation limit

The printed lower boundary is 0.825. The same page separates multiplicative correction at qualified load and airflow from additive correction at low speed and load. Those are distinct quantities, so an additive idle percentage does not reproduce the P2192 test.

The monitor requires closed-loop operation and active long-term adaptation, along with its temperature, purge, fuel-level and accumulated-air-mass conditions. The source also describes time for adaptation to stabilize after startup. A correction value observed outside that context is incomplete evidence for this diagnostic.

## Verification should resemble the original event

The table states that passing after detection requires similar conditions to be encountered. Preserve the original correction factor and operating context so that a technician can determine whether the later test actually addresses the condition that produced the record.

The code alone does not identify an injector, fuel-pressure regulator, airflow sensor or other component as defective. The parameter sheet supplies no such isolation procedure or replacement instruction. Use the matching vehicle diagnostics to determine why the correction reached its lower limit. Clearing the stored code or observing a normal value at an unrelated idle condition is not the same as verifying the qualified multiplicative correction.

## Source and applicability

GM 2009 09OBDG04 Engine Diagnostics, cited lower multiplicative fuel correction example only. Per-code vehicle, engine and calibration applicability has not been established; use the matching vehicle procedure.

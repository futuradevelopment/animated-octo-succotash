# P0D44: charger low-voltage output measurement falls below range

The P0D44 monitor in this GM table addresses the charger's low-voltage output-voltage sensing path. Its title refers to the nominal 14 V output, but the monitor is not a general battery-health test or a statement that a healthy battery must always measure exactly 14 V.

## Read the reported value in its operating state

The failure condition is a reported low-voltage DC value at or below 1.87 V. It must occur for 400 milliseconds within a 500-millisecond window while the low-voltage secondary microcontroller is awake. The documented pass branch requires a value above that boundary for 500 milliseconds.

The awake condition is part of the diagnosis. An observation from an inactive controller or a different scan parameter cannot be substituted for the specific sensor report named in the table. The diagnostic is listed as one-trip Type A.

## A low signal is not a parts verdict

Keep the sensor value, controller state and other low-voltage or reference-voltage faults together. This makes it possible to distinguish the evidence for this range test from a broader loss-of-supply event that needs its own diagnosis.

The parameter sheet does not establish whether the output itself collapsed or the sensing path reported it incorrectly. It provides no terminal-level voltage test and no instruction to replace the auxiliary battery. A technician needs the applicable charger and vehicle procedures to resolve that distinction. Physical charger investigation requires the appropriate high-voltage precautions even though this particular reported output is labelled low voltage.

## Source and applicability

GM 2015 15OBDG01 Hybrid Diagnostics, only the cited EACCM monitor and calibration. Per-code vehicle and engine applicability has not been established; these historical thresholds are not universal service specifications.

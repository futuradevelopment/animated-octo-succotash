# P0D78: driver-temperature circuit-low does not establish actual overheating

P0D78 identifies the low-circuit side of the electric-compressor output-driver temperature-sensor diagnostic. GM names the monitored value IGBT temperature. That reported temperature must be distinguished from a directly verified physical temperature of the power electronics.

## An extreme report is the monitored event

The table specifies a failure when the reported driver temperature exceeds 274°C. It requires 30 failures out of 60 samples at a 50-millisecond rate, sufficient low-voltage supply and the stated Accessory or Run/Crank condition.

The printed number belongs to a circuit-range test. It is not a normal operating allowance, a refrigerant-pressure limit or a threshold that makes contact with the assembly safe. A sensor or conversion problem can create an extreme reported value without establishing the actual thermal state.

## Recovery still has prerequisites

The pass comparison uses a value at or below the threshold. The source also lists a controller reset after failure before passing can be enabled. That distinction explains why a later reasonable reading and an eligible diagnostic pass are not automatically the same event.

Preserve the original driver-temperature report and related controller faults before any vehicle-specific verification. The parameter sheet does not name a failed semiconductor or authorize replacing the compressor from this code alone. Professional diagnosis needs the correct hardware information and the required high-voltage and refrigerant precautions; this explanation supplies no live electrical or internal access procedure.

## Source and applicability

GM 2015 15OBDG01 Hybrid Diagnostics, only the cited EACCM monitor and calibration. Per-code vehicle and engine applicability has not been established; these historical thresholds are not universal service specifications.

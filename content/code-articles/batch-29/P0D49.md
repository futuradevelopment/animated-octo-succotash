# P0D49: low charger output current is a sensor-range finding

P0D49 belongs to the low-voltage output-current sensing branch of the charger in this GM example. The important distinction is between a reported current outside the monitor's range and a conclusion about how much current a vehicle should normally demand.

## The table defines a particular controller test

Failure occurs when the low-voltage DC current reading is at or below 0.293 A for 400 milliseconds within a 500-millisecond window. The low-voltage secondary controller must be awake. The pass branch requires the reading above that threshold for 500 milliseconds.

This is classified as a one-trip Type A diagnostic. The sheet does not publish a universal vehicle-load condition or an external meter procedure for recreating the test. A current reading from an unrelated operating mode therefore cannot be used by itself to declare the sensor faulty.

## Keep current and voltage evidence separate

Record the output-current report and controller state, then consider the adjacent voltage and reference-supply faults in their own right. A current-range code and an output-voltage code identify different observations; treating them as interchangeable loses useful information.

The table does not tell the reader whether a low report arose from actual output behavior or a defective measurement path. It also provides no basis for imposing a test load on the charger. Use the vehicle-specific diagnostic procedure and qualified personnel for physical testing. The numerical limit is a historical monitor criterion, not an instruction to modify charging loads or access energized equipment.

## Source and applicability

GM 2015 15OBDG01 Hybrid Diagnostics, only the cited EACCM monitor and calibration. Per-code vehicle and engine applicability has not been established; these historical thresholds are not universal service specifications.

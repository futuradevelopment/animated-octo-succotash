# P2103: throttle driver short-to-power differs from a position error

P2103 is the throttle-motor driver short-to-power diagnostic in the cited GM parameter table. It describes an electrical fault report from the driver circuitry. It is not the same finding as a throttle blade that tracks its target poorly or a pedal-position signal that disagrees with another sensor.

## Keep the electrical direction intact

The primary criterion is that the motor driver reports a short to power. The paired low-circuit code P2102 reports a short to ground instead. The exact stored code therefore matters when selecting the appropriate circuit investigation; those reports should not be merged into a generic throttle-performance complaint.

GM lists continuous main-processor evaluation and a one-trip Type A classification. The printed timing uses implementation-specific counter values. Their service meaning is not resolved by the page, so no guessed fault duration is presented here.

## A driver report is not a replacement verdict

Record the original code, controller and related electrical faults. A technician must use the matching wiring and driver diagnostics to distinguish an external circuit condition from an internal motor or control-electronics problem. The monitor table alone does not make that distinction.

The source contains no throttle-body cleaning instruction, connector pin assignment or universal resistance specification. Nor does clearing the code verify a repair. Electronic throttle diagnosis should follow the correct vehicle procedure, including its operating and safety controls, and demonstrate that the relevant driver condition no longer returns under qualified testing.

# P2445: AIR pump stuck-off wording and the ground-side electrical check

The P2445 title describes a secondary-air pump stuck off, but GM's cited Group 04 monitor implements it as a pump control-circuit continuity fault toward ground. Its threshold is an internal driver voltage decision. The summary does not supply a mechanical pump-speed threshold or prove that the pump motor itself has failed.

## Identify which test actually failed

In the same output-driver row, P0418 represents an open circuit and P2444 represents continuity toward voltage. P2445 is therefore a distinct electrical branch in this calibration. Treating all three as synonymous with inadequate AIR flow would discard information that can guide subsequent circuit diagnosis.

The source also distinguishes activation from complete checking: the output must be activated and deactivated. A pump observed during only one command state cannot demonstrate that the driver's full electrical test has passed.

## Conditions behind a valid result

GM lists engine speed above 80 rpm and battery voltage between 9.99 V and 17.99 V. The check is continuous once enabled, with a 0.2-second recognition criterion and a two-driving-cycle illumination strategy. These qualifications prevent a static engine-off observation from being assumed equivalent to the recorded monitor event.

Preserve the command state, supply-voltage context and companion circuit faults when investigating recurrence. An absence of audible pump operation is useful context, but it does not independently identify a ground fault. Verification needs the applicable electrical monitor result and vehicle-specific control information; the code alone is not a supported instruction to replace the pump.

## Source and applicability

GM 2009 09OBDG04 Engine Diagnostics, only the cited secondary-air monitor. The file does not establish the applicability of this code to a particular model or engine; thresholds are calibration-specific.

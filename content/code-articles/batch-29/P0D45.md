# P0D45: high low-voltage charger output has its own trip classification

P0D45 is the high-range evaluation of the charger's nominal 14 V output-voltage measurement. The reference calls the monitored data the low-voltage DC sensor reading. It is not the AC inlet voltage and should not be interpreted using the charger's input-voltage limits.

## Separate detection time from trip classification

GM lists a failure at or above 16.88 V for 400 milliseconds within a 500-millisecond window. The low-voltage secondary microcontroller must be awake. A reported value below 16.88 V for 500 milliseconds is the stated pass condition.

The row assigns two trips, Type B, whereas the adjacent low-voltage range fault has a different trip classification. The short measurement window and the trip classification describe different parts of the diagnostic process; neither should be replaced with a guessed warning-lamp timetable.

## Establish what actually rose

A technician should preserve the charger output reading with the controller state and relevant reference or supply faults. That evidence supports checking whether the controller observed an excessive output or whether the measurement path itself became inaccurate.

A high reported value alone does not prove a failed converter, an auxiliary-battery defect or an external supply problem. The source gives no such component conclusion and no safe live-test point. Apply the matching vehicle procedure before deciding on hardware. Because the low-voltage output belongs to a high-voltage charging assembly, ordinary battery familiarity is not sufficient preparation for opening or probing that assembly.

## Source and applicability

GM 2015 15OBDG01 Hybrid Diagnostics, only the cited EACCM monitor and calibration. Per-code vehicle and engine applicability has not been established; these historical thresholds are not universal service specifications.

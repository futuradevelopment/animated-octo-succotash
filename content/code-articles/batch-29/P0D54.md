# P0D54: high battery-output current is separate from input overcurrent

The P0D54 row in this GM charger table monitors high-voltage DC output current. A high report on this channel cannot be interpreted using the AC input-current limit, because conversion separates the input and output quantities.

## What the controller counts

The stated failure condition is current at or above 17.7 A for 400 milliseconds within a 500-millisecond window. Both the high-voltage microcontroller and the low-voltage secondary microcontroller must be awake. The pass branch requires a value below 17.7 A for 500 milliseconds.

GM assigns one-trip Type A to this monitor. The nearby fault-bundle list merely groups P0D54 with other charger-current faults; it is not a second diagnostic specification. The actual measurement, prerequisites and timing come from the primary monitor row.

## Preserve the distinction between current and sensing

A useful event record includes the output-current report, relevant controller states and associated charger faults. That information helps the technician decide which operating conditions need to be reproduced under the correct service procedure.

The parameter table does not prove whether the output current itself was excessive or the measurement path reported it incorrectly. It also does not give a replacement rule for the traction battery. Apply the vehicle-specific diagnostic process rather than treating the threshold as a charging target or a safe conductor rating. Current measurement around a high-voltage charger requires the appropriate equipment, training and isolation procedure; no live-probing method is supplied here.

## Source and applicability

GM 2015 15OBDG01 Hybrid Diagnostics, only the cited EACCM monitor and calibration. Per-code vehicle and engine applicability has not been established; these historical thresholds are not universal service specifications.

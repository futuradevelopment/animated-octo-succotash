# P0D69: compressor voltage disagrees with its battery reference

P0D69 is a voltage-sensor plausibility check for the electric A/C compressor in the cited GM HCP2 table. It compares compressor input voltage with the battery-voltage reference named by the monitor. It does not simply declare that the compressor's supply is too high or too low.

## A valid comparison requires prerequisites

The documented failure is an absolute difference greater than 15 V for 35 failed samples out of 40 at a 100-millisecond interval. System voltage must exceed 10.2 V, the power mode must not be Crank, and the high-voltage battery contactor must be closed.

The compressor voltage signal and the battery-voltage reference must be valid. The table excludes their specified range and plausibility faults, along with listed contactor-related faults. A comparison made with invalid reference data does not establish the intended rationality failure.

## Preserve both readings

A technician needs the compressor and reference voltage values from the same operating event. Recording only one value loses the disagreement that defines P0D69. The contactor state also matters because the monitor is not intended to compare an isolated compressor supply against an unrelated energized reference.

The source does not establish which sensor is wrong or prescribe a compressor replacement. Use the applicable vehicle procedure to distinguish sensing accuracy from supply-path behavior. Electric-compressor circuitry can retain hazardous energy; this monitor description gives no permission to disconnect, probe or open the high-voltage system.

## Source and applicability

GM 2015 15OBDG01 Hybrid Diagnostics, cited HCP2/VICM electric-compressor voltage comparison. No universal vehicle fitment, terminal test or voltage-source assignment is inferred.

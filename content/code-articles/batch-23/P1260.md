# P1260: Ford anti-theft control has disabled engine operation

P1260 in the 1999 Ford PCED means the anti-theft system determined that an immobilization condition existed and disabled engine operation. It is a security-system result, not a direct diagnosis of fuel-pump pressure, ignition hardware or an internally failed PCM.

## Distinguish a recorded security event from a current failure

Ford lists both a previous theft condition and an anti-theft system failure. Those are materially different explanations. The code can refer to a recorded event, while an ongoing no-start may require diagnosis of why authorization is still not being accepted.

The source calls for reading the anti-theft system’s own diagnostic records. Those records can provide information that the powertrain P1260 entry does not contain. An engine controller’s immobilization report alone cannot identify a failed key, receiver or security module.

## Use authorized operation and the correct security procedure

The diagnostic aid refers to disarming the system with the proper key, remote or authorized entry method for the fitted system. It does not provide a bypass or support defeating the immobilizer. Equipment and authorization arrangements vary, so use the vehicle’s actual operating and service documentation.

Record whether normal authorized operation restores starting and whether relevant security faults recur. If they do, have the fitted anti-theft system diagnosed through its proper procedure. Verification means consistent authorized starting with the underlying security concern resolved, not merely erasing P1260 or replacing fuel-system parts because the engine previously would not run.

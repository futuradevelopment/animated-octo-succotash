# P1390: Ford octane adjustment is a software-controlled timing setting

Ford’s 1999 P1390 entry describes an octane-adjust function implemented in PCM software. The row states that the earlier hardware shorting bar has been removed and that the software function can retard ignition timing by three degrees. That configuration context is more specific than a generic “octane sensor fault” interpretation.

## Do not search for a removed adjustment bar

The hardware-versus-software distinction changes the next diagnostic question. For the documented arrangement, inspecting or moving a supposed octane-adjust shorting bar would not address the function the row describes. Confirm the fitted PCM strategy and the exact service definition before treating P1390 as evidence of an external circuit defect.

The possible-cause field names the PCM but provides no circuit test, threshold or diagnostic sequence proving that its hardware is damaged. The short entry should not be expanded into a blanket controller-replacement instruction.

## A bulletin is required context for changing the setting

Ford expressly limits activation of the octane-adjust software to cases directed by a Technical Service Bulletin. This article has not identified a bulletin for a particular vehicle and therefore does not recommend enabling the feature or editing calibration settings.

A technician should verify the relevant software configuration and any applicable Ford bulletin, using the vehicle’s actual identification and calibration. The source’s three-degree description explains what the historical function does; it does not establish a performance improvement, a fuel-quality diagnosis or a universal response to engine knock.

# P1138: Ford bank-one rear oxygen signal remains rich during its response check

P1138 is Ford’s rich-indicating no-switch code for HO2S-12, the bank-one downstream oxygen channel. Its 1999 description explicitly refers to the P1137 procedure. That reference is substantive: the PCM drives the mixture through rich and lean conditions and evaluates whether the rear oxygen output responds within a calibrated interval.

## Retain the rich-indicating distinction

A generic “oxygen sensor fault” label loses what P1138 adds. The record identifies the rich-indicating outcome on the rear bank-one channel. It should not be confused with P1132, which addresses the upstream bank-one channel, or P1137’s lean-indicating downstream result.

The referenced description lists wiring and connector damage, crossed wires, exhaust leakage and sensor contamination or damage. Those are diagnostic alternatives. The short cross-reference supplies no probability that the sensor is the failed component.

## Verify response under the actual evaluation

A single voltage reading with an idling engine does not establish whether the PCM’s commanded response test passed. The correct diagnostic comparison uses the intended mixture change and the matching downstream trace, with the vehicle-specific procedure providing timing and connection details.

After a demonstrated fault is corrected, verify the relevant rear-sensor response through the same evaluation. Clearing memory without re-running eligible monitoring leaves the central question unanswered. The source does not publish an independent P1138 voltage threshold or a universal catalyst diagnosis, and the shared P1137 procedure should not be expanded into either claim.

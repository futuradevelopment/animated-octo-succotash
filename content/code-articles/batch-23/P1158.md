# P1158: Ford bank-two rear oxygen channel stays rich during the response evaluation

The Ford 1999 table gives P1158 a specific channel and direction: HO2S-22, the bank-two rear oxygen sensor, indicates rich without the expected switching. Its description points to P1137 for the actual evaluation method. In that method the controller commands rich and lean conditions and waits for the downstream output to respond.

## Preserve what differentiates this result

P1157 concerns the lean-indicating outcome on the same rear channel. P1152 concerns the upstream bank-two channel. These distinctions determine which trace and physical sensor identity must be checked; grouping them all as “bank two oxygen” would lose necessary information.

The shared source lists exhaust leakage, crossed signal wiring, damaged terminals or harnesses, and a contaminated or damaged sensor. A stored P1158 does not distinguish those causes or assign failure probabilities.

## Confirm the response with the correct procedure

The available description omits a numerical response-time limit and does not define a universal rich voltage for all Ford oxygen systems. Use the applicable diagnostic procedure to evaluate the observed output against the commanded change.

A technician should also verify that the scan channel maps to the intended rear sensor. An active trace associated with the wrong bank cannot establish a passing result here. Once a demonstrated fault is corrected, repeat the downstream response evaluation and confirm the bank-two channel behaves as required. The code alone is not evidence that the catalyst or both oxygen sensors on that bank must be replaced.

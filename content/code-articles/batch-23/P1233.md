# P1233: Ford fuel-pump feedback disappears from the controller

For the conventional FPDM arrangement described in Ford’s 1999 table, P1233 means the PCM stops receiving the fuel-pump-monitor duty-cycle signal. The module normally sends feedback with the key on. Losing that feedback differs from receiving a valid message that reports a particular pump-side fault.

## Missing communication is not the same as a reported pump failure

The source distinguishes feedback meanings: about 50 percent represents the normal message, 25 percent reports missing or invalid command information, and 75 percent reports a secondary pump-circuit fault. Those are status-message duty cycles for the documented FPM circuit, not pump speed percentages to command manually.

Potential causes include loss of module ground or supply, FPM wiring faults, inertia-switch concerns and damaged electronics. The description gives different supply-path details for particular applications. Their connector numbers should not be transferred to another vehicle.

## Check the application exception first

The LS6/LS8 note changes the interpretation: P1233 there concerns fuel-level information not received over SCP from the rear electronics module. That architecture requires its own workshop procedure and should not be diagnosed as a missing conventional FPM wire.

Establish the fitted system, preserve the feedback or network evidence and investigate the relevant power and communication path. Any inertia-switch concern requires checking why it operated, not blindly restoring fuel delivery. Verification should confirm that the appropriate module information reaches the PCM again under the applicable evaluation, rather than merely that the engine starts.

This explanation is limited to the applicable systems in Ford’s US-market 1999 PCED. Confirm the vehicle and test application before using its limits. [Ford diagnostic descriptions: P1233 row](https://www.fordservicecontent.dealerconnection.com/pubs/content/~WVX2/~MUS~LEN/14/VX24002.HTM).

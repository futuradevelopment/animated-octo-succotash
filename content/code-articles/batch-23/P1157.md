# P1157: Ford bank-two downstream oxygen signal remains lean in its response test

P1157 identifies HO2S-22, the bank-two downstream oxygen channel, with a lean-indicating no-switch result in this Ford manual. The row refers directly to P1137, whose procedure drives the mixture rich and lean while monitoring downstream response within a calibrated time.

## Follow the bank-two rear channel

The cross-reference establishes a shared test method, not interchangeable sensor identities. A successful response on bank one’s rear channel does not confirm that HO2S-22 responded. Likewise, an upstream trace belongs to a different stage of the system.

Ford’s referenced causes include connector and wiring defects, crossed wires, exhaust leaks and sensor contamination or damage. Those possibilities explain why the monitor result alone cannot choose between repairing the signal path and replacing a sensing element.

## Evaluate response, not a static voltage alone

The short source row does not provide a numerical response time or a special P1157 voltage cutoff. The appropriate comparison is the sensor’s reaction during the commanded evaluation using vehicle-specific service information. A momentary lean voltage at idle does not reproduce the full diagnostic test.

After the cause is established, confirmation should address the previously missing response on the correct rear channel. If signal routing is corrected, verify bank identity as well as activity. If another fault is repaired, recheck this downstream evaluation rather than assuming it passed because memory was cleared. The article does not infer a catalyst replacement from a rear oxygen response code.

# P1518: Ford intake-runner feedback indicates an open position at closed throttle

In Ford’s 1999 table, P1518 describes the intake-manifold-runner system as stuck open. The actual monitor criterion is an input below the expected range at closed throttle. The evaluation can occur during continuous monitoring or the key-on self-tests identified by the source.

## Compare feedback with actual runner position

The diagnostic aid describes a monitor reading around 1 V at closed throttle as a possible fault indication. That voltage is a clue for the documented system, not a universal runner-position specification.

The listed causes include the monitor signal shorted to power ground or signal return, actuator damage and PCM damage. Because an electrical short can produce the low input, the code title does not independently prove that the runner plates are physically held open.

## Keep this result distinct from a bank-specific diagnosis

The same manual separately identifies bank-one and bank-two stuck-open results under P1537 and P1538. P1518’s row does not establish a universal bank assignment. Confirm the fitted actuator and feedback arrangement before mapping it to a component.

A technician should check the appropriate commanded movement and the matching feedback path using the correct procedure. Keep clear of powered levers and strong return springs. After a supported repair, verify that the closed-throttle feedback and actual runner position agree. Replacing a mechanical actuator without resolving a demonstrated monitor-wire short would leave the source’s electrical explanation unanswered.

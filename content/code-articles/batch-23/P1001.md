# P1001: Ford engine-running self-test did not complete

Ford’s 1999 PCED uses P1001 when the key-on, engine-running self-test does not finish within its intended time. The document classifies it as a non-MIL code. That classification explains why a diagnostic session can record P1001 without this particular code requesting the malfunction lamp.

## An incomplete test is different from a failed component test

Three documented avenues matter: the prescribed self-test sequence was not followed, a monitor responded unexpectedly, or engine speed was outside specification. Each concerns the conditions under which the test ran. None supports choosing a replacement part from P1001 alone.

Record whether the engine-running test actually started, whether the required operator actions were performed, and whether engine operation allowed the sequence to continue. A report containing only “self-test failed” loses the distinction between a completed test reporting a defect and an aborted evaluation.

## Repeat the correct procedure, then interpret its result

Ford directs the technician back to the PCM Quick Test procedure, specifically the QT1 entry in the symptom-chart section. Use that procedure for the applicable engine rather than improvising an engine-speed target from a different model year.

If a properly conducted repeat completes, interpret the resulting diagnostic records on their own merits. If it aborts again, the interruption and any associated symptoms become the evidence to investigate. The short P1001 description does not identify which unexpected monitor response occurred, so this article cannot convert repeated aborts into a PCM diagnosis.

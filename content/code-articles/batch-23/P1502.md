# P1502: Ford speed-information error requests transmission-lamp indication

Ford’s 1999 P1502 description concerns erroneous vehicle-speed information reaching the PCM. It explicitly follows P0500’s diagnostic logic but is intended to flash the transmission control indicator for a first speed-information fault. That indication behavior does not make the transmission itself the confirmed failed component.

## Find where this vehicle obtains speed information

The source identifies several possible origins: a speed sensor, transfer-case sensor in one listed variant, ABS control, the generic electronic module or the central timer module. The actual arrangement must be established before choosing a sensor or wiring path to test.

The referenced P0500 description compares missing or inadequate speed data with operating conditions that imply vehicle movement. Its cause list spans sensors, drive mechanisms, wiring and participating modules. An error in received speed information therefore cannot be reduced to a guaranteed VSS replacement.

## Follow the source path and preserve the indication

Record the speed input, the transmission-lamp behavior and related module faults. The P0500 aid notes that the transfer-case sensor has no dedicated PID in that application and requires its appropriate signal test; a missing scan display is not itself proof of sensor failure.

After a demonstrated fault is corrected, verify reliable information from the actual speed source through the required evaluation. The community catalog additionally mentions brake data, while this historical row discusses speed information; no unsupported brake-data diagnosis is added here. That scope difference remains marked for review.

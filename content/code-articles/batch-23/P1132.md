# P1132: Ford bank-one upstream oxygen signal remains rich without switching

Ford assigns P1132 to the bank-one upstream oxygen channel, HO2S-11, when the signal indicates rich and the expected switching is absent for the calibrated evaluation interval. The code names a monitored behavior rather than a confirmed defective part.

## Rich indication and actual mixture need separate evidence

The source refers to P1130 for possible causes. That list includes wiring faults, terminal problems, fuel pressure or injector concerns, intake and exhaust leaks and other engine conditions. Consequently, the sensor output needs to be interpreted with fuel-control and engine evidence.

P1131 is the lean-indicating counterpart on this channel. Keeping that distinction in the record prevents a fixed rich signal from being investigated using an unsupported assumption about the opposite signal direction.

## Do not resolve the source’s ambiguity by guessing

The historical P1132 sentence describes the rich indication as an attempt to correct an over-lean condition. The abbreviated table does not provide enough test-state detail to convert that statement into a reliable diagnosis of the engine’s actual mixture. The ambiguity is retained as a source-review item; no fuel-pressure adjustment is inferred from it.

Use the correct Ford procedure to determine whether the trace represents a real fueling condition or an electrical/sensing problem. After a supported repair, verify response and switching on the same upstream channel during the applicable evaluation. The absence of a warning lamp immediately after clearing memory does not establish that the original no-switch condition has been tested again.

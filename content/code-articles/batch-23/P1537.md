# P1537: Ford bank-one intake runners report a stuck-open condition

Ford P1537 in the 1999 description identifies a bank-one intake-manifold-runner stuck-open result. The monitor fails when its feedback signal is lower than the expected calibrated range. The source covers continuous monitoring and key-on self-test modes.

## Bank identity is necessary evidence

The row gives an IMRC monitor reading near 1 V at closed throttle as a possible indication and describes using an appropriate active-command or output-control function. The useful comparison is whether the bank-one mechanism moves as expected and whether its input reports that movement correctly.

P1538 addresses bank two in the same table. A shared actuator housing or similar scanner label should not cause a passing check on one bank to be accepted as proof for the other.

## A stuck-open report can have an electrical explanation

Ford’s possible causes include mechanical hardware concerns, a shorted IMRC circuit, a damaged actuator and PCM damage. Thus the code title alone cannot distinguish a physically bound runner from feedback pulled into the wrong range.

Use the exact engine’s procedure and component identification, with precautions around powered mechanisms and return springs. Verification after a demonstrated correction should establish the required runner movement and credible bank-one feedback under the relevant test. The approximate voltage in this historical aid is not a universal calibration limit, and P1537 does not authorize replacing the entire intake manifold without locating the actual cause.

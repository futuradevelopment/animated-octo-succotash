# P1235: Ford fuel-pump module reports an invalid or missing command

P1235 in the documented Ford strategy means the fuel-pump driver module detected missing or invalid command information from the PCM. The module then reports that condition back to the PCM, which records the code. This separates P1235 from a fault where feedback disappears entirely.

## Command and feedback are different signal paths

For the conventional FPM arrangement, Ford specifies a 25-percent feedback duty cycle while the invalid-command condition is detected. When the fault is no longer detected, feedback returns to the normal 50-percent message, but P1235 remains in continuous memory. A normal message now therefore does not disprove the earlier interruption.

The listed possibilities are an open or shorted pump-command circuit, module damage and PCM damage. The code does not report a measured shortage of rail pressure or identify a locked pump rotor.

## Respect the rear-module exception

Ford notes that LS6/LS8 integrates these functions into the rear electronics module and sends diagnostic information over SCP rather than a conventional FPM wire. The same wire-level duty-cycle interpretation cannot simply be imposed on that architecture.

Record the fitted module arrangement, current feedback state and stored history. A technician can then investigate the command path using the correct procedure. Verification needs reliable command reception and normal corresponding feedback through the relevant conditions. Clearing continuous memory after the message happens to return to normal does not establish that an intermittent command fault has been repaired.

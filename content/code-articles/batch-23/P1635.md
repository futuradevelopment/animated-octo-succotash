# P1635: Ford stored tire and axle information does not match the vehicle

P1635 in the 1999 Ford PCED means the tire and axle information in the Vehicle ID block does not match the vehicle’s hardware. This is a configuration-versus-hardware result, not a direct finding that an axle or speed sensor is electrically damaged.

## Compare both sides of the mismatch

Ford lists an incorrect tire size, an incorrect axle ratio and incorrect VID configuration parameters. Those are separate possibilities. A mismatch could arise because the installed hardware is wrong for the configuration or because the stored configuration does not describe the correct hardware.

The diagnostic aid specifically calls for viewing the tire and axle parameters with the appropriate scan tool and comparing them with the actual vehicle. Reading a label or assuming the factory configuration is still present is not a substitute for establishing what is fitted now.

## Do not change configuration merely to suppress the code

The correct values must be determined from the exact vehicle and approved service information. The row does not provide a universal tire-size formula, axle-ratio target or authorization to enter arbitrary parameters until P1635 disappears.

A technician should preserve the original stored values and demonstrate which side of the mismatch is incorrect before correction. Verification should then establish agreement between the proper hardware and VID information through the relevant evaluation. Clearing memory without comparing those values does not address the stated cause, and replacing a wheel-speed sensor would not resolve a proven tire/axle configuration discrepancy.

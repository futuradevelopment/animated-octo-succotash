# P1244: Ford historical generator-load input is below its limit

The Ford 1999 primary description labels P1244 as a low generator-load input. It says the PCM detects that the input remains below its calibrated limit for the required interval. This conflicts with the community catalog’s “failed high” label for this code, so the historical source meaning is stated explicitly rather than silently combining opposite directions.

## Confirm the input definition for the vehicle

The row names the monitored path GLI, while the possible-cause field refers to ALI. Both are generator/alternator load terminology in the source, but an exact connector or signal specification cannot be inferred from those abbreviations alone.

Possible causes include an open or shorted input circuit, a damaged voltage-regulator/generator assembly and PCM damage. The source does not publish the low threshold or the time requirement, and it does not rank the listed causes.

## Check charging operation alongside the signal

Ford’s diagnostic aid directs verification of the charging system. A load-input result and actual charging performance are related evidence, but neither should be replaced by the assumption that a new alternator is automatically required.

A technician should establish the correct year, generator arrangement and code definition, then investigate the load signal and charging operation with the applicable procedure. Verification must show that the appropriate input behavior and charging function are restored. Because the dictionary direction conflicts with this historical row, this draft remains marked for source review and should not supply a universal high-versus-low diagnosis.

## Source and applicability

This explanation is limited to the applicable systems in Ford’s US-market 1999 PCED. Confirm the vehicle and test application before using its limits. [Ford diagnostic descriptions: P1244 row](https://www.fordservicecontent.dealerconnection.com/pubs/content/~WVX2/~MUS~LEN/14/VX24002.HTM).

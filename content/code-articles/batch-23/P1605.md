# P1605: Ford keep-alive memory test can fail after a supply interruption

Ford’s 1999 P1605 description records a PCM keep-alive-memory test failure. Crucially, the source says external conditions can produce the code. It therefore does not establish that the controller’s memory hardware is permanently defective.

## Establish the power and service history

The listed possibilities include reprogramming, corroded battery terminals, a loose battery connection and an interrupted or open keep-alive supply, as well as PCM damage. The aid specifically notes that disconnecting the battery or PCM can produce the code on the first subsequent power-up.

That history changes interpretation. A first-start record immediately after an intentional disconnect is different evidence from repeated faults without a known interruption. Both need the actual circumstances preserved before memory is erased again.

## Verify reliable keep-alive power before condemning the controller

Use the correct circuit documentation to determine whether the PCM’s retained-memory supply and relevant connections are reliable. The table provides no universal connector pin, voltage-drop threshold or controller-replacement rule for this code.

A technician should distinguish a documented external power event from an ongoing electrical fault or a confirmed controller concern. Following a demonstrated correction, verify appropriate power retention and the relevant diagnostic result over the required operating sequence. Simply clearing P1605 or disconnecting the battery again can obscure the history rather than explain it. Reprogramming or PCM replacement should not be inferred solely from the phrase “memory test failure.”

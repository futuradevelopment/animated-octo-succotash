# P1124: Ford throttle position falls outside the self-test range

Ford uses P1124 for a throttle-position reading outside the expected self-test window in the applicable 1999 system. The description covers both key-on, engine-off and engine-running self-tests. It evaluates the position input at the test condition, rather than reporting only an intermittent electrical spike.

## Interpret the self-test window

The published range is 13.27–23.52 percent, alternatively 0.66–1.17 V. A reading outside that window is the diagnostic aid’s hard-fault indication. These numbers belong to this Ford test and should not be substituted for a general specification covering every throttle sensor.

The source lists binding or bent linkage, incorrect sensor seating, a throttle plate below its expected closed position, and a misadjusted plate or screw. Damaged sensor or PCM electronics are also possible. The mechanical entries matter because an accurately reported but incorrect physical position can be as relevant as a defective electrical signal.

## Check position before changing adjustment

Document the TP reading and test mode. Establish that the linkage, sensor installation and closed-throttle condition match the applicable service procedure. The code does not authorize adjusting a stop screw to conceal an out-of-range signal; adjustment and installation requirements need the correct vehicle information.

Once the identified cause is corrected, repeat the same self-test. A passing reading in the documented window addresses this monitor more directly than a code-clear operation or an idle that merely sounds normal. The row provides no universal throttle adjustment method or replacement recommendation.

## Source and applicability

This explanation is limited to the applicable systems in Ford’s US-market 1999 PCED. Confirm the vehicle and test application before using its limits. [Ford diagnostic descriptions: P1124 row](https://www.fordservicecontent.dealerconnection.com/pubs/content/~WVX2/~MUS~LEN/14/VX24002.HTM).

# P1474: Ford low-speed fan and hydraulic-fan systems use different P1474 tests

The 1999 Ford table supplies two P1474 implementations. One monitors the primary control for a low-speed electric fan, or the single-speed fan where fitted. The other evaluates the hydraulic cooling-fan solenoid circuit. Their electrical specifications should not be combined.

## Identify the system before applying a test

For the relay-controlled electric arrangement, the PCM checks excessive current while grounding the control and expects supply voltage through the relay coil when the control is released. The key-on self-tests cycle the command through both states.

For the hydraulic arrangement, the row describes voltage outside the expected range and a solenoid integrated into the hydraulic fan pump. Its nominal coil resistance is 10 ohms. That hydraulic-solenoid value is not a specification for an electric fan relay or motor.

## Preserve the source limitation and isolate the correct path

The electric-fan cause list unexpectedly names a fuel-pump relay. Because the surrounding row addresses fan control, that component reference is treated as unresolved source wording and is not used as a replacement recommendation.

A technician should establish which fan system is installed, then use its matching supply, control and load procedure. Verification must show correct monitored behavior during the applicable commanded states. Observing a fan spin once does not establish that its primary electrical circuit passes. Keep clear of fans that can start unexpectedly; the code alone does not establish that the cooling system can safely maintain engine temperature.

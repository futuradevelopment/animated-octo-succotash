# P1900: Ford output-shaft-speed signal is irregular or interrupted

Ford’s 1999 P1900 description refers directly to P0723. That referenced entry says the output-shaft-speed signal reaching the PCM is irregular or interrupted. The cross-reference supplies actual diagnostic content; it should not be expanded into an unsupported transmission-ratio or hydraulic-pressure diagnosis.

## Connection and installation both matter

Ford lists an improperly seated connector, an intermittently open or shorted harness, connector damage and a damaged or incorrectly installed OSS sensor. The aid explicitly calls for checking harness/connector integrity and proper sensor installation.

Those distinctions explain why a code naming the speed sensor does not automatically prove the sensing element failed. A sensor in the wrong installed condition or a connection that loses continuity can produce the same reported interruption.

## Preserve the event and follow the correct transmission route

The DTC chart separates automatic-transmission applications, which go to the transmission workshop procedure, from manual-transmission applications, which route to TJ1. That application split matters before borrowing a test sequence or connector detail.

A technician should record the signal interruption and conditions that reproduce it, then use the matching procedure to distinguish connection, installation and sensor concerns. Verification should demonstrate a reliable OSS signal under the relevant controlled conditions after a confirmed correction. A normal stationary reading or cleared memory cannot establish that an interruption occurring during operation has been resolved. The description gives no universal gap, waveform or replacement interval for all OSS sensors.

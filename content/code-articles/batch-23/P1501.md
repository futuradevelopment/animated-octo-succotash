# P1501: Ford detects vehicle-speed input during a stationary self-test

The Ford 1999 primary description uses P1501 when the PCM detects vehicle-speed input during self-test. It says the test aborts when that input appears. The catalog’s community title instead emphasizes a programmable speedometer/odometer module intermittent circuit, so this historical self-test meaning is stated separately and flagged.

## A stationary speed signal can invalidate the test

The diagnostic aid expects a 0 mph VSS input with the transmission in Park. The source identifies electrical noise from sources such as ignition wiring, the charging circuit or aftermarket equipment as a possible explanation for an unexpected input.

This is different from a signal dropout while driving. A sensor that appears to work during vehicle movement could still be involved in a self-test problem if noise makes the PCM interpret speed when none is expected.

## Confirm the unwanted input before blaming a module

Record the self-test state and the displayed speed. Establish the exact vehicle application and use the appropriate procedure to investigate an electrical-noise or input-path concern. The row does not provide a universal shielding repair, connector pin or instruction to remove aftermarket equipment without evidence.

Verification should show the expected stationary speed input and successful completion of the relevant self-test after the demonstrated cause is addressed. Replacing a speedometer module solely from the community title would not resolve the primary source’s actual criterion. The conflicting labels require application-specific review rather than an invented combined diagnosis.

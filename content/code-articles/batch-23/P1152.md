# P1152: Ford bank-two upstream oxygen output stays rich during the switching test

Ford P1152 is the rich-indicating no-switch result for HO2S-21 in the documented 1999 system. That is bank two’s upstream oxygen channel. The description says the test fails when switching remains absent for the calibrated interval, but it does not publish that interval in this row.

## Resolve what the signal represents

A rich-indicating output is an observation. It is not proof that the sensor is defective or that one particular fuel-system part has failed. The source refers to P1130’s broad list of electrical, fuel-delivery, intake, exhaust and engine-related possibilities.

The investigation needs the correct bank-two trace and supporting fuel-control information. Checking a bank-one channel or the downstream bank-two sensor would address a different input. The corresponding lean-indicating code on this upstream channel is P1151.

## Do not overread the historical description

Ford’s short wording links the rich indication to correction of an over-lean condition. Because the test-state explanation is incomplete, this article does not use that sentence to diagnose the actual mixture direction. The uncertainty is recorded for review rather than silently converted into a fuel-pressure or injector recommendation.

Use the exact engine’s procedure to distinguish an electrical signal fault from a real fueling condition. Verification should show that the affected upstream channel responds and switches during the relevant evaluation after the confirmed cause is corrected. The source gives no universal voltage repair target, replacement mileage or basis for replacing both bank-two oxygen sensors.

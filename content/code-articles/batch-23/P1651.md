# P1651: Ford power-steering switch signal appears open or shorted

The 1999 Ford description gives P1651 an open-or-shorted power-steering-pressure switch signal meaning. The input is monitored continuously. The chart routes the relevant diagnostic states to pinpoint FF, where actual switch response and circuit behavior are examined separately.

## Determine whether the input can change

FF1 observes the PSP input while steering load changes. If the expected change cannot be observed, the procedure distinguishes the switch or shorting bar from the wiring and PCM input using a controlled circuit-state test. Later checks examine open paths and unwanted connections to ground or signal return.

That sequence matters because a fixed scan input can originate from the switch or from a circuit unable to convey its state. P1651 alone does not establish which one is responsible, and it does not diagnose a failed hydraulic pump.

## Exclude a mismatched diagnostic-aid sentence

The description’s aid also mentions stoplamp function, despite the PSP heading and switch criterion. That statement is not used as a steering diagnosis here and remains flagged for review. The directly linked FF procedure provides the relevant evidence instead.

Have a technician follow the exact application’s switch test under controlled conditions, without jumpering unidentified connectors. Verification should show reliable input changes and the correct diagnostic result after the demonstrated fault is corrected. Clearing the code or observing normal steering assistance briefly does not establish that an intermittent switch-signal fault has been resolved.

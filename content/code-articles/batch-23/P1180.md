# P1180: Ford natural-gas fuel delivery is inferred too low

In the 1999 Ford description, P1180 belongs to a natural-gas fuel-delivery strategy. The PCM receives tank-pressure information through the natural-gas module and uses it in an inferred rail-pressure evaluation. The monitor fails when that inferred pressure is below the calibrated minimum.

## Identify the fuel system first

The natural-gas module is central to this description. It would be misleading to apply the row directly to a conventional gasoline engine merely because a generic scanner displays P1180. Exact vehicle, module and fuel-system applicability must be established before using the explanation.

The distinction between inferred pressure and a direct rail-pressure measurement also matters. A low inferred value is the controller’s diagnostic input; it is not, by itself, a measurement made with an independent pressure instrument at the rail.

## Investigate the low-delivery path

Ford lists a restricted fuel line and a plugged fuel filter as possible causes. The row does not rank them or provide a pressure threshold, filter replacement interval or disassembly procedure. It supports investigating delivery restriction within the applicable natural-gas system, not guessing which part to replace.

A qualified technician should use the correct pressure-system documentation and equipment, preserving the tank-pressure information and operating conditions associated with the event. Confirmation after repair must establish that the inferred delivery evaluation meets its calibrated requirement. Do not loosen high-pressure gas fittings or treat the code as proof that the fuel system is safe to open.

## Source and applicability

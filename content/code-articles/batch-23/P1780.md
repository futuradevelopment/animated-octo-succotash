# P1780: Ford transmission-control switch was not cycled during self-test

Ford’s 1999 P1780 description states that the transmission-control switch must be cycled during the engine-running self-test. If the required cycle is not observed, the code is recorded. This makes correct test execution a primary distinction before diagnosing a failed transmission component.

## Separate an omitted action from a failed signal

The source lists an open or shorted TCS circuit, a damaged switch and PCM damage, but its diagnostic aid is to verify the switch’s on/off cycling. A test performed without the requested operator action and a switch that cannot communicate that action can lead to the same recorded result.

Document whether the switch was actually operated in the prescribed sequence and what the controller saw. A physical button click does not establish that the electrical input changed, while a code from an incomplete sequence does not prove the switch is defective.

## Repeat the correct evaluation before replacing parts

Use the exact vehicle’s Quick Test instructions and transmission-control arrangement. The row supplies no universal connector pin, voltage threshold or switch location. It also does not identify an internal transmission clutch or solenoid as the cause.

If a properly conducted test still fails to observe the transition, a technician should isolate the switch and circuit using the appropriate procedure. Verification after a confirmed correction means reliable on/off input and successful completion of the relevant engine-running test. Clearing P1780 without performing that sequence leaves the stated diagnostic condition untested.

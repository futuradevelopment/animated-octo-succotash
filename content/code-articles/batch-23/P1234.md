# P1234: Ford records the non-MIL version of missing fuel-system feedback

Ford’s 1999 P1234 entry explicitly adopts the P1233 description and identifies one difference: P1234 does not illuminate the malfunction indicator lamp. A dark warning lamp therefore cannot be used to dismiss this stored fuel-system feedback result.

## Establish which feedback architecture is fitted

On the conventional fuel-pump driver module arrangement, the shared description concerns loss of the duty-cycle message reaching the PCM on the FPM circuit. It is not equivalent to a valid 25-percent command-fault message or a 75-percent secondary-circuit message. Complete absence and an explicit fault report call for different diagnostic interpretation.

The shared source also contains an LS6/LS8 exception involving missing fuel-level information over SCP from the rear electronics module. Confirm the actual architecture before searching for a feedback circuit that the application may not use.

## Use stored evidence even without a lamp request

The referenced possible causes include module power or ground loss, feedback wiring problems, inertia-switch concerns and electronic faults. They do not establish that the pump motor failed. Preserve the scan result and accompanying symptoms before resetting memory.

A technician should identify why the applicable feedback is absent and verify its return through the correct procedure. Starting the engine after a reset is weaker evidence than confirming reliable module communication. The non-MIL distinction affects indication; it does not certify fuel-system safety or eliminate the need to investigate an associated stalling or no-start complaint.

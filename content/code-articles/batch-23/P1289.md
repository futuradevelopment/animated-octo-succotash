# P1289: Ford CHT high-input diagnosis changes with the PCM strategy

The Ford 1999 manual prints two P1289 rows under the same high-input heading. One covers PCM strategies through 1998; the other covers strategies labeled 1999 and later. Their circuit interpretations differ, so using the title alone can send diagnosis in the wrong direction.

## Read the strategy split before tracing a fault

For the earlier strategy, the source describes a shorted CHT circuit and lists grounding in the harness. For the later strategy, it describes an open circuit and lists an interruption in the CHT harness. Both also include sensor, connection and PCM concerns.

The companion code note changes accordingly: the earlier row mentions P0117, while the later row mentions P0118. Those references reinforce the need to identify the actual PCM strategy. The manual’s “1999 and later” wording is historical scope, not proof that this interpretation covers every subsequent Ford model year.

## Use a known input to distinguish sensing from reception

Both rows describe comparing a controlled 1.0 V substitute signal with the scan PID. Agreement directs attention toward the sensor; disagreement leaves the related circuit and PCM in question. That comparison requires the correct connector information and professional signal-simulation equipment.

After the applicable strategy is established, investigate the corresponding open or short condition rather than combining both into a single assumed failure. Verification should demonstrate credible CHT information through the original diagnostic conditions. P1289 does not by itself prove actual engine overheating or authorize replacement of the cylinder-head-temperature sensor.

## Source and applicability

This explanation is limited to the applicable systems in Ford’s US-market 1999 PCED. Confirm the vehicle and test application before using its limits. [Ford diagnostic descriptions: P1289 row](https://www.fordservicecontent.dealerconnection.com/pubs/content/~WVX2/~MUS~LEN/14/VX24002.HTM).

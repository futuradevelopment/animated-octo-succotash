# P1383: Ford bank-one cam timing remains too far retarded

The Ford 1999 description identifies P1383 as bank-one variable cam timing that is excessively retarded or remains retarded. The catalog’s community label instead says excessive advance. This article follows the primary historical row and flags the direction mismatch rather than merging opposite conditions.

## Investigate the VCT unit’s movement and oil control

Ford lists improper timing setup, continuous oil flow to the piston chamber, a valve stuck open and a binding advance mechanism. It directs this code toward the VCT unit’s workshop procedure, not an electrical circuit check. That is a different diagnostic branch from P1380.

The source also associates this condition with rough idle, difficult starting and possible stalling. Those symptoms are supported possibilities in the historical description, not a guarantee that every P1383 event will show all three.

## Verify the retarded-position concern in the correct application

Identify the exact engine and strategy before using the code direction. The short row does not publish a cam-angle limit, oil-control specification or mechanical timing procedure. Those omissions cannot be filled by borrowing numbers from another VCT engine.

A technician should establish whether timing, hydraulic operation or mechanical binding explains the recorded position. Verification after correction should show the cam leaves the unwanted retarded state and behaves within the proper calibration. Clearing P1383 without checking position response does not prove the problem is resolved. The conflicting dictionary title remains an editorial review item, not a reason to claim both advance and retard failure simultaneously.

## Source and applicability

This explanation is limited to the applicable systems in Ford’s US-market 1999 PCED. Confirm the vehicle and test application before using its limits. [Ford diagnostic descriptions: P1383 row](https://www.fordservicecontent.dealerconnection.com/pubs/content/~WVX2/~MUS~LEN/14/VX24002.HTM).

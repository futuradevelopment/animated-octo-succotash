# P1290: Ford CHT low-input diagnosis depends on the PCM generation

Ford’s 1999 table contains two P1290 low-input descriptions, divided by PCM strategy. The row for strategies through 1998 describes an open CHT circuit. The row for strategies labeled 1999 and later describes a shorted circuit, including a harness path to ground. The same code title therefore does not supply one universal wiring diagnosis.

## Match the vehicle to the correct row

The earlier description mentions possible companion P0118; the later one mentions P0117. Those details help explain why a generic low-voltage assumption is insufficient without the strategy context. The later label in this historical manual should not be extrapolated to every modern Ford.

Both rows include damaged sensing electronics, incorrect connection and PCM concerns. Their cause lists are alternatives, not evidence that the controller or temperature sensor must be replaced.

## Check whether the controller represents a known signal correctly

The common diagnostic aid compares a controlled 1.0 V simulated input with the scan-tool voltage. Correct representation supports examining the sensing side; a disagreement keeps the wiring and PCM path under investigation. This is a professional diagnostic comparison, not an instruction to apply external voltage without approved equipment and pin identification.

Record the fitted strategy and the relevant fault behavior before repair. Afterwards, verify that the CHT input is credible and the applicable evaluation completes. A cleared P1290 alone does not establish that the earlier open or later short condition has been located, and it does not diagnose the engine’s actual temperature.

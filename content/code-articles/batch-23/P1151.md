# P1151: Ford bank-two upstream oxygen output indicates lean without switching

In the 1999 Ford description, P1151 identifies a lean-indicating no-switch condition on HO2S-21, the bank-two upstream oxygen input. The failure criterion concerns switching absent for the calibrated test period. It does not isolate the oxygen element from the wiring or the engine condition it measures.

## Keep the bank and indication in the diagnostic record

The code’s bank-two identity distinguishes it from P1131. Its lean indication also distinguishes it from P1152 on the same channel. Recording only “oxygen sensor code” removes both useful pieces of information.

Ford sends the reader to P1130’s cause list, which includes electrical connections, fuel delivery, unmetered air, exhaust leakage and engine-system concerns. That reference supports investigating alternatives; it does not rank a vacuum leak, injector or sensor as most likely.

## Explain the remaining source uncertainty

The historical text pairs a lean sensor indication with correction of an over-rich condition. The short description does not explain the test state well enough to infer the engine’s actual mixture from that sentence. This draft therefore retains the explicit lean/no-switch observation and flags the unresolved explanation.

A technician should compare the affected signal with fuel-control and engine evidence under the proper procedure. Once the cause is demonstrated and corrected, verify switching and response on bank two’s upstream channel. A plausible reading on the opposite bank, or an empty fault memory immediately after reset, cannot establish that this test now passes.

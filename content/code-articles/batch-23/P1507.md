# P1507: Ford actual idle speed stays below the requested speed

Ford P1507 in the 1999 PCED reports idle speed below the PCM’s desired rpm. It is an underspeed result, so the requested idle and actual speed need to be recorded together. The row does not provide a universal rpm threshold that can replace that comparison.

## Separate restricted airflow from an unoperated actuator

The listed possibilities include a plugged air inlet, an open IAC circuit, a control path shorted to power, loss of solenoid supply, solenoid damage and PCM damage. These alternatives span the air path and the actuator’s electrical operation.

Consequently, an engine that idles low does not automatically need an idle valve. A blocked inlet can matter, and an intact valve cannot operate correctly if its required supply or control path is interrupted.

## Use the specified IAC test in context

The historical aid gives a 6–13 ohm coil range and discusses the lack of an rpm change when the IAC is disconnected as evidence relevant to a stuck or damaged valve. Neither observation should be transplanted to a different actuator design or used without the proper test conditions.

A technician should establish the actual cause, then verify that idle follows the requested target and the applicable evaluation completes. A one-time normal idle after clearing memory does not establish reliable airflow or control. The source does not justify altering a throttle stop or replacing the PCM before the documented inlet and circuit possibilities are investigated.

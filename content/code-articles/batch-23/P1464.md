# P1464: Ford A/C demand was active when self-test expected otherwise

Ford P1464 in the 1999 table reports that the ACCS input to the PCM was high during self-test. The most immediate distinction in the diagnostic aid is whether A/C or defrost was on when the evaluation was performed. If so, the source directs a repeat with those functions off.

## An operator condition and a circuit fault can produce the same test result

The source lists active A/C during testing, a demand-circuit short to power, a damaged demand switch, relay or constant-control-relay-module damage and PCM damage. For applications using normally closed WAC relay contacts, it also lists a clutch-power circuit short to power.

That application-specific relay condition means the same wiring assumption should not be applied to every A/C arrangement. Establish which system is fitted and what the demand input actually showed during the test.

## Repeat the properly prepared test before selecting a part

Record the A/C and defrost selections together with the ACCS state. If the code disappears when the prescribed test conditions are correctly established, that is different evidence from an input that remains high despite the relevant controls being off.

A technician should investigate the latter using the correct demand and relay circuits rather than replacing an A/C pressure sensor or altering refrigerant charge. Verification requires a valid self-test with the intended demand state. The short P1464 description does not diagnose compressor performance or supply a universal relay pinout.

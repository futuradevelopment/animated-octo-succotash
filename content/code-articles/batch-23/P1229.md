# P1229: Ford commands the supercharger intercooler pump but detects no current

In this Ford 1999 description, P1229 occurs when the PCM requests operation of the supercharger intercooler pump but does not detect the expected current. The combination of an active command and missing current is the important evidence. A command PID reading “on” does not prove the pump received power or operated.

## Trace the operating path rather than replacing the pump immediately

Ford’s listed causes include an open motor, an open relay coil, an interrupted relay-to-pump circuit, an interrupted PCM-to-relay circuit and a poor motor ground. It also lists a shorted motor and PCM damage. These possibilities cover the command, relay, supply and load portions of the system.

The diagnostic aid highlights relay voltage, the supply fuse and the pump ground. Those checks help distinguish a pump that cannot receive a valid supply from a pump motor that fails despite a correct operating path. The row provides no universal fuse number or relay-terminal pinout.

## Verify command and electrical response together

Record the pump command state and use the appropriate vehicle procedure to establish where expected operation is lost. Testing around electrical loads and hot supercharger cooling components requires suitable professional precautions.

After a demonstrated cause is corrected, verification should establish that the commanded pump draws the expected current under the applicable test, rather than relying on a cleared code or a changed PID alone. This electrical-current monitor does not independently prove coolant circulation through every part of the intercooler circuit.

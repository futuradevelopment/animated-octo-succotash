# P1288: Ford cylinder-head temperature is outside self-test conditions

P1288 is Ford’s historical cylinder-head-temperature self-test range code. The description explicitly notes that the engine may not be at operating temperature. This makes test preparation part of the diagnosis rather than evidence to ignore when selecting a sensor.

## Cold and overheating conditions lead to different decisions

The diagnostic aid distinguishes an engine that is cold from one that overheats. For a cold engine, the applicable self-test should be repeated after proper preparation. If the engine is overheating, the source directs attention to the cooling system instead of treating additional warm-up as the solution.

The possible-cause list includes low coolant, overheating, connector damage, a damaged CHT sensor and PCM damage. Thus P1288 does not distinguish an actual thermal condition from a temperature input that misrepresents it.

## Verify test eligibility and input credibility

Document the self-test mode, reported cylinder-head temperature and actual engine condition. The row supplies no numerical operating-temperature threshold or universal CHT voltage window, so values from a different ECT or CHT code should not be imported as if they were specified here.

Any coolant inspection must observe precautions for a hot, pressurized system. A technician should establish whether the test conditions were unmet or a real cooling/electrical fault exists, then repeat the appropriate evaluation after correcting that cause. A plausible reading once the engine has cooled is not enough to prove that an overheating event or intermittent temperature-input problem is resolved.

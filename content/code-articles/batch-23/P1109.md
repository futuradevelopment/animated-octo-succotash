# P1109: Ford IAT2 signal has an intermittent interruption

In Ford’s 1999 diagnostic descriptions, P1109 points to an intermittent open or short in the second intake-air-temperature circuit while the engine was running. The channel identification matters: an ordinary IAT reading from a scan tool may be a different input from IAT2.

## Look for a discontinuity on the correct channel

Ford’s diagnostic aid calls for observing IAT2 while the relevant harness is disturbed or the sensor is lightly tapped. A sudden change is the observation being sought. The description does not provide a numerical temperature jump or a voltage threshold, so a specific cutoff should not be invented from another temperature-sensor code.

The stated possible causes span the harness, connector, sensor and PCM. This breadth means the stored code does not distinguish a broken conductor from an intermittent connection inside the sensor. The point of correlating a signal change with a localized disturbance is to narrow that uncertainty.

## Preserve the operating context

Record the IAT2 channel, engine state and circumstances in which the interruption occurs. An acceptable temperature with the vehicle stationary is only a current reading; it does not invalidate the earlier engine-running event. Conversely, a temperature that merely changes gradually is not the sudden interruption described in this row.

Use the exact vehicle’s component identification before selecting a connector or a replacement sensor. Verification should address the same channel and the reproducible condition that originally disturbed it. The source does not establish a universal IAT2 location or prove that every 1999 Ford has a second intake-temperature sensor.

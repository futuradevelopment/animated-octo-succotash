# P1703: Ford brake-pedal signal does not match the self-test sequence

Ford’s 1999 P1703 description distinguishes two self-test failures. During key-on, engine-off testing, the brake-pedal-position input is high when the test does not expect it. During the engine-running test, the required high/low transition is not seen. Those are different observations and should be recorded with the test mode.

## Check the procedure and the brake input together

The source directs verification of stoplamp operation and the correct Quick Test sequence. A missed operator action can invalidate the evaluation, while a signal that remains incorrect during a properly performed test requires circuit diagnosis.

Possible causes include open or shorted brake-input or stoplamp wiring, a damaged or misadjusted brake switch, PCM damage and concerns in connected modules. The description identifies different connected modules for particular applications, so the shared signal path must be traced using the exact vehicle diagram.

## Lamp operation is useful but not the whole test

Working stoplamps provide evidence about one function, but the PCM must also receive the required input states during the diagnostic sequence. Conversely, a stoplamp fault is a concrete reason to investigate the related circuit rather than immediately replacing the PCM.

A technician should establish proper adjustment, circuit behavior and test execution, then repeat the applicable evaluation. Brake-system and stoplamp concerns warrant appropriate professional attention. Clearing P1703 or obtaining one correct pedal reading does not establish that the required state transitions are reliable or that the vehicle’s braking systems have been fully assessed.

# P1181: Ford natural-gas fuel delivery is inferred too high

Ford’s 1999 P1181 description concerns the natural-gas fuel-delivery system. The PCM obtains fuel-tank-pressure information from the natural-gas module and evaluates inferred fuel-rail pressure. The reported failure is an inferred pressure above the calibrated maximum.

## The inference and application both matter

This is not a universal definition of a gasoline rail-pressure sensor circuit. The natural-gas module and its pressure information are explicit parts of the documented strategy. Confirm those components and the exact vehicle application before using this article to interpret a scan result.

The monitor’s inferred value also needs to be distinguished from an independent physical pressure measurement. The stored code records the controller’s evaluation, not a workshop test proving the actual rail pressure at every operating condition.

## Use the regulator lead without treating it as a verdict

The source names the fuel-pressure regulator as a possible cause. It gives no numerical pressure ceiling, adjustment method or replacement instruction in this row. A listed cause is a reason for the relevant professional diagnostic test, not enough evidence to order a regulator.

Preserve the pressure information and circumstances of the event, then follow the applicable natural-gas service procedure to establish whether pressure control is actually at fault. Verification should show that the delivery-pressure evaluation stays within the correct calibration under the relevant conditions. High-pressure gas components require suitable training and equipment; the absence of a current code does not establish that fittings can safely be opened.

## Source and applicability

This explanation is limited to the applicable systems in Ford’s US-market 1999 PCED. Confirm the vehicle and test application before using its limits. [Ford diagnostic descriptions: P1181 row](https://www.fordservicecontent.dealerconnection.com/pubs/content/~WVX2/~MUS~LEN/14/VX24002.HTM).

# P1650: Ford power-steering switch input is outside the expected range

Ford’s 1999 P1650 description concerns the power-steering-pressure switch input falling outside its expected calibrated range. The row also describes it as a self-test range result. This switch arrangement must not be confused with the variable pressure-sensor procedure associated with P1550.

## Observe whether the input changes with steering load

The chart routes P1650 to pinpoint FF. Its first check observes the PSP PID while steering load changes; the Taurus/Sable variant uses a voltage PID. A changing input and an input that remains fixed lead to different diagnostic branches.

The source lists the switch or shorting bar, an open signal return, an open or grounded PSP circuit and PCM damage. These possibilities prevent the code from identifying a hydraulic pump as the automatic replacement target.

## Separate the switch from the receiving circuit

The linked procedure uses a controlled open/closed substitution at the proper connector to determine whether the input circuit can represent both states. If it cannot, subsequent checks examine continuity and shorts before reaching a controller conclusion. That diagnostic logic is useful; it is not permission to bridge unknown steering connectors.

A technician should use the exact application and safe controlled conditions, then verify the relevant input response and self-test after a demonstrated correction. The historical FF procedure contains model-specific voltage and connector details, so this article does not turn them into a universal specification for all Ford power-steering systems.

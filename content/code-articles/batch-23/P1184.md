# P1184: Ford oil-temperature input is outside engine-running self-test range

Ford P1184 concerns the engine-oil-temperature input during self-test in the documented 1999 system. The row gives a 0.3–1.2 V acceptable range for the key-on, engine-running evaluation. That is a test-state specification, not a universal temperature-to-voltage curve for all Ford oil-temperature sensors.

## Record the test state with the voltage

A voltage recorded with the engine stopped or under a different diagnostic strategy should not be judged automatically against this KOER window. Identify which test produced the code and preserve the actual EOT input at that time.

The source lists harness, connector, sensor and PCM damage as possible explanations. The range result alone cannot identify which of those produced the incorrect input.

## A known-input comparison separates two questions

Ford’s aid describes comparing a controlled 1.0 V simulated signal with the scan-tool PID voltage. Correct representation of that known input points the investigation toward the sensor; disagreement leaves the receiving circuit or PCM to examine. This is the diagnostic logic, not an instruction to inject voltage without the correct connectors and service equipment.

A qualified technician should use the exact application’s procedure and establish whether the signal or the sensing element is responsible before selecting a repair. Afterwards, confirm a credible EOT input and a completed engine-running self-test within the applicable window. P1184 does not, on its own, establish excessive oil temperature, inadequate lubrication or a need for an oil change.

## Source and applicability

This explanation is limited to the applicable systems in Ford’s US-market 1999 PCED. Confirm the vehicle and test application before using its limits. [Ford diagnostic descriptions: P1184 row](https://www.fordservicecontent.dealerconnection.com/pubs/content/~WVX2/~MUS~LEN/14/VX24002.HTM).

# P1414: Ford secondary-air feedback stays high when the pump is commanded off

The historical Ford P1414 evaluation finds the AIR monitor circuit high even though the PCM has commanded the electric secondary-air pump off. The reported indication is therefore inconsistent with the requested state. It should not immediately be translated into proof that the pump is physically running continuously.

## A high monitor input has several explanations

Ford’s possible causes include an open monitor circuit from the pump, a circuit shorted to power, a damaged solid-state relay, an open pump ground, pump damage and PCM damage. Several involve how the state is represented electrically, rather than only a relay stuck on.

That breadth is useful: watching the pump or listening for it can provide context, but the monitor path and ground still need to be checked with the correct circuit information.

## Use the off command as part of the evidence

Record the requested pump state and corresponding feedback. P1413 is the opposite command mismatch in the same source—low feedback during an on command. Keeping the direction straight determines which behavior must be reproduced and verified.

A technician should isolate the documented electrical cause using the exact AIR arrangement. Verification after repair requires feedback appropriate to the off state and correct behavior when operation is subsequently requested. Clearing the code does not establish that either state was tested. The description provides no universal pinout or voltage threshold and does not prove an exhaust-flow problem merely because it names the secondary-air system.

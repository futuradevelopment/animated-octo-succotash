# P1462: Ford historical A/C pressure input is below its voltage limit

Ford’s 1999 description gives P1462 a low A/C pressure-sensor voltage meaning. It says the PCM records the code when the ACP input drops below its calibrated level. This catalog’s community title instead identifies a high input, so the discrepancy remains visible and flagged.

## Low voltage does not establish low refrigerant charge

The primary row lists a signal path shorted to ground or signal return, an open reference supply, an open ACP circuit, sensor damage and PCM damage. These are electrical possibilities. The code alone is not an independent pressure measurement or proof that refrigerant should be added.

The diagnostic aid specifies a 4.0–6.0 V reference-supply check for the documented arrangement. That figure should not be mistaken for the ACP signal’s low-failure threshold, which the row does not publish numerically.

## Confirm the definition and then isolate the circuit concern

Before applying this historical interpretation, identify the exact vehicle strategy and its high/low code assignments. A technician can then use the correct circuit diagram and pressure-sensor test to establish whether the input is being pulled low or is otherwise misrepresented.

After correcting a demonstrated cause, verify that the input is credible and the relevant diagnostic evaluation passes. Do not use P1462 alone to open refrigerant lines, alter charge or replace a compressor. Those actions require separate A/C evidence and proper equipment, and they would not resolve an unverified reference-supply or signal-circuit problem.

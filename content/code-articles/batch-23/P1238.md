# P1238: Ford records the non-MIL secondary fuel-pump circuit fault

Ford P1238 is the non-MIL counterpart of P1237 in the 1999 description table. Its explicit cross-reference adopts the secondary fuel-pump circuit diagnosis, while noting that P1238 itself does not illuminate the malfunction indicator lamp.

## Identify the pump-side electrical path

The referenced procedure concerns faults detected between the pump module and fuel pump. Listed possibilities include the power conductor, the controlled return, internal pump circuits, a locked rotor and the module itself. This is different from P1235/P1236, which concern the command received from the PCM.

For the conventional FPM arrangement, a 75-percent feedback duty cycle reports the secondary fault. The source’s return-side speed-control description means a technician must use the correct circuit diagram rather than assuming the pump return is a simple fixed ground.

## Preserve history and verify the right implementation

The referenced row retains the diagnostic record after the active fault disappears. It also distinguishes LS6/LS8 rear-module/SCP communication from conventional FPM wiring. Both details affect how a presently normal scan or an absent warning lamp should be interpreted.

The P1237 cross-reference contains an inconsistent sentence naming the sender of the normal feedback message; that attribution is not used here and remains flagged. Follow the applicable vehicle procedure to identify the actual secondary-circuit cause, then verify reliable operation under the conditions that revealed it. P1238 alone neither proves pump-motor failure nor establishes that the fuel system can be opened safely.

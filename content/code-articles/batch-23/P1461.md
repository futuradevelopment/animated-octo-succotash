# P1461: Ford historical A/C pressure input is above its voltage limit

The Ford 1999 primary table labels P1461 as high A/C pressure-sensor voltage and says the PCM records it when the input exceeds the calibrated level. The community dictionary used by this catalog labels P1461 as low input. Because those directions conflict, this article explicitly describes the historical primary source and remains marked for review.

## Establish the electrical definition before judging refrigerant pressure

The monitored quantity in this row is sensor voltage. A high electrical signal does not by itself prove excessive physical refrigerant pressure. The source lists signal-path opens or shorts, sensor damage and PCM damage among its possible causes.

Ford’s diagnostic aid calls for confirming a reference-voltage supply between 4.0 and 6.0 V in the applicable system. That range is a reference-supply check, not the missing high-input trigger threshold and not a universal ACP sensor-output specification.

## Resolve the application and signal path

A technician should establish the vehicle’s exact code definition and circuit arrangement before applying a directional diagnosis. Use the appropriate pressure-sensor procedure to distinguish a supply, signal or return concern from an actual A/C-system condition.

Verification after a demonstrated correction should establish a credible pressure input and the proper diagnostic result. The abbreviated row does not authorize adding or removing refrigerant, replacing the compressor or assuming a particular pressure value. The dictionary conflict cannot be settled simply by choosing whichever high/low label matches a preferred repair.

## Source and applicability

This explanation is limited to the applicable systems in Ford’s US-market 1999 PCED. Confirm the vehicle and test application before using its limits. [Ford diagnostic descriptions: P1461 row](https://www.fordservicecontent.dealerconnection.com/pubs/content/~WVX2/~MUS~LEN/14/VX24002.HTM).

# P1245: Ford historical generator-load input is above its limit

Ford’s 1999 primary table calls P1245 a high generator-load input. It describes the PCM seeing an input above its calibrated limit for the required interval. The community dictionary attached to this catalog instead labels the code as a low alternator-load input. Those opposite directions cannot be treated as interchangeable.

## Establish which definition applies

For the historical source covered here, the documented direction is high. The row gives no numerical boundary or timer value, so neither can be supplied as a universal specification. Confirm the vehicle’s control strategy and service definition before applying even that directional interpretation.

The possible causes include an open or shorted load-input circuit, regulator/generator damage and PCM damage. Ford uses GLI in the description and ALI in the cause list; that terminology does not establish a connector layout or a particular signal type for every application.

## Compare charging function with the input concern

The diagnostic aid calls for checking charging-system operation. That provides useful context, but a charging observation alone does not isolate the load-information path. The generator can only be condemned after the relevant system checks establish its role in the fault.

Preserve the signal and operating conditions, follow the correct vehicle procedure, and verify the load input together with charging performance after a confirmed correction. This draft remains flagged because the catalog and primary historical source disagree on direction. It should not be used to reverse a modern vehicle’s service specification or justify a blind alternator replacement.

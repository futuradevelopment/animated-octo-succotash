# P1236: Ford stores a non-MIL fuel-pump command-range fault

Ford’s P1236 description points directly to P1235 and states that P1236 does not illuminate the malfunction indicator lamp. The underlying result still concerns a fuel-pump module receiving an invalid or missing control signal from the PCM. The different lamp behavior does not change which information path is implicated.

## Interpret the message instead of assuming a failed pump

In the conventional arrangement described by the referenced row, the module reports the command fault with a 25-percent FPM duty cycle. It returns to the normal 50-percent message when the condition is no longer detected, while the diagnostic record remains in continuous memory.

That history explains how a technician can find a stored code and a currently normal feedback message together. It also distinguishes this result from a 75-percent message about a secondary pump circuit.

## Confirm module architecture and repeatability

The same source identifies an LS6/LS8 rear-electronics-module implementation using SCP diagnostic information, without the conventional FPM circuit. Determine which implementation applies before selecting a signal test.

For the applicable system, investigate the command circuit and the two communicating controllers according to the correct procedure. The source does not rank those candidates or establish that the pump itself is defective. Verification should show that the command remains valid and the appropriate status information stays normal under the conditions that exposed the fault. A dark warning lamp or a temporarily normal idle is not a substitute for that evidence.

## Source and applicability

This explanation is limited to the applicable systems in Ford’s US-market 1999 PCED. Confirm the vehicle and test application before using its limits. [Ford diagnostic descriptions: P1236 row](https://www.fordservicecontent.dealerconnection.com/pubs/content/~WVX2/~MUS~LEN/14/VX24002.HTM).

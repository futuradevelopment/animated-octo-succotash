# P1516: Ford bank-one intake-runner input needs mechanical and feedback checks

Ford’s 1999 description heading identifies P1516 as the bank-one intake-manifold-runner control input error, but the body cells are blank. Useful diagnostic support comes from the chart’s HU15 route and the pinpoint procedure that explicitly lists P1516 among the applicable codes. This article uses that direct evidence rather than inventing missing monitor thresholds.

## Begin with the runner mechanism identified by the procedure

HU15 checks linkage or cable routing, binding and whether the mechanism reaches its closed stop. It also considers return-spring operation and full movement. These details matter because an input error can be associated with a runner that does not physically achieve the expected position.

The following physical test separates runner binding from the actuator mechanism. Exact procedures vary by the application identified in the manual; a bank-one label does not establish a universal lever location or connector pin.

## Compare commanded movement with the observed result

The documented functional test commands the system and checks whether the mechanism moves from closed to fully open and remains there. That gives a second distinction: actual movement must be considered alongside feedback, rather than treating the code as proof of a failed electrical sensor.

Strong return springs and powered mechanisms require professional precautions; keep hands clear during actuation. After a demonstrated cause is corrected, verify the specified movement and input behavior through the proper test. The blank description row leaves the exact standalone P1516 monitor criterion unresolved, which remains flagged.

# P1137: Ford bank-one downstream oxygen channel does not respond lean as expected

For the documented 1999 Ford strategy, P1137 concerns HO2S-12, the bank-one downstream oxygen channel, with a lean-indicating no-switch result. The PCM deliberately drives the mixture rich and lean and watches the downstream output. Failure to detect the expected output within the calibrated interval produces the described result.

## A commanded response test is different from an idle snapshot

The source does not publish the time limit in this row. A rear sensor’s voltage at one moment therefore cannot be substituted for the complete forced-response evaluation. The diagnostic record should identify the commanded condition, the correct downstream channel and what response was actually observed.

Possible causes include damaged or contaminated sensing elements, exhaust leaks, crossed signal wires and wiring or terminal defects. This keeps the investigation broader than an automatic oxygen-sensor replacement.

## Confirm channel identity and test response

P1138 is the rich-indicating companion on the same downstream channel; Ford explicitly refers it back to the P1137 test description. That shared procedure does not make the reported indication interchangeable.

A technician should establish that the scan channel belongs to bank one’s rear sensor and use the applicable approved test to separate signal-path faults from exhaust or sensor behavior. Verification should repeat the relevant response evaluation after the confirmed cause is addressed. The table supplies no universal voltage cutoff, connector pinout or replacement interval, so none can be inferred from the code alone.

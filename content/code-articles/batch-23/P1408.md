# P1408: Ford EGR flow is too low during the engine-running self-test

Ford’s 1999 P1408 test runs specifically during the key-on, engine-running on-demand self-test. The controller commands EGR at a fixed engine speed and evaluates whether measured flow reaches the calibrated minimum. The test mode is a defining part of this code’s meaning.

## Separate the on-demand result from road monitoring

The source points to P0401 for possible causes. That entry covers the steady-driving EGR-flow monitor and describes P1408 during self-test as evidence of a hard fault. A P0401 record without P1408 directs attention to restrictions, leaks, contamination and intermittent conditions rather than proving the on-demand evaluation failed.

The referenced cause list includes vacuum supply, valve operation, restricted flow passages, regulator control, pressure-sensor reference supply and hose-routing problems. Thus low measured flow can arise from actual delivery or from the information used to estimate it.

## Repeat the correct EGR evaluation

Record that P1408 came from the engine-running self-test and preserve the measured response. The row does not state the fixed engine speed or numerical flow minimum, so those values must come from the exact application procedure rather than a generic internet specification.

A technician should determine whether the EGR path, vacuum/control system or feedback system accounts for the low result. After a confirmed correction, repeat the applicable on-demand test. A cleared fault memory or an EGR valve that moves by itself does not establish that measured flow now meets the required minimum.

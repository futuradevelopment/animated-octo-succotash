# P1460: Ford A/C relay primary control fails its electrical check

Ford’s 1999 P1460 description evaluates the wide-open-throttle A/C cutout primary control circuit. For applications using a normally open relay, the same description applies to the A/C clutch relay-control path. Relay design therefore needs to be established before interpreting the circuit.

## The commanded state determines the electrical test

When the PCM grounds the control, excessive current indicates failure. When it does not ground the control, the PCM expects supply voltage through the relay coil. Missing that expected voltage is a different failure condition.

Ford lists open or shorted control wiring, lost relay supply, relay or constant-control-relay-module damage and PCM damage. The self-test cycles the circuit on and off, so one static voltage without command context is incomplete evidence.

## Check equipment and operator conditions first

The source says A/C and defrost should be off during the key-on self-tests and suggests confirming the demand input through the ACCS PID. It also says this code can be disregarded on a vehicle not equipped with A/C. That exception belongs to this historical test context, not every modern P1460 definition.

A technician should verify equipment, test preparation and the correct relay circuit before selecting a repair. Afterwards, repeat the electrical evaluation through both requested states. The code does not independently establish low refrigerant charge or a failed compressor; those concerns require their own supported evidence.

# P1729: Ford does not see the expected low-range switch state

Ford’s 1999 P1729 description concerns the 4x4-low switch input. The switch is treated as an on/off device, and the PCM expects low voltage when the switch is on. Failure to see that low state produces the described result.

## Distinguish the selected function from the received input

An operator selecting low range does not, by itself, establish that the PCM received the expected electrical state. The diagnostic aid calls for verifying that the switch cycles on and off. The useful record therefore includes the intended state and the observed input transition.

Ford lists an open or shorted low-range harness, electronic shift-module damage and PCM damage. The row does not prove a mechanically failed transfer case or specify that the switch itself is the only possible cause.

## Use the applicable transfer-system procedure

The description does not give a universal low-voltage threshold or the conditions for engaging low range. Those must come from the exact vehicle’s operating and service instructions. Do not force a transfer-mode change under unsuitable driving conditions merely to reproduce the code.

A technician should identify the actual low-range input arrangement and demonstrate where the expected signal is lost. Verification after correction should show reliable on/off representation during the proper test. P1729 alone cannot establish that the transfer case has mechanically completed a shift, and clearing the code does not substitute for checking the documented electrical transition.

# P1127: Ford exhaust was too cool for the downstream oxygen test

Ford’s 1999 P1127 description says the downstream oxygen-sensor test was not performed because the exhaust was insufficiently warm. The strategy uses an inferred exhaust-temperature model when deciding heater operation. This is a test-condition finding, not direct proof of an open heater or a defective oxygen sensor.

## Establish whether the test was eligible

The source names insufficient engine operating time before the engine-running self-test and an exhaust system that remains too cool. It does not publish a universal minimum temperature, drive distance or warm-up duration in this row. Inventing one would remove the calibration context that determines when the test can run.

Ford directs attention to the oxygen-heater PID states. Those states help show whether the intended evaluation was being permitted. A heater shown off while the temperature model has not enabled it is a different situation from a heater that fails after a valid command.

## Repeat under the prescribed conditions

Follow the applicable self-test preparation, with suitable ventilation and precautions around hot exhaust components. Record whether P1127 recurs after the documented warm-up conditions have been satisfied. A successful downstream evaluation after adequate preparation resolves a different question from an electrical heater repair.

If another oxygen-sensor or heater fault is present, evaluate it using its own definition and test. P1127 does not establish that all oxygen-sensor circuits are healthy; it explains why this particular downstream test lacked the thermal conditions it needed.

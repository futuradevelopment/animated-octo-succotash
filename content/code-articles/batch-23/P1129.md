# P1129: Ford downstream oxygen signals do not follow the expected bank

P1129 in this Ford manual concerns the downstream oxygen-sensor channels, HO2S-12 and HO2S-22. The monitor changes fueling and checks whether the expected sensor response belongs to the intended engine bank. A missing expected response is the diagnostic result described by the row.

## Activity does not prove correct routing

A rear oxygen channel can be electrically active yet assigned to the opposite bank. For this reason, viewing two changing voltage traces is not enough: the response must correspond to the fuel change applied to the correct side of the engine.

The source lists crossed downstream harness connectors and crossed wiring, including at the applicable 104-pin connection. It does not give a universal connector location or identify which terminals have been swapped. Those details require the exact engine and harness documentation.

## Verify the downstream channel identities

P1128 is the upstream counterpart in the same manual. That distinction directs the investigation toward the rear sensor identities for P1129 rather than treating all oxygen-sensor bank codes as interchangeable.

A technician should document the channel labels, physical bank assignment and response during the approved diagnostic procedure. If wiring is corrected, repeat the bank-response evaluation; merely erasing the stored code does not show that the channels now match. The available description supports checking routing before condemning a sensor, but it does not claim every P1129 event is caused by a recent wiring repair or provide a universal replacement solution.

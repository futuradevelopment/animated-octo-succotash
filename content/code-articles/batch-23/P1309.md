# P1309: Ford’s misfire monitor is disabled by missing or unsuitable input

Ford P1309 in the 1999 table means the misfire monitor is disabled. The description particularly associates this with the camshaft-position signal generated as the CMP wheel passes the sensor. A disabled monitor is different from a completed monitor reporting that a cylinder misfired.

## Do not interpret unavailable monitoring as a clean result

The absence of a cylinder-specific misfire code while P1309 is present does not establish that combustion is normal. The controller may lack the input needed to perform the evaluation. This distinction matters when a vehicle runs poorly but the scan report contains no P030x result.

Ford’s possible-cause list includes the CMP sensor and PCM, and also names ECT, MAF and CKP inputs. The table does not rank those components or provide a universal signal waveform. Its specific diagnostic aid is to verify CMP installation and synchronization.

## Check signal context before replacing parts

Establish whether the applicable camshaft sensor is installed and synchronized according to the correct engine procedure, particularly when interpreting the actual signal relationship. A sensor that produces activity is not automatically providing the correctly timed information expected by the monitor.

After a demonstrated input or installation issue is corrected, verification should establish that misfire monitoring becomes available and completes its relevant evaluation. Clearing P1309 without confirming monitor operation leaves the original diagnostic gap unresolved. The source does not support replacing ignition coils or injectors solely because the word “misfire” appears in this code’s description.

# P1400: Ford EGR differential-pressure signal is too low

P1400 in the 1999 Ford table concerns low voltage on the differential-pressure-feedback EGR sensor input. The monitor evaluates the average signal reaching the PCM against a calibrated minimum. A low electrical input is not, by itself, proof that the EGR passage is blocked.

## Use the electrical criterion in its proper scope

Ford’s diagnostic aid identifies a DPFE PID below 0.2 V with the key on, either engine stopped or running, as a hard-fault indication for the documented system. That threshold applies to this historical input and should not be treated as a universal pressure-sensor specification.

The source lists the signal circuit shorted to ground, the reference supply shorted to ground, a damaged sensor and PCM damage. Those possibilities direct the investigation toward the signal and reference paths before assuming a mechanical EGR-flow restriction.

## Distinguish voltage failure from flow failure

The same manual contains separate EGR-flow evaluations. P1400’s useful distinction is that the pressure-feedback information itself is electrically low. A controller cannot interpret EGR flow reliably if that input does not represent the intended sensor signal.

Record the DPFE voltage and operating state, then use the correct circuit procedure to identify which path is responsible. After a confirmed repair, verify a credible signal through the applicable monitor conditions. Do not apply external voltage or replace the EGR valve solely from P1400; the row does not establish either as the appropriate remedy.

## Source and applicability

This explanation is limited to the applicable systems in Ford’s US-market 1999 PCED. Confirm the vehicle and test application before using its limits. [Ford diagnostic descriptions: P1400 row](https://www.fordservicecontent.dealerconnection.com/pubs/content/~WVX2/~MUS~LEN/14/VX24002.HTM).

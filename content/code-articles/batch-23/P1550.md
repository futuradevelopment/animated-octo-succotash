# P1550: Ford power-steering pressure sensor fails its input evaluation

The 1999 Ford description says P1550 occurs when the continuously monitored power-steering-pressure sensor input falls outside its calibrated range. The description row is brief, but the diagnostic chart routes it to pinpoint DT, which provides useful test-state and circuit distinctions.

## Confirm that the self-test action occurred

DT1 first asks whether the steering wheel was moved at least half a turn within the initial 30 seconds of the engine-running test. If that operator action was omitted, the procedure directs a repeat of the Quick Test. This means an unperformed test action must be separated from a demonstrated sensor defect.

The historical procedure then checks the sensor’s reference supply, specifying 4.0–6.0 V in the relevant test. It separately examines reference, signal and return continuity before judging sensor operation.

## Compare pressure-input response after the circuit checks

The later functional step watches the signal change as steering load changes, using a 0.5–4.5 V response range in that particular application. These values are not universal specifications for every Ford steering system or for a simple pressure switch.

A technician should follow the full application-specific sequence rather than applying a replacement conclusion from its final step alone. Steering-system checks require controlled conditions and appropriate precautions. After a confirmed correction, verify the required input response and a properly conducted self-test. P1550 alone does not establish a failed hydraulic pump or prove steering assistance is safe.

# P1237: Ford fuel-pump module detects a secondary-circuit problem

In the 1999 Ford description, P1237 reports a secondary fuel-pump circuit fault detected by the fuel-pump driver module. The affected side is the electrical path between the controller and pump, rather than merely the PCM’s command input to the module.

## Separate pump-side feedback from command faults

The conventional FPM arrangement uses a 75-percent duty-cycle message for the detected secondary fault. A normal message is approximately 50 percent. These values describe diagnostic feedback; they are not fuel-pump speed settings to apply externally.

Ford lists open or shorted pump-power wiring, an open return path, faults inside the pump, a locked rotor and module damage. It also notes that the module varies the pump’s return-side control. That makes the return path important, rather than treating every return conductor as an ordinary fixed chassis ground.

## Follow the fitted architecture and retain history

For LS6/LS8, the functions sit in the rear electronics module and diagnostic information travels over SCP; relay-associated circuits are also listed. Use the appropriate architecture’s procedure.

The row retains P1237 in continuous memory after the fault ceases. One sentence misidentifies the sender of the returning normal message; this draft flags the wording and does not adopt that sender claim. The useful distinction remains current feedback versus stored history. A technician should locate the demonstrated secondary-path problem and verify normal operation under the relevant load, using proper fuel-system precautions rather than assuming the pump motor is the only possible cause.

# P1409: Ford EGR vacuum-regulator solenoid circuit is outside its expected range

P1409 in the 1999 Ford description evaluates the electrical function of the EGR vacuum-regulator solenoid. The test fails if circuit voltage is outside the expected range. Ford explicitly notes that EGR must be enabled for this evaluation to complete.

## An unrun test is not a passing electrical check

That enable condition matters when interpreting a cleared code. If the EGR system never became eligible for monitoring, the absence of a repeated P1409 does not demonstrate that the solenoid circuit has passed.

The listed causes include an open control circuit, loss of supply voltage, a control path shorted to supply or ground, a damaged solenoid and PCM damage. These are electrical alternatives. They should not be replaced by an assumption that the EGR passage needs cleaning.

## Use the coil specification only for the applicable component

The source gives a 26–40 ohm solenoid resistance range. This is the historical EGRVR component specification in the row, not a universal resistance for all EGR actuators. Correct component identification and the approved isolated-circuit test conditions are required before applying it.

A technician should establish whether supply, control wiring, coil or controller behavior is responsible. Verification then needs correct electrical operation during an enabled EGR evaluation. A moving valve or restored engine idle is not, by itself, proof that the monitored solenoid voltage meets its requirements. The description does not publish a universal high/low voltage threshold for this test.

## Source and applicability

This explanation is limited to the applicable systems in Ford’s US-market 1999 PCED. Confirm the vehicle and test application before using its limits. [Ford diagnostic descriptions: P1409 row](https://www.fordservicecontent.dealerconnection.com/pubs/content/~WVX2/~MUS~LEN/14/VX24002.HTM).

# P1112: Ford intake-air-temperature signal is intermittent

Ford P1112 identifies intermittent behavior of the intake-air-temperature signal during comprehensive component monitoring in the documented 1999 application. It does not, by itself, say the air is continuously too hot or too cold. The event is a loss of consistent electrical information from the IAT circuit.

## Choose evidence that can reveal the interruption

The manual’s diagnostic aid is to watch the IAT PID for a sudden change while the associated wiring or sensor is gently disturbed. A temperature display that remains reasonable between events does not exclude this kind of fault. Equally, the description supplies no numerical jump threshold, so a gradual change should not be classified using an invented limit.

Ford names damage to the harness, its connector, the sensor and the PCM as possible causes. Because all four are listed, reading P1112 is only the starting point for separating a connection problem from the sensing or receiving electronics.

## Avoid confusing IAT with IAT2

This row addresses IAT; the same manual separately identifies IAT2 intermittent behavior under P1109. Verify which channel the scan tool is displaying and which input the vehicle actually uses. Substituting the second channel’s connector or specification would leave the recorded fault unexplained.

A technician should preserve the original circumstances and determine whether a particular harness area or connection reproduces the disturbance. Confirmation after correction means the relevant IAT signal remains stable under that repeatable condition and the appropriate diagnostic evaluation completes, not simply that the display shows a plausible temperature once.

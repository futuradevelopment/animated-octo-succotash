# P1705: Ford transmission-range self-test depends on the transmission application

Ford’s 1999 P1705 description heading identifies a transmission-range self-test problem, but its explanatory cells are blank. The diagnostic chart supplies a critical distinction: selected manual-transmission applications route to pinpoint TA5, while automatic-transmission applications are directed to the transmission workshop diagnosis through Note 3.

## Do not use one range-sensor procedure for both arrangements

The TA5 section explicitly lists P1705 and evaluates the clutch-pedal/park-neutral input. Its note requires the clutch down and the gear lever in neutral during the relevant self-test. The procedure then observes whether the appropriate PID changes as the prescribed pedal and gear states are varied.

A missed test state is different from a switch or circuit that cannot represent it. The following TA steps separately examine switch condition and continuity, then wiring opens and shorts. Those details support a diagnostic branch without inventing a universal automatic-transmission range-sensor specification.

## Preserve the limits of the available evidence

For an automatic transmission, this chart directs the reader elsewhere; the manual-switch TA5 test is not a substitute. Confirm the actual transmission and complete application before using the route.

A technician should perform the proper stationary test safely and verify the required input transitions after a demonstrated correction. The blank description body leaves a standalone monitor threshold unresolved, so this draft remains flagged. Clearing P1705 or replacing a range sensor by title alone would skip the documented application split and test-state requirements.

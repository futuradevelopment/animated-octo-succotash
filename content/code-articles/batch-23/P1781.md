# P1781: Ford low-range switch is outside its self-test expectation

The 1999 Ford table titles P1781 as a 4x4-low switch self-test-range result. Its description treats the switch as an on/off input and says the PCM expects low voltage when it is on. The diagnostic aid is to verify that the input cycles through both states.

## Keep the self-test context with the observed state

The same manual uses very similar low-range input logic under P1729. This source does not establish a separate numerical boundary, timer or distinct hardware failure for P1781, so none is invented to make the two descriptions appear more different than the documentation supports.

What remains useful is the recorded self-test context: was the applicable switch state requested, and did the PCM receive the expected low signal? The switch’s physical position and the controller’s received state need to be considered separately.

## Diagnose the input path before assuming mechanical transfer failure

The listed possibilities are low-range harness opens or shorts, electronic shift-module damage and PCM damage. The row does not establish a broken transfer-case gear or prescribe a transfer-case replacement.

Follow the exact vehicle’s permitted low-range operating and test conditions. A technician should locate the demonstrated signal-path problem and verify reliable on/off representation after correction. A successful electrical check does not independently prove every mechanical aspect of the transfer system is sound, while erasing the code without repeating the relevant state changes does not confirm a repair.

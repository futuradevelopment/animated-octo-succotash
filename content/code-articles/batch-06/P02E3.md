# P02E3: diesel throttle short-to-power hardware indication

For this GM strategy, P02E3 reports a short-to-power condition in the diesel throttle command circuit. The monitor relies on hardware error information and excessive H-bridge switch current during an on command.

## Do not reduce the diagnosis to a voltage reading

The documented threshold is greater than 9 A. P02E2 uses that same current magnitude for its short-to-ground category, so an overcurrent reading by itself cannot distinguish the two directions. The hardware's fault classification and the actual circuit context matter.

Monitoring is gated by powertrain-relay supply above 11 V, completion of cranking, an enabled calibration and a determinate hardware status. The failure filter is 240 of 300 counts on a 12.5 ms task, with Type A, one-trip reporting.

## Verification that addresses this fault

Retain the drive command and supply conditions associated with the recorded failure. A check performed only with the H-bridge off does not exercise the state in which this monitor evaluates excessive current.

A useful post-repair result requires normal behavior during an eligible on period, together with the appropriate service-level electrical assessment. The table cannot show whether the underlying problem is in a harness, connector, actuator or controller. It supplies neither pin assignments nor authorization to apply external power to the throttle circuit; those decisions require the exact vehicle procedure.

## Source and applicability

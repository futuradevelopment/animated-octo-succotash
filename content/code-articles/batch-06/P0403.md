# P0403: high-pressure EGR actuator open-load check

P0403 checks the high-pressure EGR command circuit for an open load in this GM implementation. Hardware feedback identifies a load resistance greater than 200 kilohms while the H-bridge driver is off.

## The requested position is part of the test

The valve must be requested away from its fully closed default. That condition matters: a closed valve at its normal unpowered default does not by itself demonstrate an electrical failure. The controller is assessing electrical loading in a specific command context.

Monitoring also requires completion of cranking, powertrain-relay voltage above 11 V, a determinate hardware status and an enabled diagnostic system. The table lists 240 failed counts among 300 samples on a 12.5 ms task, with Type A reporting after one trip.

## Use the electrical evidence before a flow conclusion

An open-load result is different from insufficient EGR flow inferred by an airflow model. It directs attention to whether the actuator's electrical path can respond, without establishing the condition of EGR passages or cooler flow.

For verification, establish an eligible command away from the default and normal hardware loading using the correct service procedure. The published resistance is a diagnostic threshold, not an instruction to measure an energized actuator. The table cannot distinguish a disconnected path, actuator fault or controller problem by itself and supplies no replacement verdict.

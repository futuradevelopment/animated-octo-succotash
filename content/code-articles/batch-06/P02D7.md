# P02D7: cylinder 6 maximum learned injector-time correction

In this SQP implementation, P02D7 identifies cylinder 6's learned energizing-time correction exceeding the maximum permitted boundary. A new map value is compared with a named maximum calibration measured in microseconds.

## Read the learning map, not just the code label

SQP estimates a small injection from the resulting rail-pressure drop during diesel fuel cut-off. The controller stores a saturation result for each defined rail-pressure level. One entry beyond the maximum can support the diagnosis even when another entry is acceptable.

That also affects verification: the source describes an unset state only when all entries are free of saturation. A favorable value from a single pressure region cannot demonstrate that every relevant learned result has recovered.

## Published limitations

The maximum heading, greater-than comparison and threshold identifier agree on an upper-limit condition. Repeated wording elsewhere in the row calls it “minimum” authority; this article does not adopt that inconsistent phrase. The actual numeric maximum is not published.

SQP authority monitoring and injection management must be enabled for the learning assessment. The table lists Type B, two-trip reporting rather than an immediate universal reset rule. A useful service review establishes whether the relevant learning events completed and whether the pressure-drop evidence supports their results. This diagnostic summary does not determine a defective part or supply a safe procedure for opening the high-pressure fuel system.

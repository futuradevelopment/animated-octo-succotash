# P02E2: throttle short-to-ground detection uses H-bridge current

P02E2 is the diesel intake throttle command short-to-ground diagnosis in the cited table. Although the generic title says circuit low, this implementation recognizes the fault through excessive current in the H-bridge switches.

## A low-circuit code can use a current threshold

The failure criterion is current above 9 A, reported by the hardware interface while the H-bridge is on. That value is specific to this monitor and should not be substituted for a voltage threshold at an arbitrary connector.

The test requires the engine to be out of cranking and the powertrain-relay supply above 11 V. It also needs a determinate hardware error state. The table filters 240 failures from 300 samples, with a 12.5 ms task, and lists Type A reporting after one trip.

## What changes the diagnostic direction

A fault observed with an active drive command provides different evidence from an open-load indication with the driver off. Preserve the command state and hardware fault classification together; current magnitude alone does not explain which side of the circuit is shorted.

After correction, a meaningful verification includes another eligible driven interval without the abnormal hardware result. The summary identifies the failure signature but does not isolate wiring from the actuator or control electronics. Use the applicable electrical service procedure rather than intentionally shorting a motor circuit to imitate this code.

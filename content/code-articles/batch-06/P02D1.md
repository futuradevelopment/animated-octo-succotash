# P02D1: why cylinder 3 can reach maximum learned injector correction

The P02D1 monitor evaluates cylinder 3's upper SQP correction boundary. Its central comparison is whether the learned energizing-time adjustment exceeds a calibration-specific maximum in microseconds.

## Understand the evidence behind the code

SQP derives a small-injection quantity estimate from fuel-rail pressure drop during diesel fuel cut-off. The result enters a learning map rather than being treated as a simple electrical pass/fail test. This separates the fault from injector short-circuit diagnoses and explains why the learning conditions matter.

A saturation status is retained at each defined rail-pressure level. One excessive entry is enough for the documented condition; returning the condition to normal requires no saturated entries. Capturing the pressure region associated with the failed learning result is therefore more informative than a lone correction reading without context.

## Limits of this source

The row's heading and greater-than comparison identify a maximum fault, although repeated narrative text calls it “minimum” authority. No numeric maximum is supplied. Applying a guessed threshold or treating the stray wording as a lower-limit definition would be unsound.

Confirmation should include a completed, enabled SQP learning assessment and the status of the affected map. The source lists Type B, two-trip reporting, but supplies no proof of a failed injector or workshop repair sequence. High-pressure fuel diagnosis belongs within the vehicle-specific service procedure.

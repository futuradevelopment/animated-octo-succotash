# P05D3: driver-mode switch voltage lands between recognized states

P05D3 evaluates an analog driver-mode switch bank 1 input that is electrically within its overall span but falls in an indeterminate region. The source describes an eight-state resistor-ladder input with gaps between recognized states.

## An in-range voltage can still be invalid

For the selected 25OBDG04B calibration, one invalid band lies between 1.0270 and 1.1030 V; another lies between 2.57 and 2.64 V. These examples illustrate the deadband logic without reproducing the entire calibration table. A voltage need not reach the high or low circuit boundary to fail this performance check.

The input must remain invalid for four seconds within a five-second window. General bank diagnostics, circuit diagnostics and performance diagnostics must be enabled. The source lists Type B reporting over two trips.

## Verification should follow individual switch states

Record the actual voltage and which switch state was being selected. A brief transition through a gap and a value that settles in that gap provide different evidence. Confirming stable recognized states addresses the monitor more directly than checking only that the input is somewhere between supply and ground.

These bands are specific to the cited source; do not transfer them to another switch-bank calibration. The table does not isolate a resistor, connection or controller input and supplies no replacement verdict. Use the applicable service procedure for the installed bank.

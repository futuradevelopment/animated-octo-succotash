# P041B: EGR temperature fails a post-soak response check

The cited P041B strategy looks for an upstream EGR temperature signal that has not changed sufficiently after a long soak and a permitted amount of EGR flow. The generic dictionary calls this sensor B; this source labels the monitored channel EGR temperature sensor 1.

## Temperature response, not just electrical range

The controller compares the current reading with an initial temperature. A value can remain within its electrical limits yet fail this response test if it does not move as expected after EGR operation. Establishing the initial reading and whether the required EGR exposure occurred therefore matters more than inspecting a single plausible temperature.

The table requires valid run/crank ignition status, an enabled diagnosis and a valid accumulated off-time result. It uses a 100 ms function task and Type B, two-trip reporting. An immediate restart without the required soak is not a like-for-like retest.

## An unresolved source comparison

The narrative repeatedly describes insufficient movement, but the extracted threshold column presents a greater-than comparison for absolute temperature change. Those fields conflict, so this article does not publish a numerical pass/fail rule or reverse the inequality by assumption.

Use the applicable vehicle service definition to resolve that comparison and the physical sensor designation. Verification should demonstrate a valid post-soak response assessment, not merely code clearing. The table does not establish a failed temperature probe independently of the EGR-flow conditions used by the monitor.

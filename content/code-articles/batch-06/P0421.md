# P0421: diesel oxidation-catalyst efficiency during regeneration

The cited P0421 section describes a close-coupled diesel oxidation-catalyst monitor associated with particulate-filter regeneration. It estimates an aging index from oxidation heat released across the catalyst relative to post-injected fuel quantity.

## Efficiency needs the right thermal event

In this regeneration-based portion, an aging index below 0.08 is the documented efficiency threshold. Post-injection must be available to create a useful exothermic response. A cool catalyst without the intended dosing event is therefore not equivalent to a completed failed efficiency test.

The source requires valid upstream and downstream temperature information and completed temperature learning. Injection-system, ambient-temperature and upstream exhaust-flow faults can disable assessment. These prerequisites mean that questionable temperature or fueling evidence must be resolved before interpreting the ratio as a catalyst-only problem.

## Reporting is configuration-dependent

The table supports exponentially weighted moving-average filtering and several response states. Although the MIL column shows Type A, the detailed text also describes two-trip behavior when filtering is disabled. A universal one-trip statement would omit that distinction.

For verification, establish that the correct regeneration-based monitor actually completed with valid inputs and evaluate its reported result. This article does not cover every rich-combustion variant referenced elsewhere in the file. It also does not prescribe a forced regeneration or authorize catalyst replacement from the code alone; aftertreatment service involves controlled high temperatures and requires the applicable professional procedure.

## Source and applicability

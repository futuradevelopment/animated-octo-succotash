# P0405: high-pressure EGR SENT feedback below its electrical range

P0405 is a low-range check of high-pressure EGR SENT position feedback in the cited system. The threshold is a raw-position value below 1% of the 5 V scale.

## A raw signal is not the commanded opening

The monitor evaluates electrical signal range, so the 1% figure should not be used as a minimum permissible valve opening. A valid fully closed valve and an invalid raw feedback value are different observations.

The source requires that a SENT position sensor be configured as present and that no SENT communication-loss fault exist. Thus this code presumes a received signal that can be evaluated; it is not interchangeable with a missing-message diagnosis.

## Prerequisites for useful confirmation

The test is enabled outside cranking with relay supply above 11 V and an active diagnostic system. It counts 480 failures among 600 samples on a 6.25 ms task and lists Type A, one-trip reporting.

Confirming recovery requires valid communication and an in-range raw signal under those conditions. If communication itself has failed, lack of a new P0405 result does not establish a good sensor. Use vehicle-specific service data to identify the SENT architecture and inspect the relevant electrical evidence. The table does not locate a wiring fault, identify a defective sensor independently of its circuit or authorize a valve replacement based only on this code.

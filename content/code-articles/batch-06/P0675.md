# P0675: cylinder 5 glow open-load monitor with a source-label conflict

P0675 is identified by both the generic dictionary and the source row heading as a cylinder-5 glow-plug open-circuit code. The same row's narrative mistakenly refers to “glow plug 4,” so its physical-channel description requires confirmation against vehicle-specific service information.

## The supported open-load strategy

The hardware detection description is consistent with the surrounding open-load monitors: detection at a 200-kilohm condition, with no open-circuit detection below 16 ohms. Those values describe monitor behavior rather than a complete specification for the heating element.

The table uses ten failures among twenty samples on a 100 ms task, with Type B reporting and glow-lamp indication. The code does not itself locate an open connection or establish that the plug must be replaced.

## Do not let the stray cylinder number choose the component

Confirm the cylinder assignment from the actual vehicle's diagnostic and wiring information before touching a glow circuit. The operating test also requires valid battery voltage, no glow-supply fault, engine running outside cranking and duty cycle between 2.50% and 97.50%, with diagnostics enabled.

Verification should establish normal loading on the correctly identified channel during an eligible assessment. A result obtained on cylinder 4 because of the copied narrative would not resolve the intended P0675 finding. The source conflict is retained for review rather than silently corrected into a physical repair instruction.

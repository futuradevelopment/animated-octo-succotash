# P054E: idle torque-forming fuel quantity below its mapped expectation

P054E evaluates torque-forming injection quantity at idle. In this strategy, failure occurs below half of the applicable minimum-fuel map value, with the map selected by combustion mode and gear state.

## There is no single universal idle-fuel threshold

The maps depend on engine speed and coolant temperature. Strong exhaust warm-up, soft warm-up, hydrocarbon-unloading and default modes use different map selections, with in-gear and park/neutral distinctions. Comparing an observed quantity with a number from the wrong mode would misrepresent the test.

The monitor requires stable gear and more than four seconds of continuously satisfied enabling conditions. It samples once per cylinder firing event and uses 71 failures among 142 samples, with Type B reporting over two trips.

## Verify true idle eligibility

The continuation includes vehicle speed below 3 km/h, accelerator position at or below 0.05%, engine running, power take-off inactive and run/crank voltage at least 11 V. Numerous validity checks gate temperature, speed, gear, pedal and injection information.

Useful evidence therefore includes the active combustion mode and the selected gear alongside the quantity. A low quantity during a different operating state is not automatically this fault. Confirmation should compare eligible idle data with the correct calibration map. The summary does not diagnose a fuel restriction, identify a faulty injector or authorize invasive fuel-pressure testing from P054E alone.

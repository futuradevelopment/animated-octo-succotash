# P02E5: throttle fails to return to its default open position

P02E5 is more specific than a general throttle tracking error in this strategy. It checks whether the diesel intake throttle returns toward its fully open default after the actuator is no longer driven.

## A follow-on check after P02E1

P02E1 must already be set. The monitor then waits more than two seconds after driver shutoff to allow the spring to move the valve. If measured throttle position remains below 75%, the documented stuck-closed condition is present.

That sequence matters: this is not simply a commanded closed position mistaken for a fault. The controller is judging the spring-return outcome after drive removal. The threshold also means the source does not require a reading of exactly zero opening to use the “stuck closed” label.

## Evaluate the sequence and feedback

The table requires valid throttle position, actuator and position-deviation status, with the diagnostic system enabled. It applies no additional debounce once the error exists and lists a 6.25 ms function task with Type A reporting.

For interpretation, establish whether P02E1 led to driver shutoff and whether the return-position reading was captured after the waiting interval. A position result before that interval answers a different question. Verification should demonstrate the appropriate default return using the applicable service procedure. The source does not prove a particular obstruction, authorize forcing the valve by hand or prescribe actuator replacement.

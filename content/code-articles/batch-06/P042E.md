# P042E: high-pressure EGR remains open after drive removal

P042E checks the high-pressure EGR valve's default return after a position-performance fault. In this implementation the unpowered default is fully closed, and the monitor looks for measured position above 6% after the return interval.

## The prerequisite code explains the sequence

P0404 must already be set. The controller then waits more than two seconds after shutting the driver off, allowing the spring to return the valve. A valve that remains beyond the 6% threshold supplies the stuck-open evidence.

This is different from an EGR valve that is intentionally commanded open. It is also more specific than the earlier tracking error: the failure concerns the return toward the default position after electrical drive is removed.

## Confirm position validity and timing

The diagnostic system must be enabled, and the source includes a gate for EGR position-sensor, valve and deviation status. It applies no further debounce after the error is present, with a 6.25 ms task and Type A reporting.

Useful evidence includes the preceding P0404 result, driver-shutoff timing and valid measured position after the two-second wait. A reading captured sooner cannot settle this check. Verification should demonstrate the correct default return through the vehicle's service procedure. The table does not establish the nature of a mechanical obstruction or instruct the user to force, dismantle or replace the valve.

## Source and applicability

# P04D2: intermittent upstream low-pressure EGR temperature behavior

P04D2 evaluates intermittent or erratic behavior in the upstream low-pressure EGR temperature signal. Its strategy uses limits related to the last good reading and the sensor's filtering response.

## The history of the signal matters

The table describes upper and lower thresholds that blend sensor limits with the last accepted temperature. The blend also depends on consecutive failed samples, sampling time and filter response time. This is more than a simple check that every reading remains between two fixed temperatures.

The threshold column lists 320°C and −60°C as boundary values, but the accompanying equations describe the dynamic evaluation. Treating those numbers as the entire pass/fail rule would omit how the monitor responds after a sudden change.

## Separate erratic behavior from an electrical-range fault

No EGR temperature electrical fault may already be detected. The engine must not be cranking, relay voltage must exceed 11 V and the test must be enabled. The failure filter is 60 counts among 75 samples on a 100 ms task, with Type A reporting.

A useful review preserves the last valid value and the sequence of changes, not only a final steady reading. Verification should demonstrate consistent valid feedback during an eligible assessment. The source does not prove an intermittent harness fault or defective probe by itself, and its extracted filter expression should not be used to recreate calibration logic without the exact service definition.

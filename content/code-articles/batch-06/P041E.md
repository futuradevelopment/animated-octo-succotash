# P041E: erratic EGR temperature changes between samples

P041E monitors the consistency of EGR temperature feedback from one sample to the next. In the cited table the channel is EGR temperature sensor 1, although the generic dictionary labels it sensor B.

## An intermittent test can fail inside the normal range

The controller evaluates the absolute change in feedback across a 100 ms loop. The source distinguishes a temperature-change path and a resistance-change path. It is the rate of change, rather than simply an extremely high or low steady reading, that supplies the evidence for this diagnosis.

That creates a useful distinction when reviewing data: a stable but incorrect reading may need a different diagnostic test, while repeated jumps can matter even if the signal returns to a plausible value. A slow scan-tool refresh can also miss the sample-to-sample behavior this monitor evaluates; that is a limitation of the observation, not proof of a good circuit.

## Verify the relevant signal path

The table requires active, valid run/crank status, no cranking and diagnostics enabled. It counts 12 failures among 25 samples and lists Type B, two-trip reporting.

Identify whether the installed system reports temperature or resistance before judging changes. The extracted threshold formatting does not clearly attach units to both numeric change limits, so those numbers are not used here as workshop specifications. Verification should establish stable, valid feedback during an eligible assessment using the appropriate vehicle procedure.

# P049C: excessive low-pressure EGR inferred from fresh-air mismatch

The documented P049C monitor evaluates excessive low-pressure EGR using an air-system model. A positive mean residual, after an operating-condition threshold adjustment, indicates the excessive-flow condition.

## A model result is not a direct leak measurement

The source associates the monitor with low-pressure EGR valve leakage. Its calculation nevertheless depends on modeled nominal cylinder flow, estimated EGR flows and measured fresh air. Valid inputs are necessary before treating the result as evidence against one valve.

The averaging window is 250 samples at 25 ms. The monitor needs stable engine speed, fuel request and low-pressure EGR flow request, with active air control and desired EGR above zero. A sudden operating transition is therefore poor evidence for reproducing the filtered test.

## Combustion mode is especially important

The supporting enable map selects the displayed DOC warm-up mode while disabling the other listed modes. The continuation also requires valid flow estimates and enable conditions lasting at least 1.10 seconds. This differs from assuming the code can be retested at any steady idle.

Verification should document the active combustion mode and the completed residual assessment, along with measured airflow and model validity. The table describes an emissions-monitoring conclusion, not a universal allowed leak rate or a guaranteed repair. Apply the appropriate vehicle diagnosis before concluding that the low-pressure EGR valve needs replacement.

## Source and applicability

2025 GM 25OBDG04B diagnostic parameter tables; the cited monitor only. Vehicle, engine and calibration applicability must be confirmed separately. These tables describe detection logic, not a complete repair procedure or a component replacement verdict.

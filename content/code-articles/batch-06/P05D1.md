# P05D1: driver-mode switch bank 1 input below its low threshold

P05D1 checks the analog driver-mode switch bank 1 for an out-of-range low input. In the cited 25OBDG04B BCM row, the threshold is below 0.5280 V.

## Use a calibration-specific voltage

This value describes the selected source's switch-bank implementation. It is not a universal threshold for every vehicle that uses P05D1; the switch's resistor network and controller calibration must match before applying it.

The table requires the bank's general diagnostic, circuit diagnostic and low-range diagnostic to be enabled by calibration. The low input must occupy four seconds within a five-second window, with Type B reporting over two trips.

## Separate a persistent low input from an ambiguous state

An input below the low boundary differs from a voltage that remains within the overall span but falls between recognized switch states. Keeping the actual voltage and duration changes which diagnostic condition is being assessed.

Verification should establish that the relevant bank is configured and its input remains in the proper valid ranges during an eligible observation period. A single successful mode selection does not prove that an intermittent low reading has been resolved. The source does not identify the failed connection or switch element and supplies no component location, replacement instruction or indication that a driver-selected mode should be forced through a bypass. Match the circuit to the exact vehicle service procedure.

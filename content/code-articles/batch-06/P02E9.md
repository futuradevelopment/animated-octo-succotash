# P02E9: throttle SENT feedback exceeds its upper electrical range

The P02E9 row defines an upper electrical-range test for diesel throttle SENT feedback: the raw-position representation exceeds 99% of the 5 V scale. This should not be read as a rule that a normally open throttle position above 99% is faulty.

## Resolve the source wording carefully

The circuit-high heading and greater-than-99% criterion agree. One strategy sentence incorrectly says electrical range “low.” The article follows the consistent heading and explicit comparison, while retaining that source discrepancy for review.

The test also requires absence of a SENT communication-loss fault. An implausibly high received value and missing communication are therefore different diagnostic observations, even if both affect the available position information.

## What constitutes comparable evidence

The source gates monitoring until cranking is over and powertrain-relay supply is above 11 V. It uses 480 failures among 600 samples on a 6.25 ms task and lists Type A reporting over one trip.

A verification should establish valid communication and an in-range raw position value under those conditions. Clearing fault memory or observing one reasonable angle is not the same as completing that check. The table does not supply pin-level voltages or establish which connected component caused the range error. Confirm the vehicle's sensor architecture before applying any electrical test.

## Source and applicability

2025 GM 25OBDG04B diagnostic parameter tables; the cited monitor only. Vehicle, engine and calibration applicability must be confirmed separately. These tables describe detection logic, not a complete repair procedure or a component replacement verdict.

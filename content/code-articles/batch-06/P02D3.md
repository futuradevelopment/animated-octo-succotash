# P02D3: cylinder 4 learning exceeds maximum energizing-time authority

P02D3 describes an upper-limit SQP learning result for cylinder 4. The controller has compared a newly learned injector time correction with a calibrated maximum and recorded saturation.

## Why normal operation may not settle the diagnosis

The source describes a small injection during diesel fuel cut-off, with quantity inferred from the drop in rail pressure. Only an eligible learning event updates the evidence. Running the engine without that event cannot by itself demonstrate that the learning fault has disappeared.

Separate flags cover the rail-pressure levels in the SQP map. The diagnosis can be set by one saturated flag, while the stated unset condition requires all flags to be false. A technician therefore needs the map's relevant status, not only a convenient operating point that currently looks normal.

## Keep the maximum interpretation bounded

The title, greater-than sign and maximum-adaptation calibration name agree. Other prose on the same page repeats “minimum authority,” apparently carried over from a neighboring row. The supported interpretation is the upper boundary; the page does not publish a numeric correction limit.

The stated prerequisites include SQP management and authority monitoring, with Type B, two-trip reporting. These facts explain when the finding is valid but do not identify its physical cause. Confirm the learning evidence and applicable service information before considering injector or fuel-system work.

# P02F3: injector 6 current-fall timing in the 25OBDG04B monitor

The cited 25OBDG04B entry uses P02F3 for injector 6's end-of-injection current decay. It measures the interval from the hold or bypass current to zero and checks both excessively short and excessively long fall times.

## Use the correct implementation

For this particular row, failure means below 7 microseconds or above 24 microseconds. Forty-one failed samples among 82, evaluated once per engine cycle, meet the documented filter. These numbers describe this source's monitor and must not be treated as a universal P02F3 definition for every controller.

The source says an injector fault or ECU fault can make the decay period abnormal. That leaves the physical cause unresolved; the code identifies the measured behavior rather than selecting a replacement component.

## Two distinctions worth preserving

First determine which side of the timing window failed. Second establish that the evaluated pulse was valid: an injection request must exist and hardware must not report a dropped pulse. Battery voltage must exceed 11 V, and specified circuit, controller, boost-voltage and pull-in faults inhibit monitoring.

A retest performed while those inhibiting faults remain active cannot establish that current decay has recovered. Confirmation should use the applicable service method to assess eligible cylinder-6 events. This article deliberately confines its numeric criteria to 25OBDG04B; another calibration's monitor may implement the same code differently.

## Source and applicability

2025 GM 25OBDG04B diagnostic parameter tables; the cited monitor only. Vehicle, engine and calibration applicability must be confirmed separately. These tables describe detection logic, not a complete repair procedure or a component replacement verdict.

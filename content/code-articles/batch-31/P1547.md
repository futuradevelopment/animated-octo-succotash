# P1547: distinguish N75 short-to-ground from a mechanical boost problem

P1547 is the short-to-ground fault for boost-pressure control valve N75 in Ross-Tech's VAG guidance. Loss of power, limp mode and irregular behavior are possible effects. The same driving complaint can arise from many boost-system problems, so the electrical qualifier is more informative than the symptom alone.

## Do not reduce the fault to low boost

The source lists wiring or connection defects and a faulty N75. It does not describe this code as proof of a leaking intercooler or worn turbocharger. As diagnostic reasoning, the ground-short finding should be investigated even if the driver describes the vehicle simply as having no boost.

A check that only examines hoses would not address the electrical alternatives on this page. Conversely, the code itself cannot identify where in the N75 path the defect lies. That requires the correct circuit diagram and vehicle test procedure.

## Preserve the specific fault description

Record the complete VAG text when interpreting results, because a general pressure-regulation complaint is different from this ground-short condition. Ross-Tech provides no universal probing point or solenoid-resistance value here. Its independent reference supports checking the connections and valve, while a measured fault is needed to justify the actual repair.

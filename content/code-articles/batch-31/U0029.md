# U0029: a global bus timeout is broader than one missing message

U0029 describes vehicle communication bus A performance. Audi's CPNB diagnostic chart defines the condition as a global timeout in which no messages are received. That is broader than a row identifying a particular missing message from one named controller.

## The pattern of missing communication matters

As diagnostic interpretation, the useful evidence includes which modules and messages remain available when the fault is present. A widespread absence and an isolated missing sender point to different questions, even though both can produce communication complaints. U0029 alone does not name the failed controller or locate an open wire.

The word global is part of the documented monitor, but the row does not provide the vehicle's complete bus topology. It should not be used to assume that every controller in the car shares the same physical network.

## Do not invent a timeout duration

The quick-reference entry does not publish a numeric timer or termination-resistance test for this code. Those details require the CPNB network and diagnostic information. A repair should explain the loss of messages on the relevant bus, rather than replacing a module because it happened to report the fault. This article is a scoped explanation of Audi's 2014 A6/S6 monitor, not a universal network troubleshooting procedure.

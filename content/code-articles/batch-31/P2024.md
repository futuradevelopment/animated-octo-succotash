# P2024: the CAED EVAP temperature circuit is evaluated in a defined voltage band

P2024 concerns the EVAP fuel-vapor temperature-sensor circuit. Audi's CAED chart lists a signal-voltage band of 4.70–5.40 V for the fault criterion. The row describes electrical monitoring of the circuit, not a measured fuel-vapor temperature or a leak-rate test.

## A fault band is not a normal-operation specification

Because the values appear in the malfunction-criteria column, they should not be presented as the sensor's required healthy voltage range. As diagnostic interpretation, a measurement has to be considered with the correct circuit and test state, rather than declared normal merely because it falls within a published pair of numbers.

The code also does not identify a loose fuel cap or prove that the EVAP canister leaks. Those findings belong to other system assessments and are not established by this row.

## Establish the circuit before replacing a part

The quick-reference entry supplies no connector map, temperature conversion or complete isolation procedure. Use CAED service information to determine how the monitored path is implemented and why the reported voltage falls in the fault region. This explanation is limited to the CAED section of Audi's 2014 A6/S6 book. It does not treat the same generic code as proof that every manufacturer's temperature sensor uses this voltage band.

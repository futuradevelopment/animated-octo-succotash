# P2026: low EVAP temperature-circuit voltage is not a cold-vapor diagnosis

P2026 is the low-voltage fault for the EVAP fuel-vapor temperature-sensor circuit. Audi's CAED chart lists a signal region from 0 to 3.25 V as the malfunction criterion. The number belongs to the electrical signal, not to a temperature scale.

## Low voltage does not establish low temperature

The row does not publish a transfer function converting voltage to fuel-vapor temperature. As diagnostic interpretation, the circuit-low label cannot be used on its own to claim that vapor in the tank is unusually cold. The signal may be unreliable because the circuit is in the reported fault condition.

Likewise, this is not a tank-pressure or EVAP leakage threshold. A pressure test result and this electrical criterion answer different questions.

## Use the signal region in the proper context

The published values are in a malfunction table and should not be represented as the sensor's normal operating range. Audi supplies no connector pin, universal resistance value or required replacement in this row. Use the CAED circuit procedure to establish the test state and explain the low feedback. This scoped description comes from the 2014 A6/S6 reference book and does not automatically apply to another engine's EVAP temperature implementation.

# P2279: intake leakage includes the PCV system and runner-position evidence

P2279 identifies an intake-air leak in Ross-Tech's VAG reference. The possible causes include a vacuum leak, an intake-manifold runner position outside specification and a faulty crankcase-ventilation system or its heating element where fitted. The investigation is therefore broader than looking for a visibly disconnected intake hose.

## The crankcase breather is a specific branch

For North American 2.0T BPY engines, Ross-Tech references an updated breather valve bulletin. It notes that a failed valve can be associated with strong engine vacuum when the oil cap is removed at idle. That is a bounded source observation, not a universal oil-cap test or a diagnosis for every engine.

The runner-position alternative also matters: an intake-related fault may need position evidence as well as a leakage check. Neither branch should be discarded because the code title says leak.

## Match the equipment before applying the note

The source says to check the PCV heating element only where applicable. As diagnostic reasoning, confirming the actual engine and ventilation arrangement avoids applying BPY-specific advice to unrelated systems. This independent reference supplies no universal allowable leak rate or runner-angle specification. The repair should follow a demonstrated defect in the applicable intake, runner or ventilation path.

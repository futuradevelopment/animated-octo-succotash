# P2541: low fuel-pressure sensor voltage is not a direct low-pressure measurement

P2541 is a low circuit signal from the low-pressure fuel-system sensor. Audi's CAED chart uses sensor voltage below 0.21 V as the detection criterion. The two uses of low should not be confused: one describes the fuel-system side being monitored, and the other describes its electrical feedback.

## Signal credibility comes before pressure interpretation

The row does not provide a voltage-to-pressure conversion. As diagnostic reasoning, a reading below this electrical boundary cannot simply be translated into a statement that the fuel pump produces no pressure. The circuit must be assessed using the correct sensor and wiring information.

Nor does the code alone demonstrate a restricted filter or an empty tank. Those are different physical findings and are not listed as established causes by this monitor row.

## Use the exact engine criterion

Audi's book includes other engine calibrations, so the CAED threshold is explicitly scoped here. The quick-reference entry provides no connector pinout, fuel-line opening procedure or mandatory sensor replacement. A supported repair explains the low signal and uses the relevant professional fuel-system checks where needed. This distinction prevents a circuit-low fault from being treated as a complete hydraulic-pressure diagnosis based only on its generic title.

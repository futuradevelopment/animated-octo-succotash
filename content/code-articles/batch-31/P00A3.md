# P00A3: an open charge-air temperature circuit can appear colder than minus 40°C

P00A3 has a generic high-circuit label for bank 2 charge-air temperature. Audi's CTUA-engine diagnostic chart describes the sensor after intercooler 2 as open-circuit and uses a reported intake temperature below minus 40°C as its criterion. The fault therefore needs interpretation in the context of the sensor's electrical behavior.

## A high signal label can accompany a cold reading

The source does not equate high circuit with physically hot charge air. Instead, its open-circuit condition is represented by an extremely low reported temperature. As diagnostic reasoning, a cold scan value should not be accepted as an accurate air-temperature measurement while this circuit fault remains unresolved.

That also means the code is not proof that the intercooler is cooling too effectively. The documented question is whether the controller has a credible temperature signal from the correct sensor.

## Scope the check to the installed circuit

The CTUA row supplies no universal connector layout or sensor-resistance test. Use the actual component identification and wiring procedure to explain the open-circuit evidence. These values come from the 2014 Audi A6/S6 reference book and should not be transferred to another engine merely because its scan tool displays the same five-character code.

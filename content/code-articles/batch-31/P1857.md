# P1857: the load-signal error sends diagnosis back to the engine ECU

P1857 is a load-signal error message from the engine control unit in Ross-Tech's VAG reference. The source lists fault codes stored in the engine ECU as the cause and directs the reader to check that controller's faults. This makes P1857 a pointer to another diagnostic record rather than a complete root-cause description.

## Read the originating fault information

A receiving controller can report that engine-load information carries an error without identifying why the engine controller considers it faulty. As an editorial explanation, the next useful evidence is the engine ECU's own stored fault information, not an assumed failed component called a load sensor.

The source associates P1857 with an illuminated malfunction lamp. That symptom does not distinguish the underlying engine problems and should not substitute for reading the original record.

## Avoid replacing the messenger

Ross-Tech does not prescribe replacing the controller that reports P1857, the engine ECU or a transmission component. It provides no universal load-value limit because the supported action is to investigate the engine faults behind the message. The repair should explain that originating problem and then assess the dependent error status. This article reflects Ross-Tech's independent VAG guidance, with no claim that all vehicles use identical load-signal architecture.

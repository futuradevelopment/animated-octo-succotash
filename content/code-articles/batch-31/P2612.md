# P2612: N280 compressor-valve wiring can explain an inactive air conditioner

P2612 is described by Ross-Tech as a short-to-ground condition for the A/C compressor regulator valve N280. The source lists faulty wiring or connections and a faulty valve, with an inoperative compressor as a possible effect. An inactive compressor therefore does not by itself prove a mechanically failed compressor assembly.

## Connector condition is useful evidence

The reference notes that N280's molded connection can become brittle and allow pin corrosion, particularly where the lower engine cover is missing. This is a reason to assess the actual connection, not a claim that every uncovered engine has this fault.

For 2.5-litre New Beetle applications, Ross-Tech specifically highlights wiring and a four-pin connector near the starter. The location is application-specific and should not be transferred to another model.

## Valve and compressor decisions differ

The source mentions replacing the valve separately where available, or the compressor. That makes correct parts applicability relevant after diagnosis. Although it offers an approximate resistance reference, it expressly notes model differences; this article does not turn that into a universal pass/fail limit. Use the installed system's electrical procedure before opening the refrigerant circuit or selecting an assembly. This is independent diagnostic guidance, not a confirmed repair result.

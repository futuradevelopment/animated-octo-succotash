# P0410: Audi's secondary-air rationality monitor uses pressure deviation

P0410 broadly identifies a secondary-air system problem. In Audi's CTUA-engine diagnostic chart, the monitor is described as a rationality check using a secondary-air pressure deviation greater than 20 hPa. That criterion concerns the plausibility of system behavior, not simply whether a pump makes a sound.

## A pressure result is different from an electrical command

As diagnostic interpretation, a pump that is commanded on or can be heard operating has not necessarily demonstrated the expected pressure behavior. Conversely, this row alone does not identify a failed pressure sensor, hose, valve or pump. It supplies the controller's detection evidence rather than the repair cause.

The threshold is a deviation. It should not be rewritten as an instruction that absolute secondary-air pressure must equal 20 hPa, nor treated as a universal specification for every Audi engine.

## Use the correct engine chart

Audi includes other P0410 descriptions elsewhere in the book, so the CTUA scope is material. The vehicle's repair procedure is needed to establish the reference pressure, enabling conditions and appropriate system checks. A useful diagnostic report explains the observed pressure discrepancy and its source instead of assuming that a generic AIR system label always requires a replacement pump.

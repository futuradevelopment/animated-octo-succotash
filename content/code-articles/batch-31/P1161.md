# P1161: G72 intake-temperature circuit faults may have few symptoms

P1161 describes an open circuit or short to positive for intake-manifold temperature sensor G72 in Ross-Tech's VAG reference. The page notes that obvious symptoms may be absent. A vehicle that appears to drive normally can therefore still have an unresolved temperature-feedback fault.

## The label contains two electrical possibilities

An open circuit and a connection to positive are not the same physical defect, even though the fault description groups them together. The source directs attention to the sensor circuit and its connections as well as the sensor itself. The code does not identify which of those paths caused the observed signal.

As diagnostic reasoning, a plausible-looking reading at one moment should be considered alongside the stored fault and the vehicle's actual circuit design. It should not be used to dismiss the record merely because no drivability complaint accompanies it.

## Avoid importing another sensor's specification

Ross-Tech provides no universal resistance curve, voltage threshold or connector layout for G72. Establish the component identity and appropriate values from the installed engine's repair information before measurement. A repair decision should identify the electrical defect or substantiate sensor failure rather than rely solely on the component named in the code. This is independent VAG guidance, not a claim that every manufacturer's P1161 has the same meaning.

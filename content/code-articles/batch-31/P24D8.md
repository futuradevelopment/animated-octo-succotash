# P24D8: the EVAP pressure-sensor number may be misleading

P24D8 is a high or short-to-positive EVAP pressure-sensor fault in the source context, but the sensor numbering requires care. Ross-Tech explicitly questions the factory-tool phrase pressure sensor 2 and identifies G950 in its diagnostic advice. The catalog's sensor-B label should therefore not be used alone to locate a second physical sensor.

## The example has only one sensor

Ross-Tech describes a 2019 Audi A6 3.0T with the DLZA engine that has one EVAP pressure sensor. In that example, disconnecting G950 sets this fault. This is useful evidence that a high/positive-short-style label can coexist with an unplugged circuit; it does not prove a wire is touching battery positive.

The page recommends checking G950 and its wiring. It also states that applicability to V8 arrangements with multiple sensors is unclear. That uncertainty remains unresolved here.

## Identify the installed arrangement first

As diagnostic interpretation, confirm the vehicle's actual EVAP sensor count and circuit before replacing a component selected only by a scan-tool number. The source supplies no universal voltage or pinout. This article follows independent Ross-Tech guidance and preserves the naming limitation rather than claiming that every P24D8 always refers to the same G950 arrangement.

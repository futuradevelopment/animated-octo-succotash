# P0194: intermittent G247 fuel-rail pressure feedback

P0194 identifies intermittent fuel-rail pressure sensor feedback. Ross-Tech names the VAG sensor G247 and lists wiring, connections, the sensor and the controller as possible causes. The key distinction is between an unreliable pressure signal and a demonstrated problem producing fuel pressure. The code alone does not settle that distinction.

## Do not lose the intermittent evidence

A normal pressure value during a later check does not describe what happened when the fault was stored. As diagnostic reasoning, compare available fault-event information with the signal behavior during the complaint. This helps frame the question around an interruption or implausible feedback rather than assuming a steady pressure deficit.

The source directs attention to the G247 electrical path. It does not provide a universal connector pinout, pressure specification or resistance value, and it does not identify a high-pressure pump as the required replacement. Those details must come from repair information for the actual fuel system.

## Where the source stops

A confirmed electrical defect and a confirmed hydraulic problem call for different repairs. Pressure-system testing should remain within the manufacturer's professional procedure; this code description is not an instruction to loosen rail fittings to check for fuel. Ross-Tech is an independent diagnostic-tool publisher, and its VAG entry should only be applied when the controller's full fault description and installed system match.

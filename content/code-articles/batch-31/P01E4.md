# P01E4: start-up temperature comparisons reveal a plausibility problem

P01E4 is a range or performance fault in the generic coolant-temperature-sensor-3 family. Audi's CPNB chart describes engine-temperature-control sensor plausibility and compares its reading with intake-air, ambient-air or fuel temperature at start-up. The listed difference is greater than 35 kelvin.

## The start-up context matters

The monitor is based on a comparison at a specified stage of operation. As diagnostic reasoning, readings collected only after the engine has warmed may not explain the start-up discrepancy. The useful evidence preserves when the disagreement occurred and which comparison inputs were involved.

The 35-kelvin figure is a temperature difference, not a maximum allowable coolant temperature. It also does not establish that all sensors must report exactly the same value throughout normal operation.

## A discrepancy does not identify the wrong input

The source names a plausibility comparison but does not provide a full isolation procedure. A diagnosis should establish which relevant temperature reading is unreliable before selecting a component. Audi's chart uses engine-temperature-control terminology, so identify the actual circuit from CPNB repair information rather than relying solely on a generic sensor number. This explanation is limited to the documented 2014 A6/S6 monitor and supplies no universal resistance curve or replacement instruction.

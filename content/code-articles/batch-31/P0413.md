# P0413: a small current threshold identifies an open secondary-air valve circuit

P0413 is the generic open-circuit fault for secondary-air switching valve A. Audi's CTUA DTC chart lists an open-circuit condition when signal current is below 0.8 mA. The units are important: this is a small electrical current threshold, not a secondary-air pressure or flow target.

## Open-circuit evidence does not locate the interruption

The criterion shows what the controller considers electrically abnormal. It does not identify whether the interruption is in a connector, wiring or the controlled component. As diagnostic reasoning, component replacement requires evidence that narrows the open path rather than simply repeating the code label.

Nor does the threshold specify the valve's normal operating current. A monitor boundary and a component operating specification are different pieces of information.

## Match the valve designation to the engine

The generic catalog supplies the valve-A designation; the Audi row itself is concise and does not provide a physical component map. Use CTUA wiring and service information to establish the relevant circuit before testing. This explanation follows the CTUA section of the 2014 Audi A6/S6 reference book. It does not provide an improvised direct-power test or infer a mechanical secondary-air blockage from an electrical open-circuit finding.

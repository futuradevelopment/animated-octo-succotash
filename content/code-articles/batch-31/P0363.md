# P0363: fuel shutoff can be the response to a misfire

P0363 describes a misfire condition in which fueling has been disabled. Ross-Tech relates the event to excessive misfire detected through crankshaft-speed fluctuations. The useful distinction is between the controller's response and the problem that triggered it: deactivated fueling does not by itself prove that an injector failed electrically.

## Find the combustion problem behind the response

The reference includes intake leaks, fuel quality, pressure and quantity, injector or injector-seal problems, plugs and coils, G28 speed feedback and compression-related causes. These are separate diagnostic branches. A controller that intentionally stops fueling a misfiring cylinder can make the resulting behavior look different from the original fault.

Ross-Tech's mechanical considerations include valve-train issues and carbon-related compression effects. Consequently, an ignition-only explanation is incomplete when the available evidence does not support an ignition failure.

## Use the fault sequence

As an editorial diagnostic approach, preserve the accompanying cylinder and mixture faults and the conditions that preceded the fuel shutoff. They may identify the original disturbance more clearly than the later deactivation status. The source associates the condition with reduced power and a malfunction lamp, but those effects cannot identify the root cause.

This independent VAG reference supplies no universal misfire count, injector replacement requirement or compression specification. The actual engine's procedure is needed to turn the recorded response into a supported repair decision.

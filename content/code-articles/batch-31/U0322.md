# U0322: body-module compatibility can involve ambient-temperature configuration

U0322 is a software-incompatibility fault involving the body control module. Audi's CTUA chart gives a specific context: an ambient-temperature value from a module that is not encoded for the ambient-temperature sensor. The issue described is configuration and expected information, rather than simply a total loss of communication.

## A communicating module can still be configured incorrectly

As diagnostic interpretation, the presence of messages does not by itself establish that the sender is supplying the type of information the receiving system expects. That is why an incompatibility code should not automatically be treated as a broken network wire or a physically failed body module.

The ambient-temperature reference also does not prove the outdoor sensor is defective. The row points to whether the module is encoded for that equipment, which is a different question from the sensor's measured resistance.

## Confirm the intended equipment and coding

Audi's quick-reference book provides no replacement coding value or universal module configuration. Establish the vehicle's actual equipment and the correct CTUA service information before changes are made. The useful diagnostic outcome explains the mismatch between expected ambient-temperature information and the module configuration. This monitor description belongs to the 2014 A6/S6 CTUA chart and does not establish the same cause for every manufacturer's U0322.

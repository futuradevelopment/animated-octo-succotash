# P1681: unfinished programming needs a software-history check

P1681 means control-module programming was not completed in Ross-Tech's VAG reference. The source identifies an unfinished flash or update and recommends performing the software update again. This is a programming-state fault, not direct evidence that the module's physical electronics have failed.

## Establish which software was being installed

Ross-Tech makes a separate point about chipped or remapped vehicles: contact the aftermarket tuner for assistance. That distinction is useful because the appropriate recovery route depends on the software history. A factory-update assumption may be incomplete when modified software is involved.

As editorial diagnostic reasoning, retain the identity of the module and the attempted update, together with any interrupted-programming record. A generic scan label does not specify which software package is correct for the car.

## Recovery is not simply code erasure

The source associates the condition with an illuminated malfunction lamp. Clearing the fault does not itself finish the programming operation that the code describes. The applicable programming procedure and suitable equipment are needed to establish whether the update completed. This article does not provide flash files, a universal recovery sequence or permission to install software from another vehicle. Ross-Tech's independent guidance supports resolving the unfinished operation before condemning the module.

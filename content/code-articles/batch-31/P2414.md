# P2414: front oxygen-signal limits depend on the selected gain characteristic

P2414 describes an exhaust-sample or signal-range problem for bank 1's front oxygen sensor. Audi's CAED chart lists two threshold bands and explains that the selected threshold depends on the gain factor used for the sensor characteristic. The gain context is therefore part of interpreting the voltage.

## One value does not tell the entire story

The source gives bands of 3.10–4.81 V and 2.5–3.10 V. It does not describe them as two normal operating ranges that every measurement should satisfy simultaneously. As diagnostic interpretation, comparing a recorded voltage with the wrong selected characteristic could misstate the monitor's conclusion.

The row also does not prove that the exhaust sample itself contains a particular oxygen concentration or that the sensor must be replaced. It describes how the signal is evaluated, not a complete cause-isolation procedure.

## Preserve the calibration context

Use the CAED diagnostic information to establish the relevant sensor, operating state and gain-dependent evaluation. The quick-reference book does not supply a universal test at an identified connector pin. This explanation is scoped to the 2014 Audi A6/S6 CAED chart; other engines in the same book can use different signal-range criteria and should not inherit these bands automatically.

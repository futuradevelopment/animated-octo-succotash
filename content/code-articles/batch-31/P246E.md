# P246E: identify exhaust-temperature sensor 4 before trusting its display label

P246E describes an electrical malfunction of bank 1 exhaust-temperature sensor 4 in Ross-Tech's reference. The source identifies sensor or wiring failure as possibilities and lists reduced power, limp mode and several warning indicators as possible effects. Correct sensor identification is particularly important before parts are ordered.

## A measuring-value label can be misleading

For rest-of-world Audi A4 B8 applications with the CAGA engine and UDS diagnostics, Ross-Tech warns that exhaust-temperature measuring values may be incorrectly labeled. It specifically directs attention to ENG106430, labeled as temperature before the particulate filter, even though the relevant component is the last, fourth sensor.

That application note prevents a familiar label from being treated as definitive component location. It does not establish the same labeling error on other engines or scan tools.

## Confirm identity through the proper diagnostic procedure

The source recommends reconciling fault changes and measuring values when the suspected sensor is disconnected. Such identification work should follow the applicable professional procedure around the exhaust system. This article does not provide hot-exhaust access instructions or a universal sensor resistance. The useful result establishes which sensor and wiring path the code actually concerns before replacement, rather than relying on an ambiguous display name.

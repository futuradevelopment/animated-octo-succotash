# P2133: the VAG high-signal fault can involve oxygen-sensor damage

The generic P2133 label refers to throttle or pedal position sensor F's high circuit. Ross-Tech describes its VAG interpretation as a high throttle-position signal and supplies an unusual diagnostic branch: oxygen-sensor damage can be relevant. The component wording differs, so confirm the full controller description before applying this article.

## Do not assume the pedal is the cause

Ross-Tech lists accelerator-pedal failure as very unlikely within its documented context and instead includes harness problems, ECM faults and oxygen sensors. It recommends inspecting and testing the pedal harness and visually checking oxygen sensors for damage. That is not a universal failure-rate claim for every vehicle with P2133.

The page also notes related pedal-signal codes and warns that oxygen-sensor problems can sometimes damage the ECM. Its recommendation to address oxygen sensors before replacing an ECM is therefore conditional on this diagnostic situation, not a general order to replace every sensor.

## Resolve the connected fault path

As diagnostic interpretation, a new controller would not explain or remove an unresolved external defect. Establish which source-specific condition is actually present. Ross-Tech provides no universal pinout or test voltage here, and the terminology difference remains a review limitation rather than proof that generic sensor F always corresponds to one VAG component.

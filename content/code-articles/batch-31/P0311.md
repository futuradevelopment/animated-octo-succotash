# P0311: interpret cylinder 11 misfire alongside fuel and compression evidence

P0311 means a misfire has been detected for cylinder 11. In Ross-Tech's reference, injector faults and fuel supply problems are possibilities alongside ignition trouble and inadequate compression. The code is therefore a location clue for the detected combustion problem, not a verdict on an injector or coil.

## A fuel fault may have a wider origin

Ross-Tech includes fuel pressure and running out of fuel among its cause list. It also includes an EVAP purge problem. As an editorial interpretation, these alternatives make the pattern of other combustion faults useful: a record involving several cylinders can support a wider investigation even when P0311 names one cylinder. It cannot, by itself, establish which shared supply or component failed.

## Avoid a numbering mistake

The source gives no engine-specific cylinder map. Confirm cylinder 11's actual location using the vehicle's repair information before inspecting or comparing components. The same number should not be assumed to occupy the same physical position across different engines.

A useful diagnostic report should state what evidence excluded or supported fuel metering, ignition and compression. A normal visual inspection alone does not resolve those branches. Ross-Tech's page is independent diagnostic guidance and does not provide a universal fuel-pressure target, compression limit or required replacement for P0311.

# P2025: EVAP temperature performance includes communication and module checks

P2025 describes EVAP fuel-vapor temperature-sensor performance. Audi's CAED chart shows that the monitor is broader than a single temperature limit: it includes range checks, comparison with coolant and intake temperatures, temperature-change behavior, communication and smart-module functional checks.

## Temperature is only one branch

The source's range checks include smart-module temperatures above 119°C or below minus 39°C. Its plausibility checks compare temperature differences, rather than treating those inputs as unrelated readings. As diagnostic interpretation, a plausible current temperature does not independently exclude a fault recorded through another branch.

## Communication can produce the same code

The row also includes delayed responses exceeding 1,000 milliseconds, an incorrect security bit, repeated checks, reset-counter behavior and a time difference between the ECU and smart module. Those criteria make message and module evidence relevant, even though the generic title emphasizes temperature.

The quick-reference chart is not a full fault-isolation tree and does not establish that all listed conditions must occur together. Use the CAED diagnostic procedure to determine which branch was responsible before choosing a repair. This article does not prescribe replacing a temperature element when the documented issue may instead involve communication or module behavior, and it does not extend the thresholds beyond this Audi calibration.

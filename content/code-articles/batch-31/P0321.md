# P0321: an implausible G28 signal can follow an unrelated no-start

Ross-Tech describes P0321 as an implausible engine-speed signal from G28. Possible effects include stalling, failure to start and a flashing glow-plug indicator. G28 provides a crankshaft reference that the controller relates to camshaft information, so an implausibility fault requires more interpretation than simply finding the sensor named in the label.

## The no-start may come first

One particularly useful source note concerns extended cranking. Ross-Tech warns that prolonged starting attempts caused by another mechanical no-start problem can produce a misleading G28 fault. Therefore, the chronology matters: a vehicle that initially would not start and subsequently stored P0321 should not automatically receive a crank sensor.

That does not exclude a sensor fault. The reference also lists a loose or faulty G28. It means the original complaint and the quality of the crank-speed evidence must be considered together.

## Look beyond the sensor body

Ross-Tech additionally describes oil or coolant migration through wiring toward the engine controller, including a Tiguan example. This supports considering the connected electrical path when contamination is found; it does not establish that every P0321 has that cause. Other interference and software notes are engine-specific.

Use the full fault description and the correct engine procedure to decide which note applies. This independent reference does not supply a universal G28 voltage test or justify controller replacement from the code alone.

# P1243: Volkswagen cylinder 7 injector N85 open-circuit evidence

P1243/17651 identifies an open circuit for cylinder 7 injector N85 in Ross-Tech's Volkswagen/VAG notes. Poor running and an engine warning lamp are listed possible symptoms.

## Keep the fuse and harness in the investigation

The source names an injector fuse, wiring-harness issue, injector failure and engine-controller failure. Its specific checks address the fuse, wiring to and from N85, and injector resistance using the repair manual. The circuit interruption still needs to be located; the component name is not a test result.

## Use the shared method with cylinder 7's information

Related injector-circuit entries have the same supported electrical checks. For P1243, confirm the engine's cylinder identification and use the N85 wiring path and installed injector specification.

Record the external-circuit finding separately from the component measurement. That distinction supports a targeted connection, wiring or injector repair without treating every open-circuit entry as evidence that all injectors require replacement.

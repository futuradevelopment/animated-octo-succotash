# P1853: Volkswagen implausible ABS message and the DSG communication-partner list

Ross-Tech describes Volkswagen P1853/18261/006227 as an implausible message from the ABS controller on the powertrain data bus. It recommends checking CAN-related wiring or connectors, the J104 ABS-controller path and relevant measuring values. The fault is not a direct diagnosis of a wheel-speed sensor.

## Preserve the communication context

The page points toward measuring blocks 125 and above for plausibility checks. The actual controller's labels and availability determine how that lead is used. A complete scan should retain the module that reports P1853 and the ABS module's own state, rather than turning the complaint into a generic network-failure label.

## The DSG/02E note adds a configuration explanation

For applicable six-speed DSG/02E systems, Ross-Tech explains that controllers retain a list of communication partners. Replacement or updating of a module can change that list and lead to this fault. It refers to the specific ESP and Tip Cruise Control installation reset procedure for that system.

This is a bounded configuration possibility, not permission to run the same basic setting on every transmission or to bypass an unresolved ABS problem. Confirm the gearbox, repair history and correct procedure first.

A supported repair distinguishes a physical data-path defect from a relevant learned-configuration mismatch, then reassesses the expected module interaction. The code alone cannot identify which of those paths applies.

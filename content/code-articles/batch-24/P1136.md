# P1136: Volkswagen additive lean trim: look beyond obvious vacuum hoses

P1136 is the Volkswagen/VAG bank 1 additive lean-trim fault identified as 17544/004406 by Ross-Tech. Additive correction addresses mixture imbalance at idle in its fuel-trim explanation. That makes the operating pattern important: a correction strongest at idle has a different diagnostic emphasis from one that persists across the engine's working range.

## An intact visible hose is not the end of the leak search

The code-specific note broadens the investigation when an ordinary external vacuum leak cannot be found. It names the N80 purge valve, brake-booster plumbing, an electric vacuum pump where fitted, and crankcase ventilation components. These are distinct paths through which a fault can influence the mixture; their presence depends on the vehicle.

Ross-Tech also associates faulty crankcase ventilation with vacuum at the oil cap and possible misfire faults. That observation is a clue to assess, not a standalone test proving which PCV component needs replacement.

## Retain the alternative explanations

The same entry includes airflow measurement, the pressure regulator, fuel pump, intake/exhaust leaks and secondary-air leakage. A trim fault must therefore be connected to an actual leak, fuel-delivery or measurement finding.

Save the learned trim values before clearing codes. Following repair, use the appropriate controller values to assess the additive correction again; an erased fault memory by itself does not show that the idle mixture imbalance has been corrected.

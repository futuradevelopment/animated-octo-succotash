# P1354: Volkswagen G149 movement-sensor fault and the battery-tray harness

P1354/17762 identifies an electrical malfunction of the G149 modulating-piston movement sensor in Ross-Tech's Volkswagen/VAG reference. The reported symptoms can include an engine warning lamp and failure to start. The code does not establish that an entire injection-pump assembly must be replaced.

## The harness location is a useful lead

The source lists a harness issue and a defective G149 sensor as separate possibilities. Its special note directs attention to wiring beneath the battery tray. That is a concrete inspection lead for an applicable installation, while the actual routing still needs to be confirmed for the vehicle.

The suggested component test is explicitly tied to the repair manual. No general resistance limit or terminal assignment is provided in the wiki entry.

## A changed symptom after reconnecting is not a complete repair

Ross-Tech reports that disconnecting and reconnecting the G149 harness has helped in some cases. This is an observation about possible connection sensitivity, not proof that repeated reconnecting repairs damaged terminals or wiring. It should not replace inspection and a supported diagnosis.

Record whether the evidence identifies a connector, harness or sensor defect, then check the circuit and original starting complaint after correction. A one-time successful start is less conclusive than a verified electrical repair, particularly when the initial problem may have been intermittent.

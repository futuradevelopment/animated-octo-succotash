# P1215: Volkswagen cylinder 3 injector short to supply versus an open circuit

P1215/17623 reports a short-to-positive condition for cylinder 3 injector N32 in Ross-Tech's Volkswagen/VAG reference. Possible symptoms include poor performance and an engine warning lamp.

## Keep the electrical direction

Ross-Tech's P1239 entry names the same cylinder 3/N32 branch but describes an open circuit. The component identity is shared; the electrical condition is different. Recording the complete code and text is more useful than reducing both to “injector 3 faulty.”

## What the reference supports checking

For P1215, the listed possibilities are an injector fuse, harness trouble, injector failure and engine-controller failure. The recommended tests combine inspection of wiring to and from N32 with an injector resistance measurement under the repair-manual procedure.

Those checks assess the external path and the component separately. Ross-Tech uses this shared method across the injector-circuit family; a resistance result alone does not identify the location of an external short to supply.

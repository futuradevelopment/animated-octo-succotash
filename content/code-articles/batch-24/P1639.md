# P1639: Volkswagen pedal-sensor plausibility: verify both channels without assuming their scales

P1639/18047/005689 describes an implausible accelerator-pedal signal involving G79 and G185 in Ross-Tech's VAG reference. Reduced output and an engine warning lamp are possible symptoms. Because the code names both channels, their relationship matters alongside the condition of either individual signal.

## Read the paired values with the correct specification

The source recommends pedal measuring values, controller-to-pedal voltage checks under the repair manual, and wiring or connector inspection. It lists the pedal, engine controller and external connections as possible fault areas. It also notes that relevant oxygen-sensor circuitry can contribute to pedal-related faults.

These are diagnostic alternatives, not proof that a pedal or controller is defective. The article does not adopt the wiki's qualitative failure-frequency statement as a measured probability.

## The published channel descriptions need application verification

This P1639 page says both channels rise together on different scales. The P1631, P1633 and P1634 pages describe opposing directions. Those generalized explanations cannot all define one universal transfer function. Confirm the actual controller's expected relationship before deciding that the observed pair is abnormal.

The useful repair evidence identifies a verified signal, supply, wiring or component defect against the correct criteria. A copied percentage pattern from another code page is insufficient grounds for replacing the pedal assembly.

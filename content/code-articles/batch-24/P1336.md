# P1336: Volkswagen torque-control limit and the intake information behind it

Volkswagen P1336/17744 is described by Ross-Tech as an engine-torque monitor exceeding its control limit. Some code lists use adaptation-limit wording. Neither wording identifies a particular sensor as defective, and the source does not define a universal torque threshold.

## A restriction and a bad signal are different explanations

The reference lists restricted air or fuel filters, unmetered intake air after the airflow sensor, and faults in airflow, intake-air temperature or coolant-temperature sensing. A real restriction changes engine operation; faulty sensing changes the information available to control it. Testing should distinguish these routes before a repair is chosen.

Reduced power and an illuminated warning lamp are documented possible symptoms. They are consistent with the complaint but do not identify which listed route is responsible.

## Retain the learned correction

Ross-Tech calls for examining oxygen-sensor adaptation before clearing faults. The associated trim information helps preserve evidence about mixture correction while the intake and input checks are made. It should be recorded with the correct controller labels rather than assuming one measuring block suits every engine.

This entry and P1335 share a diagnostic framework in the source. The actual code, operating conditions and findings still need to remain specific to the vehicle. Confirm the effect of the verified repair on the relevant inputs and complaint; an empty fault memory alone is not a completed torque-control diagnosis.

# P1347: Volkswagen G163-to-G28 correlation and paired timing faults

Ross-Tech describes P1347/17755/004935 as incorrect correlation between camshaft-position sensor 2, G163, and engine-speed sensor G28. The code points to disagreement between references, not a proven internal failure of G163.

## Mechanical and electrical explanations remain open

The documented possibilities include incorrect belt or chain installation, possible chain elongation, G163 failure and G28 failure. The suggested investigation checks timing installation and relevant measuring values as well as the sensors. The source does not publish one correlation specification suitable for every engine.

A physical timing finding and an abnormal sensor signal answer different questions. Keep both attached to the actual engine configuration instead of treating the component names in the fault description as a replacement list.

## Paired codes need application context

When P1340 accompanies P1347 on specified four-valve VR6 engines, Ross-Tech points to technical bulletin 15-07-03. It also describes an Audi 30-valve V6 case involving paired faults after tensioners were installed on the wrong heads. Those examples show why repair history and engine identity matter; neither is a universal diagnosis from the pair of codes alone.

For mixed belt-and-chain cam drives, the note additionally emphasizes correct chain-link positioning. Use the applicable workshop procedure rather than extrapolating a link count from a different engine. Confirm the corrected timing or signal relationship after repair.

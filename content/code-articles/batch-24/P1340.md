# P1340: Volkswagen cam-to-crank correlation: timing and G40/G28 evidence

P1340/17748/004928 concerns incorrect correlation between G40 camshaft position and G28 engine speed in Ross-Tech's VAG reference. It is a relationship fault. A sensor replacement is not automatically justified because the description contains sensor names.

## Separate timing installation from signal faults

The reference identifies incorrect belt or chain installation, possible chain elongation and faults in either G40 or G28. It recommends checking timing installation and using the appropriate measuring values where available. Those are alternative explanations for the relationship error; the page does not give a universal correlation limit.

Recent timing work is relevant because incorrect installation is explicitly listed. It is still necessary to confirm the actual alignment or signal defect rather than assume that the last repair must be responsible.

## Engine-specific notes can change the investigation

For 1.8T applications, Ross-Tech adds oil-pressure and potentially restricted pickup checks, and verification of the correct G40 sensor version. It also cites bulletin 15-07-03 for specified four-valve VR6 engines when P1347 accompanies this code. These notes must be matched to the engine; they are not universal instructions for every Volkswagen.

A further Audi V6 example concerns paired correlation faults after tensioner installation. Treat it as a bounded specialist observation, not proof of swapped tensioners on an unrelated engine. Verify the relevant timing and sensing behavior after the demonstrated fault is corrected.

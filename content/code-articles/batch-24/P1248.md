# P1248: Volkswagen injection-start control deviation and the N108 timing path

Volkswagen P1248/17656/004680 describes a deviation in injection-start timing control. Ross-Tech lists difficult starting and loss of power at higher engine speeds as possible symptoms. The code concerns whether timing control achieves its intended result, rather than identifying a failed pump by itself.

## Fuel history and control response matter

The source includes incorrect timing regulation, a restricted or contaminated pump control range, recent stalling or running out of fuel, and N108 injection-valve wiring among possible contributors. Asking whether the engine recently ran dry can therefore change the context before expensive pump work is considered.

Ross-Tech recommends checking injection start and fuel supply, as well as relevant fuses and N108 connections. Its output-test reference concerns commanded response; it is not an instruction to apply battery power arbitrarily to the valve.

## Keep the ALH-specific note within its scope

A special note concerns ALH engines in Golf/Jetta 9M/1J and Beetle 1C applications. It refers to Volkswagen Tech Tip 23-02-03 and a particular basic-setting response during a controlled N108 test. That example should be matched to the actual engine and original procedure before use; its fuse number and expected display are not universal Volkswagen specifications.

A useful diagnosis ties the timing, fuel-supply or valve-control finding to the complaint, then confirms the corresponding behavior after repair.

# P1242: Volkswagen cylinder 6 injector N84 open circuit

Volkswagen P1242/17650 concerns an open circuit affecting cylinder 6 injector N84 in Ross-Tech's reference. Poor engine performance and a warning lamp are possible symptoms.

## Establish the location of the interruption

The source identifies the injector fuse, wiring harness, injector and engine controller as possible contributors. Its recommended checks cover the fuse, wiring to and from N84, and injector resistance under the repair-manual procedure.

Those tests answer different questions. An external interruption can explain the code without an internal injector defect; a component measurement must be assessed using the specification for the installed injector.

## Retain N84's own evidence

This is the same electrical method Ross-Tech provides for related injector entries. The distinct identifiers here are cylinder 6, N84 and an open circuit. Preserve that mapping and the actual findings when several codes are present, rather than using a satisfactory result from a neighboring cylinder as proof about N84.

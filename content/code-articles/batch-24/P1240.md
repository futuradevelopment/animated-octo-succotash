# P1240: Volkswagen cylinder 4 injector N33 open circuit

P1240/17648 is the open-circuit entry for cylinder 4 injector N33 in Ross-Tech's Volkswagen/VAG reference. Poor running and an engine warning lamp may accompany it.

## Separate supply, wiring and component findings

The documented possibilities are an injector fuse, a harness issue, injector failure and engine-controller failure. Ross-Tech specifically recommends checking the fuse and wiring to and from the injector, then evaluating injector resistance with the applicable repair-manual procedure.

An external interruption and an internally defective injector lead to different repairs. Keep the actual N33 circuit finding alongside the component measurement rather than recording only that an injector-related code was present.

## What this code adds to the shared method

Related injector entries use the same electrical checks. P1240 identifies cylinder 4/N33 and an open circuit. Confirm the engine's cylinder numbering and the installed injector's resistance specification so that the resulting evidence belongs to the branch named by this code.

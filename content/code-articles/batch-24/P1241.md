# P1241: Volkswagen cylinder 5 injector N83 open-circuit diagnosis

Ross-Tech describes Volkswagen P1241/17649 as an open circuit at cylinder 5 injector N83. An engine warning and poor performance are possible symptoms. Verify the actual engine configuration before locating that cylinder and component.

## The interruption may be outside the injector

The reference lists the injector fuse, harness, injector and engine controller as possible fault areas. It recommends fuse inspection, checking wiring to and from N83, and an injector resistance test using the repair manual.

These observations distinguish external-circuit integrity from the injector's electrical condition. The open-circuit label does not establish a nozzle-flow problem or support an injector-cleaning diagnosis by itself.

## Apply the shared checks to the correct branch

Ross-Tech uses the same diagnostic method for neighboring cylinder codes. P1241's specific scope is cylinder 5/N83 and an open path. Use that branch's wiring information and the installed injector's resistance specification when documenting whether the supported repair concerns a connection, wire or component.

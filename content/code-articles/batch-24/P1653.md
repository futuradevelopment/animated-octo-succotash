# P1653: Volkswagen ABS-memory referral: locate the underlying brake-controller fault

Volkswagen P1653/18061/005715 directs the technician to fault memory in ABS/brake-electronics module J104. Ross-Tech lists a fault stored in that module as the cause and an engine warning lamp as a possible symptom.

## Read the originating record

The documented next step is to access Brake Electronics, address 03, and read its faults. Preserve those details alongside the identity of the controller that stored P1653. The referral does not identify a particular sensor, switch or hydraulic component.

## Why another module can report the problem

Ross-Tech explains that controllers depend on information supplied by other modules. A fault at the sending module can therefore affect a receiving controller and cause this referral entry.

The source gives P1847 the same referral meaning. Neither code is a separate component diagnosis: use J104's actual fault record and the vehicle's brake-system symptoms to choose the applicable procedure, then reassess the originating fault and the module that requested its investigation.

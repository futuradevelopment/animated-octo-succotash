# P1570: Volkswagen immobilizer start block: match the symptom before blaming the key

Ross-Tech describes P1570/17978/005488 as engine start blocked by the immobilizer. A characteristic complaint is an engine that starts and then stops shortly afterward. A complete failure to start is not automatically the same problem; the source cautions against assigning every starting fault to the immobilizer.

## Read the immobilizer's own evidence

The reference identifies unmatched keys, instrument cluster or engine controller, as well as an engine-controller power-supply fault. It recommends checking fault memory and measuring values in the immobilizer system, which may be integrated into the cluster or housed separately depending on the vehicle.

That matters because an engine-side P1570 entry can be less informative than the authorization details in the module responsible for the decision. A replacement key is not justified solely by the presence of this code.

## Establish electrical health before matching components

Ross-Tech notes that low battery voltage can disturb immobilizer operation and calls for testing with a sound battery. It also includes the engine-controller supply relay among the checks. These are separate from legitimate key or module matching performed with the correct authorization and vehicle procedure.

The useful record combines the engine's actual start-and-stall behavior, the immobilizer's authorization result and the controller's verified power supply. That separates a matching issue from an electrical problem without assuming that every no-start complaint has the same cause.

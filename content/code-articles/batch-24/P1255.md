# P1255: Volkswagen G62 coolant-temperature circuit short to ground

Ross-Tech describes Volkswagen P1255/17663 as a short to ground in the G62 engine-coolant temperature circuit. The documented complaints can include difficult starting, irregular idle and poor acceleration during warm-up. Temperature indication may also change unexpectedly.

## A temperature-related code can be an electrical problem

The source identifies faulty wiring or connections and a defective G62 sensor as possible causes. That is a different diagnostic branch from assuming the thermostat, coolant pump or radiator has failed simply because the code mentions coolant temperature.

The symptoms in the entry are examples, not pass/fail criteria for every engine. A particular idle speed or dashboard indication cannot by itself establish that G62 is defective. The circuit needs assessment using the actual vehicle's information.

## Separate the signal path from the component

Record whether the evidence concerns the external wiring or the sensor itself. The wiki does not publish a universal resistance curve, connector pinout or diagnostic voltage for this code. Those details must match the installed sensor and controller.

After repair, reassess the temperature information and the original starting or idle behavior. A normal-looking gauge alone does not prove that every temperature signal used by the engine controller is correct. Identify the installed sensor and its actual circuit; housing color alone is not a diagnostic result.

# P1220: Volkswagen cylinder 8 injector N86 short-to-positive fault

Ross-Tech's diagnostic heading associates Volkswagen P1220 with cylinder 8 injector N86 and a short-to-positive circuit condition. Poor performance and an engine warning lamp are possible symptoms.

## Resolve the reference-number discrepancy

The page title and URL use 17627/P1220, while the diagnostic heading uses 17628/P1220. This article follows the P1220/N86 heading but retains that discrepancy as an unresolved source issue. Confirm the complete scan text and component mapping against the vehicle information.

## Shared injector checks, specific circuit

The source lists an injector fuse, harness trouble, injector failure and engine-controller failure. It recommends inspecting wiring to and from N86 and measuring injector resistance using the repair-manual procedure.

Those checks separate external-circuit evidence from component evidence. They are the same method used for related injector codes, applied here to cylinder 8/N86. Neither the shared method nor a changed component resolves the source's inconsistent decimal reference number.

# P1139: Volkswagen bank 2 additive rich trim and the purge-system connection

P1139, VAG reference 17547/004409, means bank 2 additive fuel trim is too rich in the Ross-Tech description. Its fuel-trim guide explains additive adaptation as correction of an idle imbalance. This is learned mixture compensation, not a direct measurement that one named injector is leaking.

## Read the correction in context

Negative trim indicates that oxygen control is reducing fuel to compensate for a rich condition. Preserve the relevant learned values before resetting the controller. Compare the bank and operating-condition labels rather than interpreting an isolated number from an unrelated measuring block.

The code entry lists the airflow sensor, fuel-pressure regulator, injectors, oxygen-sensor control and EVAP system as possible fault areas. The inclusion of EVAP matters: an investigation limited to the injectors would omit a documented contributor to this particular rich-trim complaint.

## Prove the path before selecting a repair

A sensible diagnostic record states which branch was supported by testing. A pressure-regulation finding concerns fuel supply; an oxygen-control problem concerns feedback; a purge-system defect presents another route into the mixture-control problem. P1139 does not rank their likelihood.

Once the identified defect is corrected, reassess bank 2's additive adaptation using the vehicle's procedure. A changed code status without fresh mixture evidence is insufficient to establish that the original rich correction is resolved.

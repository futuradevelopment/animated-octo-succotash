# P1613: Volkswagen engine-warning-lamp circuit and ignition-switch contacts

Ross-Tech describes Volkswagen P1613/18021/005651 as an open or short-to-positive condition in the malfunction-indicator lamp control circuit. The engine warning lamp may not operate correctly. Absence of a lit lamp is therefore not reliable evidence that no engine problem exists when this circuit fault is present.

## The lamp is only one part of the path

The source names the lamp itself, associated wiring or connectors, incorrect controller coding and worn ignition/starter-switch contacts. Those possibilities span a display component, an electrical path and a configuration issue. A lamp replacement cannot resolve every one of them.

Ross-Tech recommends checking the lamp and circuit, verifying coding and evaluating the ignition switch. The entry provides no shared connector pinout, coding value or electrical threshold; those details must match the vehicle.

## Preserve the grouped electrical description

An open circuit and a short to supply are different faults even though the code groups them together. Determine the actual condition rather than treating the words as proof that the instrument cluster is defective.

The diagnostic outcome should restore the warning function and explain the supported fault path. Checking lamp operation after a verified repair matters separately from clearing engine codes, because an inoperative warning lamp can otherwise conceal the information the driver relies on.

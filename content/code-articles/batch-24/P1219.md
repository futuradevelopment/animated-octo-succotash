# P1219: Volkswagen cylinder 7 injector N85 circuit short to positive

P1219/17627 identifies cylinder 7 injector N85 with a short-to-positive circuit condition in Ross-Tech's Volkswagen/VAG reference. Poor performance and an engine warning lamp are documented possible symptoms.

## Preserve the cylinder and component identity

The source names an injector fuse, wiring-harness trouble, injector failure and engine-controller failure as possible causes. It does not establish which one is present. Locate the N85 circuit using the actual engine information before attaching a finding to cylinder 7.

## Supported component and wiring checks

Ross-Tech calls for inspecting wiring to and from the injector and testing injector resistance according to the repair manual. A harness defect and a component measurement answer different diagnostic questions and should be recorded separately.

This electrical method is shared across the adjacent injector-circuit entries. The distinct scope of P1219 is the N85 branch and short-to-positive fault direction; another cylinder's satisfactory test result is not evidence that this branch is sound.

# P1633: Volkswagen G185 pedal signal low: test the pedal path, not the throttle body

Volkswagen P1633/18041 concerns accelerator-position sensor 2, G185, with a signal too low. Ross-Tech explicitly directs attention to the pedal-position assembly rather than the throttle body. That distinction prevents a low pedal-signal complaint being treated as a throttle-angle sensor diagnosis.

## The connections remain a separate fault path

The source names wiring or connection faults and a defective G185 sensor, and recommends checking the connections between the engine controller and pedal. It does not establish a particular warning or driving symptom; its symptom field is unspecified. A symptom profile should therefore not be invented from the code alone.

The entry supplies no universal voltage threshold or connector pinout. These must be matched to the installed controller and pedal system.

## Resolve the source's inconsistent channel description

The P1633 page describes the two pedal channels moving in opposite directions. Ross-Tech's P1639 page describes them increasing together with different scales. Those statements cannot safely be generalized into one test rule for every Volkswagen.

Confirm the expected relationship from the correct vehicle information, then interpret the G185 reading and circuit findings against it. A low-channel code does not by itself prove a failed complete pedal assembly. The useful outcome identifies the demonstrated electrical or component defect without confusing pedal feedback with throttle-body position.

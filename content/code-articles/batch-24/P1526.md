# P1526: Volkswagen N205 cam-adjustment circuit short to positive

P1526/17934 is the bank 1 N205 camshaft-timing adjustment circuit short-to-positive entry in Ross-Tech's Volkswagen/VAG reference. Poor engine performance and an engine warning lamp are possible symptoms. It is an electrical description rather than proof that mechanical cam timing is incorrectly set.

## The harness and adjuster are separate possibilities

Ross-Tech names a wiring-harness issue, an electrical failure of N205 and engine-controller failure as possible causes. Its suggested checks are inspection of the wiring path and resistance testing of the adjuster using the factory repair manual.

The source gives no common resistance value or connector numbering. A measurement must be interpreted against the actual valve and engine specification, not a value borrowed from another cam-adjustment system.

## Preserve the direction of the circuit fault

The short-to-positive wording should remain in the diagnostic record. It is more useful than a broad statement that “cam adjustment failed,” because it directs attention to a particular electrical condition. It still does not show where that condition occurs.

A supported repair explains whether the external circuit or a demonstrated component defect was responsible. After correction, reassess the circuit code and the performance complaint using the vehicle's procedure. Changing a valve and clearing memory without confirming the electrical result leaves the original cause uncertain.

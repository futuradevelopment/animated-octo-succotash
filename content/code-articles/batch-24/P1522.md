# P1522: Volkswagen bank 2 cam adjustment: separate G163 feedback from N208 operation

Ross-Tech identifies P1522/17930 as a bank 2 camshaft-adjustment malfunction. Its possible causes distinguish wiring to G163 camshaft-position sensing, wiring to the N208 adjuster unit, mechanical adjuster failure and an engine-controller problem. That distinction prevents a feedback fault being mistaken automatically for a failed actuator.

## Trace feedback and adjustment separately

The source recommends inspecting both electrical paths, evaluating adjustment with the applicable output test or basic setting, and checking the adjuster's chain guides for wear. These are different sources of evidence; no single code establishes which one is responsible.

The entry provides no universal timing specification, terminal numbers or expected response to an activation test. Those must come from the actual engine documentation.

## Resolve the source's bank-label inconsistency

Although the heading and surrounding text identify bank 2/N208, one solution line calls N208 a bank 1 valve. This article retains the bank 2 scope of the heading but does not treat that inconsistent line as a reliable component-location instruction. Confirm the bank and component mapping before any physical work.

A useful repair record identifies the verified wiring, feedback, actuator or mechanical finding and checks the relevant function again afterward. Merely replacing an adjuster because its name appears in the code would not resolve either the diagnostic uncertainty or the source's wording error.

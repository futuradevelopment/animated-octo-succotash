# P1649: Volkswagen missing ABS message: read J104 and check communication

Volkswagen P1649/18057/005705 reports a missing message from the ABS controller on the powertrain data bus in Ross-Tech's reference. The diagnostic instructions identify brake-electronics module J104. This is a communication complaint, not a direct diagnosis of a wheel-speed sensor or hydraulic component.

## Read fault memory and communication status separately

The source lists faults stored in J104 and a communication error with it as possible explanations. It recommends reading the brake module's own faults and checking communication, including the relevant measuring values. A reachable module with an informative internal fault record presents different evidence from one that cannot communicate.

The code entry does not give a universal wiring topology, network voltage or replacement instruction. The actual vehicle's system information is required to investigate a demonstrated communication-path problem.

## Keep the brake-system evidence intact

Retain the complete scan and module identification before clearing entries. A code reported elsewhere may only describe the missing information, while J104's own records explain the originating problem more precisely.

If brake warnings or operating complaints are present, they require appropriate qualified assessment rather than a conclusion based solely on the engine-side code. After the supported issue is corrected, confirm both the relevant brake-controller status and restored module communication. P1649 alone cannot establish that the ABS controller must be replaced or that braking functions are normal.

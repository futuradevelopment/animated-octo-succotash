# P1455: Volkswagen G235 exhaust-temperature plausibility and the BBW note

P1455/17863 refers to an implausible signal from exhaust-gas temperature sensor 1, G235, in Ross-Tech's Volkswagen/VAG reference. The description questions the signal's credibility. It does not by itself establish that exhaust temperature has exceeded a mechanical limit.

## A plausibility fault still needs circuit checks

Ross-Tech lists a fuse issue, faulty G235 wiring or connectors, and a defective sensor as possibilities. Its checks cover these areas separately. Replacing the named sensor without evaluating the external circuit would leave documented alternatives unexplained.

The entry supplies no temperature threshold, resistance curve or universal connector assignment. The installed engine and sensing system determine the appropriate specifications.

## Treat the engine-specific note as a bounded lead

The wiki highlights G235 concerns on North American BBW 2.0L engines in 2004–2005 Golf/Jetta/Bora 1J/9M applications. That is Ross-Tech's application note, not a failure-rate study or proof that every P1455 vehicle has a defective sensor. Confirm the engine identity before using it to prioritize the investigation.

The repair record should identify whether the problem lay in the external circuit or the sensing component and then reassess the reported temperature information and code status. An engine warning lamp is a possible symptom, but it cannot establish which of those paths requires repair.

# P1250: Volkswagen low-fuel code: verify quantity before condemning the sender

P1250/17658 means fuel level too low in Ross-Tech's Volkswagen/VAG reference. Difficult starting is a possible symptom. The entry makes an important distinction between actual fuel shortage and a level-sender problem that makes the indicated quantity unreliable.

## Check the fuel quantity and the indication separately

The source recommends establishing the real level and adding fuel when required. If the gauge does not represent the actual quantity, it directs attention to the level sender or senders. A gauge position alone should therefore not be treated as independent proof that there is enough fuel, nor as proof that the sender has failed.

This code does not establish low delivery pressure at the engine. Any pump or pressure diagnosis needs evidence beyond the low-level entry.

## A persistent stored code can have an additional clearing condition

Ross-Tech notes that on some vehicles P1250 may remain after refueling and cites Volkswagen CTT 20-16-02; its note mentions roughly 16 km or 10 miles before clearing. This is an application-dependent observation, not a requirement to drive any vehicle with a starting or fuel problem.

Confirm the applicable procedure and current vehicle condition before drawing conclusions from immediate code persistence. A useful repair record distinguishes restored fuel quantity, corrected sender accuracy and subsequent fault status instead of assuming those three events must occur together.

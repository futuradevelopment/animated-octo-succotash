# P1850: Volkswagen missing engine-controller message and the replacement caution

P1850/18258 reports a missing message from the engine controller on the powertrain data bus in Ross-Tech's Volkswagen/VAG reference. An engine or other warning lamp may accompany it. Missing information does not itself establish that the engine controller is internally defective.

## A supply or data-path defect can make a controller appear absent

The reference lists a blown control-module fuse, wiring-harness trouble and controller failure as possible causes. Its recommended inspection concerns CAN wiring and terminals between controllers. These alternatives should be separated with the correct vehicle circuit information rather than inferred from one receiving module's complaint.

The entry gives no universal bus-voltage threshold, module pinout or network layout. A physical diagnosis must match the actual installation.

## Treat the bulletin reference as a reason to verify, not guess

Ross-Tech cites TSB 01-07-54 with a caution against replacing the ECM for this DTC. The page does not reproduce the complete bulletin scope or reasoning. Obtain the applicable original document before turning that note into a universal rule; it clearly does not support ordering an ECM solely from P1850.

A useful result identifies the demonstrated supply, connection or communication defect and confirms restored module interaction. Replacing an expensive controller without establishing the failed path can leave the missing-message cause unresolved.

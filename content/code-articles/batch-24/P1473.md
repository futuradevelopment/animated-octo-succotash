# P1473: Volkswagen leak-detection pump open circuit and canister sealing

P1473/17881/005235 identifies an open circuit associated with the EVAP leak-detection pump, LDP/V144, in Ross-Tech's Volkswagen/VAG reference. The code is not simply a synonym for a loose fuel cap. Its primary description is an electrical pump-circuit condition.

## The reference includes two different diagnostic branches

Ross-Tech lists a defective V144 pump and faulty wiring or connectors to it. It also includes a leaking EVAP canister system and recommends checking that system's seal. The electrical path and system sealing therefore need to be considered as distinct findings rather than treated as interchangeable explanations.

A seal check does not establish circuit continuity, and an electrical repair does not by itself prove that the complete vapor system is tight. Keep each test result attached to the question it actually answers.

## Use the correct pump and vehicle procedure

The entry does not specify a pump pinout, resistance threshold or leak-test pressure. Those details must come from the applicable vehicle information. The page's recommendation to check V144 is not permission to power it arbitrarily or replace it solely because its name appears in the code.

After the confirmed defect is repaired, reassess the relevant pump-circuit operation and any separately identified sealing issue. The useful outcome is documented restoration of the affected function, not just an empty fault memory.

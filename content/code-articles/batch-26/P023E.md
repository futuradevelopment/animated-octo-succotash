# P023E: Compass pressure-plausibility warning during cold acceleration

## The code concerns how the pressure signals change

P023E is turbocharger-pressure and manifold-pressure plausibility in this bulletin, with the signal rate of change below threshold. The associated Euro 6D complaint can be hesitation or surging after a cold start, particularly in second gear below 3,000 rpm, with full power seeming to arrive after a few minutes. That operating pattern helps the workshop evaluate the documented calibration case instead of diagnosing solely from a generic boost-pressure label.

## Do not merge every symptom in the update package

The same revision adds a separate 40–80 km/h acceleration hesitation description for 2018 MP vehicles. It also lists an electronic-throttle learning fault. Those are additional package items, not proof that every P023E vehicle has a throttle defect or all of the listed behaviors. Record the actual gear, engine temperature, speed range and companion faults, then verify the engine, transmission, emissions sales code and current PCM calibration.

## The supported remedy is a qualified software update

For the matching condition, FCA directs programming the PCM with the applicable latest software and clearing faults generated by the procedure. It first requires unrelated faults to be recorded and repaired as necessary. Ask the workshop to compare the original cold-start acceleration behavior after the update; a warm-only test could miss the complaint. If the pressure-plausibility fault persists, continue the vehicle-specific pressure-signal diagnosis. This bulletin supplies no authority to replace a turbocharger or pressure sensor without further evidence.

## Source and applicability

FCA bulletin 18-031-21, March 2021: EMEA 2018 Compass M6 and 2017–2018 Compass MP with 1.4 L EAQ MultiAir turbo engine and DE1 C635 manual transmission. The P023E and cold-start description specifically requires Euro Stage 6D equipment, NBD.

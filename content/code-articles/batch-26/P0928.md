# P0928: Chrysler 300 rotary-shifter lock and module identification

## Knob movement is not transmission movement

The bulletin describes a rotary shifter that may turn without the brake being depressed, producing a flashing drive indication and a return-to-Park message. It explicitly says the transmission does not leave Park in that situation. This distinction prevents an incorrect conclusion that every observed knob movement means the vehicle has selected a drive gear.

## A different symptom can share the code

The same case also includes an electronic shifter that will not move out of Park. P0928-00, the brake-transmission-shift-interlock control entry, may be found. Preserve which behavior actually occurred rather than treating the opposite symptoms as interchangeable descriptions.

## The part-number branch controls replacement

FCA first checks the electronic-shift-module part number through diagnostics. A suffix of AF or later already represents the updated module for this bulletin; the prescribed replacement branch is for the earlier unit. If the updated module is installed and the complaint persists, this document does not establish that another identical replacement will cure it. The selected part also depends on the vehicle’s equipment. After the proper repair, the source calls for checking shifter operation through the gear selections with the brake applied. Use a controlled professional verification and the vehicle’s parking precautions; do not bypass the interlock. This is a narrow hardware-revision case, not a universal P0928 diagnosis.

## Source and applicability

FCA 21-034-15 covers 2015 Chrysler 300 LX with rotary-shifter sales code C1G, built through February 13, 2015.

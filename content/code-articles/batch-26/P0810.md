# P0810: Grand Cherokee PHEV clutch control and recall sequencing

## The hybrid transition is useful evidence

The source lists P0810-00, clutch-position control error, in a transmission-software case. Associated complaints include rough engine engagement, abrupt EV-to-hybrid transitions when battery charge is low and, in some cases, loss of propulsion with a service-transmission warning. Record when the event occurs; that context is more useful than treating the code as a generic worn-clutch diagnosis.

## Check the recall before a standalone update

The bulletin directs completion of the 04B recall instructions before proceeding and says the TCM update is covered by that recall when it remains incomplete. A workshop should therefore establish the VIN’s recall status and repair history, not simply select a flash based on P0810. A key cycle restoring operation is a reported behavior, not proof that the underlying condition has been repaired.

## Keep the repair professional and bounded

The application requires the specified hybrid engine and transmission, and unrelated faults must be investigated. The source prescribes a TCM update under the proper hybrid-service precautions; it does not publish clutch travel limits, an adaptation shortcut or a universal transmission-replacement rule. After service, verify the applicable recall/update completion and reassess the original transition or propulsion complaint. Continuing or recurrent propulsion loss requires professional attention. This historical case should not be applied to a gasoline-only Grand Cherokee or another transmission merely because the scan tool shows the same base code.

## Source and applicability

FCA 21-030-24 concerns specified 2023 Grand Cherokee WL PHEV ECX vehicles with the 8P75PH DFY transmission.

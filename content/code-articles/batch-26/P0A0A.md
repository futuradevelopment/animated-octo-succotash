# P0A0A: Pacifica hybrid interlock fault: stored status versus an active fault

## The stored-versus-active distinction is mandatory

P0A0A-00 concerns the high-voltage system interlock circuit. This revision applies only when the code is stored in the battery-pack control module. If it is active, the bulletin explicitly does not apply and normal diagnosis is required. That is the decisive branch: treating an active interlock fault as a known software nuisance could bypass the investigation the manufacturer requires.

## Match the complete intermittent no-start pattern

The covered customer complaint includes loss of both gasoline and electric propulsion while the 12-volt system continues operating. After some time, propulsion becomes available again, with the warning lamp on and P0A0A retained as stored. Save the code status and timeline before clearing anything. A warning without that required symptom pattern, or a code reported by another module, does not establish this repair case.

## The repair is BPCM programming under hybrid safety procedures

For the exact stored-fault condition, FCA identifies BPCM software and prescribes the applicable update. The vehicle must be prepared by a trained hybrid technician and disconnected from external high-voltage charging during programming. This is not permission to bridge an interlock, unplug orange connectors or repeatedly attempt to force propulsion. Ask the repairer to document the initial status, software update and restored start operation. If the code is active or returns with a different pattern, pursue the interlock diagnostics rather than assume the same calibration remedy remains appropriate.

## Source and applicability

FCA bulletin 08-124-26 Rev. A, March 2026: North American 2025 Chrysler RU vehicles with 3.6 L EH3 plug-in-hybrid engine. Confirm the individual model and powertrain; the Pacifica/Voyager family heading does not extend the procedure to a non-hybrid vehicle.

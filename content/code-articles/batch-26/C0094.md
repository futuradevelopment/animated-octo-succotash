# C0094: Cherokee AWD over-temperature code and rear-drive classification

## A configuration issue can produce a temperature warning

C0094-4B identifies rear differential temperature over-temperature in this bulletin. It can appear with C149B-98, a four-wheel-drive warning and poor AWD operation. FCA identifies drivetrain-control-module misconfiguration as the cause addressed by this action. The code therefore warrants checking the documented configuration before assuming a failed temperature sensor or damaged rear drive unit. Real heat, noise or driveline symptoms must still be reported and assessed.

## Compare the stored classification with the physical unit

For an eligible VIN, the technician reads the RDU classification value in the drivetrain controller. The bulletin gives stored value 6844 a direct programming path. For other values, it requires recording the classification from the rear-drive-unit label and comparing it with the scan-tool value. Matching values end that inspection branch without replacement. This is a comparison with the installed unit, not permission to copy a classification number from another vehicle.

## Confirm the programmed result after sleep

Where reconfiguration is required, the workshop uses the dedicated RDU classification programming function, allows the vehicle to sleep and then reads back the value to verify it was written. Associated faults are cleared afterward. Ask the repairer to retain the original and final classification values and confirm AWD behavior. The action explicitly applies only to listed VINs, so an identical code on an unlisted Cherokee or another Jeep cannot establish that this configuration remedy is appropriate.

## Source and applicability

FCA bulletin 08-307-26, August 2026: North American 2026 Jeep Cherokee KM with Jeep Active Drive I, sales code DK2. The repair is restricted to the RSU 26-149 VIN list; the printed production interval is January 2, 2025–July 16, 2026.

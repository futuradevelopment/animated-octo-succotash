# U0137: Ram trailer-brake communication behind a park-assist warning

## Why the warning can look unrelated

FCA documented a park-assist-disabled message accompanied by U0137 on the specified Ram trucks. The communication path to examine is between the integrated trailer-brake module and the park-assist system. A parking-system warning therefore does not, by itself, establish that a bumper sensor is defective. The stored network code identifies a different relationship that needs to be checked.

## Stored and active are different branches

The source separates a stored U0137 from an active fault. For the stored case, its verification uses five ignition cycles beginning from bus sleep, then checks whether the code becomes active. Ordinary rapid key toggling is not equivalent to that sleep-based condition. This distinction helps establish whether the vehicle has a repeatable communication loss or only a historical event recorded in memory.

## Evidence before replacement

FCA directs diagnosis toward connector installation, harness or connector damage, water intrusion and possible aftermarket-equipment issues. These are checks within the communication diagnosis, not a ranked list of guaranteed causes. If U0137 is active, preserve a complete scan report before further repair decisions. The historical note requests technical assistance but does not publish a circuit threshold or an automatic replacement rule for either module. A useful work order should state which module reported the fault, whether it was active, and what happened after the prescribed sleep-and-wake verification. Apply the applicable current network procedure to the actual vehicle rather than replacing the trailer-brake module solely because its name appears in the code.

## Source and applicability

FCA GPOP 9004253, dated April 15, 2020, covers 2019–2020 Ram DT, DJ and D2 trucks with the specified integrated trailer-brake module application.

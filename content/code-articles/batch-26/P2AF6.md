# P2AF6: Wagoneer starter-relay indication from an unseated connector

## A relay label can hide a connection problem

The bulletin associates P2AF6-00, described here as starter relay 3 stuck off, with disabled stop/start. Its stated cause is a connector that is not fully seated at the power-distribution center. This is a specific reason to inspect the connection before ordering a relay or complete distribution assembly.

## The physical finding controls the action

FCA identifies connector D3157A and distinguishes a properly connected unit from one that needs reseating. The repair does not say to replace the power-distribution center solely from the code. Access and reconnection must follow the correct service procedure so the original seating issue is not replaced by a new connection fault.

## Verification checks pending status too

The source requires five stop/start events within one drive cycle, confirmation that warning lamps do not appear and a check that P2AF6 is not pending. A successful engine start or an empty active-code list alone is weaker evidence than that prescribed verification. If the code resets, the bulletin explicitly sends the technician back to normal diagnosis. Confirm the build window and exact application, preserve the connector finding and document the retest. This case does not establish that every P2AF6 is a loose connector or authorize bypassing the starter-control circuit.

## Source and applicability

FCA 08-138-23 concerns North American 2022–2023 Wagoneer/Grand Wagoneer WS built August 24, 2022–March 8, 2023.

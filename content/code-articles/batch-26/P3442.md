# P3442: Ram cylinder-six deactivation and optional MDS software

## The cylinder number is diagnostic information

The bulletin identifies P3442 as cylinder-six deactivation-control performance. It separately lists equivalent performance entries for cylinders one, four and seven. Retaining that cylinder identity matters when reviewing a scan; the presence of a software correction does not make all cylinder-specific mechanical or electrical findings interchangeable.

## Do not confuse the optional file with the code fix

FCA offers an optional software path for certain D2/DJ trucks with MDS/ECO drone or shudder under light throttle. It explicitly says both the optional and standard files address the other listed conditions. P3442 therefore does not, by itself, select the noise-focused option. The actual customer complaint determines whether that additional refinement is relevant.

## Verify the application and outcome

The release has a build cutoff, engine codes and transmission requirements. It also distinguishes MDS improvements for the 66RFE from stationary-PTO behavior for the AS66RC. A workshop should document those identifiers, address unrelated faults and record the installed calibration before reassessing the original warning. If the code returns with confirmed cylinder-six abnormalities, the bulletin is not evidence to ignore them. It provides a software case, not an oil-pressure threshold, lifter test or automatic deactivation-solenoid replacement rule. Persistent symptoms need the correct current diagnostic procedure rather than repeated clearing of the same cylinder code.

## Source and applicability

FCA 18-080-15 revision A concerns specified 2016 Ram 6.4 L ESA/ESB trucks built through November 8, 2015, with DFP or DF3 transmissions.

# P084F: Pacifica park-neutral output and unusual battery drain

## A code-linked battery-drain clue

The manufacturer specifically associates unusual battery drain with P084F-00 in this hybrid-controller update. The document labels the code as park-neutral switch output. That connection is useful when the complaint is a discharged battery: the park/neutral control state belongs in the investigation rather than assuming every drain begins with a defective battery.

## Do not attribute every listed symptom to this code

The release also addresses no-start, heating, permanent-code clearing and hybrid-transition behaviors. Their presence in the same bulletin does not show that P084F causes all of them. Record the actual drain and operating pattern together with the complete fault set before selecting the software path.

## The update order is explicit

This revision calls for the hybrid control processor first and the auxiliary hybrid control processor second. It removes or revises earlier procedure wording, making the exact bulletin version important. Qualified personnel should confirm vehicle applicability, perform the supported hybrid-safe programming sequence and document both final software levels. The source does not supply a parasitic-current limit, a switch-voltage threshold or a universal battery-replacement decision. After the proper repair, reassess the original battery-drain and park/neutral complaint. A returning fault requires current diagnosis; clearing memory alone does not establish that the vehicle now enters the correct operating or sleep state.

## Source and applicability

FCA 08-108-26 revision A concerns the listed 2019 RU hybrid EH3/EFLITE DFQ application in North America and China.

# P258B: Ram eTorque vacuum-pump performance and calibration

## The documented calibration issue

On the specified 2019 Ram 1500 eTorque application, FCA includes P258B among faults addressed by a PCM software release. The source describes an electric-vacuum-pump calibration change intended to reduce pump wear. That is a meaningful connection between control strategy and the pump-performance complaint. It does not establish that an already damaged pump can be restored by software.

## Do not merge unrelated checks

The same bulletin lists crankshaft-sensor codes and P0456, along with several other drivability complaints. Its small-leak verification instruction is specifically tied to P0456; it is not a P258B vacuum-pump test. Keep the actual code set and symptoms separated when planning diagnosis. A brake-assistance complaint deserves direct evaluation of the affected system rather than reassurance based on the availability of a reflash.

## The update is a coordinated repair

The documented remedy requires the PCM update and confirmation that the transmission controller and hybrid control processor also have the applicable software. Updating one module without checking the others is not the complete bulletin procedure. Before applying that path, verify the DT model, EZL engine and matching complaint, and resolve additional conditions that fall outside the bulletin. Afterward, document the installed calibration set and assess whether the original performance fault returns under the relevant conditions. This historical bulletin supplies no pressure threshold or complete vacuum-pump circuit test, so persistent faults still need the current vehicle-specific diagnostic procedure. Its existence alone is not a basis for ordering a pump.

## Source and applicability

FCA 18-076-20 revision A covers 2019 Ram 1500 DT with the 5.7 L eTorque EZL engine in the listed markets. This is the November 3, 2020 software case.

# P06E4: Pacifica wake-up performance and permanent-code clearing

## The distinction is code status

FCA lists P06E4, control-module wake-up circuit performance, in a 2018 Pacifica PHEV software bulletin. The associated concern includes permanent diagnostic codes that do not clear as expected and interfere with an emissions inspection. A permanent record is not the same observation as a presently active wake-up-circuit malfunction. Preserve the status and reporting module rather than treating every stored entry as a newly failed controller.

## One update is not the whole correction

The PCM update is linked to software in the electronic brake booster, ABS module and both hybrid control processors. The document warns that completing only the PCM portion can leave vehicle malfunctions. It also provides an inspection branch when the PCM already has the latest applicable software. These details make calibration verification more useful than repeatedly clearing memory or replacing a module named by the generic code description.

## What remains to be checked

The source still requires related systems to be checked and other symptoms or faults to be addressed. Its software path therefore does not prove every wake-up circuit is electrically sound. A workshop should document the initial code status, the full module-software set and the result of the appropriate post-update verification. If the actual fault remains active, use current vehicle-specific electrical diagnosis rather than assuming permanent-code logic explains it. The article applies to the documented 2018 hybrid, not gasoline-only Pacificas or every model year. Historical campaign and inspection comments are context, not a promise of current warranty coverage or an emissions-test pass.

## Source and applicability

FCA 18-003-21 covers 2018 Chrysler Pacifica PHEV with the 3.6 L EH3 engine in North America and APAC (China). This is a historical coordinated software case.

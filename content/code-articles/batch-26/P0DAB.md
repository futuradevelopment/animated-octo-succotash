# P0DAB: Wrangler cell-balancing performance and the recall prerequisite

## Cell balancing is one distinct battery observation

FCA lists P0DAB-00 as hybrid/EV cell-balancing performance in this battery-pack-controller software release. Other listed entries concern contactor behavior, charging current and voltage variation. These are separate diagnostic observations; P0DAB alone does not identify a defective cell or establish that all of those conditions are present.

## Check the prerequisite before the flash

The repair procedure asks whether the 95B recall instructions have been completed and routes the technician through those instructions if needed. That prerequisite is more important than treating the bulletin as a standalone software download. The document also has a branch for an RSU vehicle that already contains the applicable BPCM software.

## What the source supports

For a matching vehicle and code condition, the source supports checking the battery-controller calibration within the prescribed repair sequence. It does not provide cell-voltage tolerances, a balancing-current test or authorization to open the pack. Preserve the complete diagnostic report, applicable recall status and installed software before making a battery-replacement decision. The source requires qualified high-voltage personnel and specific vehicle preparation for the update, so this is not an owner reset procedure. After service, verify the documented repair completion and reassess the original battery fault using current guidance. A code that persists after the correct sequence still needs diagnosis; neither a cleared lamp nor this bulletin alone proves battery condition.

## Source and applicability

FCA 08-034-25 concerns specified 2024 Wrangler JL PHEV ECX vehicles built through April 1, 2024; confirm market, VIN and recall status.

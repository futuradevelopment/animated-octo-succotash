# P2AF5: Compass relay diagnosis when the auxiliary battery is depleted

## A relay-related code can be a false failure

FCA warns that the documented relay and power-distribution diagnostics are not robust against a depleted auxiliary battery. The note names P2AF5 and P2AF6 in connection with unnecessary parts replacement and no-trouble-found returns. Battery condition is therefore relevant evidence before treating the diagnostic label as proof of a mechanically stuck relay.

## The follow-up publication matters

The note directs the technician to a specific STAR case for the relay concern. It does not reproduce that complete procedure or supply a battery-test threshold. The appropriate action is to establish the auxiliary battery’s condition and follow the current referenced diagnosis, not to invent a test voltage or replace the power-distribution center merely because the code names a relay.

## Do not borrow the separate A/C remedy

A second paragraph discusses an air-conditioning clutch-control complaint and a PCM reset. That is a different case in the same note; it is not a documented P2AF5 repair. Keep the actual code set, battery findings and customer complaint separate. After the proper correction, reassess the original fault and operating behavior. This source supports avoiding an unsupported assembly replacement, but it does not establish that every P2AF5 vehicle has only a weak battery or that a returning active fault may be ignored.

## Source and applicability

FCA GPOP 9100652, dated October 14, 2026, concerns 2024–2026 MP and the specified power-distribution assembly. Original scanned page was visually checked.

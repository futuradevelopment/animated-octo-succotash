# P2181: Cooling-performance codes in an older FCA software case

## An erroneous-code example is not a cooling-system test

The bulletin explicitly includes P2181 among erroneous diagnostic codes corrected by PCM software on specified older FCA applications. That is evidence for checking calibration when the vehicle fits. It does not show that coolant level, circulation or temperature control is satisfactory on a vehicle with an actual overheating complaint.

## The release contains several unrelated behaviors

The same document addresses transmission shifts, torque-converter scheduling, cold-start behavior and other codes. Those changes should not be presented as symptoms caused by P2181. The model, engine and transmission table limits which software applies; being a Dodge or Ram from roughly the same period is insufficient.

## Use the bulletin after checking the real condition

Document whether the complaint is a warning code without observable cooling abnormalities or includes a temperature problem requiring direct diagnosis. FCA instructs technicians to address other faults before its update procedure. For an applicable software case, retain the initial and final calibration identification and verify whether the original code returns. For a persistent cooling fault, continue with the current vehicle-specific procedure rather than treating a successful flash as a completed mechanical repair. This bulletin supplies no thermostat-opening specification, coolant-temperature threshold or automatic water-pump replacement instruction. Its value is recognizing one documented false-indication path while keeping actual cooling-system evidence central.

## Source and applicability

FCA 18-093-15 covers the listed 2009–2010 Dodge, Chrysler and Ram engine/transmission combinations; verify the full model and sales-code table.

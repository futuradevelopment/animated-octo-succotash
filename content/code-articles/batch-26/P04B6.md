# P04B6: Cherokee stored fuel-door fault and false-setting logic

## Stored status is part of the documented condition

The bulletin describes P04B6-00, fuel-fill door stuck closed, in stored status without a malfunction lamp. It expressly includes a correction for false setting of that code. A stored record on a normally functioning fuel door is therefore different evidence from a door that physically cannot be opened.

## Do not use other software symptoms as proof

The same release addresses warm-up oscillation, stop/start refinement and after-run pump behavior. Those additional improvements do not show that a fuel-door fault caused the engine symptoms. Preserve the actual door operation, code status and customer complaint separately.

## The software set is coordinated

Although the title names the PCM, the repair inspects and potentially updates the BPCM, drive-motor power inverter, EVCU and PCM. A record of one completed flash is not sufficient to establish that the applicable combined sequence is finished. Confirm the build interval and hybrid engine, address unrelated faults and document the final module levels. Then reassess the original door and operating complaint. The source does not provide an actuator force specification or an instruction to dismantle a pressurized fuel system. A genuinely stuck door after the relevant update still needs the correct current mechanical and electrical diagnosis.

## Source and applicability

FCA 18-052-26 concerns North American 2026 Cherokee KM with the 1.6 L EJN hybrid engine, built December 15, 2025–April 24, 2026.

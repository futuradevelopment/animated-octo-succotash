# P0070: Ram mirror-temperature readings and the update delay

## A displayed value may need time to settle

FCA’s mirror-mounted ambient-temperature note describes a P0070/P0073 case on 2024–2025 DT trucks in which the temperature reading needs an appropriate update period with airflow. Its verification specifies sustained vehicle operation, not a momentary ignition cycle. The source uses a threshold above 20 mph and approximately fifteen minutes; its casual “highway speeds” wording should not be interpreted as a requirement to exceed local limits.

## There is a diagnostic stop point

If the reading still does not update after the specified conditions, the note directs normal diagnosis. It does not authorize indefinitely dismissing an incorrect display or repeatedly replacing the mirror sensor without testing. Record whether the displayed temperature actually changed and whether the relevant code remained present.

## Do not merge the later branch

The same page has a separate 2025–2026 instruction for both P0071 and P0073 on trucks built in a narrow July 2025 interval. That branch calls for additional service information before sensor replacement. It is not the P0070 branch. Match the year, code combination and build criteria before applying either instruction. A safe workshop verification should use suitable road conditions and preserve the initial temperature complaint. The note supplies no universal sensor-resistance specification and does not establish that every P0070 is merely display lag.

## Source and applicability

FCA GPOP 9100463, dated December 9, 2025, distinguishes a 2024–2025 DT P0070/P0073 case from a separate 2025–2026 P0071/P0073 build-window case.

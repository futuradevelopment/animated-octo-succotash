# U019F: Mercedes M256 coolant-pump communication and insulation contact

## Use the engine limit first

Mercedes links U019F00 or U019F87 in the MRG1 controller with a red coolant warning on a defined M256.9 engine population. The document expressly excludes M256.8. Similar engine-family names are therefore not enough to apply this repair. A red coolant warning also requires attention to the actual cooling condition rather than assuming that a communication code is merely cosmetic.

## The pump is not the only possible cause

The guided path begins with the pump’s power, ground and controller connections, followed by reassessment of pump actuation. The document then identifies a separate condition involving unwanted contact around the coolant pump and engine insulation or heat shielding. This is a useful distinction: a network complaint can involve the electrical environment around the pump, not just a defective pump motor.

## Controller replacement is conditional

The bulletin’s later branch checks an internal controller continuity path after the preceding criteria have been evaluated. Replacement is conditional on the specified open-circuit finding; it is not authorized by U019F alone. Such work involves the vehicle’s 48-volt system and controller connections, so use trained service personnel and the complete current Mercedes procedure. Request a record of the engine applicability, connection findings, actuation result and reason for any controller replacement. Final confirmation includes normal pump operation and fault reassessment. This summary deliberately does not turn professional connector measurements into a generic owner probing guide.

## Source and applicability

Mercedes LI20.10-P-075374 version 2, dated September 16, 2026, applies to M256.9 before engine number 2569xx30 599756 and explicitly excludes M256.8.

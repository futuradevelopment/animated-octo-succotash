# U0111: Cherokee hybrid battery communication and coordinated software

## Communication can fail within a software interaction

The 2026 Cherokee bulletin includes diagnostic improvements for U0111 and revised CAN-bus management. Its associated complaints include a vehicle that cannot start and cannot be keyed off while the 12-volt system remains powered. These details make the complete state of the vehicle and reporting modules more useful than interpreting the battery-controller communication label as proof of a failed battery pack.

## The correction spans four controllers

The repair inspects and, where necessary, updates the battery-pack controller, drive-motor power inverter, electric-vehicle controller and PCM. A coordinated change also addresses high-voltage battery drain during module programming. This is not a single-module reset: the existing software levels determine which portions of the package are needed.

## Keep the diagnostic limit clear

The bulletin lists U0111 as an improvement but does not publish a universal timeout or an electrical fault-isolation tree for it. Additional faults and symptoms still require investigation. Record which modules communicate, whether the no-start/key-off pattern occurred and which software versions were present before service. Confirmation should reassess the original operating state and communication faults after the approved procedure. Hybrid programming and any high-voltage work belong with qualified personnel using the full service instructions. The build interval, engine and market are essential limits; this document does not establish the same cause for older Cherokees or every vehicle carrying U0111.

## Source and applicability

FCA 08-184-26 concerns North American 2026 Cherokee KM with the 1.6 L EJN hybrid engine, built December 15, 2025–April 24, 2026.

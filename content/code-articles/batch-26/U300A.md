# U300A: Ram headlamp ignition-status faults: stored versus active

## The reporting module changes the interpretation

This note concerns U300A-29 in the left and right headlamp modules, not a general instruction to replace the ignition switch. FCA describes a stored invalid-ignition-signal record on the listed headlamp software versions. The code can reappear in stored form whenever the ignition is cycled even though the lamps are serviceable.

## A timed check separates the branches

The source calls for an initial clear and restart, then checks the code state ten seconds after the engine is on. If it is active, the hardware ignition line needs diagnosis and repair as appropriate. If it returns only as stored under the documented conditions, the note says no headlamp repair is required. Omitting the status or timing loses the distinction that makes this bulletin useful.

## What to ask the workshop

Record the headlamp module identities, software versions and the result of that active-versus-stored check. A functioning lamp with the specific stored event is a different case from a persistent active circuit fault or an inoperative lamp. The note supplies no universal ignition-line pinout or voltage threshold and should not be generalized to unrelated modules reporting U300A. Confirm normal lamp operation and use current service information if the actual complaint falls outside the documented software case.

## Source and applicability

FCA GPOP 9100525, dated March 26, 2025, concerns specified 2025 Ram heavy-duty headlamp modules with software 24.43.00 or 24.44.00.

# P0513: Pacifica hybrid no-start and paired control-module software

## Read the companion code

FCA documents a no-start condition with P0513 and U151A-87 on the specified Pacifica hybrid. The first code concerns an invalid key authorization; the companion code concerns a missing hybrid-control-processor secret-code message. Seeing the pair changes the investigation: the bulletin identifies a software case involving hybrid controllers, so a new physical key should not be assumed to be the correction.

## Why the module combination matters

The prescribed update covers both the hybrid control processor and auxiliary hybrid control processor, followed by confirmation of the PCM software. FCA explicitly warns that failing to update the PCM after the hybrid controllers can leave vehicle malfunctions. A repair invoice saying only “computer updated” is therefore incomplete evidence; the workshop should identify the affected modules and their final software levels.

## Keep other symptoms in context

The release also addresses permanent-code clearing and several charging or cold-weather behaviors. Those are separate issues within one software package, not symptoms that every P0513 vehicle must exhibit. Match the exact model, build date, engine and observed no-start or code combination before applying the historical bulletin. Other faults still need their own diagnosis. Where the controllers already contain the relevant correction, repeating the update is not proof that the authorization problem has been solved. Verify starting behavior and the complete code set afterward. This source does not provide a key-programming bypass, and its historical campaign period does not establish present eligibility.

## Source and applicability

FCA 08-091-21 concerns 2021 Chrysler Pacifica PHEV with the 3.6 L EH3 engine, built on or before March 26, 2021 for North America.

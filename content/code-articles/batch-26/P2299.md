# P2299: Journey pedal-signal incompatibility and the 2.4 L calibration row

## The code compares pedal information

P2299 describes incompatible brake-pedal and accelerator-pedal information in this manufacturer case. The bulletin offers a PCM software correction for the specified Journey engine. The code alone does not prove that the driver pressed both pedals incorrectly, nor does it establish which pedal sensor or switch is defective.

## Keep the engine-specific distinction

The source separates Journey 2.4 L, Journey 3.6 L and minivan sections. P2299 appears in the 2.4 L row; it should not be extended to every vehicle covered by the software bulletin. Other improvements on the page, including oil-change calculations and shift behavior, are not evidence that those symptoms are caused by the pedal-correlation code.

## Use the software case without skipping diagnosis

Confirm the JC platform and ED3/ED7 engine, preserve the complete fault report and investigate additional conditions outside the bulletin. If the software correction applies, record the installed calibration and reassess the original pedal-related complaint. An active incompatibility fault that remains afterward still needs the proper current signal and circuit checks. The source publishes no allowable pedal-angle difference or instruction to bypass a brake input. Avoid ordering an accelerator assembly simply because it is named in the generic description; the documented evidence supports evaluating calibration as one qualified diagnostic branch.

## Source and applicability

FCA 18-086-16 covers several 2014 applications, but its P2299 entry is specifically in the Dodge Journey JC 2.4 L ED3/ED7 section.

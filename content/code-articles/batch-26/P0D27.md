# P0D27: Wrangler charging-input voltage and coordinated IDCM software

## The vehicle side has a documented software case

FCA lists P0D27-00, charger input voltage too low, with integrated dual-charging-module faults in this update. Reported behavior includes inability to charge on a Level 2 station and a circuit breaker tripping when the vehicle is connected. This establishes a vehicle-software possibility, but it does not prove that a building supply or charging station is electrically sound.

## A tripping breaker is not a reset experiment

Do not repeatedly reset a protective breaker to force charging. Preserve which station was used, the charging failure sequence and the vehicle’s complete fault report so the vehicle and supply can be assessed appropriately. The bulletin does not provide a household-wiring repair method or a universal acceptable charging-input voltage.

## The repair requires compatible controllers

The IDCM update is linked to PCM, TCM, battery-pack and hybrid-controller software. The document warns that missing companion updates can leave malfunctions, so a single successful flash is not sufficient evidence of completion. Qualified personnel should confirm vehicle applicability and the full software set, then reassess the charging complaint through the approved procedure. Other fault conditions still require diagnosis before this path is used. If charging continues to fail after the correct coordinated repair, return to current vehicle and charging-equipment diagnostics rather than replacing the charging module solely from P0D27.

## Source and applicability

FCA 08-047-23 concerns specified 2021 Wrangler JL PHEV vehicles with the 2.0 L ECX engine and listed market/RSU conditions.

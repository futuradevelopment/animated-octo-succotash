# P06E9: Compass starter performance and market-specific PCM logic

## A starter-performance code has a software case

FCA lists P06E9 in a PCM update for the specified Compass, alongside separate starter-control and plausibility faults. The source also describes a no-crank pattern after repeated start-button presses that resolves when the vehicle is fully switched off and restarted. That context should be preserved in the repair history rather than reducing the complaint to “needs a starter.”

## Do not transfer another market’s symptom

The same page discusses hot-weather extended cranking for a particular European engine configuration and an intermittent no-start concern for South Korea. Those qualifiers remain attached to those symptoms. They are not automatically evidence about a North American P06E9 vehicle. Likewise, the EVAP leak test described for P0456 is not a starter diagnostic.

## Check both required software levels

For automatic-transmission vehicles, the PCM update is followed by confirmation of the TCM software. Record the exact engine, market, starting sequence and initial code set before applying that path. Other faults still require diagnosis, and a persistent starter-performance fault after the applicable correction needs the current electrical and mechanical checks. The bulletin provides no cranking-current specification or universal command to replace the starter. A completed software transfer alone does not verify that the original no-crank condition has been resolved.

## Source and applicability

FCA 18-019-23 concerns 2019 Compass MP with listed 2.4 L ED6/EDD/EDE engines; its P06E9 entry is expressly North America only.

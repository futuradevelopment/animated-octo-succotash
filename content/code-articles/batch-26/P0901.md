# P0901: FCA clutch-actuator performance and the S55 harness repair

## The recall-linked repair is central

The bulletin ties P0901-00, clutch-one actuator control-circuit range/performance, to the S55 transmission-harness service action. It does not describe the code as proof that the clutch friction parts have worn out. The useful first check is whether the actual vehicle and VIN fall within the recall-related repair history.

## Hardware and both controllers belong together

FCA says the transmission harness repair and current PCM/TCM software are required for the intended changes to be effective. A record showing only a controller flash or only a harness replacement therefore does not confirm completion of the combined procedure. Obtain the actual recall completion and software information before repeating repairs.

## The application table is detailed

The document has different model-year, build-date, engine and transmission limits for its listed vehicles. Do not apply the Cherokee’s limits to a Fiat or Chrysler solely because all appear in the heading. Other faults still require their appropriate investigation. After the specified repair, assess the original shifting or drivability concern and the returning code set under current service guidance. The bulletin supplies no universal actuator resistance, clutch-position target or instruction to replace the complete transmission. If P0901 remains after a properly completed applicable repair, continued diagnosis is necessary rather than assuming the recall reference resolves every possible cause.

## Source and applicability

FCA 21-035-16 covers specifically listed Cherokee, Chrysler 200, Renegade, Fiat 500X and ProMaster City engine/transmission/build combinations. Confirm S55 VIN applicability.

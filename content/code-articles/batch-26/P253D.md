# P253D: Ram PTO-sense high and the AS69RC software case

## Keep the transmission-specific row

The bulletin describes P253D as a high power-take-off sense-circuit indication and explicitly includes a warning-lamp case where no defect is found. That entry belongs to the AS69RC transmission section. Although the document also covers AS66RC-equipped gasoline vehicles, the P253D observation should not be automatically extended to that separate section.

## A high signal is not a load measurement

The code concerns the PTO sensing circuit, not a direct statement that towing load or transmission temperature is excessive. The same software release addresses towing and shift-quality complaints, but those listed improvements are not proof that each symptom is caused by P253D. Preserve the actual fault status, transmission sales code and any observed PTO behavior when comparing the truck with the documented case.

## Software verification includes learning

For a matching vehicle, the repair updates the transmission controller and then requires a scan-tool Quick Learn. A software download without the specified learning step is not the full procedure. The bulletin also says unrelated faults should be recorded and repaired before proceeding. If a genuine circuit defect is found, this no-defect software example does not erase that finding. After the applicable repair, confirm the original warning and PTO-related complaint as well as transmission behavior. The source gives no universal sense-circuit voltage threshold or instruction to bypass the PTO input. It is a calibration case for defined trucks, not a general permission to replace a transmission.

## Source and applicability

FCA 21-013-15 covers specified 2013–2014 Ram 3500/4500/5500 configurations. Its P253D entry belongs to the 6.7 L ETK/AS69RC DF2 section.

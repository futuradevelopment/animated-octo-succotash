# U3017: Ram eTorque controller-clock faults in the expanded BPCM update

## A timer code can accompany a charging complaint

The July 2026 revision adds U3017-00, control-module timer/clock performance, to a battery-controller software case. It also adds cell-supervision and operating complaints to the earlier release. The clock-related label is therefore not a diagnosis of the dashboard clock or an instruction to change the vehicle’s time setting.

## Use the full battery-system picture

The documented symptoms can include disabled stop/start, limp-home behavior and poor 12-volt charging. These observations should be recorded separately with the complete fault set. A low 12-volt battery may be part of the complaint, but the source does not establish that replacing it alone corrects the controller-software issue.

## Earlier update history needs checking

Because this bulletin supersedes the 2025 release, a previous BPCM update does not automatically prove the vehicle has the revision that includes U3017. Check the actual installed software and current applicable release. The repair requires the proper 48-volt contactor preparation and supported programming procedure, followed by reassessment of the original operation and faults. The bulletin supplies no internal-clock frequency threshold and does not justify replacing the controller solely from U3017. Other active faults or persistent charging abnormalities still need the appropriate current diagnosis.

## Source and applicability

FCA 08-283-26 covers North American 2025 Ram 1500 DT with the 3.6 L ERG eTorque engine and supersedes 08-333-25.

# P032F: Ram insufficient-torque indications and 6.4 L PCM coordination

## Insufficient torque is an observation, not a failed-part name

The bulletin includes P032F in a PCM software release with bank-specific air/fuel imbalance codes. It also describes low-speed engine hunting and several PTO or idle-response concerns. Those items form a documented control-software case; P032F alone does not identify an injector, throttle body or internal engine defect.

## Separate the cab-chassis conditions

Some PTO activation and automatic-resume improvements are expressly limited to DD/DP cab-chassis trucks. They should not be presented as symptoms of every 2500 or 3500 pickup with P032F. Preserve whether the complaint occurred during PTO engagement, coasting or another operating condition, and verify the exact ESL application.

## The BCM is a companion requirement

The repair calls for the PCM update and confirmation of the body-controller software. That coordination should be visible in the service record. The revision also contains a more effective correction for a separate P219B concern; that note does not quantify P032F’s torque threshold. Address other system faults before applying the bulletin and reassess the original complaint afterward. If insufficient-torque indications persist, use the current engine and control-system diagnosis rather than repeatedly flashing the vehicle. The source provides no universal torque-loss percentage or automatic component-replacement rule.

## Source and applicability

FCA 18-038-26 revision A concerns specified 2025 Ram heavy-duty pickup/cab-chassis vehicles with the 6.4 L ESL engine.

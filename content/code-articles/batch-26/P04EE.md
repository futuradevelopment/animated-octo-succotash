# P04EE: Wrangler tank-side leak from a trapped cap tether

## A small leak can come from the tether

The documented P04EE case is a very-small EVAP leak on the fuel-tank side. FCA identifies a cap tether trapped between the cap seal and filler neck as the cause. A check-gas-cap message may accompany the warning. Inspecting whether the tether crosses the sealing surface is therefore more informative than immediately condemning the purge valve or canister.

## The revised repair changes the mounting arrangement

The bulletin replaces the relevant cap/tether arrangement and fuel-door mounting base so the tether does not become caught again. Simply tightening the cap while leaving the same interference path does not address that mechanism. Verification should include correct tether routing and the original leak-related complaint, using the applicable EVAP test procedure where required.

## One applicability detail needs clarification

The document states a March 2023 build cutoff but prints an MDH code that does not match that date. This article does not silently choose one. Have the dealer confirm the current VIN applicability before ordering campaign-specific parts. The physical tether explanation remains useful, but it is not proof that every P04EE is a cap problem. If the tether is correctly routed and the seal is sound, follow normal tank-side leak diagnosis. The source provides no universal leak-test pressure and does not authorize applying shop air to a fuel tank.

## Source and applicability

FCA 14-004-23 concerns specified 2021–2023 Wrangler JL PHEV ECX vehicles. The written build date and MDH code conflict; confirm applicability through current VIN guidance.

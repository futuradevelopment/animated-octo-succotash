# P0887: Nine-speed TCM power-control faults and required configuration

## A high-circuit code has a documented calibration case

The bulletin includes P0887-00, TCM power-control circuit high, among faults addressed by transmission-controller software. That is a reason to check the applicable calibration, not proof that the electrical power circuit is healthy or that the TCM must be replaced.

## Configuration and learning are part of the update

The repair includes TCM VIN verification and proxi configuration alignment, followed by another alignment check after a module shutdown. It also clears transmission adaptive values, making the specified Quick Learn necessary. The PCM must have the appropriate software for that learning procedure to function. These details explain why a flash-only repair can leave an incomplete service sequence.

## Use the exact vehicle row

The source has different engine and build limits for Cherokee and Chrysler 200 variants. Verify those identifiers and the actual nine-speed transmission before choosing this path. If the relevant TCM software is already present, the document has an inspection branch rather than instructing repeated reflashes. Preserve the initial code status and any shifting complaint, then confirm configuration, learning completion and fault behavior after the proper repair. The bulletin provides no generic relay voltage or universal circuit test. A returning active P0887 still requires current electrical diagnosis instead of assuming that the historical software case explains every occurrence.

## Source and applicability

FCA 21-021-15 revision D concerns specified 2015 Cherokee KL and Chrysler 200 UF nine-speed engine/transmission/build combinations.

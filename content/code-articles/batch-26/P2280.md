# P2280: Ram air-cleaner-to-MAF fault and a two-trip monitor update

## Locate the fault in the correct intake segment

P2280 is identified as an airflow restriction or leak between the air cleaner and mass-airflow sensor. That location matters: it differs from a fault describing the tract downstream of the airflow meter. In this bulletin, the specific P2280 enhancement changes its detection from a one-trip fault to a two-trip fault. The update changes how the monitor confirms the condition; it does not physically remove a restriction or seal a damaged intake connection.

## Use calibration history alongside physical diagnosis

Save the stored and pending fault report and describe when the warning returned after a clear. Ask the technician to check the installed calibration against this vehicle-specific release while investigating the intake complaint. A delayed warning after programming is not proof that an actual restriction disappeared. Likewise, the long list of unrelated emission and transmission improvements in the package does not mean every listed component is defective on a truck showing only P2280.

## The transmission changes the completion procedure

The update requires more than downloading software. For a 68RFE-equipped truck, the bulletin calls for a ten-minute ignition-off interval and transmission Quicklearn. Other covered transmissions use a different, shorter ignition-off interval. The procedure also clears programming-generated codes and runs PCM configuration. Ask the workshop to document those completion steps and verify the original intake concern afterward. A returning confirmed P2280 needs the applicable airflow-restriction and leak diagnostics; repeated clearing would only hide the evidence needed to find it.

## Source and applicability

FCA bulletin 18-130-22 Rev. A, July 2022: North American 2016 Ram 2500 DJ and 3500 pickup D2 with 6.7 L ETK Cummins diesel. This calibration case is separate from other model years or chassis-cab applications.

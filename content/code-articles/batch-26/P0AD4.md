# P0AD4: Wagoneer battery-airflow indication and BPCM software

## The label does not establish a blocked duct

FCA lists P0AD4 as insufficient battery-pack airflow in a BPCM software case. Reported effects include poor battery performance or charging and a possible no-start. This establishes a control-software possibility for the specified eTorque application, not proof that the battery’s air path is physically clear or obstructed.

## Distinguish indication from measured cause

A workshop should retain the actual code status, charging complaint and any physical findings before applying the bulletin. The document requires related systems to be checked and additional faults addressed. It does not provide an airflow measurement, fan-current threshold or a direction to replace the battery pack from P0AD4 alone.

## The update has a defined preparation

The repair uses an ignition-off interval that allows the 48-volt contactor to open before programming the battery controller. That is part of a professional service sequence, not an owner reset test. Confirm the EZL engine and exact vehicle application, record the final BPCM software and reassess the original fault and charging behavior after the proper repair. If the complaint remains, current battery-cooling and electrical diagnosis is still necessary. The historical update should not be transferred to other hybrid architectures simply because they use the same base code.

## Source and applicability

FCA 08-418-25 concerns 2023 Wagoneer/Grand Wagoneer WS with the 5.7 L EZL eTorque engine in the listed markets.

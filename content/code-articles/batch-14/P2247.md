# P2247: The bank 2 upstream sensor reference-line continuity diagnosis

P2247 is the generic reference-voltage circuit/open code for bank 2 sensor 1. GM's wideband-sensor implementation identifies an open-load diagnosis at the RE line and uses several checks inside the sensor interface electronics.

## Different interface modes provide different evidence

One path examines stored continuity-test information around an aborted interface RAM check in warmup mode. Another normal-mode path uses the Nernst-cell current condition. A further path observes electrically corrected Nernst voltage while pump-current operation is active.

These are not interchangeable with a simple disconnected-sensor resistance reading. The applicable interface mode determines which observation is available and what a missing or abnormal result means.

## A ready sensor is part of the test conditions

The source includes a heated-sensor qualification, expressed as ceramic temperature above 790 °C or completion of the heating-up phase, along with power and inhibition conditions. The temperature is an internal readiness criterion, not a temperature a technician should try to reproduce by externally heating the sensor.

Useful diagnostic information includes interface mode, continuity-result availability, reference-line status and sensor readiness. An unsuccessful check while the interface is idle or unready is not necessarily the same event as the documented open-load diagnosis.

The summary describes internal signal-line behavior but supplies no universal connector mapping. It does not isolate wiring, the sensor element or interface electronics as the failed part. Use the exact vehicle procedure to distinguish those causes before selecting a repair.

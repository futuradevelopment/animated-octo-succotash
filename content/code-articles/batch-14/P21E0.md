# P21E0: How the cylinder 3 injector B low-circuit category differs from open load

P21E0 identifies cylinder 3 injector B circuit low in the generic catalog. The cited GM injector-3 row calls this the short-to-ground electrical category. Its monitored value is above 5 V while the power stage is not active.

## The source value is not an external pin instruction

The internal output-voltage observation must be read with the stage state and diagnostic category. The summary does not specify a connector measurement point or explain the full driver topology, so it would be incorrect to convert that value into a universal external short-circuit test.

The same channel has a separate open-load check using a bounded inactive-stage voltage window and a high-circuit check using active-stage current. P21E0 is therefore a distinct classification rather than a generic indication that any injector test failed.

## Conditions determine whether a retest is meaningful

The row lists three events, engine speed of at least 80 rpm and battery supply between the specified 10.9–25.5 V boundaries. Additional inhibition rules are referenced. An observation taken with no eligible events cannot demonstrate a pass.

Confirm the engine's injector B configuration before locating the circuit fault. Matching the document's channel number to the generic cylinder number does not provide a physical connector location. The code concerns electrical behavior and does not establish fuel delivery, nozzle condition or which component should be replaced without further circuit evidence.

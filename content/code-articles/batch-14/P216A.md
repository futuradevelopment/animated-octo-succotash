# P216A: Injector group E supply evidence and the importance of the high-side path

P216A names the injector group E supply circuit in the generic catalog. The GM table used here describes cylinder 5 injector “E” and evaluates short-circuit behavior on the high-side driver path. That specific documentary identity should be checked against the vehicle's calibration before physical testing.

## One code contains two electrical possibilities

The monitor can fail because the output is low while the driver is off, or because it remains high while the driver is on. The table interprets these as short-to-ground and short-to-supply patterns respectively. It lists two events for maturation and points to separate eligibility information.

A recorded code without the driver state cannot separate those alternatives. The generic “circuit/open” wording is also insufficient evidence that the actual monitor found an open connection.

## What a meaningful circuit investigation preserves

Keep the fault's electrical direction, the command state and any related driver information together. An observed fueling problem cannot substitute for those measurements, because this monitor does not assess fuel quantity or spray behavior.

The source narrows the question to the high-side path but does not isolate the ECU, injector or harness as the failed part. It also does not establish a universal shared-feed arrangement from the group letter. Mapping the actual circuit is necessary before deciding whether a single-channel issue or a wider supply connection explains the event. A later absence of the code is meaningful only if the monitor was eligible to run again.

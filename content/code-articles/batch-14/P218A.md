# P218A: Why bank 2 throttle stop learning can fail at several different stages

P218A is the generic throttle actuator B idle-position-not-learned code. The GM bank 2 source describes lower mechanical-stop learning and separates several stages that can prevent a trustworthy learned offset from being established.

## Reaching the stop is only the first stage

Initial learning first moves the throttle toward its closed position. A later stage presses it toward the lower stop with a defined drive effort, followed by a range check of the learned sensor voltages. A failure to reach position is therefore different from reaching it but failing the effort or sensor-offset checks.

The document supplies separate allowable voltage windows for the two position sensors at the lower stop. Those windows belong to this calibration and are not a universal throttle-cleaning or adjustment specification.

## Lost eligibility is not the same as a mechanical failure

The first-learning path also recognizes a procedure aborted because an enabling condition no longer holds. The subsequent learning rows reference spring-check, power, safety and adaptation states. A failed learning status alone cannot determine whether the plate physically stuck or whether the procedure stopped for another reason.

Preserve the failed learning step, sensor values, spring-check status and reason for any abort. This evidence is more useful than repeating a reset without knowing why learning ended. The source does not authorize manually forcing the throttle against its stop or selecting a replacement body from the code alone. Use the exact vehicle's learning and diagnostic procedure to distinguish a valid failed test from an incomplete one.

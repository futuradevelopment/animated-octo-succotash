# P2100: Why a throttle motor circuit-open code can include driver overheating

P2100 is the generic throttle actuator A motor circuit/open code. In the GM bank 1 throttle table, the code includes more than an open-circuit check: a separate path reports an overtemperature error from the power-stage integrated circuit.

## Two supported paths require different evidence

The open-circuit path evaluates the H-bridge driver's off-state electrical response. The overtemperature path instead uses an error status reported by the power stage. A generic code readout cannot tell which of those observations produced the result.

Both paths are qualified by controller state, actual-position validity and safety-related conditions. Thus, an invalid position signal or an inhibited operating state affects how a later retest should be interpreted. A simple continuity result would not reproduce an internal overtemperature status.

## A source description that needs clarification

A third path in the same throttle section refers to a turbine-bypass valve while its enable conditions still name the bank 1 throttle stage. That wording is retained as unresolved; this article does not silently turn it into a physical turbocharger or throttle repair instruction.

The useful next evidence is the available subtest or power-stage status, together with the exact controller calibration. The code alone does not isolate a broken motor winding or justify replacing the throttle body. Resolve which documented path applies before selecting the electrical or thermal investigation, and use the vehicle's service procedure for any actuator testing.

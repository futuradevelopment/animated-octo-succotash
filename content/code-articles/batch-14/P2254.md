# P2254: The bank 2 negative-current circuit check changes with sensor operating state

P2254 is the negative-current control circuit/open code for bank 2 sensor 1. In GM's documented wideband interface, the target is the IPE line. The monitor uses internal pump-cell continuity behavior rather than a universal voltage reading at an external connector.

## Normal operation and warmup use different checks

The normal-mode path evaluates continuity during a negative pump-current pulse and considers whether relevant test information is available in interface memory. The warmup path instead compares voltage-drop responses when internal reference current is routed through different sensor-line configurations.

Those distinctions matter when a diagnostic record reports an aborted or unavailable internal result. A lack of one test result is not automatically evidence that every possible continuity path passed or failed.

## Thermal-control quality affects the comparison

The source changes part of its voltage-deviation criteria according to heater-control accuracy. When control is accurate, the threshold includes a starting value and a term based on counted negative overshoots. It is therefore not one fixed external meter threshold for all sensor conditions.

Useful evidence includes sensor mode, heating readiness, heater-control status and the interface's continuity diagnostics. The documented heated-sensor condition is an internal eligibility requirement, not an instruction to heat the component manually.

The code does not isolate a disconnected wire, sensor defect or interface fault by itself. Use the vehicle-specific circuit and diagnostic procedure to distinguish them; applying a guessed universal resistance or voltage test would discard the operating-state logic that makes this monitor meaningful.

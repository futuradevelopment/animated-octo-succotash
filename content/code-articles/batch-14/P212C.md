# P212C: The low-voltage limit for the second bank 2 throttle-position channel

The generic P212C title refers to throttle-position sensor circuit G. In this GM table, the monitored input is throttle-position sensor 2 on bank 2. The article describes that specific mapping rather than assuming every manufacturer uses the same physical sensor arrangement.

## The check concerns the raw electrical input

The listed fault criterion is a raw signal below 0.195 V for a 0.14-second period. It is a signal-range check, so it does not by itself demonstrate that the throttle plate is physically closed, jammed or incorrectly learned.

The controller may run the check in drive or postdrive state, subject to safety fuel-cut and limp-home-related conditions. The continuation on the next page is part of the row; ignoring it would omit important eligibility information.

## Distinguish range failure from disagreement

A low electrical signal is different from two individually in-range sensors reporting incompatible angles. P212C addresses the former. Comparing sensor 2's voltage with its interpreted angle and the other relevant throttle information can establish what was actually invalid, without assuming that every throttle-related code has the same cause.

The proper follow-up uses the vehicle's sensor mapping and circuit procedure. The summary does not establish a connector pin or a safe manual throttle actuation test. Preserve the controller state and safety-related inhibitions with the signal value, because absence of a new failure during an ineligible interval is not evidence that the input passed.

# P2196: Why a rich-biased bank 1 sensor code can depend on a negative lambda offset

P2196 identifies bank 1 sensor 1 biased or stuck rich in the generic catalog. In this GM source, the upstream sensor's learned lambda offset is compared with a lower limit. This wideband control diagnosis should not be reduced to a generic narrowband-voltage rule.

## A negative offset is the specified control result

The main threshold is an offset below −0.07. Confirmation depends on the offset-adaptation debounce condition, including a slow-adaptation branch and qualified upstream lambda control. The short listed evaluation period applies after those conditions, not immediately after every engine start.

The continuation excludes active fuel cutoff in the illustrated logic and qualifies when control has resumed afterward. Sensor readiness and completed warmup also matter. An observation made while control is intentionally inactive cannot establish that the diagnostic passed.

## Keep the inferred fault separate from the component cause

A lambda offset is not the same as oxygen-sensor voltage or a displayed fuel-trim percentage. Recording the wrong parameter can make a valid diagnostic look contradictory.

Useful evidence includes the bank 1 offset, sensor operating status and adaptation eligibility. The monitor establishes a plausibility problem in that control quantity; it does not prove the sensor itself is defective or identify a particular fuel component. The applicable diagnostic procedure must distinguish mixture, sensing and control causes. After any repair, an eligible completed monitor provides stronger evidence than resetting adaptations and observing a temporarily normal value.

# P211D: The bank 2 throttle spring check examines several return behaviors

P211D is described generically as throttle actuator B control throttle-body range/performance. The GM source assigns it several bank 2 spring-related checks during throttle learning and verification. The monitored behavior is more specific than a normal requested-versus-actual tracking comparison.

## Movement under mechanical force is part of the evidence

One path checks whether the opening spring can return the throttle to the defined limp-home position by mechanical force within the allowed time. The criteria depend on whether a credible learned position exists or the system is performing initial learning.

Other paths evaluate spring-spreading behavior and return-spring response. Their limits include learned offsets and calculated positions, so a universal fixed plate-angle test would not reproduce all of the documented branches.

## Identify the failed stage before naming the cause

The source references offset-learning state, spring-check status, power and safety qualifications across these paths. A learning procedure that was aborted because conditions were lost is not necessarily evidence of the same mechanical behavior as a completed return test that failed.

Useful diagnostic information includes which spring path failed, whether first learning had completed and whether the relevant learned position was plausible. The code alone does not establish that a spring, motor or complete throttle body is the failed part. Any commanded actuator or spring testing must follow the applicable workshop procedure; the presence of a “limp-home” term in the diagnostic does not independently establish that driving is safe.

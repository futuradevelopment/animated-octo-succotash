# P2272: A lean-biased rear-sensor code with an unresolved bank label in the source

P2272 is generically bank 2 sensor 2 biased or stuck lean. The cited GM row carries P2272 but repeatedly names bank 1 in its strategy and conditions. Visual inspection confirms that wording in the original PDF. This article does not silently convert those references into a physical bank 2 test procedure.

## The row describes an intrusive response check

The stated strategy commands a rich mixture and evaluates whether the secondary oxygen-sensor maximum voltage rises sufficiently. The printed failure boundary is below 0.8 V during that rich shift. That is a documented response criterion, not a universal steady-idle voltage limit.

The continuation qualifies the check with exhaust-flow stability, accumulated gas mass, sensor readiness and modeled catalyst-temperature conditions. A rear sensor observed before the commanded mixture has reached it cannot be judged as though that response test were complete.

## What can be concluded despite the bank ambiguity

The useful principle is to distinguish failure to respond to a verified rich command from a merely low voltage seen without controlled conditions. The code alone does not identify an electrically failed sensor or prove a particular mixture cause.

The exact vehicle and calibration information must resolve the bank-specific application before the printed thresholds are used for diagnosis. Preserve command, upstream confirmation, rear response and monitor eligibility. The source limitation prevents a confident component-location instruction or replacement decision from this table alone, while the documented response logic remains useful for understanding the type of evidence required.

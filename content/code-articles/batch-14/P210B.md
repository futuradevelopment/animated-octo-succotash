# P210B: Throttle tracking error with a tolerance that changes as the command moves

P210B is the range/performance code for throttle actuator B. In the GM bank 2 implementation, it evaluates how closely actual throttle position follows the commanded value. This is a position-tracking check, distinct from a direct open-circuit or driver-overtemperature report.

## The allowable error is not one fixed percentage

The source evaluates position error in either direction. Its allowance combines a 5-percent steady-state deviation with a term based on the rate of change of the command and a listed factor of 0.02.

That rate term matters during a fast request change. Comparing actual and requested positions against only the steady-state allowance would omit part of the monitor's design. Conversely, a large static mismatch cannot be excused merely because the throttle sometimes moves dynamically.

## Valid feedback is a prerequisite for interpretation

The continuation requires actual position to be valid and includes controller, power-stage, adaptation and safety-related qualifications. An invalid position signal or a deliberately inhibited actuator must not be interpreted as a straightforward tracking failure without considering those states.

Useful data capture places commanded position, actual position and command rate on the same time axis. A single pair of numbers can miss whether the deviation was persistent or part of a changing request. The monitor does not uniquely identify a sticking plate, motor, wiring or feedback cause. The correct vehicle diagnostic procedure is needed to distinguish those possibilities before a component is selected.

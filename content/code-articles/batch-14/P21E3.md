# P21E3: High injector current with cylinder 4 and channel 2 names kept separate

The generic P21E3 designation is cylinder 4 injector B circuit high. GM's corresponding row is labeled injector 2. That difference is an unresolved channel-to-cylinder mapping, not enough evidence to decide that one source's numbering is wrong.

## The supported active-current check

The row describes a short-to-supply electrical fault using output current above 3.8 A while the power stage is active. It lists three events for maturation, a minimum engine speed of 80 rpm and a supply-voltage window. The continuation on the next page adds the referenced inhibition information.

The stage state distinguishes this monitor from the associated open-load and low-circuit checks, which use inactive-stage voltage. An off-state current observation cannot reproduce the P21E3 criterion.

## Establish identity before drawing a component conclusion

A full code readout, controller identification and calibration information are needed to choose the correct vehicle wiring diagram. Acting on either cylinder 4 or channel 2 as an assumed physical location risks investigating the wrong injector circuit.

Once identity is resolved, preserve the active-stage current and diagnostic category. The code does not measure fuel spray or establish that the injector's mechanical portion is defective. It also cannot separate a wiring fault, electrical load problem and internal driver cause by itself. The documented threshold is a monitor parameter, not a safe external energization instruction or an automatic replacement decision.

# P1323: No 24X reference pulses despite camshaft activity

GM's 1998 4.0L L47 Aurora table defines P1323 as absence of the 24X crank reference signal. The imported “low frequency” title is broader than the actual published test, which specifies zero 24X pulses while other information establishes that the engine is turning.

## The camshaft reference enables the conclusion
The monitor requires engine speed above 496 rpm, cam pulses currently arriving and more than seven cam edges since key-on. These prerequisites distinguish a missing 24X stream from an engine that has not yet provided enough rotation information. The table lists one failure in ten tests and a four-second continuous test frequency.

That context matters when interpreting a no-start or an engine-off capture. A stationary signal cannot be declared faulty using a test that requires current camshaft activity and a minimum speed. Conversely, a credible rpm display does not prove that every individual reference stream is present.

## Follow the missing information path
Capture or otherwise verify the correct 24X reference path using the vehicle-specific service method, while confirming the cam activity that enables the diagnostic. The important question is whether the 24X information reaches the controller, not simply whether some crank-related waveform exists elsewhere.

The table does not identify a connector, establish a component failure or specify a replacement sensor. Verification should show the missing pulse stream restored during the qualifying rotation state and the diagnostic no longer failing. Apply this zero-pulse interpretation only after confirming that the vehicle uses the documented historical signal architecture.

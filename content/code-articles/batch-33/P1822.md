# P1822: Internal-mode-switch B remains high when low is expected

P1822 monitors the internal transmission mode-switch B circuit in GM's 2000 4.0L L47 and 4.6L LD8/L37 table. The controller finds the circuit high, described as 12 volts, when the expected state is low. The diagnostic uses a sequence of decoded selector states rather than one arbitrary voltage snapshot.

## The state history supplies the evidence
GM describes mode B remaining high in park for more than two seconds and later appearing in the decoded state called Transitional_13. The table notes that a high B input changes the decoded D4 pattern into that transitional state. A failure count greater than one establishes the DTC.

The monitor requires valid engine-torque information, system voltage between eight and 18 volts and qualifying engine running conditions. It also specifies a torque window. These gates explain why a selector display alone, without the associated electrical and operating context, is incomplete evidence.

## A circuit state can distort the decoded range
Compare the B input with the full internal-mode-switch pattern and the actual selector sequence. A transitional label may be the consequence of one stuck bit rather than proof that the driver physically selected an intermediate position. This distinction helps prevent a range-decoding symptom from being mistaken for a mechanical selector diagnosis.

Verification should show that B changes to the expected state through the applicable sequence and that the decoded range remains coherent. The source does not identify a connector pin or prove the switch itself is defective. Use the service data for the exact historical calibration before component-level testing.

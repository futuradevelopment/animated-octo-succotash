# P1276: Pedal sensor 1 disagreement with two reference channels

P1276 is the APP1 performance diagnostic for the three-channel accelerator-pedal system documented in GM's 2002 engine table. The controller checks whether channel 1 agrees with both channel 2 and channel 3. It also recognizes invalid correlation at the pedal's minimum mechanical position.

## Agreement requires scaling
The signals are not expected to have identical raw voltages. The APP1-to-APP2 comparison uses a complementary relationship around five volts, with a 0.20-volt error boundary. The APP3 comparison includes an offset and scale conversion before applying a 0.26-volt boundary. Comparing three scan values as if they should simply match would misread the design.

The failure logic combines disagreement with both reference channels. This is more specific than finding one low or high APP1 reading, which is covered by a separate circuit diagnostic. The monitor operates every three milliseconds, using a counter that rises with errors and falls with passes; its stated threshold is 167.

## A useful correlation record
Capture the three channels together across released pedal and controlled movement using the applicable service procedure. Determine whether APP1 departs from both expected relationships, whether one reference channel is the unusual signal, or whether the problem is confined to the minimum-stop check. These observations guide interpretation without declaring a pedal assembly defective from the code alone.

GM requires valid throttle-module communication, adequate ignition voltage and no throttle-module processor fault. Verification needs those prerequisites plus restored correlation. The table establishes this monitor's mathematics, not universal voltage relationships for every GM pedal system.

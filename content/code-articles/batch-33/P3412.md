# P3412: Cylinder-2 valve-control output stays high during activation

GM's 2020 OBDG07 P3412 row diagnoses the cylinder-2 gas-exchange/deactivation valve control circuit for a high fault. It observes high voltage while the driver is on and interprets that condition as a short toward power. The code identifies an electrical control failure, not a measured loss of cylinder compression.

## Activation is the relevant state
The documented check switches the valve control on and off at the beginning of the driving cycle. It requires ECU drive state, battery voltage between the stated 10.9- and 25.5-volt boundaries and the listed early-cycle speed window. The electrical condition must last 0.5 second; the row has a two-trip classification.

A circuit can normally be high when the low-side driver is off. P3412 concerns the inappropriate high result during activation, so an isolated voltage reading without the command cannot establish the failure. This is different from the neighboring circuit-low monitor, which examines the off state.

## Compare command delivery before mechanical response
Identify cylinder 2's actual control path and determine whether it follows the on command. A valve-performance concern with correct electrical switching is a separate diagnostic question. The code itself does not locate the supply-side connection in the load, wiring or controller.

Verification should demonstrate correct active-state behavior and successful monitor completion after the cause is addressed. The published threshold cell does not supply a complete numeric short-to-power resistance specification, so one is not invented here. These criteria are document-scoped and require the matching calibration service information before use on another engine.

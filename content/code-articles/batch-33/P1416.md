# P1416: Bank-2 secondary-air response and a catalog-label correction

The original GM 2002 diagnostic table identifies P1416 as the **bank-2** secondary-air performance code. The imported catalog entry says bank 1, so that label must not determine which bank is investigated. This article follows the OEM row and keeps that disagreement explicit.

## What fails in the OEM test
With the AIR pump operating during closed-loop control and an additional eight-percent fuel offset, bank 2 fails both the lean-response and fuel-integrator checks while bank 1 passes. The lean criterion uses an oxygen-sensor value below 222 millivolts for at least 1.3 seconds; the fuel-integrator comparison uses a 20-percent change.

The controller evaluates the response for four seconds, with up to three attempts. Numerous prerequisites constrain the result, including valid engine sensor information, suitable temperature and load, adequate voltage and no relevant fueling or misfire faults. A cold stationary pump check is not equivalent to this documented running monitor.

## Use the opposite bank as evidence
The passing bank-1 response is part of the failure logic. It makes a bank-specific discrepancy meaningful, but still does not establish which air-delivery component caused it. Oxygen-sensor response, fuel correction and the commanded AIR event should be considered together before selecting a repair branch.

Confirm the exact calibration's bank identification and service procedure, then verify restored bank-2 response during an enabled test. The source says this code is not required for the 5.3L LM7 truck application in the group; that wording does not establish that it is never used. The catalog bank-label discrepancy remains a review item; it has not been silently generalized to every GM model.

# P1887: TCC release switch says released while engagement evidence agrees

P1887 compares the torque-converter-clutch release switch with the commanded clutch state and measured slip in GM's 2000 3.5L LX5 table. The failure occurs when the switch remains open, indicating released, while other evidence says the clutch is locked.

## Command alone is not the full comparison
GM requires the TCC commanded on and slip between minus 20 and 60 rpm. The transmission must be in D4, relevant TCC, input-speed and pressure-switch diagnostics must be absent, and the stated engine-torque and TCC-pressure windows must be satisfied. The release indication must persist for eight seconds, and the failure counter reaches at least two.

These conditions distinguish a contradictory switch report from a converter that was simply told to engage but did not actually do so. The relatively small slip window is part of the independent engagement evidence. A released-switch display without that context is incomplete.

## Reconcile switch and engagement information
Track the release-switch state, TCC command and slip together. Determine whether the switch disagrees consistently while engagement evidence remains credible, or whether another input prevents the comparison from being trusted. P1887 does not independently identify a bad switch or prove converter mechanical failure.

Verification should show that the release indication agrees with the clutch's supported state during the exact service check. The table supplies no universal pressure-test procedure or connector pinout. Its LX5 application scope and eight-second counter logic should remain attached to the interpretation before using the code on another GM transmission.

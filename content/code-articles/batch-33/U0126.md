# U0126: Steering-angle module message is missing at the receiver

U0126 indicates lost communication with the steering-angle sensor module in GM's 2020 OBDG07 K2P object-controller table. The external object calculating module supervises message $1E5 and identifies its absence for more than half a second. This is a missing-information fault, not a direct finding that the steering-angle value is numerically wrong.

## Power state and diagnostic enablement matter
The row requires system power mode RUN, battery voltage above nine volts, manufacturing enable counter zero and the chassis-communication diagnostic enabled. A timeout observed outside that qualified state is not automatically equivalent to the OEM monitor result.

The distinction from calibration or validity problems is useful. A steering-angle module can transmit a value that needs another diagnostic assessment, or it can fail to deliver the required message at all. U0126 in this implementation addresses the latter condition. A plausible angle displayed by another controller does not prove that this receiver is getting $1E5.

## Trace the missing message professionally
Identify the module that stored the DTC and establish whether the sender is available and its message reaches the affected receiver. Use the actual network and power-distribution information rather than assuming a failed steering sensor from the code title alone.

GM lists disabling adaptive cruise control and/or Super Cruise as the supported default response. Verification should show restored message reception through the enabled interval after correction. Steering-system calibration and physical work must follow the correct service procedure; clearing a communication code or performing an unrelated angle relearn does not independently prove that the message path is restored.

# P1779: Transmission torque-request signal reaches its fault region

P1779 is an engine-torque signal diagnostic in GM's 2002 C/K truck table for the 8.1L L18 and 6.6L LB7 engine group. The row evaluates a PWM torque-related signal received by the transmission control system. It is an information-path check, not a direct measurement that the engine produced too little torque.

## The selected signal option matters
The listed failure criterion is a 98.5-percent PWM condition for two seconds. Components must be powered, ignition voltage must be between nine and 18 volts, and engine speed must remain between 200 and 7,500 rpm for five seconds. The PWM driver-demand torque option must also be selected. Evaluation occurs every 100 milliseconds.

Those prerequisites make the signal configuration part of the diagnosis. A vehicle using another torque-information method cannot be assigned this PWM threshold merely because a scan tool displays the same code number. The table's title says delivered engine torque, while its strategy refers to driver-demand torque, so the exact service signal definition should be confirmed.

## Distinguish electrical encoding from torque output
Record the selected communication method and the PWM evidence before drawing conclusions about engine mechanical performance. A percentage at the diagnostic boundary describes the encoded signal, not a percentage of available engine power.

Verification should show valid torque-related information under the supported configuration and a completed monitor without the two-second failure condition. The source does not identify a failed transmission, engine or control module by itself, and this summary does not supply circuit pinouts or a substitute programming procedure.

# P3403: Cylinder-1 deactivation control short toward ground

P3403 is the low-circuit branch for cylinder-1 deactivation control in GM's 2015 OBDG08A document. The controller identifies a short toward ground in the solenoid's low-side output path. It is distinct from P3401's open-circuit branch, although both involve the same cylinder-specific control system.

## Driver state gives a low signal meaning
The row evaluates a low feedback condition while the driver is off. A low state while a low-side driver is actively pulling a circuit down can be expected; the off-state context is what makes this monitor's observation significant. GM's threshold description uses an impedance of no more than 0.5 ohm toward controller ground.

The test needs relay voltage of at least 11 volts, speed of at least 400 rpm and diagnostic enablement. It requires at least 20 failed samples out of 25, with a quarter-second interval. A brief unqualified measurement does not reproduce that repeated decision.

## Keep the cylinder and fault direction separate
Identify cylinder 1's circuit using the actual engine service information, then distinguish an unwanted ground connection from an interrupted path. The code does not prove which connector, wire, load or driver created the condition. It also does not directly test mechanical deactivation performance.

Verification should show the correct circuit state when the driver is off and successful diagnostic completion after the cause is addressed. Apply the published threshold only as a source-scoped monitor definition, not a powered-circuit resistance-testing recipe or universal specification for every manufacturer using this generic code.

# P1404: EGR pintle remains above its learned closed position

The cited GM 2002 diagnostic table defines P1404 as an EGR valve that fails to reach its learned closed position when commanded closed. This is more specific than the imported catalog wording “EGR System Valve 2”: the OEM row evaluates pintle feedback relative to a learned baseline.

## A repeated closure test
The listed error is more than ten analog-to-digital counts above the learned closed position for ten seconds in each of three subroutines. Between checks, the controller commands a full EGR stroke; the table specifies a 0.7-second movement between tests. This sequence attempts another closure evaluation after moving the valve.

The test requires at least 11.7 volts. Conditions for the intervening stroke include coolant between 80°C and 118°C, intake-air temperature below 100°C and desired EGR above 20 percent. An observation taken during a different command or thermal state therefore needs context before being compared with the failure criteria.

## Position evidence changes the next question
Distinguish a genuinely unclosed pintle from feedback that reports an incorrect closed position. Also distinguish an absolute scan percentage from the deviation relative to the learned baseline: the monitor does not simply demand an arbitrary displayed zero.

Verification should establish that commanded closure and position feedback agree after the applicable stroke sequence, with adequate supply voltage. The source does not identify the mechanical or electrical cause by itself. It marks this monitor as unused on the 5.3L LM7 truck application in the group, so the table's broad engine heading cannot be treated as universal EGR applicability.

# P1286: Pedal sensor 3 correlation performance

GM's 2002 electronic-throttle table assigns P1286 to a disagreement between accelerator-pedal channel 3 and the other two pedal channels. The monitor considers channel 3 against both APP1 and APP2, including correlation at the minimum mechanical position. It is a consistency check across a redundant pedal system.

## Why raw voltage comparison is insufficient
Channel 3 is offset and scaled before comparison. The table transforms its signal using a 0.61-volt offset and a 53/32 scale factor, then compares the result with the appropriate APP1 and complementary APP2 quantities. Each stated disagreement boundary is 0.26 volt. Different raw channel voltages are therefore not automatically evidence of a fault.

Both relationships matter to the failure decision. A single questionable pair of readings should not be interpreted as proof that channel 3 is responsible. The monitor checks every three milliseconds with an accumulating error counter and a threshold of 167; passing observations reduce the counter.

## Distinguish channel behavior from communication
The controller needs valid throttle-module/PCM serial data, ignition in run or crank, voltage above 5.23 volts and no throttle-module processor DTC. If those prerequisites fail, a correlation interpretation becomes incomplete.

A useful verification record shows all three pedal channels together, including the released position, and demonstrates that the correctly scaled relationships remain valid. This source does not provide a connector pinout or authorize adjusting a pedal stop. Apply the stated conversion only to the documented historical three-channel ETC calibration, not to later systems with different sensor architecture.

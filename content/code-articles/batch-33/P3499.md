# P3499: Cylinder-2 deactivation permits unwanted air pumping

P3499 is a cylinder-2 deactivation performance diagnostic in GM's 2020 OBDG07 table. The source describes detecting a “pumping air” error during half-engine operation. Unlike an open, low or high control-circuit code, this monitor evaluates whether the intended deactivation behavior is achieved.

## Performance requires trustworthy air-charge evidence
The controller needs synchronization between half-engine mode and air-charge determination, an enabled valve-lift diagnostic and valid pressure/airflow information. The listed operating window includes engine speed between 800 and 2,900 rpm. The error accumulation uses lookup-dependent counts rather than one universal elapsed-time threshold.

The continuation also requires the mode-switching transient to have settled and constrains throttle movement over a calibrated interval. This prevents an ordinary rapid operating change from being treated as equivalent to the settled performance comparison.

## Separate electrical command from achieved behavior
A valid solenoid command does not by itself prove that cylinder 2 stops pumping air as intended. Conversely, a performance result cannot be interpreted confidently if its pressure and airflow inputs are invalid. Establish both the control state and the evidence used to infer the resulting air-charge behavior.

Verification should show the intended cylinder-2 response through the exact calibration's enabled service evaluation after the cause is established. The code does not independently identify a solenoid, valve-lift mechanism or sensor as defective. The source contains a contradictory bank-2 pressure-ratio inequality elsewhere in its enable logic; that disputed value is not used here, and the complete test must be confirmed in application service data.

# P1823: Internal-mode-switch P remains low when high is expected

GM's 2000 Car V8 group 1 table defines P1823 as an internal-mode-switch P circuit that reads low when it should read high. The row describes a zero-volt state and uses selector-state history to establish that the low indication is inappropriate.

## Park history and a later transitional code
The stated condition is mode P remaining low in park for more than two seconds, followed by Transitional_8. GM explains that a low P input changes the decoded D4 pattern into that transitional state. The controller requires more than one failure count, with valid torque information and the specified running and voltage conditions.

This explains why “transitional” on a scan display does not automatically prove that a linkage is physically between positions. A wrong electrical bit can create a different decoded pattern. The actual selector position and the individual switch inputs need to be considered together.

## Compare P with the complete pattern
Determine whether the P signal is persistently low through the relevant sequence and whether the remaining switch inputs behave consistently. Separate a single-circuit state error from a broader failure of the switch supply or decoded information. The DTC itself does not establish which physical part caused the low state.

Verification should demonstrate correct P-state transitions and coherent range decoding after the documented corrective action. The source gives a monitor definition, not a pinout or a universal switch-adjustment procedure. Its 4.0L L47/4.6L LD8/L37 group scope remains necessary when interpreting the same code on another GM application.

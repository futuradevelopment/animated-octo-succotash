# P3404: Cylinder-1 deactivation control short toward supply

GM's 2015 OBDG08A table assigns P3404 to the high-circuit fault branch of cylinder-1 deactivation control. The monitored low-side driver reports a short toward controller power. This describes an electrical control-path problem, not excessive cylinder pressure or a command to increase valve lift.

## The high branch differs from an open path
The source evaluates this fault in the driver-on state and describes a very low impedance toward the controller power side. The diagnostic requires at least 11 volts at the powertrain relay and engine speed of at least 400 rpm. Twenty or more errors in 25 samples establish the failure, with evaluation every 250 milliseconds.

An open circuit and a supply-side connection may both prevent normal control, but they are different electrical conditions. The P3404 branch should therefore not be combined with a generic “replace the solenoid” assumption merely because the affected cylinder is identified.

## Follow the commanded control action
A useful check relates the cylinder-1 driver command to its electrical response using the exact application diagram. Determine whether the circuit can follow the active command or is held toward supply. Keep that evidence separate from a later mechanical-performance test of the deactivation system.

Verification should establish correct driver control and a completed electrical monitor following the demonstrated repair. The OEM table provides no component location, connector pin number or universal replacement decision. Its impedance description is a diagnostic definition, not permission to perform resistance tests on energized wiring. The 2015 GM document scope remains part of this generic-code interpretation.

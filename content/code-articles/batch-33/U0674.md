# U0674: Wastegate-position sensor B loses its SENT signal

U0674 identifies lost SENT communication from turbocharger wastegate-position feedback sensor B in GM's 2020 OBDG07 table. This is a sensor-interface diagnostic. It should not be treated automatically as a vehicle CAN-bus outage merely because the code begins with U.

## Three forms of missing communication
The row begins on physical page 370 and continues on page 371. It recognizes no signal on the line, a line held low, or a line held high. Ignition must be on and the applicable basic enabling conditions met. The source lists continuous monitoring with a two-trip classification.

Those conditions differ from a signal that arrives but has invalid frame length, checksum or data content. The neighboring SENT validation diagnostic handles such content checks. For U0674, the useful first distinction is whether the interface lacks transitions or remains fixed at an electrical level.

## Signal delivery before mechanical position
Identify the sensor-B feedback path from the correct turbocharger and controller service information. Determine whether the SENT signal reaches the controller and whether its line state is consistent with the recorded communication failure. A wastegate's physical position does not prove that its digital position information is being delivered.

Verification should demonstrate restored communication and successful monitor evaluation after the actual cause is corrected. The DTC does not establish a stuck wastegate or automatically require replacing the turbocharger. No fixed timeout or universal voltage threshold is invented from this row. The SENT architecture, sensor identity and calibration must be confirmed for the vehicle before testing.

# P349C: Cylinder-5 deactivation does not produce the expected air behavior

P349C identifies a cylinder-5 deactivation performance concern in GM's 2020 OBDG07 table. The monitor detects an unwanted air-pumping condition during half-engine operation. It is a functional result inferred from the system's operating and air-charge information, not an automatic diagnosis of an open solenoid circuit.

## Valid inputs are part of the test
GM requires synchronized half-engine and air-charge information, enabled valve-lift diagnosis and credible pressure/airflow inputs. The row uses an 800-to-2,900-rpm operating window. The continuation constrains mode-transition settling and throttle-position variation, so an unsettled transition is not the same diagnostic state.

Error accumulation depends on calibrated lookup values. Treating a brief pressure fluctuation or one cylinder event as the complete failure would omit that accumulated evidence. The code's cylinder number identifies the performance channel being evaluated, but it does not establish the location of a physical defect.

## Distinguish delivery from effect
First establish the requested operating mode and the validity of the control and sensing information. Then determine whether cylinder 5's inferred air behavior agrees with deactivation. Correct electrical switching and correct mechanical response are related but separate findings.

Verification should demonstrate the expected functional response under the matching service procedure after the cause is established. The published enable logic includes an inconsistent bank-2 pressure-ratio inequality; its numerical value is deliberately omitted here rather than treated as a usable test specification. The full calibration procedure must resolve that issue before recreating the monitor. No component replacement follows automatically from P349C.

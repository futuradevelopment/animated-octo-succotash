# P2615: Cam-position output circuit remains low when high is commanded

P2615 concerns the controller's **camshaft-position signal output** circuit in GM's 2015 OBDG06 table. It is not automatically a fault in the raw camshaft sensor input. The monitor checks the low-side output driver while the cam-position output is commanded high and the engine is not cranking.

## The low result has two documented interpretations
GM's row includes a short toward ground and an open circuit. Its threshold descriptions distinguish a very low impedance toward controller ground from an open-path condition of at least 200 kilohms. These are monitor definitions, not instructions to measure resistance on an energized circuit.

Powertrain relay voltage must be at least 11 volts. The diagnostic requires 40 failures in 50 samples, with one sample every 100 milliseconds. It is classified Type C with no MIL, and the table notes that some controllers may also set the separate output-circuit/open code P2614.

## Do not confuse input and output evidence
A valid cam-sensor waveform does not prove that a controller-generated output reaches its destination correctly. Conversely, an output fault does not by itself establish that the engine has lost mechanical synchronization. Identify the exact generated-signal path and commanded state before choosing an electrical check.

Verification should establish correct output behavior under the noncranking enabled conditions and successful monitor completion. The code does not select the wiring, load or driver electronics as the failed component. The absence of a warning lamp also does not prove this no-MIL monitor passed. Apply these details only to the documented GM implementation.

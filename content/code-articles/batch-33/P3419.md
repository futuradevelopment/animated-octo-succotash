# P3419: Cylinder-3 control circuit fails its off-state low check

P3419 monitors cylinder-3 gas-exchange/deactivation valve control in GM's 2020 OBDG07 table. The electrical fault is voltage remaining low while the driver is off, indicating a short toward ground. This newer row provides a clear low-circuit definition without relying on the concatenated open/low wording in an older GM table.

## A different test from mechanical deactivation
The ECU toggles valve control on and off early in the driving cycle. The table lists drive state, a battery-voltage window above 10.9 and below 25.5 volts, and a specified early-cycle engine-speed range as prerequisites. The low-state failure must persist for 0.5 second and carries a one-trip classification.

The code does not show whether cylinder 3 pumps air when deactivation is requested. That is a separate performance relationship. Likewise, a low electrical state during an on command is not enough to establish a failure that specifically evaluates driver-off behavior.

## Resolve the circuit direction
Use the correct engine diagram to identify cylinder 3's output. Determine whether the circuit can release from ground when the driver turns off, and distinguish an unwanted ground path from an interrupted conductor. A plausible scan value alone cannot establish the electrical path's integrity.

Verification should show proper switching through the applicable service test and no renewed low-state failure. The source's threshold entry is incomplete numerically, so no resistance value is inferred. Vehicle architecture, calibration and test access remain matters for the exact service information; this is a scoped monitor explanation, not a universal repair procedure.

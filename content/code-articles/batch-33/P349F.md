# P349F: Cylinder-8 deactivation performance leaves an air-pumping error

P349F is the cylinder-8 performance branch of GM's 2020 OBDG07 half-engine deactivation diagnostics. The controller detects air pumping that conflicts with the intended deactivated state. The code concerns achieved operation, which differs from the separate open, low and high electrical-control codes for cylinder 8.

## A qualified, stable comparison
The source requires half-engine synchronization, active valve-lift diagnosis and valid pressure/airflow information. Its continuation lists engine speed between 800 and 2,900 rpm, settling after mode switching and limits on throttle movement. Error accumulation uses calibrated lookup-dependent counts.

This means that a command to deactivate cylinder 8 is only one part of the evidence. The controller also needs trustworthy information showing the resulting air-charge behavior. A rapid demand change or invalid pressure input can make a casual comparison unlike the actual enabled monitor.

## Determine what failed to agree
Compare the desired mode, electrical control evidence and functional response. A driver that switches correctly does not independently prove successful deactivation, while a performance code cannot identify one mechanical part without supporting service tests. Preserve accompanying circuit or sensor diagnostics that affect this interpretation.

Verification should show the expected cylinder-8 response through the applicable professional service procedure after the actual cause is corrected. The OEM enable table contains a conflicting bank-2 pressure-ratio inequality, which is not used as a threshold here. Confirm the complete calibration logic before reproducing the test. The document does not authorize a universal valve, solenoid or controller replacement from this code alone.

# P1350: Spark-control pulses conflict with bypass mode

P1350 checks the relationship between ignition bypass mode and electronic spark timing pulses in GM's 1998 4.0L L47 Aurora diagnostic table. The failure can arise in two opposite ways: EST pulses appear during bypass mode, or EST pulses are absent during EST mode.

## Mode changes the expected result
For the bypass branch, the source considers more than zero EST pulses after more than one reference pulse has been detected. For the EST-mode branch, it considers zero EST pulses after more than two reference pulses. The condition lasts 0.8 second, with evaluation every 100 milliseconds.

This is why “there are ignition pulses” is not a sufficient verdict. Pulses can be wrong because they appear in a mode that should not have them, while their absence can be wrong in the other mode. The control state must be recorded with the waveform or scan evidence.

## Determine which branch occurred
A useful diagnostic record identifies the active bypass/EST mode, whether reference pulses are present and whether EST pulses agree with that state. Separate a valid reference stream with inappropriate control behavior from a situation where the enabling reference evidence is missing.

The generic catalog phrase “Ignition Control System” does not locate the cause in a coil, module or harness. The OEM row supplies a rationality test, not a component replacement instruction. Following corrective work, verify both mode-appropriate behavior and a completed monitor under the actual calibration's service conditions. These timing and pulse-count details belong to the cited 1998 L47 implementation.

# P1645: Purge output-driver feedback reports an electrical fault

P1645 checks the canister-purge output circuit in GM's 1998 4.0L L47 Aurora diagnostic document. The controller uses internal output-driver feedback to determine whether an electrical fault is present. It is not a fuel-vapor leak-size measurement or a direct test of how much vapor the engine receives.

## What the controller actually checks
The monitor requires more than ten seconds of engine operation and ignition voltage above nine volts. Eight failures in ten tests establish the result, with checks every 250 milliseconds. The table does not supply a universal resistance or a connector voltage that can substitute for this commanded-output feedback check.

Because the decision comes from the driver circuit, a purge valve that physically moves is not complete proof that the electrical path is healthy. Conversely, a vapor-flow problem is not automatically the explanation for an output-driver fault. These are different forms of diagnostic evidence.

## Relate command to feedback
A useful investigation identifies the purge command and expected circuit state for the actual application, then determines why the driver feedback disagrees. Distinguish an electrical-output concern from a separate sealing or flow concern before choosing a repair procedure. The source does not establish that the PCM itself has failed merely because it reports internal driver feedback.

Verification should allow the enabled output test to complete with correct feedback following the documented corrective action. Use the matching wiring and service information for component-level decisions. The L47-specific monitor criteria should not be applied automatically to every imported GM or non-GM catalog alias sharing P1645.

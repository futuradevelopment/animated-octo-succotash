# P3435: Cylinder-5 valve-control circuit is pulled low

In GM's 2020 OBDG07 table, P3435 detects a low electrical state in cylinder-5 gas-exchange valve control while the driver is off. The row interprets that state as a short toward ground. It is the circuit-low branch of the cylinder-deactivation control diagnostics.

## Off-state behavior is different from an intentional command
The controller deliberately switches the valve control on and off early in the driving cycle. A low state during active low-side control can be normal; the failure concerns remaining low when the monitor expects the driver-off behavior. The condition must last 0.5 second.

The source lists ECU drive state, battery voltage above 10.9 and below 25.5 volts and a narrow early-cycle engine-speed window. It classifies this branch as one trip. These criteria should remain attached to the cited implementation rather than becoming a general road-speed test instruction.

## Identify which relationship failed
Determine whether the correct cylinder-5 output can release from ground through the application-specific service test. A broken conductor and a grounded conductor need different evidence even if both interfere with solenoid operation. A mechanical deactivation malfunction with valid electrical control is another distinct question.

Verification should show correct switching and successful monitor evaluation after the demonstrated electrical cause is corrected. The source does not provide a complete numerical short-to-ground impedance in this row, so no resistance threshold is supplied here. Exact engine configuration, connector access and component decisions require the matching service information; the DTC alone does not identify a failed part.

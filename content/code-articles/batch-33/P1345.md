# P1345: Camshaft-to-crankshaft phase disagreement

P1345 is a camshaft/crankshaft correlation diagnostic in the cited GM 2002 engine table. Its specific row checks the timing of a cam signal falling edge relative to the crank signal. The monitor is concerned with signal phase, which differs from simply asking whether either sensor produces pulses.

## The documented phase window
The table identifies a cam edge outside a plus-or-minus 27-degree relationship to the crank edge. The engine must be running, and a crank-position signal-invalid diagnostic must not be present. Thirty failed tests in a 50-test sample establish the failure; the test executes at each crank falling edge, so sample completion time depends on engine speed.

GM labels this row as an installation check involving the cam sensor and high-voltage switch. That context matters: a code-reader description of “correlation” alone does not tell the technician whether the application uses this particular arrangement. Confirm the engine and service procedure before choosing an alignment or timing check.

## Useful distinctions
A valid but incorrectly phased cam signal points to a different question from a missing or electrically invalid crank signal. Likewise, a recorded phase error does not alone prove that either sensor needs replacement. Preserve evidence of pulse integrity and relative phase before deciding which branch of the vehicle-specific procedure applies.

Verification should establish the correct phase relationship with valid crank data and allow the running monitor to complete. The document marks this code as unused on the 5.3L LM7 truck application within the group; its broad engine heading is not blanket applicability evidence.

# P3436: Cylinder-5 valve-control output resists the on command

P3436 is the high-circuit diagnostic for cylinder-5 gas-exchange/deactivation valve control in GM's 2020 OBDG07 table. The controller observes voltage staying high during the driver-on state and identifies a short toward power. This is a command-delivery fault, not proof that cylinder 5's mechanical deactivation hardware is damaged.

## A brief early-cycle electrical comparison
The source specifies a 0.5-second condition and describes toggling the valve control during the start of the driving cycle. ECU drive state, an early-cycle engine-speed window and battery voltage between the documented 10.9- and 25.5-volt limits enable the check. The diagnostic has a two-trip classification.

The high state is meaningful because it persists during activation. A high reading while the driver is intentionally off does not demonstrate this fault. Likewise, a valve that moves incorrectly despite normal electrical switching would require performance evidence rather than this circuit-high interpretation.

## Keep the output and its load identifiable
Use the actual engine diagram to trace cylinder 5's control path. Determine whether it can follow the active command and whether the high-fault feedback corresponds to that behavior. The code does not locate the unwanted supply-side connection or establish an automatic solenoid replacement.

Verification should include proper on-state control and a completed electrical diagnostic after the cause is corrected. The table's short-to-power threshold is not numerically complete, so this article does not invent an impedance limit. Apply the source-specific monitor only after confirming the vehicle calibration and approved electrical test method.

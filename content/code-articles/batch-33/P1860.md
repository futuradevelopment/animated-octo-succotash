# P1860: Torque-converter PWM control circuit electrical fault

GM's 2000 Car V8 group 1 table defines P1860 as an open or short toward ground in the torque-converter-clutch PWM control circuit. The diagnostic evaluates electrical fault feedback. It does not directly establish that the clutch is mechanically slipping or that the converter must be replaced.

## Duty-cycle extremes enable this check
The listed conditions include a TCC solenoid duty cycle below ten percent or above 90 percent, system voltage between eight and 18 volts and qualifying engine operation outside fuel cutoff. The failure criterion is 43 failed observations within 50 samples.

The duty-cycle condition is especially useful when reviewing evidence. A midrange PWM command may not be the interval in which this electrical monitor evaluates the circuit. Likewise, a slip-speed reading alone does not show whether the control driver reported an open or a ground-short condition.

## Distinguish command delivery from clutch response
First establish whether the PWM electrical path follows the controller's command under the applicable test state. Then keep any hydraulic or mechanical engagement concern separate from that result. An electrical fault can prevent a meaningful clutch-performance assessment, but the code does not by itself prove every downstream effect.

Verification should show a valid control response and successful monitor evaluation after the actual electrical cause is addressed. Use the exact transmission service procedure for circuit access; the OEM table provides neither pin assignments nor a universal resistance test. These operating limits describe the cited historical L47/LD8/L37 monitor and require confirmation before use elsewhere.

# P1515: Measured throttle position differs from the modeled position

P1515 is the PCM's commanded-versus-actual throttle performance diagnostic in GM's cited 2002 ETC table. The defined throttle error is measured position minus modeled position, and the monitor considers an absolute error greater than five percent. It therefore evaluates a control relationship, rather than merely checking whether a position sensor voltage exists.

## Direction and prerequisites matter
The table uses separate high and low error counters. Their behavior depends on whether the measured position is above or below the model, and passing or opposite-direction evidence reduces or clears accumulated error. A signed error trace is consequently more informative than a single unsigned percentage.

Checks occur every 18.75 milliseconds when valid throttle-module messages are received. The desired position must be considered valid, battery-saver mode must be inactive, and the engine must be running or ignition voltage must exceed 8.5 volts. Relevant airflow, actuation, sensor, communication and processor faults also gate the test.

## Diagnose the relationship that failed
Compare measured position with the actual modeled or desired quantity used by the supported service data. A pedal-position value is not a substitute for either side of this throttle comparison. Determine whether the disagreement is consistently positive, consistently negative, or associated with loss of valid control information.

The published row contains an unclear character in one counter description, so this article does not reconstruct a complete counter algorithm from that text. Its supported five-percent criterion and direction-sensitive structure remain useful. Verify restored position tracking with valid communication and enabled conditions; the code alone does not choose between actuator, mechanical, signal or controller causes.

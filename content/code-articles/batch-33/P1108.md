# P1108: Barometric and manifold pressure remain too similar

P1108 is a BARO-to-MAP rationality diagnostic in GM's 1998 4.0L L47 Aurora engine and transmission document. Despite the catalog phrase “comparison too high,” the actual failure criterion is a pressure difference **below 11 kPa** under specified closed-throttle running conditions. The monitored relationship, rather than the short title, determines what the result means.

## A pressure comparison with strict context
GM requires the throttle switch to indicate closed, throttle position below 18 degrees, engine speed above 400 rpm and barometric pressure above 75 kPa. Throttle-position and other MAP diagnostics must not be failing. The condition persists for 15 seconds, with checks every 250 milliseconds.

Under those conditions, the controller expects manifold pressure to be sufficiently separated from its barometric reference. The code does not establish which of the two reported pressures is inaccurate, nor does it name the mechanical reason for an unexpected pressure relationship.

## Avoid a key-on comparison
Similar MAP and BARO values with the engine stopped are not the operating state defined by this monitor. Likewise, a pressure comparison during open-throttle operation cannot be judged by this closed-throttle criterion. Preserve engine state and throttle information alongside both pressure values.

A useful investigation distinguishes an incorrect pressure input from an engine condition that changes manifold pressure while the input remains accurate. Verification needs the specified running relationship to become plausible and the monitor to complete. This is a historical L47 monitor explanation, not a universal 11-kPa rule for every vehicle whose catalog contains P1108.

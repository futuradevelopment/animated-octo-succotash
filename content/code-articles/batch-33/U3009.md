# U3009: Ground-path B imbalance in the brake-control system

U3009 identifies the second independent ground-path loss detected in GM's 2020 OBDG07 brake-controller table. The monitor compares feedback from GND_1 and GND_2, which the document describes as separate vehicle-ground connections normally sharing the total current load approximately equally.

## The second branch has the opposite sign
For the GND_2-disconnected condition, the source lists a normalized comparison below minus 0.9, persisting for 200 milliseconds. The internal system must be initialized and its analog-to-digital conversion checks valid. This negative threshold distinguishes the branch from the opposite ground-loss indication; it is not a negative battery-voltage specification.

The printed equation lacks clear grouping, so no standalone calculation is reconstructed here. The supported interpretation is a directional imbalance between two monitored paths. A controller that remains responsive can still have lost one of those paths, because continued operation does not establish that the original current sharing is intact.

## Preserve the intended grounding arrangement
Use the exact brake-control wiring and professional service procedure to identify and evaluate the second path together with the first. Do not deliberately remove a working ground or add a bypass connection to make the DTC disappear. Such changes would alter the arrangement the controller is monitoring.

Verification should establish both designed paths are sound and the internal monitor evaluates successfully after the actual cause is corrected. The code does not automatically require controller replacement. Its ground labels, threshold and enabling conditions are specific to the cited module implementation, not every vehicle represented by the generic U3009 title.

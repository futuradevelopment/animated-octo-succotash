# P1371: Too few 4X pulses within a valid reference interval

In GM's 1998 4.0L L47 Aurora table, P1371 means that too few low-resolution 4X crank-reference pulses were received relative to the available high-resolution and camshaft information. It is a counting disagreement, not simply a low-voltage circuit code.

## The reference interval is part of the evidence
The published failure condition uses 48 received 24X pulses between cam pulses while the 4X count remains below eight. Engine speed must exceed 496 rpm, cam pulses must currently be arriving and more than seven cam edges must have occurred since key-on. GM lists four failures in ten tests, checked every 250 milliseconds.

These prerequisites give the low-resolution count meaning. A partial capture that starts or stops midway through the relevant interval cannot be compared directly with the table's complete count. Also, a normal 24X stream does not establish that the separate 4X stream is intact.

## Compare information paths rather than guessing a sensor
Determine whether the low-resolution stream loses pulses while the cam and 24X references remain coherent. Distinguish that pattern from a broad interruption affecting several reference signals together. Both can look like an engine-speed problem to a driver, but the controller's documented evidence is more specific.

Verification should preserve the expected relationship across complete reference intervals and let the monitor evaluate again. The table does not identify which physical sensor, connection or processing stage caused the missing information. Confirm the exact application and signal routing before testing; this historical 4X/24X scheme should not be assumed from the code number alone.

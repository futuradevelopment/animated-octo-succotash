# P3444: Cylinder-6 deactivation control is held toward power

GM's 2015 OBDG08A table defines P3444 as the circuit-high fault branch for cylinder-6 deactivation control. The low-side output driver identifies a short toward controller power. This is an electrical-integrity test, distinct from checking whether cylinder 6 achieves the intended mechanical operating mode.

## The monitor's active state
The source checks this branch with the driver on. It describes a very low impedance toward the power side and requires at least 11 volts at the powertrain relay, at least 400 rpm and enabled diagnostics. At least 20 of 25 samples must fail, with a 250-millisecond interval between observations.

These details explain why a high reading without command context is incomplete. A circuit can legitimately sit toward supply during another state. The useful question is whether the circuit can respond correctly when this monitor applies the relevant command.

## Separate a held line from an interrupted line
An unwanted supply connection and an open path can both compromise control, but the diagnostic table gives them separate branches. Preserve the reported branch and corroborate it using the exact cylinder-6 wiring information before selecting a repair. Neither branch independently proves a mechanical lifter or valve failure.

Verification should establish correct command response and a passing electrical evaluation after the demonstrated fault is corrected. The source does not prescribe a universal solenoid replacement or provide terminal assignments. Its impedance wording is a monitor definition, not an instruction to test resistance on an energized circuit, and its calibration scope must be confirmed for the vehicle.

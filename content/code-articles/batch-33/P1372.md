# P1372: Crank-reference matching repeatedly loses synchronization

P1372 is a crank-signal performance diagnostic in GM's 2000 4.0L L47 and 4.6L LD8/L37 table. The controller monitors corruption of crank-sensor A and/or B information that produces occasional resynchronization. GM gives excessive signal noise as the type of behavior this monitor is intended to detect.

## A repeated matching failure
The failure criterion is more than six losses of match within 85 cylinder events. The PCM must be in crank or run, decoding must be angle-based and camshaft faults must not be present. Evaluation occurs at the low-resolution interrupt rather than at a fixed number of seconds independent of engine speed.

Those details distinguish P1372 from a reference signal that is simply absent all the time. A waveform can contain many plausible pulses and still disrupt matching often enough to exceed the event-based allowance. One clean interval captured after the fault is not proof that the complete reference history was reliable.

## Investigate coherence across events
The useful record relates both crank inputs to the reference sequence and identifies where matching is lost. Separate isolated electrical disturbances from a consistently wrong relationship. Also note whether camshaft faults would have prevented this particular evaluation, rather than treating every synchronization code as the same test.

Verification should demonstrate stable reference matching across enough cylinder events under the applicable decode state. The table establishes what the controller detected, not whether a sensor, connection, interference source or processing stage caused it. Exact signal access and acceptable waveforms must come from the service information for the actual calibration.

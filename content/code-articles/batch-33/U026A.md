# U026A: Front-view camera messages time out at the object controller

In GM's 2020 OBDG07 IMX6 object-controller table, U026A records loss of communication from the front-view camera module. The generic catalog calls the device image-processing sensor F; the OEM row provides the supported application identity rather than a universal physical location for every manufacturer.

## The receiver supervises a set of messages
The external object calculating module checks camera messages $350 through $356. Each listed timeout is greater than three seconds. The test requires system power mode RUN, battery voltage above nine volts, manufacturing enable counter zero and the camera-communication diagnostic enabled.

This is a message-absence check. An arriving message with a bad checksum or stale counter is evaluated differently. Also, a camera that is powered does not necessarily establish that the required messages reach the receiver, while an intentionally disabled diagnostic cannot provide a meaningful passing result.

## Identify the affected information path
Preserve which receiving module stored the fault and whether all supervised messages disappear or only part of the expected information is missing. Evaluate the camera's power and communication state through the matching service procedure rather than assuming the camera itself is defective.

The source lists disabling adaptive cruise control and/or Super Cruise as the default action on the supported architecture. It does not establish that every vehicle with this generic code has those features. Verification should demonstrate restored camera-message reception through an enabled interval after the actual cause is corrected. A successful calibration alone would not prove that a missing-message path has been restored.

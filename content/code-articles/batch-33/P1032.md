# P1032: Upstream oxygen-sensor heater warm-up control circuit

P1032 concerns the upstream oxygen-sensor heater warm-up control circuit in GM's 2000 4.0L L47 and 4.6L LD8/L37 engine-group diagnostic document. GM identifies three electrical possibilities for this monitor: an open circuit, a short toward ground, or a short toward supply. The code alone does not distinguish among them.

## Electrical evidence before warm-up assumptions
Although the name includes “warm up,” the table describes a circuit check. It does not define a slow exhaust-temperature rise or a catalyst light-off failure. Replacing a sensor because it appears slow to respond would therefore skip the actual electrical evidence this code records.

The test requires system voltage above 9 volts and below 18 volts, with engine speed over 425 rpm. GM uses 100 failed readings from 120 samples to recognize the fault. These conditions help distinguish a running electrical failure from an observation made with the engine stopped or the vehicle supply outside the diagnostic window.

## Following the correct branch
The next useful distinction is whether the warm-up control path is electrically open, held low, or held high. That requires the matching wiring diagram and commanded-state interpretation; one resistance value cannot represent all three possibilities. Keep heater-control evidence separate from the sensor's exhaust-voltage response.

Successful verification should show the circuit responding correctly under enabled running conditions and the diagnostic completing without renewed failure. P1032's table is not a pinout, a heater-resistance specification, or proof that the sensor assembly is defective. Apply these facts only after confirming the vehicle uses the documented historical monitor.

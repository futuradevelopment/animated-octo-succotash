# P1275: Accelerator-pedal sensor 1 circuit and minimum-stop check

P1275 identifies the first accelerator-pedal position channel in the electronic-throttle monitor described by GM's 2002 engine table. The throttle actuator control module can report either an out-of-range signal or an invalid value at the pedal's minimum mechanical stop. Those are related but distinct ways for this code to arise.

## Two electrical comparisons
The running signal check uses a lower boundary of 0.25 volt and an upper boundary of 4.22 volts. The minimum-stop branch identifies a voltage below 0.19 volt. A value that appears acceptable during pedal travel therefore does not establish that the released-position check also passed.

The monitor requires ignition in run or crank, ignition voltage above 5.23 volts, valid communication between the throttle module and PCM, and no throttle-module processor DTC. It checks every three milliseconds. Its counter adds four for an error and subtracts one for a pass, with a threshold of 106, so recurring interruptions can matter even when normal readings occur between them.

## Keep the channel identity intact
Evaluate APP1 as the pedal input identified by this code; do not substitute a throttle-blade position reading. Compare its complete travel and released-position behavior using the correct calibration's service method. The code supports an electrical or minimum-position concern, but does not independently locate it inside the pedal assembly.

Verification should address both the signal range and the minimum-stop condition while communication and supply prerequisites are valid. These limits describe the cited historical ETC monitor, and should not be transferred to other pedal designs simply because they share a P1275 label.

# P3443: Cylinder-6 deactivation circuit fails the low-state check

P3443 is the ground-short diagnostic for cylinder-6 deactivation control in GM's 2015 OBDG08A table. The controller observes the circuit while its low-side driver is off and identifies a state consistent with an unwanted connection toward ground.

## Command context prevents a false interpretation
Low-side control deliberately uses a low state during some commands. This monitor is concerned with the inappropriate low state during its specified off-state check. The threshold description uses no more than 0.5 ohm toward controller ground; it is not a general solenoid-coil resistance specification.

GM requires at least 11 volts at the powertrain relay and at least 400 rpm, with the diagnostic enabled. Twenty or more errors in 25 observations establish the fault. Sampling every 250 milliseconds gives the controller repeated evidence rather than one isolated electrical snapshot.

## Compare the right output with the right command
Identify cylinder 6's deactivation control path on the actual engine. Relate the driver command to its electrical behavior and determine whether the circuit remains grounded when the controller expects it released. A mechanical deactivation failure with correct electrical control would be a different diagnostic finding.

Verification should demonstrate restored off-state behavior and successful monitor completion after the actual cause is addressed. The code alone does not distinguish a harness condition from a load or driver-electronics problem. Do not use the threshold as a powered resistance-test recipe or infer component location from another engine's cylinder layout. These limits belong to the cited GM implementation.

# U0670: fuel-temperature sensor A loses SENT pulse traffic

U0670 is documented as a fuel-temperature-sensor-A SENT communication failure. The useful supported finding is sparse pulse traffic: the row checks four or fewer pulses and a persistent line state. It does not compare fuel temperature with a thermodynamic limit.

## An unresolved wording conflict

The source description says “shorted low,” but the same row's line-state criterion says High and its narrative also describes a line always high. Those statements conflict. This article therefore does not turn U0670 into a definitive short-to-ground or short-to-supply diagnosis. The vehicle-specific service information must resolve the intended electrical test before circuit conclusions are made.

The table specifies 400 failures out of 500 samples at 6.25 milliseconds per sample. Communication monitoring must be enabled, and code-clear/device-control restrictions apply. Reporting is Type A, one trip.

## Useful evidence despite the limitation

Distinguish loss of digital information from an implausible temperature value transmitted normally. Preserve pulse availability, the reported line state and related sensor faults, rather than choosing a replacement from the generic label.

Verification requires valid SENT communication throughout the eligible sample window. A normal temperature value at one instant cannot exclude intermittent pulse loss. Because the source's polarity language is inconsistent, any electrical probing or repair decision requires a corrected, vehicle-specific procedure; the article remains marked for source review.

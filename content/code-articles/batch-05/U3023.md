# U3023: Power A and run/crank inputs disagree

U3023 is an input-power correlation code in this GM ECM section. The controller compares Power A with the run/crank input. The displayed malfunction expression is Power A minus run/crank voltage greater than 3.00, rather than a simple claim that either input is below one absolute supply limit.

## Why the difference matters

A believable voltage on one input cannot establish that the two inputs agree. Preserve both values from the same operating moment if available. The direction of the comparison also matters: this row describes Power A exceeding run/crank by the stated difference, not a symmetric absolute-difference test.

The monitor requires its correlation diagnostic enabled, battery present and run/crank active. The starter motor must not be engaged. A voltage relationship captured during cranking therefore does not directly recreate this documented non-cranking evaluation.

## Interpreting a repeat occurrence

The row specifies 40 failures out of 50 and Type B, two-trip reporting. It does not provide a clear sample-time unit alongside that count, so a precise total failure duration should not be invented.

Use the actual input-power diagram and related power records to investigate why the signals disagree. A completed verification should show correlated inputs while run/crank is active and the starter disengaged, with the monitor enabled. Clearing a stored code or measuring only battery-terminal voltage cannot prove that the ECM's two monitored inputs now satisfy the comparison.

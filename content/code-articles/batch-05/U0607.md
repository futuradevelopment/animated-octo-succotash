# U0607: throttle sensor 2 sends unusable SENT information

U0607 refers to throttle-position sensor 2's SENT communication circuit in this GM ECM table. The broader dictionary title includes pedal sensors, but the cited implementation does not establish a pedal-sensor fault. It checks the second throttle communication channel for electrical and message-format failures.

## More than a missing sensor

The diagnostic can fail for a CRC error or excessive message age as well as for out-of-range pulse timing. The source lists a 3.125-millisecond message-age limit and pulse bounds of 0.125977 and 0.209991 milliseconds. Wave-state checks use 0.5 V and 4.1 V. Those values describe SENT decoding; they are not a normal throttle-position sweep specification.

Evaluation requires run/crank voltage above 6.41 V and includes both intermittent accumulation and continuous-failure count paths. The row uses Type A, one-trip reporting.

## Distinguish channel behavior

Compare the availability of valid sensor 2 information with sensor 1 information and associated power or circuit faults. A problem isolated to the second channel is different evidence from simultaneous disruption of both, although the shared cause cannot be determined from this table alone.

A useful retest verifies continuous valid communication during eligible operation. A believable position value at one instant cannot rule out a timing or CRC fault. Follow the vehicle-specific diagnostic procedure before condemning a throttle assembly; this monitor summary provides neither pinouts nor a replacement instruction.

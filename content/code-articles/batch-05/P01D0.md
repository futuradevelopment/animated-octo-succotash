# P01D0: cylinder 3 produces an excessive negative injection correction

P01D0 concerns negative injection drift for cylinder 3 in the cited SQP strategy. The controller evaluates both energizing-time behavior and injection-start angle. The source calls the result over advanced, but an excessive quantity-related correction can also satisfy its described diagnosis.

## Why small injections are used

During diesel fuel cut-off, a known small injection creates a rail-pressure response that can be compared with the expected quantity response. Several injections establish the correction. Their falling-edge timing is converted into crank angle, and the mean angular position is compared with the selected start of injection.

This controlled evaluation requires the appropriate SQP and learning enables plus fuel, temperature and speed prerequisites. It is reported as Type B, two trips.

## Keep direction separate from a numeric recipe

The narrative clearly calls this negative drift. The printed positive greater-than thresholds do not explain whether a magnitude or transformed value is intended, so a signed numeric limit is not asserted here. Correct calibration information is needed before interpreting an adjustment value.

Preserve cylinder 3's correction type and completion status, then compare them with the applicable service evidence. A normal current idle does not verify a fuel-cut-off small-injection monitor. The code is not proof of an engine-wide timing fault or permission to alter injection timing manually; professional vehicle-specific diagnosis remains necessary.

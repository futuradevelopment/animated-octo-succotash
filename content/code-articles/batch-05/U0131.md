# U0131: a steering-controller message exceeds its deadline

U0131 identifies lost power-steering-controller communication in the documented GM ECM strategy. The listed message is $1E5, and its absence must exceed 10,000 milliseconds. The code therefore describes information the ECM did not receive, rather than directly measuring steering effort or diagnosing an internal steering motor.

## Conditions behind the result

The monitor checks the network in a 12.5-millisecond loop. It requires full communication, enabled normal transmission and qualifying power conditions for at least three seconds. A bus-off fault for the relevant channel must be inactive. These prerequisites separate an eligible missing-message event from a network intentionally entering shutdown.

The source classifies this as a safety-related, emissions-neutral Type C diagnostic with no emissions MIL. Absence of a check-engine light should not be used to dismiss a steering warning or abnormal steering behavior.

## Choosing the next evidence

Determine which module stored the code and whether the steering controller is currently reachable. Compare other recipients' communication records to understand whether the loss was shared or specific to the ECM. Neither a stored U0131 nor one successful scan response establishes a failed controller.

A completed retest should show the $1E5 message arriving through the relevant operating state without another timeout. Any steering symptom warrants the appropriate professional steering-system assessment; this communication monitor does not determine whether the vehicle is safe to drive.

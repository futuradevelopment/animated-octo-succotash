# U0146: the brake controller loses the gateway status message

U0146 is a gateway communication timeout in the cited brake-controller table. The electronic brake controller expects the PPEI_CGM_General_Status_HS message from the central gateway module. Not receiving it for at least 0.25 second meets the listed missing-message criterion.

## A specific receiver, a specific message

The generic title says Serial Data Gateway Module A; the source names the Central Gateway Module, or CGM. This article concerns that documented relationship. The row does not establish a gateway location, connector assignment or identical timing for every controller that may record U0146.

Ignition must be on and communication conditions must be valid, including no undervoltage and no error-passive condition. The monitor operates continuously and uses Type B, two-trip reporting. An event during a different network or power state may therefore require different interpretation.

## Separating absence from root cause

Determine whether other gateway-dependent communication is also missing. A wider loss may implicate a shared network path or power dependency, while an isolated recipient timeout calls for closer attention to that message path. Both are investigative distinctions, not component diagnoses.

Verification should show the gateway status arriving within the receiver's deadline while the monitor is enabled. A gateway that answers a scan once has not necessarily passed that recurring requirement. Since this row belongs to the brake controller, brake-system warnings still require the applicable professional assessment.

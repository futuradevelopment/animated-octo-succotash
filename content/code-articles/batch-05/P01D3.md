# P01D3: cylinder 5 exceeds the positive small-injection drift limit

P01D3 is the cylinder-5 positive-drift result from the documented SQP injection test. Its two listed failure paths are calculated energizing-time delta above 100 microseconds and start-of-injection delta above five degrees. Either quantity behavior or timing behavior can therefore explain the over-retarded label.

## This is an eligible learning event

During diesel fuel cut-off, the ECM commands a known small injection and measures its rail-pressure effect. It compares the drop with the expected quantity response and uses the falling-edge timing plus crank speed to estimate start angle. Several injections and stepped commands support the decision.

The test requires enabled SQP learning and applicable fuel-level, temperature and speed conditions. The source describes a once-per-trip evaluation when the prior driving cycle completed, otherwise resuming an interrupted status. Reporting is Type B, two trips.

## Why completion status matters

A trip with no repeated code may simply lack a completed cylinder-5 evaluation. Preserve monitor completion as well as the correction result before calling a repair successful. Similarly, a normal large injection under load does not prove that small-quantity behavior is correct.

Verification should repeat the eligible SQP test and show acceptable cylinder-5 corrections. This table does not identify a physical injector location or a safe test for opening the rail; professional vehicle-specific diagnosis is required before any replacement or high-pressure work.

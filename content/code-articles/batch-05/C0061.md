# C0061: lateral-acceleration information loses validity or correlation

C0061 concerns lateral-acceleration information from the high-performance inertial measurement unit in this EOCM3 table. One branch fails when lateral-acceleration correlation status is Unknown or Not Correlated. Another covers primary or secondary lateral-acceleration information determined invalid.

## Status and communication are separate

The correlation branch requires the status to be available and excludes relevant loss-of-communication and failed-safety indications. A status that arrives but reports no valid correlation is therefore different evidence from a message that never arrives. The source does not specify a universal lateral-acceleration mismatch in g, so no such threshold can be inferred.

The monitor runs continuously when its signal, communication and common diagnostic enables are active, with the manufacturer's enable counter at zero. GM states that detection disables adaptive cruise and/or Super Cruise in this implementation; reporting is a safety-related emissions-neutral special Type C classification.

## A useful investigation

Determine whether the correlation status failed or one of the two underlying lateral signals was invalid. Preserve those statuses along with related communication faults before assuming the physical sensor needs replacement. An ordinary-looking lateral-acceleration number does not prove the validity flags passed.

Verification should demonstrate available, valid lateral data and an acceptable correlation status while the appropriate branch is enabled. Any required calibration or driver-assistance restoration must follow the applicable professional procedure; this page does not provide a sensor mounting or calibration method.

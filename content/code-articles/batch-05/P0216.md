# P0216: requested and delivered injection pulses disagree

P0216 is an injection-quantity monitoring diagnostic in this GM ECM section. The controller compares the application software's requested energizing time with hardware input/output feedback for each actuated pulse and cylinder. It also counts a programmed pulse that the ECU fails to drive.

## Pulse duration and pulse absence are separate paths

A dropped pulse can trigger the monitor without a meaningful duration comparison for that missing event. For pulses that are delivered, the strategy has separate high and low error thresholds. This makes the code broader than the generic title's suggestion of one external timing-control circuit.

The diagnostic requires appropriate calibration enables, powertrain-relay voltage above 11 V and injection requests across the relevant cylinders. Catalyst warm-up and related injector, boost-voltage, pull-in and controller faults restrict evaluation. The failure/sample limits are named calibrations, not numeric counts supplied here.

## Source limitation

The lower-duration branch prints an absolute-difference comparison with a less-than operator. Its intended signed or magnitude convention is not adequately explained, so this article does not present that line as a complete testing recipe.

Preserve whether the event was a dropped pulse or a duration mismatch. Verification needs consistent requested-versus-actuated pulse behavior during an eligible evaluation. The source describes an internal monitoring discrepancy, not proof that an ECU needs replacement or reprogramming. Vehicle-specific professional diagnosis is required before either action.

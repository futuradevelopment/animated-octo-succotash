# C0520: IMU initialization or calibration status is unacceptable

C0520 covers controller-level high-performance IMU faults in this EOCM3 section. One branch detects initialization not completing after the calibrated initialization delay. Another documented branch concerns static-offset calibration not being completed or a detected sensor-box change with a nonzero received serial number.

## More than an acceleration-reading fault

The initialization branch checks the completion status after a timer, rather than comparing an acceleration value with a limit. It requires propulsion power mode, available initialization information and relevant communication and safety-fault conditions to be clear. The document names the delay calibration without supplying a numeric duration on these pages.

The static-offset branch separately evaluates calibration status and box-swap information. That distinction matters after component work: a calibration-related status and an initialization timeout are different evidence, even though they share C0520.

## Interpreting the service record

Preserve the detailed branch, availability flags and any recent documented component change. Do not assume a prior replacement occurred merely because this code is present. The monitor describes what the controller observed, not the repair history.

The source states that detection disables adaptive cruise and/or Super Cruise and uses safety-related emissions-neutral special Type C reporting. Verification requires acceptable initialization/calibration status under the applicable enable conditions and the proper feature checks. The cited pages do not provide the necessary calibration procedure or authorize an IMU replacement.

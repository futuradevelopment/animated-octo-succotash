# P0198: oil-temperature sensor A exceeds the high-resistance boundary

P0198 is the high electrical-range monitor for the engine-oil-temperature input in the cited GM section. Circuit resistance above 450,000 Ω meets the malfunction criterion. The code does not mean that actual oil temperature is above an overheating threshold.

## The additional enable gate matters

The diagnostic must be enabled, and either engine runtime must exceed twenty seconds or coolant temperature must be at least −20°C. The ECM evaluates four failures out of five samples at one-second intervals. Reporting is Type B, two trips.

Those conditions mean an observation immediately after a very cold start may not represent an eligible test. Preserve runtime and coolant temperature with the sensor's electrical status rather than interpreting every startup reading identically.

## Separate input integrity from oil condition

A high-resistance result calls for the vehicle-specific sensor-circuit investigation. It cannot prove low oil level, poor lubrication or a faulty oil cooler. The table's controller-specific driver description also does not provide external terminal assignments or a direct probing method.

Verification should demonstrate acceptable electrical range while the runtime or coolant gate is satisfied and the monitor completes its sample window. A single normal reading after code clearing is weaker evidence. If the input returns intermittently, keep the event history so the professional diagnosis can distinguish a persistent range failure from a connection or signal problem that has temporarily disappeared.

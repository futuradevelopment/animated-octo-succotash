# P01D2: the cylinder 4 SQP result drifts in the advanced direction

P01D2 identifies excessive negative quantity and/or timing drift for injector 4 in this GM source. It belongs to the shared SQP strategy, which evaluates known small injections during diesel fuel cut-off. The cylinder number identifies the result channel; it does not establish physical injector position without vehicle-specific numbering.

## The pressure trace carries two kinds of evidence

The size of the rail-pressure drop supports an energizing-time correction estimate. The falling-edge position, combined with crank-wheel speed, supports injection-start angle. Multiple injections are used to determine drift rather than relying on a single normal operating pulse.

Quantity or timing diagnosis and SQP learning must be enabled, with the documented fuel and operating-condition gates satisfied. Reporting is Type B, two trips.

## A source convention remains unclear

Although the narrative explicitly says negative drift, the threshold column prints positive greater-than values without explaining whether they are magnitudes. This article does not prescribe a signed adjustment threshold from that ambiguous presentation and retains a review flag.

Preserve whether cylinder 4 failed the quantity or timing path and whether the sequence completed. Verification needs another eligible completed SQP evaluation. Resetting learned values or replacing an injector is not justified by this code alone; use the vehicle's approved professional diagnostic procedure before changing the fuel system.

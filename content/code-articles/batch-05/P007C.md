# P007C: upstream charge-air temperature resistance is too low

P007C is the low-electrical-range monitor for the charge-air-cooler upstream air-temperature sensor in this GM table. The criterion is sensor resistance below 55 Ω. The “low” label concerns electrical range, not a claim that the charge air is unusually cold.

## A resistance monitor with a time window

The engine must not be cranking, run/crank-relay voltage must exceed 11 V and the calibration must enable the test. Failure requires 30 failing counts within 38 samples, evaluated in a 100-millisecond task. Reporting is Type B, two trips.

These details make a sustained out-of-range electrical condition different from a plausible but biased temperature. The code does not measure the cooler's heat-removal performance or compare inlet and outlet air temperatures.

## What to establish next

Confirm that the affected input is the upstream air-temperature sensor used by this implementation. “Charge-air temperature” can be confused with the cooler's coolant-temperature input, which has different monitor criteria. Use the vehicle's sensor mapping rather than selecting a component from the label alone.

Preserve the out-of-range status and related circuit evidence, then follow the appropriate isolated circuit tests. The internal resistance criterion is not permission to measure resistance on a powered circuit. Verification should show an electrically valid input during a complete enabled sample window; a code clear or one reasonable displayed temperature is incomplete evidence.

# P00B2: radiator temperature fails a cold-soak comparison

P00B2 is a radiator-coolant-temperature bias check in the explicitly labeled diesel L6 ATM–LZO section of this GM document. It compares the radiator-outlet sensor with two other temperature references after a soak, rather than judging only whether the reading falls within its electrical range.

## Match the physical sensor before using a threshold

The configurable mapping identifies the radiator input as physical temperature sensor 3. Its comparison references are engine-inlet coolant and outside-air temperature. For that mapping, the supporting pages list threshold A as 21°C and threshold B as 10.73°C, with different rules for ordinary disagreement and disagreement not explained by auxiliary heating.

The radiator comparison requires more than 28,800 seconds of propulsion-off soak and ambient temperature above −20°C. Reference sensors must be available and not faulted. The monitor runs once per valid cold start and uses Type B, two-trip reporting.

## Diagnostic meaning

Preserve all comparison temperatures and any block-heater history. A warmed engine and a cold radiator can reflect auxiliary heating, which the strategy explicitly evaluates; one temperature difference should not be treated as a failed sensor without that context.

Verification needs another eligible soak event with valid reference data. A hot-engine comparison cannot replace this cold-start test. The document explains the bias logic but does not establish a radiator, thermostat or sensor replacement solely from P00B2.

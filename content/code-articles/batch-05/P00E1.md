# P00E1: cooler inlet-coolant temperature input has excessive resistance

P00E1 is an electrically high-range fault for the charge-air-cooler inlet-water temperature input. The documented resistance criterion is above 166,297 Ω. This is the coolant sensor A implementation, not a measurement of charge-air temperature or cooler efficiency.

## Read the unit before interpreting “high”

The threshold is in ohms. It does not mean the controller observed coolant above a temperature limit. A service investigation needs to establish why the electrical input has excessive resistance rather than assuming the cooler overheated.

The diagnostic is calibration-enabled, requires the engine outside cranking and requires run/crank-relay voltage above 11 V. It accumulates 30 failing counts in 38 samples, evaluated in a 100-millisecond task, and uses Type B, two-trip reporting.

## Evidence and verification

Preserve the sensor's raw status and whether the problem returns only intermittently. A current believable temperature can coexist with a history of excessive resistance; it does not demonstrate that the complete monitored window passed.

Confirm the inlet-water channel using the actual vehicle's sensor mapping before electrical tests. The source does not identify the component location or prove whether the sensor or an associated circuit is responsible. Verification requires a consistently valid input during enabled operation, using the vehicle-specific circuit procedure rather than substituting values from another temperature sensor or condemning the cooler assembly.

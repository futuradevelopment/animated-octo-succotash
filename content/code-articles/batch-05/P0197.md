# P0197: oil-temperature sensor A has a low-resistance circuit result

P0197 monitors an electrically low engine-oil-temperature input in this GM ECM section. The stated criterion is circuit resistance below 25 Ω. The accompanying strategy describes a controller-specific short-to-ground check when the relevant output is powered off.

## What “low” establishes

The result concerns the electrical input, not a finding that the engine oil is physically too cold. It also does not measure oil quantity, pressure or lubricant condition. Those are separate questions that this resistance check cannot answer.

The diagnostic must be enabled. Failure requires four failing samples out of five, sampled once per second, and the row lists Type B, two-trip reporting. A very brief normal value between failures therefore does not necessarily establish that the monitored window passed.

## Diagnostic interpretation

Preserve the raw oil-temperature circuit status and the operating state in which the low resistance was reported. The controller's internal criterion is not an instruction to attach an ohmmeter to an energized circuit or to substitute a resistor.

Verification should show a stable electrically valid sensor-A input during a complete enabled evaluation. If the scan temperature returns to a believable value only intermittently, investigate that history rather than assuming the oil's temperature actually changed abruptly. The source supplies no sensor location or part-failure ranking; use the correct vehicle's circuit isolation and service information before deciding on a replacement.

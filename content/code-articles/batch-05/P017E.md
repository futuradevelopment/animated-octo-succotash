# P017E: head-temperature signal makes implausible step changes

P017E is described as an erratic cylinder-head-temperature signal monitor. The ECM predicts acceptable limits for the next reading using the previous sample and a sensor time constant. Positive or negative steps beyond those calculated limits indicate a response faster than the sensor should produce.

## The sequence is the evidence

A temperature may remain within a broad range while changing too abruptly between samples. A normal present-time reading therefore cannot disprove the recorded event. Preserve the preceding stable value, abrupt step and subsequent recovery whenever the diagnostic record supports them.

The row requires an enabled diagnostic and excludes listed head-metal erratic and high/low circuit-fault states. It uses five seconds of failure in a six-second window, continuous sampling and Type A, one-trip reporting.

## Unresolved sensor mapping

Although the heading and explanatory prose concern cylinder-head temperature, the assignment line names the radiator temperature sensor. The continuation page provides constants for several physical inputs, but that conflict prevents selecting one as an unquestionably verified P017E calibration. This article deliberately omits a numeric time constant or temperature endpoint.

Use the actual vehicle's corrected service information to identify the channel and verify stable, plausible signal response during an enabled test. The source supports an erratic-signal explanation, not a specific sensor replacement or a conclusion that physical head temperature actually changed at that rate.

# U0076: GM identifies a powertrain sensor CAN bus-off fault

The generic title calls U0076 “Communication Bus D Off,” but this GM ECM row describes the powertrain sensor CAN bus, also called Bus S in its strategy. That naming difference matters: the document supports a specific sensor-network interpretation, not a universal assignment of Bus D to a particular harness.

## What the controller counts

The malfunction criterion is repeated bus-off activity, with at least 10 counts and a 100-millisecond window listed. Evaluation runs in a 12.5-millisecond loop. The row gives Type A, one-trip reporting.

The test assumes the CAN channel requests full communication and normal transmission is enabled. General conditions must have been met for at least three seconds. Its power-mode branches also consider run/crank voltage and impending shutdown, so communication observed during a key transition is not automatically an eligible test.

## Diagnostic consequences

Identify the sensor-bus topology for the actual vehicle before grouping the associated missing-device codes. A bus-off condition concerns the channel's operation; it does not tell which sensor, connection or controller initiated it. If several sensors become unavailable together, a shared network or supply dependency deserves investigation, but that remains diagnostic reasoning rather than a proven cause.

Verification should show normal communication across that sensor channel during eligible operation and no renewed bus-off result. The source supplies monitor logic, not connector pinouts or a component-replacement decision.

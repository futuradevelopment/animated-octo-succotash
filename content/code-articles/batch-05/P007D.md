# P007D: charge-air upstream temperature input has excessive resistance

P007D indicates an electrically high-range charge-air-cooler upstream air-temperature input in this GM ECM section. Its criterion is resistance above 311,274.31 Ω. That threshold describes the sensor circuit's electrical interpretation, not a maximum allowable charge-air temperature.

## Distinguish electrical range from thermal plausibility

A circuit can fail this resistance check without the controller having established any real overheating condition. Conversely, a sensor that remains electrically in range may still need a separate plausibility assessment. This code alone cannot diagnose the cooler's thermal performance.

The test is calibration-enabled, requires the engine not to be cranking and requires run/crank-relay voltage above 11 V. It accumulates 30 failures out of 38 samples in a 100-millisecond task, with Type B, two-trip reporting.

## Useful evidence

Identify the upstream air-temperature channel on the actual vehicle and preserve its raw range status. Compare an intermittent return to a believable reading with whether the electrical monitor completes successfully; those are not equivalent observations. The source does not locate an open connection or establish a failed sensing element from resistance alone.

Verification should demonstrate that the monitored resistance remains within the valid range through an eligible evaluation. Electrical checks need the vehicle-specific circuit and isolation procedure. Do not use the displayed threshold as a universal value for another coolant, manifold-air or downstream charge-air sensor.

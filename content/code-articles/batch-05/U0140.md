# U0140: body-controller messages have several timeout windows

U0140 describes missing body-control-module traffic received by the ECM in this source. It covers several messages rather than one universal “BCM offline” timer. For example, $0F1, $1E1, $1F1 and $451 have 500-millisecond limits; $12A and $139 use one second; $120 and $135 use ten seconds.

## Preserve the receiver's context

Those differing deadlines mean a brief interruption may affect some monitored information before other messages fail. Keep the reporting-module identity and any detailed failure record. An unrelated body function working normally does not demonstrate that every periodic message required by the ECM arrived.

The row lists Type C, one-trip, emissions-neutral reporting with no emissions MIL. Monitoring requires an enabled, fully communicating channel and the applicable bus-off code to be inactive. Its general conditions must be satisfied for at least three seconds, and power-state transitions influence eligibility.

## A focused diagnostic question

Ask whether the BCM became unavailable to multiple modules or whether only this receiver missed its required traffic. The answer helps select the vehicle-specific network investigation; it does not independently establish a wiring or controller failure.

After addressing a verified cause, check the relevant messages under the power conditions that originally produced the event. Erasing the history during a non-enabled state is not a successful monitor result. The source does not support replacing the BCM solely because its name appears in the code.

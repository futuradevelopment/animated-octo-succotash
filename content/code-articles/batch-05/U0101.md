# U0101: TCM message deadlines differ within one ECM monitor

U0101 means the documented ECM stopped receiving one or more expected transmission-controller messages. The table distinguishes messages by identifier rather than assigning one timeout to the entire TCM. For example, $3F5 has a 175-millisecond deadline; several other messages use 500 milliseconds, while $18A is allowed 10 seconds.

## Why one responsive module is not enough

A TCM can answer a scan request while a required periodic message is absent or late. Conversely, a larger bus problem may prevent the ECM receiving otherwise valid transmissions. The code describes the receiver's evidence and does not choose between those causes.

The enable rules require the corresponding bus-off fault to be inactive: U0073 for Bus A, U0074 for Bus B, or U0076 for the sensor bus. They also require full communication, enabled normal transmission and qualifying power conditions sustained for at least three seconds.

## Use the timing information

Preserve the event's power mode and the reporting module. A very brief dropout could affect the shortest-deadline message without satisfying a ten-second timeout; this is why the detailed failure record matters more than the generic label.

This ECM row lists Type A, one-trip reporting. A useful verification confirms the expected TCM traffic during an eligible operating state, not simply that the code can be erased. Vehicle-specific network and transmission service information remains necessary to locate the fault.

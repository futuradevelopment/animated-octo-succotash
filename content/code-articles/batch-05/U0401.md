# U0401: received engine messages fail integrity checks

U0401 is invalid engine-controller data, not simply an absent engine-controller message, in the cited brake-control strategy. The receiver checks rolling counters, protection values and validity information carried in messages it has actually received.

## Several checks share this code

For the electronic-shift braking request, the table checks whether the rolling count stays unchanged and whether the checksum matches. Similar checks cover hill-descent switch information and commanded axle torque. The displayed counter thresholds differ: some rows use 10 with a two-count step, while axle-torque rows use 25. These are monitor counters, not a blanket claim of ten failed network packets.

Evaluation requires ignition on, valid communication conditions and receipt of the relevant new message. The row lists continuous monitoring and Type B, two-trip reporting.

## Why this changes diagnosis

A controller that answers a scan does not prove the content of its periodic messages is usable. Conversely, replacing a network connection solely because the label says “communication” overlooks that this fault can concern received data integrity.

Preserve the reporting module and detailed invalid-data condition, then examine related source-module and network faults. Verification needs correctly updating counters and valid protected data during an enabled receiver evaluation. This summary supplies no basis to reprogram or replace an engine controller without vehicle-specific diagnosis, and the brake-controller context requires proper assessment of any braking warning.

# C053B: brake-coil supply feedback disagrees with its switch state

C053B covers several brake-coil supply checks on the cited page. The controller switches power to slip-control and base-brake coils, then evaluates whether the feedback follows the commanded safety-switch state. Feedback should be high with the relevant switch on and low with it off.

## Identify the failing supply path

The slip-control and base-brake paths have different feedback criteria. A single generic “ABS valves supply voltage” label cannot identify which branch failed. All four shown branches use 50-millisecond maturation and may be inhibited by listed upstream power or supply faults.

The slip-control switch-off row contains conflicting numeric wording: its threshold column and explanatory sentence give different values. This article deliberately does not present that disputed value as a testing specification. The source remains marked for review; the on/off feedback principle and branch distinction are still supported.

## What a diagnostic check should establish

Keep the full brake-controller failure subtype and the commanded switch state with the measured feedback record. A low feedback value with a switch deliberately off is different from low feedback when power was commanded on. That relationship is more informative than an isolated voltage.

Verification requires the applicable professional brake-system tests to pass for the identified supply branch. The table mentions switch or circuit-board problems as monitored possibilities, but does not establish which one occurred or justify replacing the brake unit without diagnosis. It provides no safe manual energizing procedure.

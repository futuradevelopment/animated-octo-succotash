# P020E: injector 5 pull-in current timing is outside the permitted range

P020E is a current-pulse timing monitor for injector 5, rather than a direct measurement of fuel-start crank angle. The source defines pull-in as the rise to 20 A at pulse start. The period must not be below 50 microseconds or above 90 microseconds.

## A valid pulse is required for the comparison

The calibration must enable the monitor, key must be on and battery voltage must exceed 11 V. Relevant injector-circuit, controller-status and boost-voltage faults are excluded. Hardware-reported dropped pulses are also excluded from this timing evaluation.

That distinction matters when an injection command is missing entirely: a missing pulse is different evidence from a pulse whose current reaches its target at the wrong time. The source provides a separate controlled reactivation path as part of the enable logic.

## Interpreting a repeat result

The monitor accumulates ten failures out of twenty engine-cycle samples and uses Type A, one-trip reporting. Preserve both the measured duration and whether it violated the low or high boundary. The table does not prove a specific injector or controller defect.

Verification should show acceptable injector-5 current-rise timing over an eligible evaluation. Smooth running or a cleared history is insufficient if the test has not run. Use the actual vehicle's professional electrical and fuel-system procedure; do not manually energize an injector from these monitor values.

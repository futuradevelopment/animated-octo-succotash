# P017D: head-temperature high-circuit interpretation needs source correction

P017D is titled Cylinder Head Temperature Sensor Circuit High in this GM table. The malfunction column describes resistance above a calibrated high limit, consistent with an electrical-range test. However, the same row's prose says short to ground and its sensor-assignment line names the radiator input, creating a genuine internal conflict.

## What remains supported

The row requires the diagnostic enabled and lists five seconds of failure within a six-second window, continuously sampled. Engine runtime above ten seconds or minimum intake-air temperature above −20°C is an additional condition. Reporting is Type A, one trip.

The page includes several high-resistance values for different mapped temperature sensors. Because the explicit assignment conflicts with the cylinder-head title, this article does not select one value as the verified P017D threshold. Guessing would risk applying a radiator specification to a head-temperature circuit.

## A useful diagnostic boundary

Treat the code as a reason to obtain the exact vehicle's cylinder-head-temperature high-circuit procedure and preserve the reporting module's full code details. “High” is an electrical-range description, not proof of physical cylinder-head overheating.

Verification must use the corrected input mapping and proper enabled monitor. A normal-looking temperature after clearing the code is insufficient. The article remains source-review flagged; it provides a supported monitor outline without inventing a resistance specification, component location or repair.

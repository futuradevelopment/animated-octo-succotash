# P00B3: radiator-temperature input resistance falls below its limit

P00B3 is a radiator-coolant-temperature electrical-range fault in the source's diesel L6 ATM–LZO section. The configurable input map assigns the radiator sensor to temperature sensor 3. Its low-resistance threshold is 41.1 Ω; the other resistances on the page belong to other mapped temperature inputs.

## Avoid using the wrong row value

This mapping matters because the same table also lists 48 Ω, 43.2 Ω and 9 Ω for different channels. Selecting the first resistance on the page would misstate the documented radiator criterion. The source describes the fault as a short-to-ground condition in the signal circuit or sensor, but the monitor cannot by itself locate that condition.

Failure must occupy five seconds within a six-second window. The diagnostic must be enabled and is continuously sampled, with Type B, two-trip reporting.

## Interpreting a low circuit result

“Circuit low” describes electrical range; it is not evidence that radiator coolant is too cold. Preserve the input's raw electrical status and the exact sensor assignment before connecting the result to a thermal complaint.

Verification should demonstrate a valid radiator input for a complete eligible monitoring window. A short-lived normal reading after a restart does not establish that the fault is resolved. Use the vehicle-specific circuit-isolation procedure for electrical checks; the table's internal resistance limit is not permission to test resistance on a powered circuit.

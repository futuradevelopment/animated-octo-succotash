# P00B4: radiator-temperature input resistance exceeds its range

P00B4 monitors excessive resistance of the radiator-coolant-temperature input in the diesel L6 ATM–LZO section. The source maps this input to temperature sensor 3, whose high threshold is 354,667 Ω. Other sensor thresholds printed alongside it should not be applied to the radiator channel.

## Conditions and meaning

The description associates the result with a short toward high voltage or an open in the sensor or signal circuit. It does not identify which connection or component caused that electrical pattern. Nor does “circuit high” establish that coolant temperature is physically high.

The diagnostic must be enabled. The additional condition is engine run time above ten seconds or minimum intake-air temperature above −20°C. Failure is five seconds in a six-second window, continuously sampled, with Type B, two-trip reporting.

## What changes the next check

Preserve whether the input was out of range continuously or returned to normal intermittently. Also confirm that a proposed test uses the radiator channel's mapping; the page's 235,000-Ω and 364,600-Ω values refer to other inputs.

A useful verification confirms acceptable electrical range during an eligible monitoring interval, including the runtime or temperature gate. A plausible displayed temperature before that gate is met is incomplete evidence. The source provides no universal connector location or replacement rule and should be paired with the vehicle's circuit-testing procedure.

# U0121: the TCM loses ABS-controller messages

This U0121 entry is in GM's transmission-controller section. The TCM checks for messages from the anti-lock brake controller, identified in the description as a non-OBD module. The listed identifiers $0C1, $0C5, $1E9, $1FC, $22A and $2F9 each have a greater-than-ten-second absence criterion.

## The reporting module matters

These are the TCM's deadlines. They should not be substituted for the timeout used by an engine or brake controller with a similar code. A recipient-specific record may reflect missing information needed by that recipient without demonstrating that every function of the transmitting module stopped.

The monitor requires full communication, normal transmission and appropriate power conditions for at least three seconds. It excludes the relevant bus-off code for the channel carrying the message. The table describes the diagnostic as emissions-neutral Type C.

## Interpreting the network evidence

Review whether the ABS controller is accessible and whether other recipients also report losing it. Widespread loss and a timeout isolated to the TCM suggest different investigation paths, although neither observation alone proves a failed part. Preserve timing and related power/network faults before drawing that distinction.

Verification means expected ABS messages return during an enabled TCM evaluation. Do not treat clearing U0121 as proof of brake-system readiness. Brake warnings or abnormal behavior require vehicle-specific professional checks; the communication summary cannot confirm that anti-lock or base braking functions are operating normally.

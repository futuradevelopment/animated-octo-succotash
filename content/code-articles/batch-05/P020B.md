# P020B: cylinder 2 injection timing refers to driver pull-in duration

P020B measures injector 2's current-rise behavior in this documented implementation. The hardware reports the pull-in period: the time needed to reach 20 A at the beginning of an injection pulse. Less than 50 microseconds or more than 90 microseconds is the failure criterion.

## Read the generic title carefully

The code name does not, in this source, identify an advanced or retarded fuel-start angle. It identifies an electrical timing result. The table allows either injector or ECU faults to cause it, so a component replacement cannot be selected solely from the name.

Evaluation requires key on, battery voltage above 11 V and a calibration-enabled monitor. Injector electrical, controller-status and boost-voltage fault restrictions apply. A dropped pulse is excluded; an appropriate application request or enabled reactivation path supplies the evaluated pulse.

## The sample unit matters

The ECM uses ten failures within twenty samples, one sample per engine cycle. That is not a fixed twenty-millisecond window; elapsed time depends on engine operation. Reporting is Type A, one trip.

Preserve the measured pull-in duration and its direction of error. Verification requires valid injector-2 pulse timing under enabled conditions, not merely evidence that the circuit is no longer open. Vehicle-specific professional driver testing is necessary before identifying the injector, circuit or ECU as the cause.

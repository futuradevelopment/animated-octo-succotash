# U0671: sensor B fuel-temperature communication needs polarity confirmation

U0671 identifies fuel-temperature sensor B in the cited ECM table. The controller evaluates SENT pulse traffic, with four or fewer pulses forming part of the failure criterion. The code describes lost usable communication rather than proving that fuel temperature itself is excessive or implausible.

## Read this source cautiously

The row contains a polarity conflict: its opening description says the signal is shorted low, while the criterion and subsequent explanation identify a continuously High line state. The supported article therefore retains the communication meaning without selecting a short-to-ground or short-to-supply repair path.

The table requires 400 failing samples out of 500, sampled at 6.25 milliseconds each, with the communication diagnostic enabled. It also restricts evaluation around code-clear/device-control activity and lists Type A, one-trip reporting.

## What to preserve

Keep sensor B's identity separate from sensor A when reviewing the failure record. Whether only B loses pulses or both channels lose information can alter the investigation, but the actual circuit relationship must come from the vehicle's service information. This table does not prove a shared housing, supply or connector.

An appropriate retest demonstrates valid sensor B messages over an eligible monitoring interval. A currently believable fuel-temperature display does not establish that pulse loss has stopped. Source review remains necessary for the conflicting electrical-state wording before using it as a circuit-testing specification.

[GM 03A, PDF page 750](https://gsi.ext.gm.com/gmspo/mode6/pdf/2025/25OBDG03A.pdf#page=750). This explanation covers the documented 2025 monitor. Confirm the vehicle's module, engine and calibration before applying these criteria; the document's vehicle list does not establish this code's applicability to every listed model.

# P017C: the cylinder-head metal-temperature input is electrically low

P017C monitors the cylinder-head metal-temperature input in the explicitly labeled diesel L6 ATM–LZO section. The table maps Engine Metal Head Temperature to physical sensor 8. For that channel, the low-resistance threshold is 9 Ω.

## Channel mapping is essential

The page also lists thresholds for coolant and radiator sensors. Those values belong to different physical inputs; the first listed 48-Ω value is not the head-metal criterion. Confirming the mapping avoids a materially wrong electrical interpretation.

The source describes short-to-ground coverage in the sensor or signal circuit. Failure requires five seconds within a six-second window, with the diagnostic enabled and continuous sampling. This head-temperature implementation lists Type A, one-trip reporting.

## Distinguish an electrical fault from engine temperature

The code concerns resistance outside range. It does not prove the cylinder head is cold, hot or physically damaged. A scan temperature derived from an invalid electrical input should not be treated as an independent thermal measurement.

Preserve the raw circuit status and the identity of the head-metal input, then use the vehicle-specific isolation procedure to determine the cause. Verification should demonstrate valid resistance throughout an eligible window. A replacement decision cannot be made from the code alone, and the table's internal limit is not an instruction to measure resistance on an energized sensor circuit.

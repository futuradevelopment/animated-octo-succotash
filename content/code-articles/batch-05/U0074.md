# U0074: Bus B off events require channel-specific interpretation

U0074 is the Bus B off monitor in this GM ECM document. Its criterion is repeated bus-off activity: the row lists at least 10 counts in a 100-millisecond window. The monitor executes in a 12.5-millisecond loop and uses Type B, two-trip reporting.

## Keep Bus B separate from a module timeout

The letter identifies the channel monitored by this implementation. It is not a component location and cannot be used to select a wire without the vehicle's network information. A controller missing from a scan may be a consequence of the communication state; U0074 alone does not prove that controller has failed.

The enable logic also matters when an event occurs around starting or shutdown. It considers communication state, supply voltage, run/crank conditions and the accessory-to-off transition. Those branches explain why an apparently similar voltage dip or key transition may not produce the same diagnostic outcome.

## A useful retest

Record which module stored U0074 and whether other faults concern recipients on Bus B. Review any Bus B lost-message monitor in that context, because the cited GM communication strategy can inhibit individual timeouts when the corresponding bus-off code is active.

After a supported repair, assess communication across the affected channel through the operating state that produced the event. One successful connection and an erased fault history are weaker evidence than an eligible monitor completing without new bus-off accumulation.

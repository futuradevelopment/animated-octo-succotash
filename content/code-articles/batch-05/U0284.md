# U0284: grille-shutter module A stops answering on LIN

U0284 monitors communication with active grille-shutter module A, not the shutter's physical position. The GM ECM expects the ACM1Rsp_31_C02 response on LIN. The listed malfunction criterion is no response for at least 1,250 milliseconds.

## Check the communication prerequisites

The slave must be calibrated as present, the LIN module initialized and the LIN channel enabled. The row also includes actuator or powertrain-relay conditions and excludes an impending accessory-to-off transition through its general enable logic. These details matter when a shutter is unpowered by design or the vehicle is changing power modes.

This implementation evaluates LIN communication in a 500-millisecond loop and lists Type B, two-trip reporting. The message timeout and the software loop period describe different parts of the monitor; they should not be substituted for one another.

## What the code cannot establish

A shutter that appears closed is not proof of this communication failure, and a shutter that moves once does not prove uninterrupted responses. Preserve whether the module was reachable and powered when the fault occurred. Use the vehicle-specific LIN and power-distribution information to investigate the missing response.

A meaningful verification confirms repeated valid replies during an enabled interval, then separately checks shutter operation if a performance concern exists. The cited communication row provides no mechanical jam test or basis for replacing the entire shutter assembly from this code alone.

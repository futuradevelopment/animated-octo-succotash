# U0129: the ECM misses brake-system control messages

U0129 records lost communication with the brake-system control module in this GM ECM table. Its message deadlines vary considerably. Messages $0C1 and $0C5 use more than 500 milliseconds, $214 and $22A use more than one second, and $17D and $1FC use more than ten seconds.

## What the range of deadlines means

The code is not a timer proving the whole brake controller was offline for one fixed period. A shorter interruption can affect a faster message first. Preserve the reporting-module information and available failure details before treating all U0129 occurrences as identical.

The monitor runs only with full communication requested, normal transmission enabled and appropriate power conditions. The corresponding bus-off fault must be inactive, and general enabling conditions must persist for at least three seconds. This implementation uses Type A, one-trip reporting.

## Interpreting a brake communication complaint

Compare brake-controller accessibility with what other modules report receiving. A controller that responds to diagnostics may still be missing a required periodic message. Loss reported by several recipients points toward shared dependencies worth investigating, but is not proof that the brake controller needs replacement.

Verification requires restored required traffic during an eligible ECM evaluation. It also requires the applicable brake-system checks when braking warnings or abnormal operation are present. A communication code by itself cannot establish the mechanical or electronic braking system's condition, and this table supplies no brake repair procedure.

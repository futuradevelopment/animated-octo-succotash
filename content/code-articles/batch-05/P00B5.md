# P00B5: radiator-temperature changes faster than the sensor model permits

P00B5 is a rate-of-change plausibility monitor for radiator coolant temperature. The ECM calculates upper and lower limits for the next sample using the previous reading and the sensor's time constant. It fails when a positive or negative step crosses the respective calculated limit.

## A dynamic limit, not one temperature threshold

A reading can lie within the ordinary temperature range yet arrive too abruptly to be credible. Conversely, a large gradual temperature change is not necessarily the same failure. The sequence of samples is therefore essential evidence; one current temperature reading cannot reconstruct the event.

The source identifies the radiator input through its configurable sensor map. The diagnostic must be enabled, with the listed radiator high/low circuit fault and erratic-test status restrictions clear. It accumulates five seconds of failure in a six-second window and uses Type B, two-trip reporting.

## Diagnostic direction

Preserve a trace showing the abrupt change, previous stable value and any recovery. If a basic electrical-range fault is active, interpret that first because the erratic monitor's prerequisites are no longer equivalent to a clean enabled test.

Verification should show a realistic continuous signal while this monitor is allowed to run. The code does not independently prove coolant surging, a thermostat fault or a failed radiator. The applicable vehicle circuit and sensor procedure is needed to establish why the reported temperature jumped.

# U0100: the brake controller misses expected engine messages

U0100 has different details depending on the module that records it. The cited page is an electronic brake-control module table: it checks whether expected messages from the engine controller arrive within their allowed intervals. It does not directly test the engine controller's internal hardware.

## The timeout is message-dependent

Several engine-status and torque messages use a 0.25-second absence threshold. Engine General Status 4 uses 1.25 seconds, while Engine General Status 6 uses 0.50 seconds. These examples show why “the ECM disappeared for a quarter-second” is too narrow an explanation of every U0100 event in this row family.

The monitor requires ignition on and valid communication conditions, including no undervoltage and no error-passive condition. It operates continuously and lists Type B, two-trip reporting.

## What to establish next

Identify the reporting module before choosing a diagnostic procedure. A brake controller's missing engine message and an engine controller that cannot be contacted by any tool are different observations. Compare availability from other recipients and preserve associated network and power faults to determine whether the interruption is local or shared.

For verification, the relevant engine messages must arrive normally while the receiver's monitor is enabled. Merely starting the engine does not prove every required message is present. Because this implementation is in the brake system, braking warnings or abnormal brake behavior require the appropriate professional assessment; an engine communication code cannot establish brake-system safety.

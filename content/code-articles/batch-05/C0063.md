# C0063: yaw-rate data is invalid or uncorrelated

C0063 is a yaw-rate information fault in this documented high-performance IMU strategy. The EOCM3 monitor can fail because the yaw correlation status is Unknown or Not Correlated, or because primary or secondary yaw-rate data is determined invalid.

## Read the status alongside the number

A yaw value that appears reasonable does not establish that its protected status is valid. The source tests availability, communication state and failed-safety indications before interpreting the correlation or validity result. It does not supply a universal degrees-per-second disagreement threshold for this DTC.

The monitor runs continuously with common, signal and relevant communication enables active and the manufacturer's enable counter at zero. The source specifies disabling adaptive cruise and/or Super Cruise after detection, with safety-related emissions-neutral special Type C reporting.

## Diagnostic decisions

Separate a correlation failure from one channel's invalid-data flag. Also keep those cases separate from a loss-of-communication code: this monitor's enable logic explicitly accounts for communication faults. That distinction prevents treating every yaw-related warning as a simple missing sensor.

A meaningful verification shows both valid available yaw information and acceptable correlation when the monitor is enabled. Restoring driver-assistance operation may require further vehicle-specific checks. This document does not give a mounting-angle adjustment, road maneuver or sensor calibration procedure, so those actions should follow the applicable professional service information rather than the code name alone.

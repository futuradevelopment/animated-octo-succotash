# P0181: fuel-filter temperature drifts away from its reference

P0181 checks fuel-temperature sensor A for offset or drift in this GM section. The source identifies the measured input as fuel-filter temperature and evaluates its average absolute difference from a reference temperature. The listed disagreement threshold is 30°C.

## Cold-soak comparison, not fuel overheating

The engine-off time must exceed 28,800 seconds and the time since engine rotation begins must be below three seconds. The test collects twenty samples at 100 milliseconds each. It also requires usable serial data, a valid engine-off timer and no relevant temperature or communication faults.

The fuel-filter heater must be off. A separate reference selection applies when the fuel-fired heater has been active, so the code cannot be reduced to one assumed reference sensor on every event. That heater context matters when temperatures have not equalized as expected.

## Diagnostic evidence

Preserve the reference identity, fuel-filter temperature and heater history from the eligible start. A disagreement with a bad reference is not equivalent to a verified fault in sensor A; the monitor's reference-fault restrictions reflect that dependency.

This implementation uses Type B, two-trip reporting. Verification requires a completed qualifying soak comparison with valid inputs, not merely a normal warm fuel temperature. The source does not establish a specific sensor location beyond its fuel-filter role or identify a replacement part from the DTC alone.

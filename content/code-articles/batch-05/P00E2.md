# P00E2: cooler coolant-temperature signal violates its response model

P00E2 detects intermittent or erratic charge-air-cooler inlet-water temperature information. The ECM computes allowable next-sample limits from the last good reading, sensor-range endpoints and response filtering. A temperature excursion beyond those calculated limits can fail the monitor.

## The printed endpoints are not the whole test

The table lists 150°C and −60°C alongside the algorithm, but the actual explanation uses dynamic upper and lower thresholds. Treating P00E2 as only “above 150°C or below −60°C” would omit the dependence on the previous valid sample and consecutive failures.

The engine must not be cranking, run/crank-relay voltage must exceed 11 V and the coolant-temperature input must have no electrical fault. The monitor requires 60 failures in 75 samples in a 100-millisecond task and uses Type B, two-trip reporting.

## What to capture

A time trace showing sudden jumps and the last stable value is more useful than a lone post-event reading. Keep electrical-range codes in context: an active circuit fault changes eligibility of this separate erratic-signal test.

Verification means the coolant signal follows an acceptable response through an enabled interval. It does not require guessing a physical coolant-temperature limit or replacing a pump from the code alone. Any cooling-performance complaint should be evaluated separately with the actual vehicle's professional cooling-system and circuit procedures.

# P0184: fuel-temperature sensor A changes implausibly quickly

P0184 is an intermittent fuel-temperature-signal monitor. The ECM compares a new reading with limits that depend on the last good sample and the number of consecutive bad samples. The source's formulas use 156°C and −56°C as range references, rather than treating them as the only possible failure temperatures.

## The recent signal history matters

A sudden excursion can be unacceptable before reaching either endpoint because the dynamic limit retains information about the preceding valid temperature. Preserve the trace around the fault, including how quickly the signal returned; a normal reading after recovery cannot establish that the monitor passed.

The row requires at least one valid serial value, the sensor-bus relay commanded on and the listed circuit, relay and communication faults inactive. It displays several voltage prerequisites associated with the architecture; these should not be collapsed into one universal supply rule.

## Retesting the correct condition

Failure requires ten failing samples out of fifteen at 100 milliseconds per sample, with Type B, two-trip reporting. A basic circuit fault or unavailable serial data can change whether this erratic-signal test is meaningful.

Verification should show plausible temperature evolution while all relevant prerequisites are satisfied. This monitor does not diagnose fuel overheating, contamination or injector performance. Use the vehicle's actual fuel-temperature circuit and communication procedure to identify the cause rather than replacing a sensor because the current reading briefly looks abnormal.

# P2840: Volkswagen’s fourth/sixth shift-fork feedback is absent

The DQ381 0GC table maps shift fork D to the 4–6 gear-shift module. Volkswagen gives P2840 a no-signal criterion lasting more than one second. The fault therefore identifies unavailable position feedback for that channel, rather than establishing a transmission-wide loss of all sensor information.

## Retain the exact circuit classification

The related P2841 entry addresses a signal outside its expected duty-cycle or period range. P2840 instead concerns signal absence. A reported fixed position should not be assumed to be a valid live measurement when the controller has recorded missing feedback.

The source lists continuous monitoring, a two-second monitoring-time entry and two driving cycles for MIL illumination. It does not give a connector pin, sensor resistance or direct test-voltage specification for this row.

## The fourth/sixth mapping guides the investigation

A technician should use the actual 0GC service information to connect the lettered channel to its wiring and mechanism. Other shift-fork codes have different gear-pair mappings. Evidence from one module cannot simply stand in for the missing D-channel signal.

The table also separates incorrect neutral indication and a stuck/disengagement timeout from this position-circuit fault. That distinction prevents an unsupported conclusion that the fork is mechanically jammed merely because its feedback disappeared. Verification requires restored, credible D-channel information through the appropriate checks. Clearing memory or successfully selecting a gear outside this pair does not establish that P2840’s monitor has passed.

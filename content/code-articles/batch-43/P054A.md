# P054A: Audi cold-start cam timing exceeds its target difference

P054A identifies a cold-start exhaust-cam timing condition. In Audi’s CEUA/CGTA 4.0L reference chapter, the listed criterion is a difference between target and actual camshaft position greater than eight degrees of crank angle. The catalog’s bank-1 designation identifies the affected side; it does not make this numerical limit universal.

## Cold-start timing is a particular observation

The monitor compares a commanded position with the measured response. A comparison between two measured cam positions is not the same quantity, and an ignition-timing value is not a substitute for either camshaft value. The specified unit is crank angle, which should not be silently relabeled as camshaft angle.

The cold-start context also matters when reviewing a vehicle that appears normal after warm-up. A later response does not reproduce the original conditions simply because the engine is running and no warning is presently displayed. The source does not provide a temperature window, a persistence time, or an exact enable sequence for this summary row.

## Calibration limits are not interchangeable

Audi’s CEJA W12 chapter lists a different target-difference range, greater than 10–22 degrees, for the same code family. That difference is a concrete reason to identify the engine before applying a numerical boundary. It is not evidence that the two engines share a repair procedure.

The chart does not choose between hydraulic control, mechanical timing and signal problems. Diagnosis needs the corresponding service procedure and the original operating data. Verification should address the cold-start target-versus-actual relationship, rather than relying solely on a satisfactory warm idle or on erasing the stored DTC.

# P047D: Audi exhaust-pressure sensor B exceeds the high signal boundary

P047D appears in Audi’s CBEA TDI diagnostic chart when exhaust-pressure sensor B has a signal above 4.9 V. The word “high” describes the electrical input in this entry. It does not translate directly into a measured exhaust restriction or a pressure value.

## What the 4.9 V figure can establish

The criterion identifies the upper end of the monitored signal. It is useful only after the correct sensor channel and engine application have been established. A pressure reading from another channel, or a voltage specification borrowed from a different engine, cannot confirm or disprove this particular monitor.

Audi separately assigns P047C to a sensor-B signal below 0.2 V. Having distinct low and high entries is a practical reason to retain the exact DTC rather than summarizing both as an exhaust-pressure fault. Opposite electrical conditions can lead to different diagnostic branches even when the component name is identical.

## Do not turn a boundary into a replacement instruction

The reference chart does not identify which wiring defect, supply problem, or internal sensor fault produced the high input. It also provides no voltage-to-pressure conversion, allowable duration, or connector-level test for this row. Those missing details should not be filled with a generic instruction to replace a pressure sensor.

A professional evaluation should reconcile the recorded code with the correct circuit description and available operating data. If the signal is now plausible, the earlier high reading still needs an explanation. Successful verification concerns the circuit behavior under the applicable conditions; clearing the stored record alone does not demonstrate that the high-limit event has been resolved.

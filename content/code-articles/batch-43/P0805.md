# P0805: Volkswagen assesses clutch-position feedback as a PWM signal

Volkswagen’s 2015 Jetta CNLA transmission table describes P0805 as an incorrect PWM input from clutch-position sensor A. The listed lower duty-cycle boundary is 7.5 percent and the upper boundary is 92.5 percent. The criterion concerns the encoded electrical signal, not a clutch travel distance in millimeters.

## Duty cycle is not actuator position by itself

The table does not publish a conversion from the PWM percentage to physical clutch movement. It would therefore be unsupported to call 7.5 percent fully open or 92.5 percent fully closed. Those values are signal-range boundaries in this monitor.

The enabling information requires the common high-side switches for the relevant gearbox subsystems to be on, their output voltages above 9 V and TCU supply below 16 V. Those supply prerequisites matter before an abnormal signal is attributed to the position-sensing element itself.

## Distinguish a malformed input from a missing one

The adjacent P0809 entry describes sensor-element signal failure with no signal. P0805 is the range-check category. A technician should retain the exact code and evaluate the appropriate PWM evidence rather than treat both as a confirmed open wire.

The source lists 100 milliseconds of monitoring, continuous checks and two driving cycles for MIL operation. It gives no connector assignment or immediate component-replacement decision. Verification should establish a valid position signal and the required supply conditions through the matching DQ200 procedure; a normal gear selection alone does not demonstrate that the clutch-position signal monitor has passed.

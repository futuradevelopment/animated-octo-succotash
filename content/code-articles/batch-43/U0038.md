# U0038: Audi distinguishes internal CAN silence from a single missing module

Audi’s CHJA hybrid table calls U0038 an internal master/slave CAN communication check and describes a global timeout with no message received. The catalog labels the code as vehicle communication bus B performance. The source’s internal-link context is important before that general title is applied to the vehicle’s external diagnostic network.

## Determine the extent of the missing communication

The same section lists a separate missing-message entry for battery energy management and another for implausible battery-controller data. U0038’s global-timeout wording is therefore different from evidence that one named module sent an invalid value. A useful scan record preserves that difference instead of reducing every network DTC to “CAN fault.”

“Global” in this row refers to the source’s identified communication check. It does not establish that every network in the car has stopped working, or that the diagnostic connector itself is inoperative. Successful communication with an unrelated controller would not necessarily settle an internal master/slave link problem.

## Do not infer a repair from the timeout label

The quick-reference chart supplies no timeout duration, message identifier, termination-resistance specification or controller-replacement branch. The exact reporting module and matching service information are needed to determine which communication path is being monitored and how it can be evaluated.

Verification should demonstrate restored operation of that path under the applicable conditions and reconcile any companion faults. Clearing U0038 while the vehicle temporarily communicates does not explain the original event. This interpretation gives the timeout its proper scope without assigning an unsupported wiring location or treating a broad bus label as proof of a failed hybrid battery controller.

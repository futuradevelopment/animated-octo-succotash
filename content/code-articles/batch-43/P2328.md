# P2328: Audi evaluates coil-J primary control voltage against a ranged threshold

The CEJA W12 reference associates P2328 with ignition coil J primary control circuit high. Its printed signal-voltage criterion is greater than a threshold shown as 5.1 to 7.0 V. The source does not say which operating or calibration conditions select a value within that range.

## A range of thresholds is not a normal operating window

The two figures should not be presented as an acceptable control-voltage band. They belong to the malfunction criterion. The page also supplies no information about timing or the external point at which an equivalent signal could be checked.

The corresponding circuit-low entry, P2327, uses signal current above 24.0 mA. This difference is diagnostically useful: high and low descriptions do not mean the manufacturer simply compares one voltage to two boundaries. The relevant circuit behavior must be evaluated with the test matching the stored code.

## Retain the primary-control scope

P2328 does not publish a secondary ignition output limit or prove that a spark plug is defective. The letter J identifies a channel in the reference, while its physical location and terminals must be determined from the CEJA workshop information.

A technician should use that application-specific procedure to establish the monitored path and reconcile any companion faults. Verification needs evidence that the original high-control condition is resolved under suitable test conditions. An erased code or an observation from another coil cannot establish that coil J’s monitor has passed.

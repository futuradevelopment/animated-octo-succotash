# P2847: Volkswagen checks fifth/seventh fork position while neutral is expected

Volkswagen associates shift fork C with the 5–7 actuator in its DQ381-7A/F 0GC table. P2847 is the incorrect-neutral-position entry. The monitor detects the actuator leaving neutral by more than 3 mm when its nominal state is neutral.

## Keep the neutral requirement attached to the distance

The distance threshold is meaningful because the control system expects neutral. It should not be used as a general limit on fork travel during normal engagement. Nor is it a workshop instruction to adjust the mechanism to a three-millimeter clearance.

The table lists continuous monitoring with a two-second monitoring time and MIL operation after two driving cycles. It does not supply a physical reference point for an external measurement, so a technician must use the appropriate position-data and mechanical procedure for the actual 0GC application.

## Compare related C-channel classifications

P283B concerns missing position feedback, whereas P284B concerns a timeout during disengagement. P2847 requires a different interpretation: the neutral-state position is wrong. The presence of a named fork does not automatically establish whether the feedback, actuator control or mechanism is responsible.

Professional diagnosis should reconcile the recorded state with credible C-channel position information before selecting a repair. Verification must show the expected fifth/seventh actuator position while neutral is nominal, using the prescribed checks. A clean scan immediately after clearing memory or successful movement of another fork does not address this particular neutral-position disagreement.

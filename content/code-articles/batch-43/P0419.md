# P0419: Audi W12 secondary-air control B has a distinct voltage monitor

Audi’s CEJA W12 reference chart places P0419 at the secondary-air system control B circuit and lists a signal-voltage interval of 4.70–5.40 V. The source does not identify that value as the supply voltage of the air pump itself. Treating it as a pump-power test would therefore add a claim the chart does not make.

## The fault concerns a control circuit

The same engine chapter contains separate low and high entries for control B. P2259 uses a low signal-voltage interval, whereas P2260 uses a current-based criterion. These neighboring records show why matching only the words “secondary air” is insufficient: the electrical quantity and the fault category must also agree.

For P0419, the chart’s narrow voltage interval is a monitor criterion, not a general statement that every secondary-air wire should measure approximately five volts. The correct circuit drawing and diagnostic procedure are needed to establish where and under what state the controller evaluates that signal.

## Avoid a system-wide conclusion from one row

The code alone does not establish low air delivery, a seized pump, a leaking valve, or a blocked passage. None of those causes is ranked or confirmed in this reference entry. A professional investigation should retain the precise control-B identity and the operating circumstances in which the fault was stored.

The book supplies no persistence time or component-replacement branch here. Verification must explain the original electrical condition using the matching W12 service information. Merely observing secondary-air operation on another occasion cannot establish that this specific control-circuit event has been corrected.

# P24D7: Audi distinguishes a low EVAP pressure signal from low tank pressure

In the Audi Q5 CHJA hybrid table, P24D7 is the low-circuit entry for EVAP pressure sensor/switch B. The controller’s listed electrical criterion is below 0.20 V. That value should not be described as “low tank pressure,” because the table does not give a voltage-to-pressure conversion for this row.

## The low-input branch needs the correct channel

The adjacent pressure-range entry uses kilopascals, while P24D7 uses volts. Keeping those quantities separate prevents a low electrical input from being treated as proof of a specific vapor-system condition. The B designation is equally important; a normal reading from a differently identified pressure sensor would not settle this monitor.

The chart also gives the circuit’s upper signal entry a boundary above 4.88 V. Those opposite limits illustrate the need to preserve the exact stored code when planning circuit diagnosis. The source does not say that a voltage lying between the two values proves the sensor is accurate throughout its operating range.

## Check the event, not just the present display

A professional assessment should use the applicable circuit description to identify the signal, supply and reference information that belong to the installed system. This reference entry supplies no connector pin, detection duration or failed-component conclusion. An open-circuit, grounding or sensor diagnosis requires additional evidence from the proper procedure.

After a repair, verification must address the original low-signal event under the relevant conditions. An erased DTC or a plausible later pressure display alone does not explain why the input fell below its boundary. The row supports a focused electrical investigation without substituting a generic EVAP leak repair.

# P2789: Volkswagen records clutch-A adaptation reaching either limit

Volkswagen’s 2015 Jetta CNLA transmission table maps P2789 to clutch A, identified in the criterion as clutch 1. The monitor checks adaptation results and records the adaptation reaching an upper or lower limit. Its listed frequency condition is twelve occurrences within 300 seconds.

## A limit result is not a direct wear measurement

The source does not publish the numerical adaptation endpoints or identify the physical quantity represented by each limit. Reaching a limit therefore should not be translated into a particular lining thickness, clutch travel or remaining service life. The table provides a control-learning result, not a component wear measurement.

Both upper and lower limits are included. A generic scan description saying only “adaptation at limit” may conceal which direction occurred, so the appropriate application data should be retained before drawing conclusions.

## Supply and control prerequisites still matter

The enabling conditions require gearbox subsystem 1’s common high-side switch on, output voltage above 9 V and TCU supply below 16 V. The source lists continuous checking and MIL operation after two driving cycles. Those conditions distinguish the recorded adaptation result from an arbitrary stored value read with the system inactive.

A qualified technician needs the matching DQ200 procedure to explain the limit events and determine any required repair or learning operation. The code is not, by itself, an instruction to erase adaptations. Verification should demonstrate acceptable learning results under the prescribed conditions and address the original repeated-limit event, rather than simply reset the memory and assume the underlying cause has disappeared.

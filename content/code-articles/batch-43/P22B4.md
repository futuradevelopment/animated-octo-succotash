# P22B4: Toyota’s downstream negative-control high fault uses a 4.59 V boundary

Toyota’s P22B212, mapped explicitly to SAE P22B4, concerns the negative-control terminal of air-fuel ratio sensor 2. The manufacturer describes a short-to-battery category when A1B- exceeds 4.59 V for at least five seconds. The fault uses two-trip detection logic.

## Do not confuse sensor position with signal polarity

Sensor 2 is the downstream sensor, farther from the engine. “Negative current control” identifies the A1B- channel; it does not indicate a second bank or a requirement for a negative terminal voltage. Toyota expressly notes that these O2-labeled DTCs relate to an air-fuel ratio sensor.

The positive-control high code P22AD has different voltage and correlation criteria. Applying its 6.135 V A1B+ limit to P22B4 would evaluate the wrong channel. The negative-control high monitor also has its own enabling exclusions for competing sensor faults.

## Diagnose the electrical path, then confirm the monitor

The procedure first checks connector seating and harness-side signal voltages with the sensor disconnected. Both individual terminal biases and their separation are relevant. If those results are abnormal, the harness is evaluated for continuity and unintended connections before the ECM decision branch.

These tests distinguish possible circuit locations rather than assuming the sensor is the only cause. After repair, the confirmation sequence includes engine operation, pending-DTC review and All Readiness for P22B212. A completed normal judgment provides stronger evidence than a code-free scan immediately after clearing memory, particularly if the enabling conditions were never met.

# U0112: Audi’s hybrid controller reports a missing battery-management message

Audi’s CHJA hybrid reference describes U0112 as a CAN communication entry for the battery energy control module: the expected message is not received. The broader catalog includes a module-B qualifier, but this source row does not identify a separate B unit. That naming detail remains flagged rather than being converted into a physical module location.

## Missing data differs from invalid data

The neighboring U0413 row concerns an implausible message from battery management. U0112 describes absence instead. A scanner can therefore show a communication problem without proving that a present battery value is wrong; the two codes describe different evidence and should lead to different diagnostic questions.

The reference does not give a timeout, message identifier or receiving-controller test sequence. It also does not establish that the battery controller has failed internally. Communication availability depends on the actual network and power arrangement, which must be identified from the matching vehicle documentation.

## Preserve which controller could not receive the message

A useful scan record includes the module reporting U0112, other communication faults and the system state when they occurred. The ability to communicate with one module later does not establish that the required message was present during the recorded event. Conversely, the generic code title alone cannot identify which wire or controller to replace.

Verification should demonstrate restored communication under the applicable service conditions. Because this is a hybrid battery-management context, opening the pack or probing high-voltage equipment is not a logical first step from a missing-message row. The exact module identity and the unexplained B qualifier should be settled before a component-level conclusion is made.

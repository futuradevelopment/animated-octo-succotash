# P24D6: Audi checks EVAP pressure B against a broad plausibility window

Audi’s CHJA hybrid chart lists two pressure criteria for P24D6: above 149 kPa or below 11 kPa. This is the range/performance entry for EVAP pressure sensor/switch B. Unlike its neighboring electrical codes, this row expresses its criterion in pressure units.

## Do not confuse the reported pressure with an electrical threshold

P24D5 and P24D7 use signal-voltage boundaries for the same named sensor group. P24D6 instead asks whether the pressure value is within the stated range. A technician therefore needs to know which data item and unit the scan tool displays before comparing it with this table.

The source does not identify the pressure reference as gauge or absolute in this row. That omission matters: simply translating a dashboard or test-equipment reading into kilopascals does not ensure that the same quantity is being compared. The full application-specific procedure must settle the reference and the conditions in which the monitor runs.

## A range fault is not automatically a leak verdict

An implausible pressure value can guide the diagnostic investigation, but this summary does not establish a leak location, a stuck valve or a confirmed sensor failure. Nor does it specify a time limit, engine state or approved pressure-test setup. Those details should not be improvised from the two boundary values.

The useful next decision is to reconcile the code, the sensor-B channel and the correctly referenced pressure information. Verification needs valid readings under the manufacturer’s prescribed conditions and an explanation of the original out-of-range event. Clearing memory or passing an unrelated electrical check cannot, on its own, establish that the pressure plausibility problem is resolved.

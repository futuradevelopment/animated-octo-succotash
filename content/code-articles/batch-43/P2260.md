# P2260: Audi’s secondary-air circuit-high row uses current rather than voltage

For P2260, Audi’s CEJA W12 reference lists secondary-air injection control B circuit high and a signal-current band from 0.60 to 2.40 A. Although the title says “high,” the printed numerical quantity is current, not voltage. Rewriting the figures as volts would create a different diagnostic claim.

## Do not combine unlike monitor quantities

The paired circuit-low entry, P2259, specifies 0.0 to 3.26 V. Because one row uses amperes and the other volts, their endpoints do not define a single acceptable electrical range. The quick-reference document does not explain the sensing arrangement or the control state in which either criterion is applied.

Likewise, this current band is not a published specification for secondary-air pump delivery. The row addresses the control circuit; it supplies no air-mass target, pressure target or test that proves the emissions system is working correctly overall.

## Follow the correct control-B branch

The letter B is the source’s identifier. The page does not locate a relay or distinguish a particular physical bank for the reader. A qualified technician needs the matching CEJA wiring and diagnostic information to associate that label with a testable circuit.

The appropriate repair verification should reconcile the original high-circuit finding with correct electrical behavior under the prescribed conditions. Clearing P2260 or hearing the pump run at another time does not independently demonstrate that the controller’s current-based criterion has been resolved.

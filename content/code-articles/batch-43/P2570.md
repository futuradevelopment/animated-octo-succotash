# P2570: Audi’s radiator-identification signal remains at the high end

P2570 is listed in Audi’s A3 PZEV table as a radiator-identification sensor signal that is always high, with a criterion above 5.0 V. The source does not provide a persistence time for “always,” so the description should not be turned into an invented number of seconds.

## A high electrical value is not a temperature result

The generic title refers to the direct-ozone-reduction catalyst temperature-sensor circuit. Audi’s RIS terminology is supported by the related CBFA workshop description of G611, which sends radiator identification and temperature information over a LIN data connection. Neither source says that the high-voltage criterion directly establishes an overheated radiator.

The opposite RIS entry, P2569, has a signal boundary below 0.2 V. Retaining that distinction is useful when identifying the electrical branch under investigation. It does not establish that every value between those limits represents a valid temperature or a correctly identified radiator.

## Confirm which part of the information path failed

The Volkswagen CBFA supporting procedure separates power, ground and LIN wiring checks before reaching its component decision. The Audi quick-reference row does not identify the point at which its 5.0 V signal is evaluated. Consequently, that limit must not be treated as a ready-made external bus-wire test.

A qualified evaluation should use the correct PZEV application, the stored DTC and the actual vehicle’s wiring and diagnostic information. The related manual’s connector details are not automatically interchangeable across models. Verification needs valid identification and temperature information under the prescribed conditions; replacing a radiator solely because its name appears in the scan description would bypass the documented electrical investigation.

# P0361: Audi’s coil-K circuit monitor includes an internal-check alternative

In the CEJA W12 chapter, P0361 identifies ignition coil K’s primary/secondary circuit. Audi lists a signal-current threshold expressed as below 0.25 to 2.0 mA, followed by an alternative internal-check failure. The table does not reveal which branch a particular stored event used.

## Avoid treating the range as a fixed meter target

The lower and upper figures describe the source’s threshold range; they are not an instruction to find a current between those values at a disconnected coil. The reference omits the calibration conditions, measurement point and timing needed for an external comparison.

The primary/secondary wording is broader than the catalog’s primary-control/open title. Neither wording proves that coil K has an open winding. A controller’s internal check can produce the same DTC classification, and the summary does not identify the internal logic being evaluated.

## Keep coil-K evidence distinct

The engine has separate high and low primary-control entries for this lettered channel. Those rows use different quantities and thresholds; their existence does not authorize importing one of their criteria into P0361. The exact stored code determines which summary applies.

The vehicle-specific circuit diagram is needed to identify coil K and its connections. Qualified diagnosis should relate the recorded event to that channel, with verification through the applicable service checks. Substituting a generic ignition test or clearing the code without checking the original condition would not establish that this monitor has been satisfied.

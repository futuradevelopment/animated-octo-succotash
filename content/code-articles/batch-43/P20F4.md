# P20F4: Audi’s reductant-adaptation row needs its label conflict retained

The catalog labels P20F4 as reductant consumption too low. Audi’s Q7 CNRB reference instead labels its P20F4 row consumption too high and lists an SCR adaptation value of at least 1.79. The numerical criterion can be reported for that source, but the opposed direction labels should not be silently combined.

## An adaptation value is not a measured usage rate

The CNRB row gives an SCR adaptation quantity. It does not state liters per distance, a tank-level loss, or a dosing quantity measured directly at an injector. Converting 1.79 into a universal consumption rate would invent a unit and a calculation that the source does not provide.

A second original Audi reference, the CPNA chapter for the A8, uses the catalog’s low-consumption wording for P20F4 but a different adaptation threshold, greater than 2.50. This comparison exposes both an application-specific numerical difference and an unresolved wording conflict. It does not establish which description should replace the other across all vehicles.

## Resolve the application before changing dosing behavior

The practical next step is to identify the installed engine and obtain its current complete diagnostic definition. A technician should not increase or reduce dosing merely because one summary calls consumption high or low. The table does not supply such a repair instruction or isolate an injector, pump or sensor.

Verification requires the correct calibration’s adaptation criterion and supporting diagnostic evidence. This draft retains source review because the direction conflict matters to interpretation; a cleared code or a change in tank usage alone cannot resolve the conflicting descriptions.

# P047C: Audi exhaust-pressure sensor B reaches the low electrical limit

The CBEA diesel table identifies P047C as a low electrical signal from exhaust-pressure sensor B. Its listed boundary is below 0.2 V. That number belongs to the sensor circuit monitor; it is not an exhaust backpressure specification expressed in pressure units.

## Separate a low signal from a pressure diagnosis

A report of low voltage does not, by itself, establish that exhaust pressure is low. Converting the signal into a pressure conclusion would require the correct sensor characteristic and circuit information, neither of which this reference row supplies. Replacing an exhaust component on the assumption that the code measures insufficient backpressure would therefore skip the actual evidence.

The neighboring P047D entry watches the same named sensor at the opposite electrical boundary, above 4.9 V. This distinction helps a technician select the correct circuit branch and check whether the scan description agrees with the code that was actually recorded. The two limits are not interchangeable acceptance values for another pressure sensor.

## Keep the investigation within the documented application

Useful diagnostic records identify the engine, the reporting controller, and the sensor-B designation before comparing a measured or reported signal with this table. A plausible reading obtained later does not explain an earlier low-limit event; the operating circumstances and any related electrical faults still matter.

The quick-reference book provides no connector assignment, persistence time, or authorized jumper test here. Those details must come from the matching wiring and repair information. The supported conclusion is a low circuit signal requiring investigation, not a confirmed blocked exhaust, failed sensor, or completed repair.

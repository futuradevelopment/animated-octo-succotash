# P2836: Volkswagen’s second/reverse shift module has no position signal

In the DQ381 0GC transmission table, Volkswagen identifies shift fork B as the 2–R gear-shift module. P2836 uses a no-signal condition lasting more than one second. The mapping is important: this is the position-information channel for second and reverse, not a general vehicle-speed sensor fault.

## Do not turn missing feedback into a confirmed stuck fork

The table has separate functional codes for an incorrect neutral position and a disengagement timeout. P2836 reports the absence of the sensor information itself. Without that distinction, a technician could mistake an electrical-feedback problem for proven mechanical resistance.

The related range/performance code P2837 tests PWM duty cycle and oscillation period. Those are different observations from complete signal loss. Volkswagen lists continuous checking, a two-second monitoring entry and two driving cycles for MIL operation for P2836.

## Preserve the affected gear pair

The 2–R label is the source’s channel mapping; it does not supply a connector location or authorize a physical adjustment. Application-specific service information is required before accessing the mechatronic or shift mechanism.

A professional investigation should compare the recorded signal-loss event with the available position data and related faults, using the correct circuit checks. The table alone does not select a sensor, actuator or complete transmission for replacement. Verification should demonstrate reliable B-channel feedback under the prescribed conditions. The ability to move in a different gear is not sufficient evidence that the second/reverse position monitor has passed.

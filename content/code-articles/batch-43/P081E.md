# P081E: Volkswagen checks clutch-B slip while its drive state is active

Volkswagen maps P081E to the second drive-off clutch in its DQ381-7A/F 0GC table. The general description is excessive clutch B slippage. The published criterion is detected slip above 150 rpm while the clutch state is Drive.

## The clutch state qualifies the slip value

A speed difference during an intentionally open clutch state is not the condition described by this row. The technician needs the relevant commanded or reported clutch state together with the slip information. The threshold is a rotational-speed difference, not a pressure or wear measurement.

The paired clutch-A code P0811 has a separate channel identity. A satisfactory result for the first clutch cannot establish the behavior of clutch 2, even though the listed numerical threshold is the same.

## Slip detection does not identify the failed part

The table describes a rationality check and does not specify whether a particular event arose from friction capacity, control response, hydraulic behavior or unreliable speed information. Those distinctions require the matching 0GC diagnostic procedure. It is not a direct instruction to replace the clutch pack or perform an adaptation reset.

The monitor is listed as continuous, with two seconds of monitoring and two driving cycles for MIL illumination. Professional verification should establish credible speed data and acceptable clutch-2 response in the applicable Drive state. A smooth shift at one unrelated operating point or a code-free scan immediately after clearing memory does not demonstrate that the original slippage condition has been resolved.

# P2331: Audi’s coil-K high fault concerns a primary-control voltage threshold

Audi’s CEJA table classifies P2331 as ignition coil K primary control circuit high. Its signal-voltage criterion is shown as greater than 5.1 to 7.0 V. Because the summary presents a range, neither endpoint should be promoted to an unconditional limit for every vehicle state.

## Separate this voltage category from other coil-K entries

The related P2330 circuit-low code uses signal current above 24.0 mA. P0361 has a low-current or internal-check criterion. These are different monitor descriptions for the same lettered channel, not three equivalent tests of one numerical value.

Preserving those distinctions helps prevent a generic “coil K fault” diagnosis from losing the actual evidence recorded by the controller. The source does not identify which physical part has failed or provide a component-replacement decision for P2331.

## Use the correct control-circuit context

The reference gives no terminal assignment, threshold-selection rule or detection duration. A meaningful electrical comparison requires the matching CEJA circuit information and test conditions. The stated volts are part of the primary-control monitor, not a measurement of the coil’s secondary ignition output.

The channel letter also does not establish a physical cylinder position on this page. That identification must precede any professional test. Verification should show that the original high-voltage classification no longer occurs under the applicable checks, with related faults reconciled. A normal reading from a different coil or a cleared warning alone cannot establish that result.

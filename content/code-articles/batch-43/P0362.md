# P0362: Audi reports a coil-L circuit or internal-check failure

P0362 belongs to ignition coil L in Audi’s CEJA W12 reference. Its row gives two possible criteria: signal current below a threshold represented by 0.25 to 2.0 mA, or failure of an internal check. A useful interpretation preserves both possibilities instead of asserting that a wire is certainly open.

## An internal criterion is not a secondary-voltage measurement

The manufacturer calls this a primary/secondary circuit entry, but it does not publish a spark-voltage requirement. The milliamperes in the row concern signal current. They cannot be converted into a conclusion about spark strength, plug condition or a measured secondary waveform.

The threshold is shown as a range, with no selection rule or detection duration. Choosing either endpoint as the definitive limit for every CEJA operating condition would add information the source does not provide.

## Identify the lettered channel through the proper diagram

The reference does not map coil L to a physical position or connector terminal on this page. Matching workshop information is required before any circuit measurement. Related coil-L high and low codes are separate monitor categories, so a procedure for one should not be assumed to diagnose P0362 unchanged.

A professional investigation should determine which available evidence supports the circuit or internal-check path and verify the identified channel accordingly. Merely observing that the engine starts, or replacing an ignition part because it appears in the code title, does not explain the original recorded failure.

# P2768: Volkswagen detects a missing second input-shaft speed signal

Volkswagen identifies input/turbine speed sensor B as the shaft-2 speed channel in its DQ381 0GC table. For P2768, the rationality check records no signal for more than one second with ignition on. The general “intermittent” title should be interpreted through that specific missing-signal criterion.

## No signal and zero speed are different observations

The row does not say that every zero-rpm reading is a fault. A valid speed signal indicating a stationary shaft is conceptually different from the absence of the signal itself. The correct service data and measurement method are needed to establish which condition the controller recorded.

The related P2766 range/performance entry evaluates a reported shaft-2 speed above 12,000 rpm. That is another category entirely: an out-of-range value rather than missing information. Preserving the exact code prevents both events from being reduced to an unsupported sensor-replacement verdict.

## Use the source’s timing fields correctly

The no-signal threshold exceeds one second, while the separate monitoring-time column lists two seconds. Checks are continuous and MIL operation is listed after two driving cycles. The table does not explain a connector-level test or identify a physical wiring defect from this timing alone.

Professional diagnosis should establish the correct shaft-2 signal path and reconcile any companion speed or communication faults. Verification must demonstrate reliable feedback under the relevant conditions. A cleared code or plausible reading from the other input shaft cannot establish that this intermittent signal-loss monitor has passed.

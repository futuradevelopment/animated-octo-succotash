# P0211: Audi separates cylinder-11 injector logic faults from low-current faults

P0211 identifies the cylinder-11 injector circuit in Audi’s CEJA 6.3L W12 chapter. The chart calls its criterion an internal logic failure, without publishing a voltage, current or resistance threshold for this particular entry. That limited description supports a circuit-monitor explanation, not a claim that a measured injector winding is definitely open.

## Retain the distinction from P0291 and P0292

For the same cylinder, P0291 has a low-current boundary below 2.1 A. P0292 belongs to a different category: a low-side short to battery positive with current above 14.70 A. A scan report that reduces all three to “bad injector” discards useful information about which diagnostic classification the controller recorded.

The reference does not explain how its internal logic test relates in time to the two current monitors. It would be speculative to present P0211 as necessarily preceding either one, or to infer a fault progression from their code numbers.

## Use the exact circuit before deciding on a component

Cylinder 11 must be identified with the CEJA layout and appropriate connector information. The brief table does not establish which physical bank or terminal to probe, nor does it authorize a substitution test or fuel-system disassembly.

A technician should reconcile the stored circuit classification with the matching electrical procedure and any companion records. Successful verification needs evidence that the cylinder-11 circuit satisfies its applicable checks. Clearing the memory or replacing an injector without isolating the reported circuit condition would leave the original internal-monitor result unexplained.

# U0413: Audi receives battery-management data it cannot accept

U0413 appears in Audi’s CHJA hybrid reference as an implausible CAN message from the battery energy control module. The important distinction is that the row concerns the validity of received information. It does not describe the same event as the adjacent U0112 entry, where the expected message is absent.

## A communication path can exist while its data are unusable

Receiving a message does not establish that its contents satisfy the controller’s plausibility checks. On the other hand, this summary does not identify the rejected data field, a permissible value range, a message counter or a checksum rule. None of those details should be invented to make the code sound more specific than its source.

The catalog names battery energy control module B, while Audi’s row simply names the battery controller. The source does not locate or independently identify a B module. That unresolved qualifier is retained in the review status and should be resolved through the correct vehicle information before selecting a component.

## Investigate the sender and receiver relationship

A diagnostic record should distinguish which controller logged the invalid-data event from the controller whose information was being evaluated. Those roles are not necessarily the same. Relevant companion faults and the recorded system state can guide the applicable factory procedure, but the reference itself gives no replacement instruction.

A successful network connection or a clear fault memory is not complete verification of data plausibility. The required battery-management information must be received and accepted under the prescribed conditions. This interpretation does not justify opening the high-voltage battery or attributing the fault to a specific cell, sensor or controller without further evidence.

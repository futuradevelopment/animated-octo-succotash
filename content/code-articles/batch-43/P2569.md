# P2569: Audi’s PZEV radiator-identification temperature signal is low

The A3 PZEV reference table labels P2569 as a low radiator-identification sensor signal and gives a boundary below 0.2 V. The general catalog describes the direct-ozone-reduction catalyst temperature-sensor circuit. The related CBFA workshop procedure explains why radiator identification and temperature information belong together: G611 sends both kinds of information to the engine controller through LIN communication.

## Separate the sensor information from the network path

The numerical limit in the Audi DTC table should not automatically be applied to the external LIN wire. The summary does not identify the precise measurement point behind its RIS signal value. Meanwhile, the supporting Volkswagen procedure treats sensor supply, ground and the data connection as separate parts of the diagnosis.

That distinction prevents two shortcuts: assuming the radiator is actually cold because the signal is low, or deciding that any communication fault proves the temperature element has failed. A technician must establish the correct application and determine which information the controller is reporting.

## Use the matching vehicle procedure

The supporting CBFA procedure checks the electrical prerequisites and wiring before its component decision. It is evidence for a diagnostic sequence, not proof that the Volkswagen terminal numbers or replacement arrangement apply unchanged to an Audi A3. Those details remain vehicle-specific.

The source table also restricts this RIS entry to PZEV applications. A similar engine designation alone is insufficient to extend it to every emissions configuration. Verification should establish both credible RIS information and the required communication, using the actual vehicle’s repair information rather than treating an erased code as confirmation that the radiator-identification system is functioning.

# P0292: Audi’s cylinder-11 injector high fault is a low-side electrical event

For cylinder 11, Audi’s CEJA table assigns P0292 to the injector circuit-high category. The source describes a low-side short to battery positive and gives signal current above 14.70 A. This is a specific electrical classification, not a finding that the injector is supplying too much fuel.

## Interpret the terminology together

The word “low” within “low side” does not reverse the high-circuit diagnosis. It qualifies the control path named in the source. The separate circuit-low code, P0291, uses a current boundary below 2.1 A and represents a different recorded condition.

P0211 is different again: it describes the cylinder-11 circuit/open category through an internal logic failure. Keeping all three distinctions visible helps the technician select the relevant service branch instead of assuming every injector-related DTC calls for the same part.

## The summary is not an activation procedure

Audi’s quick-reference table gives neither output-stage terminal assignments nor a safe method for measuring the stated current. It does not instruct the reader to bridge the circuit or apply battery voltage to an injector. The exact CEJA diagnostic procedure is needed before electrical testing.

The useful repair question is which part of the identified circuit explains the controller’s high-fault assessment. Verification should answer that question with the appropriate circuit checks and operating conditions. An erased DTC, an injector swap or a brief normal idle would not by itself establish that the low-side fault has been resolved.

# P054C: Audi separates the bank-2 cold-start timing event

For P054C, the generic designation points to bank-2 exhaust-cam timing that is too advanced during cold start. Audi’s CEUA/CGTA table describes the monitored comparison as target position versus actual position and lists a difference greater than eight crank-angle degrees.

## Bank identity and monitor values serve different purposes

Bank 2 tells a technician which cam-control channel the code identifies. The eight-degree criterion describes the source’s comparison for that application. Neither detail supplies the engine’s physical bank location, connector arrangement, or timing alignment procedure. Those must come from the exact vehicle information.

The adjacent P054A row belongs to the corresponding bank-1 code. A fault on one bank should not be converted into a diagnosis of both banks solely because the monitor limits look alike. At the same time, any observed difference between the two channels can be useful evidence when interpreted through the applicable diagnostic procedure.

## Verify the correct cold-start case

The W12 section of the same reference book uses a greater-than-10–22-degree range for this family. Applying that range to the V8, or treating eight degrees as a universal repair limit, would mix distinct source applications. The summary also does not state how long the mismatch must persist.

An investigation should preserve the recorded cold-start conditions and distinguish commanded motion from actual cam response. The chart does not identify a particular failed actuator or mandate a timing-component replacement. A successful warm-engine check cannot by itself settle a fault defined around a different operating event; verification needs the matching cold-start monitor and service criteria.

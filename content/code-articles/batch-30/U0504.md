# U0504: Aviator gearshift data faults with multiple door-latch warnings

U0504 in the gearshift module can be a companion to a door-latch software problem on certain Lincoln Aviators. Ford SSM 55241 describes door-fault, transmission-not-in-park or hill-start-assistance messages with B1262:92 in multiple door-latch modules. U0504 may appear in the GSM as part of that same event.

## The receiving module is not automatically the failed part

The bulletin identifies software in the door-latch controllers as the possible source. A code recorded by the gearshift module does not therefore justify replacing the shifter without checking the door-module evidence. Preserve the entire scan, especially the number of latch modules reporting B1262:92 and the exact displayed messages.

The multiple-module condition matters. An isolated door that will not latch, a single unrelated body code or an actual inability to secure the vehicle does not automatically demonstrate the described software pattern. Those observations require assessment in their own right rather than being dismissed because U0504 is also stored.

## The update covers the specified door modules

Ford directs running software-update applications for door control modules E, F, G and H using FDRS. Updating only the GSM because it contains the communication entry would not follow the repair described in this message. The technician should verify the relevant software actions and then reassess the original warnings and functions.

Have the actual door-latch and park condition confirmed before relying on a warning disappearing. This article explains a qualified software case on 2025–2027 Aviator, not a method to override a latch or parking interlock. The source provides no universal circuit test or automatic replacement instruction for the gearshift module.

## Source and applicability

Ford SSM 55241, October 2026: 2025–2027 Lincoln Aviator with the described door or park-related messages and B1262:92 in multiple door-latch control modules.

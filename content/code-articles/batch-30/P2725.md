# P2725: solenoid E feedback error is accumulated and reset conditionally

P2725 is the electrical feedback-current diagnosis for the solenoid labelled SLB1 in this transmission table. The controller accumulates the difference between its target current and measured feedback. A code title mentioning solenoid E does not make the result a direct measurement of clutch pressure.

## The accumulator explains why one sample is insufficient

The error is added to a running total every ten milliseconds. The source clears that total when the detection window becomes invalid, when the error is within its specified small band or when the error changes sign. Persistent one-direction tracking error therefore differs from a momentary deviation that recovers or reverses.

The printed accumulator threshold should not be interpreted as an instantaneous current limit at the solenoid. Its meaning comes from repeated error samples and the reset rules, not from treating the total as a single electrical reading.

## Use the correct neighboring fault information

The page gives separate low- and high-circuit diagnoses for SLB1. Those faults affect the eligibility of this tracking check and use different criteria. Preserve the exact code set together with commanded current, feedback and operating state before selecting a test.

The source requires adequate ignition voltage, an enabled diagnostic state and no emergency mode. It supplies no universal wiring pinout, resistance specification or valve-body replacement order. A technician should use the exact transmission procedure, then verify that current follows the target during a valid evaluation and that any associated shift complaint is resolved.

# P0571: brake-switch plausibility is checked against vehicle movement

The cited transmission controller evaluates P0571 by comparing the brake-switch state with vehicle acceleration and deceleration events. The purpose is plausibility: a switch signal can exist electrically while reporting a state that does not fit repeated vehicle behavior.

## Two types of disagreement are monitored

One branch counts acceleration events while the switch reports on. The other counts deceleration events while it reports off. The table describes a threshold of ten relevant events. This event-based strategy is different from a simple fixed voltage measurement taken with the vehicle parked.

The monitor requires valid operating conditions, including powered components and a supply within the documented range. Output-speed faults also affect its ability to evaluate the relationship. A trustworthy movement signal is therefore part of the evidence, not an unrelated detail.

## A communication fault answers another question

The neighboring P0703 description checks the rolling count of the brake-switch network message. Missing messages or an unexpected counter concern communication integrity; P0571 concerns the meaning of the reported switch state relative to movement. Both should be interpreted before assuming that a switch replacement will resolve the complaint.

A technician should preserve the switch status, relevant vehicle-motion data and accompanying faults, then follow the exact transmission and brake-switch procedure. The table does not specify pedal adjustment or identify a failed stop-lamp component. Verification needs credible switch-state transitions and an enabled plausibility test. Deliberately creating unsafe braking or acceleration conditions to accumulate the event count is not an appropriate diagnostic shortcut.

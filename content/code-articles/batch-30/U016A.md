# U016A: a Transit self-test code on vehicles built without a TCU

U016A does not always mean a fitted module has failed. Ford SSM 54351 documents a configuration-specific example on 2026 Transit vehicles manufactured without a telematic control unit, or TCU. During a diagnostic self-test, these vehicles may record U016A in the secondary on-board diagnostic control module C, abbreviated SOBDMC.

## Build information is the deciding evidence

The qualifying feature is the factory configuration identified by minor feature code IEPAA. Ford instructs technicians to confirm that information in the vehicle’s PTS build record. An owner’s impression that connected services are unavailable is not equivalent to checking the original build specification: disabled services, failed equipment and absent equipment are different situations.

The bulletin also identifies U0146 in the anti-lock brake system module as a possible companion finding. Either code may be seen during the self-test; the presence of an ABS communication entry does not by itself establish a braking hardware failure in this documented case.

## When no repair is appropriate

For the described vehicles without a TCU, Ford states that diagnosis or repair of this self-test finding is unnecessary. That conclusion is bounded by the model year, factory feature code, reporting module and test context. It should not be extended to a Transit fitted with a TCU or used to dismiss a separate operating symptom.

Keep the complete scan report and ask the workshop to verify the build information before ordering a communication module or investigating wiring for equipment the vehicle never had. This bulletin explains why matching a code title to a replacement part can be misleading when configuration has not yet been established.

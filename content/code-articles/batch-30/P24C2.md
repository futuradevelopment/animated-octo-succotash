# P24C2: Super Duty exhaust-temperature faults and the PCM software case

P24C2 is among the diagnostic entries in Ford TSB 21-2055 for certain 6.7L Super Duty trucks. The complaint is an illuminated malfunction lamp, and the vehicle may also be restricted to forced idle. Ford identifies several PCM software strategies as possible causes of the listed fault conditions within the stated production range.

## Software applicability does not follow from the code alone

The bulletin requires the 2020–2021 model range, 6.7L diesel and build date on or before February 10, 2021. Preserve the full PCM scan and note whether the truck is actually in forced idle. A later-built truck or an unrelated exhaust-temperature complaint is not established as the same case merely because it has P24C2.

For a qualifying vehicle, Ford directs PCM reprogramming. The source does not prescribe replacing all exhaust-temperature sensors or treating every companion code as an independent hardware failure. It also does not provide a universal sensor-correlation threshold for diagnosing vehicles outside the bulletin.

## Forced idle adds a separate recovery requirement

After programming, the procedure asks whether forced idle remains. If it does not, the described repair is complete. If it does, Ford requires an additional controlled recovery procedure with specified temperature and operating conditions. Programming and recovery are therefore separate milestones.

That recovery must be performed by trained service personnel; the source warns that full power returns immediately when the restriction clears. This article does not provide acceleration instructions for attempting it on the road. Ask the workshop to document software completion, recovery status and reassessment of the original faults rather than assuming that a cleared lamp proves normal operation.

## Source and applicability

Ford TSB 21-2055, March 3, 2021: 2020–2021 F-Super Duty with 6.7L diesel, built on or before February 10, 2021, and qualifying PCM faults.

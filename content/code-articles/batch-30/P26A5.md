# P26A5: bypass-valve feedback falls into an unexpected position band

The cited GM P26A5 row evaluates coolant-bypass valve position feedback when the valve has not reached the expected position. It is a performance check within the feedback signal's usable range, rather than the separate extreme-low or extreme-high circuit diagnosis.

## The intermediate bands matter

The source describes two feedback bands: above 5 percent but below 30 percent, or above 70 percent but below 95 percent. Three failed samples out of five, taken at 100-millisecond intervals, satisfy the printed sample criterion. These percentages describe controller feedback, not a universal coolant-flow rate.

Evaluation requires system voltage above 10.2 V and an active propulsion system. The listed control-circuit and feedback high/low faults must not be active. Those exclusions matter because an electrically invalid signal should not be treated as a trustworthy valve-position performance measurement.

## Keep the source's naming limitation visible

The original row calls P26A5 a stop/minimum-stop performance condition, while the generic dictionary uses range/performance terminology. The article retains the documented band-based behavior without assuming that every calibration uses the same title or endpoint definition.

The source gives no universal replacement or relearn instruction for this code. A workshop should establish the commanded state, actual feedback and relevant circuit status using the exact system procedure. Verification should show an appropriate valve response while the performance test is eligible. Clearing memory or seeing a percentage outside one failing band at a single instant is not a complete post-repair result.

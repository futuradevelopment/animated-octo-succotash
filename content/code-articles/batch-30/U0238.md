# U0238: Lincoln Aviator audio loss and the DSP recovery test

U0238 in Ford SSM 54752 concerns an Aviator with no audio and no communication with the digital signal processing module, or DSP. The code is stored in the audio control module. The described case is restricted to 2025–2026 vehicles equipped with the 28-speaker system identified by feature code IDBBN.

## Equipment verification comes first

The bulletin instructs the technician to confirm the factory feature code in PTS build information. Speaker count or a trim badge guessed from appearance is not the same evidence. A different audio configuration, or sound loss while DSP communication remains normal, does not establish the exact condition described here.

Ford uses a controlled interruption of the DSP fuse supply to distinguish diagnostic paths. The fuse must be inspected for an open circuit and proper blade contact before the recovery result is interpreted. Finding a fuse problem is different from restoring communication after interruption with a good fuse.

## Recovery does not end this repair path

If communication returns with the DSP after the specified one-minute interruption and reinstallation of a good fuse, the bulletin directs DSP replacement. Temporary recovery is therefore the qualifying observation for that repair, not proof that the underlying problem is permanently fixed. If the problem persists or a fuse concern is found, Ford directs normal Workshop Manual section 415-00 diagnosis instead.

Provide the workshop with the feature configuration, full scan and whether audio and communication failed together. Use the exact vehicle service procedure for fuse identification and handling. This source does not justify replacing every audio component, repeatedly cycling fuses, or applying the same diagnosis to other Aviator sound systems.

## Source and applicability

Ford SSM 54752: 2025–2026 Lincoln Aviator equipped with the 28-speaker audio system, minor feature code IDBBN.

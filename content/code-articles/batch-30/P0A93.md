# P0A93: Ford DCACA inverter message with the exact 96 suffix

P0A93:96 has a specific Ford truck application that should not be confused with a generic traction-inverter cooling diagnosis. SSM 52213 concerns a service message in the center display and a fault stored in direct current/alternating current converter module A, abbreviated DCACA. The covered vehicle must have the HUKAK inverter feature.

## The reporting module and equipment define this case

The bulletin covers 2022–2023 F-150 and 2023 F-Super Duty trucks with that equipment. Ford instructs technicians to confirm the feature in the factory build record. A matching base code on a different module or a truck without this inverter does not establish the same condition.

Keep the complete P0A93:96 suffix and the center-display message when documenting the complaint. The module identity distinguishes the bulletin’s DCACA software case from other systems that can use related code wording. It would be inappropriate to infer a failed traction-battery cooling pump from this source.

## The correction is a qualified software action

Ford says the described condition may be due to the DCACA software level and directs reprogramming with the appropriate FDRS software. The bulletin does not prescribe cooling-system parts, inverter disassembly or electrical probing. It states that its defined condition has no effect on vehicle operation, but that statement should not be extended to other warnings or symptoms.

Ask the workshop to verify configuration and installed software, then assess whether the original message and fault remain after the prescribed update. The January 2024 document supports this particular repair path; it does not identify the latest available software today or guarantee that every P0A93 will be resolved by programming.

## Source and applicability

Ford SSM 52213, January 2024: 2022–2023 F-150 and 2023 F-Super Duty equipped with DCACA inverter minor feature code HUKAK; P0A93:96 in DCACA.

# P006F: high voltage when the turbo driver should be off

P006F in this GM diesel table concerns the turbocharger boost-control high-side driver. The electrical problem is voltage remaining high when that driver is commanded off. This distinction separates a control-circuit fault from a conclusion that the turbocharger is mechanically producing too much boost.

## Compare the voltage with the commanded state

The source associates the off-state high-voltage condition with a short to power. A voltage reading without its command state is incomplete evidence: a powered circuit during an intended on-state does not reproduce the condition described here.

The monitor is enabled only after battery voltage has remained above 11 V for more than three seconds, with the starter no longer actively cranking. Additional basic conditions and inhibiting faults are defined elsewhere in the same document. A result taken during cranking or an unstable supply should not be compared directly with this enabled-state example.

## What the timing establishes

The original table requires the fault condition for 0.1 second and lists a 0.1-second monitoring rate. This is a circuit evaluation; it does not require proving a sustained boost-pressure error first. Preserve any associated driver or supply faults and the command-versus-feedback evidence before deciding which circuit test is needed.

The table is not a wiring diagram and does not identify a vehicle-specific connector, pin or replacement actuator. Use the correct engine procedure to distinguish the harness, controlled load and controller output. A replacement turbocharger is not justified solely by the word “boost” in the code description.

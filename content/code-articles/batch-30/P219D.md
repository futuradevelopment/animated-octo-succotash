# P219D: interpret cylinder-two imbalance against the correct bank baseline

P219D points to cylinder two in the air-fuel imbalance family. The cited GM monitor evaluates how that cylinder differs from its bank's average behavior. A scan showing only a bank fuel-trim number therefore does not reproduce the cylinder-specific evidence behind this fault.

## Resolve direction before discussing a repair

P219D is included in both the lean and rich monitor paths. Their normalized limits differ, but the code remains the same. Treating every P219D as a lean fuel-delivery problem would ignore the documented rich-side possibility.

Ask for the cylinder-specific findings, the bank comparison and the operating point recorded when the test failed. The numerical limits in this table belong to the controller's modeled comparison; they should not be converted into a universal injector flow tolerance or a permissible fuel-pressure error.

## A valid roughness signal is a prerequisite

The monitor depends on plausible segment timing and learned trigger-wheel correction. It also excludes active rough-road detection and requires normal synchronized engine operation. Those requirements help distinguish an eligible combustion-related comparison from a period in which the input used for that comparison is unreliable.

The table does not specify cylinder-two physical location for every engine, and it does not order replacement of any component. Confirm the actual engine's numbering and service procedure before identifying parts. After an evidence-based correction, verify that the comparison has run in its calibrated operating region. Simply clearing the code, idling briefly or changing a bank-wide adaptation value does not demonstrate that the cylinder-two imbalance was resolved.

## Source and applicability

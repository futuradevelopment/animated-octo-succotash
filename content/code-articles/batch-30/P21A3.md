# P21A3: cylinder-eight imbalance needs a cylinder result and a bank reference

P21A3 is the cylinder-eight air-fuel imbalance code in this family. The cited GM strategy compares a cylinder's calculated air-fuel behavior with its bank average. An overall bank value and the cylinder-specific comparison should therefore be retained together when reviewing the event.

## Do not mistake a prerequisite for a failed component

The monitor needs valid engine-roughness information, plausible segment duration and completed trigger-wheel adaptation. Normal engine synchronization is also required. These statements describe when the calculation is usable; they do not mean that the presence of P21A3 diagnoses a timing-wheel or crankshaft-sensor failure.

Active rough-road detection and an operating point outside the calibrated speed/air-charge region can prevent evaluation. A subsequent drive or idle period without the code may simply lack a qualifying monitor opportunity.

## Establish which side of the comparison failed

Both rich and lean branches include P21A3. The generic code label does not identify the direction, so a repair proposal should explain the actual cylinder-eight evidence before selecting tests or parts. The source does not prescribe an injector replacement or a universal compression, fuel-pressure or resistance limit.

Cylinder numbering and vehicle applicability must come from the exact engine's documentation. After a confirmed cause is corrected, verify that the shared monitor's prerequisites are satisfied and that an eligible evaluation has occurred. Because the table lists a once-per-driving-cycle comparison and a two-trip classification, fault-memory clearing alone is a particularly poor substitute for documented post-repair evidence.

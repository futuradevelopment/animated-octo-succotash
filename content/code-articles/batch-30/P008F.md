# P008F: compare coolant and fuel temperatures at the captured start

P008F is a plausibility comparison between engine-coolant and fuel-temperature readings captured at startup. This GM monitor is designed to detect a biased reading; it does not identify which of the two sensors is wrong simply because their reported temperatures differ.

## The relevant readings are the stored startup values

The cited calibration requires an engine-off period of at least 28,800 seconds, or eight hours. Comparing temperatures after the engine has warmed up answers a different question. Preserve the captured starting values and the recorded soak history rather than substituting two convenient live readings later in the trip.

The diagnostic runs once per trip under its enabling conditions. A code-free period after clearing memory may therefore mean that this specific comparison has not yet been evaluated again.

## The block heater changes one branch

The main table and its continuation describe a large-difference branch and a second, narrower-difference branch. The latter additionally requires that a block heater has not been detected. The calibration lookup tables distinguish those branches; treating one temperature difference as the complete diagnostic rule would lose the heater condition.

A workshop should first establish whether the captured values and operating history are consistent with the actual application. Electrical checks then need to identify which temperature signal, if either, is inaccurate. This document does not make an observed difference an automatic order to replace both sensors, nor does it provide a universal thermostat diagnosis. Its numerical lookup values are calibration data rather than normal allowable temperatures for every vehicle.

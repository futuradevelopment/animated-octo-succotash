# U0293: F-150 Lightning backup-power faults and gateway software history

U0293:00 has a specific software context in Ford SSM 52527 for 2022–2023 F-150 Lightning. The message pairs it with U019B:00 in another control module and describes unavailable high-voltage-to-low-voltage energy transfer and intelligent backup power. It identifies the gateway module software level as the cause of that particular condition.

## The reporting module is not necessarily the source

U0293:00 is reported in the SOBDM while U019B:00 is reported in the SOBDMC. Ford expressly states that replacing or reprogramming either of those modules would not resolve the described gateway-software issue. That distinction prevents a communication-code title from being turned directly into an order for the module named in a scan report.

The feature complaint is also part of the match. A vehicle with different warnings, a no-READY condition or an isolated code has not automatically demonstrated this service-message scenario. Preserve both module identities, full suffixes and a precise description of which backup-power function failed.

## Read the bulletin as a dated service record

The May 2024 notice was interim guidance. It said a solution was expected later and that certain programming operations were temporarily suspended. Those statements do not establish today’s repair availability or justify indefinite inaction. The workshop should consult the applicable Ford service and field-action information for the vehicle’s present software status.

This article documents why the original fault combination led away from replacing the reporting modules. It does not provide a high-voltage test or instructions for modifying home backup-power connections. Any continuing fault should be evaluated against the vehicle’s actual warnings and current service procedure.

## Source and applicability

Ford SSM 52527, May 2024: 2022–2023 F-150 Lightning with U019B:00 in SOBDMC, U0293:00 in SOBDM and the described energy-transfer or intelligent-backup-power concern.

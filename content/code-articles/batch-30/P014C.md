# P014C: the upstream NOx sensor also supplies oxygen-response evidence

The generic P014C label describes a slow rich-to-lean oxygen response. In this GM diesel implementation, the oxygen measurement comes from the upstream NOx sensor. That detail is essential when identifying the relevant component: the code is not automatically a diagnosis of a conventional gasoline switching oxygen sensor.

## A transition test needs valid starting conditions

The monitor compares the measured oxygen response with a modeled oxygen concentration during an overrun-related state transition. Communication with the NOx sensor and an active oxygen-concentration signal are required. Post-injection must be inactive, and the engine must be operating within the documented speed, pressure and temperature windows.

An invalid communication state or an uncompleted transition is not equivalent to a valid slow-response failure. The useful record includes the sensor's oxygen data, the modeled signal and the operating state in which the evaluation was attempted.

## Do not reverse an ambiguous printed inequality

The source's slow-response description appears beside a response-time inequality that is not sufficiently explained to turn it into a reliable standalone service limit. This article therefore does not present that inequality as a technician's pass/fail test. The original calibration-specific procedure is needed to resolve it.

The monitor description also supplies no automatic NOx-sensor replacement instruction. Establish that the correct signal and operating transition have been evaluated before deciding whether the sensor, its communication or another condition needs investigation. Verification should reproduce a valid monitoring opportunity, rather than treating cleared memory or an oxygen value observed at idle as proof of repair.

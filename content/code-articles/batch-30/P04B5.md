# P04B5: F-150 PowerBoost fuel-door latch checks before deeper diagnosis

P04B5 on a 2021 F-150 PowerBoost can appear with a fuel-door closure message or refueling difficulties. Ford SSM 49886 describes a release tappet that has separated from the fuel-door housing, slow filling or fuel spit-back. It identifies opening the door without first using the release button as a possible background to that condition.

## Door operation and refueling symptoms should be recorded together

The bulletin’s first check is whether the release tappet is properly installed and whether the door closes correctly and opens using the release button. A door that appears shut is not the same observation as a correctly installed release mechanism. Conversely, a stored P04B5 does not by itself prove that the tappet has detached.

Note whether the release button works, whether the closure warning appears and whether the filling complaint began after the door was opened manually. These details help the technician distinguish the described mechanical release issue from another cause of slow filling or a continuing fuel-system fault.

## Correct a verified release problem before ordinary diagnosis

For a separated tappet, Ford gives a specific release-and-reinstallation procedure with the part’s locating features aligned correctly. That procedure belongs to the original service instructions; forcing the latch or prying the door is not an equivalent repair. The bulletin places this inspection before normal diagnostic work, rather than declaring that every P04B5 requires fuel-system components.

If fuel spits back, stop the filling attempt and have the concern assessed instead of repeatedly trying to force fuel into the tank. The source supports a targeted preliminary inspection on the stated PowerBoost model, not a universal fix for fuel-door codes or a reason to bypass the release system.

## Source and applicability

Ford SSM 49886: 2021 F-150 PowerBoost with the described fuel-door, refueling or P04B5 concern.

# P21A0: cylinder-five imbalance can be hidden by a normal-looking bank average

P21A0 is a cylinder-five air-fuel imbalance code. In the cited GM strategy, the individual cylinder is judged against the bank's average air-fuel behavior. That comparison explains why a generally reasonable bank value does not rule out a meaningful difference in one cylinder.

## Preserve the individual evidence

The table includes P21A0 in both lean-side and rich-side evaluations. The normalized comparison is not the same quantity as a scan tool's familiar short-term fuel-trim percentage. Record the available cylinder-specific result and the operating point instead of treating a single bank correction as proof of the cause.

The source does not identify an injector leak, a restricted injector or an intake leak as the inevitable explanation. Those possibilities require application-specific evidence. The fifth cylinder's physical location also depends on the actual engine, which this document-level assignment does not establish.

## Distinguish an unavailable test from a passing test

The comparison relies on valid engine-roughness and segment-time information. It requires trigger-wheel adaptation, normal synchronization, no active rough-road detection and a calibrated speed/air-charge operating region. A monitor that was prevented from running cannot demonstrate that the original cylinder-five condition disappeared.

GM lists the evaluation once per driving cycle. Repair verification should therefore record whether an eligible evaluation actually occurred and whether associated faults remain. The source supports this interpretation of the monitor; it does not provide a universal component replacement order or a road-test recipe for every vehicle carrying P21A0.

# P2759: torque-converter pressure control has an electrical tracking test

P2759 is the electrical feedback-current monitor for the SLU pressure solenoid in this transmission document. Although the generic description references torque-converter clutch pressure control, the cited test compares commanded electrical current with feedback current. It does not directly measure the converter's mechanical condition.

## The source evaluates sustained error

A running sum of target-minus-feedback error is updated every ten milliseconds. The table clears the accumulated value when the detection window is inactive, the error returns to the specified small band or the error changes direction. Those details distinguish sustained tracking disagreement from an isolated sample.

The accumulator limit is not an instantaneous coil-current specification. A technician should retain the command and feedback history, along with the controller state, instead of using the large accumulated number as a meter target.

## Separate electrical branches from pressure or slip complaints

The same table defines separate SLU low- and high-circuit faults, and those faults affect eligibility for this test. Their circuit categories should be interpreted before drawing conclusions from a pressure-control label. A shift or lockup complaint may require additional diagnosis even after the electrical issue is understood.

The monitor requires adequate ignition voltage and an enabled diagnostic state without emergency mode. The summary provides no universal pinout, resistance value or converter replacement rule. Use the exact transmission procedure to establish the cause, then verify current tracking under eligible conditions and assess the original drivability complaint independently.

## Source and applicability

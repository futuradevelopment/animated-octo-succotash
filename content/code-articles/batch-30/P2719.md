# P2719: solenoid D performance is checked during a stable current command

P2719 is a performance diagnosis for the SLC3 solenoid in this GM transmission table. Its branch evaluates a current error while the commanded solenoid current is high and constant. That is a different question from whether the circuit is simply open or shorted to battery supply.

## A stable test window is essential

The documented branch requires no shifting control, no emergency mode, warm enough oil and a stable supply. The current target must exceed the specified level and remain constant. A mismatch observed while the command is changing during a shift does not reproduce that stable-command test.

Within the eligible window, the source describes an error-current threshold above 80 mA and a 2.75-second duration. Those figures belong to this particular SLC3 implementation; other controllers using P2719 can employ different monitor logic.

## Preserve the conditions that made the error meaningful

A useful record pairs commanded and measured current with fluid temperature, supply behavior and the transmission's control state. The page also lists temperature-sensor faults that prevent the evaluation. An invalid temperature signal can therefore affect test eligibility without proving that it caused the solenoid's electrical behavior.

The table does not establish a hydraulic failure or order replacement of the complete transmission. Follow the correct circuit and solenoid procedure to investigate the recorded tracking error. Verification should show acceptable tracking under the same eligible stable-command conditions, with the original drivability complaint and associated faults considered separately.

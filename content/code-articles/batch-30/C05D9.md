# C05D9: Bronco Sport 2.0L rear-drive motor repair instead of the complete unit

C05D9:71 is listed in Ford SSM 51117 for a specific 2021–2022 Bronco Sport 2.0L all-wheel-drive concern. The customer may see an AWD warning indicator or fault message, with this code or the listed companion motor-circuit faults stored in the AWD module.

## The engine-specific branch matters

The same service message also covers several other Ford and Lincoln vehicles and the Bronco Sport 1.5L, but those appear under a C0095 branch. They are not evidence that C05D9:71 applies identically to every model in the heading. Confirm the 2.0L Bronco Sport configuration, full suffix and reporting module before using this case.

Ford identifies possible misalignment of a rear drive unit motor magnet ring. That proposed cause concerns the motor within the rear-drive system; it does not mean the code proves failure of every component in the rear drive unit. The Workshop Manual diagnosis remains part of deciding whether the condition matches.

## A smaller service component changes the repair choice

The bulletin states that replacement of the entire rear drive unit is no longer required for the described condition. A rear-drive motor is available separately, and Ford directs its replacement using the relevant section 205-02 procedures. This is the practical distinction the bulletin adds: confirmed motor-related trouble can have a targeted service remedy.

Provide the technician with the exact warning, full AWD scan and vehicle configuration. Do not test AWD availability by deliberately seeking wheelspin or poor traction. This source does not establish general driving capability during a warning, current parts availability or a repair decision for a different C05D9 suffix.

## Source and applicability

Ford SSM 51117: C05D9:71 applies to the described 2021–2022 Bronco Sport 2.0L AWD warning case; the other models and 1.5L Bronco Sport use a different code branch in this source.

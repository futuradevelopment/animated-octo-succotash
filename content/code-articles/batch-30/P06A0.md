# P06A0: Ford variable-displacement A/C diagnosis before compressor replacement

P06A0 can accompany poor air-conditioning performance on Ford vehicles equipped with an external variable displacement control compressor, abbreviated EVDC. Ford SSM 47967 focuses on improving diagnosis of that configuration before a compressor is replaced. It does not establish that every 2013–2019 Ford uses this compressor design.

## Confirm the hardware before choosing the test

The service message is equipment-specific. A technician should identify the installed compressor and applicable service information before using an EVDC procedure. The model-year range alone is insufficient, and the bulletin does not provide a model-by-model fitment list.

Poor cooling and a PCM code are also different observations. The bulletin covers improper climate performance with or without P06A0, so neither symptom should be treated as a complete diagnosis of internal compressor damage. The relevant question is whether the control system and compressor respond as expected under the appropriate test.

## A dedicated control-valve test adds evidence

Ford identifies the EVDC control-valve tester, tool reference 339-EVDC100, and directs its use to reduce misdiagnosis and unnecessary compressor replacement. It asks technicians to document the results. The message itself does not publish a numerical pass/fail limit or the tester’s operating sequence; those belong to the tool instructions and vehicle procedure.

Ask the workshop to record the exact compressor configuration, complaint and test result supporting its repair recommendation. This source cannot justify condemning the whole compressor from P06A0 alone, nor does it support adjusting refrigerant charge as a substitute for diagnosis. Refrigerant-system work and powered component tests should use the required professional equipment and procedures.

## Source and applicability

Ford SSM 47967, 2019: applicable 2013–2019 vehicles equipped with an external variable displacement control A/C compressor; exact model fitment must be established separately.

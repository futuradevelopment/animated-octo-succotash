# P2734: solenoid F diagnosis uses cumulative command-versus-feedback error

P2734 identifies the electrical current-tracking monitor for solenoid F, labelled SL5 in this GM transmission section. The controller compares linear-solenoid feedback current with the commanded current and accumulates the difference. This is distinct from detecting a single high-current or low-current circuit condition.

## Read the accumulated value as a diagnostic quantity

The source updates its running error sum on each ten-millisecond processor cycle. It lists a cumulative detection period of one to three seconds. The resulting threshold is an accumulated calculation and must not be presented as the current that should physically flow through the coil at one instant.

A useful trace includes the target and feedback together over time. A single value taken after the command changed can conceal either recovery or sustained tracking error, so it does not reproduce the complete monitor.

## Supply and controller state constrain evaluation

The documented prerequisites include valid ignition and battery supplies, completion of the TCM's nonvolatile-memory read and an enabled operating state. Solenoid cut and emergency modes must not be active, and the related solenoid-F low/high circuit faults must not be detected.

Those exclusions help establish whether an apparent lack of recurrence was a genuine passing opportunity or a disabled test. The table does not order replacement of the solenoid, valve body or transmission. Use the application-specific diagnostic procedure to establish the cause, then verify normal current tracking and the original operating complaint during an eligible evaluation.

## Source and applicability

GM 2015 15OBDG06 transmission document, MGG-unique SL5 monitor. Only the cited monitor and calibration are described; per-code vehicle and engine applicability has not been established.

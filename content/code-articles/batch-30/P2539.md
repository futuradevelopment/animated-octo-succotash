# P2539: Transit KOEO self-test code versus a running-engine fault

P2539 during a key-on engine-off self-test can have a no-repair interpretation on the Transit configuration covered by Ford SSM 51033. The bulletin explains that the PCM can set the code when it does not detect a change in the fuel-delivery pressure switch after engine shutdown. This is a test-context finding, not automatic proof of low fuel pressure.

## The running-engine result is decisive

Ford distinguishes the KOEO test from a key-on engine-running self-test. For the bulletin’s no-action conclusion, P2539 must be absent after the running test. A fault that remains present with the engine running does not satisfy that condition.

The message adds three more requirements: no illuminated malfunction lamp while running, no drivability concern and no other diagnostic codes. These conditions work together. A KOEO P2539 accompanied by poor running or another current fault should not be dismissed by citing only the bulletin’s headline.

## Preserve the test sequence

Ask the workshop to record which self-test produced the code, the result of the running test and whether any warning or symptom remained. The vehicle must also match the 2015 model year, 3.2L engine and March 6, 2015-or-later production boundary.

When all the stated conditions match, Ford says no further service is required for that P2539 finding. The bulletin does not instruct replacing the pressure switch, fuel pump or PCM. When a condition does not match, use the applicable fuel-system diagnostic procedure. This source provides no owner-level pressure measurement or instruction to open a fuel line; its value is preventing an unnecessary repair of a qualified self-test-only result.

## Source and applicability

Ford SSM 51033: 2015 Transit with 3.2L Duratorq-TDCi built on or after March 6, 2015; P2539 during a key-on engine-off self-test.

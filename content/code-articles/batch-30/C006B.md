# C006B: stability intervention duration needs its speed and mode context

C006B describes stability control remaining active for an implausibly long period in this GM monitor. The controller is judging the duration of vehicle-dynamics intervention. It is not a direct verdict that one wheel-speed sensor or the brake controller has failed.

## Two timing branches appear in the source

The original table uses vehicle speed to choose a duration limit. One branch allows a longer intervention at or below 62.19 mph than above that speed. A second branch also changes its duration at the same speed boundary, but uses longer times. The strategy mentions normal and sport operation without clearly assigning each printed branch to one mode.

That unresolved mapping matters: quoting one of those values as a universal C006B test would discard part of the source. The documented evaluation also requires ignition on and speed above 12.43 mph. An observation made while stationary cannot reproduce this particular monitor.

## Preserve the event that produced the code

A useful record includes the selected driving mode, vehicle speed, intervention status and elapsed intervention time. Those data distinguish an extended genuine stability event from intervention that appears inconsistent with vehicle behavior. The table itself does not identify which underlying fault produced either situation.

Brake and stability diagnosis requires the applicable vehicle procedure and suitable professional equipment. Do not deliberately provoke a stability event to reach a printed timer. Repair verification should establish that the original intervention complaint is resolved under appropriate conditions, with the correct calibration-specific criteria.

## Source and applicability

GM 2020 20OBDG03C brake-system control module table. Only the cited monitor and calibration are described; per-code vehicle and engine applicability has not been established.

# U0037: Mustang GTD suspension warnings and VDM software

U0037 appears in Ford SSM 55237 as part of a specific Mustang GTD suspension and hydraulic warning case. The bulletin covers 2025–2026 GTD vehicles built on or before September 28, 2026. It does not establish the same diagnosis for an ordinary Mustang, Mustang Mach-E or Ford GT.

## A collection of warnings can have one software context

Reported messages can concern suspension, front lift, drive modes or active aerodynamics, including a speed-limitation message. Ford explains that the vehicle dynamics module, or VDM, software may incorrectly detect or report suspension and hydraulic faults. U0037 is one of several codes that may be stored in the VDM or powertrain control module in this condition.

The combination matters more than the generic code title alone. Save the full scan, identify the module reporting each code and record the exact driver messages. A list of related codes is not a requirement that every listed fault must be present. Equally, a matching code does not prove that an observed physical hydraulic problem is imaginary.

## The documented correction

Ford directs reprogramming the VDM with the appropriate FDRS software. Confirming the GTD identity and build date comes before applying that instruction. The bulletin supplies a software correction for the described condition; it does not provide component replacement criteria or a hydraulic pressure-testing procedure.

Follow the vehicle’s displayed operating restrictions while arranging diagnosis. After programming, the technician should determine whether the original messages and current faults remain. A persistent concern requires the relevant service diagnosis rather than repeated assumptions that all suspension warnings originate in this software case.

## Source and applicability

Ford SSM 55237: 2025–2026 Mustang GTD built on or before September 28, 2026; hydraulic or suspension warning condition described in the bulletin.

# P2124: F-150 intermittent pedal faults and harness routing at the booster

P2124 can appear during the intermittent accelerator-pedal response condition described by Ford SSM 46829. The covered 2015–2017 F-150 may also show wrench, hill-descent, airbag, ABS or stability-control indicators. Ford identifies incorrect routing of the accelerator-pedal-position sensor harness behind the brake-booster-to-pedal bracket as a possible cause.

## Routing and conductor damage are separate findings

The bulletin directs the workshop to determine whether the harness is trapped by the incorrect route. If it is, the specified procedure frees it and inspects for damaged circuits before restoring proper routing. Repositioning a harness without checking damage is not the same as completing that correction.

Conversely, a correctly routed harness sends the technician to normal diagnosis. The bulletin does not establish that every intermittent pedal code originates at this bracket. A matching P2124 and a sound route require more evidence rather than speculative pedal-sensor replacement.

## Keep the intermittent context

Record when pedal response was lost, which warning indicators appeared together and whether the fault remained current afterward. The complete code group can help identify a shared harness event, whereas a single code screenshot omits that context. Do not deliberately provoke loss of throttle response during driving to collect more evidence.

Have a technician inspect the bracket and harness using the relevant Workshop Manual procedure. This article does not provide instructions for loosening braking-system hardware or bypassing pedal signals. The bulletin’s practical contribution is a specific physical cause to check before assuming an internal accelerator-pedal sensor fault, followed by normal diagnosis when the routing concern is absent.

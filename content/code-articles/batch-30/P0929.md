# P0929: F-150 console shifter faults need wiring inspection and module setup

P0929 on a covered F-150 console shifter can accompany failure to leave or enter park, failure to stow, excessive lever movement or a wrench warning. Ford TSB 25-2324 identifies possible gear shift module concerns and a separate wiring problem on circuit CCB61. A clicking complaint is included specifically for the 2024 model year.

## Inspect the path before fitting the module

The service procedure first checks both sides of connector C211 for damaged or pushed-out terminals. If that inspection is satisfactory, it checks the CCB61 circuit between the ABS module and body control module for an open. Model-year and powertrain-specific diagrams determine the connector details; the bulletin should not be treated as a universal pinout for every F-150.

These findings change the work required before module installation. Damaged terminals or an open circuit need repair, while a sound circuit does not need speculative wiring replacement. In this bulletin’s qualifying case, both branches then proceed to gear shift module replacement.

## Replacement includes more than installing hardware

Ford requires programmable module installation and the TRON module-authentication procedure with FDRS. A fitted module without its prescribed programming and authentication is not the complete repair. Record the original active code suffixes and the wiring findings so a later concern can be distinguished from incomplete setup.

Have the vehicle secured and assessed if the shifter cannot select park; do not infer the actual transmission position from lever appearance alone. The bulletin’s stated return-to-park behavior is not a substitute for confirming that the vehicle is safely immobilized. Column-shift trucks and vehicles outside the defined build range require their own diagnosis.

## Source and applicability

Ford TSB 25-2324, July 16, 2025, North America: 2021–2025 F-150 with console shift, built on or before March 17, 2025; qualifying shifter symptoms or active P0929:77/:00/:07/:9A in the GSM.

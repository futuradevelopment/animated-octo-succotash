# P0845: Escape pressure-sensor codes from a damaged shared reference harness

P0845 can appear with many seemingly unrelated faults in the Escape wiring case described by Ford SSM 50245. The bulletin concerns possible loss of a voltage reference when harness 14290 contacts the steering-shaft universal joint. A malfunction lamp, rough running or an open fuse 44 may occur, with or without the listed diagnostic entries.

## A transmission-related code can share an external electrical cause

The source identifies a physical harness area above the steering shaft near the upper brake-pedal mount. Steering movement can cause a short if the harness contacts the rotating shaft. That is a different explanation from assuming that the transmission pressure sensor or internal transmission hardware has failed.

The wide code list supports looking for a shared electrical event when several systems report low or implausible signals together. It does not mean every listed code must be present, or that P0845 alone confirms this chafing site. Save the entire scan, fuse condition and timing of the symptoms so the technician can evaluate that pattern.

## Damage and routing both matter

Ford directs repair when damage is found, followed by moving the harness away from the joint and securing its locator on the provided stud. Merely repairing the damaged insulation while leaving the contact route unchanged would not complete the stated correction. Conversely, a harness without damage requires continued diagnosis rather than speculative replacement.

Do not deliberately turn the steering to provoke an electrical short. Have the workshop inspect the area using the applicable procedures. This bulletin supplies a targeted shared-circuit check for 2020–2021 Escape; it is not a universal test specification or a reason to replace a transmission from P0845 alone.

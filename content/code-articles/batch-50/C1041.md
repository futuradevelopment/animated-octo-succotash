# C1041: Incomplete ABS programming must be addressed before replacement

## The entry describes an unfinished programming state

For Ariya, C1041-55 is an ABS configuration entry associated with incomplete programming. The power-on diagnosis is listed as one second or less under the stated supply conditions. The source separates current and past results and cautions against replacing the ABS actuator and control unit for a past code alone.

This differs from a direct valve, pump or hydraulic-pressure fault. A module may be present and communicating while its programming process is incomplete, so the broad Control unit label should not be interpreted as proof of a failed electronic assembly.

## Complete programming and evaluate self-diagnosis

Nissan's procedure performs the ABS programming work before the subsequent self-diagnostic decision. It specifically warns against replacement until self-diagnosis has been completed. The later replacement instruction belongs to that diagnostic context, including the continuing C1041 result, rather than being the first response to an unfinished setup record.

Keep any recent module-replacement or programming history and the original fault status for the workshop. The correct software and configuration must be obtained through the applicable authorized service process; copying settings from another vehicle does not establish compatibility.

The entry lists normal control as its response, but that is not a blanket certification that the whole brake system is safe. A technician must assess any actual warning or braking symptom and verify the completed programming and required post-service checks.

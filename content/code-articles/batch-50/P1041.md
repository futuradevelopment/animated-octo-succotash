# P1041: Missing front-inverter information starts a two-controller diagnosis

## Identify which controller is reporting the loss

The Ariya VCM's P1041-87 entry concerns a signal it cannot receive from the front traction-motor inverter while the vehicle is READY. The table does not publish a timeout value or identify an individual CAN wire. It therefore supports a missing-information diagnosis without establishing a universal communication-delay specification.

Nissan's procedure separates the reporting VCM from the inverter that normally supplies the information. That distinction prevents a communication complaint from being automatically interpreted as internal motor damage or a mechanically failed traction unit.

## Read the inverter's own fault memory

The diagnostic branch checks the front inverter for its own DTCs. If it has stored faults, their procedures take priority. The alternative VCM replacement branch is part of this specific factory flow, not a justification to replace a controller before the correct scan and applicability checks.

Confirmation begins in READY and can extend to a driving evaluation when the stationary observation does not reproduce the problem. Any driving test requires a technician's assessment that the vehicle is safe and the route appropriate. Retain the original operating event, complete suffix and both controllers' results; a cleared dashboard warning alone cannot demonstrate restored communication under the relevant conditions.

The source provides no fail-safe for this entry. That absence must not be converted into a promise of unrestricted operation, particularly when another inverter code or an actual loss of propulsion is present.

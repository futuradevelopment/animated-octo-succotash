# C106E: Nissan Ariya steering-angle initialization and signal faults

## The suffix changes the starting point

On the cited Ariya brake controller, C106E-54 means the steering-angle neutral position has not been fully adjusted. C106E-55 and C106E-64 instead report a steering-angle sensor malfunction communicated over CAN. All three monitors run with the power switch on and normal supply voltage, with a detection delay of one second or less. Keeping the suffix matters because an incomplete reference setting is different from a failed sensor or its supply.

The manual lists suspension of stability and traction control, hill-start assistance, brake limited-slip control, brake assistance, brake-force distribution, and cooperative regenerative braking. The code should therefore be assessed as part of a brake-system complaint, not dismissed because the steering wheel still turns normally.

## Adjustment precedes the replacement decision

The procedure first calls for the specified neutral-position adjustment and another ABS self-diagnosis. For -54 that persists, the technician checks the related steering-angle codes and watches whether the scan-tool angle changes when the wheel moves. For -55 and -64, connector inspection, sensor power and ground, ABS power and ground, and CAN diagnosis precede the final live-data comparison.

Equipment changes the supply branch: the cited procedure distinguishes vehicles with ProPILOT Assist 2.0 from those without it. It does not support applying one fuse location to every Ariya. Once the preceding checks pass, normal changing angle data directs attention to the ABS controller; abnormal data directs attention to the sensor. A historical PAST record alone does not justify replacing the ABS assembly. Calibration and brake-system decisions belong with a suitably equipped technician.

# P14C1: The BCM supplies the stop-lamp switch fault report

## A report received from another module

P14C1-00 in the Ariya VCM identifies a stop-lamp switch malfunction signal received from the body control module. It is checked with the power switch on. The entry names the switch circuit, its harness and connectors, and the switch itself as possible causes, but supplies no numerical voltage threshold or detection delay.

This distinction matters when a scan tool displays the code under EV control. The VCM is recording information originating in the BCM; its location in the scan report does not prove an internal VCM fault.

## Obtain the body controller's diagnostic detail

The factory diagnosis asks for the BCM's self-diagnostic result and then directs any detected code to its own procedure. The BCM result can provide the more specific circuit evidence that the VCM's received report lacks. If that module has no current code, the published flow ends rather than instructing immediate switch replacement.

Keep the original scan, including intermittent or history status where available, before memory is cleared. A technician can then relate the report to pedal operation and the correct wiring information. Because stop-lamp operation informs following drivers, an observed lighting fault needs prompt assessment; this brief VCM entry is not a substitute for verifying the actual lights and brake-related functions.

The absence of a listed fail-safe does not verify stop-lamp performance. The BCM diagnosis and an actual symptom check answer different questions and both may be needed to understand a reported lighting problem.

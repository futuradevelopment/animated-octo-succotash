# U1C03: The ambient-light fault pattern distinguishes supply from a network participant

## Ambient lighting has a shared communication path

The Ariya BCM's U1C03-08 entry concerns the LIN network serving advanced ambient lights in the front doors and upper instrument panel. It can be detected in power-on or AUTO ACC, with diagnosis listed as one second or less. The possible causes include the line, individual light assemblies and BCM.

The factory procedure first examines the four associated B2C76-through-B2C79 fault records. All four appearing together leads to a different branch from one individual light's fault. That distinction can separate a shared supply or communication issue from a problem localized to one participant.

## Compare the network response systematically

Nissan checks the room-lamp supply, the ambient-light supply paths and the BCM's LIN output before isolating individual lights. Its later test observes how the other fault records respond as each light is disconnected in turn, with reconnection between tests.

This is a controlled diagnostic comparison, not a recommendation to leave lights unplugged until the warning disappears. A changed network result must be interpreted against the correct table and original fault pattern.

Save the complete BCM scan and identify which lighting sections actually malfunctioned. A technician can then use the factory circuit and waveform information to distinguish supply loss, line damage and a network participant. The shared communication code alone does not prove that the BCM requires replacement.

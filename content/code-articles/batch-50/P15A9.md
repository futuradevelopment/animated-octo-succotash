# P15A9: The suffix separates unexpected AC voltage from lost input

## Two operating states share the base code

For Ariya, P15A9-24 concerns AC voltage being detected when charging is not underway. Its table specifies at least 70 V for six seconds. P15A9-2F instead concerns loss of AC input during normal charging while EVSE voltage is detected, with a duration exceeding 100 seconds. Combining these conditions would reverse the context needed for diagnosis.

Both branches compare known-working charging equipment with the equipment associated with the complaint. The -24 test intentionally keeps charging from starting; the -2F test observes an actual charging session. Charging-timer settings therefore affect whether the -24 comparison is valid.

## Preserve the source's threshold boundary

In the -24 diagnostic flow, an AC-voltage reading of 70 V or less goes down one branch, although the detection table includes 70 V in its triggering range. That equality boundary remains unresolved here and this article is marked for review. It should not be silently changed to a different inequality.

Technicians also check charger and VCM fault memories before a component decision. Save the full suffix, charging state and station history. High-voltage measurements and charger inspection require qualified personnel; neither variant justifies bypassing a charging interlock.

For -2F, the diagnostic endpoint also includes the on-board charger's own fault memory. A station comparison and a charger scan provide different evidence, so neither should be silently omitted when interpreting that suffix.

# P30E6: The excitation-current suffix changes the motor-versus-inverter test

## Two suffixes require different evidence

For Ariya's rear inverter, P30E6-11 and -12 describe an excitation-module error in READY, with diagnosis within one second and rear-motor control stopped. The common description does not make their tests interchangeable. The -11 flow inspects excitation bus-bar and harness connections before its inverter branch.

The -12 flow instead evaluates the rear rotor coil for a short. Its specific test treats 4.55 ohms or less as the short-circuit condition at the stated excitation terminals. That figure belongs to the cited motor procedure; it is not a universal specification for every electric traction motor.

## Historical low-voltage service can matter for -12

Nissan notes that voltage fluctuations during 12-volt battery installation can leave a past -12 fault. The history/current distinction and battery-service record therefore deserve attention before a stored result is equated with an active rotor defect.

These procedures require removal and access to high-voltage drive components. They belong with a qualified EV technician using correct isolation, measurement and equipment-specific instructions. Preserve the complete suffix, fault status and service history. A generic code reader that drops the suffix cannot supply enough information to choose between the two published diagnostic paths.

The -12 confirmation includes an additional driving observation compared with the shorter -11 sequence. Preserve which suffix is being confirmed so a result from one test is not mistakenly treated as validation of the other.

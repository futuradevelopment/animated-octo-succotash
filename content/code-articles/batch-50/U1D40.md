# U1D40: The CAN fault is confirmed while charging with the key off

## The vehicle state distinguishes this communication fault

In the Ariya charger procedure, U1D40-87 describes a CAN-bus error during normal charging with the key off. The listed detection time is a maximum of nine seconds, and normal charging stops. The possible-cause entry identifies an open or short in the communication harness or connectors.

The key-off charging condition is important. A network that appears normal during a brief power-on scan has not necessarily been observed in the state this monitor uses. Conversely, the entry does not provide a direct basis for replacing the on-board charger just because that module stores the code.

## Repeat the correct observation before circuit diagnosis

The confirmation allows normal charging in the key-off state for at least 120 seconds, then checks the charger result. If the fault returns on repeat confirmation, Nissan directs the CAN communication circuit workflow. The observation period and the monitor's detection time serve different purposes.

Its preparation also addresses results in the charger, EV/HEV and both high-voltage battery diagnostic groups. A complete saved scan is therefore useful before memory clearing, particularly when another controller records the same charging interruption.

Record whether the fault occurred during unattended charging or another vehicle state. A qualified technician can use that history with the network diagrams and safe charging procedure; repeatedly cycling the power switch is not equivalent to the specified key-off test.

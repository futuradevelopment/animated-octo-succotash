# P30E7: Excitation-current diagnosis separates connection, coil and inverter faults

## An abnormal excitation-current condition

The Ariya rear inverter's P30E7-01 entry states that excitation-module current is not flowing normally in READY. Diagnosis occurs within one second and rear traction-motor control stops. The possible-cause list includes both the rear inverter and motor, so the code does not independently identify which assembly needs attention.

Nissan first checks whether other rear-motor codes are present. Its inspection-priority chart determines which procedure takes precedence when they are. This avoids treating a secondary current complaint before a more informative underlying fault.

## Connections and coil condition distinguish the branches

The subsequent flow examines the excitation harness and bus-bar connections, then assesses rotor-coil resistance using the separate component-inspection specification. A normal coil result leads to the inverter branch; an abnormal result leads to the motor branch. The entry itself does not supply a universal resistance number.

Record the complete rear-controller scan and whether the complaint occurred during initial movement, because confirmation includes a low-speed operating event. Accessing the excitation components requires drive-unit work and proper high-voltage precautions. These are workshop procedures, not instructions to probe an installed energized unit or substitute a guessed coil limit from another DTC.

The confirmation includes initial movement rather than only a stationary READY check. If the original complaint occurred as the vehicle began to move, that history directly relates to the operating event the factory chose to observe.

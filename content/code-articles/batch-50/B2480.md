# B2480: The rear-air-mix scan label means the front passenger mode door here

## Nissan explicitly corrects the displayed component name

In this Ariya procedure, CONSULT can display Rear air mix door motor for B2480-93, but Nissan states that the actual component is the front passenger-side mode-door motor. That model-specific note is essential: following the uncorrected label could send diagnosis to the wrong part of the HVAC assembly.

The monitor detects a drive error through the door-motor LIN signal for at least two seconds with the power switch on. Possible causes include wiring, installation condition, the motor and A/C auto amplifier. The code therefore does not establish a seized actuator by itself.

## Power, communication and installation are separate checks

The factory flow checks motor supply, its ground path and the LIN waveform before evaluating installation. Only after those conditions are considered does it reach a motor or controller branch. A motor fitted incorrectly and one receiving an invalid electrical command are different explanations for failed door movement.

Nissan also directs a shared door-motor-circuit investigation when several specified door-motor DTCs appear together. Save the complete HVAC scan so that broader pattern is not lost by clearing only B2480.

Document which vents fail to change mode and any recent dashboard or HVAC work. A technician should use the matching connector layout and the corrected component identity; the scan label alone is not a reliable guide to parts selection on this model.

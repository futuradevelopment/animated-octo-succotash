# C10B6: Nissan Ariya electric parking-brake system fault

## The code does not identify one failed component

C10B6-68 is a general electric parking-brake system malfunction in the cited Nissan Ariya brake manual. Its monitor runs with the power switch on and normal supply voltage, with a listed detection delay of one second or less. The source does not give a motor-position target, measured current limit, or pad-thickness threshold for this particular detection entry.

The parking-brake actuator appears in both the historical and current possible-cause columns. The ABS actuator and electronic controller are an additional possibility for a current fault. Those distinctions matter because the diagnostic flow first examines the rear brake hardware rather than treating the controller as the default failed part.

## Inspect the mechanical brake assembly

The factory procedure calls for inspection of the rear pads, rear caliper assembly and parking-brake actuator, and rear disc rotor. It refers the technician to the individual component inspection procedures for their actual acceptance criteria. Any defective parts found are repaired or replaced before the next diagnostic stage.

After reassembly and the specified power-off rest, the procedure uses five parking-brake apply-and-release cycles and another ABS self-diagnosis. A continuing CRNT C10B6-68 leads to ABS assembly replacement in that final branch. A PAST result instead leads to clearing historical memory, and the source expressly prohibits replacing the assembly solely for that old record.

The fail-safe response suspends electric parking-brake operation. Inspection and repeated operation therefore require proper stationary vehicle security and a qualified brake technician. Clearing the code without checking the pads, caliper, actuator, and rotor would omit the first substantive part of this factory diagnosis.

# B24D8: Compressor electronics overheating leads to refrigerant-cycle checks

## The monitored temperature is internal to the compressor

The Ariya B24D8-4B entry describes excessive electric-compressor intelligent-power-module temperature while READY. Diagnosis is listed as less than one second, and compressor operation is stopped or its speed is limited. The table does not publish a numerical temperature threshold.

The possible causes focus on refrigerant leakage, insufficient refrigerant and an abnormal refrigerant cycle. A temperature-sensor label therefore does not automatically mean the sensor itself is the failed part. The electronics can be reporting a condition whose cause lies in the operating system around it.

## Establish the refrigerant condition before adding anything

Nissan first checks for leakage, then examines the refrigerant cycle. If those checks are normal, its flow calls for recovery and charging with the specified refrigerant amount. That is a controlled service operation, not an instruction to top up an unknown charge until cooling improves.

The confirmation runs air conditioning in READY with a full-cold request. An apparently normal result with no compressor demand does not reproduce the same thermal context. Record whether cooling fades after operation begins or fails immediately, without intentionally running an overheating system to force the code back.

Refrigerant recovery and electric-compressor work require qualified personnel, correct equipment and EV-specific precautions. Preserve related compressor and cooling-system faults so the workshop can distinguish the primary thermal condition from a later protective shutdown record.

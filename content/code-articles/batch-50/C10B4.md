# C10B4: Nissan Ariya electric parking-brake overheat

## A thermal warning in the parking-brake system

C10B4-98 means that the cited Nissan Ariya brake controller has detected a high-temperature state in the electric parking-brake system. Although the reproduced section heading contains a spelling error, the CONSULT term and detection description clearly concern overheating. The monitor operates with the power switch on and normal supply voltage; its listed delay is one second or less. No actual temperature threshold is supplied in this entry.

The possible causes include the parking-brake actuator and its wiring or connections. For a current record, the ABS actuator and electronic controller are also listed. The fail-safe response suspends the electric parking-brake function, so the vehicle needs professional assessment and secure stationary handling rather than an assumption that a switch command has applied the brake.

## The two diagnostic outcomes differ

The first diagnostic stage clears ABS memory and, after approximately a minute, checks the system while the parking brake is operated under the specified stationary conditions. If C10B4-98 is detected at that point, the manual directs attention to a stuck parking-brake actuator. It does not immediately prescribe an ABS assembly.

If that stage does not reproduce the code, a second stage waits at least a minute and uses five apply-and-release cycles before another ABS self-diagnosis. Only a continuing CRNT result in that branch directs ABS-controller replacement; a PAST result is handled as historical memory. These controlled checks are workshop procedures, not an invitation to cycle an overheating brake repeatedly. The technician must preserve the distinction between a mechanical sticking problem and a current fault that survives the prescribed verification.

# P159D: Low battery-voltage information calls for a charge-and-recheck sequence

## Read the battery signal in its proper system

For the Ariya VCM, P159D-23 concerns the Li-ion battery voltage communicated over CAN. The monitored value is below a specified limit, and the stated response is a normal stop of the high-voltage system. The source does not publish the limit or a timer, so neither should be invented from the five-character code.

This is a traction-battery entry. It should not be conflated with the separate low-voltage battery checks used to prepare many diagnostic procedures. Both systems can affect vehicle operation, but the monitored signal here is explicitly the Li-ion pack voltage.

## Recheck after the documented charging step

Nissan's flow calls for a full normal charge followed by confirmation. If P159D-23 returns, diagnosis moves to the appropriate 66 kWh or 91 kWh battery workflow. This order separates a response to insufficient charge from a condition that persists after the prescribed replenishment.

The charging step assumes the vehicle and charging connection are safe for that procedure. Damage, abnormal heat or another battery warning requires professional assessment rather than repeated charging attempts. Record charging completion and whether the code returned afterward; those observations are more useful than treating one low-voltage report as proof that an entire pack needs replacement.

The source calls for normal charging, not quick charging, in this diagnostic step. Keeping that distinction avoids substituting a different charging event and then interpreting its outcome as if the prescribed confirmation had been completed.

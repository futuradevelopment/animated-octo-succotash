# B2489: Compressor high input voltage requires battery and inverter checks

## The threshold concerns the high-voltage supply

For Ariya, B2489-17 is a compressor high-voltage input fault monitored in READY. The cited threshold is more than 420 V for at least two seconds, and compressor operation stops. This is the high-voltage system input, not the vehicle's 12-volt supply and not a refrigerant-pressure specification.

The source names the compressor, Li-ion battery and front traction inverter as possible causes. That combination is meaningful because an abnormal supply can be observed by the compressor without originating inside it.

## Check the upstream systems in the documented order

Nissan's diagnosis checks the Li-ion battery workflow first and the front inverter workflow next. The electric-compressor replacement branch is reached when those inspections are normal. Reading a high-input-voltage code under HVAC does not remove the need to examine the supplying systems.

Confirmation operates the air-conditioning system in READY with the temperature set to full cold. A stationary power-on scan without compressor demand does not reproduce all of that operating context, even if it can read the stored code.

Preserve related battery, inverter and HVAC faults before clearing memory. A qualified EV technician must assess the vehicle and use the correct high-voltage precautions; attempting to probe compressor supply terminals with improvised equipment is not an appropriate way to verify the published threshold. The code alone does not identify a failed battery pack.

# P104B: Compare charging equipment before condemning the port sensor

## A low reported value blocks quick charging

P104B-16 refers to quick-charge port temperature sensor 1 in this Ariya VCM procedure. The monitored value falls below a specified limit for more than two seconds, and quick charging is prohibited. The table does not state that limit numerically, so the code should not be translated into an invented temperature or voltage specification.

The possible causes include charging equipment as well as the sensor circuit, port and VCM. A fault observed at one charger therefore does not by itself establish that an onboard component must be replaced.

## A different charger is an intentional comparison

Nissan's first diagnostic branch repeats confirmation using a different quick charger. If the condition disappears, the flow identifies charger influence before progressing into vehicle circuit checks. If it persists, the quick-charge temperature-sensor circuit is investigated, followed by an intermittent-fault evaluation.

This comparison changes the evidence available for diagnosis; it is not a reason to keep attempting charging when the port is damaged, unusually hot or otherwise unsafe. An EV technician should assess those conditions and supervise the applicable test. Preserve which charging station produced the fault and whether it repeated elsewhere, because that history directly supports the factory sequence.

The confirmation distinguishes a preliminary power-on check from a subsequent quick-charging observation. Documenting which stage reproduces the fault helps preserve whether charging equipment had actually participated in the event.

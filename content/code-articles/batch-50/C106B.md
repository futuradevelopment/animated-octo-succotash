# C106B: Brake-pedal operation and the communicated stop-lamp signal do not agree

## The ABS controller is missing expected brake information

The Ariya C106B-64 entry concerns a stop-lamp switch signal that is not input when the brake pedal operates. CAN communication is the identified signal path, with diagnosis listed as one second or less under the stated power-on conditions. The code therefore describes a disagreement observed by ABS rather than direct proof of a broken pedal switch.

Possible causes include the switch and its circuit, BCM, communication path, ABS unit and supporting supply. Multiple brake and stability functions can be suspended, so an actual braking or stop-lamp concern needs prompt professional evaluation.

## The BCM's own result is the first branch

Nissan begins with BCM self-diagnosis and follows any detected code. It then inspects both BCM and ABS connectors and terminals before reconnecting and repeating the ABS observation. This order preserves the distinction between the source of brake information and the controller that reports it missing.

The factory note separates current from past status and does not support ABS-unit replacement for a historical record alone. Save that status and the complete scan before clearing memory, along with whether the stop lamps actually responded to pedal input.

A visual lamp check and a valid CAN signal are different observations; one cannot automatically substitute for the other. The technician needs the matching switch, body-controller and network procedures before selecting a component or declaring the related functions restored.

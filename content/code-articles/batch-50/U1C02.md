# U1C02: A shared LIN network needs symptom-led isolation

## Several body devices share the diagnostic context

The Ariya BCM's U1C02-08 entry covers a LIN communication error involving window controls and motors, roof or shade equipment and the passenger mirror controller where fitted. The monitor runs in power-on or AUTO ACC. Its scope does not mean that all listed devices have failed simultaneously.

Nissan prioritizes specified component fault variants before the general LIN investigation. It also separates current faults from past records, using actual window, roof, shade and mirror operation to decide whether further diagnosis is required.

## The pattern of failed functions narrows the path

The procedure distinguishes all windows being inoperative from one particular window failing. It checks the relevant device's power supply and ground before its LIN circuit, then considers optional roof and mirror equipment. This symptom pattern is more informative than a blanket recommendation to replace every network participant.

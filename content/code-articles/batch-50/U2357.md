# U2357: A DC/DC error message is different from a missing message

## The VCM receives an error report

For Ariya, U2357-04 means the VCM receives an error signal from the DC/DC converter over CAN for more than two seconds with the power switch on. This is not described simply as a message timing out. The distinction matters because the sending converter may have its own more specific diagnostic information.

Nissan identifies the communication circuit and DC/DC converter as possible causes. The procedure starts with CAN diagnosis, then checks the converter's self-diagnostic result before progressing through component decisions.

## Follow the sender's fault before replacing the receiver

If the converter has a code, its applicable procedure is used. The later flow includes converter replacement and repeat confirmation, reaching the VCM only if the same complaint returns. Those conditional steps should not be compressed into a claim that either controller is automatically bad when U2357 appears.

Preserve all converter and VCM results, especially whether a current converter fault accompanied the message. Testing the DC/DC unit involves high-voltage equipment and requires trained EV personnel and correct isolation procedures. A 12-volt charging symptom can be useful history, but it cannot replace the source's communication and converter-specific checks.

The confirmation allows a power-on observation before checking EV/HEV. Retaining whether the converter reports a current fault at the same time helps distinguish its original error message from a historical VCM record after the event has ended.

# B24C6: The blower control line must be distinguished from the motor itself

## The commanded-on state enables the monitor

For Ariya, B24C6-12 detects a blower control-signal circuit short to battery lasting at least one second while the blower is on. Blower operation stops as the protective response. The possible causes include the control wiring, blower motor and A/C auto amplifier.

A non-running fan is therefore not enough to identify the motor as failed. The controller may have intentionally stopped it because the command path does not behave correctly. The operating state also matters: the monitor is described with blower demand present.

## Waveform behavior and unwanted voltage answer different questions

Nissan first checks the control waveform under specified fan-command conditions. It then isolates the relevant connectors and checks the control line for unwanted voltage. Those observations distinguish the command behavior from a harness short and should not be collapsed into one generic battery-voltage reading.

The source's waveform graphics are needed for exact comparison; the text table does not provide a complete numerical duty-cycle specification for every speed. A technician must use the full diagram rather than infer missing waveform details.

After the motor branch, the flow verifies operation across the manual speed range before considering the auto amplifier. Preserve which fan speeds worked, whether the fault was current and the complete HVAC scan. These details help avoid replacing a motor without addressing the control-line condition.

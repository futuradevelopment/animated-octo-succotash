# P18A5: Auto-P cancellation is a recorded configuration state

## A stored state can differ from a broken component

The Ariya VCM's P18A5-00 entry is set when the automatic Park function has been cancelled. The table lists no component cause, numerical threshold or fail-safe action. Its meaning is therefore unusually direct: the code records the cancellation state rather than identifying a damaged parking actuator.

That distinction matters after service work. A technician should establish why automatic Park was cancelled and whether the vehicle is ready for that function to be restored, rather than treating the presence of a powertrain code as an automatic hardware-replacement instruction.

## The correction uses the designated work-support function

Nissan's procedure accesses the cancellation setting through CONSULT and changes the cancellation state to off. The wording is easy to misread: turning cancellation off restores the function. It does not mean turning automatic Park itself off.

Any configuration change must be performed with the vehicle secured and in accordance with the applicable service instructions. This article is not a substitute for verifying the actual selected range and parking security. Keep the original scan and relevant service history so the technician can distinguish an intentional workshop state from an unexpected configuration. The source provides no justification to replace the VCM or parking actuator solely for this entry.

This setting concerns automatic selection of Park, not a diagnosis of the separate parking-brake mechanism. Keeping those functions distinct prevents a configuration record from being misreported as proof of a failed brake actuator.

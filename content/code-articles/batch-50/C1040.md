# C1040: An emergency-brake report starts with ADAS controller evidence

## The brake controller reports another system's malfunction

The Ariya ABS entry C1040-63 concerns a malfunction detected in the ADAS control unit 2 system through CAN information. The power-on diagnosis is listed as two seconds or less. The source distinguishes a current fault from a past event and explicitly warns against replacing the ABS unit solely for a past DTC.

That status distinction matters because a communication interruption or supply event can leave history without demonstrating the same malfunction now. It does not mean that an actual braking or assistance complaint should be dismissed because the code later becomes historical.

## Read the originating system before judging the receiver

Nissan first performs self-diagnosis of ICC/ADAS 2. Any detected code receives its own procedure. The flow then checks ABS power and ground, followed by the ADAS and ABS connectors and terminals before repeating the ABS observation.

This order prevents a fault recorded under ABS from being automatically attributed to the ABS actuator. The communication sender, receiving controller and their electrical connections are separate diagnostic possibilities.

The confirmation is specifically power-on without entering READY, after the prescribed sleep interval. A workshop should preserve that distinction and the complete scan rather than substitute an unrelated driving test. Record which assistance warning appeared and whether braking behavior changed. Any uncertain braking performance requires professional assessment before the vehicle is driven.

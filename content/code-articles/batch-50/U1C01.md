# U1C01: Hands-free liftgate operation distinguishes a past LIN event

## The communication path serves the hands-free sensor

The Ariya BCM's U1C01-08 entry identifies a LIN communication error involving the hands-free sensor control unit. It can be detected in power-on or AUTO ACC, with a listed delay of one second or less. The possible causes are the LIN line, sensor controller and BCM.

Nissan does not treat all stored occurrences identically. A current fault proceeds to diagnosis, while a past fault prompts a check that the hands-free automatic back-door function operates correctly. That functional observation helps distinguish a historical interruption from an unresolved present complaint.

## Supply and ground precede the serial-path decision

The diagnostic flow checks the hands-free sensor controller's power supply and ground before examining automatic-back-door serial communication. A controller without a valid supply cannot be judged solely from its failure to communicate, which explains the order of these branches.

Only after those checks does the source reach the sensor-controller replacement branch. The code is not a direct instruction to replace the BCM or the entire powered liftgate mechanism.

Record whether the concern affects the hands-free request specifically or other back-door controls as well. During any operation check, keep people and objects clear of the moving door and use the manufacturer's precautions. Preserve the original fault status before clearing memory, because current and past results lead to different published next steps.

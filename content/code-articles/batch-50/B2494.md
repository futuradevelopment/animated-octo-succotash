# B2494: The heated-wheel relay circuit starts with its fuse and control supply

## The relay control path is the monitored circuit

The Ariya B2494-13 entry concerns an open or ground-short condition in the heated steering-wheel relay control circuit lasting at least one second with power on. Heated-wheel operation is stopped. The source lists a fuse, relay, A/C auto amplifier and wiring as possible causes.

That scope differs from a direct diagnosis of the heating element inside the wheel. A cold wheel can be the result of a disabled relay-control path, and the code alone does not identify the element or justify opening steering-wheel components.

## A blown fuse requires the affected circuit to be repaired

The factory flow begins with the specified fuse. If it is open, Nissan calls for repair of the affected circuit before fuse replacement. Repeatedly fitting another fuse without investigating the cause is not the documented response.

Later branches check the control-signal voltage, relay supply, wire continuity and unwanted ground connection before evaluating relay operation. Those stages distinguish loss of supply from a failed relay and from the controller commanding it.

Keep the full HVAC scan and whether other steering-wheel functions are affected. The exact fuse and connector references belong to this vehicle's wiring configuration and should be checked against its manual. Work near steering-wheel restraint components requires the appropriate service precautions; this relay code is not a reason to disturb an airbag assembly.

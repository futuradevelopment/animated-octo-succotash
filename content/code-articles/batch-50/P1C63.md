# P1C63: Connector engagement must be verified at the on-board charger

## The error concerns engagement at the charging assembly

P1C63-97 in the Ariya on-board charger procedure identifies an AC connector engagement error. The listed diagnosis can run in READY, power-on or AUTO ACC, with a 300-millisecond detection time. Normal charging is stopped as the protective response.

The possible causes include the charger and charge-port harness connector. This is not simply a statement that the external charging plug was inserted incorrectly. The diagnostic flow proceeds to the charger's high-voltage harness installation and mating connector condition, so the actual location must be established from the matching diagram.

## Installation and condition are separate inspections

Nissan first examines whether the harness connector is properly installed. It then checks both the harness-side and charger-side connectors for abnormalities. Only after secure reconnection and repeat confirmation does the flow reach the on-board charger replacement branch.

A connector that appears seated and a connector with undamaged terminals are different findings. Retaining recent charging-hardware service history can help the technician understand which of these checks is especially relevant, without assuming that recent work caused the fault.

These inspections involve high-voltage connections and require trained EV personnel, verified isolation and appropriate protective equipment. Do not unplug or reseat the charger harness as a casual test. Preserve the full suffix and fault status so the workshop can repeat the prescribed observation after correcting the actual connection condition.

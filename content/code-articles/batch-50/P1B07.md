# P1B07: A coolant-temperature circuit short is not proof of hot coolant

## Voltage detects an electrical fault

For the Ariya 91 kWh battery, P1B07-11 identifies a short-circuit condition in the battery-pack water-temperature sensing circuit. The power-on diagnosis uses the sensor voltage and is listed as two seconds or less. Its protective response limits charging and illuminates the EV-system warning.

The name describes coolant-temperature sensing, but the code does not itself report the coolant's actual temperature. Treating every temperature-related DTC as overheating would overlook the electrical condition that this entry monitors.

## Sensor condition and wiring lead to different decisions

Nissan checks the battery water-temperature sensor first, then its circuit when the sensor inspection is normal. The battery-controller replacement branch is reached only after the preceding checks. That order distinguishes a sensor fault from wiring damage and from the controller interpreting the signal.

The separate component-inspection reference supplies the applicable specifications; this DTC entry does not publish a resistance curve. A generic thermistor chart from another vehicle is therefore not an adequate substitute. Preserve related battery and thermal-management codes and any recent coolant service for the technician. Sensor access and electrical work around a traction battery require the correct EV precautions and equipment-specific service information.

The named protective pattern limits charging rather than stating a complete charging stop. Preserving that wording matters when comparing the actual complaint with the controller response described for this particular sensor-circuit code.

# P161E: The heater and compressor interlock path must remain intact

## The interlock monitors connector engagement

For Ariya, P161E-96 concerns connection-detection circuit 1. The VCM detects that a high-voltage harness connection at the junction box serving the PTC heater or electric compressor is not engaged. The published response normally stops the high-voltage system when the vehicle is stopped.

This is an interlock diagnosis, not permission to bridge the circuit so the vehicle will operate. Its purpose requires the detection path to reflect the actual connector condition. A circuit fault and an incompletely seated high-voltage connector can require different repairs even when they produce the same warning.

## Keep low-voltage feedback and high-voltage handling separate

The factory flow examines the junction-box interlock path and connector installation, then follows its supply and return wiring toward the VCM. It also includes VCM power-supply checks. That progression can distinguish the junction-box path from faults elsewhere in the detection circuit.

The underlying procedure includes strict high-voltage isolation and verification requirements. Connector handling, waveform checks and component access are work for trained EV personnel with the correct protective equipment. Report any recent heater, compressor or junction-box service to the workshop, but do not unplug, reseat or bypass orange-cable connections as a roadside experiment.

The source also warns that some diagnostic actions can create additional codes when performed with the service plug removed. The workshop must distinguish those procedure-induced records from the customer's original interlock complaint.

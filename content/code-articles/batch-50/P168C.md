# P168C: Compare both high-voltage branches before blaming main relay 2

## Startup voltage is the monitored result

For Ariya, P168C-72 occurs when front-inverter voltage remains below a specified level after system main relay 2 is commanded on as READY begins. The potential causes extend beyond the relay to the precharge path and several high-voltage components. A low observed bus voltage therefore does not isolate a single failed part.

The factory flow first prioritizes related relay-circuit DTCs, then compares battery-side, DC/DC-side and inverter-side voltage information. Missing voltage at both downstream branches leads to a different investigation from missing voltage only at the inverter.

## A broad isolation sequence explains the long cause list

Later steps separate control wiring and battery-controller supply from downstream heater, compressor, charger, converter and inverter paths. The manual uses equipment-specific isolation and resistance checks, including attention to measurement polarity and settling behavior. Those details make a generic one-reading resistance test an inadequate substitute.

This article deliberately does not provide a battery-disassembly or live-testing recipe. The sequence requires qualified EV personnel, verified de-energization and the correct battery and drivetrain documentation. Preserve the startup event and complete scan results; replacing the main relay solely from the code title can miss a downstream condition that prevents the expected voltage rise.

The initial comparison uses controller data rather than immediately opening a high-voltage connection. That lets a technician distinguish the affected voltage branch before undertaking the more invasive isolation stages required by a later result.

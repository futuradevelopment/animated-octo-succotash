# P102D: Keep the water-pump failure suffix with the code

## The base code covers several pump reports

P102D identifies electric water pump 1 in the Ariya VCM procedure, but its suffix changes the evidence. The -01 row describes an electrical malfunction report, -96 a mechanical report and -98 an overheating report. The -7B and -94 rows use broader malfunction wording; coolant is also listed for -7B. These are received failure reports, not published current or flow measurements.

The detection rows operate with the power switch on and provide no numerical delay. A technician should therefore retain the complete scan result rather than assigning a universal temperature threshold or assuming every variant proves the pump has seized.

## Follow the reported fault into the pump circuit

Nissan checks for other VCM codes first, then directs diagnosis to the electric-water-pump circuit. Confirmation includes both a power-on observation and a READY observation, allowing the relevant operating state to be tested before judging the outcome.

The final controller decision is conditional on circuit checks and a repeated fault. Simply erasing P102D does not establish coolant circulation or eliminate the cause of an overheating report. Preserve coolant-service history and the original suffix for the technician; servicing this EV thermal system requires the matching factory procedure.

For the -7B variant, the inclusion of coolant in the cause list is a useful difference from the electrical -01 report. It supports checking the specified cooling-system context rather than treating every suffix as the same internal pump failure.

# U1C00: The BCM LIN complaint points to the light-and-rain sensor path

## This LIN entry has a specific peripheral

For the Ariya BCM, U1C00-08 concerns a LIN communication error associated with the light-and-rain sensor circuit. The possible causes include an open or short in that path, the sensor and the BCM. The monitor can run with power on or in AUTO ACC, with diagnosis listed as one second or less.

That scope is narrower than saying that every vehicle network has failed. LIN communication for this sensor and the broader CAN network are different diagnostic paths. A generic communication label should not erase the specific peripheral named in the source.

## A past startup event needs a recurrence check

Nissan notes that the DTC can be detected when power is turned on following an earlier error or operation. It permits clearing that history once and checking whether the fault returns. This distinction is useful after service, but it is not a reason to repeatedly erase an active complaint without investigation.

The actual diagnostic direction is the LIN-circuit procedure. Save the original BCM result and any related automatic-lighting or wiping symptoms before reset so the technician can relate a recurring communication error to an operating complaint.

The entry provides no standalone sensor replacement instruction and no pin-level limit. Correct wiring information and the referenced circuit procedure are needed to separate the sensor, its supply and communication path, and the BCM before parts are selected.

# U1327: Separate an unwritten MAC key from an incomplete write

## The suffix identifies the setup state

In the Ariya VCM, U1327-52 means MAC-key writing is incomplete. U1327-54 means the key was not written after controller replacement. The listed explanations include the writing process, communication between CONSULT and the VCM and, for -52, installation of a controller previously used in another vehicle.

Nissan gives -54 priority when both variants appear. That order separates an omitted setup operation from a write that did not finish successfully. Treating both as a generic broken CAN network would miss the service history encoded by the suffix.

## Use the authorized writing process and verify its result

The -54 procedure repeats the prescribed key-writing process with CONSULT restarts before its final replacement branch. The -52 procedure likewise checks whether the current fault remains after writing.

Tell the servicing workshop whether a controller was replaced and whether the setup operation completed. Retain current-versus-history status and the exact suffix. A used module is not established as interchangeable merely because its connectors fit; correct part selection, authorized configuration and successful post-work self-diagnosis are essential to interpreting these entries.

The -54 sequence permits multiple writing attempts with CONSULT restarts before its final controller decision. That is a bounded factory recovery process, not evidence that endless retries will fix incompatible hardware. Record the outcome of each authorized attempt so an interrupted write can be distinguished from a completed operation followed by another current fault.

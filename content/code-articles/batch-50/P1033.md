# P1033: A battery-heater report can stop A/C control

## A communicated heater fault, not a cabin-temperature complaint

In the Ariya VCM procedure, P1033-11 is monitored in READY. The controller receives a battery coolant heater malfunction signal over CAN, and the listed detection time is more than two seconds. The possible-cause entry identifies a shorted heater IGBT. That is the manual's diagnostic direction, not proof obtained by reading the code alone.

The stated protective response stops A/C control. Consequently, a climate-control complaint may be downstream of the battery-heater fault. Replacing a cabin sensor solely because air conditioning stopped would ignore the monitored message and its origin.

## The receiving controller checks the climate controller first

Nissan first asks whether the A/C auto amplifier stores a fault. A detected A/C code receives its own diagnosis before the VCM confirmation is repeated. The battery-heater replacement branch follows only if the specified P1033-11 condition returns after those checks.

The manual distinguishes battery capacities and driveline configurations in its repair references. Those references matter because heater access and isolation procedures are not interchangeable across every Ariya. This article explains the diagnostic relationship; high-voltage heater testing and battery work belong with a qualified EV technician using the correct equipment-specific instructions.

The confirmation waits in READY before reading EV/HEV results. A power-on scan that never reaches that state does not reproduce the stated detection condition, even if it successfully communicates with the controller.

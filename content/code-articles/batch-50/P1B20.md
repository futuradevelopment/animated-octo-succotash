# P1B20: Relay-control and CPLC communication variants need different tests

## One label covers two different monitored paths

For Ariya's 91 kWh battery, P1B20-11 describes a short in the quick-charge relay-controller circuit. Its listed response stops quick charging. P1B20-87 instead concerns a CAN data error from the CPLC lasting more than two seconds, with an EV warning listed as its protective pattern.

The shared Relay 4 Control Circuit label is therefore insufficient to choose the diagnostic path. Retaining the suffix prevents a communication problem from being incorrectly treated as a shorted relay-drive wire.

## Read the branch and retain the source discrepancy

The -11 flow checks the relay-controller circuit before reaching the junction-box branch. That branch includes a parenthetical reference to a battery current sensor, although the entry concerns relay control. This unexplained wording is retained as a source-review limitation rather than being adopted as a diagnosis.

The -87 flow separately diagnoses CAN and repeats confirmation before considering the CPLC. Preserve both the suffix and associated communication codes. Circuit work and junction-box access require qualified EV personnel with the correct battery documentation. Obtain clarification of the ambiguous -11 repair reference before selecting parts; the two variants do not authorize the same replacement simply because their base code matches.

The -87 table describes erroneous data from CPLC rather than a measured relay-control short. That received-message condition is the reason the network workflow appears in its branch instead of the -11 electrical-circuit inspection.

# P172B: Two battery pressure readings disagree

## A comparison fault has two sides

The Ariya VCM monitors P172B-64 in READY by comparing battery-pack pressure sensor 1 with sensor 2. A difference exceeding a specified value for more than five seconds meets the listed condition. The source does not disclose that difference numerically, so a universal pressure-gap limit cannot be inferred.

Both sensor circuits and both sensors appear among possible causes. The code establishes disagreement, not which reading is correct. Replacing sensor 1 simply because its number comes first would discard the central purpose of this comparison.

## Use the battery-specific circuit procedure

Nissan directs diagnosis to the two pressure-sensor circuits, with separate references for the 66 kWh and 91 kWh batteries. Those references matter because a valid comparison depends on correct wiring, sensor supply and the applicable battery configuration.

Preserve the original code and associated battery faults for the technician. A disagreement between reported values should not be treated as proof of actual dangerous pack pressure, but neither should an accompanying battery warning be ignored. Accessing or testing components within a traction battery requires trained EV personnel and the correct isolation process. Clearing the comparison code without checking both signal paths does not verify that their measurements have become reliable.

Confirmation waits in READY before reviewing EV/HEV results. A difference seen only in unrelated key-off data should not be substituted for the operating state that the published correlation monitor actually specifies.

# B24A2: Unwritten climate configuration is a setup problem

## The missing information is vehicle specification

The Ariya HVAC procedure defines B24A2-55 as vehicle specification not being written. It is monitored with the power switch on and uses a delay of at least two seconds. The possible-cause entry is incomplete configuration, rather than a sensor, compressor or refrigerant defect.

That meaning is especially relevant after controller replacement or service programming. A controller can communicate with a diagnostic tool while still lacking the configuration required for the installed vehicle. Successful communication alone does not establish that setup is complete.

## Complete the prescribed configuration for the actual equipment

Nissan's diagnostic branch performs the configuration work procedure. It does not direct replacement of the A/C auto amplifier solely because this setup code is present. The correct specification must be derived from the vehicle and the applicable authorized service process, not copied from an apparently similar car.

Retain the original scan and any record of recent controller installation or configuration attempts. Those details help distinguish a setup operation that was omitted from one that was started but did not finish correctly. They do not prove that a replacement module is otherwise compatible.

The entry lists no particular fail-safe response, so it cannot by itself predict which climate functions will be unavailable. A qualified workshop should verify the configured equipment and the resulting HVAC operation. Guessing option values to make the code disappear would not demonstrate a correct vehicle specification.

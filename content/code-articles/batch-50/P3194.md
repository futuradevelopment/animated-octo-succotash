# P3194: Wheel-rotation information is abnormal at the VCM

## The VCM sees information supplied by ABS

The Ariya P3194-00 entry describes abnormalities in wheel-rotation sensor signals received from the ABS actuator and control unit with the power switch on. It is labeled as a communication error, but that label alone does not identify an open CAN wire or a particular wheel sensor.

Nissan lists the communication circuit, ABS controller and VCM as possibilities. Cruise operation is prohibited as the protective response, including the applicable ProPILOT function. That consequence should not be confused with a direct measurement of braking effectiveness.

## Companion communication errors change the route

The flow first diagnoses CAN communication. It then distinguishes a P3194-only situation from other CAN errors, explicitly treating U1000 separately in that decision. Depending on the result, the procedure leads into brake-control diagnosis or a controller sequence followed by repeat confirmation.

The important service evidence is therefore the complete code set, not just this one label. A technician should retain ABS results and the original operating event before clearing memory. Wheel-speed or brake-system evaluation must follow the appropriate safety precautions. Replacing a wheel sensor merely because wheel information is mentioned would skip the source's communication and controller distinctions.

The source's later sequence repeats confirmation after a controller change before considering the next component. That conditional order matters: the final ABS branch is not a blanket instruction to replace both controllers whenever this code appears.

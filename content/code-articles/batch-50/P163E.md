# P163E: Quick-charge current must follow the command

## A persistent command-to-current difference

The Ariya P163E-62 condition is an actual quick-charge current differing from the command by more than 3 A for over ten seconds. It is monitored during quick charging. That comparison is different from deciding whether the absolute charging speed seems slow; the command itself is part of the diagnostic evidence.

Possible causes include the external quick charger, charge port, CPLC and VCM. Nissan first repeats confirmation with a different quick charger, using the outcome to separate station influence from a fault that persists with another charging source.

## Communication and port checks follow the comparison

If the condition returns, the flow checks the CPLC for its own codes, then examines the charge port and considers intermittent faults. The VCM is reached only after the earlier branches, rather than being declared defective by the current difference alone.

Useful service history includes the charging station, elapsed session time and whether the same failure occurred elsewhere. Do not infer a battery-capacity defect solely from a reduced charge rate or this code. A technician must use the prescribed charging observation and safe hardware inspection; any damaged connector or abnormal heating must be addressed before repeating a charging test.

The confirmation includes a full quick-charge observation followed by a stop and subsequent scan. Merely noting the station's displayed current while charging continues does not capture the entire factory confirmation sequence.

# P1B05: A broad temperature disagreement needs individual sensor codes

## A majority comparison differs from one shorted sensor

P1B05-62 in the Ariya 91 kWh battery concerns a deviation in temperature characteristics involving more than half of the module-temperature sensors. The listed condition must continue for more than two seconds. The source does not supply a numerical temperature-gap limit, so that threshold cannot be reconstructed from the label.

The factory procedure looks for the individual P1B30-through-P1B3B sensor-family codes. When one is present, it directs checks of the indicated circuit and sensor before deciding between the relevant module and cell controller.

## The absence of a local code creates a different branch

When no individual sensor fault identifies a location, Nissan repeats confirmation after the prescribed diagnostic-memory sequence. Its broad controller-replacement branch is conditional on recurrence there. It should not be presented as the first repair for any temperature-related warning.

Record the entire battery scan, including both battery diagnostic groups and any numbered sensor entries. That preserves the information needed to distinguish a localized sensing-path problem from the wider comparison condition. High-voltage pack access, controller configuration and module work require qualified EV personnel and the matching 91 kWh instructions; the article does not establish that several modules are physically overheating.

The source distinguishes an individual sensor's circuit result from a sensor inspection result. A repaired harness and a replaced sensor are therefore different outcomes, even if either correction eventually removes the wider temperature-comparison warning.

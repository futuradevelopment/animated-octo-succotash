# P0E89: Charging-current demand exceeds the accepted request range

## What the threshold actually describes

P0E89 is labeled battery charger B input current too high in Ford's hybrid OBD summary. The stated failure condition is a received battery charging current request above 100 amperes. Monitoring applies while the charger is in its ready state, with a listed duration below one second.

The distinction between requested current and actual flowing current is essential. This row does not prove that 100 amperes were measured through an AC charging cable or that an inverter power stage physically drew that current. It identifies a control request outside the allowed range in the documented architecture.

## Investigate the control relationship

Preserve the current request, charger state and module-specific faults before resetting the system. The same section separately checks lost hybrid-controller communication, lost battery-controller communication and invalid battery data. A technician can use those results to distinguish a numerical request problem from a missing or invalid message.

The code is not, on its own, a command to replace the charge port, charger or traction battery. The corresponding factory service procedure must establish which controller originated the request, whether its inputs were credible and whether the event repeats under the proper readiness conditions.

Keep diagnosis at the scan-data level until a qualified hybrid technician determines that physical high-voltage testing is required. The monitor threshold is useful for understanding a rejected demand, but it is not a safe current-test instruction for exposed energized charging components.

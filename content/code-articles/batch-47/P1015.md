# P1015: Wastegate control pressure misses a stable target

## The target must first settle

Ford lists P1015 as wastegate control pressure lower than expected. In the cited control-pressure test, the desired-pressure stability condition is bounded by 0.5 inch of mercury, and the listed malfunction error is greater than 3 inches of mercury. The monitoring duration is five seconds. The wastegate pressure, wastegate control and BARO inputs must be usable.

This is a control-result comparison rather than the low-voltage circuit test. A pressure sensor can remain electrically in range while the controlled pressure fails to follow the expected value. Conversely, unreliable pressure or BARO information can make a pneumatic system appear to miss its target.

## Preserve command and response together

A diagnostic recording should include desired pressure, measured pressure and the operating state in which the request became stable. A rapid command change is not the same observation as a persistent error during the qualified interval. Before using that difference to condemn a valve or actuator, a technician should establish that the measurement path is credible and use the matching pneumatic-system procedure.

The adjacent P1016 row has the same printed description but a different error magnitude. That duplication is retained as a source limitation; the summary does not explain the directional distinction between the two codes. This article therefore does not turn either row into an unsupported universal hose or component replacement instruction.

The documented thresholds are useful for understanding why a fault matured. They do not replace calibration-specific service checks or prove which part caused the mismatch.

# P0164: Excess voltage on the bank-two third oxygen-sensor signal

## The voltage exceeds the monitoring envelope

The 2010 Ford OBD summary lists P0164 for the bank 2, sensor 3 oxygen-sensor signal exceeding 1.1 volts for ten seconds. Its continuous overvoltage check requires the rear sensor heaters to be usable, inferred sensor temperature of at least 400°F and battery voltage between 11 and 18 volts.

This is different from a functional test that asks whether a sensor can switch between rich and lean states. A high-voltage electrical event should not be treated simply as evidence of an overly rich exhaust mixture. The source identifies heater or battery power shorted to the signal as the type of condition behind the overvoltage check.

## Verify that the third sensor actually exists

The document discusses systems with a third downstream sensor for very-long-term fuel correction. It also states that Ford's first PZEV example used a four-cylinder engine and only bank-one codes. The generic bank-two table entry does not prove that a particular vehicle has bank 2, sensor 3.

A technician must establish the actual exhaust-sensor arrangement before selecting a connector or test point. Preserve the signal voltage, heater faults and operating snapshot, then use the matching circuit procedure to distinguish signal contamination from sensor behavior.

The overview supplies no universal pinout or repair sequence. Confirmation should demonstrate a valid signal on the correctly identified circuit and a completed monitor, not merely a rich/lean reading obtained from a different downstream sensor.

# U2111: Low communication voltage on a dual-throttle sensing channel

## The documented electrical event

Ford lists U2111 in the throttle-position sensor checks for throttle body B on dual-throttle applications. The fault is a low SENT communication-circuit condition lasting more than four seconds, mapped to U0608 with subtype 16. It is distinct from an intermittent data event or a reported internal sensor-device fault.

The source has a naming inconsistency: the section and neighboring rows identify sensor/switch C, while the U2111 line says sensor/switch B. Both statements occur in the original table. This article retains a source-review flag rather than silently deciding which printed letter should replace the other.

## Resolve the physical channel before testing

Preserve the complete code, subtype and controller identification. The correct wiring diagram and service definition must establish which connector and sensing channel the installed calibration means. The letter on a shortened scan-tool description is not sufficient to choose a throttle body when the source itself is inconsistent.

A communication line held low does not directly measure a closed throttle angle. Its significance is that valid digitally encoded position information cannot be trusted. Ford lists MIL and wrench warnings, so any associated loss of predictable throttle response should be assessed professionally.

The summary provides the timing and electrical classification, but not a universal terminal map or a component replacement verdict. Confirming the actual dual-throttle architecture is part of the diagnosis, not a detail to assume after parts have been ordered.

# P1A08: A generator-mode command conflicts with the neutral operating state

## The operating state defines the fault

Ford's internal hybrid-controller checks list P1A08 as generator mode signal. The detailed condition concerns an invalid generator-mode command for Neutral operation when vehicle speed is below 2 km/h and the selected gear is Neutral. The table describes continuous monitoring and a duration below one second.

This is a command-validity problem in a particular operating state. It does not, by itself, show that the generator windings are open, that the traction battery has failed or that a mechanical gear is physically engaged. The control module is evaluating whether the requested mode is appropriate to the state it understands.

## Preserve the state seen by the controller

Record the reported gear position, vehicle speed, generator operating command and other hybrid-controller faults. A disagreement between actual selection and received range information would lead to a different investigation from a valid Neutral input accompanied by an inappropriate command. The summary does not choose between those possibilities.

A technician should use the matching hybrid-control procedure to examine that relationship and any relevant communication or processor diagnostics. Clearing memory before saving the state can remove the evidence needed to explain why the command was rejected.

Do not attempt to manipulate generator control or perform improvised Neutral tests around moving driveline components. The overview contains a diagnostic condition, not a service actuation procedure. Professional confirmation should establish that the controller recognizes the correct state and requests a valid mode safely.

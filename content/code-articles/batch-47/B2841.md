# B2841: Connector B installation is checked separately at the SRS unit

## Do not substitute the neighboring connector code

B2841-13 identifies SRS-unit connector B not properly installed in the cited Honda procedure. Although its confirmation timing resembles the connector-A check, the reported connection is different. Keeping the complete code prevents a technician from inspecting or replacing parts associated with the wrong connector.

Honda specifies vehicle ON mode, a battery supply of 10 to 16 volts and an approximately six-second confirmation period. One drive cycle can set the fault and illuminate the SRS indicator. The page lists poor connector-B contact and internal SRS-unit failure as possible causes, without declaring the list exhaustive.

## Establish a repeatable result safely

Save the code status, battery information and any related restraint diagnostics. The source cautions that low battery charge can distort test results; below 10 volts the SRS lamp can illuminate for the supply condition itself. That observation should remain separate from a correctly enabled connector-installation result.

An SRS-qualified technician must follow the exact deactivation and connector-handling procedure before inspecting the unit. The advanced-diagnostics extract is not a substitute for those service instructions and does not authorize live probing or connector bypasses.

If the fault does not recur under the proper conditions, retain the intermittent connection history instead of assuming the original warning was meaningless. If it does recur, the full troubleshooting procedure must distinguish the connection from the unit itself before a replacement decision is made.

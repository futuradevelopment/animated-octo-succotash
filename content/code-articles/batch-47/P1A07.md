# P1A07: The inverter sees an unexpectedly low high-voltage input

## Two paths can report the low-voltage condition

In the cited Ford hybrid monitor, P1A07 is inverter high-voltage performance. Its threshold can be met when the battery-voltage CAN value is below 150 volts for 100 milliseconds, or when the measured inverter input voltage is below that level for the same duration. Either path can satisfy the stated condition.

The check begins after 500 milliseconds of vehicle power-up time and uses a low-voltage battery window of 6 to 19 volts. The source also names battery communication and inverter voltage-sensor diagnostics among the prerequisites. A high-voltage performance label therefore cannot be interpreted without the accompanying low-voltage and communication context.

## Distinguish a low value from a disagreement

Ford separately identifies a correlation diagnostic when voltage measurements disagree by more than the permitted amount. P1A07 instead asks whether either specified input falls below its low boundary. Recording both values helps avoid treating a low-voltage event and a sensor-to-sensor disagreement as the same failure.

A hybrid-qualified technician should preserve power-up timing, contactor state and related faults, then follow the matching factory procedure. The overview does not establish whether the battery, contactors, measurement circuitry or another part caused the low reading.

The 150-volt threshold is a monitor criterion, not permission to probe the high-voltage bus. Safe isolation, verification of de-energization and any required electrical testing belong to the vehicle-specific professional service process.

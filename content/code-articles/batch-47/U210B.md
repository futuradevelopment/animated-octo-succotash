# U210B: A legacy fuel-pump disable signal must be read with its equipment context

## Forty percent is not universally a fault

Ford's mechanical-returnless fuel-system summary lists U210B for the fuel pump A disabled circuit and explicitly marks the code obsolete. The corresponding legacy feedback value is a 40% fuel-pump-monitor duty cycle. That number has a conditional meaning in the surrounding table.

For vehicles with an event-notification signal, 40% indicates that the pump module is receiving an invalid signal from the restraints control module. For vehicles without that signal, the same duty cycle indicates normal pump-module operation. Identifying the vehicle's equipment is therefore essential before interpreting the waveform.

## Separate command, feedback and crash-related information

The pump-control command and pump-monitor feedback are different signals. A percentage taken from the command table cannot be substituted for the feedback percentage associated with this diagnostic. Record the full module scan and the relevant signal identity before a technician tests the system.

The documented pump check operates with battery voltage from 11 to 16 volts and typically uses two to five seconds. The source does not authorize bypassing an event-notification or fuel-disable function to make the engine run. Such intervention could defeat a protective feature and would not explain the invalid signal.

Use the installed calibration's current factory procedure, especially because this code is labeled obsolete. Retain any restraints-module or communication faults and let a qualified technician establish the signal path before condemning the fuel pump itself.

# B1232: Evaporator temperature circuit short has two wiring paths

## The temperature signal is the subject

Honda B1232 identifies a short in the evaporator temperature sensor circuit. The climate unit may also display indicator 0A for this diagnosis. It is an electrical temperature-sensor fault, not a measurement of refrigerant pressure or evidence by itself that the evaporator assembly must be replaced.

The source first duplicates the complaint using the climate self-diagnostic function after a code clear and ignition cycle. If the fault does not return, the stated direction is to check for loose wiring or poor connections in this sensor circuit.

## Two shorts are tested separately

For a persistent code, Honda disconnects both the climate controller and the evaporator temperature sensor. It checks T-EVA for an unwanted connection to body ground. If that test is satisfactory, it then checks for an unwanted connection between T-EVA and SENS COM-H.

These branches distinguish a grounded signal from a signal shorted to its common return. Both can require harness repair, but neither is demonstrated simply by reading B1232. Connector isolation is part of what makes the continuity result meaningful.

## Component testing comes afterward

When the wiring passes, the procedure calls for the separate evaporator-temperature-sensor test. A failed sensor leads to sensor replacement; a passing sensor leads to climate-unit replacement. The extract does not include that sensor's resistance-temperature chart, so a generic resistance value would be an unsupported addition. Have a technician follow the full vehicle procedure before authorizing parts or unrelated refrigerant work.

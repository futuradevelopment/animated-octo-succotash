# B1042: Wiper backup line is checked before control units

## What the security-line title refers to

Honda calls B1042 a front-wiper security-line error. The actual test sequence identifies the BACK UP(WIPER) circuit between the BCM and the windshield wiper control unit/motor. This circuit identity is more useful for diagnosis than interpreting the word security as an immobilizer problem.

After a clear-and-recheck confirms the fault, Honda isolates both ends of the backup line. The first wiring branch checks for a short to ground. If it is not grounded, the next branch checks end-to-end continuity for an open or poor connection. These are different failure modes and lead to wiring repair rather than immediate module replacement.

## Replacement depends on the preceding results

Only after the backup wire passes those checks does the source direct replacement of the wiper control unit/motor. If B1042 remains after that step, the BCM is the subsequent replacement direction. The order matters: the document does not call for replacing both assemblies together on the strength of the initial code.

If the code fails to return during verification, Honda treats it as intermittent and asks for attention to loose or poor connections. Multiple body faults first require the referenced B-CAN diagnostic sequence.

## Visibility and workshop precautions

Save the scan results and report whether wiping or parking behavior is unreliable. Avoid driving where poor wiper operation compromises visibility. The connector-isolation tests should be performed by a qualified technician using the applicable wiring diagram; this overview is not a live-circuit probing procedure.

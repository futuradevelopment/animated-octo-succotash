# P1920: Communicated engine speed disagrees with the hybrid calculation

## A cross-check between two speed values

Ford's hybrid P1920 monitor compares the engine-speed information received over CAN with an internal engine-speed calculation. The cited failure conditions are a difference greater than 500 rpm for 500 milliseconds, or greater than 550 rpm for 1,000 milliseconds. Both printed alternatives are preserved rather than merged into a new invented threshold.

This is not the same observation as losing every engine-controller message. The adjacent communication diagnostic has its own missing-message criterion. P1920 can therefore direct attention toward the credibility and agreement of speed information even when communication has not disappeared entirely.

## Keep both measurements and their timing

Capture the received engine speed, any available calculated speed and the state in which the mismatch occurred. Related engine, generator, motor and network faults may help a qualified technician determine whether one input or the calculation context is unreliable. A single dashboard tachometer reading cannot reproduce the comparison inside the hybrid controller.

The overview describes continuous monitoring but does not supply a crank-sensor replacement rule or a complete network test sequence. The correct vehicle procedure must identify how the internal speed is derived and what prerequisites apply to its interpretation.

Avoid treating the code as proof of engine overspeed. It describes a difference between values, not a standalone maximum-rpm limit. Verification should demonstrate consistent speed information through the relevant operating transition after the underlying cause has been established.

# B1003: BCM update did not complete correctly

## This code concerns an update event

The Honda procedure states that B1003 appears when a body control module update has not completed correctly. That definition gives the repair history particular value: record any recent programming attempt, interruption or module work together with the original scan results.

Honda first verifies persistence by clearing the DTC with HDS, cycling OFF and ON and checking again. A returning B1003 directs the technician to update the BCM. If the code does not return, the source treats the event as intermittent and the system as operating correctly at that moment. It does not prescribe automatic module replacement.

## Programming support must match the procedure

Before the update, this source requires a fully charged vehicle battery and a 12-volt jumper battery to maintain voltage. It explicitly distinguishes that arrangement from a battery charger. It also prohibits switching to ACCESSORY or OFF during reprogramming. These are instructions for this factory procedure, not a universal specification for every manufacturer's programming equipment.

A qualified repairer should use the correct software and complete vehicle-specific update workflow. Repeatedly attempting a flash without resolving an unstable supply or an interrupted procedure does not address the reason the earlier update failed.

## Keep related faults in context

When several body-system codes are stored, Honda calls for B-CAN System Diagnosis Test Mode A. Preserve those records before the update so a communication problem is not lost among programming symptoms. The supplied page gives no update-file identifier or VIN-wide applicability, so those must be established separately.

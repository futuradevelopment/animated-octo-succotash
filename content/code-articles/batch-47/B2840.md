# B2840: The restraint controller does not accept connector A installation

## A connector-specific installation check

Honda identifies B2840-13 as SRS-unit connector A not properly installed. The cited confirmation is performed with vehicle ON mode, a 10-to-16-volt battery supply and approximately six seconds of waiting. The SRS indicator can illuminate after one drive cycle.

The possible-cause field names a poor connection between connector A and the SRS unit, but it also includes internal SRS-unit failure. The code therefore points to a specific installation check without proving, from the code alone, that an external connector is visibly loose.

## Keep restraint-system work controlled

Record the exact suffix and any recent authorized work near the restraint controller. A technician should use the vehicle's SRS precautions and connector-identification procedure before touching the connection. The connector letter is application-specific; it is not permission to unplug whichever yellow connector is easiest to reach.

Battery condition also matters. Honda warns that an undercharged battery can invalidate testing and that supply below 10 volts can illuminate the SRS indicator independently of this qualified confirmation. Preserve that context rather than replacing the controller based only on a warning lamp.

The advanced page does not provide a terminal map, retention-force specification or safe powered disconnection procedure. Proper verification requires the matching SRS troubleshooting steps and a valid repeat check. Do not bridge connector interlocks or deployment circuits to suppress the diagnostic; doing so would remove evidence and could compromise restraint operation.

# P2276: The last bank-two oxygen sensor does not demonstrate a rich transition

## A functional switching result

Ford lists P2276 for bank 2, sensor 3 remaining lean in the rear oxygen-sensor functional monitor. The test watches the sensor's rich and lean excursions during operation and can deliberately alter mixture to obtain a response when ordinary operation has not provided one. It is therefore different from the circuit-overvoltage test for the same sensor position.

Several prerequisites must be satisfied, including completed front-sensor response checks, usable heaters and no fuel-system or sensor-circuit faults that would invalidate the comparison. Typical entry conditions also include warmed sensor operation, closed-loop fueling and part throttle.

## Confirm the sensor layout and test completion

The overview discusses third downstream sensors used for long-term fuel correction, but its early four-cylinder PZEV example only uses bank one. The printed bank-two code does not establish that a particular vehicle has a third sensor on that bank. Verify the exhaust layout before interpreting a connector or scan parameter as HO2S23.

A qualified technician should preserve the completed monitor result and the sensor response during an appropriate commanded or natural mixture transition. A single lean reading during an unqualified condition is not the complete failure test.

The source's concise rich/lean threshold labels are not converted here into a universal switching specification. Application-specific service information must establish the correct test and interpretation. The code alone does not prove a failed sensor or a catalytic-converter replacement requirement.

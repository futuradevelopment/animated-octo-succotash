# U1604: Battery monitor F-CAN fault can light POWER SYSTEM only

## Read the correct warning and memory

U1604 is the battery condition monitor's F-CAN communication diagnosis for motor-controller information. Honda specifies a pending record during the first failing drive cycle. A recurrence on the next cycle stores a confirmed code and freeze data and turns on the POWER SYSTEM indicator; the MIL remains off.

The POWER SYSTEM indicator can clear on the next trip in which the diagnostic runs without the malfunction. That recovery rule differs from a three-trip MIL rule and makes it particularly useful to preserve the stored history when the dashboard appears normal at the repair appointment.

## Data timing and the relay connection

The monitor becomes eligible five seconds after the 12-volt battery reaches 10.2 V following ON mode. Both missing signals and abnormal motor-controller information have a stated threshold of at least two seconds.

The cause list includes open or shorted F-CAN A_H/A_L circuits, an open IGHLD or IGA relay path, an IGHLD1 relay stuck off and an internal fault in either participating module. The relay connection is significant: a module that loses its required power can disappear from the network without a failed communication wire.

## Avoid a battery-cell conclusion

The battery condition monitor is the reporting unit here, but this definition does not diagnose an individual traction-battery cell. Have a qualified technician evaluate the low-voltage supply, relay and data paths using the correct wiring information. Keep the pending-versus-confirmed status and indicator history with the repair record before clearing the fault.

# P2072: A historical throttle controller recognizes an ice-blockage condition

## Controller generation is essential

Ford's 2010 OBD summary lists P2072 as throttle-body ice blockage and explicitly limits it to Gen2 electronic throttle control. The code is non-MIL in that table, with continuous monitoring and a listed duration below five seconds. It should not be assumed to exist with identical behavior on later integrated throttle controllers.

The surrounding explanation describes a separate Gen2 throttle-position controller receiving a duty-cycle request from the main processor. One defined command range is an ice-breaker mode, distinct from the ranges used for learning the hard stop or normal throttle operation. That architecture explains the code's context without proving that every restricted throttle contains ice.

## Establish conditions before disturbing the throttle

Record ambient conditions, controller identity and companion stuck-throttle or actuator faults. A technician can then use the matching service procedure to distinguish the documented ice-blockage diagnosis from other causes of restricted movement. The summary does not provide a universal thawing, cleaning or replacement instruction.

Do not force an energized throttle plate by hand or treat the duty-cycle table as a guide for applying external signals. It describes internal controller communication, not a safe bench-test procedure for the owner.

If throttle response is unreliable, professional assessment takes priority over repeated attempts to reproduce the symptom. Confirmation should match the actual Gen2 system and the original environmental conditions while establishing safe, predictable throttle movement.

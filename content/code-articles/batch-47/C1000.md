# C1000: Stability-control activation lasts longer than the monitor accepts

## The code concerns an operating event

The Honda C1000-94 extract identifies ABS/VSA activation time too long. Its monitor executes while VSA is operating, with a listed duration of about 30 seconds and a minimum 12-volt-system voltage of 10 volts. The documented confirmation includes a road-speed condition, so a stationary scan cannot reproduce every part of the evaluation.

The source lists VSA-modulator internal failure as a possible cause but warns that its cause list may be incomplete. The code should therefore be preserved as evidence of an excessive activation event, not treated as an unconditional replacement instruction.

## Understand which functions the response removes

The listed fail-safe action stops traction control, stability assistance, engine-drag torque control and agile-handling assistance. This explains why several handling-related functions can become unavailable together even when only one primary diagnostic is being investigated.

A technician should capture the event record, system voltage and companion wheel-speed or brake-control faults before clearing memory. Any confirmation drive must follow the full factory procedure, local conditions and the vehicle's actual safety state. The source specifically rejects substituting operation on a lift for the stated road test.

Do not deliberately provoke a skid or sustained stability intervention to see whether the code returns. Professional diagnosis should first determine whether the vehicle is suitable for testing and establish why the activation persisted. A cleared warning without a qualified completed evaluation does not demonstrate that the original condition has been resolved.

# P139B: Upstream EGR sensing trouble produces a large positive differential

## Read the pressure relationship

The Ford P139B monitor concerns the upstream hose of EGR sensor C. In the cited table, the qualifying malfunction is a differential-pressure signal greater than 13.0 kPa for 25 seconds. The test follows completed electrical checks and requires usable EGR valve, temperature and pressure information.

That positive-pressure threshold distinguishes it from the downstream hose check, which looks for a sustained negative value. A generic description such as EGR pressure fault loses the direction that helps a technician select the appropriate sensing side.

## Verify the sensing path before judging flow

Preserve the actual DPFE value, EGR operating state and companion circuit faults. A hose that is disconnected or obstructed can prevent the sensor from representing the intended pressure difference. However, the code does not distinguish those two physical possibilities by itself, and the OBD table does not provide a universal cleaning or hose-replacement procedure.

The next step is a vehicle-specific inspection of routing and sensing passages by a technician familiar with the engine's EGR arrangement. Hot exhaust components must be allowed to cool before close inspection. Electrical plausibility should also be established before using a pressure value to condemn mechanical parts.

The source's entry-condition wording calls EGR flow near zero while printing a greater-than value beside it. That internal inconsistency remains unresolved here; no flow threshold is invented from it. The clearly printed pressure-and-time criterion is retained, and the article remains flagged for review of the ambiguous entry condition.

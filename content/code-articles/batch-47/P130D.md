# P130D: Severe knock events trigger a power-protection response

## The event behind limited power

Ford calls P130D an engine-knock/combustion performance fault with forced limited power. The cited monitor counts severe knock events: its typical threshold is more than ten events within a span of several thousand combustion events. This is an event-based test, not the same ten-second electrical check used for adjacent knock-sensor circuit codes.

The documented severe-knock operating window includes engine load of at least 90%, engine speed from 1,000 to 4,000 rpm and coolant temperature of at least 140°F. These figures explain the calibration's observation window. They are not instructions to reproduce heavy-load combustion trouble on a public road.

## Distinguish combustion evidence from sensor continuity

Save the operating snapshot and all related ignition, fueling and sensor faults. An electrical knock-sensor code asks whether a signal path is usable; P130D concerns the event rate recognized by the combustion protection strategy. Replacing a knock sensor solely because its name appears nearby in a code table would not address that distinction.

The summary does not assign a single cause, fuel specification change or component replacement to this event count. A qualified technician should investigate the correct engine's combustion and protection strategy using its service information, while preserving the conditions that prompted reduced power.

Avoid repeated high-load attempts to see whether the warning returns. The controller has identified a condition serious enough to limit output, and a safe verification plan should first establish why that protection was invoked.

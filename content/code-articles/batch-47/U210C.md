# U210C: The second fuel-pump module reports a legacy disabled-circuit state

## Identify the second pump channel

U210C is the fuel pump B disabled-circuit code in Ford's cited returnless-system table. It is marked obsolete and associated with a 40% pump-monitor feedback duty cycle. A separate code covers loss of communication with module B, while other rows identify invalid control data, driver-module errors and secondary-circuit faults.

Those distinctions prevent a stored disable-state code from being treated as a generic instruction to replace pump B. No feedback, invalid feedback and a particular disable-related feedback state are different observations. The factory table lists no feedback as zero or 100% duty cycle for the communication check, rather than the 40% state attached to U210C.

## Establish the applicable signaling arrangement

Capture the second pump module's identity and its monitor-feedback value, with battery voltage and companion codes. The relevant check uses an 11-to-16-volt supply window and a two-to-five-second monitoring duration. Its percentage belongs to the feedback circuit, not an arbitrary pump-speed command.

The nearby system explanation also shows that a 40% feedback value depends on whether an event-notification signal is fitted. A technician needs the exact application diagram and current service definition before selecting a fault path for this obsolete code.

Do not bypass a pump-disable input or infer a failed motor from the code alone. Proper verification resolves why the controller interpreted the second module's state as disabled and confirms normal communication under the correct equipment configuration.

# P164B: Bank-two oxygen-sensor trim performance is an interface diagnosis

## Establish which sensor system is fitted

For P164B, Ford identifies bank 2, sensor 1 positive-current trim circuit performance. The cited implementation uses an NTK UEGO sensor, and the reported fault is an erratic RL circuit. The bank designation identifies the affected upstream sensor system; it does not establish a catalyst failure or a measured lean mixture.

The interface electronics must report the malfunction while the heater prerequisites are satisfied. Ford lists continuous monitoring, an 11-to-16-volt battery window and a ten-second duration. A scan made during low supply voltage or incomplete heater operation should therefore be interpreted with the companion diagnostics intact.

## Retain the distinction between performance and circuit extremes

The same table gives different codes for the bank-two trim path being open, low or high. P164B preserves a different observation: erratic operation reported by the interface. Recording the exact code is more useful than summarizing the entire family as an oxygen-sensor fault.

Where service information allows it, a technician can compare the two upstream sensor systems while respecting their circuit design. That comparison may help localize an inconsistent response, but the summary does not authorize swapping connectors or applying a conventional narrowband test to the UEGO wiring.

Confirmation should include the correct sensor identification, a valid supply and heater state, and an opportunity for the interface monitor to complete. The document contains no universal trim-circuit resistance or parts-replacement instruction, so those decisions require the matching factory diagnostic procedure.

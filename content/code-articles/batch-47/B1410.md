# B1410: Primary cellular antenna disconnect does not prove an open lead

## Read the test branch as well as the title

B1410 is titled primary cellular antenna disconnect in the Honda telematics procedure. However, its diagnostic branch checks continuity between two specified terminals at the disconnected telematics antenna connection. Continuity sends the repair toward a shorted antenna lead; absence of continuity sends it toward the TEL antenna.

That result shows why the word disconnect should not be treated as proof of an open wire. The fault label summarizes what the system detected, while the factory isolation test separates the listed repair directions.

## Verification includes a shutdown interval

Honda first checks connectors for poor connections or loose terminals. The code is cleared, the vehicle is switched OFF and the driver's door is opened for a wait longer than one minute. After switching ON, the procedure waits at least another minute before reading DTCs.

If B1410 does not return, the source calls it intermittent and says the system is functioning correctly at that time. A returning code proceeds to the antenna check, again following the specified shutdown interval before connector disconnection.

## Appropriate service scope

A technician should use the exact telematics connector layout and antenna-lead information before conducting the continuity test. This extract does not diagnose cellular coverage, an account subscription or an external network outage. Preserve the fault and any service symptoms, but do not replace the telematics controller or infer a software remedy from this code when neither is the stated outcome of its supplied branch.

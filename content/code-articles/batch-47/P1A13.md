# P1A13: Regenerative braking is disabled at the brake controller’s request

## Follow the request back to its origin

In Ford's hybrid-system check, P1A13 records regenerative braking being disabled at the request of the brake-system control module because of a regenerative-braking fault. The hybrid controller is recording a system response initiated elsewhere. The code alone does not identify the original failed sensor, actuator or communication path.

The braking-system explanation shows why that distinction matters. The brake controller continuously coordinates allowed regenerative braking with hydraulic braking and powertrain information. A fault that prevents dependable coordination can therefore remove regeneration without proving that the drive motor itself has failed.

## Read the brake and hybrid modules together

Preserve the brake-controller faults alongside P1A13, including their status and operating snapshot. Ford notes that some PHEV brake-related OBD diagnostics are passed through the hybrid controller under different code numbers. Matching the reporting modules prevents a single underlying brake fault from being mistaken for several unrelated component failures.

The source describes continuous monitoring but does not provide a universal regeneration-disabled threshold or repair instruction for every originating brake fault. The specific brake-system diagnosis must establish why the request was made before normal regenerative operation can be confirmed.

Do not assume that loss of regeneration leaves braking behavior unchanged, and do not attempt an aggressive road test to measure its effect. If brake feel, warning messages or stopping behavior are abnormal, arrange professional diagnosis. Clearing the hybrid response code without resolving its originating brake fault does not explain the protective request.

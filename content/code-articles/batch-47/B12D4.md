# B12D4: Starter-request fault is traced between BCM and PCM

## A request signal is not the starter motor

Honda B12D4 identifies a starter-request output circuit malfunction. The source's diagnostic context is the power control unit, while the actual electrical sequence examines the STS connection between the BCM and PCM. The code does not by itself establish a failed starter motor or authorize replacing one.

Verification uses five READY-to-OFF cycles after clearing the code. A nonreturning fault is treated as intermittent, with loose or poor connections needing attention. Multiple body faults require the B-CAN diagnostic order referenced in the procedure.

## Isolate the wiring before selecting a module

For a persistent fault, Honda first isolates the relevant modules and tests STS for a short to power, followed by a short to ground. Only after those branches pass does it reconnect the BCM for internal-output checks. Those decisions distinguish harness faults from a control-unit output problem.

The later BCM-versus-PCM branch contains unclear voltage wording: it asks whether voltage varies from a value of 1.72 V or less, without clearly describing the expected transition. This article remains flagged for review rather than turning that wording into an unambiguous replacement threshold.

## Why the complete procedure is necessary

The source includes a scan-tool SCS step and a wait before PCM disconnection. Those preparatory requirements are part of the factory test, not optional details for live probing. Have a qualified technician verify the current vehicle-specific procedure and connector states before measurements or module replacement. Preserve the original code and starting complaint first.

# B1193: Steering-switch LIN fault starts with power and ground

## A lost switch can be an unpowered switch

Honda B1193 means the gauge control module has lost communication with the steering switch connected by LIN. The procedure identifies the audio remote-HFL switch as the component tested. This is a LIN diagnosis, so a generic two-wire CAN test would not follow the documented circuit.

The factory sequence first confirms recurrence after clearing the code, cycling OFF and ON and waiting at least four seconds. If it remains, fuse C30 is checked. A repeated blown fuse requires correction of a short in that circuit rather than repeated fuse replacement.

## Supply, return and data are separate decisions

Next, Honda checks for battery voltage on the switch's +B feed. Missing voltage directs repair of an open or high-resistance feed. The following branch checks the steering ground path and identifies G403 when that return is deficient.

Only after those supply checks does the procedure test continuity on the LIN(START SW)/STRG SW LIN connection between the gauge module and switch. An open or poor connection leads to wiring repair. With that path intact, the final direction is replacement of the audio remote-HFL switch.

## Why this order matters

Replacing a switch before verifying its feed and return could leave the communication loss unchanged. Preserve the original scan and follow the referenced B-CAN diagnostic order when other body faults are present. Steering-wheel access and connector work should be handled by a qualified technician using the applicable restraint-system precautions and wiring information.

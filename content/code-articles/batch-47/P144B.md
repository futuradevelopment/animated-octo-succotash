# P144B: The hybrid EVAP fresh-air path is tested during purge

## A fresh-air restriction, not merely an EVAP leak

Ford's P144B monitor concerns the fresh-air line to the evaporative leak-check module. The test runs once per driving cycle with the engine running, purge flow commanded and the changeover valve open. The excessive-vacuum check must already have completed successfully.

This arrangement distinguishes a restriction investigation from the engine-off small-leak test. The controller is observing how the fresh-air path behaves during purge, not simply looking for a loose fuel cap. The cited entry conditions include closed-loop fueling, at least 11 volts of battery supply and usable pressure and airflow information.

## Keep the pressure reference explicit

The printed thresholds distinguish relative and absolute vacuum at the leak-check module. They give a relative value below −20 inches of water or an absolute-vacuum value above 60 inches of water. Those labels must not be collapsed into one unlabeled pressure number when interpreting scan data.

The source also provides Mode $06 identification for the blocked fresh-air-line result and warns that a default zero can mean the monitor has never completed. Preserve test completion status with the result before treating a displayed zero as a pass.

A technician should inspect and test the correct fresh-air, purge and valve arrangement using the vehicle-specific procedure. The overview does not establish a particular blocked component or authorize sealing lines to reproduce the fault. Its useful contribution is the test's operating state, pressure-reference distinction and separation from a leak diagnosis.

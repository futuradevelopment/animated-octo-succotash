# B1413: TEL antenna short needs isolated lead checks

## Separate a ground short from a shield short

Honda B1413 identifies the TEL antenna as shorted to ground. After verifying recurrence, the procedure disconnects the telematics unit's D two-pin connection and the antenna connection. It first tests TEL ANT2 for a short to body ground, then tests the signal for an unwanted connection to its shield.

Either wiring fault directs replacement of the affected antenna lead. These separate checks explain why an intact-looking cable or a stored antenna code alone cannot decide whether the roof antenna is defective.

## One source detail remains unresolved

The final roof-antenna check changes the test-condition label to telematics connector C, a four-pin connector, although the preceding isolation used D. The extract does not explain that change. This article is flagged for review; it does not provide a pin-by-pin repair recipe or silently assume the two connector references are interchangeable.

The final branch distinguishes the TEL antenna from the telematics control unit, but the correct connector states should be established from current vehicle-specific information before using that decision.

## Verification before replacement

Honda specifies a code clear, OFF mode with the driver's door open for more than one minute, then ON mode and at least one minute before rescanning. A nonreturning fault is treated as intermittent. Have a technician preserve the original scan, inspect connection quality and resolve the connector discrepancy before authorizing an antenna, lead or controller. The code does not establish a cellular-service coverage problem.

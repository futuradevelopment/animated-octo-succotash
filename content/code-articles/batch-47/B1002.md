# B1002: Persistent BCM EEPROM error has a defined verification step

## A stored memory error needs confirmation

Honda defines B1002 as an internal body control module error involving EEPROM. The supplied troubleshooting page makes persistence the decisive observation. It does not instruct the technician to replace the BCM simply because a historical B1002 appears in a scan.

The factory sequence uses HDS to clear the code, cycles the vehicle through OFF and ON, waits at least six seconds, and then checks the BCM again. If B1002 returns, the stated repair direction is replacement of the body control module. If it does not return, Honda classifies the event as intermittent and says the BCM is functioning correctly at that time.

## What this branch does not prove

A successful recheck is a result under the test conditions, not proof that the original event never occurred. Preserve the initial scan and the conditions surrounding the complaint before performing the clear-and-recheck sequence. That record matters if the error later returns.

The source supplies no component-level EEPROM repair, memory-resistance test or software-update remedy for B1002. An update-related BCM fault has its own diagnostic context and should not be substituted merely because both involve the same module.

## When several body codes are present

Honda directs technicians with multiple faults to B-CAN System Diagnosis Test Mode A. That instruction affects diagnostic order: the complete body-network assessment should guide which fault is addressed first. Any BCM replacement and required vehicle-specific setup should be handled through the applicable service procedure.

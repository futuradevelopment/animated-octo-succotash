# P0997: The sixth F21 shift solenoid has a monitored current response

## Find the variable-force circuit, not just the letter

Ford's Aisin F21 description identifies shift solenoid F as one of the variable-force solenoids. P0997 reports stuck control current on that circuit. The neighboring codes distinguish its open/short-to-ground condition from a short to power, so the complete code is more useful than a generic transmission-solenoid warning.

The general electrical-current monitor uses feedback current and a half-second out-of-range duration. It does not decide the fault solely from whether a shift felt harsh. Mechanical functional checks use achieved ratios and shift behavior, providing a separate line of evidence.

## Read the transmission controller directly

The documented F21 controller stores its own DTCs and freeze-frame information and communicates with the engine and brake controllers over CAN. Preserve those transmission records, including command and current-related parameters, before clearing the system or disconnecting the controlled circuit.

A technician must use the actual F21 service diagram and current-control checks to determine whether the fault is in the load, wiring or driver path. The OBD overview does not publish a universal solenoid-F resistance or authorize applying power directly to the circuit.

Do not assume that replacing the entire transmission is justified by a current-range code. A defensible repair explains the feedback fault, restores the expected current response and then confirms transmission function safely. The name SSF and this diagnostic interpretation belong to the documented application, not every six-solenoid transmission.

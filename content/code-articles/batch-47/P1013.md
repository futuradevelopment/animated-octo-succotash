# P1013: Wastegate pressure signal above the high-voltage boundary

## What the high signal means

Ford's wastegate control pressure sensor circuit check assigns P1013 when signal voltage exceeds 4.93 volts. Its table describes continuous monitoring over five seconds. The adjacent sensor characterization reaches 4.8 volts at approximately 112.8 kPa, so the fault boundary lies beyond the illustrated normal conversion points.

The word pressure in the component name can be misleading during diagnosis. This code describes the electrical input being too high. It is not the same as a demonstrated boost overshoot, and it does not by itself establish a wastegate mechanical failure. The source separately lists pressure-control and atmospheric-correlation monitors for those different questions.

## Keep the raw input in the record

Capture the voltage-oriented parameter, converted pressure and BARO reading while the symptom is present. If the converted value is at a displayed maximum, that may conceal how far the input has moved outside its usable range. A qualified technician should verify the signal and reference circuit using the matching factory terminal information before treating the pressure number as a real pneumatic measurement.

The monitor summary does not specify a universal resistance value, jumper test or replacement sequence. Those details must come from the correct vehicle procedure. In particular, applying battery voltage to a sensor input would not reproduce a legitimate diagnostic comparison.

A useful repair confirmation addresses the original high-voltage condition and verifies sensible pressure tracking, rather than relying only on a temporarily extinguished warning.

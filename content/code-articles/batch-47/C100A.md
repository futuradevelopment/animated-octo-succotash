# C100A: One ABS code groups several brake-pedal signal checks

## The base code is broader than one sensor failure

Ford's PHEV mapping associates ABS-module C100A with several brake-pedal angle checks: zero-point bias, stored-data checksum, comparison between sensor tracks and plausibility against the brake on/off indication. The corresponding hybrid-controller codes distinguish those individual checks. Reading only the ABS base code can therefore hide which observation actually failed.

The detailed examples differ substantially. The bias test requires both sensor circuits and their supply to be in range and uses vehicle speed of at least 20 km/h. The track-comparison test waits beyond 1.8 seconds after power-on and detects a six-percent difference lasting more than 150 milliseconds. The checksum test instead compares stored and calculated information.

## Use the paired code to choose the diagnostic question

Save both ABS and hybrid-controller results before clearing either module. Ford explains that paired codes should correspond unless a service tool has cleared one side. That mapping can help recover whether the event concerns calibration, electrical credibility or agreement between inputs.

The pedal-angle sensor contributes to requested braking torque. A qualified technician must use the correct procedure for the identified subfault and verify brake operation safely. A generic sensor replacement or recalibration is not established by C100A alone.

The printed mapping supplies a relationship between modules, not proof that every listed test failed simultaneously. Keeping the specific companion diagnostic prevents a broad ABS label from turning into an unnecessarily broad repair.

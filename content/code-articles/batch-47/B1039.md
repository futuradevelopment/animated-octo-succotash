# B1039: BCM authentication ID does not match

## Mismatch is different from missing information

Honda describes B1039 as an immobilizer F-CAN authentication ID mismatch reported by the body control module. The definition concerns information that does not match the expected identity. It should not be replaced with the neighboring missing-information diagnosis or treated as proof that the vehicle has the wrong physical key.

The factory page provides a short but specific decision sequence. The technician clears the DTC with HDS, cycles the vehicle from OFF to ON and reads the BCM again. If B1039 is present again, the instruction is to register the body control module. If it is absent, the source classifies the event as intermittent and says the system is functioning correctly at that time.

## Registration is the documented service direction

The procedure does not direct BCM replacement, key replacement or wiring repair solely from this code. It also does not provide the registration steps in the supplied extract. Those steps must come from the applicable vehicle service information and be performed through a legitimate professional repair process.

Record prior BCM replacement or registration work when available, because the stated corrective action concerns the module's identity registration. That history can guide the repair discussion without establishing the cause by itself.

## Related body faults still matter

Honda explicitly points multiple-DTC cases to B-CAN System Diagnosis Test Mode A. Preserve the complete scan before clearing memory, and use that diagnostic order when communication faults accompany B1039. A single successful recheck describes current operation; it does not erase a recurring authentication complaint.

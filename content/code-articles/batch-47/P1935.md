# P1935: Brake-pressure data arrives over the network outside its usable range

## A received value, not necessarily a broken wire

P1935 appears in Ford's brake-torque message diagnostics for stop/start dependability. The stated condition is brake-pressure sensor information out of range over the network. The monitor is continuous, has no preceding sequence, and lists a fault duration below five seconds.

The adjacent direct brake-line pressure sensor circuit test uses a different code. That distinction makes the reporting controller important: a received-data fault should not immediately be treated as proof that its own physical sensor wire is open. The pressure-producing module and the module interpreting its network message may be different diagnostic endpoints.

## Retain module identity and companion faults

Save the scan results from the relevant control modules, including the code's status and the pressure value seen by each available diagnostic channel. A technician can then distinguish absent communication, an explicitly invalid value and a pressure measurement that is present but outside the expected range. The summary does not provide a universal pressure threshold for P1935.

Ford's warning classification also varies: the table specifies MIL operation for MHT applications and non-MIL operation for other vehicles. Warning-lamp behavior must therefore be matched to the actual powertrain rather than used as a blanket severity ranking.

Because this information contributes to brake and stop/start dependability, follow the correct brake-system diagnostic procedure and avoid road testing with uncertain braking performance. A module replacement or brake-pressure sensor replacement is not established by the received-data code alone.

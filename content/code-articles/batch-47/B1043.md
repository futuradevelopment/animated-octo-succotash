# B1043: Wiper-unit EEPROM fault is reported through the BCM

## Separate the reporting module from the named fault

The Honda scan context for B1043 is the body control module, but the definition names an internal EEPROM error in the front-wiper unit. That distinction prevents a common diagnostic shortcut: the module displaying a code is not necessarily the assembly identified by its description.

The factory verification clears the DTC with HDS, cycles the vehicle through OFF and ON and checks for B1043 again. If the code returns, the procedure directs replacement of the windshield wiper control unit/motor. It does not direct BCM replacement in this branch.

## Persistence is the decision point

If B1043 does not return, Honda calls the event intermittent and says the system is operating correctly at that time. This does not explain the original memory error or guarantee that it cannot recur. Retaining the original fault record and the driver's account of wiper behavior gives the repairer useful context if the problem returns.

The supplied page contains no EEPROM repair method, reflash instruction or measurable memory threshold. Those remedies should not be inferred from the word EEPROM or imported from another module's diagnostic procedure.

## Completing the assessment

Where multiple body codes are present, Honda requires the B-CAN diagnostic sequence referenced in the note. A technician should establish that sequence before treating B1043 in isolation, then verify the correct wiper assembly for the vehicle. If wiper operation is unreliable, arrange repair before driving in conditions that require dependable windshield clearing.

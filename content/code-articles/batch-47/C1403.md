# C1403: EPS motor angle signals disagree

## An electrical angle-signal diagnosis

Honda describes C1403-14 as incorrect motor angle sensor SIN/COS signals. These are the named signals in the EPS motor/control-unit diagnosis. This description concerns the controller's angle information; it is not a wheel-alignment measurement or a specification for the steering wheel's straight-ahead position.

The documented battery-voltage range is 7.5–19.2 V. The confirmation procedure cycles the vehicle through ON, OFF and ON, after which regular diagnosis evaluates the condition. Approximately one second of detection can produce the code in one drive cycle and illuminate the EPS indicator.

## Consequence and diagnostic limits

The fail-safe stops EPS assistance. Honda says the controller continues diagnosis and that assistance can return when voltage is normal after the next ignition-on event. That wording describes the recovery condition in this source; it does not prove that the 12-volt battery is the failed component.

An internal EPS motor/control-unit failure is the listed possible cause. No numerical SIN/COS relationship, phase-angle tolerance or connector-level test is supplied on this sheet. A technician must use the applicable complete EPS procedure before deciding whether a measured signal is acceptable or condemning an assembly.

## Responding to a changing symptom

If assistance disappears and then returns after restarting, retain the original code and operating history. Clearing the memory immediately can obscure that sequence. Because the documented response affects steering effort, diagnosis and any controlled confirmation should be handled by a qualified repairer rather than attempted through roadside steering maneuvers.

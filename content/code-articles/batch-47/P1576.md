# P1576: The F21 transmission receives unusable pedal-position information

## The receiving module gives the code its meaning

In Ford's Aisin F21 transmission description, P1576 is associated with invalid or faulted pedal-position information received from the engine controller over CAN. The transmission uses engine information to manage its operation, so the receiving controller can record a fault even though the pedal sensor is not wired directly to that controller.

The same section distinguishes a bus-off condition from missing engine-controller messages and from invalid individual data items. P1576 belongs to the latter category. Replacing a pedal assembly merely because the transmission reports this code would skip the distinction between the original input and its communicated status.

## Compare sender and receiver evidence

Preserve the engine and transmission scans together. Relevant questions include whether the engine controller reports a pedal-input fault, whether its displayed pedal data is credible, and whether the transmission receives an explicitly invalid value. These are investigative comparisons; the overview does not prescribe one guaranteed cause.

Ford describes the F21 as having a standalone OBD-capable transmission controller with its own freeze-frame and fault storage. Reading that module directly can retain evidence that a generic engine-only scan omits.

A technician should follow the matching network and pedal-data procedures before selecting parts. The document supplies no terminal test or universal message threshold for P1576. Verification should demonstrate usable pedal information at the receiving transmission controller, not just a moving pedal percentage displayed somewhere else.

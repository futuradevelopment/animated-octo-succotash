# C1404: EPS U-phase high voltage uses limited backup assist

## A fault in one named motor phase

C1404-13 identifies high voltage in the EPS motor U-phase circuit in the cited Honda procedure. The named phase is important: the code is not, by itself, a diagnosis that the vehicle's entire charging system is operating at excessive voltage. The sheet does not publish the U-phase failure threshold.

Diagnosis requires 12-volt battery voltage above 7.5 V. Honda's confirmation sequence uses READY mode and controlled steering movements; regular diagnosis then has an approximately one-second detection duration. One drive cycle is sufficient for the EPS indicator to illuminate.

## Limited assistance is part of this fault response

Unlike an EPS condition whose stated response is complete loss of assistance, this entry specifies continued, limited assistance under backup control. The controller keeps monitoring and can restore normal assistance when the system returns to normal. Consequently, an illuminated warning with some remaining steering assistance is consistent with this document and does not make the fault irrelevant.

The listed possible cause is an internal EPS motor/control-unit failure. The advanced-diagnostics page does not contain a repair authorization based solely on the code, an external power-injection test or a measured phase-voltage limit. Those details require the vehicle-specific EPS troubleshooting procedure.

## Service priorities

Preserve the diagnostic record and report any change in steering effort. A qualified technician can establish whether backup operation is active and perform the specified confirmation safely. Do not rely on the remaining assistance as proof that continued driving is appropriate, and do not attempt to energize the motor phase directly to test it.

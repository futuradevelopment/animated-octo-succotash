# P2131: The third pedal track fails a Gen2 agreement check

## A generation-specific pedal comparison

Ford's 2010 summary assigns P2131 to accelerator-pedal position sensor F range/performance and marks it Gen2 only. The associated range check looks for disagreement between sensor readings greater than 1.1 degrees. It runs continuously and lists a duration below one second, with a wrench warning rather than MIL classification in that table.

The continuity tests use separate voltage boundaries. A sensor voltage that remains between those electrical endpoints can still disagree with the other pedal information. Consequently, an apparently normal single-channel voltage does not by itself explain away the range/performance result.

## Compare the tracks under the correct procedure

Preserve all available pedal-track data and companion codes, identifying which controller generation and pedal arrangement are installed. The same source describes a different two-track correlation diagnostic for later Gen3/Gen4 systems, so their code and comparison logic should not be substituted for this Gen2 test.

A technician can follow the matching circuit and pedal-sensor procedure to evaluate agreement through the permitted operating range. The summary does not publish a universal connector pinout or establish whether the pedal assembly, wiring or controller is responsible.

Unpredictable throttle response should be assessed professionally before further driving. Clearing the code or observing one smoothly changing percentage is insufficient confirmation; the relevant evidence is consistent agreement between the documented pedal channels under the conditions of the actual monitor.

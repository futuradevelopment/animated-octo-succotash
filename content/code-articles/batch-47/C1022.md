# C1022: The VSA pump motor is missing a valid power source

## Start with the power path

Honda describes C1022-14 as a pump-motor power-source failure. The listed possibilities include an open, short to ground or poor connection between the VSA modulator and the under-hood fuse/relay box, a blown B3-2 fuse, and an internal modulator fault. The component named in the code is therefore not automatically the failed component.

The monitor runs during regular diagnosis with a low-voltage supply of at least 9 volts. Its diagnostic duration is about two seconds, while the specified confirmation procedure includes a longer vehicle-operation period. These are different timings: the fault-decision duration should not replace the complete confirmation conditions.

## Preserve the electrical evidence before replacement

Record the supply condition, fuse state and accompanying brake faults. A technician should follow the application-specific motor-feed procedure to distinguish an interrupted supply from an internal load or controller problem. Repeatedly fitting fuses without explaining a renewed failure would not complete that diagnosis.

Honda lists ABS, traction/stability, hydraulic-boost compensation and some parking-brake functions among the affected fail-safe responses. Any test drive requires a professional decision that braking remains suitable for the specified controlled check.

Do not bridge the fuse or supply the motor externally to bypass the fault. The useful repair result is a sound protected power path and a completed system verification, not simply a motor that can be made to run temporarily.

# P115E: The throttle airflow adjustment has reached its limit

## An adaptation limit is not a stuck-plate diagnosis

Ford's cited throttle-actuator table describes P115E as airflow trim at its maximum limit. It places the code alongside, but separately from, stuck-open, stuck-closed, motor-current and cross-wiring diagnostics. That organization matters: reaching the limit of an airflow adjustment does not by itself prove that the throttle plate is physically jammed.

The table describes continuous evaluation and a monitoring duration below five seconds. It also identifies P115E as legacy and says that P0FB6 replaces it from new 2023-model-year applications. A scan-tool label or internet code list that ignores the controller generation can therefore send an investigation toward the wrong diagnostic definition.

## Match the code to the installed calibration

Keep the full reported code, controller identification, freeze-frame information and any companion throttle faults. The first useful distinction is whether the event concerns an exhausted airflow correction, an actuator that cannot move, or a sensor whose position information is unreliable. Those are different observations even when each can affect idle or torque control.

The summary does not give the numerical trim limit or a cleaning, reset or replacement instruction for P115E. Cleaning a throttle body and clearing learned values should not be presented as a factory-proven cure from this document alone. A technician needs the matching service procedure to evaluate the airflow path and the recorded adjustment.

If throttle response is unpredictable or a reduced-power mode affects safe control, arrange professional diagnosis rather than attempting to reproduce the fault in traffic.

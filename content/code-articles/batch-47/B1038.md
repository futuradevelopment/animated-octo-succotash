# B1038: Missing authentication information requires network review

## Start with communication availability

The title for Honda B1038 is immobilizer F-CAN authentication ID not received. The procedure prioritizes a stored keyless-access power-unit U0073, then checks CAN gateway faults before using the gateway's bus-connected-unit test. These prerequisites point to communication diagnosis before any assumption that a key must be replaced.

The first branch asks whether the BCM detects gateway bus B. If it does not, the procedure checks the F-CAN B high and low paths between the BCM and gateway. With intact wiring, connection quality and a controlled BCM substitution are considered; an open circuit instead directs a wiring repair.

## An important limitation in the original document

The later table identifies the transmitting unit for B1038 as the VSA modulator-control unit and evaluates its availability on bus A and bus B. That association is unusual alongside the immobilizer-authentication title. The article is therefore flagged for review rather than silently converting the table into a different transmitter or an unrelated key-registration procedure.

The full extract continues through both VSA-to-gateway circuit branches. Those details establish what the document says, but do not resolve whether its transmitter table is correct for every intended application.

## Practical service direction

Retain the entire network scan, including gateway and keyless-access faults, and have the exact vehicle procedure checked before component replacement. The supplied evidence supports investigating missing communication and connection quality. It does not support an immobilizer bypass, a generic key-fob remedy or a claim that an authentication mismatch has already been established.

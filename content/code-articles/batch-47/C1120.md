# C1120: Parking-brake switch circuits need a separate check

## The input being monitored

The Honda procedure identifies C1120-14 as a fault in the electric parking brake switch circuit. Its listed electrical paths are SW1, SW3, SW4 and SW6 between the switch and the VSA modulator-control unit. This directs attention to the driver's request reaching the controller; the code by itself does not identify a failed rear actuator.

Regular diagnosis runs with the vehicle in ON mode. The stated battery-voltage window is 9–16 V, and the amber brake indicator can illuminate within one drive cycle. The duration field is blank, so this source does not establish a minimum number of seconds before detection.

## What the fail-safe actually says

Honda describes loss of some parking-brake functions if both the parking-brake switch and drive-away assist function have failed. That qualification matters: the document does not say that every stored C1120-14 causes an identical response in every operating condition. Treat a parking-brake warning seriously and have the vehicle secured and inspected before depending on the affected function.

## Where diagnosis should concentrate

The listed possibilities include an open circuit, a short to ground, poor connections, the switch itself and an internal VSA fault. A technician needs the applicable wiring information to separate those paths before selecting a component. This advanced-diagnostics sheet supplies operating conditions and candidate causes, but no connector-pin test or resistance specification; neither should be improvised from its code title.

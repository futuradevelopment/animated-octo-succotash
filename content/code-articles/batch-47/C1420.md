# C1420: Main and sub steering-torque signals fail correlation

## The comparison behind this code

The Honda definition of C1420-29 is incorrect correlation between the main torque sensor and sub torque sensor. The diagnostic concern is the relationship between their outputs. A code with that description does not establish which channel is wrong or prove that either one can be trusted as a reference without further testing.

The documented enabling range is 4.5–5.5 V for the torque-sensor power supply. Confirmation includes ignition-state changes, READY mode and steering movement. Regular diagnosis takes about one second, and a single drive cycle can illuminate the EPS indicator. No numerical difference between the two torque outputs is given in this extract.

## Why the steering response can vary

Honda describes either stopped assistance or continued limited assistance. It also states that recovery can occur when the torque-sensor output voltage returns to normal after the next ignition-on event. That range of responses should be retained when interpreting a driver's report; the source does not promise one fixed amount of assistance for every occurrence.

The possible causes listed are an internal steering-gearbox fault and an internal EPS motor/control-unit fault. Selecting between them requires the complete application-specific EPS troubleshooting information, not a guessed sensor-correlation tolerance.

## A useful diagnostic record

Keep the main and sub channel identities, the exact suffix and any related torque-sensor codes together in the repair record. Because the fault can affect steering assistance, a qualified technician should conduct the confirmation and electrical assessment. Restarting until the warning disappears is not a substitute for establishing why the signals disagreed.

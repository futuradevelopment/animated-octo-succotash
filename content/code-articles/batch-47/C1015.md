# C1015: An ABS vacuum-supply code needs its paired hybrid diagnostic

## A shared label with different underlying checks

In Ford's PHEV mapping, ABS-module C1015 corresponds to vacuum-supply plausibility and low-vacuum or leak-related conditions. The hybrid-controller side uses C0021 or P050F to retain the more specific diagnostic meaning. C1015 alone therefore does not identify one failed pump or one leaking hose.

The brake-system description explains that an electric vacuum pump supports the booster when the engine is stopped. In the documented low-vacuum monitor, a rapid vacuum change and a sustained vacuum-level condition are evaluated together. The printed criteria include a change rate above 500 mbar per second for at least 100 milliseconds and a vacuum level below −40 mbar for 600 milliseconds.

## Preserve the companion result before clearing

Read the ABS and hybrid modules together to establish which mapped condition is present. The source says the paired diagnostics should correspond unless one module has been cleared with a service tool. A missing companion after separate clearing is therefore different from evidence that the ABS code was false.

A technician should evaluate the correct vacuum supply and booster-control procedure, including any supply-voltage faults that can invalidate the monitor. The summary does not turn the rate criterion into a universal vacuum-pump replacement threshold.

Because vacuum assistance affects braking effort, do not drive solely to recreate an abnormal pedal condition. Professional verification should establish reliable assistance and resolve the specific paired fault, not merely erase the broad C1015 label.

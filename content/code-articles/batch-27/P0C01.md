# P0C01: motor A overcurrent has fast and intermittent detection branches

P0C01 is the motor A phase-current overcurrent monitor in the GM hybrid document. The source describes protection of the inverter switching devices through two detection paths. It is different from a sensor high-range code evaluated with PWM output disabled.

## Two counters address different patterns

The criterion is a U, V or W phase-current sensor report above 600 A. One branch looks for fast repeated events using two qualifying counts among ten. The other addresses slower intermittent events using five counts among fifty. Both branches use the stated 2.08 ms task rate.

The wakeup signal must be on, and the table lists one-trip reporting. Preserve the event history and phase-current information rather than assume a single later scan reading can reproduce either filtered pattern.

## Overcurrent protection does not locate the cause

This monitor's purpose is protective, but the code alone does not identify a failed motor, inverter or sensing component. Review related current-sensor range and correlation faults because those reports affect confidence in the measurements being interpreted.

The published 600 A value is a calibration criterion, not a current level to generate deliberately. The actual vehicle service procedure must determine safe diagnosis and repair verification. Work around inverter power circuits requires trained hybrid personnel and proper high-voltage isolation. Clearing the code without establishing credible current behavior and the applicable monitor result does not demonstrate a resolved fault.

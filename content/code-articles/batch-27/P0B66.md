# P0B66: a repeated high block 9 measurement requires source-aware diagnosis

In this GM battery-controller table, P0B66 identifies block 9 voltage measurement out of range high. The code corresponds to the generic voltage-sense I high description, but the numerical threshold belongs to the cited 2010 controller calibration.

## Understand what is actually counted

The monitored block 9 reading must exceed 23 V. Fifteen failures among twenty samples, sampled at 100 ms intervals, establish the documented condition. This filtered rule does not justify diagnosing a fault from an isolated scan refresh that happens to look unusual.

The companion low-range code uses a paired block 9/block 10 condition, while the performance code compares scaled block readings with pack voltage. P0B66 does neither of those things. Keeping the branch definitions separate helps a technician avoid applying the wrong pass/fail rule.

## Collect evidence that can distinguish the cause

Retain block 9 data, total-pack information and any controller faults. The test requires RUN mode, a 9–18 V low-voltage supply and no active P0A1F. A code that does not immediately return outside those conditions has not necessarily passed its monitor.

A high sensor report is not sufficient evidence of a physically overcharged block, nor does the source prescribe replacing the complete battery. Use the exact vehicle's hybrid diagnostic procedure to establish the measurement path and battery condition. The monitor table provides no safe instructions for opening or probing a high-voltage assembly.

## Source and applicability

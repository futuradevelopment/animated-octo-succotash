# P0C14: motor B phase U overheating depends on PIM Temp 2 validity

P0C14 is the motor B inverter phase U overtemperature code in the cited GM document. The row uses PIM Temp 2, not an assumed first temperature channel based on phase lettering. Match that mapping to the actual controller before identifying hardware.

## The sensor must support a thermal conclusion

The source requires an in-range PIM temperature and inactive P0BE1 performance fault. Those conditions are important because a direct circuit fault can make a reported temperature unsuitable for a physical overheating diagnosis.

GM gives an initial boundary above 88°C and a lower 85°C reset boundary. The monitor uses 500 qualifying counts among 650 at a 10.4 ms rate and lists one-trip reporting. Detection is therefore a filtered thermal event, not merely one scan refresh near a numerical limit.

## Record the history needed for verification

Preserve the temperature trend, related sensor faults and operating context before the system cools. A later normal reading cannot establish why the event occurred or whether its cause remains.

The table does not identify a specific cooling component or mandate inverter replacement. A qualified hybrid technician must follow the actual vehicle procedure to establish the cause and confirm credible recovery under eligible operation. Physical inverter access requires proper high-voltage isolation. These historical thresholds must not be used to justify deliberately forcing the system into an overheated state.

## Source and applicability

GM 2010 10OBDG10 Hybrid Diagnostics, cited BPCM or hybrid-controller monitor only.

# P0B65: the block 9 low-range test includes block 10

The source assigns P0B65 to the block 9 low-voltage measurement branch. Its generic circuit-I name is useful for code identification, but the GM document supplies the actual monitored relationship. A low-range code is not, on its own, a measurement of usable battery capacity.

## Why two channels should be recorded

The failure criterion requires block 9 below 2 V and block 10 below 2 V. A single scan value cannot show whether that complete paired condition occurred. Preserve both readings at the time of the event and distinguish them from a later, recovered display.

Detection is based on fifteen failures in twenty samples with a 100 ms interval. The rule therefore concerns repeated evidence. A momentary value and a matured stored code are related observations, but they are not equivalent states.

## Do not overlook controller eligibility

The battery controller must be in RUN, its low-voltage supply must remain in the 9–18 V window, and P0A1F must be inactive. These prerequisites are part of the diagnosis, not additional specifications for the high-voltage battery blocks.

The table does not state that replacing block 9 resolves every occurrence. A qualified hybrid technician needs the correct sensing-circuit information to establish whether the paired low reports reflect real battery voltage or a measurement-path problem. Verification should show eligible operation and stable relevant readings; clearing memory alone does not supply that evidence.

# P0B88: block 16 low sensing is a neighboring-channel event

P0B88 identifies the low-range branch for block 16 voltage measurement in this GM source. Its standardized circuit P wording is not a battery-layout diagram. Match the controller and service documentation before associating the code with any physical component.

## Why the adjacent value changes interpretation

The published failure requires block 16 below 2 V and block 17 below 2 V. That paired condition makes the neighboring measurement necessary evidence. A technician should retain the two-channel record rather than infer the event from a single minimum value after the fact.

Fifteen failing samples among twenty are required at a 100 ms sampling interval. Consequently, the stored fault reflects a filtered pattern under the monitor conditions, not simply one low scan update.

## Check whether a retest can evaluate the branch

The source requires RUN mode, a 9–18 V low-voltage supply and no active P0A1F. These prerequisites concern controller operation and must not be confused with the high-voltage block thresholds.

If those conditions were unavailable after memory clearing, lack of an immediate return is inconclusive. The paired readings and associated faults should guide the applicable sensing-path diagnosis.

# P0C53: motor A resolver circuit A high has its own reference-voltage filter

P0C53 is the motor A position-sensor circuit A high monitor in this GM document. It evaluates resolver S13 circuit reference voltage. The generic code title should not be interpreted as a direct report that rotor angle or motor speed is too high.

## Use the high-range criterion

The source threshold is S13 reference voltage above 3.0 V. The wakeup signal must be on. GM confirms twenty qualifying counts among thirty at a 10.4 ms rate, with one-trip reporting.

The low-range counterpart P0C52 uses a larger qualifying-count requirement. Consequently, a technician should not assume the two directions mature identically or use a brief observation from one branch to reconstruct the other.

## Preserve the electrical context

Retain the reference-voltage report and related resolver circuit, performance and learning codes. A high reference fault and an unlearned offset describe different checks. The source does not identify which connection or internal component produced the high report, and it does not prescribe mechanical adjustment or resolver replacement.

The actual vehicle service information must identify the S13 circuit and appropriate diagnostic method. The published voltage limit is a controller criterion, not permission to inject voltage or probe an energized inverter assembly. A trained hybrid technician should confirm credible reference behavior under eligible operation after establishing safe high-voltage conditions for any physical work.

## Source and applicability

GM 2010 10OBDG10 Hybrid Diagnostics, cited BPCM or hybrid-controller monitor only. Historical calibration values are not universal specifications; no per-code model, engine or hardware fitment has been established.

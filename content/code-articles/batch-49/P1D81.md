# P1D81: VCU output permission conflicts with a blocked fault signal

## Permission and protection status are compared

Honda P1D81 evaluates the relationship between the VCU EN output-permission signal and the VCU FO fault-related signal inside the PCU. The documented criterion is a blocked VCU FO state continuing for at least 2.5 seconds even though VCU EN permits output. Monitoring requires a 12-volt supply of at least 8 V.

The factory description explains that a PDU fail-safe event can cause coordinated gate blocking. It also notes that a disconnected VCU FO path can block traction-motor and generator gate signals even when no actual fail-safe event has occurred. That distinction makes the signal path itself relevant, rather than assuming every blocked-output event proves a power-stage failure.

## A blocked gate must not be bypassed

The possible-cause section identifies internal PCU failure. It does not provide an external jumper test or a method for overriding output permission. The protective relationship is part of the system's operation, so forcing a permissive state would not be a valid repair or confirmation.

Record the fault and associated operating data before clearing memory. Honda specifies one-drive-cycle MIL illumination, a power-system warning and pending, confirmed and freeze-data storage in the motor control module.

A qualified technician should use current Honda diagnostic information to establish why permission and protection states disagree. Any service access to the PCU must observe the required high-voltage isolation process, regardless of whether the immediate symptom is loss of output rather than an obvious electrical fault.

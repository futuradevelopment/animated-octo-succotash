# P1D65: A crash-cutoff request has shut down the high-voltage system

## The restraint system is central to this diagnosis

Honda P1D65 identifies high-voltage system shutdown after a collision-detection signal. The factory note states that airbag deployment stores this DTC and stops the motor. This is different from a code that reports a missing crash-signal circuit: the record concerns the shutdown request being detected.

When an airbag has deployed, the source places the required post-deployment component inspection and replacement work before this troubleshooting. Clearing a powertrain code is therefore not a substitute for assessing and restoring the restraint system or checking the vehicle after collision damage.

## SRS records determine the next diagnostic route

The procedure first checks the SRS system with HDS. If SRS DTCs are present, it directs the technician to those diagnostic procedures. If none are present, the document treats the powertrain record as intermittent and refers to the original freeze or snapshot conditions. That branch is not a declaration that a previously damaged vehicle is safe or that all post-collision work is complete.

Preserve both the SRS and electric-powertrain records and obtain an accurate event history before any reset. The excerpt does not provide an owner-level method to re-enable the high-voltage system or bypass crash cutoff.

A qualified repair facility must follow the current Honda post-deployment and electric-powertrain precautions for the exact vehicle. Do not attempt to reproduce a collision signal, defeat a shutdown path or infer safe operation solely from the absence of a current warning.

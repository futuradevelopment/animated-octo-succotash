# P158E: The second battery-current channel must be checked with its companion codes

## A supply fault takes priority over the channel fault

Honda P158E identifies a low circuit condition on battery-current sensor channel 2. The factory procedure first verifies recurrence, then checks for P06B1, the current-sensor power-supply-low code. If that supply code is present, diagnosis is redirected there before continuing with the channel-specific branch.

The next distinction is whether P158D and P158E occur together. Simultaneous low readings on both channels lead to investigation of the shared VCCISOC supply path. This is different evidence from a fault affecting only the second channel, and retaining the complete DTC list is essential to following the correct sequence.

## The isolated channel branch investigates ISOCF

When the shared-supply pattern is absent, the procedure examines the ISOCF path for a ground short and separates harness behavior from the sensor by controlled disconnection. Other branches use a known-good sensor to distinguish it from the battery condition monitor module. These are conditional diagnostic steps, not authorization to replace a sensor solely because the code says “circuit low.”

The work requires service-plug removal and access under the IPU cover with the correct Honda high-voltage precautions. It must be performed by qualified personnel using the exact connector information.

Preserve freeze data and companion supply or channel records before clearing. The source contains no universal signal-voltage threshold for P158E in this troubleshooting excerpt, so thresholds from another channel or model should not be substituted without supporting service information.

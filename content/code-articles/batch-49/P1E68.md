# P1E68: The brake master-cylinder cut valve enters a self-lock fault

## The fault is checked after a brake-pedal action

Honda P1E68-00 concerns a self-lock condition associated with the master-cylinder cut valve in the electric servo brake system. The factory summary places the monitor in regular diagnosis. Its listed confirmation conditions include ON mode, a firm pedal application followed by release, and a 12-volt supply between 9.5 and 16.7 V.

The approximate diagnostic duration is one second. The excerpt does not publish a pressure threshold or explain a field adjustment for releasing the reported condition. “Self lock” should therefore not be turned into an instruction to manipulate a valve or force the brake hydraulics.

## The source names two actuator-related possibilities

The possible-cause list includes an internal tandem-motor-cylinder fault and an internal pedal-feel-simulator problem involving the cut valve. Those alternatives need the proper Honda diagnostic sequence; the code alone does not establish which assembly is defective.

Honda describes one-drive-cycle red and amber brake warnings with suspension of electric servo assistance and numerous cooperative functions, including regenerative braking and automatic hold. Keep the exact P1E68-00 record and related brake data before clearing so the event can be assessed in context.

Because the fault affects a system that supplies braking assistance, diagnosis and verification belong with a qualified brake technician. Do not assume the vehicle is safe for normal driving simply because the pedal moves or a restart temporarily extinguishes an indicator; supported brake operation must be verified using the current service procedure.

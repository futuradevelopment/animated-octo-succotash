# P100C: Electric VTC pulse disagreement is a circuit clue

## Why counting pulses matters

Honda P100C monitors feedback associated with the electric variable valve timing motor. The documented failure condition is a disagreement between EVTS and EVTD pulse counts lasting at least five seconds while the electric VTC relay is on. The monitor operates continuously with battery voltage at or above 10.5 V. A timing-control complaint accompanied by this code therefore warrants attention to the electrical feedback path before assuming that a mechanical timing component has failed.

The cause list names opens, shorts and electrical noise affecting the EVTS or EVTD lines. These are distinct possibilities: a missing pulse stream and an extra noise-induced transition can both disrupt a count comparison. The excerpt supplies no universal waveform amplitude, connector pin or resistance specification for separating them.

## Read the signal names cautiously

There is an unresolved naming inconsistency. The introductory description discusses EVTS and EVTM feedback, including motor direction, whereas the stated malfunction threshold compares EVTS with EVTD. The article remains flagged for review so that this discrepancy is not silently converted into wiring advice. Use the correct vehicle schematic and current Honda procedure to identify the actual lines.

The factory confirmation route uses the HDS VTC test with the vehicle on. Following that controlled test and recording the result is more informative than repeatedly erasing the code. Honda lists this as a one-drive-cycle MIL fault, with pending, confirmed and freeze-data records retained when detected.

# P1D70: Several traction-current checks fail together

## The code summarizes a combination of failures

Honda P1D70 is a multiple-performance fault for the traction-motor phase-current sensing system. The source describes detection when at least two phase-current or sensor-supply checks fail, or when a three-phase-sum failure occurs together with at least one individual phase failure. The listed monitor duration is at least 200 milliseconds, with an 8 V minimum 12-volt supply.

This combined logic is the useful distinction. The DTC is not simply a renamed single-phase sensor fault. Related U-, V-, W-phase and current-sum records may explain which combination caused the controller to declare a broader sensing problem.

## Keep the component records alongside the summary

The factory possible-cause section identifies internal PCU failure. It does not name an external phase sensor that can be replaced from this code alone. The comparison also depends on the sensor-power path, so treating each stored phase fault as an unrelated failed component could miss a common internal problem.

Save the full motor-control DTC list and freeze data before clearing memory. Honda specifies one-drive-cycle MIL illumination and a power-system warning, with pending and confirmed storage in the motor control module. Those records help a qualified technician reconstruct the combination rather than relying on the summary label.

The correct Honda procedure must determine the permitted checks. Do not disconnect or probe individual high-voltage motor phases to manufacture a comparison; PCU and traction-circuit access requires the prescribed isolation process and appropriate training.

# P1E49: A stuck brake-motor current record is separated from an open path

## The factory page checks the connected motor circuit

Honda P1E49-00 is a stuck motor-current condition in the electric servo brake system. The troubleshooting page groups it with the drive-motor open-circuit code, then verifies whether either record returns after a clear, power cycle and pedal applications. A non-returning result is treated as intermittent rather than proof that a permanent motor fault is present.

For a repeated fault, the source first examines continuity across the motor-phase paths as seen from the disconnected controller connector. The result determines whether diagnosis moves toward controller connections or toward checking the individual harness paths to the tandem motor cylinder.

## Disconnection distinguishes the motor from its wiring

When the branch proceeds to individual wiring checks, the tandem motor cylinder is disconnected so the harness can be evaluated separately. Intact paths lead to the motor branch; an open path leads to a wiring repair. This is why the current-fault title alone cannot identify the failed assembly.

The page specifies an OFF-mode waiting period with the driver's door open before connector work. A qualified brake technician must follow those conditions and the exact Honda connector information; a casual continuity check with the system awake is not equivalent.

Save P1E49-00, any P1E4B-00 companion record and freeze data before clearing. Do not feed the motor directly, bridge phase wiring or assume that pedal movement confirms normal assistance. The supported brake functions need proper verification after the cause is corrected.

# P145F: An unstable EVAP reference pressure disrupts leak testing

## Check the reference before calling it a leak

Honda P145F evaluates pressure variation during the EVAP leak-check module's reference measurement. The excerpt identifies a spread of at least 0.3 kPa between maximum and minimum readings as the failure criterion. This is a stability check within the measurement process; the code alone does not establish a loose fuel cap or identify an external leak.

The module compares pressure reduction through a reference orifice with pressure reduction in the evaporative system. It measures the reference again because pump characteristics can change during the test. An unstable reference undermines that comparison before the result can reliably describe the sealed system.

## The shutdown interval is part of the evidence

The documented automatic sequence requires at least ten minutes in ON mode, followed by at least five hours off. At PCM wake-up, the listed coolant range is 5–35 °C, barometric pressure must be at least 76 kPa and battery voltage at least 10.5 V. The excerpt gives different completion times for particular 2019–2021 market configurations, so a single universal waiting time should not be substituted.

Possible causes include the vacuum pump, its motor, the control valve and excessive or insufficient reference-orifice flow. Those alternatives require the correct diagnostic procedure, not an assumed pressure-sensor replacement. The HDS route specifically calls for the EVAP leak-check module test. Work around fuel vapors belongs in a suitable professional setting; avoid improvised pressurization or ignition sources while investigating the system.

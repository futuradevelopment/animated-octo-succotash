# P1659: Missing throttle-relay output is an electrical supply fault

## The commanded relay state and voltage disagree

Honda P1659 addresses missing voltage from the PGM-FI subrelay circuit after the system commands it on, or while the throttle actuator is operating. The stated threshold is an absence lasting at least 200 milliseconds. Monitoring requires ON mode and a battery-voltage reading of at least 10 V.

The PCM uses accelerator-pedal information to calculate a target throttle opening and uses the throttle-position sensors to assess the actual opening. The relay supplies part of that control system. This particular code concerns that supply path rather than directly declaring that a pedal sensor or throttle-position sensor has failed.

## Keep the relay, wiring and fuse possibilities separate

Honda lists opens in the DBW RLY OUT and DBW RLY CL− lines, subrelay-circuit failure, a throttle-actuator fuse problem and an internal PCM fault. These alternatives explain why the code text cannot identify a single replacement component. The appropriate vehicle diagram and circuit tests are needed to determine where the commanded supply is lost.

Store freeze data before clearing the record and note any actual throttle-control symptoms. This is a one-drive-cycle MIL fault in the excerpt, with pending and confirmed records retained. If throttle response is unreliable, diagnosis should occur in a controlled professional setting rather than through repeated road attempts. The document gives monitor criteria, not permission to bypass the relay or feed the actuator directly.

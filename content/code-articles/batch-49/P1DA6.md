# P1DA6: V1 range performance is verified under a drive-ready state

## The specific V1 code should not be lost in a group label

Honda P1DA6 is the V1 voltage-sensor range/performance branch in a procedure that also covers V2M and V2S comparison faults. The shared page does not make those sensor identities interchangeable. Retaining the exact DTC and any companion records helps the technician identify which measurement path the controller has questioned.

The factory verification moves beyond a simple ignition-on check into a defined drive-ready operating state. It then checks for pending or confirmed recurrence of the listed range/performance codes. The excerpt supplies no standalone numerical V1 tolerance, so thresholds from another voltage-sensor code should not be borrowed to fill that gap.

## Recurrence and an intermittent record lead to different conclusions

If a listed code returns during the prescribed verification, the page directs replacement of the PCU. If it does not, the record is treated as intermittent and the original freeze or snapshot conditions guide further work. This is a conditional factory branch, not justification to order a PCU from a historical scan alone.

The confirmation involves a vehicle capable of moving, so it must be performed in a controlled professional environment using the complete Honda service instructions. The excerpt is not an owner test sequence.

Preserve the measured data and fault status before any clear. Any subsequent access to voltage-control electronics requires trained hybrid personnel and the required high-voltage isolation process; a range/performance label does not make internal measurement points safe to probe.

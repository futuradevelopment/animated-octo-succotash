# P158A: Two HV battery current measurements disagree

## Correlation is different from excessive current

Honda P158A compares current values calculated from the battery-current sensor's ISOC and ISOCF signals. The documented monitor requires an absolute difference of at least 10 A for two seconds while the ISOC-derived current is between −30 A and +30 A. It is a disagreement test within that operating window, not a statement that the traction battery is drawing an excessive current in every condition.

The battery condition monitor module performs the comparison. Its enable table specifies a 7.7 V minimum on the 12-volt supply and an initial 50-millisecond delay after the relevant supply threshold is reached in ON mode. These values describe monitor eligibility; they are not recommendations for acceptable battery condition during service.

## Follow the common measurement path

The factory cause list includes an open SGISOC line, the current sensor itself and an internal problem in the battery condition monitor module. That list makes the shared signal reference and interpretation path relevant to diagnosis. The code does not, by itself, demonstrate deteriorated battery cells or justify replacement of the entire high-voltage battery.

Save the two current readings and associated diagnostic records before clearing memory. Honda describes a two-drive-cycle MIL fault and a power-system indication, with a pending record on the first detection. Any access to the high-voltage assembly must follow the applicable Honda isolation procedure and be handled by a qualified technician. The monitor excerpt supplies no safe substitute for those service instructions.

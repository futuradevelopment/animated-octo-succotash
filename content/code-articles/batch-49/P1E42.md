# P1E42: Companion actuator codes guide a stuck-off brake relay diagnosis

## The visual decision tree separates an isolated relay fault

Honda P1E42-00 concerns an electric-servo-brake fail-safe relay reported stuck off. The factory flowchart distinguishes P1E42-00 alone from cases that also contain one of the listed master-cylinder valve, pedal-feel-simulator valve or FET-stuck-off records. If a listed companion code is present, diagnosis is directed to that code's troubleshooting procedure.

This visual distinction matters because the prose uses two affirmative YES branches without repeating the word “only” in the first. Reading the flowchart together with the detailed steps prevents the relay/controller branch from being applied indiscriminately to every combination of brake faults.

## Connection review belongs to the relay-only branch

For the isolated relay result, the detailed instructions call for checking loose terminals and poor connections at the electric-servo-brake controller's 22-pin connector and reviewing authorized service information before the controller/pedal-feel-simulator decision. The page does not support skipping those checks or replacing an assembly solely from the DTC title.

A non-returning P1E42-00 is treated as intermittent, using original freeze or snapshot information to understand the event. Preserve all brake records before clearing so the correct branch can still be selected.

The source supplies no relay-bypass test or safe method to force servo assistance back on. Qualified brake personnel must use the complete Honda procedure and verify normal supported operation afterward. An extinguished indicator following a restart does not by itself prove that the fail-safe path and related actuator functions have recovered.

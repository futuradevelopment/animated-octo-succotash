# P1E41: The brake fail-safe relay is reported stuck on

## The flowchart gives companion valve codes priority

Honda P1E41-00 identifies a stuck-on electric-servo-brake fail-safe relay. The factory confirmation includes at least a five-second wait after switching back on. The accompanying flowchart separates a relay-only result from a result that also contains P1E34-00 or P1E38-00, the two listed cut-valve stuck-on records.

When a companion valve code is present, the flowchart directs diagnosis to that code's procedure. When only P1E41-00 remains, it directs the technician toward the controller/pedal-feel-simulator branch. The prose below uses two YES labels, but the visual decision tree makes clear that these represent different code combinations.

## The relay-only branch still includes checks before replacement

The detailed instructions require inspection for loose terminals and poor connections at the brake controller's 22-pin connector and review of authorized service information before the assembly decision. That is not an unconditional instruction to replace the controller from a historical relay code alone.

If P1E41-00 does not return, the source treats the event as intermittent and refers to the recorded freeze or snapshot conditions. Preserve the complete code set before clearing so the distinction between an isolated relay fault and companion valve faults remains available.

A fail-safe relay belongs to the brake system's protective logic. Do not bridge or hold it on to suppress the warning. Qualified brake personnel should apply the full Honda procedure and verify correct supported braking operation after the cause is addressed.

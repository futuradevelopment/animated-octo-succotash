# P1E24: High redundant pedal feedback can follow a signal-to-supply short

## The wiring branch comes before the pedal assembly

Honda P1E24-00 identifies high voltage on the redundant brake-pedal stroke-sensor circuit. The cited procedure first verifies whether the fault returns after an HDS clear and power cycle. A non-returning fault is treated as intermittent, with the recorded freeze or snapshot conditions used to guide further investigation.

For a repeated fault, the procedure checks whether the ESB SVCC supply is shorted to either the BPS or BPSR signal line. It then checks the ESB SGND reference path. These branches explain how a high signal can arise from wiring or a missing reference rather than only from an internal sensor defect.

## Substitution is a diagnostic comparison, not the first step

Only after the specified wiring checks does the source use a known-good pedal assembly and repeat the fault check. If the fault disappears, the original pedal assembly is implicated by that comparison. If it persists, the procedure calls for connector and authorized-service-information checks before the brake-controller/pedal-feel-simulator decision.

The factory instructions include an OFF-mode waiting period with the driver's door open before connector work. This article summarizes the diagnostic logic; it is not a substitute for that complete safety and connector sequence.

Retain the full P1E24-00 record and related brake data before clearing. Diagnosis must be performed by qualified brake personnel using the correct Honda information, followed by verification of proper pedal sensing and supported braking operation.

# P1A55: Torque adjustment is checked between two internal requests

## The prose identifies a command-to-target comparison

Honda P1A55 is described as a difference between commanded traction-motor torque and target torque inside the control process. That is a different diagnostic idea from directly comparing a target with estimated motor output. The PCU controls output using phase-current information, and a malfunction can disturb the relationship between the requested control values.

The excerpt provides a set of torque-difference and duration pairs rather than one fixed timer. Its examples range from a large difference allowed for a fraction of a second to a smaller difference allowed longer. This indicates that severity and duration are considered together; it does not support a universal single-threshold road test.

## A table heading conflicts with the explanation

Although the description and threshold sentence refer to commanded versus target torque, the table heading refers to target versus estimated torque. That unresolved inconsistency is material to interpreting scan data. This article remains marked for review, and the table should not be used as a definitive pass/fail specification until the current Honda information resolves the compared quantities.

The possible causes include the I1 current sensor and an internal PCU fault. The excerpt identifies one-drive-cycle MIL storage with a power-system warning and freeze data. Save that evidence before resetting the system and have the correct diagnostic sequence applied by a qualified hybrid technician. Neither the code nor the contradictory table establishes which component should be replaced.

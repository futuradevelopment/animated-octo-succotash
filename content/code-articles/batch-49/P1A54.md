# P1A54: Motor torque estimation departs from the target

## The estimate uses current and rotor angle

Honda P1A54 compares target traction-motor torque with torque estimated from motor angle and current information. The PCU uses phase-current sensors to control motor output, and the monitor checks whether the estimated result remains consistent with the target. It is a control-performance comparison, not a direct measurement of torque at the wheels.

The factory table uses a variable time allowance. For example, a 292 N·m difference corresponds to 433 milliseconds, while an 82 N·m difference corresponds to 1.7 seconds. These are paired monitor values: using the longer time with the larger difference would misrepresent the documented calibration. Intermediate rows should likewise be read as complete pairs.

## Keep the event data before deciding on hardware

Monitoring is continuous in ON mode, and the possible-cause section names an internal PCU fault. That cause entry does not provide a component-level test or establish which internal function is responsible. The actual target, estimated torque and associated operating conditions are more useful evidence than the code title alone.

Honda classifies the fault as a one-drive-cycle MIL condition with a power-system indication, and stores pending, confirmed and freeze-data records in the motor control module. Preserve those records before clearing memory.

A technician should follow the matching Honda diagnostic procedure before any PCU decision. Access to the traction-drive electronics requires high-voltage precautions, and an owner should not attempt to provoke a large torque disagreement as a confirmation test.

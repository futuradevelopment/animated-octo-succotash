# P1A48: Shift-by-wire different-run monitoring points to PCM verification

## The exact internal fault label should be retained

Honda P1A48 is identified as the PCM's shift-by-wire different-run internal malfunction. The cited procedure groups it with separate parking-position and display-position internal codes, but it does not merge their meanings. Keeping the complete code list is preferable to reporting only a generic “transmission fault.”

The factory confirmation sequence evaluates multiple selected shift positions in READY TO DRIVE mode, with specified observation periods. That sequence checks whether the internal diagnostic result returns across the relevant shift states. It is not a physical road test of whether the vehicle will move unexpectedly.

## The replacement branch is conditional

If one of the listed internal codes repeats, the document directs the technician to applicable authorized service information or a controlled known-good PCM substitution. The original PCM is replaced only if the fault disappears under that substitution branch. A stored P1A48 by itself therefore does not justify immediately ordering a controller or a transmission.

If the code does not repeat, Honda treats the event as intermittent and refers to the on-board snapshot conditions. Preserve that information before clearing so the original state is not lost.

Because the confirmation involves shift selection in a drive-ready vehicle, it must be performed in a secured professional environment using the full Honda procedure. The excerpt does not publish the internal different-run threshold or explain a safe owner adjustment. Do not improvise shift-control or parking-system tests from the DTC label.

# P158F: An elevated ISOC signal can follow loss of its reference

## What the upper signal limit means

Honda P158F monitors the ISOC output used by the battery condition monitor module to calculate battery current. The factory threshold is more than 4.74 V for at least 500 milliseconds. This is an electrical signal-range fault. It does not establish that the battery's actual charge or discharge current is exceptionally high.

Monitoring begins only after the stated initial delay in ON mode and requires a 12-volt supply of at least 7.7 V. Those enable conditions explain when the controller is permitted to judge the signal; they do not replace normal battery and power-supply checks during diagnosis.

## The reference circuit is a distinct possibility

The source specifically lists an open SGISOC line, a failed battery-current sensor and an internal battery condition monitor module fault. An open reference can move a signal toward an implausible high reading without a corresponding rise in actual current. That distinction helps prevent a current-sensor code from being mistaken for proof of a failing traction-battery cell group.

Record available current data and freeze information, then use the correct Honda wiring and diagnostic procedure to isolate the cause. This advanced-diagnostics excerpt contains no universal connector test or replacement instruction. The listed fault class uses two drive cycles for MIL confirmation and also identifies the power-system indicator. Because the relevant hardware is associated with the high-voltage battery, inspection requiring access must be performed by trained personnel using the required isolation and verification steps.

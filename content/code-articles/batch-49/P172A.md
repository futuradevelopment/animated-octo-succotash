# P172A: The key-release wake-up output disagrees with its return

## The output has its own feedback check

Honda P172A concerns the shift-by-wire shifter control module's MTR CUT2 output and its return signal on the path involving the body control module. The labeled malfunction threshold specifies an abnormal return signal for at least two seconds while MTR CUT2 is commanded off. This is a commanded-state comparison, not proof that the physical key-release switch itself has failed.

The source lists a short to power on the SRKS line, an internal shifter-assembly fault and an internal body-control-module fault. Those alternatives require the appropriate wiring information to determine which part of the output and return path is responsible.

## The operating-mode descriptions need reconciliation

The introductory explanation places key-release wake-up activity in OFF/LOCK mode. The enable table and confirmation instructions, however, specify ON mode. The excerpt does not explain the relationship between those operating states. This article retains a source-review flag rather than inventing a universal reproduction sequence from the inconsistent descriptions.

Preserve the exact vehicle state and diagnostic records, and consult current Honda instructions before circuit testing. The document specifies pending and confirmed storage with freeze data in one drive cycle, without MIL illumination or a blinking shift-position indicator. Accordingly, a quiet dashboard does not demonstrate that the return-signal monitor has passed. Service involving shift-by-wire behavior also requires the vehicle to be secured against unintended movement.

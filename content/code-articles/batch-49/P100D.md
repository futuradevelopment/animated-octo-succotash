# P100D: The electric VTC motor remains active after shutdown

## A fault detected with the vehicle off

Honda P100D addresses electric VTC feedback after the PCM has turned off the motor relay in OFF/LOCK mode. The expected EVTM feedback is 100 percent duty within a five-percentage-point tolerance. Feedback outside that band for at least five seconds triggers the documented monitor. Its battery-voltage enable floor is 10.5 V.

That shutdown context distinguishes the code from a motor-speed disagreement while the system is operating. A useful record includes whether the fault was discovered after parking, together with the stored data, rather than only the engine's behavior during a subsequent start.

## Several paths can preserve the wrong signal

The factory cause list includes a motor VB2 supply short to power, a grounded relay-control line, a relay circuit stuck on and a grounded EVTM feedback line. These alternatives explain why the wording “relay stuck on” is not sufficient evidence to replace a relay immediately. A feedback wiring fault can also make the reported state disagree with the commanded state.

The excerpt is a monitor description, not a terminal-by-terminal isolation procedure. A technician should use the matching diagram and shutdown testing instructions before measuring the circuit or disconnecting components. The stored condition is classified as a one-drive-cycle fault with the MIL off; pending and confirmed records and freeze data can still be present. Absence of an illuminated engine lamp therefore does not invalidate a scan-tool report of this particular code.

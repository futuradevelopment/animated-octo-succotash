# P161B: A park-pawl program check fails during activation

## The fault concerns the driver's control program

Honda P161B identifies a problem detected while the park-pawl actuator driver unit checks its control program at activation. The unit operates the actuator that engages or releases Park. If its program is abnormal or has not been written, the unit reports the condition to the PCM, which stores the DTC.

This is not a monitor of how long a normal Park movement takes. The diagnostic definition directs attention to the unit's software state and internal checks. A recent module replacement or programming event is consequently useful history to preserve, although the code does not prove that such work caused the fault.

## A software label is not a programming authorization

The possible-cause list includes both an unwritten control program and an internal circuit failure. The excerpt does not identify a software package, programming sequence or replacement decision. Confirm the actual unit, vehicle configuration and current Honda service instructions before attempting either programming or parts replacement.

For confirmation, the document specifies ON mode and a wait of at least five seconds. It describes a blinking shift-position indicator with pending and confirmed records and freeze data, while the MIL remains off. Turning the vehicle off can extinguish that indicator without establishing that the activation check will pass next time.

Because reliable Park engagement is involved, keep the vehicle secured using the prescribed precautions. An indicator change or erased DTC should never be used as the sole evidence that the parking mechanism can safely restrain the vehicle.

# P1A51: The PCM detects an unsafe acceleration torque calculation

## The monitor compares calculated driving forces

Honda P1A51 is the acceleration-specific branch of the PCM's internal torque-calculation monitoring. The controller derives target drive force from pedal inputs, external requests and auxiliary loads, then compares the requested and permitted behavior with drive force calculated from its torque commands. The cited factory diagram includes engine, traction-motor and generator contributions.

For this branch, both a time-based judgment and an accumulated-difference judgment must indicate an abnormal result. The permitted duration varies with the size of the force disagreement. The excerpt therefore does not support a single fixed number of seconds or a universal torque threshold for all driving conditions.

## Preserve the detailed code behind the representative code

Honda identifies P061B as a representative DTC stored when the acceleration, deceleration or different-run branch is recorded. P1A51 supplies the more specific acceleration context; discarding it and investigating only P061B loses useful information. The source lists internal PCM failure as a possible cause but does not provide a stand-alone replacement or reprogramming decision.

This one-drive-cycle MIL fault retains pending and confirmed records, freeze data and an on-board snapshot. Those records should be preserved before clearing memory because they describe the calculation and operating conditions involved.

A suspected unintended-acceleration condition must be handled in a controlled professional setting. The monitor description is not an invitation to reproduce abnormal acceleration on public roads, and a reset alone cannot verify that the underlying torque-control problem has been resolved.

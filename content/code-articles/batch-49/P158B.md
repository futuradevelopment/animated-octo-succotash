# P158B: The battery-current sensor reference path is checked before substitution

## The factory path begins with the sensor reference

Honda P158B is a current-sensor circuit fault associated with the high-voltage battery. After verifying that the DTC returns in the specified operating state, the cited procedure checks the SGISOC connection between the battery-current sensor and battery condition monitor module. An open reference wire leads to a wiring repair rather than an immediate sensor decision.

That ordering matters because the monitor module depends on a sound sensor reference to interpret current information. A circuit code should not be converted into a diagnosis of deteriorated battery cells or an assumed need for a complete battery pack.

## A known-good sensor separates two remaining branches

If the reference path passes the required check, the factory procedure uses a known-good current sensor, reassembles the IPU and repeats the fault verification. If P158B disappears, the original sensor is implicated. If it returns, the branch points toward the battery condition monitor module. This is a conditional comparison after the wiring check, not a recommendation to replace both parts.

The procedure requires service-plug removal and substantial IPU access, including the junction-board area. Those operations demand the full Honda high-voltage service precautions and qualified personnel. This article does not replace the safe-access sequence or connector instructions.

Keep pending, confirmed and freeze-data records before clearing. When the fault does not repeat, Honda directs investigation using the original event conditions; a temporary absence after reset is not proof that the reference connection is permanently sound.

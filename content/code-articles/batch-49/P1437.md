# P1437: An inverter-short record requires motor and position-circuit evidence

## The companion gate-line code changes the path

Honda P1437 is labeled as a traction-motor inverter short. The cited factory procedure first determines whether that code can be reproduced under its controlled operating conditions. If P1437 does not return, it checks for P1440, the traction-motor inverter gate-line fault, and redirects diagnosis there when present. If neither is present, the stored event is treated as intermittent rather than a confirmed permanent short.

For a repeated P1437, the procedure moves into high-voltage motor checks. It specifies a milliohm-capable instrument and a 20 °C transmission-temperature condition for its winding-resistance comparison. The cited values are approximately 38.4–40.4 milliohms for the stated terminal pairs, not ordinary ohms and not a universal specification for other motors.

## Position feedback remains a separate decision

If the winding comparison passes, the source next calls for the traction-motor rotor-position-sensor circuit check. Its branches distinguish a wiring repair from major assembly decisions. That ordering matters: the word “inverter” in the code does not eliminate the motor and position-information paths from diagnosis.

This work requires service-plug removal, PCU removal and the complete Honda electrical-safety procedure. It is strictly a qualified high-voltage service task, not an owner test with exposed conductors.

Save freeze and companion-code information before clearing. The factory decision tree, including its temperature and measurement requirements, must be applied to the exact vehicle before any motor, PCU or transmission assembly is condemned.

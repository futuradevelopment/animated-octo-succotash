# P1E27: A high PU pressure-sensor signal needs confirmation and connector review

## The PU channel is the one identified by this code

Honda P1E27-00 refers to high circuit voltage on the PU brake-fluid-pressure sensing channel. The factory page also lists separate codes for the PUR, PL and PLR channels, but those are distinct identities. Record the exact suffix and channel combination rather than reducing the result to an unspecified pressure-sensor fault.

The confirmation sequence uses an HDS clear, a power cycle and several brake-pedal applications before checking whether the fault returns. The page does not publish the electrical high-voltage threshold or a hydraulic pressure specification. A high sensor-circuit code therefore should not be reported as proof that actual brake-fluid pressure is excessive.

## The source requires checks before its assembly decision

If one of the listed codes repeats, the procedure calls for inspection of loose terminals and poor connections at the electric-servo-brake controller's 22-pin connector and review of authorized service information. Only after those checks does its branch reach the controller/pedal-feel-simulator replacement instruction.

If the code does not repeat, the event is treated as intermittent, with freeze or snapshot information used to recover the original conditions. Preserve that data before clearing so the intermittent branch remains useful.

A qualified brake technician should apply the exact Honda troubleshooting procedure and verify restored function. The excerpt does not authorize opening hydraulic lines, bypassing the sensor or assuming the vehicle retains normal assistance simply because a warning has temporarily disappeared.

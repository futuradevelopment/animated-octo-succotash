# P1E32: The master-cylinder cut valve is judged stuck open

## The Honda suffix identifies the brake-system case

The cited Honda P1E32-00 record concerns a master-cylinder cut valve judged stuck off, or open, in the electric servo brake system. The monitor can run during both the initial self-check and regular operation. Its listed confirmation state uses a released brake pedal, a 12-volt supply between 9.5 and 16.7 V, and at least one second in ON mode without pressing the pedal.

That released-pedal requirement is part of this specific monitor. Repeatedly applying the brake immediately after startup would not preserve the confirmation state described in the excerpt. The approximately one-second diagnostic duration is also not a general hydraulic leak-test specification.

## The warning can affect several brake functions

Honda lists both red and amber brake indicators for this one-drive-cycle condition. The fail-safe description disables electric servo assistance and several cooperating functions, including regenerative braking, automatic hold and brake-related driving-support control. The practical significance extends beyond the valve name shown by a generic scanner.

The possible causes are an internal pedal-feel-simulator cut-valve problem and an internal electric-servo-brake control-unit fault. The excerpt supplies no pressure test, adjustment or owner repair procedure that separates them.

Preserve the complete brake-system DTC and diagnostic data, including the -00 suffix. A qualified brake technician should use the matching Honda troubleshooting instructions and secure the vehicle appropriately. Do not assume normal braking assistance remains available merely because the pedal can still be moved or the code has been cleared.

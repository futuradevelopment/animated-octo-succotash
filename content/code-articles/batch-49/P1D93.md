# P1D93: PCU coolant overheating is separated from component temperature faults

## Companion thermal codes are checked first

Honda P1D93 concerns excessive PCU coolant temperature. Before its own confirmation test, the factory procedure looks for specific internal-PCU, traction-inverter, generator-inverter, DC-DC converter, reactor and VCU overtemperature codes. If one is present, diagnosis is redirected to that component-specific record.

This ordering prevents a general coolant-temperature label from obscuring a more specific thermal fault. Preserve the complete DTC list rather than clearing companion records and then investigating P1D93 in isolation.

## A completed monitor result directs the cooling check

With those priority codes absent, the source uses the recorded freeze-data operating range and the HDS OBD-status result. FAILED leads to a PCU coolant-circuit inspection. PASSED is treated as an intermittent event, while NOT COMPLETED means the required monitoring result is still unavailable. Neither an incomplete monitor nor a cleared warning proves that the thermal problem has been resolved.

The subsequent branches distinguish a coolant-temperature sensor decision from cooling-fan-control troubleshooting based on the coolant-circuit inspection result. The excerpt does not publish a universal temperature threshold or authorize immediate sensor replacement merely because the coolant code is stored.

Professional confirmation must account for the vehicle's condition and avoid deliberately provoking overheating. Keep freeze data before reset, use the exact Honda inspection procedure and observe hot-coolant and high-voltage precautions around the PCU. Do not open a hot cooling circuit or continue loading a system that is showing active thermal distress.

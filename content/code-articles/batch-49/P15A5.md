# P15A5: Repeated inverter overcurrent events need a wider diagnosis

## The controller counts events

Honda P15A5 is associated with the traction-motor inverter and its phase-current information. The excerpt describes two ways of recognizing a problem: repeated operation of the overcurrent-detection path, or repeated movement of the current-sensor output from its normal band into a failure band when that detection path is not reporting correctly. In each description, three events within 1.2 seconds are significant.

The monitor operates with at least 8 V on the 12-volt supply. The document does not publish the actual sensor-voltage boundary used for its overcurrent decision, so an arbitrary voltage limit must not be inferred from the schematic illustration.

## Follow both the current and position evidence

The listed possibilities extend beyond the power control unit. They include traction-motor power cabling, rotor-position-sensor wiring, the motor, the position sensor and an internal PCU fault. Position information matters to controlled motor operation, which is why an inverter-current code alone is insufficient grounds to condemn the inverter.

Preserve the stored operating data and companion faults so the correct Honda procedure can distinguish a current event from a measurement or control problem. The fault is classified as one-drive-cycle MIL illumination with a power-system warning. Repeated attempts to provoke an overcurrent event are not an appropriate owner test. Qualified hybrid personnel must follow the high-voltage isolation and verification requirements before accessing motor cables, sensors or the PCU.

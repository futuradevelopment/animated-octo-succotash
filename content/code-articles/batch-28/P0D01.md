# P0D01: Ventilation-switch pilot test after charging-switch checks

## The sequence behind the code

P0D01 is the control-pilot charging-ventilation-switch range/performance check in GM’s 2015 table. It uses a narrower normalized voltage window than the neighboring charging-switch check. The stated failure conditions are pilot voltage above 10% or below 4% of battery voltage, rather than an absolute voltage or a charging-current limit.

This diagnostic runs with the ventilation switch closed, CPDIAG asserted, the cord reported not connected and system voltage above 9 volts. Both the pilot circuit/performance diagnostics and the charging-switch performance diagnostic must have completed during the current key cycle. Those prerequisites are central to interpretation: a ventilation-switch code cannot be assessed only from a snapshot taken during normal plugged-in charging.

## Practical diagnostic distinctions

First establish whether the preceding tests completed and what switch state was requested when the failure occurred. A missing prerequisite can explain why a later test has not run; it is not evidence that the ventilation switch passed. The documented counter requires 30 failing samples within 50 observations at 100-millisecond intervals.

Second, retain the normalized result and its battery-voltage reference. Comparing the raw pilot voltage directly to 4 or 10 volts would misread percentages as voltages. A value on either side of the window can trigger this performance monitor, so the code is not a diagnosis of one specific wiring defect.

The name does not establish that a battery ventilation fan has failed. The source describes an electrical pilot-switch test. Identifying the vehicle’s actual interface hardware and conducting any circuit work belongs to its approved charging-system service procedure.

## Source and applicability

15OBDG01 Hybrid Diagnostics, cited controller and monitor only. Historical calibration limits are not universal specifications; per-code vehicle, engine and hardware applicability must be verified.

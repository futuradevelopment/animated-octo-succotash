# C0031: Ford Transit wheel-speed fault with a debris-related inspection lead

## Noise and a wheel-speed code can be linked evidence

Ford SSM 47785 covers some 2015–2019 Transit vehicles with a front wheel-bearing-type noise and/or C0031 or C0034 in the ABS module. The important “and/or” means the communication includes a noise complaint, a code complaint or both. It does not require every vehicle to show all symptoms before the diagnostic lead is considered.

C0031 identifies the left-front wheel-speed sensor in the generic catalog, but the bulletin addresses both front sensor codes. The exact stored code and reported side should therefore be retained rather than treating the two front wheels as interchangeable.

## The source does not immediately condemn the bearing

The published procedure calls for a technician to remove the front wheel-speed sensor under Workshop Manual Section 206-09 and clean debris from the sensor body and the back of the bearing. This gives a specific contamination-related inspection point before deciding that a bearing or sensor must be replaced.

The result matters. If noise or the wheel-speed codes remain, Ford directs normal diagnostics to continue. A quieter bearing area alone does not establish that a stored ABS fault has been resolved; conversely, a cleared code does not prove that a persistent noise has been corrected.

The message also requested dealer reporting to support the manufacturer’s investigation. It does not supply a universal debris source, resistance specification or replacement part. The useful service evidence is the original noise and code status, what contamination was found and the result after the approved procedure. Because wheel-speed information serves the braking system, remaining faults require diagnosis rather than an assumption of restored ABS operation.

## Source and applicability

Ford SSM 47785: some 2015–2019 Transit vehicles with front bearing-type noise and/or C0031/C0034 in ABS. Sensor/bearing-area cleaning is a documented inspection step, with normal diagnosis required if noise or codes remain.

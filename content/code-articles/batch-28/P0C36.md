# P0C36: Sensor F high circuit corresponds to the cold end of its scale

P0C36 identifies a high electrical signal for battery-temperature sensor F in the cited GM table. Its explicit comparison is a reported temperature below −40°C together with an ADC count above 3992. The code label and converted temperature therefore point in different directions by design of the signal relationship.

## Preserve both representations

The ADC value helps explain why a circuit-high code can accompany an extremely cold displayed temperature. Neither value independently establishes the physical temperature of the battery. A workshop needs the actual sensor circuit information to distinguish a real thermal condition from a measurement-path issue.

The failure requires 1.4 seconds within a two-second window at 200-millisecond intervals. The pass criterion is temperature at least −40°C and ADC no greater than 3992 for two seconds. Timing belongs to both sides of the diagnostic.

## Review the prerequisites

Communication, reference-voltage and internal-performance exclusions in the shared table must be respected; the specified bus-off condition must be absent and the secondary protection self-test inactive. An inhibited monitor cannot provide a fresh pass result.

The strategy sentence's “above” wording conflicts with the explicit cold-temperature limit, which remains flagged for source review. No universal F-sensor location or replacement instruction follows from this document. Physical battery work requires the correct vehicle service procedure and qualified high-voltage personnel.

## Source and applicability

15OBDG01 Hybrid Diagnostics, cited controller and monitor only. Historical calibration limits are not universal specifications; per-code vehicle, engine and hardware applicability must be verified.

# P0C62: Motor B resolver circuit B high differs from its low branch

P0C62 monitors the high side of the motor-B resolver S2/4 reference-voltage circuit in this 2015 GM table. The explicit threshold is above 4.5 volts. The circuit-B label identifies a resolver path; it is not a second description of the drive motor's identity.

## Use the correct calibration and count

The wakeup signal must be on. The high condition qualifies 20 failed counts in 30 observations at 10.4-millisecond intervals, with 208 milliseconds listed as the accumulated failure time. The low-side P0C61 row uses a different count and duration. Those branches should not be assigned one assumed common timer.

These values belong to the cited controller. Thresholds from older motor tables or another resolver design must not be substituted without establishing applicability.

## Preserve the electrical evidence

A high reference-voltage report does not identify which physical component caused it. Keep the measured diagnostic value, wakeup state and related position-sensing records for the workshop. A learning-limit code concerns a different mechanism and cannot be treated as interchangeable with this electrical-range fault.

The document does not specify a universal connector cavity, wire color or replacement motor. A trained high-voltage technician must use the exact vehicle's circuit information to determine whether the report reflects a resolver, wiring or controller issue. Verification needs a valid awake-controller assessment, rather than only an erased fault memory.

## Source and applicability

15OBDG01 Hybrid Diagnostics, cited controller and monitor only. Historical calibration limits are not universal specifications; per-code vehicle, engine and hardware applicability must be verified.

# U0252: 2023 F-Super Duty history code after BCM self-test

## A history entry can come from the test sequence

Ford SSM 51578 identifies U0252:87 among several codes that may appear in the body control module after a diagnostic self-test on some 2023 F-Super Duty vehicles. The documented cause is an incorrect internal measurement sequence during self-test. The code then becomes a history entry, with status 0x48 or 0x08, because the BCM detects no continuing problem.

This is more specific than the generic “lost communication with rear lighting control module B” label. The reporting module, :87 suffix, history status and self-test trigger together establish the bulletin’s context. A currently active communication loss with malfunctioning lights is not explained away by the code string alone.

## The no-service exception has strict conditions

Ford said the listed entries could be ignored only when no other BCM DTCs were present, the malfunction indicator lamp was off while the engine ran and there were no drivability concerns. The listed self-test code group is the exception; additional faults change the assessment. The message also stated that BCM replacement or reprogramming would not resolve this particular condition.

Those limits make it important to retain the full scan report before clearing history. Merely seeing U0252 disappear after clearing does not prove the communication network was repaired, and repeating the self-test may reproduce the same artifact.

Compare code status and actual vehicle symptoms with the exact bulletin conditions. If the entry remains current, additional codes exist or a related feature is inoperative, the narrow exception is not established. Use applicable network and lighting diagnostics instead of automatically replacing a rear module or assuming all U0252 occurrences are harmless.

## Source and applicability

Ford SSM 51578: some 2023 F-Super Duty vehicles, U0252:87 in BCM after self-test with history status 0x48/0x08. No-service exception requires no other BCM faults beyond the listed group, MIL off with engine running and no drivability concern.

# P0D2D: Early Mustang Mach-E no-start after charging and remote start

## A software case with a distinctive sequence

Ford’s 2021 Customer Satisfaction Program 21B02 supplement addresses certain 2021 Mustang Mach-E vehicles built at Cuautitlan from February 24, 2020 through January 9, 2021. Affected VINs were identified through Ford’s service systems. The described event is a no-start after charging and using remote start, sometimes with P0D2D in the secondary on-board control module C, or SOBDMC.

The document describes false detection of a voltage-sensor fault and a restart after a 30-second shutdown. That recovery behavior helps identify the historical case, but a temporary restart is not evidence that the calibration concern has been corrected. Nor does it establish the cause of a persistent no-start outside that sequence.

## Previous update history can matter

The February 25, 2021 supplement warned that repairs dated February 24 or earlier might not have calibrated every required module because of a diagnostic-system concern. Those VINs required the revised programming procedure. A service invoice saying “software updated” is therefore incomplete evidence without the date and modules actually updated.

The program targeted the PCM and potentially five additional modules, depending on available updates and equipment. It did not require replacement parts. This supports checking calibration history before condemning an inverter voltage sensor from the generic code title alone.

The program’s published term ended February 28, 2022; this article does not promise present eligibility or free repair. A current service assessment should verify the VIN, installed calibrations and superseding instructions. High-voltage component work is not justified solely by this historically documented software-related P0D2D event.

## Source and applicability

Ford CSP 21B02 Supplement 1 dated 2021-02-25: certain VIN-selected 2021 Mustang Mach-E vehicles, Cuautitlan build 2020-02-24 through 2021-01-09; post-charge/remote-start no-start with P0D2D in SOBDMC. Includes pre-2021-02-25 repair-history issue; program terms are historical, not current coverage.

# B00D5: 2021 Edge and Nautilus restraint-indicator code in a wider gateway fault

## Look beyond the restraint-indicator label

Ford SSM 50127 describes 2021 Edge and Nautilus vehicles with multiple warnings in FordPass or the instrument cluster. Power windows, the power liftgate or climate control may also become inoperative. The scan pattern can include network-related codes across MS1, HS1 and HS3, with B00D5:01 and B1202:01 in the restraints control module and faults in other modules.

In that combination, Ford identifies a gateway-module software concern as a possible cause. B00D5’s generic passenger-disable-indicator description should therefore not automatically lead to replacement of the indicator or restraints control module. The wider symptom pattern is substantive diagnostic evidence.

## Why a full vehicle scan matters

An isolated B00D5 from another model or with another suffix is not established as the same case. Preserve the :01 suffix, reporting modules and the functions that stopped working. A scan restricted to the restraint system can omit the cross-network context that makes this bulletin relevant.

The documented correction is reprogramming the gateway module to the applicable software level using Ford’s diagnostic system. The target module is the GWM, even though the visible warning or stored code may come from another controller. This distinction helps avoid replacing a module that is reporting the problem rather than causing the documented communication behavior.

Software service should be followed by verification of the affected functions and reassessment of the complete code set. The message does not prove that all restraint warnings are software artifacts or that an individual vehicle’s restraints are functional. Persistent warnings or a pattern that does not match require the relevant manufacturer diagnostic procedures.

## Source and applicability

Ford SSM 50127: 2021 Ford Edge/Lincoln Nautilus with multi-feature warnings and MS1/HS1/HS3 network concerns, including B00D5:01/B1202:01 in RCM. Documented remedy targets GWM software; not an isolated universal B00D5 diagnosis.

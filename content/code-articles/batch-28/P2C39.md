# P2C39: F-150 2.7L temperature warnings need model-year-specific diagnosis

## The code combination changes the repair path

Ford TSB 26-2217 addresses North American 2024–2025 F-150 vehicles with the 2.7-liter EcoBoost engine, specified temperature warnings and P1299, P1285 and/or P2C39 in the PCM. The bulletin attributes the documented concern to PCM software and/or the cylinder-head-temperature sensor. Its description notes normal cooling-fan operation and no loss of coolant; those case details must not be used to dismiss evidence of actual overheating on another vehicle.

The service procedure distinguishes the years. A 2024 F-150 setting P2C39 enters the PCM software-update branch. If that vehicle does not also have P1285 or P1299, the bulletin considers the repair complete after that branch. It does not prescribe a temperature-sensor replacement solely because P2C39 is present.

## When sensor diagnosis enters the decision

For a 2024–2025 vehicle with P1285 and/or P1299, the procedure requires the specified engine-temperature pinpoint test, DL1–DL10. Sensor replacement with the updated version follows if those codes remain. A 2025 vehicle with only P2C39 does not automatically qualify for the 2024 software branch; the bulletin sends unmatched cases to normal workshop diagnosis.

This distinction prevents a parts list from being mistaken for a mandatory replacement list. The sensor is explicitly conditional. The bulletin also notes that resetting adaptive transmission strategy during programming may temporarily change shift feel while relearning occurs.

Record the exact model year, engine, warning messages and complete code set before selecting a branch. An over-temperature warning still requires evaluation; the presence of a published software case is not proof that the engine’s actual temperature is normal.

## Source and applicability

Ford TSB 26-2217 dated 2026-05-06: North American 2024–2025 F-150 2.7L EcoBoost with specified temperature warnings and PCM codes. P2C39-only software branch is for 2024; P1285/P1299 trigger separate testing. Current supersession and exact vehicle applicability require verification.

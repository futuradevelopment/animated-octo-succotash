# P2CFC: Explorer and Aviator warm A/C with a BCMC terminal concern

## The HVAC code can point to a connection elsewhere

Ford SSM 50811 addresses some 2020–2022 Explorer and Aviator vehicles with air conditioning blowing warm air and P0645, P2CFC and/or P2CFD stored in the HVAC module. The message identifies spread terminals or terminal pushout in wire harness 14290 and the corresponding body control module C connections as a possible cause.

The distinction between the reporting HVAC module and the implicated BCMC connection matters. A code found in the climate-control module does not automatically establish that module as faulty. Similarly, warm air plus an A/C clutch control-circuit code is not proof of a refrigerant charge problem or a mechanically failed compressor.

## What Ford asks technicians to check first

Before replacing the BCMC, the bulletin directs inspection of its pins and the mating wire terminals for damage. Spread contacts and pushed-out terminals are different failure mechanisms: one can reduce contact grip, while the other can prevent correct engagement. The inspection must follow Workshop Manual Section 419-10 and the appropriate wiring-repair instructions, rather than using improvised probes that could alter terminal fit.

Where damage is found, the connection is repaired and reassembled according to the prescribed procedure. The stated functional verification is that the A/C produces cold air. A cleared code without restored cooling would not satisfy that symptom-based check.

The bulletin is a targeted diagnostic lead, not a declaration that every P2CFC requires harness or BCMC replacement. Match the model years, warm-air complaint, module and accompanying code pattern, then continue appropriate diagnostics if the connection concern is not present or the malfunction remains.

## Source and applicability

Ford SSM 50811: some 2020–2022 Ford Explorer/Lincoln Aviator vehicles with warm A/C and P0645/P2CFC/P2CFD in HVAC. Harness 14290/BCMC terminal inspection precedes replacement; applies to this documented symptom and vehicle group.

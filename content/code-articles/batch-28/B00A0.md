# B00A0: Mazda B00A0:09 after low-voltage cranking

## The Mazda case behind the generic code

Mazda bulletin 08-003-22 documents B00A0:09 in the SAS control module with an illuminated airbag warning lamp. This case concerns US-specification 2016–2020 CX-3 vehicles below VIN JM1DK******463689, produced before November 5, 2019, and 2017–2020 CX-5 vehicles below VIN JM3KF******764404, produced before December 9, 2019. Mexico-specification vehicles are excluded because the bulletin says they lack this occupant-classification system.

The suffix matters. Mazda describes B00A0:09 as unstable internal signal output from the occupant-classification sensor. The documented mechanism is an overly short low-voltage detection period during cranking, with cold-weather starting demand making the concern more frequent. It is not evidence that every B00A0 occurrence has the same cause.

## Why the warning may remain after starting

The bulletin explains that the lamp can stay illuminated for the drive cycle even after voltage recovers. Thus a normal voltage reading after the engine starts does not rule out the reported starting event. Mazda’s statement about normal system operation after voltage stabilizes is specific to this verified concern; the code alone cannot establish restraint-system readiness on another vehicle.

The published remedy is replacement of the passenger-seat cushion assembly with the modified version containing the revised sensor, followed by repair verification. Part selection depends on VIN and seat equipment, so a single generic cushion number is inappropriate.

Have a qualified restraint-system technician match the complete code, starting-voltage history, build limits and seat configuration before applying this repair. The bulletin does not justify replacing the SAS module or bypassing the occupant sensor.

## Source and applicability

Mazda bulletin 08-003-22: B00A0:09 in the SAS module; US-spec 2016–2020 CX-3 below JM1DK******463689/before 2019-11-05 and US-spec 2017–2020 CX-5 below JM3KF******764404/before 2019-12-09. Mexico-spec vehicles excluded; exact VIN and seat configuration must be checked.

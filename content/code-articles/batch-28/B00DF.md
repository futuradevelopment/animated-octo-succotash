# B00DF: 2024 Nautilus B00DF:4A generated during self-test

## A diagnostic-event code with a specific suffix

Ford SSM 52117 concerns some 2024 Lincoln Nautilus vehicles that store B00DF:4A in the restraints control module when a diagnostic self-test is performed. The message attributes the condition to an internal counter reaching a specified timeframe. It does not describe a failed physical passenger-restraints disable switch.

That distinction matters because the generic B00DF label can otherwise encourage replacement of a switch or restraint component without matching the actual event. Record the :4A suffix, the reporting module and whether the code first appeared during self-test. A fault with another suffix or an independent warning symptom is not established as the same condition by this bulletin.

## What Ford said about repair

The December 2023 message stated that this particular B00DF:4A condition did not affect functionality and that replacing or reprogramming the RCM would not resolve it. Engineering expected a Ford Power-Up over-the-air software solution in the third quarter of 2024. The message discussed automatic delivery when connectivity was enabled and service visits for vehicles that did not receive the planned update.

Those statements describe the manufacturer’s plan at publication. They do not confirm current update availability, successful installation on an individual vehicle or the safety status of a restraint system with other faults. The useful next step is checking present vehicle software and service history against current manufacturer information.

Avoid interpreting repeated self-tests as a repair or replacing the RCM solely to erase this entry. A restraint-system technician should distinguish the documented self-test artifact from any current warning, malfunction or additional DTC requiring normal diagnosis.

## Source and applicability

Ford SSM 52117, December 2023: some 2024 Lincoln Nautilus vehicles with B00DF:4A in RCM during diagnostic self-test. Historical Q3 2024 update expectation is not verified current availability; functionality statement applies only to the documented condition.

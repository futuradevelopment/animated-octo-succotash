# P0230: The fuel pump power-relay circuit is not the pump pressure test

Ford describes P0230 as the fuel pump primary circuit in its single-speed system and as the pump electronics module power-relay circuit in another control arrangement. Both descriptions concern electrical control evidence, rather than a direct measurement of delivered fuel pressure.

## Identify the pump-control architecture

The single-speed table groups primary and secondary circuit faults, while the later fuel pump A table separates relay, command-signal, secondary-output, internal-module and communication results. A generic P0230 description does not establish which version is installed.

In the pump A strategy, the source says the fuel pump driver detects the relay circuit fault and gives no separate numerical threshold. Publishing a universal relay resistance or pump-current limit from this code would therefore go beyond the evidence.

## Separate a commanded-off pump from a failed circuit

The document's duty-cycle description shows that some valid command states intentionally switch the pump off. It also distinguishes invalid commands from normal operation through feedback status. An inactive pump is not sufficient by itself to reproduce the P0230 diagnostic condition.

The check runs continuously within a battery-voltage window of 11–16 volts, with a listed two-to-five-second evaluation. Preserve the command, module feedback and exact code category. This information narrows the electrical branch that needs investigation; it does not prove the pump motor or fuel-pressure regulator has failed. Use the matching vehicle circuit procedure for the repair decision.

## Source and applicability

This explanation covers the cited Ford monitor variants, not every vehicle displaying this code. Match the engine, sensor architecture and calibration before applying numerical limits.

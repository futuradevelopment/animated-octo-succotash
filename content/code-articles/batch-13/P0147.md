# P0147: The bank 1 sensor 3 heater circuit has its own identity

P0147 is listed in Ford's bank 1 sensor 3 oxygen-heater circuit group. The sensor number should remain attached to the diagnosis: the source covers several downstream heater channels, and a generic “rear O2 heater” description is not enough to select one.

## Circuit checks differ from current and temperature checks

Ford separates heater voltage-driver monitoring from heater current, temperature-control and impedance strategies. The voltage check runs continuously, while current and impedance checks normally run once per driving cycle. A recurring circuit result can therefore appear on a different schedule from a current test that has not yet repeated.

The published voltage-test conditions include inferred sensor temperature and a battery-voltage window. The driver reports its own malfunction status, rather than the code supplying a universal resistance value for the heater.

## Use the exact sensor arrangement

The same table lists P0055 as bank 1 sensor 3 heater resistance. That separate label helps distinguish the circuit category from the current-based evaluation. It does not prove that both codes identify an identical failure mode.

Confirm the installed sensor layout and full code format, then use the vehicle's circuit procedure to interpret driver status and supply behavior. The summary does not assign a connector pin or physical exhaust position. Verification should show that the relevant circuit monitor runs without repeating its fault, while separately checking completion of any other affected heater tests.

## Source and applicability

This explanation covers the cited Ford monitor variants, not every vehicle displaying this code. Match the engine, sensor architecture and calibration before applying numerical limits.

# P0167: Bank 2 sensor 3 heater circuit monitoring is separate from resistance testing

Ford lists P0167 for the bank 2 sensor 3 oxygen-heater circuit. Its location within the source matters because several downstream sensor channels and several kinds of heater checks are described together. The code should not be reduced to an unidentified rear sensor fault.

## Identify the monitored electrical category

The voltage-driver check is continuous, while heater-current and impedance checks are generally once-per-cycle evaluations. Ford also describes a temperature-control monitor that watches the control system at its limits. These strategies provide different evidence even when they involve the same sensor assembly.

The source lists P0061 separately for bank 2 sensor 3 heater resistance. Seeing P0167 does not automatically mean that the current-based resistance criterion was the one that failed. Retain the expanded code, driver status and test completion information where available.

## Confirm sensor 3 before using a result

The published entry conditions distinguish inferred temperatures for sensor 2 and sensor 3. They do not provide a universal exhaust diagram, so an engine-specific sensor map is needed before selecting a connector or part.

Verification should demonstrate that the relevant circuit check no longer reports its fault under the documented operating conditions. A sensor 2 Mode $06 result is not automatically evidence for sensor 3, and a cold resistance reading is not equivalent to the running driver evaluation. The summary does not prescribe a replacement or identify the root cause without further circuit evidence.

## Source and applicability

This explanation covers the cited Ford monitor variants, not every vehicle displaying this code. Match the engine, sensor architecture and calibration before applying numerical limits.

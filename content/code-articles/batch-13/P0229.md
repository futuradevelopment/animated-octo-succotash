# P0229: A short interruption at the second throttle can precede a communication-loss code

P0229 identifies intermittent sensor C behavior in Ford's dual-electronic-throttle SENT strategy. The cited implementation belongs to throttle body B. Confirm that arrangement before using the lettered sensor description to identify a component.

## Timing separates this result from longer faults

Ford gives the intermittent check a fault persistence of more than 0.4 seconds. The neighboring sensor-fault and communication-loss checks require more than four seconds. A brief disruption can therefore satisfy P0229 without producing the longer-duration result.

This makes a time-resolved record more useful than one stable throttle reading obtained later. Preserve sensor status, communication events and the duration of any dropout. The absence of a communication-loss code does not prove that the signal remained uninterrupted.

## Keep the second throttle's data separate

The source has distinct code groups for the first and second electronic throttle bodies. A clean sensor A record is not verification of sensor C. Likewise, analog voltage thresholds from another section are not the published SENT intermittency criterion.

Ford lists continuous monitoring with MIL and wrench indications for this group. Verification should establish that the relevant second-throttle monitor runs without recurring interruptions. The source explains why a brief event can matter, but it does not identify a connector, prescribe probing steps or prove which component caused the event. Those decisions require the actual vehicle's dual-throttle circuit information.

## Source and applicability

This explanation covers the cited Ford monitor variants, not every vehicle displaying this code. Match the engine, sensor architecture and calibration before applying numerical limits.

# P2112: A stuck-closed throttle code needs the original control context

P2112 is Ford's throttle actuator A stuck-closed result. The monitor concerns failure to achieve the intended plate response. It does not establish from the code alone whether the motor, position feedback, mechanism or control electronics caused that failure.

## Distinguish the fault event from fallback behavior

Ford's electronic-throttle overview describes strategies that disable plate control or request a default position after a significant fault. A plate position observed afterward may therefore reflect the protective response rather than the initiating event. Preserve desired and actual position data and companion codes from the original occurrence when available.

The source separately lists current-range, cross-wiring and position-related categories. Those distinctions help organize evidence instead of treating every throttle code as the same mechanical problem.

## Do not guess the angle-error sign

An early monitor table prints desired-versus-actual comparisons for stuck-open and stuck-closed faults without clearly defining the subtraction convention. Its later actuator table confirms the code category but does not resolve a universal signed limit. This article consequently avoids publishing a guessed numerical P2112 threshold.

Use the matching engine and throttle architecture's procedure to determine the relevant error and monitoring duration. Verification should show credible feedback and correct response to eligible commands while the actuator check completes. The summary does not support forcing the throttle plate, bypassing control protection or automatically replacing the assembly based only on a stored stuck-closed description.

## Source and applicability

This explanation covers the cited Ford monitor variants, not every vehicle displaying this code. Match the engine, sensor architecture and calibration before applying numerical limits.

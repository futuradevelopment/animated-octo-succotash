# P00D2: Bank 1 oxygen heater performance and the impedance test distinction

Ford's heater table describes P00D2 as bank 1 sensor 2 heater control range/performance, and its Mode $06 table associates it with the HO2S12 impedance result. This is more specific than assuming every oxygen heater code represents an open heating element.

## Identify which electrical property failed

The documented impedance test requires a warmed sensor element, sufficient heater-on time and a stable inferred thermal state. It also excludes deceleration fuel shutoff and certain commanded lean or enrichment conditions. Those restrictions matter because the controller evaluates the sensor under a controlled operating context, not as an unpowered resistor on a bench.

The impedance limit is tabulated against both voltage and inferred element temperature. A single resistance number taken from the table cannot serve as a universal replacement threshold. For supported CAN applications, monitor $42, test $82 is the relevant bank 1 impedance result; test $81 concerns heater current instead.

## Resolve the source's numbering conflict

The P00D2 row appears under a “sensor 3” group heading, while its row description and Mode $06 mapping both identify sensor 2. This article retains that conflict rather than inventing a component location.

Use the full code, engine-specific sensor diagram and reported test identity to resolve the installed channel. The source supports distinguishing impedance from current evaluation, but its inconsistent heading is insufficient to select a physical sensor without vehicle-specific confirmation.

## Source and applicability

This explanation covers the cited Ford monitor variants, not every vehicle displaying this code. Match the engine, sensor architecture and calibration before applying numerical limits.

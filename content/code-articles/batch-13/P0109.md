# P0109: MAP intermittency is an event-count diagnosis

P0109 addresses intermittent manifold absolute pressure or barometric sensor behavior in Ford's cited monitor. The controller counts brief out-of-range events during a driving cycle. A normal pressure value at the moment of inspection therefore does not contradict a stored intermittent result.

## Separate intermittency from rationality

Ford gives the intermittent check a 25-event-per-trip criterion. Nearby tables describe P0106 rationality checks that compare measured MAP with barometric pressure or an estimated pressure. These are different questions: one concerns repeated electrical-range excursions, while the other asks whether a reading makes sense against a reference.

A successful key-up MAP-to-barometric comparison consequently does not prove that P0109's intermittent condition has disappeared. Preserve a time record that can reveal short excursions, along with whether the events occur at start-up or during running operation.

## Avoid adopting an unrelated pressure limit

The same document presents more than one MAP rationality variant with different stabilization periods and comparison limits. Those values are not P0109's event-count threshold and should not be borrowed as its universal test specification.

The cited source supports focusing on recurring out-of-range behavior and monitor completion. It does not identify a particular connector pin, harness location or replacement component. Use the installed sensor architecture and calibration-specific circuit procedure to determine the cause, then confirm that valid operation no longer accumulates the intermittent events rather than simply clearing the memory.

## Source and applicability

This explanation covers the cited Ford monitor variants, not every vehicle displaying this code. Match the engine, sensor architecture and calibration before applying numerical limits.

# P0055: A sensor 3 heater resistance code is not a rear sensor location guide

Ford lists P0055 in the sensor 3 heater group for bank 1. Its heater-resistance label belongs to a family in which the controller monitors electrical current, voltage-driver behavior and temperature control separately. Confirm that the vehicle actually uses the documented sensor arrangement before selecting a physical component.

## Sensor number changes the applicable conditions

The source gives distinct inferred-temperature ranges for sensor 2 and sensor 3 during the heater current check. It also requires at least 30 seconds of heater operation, engine speed below the listed limit and an appropriate battery-voltage range. A cold disconnected sensor measurement is therefore not equivalent to the controller's enabled current evaluation.

Heater current is checked once per driving cycle; voltage checks are continuous. If the current monitor has already finished, waiting at idle may not produce a new result. Review its completion state rather than assuming the absence of an immediate repeat fault clears the circuit.

## Keep current and impedance evidence separate

The summary supplies different current limits for several sensor constructions. It also describes a rear-sensor impedance test, but that test has its own conditions and is not a general ohmmeter specification for P0055.

Use the exact sensor type and calibration's service information to interpret a measured value. The monitor summary does not establish connector pins, exhaust location or a mandatory replacement. Its useful conclusion is which heater channel and test family require further evaluation.

## Source and applicability

This explanation covers the cited Ford monitor variants, not every vehicle displaying this code. Match the engine, sensor architecture and calibration before applying numerical limits.

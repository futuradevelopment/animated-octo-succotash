# P0231: Low secondary fuel-pump circuit feedback needs the correct system context

P0231 is the fuel pump secondary-circuit-low result in Ford's single-speed returnless fuel-system check. It is distinct from P0230, which concerns the primary circuit, and from pressure-control faults elsewhere in the OBD summary.

## A pump-off state can be intentional

Ford's command table distinguishes valid off requests from invalid duty cycles. Both can leave the pump stopped, but the module's feedback status differs. Consequently, observing that the pump is not running does not establish the low-secondary-circuit condition.

The source also describes feedback duty cycles that identify invalid commands, internal module errors and secondary-circuit concerns. These are coded status messages, not percentages of fuel pressure. Preserve command and feedback together to avoid treating a diagnostic status value as direct pump output.

## Do not invent a universal low-voltage threshold

The single-speed check operates within an 11–16-volt battery window and lists a two-to-five-second monitoring duration. It does not supply a separate P0231 terminal voltage boundary or connector pin assignment on these pages.

Use the exact vehicle's control architecture and circuit information to determine how the secondary low condition is detected. Verification should show that the correct circuit monitor no longer reports the fault while valid pump commands are present. The code alone cannot establish whether the cause lies in the pump assembly, its wiring or another part of the controlled circuit, and it is not a fuel-pressure test result.

## Source and applicability

This explanation covers the cited Ford monitor variants, not every vehicle displaying this code. Match the engine, sensor architecture and calibration before applying numerical limits.

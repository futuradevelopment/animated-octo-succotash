# P0012: Why retarded intake timing needs a commanded-position comparison

P0012 identifies bank 1 intake cam timing that remains too far retarded in Ford's variable cam timing monitor. It is a response or target-error result: the important comparison is where the cam should be versus where the controller sees it, not simply whether the cam position sensor produces a signal.

## Check whether timing control was actually enabled

The documented functional checks require a command to advance or retard the cam. The table includes a 400 rpm minimum for oil-pressure availability and a start delay of at least two seconds, with the delay dependent on coolant temperature. A reading taken while cranking or before control is enabled therefore cannot reproduce the functional test.

Ford also lists sensor failures and throttle failure mode among conditions that disable cam timing control. If those conditions are present, interpret an apparently motionless cam in that context before attributing the result to a mechanical timing fault.

## Separate target error from alignment

The summary assigns different monitoring windows to functional checks and accumulated target error: seconds for the former, several minutes for the latter. Its separate correlation monitor concerns crank/cam alignment, so P0012 alone does not establish a slipped tooth.

For supported CAN applications, Mode $06 monitor $35, test $81 reports bank 1 retarded-position error. Compare the result with its reported limit and retain commanded/actual timing and operating conditions. The summary does not provide a universal oil, actuator or timing-chain replacement decision.

## Source and applicability

This explanation covers the cited Ford monitor variants, not every vehicle displaying this code. Match the engine, sensor architecture and calibration before applying numerical limits.

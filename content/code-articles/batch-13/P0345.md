# P0345: Bank 2 intake cam circuit evaluation depends on engine-event relationships

P0345 is the bank 2 intake cam-position circuit result in Ford's ignition-system monitor. The source evaluates the cam signal in relation to engine-position events. It does not define P0345 as a direct command-response test of the variable cam timing actuator.

## Match the expected event ratio to the engine

Ford gives several possible ratios of engine-position events to cam events, selected according to cylinder count. Those alternatives make the engine configuration essential. Applying one ratio to every P0345 vehicle would be an unsupported diagnostic shortcut.

The check is continuous once its operating conditions are met, with a 200 rpm entry speed and a monitoring duration below five seconds. Retain the relevant crank and intake-cam event evidence rather than relying solely on a static cam-angle display.

## Distinguish the neighboring intermittent code

The same table assigns P0349 to bank 2 intake cam intermittency, described as a signal occurring in an unexpected location. That separate category helps distinguish an event-pattern problem from a broader circuit result, even though both require the correct signal reference for interpretation.

The summary does not supply a bank-location diagram, connector pinout or a universal sensor voltage. Use the exact engine's procedure to determine whether the recorded relationship is valid and what caused any failure. Verification should establish a completed signal check with the correct event pattern; replacing a cam actuator or timing component solely because P0345 is present is not supported by this source.

## Source and applicability

This explanation covers the cited Ford monitor variants, not every vehicle displaying this code. Match the engine, sensor architecture and calibration before applying numerical limits.

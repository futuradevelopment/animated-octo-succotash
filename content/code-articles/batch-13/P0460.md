# P0460: A broad fuel-level circuit code can represent either electrical extreme

Ford's fuel-level input table includes P0460 as a broad circuit result that can accompany either a low or high electrical input. A scanner that displays only “fuel level sensor circuit” may therefore omit the direction needed to select the appropriate diagnostic branch.

## Preserve the expanded failure information

The source associates the low condition with a very small resistance/input count and the high condition with a large resistance/input count. It also lists more specific P0462 and P0463 codes. Retrieve the complete code format and actual input state before assuming that P0460 identifies one fixed failure mode.

The electrical check is continuous and is listed with a 30-second duration. That differs from the noisy-input monitor, which counts large changes between samples, and from the stuck-input monitor, which compares consumed fuel with indicated level over much longer operation.

## A believable gauge reading does not cover every test

A level display can look plausible at one moment while electrical excursions or a failure to track fuel consumption occur elsewhere in the trip. Conversely, slow gauge movement alone does not establish an electrical high or low circuit result.

Use the correct sender circuit and vehicle-specific scaling before applying the published example limits. The source does not define the sender's physical access procedure or prescribe replacement. Verification should establish a valid electrical input while the relevant monitor runs, with noise and stuck-reading concerns assessed as separate diagnostic categories.

## Source and applicability

This explanation covers the cited Ford monitor variants, not every vehicle displaying this code. Match the engine, sensor architecture and calibration before applying numerical limits.

# P0120: A SENT throttle sensor can report a fault while still communicating

In Ford's SENT throttle-position strategy, P0120 means sensor A reports a fault state lasting more than four seconds. This is a specific implementation of the broader throttle/pedal sensor circuit description; it should not automatically be treated as an analog signal below a voltage limit.

## Failure status is not the same as no communication

The source separately identifies U0606 for communication loss and other codes for communication-line low or high conditions. P0120's device-fault status can therefore convey different information from a missing SENT message. Preserve the complete code set and the scanner's expanded descriptions before selecting a diagnostic branch.

The monitor operates continuously and the document associates it with both MIL and wrench indications. That classification describes the documented response, but it does not determine a vehicle's available torque or whether it is safe to continue driving in a particular fault state.

## Confirm which throttle architecture is fitted

Ford also documents analog throttle-position checks elsewhere. Their voltage thresholds are not substitutes for this digital device-status criterion. Similarly, dual-throttle applications have a separate sensor C channel and code family for the second electronic throttle body.

Use the engine-specific procedure to evaluate the SENT sensor, its data and its circuit. A successful verification needs the relevant fault status to remain absent while the monitor runs. Simply seeing a changing percentage on a generic throttle display does not establish that the device's internal diagnostic status is healthy.

## Source and applicability

This explanation covers the cited Ford monitor variants, not every vehicle displaying this code. Match the engine, sensor architecture and calibration before applying numerical limits.

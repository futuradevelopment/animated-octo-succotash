# P0369: Resolve the bank 1 cam-channel label before diagnosing intermittency

P0369 is listed as an intermittent cam-position circuit result with the expanded form P0365_02 in Ford's summary. The neighboring P0365 base row identifies bank 1 exhaust cam position, but the P0369 text itself says intake. That inconsistency must be resolved against the actual vehicle before selecting a sensor.

## The supported monitor behavior is still useful

The table describes intermittent cam behavior as an event appearing in an unexpected location. It also compares engine-position events with cam events through a cylinder-count-dependent ratio. This is signal-pattern evidence, not a direct declaration that a variable cam timing actuator is stuck.

Ford lists continuous monitoring above the documented 200 rpm entry condition and a duration below five seconds. A visible pulse or a plausible cam-angle reading at one later moment does not establish that the earlier event sequence was correct.

## Do not guess the physical channel

Use the complete manufacturer-format code and engine-specific wiring or waveform information to resolve the row's intake/exhaust conflict. This article does not silently correct the manual or assign a universal sensor location.

Once the channel is confirmed, verification should show consistent cam-event placement relative to engine position while the monitor runs. The source does not provide a unique terminal voltage, timing-drive diagnosis or replacement instruction. Its useful contribution is the event-pattern distinction and the explicit warning that the printed channel label is internally inconsistent.

## Source and applicability

This explanation covers the cited Ford monitor variants, not every vehicle displaying this code. Match the engine, sensor architecture and calibration before applying numerical limits.

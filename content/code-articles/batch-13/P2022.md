# P2022: Bank 2 runner feedback is electrically high before position can be trusted

Ford lists P2022 as bank 2 intake manifold runner position sensor circuit high. The documented high boundary is above 4.7 volts. This describes an electrical range condition, not automatically a valid report that the runner plates are fully open.

## High voltage and excessive travel are different categories

The same source assigns P2020 to bank 2 position over-travel and P2005 to stuck-open behavior. Those functional results concern the mechanism's reported response relative to its command or permitted range. An electrically invalid signal needs to be resolved before relying on it for either conclusion.

The circuit check lasts five seconds, while functional stuck/over-travel evaluation uses four events. A successful electrical repair can therefore require an additional functional verification opportunity before the entire runner system has been assessed.

## Match the documented architecture

The table is explicitly for a vacuum-actuated V-engine arrangement and begins monitoring after coolant exceeds 40°F. It does not establish that all P2022 applications share the same hardware or sensor scaling.

Preserve the bank 2 signal, operating conditions and companion control or functional codes. The engine-specific procedure is needed to locate the circuit and determine whether the high state comes from sensing, wiring or control electronics. The cited summary does not identify a replacement part. Verification should demonstrate a valid feedback range and appropriate command response, not merely a temporarily absent warning.

## Source and applicability

This explanation covers the cited Ford monitor variants, not every vehicle displaying this code. Match the engine, sensor architecture and calibration before applying numerical limits.

# P0136: Rear oxygen activity is judged after several other tests finish

In Ford's rear oxygen-sensor functional check, P0136 describes lack of activity from bank 1 sensor 2. Depending on the diagnostic implementation, the source also lists more specific stuck-lean and stuck-rich alternatives. This functional result is not automatically the same as a wire shorted high or low.

## The test relies on a trustworthy fuel system

The activity monitor follows front-sensor response and other oxygen-sensor checks. Ford excludes heater, circuit, misfire and several fuel-system malfunctions that would undermine the interpretation. A rear sensor that appears inactive while one of those prerequisites has failed cannot be evaluated in the same way as a completed functional test.

The entry conditions include warmed coolant, sufficient rear-heater operation, closed-loop fueling and a limited fuel-trim range. Purge-related activity and cold-start spark-retard operation can also prevent the test from running. These details explain why a quick cold idle is an inadequate verification window.

## Interpret switching evidence, not only one voltage

The source evaluates whether the rear signal traverses its rich/lean voltage envelope. It maps the bank 1 rear switch-point result to Mode $06 monitor $02, test $01. Retain completion status and the actual test result before deciding that a static reading proves a failed sensor.

This monitor summary identifies the behavior being evaluated. It does not independently distinguish the sensor assembly from fueling, exhaust or circuit causes on an individual vehicle, and it does not provide a universal replacement procedure.

## Source and applicability

This explanation covers the cited Ford monitor variants, not every vehicle displaying this code. Match the engine, sensor architecture and calibration before applying numerical limits.

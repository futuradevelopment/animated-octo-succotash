# P0156: Bank 2 rear sensor activity requires a completed functional check

P0156 identifies lack of activity from the bank 2 rear oxygen sensor in Ford's functional-check table. The document also lists stuck-lean and stuck-rich alternatives for that channel. These functional descriptions concern response across a voltage envelope, rather than directly identifying an open or short circuit.

## Check that the test had a valid opportunity

The rear activity check follows several front-sensor and circuit evaluations. It is inhibited by specified oxygen-heater, fueling, misfire and related faults. If those prerequisites have not passed, an unchanging rear reading has a different evidential value from a completed monitor failure.

Ford also requires warm operating conditions, sufficient rear-heater time, closed-loop operation and fuel trims within a stated range. Certain purge activity and cold-start emission-reduction operation exclude the test. A brief observation immediately after starting therefore cannot establish whether the activity monitor has genuinely evaluated the sensor.

## Select the bank 2 data

The published Mode $06 mapping assigns the HO2S22 switch-point result to monitor $06, test $01. This differs from bank 1's monitor ID. Retain the code identity and completion state so that a bank 1 result is not accidentally used to clear a bank 2 concern.

The diagnostic summary explains what movement is expected under eligible conditions. It does not identify the physical sensor location or decide among sensor, circuit and other vehicle-specific causes. Those decisions require the matching service information and supporting measurements.

## Source and applicability

This explanation covers the cited Ford monitor variants, not every vehicle displaying this code. Match the engine, sensor architecture and calibration before applying numerical limits.

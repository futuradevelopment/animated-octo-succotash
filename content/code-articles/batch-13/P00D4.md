# P00D4: Interpreting a bank 2 oxygen heater impedance result

P00D4 is linked to bank 2 sensor 2 heater range/performance in Ford's row description and to HO2S22 impedance in its diagnostic test mapping. The controller can therefore be reporting a warm-element electrical behavior problem rather than simply an absence of heater supply.

## Temperature changes the meaning of impedance

The source's impedance limit depends on inferred element temperature and voltage. Its enabling conditions also require heater operation and a stable thermal estimate. An arbitrary resistance reading taken at room temperature cannot be compared directly with that operating table.

Fueling state matters as well: the test excludes deceleration fuel shutoff and specified lean or enrichment commands. If the monitor has not completed after a repair, record whether these conditions prevented evaluation before interpreting the missing result as successful verification.

## Read the correct bank and test

For supported CAN diagnostics, Ford identifies bank 2 impedance as monitor $46, test $82. The neighboring $81 result is heater current and corresponds to a different code family. A scanner that displays only a generic heater result may hide this important distinction.

There is a documentation conflict: the P00D4 row is placed beneath a sensor 3 heading, while the row and test mapping point to sensor 2. Resolve that numbering against the actual engine and calibration before locating or replacing anything. This explainer preserves the limitation rather than treating the inconsistent heading as a wiring diagram.

## Source and applicability

This explanation covers the cited Ford monitor variants, not every vehicle displaying this code. Match the engine, sensor architecture and calibration before applying numerical limits.

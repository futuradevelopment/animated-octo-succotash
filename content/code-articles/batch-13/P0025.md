# P0025: What an over-retarded bank 2 exhaust cam result means

P0025 concerns the bank 2 exhaust cam staying too far retarded relative to the variable cam timing strategy. Ford lists it alongside, but separately from, intake timing, actuator-circuit and crank/cam correlation faults. Keep that separation when choosing which data to investigate.

## Distinguish commanded timing from base timing

A response monitor needs an active timing command. The documented checks require cam control to be enabled and requested to advance or retard. They also depend on running conditions that allow oil pressure to develop. A base-timing observation made with the control disabled does not by itself explain failure to follow a commanded position.

The source gives a separate alignment criterion for crank/cam correlation. That criterion is not presented as the P0025 decision rule. Therefore, P0025 alone cannot establish how many teeth, if any, a timing drive has moved.

## Confirm the correct test result

Ford maps bank 2 retarded-position error to Mode $06 monitor $36, test $81. Because the mapping groups intake and exhaust retarded results, retain the full DTC and the engine's cam-specific data labels rather than identifying the component from the Mode $06 label alone.

The listed target-error window is longer than a brief actuator response check. A useful verification record includes commanded and measured exhaust timing, enabling conditions and completion status over the applicable window. The summary supplies monitor logic, not a universal procedure for replacing a cam phaser, solenoid or chain.

## Source and applicability

This explanation covers the cited Ford monitor variants, not every vehicle displaying this code. Match the engine, sensor architecture and calibration before applying numerical limits.

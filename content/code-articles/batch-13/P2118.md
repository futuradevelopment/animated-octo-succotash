# P2118: Throttle motor current performance is different from plate position error

Ford lists P2118 as throttle actuator A control motor current range/performance, paired with P2100_1D. The monitored category is motor-current behavior, which is distinct from the plate being reported stuck open or closed.

## Current and position answer different questions

The same table assigns separate codes to stuck positions, throttle-body range/performance and a cross-wired motor circuit. A plate that moves during one observation can still have abnormal current behavior; conversely, an incorrect position does not by itself prove that the current monitor failed.

Preserve the complete code format, the current-related diagnostic information available through the correct tool and any companion position or control codes. The summary does not provide a universal ampere threshold for P2118, so a guessed current limit should not be used as a replacement criterion.

## Confirm actuator A on the installed system

Ford also describes a second electronic throttle body with a separate motor-current code. A result from actuator B is not verification of actuator A. The source does not assign a universal physical location to those letters.

The listed actuator check is continuous and has a duration below five seconds. Verification should show that the relevant current-performance monitor completes without recurrence under the proper conditions. Use the vehicle's service procedure for any electrical or actuator testing; the summary does not identify whether the motor, drive circuit or mechanical loading caused the result and does not prescribe automatic throttle-body replacement.

## Source and applicability

This explanation covers the cited Ford monitor variants, not every vehicle displaying this code. Match the engine, sensor architecture and calibration before applying numerical limits.

# P0134: No oxygen-sensor activity does not identify one universal electrical fault

Ford's UEGO summary identifies P2237, the bank 1 sensor 1 positive-current-control open-circuit result, as a replacement for P0134 in the documented Bosch architecture. This is an important scope limit: the newer monitor explains one specific no-movement mechanism, not every possible vehicle that displays the older P0134 code.

## Understand what the newer monitor watches

The cited strategy looks for lambda remaining close to stoichiometric with insufficient movement while the controller applies its diagnostic excitation. Its prerequisites include healthy heaters and the absence of specified fuel, misfire and circuit faults. A sensor signal is therefore interpreted within a controlled fueling context, rather than judged from one idle snapshot.

The source also distinguishes closed-loop operation from open-loop operation requested because of a UEGO fault. Different stages use different timing and movement criteria. That makes the operating mode part of the evidence.

## Confirm the code translation

Before applying those criteria, retrieve the complete manufacturer code and confirm that the installed sensor uses the described Bosch ASIC arrangement. A generic P0134 description alone does not prove that this replacement diagnostic or its thresholds are implemented.

The useful next distinction is between an established lack-of-movement test result and an observation made while prerequisites were not satisfied. The document does not justify replacing the oxygen sensor solely because a scan-tool value appears fixed, nor does it provide connector-level repair instructions for all P0134 applications.

## Source and applicability

This explanation covers the cited Ford monitor variants, not every vehicle displaying this code. Match the engine, sensor architecture and calibration before applying numerical limits.

# P0022: Bank 2 intake timing and the limits of a bank comparison

P0022 is Ford's bank 2 intake cam timing over-retarded result. The monitor evaluates the variable cam timing system's response to a requested phase. A generic description such as “cam sensor problem” loses the distinction between position feedback, the command and actual cam movement.

## Use bank 2 evidence

The source lists bank 2 intake advance, retard and actuator-circuit codes separately. For the retarded result, the relevant question is whether bank 2 follows its own target under enabled control. Another bank can provide context, but different commands or disabled control make a simple side-by-side position comparison misleading.

Ford's CAN Mode $06 table assigns bank 2 retarded-position error to monitor $36, test $81. This helps avoid reading bank 1's result while investigating P0022. The summary also describes a bank-to-bank variance check, but that does not turn every bank 2 target error into a fault on the other bank.

## Account for the operating window

Cam timing control requires an advance or retard request and sufficient engine operation for oil-pressure availability. Cranking, certain learning routines and specified sensor failures can inhibit control. Record those states with commanded and actual phase before judging response.

Functional checks take seconds; target-error monitoring is listed at 300–900 seconds. Verification should establish that the appropriate monitor has completed under valid conditions. An immediate lack of a returning code after clearing memory does not demonstrate a successful response across that longer window.

## Source and applicability

This explanation covers the cited Ford monitor variants, not every vehicle displaying this code. Match the engine, sensor architecture and calibration before applying numerical limits.

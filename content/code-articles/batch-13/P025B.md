# P025B: The fuel pump module is reporting invalid control data

P025B means the documented Ford fuel pump A system has reported invalid control data. The module communicates that status through its fuel-pump-monitor feedback signal, so the fault should be interpreted as a control-data result rather than immediately as low fuel pressure.

## The feedback duty cycle identifies a status

Ford specifies feedback of 20 percent, with a four-percentage-point tolerance, for this result. Its status table explains that the module is receiving an invalid duty-cycle command from the powertrain controller. The 20-percent value is therefore a diagnostic message, not a request to operate the pump at one-fifth capacity.

The source separately identifies command-circuit faults, secondary-circuit concerns, internal module errors and complete loss of feedback. Those distinctions matter because they lead to different evidence questions.

## Compare the incoming command with the returned status

Preserve the command state and feedback together. Ford's command table shows that valid-off requests and invalid requests can both stop the pump while producing different feedback. A stopped pump alone cannot distinguish them.

The monitor operates within an 11–16-volt battery window and has a listed two-to-five-second duration. Verification should show that valid commands produce the expected status and that the invalid-data result does not recur. The summary does not determine which controller, wire or connection caused an invalid command, so a module or pump replacement requires further vehicle-specific diagnosis.

## Source and applicability

This explanation covers the cited Ford monitor variants, not every vehicle displaying this code. Match the engine, sensor architecture and calibration before applying numerical limits.

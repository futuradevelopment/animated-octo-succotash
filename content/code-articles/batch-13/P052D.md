# P052D: Cold-start bank 2 retard error can disappear before inspection

P052D identifies bank 2 cam timing that is too far retarded during Ford's cold-start emission-reduction strategy. Because the monitor is tied to early start-up control, an apparently normal cam angle later in the drive does not reproduce the original evaluation.

## The requested phase is the reference

The check requires active cam timing control with an advance or retard command. Ford lists a five-second duration and a maximum 60-second interval since cold-start cam-phase monitoring began. Retain the requested and actual bank 2 phase within that period, rather than treating any retarded position as abnormal in isolation.

The document gives an 11-degree over-retard target-error criterion. It also describes a separate minimal-response condition under a ten-degree phasing command. A controller can therefore have evidence about error magnitude or inadequate movement; neither directly names the failed mechanical component.

## Verify the same operating opportunity

A normal bank 1 response is not a bank 2 test, and a warm restart may not recreate the relevant cold-start strategy. Use the actual engine's diagnostic procedure to establish when the monitor is enabled and which data represents bank 2.

The summary supplies no universal sensor location, oil-control test or timing-chain replacement rule. A useful verification record shows the matching command and response during an eligible cold start with the diagnostic check completed. An absent code immediately after clearing memory is insufficient when the required early window has not occurred.

## Source and applicability

This explanation covers the cited Ford monitor variants, not every vehicle displaying this code. Match the engine, sensor architecture and calibration before applying numerical limits.

# P0061: When bank 2 sensor 3 heater current is the relevant evidence

P0061 belongs to Ford's bank 2 sensor 3 heater-resistance group. The sensor number is important: a generic scanner description that merely says “rear oxygen sensor” can hide which monitored heater channel the code addresses.

## Verify the installed arrangement

The cited summary groups sensor 2 and sensor 3 heater checks but gives them different inferred-temperature limits during current monitoring. It does not provide a universal exhaust layout or connector location. Confirm the engine's sensor numbering in its service information before connecting a test result to a component.

The current monitor runs once per driving cycle and requires an eligible heater-on period and supply-voltage state. In contrast, the heater voltage check is continuous. A recurring voltage fault and a completed current test are different kinds of evidence even when they involve the same assembly.

## Apply the correct sensor-family limits

Ford lists current boundaries for multiple heater constructions rather than one common resistance specification. The document also describes sensor impedance as a separate warm-element test. Neither set of figures should be transferred indiscriminately to a cold sensor 3 resistance measurement.

For verification, retain the complete DTC, the identified sensor technology and the current monitor's completion status under its required conditions. If the tool only exposes a bank 2 sensor 2 Mode $06 result, that is not automatically evidence about sensor 3. This summary supports monitor interpretation; it does not resolve the wiring or replacement decision for an individual vehicle.

## Source and applicability

This explanation covers the cited Ford monitor variants, not every vehicle displaying this code. Match the engine, sensor architecture and calibration before applying numerical limits.

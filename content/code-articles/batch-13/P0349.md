# P0349: Bank 2 intake cam intermittency can be a misplaced event

P0349 concerns intermittent bank 2 intake cam-position circuit behavior. Ford's cited description emphasizes a cam signal appearing at an unexpected location in the engine-event sequence. A signal can therefore be present and still fail this particular check.

## Preserve phase relationships, not only voltage activity

The monitor compares engine-position and cam events using a cylinder-count-dependent relationship. Observing a pulse on the cam channel does not prove that the pulse belongs at that point in the sequence. The timing relationship is part of the diagnostic evidence.

Ford lists a 200 rpm entry condition and continuous monitoring with a duration below five seconds. The document does not provide a single expected waveform for every engine, so the matching service reference is needed before judging an event as misplaced.

## Use the code's specific category

P0345 is listed separately for the bank 2 intake cam circuit, while variable cam timing response codes appear in another monitor family. P0349 alone does not establish an actuator response problem or quantify mechanical timing displacement.

Record the full code, synchronization context and any companion crank/cam faults. A later stable cam-angle value may simply miss the earlier interruption. Verification should demonstrate repeatable event placement while the correct monitor operates. The source identifies the behavior under evaluation but does not determine whether a sensor, circuit connection, target feature or other vehicle-specific issue is responsible.

## Source and applicability

This explanation covers the cited Ford monitor variants, not every vehicle displaying this code. Match the engine, sensor architecture and calibration before applying numerical limits.

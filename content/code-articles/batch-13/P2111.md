# P2111: A stuck-open throttle result is a command-response diagnosis

Ford identifies P2111 as throttle actuator A control system stuck open. The diagnostic category concerns the relationship between desired and actual throttle position. It is separate from the motor-current, cross-wiring and sensor-circuit results listed in the same summary.

## Preserve the requested and observed positions

A throttle plate found open after a fault is not automatically a direct record of what caused the fault. Ford's dependability section describes cases in which control is disabled or a default position is commanded. The fallback state must therefore be distinguished from the original command-response failure.

The document contains different monitor descriptions, including a fast stuck-position check and a later actuator table with a broader duration. Match the actual calibration before using one timing figure as universal.

## The printed angle rule needs careful interpretation

The early table presents signed desired-versus-actual angle comparisons for stuck-open and stuck-closed results without defining the subtraction convention. This article does not convert those statements into an assumed universal positive or negative error threshold.

Use the exact diagnostic procedure to interpret position error and confirm valid sensor feedback. The code does not prove whether the cause is mechanical restriction, electrical control or another implementation-specific issue. Verification should demonstrate the correct commanded response and a completed actuator monitor. The source supplies no blanket throttle-body cleaning or replacement instruction, and a temporary default position should not be used alone to make that decision.

## Source and applicability

This explanation covers the cited Ford monitor variants, not every vehicle displaying this code. Match the engine, sensor architecture and calibration before applying numerical limits.

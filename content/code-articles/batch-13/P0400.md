# P0400: EGR flow is inferred from a controlled MAP response

Ford's cited P0400 strategy evaluates exhaust-gas recirculation through a manifold-pressure differential during controlled running conditions. It is a functional flow check, not simply an electrical continuity test of the EGR valve.

## Stable conditions make the pressure comparison meaningful

The monitor requires a relatively narrow running window: the source lists 1,400–2,600 rpm and 35–70 mph, with limits on changes in speed, manifold pressure, load and throttle angle. These conditions reduce unrelated pressure changes that could obscure the EGR response.

Ford lists 200 seconds and 600 data samples for the evaluation. A brief actuator command during an unstable transient therefore is not the same evidence as the completed monitor. The relevant question is whether the expected differential develops under the documented conditions.

## The diagnostic result is normalized

The malfunction table gives a MAP-differential criterion below 1.0, while Mode $06 identifies the recorded quantity as a normalized, unitless differential with a 0–2 range. Do not read that number as one kPa, one volt or one inch of mercury.

For supported applications, monitor $31, test $82 exposes the normalized result. Record its limit and completion state with the operating data. The summary explains a deficient monitored response, but does not establish whether the cause is an EGR passage, valve, sensor or another engine-specific issue. A repair decision needs the matching diagnostic procedure and supporting evidence.

## Source and applicability

This explanation covers the cited Ford monitor variants, not every vehicle displaying this code. Match the engine, sensor architecture and calibration before applying numerical limits.

# P0059: Reading bank 2 front heater current without borrowing bank 1 limits

P0059 identifies the bank 2 front oxygen sensor heater-resistance result in Ford's OBD summary. The practical evidence is a heater-current evaluation performed under defined thermal and electrical conditions. A code title alone does not identify the installed sensor supplier or the correct current limit.

## Match the current test to its architecture

Ford publishes separate conventional HO2S and UEGO sections. The UEGO table further distinguishes an intrusive current test from other current evaluation, with supplier-dependent limits. Two front sensors can only be meaningfully compared after confirming that their technology, test mode and operating state match.

The current monitor generally executes once per driving cycle. Heater voltage and temperature-control monitoring run on different schedules. This matters when an electrical repair is followed by a short idle: the desired current test may not have rerun even though live voltage data looks plausible.

## Find the bank 2 result

The summary maps bank 2 sensor 1 heater current to Mode $06 monitor $45, test $81. Bank 1 uses a different monitor ID. Capture the actual result, limit and completion status instead of relying on an undifferentiated “oxygen heater ready” display.

The source also requires successful prerequisite checks and an eligible battery-voltage and sensor-temperature state. A heater circuit fault can prevent meaningful current evaluation. P0059 therefore supports investigation of the bank 2 heater channel, while the final choice between wiring, control and sensor repair requires vehicle-specific evidence.

## Source and applicability

This explanation covers the cited Ford monitor variants, not every vehicle displaying this code. Match the engine, sensor architecture and calibration before applying numerical limits.

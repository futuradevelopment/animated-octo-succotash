# P0015: Interpreting a bank 1 exhaust cam that stays retarded

Ford places P0015 in the variable cam timing response monitor for the bank 1 exhaust cam. The controller has asked for a particular cam position but the measured behavior remains on the retarded side. That distinction matters because a powered actuator circuit can still fail a functional position test.

## Preserve the command and response together

The monitor runs with cam control enabled and an advance or retard command active. Ford gives a five-to-ten-second duration for circuit and functional checks, while target-error evaluation can extend to 300–900 seconds. A single stationary reading does not describe that complete evaluation.

Useful evidence is the requested exhaust phase, measured phase and the period over which the difference persists. Also retain coolant temperature, start elapsed time and relevant sensor faults: the document lists several conditions that suppress variable cam timing control. These are reasons a test may be unavailable, rather than proof that the exhaust cam hardware has failed.

## Read the right bank and failure category

Bank 1 retarded-position error is exposed in the summary's CAN Mode $06 mapping as monitor $35, test $81, shared with the intake retarded code P0012. The code and engine-specific data labels are therefore needed to identify the actual cam involved.

Do not substitute the separate crank/cam correlation threshold for P0015's target-error strategy. This document supports interpretation of controller evidence; it does not identify a component location or establish which repair will correct the discrepancy.

## Source and applicability

This explanation covers the cited Ford monitor variants, not every vehicle displaying this code. Match the engine, sensor architecture and calibration before applying numerical limits.

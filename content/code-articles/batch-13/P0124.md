# P0124: Short throttle sensor interruptions can use different detection rules

Ford lists P0124 as intermittent throttle-position sensor A behavior. Its OBD summary includes both conventional paired-sensor monitoring and a SENT digital implementation. The same base code therefore does not justify applying one electrical test to every throttle body.

## Identify the signal format

For the SENT version, Ford specifies a fault present for more than 0.4 seconds. A separate device-fault or communication-loss result requires a longer persistence period. That difference explains why a short disruption may produce P0124 without the longer-duration code also being present.

The preceding analog table distinguishes sensor A continuity, sensor B continuity and A/B correlation. Its voltage and angular-disagreement figures describe those checks, not a published universal P0124 interruption threshold for every architecture.

## Capture timing as well as position

A throttle percentage that moves smoothly during a quick inspection can coexist with an earlier brief fault. Preserve any available event timing, sensor status and companion communication or correlation codes. These observations help identify the correct test category without assuming the pedal assembly is the failed component.

The summary associates these throttle sensor faults with MIL and wrench indications and describes continuous monitoring. Verification should establish that the matching monitor no longer observes interruptions under the relevant conditions. The document does not provide terminal assignments, physical sensor location or a replacement instruction; those require the actual vehicle's throttle system information.

## Source and applicability

This explanation covers the cited Ford monitor variants, not every vehicle displaying this code. Match the engine, sensor architecture and calibration before applying numerical limits.

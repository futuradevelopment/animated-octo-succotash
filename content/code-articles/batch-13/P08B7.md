# P08B7: Clutch sensor B high input needs channel-specific verification

Ford assigns P08B7 to clutch pedal position sensor B circuit high in its dual-sensor monitor. The result concerns the electrical range of the second channel, not merely whether the two pedal-position readings disagree.

## Keep the B-channel evidence visible

The same table identifies sensor A and B low/high results and a separate A/B correlation code. A healthy first-channel display cannot clear the B-channel concern. Record the individual signals and any correlation result together so that an invalid electrical input is not treated as a trustworthy position measurement.

The listed sensor-monitor duration is below one second with continuous execution. That timing explains why a short circuit excursion can matter even if the pedal reading looks normal during a later inspection.

## Do not substitute switch logic or another sensor's voltage limit

Ford's clutch-switch checks use different state logic and repeated driving events. The page also describes a sensor-plus-switches implementation. Determine the installed arrangement before choosing a test.

No numerical P08B7 voltage boundary is published on the cited page. The appropriate limit and terminal information must come from the vehicle's service procedure. Verification should demonstrate stable, valid B-channel behavior and successful correlation where applicable. The source does not establish a failed sensor assembly or controller from the code alone, and it does not justify bypassing any clutch-related interlock to make a test pass.

## Source and applicability

This explanation covers the cited Ford monitor variants, not every vehicle displaying this code. Match the engine, sensor architecture and calibration before applying numerical limits.

# P04F0: High-load EVAP purge behavior is tested under boost

P04F0 identifies high-load EVAP purge-line A performance in Ford's boosted-engine strategy. The document notes that it replaces P144C. This monitor evaluates check-valve-related pressure behavior during boost, rather than simply repeating the ordinary parked EVAP leak test.

## Boost creates the diagnostic opportunity

The source describes once-per-cycle evaluation during boosted operation, with a five-to-ten-second duration depending on boost level. It requires healthy pressure, temperature, purge and fuel-level inputs. An idle check without the required pressure relationship cannot reproduce this monitor.

Ford provides more than one implementation. Their fuel-level, ambient-temperature and boost conditions differ, and the pressure-rate limits can vary with fuel level. A single numerical threshold should therefore not be published as universal for all P04F0 vehicles.

## Distinguish the check-valve results

The dual-path description separates pressure-rise and vacuum-rate behavior for different check-valve paths. The Mode $06 listing includes outcomes for each path and for a combined pass. Retain the result identity rather than treating any EVAP pressure value as the failed test.

The source warns that default zero values can appear for uncompleted phases. Confirm that the boosted-operation test actually ran before calling such a value successful verification. P04F0 identifies an abnormal monitored purge-path response, but the summary does not locate a specific valve or establish which part requires replacement on an individual engine.

## Source and applicability

This explanation covers the cited Ford monitor variants, not every vehicle displaying this code. Match the engine, sensor architecture and calibration before applying numerical limits.

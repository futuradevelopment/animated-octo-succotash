# P0339: Crank signal timing can be wrong even when pulses are present

P0339 is Ford's intermittent crankshaft-position sensor A result. The published monitor looks beyond whether a crank signal exists: it checks the sequence and timing of the teeth represented by that signal.

## Pulse presence is not enough

Ford lists an incorrect tooth count after recognition of the missing tooth, implausible tooth timing and a missing-tooth feature in the wrong expected position as malfunction evidence. A waveform can therefore contain pulses yet still fail the pattern checks.

The same page gives a separate P0335 criterion for a missing crank signal while camshaft information indicates engine rotation. That distinction prevents a simple “signal present” observation from being used to dismiss P0339.

## Capture the pattern under an enabled condition

The cited check is continuous with an engine-speed entry condition of 500 rpm and a monitoring duration below five seconds. Preserve the relationship between ordinary teeth, the reference gap and the cam signal when investigating an intermittent event. The source does not specify a universal sensor voltage or tooth-wheel geometry for every engine.

The printed timing statement combines time terminology with speed values, so this article does not convert it into a guessed oscilloscope limit. Use the matching engine's reference waveform and diagnostic procedure for numerical interpretation. Verification should establish a consistent, correctly phased pattern while the monitor runs; the code alone cannot identify whether the cause is the sensor, circuit, target or another vehicle-specific issue.

## Source and applicability

This explanation covers the cited Ford monitor variants, not every vehicle displaying this code. Match the engine, sensor architecture and calibration before applying numerical limits.

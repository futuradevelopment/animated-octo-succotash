# P2005: A bank 2 stuck-open runner result needs its own command and feedback

P2005 is Ford's bank 2 intake manifold runner control stuck-open result in the documented vacuum-actuated V-engine system. The bank identity matters because a working bank 1 runner does not demonstrate that bank 2 follows its own command.

## Compare the requested state with measured response

Ford's functional criterion is that the plates do not match the commanded position or exceed their operational range. The stuck-open code identifies one category within that evaluation. Preserve bank 2 command and feedback rather than judging a single open-position reading without context.

The monitor operates after coolant temperature exceeds 40°F and uses four functional events. That schedule differs from the five-second electrical circuit check. A brief successful actuation or a circuit pass does not necessarily complete the stuck-position evaluation.

## Separate feedback validity from mechanism response

The same source lists bank 2 position-sensor low/high, over-travel and control-circuit codes. Those results help identify whether the evidence concerns sensing, electrical control or functional position. P2005 alone does not determine which physical component caused the mismatch.

Apply this explanation only after confirming the installed IMRC architecture; the cited table does not establish universal model or engine coverage. Verification should include valid feedback and matching commanded/actual behavior across eligible events. The source provides no blanket manifold, actuator or vacuum-line replacement instruction, and it does not identify the physical bank location for every engine.

## Source and applicability

This explanation covers the cited Ford monitor variants, not every vehicle displaying this code. Match the engine, sensor architecture and calibration before applying numerical limits.

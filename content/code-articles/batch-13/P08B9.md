# P08B9: Clutch pedal correlation can involve sensors or a sensor-and-switch arrangement

Ford uses P08B9 for clutch pedal A/B correlation in one arrangement and for in-range rationality or dual-switch hardware faults in another. The same base code can therefore refer to different input relationships, making the installed pedal architecture the first important distinction.

## Compare valid inputs in the correct arrangement

In a two-sensor system, preserve the individual A and B signals and any electrical low/high codes before interpreting their correlation. In the sensor-with-switches version, the expected agreement involves a different set of states. A generic pedal percentage may not expose all the inputs used by that check.

The source lists sub-second detection for sensor faults, while switch evaluation requires repeated driving events. One stationary pedal sweep cannot be assumed to complete every P08B9-related monitor.

## The printed cycle wording needs confirmation

The switch section refers to more than 40 clutch applications at different speeds, while the sensor-with-switches row says 40 drive cycles. This article does not silently equate those different units. The exact calibration's procedure is needed to determine the applicable completion requirement.

Ford does not publish a universal numerical correlation threshold on this page. Verification should demonstrate the expected relationship for the actual hardware and a completed monitor, rather than only an erased code. The summary does not identify the faulty input or authorize bypassing a switch or clutch safety function to resolve the disagreement.

## Source and applicability

This explanation covers the cited Ford monitor variants, not every vehicle displaying this code. Match the engine, sensor architecture and calibration before applying numerical limits.

# P0060: Bank 2 rear oxygen heater current versus sensor impedance

Ford associates P0060 with bank 2 sensor 2 heater resistance. The summary's Mode $06 mapping makes the measured quantity clearer: monitor $46, test $81 reports HO2S22 heater current in amps. That is different from the neighboring heater-impedance result.

## Use the current monitor's prerequisites

The current test follows the heater voltage check and is inhibited by heater-voltage faults. Ford lists at least 30 seconds of heater-on time, an inferred sensor-temperature window and battery voltage from 11 to 16 volts. Those conditions explain why a measurement during an early cold start may not represent the evaluated operating state.

Sensor construction matters too. The table provides different lower-current limits for thimble, planar and fast-light-off designs. It would be incorrect to publish one of those values as a specification for every vehicle that reports P0060.

## Do not substitute the impedance test

The same source contains a separate temperature-dependent impedance strategy. Its Mode $06 test ID is $82, and bank 2's associated range/performance code is P00D4. Its warm-up, fueling and voltage conditions differ from the heater-current check.

A useful verification record therefore identifies which test failed, the sensor family, the actual limit and whether the monitor completed again. That distinction prevents a rear-sensor signal issue or an impedance result from being mistaken for direct proof of a failed heater element. Physical circuit diagnosis still needs the correct vehicle wiring information.

## Source and applicability

This explanation covers the cited Ford monitor variants, not every vehicle displaying this code. Match the engine, sensor architecture and calibration before applying numerical limits.

# P0704: Clutch switch comparison needs repeated driving events

Ford uses P0704 for continuous clutch-switch comparison, with expanded forms that identify switch A or switch B. The base code alone can therefore hide which switch comparison the controller reported.

## A comparison result is not one fixed switch state

The source separately lists stuck-high and stuck-low clutch-switch results. P0704's comparison category should not be assumed to mean either of those states without the full diagnostic information. Preserve the expanded code and the switch states as the pedal moves through the relevant positions.

The monitor is continuous, but Ford lists more than 40 clutch application cycles while driving at different speeds as its evaluation requirement. “Continuous” therefore does not mean that one stationary pedal operation is a complete verification opportunity.

## Distinguish switches from position sensors

The same page describes analog clutch-position sensor circuit and correlation checks with sub-second detection. Those sensor checks have a different schedule and cannot be substituted for the repeated switch-comparison evaluation.

The cited switch result is non-MIL, so the absence of a check-engine light is not proof that the concern is absent. Use the actual clutch-control architecture and vehicle-specific procedure to identify the inputs and test conditions. The summary does not justify bypassing a start interlock or replacing a switch without evidence. Verification should demonstrate consistent comparison behavior across the applicable monitored events, not merely successful starting once.

## Source and applicability

This explanation covers the cited Ford monitor variants, not every vehicle displaying this code. Match the engine, sensor architecture and calibration before applying numerical limits.

# P002C: Resolve the exhaust profile-driver command state before testing

P002C is an exhaust camshaft profile-actuator A circuit-high code for bank 1. The cited GM strategy calls the output exhaust profile actuator 1 and describes a short toward controller power. This electrical classification should not be confused with exhaust timing being too advanced.

## A documented on/off contradiction

The strategy says feedback is evaluated with the output powered off, and the malfunction description repeats that off-state condition. The enable column instead says the output is commanded on. Because the two statements disagree, the document cannot by itself establish the correct commanded state for a workshop reproduction test.

Other details are consistent: the electrical criterion corresponds to signal-to-power impedance below 0.5 Ω, supply must exceed 11 V, and ignition is in crank or run. The monitor uses four failing samples within five and one-trip reporting. These are calibration-specific monitor details, not connector instructions.

## Preserve the evidence that resolves the ambiguity

Capture the actual command, supply and feedback associated with the stored event. Then confirm the intended test state in the matching service procedure. Applying the summary's contradictory command note without that check risks comparing feedback under the wrong operating condition.

The supported finding remains a power-directed circuit problem, distinct from an open path or mechanical profile performance. The table cannot identify a particular actuator, wire or controller as the failed part, and it does not authorize a replacement merely from the code display.

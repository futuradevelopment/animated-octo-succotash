# P2482: EGT sensor 5 circuit high and architecture-specific thresholds

The P2482 row monitors electrical high-range behavior at exhaust gas temperature sensor 5. It supports analog sensing and digital thermocouples, so the displayed code alone does not identify the electrical architecture or a single test value that applies to both.

## High resistance differs from high reported temperature

The analog branch fails when raw resistance exceeds 100,000,000 Ω. That is the controller's extreme high-resistance comparison, not the expected resistance of a healthy hot probe. The digital branch instead fails when reported temperature exceeds 1,289.85°C. Treat these as alternative monitor inputs, not two measurements required on every vehicle.

The diagnostic counts 19 failures in 25 samples at 100 ms per function task. Its reporting classification is Type A, one trip. This is specifically the high-range row's behavior; do not import a two-trip assumption from a nearby temperature code.

## Establish a valid channel and operating state

A qualifying test requires valid supply voltage, active ignition run/crank, no cranking, no diagnostic reset and no lost-communication error. The sensor initialization delay must also have finished. A temperature value observed before initialization completes does not by itself demonstrate a completed P2482 evaluation.

Record the selected sensor channel, architecture and whether the fault is current. For analog sensing, an extreme resistance report guides investigation of that circuit's continuity and connections under the vehicle procedure. For digital sensing, separate the module's communication status from the temperature information it receives from the probe. Neither branch proves that exhaust gases actually reached the threshold. Identify the physical sensor 5 from service information before replacing a probe or disturbing hot exhaust hardware.

# P2483: EGT sensor 5 response plausibility after an engine-off soak

P2483 is a response-plausibility check for bank 1 exhaust gas temperature sensor 5. The documented strategy compares a maximum temperature over a calibrated observation period with a temperature captured after an engine-off soak. It can identify a sensor outside the exhaust pipe or information that remains stuck, but it cannot distinguish those causes by itself.

## The baseline is part of the test

Failure occurs when the resulting temperature difference is below the EGT sensor 5 temperature map. The map depends on the captured temperature; the source does not publish one universal numerical rise threshold. Comparing an arbitrary pair of live readings would therefore not reproduce this monitor.

The engine-off prerequisite prints a value above 10,800 without a unit in the table. Treat the required soak as calibration-specific rather than turning that number into a service waiting time. The engine must subsequently be running, the not-running timer must be valid, and the sensor initialization delay must have elapsed.

## Eliminate invalid prerequisites first

The row excludes key-on, quick-change, high-range, low-range and communication faults for this sensor. It also requires the diagnosis not to be aborted or already reported. Those gates explain why a flat live trace may coexist with no completed response test.

Preserve the cold baseline, subsequent warm-up trace and monitor status. Compare the trace with other relevant exhaust-temperature information and verify the sensor's actual installation using vehicle documentation. The table lists no debounce and Type B, two-trip behavior; that does not mean an immediate result on every restart. Exact reproduction requires the missing calibration map, observation interval and confirmed soak units.

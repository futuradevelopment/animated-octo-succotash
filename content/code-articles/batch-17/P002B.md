# P002B: A low exhaust profile-control circuit is an on-state electrical finding

P002B is the low-circuit member of the bank 1 exhaust profile-actuator A family. In the cited GM monitor, exhaust profile actuator 1 is commanded on and its driver feedback falls outside the expected electrical range. The resulting classification is a connection toward ground.

## Follow the driver command

The table describes a controller-specific voltage assessment corresponding to less than 0.5 Ω between the signal and controller ground. This identifies the modeled failure condition; it is not a universal specification for probing an unknown connector.

The on command is an explicit prerequisite. So are diagnostic enablement, system supply above 11 V and crank/run ignition. The monitor confirms four failing observations within five samples, and the row lists one-trip reporting. These details distinguish a repeated eligible driver problem from a single low reading taken in an unrelated operating state.

## Keep electrical and mechanical questions separate

A profile actuator that does not visibly move may be uncommanded, electrically impaired or experiencing another condition. P002B specifically contributes the powered-on low-circuit evidence. A useful diagnostic capture therefore retains command, driver feedback and supply at the same time.

The next isolation work should establish where the ground-directed electrical path occurs using the correct circuit information. The monitor summary cannot choose between wiring, actuator and output-stage causes. It also does not justify replacing an exhaust timing component simply because the generic code name contains the word camshaft.

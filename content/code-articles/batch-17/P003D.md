# P003D: The intake profile pin must return before the engine cycle ends

P003D identifies the intake camshaft profile actuator A as stuck on in the generic bank 1 reference. The cited GM monitor follows intake profile actuator 1 through an extension event and checks that its pin returns to the retracted state before the engine cycle ends.

## The missing return is the important observation

The controller tracks extending, extended and retracted Hall-feedback states. If extension has been recognized but the feedback never reaches the retracted boundary before the end of the cycle, the strategy reports a pin remaining out. An extended reading during the intended active portion of the sequence is therefore not sufficient evidence of this fault.

The row requires a running engine, system voltage above 11 V and diagnostic enablement. Its confirmation column lists one failure report within five samples, followed by one-trip reporting. That differs from treating every snapshot of extension as a persistent mechanical jam.

## Keep the cycle timing with the feedback

A meaningful record shows the extension event, the expected return window and the subsequent feedback state. Without cycle timing, a normal commanded extension can resemble a pin that failed to return.

The listed feedback boundaries lack a clear physical unit in this summary, so they are not presented here as external measurement specifications. The monitor also cannot determine whether an incorrect state comes from pin motion or its feedback path. Distinguishing those possibilities requires the applicable actuator and sensor procedure, rather than forcing the mechanism or ordering a part from this code alone.

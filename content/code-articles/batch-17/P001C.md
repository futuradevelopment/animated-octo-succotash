# P001C: A high intake-actuator circuit code has a conflicting command-state note

P001C identifies a high control-circuit condition for the intake camshaft profile actuator A on bank 1. GM's cited strategy classifies a connection toward controller power using voltage feedback from intake profile actuator 1. It is an electrical result, not a measurement of excessive camshaft advance.

## What the source supports and what conflicts

The strategy and failure-description columns both say the short-to-power assessment occurs while the output is powered off. However, the same row's enable column says the output driver is commanded on. Those statements cannot define one unambiguous reproduction procedure, so this article does not choose a command state by guesswork.

The electrical specification is below 0.5 Ω between signal and controller power. Supply above 11 V, an enabled diagnostic and crank/run ignition are also listed. The confirmation count is four failures in five samples, with one-trip reporting.

## Resolve the operating state before testing

Preserve the actual command and feedback observed at the event, then check the vehicle's applicable diagnostic procedure for the intended state. A trace without that command context cannot settle the conflict in the summary table.

The source still separates this power-directed circuit classification from an open circuit or a cam-position performance fault. It does not identify the defective part or provide connector-level resistance instructions. Repair decisions need the matching controller and actuator information, particularly because applying the contradictory on/off note literally could test the wrong condition.

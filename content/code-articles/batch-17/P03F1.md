# P03F1: Exhaust profile C is an electrical channel, not a bank-wide diagnosis

P03F1 identifies an open control circuit for exhaust profile actuator C on bank 1. GM's cited monitor names that channel exhaust profile actuator 3. The diagnostic selects one output and tests its electrical response, so a general camshaft symptom does not establish the same finding.

## An on-state feedback failure defines the open result

The controller compares driver voltage with its own acceptable range while the output is powered on. The open-circuit specification corresponds to more than 200 kΩ between signal and controller ground. This describes the controller's classification; the document does not publish a connector pinout or a direct resistance-measurement procedure.

Supply above 11 V, crank/run ignition and diagnostic enablement create the valid test window. Four failures within five samples confirm the condition, followed by the listed one-trip reporting. A lone inactive-state reading is not equivalent to repeated abnormal feedback under command.

## Verify the correct output before isolating the circuit

Match the recorded command and feedback to exhaust profile actuator 3. A healthy result from another exhaust output does not prove this path is connected. Likewise, apparent absence of profile movement does not reveal whether this particular electrical monitor had an eligible on command.

Once the commanded electrical discrepancy is established, wiring, load and controller isolation require the exact service information. The table does not identify which component caused the open classification or support replacing mechanical timing parts solely from P03F1.

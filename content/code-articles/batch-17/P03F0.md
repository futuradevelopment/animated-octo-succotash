# P03F0: The intake profile-C pin must complete its return sequence

P03F0 is the stuck-on entry for bank 1 intake profile actuator C. The GM implementation names intake profile actuator 3 and follows its Hall-feedback sequence. The relevant failure is a pin that has extended but has not returned to the retracted region by the end of the engine cycle.

## A return deadline distinguishes normal extension from failure

The system recognizes extending, extended and retracted feedback states. Either of the first two can establish that an extension event occurred. The monitor then expects the retracted state within the cycle; observing extension at an appropriate earlier moment is not itself evidence of a stuck pin.

Diagnostic enablement, a running engine and supply above 11 V are required. The confirmation column lists one failure report within five samples, with one-trip reporting. These details describe the monitor's decision window rather than the duration for which an operator should hold an actuator active.

## Record the complete state transition

The useful evidence includes the extension event, the return opportunity and the final reported state for actuator 3. Data from another profile output cannot verify this channel, even when the related controller logic is similar.

The row supplies numerical feedback boundaries without explicit physical units, so no external voltage or displacement specification is inferred here. It also cannot distinguish an actual pin-return problem from incorrect feedback by itself. The matching service procedure is necessary to resolve those possibilities without mechanically forcing the cam-profile hardware.

# P01D7: Cylinder 7 timing performance can be learned from rail-pressure changes

P01D7 is a cylinder 7 injection-timing performance code associated with the over-retarded direction. In this GM diesel monitor, the controller uses small-quantity learning to evaluate positive drift in injection quantity or timing. It does not determine the fault simply by comparing an ordinary idle correction number with a universal limit.

## Two measurements contribute to the assessment

During eligible fuel-cut conditions, the strategy commands a known small injection and examines the resulting fuel-rail pressure drop. Comparison with the expected drop allows an energizing-time correction to be estimated. Separately, the falling edge of the pressure signal helps identify injection start; crankshaft speed converts that event into angular timing.

The monitor therefore has both quantity-related and timing-related evidence. A positive duration correction and a delayed angular event are not interchangeable measurements, even though this diagnostic can respond to the documented drift paths.

## Confirm that the learning operation completed

Several trial quantities are used to characterize the injector's small-quantity behavior. The source describes completion based on convergence or a limit on the number of learning steps. An interrupted operation can resume rather than representing a newly completed result on every drive.

Retain the learning state, correction type and eligible operating conditions before deciding what a stored P01D7 demonstrates. The table's two-trip reporting is separate from the individual trial injections. It provides no instruction to open a high-pressure fuel connection or replace injector 7 without the matching diagnostic procedure.

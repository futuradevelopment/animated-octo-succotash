# P021A: Cylinder 7 injection timing can mean the current pull-in interval

P021A is called cylinder 7 injection timing in the generic reference. The cited GM implementation times the injector's electrical pull-in phase: how long the current takes to reach its initial target. That is distinct from measuring injection start in crankshaft degrees.

## The controller times the current ramp

The hardware interface reports the pull-in interval for injector 7. The row describes a 20 A current target and classifies intervals below 50 microseconds or above 90 microseconds as out of range. These figures describe internal monitoring; they are not instructions to apply that current to an injector manually.

The monitor requires its calibration enable, key-on operation and battery voltage above 11 V. Ten failed samples within twenty establish the fault, with one sample per engine cycle. The table also excludes dropped-pulse information and certain existing electrical or boost-supply faults.

## Preserve a real injection opportunity

A missing request or a dropped pulse should not be treated as an ordinary pull-in measurement. Retain whether injection was requested, whether the hardware reported a valid pulse and which electrical faults were already present. Those observations distinguish an abnormal ramp from a test that never had its stated opportunity.

Some internal enable identifiers use cylinder C while the heading and measured injector are cylinder 7. That mapping is not resolved here. Confirm the applicable channel information before attaching the code to hardware or choosing between an injector and controller investigation.

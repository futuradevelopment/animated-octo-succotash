# P040E: An erratic EGR temperature signal is assessed between consecutive samples

P040E is an intermittent or erratic EGR temperature-circuit code. In the cited GM row, the downstream EGR temperature sensor is evaluated for rapid changes in its resistance signal. A plausible average temperature does not rule out this particular form of signal instability.

## Rate of change is different from an absolute range fault

The controller compares consecutive readings in a 100-millisecond loop. An absolute resistance change above 25 Ω exceeds the documented permitted step. The monitor uses twenty failures within thirty samples and two-trip reporting.

Because this assessment concerns differences between samples, a slow display or smoothed graph can hide the events that triggered it. Conversely, an unusually high but steady reading answers a different diagnostic question. Preserve the unsmoothed sequence and sampling context when available rather than relying only on the final displayed temperature.

## Establish that the same monitoring window existed

Supply must exceed 11 V, ignition must be valid and the monitor enabled. The source excludes engine cranking and diagnostic-system disablement. Those conditions matter when comparing a starting transient with the recorded event.

The generic sensor-A designation and this document's downstream sensor-2 naming must be matched to the actual vehicle before choosing a channel. The monitor establishes excessive signal steps; it does not locate a wiring interruption, identify an internal sensor defect or demonstrate a real thermal shock. Those alternatives require the correct system-specific diagnostic procedure.

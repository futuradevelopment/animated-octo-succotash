# P02D9: Cylinder 7 maximum adaptation is a map-wide finding

P02D9 identifies cylinder 7 injector offset learning at the maximum limit. GM's strategy checks newly learned energizing-time corrections against a calibrated upper boundary. The finding concerns available adaptation authority, rather than a direct measurement that the injector is permanently flowing too much fuel.

## Check which learned entry reached the limit

The learning process uses small injections during eligible fuel cut and estimates their quantity from rail-pressure reduction. A separate nonvolatile status is retained for each pressure level in the learning map. If any entry remains saturated at the upper boundary, the map can continue to support this diagnostic finding.

That storage arrangement explains why a normal-looking correction at one operating point cannot verify all previously learned conditions. The source requires all relevant saturation flags to be false before its stated condition is unset.

## Resolve the source wording without changing the direction

The heading, comparison and stored-status description all concern maximum authority, but a later sentence says minimum authority. This article retains the clearly identified upper-bound logic while flagging that inconsistent wording. It does not fabricate a numerical limit; the table refers to a calibration parameter.

For verification, retain the failed pressure region and whether small-quantity learning actually completed with its management and authority checks enabled. A code erase alone is not evidence of a healthy learned map. The document supplies no universal injector replacement, adaptation reset or high-pressure fuel-system procedure.

# P040D: The EGR temperature high-circuit result is a resistance-range finding

P040D identifies a high EGR temperature-sensor circuit condition. The GM implementation calls the monitored device the downstream EGR temperature sensor, also labeled sensor 2 in the table. Its electrical assessment should not be treated as a direct declaration that exhaust temperature is dangerously high.

## The controller compares sensor resistance with a limit

The documented failure boundary is measured resistance above 885 Ω. The monitor records sixteen failures within twenty-five samples, with a 100-millisecond task interval and two-trip reporting. Those counts concern eligible observations; they do not establish that the sensor remained outside range for an entire drive.

The diagnostic must be enabled, ignition must be in range and supply must exceed 11 V. Cranking and a disabled diagnostic system exclude the stated operating window. An abnormal reading during excluded operation is not a faithful reproduction of this monitor's result.

## Separate sensor identity from the code's generic letter

The generic reference uses sensor A, while this document identifies a downstream sensor 2. The article retains the document's functional location without assigning a connector or physical mounting position on an unspecified engine. Confirm the exact vehicle mapping before selecting a temperature channel to test.

A useful record preserves measured resistance, eligibility and the named sensor channel. The table does not determine whether a confirmed high-resistance result originates in the sensor, connection or measurement path, and it does not support replacing an EGR component solely from the code label.

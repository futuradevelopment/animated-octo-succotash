# P002A: Exhaust profile-actuator continuity is assessed under command

P002A refers to the bank 1 exhaust camshaft profile actuator A control circuit being open. The GM implementation calls the monitored output exhaust profile actuator 1. It examines whether the energized driver returns voltage feedback within the range expected for a connected electrical path.

## An open classification is not a motion test

The source represents the open-circuit boundary as impedance above 200 kΩ between signal and controller ground. The controller reaches that classification through its own voltage measurements. It does not directly measure whether the exhaust cam has moved to a requested angle, and the table does not provide a hand-held resistance-test procedure.

An enabled diagnostic, system voltage above 11 V and crank/run ignition establish the stated test opportunity. Four unsuccessful samples out of five mature the fault. The one-trip indication describes reporting, rather than a requirement for the circuit to be open continuously for an entire journey.

## Compare the correct evidence

Retain the exhaust actuator's on command alongside its feedback and supply condition. A quiet output while no command is issued does not demonstrate the documented open-circuit behavior. Conversely, a feedback failure under a valid command deserves electrical isolation before a mechanical profile-shift conclusion is drawn.

The summary does not determine whether the interruption is in the connected circuit or the controller's driver, and it supplies no model-specific component location. Use the applicable wiring and actuator diagnostic procedure to resolve that question without turning this code into an automatic parts recommendation.

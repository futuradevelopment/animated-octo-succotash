# P005A: An exhaust profile performance code can report movement without a command

P005A has a bank 1 exhaust profile-actuator A performance/stuck-off description in the generic dictionary. The specific GM row instead evaluates unintended firing of exhaust profile actuator 1. That difference makes it important to read the applicable monitor description before assuming the code means the pin simply failed to move.

## What qualifies as unexpected movement

The controller recognizes extending, extended and retracted feedback regions. For this strategy, crossing the extension boundary without a corresponding command is the significant event. A pin moving during a legitimate request does not satisfy that description merely because its feedback is in the same region.

The system must be running with supply above 11 V and the diagnostic enabled. Four incorrect position readings within five cylinder events mature the result, with one-trip reporting. This count concerns eligible observations, not a requirement for continuous abnormal movement throughout a trip.

## Evidence to retain before mechanical conclusions

Align the exhaust actuator command with the feedback sequence. If the capture omits the command, it cannot establish that the movement was unintended. If the capture omits event timing, it may miss the brief transition the controller evaluated.

The numerical state boundaries in this row do not include a clear physical unit, and the generic stuck-off label does not fully describe the cited strategy. Neither limitation should be silently resolved by inventing a voltage or motion test. Vehicle-specific service information is needed to distinguish incorrect feedback from actual uncommanded pin action.

# C052F: Distinguish a driver held in reset from weak bootstrap charge

C052F has an ABS pump supply-circuit/open label in the generic dictionary. The GM tables associate it with two particular internal motor-driver checks: a power-on-reset condition and bootstrap undervoltage. Those branches should remain separate when planning the investigation.

## Two ways the driver can fail to operate

In the reset branch, a reset control held high prevents the ASIC's internal logic from operating, and the driver reports fault and reset status. In the bootstrap branch, the stored charge used to drive the high-side output is insufficient, producing a different status indication. Both can interrupt normal motor control, but their diagnostic evidence is different.

The documented prerequisites include a completed power-switch self-test, active enable feedback, an enabled driver and valid serial data without an interface fault. Battery voltage must exceed 6.8 V. Both rows show a 390-millisecond maturation interval.

## Use the expanded status, not only the code name

Retain whether the module reported reset status or bootstrap-voltage status. A generic open-circuit description does not identify which one occurred, and the table does not justify locating a broken supply wire from that description alone.

A test performed while the driver remains disabled cannot verify the same high-side operating condition. Likewise, communication integrity matters before interpreting the ASIC flags. The source offers no numeric bootstrap threshold or board repair procedure. Investigation of this brake-controller circuitry needs the applicable professional service information.

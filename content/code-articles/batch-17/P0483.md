# P0483: Fan performance uses weighted command-following evidence

P0483 is a fan rationality or performance code. The cited GM strategy applies to its documented engine-driven fan system and evaluates the difference between measured and commanded fan speed while the fan clutch is commanded on. It is not simply an absence-of-speed diagnostic.

## A weighted result needs enough valid observations

The monitor uses an exponentially weighted residual and operating-condition weights. It does not report pass or fail until the accumulated filtered weighting exceeds 0.60. A short observation before enough eligible data has accumulated cannot demonstrate the same result.

The enables exclude relevant temperature, output-driver and fan-speed sensor faults. They also constrain supply, ambient conditions, drive speed and the rate of fan-speed change. An abrupt transient or invalid speed input therefore needs to be distinguished from established poor command following.

## Treat the printed threshold wording carefully

The narrative says the residual should remain between lower and upper limits. The threshold cell prints less than −470 rpm and greater than 500 rpm together, an impossible simultaneous condition. Original-page inspection confirms that wording. This article does not silently replace its conjunction or publish it as an executable test rule.

Useful evidence includes the requested speed, measured speed, eligibility and accumulated weighting. The supported monitor concept can guide interpretation while the exact signed failure condition is verified against the matching calibration. It does not determine that the fan clutch needs replacement from the code alone.

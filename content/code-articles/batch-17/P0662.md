# P0662: Read the reported tuning-valve fault separately from its inconsistent heading

P0662 is generically a high intake manifold tuning-valve control-circuit code for bank 1. In the GM row, the failure criterion is a power-stage report of a short toward battery on H-bridge output one. However, the row's strategy heading calls it an open circuit, creating an interpretation limit that needs to remain visible.

## Use the actual reported status without rewriting the source

The criterion identifies the output-one short-to-battery status as true, with a one-second evaluation and two-trip reporting. The source's open-circuit heading does not justify silently converting that reported status into an open-wire diagnosis.

The listed battery window is above 9 V and below 17.5 V. A relevant power-stage enable state and the stated H-bridge diagnostic status are additional prerequisites. A test performed with the driver disabled is therefore not an equivalent opportunity to reproduce this result.

## Keep the unresolved label with the evidence

Record the expanded actuator fault information, supply and diagnostic state. The exact controller procedure must resolve which electrical classification applies before choosing a circuit test. A valve-position error or lack of movement alone cannot distinguish an open path from a connection toward power.

The supported table evidence does not identify a replacement component or provide a universal probing instruction. Retaining the discrepancy is more useful than hiding it inside a generic high-circuit explanation that implies the source is unambiguous.

# P0650: A failed warning-lamp circuit can store a code without illuminating the lamp

P0650 identifies a malfunction-indicator-lamp control circuit/open fault. The GM example monitors the lamp's low-side driver for an electrical path that does not respond as expected. Because the warning lamp itself is the monitored output, relying only on its visible state can miss the stored diagnostic result.

## An off-state voltage observation classifies the open path

The cited strategy detects low feedback voltage while the driver is off and associates that behavior with an open circuit. Its electrical specification is impedance above 200 kΩ between signal and controller ground. This describes the monitor's classification, not a stand-alone instruction to measure resistance at an unidentified powered connector.

Run/crank voltage must exceed 11 V, and remote vehicle start must be inactive. The table lists one failed sample out of one, with a 50-millisecond sample interval. It explicitly indicates no MIL illumination for this diagnostic.

## Use diagnostic status as well as the visible lamp

A dark lamp does not establish that the controller found no fault, particularly when the lamp-control path is the subject of the check. Preserve the driver state, supply and stored code information before drawing conclusions from appearance alone.

The document also notes that some controllers can set P263A for a related lamp-control ground-short classification. It does not establish that both codes always occur together or prove one common failed part. Proper circuit identification and the matching controller procedure are needed to distinguish the lamp path, connection and output-stage possibilities.

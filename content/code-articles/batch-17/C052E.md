# C052E: Gate-drive undervoltage differs from low vehicle supply

C052E concerns a low ABS pump motor-control circuit condition. The cited GM implementation checks whether each active gate-drive output has sufficient gate-to-source voltage to operate its power transistor correctly. That is a more specific question than whether the vehicle battery is low.

## An active-output assessment

The ASIC monitors its high-side and low-side gate-drive outputs independently. A gate-drive undervoltage condition on either active output sets the fault indication described in this row. The table does not provide the numeric gate threshold, so a generic voltage figure should not be invented for an external test.

The monitor is eligible after the power-switch self-test, with the driver enabled and its enable feedback active. Serial data must be valid and free of the related interface fault. Vehicle supply above 6.8 V is another prerequisite, while 390 milliseconds is the stated maturation period.

## Questions that separate the diagnostic paths

First determine whether the driver was active when the result appeared. An inactive output is not required to behave like an enabled gate. Next establish whether the diagnostic status arrived through a valid serial exchange; communication faults can undermine the evidence used to assess the driver.

A normal supply measurement at a different moment does not verify this active gate-drive condition. Nor does the code alone decide between wiring, load or driver hardware work. The source supports a focused interpretation of the brake-controller result, with further isolation reserved for the matching service procedure.

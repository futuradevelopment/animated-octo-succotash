# P03F3: Do not reproduce a high exhaust profile-C fault from a contradictory state note

P03F3 is a high-circuit code for exhaust profile actuator C on bank 1. GM's documented output is exhaust profile actuator 3. The strategy describes feedback consistent with a connection toward controller power, rather than excessive mechanical actuator travel.

## A source conflict changes the test setup

The narrative places the voltage assessment in the powered-off state, and the malfunction description agrees. The enable column nevertheless states that the driver is commanded on. Those entries do not define a single consistent operating state, so the intended reproduction command must be verified elsewhere in the applicable service information.

The row also specifies signal-to-power impedance below 0.5 Ω, system supply above 11 V, enabled monitoring and crank/run ignition. Four failures in five samples confirm the documented finding. These figures remain monitor specifications, not a connector-level repair procedure.

## Preserve evidence before choosing a direction

Record the command and feedback for the actual exhaust profile-3 channel at the event. A voltage trace without command history cannot decide whether the driver behaved normally for its state. Nor can a measurement from another profile output settle this channel's diagnosis.

The supported electrical classification remains useful for separating P03F3 from open-circuit and ground-directed faults. It does not identify a failed actuator or controller, and the contradictory state note should not be resolved by silently rewriting the manufacturer's table.

# P0683: Ford glow-plug module communication check

Ford's 2002 7.3L diesel summary assigns P0683 to the glow-plug control module communication line. The module returns diagnostic status to the PCM; the fault is set when the PCM cannot determine a valid pass-or-fail message. That is a communication result, rather than a count of defective glow plugs.

## A test that needs a real heating command

The monitor is continuous, but its listed entry conditions include enabled glow plugs and an on-time greater than 8.5 seconds. A brief warm-engine command does not provide the same test opportunity. When checking whether a repair has been evaluated, record the actual commanded interval instead of assuming that every key cycle completes this diagnostic.

The summary separately lists P0670 for control-line driver faults. Seeing both codes changes the investigation: an unavailable command path can undermine an attempted communication check, while a communication fault alone does not establish that the control output is electrically defective.

## What the code can establish

P0683 supports checking the module's diagnostic exchange and its required operating conditions using the correct wiring and service information. It does not say which cylinder failed to heat, and it does not prove that the module itself must be replaced. High-current glow-plug circuits should be tested with the specified equipment and safeguards; this monitor description is not a substitute for the electrical diagnostic procedure.

# P1282: Ford running-engine ICP exceeds the pressure ceiling

P1282 is the excessive injection-control pressure fault in Ford's 2002 7.3L diesel summary. The engine must be running, and measured ICP must exceed 25 MPa for more than 1.5 seconds. This is an actual-pressure ceiling, rather than a comparison against requested pressure.

## Distinguish the decision from adjacent ICP faults

P1209 compares command with feedback, so it can identify poor pressure tracking even when the absolute pressure is below the P1282 ceiling. P1281 instead checks for an electrically high sensor signal. The three codes describe different evidence and should not be treated as interchangeable descriptions of a failed pressure regulator.

The functional monitor lists an acceptable ICP sensor as a prerequisite. Review sensor-circuit faults and the validity of the reported pressure before treating a derived scan value as proof of hydraulic overpressure.

## Preserve the event

An event record containing actual pressure, requested pressure and engine state is more informative than the code alone. It can show whether the excessive value followed a command or departed from it, although the source does not assign a particular failed component to either pattern. Use the applicable professional pressure-control diagnostic procedure to resolve the cause. The 25 MPa monitor limit is not a safe handling limit or permission to open a pressurized fitting.

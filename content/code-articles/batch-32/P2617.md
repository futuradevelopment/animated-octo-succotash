# P2617: Ford 6.0L FICM crankshaft-position input or synchronization fault

Ford's P2617 monitor concerns crankshaft-position information received by the fuel injector control module. The FICM increments a counter when the CKP input is absent and when the engine is out of synchronization with camshaft-position information. This is more specific than a generic engine-speed sensor fault.

## Cranking and running use different counts

The 2004 6.0L summary enables P2617 above 90 rpm and lists five errors for cranking mode and ten for running mode. Preserve the operating mode with the fault, because it changes the documented detection context.

P0336 in the same section describes the PCM's crankshaft-pattern check. P2617's receiving-module context should not be lost when interpreting several position-sensor codes. The sensor may be part of the investigation, but the code is not a direct verdict against it.

## Keep both position signals in view

Because the criterion includes synchronization with CMP, retain camshaft-related codes and relevant signal information. P2614 describes the corresponding FICM camshaft-input problem. The applicable signal-path and synchronization procedure is needed to isolate the cause; the OBD summary does not justify replacing the crank sensor, FICM or engine timing components solely from this code.

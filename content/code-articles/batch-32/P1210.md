# P1210: Ford ICP remains implausibly high with the engine off

The useful distinction in Ford's P1210 definition is the engine-off condition. For the documented 2002 7.3L diesel monitor, engine mode must be off and engine speed must be zero. Actual injection-control pressure above 8 MPa for more than three seconds triggers the fault.

## A plausibility check at rest

A pressure value that may occur during operation has a different meaning after the controller recognizes the stopped state. P1210 therefore should not be interpreted using the running-engine thresholds for P1209 or P1282. Record whether the reported pressure decays after shutdown and whether engine speed actually reaches zero in the recorded event. These observations preserve the conditions the monitor uses.

Ford requires acceptable ICP sensor status for the functional check. That requirement does not prove the sensor's complete accuracy; it means the monitor is distinct from the dedicated circuit-low and circuit-high checks.

## What to investigate next

The evidence concerns unexpected retained or reported pressure, not a specified failure of the high-pressure pump. A qualified diagnostic procedure must separate a pressure plausibility problem from actual system behavior. Do not loosen the high-pressure system to find out whether pressure remains. The source provides an engine-state condition, a threshold and a timer, but no safe depressurization procedure or component-level replacement instruction.

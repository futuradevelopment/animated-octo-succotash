# P0360: Ford coil J primary-monitor feedback fault

P0360 is the coil J entry in the ignition-coil circuit catalog. Ford's 1997 gasoline OBD summary includes it in the P0351–P0360 primary-coil monitor family. The source evaluates ignition diagnostic monitor feedback against the PIP timing reference: each commanded spark event should have the corresponding primary-firing feedback.

## Primary feedback is not a spark-plug test

Ford's EDIS circuitry determines whether primary current reaches its required level within the applicable interval and returns diagnostic information to the PCM. Missing feedback can therefore identify a primary-side problem without directly measuring spark at the plug. The exact coil-to-cylinder mapping must come from the actual engine's service information.

The family is monitored continuously, with a typical duration under five seconds and engine speed above the stated 200 rpm minimum. The document spans several ignition arrangements; it does not establish P0360 applicability to every listed engine.

## Injector shutdown can be a protective response

Ford describes temporary fuel-injector disabling after a primary-coil failure to protect the catalyst, with subsequent reevaluation. An associated injector shutdown should therefore be interpreted in the context of the ignition fault rather than automatically diagnosed as an independent injector failure. Use the correct primary-ignition diagnostic procedure and high-voltage precautions.

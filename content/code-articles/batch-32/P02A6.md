# P02A6: Ford cylinder 4 fuel trim at maximum

P02A6 names cylinder 4 fuel trim at the maximum limit in Ford's 2015 diesel fuel-balancing table. This functional result describes the correction demanded by the balancing controller. It is separate from the injector's electrical open, short and response monitors.

## Conditions make the result meaningful

The controller requires acceptable crankshaft-position input and completed FBC wheel learning. Regeneration must be inactive. Ford lists engine speed between 500 and 3,000 rpm and injection quantity between 3.5 and 90 mg per stroke, with a typical 7.5-second evaluation. These details give the diagnostic record useful context beyond the cylinder number.

The companion P02A7 code identifies the opposite, minimum boundary on cylinder 4. Losing the direction in a generic balance-fault description removes information that the controller supplied.

## Do not equate a limit with a replacement

The source evaluates an internal cylinder-balance limit; it does not state an external injector flow quantity corresponding to that value. Keep the actual operating conditions and correction data, then follow the correct engine's balance diagnostic procedure. Additional circuit or mechanical evidence is needed to determine why the correction reached its upper bound. The code alone does not justify replacing a set of injectors.

## Source and applicability

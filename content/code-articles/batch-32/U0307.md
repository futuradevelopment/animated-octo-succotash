# U0307: Ford glow-plug module reports safe-glow mode

U0307 has the standard software-incompatibility-with-glow-plug-module title. Ford's 2015 diesel summary gives the specific trigger as the glow module reporting safe-glow mode. Keep that implementation detail separate from an assumption that someone installed the wrong software.

## Understand the communication context

The glow-plug module exchanges data and diagnostics with the ECU over the diesel high-speed CAN network. Ford lists U0307 under continuously monitored communication malfunctions. U0407 is a different entry for a calibration-verification number not received by the ECU, and loss of communication has its own code.

Those distinctions matter because a received safe-mode report is not identical to complete absence of the module's messages.

## What further diagnosis must establish

Retain the module's other faults, supply information and relevant identification data. The summary does not explain every cause of safe-glow operation and does not prescribe an automatic reflash or module replacement. Use the exact application's glow-plug module diagnostic procedure to determine why the mode was reported. The glow plugs are duty-cycle controlled; applying constant battery voltage as an improvised test can overheat them and is specifically inconsistent with the documented system operation.

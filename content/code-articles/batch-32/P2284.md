# P2284: Ford 6.0L ICP feedback exceeds commanded pressure

P2284 is broadly an injection-control pressure sensor range/performance code. Ford's 2004 6.0L diesel implementation gives it a specific direction: actual ICP exceeds commanded ICP by 3.0 MPa for more than seven seconds while the engine is running.

## A tracking error, not an absolute ceiling

Both requested and measured pressure are needed to understand this event. A pressure below the absolute high-pressure limit can still fail P2284 if it exceeds the current request by enough. Conversely, an elevated pressure that follows an elevated command answers a different diagnostic question.

The monitor requires acceptable ICP sensor status. P2285 and P2286 provide separate electrical range checks, and their presence can undermine a simple interpretation of the pressure display.

## Preserve the direction

P2290 is the opposite tracking condition, where actual pressure is below command. P2288 checks an absolute running pressure ceiling. Keeping those distinctions prevents a generic ICP performance label from obscuring the controller's actual observation. The source does not isolate a regulator, pump or injector fault. Use the correct 6.0L pressure-control procedure to establish the cause, with appropriate high-pressure equipment and handling precautions.

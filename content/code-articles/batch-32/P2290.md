# P2290: Ford 6.0L actual ICP falls below commanded pressure

P2290 is injection-control pressure too low. Ford's 2004 6.0L diesel summary defines the low condition relative to command: actual pressure is more than 3.0 MPa below requested pressure for over seven seconds with the engine running. It is not a single universal minimum pressure.

## Preserve request and feedback together

A measured pressure can only be evaluated against this criterion when its command is known. A later idle value may not reproduce the demand present during the fault. Record the operating state and the pressure error over time rather than relying on one number.

Ford requires acceptable ICP sensor status. P2285 and P2286 are separate signal-range checks, and an invalid input can complicate any apparent pressure deficit.

## Avoid an automatic pump diagnosis

The source identifies failed pressure tracking but does not isolate a pump, regulator, injector or leak. P2284 covers the opposite tracking direction and P2288 an absolute high-pressure condition. Use the correct 6.0L pressure-control diagnostic procedure to distinguish possible causes and verify that feedback follows demand after repair. High-pressure system work requires the specified equipment and precautions; this monitor is not a component-level repair instruction.

# U0002: Ford ECM transmit CAN buffer remains overloaded

U0002 is high-speed CAN communication bus performance. In Ford's 2015 diesel summary, the specific criterion is an ECM transmit CAN buffer overload lasting more than five seconds. This describes a communication-processing condition rather than a direct electrical open-circuit finding.

## Not every network fault means a broken wire

The same source separately assigns U0073 and U0074 to bus-driver detection of a short or open, and module-specific U-codes to missing messages. U0002 preserves a different observation: the transmit buffer is overloaded. It should not automatically be translated into a failed termination resistor or disconnected module.

Ford lists continuous monitoring with no sensor prerequisites. The five-second overload criterion is the useful persistence condition for this particular code.

## Keep the network evidence together

Retain the reporting module, other communication codes and whether modules remain accessible. Those observations help a technician select the correct network diagnostic branch, but the summary provides no universal causal rule from U0002 alone. Use the actual vehicle's network topology and service procedure to investigate the overload. Replacing a module or altering bus wiring based only on the broad bus-performance label would exceed what this monitor establishes.

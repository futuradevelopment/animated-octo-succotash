# U0407: Ford ECU does not receive the glow-module verification number

U0407 is invalid data received from the glow control module. In Ford's documented 2015 diesel implementation, the threshold is a calibration-verification number not received by the ECU. This is more specific than a generic statement that all glow-plug communication has failed.

## Missing identification data versus a missing module

The source separately lists loss-of-communication and safe-glow-mode faults. U0307 corresponds to the glow module reporting safe-glow mode, while U0407 addresses the verification-number information. Preserve these distinctions when reviewing a cluster of module codes.

Ford describes continuous monitoring. The module communicates over a dedicated diesel high-speed CAN path, so diagnosis requires the correct application network information rather than an assumed universal connector or bus layout.

## Do not infer the repair from the title

A missing verification number does not, by itself, prove that a nonstandard calibration was deliberately installed. The summary gives no universal reprogramming remedy or part-replacement instruction. Retain module identification and accompanying power or communication faults, then follow the appropriate diagnostic procedure. Keep physical glow-plug tests within the prescribed method: these plugs use duty-cycle control and can overheat if constant battery voltage is applied.

# P2286: Ford 6.0L ICP sensor voltage exceeds its range

Ford defines P2286 as injection-control pressure sensor circuit high. The 2004 6.0L diesel summary sets the electrical boundary above 4.83 volts. This is a signal-range result, so it should not be treated as direct proof that hydraulic pressure exceeded its allowed operating limit.

## Compare the right type of high fault

P2288 is the separate running-engine excessive-pressure check, while P2289 checks excessive pressure with the engine off. P2286 has no listed entry conditions and typically evaluates in less than one second. Its continuous electrical test can therefore fail without either pressure monitor's operating window.

The source's threshold belongs to this 6.0L implementation. An older 7.3L ICP monitor uses different code names and boundaries; those values should not be mixed into this diagnosis.

## Establish signal credibility

Retain the electrical fault alongside any functional pressure codes. The applicable circuit tests must determine whether the sensor input is valid before a scan-tool pressure number is accepted as evidence of actual overpressure. The monitor cannot identify the failed connector, sensor or controller component by itself. Use the prescribed electrical method and pressure-system safeguards before any hydraulic investigation.

## Source and applicability

# P2289: Ford 6.0L ICP remains too high with the engine off

P2289 identifies injection-control pressure too high with the engine off. In Ford's 2004 6.0L diesel monitor, actual ICP above 10 MPa for more than twelve seconds is the listed fault condition. The engine-off requirement is essential to interpreting the pressure value.

## Do not use the running threshold

P2288 permits a different pressure ceiling during engine running, while P2284 compares actual pressure with command. P2289 instead checks whether an unexpectedly high value remains in the stopped state. Preserve shutdown timing and the pressure trend when investigating the event.

The monitor requires acceptable ICP sensor status. That separates it from electrical out-of-range codes, but it does not make the displayed pressure an independent mechanical measurement.

## Separate retained pressure from a reporting problem

The proper diagnostic procedure must establish whether the reading reflects the system's actual condition or an inaccurate pressure indication. The code itself does not identify the pump, regulator or sensor as the failed component. Do not open the injection-control system to find out whether pressure remains. The OBD summary contains a detection criterion, not a safe depressurization or component-removal procedure. Use the exact engine service information and suitable high-pressure diagnostic equipment.

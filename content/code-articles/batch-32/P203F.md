# P203F: Ford calculates insufficient remaining DEF range

P203F is reductant level too low. In Ford's 2015 diesel summary, the fault is part of the diesel exhaust fluid warning system and is recorded when calculated DEF range reaches 200 miles. This is an estimated remaining-distance decision, not a statement that the tank is completely empty.

## Why the estimate may differ from expectation

The calculation uses the tank's three-pin level sensor and the volume of DEF commanded into the exhaust over distance. Both stored fluid and consumption history therefore contribute to the warning. Ford explicitly acknowledges tolerance between actual and reported remaining mileage. The number should not be interpreted as a guaranteed driving allowance.

The monitor requires acceptable status from the combined DEF temperature/level sensor. A low-level warning and an electrical level-sensor code ask different diagnostic questions.

## What confirms a refill

The summary states that the fault is erased after the system detects a refill event. That makes recognized refill information relevant to verification; merely clearing a code does not establish that the calculation has registered new fluid. Follow the vehicle's specified refill and diagnostic instructions. If the warning persists, assess the sensor and recognized refill state rather than assuming the SCR catalyst has failed.

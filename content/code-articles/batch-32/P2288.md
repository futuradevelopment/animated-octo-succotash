# P2288: Ford 6.0L running injection-control pressure is too high

P2288 means injection-control pressure too high in Ford's 2004 6.0L diesel summary. The engine must be running, and actual pressure must exceed 29.5 MPa for more than three seconds. This is an absolute pressure ceiling, not merely a difference between request and feedback.

## Distinguish the control questions

P2284 evaluates actual pressure above command, while P2289 evaluates high pressure with the engine off. A diagnostic record should preserve engine state and both actual and desired pressure so these separate results are not collapsed into one general high-pressure complaint.

Ford requires acceptable ICP sensor status for the functional check. The electrical-high code P2286 describes an invalid signal-range condition rather than the same hydraulic ceiling.

## What the code cannot prove

P2288 establishes excessive reported pressure in the defined running window. It does not identify which pressure-control component caused the condition or prove that a specific part must be replaced. Validate the pressure information and follow the correct 6.0L control-system diagnostic procedure. The monitor's 29.5 MPa boundary is not a safe handling pressure or a reason to loosen connections; high-pressure work requires the specified release procedure and equipment.

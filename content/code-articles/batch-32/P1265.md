# P1265: Ford cylinder 5 injector drive circuit short

P1265 identifies cylinder 5's high-side-to-low-side injector short in Ford's 2015 diesel summary. It is a circuit diagnosis made by internal driver logic. The source does not derive it from fuel pressure, exhaust oxygen or cylinder contribution, so those measurements should not be substituted for the named electrical investigation.

## A shared monitor with a specific cylinder

The P1261–P1268 group uses the same continuous check and 0.3-second typical duration. P1265's distinguishing information is cylinder 5. The manual's coverage of multiple engines means the vehicle's own service information must establish the physical cylinder and wiring; the code number alone is not a location diagram.

Ford separately lists P0205 for an open circuit and P02F2 for an implausible cylinder 5 injector response. A high-to-low-side short should retain its specific classification when passed between scan tools or written in a repair order.

## What a repair decision still needs

The electrical fault tree must isolate the injector, circuit connections and driver path before replacement is justified. The monitor summary provides no blanket instruction to replace all injectors or the controller. Use the prescribed precautions for the injector actuation system and avoid improvised powered tests.

# P1670: Ford IDM engine-feedback response is missing

Ford assigns P1670 to an engine-feedback signal not detected in the documented 2002 7.3L diesel system. The controller commands a response from the injector driver module and sets the code when that response is not received. The essential failure is an expected exchange that did not arrive.

## The engine state matters

The listed entry condition is a running engine, expressed as mode 2. The check is continuous and typically evaluates in less than one second. A stopped-engine observation does not automatically reproduce the same diagnostic conditions, even if the scan tool still shows the stored code.

The neighboring P1316 monitor uses the same general engine-feedback relationship to learn that the IDM has stored codes. P1670 is different: it identifies absence of the requested response rather than successful receipt of a stored-fault indication. That distinction is useful when choosing between retrieving IDM diagnostic details and investigating an unavailable feedback path.

## Avoid an unsupported component verdict

The OBD summary does not state that every missing response proves the module itself has failed. The event must be interpreted with the correct module supplies, communication wiring and service tests. Preserve other module and injector codes before clearing anything. Injector-driver circuits require suitable professional testing equipment; a monitor description does not supply safe probing points or a substitute wiring diagram.

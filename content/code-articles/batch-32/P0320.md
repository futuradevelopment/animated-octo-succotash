# P0320: Ford ignition timing-reference pulses are missing or irregular

Ford's 1997 gasoline summary uses P0320 for the crankshaft-derived profile ignition pickup signal, commonly called PIP. The controller evaluates timing between successive reference events. Excessive change in three successive PIP events indicates a missing or noisy timing reference.

## The processed signal matters

Ford describes an EDIS chip that processes the crankshaft wheel signal and supplies the lower-data-rate PIP signal to the PCM microprocessor. P0320 therefore should not be reduced to a declaration that the physical crankshaft sensor is necessarily defective. The monitored signal path includes processing and delivery of the reference events.

The table lists an interval above 350 milliseconds and an out-of-range relationship between current and prior periods among the checks. Monitoring is continuous, typically under five seconds, with engine speed above the stated 200 rpm minimum.

## Keep ignition feedback distinct

Camshaft identification and ignition diagnostic monitor feedback are evaluated separately. Their codes can add context but are not substitutes for the missing or irregular PIP evidence. Preserve cranking versus running circumstances and related position or ignition codes, then use the correct ignition-system diagnostic procedure. The source covers multiple EDIS/COP arrangements and does not provide one universal module location or wiring pinout.

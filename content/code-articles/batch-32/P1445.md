# P1445: Ford purge-flow sensor circuit fault versus inadequate purge flow

P1445 belongs to Ford's purge-flow sensor circuit checks in the 1997 gasoline OBD summary. The catalog identifies the high-input member of this sensor family, while the cited summary groups P1444 and P1445 as continuity checks. It does not give a separate P1445 voltage threshold, so no universal high-voltage test value is inferred here.

## Sensor circuit and purge function are separate

Ford uses the purge-flow sensor to compare the signal with the canister purge valve substantially open and then commanded closed. An inadequate change supports the separate P1443 functional fault. P1445 instead addresses the sensor circuit's electrical credibility. A failed circuit can therefore undermine the interpretation of a purge-flow comparison.

The source describes the circuit checks as continuous, whereas the functional purge check runs once per driving cycle under specific conditions. Do not apply the functional test's road-speed, load or valve-command window as a universal prerequisite for this sensor circuit code.

## Choose the right diagnostic branch

Preserve any P1443 or P0443 companion faults, since they add flow-performance or purge-valve driver evidence. Follow the exact vehicle's purge-flow sensor circuit procedure before judging canister flow. This summary does not isolate a failed sensor or authorize replacing the canister or purge valve from P1445 alone.

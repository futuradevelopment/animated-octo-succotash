# P1291: Ford bank 1 injector high-side circuit short

P1291 identifies a bank 1 injector high-side short to ground or battery in Ford's 2015 diesel summary. Internal driver logic recognizes the electrical condition. The bank designation is useful, but the code does not isolate one cylinder within that bank.

## Bank fault and cylinder fault are different evidence

The same document assigns P1261 through P1268 to individual-cylinder high-side-to-low-side shorts. Those codes describe a different electrical relationship. Reading P1291 as a cylinder 1 code would confuse bank numbering with cylinder numbering and discard the source's actual distinction.

Ford lists continuous monitoring, no sensor prerequisites and a typical duration of 0.2 second for P1291. The check is not a long fuel-balance evaluation and does not need a measured combustion deficit to identify the driver fault.

## Direct the investigation appropriately

Retain all accompanying injector-driver codes and identify the actual engine's bank layout from its service information. A shared bank circuit requires a different investigation from a lone cylinder performance result. The monitor cannot determine from the code alone whether a harness, injector or controller component caused the short. Injector actuation circuits can use hazardous voltages; diagnosis requires the specified isolation and testing procedure.

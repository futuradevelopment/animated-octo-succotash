# P2702: Ford 5R110W intermediate clutch functional failure

Ford's 5R110W implementation uses P2702 for intermediate-clutch failed-on or failed-off behavior. The controller evaluates the clutch in particular gears and shifts using intermediate and output shaft-speed information. This is a functional result, not a direct electrical open/short diagnosis.

## Which behavior was observed

The source checks failed-off behavior in third gear or shifts into it. Failed-on detection uses other specified gears and shifts, where that clutch should not produce the same engagement. The exact internal gear convention belongs to the 5R110W application and should not be generalized to another transmission.

Ford cycles the clutch after each bad event and tests again; three bad events are the listed duration. This repeated confirmation distinguishes the monitor from one momentary ratio discrepancy.

## Read companion faults

P0761 and P0762 provide the failed-off and failed-on directions in this group. Retain them with P2702, along with shaft-speed faults that may affect the functional evidence. The summary does not identify a particular valve, friction component or solenoid as the inevitable cause. Use the correct transmission diagnostic procedure to isolate the failed functional response and verify the relevant operating states after repair.

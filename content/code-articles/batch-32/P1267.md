# P1267: Ford cylinder 7 injector high-to-low-side short

Ford assigns P1267 to a high-side-to-low-side short in cylinder 7's injector circuit. The driver's internal logic recognizes the short. This identifies both a cylinder and an electrical fault type, but it does not identify a leaking nozzle or prove a mechanical combustion problem.

## Keep application and category precise

The 2015 summary spans more than one diesel engine. A cylinder 7 entry naturally requires an engine with that cylinder; the document's general coverage is not proof of universal applicability. Establish the exact wiring and numbering from the vehicle's service information.

The table distinguishes P1267 from cylinder 7 open-circuit code P0207 and implausible-response code P02F4. Its typical 0.3-second duration belongs to the continuous electrical monitor, not a prolonged fuel-balancing test.

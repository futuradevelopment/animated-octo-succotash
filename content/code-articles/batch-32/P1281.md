# P1281: Ford ICP sensor signal above its electrical range

Ford identifies P1281 as injection-control pressure circuit out of range high in the 2002 7.3L diesel OBD summary. Its decision boundary is above 4.90 volts. The word high describes the sensor circuit signal, so it must be distinguished from a valid sensor reporting genuinely excessive injection-control pressure.

## Two different kinds of high reading

Ford uses P1282 for the excessive-pressure functional monitor, which requires a running engine and evaluates actual pressure against a pressure limit. P1281 instead has no listed entry conditions and is checked continuously, typically in less than one second. Those differences explain why a high-input electrical code can appear without satisfying the running pressure test.

The source does not turn 4.90 volts into a repair specification for the pump or pressure regulator. It is a fault-detection boundary for this particular electrical input.

## Diagnostic interpretation

Establish whether the ICP signal is electrically valid before interpreting the pressure number derived from it. Preserve accompanying functional codes and the circumstances of the event, then use the correct circuit diagram and service checks to distinguish the sensor, wiring and controller input path. Do not infer that a pressure-control part needs replacement solely because a scan tool displays a high value. Hydraulic pressure testing requires the specified professional equipment and pressure-release precautions.

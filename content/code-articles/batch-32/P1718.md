# P1718: Ford transmission temperature stays implausibly high

Ford describes P1718 as a transmission-fluid temperature input stuck at a high value in its 2002 diesel OBD summary. This is a functional plausibility result. It does not automatically mean that the transmission fluid actually reached a dangerous temperature, and it is not the same test as the electrical voltage limits for P0712 or P0713.

## Look at the temperature history

The functional check uses a 600-second monitoring duration and expects more than the listed 6°F change after startup. Its enabling context includes a long soak, accumulated running time, operation in gear with positive torque and vehicle movement. An apparently high but unchanging reading deserves a different investigation from a credible temperature that rises with load.

Ford also documents coolant-temperature substitution when the TFT input malfunctions. That fallback can affect how temperature-related control behavior is understood after the fault.

## Confirm the relevant monitor

Preserve the initial reading and the subsequent temperature trend, then establish whether the circuit checks passed and whether the functional test conditions were met. The source's hot/cold coolant row does not provide a sufficiently clear universal threshold recipe, so use the exact application procedure for test conditions. The distinction from P1713 is the high-value direction; both belong to the same change-over-time check. Neither code alone identifies a failed transmission assembly.

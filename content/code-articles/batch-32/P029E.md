# P029E: Ford cylinder 2 fuel trim reaches the maximum limit

Ford assigns P029E to cylinder 2 fuel trim at the maximum limit. The 2015 diesel summary places it in fuel-balancing control, where the controller evaluates cylinder correction during a defined running window. The code is not a declaration that cylinder 2's injector circuit is electrically high.

## Why learning and operating mode matter

The FBC wheel-learning process must be complete, regeneration must be inactive and crankshaft-position sensor status must be acceptable. The listed range is 500–3,000 rpm with 3.5–90 mg of injection quantity per stroke. A technician needs that context to judge whether a captured correction represents the monitor that set the code.

Ford gives the evaluation a typical 7.5-second duration. P029F uses the same balancing family but identifies the minimum boundary for cylinder 2, so the two codes should retain their different directions.

## From correction to diagnosis

An upper correction limit tells the technician that the controller has run out of the permitted adjustment in that direction. It does not independently measure injector flow or isolate a failed part. Preserve the balance data and use the engine-specific contribution procedure to investigate why cylinder 2 requires the correction. Do not infer cylinder location from the code alone.

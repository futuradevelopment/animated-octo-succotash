# P029B: Ford cylinder 1 fuel trim reaches its minimum boundary

P029B identifies the minimum fuel-trim limit for cylinder 1 in Ford's documented fuel-balancing control monitor. It is the lower-bound counterpart to P029A. The code describes the controller's correction limit, so it should not be interpreted as a direct measurement that the injector delivered a particular quantity of excess fuel.

## Read the correction in context

The test requires completed FBC wheel learning and acceptable crankshaft-position sensor status. Ford also excludes regeneration and lists a 500–3,000 rpm speed window with injection quantity between 3.5 and 90 mg per stroke. Those details explain why correction data collected during a different operating mode may not reproduce the fault decision.

A typical evaluation lasts 7.5 seconds. The source's internal limit value has no stated workshop conversion into flow or injector resistance.

## What to preserve

Keep cylinder 1's minimum-direction result and the qualifying operating data when investigating the imbalance. A companion circuit code would add electrical evidence, but P029B itself is not an open/short diagnosis. Apply the exact engine's cylinder-balance procedure to distinguish the source of the needed correction before authorizing an injector replacement or a mechanical repair.

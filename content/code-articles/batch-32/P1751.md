# P1751: 1994 Mustang California shift-solenoid 1 functional failure

Ford's 1994 Mustang chart assigns P1751 to shift-solenoid 1 functional failure for the California calibration. The row describes mechanical or hydraulic failure of the shift-solenoid function. That source-specific scope should not be extended to every Mustang or every Ford transmission carrying the same code string.

## Functional failure differs from circuit failure

P0750 is the chart's SS1 electrical circuit-failure entry. P1751 concerns the function achieved, and the resulting gear can depend on failure mode and manual-lever position. Retain the selector state and shift behavior rather than assuming that the functional code proves an open winding.

The linked Pinpoint Test A is explicitly an electrical-system test. Ford warns that engine, electrical and internal transmission conditions can affect the broader complaint.

## Use the tester results to choose the branch

The procedure checks circuits and solenoid activation before evaluating whether the transmission upshifts when commanded by a transmission tester. A successful electrical test does not resolve every mechanical or hydraulic possibility. Follow the exact engine's wiring and the relevant functional or symptom diagnosis to isolate the cause. The code alone does not prove that replacing SS1 will correct the vehicle's gear-selection problem.

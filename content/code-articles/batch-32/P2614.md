# P2614: Ford 6.0L FICM loses camshaft-position synchronization

P2614 is camshaft-position output circuit/open in Ford's 2004 6.0L diesel summary. The fuel injector control module increments a fault counter when its camshaft-position input is absent or the engine is out of synchronization with the crankshaft-position signal. The title therefore covers more than a simple continuity measurement.

## Identify which module made the observation

Ford's adjacent P0341 check describes the PCM's camshaft-pattern monitoring. P2614 specifically concerns the FICM's input and synchronization assessment. Knowing the receiving module helps keep a signal-distribution problem separate from an assumption that the sensor itself is defective.

The P2614 check is enabled above 90 rpm. Ford lists five errors in cranking mode and ten in running mode, so the engine state affects the counting criterion.

## Preserve the synchronization evidence

Record camshaft and crankshaft-related codes together and retain whether the event occurred during cranking or running. The source does not provide a universal rule that P2614 requires a new cam sensor or FICM. Use the correct engine's signal and synchronization diagnostic procedure to isolate the problem. The related P2617 code addresses crankshaft information at the FICM and adds a different observation if present.

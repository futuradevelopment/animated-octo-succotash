# P029A: Ford cylinder 1 fuel-balance correction reaches its upper limit

P029A is cylinder 1 fuel trim at the maximum limit in Ford's 2015 diesel fuel-balancing control table. The code concerns the controller's balance correction, not the electrical high side of the injector. That distinction matters because an adaptation-limit result does not by itself identify a shorted or open injector circuit.

## The balancing test has prerequisites

Ford lists engine speed from 500 to 3,000 rpm, injection quantity from 3.5 to 90 mg per stroke, completed FBC wheel learning and no active regeneration. The crankshaft-position input must be acceptable. The typical monitoring duration is 7.5 seconds. These conditions define an actual balancing evaluation rather than any arbitrary idle observation.

P029B is the corresponding minimum-limit result for cylinder 1. Retaining which boundary was reached is more informative than recording only a generic cylinder-balance fault.

## Interpreting the limit

The source evaluates an internal cylinder-balance limit value; it does not convert that value into a universal injector flow specification. Preserve the correction direction and operating window, then use the correct engine's balance diagnostic procedure to find why compensation reached its boundary. The code alone cannot distinguish injector delivery from other causes of unequal cylinder contribution.

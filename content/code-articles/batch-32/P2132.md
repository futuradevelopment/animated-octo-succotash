# P2132: Ford 6.0L pedal sensor F circuit voltage is low

P2132 identifies throttle/pedal position sensor F circuit low in Ford's 2004 6.0L diesel system. The stated electrical threshold is below 0.25 volt. The check runs continuously, typically evaluates in less than one second and has no listed enabling conditions.

## The redundant channels change the effect

Ford describes separate D, E and F pedal sensor circuit checks. The source says one failed pedal sensor does not produce a customer drivability effect in this implementation, whereas two or more failed sensors leave the engine at idle. That makes the full set of pedal codes important; a single code and multiple-channel failure are materially different situations.

The document also says these pedal faults do not illuminate the MIL. Lack of an engine warning lamp is therefore not evidence that the pedal inputs are healthy.

## Diagnose the electrical input

The code describes a low signal, not proof that the driver pressed the pedal insufficiently or that the throttle valve is mechanically stuck. Preserve companion channel faults and follow the correct pedal-circuit diagnostic procedure. The monitor does not identify one failed component or provide a universal pinout. Its stated drivability behavior should not be generalized to other Ford engines or model years.

# P1280: Ford injection-control pressure signal below range

P1280 in the documented Ford 7.3L diesel system means the injection-control pressure sensor circuit is below its electrical range. Ford sets the low-input boundary at less than 0.04 volt. The code describes the sensor signal presented to the controller; it does not, by itself, establish that the hydraulic system is producing insufficient pressure.

## Separate signal quality from pressure control

The ICP electrical monitor runs continuously, with no listed enabling conditions and a typical duration below one second. This differs from P1209 and P1211, which compare commanded and measured pressure while the engine is running. An invalid pressure input can make a pressure-control interpretation unreliable, so review electrical faults before drawing conclusions from the displayed pressure value.

The companion P1281 code marks the opposite electrical boundary. This pair helps identify an input-range problem, but neither description names a connector terminal or isolates a single component.

## Evidence to retain

Record whether the low signal is present continuously or only during a particular operating event, together with any pressure-control codes. Follow the correct sensor-circuit procedure to establish signal integrity before considering hydraulic component replacement. Injection-control pressure is a high-pressure system; the monitor threshold is not an instruction to loosen a fitting, improvise a pressure test or probe an unidentified circuit.

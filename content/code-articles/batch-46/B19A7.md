# B19A7: a driver cushion blower-control short is distinct from a failed heater element

B19A7 can disable the driver's climate-controlled seat without identifying a failure of its heating element. Ford defines the fault as grounding of the driver cushion blower speed-control circuit. The controller responds by shutting down the driver-seat climate system.

## Follow the command path

The cited configuration uses VHS18 for the speed command and RHS03 for the blower return. Ford first separates the module and cushion TED from the circuit before checking the command wire against ground. It then checks the command wire against the return conductor.

Both tests require more than 10,000 ohms. The first rules out a path to the vehicle ground; the second examines an unwanted connection between two named harness circuits. Treating either result as a direct measurement of blower resistance would misread the procedure.

## Confirm more than the disappearance of a code

When the wiring passes the specified checks, the factory branch identifies the cushion TED as the component to replace. This is not the same branch as B19A3, which addresses unwanted voltage rather than grounding. The original code should be recorded before work begins so those failure modes are not confused. Under-seat access also involves side-airbag connections and must follow the restraint safety process. A completed repair needs a repeated self-test and demonstrated climate operation; an electrically adjustable seat alone does not prove its blower-control function has recovered.

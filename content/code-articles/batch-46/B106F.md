# B106F: the final overload threshold in the Fusion SJB

B106F has a different implication from an ordinary intermittent lamp or accessory circuit fault. In the cited Fusion Smart Junction Box procedure, it means repeated overloads have reached the third protection threshold. At that point, one or more output functions are permanently disabled.

## Why clearing codes is insufficient

Ford associates this final stage with B1342 as well. When B1342 accompanies permanent output disablement, the manual says SJB fault codes cannot be cleared. That limits the value of repeating a module self-test as proof of repair: the disabled module cannot demonstrate that the external circuit has become healthy.

The procedure instead calls for a meter measurement of the affected output circuit to establish that the original fault no longer exists. Identifying the companion circuit code and repairing its overload condition comes before fitting another junction box. Reversing that order risks exposing the replacement to precisely the fault that disabled the original.

## Keep the diagnosis tied to the actual output

B106F does not name a particular lamp, relay or wire by itself. The useful evidence is the complete SJB code record, the function that stopped operating and the corresponding wiring test. Ford's final self-test branch distinguishes persistent B106F or B1342 from a repaired, recoverable circuit condition. Module replacement is the endpoint of that documented sequence, not a substitute for finding the external overload.

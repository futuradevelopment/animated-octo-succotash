# B1331: the luggage lamp and latch share a ground-controlled path

B1331 appears in Ford's Fusion luggage-compartment lamp diagnosis. The lamp receives power from demand lighting, while a switch inside the lid latch completes its ground path when the compartment opens. The SJB's ajar-input fault therefore needs to be considered with the latch and lamp wiring.

## Separate an always-on lamp from a dark lamp

The factory procedure starts by observing the lamp. For an always-on complaint, disconnecting the latch distinguishes a ground remaining in the harness from a latch-controlled condition. For a dark lamp, Ford checks the power feed first, then checks the circuit using the lamp's own return path.

This difference matters: a lamp can have a satisfactory power supply yet remain dark because its ground-controlled path is open. Replacing the bulb or lamp alone would not repair that return.

## Check the physical lid independently

The code describes an electrical input, not a guarantee that the lid is mechanically latched. Verify secure closure separately. Ford's procedure moves between the lamp connector and latch connector to distinguish the wire from the latch switch, rather than assuming an ajar message always requires a new junction box. Record whether the lamp never lights, remains on with the lid closed or changes when the harness moves. Following repair, confirm truthful lid-state indication and lamp behavior in both open and closed positions.

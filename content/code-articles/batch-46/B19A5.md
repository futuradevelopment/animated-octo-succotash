# B19A5: a grounded cushion blower command shuts down the passenger climate seat

Ford B19A5 belongs to the passenger cushion blower's command path. The Dual Climate Controlled Seat Module supplies power and ground to the TED assembly but controls blower speed through a separate circuit. Grounding that control circuit causes the passenger seat system to be disabled.

## Two different paths to ground are checked

The first Fusion test isolates the module and cushion assembly, then checks the control circuit against chassis ground. The second compares the same control path with the blower's ground circuit. Both checks use a greater-than-10,000-ohm criterion under the specified disconnected conditions.

These are related but distinct questions. A chafed control wire can touch the body, or it can contact the return conductor within the harness. The diagnostic sequence avoids assuming that a grounded signal automatically means the thermoelectric device itself has failed.

## The cushion assembly is the relevant component

If the prescribed harness checks pass, the procedure directs attention to the passenger cushion TED rather than the backrest unit. That branch should be understood only after circuit isolation is complete. B19A1 concerns unwanted voltage on this area of the system and is not an interchangeable description of B19A5. A qualified technician must follow the seat-mounted airbag precautions before access. Following repair, check passenger-seat heating and cooling operation as well as the code record, because code clearance alone does not demonstrate restored airflow.

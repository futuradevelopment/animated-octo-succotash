# B19A1: unwanted voltage on the passenger cushion blower command

The passenger seat cushion blower has a power supply and a separate speed-control signal. B19A1 concerns the latter: Ford says a short to voltage on this command circuit causes the seat module to shut down the passenger climate-controlled seat. It does not simply mean that the blower is running too fast.

## Locate the unwanted supply

The Fusion procedure identifies VHS23 as the cushion blower control path. The diagnostic sequence disconnects the controller and checks for voltage on the isolated harness, then repeats the assessment with the cushion TED assembly disconnected. That comparison distinguishes a voltage source remaining in the harness from one associated with the assembly.

Ford also tests whether the control wire is shorted to the blower's separate feed. The specified isolation criterion is greater than 10,000 ohms. This matters because two wires can touch each other without either being directly grounded.

## The final component check has a different scale

The procedure's internal TED isolation check uses greater than two million ohms between the named component terminals. It is not a blower winding-resistance specification. Confusing those measurements could condemn a serviceable assembly. Because the work intersects a seat-mounted airbag circuit, diagnosis requires the factory restraint depowering and restoration process. Keep the observed passenger-seat shutdown and complete DTC record available for the technician before clearing anything.

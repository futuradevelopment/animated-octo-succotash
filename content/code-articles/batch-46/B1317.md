# B1317: compare other modules before condemning the Fusion junction box

The Fusion Smart Junction Box stores B1317 when it detects supply above 15.5 volts in the cited procedure. That record can represent a charging-system problem, a module-specific concern or a previous charging event. It does not automatically identify an internally failed junction box.

## Look for a vehicle-wide event

Ford begins by retrieving continuous-memory codes from all modules. Similar high-voltage records in several modules point the investigation toward charging-system overvoltage rather than several independent controller failures. This comparison also preserves evidence that could be lost if each module is cleared separately.

The next check monitors battery voltage with accessories and lamps off during the specified running test. A rise to the procedure's high-voltage boundary sends diagnosis back to the charging system. A normal reading later cannot reconstruct every earlier voltage spike, which is why the stored code context remains useful.

## Repeat the module test after the supply check

Only after those steps does Ford clear the SJB memory and repeat its self-test. A returning B1317 follows a different branch from one that disappears. The manual specifically notes that charging or jump-starting can leave a historical code. Report any recent battery work and accompanying symptoms, including whether other electrical systems were affected. The 15.5-volt figure belongs to this SJB procedure; it should not be assumed to be every controller's threshold on every Ford application.

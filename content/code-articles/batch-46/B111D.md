# B111D: passenger-seat shutdown can follow an overloaded blower output

B111D is a passenger blower-output diagnosis in Ford's Fusion climate-seat system. The source describes a grounded circuit or excessive current causing the seat module to overheat and stop the passenger seat. The wording does not establish that the passenger cushion itself reached a particular temperature.

## Divide the harness from the assemblies

The factory sequence examines the shared passenger blower feed CHS08, then its isolation from return RHS08. With the relevant components disconnected, both checks require more than 10,000 ohms. The aim is to locate an unwanted current path before evaluating the individual cushion and backrest units.

The following component test has a different purpose and scale: the manual specifies 4,000–10,000 ohms between designated blower terminals. It also prescribes meter-lead polarity because reversed leads can produce false results. A resistance value obtained in another configuration cannot be substituted for that test.

## Repair the cause of the protective shutdown

If a harness short is responsible, replacing the controller alone leaves the overload in place. If the wiring passes, the separate assembly measurements help identify which load requires attention. This work includes the passenger seat airbag connection, so factory restraint precautions are part of the service procedure. Record whether only the passenger climate function fails and which mode was selected. After repair, confirm actual blower operation and repeat the module test rather than relying solely on cleared fault memory.

# B2924: when a non-navigation audio button is held active too long

B2924 is the Audio Button Stuck code used by the non-navigation Fusion front controls interface module. The FCIM detects a switch active for more than three seconds during self-test or more than two minutes during normal operation. It then disables that switch until the input is no longer active.

## A disabled button does not prove the radio is dead

The FCIM broadcasts button requests over the medium-speed CAN network. If that module loses communication, the audio system can remain in its previous operating state while steering-wheel controls continue working. That pattern helps separate a front-panel problem from a complete loss of audio-module function.

The same panel also provides climate-system controls, making the complete symptom report useful when assessing a network or panel concern.

## Repeat the test without touching the controls

Ford first retrieves communication codes from the audio system. After those are addressed as appropriate, the FCIM codes are cleared and its self-test is repeated with no buttons pressed. Holding a button during this test could satisfy the short self-test timing threshold and confuse the result.

A returning B2924 under those conditions selects the FCIM replacement branch. Otherwise, the procedure inspects its connector for corrosion or damaged terminals and reproduces the complaint before a final decision. Confirmation should include normal response from the formerly affected button as well as a clean test performed with the controls released.

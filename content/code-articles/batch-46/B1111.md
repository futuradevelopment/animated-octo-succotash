# B1111: the overheating threshold belongs to the seat controller's driver circuit

B1111's overtemperature description can be misread as a measurement of the seat cushion. Ford's Fusion procedure is more specific: the temperature belongs to the Dual Climate Controlled Seat Module's TED driver integrated circuit. Above 175°C, the module shuts down the driver-seat system.

## Shutdown protects the controller

The cushion and backrest each contain a thermoelectric assembly that heats or cools airflow. The controller manages these loads and their blowers. The cited threshold is an internal electronic protection limit; it should never be interpreted as an acceptable upholstery temperature or an instruction to heat a seat for testing.

Ford groups the investigation with the driver TED overcurrent test. The sequence checks output circuits for grounding and unwanted voltage, then compares the device-and-harness resistance with the specified range. This seeks the electrical conditions around the overloaded driver rather than concluding that a cabin-temperature sensor caused the shutdown.

## Record which operation produces the failure

The normal system runs with the engine operating. Scan-tool commands can activate it with the engine stopped, but only in fifteen-second intervals described by the manual. That distinction prevents a timed diagnostic activation from being mistaken for spontaneous shutdown. Because diagnosis involves seat-mounted restraint connections, use a technician following the depowering procedure. Note whether the fault appears in heat, cool or both modes and whether the passenger seat continues functioning.

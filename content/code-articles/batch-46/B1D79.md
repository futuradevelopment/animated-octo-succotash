# B1D79: the navigation audio module's microphone test-tone failure

B1D79:01 is recorded by the audio control module during the microphone test on the navigation-equipped system. The ACM produces a tone and expects the microphone path to return an adequate response. Failure of that check does not identify which part of the path has lost the signal.

## Follow the navigation signal route

The microphone feeds the accessory protocol interface module, which also passes the microphone signal to the navigation ACM. A vehicle can therefore enter voice mode yet still have a problem delivering the signal to the navigation unit. Ford distinguishes this ACM test from the APIM microphone-detection code B1A16.

The procedure checks for a fluctuating AC signal while a command is spoken, then investigates the intermodule microphone circuits for unwanted voltage, an open or a ground fault.

## Why sequence and applicability matter

For the ACM signal check, the specified connector is disconnected only after the audio module powers up; otherwise the module may not receive its network RUN message. This condition explains why an isolated meter reading is insufficient without the test setup.

The published steps contain inconsistent APIM connector references, which require wiring-diagram verification before terminal testing. This article is consequently marked for review. The final diagnostic branches inspect module terminals and repeat operation before replacing an ACM or APIM. Verification should exercise navigation voice recognition and the microphone test, rather than relying solely on normal radio playback.

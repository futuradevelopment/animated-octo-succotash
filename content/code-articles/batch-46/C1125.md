# C1125: separating a fluid-level warning from a grounded sensor input

C1125 is a brake-fluid level input fault recorded by the Smart Junction Box. The fluid-level switch normally grounds its input when a low-fluid condition exists. A grounded circuit can therefore resemble the same electrical state, but the code alone cannot establish whether the brake fluid is actually at the correct level.

## Treat the brake warning as a real complaint

Check fluid condition and braking symptoms through qualified service before reducing the problem to an indicator fault. The cluster's brake lamp also responds to parking-brake status and ABS brake-distribution information. Companion ABS or communication codes may explain additional warnings and change the diagnostic route.

The source distinguishes the fluid switch's external ground from the parking-brake switch's case ground. Their wiring and test points should not be interchanged.

## Isolate the level-input path

Ford disconnects the fluid-level switch, clears SJB codes and repeats the self-test to determine whether C1125 remains. A returning code leads to a check for a ground short on the isolated input conductor; the specified isolation criterion is greater than 10,000 ohms.

If the wire passes, SJB connector condition and module operation are checked before replacement. These electrical results do not rule out a hydraulic problem or authorize driving with low fluid. Repair verification must establish correct fluid-level reporting, resolve the warning's actual cause and confirm that any associated brake-system concerns have also been addressed.

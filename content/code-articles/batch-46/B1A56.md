# B1A56: why a weak antenna self-test does not prove the radio is defective

B1A56:21 is an antenna signal-amplitude code. The audio control module sets it when measured signal strength falls below its configured threshold during the self-test. Ford does not publish a numerical threshold in this procedure, so a specific universal signal-strength limit cannot be inferred.

## Rule out a misleading reception complaint

The diagnostic sequence first considers radio data system category filtering. If the radio scans only for a selected genre, it may continue scanning because no matching station is available. That behavior can resemble poor reception without demonstrating an antenna defect.

Ford also compares reception with the engine running and stopped. Interference limited to engine operation leads toward grounding, noise suppression, charging or ignition checks rather than immediate antenna replacement.

## Follow the Fusion antenna architecture

In the Fusion, the ACM powers the antenna's AM amplification function. The published test checks for more than 10 volts on the enable supply, then separates wiring, antenna and cable faults. The rear-window antenna-module branch elsewhere on the page belongs to the MKZ and is not the Ford branch.

A replacement antenna cable can be temporarily routed for comparison before the original is removed, helping establish whether the cable is responsible. ACM connector inspection is reserved for the later stages. Successful verification combines acceptable reception under the original conditions with a repeat self-test, rather than assuming that any momentary improvement proves the radio itself was faulty.

# C1705: the center parking-sensor voltage fault with a location-label caveat

Ford titles C1705 Rear Center Sensor Circuit Short to Vbat. Its setting description then calls the location left rear center. Because those labels are not identical, the exact physical sensor and connector must be confirmed against the vehicle's parking-aid layout before a part is disconnected or replaced.

## The electrical condition is clear

The PAM sets this continuous and on-demand code when the relevant sensor signal line is shorted to voltage. This is separate from the normal reference supply used to operate the sensors. It is also distinct from an open or a grounded signal, which use a different diagnostic branch.

Ford checks the overall code pattern first. Multiple affected sensors justify inspecting the bumper harness for shared damage; the isolated signal circuit is then measured with both sensor and PAM disconnected as specified.

## Keep two source uncertainties separate

The location wording requires diagram verification. Independently, the later known-good-sensor substitution step has counterintuitive repair branches that require confirmation from corrected service information. Neither problem changes the explicit short-to-voltage setting description, but both limit how the published page should be used for a repair decision.

The final stages include PAM terminal inspection if the fault pattern reaches that branch. Verification should establish the correct sensor identity, remove the unwanted voltage source and confirm normal parking-aid response. Replacing whichever bumper sensor appears most central is not an adequate substitute for that identification.

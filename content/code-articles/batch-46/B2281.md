# B2281: a grounded right-turn request can keep the indicators flashing

A right indicator that continues flashing can be a request-circuit problem rather than a failed lamp. Ford B2281 records a grounded right-turn input at the Fusion Smart Junction Box. The switch normally grounds that input only when the right-turn position is selected.

## Separate the request from the output

The junction box supplies the lamps after interpreting the multifunction-switch request. Ford's test therefore disconnects the switch and observes whether the unwanted flashing continues. If the behavior stops, the switch branch is relevant. If it continues, the investigation moves to the request wiring instead of immediately replacing the lamps.

The right-hand path is identified as CLS41 in this procedure. With the SJB isolated, the specified request circuit should measure more than 10,000 ohms to ground. That test concerns the input harness, not the resistance of a turn-signal bulb.

## Confirm the reported side

B2282 describes the corresponding left-turn input and uses a different circuit. Record the actual side, whether the stalk is centered and whether the fault is repeatable before the code is cleared. Ford examines the SJB connector for poor contact or corrosion before its final module branch. Reliable turn indications are needed to communicate driving intentions, so a persistent unintended signal should be repaired and its normal switching verified rather than hidden by removing a lamp.

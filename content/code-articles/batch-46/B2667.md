# B2667: why a liftglass code can refer to a Fusion trunk switch

A Fusion sedan does not acquire a liftglass because a scan tool displays B2667. Ford retains the label Liftglass Release Switch Circuit Failure while using this procedure to diagnose the luggage compartment lid release. The relevant hardware is the trunk release switch, its wiring and the Smart Junction Box input.

## A request that stays active

The SJB accepts a release request and briefly supplies the latch actuator. B2667 can result when the switch input is grounded or the request remains active for more than two minutes. This is different from proving that the latch motor itself has failed.

The distinction helps when the trunk opens from one authorized control but not another. A working release path provides useful evidence about the actuator, while a continuously asserted input points toward the switch side of the system.

## Follow the command through the system

Ford first checks related door-lock operation and uses an SJB active command to separate an input problem from an output or latch problem. Subsequent measurements examine the switch ground, signal continuity and release output as directed by the wiring diagram.

Because latch power is momentary, a meter reading taken after the command has ended cannot establish a missing output. Record the fault and reproduce the request before replacing parts. A successful repair should restore normal release from the affected control without leaving the switch input continuously active.

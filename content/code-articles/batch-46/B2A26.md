# B2A26: a keypad button circuit can remain grounded without being pressed

The Fusion entry keypad communicates button presses through individual or combined grounded inputs. The Smart Junction Box interprets that pattern to identify the selected button. B2A26 indicates an unwanted ground on one of those keypad input circuits during the on-demand test.

## Distinguish a stuck input from an incorrect entry attempt

Ford first confirms correct keypad operation before treating the complaint as an electrical failure. With B2A26 present, the procedure disconnects the keypad and repeats the self-test. A fault that disappears follows the keypad branch; one that persists leads to harness grounding checks.

The procedure also uses a keypad-state PID to compare reported button activity with actual presses. This provides evidence about the command reaching the module, separate from whether the lock actuator moves.

## Keep the input, ground and illumination circuits separate

A keypad has dedicated grounding and separate illumination functions. A dark keypad or an inoperative lock therefore does not, on its own, identify which circuit failed. Ford checks opens and unwanted contact between input wires before the final SJB inspection. A technician should preserve the original code and note whether one button, a combination or all keypad commands fail. The repair should restore accurate button recognition and normal authorized lock operation, rather than simply suppressing the code or changing a user entry setting.

# B1D78: an open audio-jack circuit on the navigation system without SYNC

B1D78:13 identifies an open auxiliary audio input circuit in a specific configuration: the navigation audio control module on a vehicle without SYNC. Ford says the open must be detected for more than 250 milliseconds before the code is stored in continuous memory.

## Identify the actual signal route

Without SYNC, the audio input jack feeds the ACM directly. With SYNC, the jack instead feeds the accessory protocol interface module before audio reaches the ACM. The broader symptom test covers both arrangements, but that does not expand the stated B1D78 setting condition to every SYNC vehicle.

The jack has no separate external power or ground circuits. Treating it like a powered USB socket would therefore send diagnosis in the wrong direction.

## Prove the source device works

Ford begins with a multimedia interface tester to distinguish the vehicle input from a faulty player or unsuitable connection. It then isolates the jack circuits to check for unintended voltage, continuity and ground shorts. Under the specified disconnected conditions, conductor continuity is below 5 ohms and ground isolation exceeds 10,000 ohms.

Only after the circuits pass does the procedure substitute a known-good audio jack and consider the receiving module. Connector inspection remains part of that decision. Verification should use a dependable audio source and confirm playback through the auxiliary input, while recording the exact equipment configuration and whether the original code returns.

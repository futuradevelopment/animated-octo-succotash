# B1299: a shared parking-sensor supply can disable several readings

When several rear parking sensors stop reporting together, B1299 directs attention to their shared supply. The Fusion Parking Aid Module supplies sensor reference voltage and signal return, while each sensor has its own signal input. A fault on the common supply can therefore look broader than one damaged sensor.

## Separate a sensor fault from a harness fault

Ford defines B1299 as the sensor supply being shorted to ground or to the signal-return circuit. The procedure begins with bumper-harness inspection, including damage and corrosion. It then isolates the left outer, right outer and center sensors in sequence, checking whether B1299 returns after each disconnection and self-test.

This is a useful diagnostic distinction: a sensor can internally pull down the shared circuit, but the harness can produce the same code. Replacing the module solely because multiple sensors fail would skip that distinction.

## What the electrical checks establish

With the relevant components isolated, the supply-to-ground and supply-to-return checks each use a greater-than-10,000-ohm criterion. Those are resistance checks of the specified disconnected circuits, not a sensor operating-voltage specification. Only after these branches does Ford inspect the PAM connector and consider module replacement if the concern persists. Until the system has been verified, a silent parking aid should not be treated as evidence that the space behind the vehicle is clear.

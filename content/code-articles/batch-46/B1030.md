# B1030: a driver heated-seat control fault is not automatically a failed mat

The HVAC module records B1030 when the driver heated-seat control circuit has an electrical fault. Suffix :12 identifies a short to voltage; :14 covers a short to ground or an open. These definitions concern the command connection to the heated seat module, rather than directly declaring the cushion heater mat defective.

## Separate a command from heat production

The HVAC module requests operation with a momentary ground signal. The heated seat module supplies the mats and monitors their temperature sensor. An open temperature-sensor circuit can disable heat, but that symptom alone does not establish the B1030 control-circuit fault.

Ford compares passenger-seat operation, checks indicator behavior and follows switch data through the applicable control modules. Navigation equipment adds the front controls interface module to that communication path.

## Test under the correct conditions

The control-line checks distinguish unintended voltage, continuity and unwanted grounding. The broader symptom procedure then examines mat resistance and temperature-sensor wiring. Ford cautions that a surface thermometer is not an accurate substitute for its specified electrical tests and that normal warming takes time.

Some source steps unexpectedly label the front cushion as rear, so component references require verification and this draft retains a review flag. Seat work also involves side-airbag precautions. A qualified technician should complete restraint-system restoration before returning the vehicle. The final check should confirm the driver's control command and actual heat response, not merely an illuminated button.

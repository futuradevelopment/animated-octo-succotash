# B19A2: a backrest blower-control fault can shut off the passenger seat

A passenger climate-controlled seat can stop operating because of a problem confined to the backrest blower command. Ford B19A2 identifies that circuit, rather than the cushion's corresponding speed wire. The module disables the passenger seat when the command path is shorted to voltage.

## Use the backrest circuit identity

In the cited Fusion configuration, the backrest control path is VHS21 and the assembly connector is C3311. Ford first checks for unwanted voltage with the seat module isolated, then removes the backrest assembly from the circuit. Voltage still present after that second isolation directs attention to the wiring.

A separate resistance check looks for contact between the control path and the blower feed. Passing a ground-isolation test alone would not answer that question. The procedure expects more than 10,000 ohms between those specified disconnected circuits.

## Do not treat the code as a generic seat-motor failure

The remaining component test checks internal isolation between two designated TED terminals, with a greater-than-two-megohm criterion. It concerns the thermoelectric blower assembly, not the electric motors that adjust seat position. A powered seat track may therefore work normally while heating and cooling remain unavailable. Service around these connectors must follow the seat-airbag safety procedure and avoid spreading module terminals with probes. The final test should restore the climate function, not merely movement of the seat.

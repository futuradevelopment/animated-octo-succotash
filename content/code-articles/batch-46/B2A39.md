# B2A39: puddle lamps staying on require an output-circuit check

Ford's Fusion puddle lamps can be requested by opening a door, the interior dimmer control, a valid keypad unlock or an authorized remote unlock. A lamp remaining on therefore needs its request conditions checked before the output circuit is blamed.

## Separate a shared lighting request from a local supply

The B2A39 procedure first asks whether interior courtesy lamps are also illuminated. If they are, the diagnosis moves to the courtesy-lighting test. If they are not, Ford isolates the SJB puddle-lamp output and checks whether the puddle lamps remain lit.

A lamp that still illuminates with that output disconnected supports an unwanted voltage source in the harness. One that goes out leads to junction-box connector checks before module replacement. This distinction avoids treating every persistent puddle light as an internally failed SJB.

## Retain the source's definition conflict

The short label says the puddle-lamp output circuit is open, while the same page defines the code as a short-to-voltage finding. That inconsistency remains flagged for review, and the article describes the actual test context rather than correcting the label without evidence. Record which courtesy and exterior-entry lights remain on and whether all doors are closed. Verification should include the normal entry-light requests and their cancellation, not simply clearing the code or temporarily disconnecting a lamp.

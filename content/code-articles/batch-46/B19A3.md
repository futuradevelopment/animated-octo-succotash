# B19A3: the driver cushion blower signal must be isolated from its power feed

B19A3 points to the driver's cushion blower speed signal in the Fusion climate-controlled seat. The seat module normally supplies the blower's power and sends a distinct voltage signal to set its speed. A short to voltage on that control path makes the module disable the driver-seat system.

## Why a supply check alone is incomplete

A blower can have a valid power feed while its command wire is electrically wrong. Ford's test therefore examines VHS18 independently. It checks unwanted voltage with the controller disconnected, repeats after disconnecting the cushion TED, and then checks separation between the command circuit and the blower feed.

The distinction between harness-side and component-side measurements is important. Voltage remaining on the isolated harness supports a wiring repair; a failing internal-isolation measurement supports a different branch. The factory sequence avoids substituting one observation for the other.

## Verify the correct assembly and safe access

The cushion TED identified here is C3300, not the backrest assembly. Ford's component isolation test expects more than two million ohms between its specified terminals, whereas the harness-to-feed isolation check uses more than 10,000 ohms. Neither is a temperature target or a universal motor resistance. The procedure requires restraint-system precautions around both front-seat airbag connections. Have the technician verify the failed control path before replacing a seat module merely because the complete driver climate function has stopped.

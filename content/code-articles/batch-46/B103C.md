# B103C: an open driver TED circuit does not always stop the seat controller

Ford B103C can be recorded while the climate-seat module continues operating. The Fusion monitor describes an open, disconnected or greater-than-90-kilohm load in the driver cushion or backrest TED circuit. That differs from overcurrent faults that explicitly shut down the seat.

## Check the circuit before the device

The factory sequence isolates the cushion, backrest and module, then checks the relevant harness paths for continuity. It separately looks for unwanted voltage before measuring the TED assemblies themselves. This order helps distinguish a disconnected harness from an open thermoelectric element.

The component check uses a 0.9–10-ohm range for the specified TED terminals. That service measurement is not the same as the monitor's greater-than-90-kilohm fault criterion; one describes the expected isolated component, while the other describes what the controller recognizes as an open load.

## Verify the duplicated connector label

Step X3 lists C3310 for both the backrest and cushion even though the earlier disconnection list distinguishes them. That source inconsistency remains flagged, so the duplicated label is not used here as a probing instruction. The correct factory diagram must establish component identity. Under-seat tests also require restraint-system depowering and careful terminal handling. Note which part of the seat still responds in heating or cooling; continued controller activity does not establish that both TED circuits are intact.

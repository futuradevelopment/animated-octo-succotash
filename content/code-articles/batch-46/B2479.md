# B2479: when the warning input still reports an applied parking brake

B2479 concerns the parking-brake warning switch input to the Smart Junction Box. The switch normally grounds that input when the parking brake is applied. A ground that remains when it is released can therefore make the electrical status disagree with the brake's actual position.

## The red brake lamp has other inputs

The instrument cluster also receives brake-fluid and ABS-related information. The SJB transmits switch status over the medium-speed network, while ABS brake-distribution information uses the high-speed network. A permanently illuminated brake warning must therefore be assessed as a brake-system complaint, not dismissed solely because B2479 appears.

Ford's procedure checks cluster lamp control and relevant cluster and ABS codes before concentrating on the parking-brake input.

## Compare status with the physical control

The PRK_BRAKE data item is observed while the parking brake is applied and released. If its state disagrees, disconnecting the switch under the specified test conditions helps separate a stuck switch from a grounded wire. The isolated signal circuit is then checked for more than 10,000 ohms to ground.

If wiring passes, SJB connector inspection precedes a module decision. These tests do not certify the mechanical brake or hydraulic system as safe. Persistent warning, low fluid or abnormal braking requires professional assessment before further driving. Repair confirmation should show correct switch status and warning behavior while also resolving any other brake-related faults recorded during the investigation.

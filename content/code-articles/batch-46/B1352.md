# B1352: a missing key-reminder chime can begin at the ignition switch input

The key-reminder chime depends on several pieces of information. In the Fusion, the SJB receives a hardwired key-in signal and driver-door status, then requests the instrument cluster's chime over medium-speed CAN. B1352 concerns the key-in input rather than the sounder alone.

## Check whether the cluster can sound a warning

Ford first checks another chime function and the driver-door message. These observations separate a cluster that cannot make the expected warning from one that lacks the correct request. The key-in switch is part of the ignition switch and supplies voltage to the SJB when a key is inserted.

The code sets for an open key-in circuit or when the SJB sees other ignition states without the expected key-in input. A working ignition switch in one function therefore does not establish that its key-reminder contact is working.

## Use the recorded code to narrow the circuit

With B1352 recorded, the procedure tests the ignition switch before deciding between the switch and an open input wire. It does not begin by replacing the instrument cluster simply because the chime is absent. Note whether the door warning is correct and whether other audible warnings operate. This information helps a technician follow the signal from the switch, through the SJB and network, to the cluster, then confirm the restored reminder under its normal conditions.

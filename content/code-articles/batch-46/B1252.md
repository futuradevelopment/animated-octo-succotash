# B1252: distinguishing USB overload from an incompatible media device

B1252 is a USB-port fault in the Fusion SYNC system. Suffix :04 is described as System Internal Failure but specifically means the APIM detected a USB over-temperature condition. Suffix :11 means Circuit Short to Ground and is associated with detected over-current. Either can originate in the cable and port or the connected device.

## Start with a controlled device comparison

Ford tests playback with its multimedia interface tester before assigning a vehicle fault. A customer's device failing while that reference device works redirects the investigation toward the device or its use. Charging support and audio compatibility are separate questions.

The system does not automatically select USB merely because a device is connected, and the manual excludes DRM-protected audio from mass-storage playback. Those operating characteristics should not be mistaken for proof of an electrical overload.

## Separate the USB path from the APIM

The procedure inspects and reseats the USB connection, then compares USB, auxiliary audio and Bluetooth behavior. If only USB fails, the cable and port assembly is isolated before condemning the APIM. Ford treats that cable and port as one service assembly.

A prescribed master reset erases paired devices, phone history and preferences, so its consequences should be explained before service. Module connector inspection and initialization remain part of the final checks. A completed repair should restore the affected input with a suitable test device and establish whether the original customer device also operates correctly.

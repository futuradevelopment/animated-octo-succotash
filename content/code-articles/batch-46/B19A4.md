# B19A4: a backrest command-wire fault behind driver-seat shutdown

The driver climate-controlled seat can be disabled even when its cushion blower is not the source of the fault. B19A4 identifies the backrest blower command circuit. Ford's Fusion description ties shutdown to that circuit being shorted to voltage.

## Separate the control wire from the shared feed

The relevant backrest speed path is VHS16, while the blower feed is CHS03. The test checks the speed path first with the controller isolated, then with the backrest TED disconnected. This provides evidence about whether the unwanted voltage remains in the harness or involves the assembly.

The next check asks whether the command and feed circuits are shorted together. Ford specifies more than 10,000 ohms between those isolated paths. A clear result to chassis ground alone would not establish this separation, because an inter-wire short has a different destination.

## Match the measurement to its purpose

The final internal-isolation check at the backrest TED uses a much higher, two-megohm boundary. It should not be compared with a winding or heating-element specification from another seat system. This assembly combines thermoelectric and blower functions, so the code is not a generic electric-seat adjustment fault. Diagnosis requires the prescribed airbag depowering process and careful connector probing. Record which climate mode was selected when the driver seat stopped, then confirm the repaired system actually operates after its fault memory is cleared.

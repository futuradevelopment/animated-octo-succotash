# B1B71: test the evaporator-temperature circuit before dismantling the dashboard

The evaporator discharge-air temperature sensor is difficult to reach on the Fusion described by Ford's B1B71 procedure. The manual specifically says instrument-panel removal is needed to disconnect it. That makes the preliminary circuit checks consequential rather than a formality before replacing a sensor.

## Use the suffix to choose the electrical problem

B1B71:11 represents a reference circuit pulled excessively low; :15 represents an open circuit or unwanted voltage. The HVAC module supplies a reference through VH406 and uses RH111 as the return. Ford first measures the sensor-and-wiring resistance from the appropriate module connector and compares it with the temperature table.

The resulting branch separates a grounded reference from unwanted voltage, or an internal sensor fault from a wiring defect. Before the steps requiring sensor disconnection, the manual explicitly calls for visible harness inspection for the relevant short or open. That inspection can identify a repairable problem without assuming the inaccessible sensor itself is defective.

## Equipment and isolation are part of the test

Electronic manual and dual automatic climate systems use different module connectors in this procedure. The continuity branches divide the harness at an intermediate connection before condemning the sensor. A technician therefore needs the installed control type and full suffix, along with the matching wiring diagram. Dashboard disassembly and a sensor replacement should follow that evidence, not simply the presence of the base code.

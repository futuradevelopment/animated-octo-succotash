# C1703: checking the right rear parking sensor's electrical path

C1703 directs the Fusion parking-aid diagnosis to the right rear sensor. Although the label includes blockage, Ford's setting description for this code is electrical: an open in a sensor circuit or a signal wire shorted to ground. Dirt on the bumper is not sufficient evidence to explain that circuit finding.

## Let the other codes guide the starting point

The parking aid module supplies sensor reference voltage and signal return while monitoring an individual input from each sensor. If several sensor codes appear together, Ford first inspects the bumper harness for damage, grounds and corrosion. A shared harness problem deserves attention before multiple sensors are ordered.

An isolated C1703 instead directs the technician toward the right rear sensor's circuits. The connector identity must come from the applicable vehicle diagram.

## Separate wiring from the sensor

With the sensor and module disconnected as specified, the procedure expects less than 5 ohms through the relevant conductors and more than 10,000 ohms for the ground-isolation test. Those are disconnected-circuit checks, not operating sensor values.

If the electrical path passes, the subsequent branch considers the sensor; if every sensor has reported faults, module connector and operation checks also become relevant. A cleared code is only part of verification. Confirm correct parking-aid response after repair and continue to look around the vehicle when reversing, because an electrical self-test does not make the system a substitute for observation.

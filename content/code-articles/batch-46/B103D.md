# B103D: driver-seat blower load can overheat its electronic output stage

The overtemperature in B103D concerns the electronic driver supplying the seat blower circuit. Ford's Fusion description says grounding or excessive current in that output path can overheat the climate-seat module, which then disables the driver seat. It is not a direct measurement of the occupant-facing upholstery.

## Isolate the load that the controller sees

Ford first checks the blower feed for grounding with the module, cushion and backrest assemblies disconnected. It then checks for a short between the feed and return. Each isolation test uses a greater-than-10,000-ohm criterion in the documented setup.

Only after those wiring checks does the procedure measure the cushion and backrest blower assemblies separately. The stated range is 4,000–10,000 ohms, with the meter's positive and negative leads placed in a specified orientation. The manual warns that reversed polarity can give a misleading reading and condemn the wrong part.

## A stopped seat is a protection response

Because shutdown protects the output stage, the symptom does not prove the module was the first component to fail. Leaving an overloaded circuit in place can defeat a parts-only repair. The procedure intersects both front-seat side-airbag connections and requires the appropriate depowering process. Document whether the failure occurs immediately or after a period of climate operation, then verify the corrected blower circuits and system behavior before returning the seat to service.

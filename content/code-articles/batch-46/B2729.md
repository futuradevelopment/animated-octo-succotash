# B2729: driver cushion temperature diagnosis starts with airflow

A driver climate-seat shutdown with B2729 warrants an airflow inspection before a controller is ordered. Ford's Fusion procedure begins with the TED blower area and its filter because conditioned air must pass through a manifold beneath the cushion surface. A restriction can undermine that heat-transfer path.

## Compare the cushion with the backrest

The source specifies sustained TED temperatures above 85°C in heating or above 70°C in cooling, lasting more than 34 seconds. It also lists a disconnected TED or blocked duct. These describe the device monitor, not a comfortable or safe seat-surface temperature.

Ford observes cushion and backrest temperature PIDs while the system runs. A cushion temperature that climbs disproportionately while operation continues sends diagnosis toward TED installation and a crushed or restricted manifold. A seat that does not operate follows thermistor and blower-wiring checks instead.

## A temperature code can have an electrical explanation

The electrical branch tests the thermistor signal for grounding or contact with its return, then checks blower supply, return and speed-control continuity. This prevents a false temperature observation or absent airflow from being treated as proof of a defective controller. Seat trim and wiring work must respect the installed side-airbag system. Record whether the problem occurs in heating, cooling or during a mode change, then verify both temperature behavior and the repeat self-test after repair.

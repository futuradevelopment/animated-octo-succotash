# C1743: unwanted voltage on the Fusion parking-aid speaker wiring

C1743 identifies a different electrical failure from the open-circuit sounder code C1742. In the Fusion parking-aid test, C1743 means voltage is reaching the warning-speaker circuit where it should not. The speaker and module still need to be separated from the wiring before that conclusion can be localized.

## Follow the voltage branch

Ford first deals with any other parking-aid codes and measures the disconnected speaker. The stated acceptable speaker resistance is 40–60 ohms. If it passes and C1743 was recorded, the procedure follows its short-to-voltage branch rather than the open and ground checks used for C1742.

That branch tests both specified sounder conductors for unwanted voltage with the circuit isolated as directed. Any detected voltage sends diagnosis toward repairing the affected wire. A powered-harness fault can therefore remain even when the speaker's own resistance is satisfactory; changing the sounder would not remove that unwanted supply.

## Confirm the warning function after repair

If the electrical checks pass, the factory sequence examines the Parking Aid Module connection for corrosion, damaged terminals and poor seating before considering replacement. The sounder's job is to change warning rate as distance decreases. Clearing C1743 confirms neither that every sensor reports distance correctly nor that the warning can be heard. The final operation check must demonstrate the restored warning behavior, with the vehicle safely controlled and obstacles assessed directly.

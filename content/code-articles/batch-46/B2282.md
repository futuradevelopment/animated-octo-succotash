# B2282: the left indicator request can remain active without the stalk being selected

B2282 identifies the left-turn command input in Ford's Fusion indicator system. The Smart Junction Box sends a voltage signal to the multifunction switch, which grounds it when a left turn is requested. An unintended ground can imitate that request and keep the lamps flashing.

## Observe what changes when the switch is isolated

The factory procedure uses the response to switch disconnection to separate the switch from the remaining circuit. Continued flashing directs attention to the harness and SJB; cessation follows the switch-replacement branch. That observation is more informative than replacing bulbs merely because they are involved in the visible symptom.

For the isolated left-turn path, identified as CLS39, the test expects greater than 10,000 ohms to ground. This is a harness-isolation criterion. It must not be applied across a connected electronic module or treated as a bulb specification.

## Preserve the input-versus-output distinction

The SJB interprets the request before powering the lamps. A fault in that request path can therefore affect normal-looking lamps without an internal lamp defect. The matching right-turn code is different, so keep the side and complete code record together. Ford's last checks inspect junction-box terminals and connector seating before considering the module itself. After repair, verify cancellation, left and right selection and the absence of unintended flashing so the signaling function is restored.

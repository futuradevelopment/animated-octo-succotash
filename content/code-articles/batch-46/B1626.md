# B1626: a grounded keypad-lighting output is separate from a stuck button input

Ford B1626 points to the output that lights the entry keypad. It is different from a keypad input code: the buttons may still be recognized while their illumination circuit is grounded. The Fusion manual treats these as separate functions rather than a single all-or-nothing keypad failure.

## Repeat the test with the keypad isolated

The first check establishes whether the keypad can operate the door locks. When B1626 is recorded, Ford disconnects the keypad, clears the fault and repeats the SJB test. A returning code directs attention to the harness; a disappearing code follows the keypad component branch.

The isolated illumination wire, identified as CPK28 in the cited configuration, must show greater than 10,000 ohms to ground in the specified test. That value applies to the harness with the relevant module connection removed, not across an assembled LED circuit.

## Check the light without losing the original evidence

Other branches in the same source cover an open feed, unwanted voltage and the separate LED ground. They should not be selected merely because the lamp is dark; the recorded fault and isolation result choose the route. Save the initial DTC set before disconnecting components so induced faults are distinguishable. After repair, verify that keypad lighting responds normally to use and turns off appropriately, while confirming the lock-control function continues to operate.

# B2103: the signal-strength evidence behind an antenna-not-connected label

The B2103 label says Antenna Not Connected, but Ford defines the setting condition as signal strength below a preconfigured threshold during self-test. That distinction matters: the code is evidence of inadequate received signal, not visual confirmation that someone has unplugged the antenna.

## Confirm the audio configuration

This particular code applies to base and mid-level sound systems. The same reception procedure also discusses another antenna code and different hardware on related models. Its Lincoln rear-window antenna module should not be assumed to exist on the Fusion being diagnosed.

For the Ford branch, the antenna passes AM and FM signals through the cable to the audio control module. The ACM also supplies power for AM amplification. An interrupted enable circuit can therefore affect reception even with the main antenna cable physically attached.

## Use comparisons before condemning the radio

The procedure checks station-category settings and compares engine-on with engine-off reception. Engine-dependent noise sends the investigation toward suppression equipment and electrical-system interference. Persistent poor reception leads to antenna power, wiring, antenna and cable isolation.

A known-good cable can be routed temporarily to test the cable hypothesis before dismantling the original installation. The ACM is considered only after the appropriate checks, including its connectors. Repeating the self-test and reproducing the original reception conditions provides stronger confirmation than clearing B2103 alone or replacing a radio because of the code's wording.

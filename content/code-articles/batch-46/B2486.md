# B2486: both climate seats can pause when their module supply leaves range

B2486 can explain simultaneous loss of both climate-controlled seats without proving that either TED assembly failed. Ford says the Dual Climate Controlled Seat Module records this code when its input drops below 10 volts or rises above 15 volts. The module enters standby and suspends both seats.

## Restoring voltage is part of recovery

The source describes operation resuming after supply returns to the 10–15-volt range and a climate-seat button is selected. This makes battery and charging history relevant, particularly when the complaint appeared during a low-voltage event or charging work.

The diagnostic order checks other modules for related faults, tests battery condition, and compares charging behavior under load and without load. It then examines the module's own feed and ground rather than assuming a good battery reading proves every connection is sound.

## A final code-reference mismatch remains unresolved

The closing module test asks whether B1317 or B1318 remains present, although the procedure heading and monitor describe B2486. That cross-reference is retained as a review limitation. It should be verified against the current factory information before using the branch to justify module replacement. The under-seat supply checks also intersect a side-airbag connection and require the prescribed restraint process. Record whether both seats recover together as supply stabilizes; this is useful evidence distinct from clearing the stored fault.

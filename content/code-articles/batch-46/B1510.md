# B1510: a persistent flash-to-pass request can hold the high beams on

B1510 refers to the flash-to-pass request, not directly to a high-beam bulb. In the Fusion circuit, the multifunction switch grounds an input to the Smart Junction Box when flash-to-pass is selected. An unwanted ground can imitate that command and keep the high beams illuminated.

## Separate the two stalk requests

Ford distinguishes B1510 from B2A23, which names the normal high-beam input. Both lead into a shared symptom procedure, but the request circuits remain separate. A scan record retaining the exact code helps the technician select the correct input rather than assuming every stalk-related lighting fault is the same.

The procedure disconnects the multifunction switch and observes the lamps. Continued illumination leads to isolated input-circuit checks; if the unwanted behavior stops, the switch branch is relevant. The specified harness checks use greater than 10,000 ohms to ground.

## Lamp behavior also depends on the application

Ford's source includes a separate Milan shutter arrangement, while the Fusion has its own output-circuit branch. Those differences matter when interpreting a lamp that stays on after a connector is removed. A Fusion diagnosis should use its matching branch and wiring diagram. The final SJB decision follows connector inspection and repeat testing. Restore proper high-beam and flash-to-pass control before normal driving so an unintended bright-beam command does not dazzle other road users.

# B2071: a stuck hazard request is different from a failed flasher output

The Fusion hazard switch is a momentary request device. The Smart Junction Box supplies a signal to it and interprets a grounded input as a request for hazard flashing. B2071 records an unwanted ground on that input during the on-demand test.

## Test the request before the lamps

With B2071 present, Ford disconnects the hazard switch and repeats the SJB self-test. If the code disappears, the switch branch is indicated. If it remains, the procedure isolates the SJB and checks the request wire for grounding, using a greater-than-10,000-ohm criterion.

The important separation is between the small command circuit and the circuits that power the lamps. All hazard lamps can behave incorrectly because the module is receiving a false request, even though the bulbs and their output wiring still work.

## Use the Fusion equipment branch

The same workshop page includes an MKZ arrangement with the switch integrated into the Front Controls Interface Module. That component-replacement instruction does not apply automatically to a Fusion's separate hazard switch. The cited B2071 branch identifies Fusion connector C2039 and checks the request path before the final junction-box inspection. Record whether the lamps are continuously commanded, completely unavailable or intermittently unresponsive. The repaired system should pass its self-test and operate correctly from the switch, because hazard signaling is a functional check beyond clearing a stored code.

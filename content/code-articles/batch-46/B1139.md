# B1139: separating an unrecognized remote identity from a weak key battery

The remote functions in this Fusion depend on the Smart Junction Box recognizing an integrated keyhead transmitter, or IKT. B1139 means the received transmitter identification code is invalid for that system. It does not, by itself, establish that the radio receiver or key battery has failed.

## Reception and recognition are different

Ford uses scan-tool data for the last transmitter identity and transmitted command to establish whether the SJB receives a button press. Comparing the received identity with stored transmitter information then addresses recognition. This separates a silent transmitter from one that is heard but is not accepted.

A compatible, known-good transmitter is useful for comparison. The workshop procedure also considers interference from aftermarket equipment and requires the correct customer transmitters during programming diagnosis.

## Avoid erasing useful evidence

A weak or removed transmitter battery does not erase its identification memory. Consequently, replacing a battery is not automatically a reason to program every key again. Battery condition should be checked as its own issue before changing stored transmitter information.

B2425 describes rolling-counter synchronization, while other module-specific remote codes describe different programming or identity faults. Record the reporting module and companion codes rather than treating all remote complaints as B1139. Authorized programming and an inspection of SJB connectors belong in the appropriate diagnostic branches. Confirm operation with the customer's legitimate transmitters after the identified fault has been repaired.

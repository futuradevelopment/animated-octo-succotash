# U2013: a navigation control-panel timeout caused by an active switch

U2013:63 means Switch Pack: Circuit / Component Protection Time-Out in the navigation FCIM covered here. Despite its U prefix, the defined trigger is a switch that stays active too long. It is not simply another name for lost communication with the radio.

## The timeout protects a specific input

Ford sets the code if a switch remains active beyond three seconds during self-test or two minutes during ordinary operation. The FCIM disables that switch until it detects that the input has been released. A button can consequently stop responding while other audio controls still operate.

For the Fusion, this definition is limited to the navigation FCIM. The source's additional non-navigation application belongs to the MKZ, while a non-navigation Fusion uses B2924 for the described stuck-button condition.

## Separate network faults from the switch fault

The procedure begins with relevant continuous communication codes. It then clears FCIM codes and repeats the self-test with every front-panel button released. A recurring U2013:63 under those controlled conditions supports the panel replacement branch rather than an assumption based on a single historical event.

If the code does not recur, connector inspection and reproduction of the complaint remain necessary before replacement. The panel exchanges commands over medium-speed CAN, so normal radio playback alone does not establish healthy panel operation. Final verification should exercise the affected navigation or audio controls and repeat the untouched-button self-test.

# B119F: why navigation can lose GPS while satellite radio still works

A working satellite-radio channel does not prove that the navigation unit receives GPS. In this Ford system, a splitter in the front satellite-radio antenna cable separates the satellite-radio and GPS paths. A defect after that split can affect navigation without silencing the radio service.

## Read the GPS failure suffix

B119F:01 means General Electrical Failure in the GPS antenna circuit. B119F:13 specifically means Circuit Open. The audio control module uses the GPS information to calculate vehicle position and travel direction, so the relevant complaint is the navigation signal path rather than ordinary AM/FM reception.

Ford starts with the satellite signal-strength data item. If it reports No Signal, the procedure redirects to the broader satellite reception test. If satellite reception is present, the GPS-specific code check becomes the next discriminator.

## Confirm a returning fault

The procedure clears ACM codes and performs its self-test before using a returning B119F:01 or :13 to select the front antenna-cable replacement branch. If those codes do not return, it instead examines ACM connectors and verifies whether the navigation concern persists.

That sequence keeps a historical code from becoming the sole reason to buy an audio module. It also explains why replacing the roof antenna without considering the split cable may miss the identified path. After repair, confirm GPS-dependent navigation operation and recheck the module rather than accepting satellite-radio audio as the only proof of success.

# B1578: parking lamps can stay on because the junction box sees a false request

Ford B1578 is associated with the parking-lamp request coming from the headlamp switch. The Fusion Smart Junction Box uses that request to energize its internal parking-lamp relay, supplying the front and rear lamps. A grounded request can therefore keep several lamps on together.

## The presence of the code changes the test path

Ford first checks whether B1578 was recorded. With that code, the procedure examines the switch input and then isolates the request wiring. Without it, the always-on complaint follows an output-circuit voltage-short check. The same visible symptom can thus originate on either side of the junction box.

A disconnected-switch supply check and an isolated harness-to-ground measurement help distinguish the switch from its wiring. The ground-isolation criterion is greater than 10,000 ohms under the factory conditions.

## Confirm the wire identity from the diagram

The source labels the request circuit CLS34 consistently but gives differing color descriptions in a step heading and its measurement text. That mismatch remains flagged for review, and no wire should be selected by that inconsistent color alone. Verify the connector and circuit identifier in the applicable wiring diagram. Record which exterior lamps remain illuminated and whether the headlamp switch position changes them, then verify normal control after the repair rather than merely extinguishing the lamps temporarily.

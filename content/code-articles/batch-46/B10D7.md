# B10D7: when the Fusion reports a key-programming failure

A base-code reading of B10D7 leaves out an important distinction. Ford's Fusion Pinpoint Test I specifically covers B10D7:05, the programming-failure variant. Other suffixes have separate tests and should not be diagnosed from this branch.

## Compare both keys before blaming the vehicle

The procedure describes two possibilities: a problem encountered while programming the integrated keyhead transmitter, or a defective transponder in that key. During starting, the transceiver reads the identification and sends it to the instrument cluster. A fault in this process can leave the vehicle unable to start.

Ford asks for both customer keys and evaluates them individually. If only one exists, the service process requires another correctly cut, compatible encoded key. This comparison helps distinguish a key-specific problem from a result that follows the vehicle regardless of which key is used. An ordinary mechanical copy without the correct transponder capability is not an equivalent test.

## Compatibility and the repeat check matter

The manual warns that unapproved encoded keys may not work consistently across temperature changes. After the appropriate programming procedure, the cluster codes are cleared, the ignition is cycled and the result is checked with each key. A returning :05 result directs attention to the affected key. Different cluster faults lead to their own chart. Record the full code and key history for an authorized technician rather than repeatedly attempting unrelated programming routines.

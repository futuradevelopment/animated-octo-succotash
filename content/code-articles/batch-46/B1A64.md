# B1A64: interpreting a left solar feedback fault within the linked HVAC inputs

Ford defines B1A64:15 as Left Solar Sensor: Circuit Short to Battery or Open. The setting description is higher-than-expected voltage on the left feedback circuit. A short to voltage, an open conductor or an open sensor can therefore produce the reported electrical condition.

## The left input is not diagnosed in isolation

The Edge HVAC module links the short-to-voltage monitoring of both solar inputs with the cabin-temperature input. Ford explicitly says that a voltage short in any one of those paths sets all three related DTCs. A left solar code can therefore be part of a shared diagnostic response even when the originating voltage fault is elsewhere.

This is why the complete climate-module code list should be retained before anything is cleared. The companion pattern helps frame the electrical investigation.

## Let measurements identify the conductor

The procedure checks the cabin-temperature, right solar and left solar feedback wires with the specified connectors disconnected. It looks for unwanted voltage and repairs the circuit that actually fails the test. Selecting the left sensor from the code title alone skips that discrimination.

When no unintended voltage is found, the next branch examines HVAC connector corrosion, damaged pins and displaced terminals, then repeats operation and self-test. Module replacement follows only if the concern persists through that sequence. Verification should resolve the shared code pattern and preserve the distinction between a measured left-channel fault and a code triggered by the linked diagnostics.

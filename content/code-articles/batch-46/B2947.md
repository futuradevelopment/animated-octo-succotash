# B2947: global window opening needs an enabled feature and an intact command circuit

The Fusion global-open feature is optional and configurable. Before diagnosing B2947, Ford requires the feature to be enabled and the one-touch window functions to operate. A disabled setting or an uninitialized motor can explain a complaint without proving a broken command wire.

## Separate configuration from the electrical fault

On the equipped system, a sustained remote unlock request tells the Smart Junction Box to command both front windows downward. The feature does not operate while accessory delay is active. B2947 specifically covers an open global-open circuit or a short to ground, rather than every reason that remote window opening might be unavailable.

The factory B2947 branch isolates both front window motors and the SJB. It checks continuity from the module to each motor, then checks the shared command path against ground. The criteria are less than 5 ohms for the specified continuity paths and greater than 10,000 ohms for isolation.

## Motor initialization is part of restoration

Ford calls for the appropriate de-initialization and initialization after relevant circuit repairs. Clearing B2947 alone therefore does not complete the work. Note whether local one-touch operation works on both sides and whether all authorized remotes behave the same way. Those observations separate a configuration or transmitter issue from a shared wiring failure. Verify window movement safely with the openings clear, following the applicable initialization procedure.

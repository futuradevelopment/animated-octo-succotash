# B2A23: the high-beam switch input can fail while the lamps themselves remain sound

A high-beam lamp staying on does not identify the lamp assembly as the defective component. B2A23 means the Fusion Smart Junction Box detects grounding of the high-beam request input. The switch normally uses that ground signal to request the function.

## Check whether the switch is holding the request

Ford first separates complaints accompanied by B2A23 or the flash-to-pass code from complaints without those input faults. It then disconnects the multifunction switch and observes whether illumination continues. A response that changes when the switch is isolated is different evidence from a lamp that remains powered independently.

The subsequent request-circuit check tests isolation from ground, using greater than 10,000 ohms on the specified disconnected harness paths. This is separate from checking the lamp's power output for unwanted voltage. Mixing the two tests could produce an incorrect module diagnosis.

## Keep the full symptom description

Note whether the unwanted high beam occurs with low beams selected, during flash-to-pass or regardless of switch position. The shared manual also describes another model's shutter-based headlights, so its observations should not be transferred automatically to the Fusion. Ford examines the SJB connector and terminals before the final replacement branch. A successful repair must restore normal driver control of the lights, with both requested illumination and cancellation verified rather than relying on a cleared code alone.

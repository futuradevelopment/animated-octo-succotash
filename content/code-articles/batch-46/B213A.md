# B213A: why a dimmer fault can leave the dashboard at full nighttime brightness

A dashboard stuck at full nighttime brightness can be a deliberate fallback rather than a failed set of lamps. Ford's Fusion procedure says a dim-up, dim-down or dome-lamp request held grounded for longer than 17 seconds causes that fallback. B213A records the associated input-circuit fault.

## The dimmer sends several requests

The first switch detent requests brighter or dimmer illumination. The second also supplies the dome-lamp request, and the SJB needs both relevant inputs to control courtesy lighting from the dimmer. This explains why a fault at one switch can affect more than panel brightness.

Ford repeats the self-test with the dimmer disconnected, then checks the request circuits for unwanted grounding if the fault remains. Other branches evaluate the switch, its signal voltages and the return path before considering the junction box.

## One repair reference needs verification

Step A8 measures the return circuit RLN29 but names CLN27 in its open-circuit repair instruction. That mismatch remains flagged for review; the applicable diagram should resolve the wire identity before repair. The stable diagnostic point is the distinction between a continuously asserted request and missing lamp power. Record whether courtesy-lamp control also behaves incorrectly, then verify both dimming directions and the courtesy function after the electrical concern is corrected.

# B1318: low supply voltage at the Fusion Smart Junction Box

B1318 describes what a reporting module sees, not necessarily the voltage available at the battery posts. In the cited Fusion Smart Junction Box test, the fault threshold is below 10 volts. Other modules can use different criteria, so the reporting module belongs in the diagnosis.

## Compare the supply with the battery

Ford first clears and repeats the SJB self-test, then checks for charging-system faults and assesses battery condition. A previous low-voltage event may no longer be present. If the fault persists with a sound, charged battery, the procedure measures the SJB supply and compares it directly with the battery reading.

The specified supply should be within 0.2 volt of the recorded battery voltage. A larger difference points toward resistance in the supply path, even when a battery test appears acceptable. The sequence separately checks the module grounds, using a less-than-5-ohm criterion under the stated disconnected-battery conditions.

## Preserve the conditions of the original event

Starting difficulties, recent charging work and faults stored in other modules help explain whether B1318 reflects a vehicle-wide event or a local feed problem. The source warns that leaving the battery connected when instructed otherwise can produce false resistance readings. Its final branch examines connector corrosion and terminal condition before considering an SJB. Replacing the junction box before checking these paths would leave a voltage-drop fault unresolved.

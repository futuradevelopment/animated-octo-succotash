# B10D5: an antenna fault does not automatically erase the Fusion's learned keys

Ford's Fusion B10D5:13 procedure focuses on the Passive Anti-Theft System transceiver antenna. The :13 suffix is the circuit-open variant. A scan result with this code does not, by itself, establish that the vehicle has forgotten its authorized keys.

## Installation comes before the replacement decision

The factory test begins by checking that the PATS transceiver is correctly installed. It then clears instrument-cluster faults, cycles the ignition and retrieves the result again. A returning B10D5:13 after that sequence leads to the transceiver replacement branch. If it does not return, the test treats the system as satisfactory at that time.

This short procedure has a narrow scope. It does not supply a resistance specification for an antenna repair, describe an immobilizer bypass or justify replacing the instrument cluster. It is therefore better used to identify the affected part of the authorization system than to infer unrelated security faults.

## Keep antenna service separate from key programming

Ford explicitly notes that replacing this PATS transceiver does not require programming the keys into the instrument cluster again. That distinction matters when estimating what a repair actually involves. A key-programming failure and a transceiver antenna failure have different diagnostic branches. Provide the full B10D5:13 record, any other anti-theft codes and information about recent steering-column or ignition-area work to the servicing technician; confirm operation through the prescribed repeat test.

# C1704: using distance and attenuation data to evaluate the right rear sensor

C1704 concerns the right rear parking sensor's operation. Ford's code-specific description identifies internal sensor failure or an incorrect attenuation time. The procedure therefore uses live sensor behavior as well as the stored fault, rather than treating the words Circuit Fault as proof of a broken wire.

## Remove conditions that distort the test

Other parking-aid DTCs are diagnosed first. The sensor faces and bumper are checked for obstruction, and Ford calls for the azimuth and elevation system checks. If those pass after cleaning, contamination may have been responsible for the concern.

The suspect sensor must also sit flush in its bezel. A displaced sensor or an object in the test area can make distance readings misleading even when the electronics are functioning.

## Interpret the data in its stated setup

With the vehicle secured for the workshop test and the detection area clear, the procedure expects a distance PID of 255 centimetres. It then checks whether attenuation data fall between 0 and 16 milliseconds. These are the procedure's test conditions, not a promise that every real obstacle should produce those readings.

An out-of-range result leads to sensor replacement and retesting before the PAM branch. Module connectors are inspected if the concern persists. These checks should be performed with controlled vehicle movement and professional precautions; a driver should continue using direct observation rather than relying on a parking aid that has recorded a fault.

# B2949: unwanted voltage on the shared front-window global-open signal

B2949 concerns the electrical command shared by the front window motors for global opening. Ford distinguishes it from B2947: B2949 means the Smart Junction Box detects a short to voltage, while B2947 covers an open or grounded command path.

## Use successive isolation to locate the source

The factory voltage-short branch first disconnects the SJB and checks the global-open wire. It then isolates the left front motor, followed by the right, to determine whether the unwanted voltage remains in the harness or disappears with a particular assembly. That sequence avoids assuming that both motors failed because both windows ignore the remote command.

The applicable Fusion circuit is CPW01 in the cited procedure. Its identity matters more than a general assumption that any window wire should carry battery voltage; this check concerns an isolated command path in a specific test configuration.

## Verify the prerequisites after repair

Global opening must be enabled, one-touch functions must work and accessory delay must not be active. Ford also calls for motor initialization after the relevant repair branches. These prerequisites explain why clearing the electrical code may not immediately demonstrate the full feature. Preserve whether the problem affects both front windows and whether local controls still work. A final controlled test should confirm normal local operation and authorized remote opening, with people and objects clear of the window travel.

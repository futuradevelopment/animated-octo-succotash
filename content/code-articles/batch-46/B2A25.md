# B2A25: a door-lock request that stays grounded on the Fusion

B2A25 can arise from the door-lock request circuit rather than from the latch motor. In the Fusion portion of Ford's procedure, the Smart Junction Box supplies voltage signals to both front door switches. Pressing lock or unlock grounds the corresponding request input.

## A held button can resemble a circuit fault

Ford defines B2A25 as an on-demand fault associated with a grounded lock or unlock input. It also notes that holding either door-lock switch for more than two minutes can set it. A stored result therefore needs to be compared with how the switches were being used during testing.

The diagnostic order isolates the passenger switch first, then the driver switch on Fusion and Milan applications, repeating the SJB test. A code that disappears after a particular switch is disconnected has a different implication from one that survives with both switches isolated. The latter leads to wiring checks rather than immediate switch replacement.

## Do not borrow the Lincoln branch

The same source describes an MKZ arrangement with a Driver Door Module and separate driver-switch codes. Those details are not interchangeable with the Fusion's SJB-controlled arrangement. For the relevant isolated Fusion request circuits, Ford uses greater than 10,000 ohms to ground before evaluating the junction-box connection. Record which switch causes abnormal locking and whether the condition persists untouched; that evidence helps identify a stuck request rather than a failed door actuator.

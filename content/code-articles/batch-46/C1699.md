# C1699: unexpected voltage on the left rear parking sensor signal

C1699 is a voltage-short code for the left rear parking-aid signal. The PAM normally provides a sensor reference and return while receiving a separate signal from that sensor. This code concerns unwanted voltage on the signal channel, not simply the presence of the normal sensor supply.

## Isolation gives the voltage reading meaning

Ford disconnects both the suspect sensor and the parking aid module before checking the specified harness circuit with the ignition on. Voltage remaining on that isolated path supports a wiring short. Measuring at a fully connected powered sensor would not reproduce the same diagnostic condition.

When more than one parking code is present, the procedure first checks the bumper harness for damage or corrosion. The number of affected channels can therefore change where the investigation starts.

## A substitution branch needs review

The next published step substitutes a known-good sensor, but its outcome text is counterintuitive: the no-concern branch calls for circuit repair while another branch calls for sensor replacement. That direction must be checked against a corrected procedure before it is used to authorize parts. This article does not silently reverse the printed branches.

The voltage-isolation test and left-channel definition remain clear. Module connector checks appear later if the wider fault pattern warrants them. After an evidence-based repair, repeat the PAM self-test and confirm parking-aid operation while maintaining normal visual checks around the vehicle.

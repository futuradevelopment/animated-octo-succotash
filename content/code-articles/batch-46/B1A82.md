# B1A82: tracing a message-center switch fault through the steering wheel

B1A82 concerns the external trip or message-center switch input to the instrument panel cluster. In the Fusion branch of this manual, the buttons are part of the left steering-wheel switch assembly. The Lincoln branch instead uses different front-control hardware and must not be applied to the Ford.

## Read the failure suffix

The cluster records :11 for a signal circuit short to ground and :13 for an open circuit. Both can leave the message center unresponsive, but they require different electrical evidence. A blank display also needs checking against the intentionally selectable blank display before it is called a failed cluster.

Ford checks a reference near 5 volts and uses switch resistance behavior, circuit isolation and continuity to separate the switch, harness, clockspring and cluster.

## Keep the connector discrepancy visible

Step AU12 prints the same cluster terminal for hybrid and non-hybrid signal checks, although earlier steps distinguish those terminals. This inconsistency requires verification against the correct vehicle wiring diagram before probing; it is not resolved here by choosing a pin number.

Some branches require driver-airbag removal to isolate the steering-wheel wiring and clockspring. Those steps belong with a technician following the restraint-system precautions, not improvised probing around the airbag. After a verified repair, confirm each message-center button and repeat the cluster self-test. Replacing the cluster before resolving the switch path can leave the original fault untouched.

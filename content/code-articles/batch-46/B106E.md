# B106E: why the Fusion junction box can switch an output off

An electrical accessory that stops working with B106E may have lost its supply because the Smart Junction Box deliberately shut down the output. The Fusion procedure describes protection built into the module's solid-state drivers. It does not identify the failed accessory from B106E alone.

## Read the companion circuit fault

The SJB counts repeated overloads against three thresholds. Reaching either of the first two produces B106E together with a code identifying the affected circuit. That companion fault is therefore essential evidence: it directs diagnosis toward the particular output, rather than toward every circuit supplied by the junction box.

Ford requires correction of the underlying electrical fault before another self-test. Clearing the protection code while leaving a short in place can repeat the overload. A replacement module exposed to the same wiring defect can also be damaged. The sequence matters more than simply obtaining an empty fault-code screen.

## Distinguish a resettable shutdown from permanent disablement

Before the final threshold is reached, repairing the circuit, clearing faults and completing the self-test can restore operation. B106F represents the later, permanently disabled state; B106E should not be interpreted as that state automatically. Record all SJB codes and the failed function before disturbing connections. A technician can then verify the repaired circuit and check whether the output resumes its normal operation.

# U2014: the internal satellite receiver fault in a navigation audio module

U2014:96 is not a generic lost-network-message diagnosis in this procedure. Ford calls it Control Module Hardware: Component Internal Failure and associates it with a fault inside the audio control module's satellite-radio receiver. The described result is complete loss of satellite-radio functionality.

## Apply the correct equipment restriction

For the Fusion coverage here, the relevant module is the navigation ACM. The source also mentions a non-navigation application on the MKZ; that separate Lincoln configuration is not a reason to extend the Ford definition to every radio.

A silent satellite service still needs preliminary checks. Ford verifies that satellite information appears on the display, checks subscription status and reads the satellite signal-strength data. An expired subscription or absent antenna signal has its own diagnostic direction.

## Understand the replacement decision

Once the appropriate navigation branch is reached, a present U2014:96 directs replacement of the ACM. Other unresolved satellite complaints proceed through connector inspection and confirmation before that decision. The distinction prevents a service subscription problem from being mistaken for the internal hardware code.

The built-in receiver's electronic serial number is associated with the vehicle when service is activated. Ford consequently warns against simply swapping ACMs between vehicles as a diagnostic shortcut. Any replacement requires the appropriate service and subscription handling. Verification should restore the intended satellite functions and confirm that the hardware fault no longer returns.

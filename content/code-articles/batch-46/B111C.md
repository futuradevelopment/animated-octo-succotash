# B111C: a missing passenger TED load can coexist with partial seat operation

The passenger climate-controlled seat uses separate cushion and backrest thermoelectric assemblies. B111C records an open, disconnected or very high-resistance load in those passenger TED circuits. Ford says the module continues its normal operation while setting this code, so complete shutdown is not a required symptom.

## Preserve which function still works

The procedure's monitor criterion includes sensed resistance above 90 kilohms. It then diagnoses the harness independently: continuity is checked with the assemblies and module isolated, followed by an unwanted-voltage check. This separates electrical connection quality from the TED's own condition.

The specified component test expects 0.9–10 ohms between its designated terminals. A controller reporting an open load and a technician measuring a device directly are different observations; they should be reconciled through the intervening wiring rather than treated as contradictory results.

## One source label must be resolved

The final component step repeats connector C3311 for both the cushion and backrest, while the earlier list distinguishes passenger cushion C3303 from backrest C3311. That discrepancy remains a review limitation. Confirm the actual component and factory diagram before measurement instead of copying the repeated label. The service process includes the passenger side-airbag connection and requires restraint precautions. A useful repair record notes the affected mode, which seat area responds and whether the fault repeats after the harness and component checks.

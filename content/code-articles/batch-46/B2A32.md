# B2A32: an open-circuit label accompanies a voltage-short test for backlighting

B2A32 needs its factory diagnostic explanation alongside the brief label. The Fusion workshop page calls it an LED backlighting output open circuit, yet says it sets when the SJB detects a short to voltage. That conflict is preserved here rather than silently choosing a different definition.

## Follow the actual always-on complaint

The Smart Junction Box normally sends pulse-width-modulated voltage to hardwired dimmable lighting when parking lamps are selected. The duty-controlled output follows the dimmer request. An external voltage supply on that output can leave switch illumination on when it should not be.

Ford first checks exterior-light behavior, because illuminated exterior lamps may indicate a wider request problem. If that branch is excluded, the procedure isolates the SJB output and observes whether the backlit components remain illuminated. Continued light with the output disconnected points toward an unwanted harness supply.

## Confirm the application-specific circuit

The source distinguishes Fusion/Milan wiring from the MKZ's separate circuit. It does not justify applying a Lincoln wire reference to a Fusion. Connector condition is assessed before the final module branch. Because the title and triggering explanation disagree, verify the exact factory revision before interpreting a scan-tool description as a component diagnosis. Record whether all dimmable controls or only one item remains lit, then confirm normal brightness response and switch-off behavior after repair.

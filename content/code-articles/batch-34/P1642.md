# P1642: Jaguar AJ26 CAN circuit fault with all network data unavailable

P1642 identifies a CAN circuit malfunction in Jaguar's 1997 AJ26 summary. The manufacturer describes all CAN data as unavailable and inhibits cruise control when the fault is detected.

## This is broader than one missing message

The adjacent P1638 entry concerns an instrument-cluster message, whereas P1642 describes the broader network condition. Treating both as an instrument-pack failure would discard an important difference in the source.

Jaguar lists a CAN short and control-module failure among the possibilities. It specifically directs the reader to additional recorded codes to help locate the module source. Those companion records are therefore part of the diagnostic evidence, not merely unrelated entries to erase first.

## The affected module is not named by this code alone

The code does not establish whether the initiating defect is in the ECM, another module or the wiring. Cruise inhibition is a documented response and should not automatically be diagnosed as a separate switch or actuator problem.

The monitoring condition is ignition on for more than five seconds, with a one-trip check-engine entry. Use the exact AJ26 network topology and appropriate professional communication tests. The summary does not provide a bus-resistance specification, isolation sequence or replacement instruction. Preserve module identities and the complete fault record before narrowing the cause.

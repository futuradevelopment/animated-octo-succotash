# P1722: Jaguar 5 HP 24 stall-speed failure

P1722 identifies a transmission stall-speed failure in Jaguar's 1997 5 HP 24 summary. The manufacturer lists several ways the observed behavior can become incorrect, including fluid level, range selection, speed information and mechanical trouble.

## The code is not a standalone torque-converter diagnosis

Jaguar includes low transmission oil level, incorrect selector-cable adjustment or installation, an output-speed sensor problem and mechanical transmission failure. The selector-cable entry is especially useful because the intended range and the actual operating state may not agree.

The speed-sensor reference also means the controller's interpretation can be affected by inaccurate speed information. Establishing mechanical failure requires evidence beyond the name “stall speed.”

## The listed response is fifth gear

When the fault is detected, the source specifies electronic limp-home operation in fifth gear and engine-power limitation. This differs from the fourth-gear mechanical fallback used by several neighboring codes. The warning entries are two trips for check engine and an immediate amber gearbox-fault indication.

The service-monitor description includes strong acceleration from a standstill. It is not a public-road test recommendation or a stationary brake-torque procedure. Professional evaluation should follow the applicable transmission instructions and determine whether testing is appropriate. The summary provides no stall-speed specification or permission to hold the vehicle against its brakes.

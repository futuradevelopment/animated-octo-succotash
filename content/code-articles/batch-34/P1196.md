# P1196: Jaguar downstream heater fault and supply-voltage evidence

P1196 identifies the downstream oxygen-heater low-resistance classification in Jaguar's 1995 AJ16 summary. Its cause reference to P1190 introduces an important alternative to a failed sensor heater.

## Check the meaning of the voltage clue

P1190 lists battery voltage above 17 volts producing excessive heater current. Its other possibilities include an ECM-to-heater wire shorted to battery voltage, heater circuits shorted to ground and heater failure. For P1196, those mechanisms apply to the downstream heater group.

The published 17-volt value describes a possible overvoltage cause. It is not a normal charging specification, and the summary does not say it is the complete threshold that sets P1196. That distinction prevents turning a useful diagnostic clue into an unsupported test limit.

## Separate supply trouble from heater trouble

Establishing the electrical supply condition can change how heater-current evidence is interpreted. If the supply or wiring is abnormal, the heater-related code cannot by itself prove an internally defective downstream sensor.

Jaguar lists idle exceeding 25 seconds and two consecutive qualifying trips for the warning. A brief restart is not the same verification interval. Use the exact AJ16 service information for further circuit checks; the summary provides neither a universal heater resistance nor an instruction to replace both downstream sensor assemblies.

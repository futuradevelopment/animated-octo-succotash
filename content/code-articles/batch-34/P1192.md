# P1192: Jaguar downstream heater short and the upstream cross-reference

P1192 identifies a short-circuit fault in the downstream oxygen-sensor heater group on the 1996–1997 Jaguar AJ16 system. The summary uses P1186's cause list to explain the electrical possibilities.

## Two different electrical paths

That referenced list includes a heater circuit shorted to the sensor and heater harness wiring shorted to battery-positive voltage. The first possibility concerns unwanted interaction with the sensor; the second concerns the external supply environment. Neither is established simply by observing an unusual exhaust-mixture reading.

P1192 retains the downstream location even though the referenced P1186 row concerns upstream heaters. Following a reference should transfer the applicable fault mechanisms, not the sensor position. This is particularly important when scanner descriptions omit “downstream” or “both sensors.”

## Evaluate recurrence under the listed condition

Jaguar specifies an idle below 1,000 rpm lasting more than three minutes and twenty seconds, with two consecutive qualifying trips for the check-engine warning. A code that has not immediately returned after clearing has not necessarily been retested.

Confirm the affected heater wiring against the correct vehicle diagram before selecting a repair. The summary does not provide direct-voltage probing instructions, a resistance threshold or evidence that both sensor assemblies require replacement. It provides a bounded electrical diagnosis path for this AJ16 application.

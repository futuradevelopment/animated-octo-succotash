# P1791: Jaguar 4L80-E throttle-position signal to the transmission

P1791 identifies the throttle-position signal in Jaguar's 4L80-E transmission summary for XJ12 and supercharged AJ16 XJR applications. This manufacturer row differs from the catalog's ignition-supply wording, so identifying the transmission is essential.

## The signal travels between controllers

Jaguar lists an open, ground short or battery-voltage short in the ECM-to-TCM throttle signal circuit, along with an erroneous ECM throttle-signal output. The fault therefore concerns information delivered to the transmission controller. It does not directly prove that the pedal sensor, throttle sensor or ignition supply is defective.

A valid throttle value visible in one module does not necessarily establish that the receiving TCM has valid information. The inter-controller path named by the source must remain part of the diagnosis.

## Application-specific warning details

The monitoring condition is ignition on. The row lists two trips for the check-engine warning, one for the transmission warning and no limp-home action. Those details should not be borrowed from the adjacent ZF transmission summaries.

Use the 4L80-E-specific wiring and workshop tests before interpreting the stored code. This article preserves the documented definition and flags the catalog conflict; it does not silently reconcile them into a universal Jaguar meaning. The summary provides no signal-voltage specification or component replacement instruction.

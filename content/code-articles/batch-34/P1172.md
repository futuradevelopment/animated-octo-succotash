# P1172: Jaguar AJ16 rich combustion across both cylinder groups

P1172 reports combustion that is too rich across all cylinders in the 1995 Jaguar AJ16 diagnostic summary. Its scope is broader than the individual cylinder-group rich codes listed beside it.

## Why the all-cylinder scope matters

Jaguar's possible causes include excessive fuel pressure from a regulator problem, a restricted return pipe, leaking injectors and an airflow signal biased high. For a naturally aspirated engine, the table also calls out an incorrect airflow sensor. These are alternatives to investigate, not a ranking of common failures.

The shared-cylinder description makes evidence affecting the whole engine especially useful. For example, establishing the correct airflow sensor specification and evaluating measured fuel delivery can separate an input error from a fuel-system problem. That is a diagnostic interpretation of the listed causes, not proof of which component failed.

## Conditions for evaluating recurrence

The summary describes a warm engine and sustained running above 20 mph for more than 25 seconds, with two consecutive qualifying trips before the check-engine warning. A brief cold idle after clearing memory does not reproduce that documented condition.

Fuel-pressure and leakage evaluation require suitable professional equipment and the applicable workshop procedure. This code alone does not identify a leaking injector or justify replacing oxygen sensors. The explanation applies to the cited AJ16 system, not every manufacturer's use of P1172.

# P1566: Jaguar S-TYPE cruise-command switch input low

P1566 describes a low, out-of-range cruise-control command input from the steering-wheel switches in Jaguar's 2000 S-TYPE summary. The row concerns the command signal reaching the PCM.

## An input fault can disable cruise operation

Jaguar lists open or resistive switch-to-PCM wiring, a short to ground, switch failure and accelerator-pedal sensor failure. Including the pedal sensor makes this broader than a guaranteed steering-wheel switch replacement. The correct diagnosis needs evidence linking the low input to the relevant circuit or component.

The PCM response is to inhibit speed control. That helps distinguish loss of cruise operation as a consequence of this recorded fault from a separate failure of the system to maintain speed after valid engagement.

## The switches must be exercised for the documented check

The listed monitoring condition involves operating all cruise-control steering-wheel switches during a drive. Observing one button or one static input does not represent the complete check described by the source. The row does not list check-engine activation.

Apply this information only to the documented 2000 S-TYPE powertrain scope, which the compilation bounds by VIN. Steering-wheel circuit work requires the applicable professional procedure because of nearby restraint components. The summary provides no resistance ladder, airbag access steps or universal switch voltage specification.

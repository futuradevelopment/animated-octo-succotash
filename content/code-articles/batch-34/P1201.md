# P1201: Jaguar AJ16 cylinder-one injector fault after shutdown

P1201 identifies an open or short circuit for the number-one fuel injector in Jaguar's 1995 AJ16 diagnostic summary. Its monitoring condition includes a shutdown interval, which distinguishes it from the neighboring running-engine injector code.

## Two codes can observe the same circuit differently

The P1201 row describes running the engine and then leaving the ignition off for more than two seconds. P0201, by contrast, is listed with the engine running for over two seconds. Seeing one code without the other therefore does not automatically make the recorded fault contradictory; the observation windows differ.

Jaguar directs P1201 to the P0201 cause list: a disconnected injector, open or shorted injector harness wiring, or injector failure. This is electrical evidence. It does not establish whether an injector nozzle is blocked or whether the cylinder has a separate mechanical problem.

## Preserve cylinder identity

The “1” in this entry identifies cylinder one, rather than bank one or the first injector a technician happens to reach. Use the applicable cylinder identification and circuit diagram before testing.

The summary lists two consecutive qualifying trips for the warning. Confirmation should account for the documented shutdown condition, rather than only observing a short idle. Professional injector-circuit evaluation should precede parts replacement; the code alone does not justify opening the fuel rail.

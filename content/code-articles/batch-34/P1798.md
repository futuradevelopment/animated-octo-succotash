# P1798: Jaguar transmission missing the instrument-pack CAN message

P1798 identifies a missing instrument-pack CAN message in Jaguar's 1997 5 HP 24 transmission summary. Its expected behavior differs from the neighboring missing-ECM-message fault.

## No automatic fourth-gear conclusion

Jaguar lists no check-engine activation, other warning or default action for P1798. P1797, by contrast, includes a fourth-gear fallback and engine-power limitation. Assigning that response to P1798 simply because both are CAN faults would misread the source.

The possible causes include CAN-related faults in other modules, an open instrument-pack-to-TCM connection, a CAN short, instrument-pack failure and TCM failure. The missing message identifies the communication relationship but does not isolate the defective endpoint.

## A quiet fault still has diagnostic content

The monitoring condition is ignition on. Absence of a listed warning does not make a recorded communication fault meaningless, and it does not establish that every instrument display or transmission function is normal when additional faults are present.

Professional diagnosis should preserve the exact reporting module and compare the other network records before narrowing the cause. Use the appropriate 5 HP 24 network information rather than the same-code definition from another Jaguar transmission. The summary supplies no bus measurement specification, instrument-pack replacement instruction or basis for diagnosing a mechanical gearbox defect from P1798 alone.

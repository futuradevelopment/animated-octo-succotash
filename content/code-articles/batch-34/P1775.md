# P1775: Jaguar transmission request for the check-engine warning

P1775 records a transmission-controller request for the check-engine warning in Jaguar's 1995 AJ16 engine-management summary. It is a notification of a transmission fault, not the underlying fault's complete diagnosis.

## Read the transmission controller

Jaguar explicitly directs the reader to the TCM's recorded codes. The ZF transmission introduction explains that emissions-related transmission faults can activate the engine warning and store P1775 in engine-controller memory. An engine-only scan can therefore reveal the request while omitting the code that explains why it was made.

The engine-management row lists ignition on and a one-trip warning entry. Those details should not be confused with the monitoring conditions for the original transmission fault, which may require driving or other specific conditions.

## Avoid a parts decision from the request alone

P1775 does not identify a shift solenoid, sensor, fluid condition or mechanical failure. Replacing a component from this code alone would skip the diagnostic information the manufacturer tells the reader to retrieve.

Preserve both module records and establish which TCM fault requested the warning. Professional diagnosis then follows that fault's applicable procedure. Clearing only the engine-controller request is not evidence that the transmission fault has been corrected. This explanation is bounded to the documented Jaguar systems and should not be transferred to another manufacturer's definition of P1775.

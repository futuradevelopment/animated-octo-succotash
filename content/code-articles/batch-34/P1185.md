# P1185: Jaguar AJ16 upstream oxygen-heater open-circuit fault

P1185 concerns the heater circuits for both upstream oxygen sensors in Jaguar's 1996–1997 AJ16 diagnostic summary. It is a heater fault, which should be separated from the sensors' exhaust-mixture signal circuits.

## An open-circuit label has several causes

Jaguar includes excessive heater resistance and harness resistance, an open harness path and a harness short to ground. Consequently, the description is the controller's fault classification; it is not a direct measurement proving one particular wire is broken.

Because the row names both upstream sensors, keep the diagnosis focused on the upstream heater system and its wiring. Replacing a downstream sensor based only on an abbreviated scanner description would address the wrong group. The table does not establish that two sensors failed simultaneously or provide a universal resistance specification.

## Monitoring and confirmation

The documented operating condition is idle below 1,000 rpm for more than three minutes and twenty seconds. Two consecutive qualifying trips are listed before the check-engine warning. That relatively long idle window explains why an immediate restart may not settle whether the fault remains.

Use the correct wiring information to distinguish supply, control and heater-element defects. Record associated heater codes and the actual circuit findings before selecting a repair. This explanation is bounded to the AJ16 summary; it is not an electrical test procedure for later Jaguar oxygen-sensor systems.

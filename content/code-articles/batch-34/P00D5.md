# P00D5: Volkswagen CJAA oxygen-sensor offset correlation

P00D5 identifies an offset-adaptation disagreement involving oxygen sensors one and two in Volkswagen's 2014 CJAA chart. It is a relationship between sensor information rather than a simple high- or low-voltage fault in one named wire.

## The threshold describes a difference

Volkswagen lists an air-fuel-ratio offset exceeding 0.05 as the malfunction criterion. The value is dimensionless in the chart. It should not be converted into volts, a percentage fuel trim or a universal acceptable exhaust mixture.

Because two sensors are involved, the code alone does not identify which signal is inaccurate. A comparison can become inconsistent without telling the technician which participant should be replaced. That is a logical limitation of a correlation monitor, not a manufacturer claim that both sensors have failed.

## Preserve the adaptation context

The source calls this an offset-adaptation check. It is distinct from the adjacent heater-performance rows, which assess sensor heating. A heater code and P00D5 may provide different kinds of evidence even though they involve oxygen sensors.

Use the exact CJAA diagnostic information to review sensor data and the relevant adaptation conditions. The quick-reference book supplies no fault-duration requirement, parts test or reset procedure for this row. Do not treat erasing learned information as proof that the underlying disagreement has been corrected.

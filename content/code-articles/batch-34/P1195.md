# P1195: Jaguar downstream heater classification and installation checks

P1195 is a downstream oxygen-heater low-resistance classification in Jaguar's 1996–1997 AJ16 summary. Jaguar refers its possible causes to P1189, making the referenced row essential to interpreting the code.

## The label is less precise than a resistance measurement

The referenced list includes a loose oxygen sensor, heater shorts to ground or battery voltage, excessive resistance or an open heater circuit, and heater failure. The published high-resistance possibilities coexist with the low-resistance heading. This article preserves that limitation instead of inventing an ohm threshold or correcting the table without evidence.

The installation-related entry also means that diagnosis should not be confined to the sensor's electrical connector. However, the code itself does not establish which installation or circuit condition is present.

## Keep the downstream scope

P1189 concerns upstream heaters; P1195 transfers the diagnostic possibilities to the downstream pair. That distinction should remain visible in the repair record even if a scanner gives both codes similar descriptions.

The monitoring condition is idle for more than 25 seconds, with two consecutive qualifying trips before the check-engine warning. Obtain the applicable AJ16 workshop specifications for any further tests. A code classification alone cannot establish that both downstream heaters have failed or that replacing them will address the recorded event.

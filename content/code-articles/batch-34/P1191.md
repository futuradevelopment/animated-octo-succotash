# P1191: Jaguar downstream oxygen-heater open-circuit fault

P1191 concerns both downstream oxygen-sensor heater circuits in Jaguar's 1996–1997 AJ16 summary. Jaguar directs the reader to the P1185 cause list, while retaining the downstream sensor location for this code.

## Follow the reference without changing the location

The referenced possibilities are excessive heater resistance, resistive or open harness wiring, and a harness short to ground. That cross-reference gives electrical context; it does not turn P1191 into an upstream-sensor diagnosis.

The distinction matters when a scan tool shortens the description to “oxygen heater open.” Before interpreting test results, identify which sensor group the recorded code represents and use the matching wiring information. A functioning upstream heater does not establish that the downstream heater path is intact.

## What counts as a meaningful recheck

Jaguar lists idle below 1,000 rpm for more than three minutes and twenty seconds as the monitoring condition. The check-engine warning requires two consecutive qualifying trips in the summary. An immediate restart or a brief idle after a repair does not cover that documented interval.

The source does not provide a resistance limit or prove simultaneous failure of both downstream sensor assemblies. Distinguish the wiring, supply/control path and heater elements using the applicable workshop procedure. This explanation is limited to the historical AJ16 system and should not be transferred to later sensor-control designs.

# P1187: Jaguar upstream heater fault with temperature-related possibilities

P1187 is an upstream oxygen-sensor heater open-circuit classification in Jaguar's 1995 AJ16 summary. Its cause list extends beyond a disconnected heater, which is a useful distinction when interpreting this code.

## Why the electrical label is not the whole diagnosis

The table includes excessive resistance in both heaters, resistive or open harness wiring, and an airflow-sensor signal fault. It also includes an ignition fault in which retarded ignition raises exhaust-gas temperature. Jaguar therefore allows conditions affecting the inferred heater behavior as well as straightforward electrical interruptions.

An apparently intact heater connection does not eliminate every listed possibility. Conversely, evidence of an airflow or ignition problem does not prove that the heater wiring is sound. The useful next distinction is between a measured circuit defect and an operating condition that can distort the monitor's assessment.

## Keep the sensor group and timing straight

P1187 names both upstream sensors. The downstream counterpart P1193 points back to this row's possible causes, so the sensor group must be retained when reading scanner abbreviations.

The documented monitor condition is idle below 1,000 rpm for more than three minutes and twenty seconds; the warning takes two consecutive qualifying trips. This summary supports that bounded explanation, but supplies no universal heater-resistance limit and does not identify a failed part without further testing.

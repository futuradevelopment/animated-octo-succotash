# P1697: Jaguar adaptive-cruise headway-switch fault

P1697 identifies a malfunction in the adaptive speed-control headway-switch circuit in Jaguar's 2000 AJ27 summary. The headway command is the selected following-distance input, distinct from the network communication fault represented by P1696.

## The source points to the command switch

Jaguar lists adaptive speed-control switch failure as the possible cause. It does not identify a radar sensor, specify a short-to-ground condition or provide a resistance ladder. Those extra conclusions should not be added simply because the broader system controls following distance.

The table describes ignition on for more than one minute as the monitor condition. That is longer than the five-second communication-monitor interval listed for P1696. A quick key cycle does not cover the full condition stated for this input fault.

## Cruise inhibition does not distinguish every cause

The ECM inhibits cruise when P1697 is detected and the row associates an amber warning/message, without a check-engine warning. Loss of cruise operation can therefore be the response to invalid switch information; it does not establish a separate cruise actuator failure.

Professional diagnosis should confirm the fitted adaptive system and evaluate the correct switch input using its workshop specifications. The summary gives useful fault identity and timing but no adjustment, bypass or replacement procedure. Preserve that scope when interpreting a scanner's generic distance-control description.

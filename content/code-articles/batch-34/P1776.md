# P1776: Jaguar transmission torque-reduction request lasts too long

P1776 identifies a duration fault in the transmission's torque-reduction request in Jaguar's 1995 AJ16 engine-management summary. It concerns how long a request persists, rather than an automatically proven broken signal wire.

## The source includes operating demands

Jaguar lists rapid repeated shift demands that require torque reduction when that reduction may not be possible. It also lists a possible TCM fault in which the request lasts too long. The first entry means the diagnostic context includes the sequence of shift demands, not just the electrical condition of a single wire.

That does not establish driver fault on a particular vehicle. The code and the table alone cannot determine whether unusual demands or a controller problem caused the event. Recorded operating context is needed to distinguish the alternatives.

## Separate duration from circuit integrity

The neighboring P1777 row describes torque-reduction circuit malfunction and lists open or shorted wiring. P1776 should not inherit that electrical diagnosis without evidence.

The monitor condition involves driving so automatic gear changes occur, with a one-trip check-engine entry. Professional evaluation should review the shift sequence and the relevant TCM information before selecting a repair. The summary supplies no maximum request time, no transmission adjustment and no reason to force repeated harsh shifts merely to reproduce the complaint.

# P1363: Jaguar AJ16 cylinder-three ignition primary circuit

P1363 identifies a primary ignition-circuit malfunction for cylinder three in Jaguar's 1995 AJ16 summary. It is more specific than a general misfire code, but it still has more than one possible cause.

## The crank reference is part of the source's diagnosis

The row refers to P1361's causes: open or resistive ECM-to-coil primary wiring, a primary circuit shorted to ground, crankshaft-position sensor trouble and ignition-coil failure. Jaguar explicitly points to P0335 and P0336 for the crank-sensor possibilities.

That reference matters because coil activation depends on valid engine-position information. A coil-related code should not automatically trigger coil replacement when companion crank-sensor evidence points toward a shared timing input. Conversely, the reference is not proof that the crank sensor is defective.

## Different from the timing-specific entry

The neighboring P1373 describes incorrect spark timing for the same cylinder and has a narrower cause reference. Retain the exact code when evaluating what was detected rather than treating both as equivalent ignition failures.

Jaguar lists more than one second of engine operation and two consecutive qualifying trips for the warning. Use the correct AJ16 circuit specifications for further diagnosis. High-voltage ignition evaluation requires suitable professional equipment; this summary supplies no instruction to probe an operating ignition coil directly.

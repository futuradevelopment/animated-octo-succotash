# P2275: Volkswagen sensor-three stuck-rich response check

P2275 identifies a stuck-rich oxygen-sensor signal for bank one, sensor three in Volkswagen's 2014 CBTA/CBUA chart. The row includes a steady-response criterion and an alternative check following fuel cutoff.

## Fuel cutoff provides different evidence

One listed condition concerns a rear signal that does not oscillate above the 0.64–0.65-volt reference, with a 15-percent enrichment-related entry. The alternative describes sensor voltage remaining at least 0.15 volts after accumulated oxygen mass following fuel cutoff exceeds 3,500 milligrams, with at least one check.

The second condition matters because it evaluates the signal after a defined exhaust event, not simply while the engine happens to show a rich reading. A static voltage snapshot cannot substitute for that history.

## Limits of the quick reference

The row does not fully explain the control sequence or establish which physical cause holds the signal rich. It also does not prove that the fuel system is over-delivering continuously. Preserve the observed sensor behavior separately from a diagnosis of actual mixture.

Professional evaluation should use the correct sensor-three circuit and complete monitor procedure. The neighboring sensor-two code uses different reference information. Do not merge their values or infer a sensor replacement from P2275 without confirming the relevant response and operating context.

# P0684: Volkswagen CJAA glow-controller communication fault

P0684 concerns communication between the glow-control unit and engine management in Volkswagen's 2014 CJAA chart. The row describes missing communication or an error message from the automatic glow-time controller.

## A communication record is different from a failed plug

The neighboring entries identify individual glow-plug circuits using current or resistance criteria. P0684 instead concerns information exchanged with the controlling module. Replacing a numbered glow plug from this code alone would skip the communication problem actually described by the source.

The two listed indications are also worth keeping separate. A missing message and a controller-reported error are not necessarily the same electrical event. The generic code string does not establish which detailed condition the vehicle recorded.

## Use the module context

Professional diagnosis should retain the full engine-controller fault information and determine whether the glow-control unit communicates and what additional information it reports. That is a logical next distinction from the source's two alternatives, not a manufacturer-specified pin test.

The quick-reference book provides no network protocol, connector layout, timeout duration or module replacement instruction for this row. It does not prove that the glow-control module itself is defective, nor does it establish the condition of every glow plug. Apply this explanation only to the documented CJAA chart and use the complete vehicle procedure to resolve the communication fault.

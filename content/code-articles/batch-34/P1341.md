# P1341: Jaguar XK bank-two camshaft signal range or performance

P1341 identifies a bank-two camshaft-position sensor range or performance fault in Jaguar's 2003 XK diagnostic summary. The source distinguishes the sensing circuit from the physical conditions at the sensor face.

## Signal quality has electrical and mechanical contributors

Jaguar lists disconnection, an incorrect sensor gap, foreign material on the sensor face, an open sensing circuit, shorts to ground or higher voltage, and sensor failure. A range/performance description therefore does not establish that the sensor electronics are defective. Installation and the signal path can also prevent usable information from reaching the controller.

The bank-two identity must remain attached to the diagnosis. A camshaft code elsewhere on the engine is not evidence that this particular circuit has been tested correctly.

## The summary's verification context

The row describes a start-and-stop sequence repeated three times, followed by a minute of idle, and lists two qualifying trips for the warning. It lists no separate default action. These details do not amount to a guarantee that every vehicle will start or run normally.

Use the exact XK workshop specifications before evaluating sensor clearance or electrical measurements. The source does not provide a numerical gap or a universal waveform. Preserve that limitation instead of substituting specifications from a different Jaguar engine.

# P240C: Volkswagen leak-detection pump heater high-current classification

P240C identifies the high classification for the leak-detection pump heater-control circuit in Volkswagen's 2014 CBTA/CBUA chart. The manufacturer's detailed criterion uses current rather than a high-voltage reading.

## “High” does not mean every test should measure voltage

Volkswagen lists signal current above a threshold range of 2.2–4 amperes. The exact threshold within that range is not assigned to an individual calibration in the quick-reference row. Preserve both the measurement type and that limitation when interpreting data.

The nearby P240B heater fault uses a low-voltage criterion, while P240A uses a different voltage-based classification. The heater-code family therefore cannot be reduced to one interchangeable voltage test.

## Keep the heater separate from the pump

P240C concerns the heater circuit. Other codes on the page identify the leak-detection pump motor control. A heater-current event does not directly establish a motor fault or the existence of a fuel-vapor leak.

Professional diagnosis should use the correct heater path and current-test method from the full workshop procedure. The summary supplies no safe external energizing instruction, normal heater resistance or failed-part conclusion. It supports the recorded high-current classification while leaving the cause and appropriate repair to configuration-specific testing.

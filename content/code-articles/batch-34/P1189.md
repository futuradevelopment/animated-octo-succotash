# P1189: Jaguar upstream heater low-resistance classification

P1189 is labeled a low-resistance fault for both upstream oxygen-sensor heaters in the 1996–1997 Jaguar AJ16 summary. Its listed causes are broader than that short label might suggest.

## Read the cause list before choosing a part

Jaguar includes a loose oxygen sensor, heater circuitry shorted to ground or battery voltage, excessive heater resistance or an open circuit, and heater failure. The coexistence of low-resistance wording with high-resistance possibilities is a limitation of the published summary. It should not be silently rewritten into a precise resistance test that the source does not provide.

The useful conclusion is that both the installation and the electrical heater path need evaluation. The code does not establish a specific resistance value, a single failed sensor or a requirement to replace both upstream sensors.

## Distinguish it from P1190

The neighboring P1190 row explicitly includes excessive battery voltage and a different set of electrical possibilities. That distinction matters even if a scanner displays nearly identical descriptions for both codes.

For P1189, the stated operating condition is idle lasting more than 25 seconds, with two consecutive qualifying trips for the warning. Confirm the exact AJ16 application and obtain the relevant workshop tests before interpreting a measured value. Treat the table's broad classification as a starting point for diagnosis, not as a completed diagnosis.

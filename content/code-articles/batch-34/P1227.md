# P1227: Jaguar mechanical-guard sensor low input

P1227 is the low-voltage mechanical-guard sensor fault in Jaguar's 1997 AJ26 engine-management summary. Its diagnostic direction differs from the broader mechanical-guard performance fault.

## A low signal can follow an interrupted path

The listed causes are open or resistive sensor-to-ECM wiring, a sensor supply fault and sensor failure. The source therefore does not support treating “low” as proof of a short to ground. An interrupted supply or signal can also produce the controller's low-input classification.

The neighboring P1226 includes a seized actuator or broken spring, while P1227's row concentrates on the electrical sensing path. Keep that distinction when deciding which evidence a particular code actually provides. Mechanical concerns may still require assessment, but they should not be invented as this row's stated diagnosis.

## Warning behavior helps interpret symptoms

Jaguar lists ignition on for more than five seconds as the monitoring condition. When the first-trip amber warning occurs, cruise control is inhibited; the check-engine entry requires two trips. Consequently, disabled cruise operation can be an expected response to the guard-sensor fault.

Use the exact AJ26 circuit diagram and sensor specifications to evaluate the supply and signal. This summary contains no universal voltage threshold or authorization to bypass the mechanical guard. The code identifies a low-input condition, not a confirmed failed assembly.

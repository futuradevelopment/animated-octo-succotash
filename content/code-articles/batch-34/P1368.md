# P1368: Jaguar V12 B-bank ignition monitoring fault

P1368 is the B-bank ignition-monitor fault in Jaguar's V12 Nippondenso summary. It is a bank-level monitoring result rather than a diagnosis of one numbered cylinder.

## What Jaguar's reference includes

The row directs the reader to P1367's possible causes: a disconnected ignition module, open or shorted module-to-ECM wiring, ignition-coil failure, coil-relay failure and ignition-module failure. The electrical shorts can involve ground or battery voltage.

For P1368, those mechanisms must be evaluated on the B-bank system. The reference to the A-bank row shares diagnostic logic without changing the affected bank. This matters when a generic scanner displays only “ignition system group two.”

## The relay is a separate possibility

Because Jaguar includes the coil relay as well as the coil and module, missing ignition activity does not automatically prove either electronic component is defective. Supply/control evidence and the feedback path can lead to different conclusions.

The source describes idling after more than ten seconds of engine operation and a one-trip warning entry. These details apply to the documented V12 system; AJ26 and AJ27 uses of the same code need their own rows. High-voltage ignition testing requires appropriate professional procedures, and the summary does not authorize probing live ignition outputs or replacing every component named.

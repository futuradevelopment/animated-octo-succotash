# P014D: Volkswagen CJAA lean-to-rich response timing

P014D identifies a lean-to-rich oxygen-sensor response problem for bank one, sensor one in Volkswagen's 2014 CJAA chart. The detailed criterion compares oxygen signals on opposite sides of the NOx trap.

## Relative timing matters

The source describes one case where the first sensor responds later than the second by more than 1.5 seconds. It also describes the reverse timing relationship with a 0.45–0.72-second limit dependent on exhaust mass flow. These are separate directional comparisons, not one fixed delay that can be applied regardless of flow.

This explains why the generic “slow sensor one” title is not a complete test procedure. A comparison depends on both signals and their operating context. The code cannot independently prove which sensor or exhaust-system condition produced the mismatch.

## Preserve the CJAA scope

The neighboring sensor-two slow-response entry uses related comparative language. Do not substitute a universal oxygen-sensor switching specification or a different engine's voltage threshold for this timing monitor.

Professional diagnosis should review the relevant response data under the correct service conditions. The quick-reference row supplies no sensor replacement instruction or complete monitor-enabling criteria. It supports a timing-based explanation, while leaving the cause unresolved until the actual signal relationship and exhaust-flow context are evaluated.

# P0042: Volkswagen CBUA sensor-three heater circuit monitor

P0042 concerns the bank-one, sensor-three oxygen-sensor heater circuit in Volkswagen's 2014 CBUA chart. The manufacturer explicitly restricts this row to CBUA, even though the surrounding section covers both CBTA and CBUA engines.

## A heater diagnostic value is not a mixture reading

The table places a heater-voltage band of 2.34–3.59 volts in the malfunction-criteria column. That is a diagnostic observation for this circuit, not a target exhaust-mixture signal or a universal heater supply specification.

The neighboring P0043 and P0044 rows classify the same heater circuit below and above that band. Keeping those entries separate helps retain the controller's electrical classification. P0042 is not a direct diagnosis that the sensor's exhaust-gas measurement has become inaccurate.

## Application and limits

Other sections of the same book contain different heater values and inconsistent sensor numbering, so this explanation deliberately uses the clearly labeled CBUA-only rows. Do not combine their thresholds with a different engine chart.

Professional diagnosis should identify the actual sensor-three heater circuit and apply the vehicle's full electrical test procedure. The quick-reference table provides no connector pinout, current command, enabling conditions or replacement decision. It supports a bounded circuit-monitor explanation; it does not establish which wire, heater element or controller component caused the recorded event.

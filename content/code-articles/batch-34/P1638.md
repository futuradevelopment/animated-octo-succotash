# P1638: Jaguar AJ26 missing instrument-cluster CAN message

P1638 means the expected instrument-cluster CAN message is missing in Jaguar's 1997 AJ26 engine-management summary. It identifies a communication relationship between the instrument pack and ECM.

## Display data can disappear without a sensor diagnosis

The source notes that engine-speed and coolant-temperature data are missing at the instrument pack in this condition. That does not establish that the crankshaft or coolant-temperature sensor itself failed. The information can become unavailable because the communication path is interrupted.

Jaguar lists an open CAN connection between the instrument pack and ECM, a CAN short, instrument-pack failure and ECM failure. The code alone cannot distinguish a network-path defect from a failed endpoint.

## A missing endpoint differs from a general bus fault

The neighboring P1642 row describes a broader CAN malfunction with all CAN data unavailable and cruise inhibition. P1638 should not automatically inherit that complete network-failure interpretation; its row names the instrument message specifically and lists no separate default action.

The monitor condition is ignition on for more than five seconds, with a one-trip check-engine entry. Use the correct network diagram and companion module records to establish the fault scope. The summary provides no terminating-resistance target or wiring-probe procedure, and it does not justify replacing the instrument pack solely from this code.

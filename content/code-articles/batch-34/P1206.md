# P1206: Jaguar AJ16 cylinder-six injector fault and companion codes

P1206 concerns an open or short circuit for injector six in Jaguar's 1995 AJ16 diagnostic summary. It supplies a circuit-specific lead that should be kept separate from a general cylinder-six combustion diagnosis.

## Use companion evidence carefully

The injector cause list includes disconnection, harness opens or shorts and injector failure. The misfire summary separately notes that injector-circuit faults can accompany misfire codes, while also listing mechanical, ignition and fuel-quality causes for misfire. A companion misfire can therefore help connect the event to a cylinder, but it does not prove every misfire is caused by this injector.

P1206 retains cylinder six even though its cause list references P0201. Shared diagnostic references are not instructions to test the first cylinder instead.

## Why a shutdown check matters

Jaguar's listed condition is running the engine and then leaving the ignition off for longer than two seconds. It assigns two consecutive qualifying trips to the warning. A check made only with the engine running does not cover the complete condition described for this fault.

Determine whether the wiring or injector is electrically defective using the appropriate AJ16 workshop information. The table provides no universal resistance, connector pinout or fuel-rail procedure. Treat the code as evidence requiring confirmation, rather than a request to replace injector six automatically.

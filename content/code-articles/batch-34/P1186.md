# P1186: Jaguar AJ16 upstream oxygen-heater short-circuit diagnosis

P1186 identifies a short-circuit fault affecting both upstream oxygen-sensor heater circuits in the 1996–1997 Jaguar AJ16 summary. The source points to electrical coupling, not an exhaust-mixture problem.

## Which short matters

The possible causes include a heater circuit shorted to the sensor and heater harness wiring shorted to battery-positive voltage. These are different fault paths. One can involve interaction within the sensor assembly; the other can involve the external wiring. A mixture reading by itself cannot distinguish them.

The upstream designation is also essential. Jaguar separately assigns P1192 to the downstream heater group and refers that row back to the same kinds of causes. Similar electrical logic does not make the two sensor locations interchangeable.

## A useful verification window

The table describes idling below 1,000 rpm for over three minutes and twenty seconds, with two consecutive qualifying trips before the warning. A quick key cycle is therefore a weak basis for calling the problem resolved.

Professional diagnosis should establish the affected heater circuit's connection to supply and to the sensor signal circuitry using the exact vehicle diagram. The summary gives no permission to apply battery voltage directly to a sensor. It also does not establish that both upstream sensor assemblies need replacement simply because their heater group appears in the code description.

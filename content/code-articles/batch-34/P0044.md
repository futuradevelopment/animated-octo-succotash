# P0044: Volkswagen CBUA sensor-three heater voltage high

P0044 identifies the high-voltage condition for the bank-one, sensor-three heater circuit in Volkswagen's 2014 CBUA chart. The row's malfunction criterion is heater voltage above 3.59 volts.

## High heater voltage is a circuit classification

The number belongs to the heater-control monitor. It is not an oxygen-content reading, a rich-mixture threshold or a voltage that should be supplied externally during testing. A scan tool's short “O2 high” label can conceal that important distinction.

Volkswagen places this row next to P0043's low-voltage classification and P0042's separate heater-circuit band. The source therefore supports distinguishing which electrical condition was recorded, while leaving the root cause to the full diagnostic procedure.

## Use the explicitly limited row

The table marks sensor-three heater codes CBUA only within the CBTA/CBUA section. Earlier engine charts in the same book show different values and some inconsistent sensor wording. Those entries should not be mixed into this CBUA explanation.

Professional diagnosis should confirm the fitted engine, the actual third-sensor heater wiring and the applicable test conditions. The summary does not specify a failed sensor, a shorted wire location or a controller replacement. It also does not state whether the high condition was persistent or intermittent, so preserve the original fault information before clearing memory.

# P1696: Jaguar AJ27 adaptive-cruise CAN communication fault

P1696 identifies an adaptive speed-control CAN malfunction in Jaguar's 2000 AJ27 summary. The communication path includes the adaptive speed-control module, its booster control module and the ECM.

## More than one endpoint can be involved

Jaguar lists open CAN connections between those modules, a CAN short, and failure of either adaptive speed-control module. The code does not identify which endpoint or wire is responsible. A diagnosis focused only on the engine controller would overlook the specific module relationships named by the source.

The distinction from P1697 is also useful. P1697 concerns the headway-switch input, while P1696 concerns communication. Both can inhibit cruise operation, so that shared symptom does not make their diagnostic paths interchangeable.

## Documented response

The listed monitor condition is ignition on for more than five seconds. Jaguar inhibits cruise control when the fault is detected and associates an amber warning/message, without check-engine activation for this row.

Confirm that the vehicle has the documented adaptive system and use the relevant network information and companion module faults to narrow the cause. The summary does not supply a distance-sensor calibration, a bus-test value or a module replacement procedure. Do not infer a radar or brake-booster hardware failure merely from the names of modules participating in the network.

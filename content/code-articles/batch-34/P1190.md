# P1190: Jaguar upstream heater fault and excessive system voltage

P1190 identifies a low-resistance classification for both upstream oxygen-sensor heaters in Jaguar's 1995 AJ16 summary. One listed cause makes the vehicle's electrical supply particularly relevant.

## The source includes overvoltage

Jaguar explicitly lists battery voltage above 17 volts producing excessive heater current. It also includes an ECM-to-heater wire shorted to battery voltage, heater circuits shorted to ground and failure of both heaters. The 17-volt figure is a documented possible-cause condition, not a general charging-system target or a complete fault-setting threshold.

This distinction can prevent a misleading parts decision. Excessive heater current can arise because of the supply or wiring, so a heater-related code does not automatically prove that an oxygen sensor is internally defective. Establishing actual system voltage is relevant before interpreting the heater circuit in isolation.

## Timing and sensor position

The monitor condition is idle for more than 25 seconds. Two consecutive qualifying trips are listed before the check-engine warning. This row names the upstream heater pair; P1196 is the downstream counterpart that refers back to these causes.

Use the correct AJ16 electrical information for further checks. The summary does not supply a universal heater resistance or authorize energizing sensor circuits directly. Resolving an identified supply fault and then evaluating heater operation is more informative than assuming the code itself names a replacement part.

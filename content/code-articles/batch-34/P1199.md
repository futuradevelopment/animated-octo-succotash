# P1199: Jaguar V12 low fuel-level signal versus the AJ16 definition

P1199 is a low-voltage or malfunctioning fuel-level sensing input in Jaguar's V12 Nippondenso diagnostic summary. Jaguar's AJ16 summary uses a broader circuit-malfunction description, so the engine-management system changes how this code should be interpreted.

## The V12 diagnostic direction

For the V12 row, Jaguar lists a sensing wire shorted to ground and fuel-level sensor failure. Monitoring is described with the ignition on for more than one minute, and the warning entry is one trip. An electrically low input should not be treated as proof that the tank is empty.

By comparison, the 1995 AJ16 row includes the instrument-pack-to-ECM signal path, possible instrument-pack trouble and open or shorted wiring. Its monitor starts with the engine running and lists two trips. Applying those conditions interchangeably would obscure a useful application difference.

## Resolve the system before the component

Identify the engine controller and confirm which manufacturer row applies before judging the sender or instrument pack. That matters particularly when a scanner supplies only “fuel level low.” The code describes an input fault, while actual fuel quantity is a separate question.

Use the relevant wiring and workshop specifications for diagnosis. This summary supplies no universal sender resistance or safe tank-disassembly procedure; any work involving fuel-system access requires appropriate professional precautions.

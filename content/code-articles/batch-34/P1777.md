# P1777: Jaguar transmission torque-reduction signal circuit

P1777 identifies a torque-reduction signal circuit malfunction in Jaguar's 1995 AJ16 summary. The circuit carries a transmission-related request used by engine management; the code does not directly identify an ignition coil fault.

## Invalid signal and excessive duration are different

Jaguar lists an open torque-reduction signal wire, shorts to ground or battery voltage, and a possible TCM fault producing an invalid signal. The neighboring P1776 concerns request duration and repeated shift demands. Keeping those definitions separate prevents a timing complaint from being treated automatically as a wiring break, or vice versa.

The phrase “ignition retard request” used in some catalogs describes the torque-management context. It should not redirect this diagnosis toward spark plugs or individual cylinder ignition components without supporting evidence.

## Conditions and interpretation

The source lists the engine running at normal operating temperature and two consecutive qualifying trips for the warning. It gives no universal signal voltage, pulse width or connector pinout.

Professional diagnosis should establish whether the request signal is electrically valid between the relevant controllers and consult the correct AJ16/automatic-transmission wiring. The code alone cannot choose between a wiring defect and a faulty TCM output. Preserve companion transmission information before clearing memory so the signal complaint can be related to the actual operating event.

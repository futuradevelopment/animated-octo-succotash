# P1797: Jaguar transmission missing the ECM CAN message

P1797 identifies a missing ECM CAN message at the transmission controller in Jaguar's 1997 5 HP 24 summary. It names a particular communication relationship rather than every form of network failure.

## Two endpoints and the path remain possible

Jaguar lists CAN-related faults in other modules, an open ECM-to-TCM network connection, a CAN short, ECM failure and TCM failure. The receiving controller's code therefore cannot determine which endpoint or wire caused the missing message.

The neighboring P1796 is the broader CAN circuit malfunction. P1797 specifically preserves the missing-engine-controller-message identity, which can help organize companion fault evidence and avoid treating all communication codes as duplicates.

## Why transmission behavior may change

The listed monitor condition is ignition on. When the fault is detected, the source describes fourth-gear mechanical limp-home operation and engine-power limitation. The gearbox-fault indication is immediate; the check-engine entry is two qualifying trips.

These changes are documented protective responses to missing information, not independent proof that a clutch or gear has failed. Professional diagnosis should compare module communication records and the exact network diagram before selecting a repair. The summary does not provide a module programming solution, terminating-resistance value or permission to replace either controller merely because its name appears in the row.

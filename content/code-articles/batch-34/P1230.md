# P1230: Jaguar AJ26 fuel-pump relay control fault

P1230 identifies a fuel-pump relay malfunction in Jaguar's 1997 AJ26 summary. The code names the relay-control system and does not by itself establish that the fuel pump has failed.

## Separate control power from pump delivery

Jaguar lists relay failure, a relay-to-ECM circuit fault, an open relay-coil supply and an ECM ground-circuit fault in the relay-coil drive. These possibilities concern whether the relay can be controlled correctly. They are distinct from proving adequate pump pressure or fuel volume.

This distinction helps interpret a no-start or fuel-delivery complaint without assuming that the expensive component is the cause. The published row does not document those symptoms for every event, and the code alone cannot identify which portion of the control path is abnormal.

## What the summary supports

The listed monitor condition is ignition on for more than five seconds, with two trips in the check-engine column and no separate default action. The absence of a listed default does not certify that fuel delivery remains available; it merely describes this summary entry.

Use the exact AJ26 diagram and workshop procedure to evaluate the relay, its coil supply and the controller's drive path. Directly bridging relay terminals is not a diagnostic instruction supplied by this source. Any fuel-pressure work requires suitable professional equipment and fuel-system precautions.
